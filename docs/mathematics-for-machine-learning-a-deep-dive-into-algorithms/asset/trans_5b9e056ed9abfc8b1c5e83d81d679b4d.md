

## 7.3 KERNEL TRICK

核技巧是机器学习中的一个变革性概念，尤其在支持向量机（SVM）的语境下。它是一种数学技术，允许算法在更高维的特征空间中运行，而无需显式计算变换。这一巧妙的技巧使 SVM 能够在保持计算效率的同时处理数据点之间复杂的非线性关系。

### 动机

在许多现实场景中，数据在其原始特征空间中不是线性可分的。然而，它可能在更高维的空间中变得可分。挑战在于显式地将数据映射到该空间的计算成本，因为这涉及在潜在的高维域中计算坐标。核技巧优雅地解决了这个问题。

### 核函数

核技巧的核心是核函数。核函数计算变换空间中数据点之间的相似性或距离，而不需要显式计算该空间中的坐标。它有效地以简洁的方式封装了变换。

### 高维中的点积

核函数计算变换空间中数据点的点积。这使得 SVM 可以使用核值（点积）而不是显式变换，从而避免在更高维空间中进行繁重的计算。

### 常见核函数

- **线性核：** 线性核计算数据点之间的标准点积，相当于原始特征空间。它主要用于线性 SVM。
- **多项式核：** 多项式核将点积提升到指定的幂次，引入多项式项以捕捉非线性关系。
- **径向基函数（RBF）核：** RBF 核，也称为高斯核，根据数据点与参考点的相似性为其分配权重。它广泛用于非线性 SVM。
- **Sigmoid 核：** Sigmoid 核计算类似于 Sigmoid 曲线的函数。它通常用于神经网络和 SVM。

### 核技巧的优势

- **计算效率：** 通过避免显式变换，核技巧防止了维度爆炸，同时仍允许 SVM 在更高维空间中运行。
- **非线性：** 核技巧使像 SVM 这样的线性算法能够捕捉数据点之间复杂的非线性关系，使其更加多用途。

### 应用

- **在 SVM 中：** 核技巧通过有效地将数据转换到更高维空间（在该空间中可能实现线性分离），将线性 SVM 扩展到非线性分类。
- **在其他算法中：** 核技巧的应用不限于 SVM。它还用于其他算法的核化版本，例如核化主成分分析（PCA）和核化岭回归。

### 挑战

- **超参数调优：** 不同的核函数及其超参数会影响性能。正确选择和调优至关重要。
- **计算成本：** 尽管比显式变换更高效，但计算核值对于大型数据集来说仍可能具有挑战性。

总而言之，核技巧是一种精湛的技术，它使算法能够发挥更高维空间的力量，而无需承受显式变换的计算负担。在 SVM 中，它是解锁处理复杂非线性数据关系能力的关键，使其成为机器学习在多样数据集中捕捉复杂模式能力的基石。

## 7.4 间隔与松弛变量

在支持向量机（SVM）中，间隔和松弛变量的概念在定义类别之间的决策边界时，对于在精度和灵活性之间找到最佳平衡起着关键作用。它们允许 SVM 处理数据无法完全分离的情况，并引入软间隔的概念来容纳误分类的点。

### 间隔

SVM 中的间隔是决策边界（超平面）与两个类别中最近数据点之间的距离。最大化间隔是 SVM 的核心原则，因为它能带来对未见数据的更好泛化。更宽的间隔表明分类的置信度更高。

### 硬间隔 SVM

在硬间隔 SVM 中，目标是找到一个能以最大可能间隔完美分离类别的超平面。然而，硬间隔 SVM 对数据中的异常值和噪声敏感。如果单个数据点是异常值或错误，它可能会显著影响决策边界。

### 软间隔 SVM

为解决硬间隔 SVM 的局限性，软间隔 SVM 引入了松弛变量的概念。松弛变量允许训练数据中存在一定程度的误分类。目标变为在最大化间隔和最小化误分类错误之间进行权衡。

### 松弛变量

松弛变量（通常表示为 ξ、xi 等）被引入用于量化每个数据点允许的误分类程度或“松弛度”。它们表示误分类点与决策边界之间的距离。软间隔 SVM 中的优化问题涉及在仍然最大化间隔的同时最小化松弛变量之和。

### C 参数

参数 C 控制在最大化间隔和允许误分类之间的权衡。较小的 C 值强调更宽的间隔，即使某些点被误分类。较大的 C 允许更多点被误分类以实现更窄的间隔。

### 正则化与控制

C 参数在 SVM 中充当一种正则化形式。高 C 更强调精确分类，如果不仔细选择，可能导致过拟合。低 C 强调更广泛的间隔，使模型对异常值和噪声更具抵抗力。

### 松弛变量的影响

松弛变量为 SVM 提供了一定的灵活性，以容纳无法完美分离的数据。它们帮助 SVM 处理数据不完全线性可分的情况，同时仍力求获得有意义的间隔。

### 权衡与灵活性

松弛变量引入的平衡解决了模型复杂性（灵活性）与泛化（精度）之间的困境。通过允许受控数量的误分类，模型可以更好地泛化到未见数据。

### 应用

软间隔 SVM 在现实场景中有应用，在这些场景中数据可能不完全符合线性可分性。它们在处理噪声或重叠数据时特别有用。

总而言之，间隔和松弛变量的概念是支持向量机的核心组成部分，尤其是在数据不可线性分离的情况下。这些概念之间的相互作用使 SVM 能够在精度和灵活性之间取得平衡，从而能够处理各种复杂度和噪声水平的广泛分类任务。

### 8.1 感知机与激活函数

感知机和激活函数是神经网络的基本组成部分，构成了深度学习领域所依赖的复杂架构的基础模块。它们在转换输入数据、引入非线性以及使神经网络能够建模数据中复杂关系方面发挥着至关重要的作用。

### 感知机：神经网络的神经元

- 感知机是生物神经元的简化模型。它接收多个输入信号，对它们应用权重，并产生一个输出信号。
- 输入的加权和连同偏置项一起传递给激活函数以产生输出。
- 在数学上，感知机的输出可以表示为：输出 = 激活函数（加权和 + 偏置）

### 激活函数：引入非线性

- 激活函数为神经网络引入非线性，使其能够近似复杂函数。
- 没有非线性，神经网络将表现得像线性模型，严重限制其捕捉复杂模式的能力。
- 常见的激活函数包括：
- Sigmoid：将输入映射到 0 到 1 之间的范围，适用于二元分类。
- ReLU（修正线性单元）：对正值输出输入，对负值输出零，避免梯度消失。
- Tanh（双曲正切）：将输入映射到 -1 到 1 之间的范围，类似于 Sigmoid 但以零为中心。
- Softmax：用于输出层进行多类分类，将原始分数转换为概率分布。
