

**用例：** Softmax 回归用于多类场景，例如图像分类（识别图像中的对象）、情感分析（对文本情感进行分类）和手写识别。

**可解释性：** Softmax 回归中的系数能提供每个自变量如何影响每个类别可能性的洞察。

**优势：** Softmax 回归处理多类分类的方式与逻辑回归的概率解释保持一致。它为多类问题提供了一种强大且可解释的方法。

**假设：** Softmax 回归假设自变量与每个类别 logits 之间的关系是线性的，且误差是独立同分布的。

**扩展：** Softmax 回归可以通过深度学习和神经网络等技术进行扩展，以处理更复杂的数据和特征表示。

总而言之，Softmax 回归是一种处理多类分类问题的多功能技术。通过建模每个类别的概率并使用 softmax 函数，它为将实例分配到多个类别提供了一个概率框架。这种方法在处理复杂分类场景的同时，有助于保持可解释性，并与概率和逻辑回归的概念保持一致。

## 6.3 二元分类与多类分类

二元分类和多类分类是机器学习中两种基本的分类问题类型。虽然两者都涉及将实例分配到预定义的类别，但它们在类别数量和用于解决它们的技术方面有所不同。让我们来看看这两种场景的主要差异和特征：

### 二元分类：

- **类别数量：** 在二元分类中，恰好有两个类别或类别。示例包括垃圾邮件检测（垃圾邮件或非垃圾邮件）、医疗诊断（疾病存在或不存在）和情感分析（积极或消极情感）。

- **输出：** 二元分类模型的输出通常是单个概率分数或二元标签（0 或 1），指示每个实例的预测类别。

- **算法：** 常用于二元分类的算法包括逻辑回归、支持向量机（SVM）、决策树、随机森林和神经网络。

- **评估指标：** 二元分类的常见评估指标包括准确率、精确率、召回率（灵敏度）、F1 分数、ROC 曲线和 AUC。

- **一对其余（OvR）：** 某些算法，如 SVM 和 Softmax 回归，可以通过使用一对其余（OvR）方法来调整以处理多类问题。这涉及训练多个二元分类器，每个用于一个类别与其余类别的比较。

### 多类分类：

- **类别数量：** 在多类分类中，有三个或更多类别或类别。示例包括图像识别（识别图像中的对象）、语言识别（检测文本的语言）和音乐流派分类。

- **输出：** 多类分类模型的输出通常是所有类别上的概率分布，指示给定实例中每个类别的可能性。

- **算法：** 用于多类分类的算法包括 Softmax 回归、决策树、随机森林、k 近邻（k-NN）、朴素贝叶斯和神经网络。

- **评估指标：** 多类分类的评估指标包括准确率、精确率、召回率、F1 分数（可扩展到多类情况）、混淆矩阵以及 ROC 曲线和 AUC 的多类版本。

- **Softmax 回归：** Softmax 回归是专门为多类分类设计的算法。它将逻辑回归的概念扩展到处理多个类别，并预测每个类别的概率。

- **一对一（OvO）：** 处理多类问题的另一种方法是一对一（OvO），即为每对类别训练一个二元分类器。赢得最多二元比较的类别将被选为最终预测。

### 决策边界：

- 在二元分类中，决策边界是一条分隔两个类别的线或曲面。

- 在多类分类中，决策边界可能更复杂，涉及每个类别的多个区域。它取决于所使用的特定算法。

### 用例：

- 二元分类适用于问题涉及两个截然不同结果的场景。

- 多类分类用于需要将实例分配到多个截然不同的类别或类别的情况。

总而言之，二元分类和多类分类之间的区别在于类别的数量以及用于解决它们的技术。二元分类处理两个类别，而多类分类处理三个或更多类别。两者之间的选择取决于问题的性质和可用的数据。

## 6.4 评估指标

评估指标是机器学习中用于量化预测模型性能的重要工具。这些指标有助于评估模型的预测与实际结果的匹配程度，并提供关于模型优缺点的洞察。不同的任务类型（如分类、回归和聚类）使用不同的指标。让我们来探讨一些关键的评估指标及其重要性：

### 分类指标：

- **准确率：** 准确率衡量所有实例中被正确分类的实例所占的比例。它是一个简单直观的指标，但在类别不平衡时可能会产生误导。

- **精确率：** 精确率计算所有被预测为正例的实例中真正例预测（正确预测的正例实例）所占的比例。它强调正例预测的质量。

- **召回率（灵敏度）：** 召回率计算所有实际正例实例中真正例预测所占的比例。它强调识别正例实例的能力。

- **F1 分数：** F1 分数是精确率和召回率的调和平均数。它在精确率和召回率之间取得了平衡，在类别不平衡时特别有用。

- **特异度：** 特异度计算所有实际负例实例中真负例预测（正确预测的负例实例）所占的比例。

- **混淆矩阵：** 混淆矩阵是一个表格，显示真正例、真负例、假正例和假负例预测的计数。它是模型性能的可视化表示。

- **ROC 曲线：** ROC 曲线在各种阈值下将真正例率（召回率）与假正例率进行对比。它有助于可视化灵敏度和特异度之间的权衡。

- ROC 曲线下面积（AUC）：AUC 衡量 ROC 曲线下的面积。它提供一个单一数值来量化分类器的整体性能。

### 回归指标：

- **平均绝对误差（MAE）：** MAE 计算预测值与实际值之间的平均绝对差。它提供了对模型平均预测误差的概念。

- **平均平方误差（MSE）：** MSE 计算预测值与实际值之间的平均平方差。它对较大的误差惩罚更严重。

- **均方根误差（RMSE）：** RMSE 是 MSE 的平方根。它更具可解释性，并提供误差平均幅度的度量。

- **R 平方（决定系数）：** R 平方衡量模型解释的因变量方差所占的比例。它在 0 到 1 之间，值越高表示拟合越好。

### 聚类指标：

- **轮廓系数：** 轮廓系数衡量簇的紧凑度和分离度。它量化了同一簇内的实例彼此相似的程度，以及它们与其他簇中实例的不同程度。

- **惯性：** 惯性衡量实例与其簇的质心之间的平方距离之和。它提供了对簇紧凑程度的概念。

- **Davies-Bouldin 指数：** Davies-Bouldin 指数评估每个簇与其最相似簇之间的平均相似性，同时考虑它们质心之间的距离。

选择指标：评估指标的选择取决于问题类型、数据特征和分析的具体目标。选择与预期结果相一致并反映模型预测实际影响的指标非常重要。
