

总而言之，Lasso 回归是一种正则化技术，结合了线性回归和特征选择的优点。通过向代价函数引入绝对值惩罚项，Lasso 促进稀疏系数解，有效排除不那么相关的预测器，并提供更简单、更具可解释性的模型。

## 12.3 弹性网（Elastic Net）

弹性网（Elastic Net）是一种混合正则化技术，结合了岭回归（Ridge Regression）和 Lasso 回归的特点。它旨在通过在线性回归代价函数中同时引入 L2（岭）和 L1（lasso）惩罚项，来解决每种方法的局限性。这样一来，弹性网既能发挥两种正则化技术的优势，又能减轻各自的弱点。

在数据集存在高多重共线性且预测器数量较多的情况下，Lasso 回归可能难以发挥良好性能，因为它倾向于仅选择部分预测器而忽略其他预测器。此外，岭回归可能仍会保留许多相对较大的系数。弹性网旨在通过引入新参数 "l1_ratio" 来克服这些局限性，该参数控制 L1 和 L2 惩罚之间的平衡。

弹性网代价函数同时包含平方差之和（如标准线性回归中）、平方系数之和（如岭回归中）以及绝对系数之和（如 Lasso 回归中）。代价函数如下：

代价 = 平方差之和 + alpha * ((1 - l1_ratio) * 平方系数之和 + l1_ratio * 绝对系数之和)

在这里，"alpha" 控制正则化的整体强度，与岭回归和 Lasso 回归类似。"l1_ratio" 参数决定 L1 和 L2 惩罚之间的平衡。当 "l1_ratio" 设置为 1 时，弹性网本质上等同于 Lasso 回归。当 "l1_ratio" 设置为 0 时，它变得等同于岭回归。对于 0 和 1 之间的值，弹性网融合了两种方法的特性。

当数据集具有许多特征且其中一些高度相关时，弹性网特别有用。它像 Lasso 一样允许自动特征选择，但通过引入岭回归的惩罚项，它也可以处理多个相关特征应一起保留的情况。这种平衡使得弹性网在 Lasso 或岭回归单独使用可能无法发挥最佳性能的场景中更加通用和强健。

总而言之，弹性网是一种正则化技术，通过引入一个平衡两种方法各自惩罚的参数来结合岭回归和 Lasso 回归。这种平衡为处理线性回归模型中的多重共线性、特征选择和系数大小控制提供了一种灵活的方法。

## 12.4 选择正则化参数

选择适当的正则化参数（例如岭回归和 Lasso 回归中的 "alpha"，或弹性网中的 "alpha" 和 "l1_ratio"）是有效应用这些正则化技术的关键步骤。这些参数控制正则化强度以及不同惩罚项之间的平衡，影响模型的复杂度、偏差-方差权衡以及泛化性能。选择正则化参数的方法如下：

- 网格搜索或交叉验证：一种常见方法是在一系列潜在参数值上执行网格搜索。你可以创建 alpha 值的网格（以及弹性网的 l1_ratio），并使用交叉验证评估模型性能。交叉验证通过多次将数据集分为训练子集和验证子集，来帮助评估模型对新的、未见数据的泛化能力。
- 交叉验证分数：在网格搜索或交叉验证期间，监控不同参数组合在验证集上的性能指标，如均方误差（MSE）、根均方误差（RMSE）或平均绝对误差（MAE）。目标是找到在偏差和方差之间实现最佳权衡的参数值。
- 正则化路径：对于岭回归和 Lasso 回归，绘制正则化路径可能会有所帮助，它显示了随着正则化参数变化系数如何变化。这可以提供哪些系数被缩减到零以及模型正则化速度有多快的见解。
- L-曲线方法：对于岭回归，可以使用 L-曲线方法。它涉及将交叉验证误差与系数的 L2 范数进行绘图。当误差开始趋于平缓而系数的范数仍然相对较小时，该点可以指示 alpha 的良好选择。
- 信息准则：某些信息准则，如赤池信息准则（AIC）和贝叶斯信息准则（BIC），可以帮助选择正则化参数。这些准则在模型拟合度与模型复杂度之间取得平衡，可以引导你选择一个仍能捕捉数据中基本模式的更简单模型。
- **领域知识**：有时，领域知识可以为正则化参数的合理范围提供见解。例如，如果你知道大多数预测器可能都相关，你可能会倾向于较低的 alpha 值。
- **嵌套交叉验证**：为了更准确地估计模型的泛化性能，你可以使用嵌套交叉验证。在这种方法中，外层循环使用交叉验证执行模型评估，而内层循环执行网格搜索以选择最佳参数。这有助于防止在参数选择中使用的验证集上过拟合。
- **正则化路径稳定性**：对于弹性网，你还可以评估在交叉验证期间数据不同分割中所选特征的稳定性。在多个分割中始终出现的特征更可能是强健可靠的预测器。

请记住，最优参数值可能会根据特定数据集和你要解决的问题而有所不同。在模型复杂度和泛化性能之间取得平衡很重要。正则化参数应基于严格的评估技术来选择，而不应仅仅依赖直觉。

### 13.1 决策树构建

决策树是一种常用的机器学习算法，用于分类和回归任务。它们通过递归地将输入特征空间划分为尽可能相关于目标变量的同质子集来工作。决策树的构建涉及选择用于拆分的特征以及确定每个节点的拆分标准。决策树构建过程概述如下：

- **根节点**：初始步骤是选择最佳特征来拆分数据集。所选特征是基于某个标准（通常旨在最小化不纯度或最大化信息增益）最能分离数据的特征。
- **拆分标准**：所选拆分标准取决于任务类型。对于分类，常见标准包括基尼不纯度和熵，它们衡量一组标签中的无序或随机程度。对于回归，均方误差（MSE）是常见标准，用于量化子集内目标值的方差。
- **拆分过程**：一旦选择初始特征，数据集将根据该特征的可能值拆分为子集。每个子集对应从根节点延伸出的一个分支。然后该过程对每个子集递归重复。
- **停止标准**：递归继续，直到满足停止标准。停止标准可能包括达到树的最大深度、节点中的样本数最少，或达到不纯度减少的阈值。
- **叶节点**：当满足停止标准时，会创建称为叶节点的终端节点。这些节点代表分类或回归任务的最终预测。对于分类，叶节点中的多数类通常被选为预测类。对于回归，使用叶节点中样本的平均或中位数目标值作为预测值。
- **剪枝（可选）**：构建完整树后，可以应用剪枝来防止过拟合。剪枝涉及移除对改进验证数据上的模型性能贡献不大的分支。这会产生一棵更简单、更具泛化能力的树。
