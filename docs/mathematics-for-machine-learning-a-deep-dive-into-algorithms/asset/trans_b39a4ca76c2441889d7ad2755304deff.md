### 7.1 线性支持向量机

线性支持向量机（SVM）是机器学习领域（尤其是分类领域）中的基础算法。它在二元分类任务中表现出色，通过寻找最优超平面来最佳分离两类数据点，同时最大化它们之间的间隔。该技术建立在线性代数、优化和凸几何的原理之上。

**间隔最大化与超平面：** 线性 SVM 的核心是间隔的概念。间隔是超平面与任一类别中最近数据点之间的距离。SVM 旨在找到最大化该间隔的超平面，因为人们认为这能更好地泛化到未见数据。

**线性可分性：** 线性 SVM 假设数据是线性可分的，即存在一个超平面可以完全分隔两类。如果数据不是线性可分的，SVM 会引入软间隔的概念，允许一定程度的误分类，同时仍努力寻找最佳分离超平面。

**支持向量：** 最接近超平面、即“支撑”超平面的数据点称为支持向量。这些点至关重要，因为它们定义了间隔，并对超平面的位置影响最大。

**优化目标：** 线性 SVM 被表述为一个优化问题。它旨在最小化超平面的权重（以避免过拟合），同时最大化间隔。此类优化问题通常使用二次规划等技术求解。

**核技巧：** 虽然线性 SVM 对线性可分数据效果良好，但可以通过核技巧扩展以处理非线性数据。通过使用核函数将数据转换到更高维特征空间，SVM 可以找到有效分隔数据的超平面，即使在原始空间中无法进行线性分隔也是如此。

**正则化：** 线性 SVM 包含一个正则化参数（通常表示为 C），用于平衡最大化间隔与最小化分类误差之间的权衡。较小的 C 强调间隔，可能导致更多误分类，而较大的 C 优先考虑准确分类，可能导致更小的间隔。

**应用：** 线性 SVM 在文本分类、图像分类、生物信息学和金融等多个领域都有应用。在处理高维数据时尤其有用，此时其他分类方法可能会遇到困难。

**优势：** 由于其最大化间隔的特性，线性 SVM 对过拟合具有鲁棒性。它可以处理高维数据，并且在数据并非完全线性可分时通常仍然有效。此外，决策边界仅由支持向量定义，因此对异常值不太敏感。

**局限性：** 线性 SVM 的主要局限性在于其依赖线性可分性。在数据不是线性可分的，或者决策边界高度非线性的情况下，非线性 SVM（使用核函数）可能更合适。

总结而言，线性支持向量机是一种强大的分类算法，它利用线性代数和优化原理来寻找分离数据的最优超平面。其对最大化间隔的关注确保了对未见数据的更好泛化能力，并提升了其鲁棒性。虽然它特别适用于线性可分数据，但通过核技巧的扩展使其能够处理更复杂的场景，使其成为机器学习工具箱中一种多功能的工具。

### 7.2 非线性支持向量机

非线性支持向量机（SVM）是线性 SVM 的扩展，能够对在原始特征空间中不可线性分离的数据进行分类。通过应用核技巧，非线性 SVM 可以将数据转换到更高维空间，其中数据可能变得线性可分，从而允许 SVM 找到更复杂的决策边界。这种技术在各个领域应对复杂分类任务中起着关键作用。

**核技巧与特征映射：** 核技巧是非线性 SVM 的精髓。它避免显式地将数据转换到更高维空间，而是计算该空间中数据点之间的点积。这是通过核函数实现的，核函数在转换后的空间中定义数据点之间的相似性或距离，而无需显式计算转换本身。

**超参数调优：** 非线性 SVM 引入了额外的超参数，例如核函数的选择和核特定参数。仔细调整这些超参数对于实现最佳性能和防止过拟合至关重要。

**应用：** 非线性 SVM 在图像分类、自然语言处理、生物信息学等多个领域都有应用。当数据呈现线性分类器无法捕捉的复杂非线性关系时，它们特别有用。

**优势：** 非线性 SVM 的关键优势在于其能够处理线性分类器无法捕捉的复杂决策边界。核技巧允许它们将数据隐式地转换到更高维空间，使其适用于广泛的分类任务。

**局限性：** 虽然非线性 SVM 功能强大，但计算密集，尤其是在处理大型数据集和某些核函数时。正确选择和调整核函数及超参数对于避免过拟合至关重要。

总结而言，非线性 SVM 通过利用核技巧在更高维空间中有效运作，扩展了原始线性 SVM 的能力。这样一来，它们解决了线性可分性的局限性，使对复杂且非线性可分数据的分类成为可能。这种多功能性使非线性 SVM 成为机器学习中不可或缺的工具，能够应对各个领域中复杂的分类任务。
