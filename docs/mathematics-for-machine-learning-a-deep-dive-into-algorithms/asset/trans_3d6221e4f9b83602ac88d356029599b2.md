- 在线性回归中，Lasso 和 Ridge 等正则化技术被应用于防止过拟合并提高模型稳定性。

**模型解释：** 正则化可以通过减少对噪声或无关特征的强调，使模型更具可解释性。

**权衡：** 正则化涉及在拟合训练数据（低偏差）和避免过拟合（低方差）之间进行权衡。最佳平衡取决于特定问题和数据特性。

**局限性：** 虽然正则化有助于防止过拟合，但它可能不适合所有场景。在尽可能紧密地拟合训练数据至关重要的情况下，强正则化可能导致欠拟合。

总之，正则化技术对于通过控制模型复杂度来实现对新数据具有良好泛化能力的模型至关重要。通过向优化过程添加惩罚项，正则化有助于在捕获数据模式和避免过拟合之间取得平衡。L1 和 L2 正则化等技术已成为机器学习工具箱中的基本工具，增强了各种应用中模型的稳定性、可解释性和性能。

### 6.1 逻辑回归

逻辑回归是机器学习中广泛使用的统计方法，用于建模一个或多个自变量与二元结果之间的关系。尽管名字叫逻辑回归，但它用于分类任务而非回归。它是一种基本技术，可提供关于某一事件发生概率的洞察，并是更复杂分类算法的基础。让我们深入了解逻辑回归如何为机器学习领域做出贡献：

**基本思想：** 逻辑回归将二元结果（0或1）的概率建模为自变量的函数。它使用逻辑函数（Sigmoid函数）将变量的线性组合映射到0到1之间的概率值。

**Sigmoid函数：** 逻辑函数是一种S形曲线，它将变量的线性组合“压缩”到[0, 1]范围内。它定义为 p(x) = 1 / (1 + e^(-z))，其中z是变量的线性组合。

**对数几率：** 对数几率（概率p(x)的logit变换）表示为 log(p(x) / (1 - p(x))) = z。这个对数几率可以取负无穷到正无穷之间的任何值。

**参数估计：** 类似于线性回归，逻辑回归涉及估计自变量的系数（权重）。这些系数决定了每个变量对对数几率的影响。

**最大似然估计：** 系数使用最大似然估计（MLE）来估计，它最大化了在逻辑模型下观察到给定二元结果的可能性。

**决策边界：** 决策边界是一个阈值，用于将预测概率分为两个类。对于二分类，如果预测概率高于阈值，则将实例分配给类1；否则，分配给类0。

**训练：** 逻辑回归模型使用梯度下降等优化技术进行训练，以找到最佳系数值。

**正则化：** 可以将L1（Lasso）和L2（Ridge）正则化应用于逻辑回归，以防止过拟合并提高泛化能力。

**多类逻辑回归：** 逻辑回归可以使用一对其余（OvR）或Softmax回归等技术扩展到多分类问题。

**用例：** 逻辑回归应用于各个领域，包括医疗诊断（疾病预测）、金融（信用风险评估）、营销（客户流失预测）和自然语言处理（情感分析）。

**可解释性：** 可以解释逻辑回归系数，以了解每个变量对二元结果概率的影响方向和幅度。

**优点：** 逻辑回归简单、可解释且计算高效。它作为许多分类任务的基线模型，在探索更复杂的算法之前可以作为一个良好的起点。

**假设：** 逻辑回归假设自变量与二元结果的对数几率之间的关系是线性的，且误差是独立同分布的。

总之，逻辑回归是一种基础分类算法，用于建模二元结果的概率。通过使用逻辑函数将变量的线性组合映射到概率，它为理解和预测二元事件提供了一个强大的工具。尽管简单，逻辑回归仍然是机器学习工具箱中的一项宝贵技术，在各种应用中提供洞察力和预测能力。

### 6.2 Softmax回归

Softmax回归，也称为多项逻辑回归或多类逻辑回归，是逻辑回归的扩展，用于处理多分类问题。它将逻辑回归的思想推广到存在超过两个类别的场景中。Softmax回归对每个类别的概率进行建模，并提供一种方法将实例分配给多个类别之一，同时保持概率解释。让我们探讨Softmax回归如何为机器学习领域做出贡献：

**基本思想：** Softmax回归将多个类别的概率建模为自变量的函数。它使用Softmax函数将每个类别的原始得分（logits）转换为归一化概率。

**Softmax函数：** Softmax函数接受每个类别的得分（logits）输入向量，并将其转换为所有类别上的概率分布。它定义为每个类别k的 p(y = k|x) = e^(z_k) / Σ(e^(z_i))，其中z是logits向量。

**参数估计：** 类似于逻辑回归，Softmax回归涉及估计自变量的系数（权重）。每个类别都有自己的一组系数。

**最大似然估计：** 系数使用最大似然估计（MLE）来估计，它最大化了在Softmax模型下观察到给定多类结果的可能性。

**训练：** Softmax回归模型使用梯度下降等优化技术进行训练，以找到最佳系数值。

**决策规则：** 在Softmax回归中，预测概率最高的类别被选为实例的预测类别。

**多类公式：** Softmax回归的公式旨在对所有类别的联合概率分布进行建模。它确保所有类别的预测概率之和为1。

**交叉熵损失：** Softmax回归中使用的损失函数是交叉熵损失，它衡量预测概率与真实类别标签之间的差异。

**正则化：** 类似于逻辑回归，Softmax回归可以使用L1（Lasso）和L2（Ridge）正则化等技术进行正则化。
