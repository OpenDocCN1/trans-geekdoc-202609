

总之，K-Means 聚类是一种多功能且广泛采用的技术，用于发掘数据中的模式和结构。其简单性、可解释性和可扩展性使其成为跨不同领域进行初步数据探索、分割以及各种聚类任务的宝贵工具。然而，理解其局限性并选择合适的参数是获得有意义且准确结果的关键。

[224]

### 11.2 层次聚类

层次聚类是另一种强大的无监督机器学习技术，用于将数据点分组为聚类。与 K-Means 不同，层次聚类不需要预先指定聚类的数量。相反，它创建一个可以可视化为树状图（dendrogram）的层次聚类结构。当数据表现出嵌套或层次关系时，这种技术尤其有用。让我们深入探讨层次聚类的复杂性：

#### 算法概览：

- 初始化：每个数据点最初作为独立的聚类。
- 合并或凝聚：基于所选的连接准则（例如单链接、完全链接、平均链接）迭代合并相似聚类，该准则定义了如何测量聚类之间的相似性。
- 树状图：在聚类合并过程中，构建一棵树状图，展示聚类形成的层次结构。

[226]

#### 连接准则：

- 单链接：测量两个聚类中最近点之间的距离。容易将小聚类“链式”连接在一起。
- 完全链接：测量两个聚类中最远点之间的距离。对离群值和“链式”连接更稳健。
- 平均链接：测量两个聚类中所有点对之间的平均距离。

[227]

#### 局限性：

- 可扩展性：层次聚类在计算上可能变得昂贵，尤其是对于大型数据集。
- 主观性：连接准则的选择可能会影响结果。不同的准则可能导致不同的聚类分配。
- 树状图解释：虽然树状图提供了洞察，但从中确定最佳聚类数量可能具有主观性。

#### 应用：

- 分类学与生物学：层次聚类用于根据物种的遗传或表型特征对其进行分类，创建分类树。
- 文本文档聚类：层次聚类用于将相似文档分组为主题，从而实现更轻松的信息检索。
- 市场细分：层次聚类可以帮助根据更复杂的标准或行为对客户进行细分。

[228]

- 图像分割：在计算机视觉中，层次聚类可以根据颜色或纹理相似性将图像分割为区域。
- 药理学：在药物发现中，层次聚类有助于将结构或性质相似的化合物分组。

#### 扩展与变体：

- 凝聚式与分裂式：凝聚式层次聚类从单个数据点开始并将其合并为聚类。分裂式层次聚类从所有数据点位于一个聚类中开始，并将其分割为较小的聚类。
- Ward 方法：一种在合并过程中最小化聚类内方差的连接准则。
- 基于特征的层次聚类：这种变体不聚类数据点，而是聚类特征或变量，以识别相关特征的组。

总之，层次聚类是一种多功能技术，用于揭示数据中的层次关系。它能够通过树状图可视化层次结构，这使其成为理解复杂数据关系和创建分类体系的宝贵工具。仔细考虑连接准则和树状图的可解释性对于从层次聚类中获得有意义的洞察至关重要。

[229]

### 11.3 主成分分析（PCA）

主成分分析（PCA）是一种降维技术，用于将高维数据转换为低维表示，同时尽可能保留原始变异性。它旨在找到数据空间中数据变化最大的方向（主成分）。PCA 广泛用于可视化、噪声降低和特征提取。让我们探讨 PCA 的关键概念和应用：

#### 算法概览：

- 数据中心化：通过减去每个特征的均值来对数据进行中心化，以确保主成分代表围绕原点的变化。
- 协方差矩阵：计算中心化数据的协方差矩阵，以了解特征之间的关系。

[231]

- 特征值分解：计算协方差矩阵的特征值和特征向量。特征向量即为主成分。
- 选择主成分：按对应特征值递减顺序对特征向量进行排序。选择前 k 个特征向量以保留大部分方差。
- 投影：将中心化数据投影到所选主成分上，以获得低维表示。

#### 优势：

- 降维：PCA 在保留最重要信息的同时减少特征数量，使数据更易于管理和解释。
- 噪声降低：高维数据通常包含噪声。通过关注方差最大的方向，PCA 可以抑制噪声。
- 可视化：PCA 允许在低维空间中可视化数据，从而促进洞察和模式识别。

[232]

- 特征提取：PCA 可以将数据转换为一组新特征，这些特征可能捕获建模所需的更多相关信息。

#### 局限性：

- 线性性：PCA 假设特征之间存在线性关系。非线性变化可能无法有效捕获。
- 信息损失：降维本质上涉及丢失一些信息。挑战在于找到合适的平衡点。
- 可解释性：主成分是原始特征的线性组合，这可能使其解释性不够直观。

#### 应用：

- 图像压缩：在计算机视觉中，PCA 用于在保留关键特征的同时减少像素数量来压缩图像。

[233]

- 特征工程：PCA 可以将原始特征转换为一组减少的特征，这些特征捕获数据中的大部分方差。
- 数据可视化：通过将数据投影到低维空间，PCA 使高维数据的可视化成为可能，以便更好地理解。
- 数据预处理：PCA 可以作为预处理步骤，在应用机器学习算法之前降低数据的维度。
- 遗传学：在基因组学中，PCA 可用于分析基因表达数据并识别不同条件下的模式。

#### 扩展与变体：

- 核 PCA：通过使用核函数将数据映射到更高维空间来扩展 PCA，以捕获非线性关系。
- 稀疏 PCA：向主成分引入稀疏性，从而产生仅使用原始特征子集的解决方案。
- 增量 PCA：适合处理大型数据集，该方法以较小批次处理数据以增量方式计算主成分。
