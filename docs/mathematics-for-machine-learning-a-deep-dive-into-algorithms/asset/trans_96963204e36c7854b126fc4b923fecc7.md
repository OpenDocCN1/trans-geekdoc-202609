

**基于梯度的单侧采样：** LightGBM 使用基于梯度的方法来选择用于树构建的数据样本，从而加速收敛并减少过拟合。

**按叶子生长树：** 与传统的深度优先树生长不同，LightGBM 使用按叶子生长树策略，这可能导致更深的树和更好的模型性能。

**分类特征支持：** LightGBM 可以直接处理分类特征，无需进行独热编码。

**并行与 GPU 学习：** LightGBM 支持并行处理和 GPU 加速，进一步提升其速度和可扩展性。

**单调性约束：** 它允许用户为特征定义单调性约束，从而在特征和目标变量之间强制实施所需的关系。

XGBoost 和 LightGBM 都高度高效，两者之间的选择通常取决于特定的数据集、问题复杂度和可用资源。它们拥有大量可调节的超参数，以便在特定任务上实现最佳性能。

### 14.1 自编码器

自编码器是一种人工神经网络架构，主要用于无监督学习任务，例如降维、特征学习和数据压缩。其设计目的是将输入数据编码为较低维度的表示，然后将其解码回原始形式，旨在学习一种捕捉数据基本特征的压缩表示。自编码器由编码器和解码器组成，两者协同工作以学习高效的数据表示。

以下是自编码器的组件及其工作原理的概述：

**编码器：** 编码器接收输入数据并将其映射到较低维度的表示，通常称为“编码”或“潜在”空间。编码是对输入数据的压缩表示，捕获其最重要的特征。

**解码器：** 解码器接收来自编码器的编码表示，并试图从中重建原始输入数据。目标是将重建误差最小化，以鼓励网络学习有意义的编码。

**损失函数：** 在训练期间，重建误差用作损失函数。通过反向传播，将输入数据与重建输出之间的差异最小化，从而调整神经网络各层的权重。

**瓶颈层：** 网络中间对应编码的层通常被称为“瓶颈”层。其维度低于输入层和输出层，迫使网络捕获数据中最相关的特征。

**自编码器可以拥有多种架构，每种都有其自身特征和应用场景：**

**标准自编码器：** 最简单的自编码器形式，由编码器、解码器和瓶颈层组成。它主要用于降维和特征学习。

稀疏自编码器：为编码引入稀疏性约束，鼓励瓶颈层中的一些神经元处于非活跃状态。这可以产生更稳健且更具信息量的表示。

*去噪自编码器：* 训练用于从噪声输入中重建干净数据。它帮助网络学习从损坏的数据中提取有用的特征和模式。

*变分自编码器（VAE）：* 自编码器的概率版本，学习在编码空间中生成数据。VAE 用于生成新数据样本以及执行图像合成等任务。

*卷积自编码器：* 对图像数据使用卷积层，使其能够捕捉图像中存在的空间层次结构和模式。

*循环自编码器：* 包含循环层，以处理时间序列或文本等序列数据。

自编码器在多个领域都有应用，包括图像去噪、异常检测、图像压缩和特征提取。它们也是生成对抗网络（GANs）和迁移学习等更高级技术的基本组成部分。

### 14.2 生成对抗网络（GANs）

生成对抗网络，通常称为 GANs，是 Ian Goodfellow 及其同事于 2014 年引入的一种神经网络架构。GANs 的设计目的是生成与给定训练数据集相似的新数据样本。GANs 的核心思想是让两个神经网络（即生成器和判别器）以类似游戏的方式相互竞争。

**以下是 GANs 的工作原理及其组件的角色：**

**生成器：** 生成器的任务是创建与训练数据相似的新数据样本。它以随机噪声作为输入，并生成合成数据样本。起初，生成器产生随机且无意义的输出。

**判别器：** 判别器（又称评论家）旨在区分训练集中的真实数据和生成器产生的假数据。它将真实数据和合成数据作为输入，并分配输入数据为真实数据的概率。

**GANs 的训练过程涉及生成器和判别器之间的来回竞争：**

**训练判别器：** 判别器在训练集的真实数据样本和生成器生成的假数据样本上进行训练。它学习为真实数据分配高概率，为假数据分配低概率。

**训练生成器：** 生成器经过训练以生成能够欺骗判别器的数据样本。它试图通过生成判别器难以与真实数据区分开来的样本来提高输出质量。

**对抗过程：** 训练过程在训练判别器和训练生成器之间交替进行。目标是达到这样一个点，即生成器创建的数据与真实数据无法区分。

**损失函数：** GANs 为生成器和判别器使用特定的损失函数。生成器旨在最小化判别器正确分类生成数据的能力，而判别器旨在正确分类真实数据和假数据。

**收敛：** 理想情况下，随着训练的进行，生成器在生成现实数据方面变得更加熟练，而判别器在区分真实数据和假数据方面面临更大挑战。在最佳情况下，生成器产生的数据与真实数据几乎无法区分。

GANs 在多个领域取得了显著突破，包括图像生成、风格迁移、数据增强甚至文本到图像合成。然而，训练 GANs 可能具有挑战性，因为保持生成器和判别器之间的平衡非常微妙，且训练过程可能容易出现模式崩溃（即生成器产生的样本范围有限）。尽管存在这些挑战，GANs 彻底改变了生成模型领域，并激发了众多变体和应用。

### 14.3 Transformer

Transformer 是一种开创性的神经网络架构，由 Vaswani 等人在 2017 年的论文 "Attention Is All You Need" 中提出。它们最初专为自然语言处理任务（例如机器翻译）而设计，但此后已成为包括语言、视觉乃至蛋白质折叠在内的多个领域中许多最先进模型的基础。Transformer 对涉及数据序列的任务尤其有效，使其具有多功能性和强大性。

Transformer 的关键创新是自注意力机制，该机制使模型在进行预测时能够对序列中不同单词或元素的重要性进行加权。这种机制使 Transformer 比传统的循环网络或卷积网络更有效地捕获数据中的长程依赖关系和关联。

以下是 Transformer 的组件及其工作原理的概述：

**自注意力：** 自注意力机制计算输入序列元素的加权和，其中权重由元素之间的关系决定。它为每个预测中更相关的元素分配更高的权重。

**多头注意力：** 为了捕获关系的不同方面，Transformer 并行使用多个注意力机制，每个称为“头”。这种多头注意力机制增强了模型关注各种模式和关系的能力。

**位置编码：** 与固有地捕获序列顺序的循环网络不同，Transformer 缺乏此属性。为了克服这一点，将位置编码添加到输入嵌入中，以提供序列中每个元素位置的信息。

**编码器和解码器堆栈：** Transformer 由编码器和解码器堆栈组成。编码器处理输入序列并生成表示，而解码器生成输出序列。编码器和解码器都包含多层自注意力和前馈神经网络。

**注意力掩码：** 对于涉及序列到序列映射的任务（例如机器翻译），使用注意力掩码来确保预测仅基于每个步骤中可用的信息。
