To execute this analysis, a database was created from all W-shaped structural steel sections as provided by the American Institute of Steel Construction (AISC) manual[98] [37]. This database contains two independent features (Z and fy) for each beam, as well as M (as a dependent variable). Simply, since we know the DGP (i.e., Equation 8.1), I multiplied the plastic modulus of each steel section by two steel Grades (A992 and A36).

The compiled database was used in an analysis that I carried out through the Tetrad[99] software and using two algorithms (namely, the PC algorithm, a constraint-based, and the FGES algorithm, a score-based).
