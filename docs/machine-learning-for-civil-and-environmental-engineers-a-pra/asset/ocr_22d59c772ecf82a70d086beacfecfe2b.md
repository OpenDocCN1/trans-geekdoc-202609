# # Multivariate analysis

+   - **Principal Component Analysis**
+     Reduce a large set of variables into a smaller set of components.

+   - **Correlation matrix**
+     Examine the relationship of multiple variables at the same time.

+   - **Scatter plot 3D**
+     Visualize the relationships between 3 numerical variables.

+   - **Parallel coordinates plot**
+     Visualize a high number of variables at the same time.
