# 4.1.2.7 K-Means Clustering Algorithm

K-Means is another commonly used clustering algorithm that identifies the optimal number of clusters in a dataset by examining the total decrease in intra-cluster94 variation attained from increasing the number of clusters. The K-Means minimizes the Euclidean distances between each data point and the centroid of its cluster, squares it, and sums it with others (aka. the sum of the squared errors, SSE) – see Equation 4.35). This K-Means was proposed by MacQueen [71] and finetuned by Hartigan and Wong95 [72]. A flowchart of the K-Means algorithm is shown in Figure 4.29.

$$SSE = \sum_{p=1}^k \sum_{x_i \in C_p} p_i - \mu_p^2$$ (4.35)

where p_i is the data point, \mu_p is the centroid of the clusters, and C_p is p^{th} cluster.

*How does this algorithm work?*

A typical K-Means analysis starts by arriving at the number of clusters96 k (see Figure 4.29). This algorithm then selects random points in the data space97 as the centroid of clusters (\mu_p).
