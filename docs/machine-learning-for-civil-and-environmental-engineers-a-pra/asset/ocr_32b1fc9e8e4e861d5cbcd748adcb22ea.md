To carry out this analysis, upload this dataset.

Step 1: Select the K-Means clustering analysis. Navigate to Property⁶⁵ and then Find Optimal Number of Clusters option and select TRUE. This allows Exploratory to find the optimal number of clusters via the elbow method.
