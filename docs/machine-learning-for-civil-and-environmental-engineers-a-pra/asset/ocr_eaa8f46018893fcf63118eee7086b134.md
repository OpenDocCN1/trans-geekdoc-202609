# 4.1.1.14 Logistic Regression (LR)

The logistic regression65 (LR) maximizes the likelihood of observing a continuous or a categorical phenomenon. LR is a generalized linear model that applies a binomial distribution to fit regression models to binary response variables.

# How does it work?
