# 3.9.2 Regression

Regression<sup>122</sup> is perhaps one of the first things that come to an engineer's mind when they are tasked with analyzing data. A common goal<sup>123</sup> is to create a model that can be used to either predict this data or possibly explain the underlying mechanism that has generated such data. In reality, regression can be used for many other applications. In lieu of the above two applications, regression can also be used to:

+   - Characterize relationships between dependent variables and the independent variable.<sup>124</sup>
+   - Determine the importance of dependent variables with regard to the independent variable.
+   - Compare possible combinations of dependent variables (i.e., form of regression, need for interaction terms).

There are many forms of regressions, most of which are a function of the availability and types of the present data. I will start with the simplest case of linear regression.<sup>125</sup> The simplest form of regression is one where we fit a line on the data to describe the relationship in the data. Such a line is likely to have a slope \(\beta_1\) and an intercept \(\beta_0\), and hence the following equation turns suitable to describe such a line:

\( Y = \beta_0 + \beta_1 X + \epsilon \quad (3.6) \)

In Equation 3.6, the \( Y \) is the dependent variable, the \( X \) is the independent variable, and \( \epsilon \) is the error term. Thus, this is a simple<sup>126</sup> linear<sup>127</sup> regression for a single independent variable and one dependent variable. There is a clear interpretation of the slope and intercept. Simply, \(\beta_0\) is the mean of \( Y \) when \( X = 0 \), and \(\beta_1\) is the change in \( Y \) due to one unit change in \( X \).<sup>128</sup>

There are five assumptions to linear regression. These include:<sup>129</sup>

+   - Existence of a linear relationship.
+     - The dependent and independent variables should be linearly related
+       - Can be determined via scatter plots.
+     - If this assumption is violated, then:
+       - Transforming the variables can restore this assumption.
+       - Add new variables to replace the problematic ones.
+   - Multivariate normality.
+     - Any linear combination of the variables should have a normal distribution.
+       - Can be checked by inspecting distribution plots or QQ-plots.
