There are other techniques than those listed above. For example, stacking, blending, bagging, and boosting are three such common techniques. Stacking149 combines predictions from various models. These predictions are stacked together and used as input to train the ensemble. Blending150 is similar to stacking but uses a holdout set from the training set to make predictions. Bagging151 adopts bootstrapping152 to generate data that can be input to train parallel models. Each model then learns the error predicted by previous models. Boosting, on the other hand, converts weaker models into a strong one.153 Boosting is a process to correct arising errors from previous iterations by adjusting emphasis (i.e., weights) according to the degree of errors.154 Boosting is applied sequentially and does not allow parallel operation (unlike bagging155 – see Figure 9.18).
