Rule 1 : If x is A<sub>1</sub> and y is B<sub>1</sub>, then f<sub>1</sub> = a<sub>1</sub>x + b<sub>1</sub>y + r<sub>1</sub> (4.1)

Rule 2 : If x is A<sub>2</sub> and y is B<sub>2</sub>, then f<sub>2</sub> = a<sub>2</sub>x + b<sub>2</sub>y + r<sub>2</sub> (4.2)

where x,y = input arguments, A,B = the linguistic labels, a,b,r = output function parameters.
A typical fuzzy inference contains five layers [6]:

Layer 1: every node i in this layer is an adaptive node characterized by a bell-like function, e.g.:

\(\mu_i(x) = \frac{1}{1 + |\frac{x - \delta_1}{\alpha_1}|^{2\beta_1}}\) (4.3)

where \(\mu_i(x) = i^{th}\) resultant of 1<sup>st</sup> layer, x = node input, \(\alpha_1, \beta_1, \delta_1 =\) parameter set. Parameters of the first layer are usually
denoted as the premise set. The resultants of the first layer are the membership values of the premise part.
