# Definitions

+   - **Code library** A collection of pre-built modules and codes that can be used repeatedly in different problems.
+   - **Coding-based ML** A user codes or programs an executable script to run a ML analysis.
+   - **Coding-free ML** An online portal or software with an intuitive graphical interface used to run a ML analysis.
+   - **Relative compactness** defined as the volume to surface ratio to that of the most compact shape with the same volume.
