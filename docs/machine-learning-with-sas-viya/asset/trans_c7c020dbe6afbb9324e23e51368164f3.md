## 添加非结构化数据

非结构化、自由格式的文本数据在商业中很常见。例如，调查结果、呼叫中心日志、产品评论、社交媒体信息流、博客、客户反馈和其他文本数据包含对预测建模结果有用的信息，这些信息在结构化数据中不易获得。因此，分析这些组合的文本数据源并将其与结构化数据一起使用是非常有信息量的。
