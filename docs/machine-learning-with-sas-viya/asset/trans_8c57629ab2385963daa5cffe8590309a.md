## 模型部署
选择 `champion model` 后，是时候通过对新数据进行评分来使用模型了。评分过程有时被称为模型部署、模型生产或模型实现。

### 对冠军模型进行评分
分析生命周期中之前执行的所有任务都导向此任务：通过评分生成预测。当模型投入生产时，组织才能从模型中获得价值。为了最大化该价值，有必要随时间监控模型性能并根据需要更新模型。

| `Model Studio: Scoring` |
| --- |
| 对于评分，模型首先被翻译成另一种格式（通常为 `score code`）。在 `SAS Viya` 环境中，`score code` 是一个 SAS 程序，您可以轻松地在评分数据集上运行。然后将模型应用于评分数据集以获得预测结果。根据模型的预测，企业做出业务决策并采取行动。图 12.16：模型实现![图 1.1 一些 JMP 帮助选项](Images/Image1322.png) |
| `Model Studio` 节点可以创建两种类型的 `score code`：`DATA step` 或分析存储（也称为 `ASTORE`）。要为整个管道生成 `score code`，生成节点评分代码的每个节点的 `score code` 会被追加到单个 `DATA step` 中。当管道中的节点产生多个分析存储，或一个或多个分析存储和 `DATA step` `score code` 时，会创建 `EP score code` 文件。`EP score code` 表示这些管道产生的 `score code`。要在 `Model Studio` 外运行此代码，请参阅 “[从分析存储模型运行评分代码](http://pubshelpcenter.unx.sas.com:8080/preproduction/?activeCdc=vdmmlcdc&cdcId=capcdc&cdcVersion=8.4&docsetId=vdmmladvug&docsetTarget=p1uq2mo9js2r33n1sr99795f3plj.htm&locale=en)” in SAS 文档。图 12.17：评分您的模型![图 1.1 一些 JMP 帮助选项](Images/Image13361.png) |
| 表 12.1 总结了哪些 `Model Studio` 节点产生 `score code`，以及它们产生的代码类型。表 12.1：评分节点 |
| `DATA Step` || `Analytic Store (ASTORE)` ||  |
| --- | --- | --- |
| 聚类 || 插补 || 异常检测 |
| 决策树 || 线性回归 || 贝叶斯网络 |
| 集成 || 逻辑回归 || 森林 |
| 特征提取 || 神经网络 ** || `Gradient Boosting` |
| 过滤 || 替换 || SVM |
| GLM || 转换 || 文本挖掘 |
** `DATA step` 对于少于六层的网络，`analytic store` 对于六层或更多层的网络。 |
| 下载 `score code` 后，`SAS Viya` 中有几种模型部署选项：● `Model Studio` 中的 `Score Data node` 使您能够使用管道中前置节点生成的 `score code` 对数据表进行评分。评分表保存在 `caslib` 中。默认情况下，评分表是临时的，仅存在于节点的运行期间，并且具有本地会话范围。`Score Data node` 使您能够将评分表保存到磁盘中与指定输出库关联的位置。保存到磁盘后，此表可供其他应用程序用于进一步分析和报告。● 创建 `ASTORE` 代码的模型可以在 `SAS Studio` 中使用 `ASTORE procedure` 进行评分。● 您还可以在 `SAS Model Manager` 中运行评分测试。这将在后面展示。● `Model Studio` 为 `score code` 创建 API，可从 SAS 或 `Python` 调用，或通过 `REST API` 调用。在 `Model Studio` 中的项目中，您可以转到 `Pipeline Comparison` 选项卡，然后点击右上角的 `Project pipeline menu`（三个垂直点）并选择 `Download score API`。它提供的代码可直接在其他应用程序中使用。（您只需修改正在调用的 `CAS` 服务器和端口、要评分的数据源，以及输出 `caslib` 和评分输出表的名称。）即使您从 `Python` 程序通过 API 调用 `score code`，`score code` 也在 `CAS` 中运行，而不在 `Python` 中运行。● `Score code` 还可以发布到 `Micro Analytics Services`（Web 服务）和 `SAS Event Stream Processing`。`SAS Model Manager` 简化了分析模型的管理和维护。分析模型能够实现更好的决策。`SAS Model Manager` 提供基于 Web 的环境，以支持模型生命周期管理和治理。您可以轻松管理建模流程并识别用于部署的 `champion models`。性能监控和警报可自动化模型更新过程，以解决模型退化并确保模型反映当前状况。图 12.18：SAS Model Manager![图 1.1 一些 JMP 帮助选项](Images/Image1362.png) |
