其他可能的漏洞包括权限设置中的 Bug、缓冲区溢出 Bug 和内核缺陷。缓冲区溢出 Bug 是恶意软件非常常见的攻击目标，部分原因在于其熟悉度和可预测性。它们在功能上类似于 SQL 注入。软件通常会为用户输入分配一段固定的空间，即缓冲区。如果提供的输入不适合分配的缓冲区，缓冲区可能会像堵塞的水槽一样溢出。黑客可能会在溢出部分包含新语句，导致其他事情发生。影响 OpenSSL 加密软件的 Heartbleed（心脏出血）漏洞就是此类 Bug 的一种变体，因为它允许攻击者利用缓冲区限制问题查看受保护的数据。与 SQL 注入一样，这些攻击向量的主要吸引力在于它们能让入侵者访问非公开信息。在我们的故事中，Compbiz 产品中的安全缺陷允许未经授权访问数据库。因此，缓冲区溢出利用或 SQL 注入很可能是 Brian 恶意软件的嫌疑对象。

发现漏洞（如上述的 SQL 注入或缓冲区溢出机会）只是第一步。当有人投入时间和精力将漏洞武器化，从而创建出利用代码时，软件漏洞才变得危险。利用代码随后可被恶意使用，也可用于和平研究。此外，利用代码可能只是给计算机所有者带来麻烦，因为它们导致受感染机器运行变慢；也可能具有破坏性，导致重要文件损坏或删除。与破坏性利用代码相比，安全消费者可能对麻烦型利用代码的反应更加矛盾，尽管如果计算机运行受损是因为它已成为僵尸网络的一部分，麻烦型利用代码的社会成本可能是一样的。

在确定安全缺陷后，黑客可能会编写一个工具来利用该漏洞，或许将其作为用户想要安装的东西的“特洛伊木马”附件。一旦编写了该工具，目的就是让某人在黑客想要攻陷的系统上安装该工具。传统上，这需要目标实际打开一个可执行文件；但黑客也成功地将恶意软件嵌入文字处理文件和 PDF 文件中。[13](#section9.xhtml#ftn.20) 此外，恶意黑客可以感染那些并非有意安装任何东西的网站访问者。例如，他们可能利用网站编码将一个恶意网站嵌入到访问者打算访问的网站中，从而传播特洛伊木马。[14](#section9.xhtml#ftn.21) 我们故事中的黑帽黑客 Brian 利用一个恶意网站访问了 Retailco 保护不力的系统。

最近引起广泛关注的一种特定攻击类型是勒索软件。勒索软件是一种恶意软件威胁，对律师事务所可能造成毁灭性打击。当计算机感染勒索软件时，恶意软件会加密计算机上的所有文件。然后勒索软件会向用户显示一条消息，指示他们在特定时间限制内（通常仅几天）支付赎金，否则解密密钥将被销毁，数据将永远无法访问。虽然存在一些潜在的技术解决方案，但如果公司不持续备份必要文件，支付赎金的诱惑可能非常大。FBI 甚至在受害者是否应直接支付赎金的问题上表现出了一些矛盾态度。

勒索软件通常通过网络钓鱼邮件中的恶意链接传播，这与我们故事中 Brian 的技术非常相似，只不过 Brian 的目标是窃取信息，而不是破坏网络的可访问性。医院已成为勒索软件极具吸引力的目标，因为获取患者档案中最新、最准确的信息可能关乎生死。对于许多其他需要立即访问数字存储信息的职业来说，勒索软件也是一种威胁。2017 年，一家律师事务所起诉其保险提供商，辩称该提供商在事务所计算机感染勒索软件且存储数据无法访问长达三个月时，拒绝提供业务中断保险赔偿，违反了合同义务。[15](#section9.xhtml#ftn.22)

加密货币挖矿恶意软件是另一种日益增长的网络安全威胁，尽管其对受感染系统的影响可能不如勒索软件严重。此类恶意软件不加密数据，而是重新分配计算机资源，代表某个中心操作员“挖掘”加密货币，从而直接为该操作员创造利润。

## d. 技术黑客攻击加人为错误

针对机构的黑客通常需要凭证才能获得访问权限。获取此信息的方法有很多，但其中最有效的可以说是网络钓鱼，它主要利用另一种类型的漏洞——人为操作员。网络钓鱼骗局长期以来一直是获取访问权限的有效途径，这些骗局造成的后果对受害者来说可能代价高昂。

FBI 追踪一种特定类型的网络钓鱼骗局，通常称为商业电子邮件入侵（BEC）骗局或 CEO 冒充骗局，自 2013 年 FBI 开始追踪此类骗局以来，已造成公司至少 30 亿美元的损失。[16](#section9.xhtml#ftn.23) BEC 骗局通常涉及犯罪分子伪造实际高管或实际业务合作伙伴的身份，然后诱骗受害者将大笔资金汇入某个银行账户。此类骗局通常具有很强的针对性，但也存在更通用的网络钓鱼攻击方法，试图感染计算机恶意软件或获取访问凭证。当一名公司员工成为涉及恶意软件的网络钓鱼攻击的受害者时，这会使其他公司计算机面临风险。即使黑客仅获得了该员工的凭证，这仍可能足以促成大规模客户信息或知识产权窃取。
