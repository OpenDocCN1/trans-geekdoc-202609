

# 伊利诺伊州在犯罪记录销毁条款方面独树一帜

伊利诺伊州因其纳入了与记录销毁相关的刑事条款而独树一帜。在其他地方，记录销毁要求通常被视为监管违规。

在密歇根州，维护个人信息数据库者必须在个人从数据库中移除时，彻底移除并销毁关于该个人的信息。[^136]

田纳西州同样要求负责任地销毁不再需要保留的个人信息。在田纳西州，违反该条款被视为违反州消费者保护法。[^137]

# 主观恶意与协助者责任

随着责任从最直接的不法行为人向外扩展，各州通常要求协助者与使用被盗信息的身份窃贼具有同等的 culpability（刑事责任/过错）。通常，身份盗窃所需的 *mens rea*（主观恶意/犯罪故意）为故意、知情或蓄意。极少数州承认鲁莽行为可支持作为主要或协助犯罪的身份盗窃责任。

根据阿拉巴马州的《消费者身份保护法》，如果消费者报告机构在未能遵守消费者关于冻结因身份盗窃导致的信用信息变更的请求时表现出鲁莽行为，则可被追究民事责任。

在阿拉斯加州，一级刑事冒充要求行为人鲁莽地损害了受害者的财务声誉。

在佛蒙特州，某人鲁莽地协助他人实施身份盗窃属于犯罪。[^138]

特拉华州是唯一一个鲁莽的 *mens rea* 可支持身份盗窃主犯罪的州，因为该法律提及鲁莽持有信息。然而，即使持有个人信息是“鲁莽”的，该持有行为仍必须具有实施犯罪的意图。[^139]

# 五、惩罚

各州司法系统在如何给犯罪分级以及可施加何种监禁刑期或罚款方面存在显著差异。各州使用不同的标准来确定量刑和犯罪分级，因此在具体节点上比较各州是低效的。身份盗窃罪行可以是轻罪或重罪，且两者的区别往往取决于受害人或行为人是谁。

许多州承认可能加重惩罚范围的因素。在大多数州，惩罚可能受行为人获取的价值、受害人损失的价值或受害人数量的影响。约四分之一的州在受害人为老年人或属于其他弱势群体时，承认加重身份盗窃罪行。

内华达州针对公职人员实施的身份盗窃设有单独罪名。[^140] 两类身份盗窃均为 B 类重罪，但违反 `205.464` 条的最低监禁期限为五年，而更通用的 `205.463` 条身份盗窃法的最低监禁期限为一年。此外，根据内华达州的通用身份盗窃法，针对老年人的身份盗窃违规最低监禁期限为三年，而如果行为人是违反 `205.464` 条的公职人员，最低监禁期限为七年。除受害人弱势性外，可能增加最低监禁刑期的其他因素包括受影响的受害人数量和受害人遭受的经济损害。

# 六、受害人赔偿

本节将讨论三种主要类型的受害人赔偿：身份盗窃护照、恢复原状（赔偿）和民事救济。

身份盗窃受害人还受益于对信用报告机构施加要求的法律。

- 阿拉巴马州、弗吉尼亚州和新泽西州要求这些机构从消费者的信用档案中屏蔽因身份盗窃而添加的项目。
- 特拉华州和蒙大拿州要求信用报告机构接受身份盗窃护照作为争议通知。
- 西弗吉尼亚州规定了当消费者请求安全冻结时信用报告机构的要求。

此类冻结允许消费者阻止其信用报告中的新活动。消费者随后可根据需要解冻其信用。西弗吉尼亚州是少数几个在与身份盗窃相关的法规中涉及安全冻结的州之一。信用机构过去会对安全冻结收费，一些州身份盗窃法设定了可收取的安全冻结费用上限。自 2018 年 9 月起，联邦法律要求信用机构免费向客户提供安全冻结。这一要求是作为国会于 2018 年通过的《经济增长、监管救济和消费者保护法案》的一部分而增加的。

十个州允许受害人申请身份盗窃护照。[^141] 内华达州设有“身份盗窃计划卡”，似乎起到与身份盗窃护照相同的作用。在十个州中有八个（弗吉尼亚州和新墨西哥州除外）要求身份盗窃受害人在申请身份盗窃护照前必须先报警。获批的申请将转交州检察长，由其向受害人签发身份盗窃护照。

受害人可向执法机构出示身份盗窃护照，“以帮助防止受害人因他人使用其身份实施的犯罪而被逮捕或拘留。”[^142] 这类似于其他身份盗窃法律中关于受害人权利的条款，即如果犯罪是利用其信息实施的，受害人有权要求法院记录修改以反映其事实上的清白。在俄克拉荷马州，此类撤销记录可用于获取身份盗窃护照。身份盗窃护照也可与债权人和信用报告机构共享，作为潜在欺诈性指控的通知。

关于谁可以获得身份盗窃护照存在一些限制。

- 爱荷华州要求受害人必须是该州公民或在爱荷华州遭遇身份盗窃，才能获得身份盗窃护照。[^143]
- 内华达州法律规定，内华达州居民可在任何州向执法机构报案，但在内华达州遭遇身份盗窃的非居民必须在该州报案。[^144]

大多数州不使用身份盗窃护照这一工具。相反，各州通常规定身份盗窃受害人可寻求报销哪些费用。大多数州身份盗窃法涉及对身份盗窃受害人的恢复原状（赔偿）。这可能包括律师费、信用监控费用或更换支票的费用等。

在十个州，身份盗窃法为受害人创设了民事诉因。[^145] 另外三个州在有限情况下创设了民事诉因。

- 南卡罗来纳州承认导致非法居留的身份欺诈受害人享有诉权，但不适用于普通身份欺诈。
- 加利福尼亚州和怀俄明州承认针对违反各自州在线冒充法的行为提起私人诉讼的权利。

许多身份盗窃法根据受害人身份加重处罚或提高罪级。十三个州在受害人为老年人时规定更严厉的惩罚。一些关于冒充的州法律规定，如果被冒充者为执法人员或武装部队成员，则构成更高级别的犯罪。
