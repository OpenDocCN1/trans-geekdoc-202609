

# 恶意软件

恶意软件也称为恶意代码，形式多种多样，包括特洛伊木马和 Rootkit。**特洛伊木马**是一段看似合法但具有有害影响的软件，其潜在危害可能包括允许恶意用户获得系统的后门访问权限。赛门铁克针对 Windows 机器将“Rootkit”定义为：“利用系统挂钩或修改来隐藏文件、进程、注册表项和其他对象，以隐藏程序和行为的程序。”[9](#section9.xhtml#ftn.16) 简单来说，Windows 机器上的 Rootkit 可以让攻击者在被发现前造成更大的破坏。Rootkit 还被用于赋予攻击者提升的授权级别。Stuxnet 蠕虫包含一个 Rootkit，被认为是首个已知影响工业控制系统的 Rootkit。

## i. 僵尸网络

某些恶意软件并非旨在危害目标，而是将该计算机作为工具用于攻击其他目标。当计算机以这种方式被控制时，有时被称为**僵尸系统**。僵尸化恶意软件可用于控制未受保护（或保护不足）的计算机，使其成为同一个“僵尸群”或**僵尸网络**中的成千上万台计算机之一。僵尸网络可定义为“通常被编程用于执行某些重复性任务、处于单一控制机制下的计算机网络。”[10](#section9.xhtml#ftn.17) 僵尸网络主控者随后可利用僵尸网络发送海量垃圾邮件，或指令僵尸网络向组织网站发送海量数据和请求，发起**分布式拒绝服务（DDoS）**攻击。

旨在“僵尸化”系统的病毒可能利用**零日漏洞**来攻陷大量系统，但非零日漏洞同样可能奏效。零日漏洞的广泛有效性通常不是构建僵尸网络的必要条件。要构建僵尸网络，黑客只需使用一种足够多计算机都易受攻击的攻击方法。

## ii. 拒绝服务攻击

另一类攻击是**拒绝服务（DoS）**攻击。DoS 攻击由攻击者发起，通过向目标计算机系统发送海量数据和请求，使目标无法正常运行。DoS 攻击是一种需要随时间进行多次攻击的网络行动示例，因为一旦攻击停止，目标系统将会恢复。CERT 将 DoS 攻击定义为旨在“阻止服务的合法用户使用该服务”的攻击。[11](#section9.xhtml#ftn.18)

随着网络容量的增长，攻击者放大了攻击规模。**分布式拒绝服务（DDoS）**攻击是来自大量计算机的同时发起的 DoS 攻击。有了 DDoS 攻击，防御者更难阻断导致系统崩溃的“噪音”源头。DDoS 攻击之所以仍是严重威胁，部分原因在于当前技术市场上涌入了大量联网设备，且许多设备在设计时未考虑安全性。例如被 **Mirai 僵尸网络** 操控的摄像头和 DVR，该僵尸网络是针对 Dyn 发动 DDoS 攻击的工具。联网闭路电视摄像头让人们能通过智能手机随时随地查看家庭情况，但这种连接性也导致部分摄像头被攻陷。从摄像头到计步器和冰箱，市场推出了许多新型联网设备。若缺乏安全关注，这些设备往往易被攻陷并被用于向目标发送数据噪音，导致其系统崩溃。

但有时，系统崩溃可能是因为过多合法用户同时尝试访问。联邦**计算机欺诈和滥用法案（CFAA）**涉及的一个案例就考虑了这一问题。在 *Pulte Homes, Inc. v. Laborers’ Intern. Union of North America* 一案中，一个工会发起运动鼓励人们就劳工问题联系一家建筑商。[12](#section9.xhtml#ftn.19) 该运动非常成功，随着联系请求涌入，电话线和传真线被占满。由于难以区分大量合法请求和 DDoS 攻击，因此很难有效将 DDoS 攻击定罪。在 *Pulte* 案中，法院裁定该洪水般的联系尝试构成了 CFAA 下一项主张所指的传输行为，但驳回了 Pulte 关于狂轰滥炸的电话和电子邮件构成未经授权访问的论点。

DDoS 攻击难以防御，还可能压垮被动防御措施，使系统更容易遭受其他攻击。这些攻击对企业也造成高昂成本。网站安全公司 Incapsula 通过调查收集数据，于 2014 年发布报告估计 DDoS 攻击每小时给企业造成约 40,000 美元的损失。人们高度担忧攻击者可能针对关键基础设施（如医院和国防设施）发动 DDoS 攻击。2016 年，攻击者通过让一家主要 **DNS** 基础设施提供商下线，成功中断了美国数百万用户的互联网接入。使用 **Dyn** 域名系统的网站（包括 **Twitter** 和 **Reddit** 等知名服务）突然无法访问。攻击手段是利用 **Mirai 僵尸网络** 发动的 DDoS 攻击，该网络允许约 100,000 个物联网设备被用作针对该提供商的大规模武器。

DDoS 攻击历来依赖僵尸网络，但近期发展表明并非总是如此。2018 年 2 月 28 日，热门开发者平台 **GitHub** 遭遇了一场高达 1.35 Tbps 的天文数字级 DDoS 攻击，打破了此前针对 Dyn 攻击时创下的 1.2 Tbps 纪录。GitHub 使用可缓解 DDoS 攻击的安全产品，攻击在约二十分钟内结束。这是一场利用 **memcached 服务器** 的**放大攻击**，memcached 服务器是一种提高网络和网站访问速度的互联网功能。攻击 GitHub 时，攻击者伪造受害者的 IP 地址并向 memcached 服务器发送请求，导致服务器响应的数据量是攻击者从伪造 IP 地址原始发送量的五十倍。

DDoS 攻击也作为一种服务提供，让技术不精的人也能付费针对选定目标发动攻击。2018 年，一个国际执法团队关闭了 **Webstresser.org**，该网站被认为当时是互联网上最大的 DDoS 租赁网站。

## c. 黑客技术

软件产品固有缺陷，其中一些是安全漏洞。要利用安全漏洞，黑客会识别代码中允许外部人员对系统施加一定控制的脆弱点。该点有时被称为“**攻击向量**”，因为它是黑客获取系统未经授权访问权限的路径。

过去几年中，许多针对私营公司的公开攻击都涉及“**SQL 注入**”，这是一种非常流行且有效的黑客手段，尤其是在目标为窃取信息时。**SQL** 代表“结构化查询语言”，这是一种常用于管理大型数据库的编码语言。如果用户有机会输入数据，导致系统执行比预期输入更多的命令或产生更多信息，代码就可能容易受到 SQL 注入攻击。SQL 注入本质上是通过使用相似语法打断预写命令并插入新命令。
