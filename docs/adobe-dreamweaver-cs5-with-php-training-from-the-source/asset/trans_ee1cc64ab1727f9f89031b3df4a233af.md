## 介绍

我的第一次接触 PHP 大约是 10 年前。当时，我已经拥有丰富的网站开发经验。我最初是在文本编辑器中编写 HTML，随后 Dreamweaver 成为我最喜欢的创作工具。新项目涉及每天发布超过 30 篇文章，这是一个订阅服务，因此网站需要密码保护且可搜索。普通网站无法满足需求，这时 PHP 来了。

PHP 让与数据库通信变得轻松，内容可以存储在数据库中，从而实现搜索。无需为每篇文章创建新页面，只需动态加载所需项目即可。您还可以密码保护站点的管理区或会员专区。PHP 还能发送邮件、上传文件，并将文件附加到邮件中——这些功能在本书中将一一讲解。PHP 也是三大最流行内容管理系统（Drupal、Joomla!、WordPress）的驱动力。

那么 Dreamweaver 在其中扮演什么角色呢？Dreamweaver 自 2002 年起对 PHP 的支持力度逐渐增强，主要通过服务器行为（server behaviors）自动生成用于基本任务的 PHP 代码。但其支持水平在 Dreamweaver CS5 中出现了质的飞跃。服务器行为仍然存在（参见 [第 6 课](#ch06.html#ch06)），但已让位于更高级的功能。

主要变化体现在代码提示、内嵌 PHP 文档（含示例）、变量自动补全、动态相关文件的自动发现，以及——或许最出色的——在不离开文档窗口的情况下查看和浏览 PHP 页面的能力。因此，现在可以在 Dreamweaver CS5 中直接为 WordPress、Joomla! 和 Drupal 设计样式，而无需生成静态页面。这些改进详见 [第 1 课](#ch01.html#ch01)，概括而言，它们既吸引设计师也吸引开发者。

PHP 的流行源于其易学性，能够快速取得实际成果。当然，像任何技能一样，成为专家需要时间和实践。Dreamweaver CS5 的新增 PHP 功能不仅帮助学习，而且在您逐步成长时会显得更加有用。Dreamweaver 是我首选的网站外观设计和文件组织工具，但我之前也会使用专门的 PHP 开发工具处理动态开发部分。Dreamweaver CS5 改变了一切，让我能在同一个程序中拥有两者的最好之处。

### 本书适用对象

本书属于“超越基础”的教材，您应已具备网站构建的基本理解，也应熟悉 HTML，因为 PHP 代码需要嵌入页面的结构中以显示动态输出。您不必记忆每个标签和属性，但如果分不清 `<ul>` 与 `<li>` 标签，就会感到困惑。所有示例文件和练习均采用 CSS 样式，但本书不以设计为重点。您不必懂 CSS 也能完成练习，但具备相关技能会让您的 web 开发能力更上一层楼。您还会发现，在阅读 [第 4 课](#ch04.html#ch04) 时创建新 WordPress 主题会更轻松。您无需事先了解 PHP。本书不以正式方式教授 PHP，但 [第 3 课](#ch03.html#ch03) 提供快速入门，帮助您编写 PHP 代码，而 [第 5 课](#ch05.html#ch05) 则讲解使用 MySQL（最流行的开源数据库）进行数据库设计的基本概念。

如果您已经掌握一些 PHP，那更好不过。本书进度较快， [第 7–12 课](#ch07.html#ch07) 大量使用 Zend 框架，这是一个强大的 PHP 组件库，能大幅减少创建动态站点的工作量。 [第 12 课](#ch12.html#ch12) 也使用了 jQuery JavaScript 框架。您无需事先了解 jQuery 或 JavaScript，但了解它们会让学习更轻松。

### 如何使用本书

时间宝贵，您可能想直接跳到解决当前问题的方案。如果您拥有丰富的 PHP 经验，这种做法或许可行。但大多数读者应从 [第 1 课](#ch01.html#ch01) 开始，按顺序逐课完成，因为每课都在前一课的基础上继续深入。若跳过某一课，可能会错过关键说明，导致需要回头补读。

每课开头的“大约时间”仅为完成练习的估算，请不要将其视为挑战，也不要因耗时过长而沮丧。每课内容丰富，请耐心吸收，并根据自己的节奏将课程分成更小的块来进行。

大多数课程包含参考章节，随后是实践练习。每一步骤既说明要做什么，也解释原因，旨在帮助您思考如何将相同技术应用于自己的项目。本书不是点按即得的操作手册，而是旨在激发您解决问题的能力。思考得越多，收获越大。

### 附带文件

随书光盘中包含完成练习所需的全部文件，唯一例外是 [第 2 课](#ch02.html#ch02) 中描述的 PHP/MySQL 开发环境以及 [第 12 课](#ch12.html#ch12) 中的 LightBox Gallery 小部件。PHP 与 MySQL 更新频繁，建议从官方渠道获取最新版本。对于 LightBox Gallery 小部件，练习的一个目标是向您展示如何安装 Adobe Widget Browser 并从 Adobe Exchange 下载小部件。
