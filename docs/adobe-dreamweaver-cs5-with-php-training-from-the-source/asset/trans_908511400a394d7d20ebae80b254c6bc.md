#### `Using a do… while loop`

在`do… while`循环中，条件的条件放在循环末尾，如下：

do {  

  // do something  

} while (condition is TRUE);

该结构确保循环体内的代码至少执行一次。`loops_02.php`中的示例如下：

$i = 1000;  

do {  

  echo $i++ . '<br />';  

} while ($i <= 10);

由于`$i`为1000，循环体内的条件永远不会为`TRUE`，因此只显示1000，随即结束。

Dreamweaver服务器行为使用此类循环来显示数据库结果，因为Dreamweaver会自动获取结果集的第一行，准备显示。后续行的获取作为条件，循环在无更多行时终止。若改用`while`循环，则第一行不会被显示。

#### `Using a for loop`

`for`循环虽然语法稍复杂，但几乎不可能无限循环，因为可以在循环头部同时设置计数器、条件和递增操作。

`loops_03.php`中的示例展示了如何输出1到10的数字：

for ($i = 1; $i <= 10; $i++) {  

  echo $i . '<br />';  

}

循环头部的三个用分号分隔的语句控制循环行为：

- 第一个语句在循环开始前执行，这里用于初始化计数器变量。
- 第二个语句设置循环继续的条件。
- 第三个语句在每次迭代结束后执行，这里递增计数器。

在此示例中，计数器从1开始，但更常见的做法是从0开始，因为数组下标从0开始，可使用数组大小作为条件。虽然`for`循环通常以1递增，但也可以使用其他增量，如`$i += 10`，或倒序递减，先设置较大的计数器值，每次递减。

可以构造更复杂的`for`循环，但这里展示的是最常见的实现。

### ![Image](graphics/tip.jpg)**TIP:**

所有示例均使用`$i`作为计数器变量。`$i`本身并无魔力，它是源自早期内存受限时代的惯例。如果`$i`已被占用，开发者通常会使用`$j`和`$k`作为后续计数器。

#### `Breaking out of a loop`

有时需要在满足特定条件时提前结束循环，例如查找特定值时。为此使用`break`关键字。

`loops_06.php`是对前文`while`循环的改写：

$i = 1;  

while ($i <= 10) {  

  echo $i++ . '<br />';  

  if ($i == 5) {  

    **break;**  

  **}**  

}

循环仅显示1到4，因为当`$i`等于5时循环被中断。

TIP：之所以没有显示5，是因为后置递增运算符先执行当前操作后再递增变量。脚本先显示4，随后将`$i`递增至5，`break`立即终止循环，导致5未被显示。

若仅想跳过当前迭代而非终止循环，则使用`continue`关键字。

`loops_07.php`示例如下：

$i = 1;  

while ($i <= 10) {  

  **if ($i == 5) {**  

    **$i++;**  

    **continue;**  

  **}**  

  echo $i++ . '<br />';  

}

输出为1-4和6-10。`continue`会让循环直接回到顶部，跳过剩余代码。`continue`必须放在需要跳过的代码之前，且在条件中递增计数器，否则会导致无限循环。

### `Including External Files`

在PHP中，将一个文件的内容包含到另一个文件是极大的时间节省。可以将多个页面共用的HTML或PHP片段存放在外部文件中，修改外部文件会自动反映到所有引用它的页面。这些合并操作在服务器端被称为*server-side includes* (SSI)，但在PHP中通常称为`includes`或`include files`。

可使用以下命令在另一个文件中包含文件：

- `include`
- `include_once`
- `require`
- `require_once`

为什么需要四种相同功能的命令？

使用`include`时，若外部文件缺失，脚本仍会继续执行；而`require`在找不到文件时会立即停止脚本，因此`require`表示“必须”。`include_once`和`require_once`则确保文件仅被包含一次，防止在大型项目中因多次包含导致的函数或类重复定义错误。

包含外部文件时，命令后跟一个包含相对路径的字符串，该字符串可以选择加括号。下面两种写法均合法：

include('../test_includes/header_02.html');  

include '../test_includes/header_02.html';

包含功能如此重要，必须掌握正确用法。下面的练习将展示如何避免常见错误。
