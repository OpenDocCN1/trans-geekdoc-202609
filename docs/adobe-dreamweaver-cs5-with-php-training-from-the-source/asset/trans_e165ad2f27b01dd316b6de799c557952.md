### Setting Up a Local Testing Environment

PHP 的根源在于 Linux，它的设计是模块化的。这使得服务器管理员可以自行决定启用哪些功能，就像购买新车时选择可选配置一样。额外功能通常需要在编译 PHP 时就被编译进去。从源码编译 PHP 需要专业知识。好在，已经有几个“一键包”帮你完成所有工作，它们不仅安装了功能丰富的 PHP，还安装了 Web 服务器、MySQL 和 phpMyAdmin。

不要被需要 Web 服务器的说法所迷惑。它并不意味着要设置一台独立的计算机。所谓 *Web 服务器* 只是一款运行在计算机上的软件，它等待网页请求并将其返回浏览器。MySQL 也是 *数据库服务器*，它只是一款响应数据库查询或修改请求的软件。对于本地测试环境，所有软件都可以安装在你现有的计算机上。服务器通常在后台运行，占用极少资源。如果需要，你也可以手动启动和停止服务器。

不需要特殊的硬件规格。只要你的电脑能运行 Dreamweaver CS5，就足够了。Windows 上的基本安装约占 250 MB，Mac OS X 需要大约两倍的磁盘空间。不过，你还需要空间来存放文件和数据库。如果分配 1 GB，应该足够。

在 99 % 的情况下，安装过程快速且无误。出现问题时，通常是因为你之前手动尝试安装其中一个或多个组件失败了。另一个常见原因是软件冲突：Web 服务器监听 80 端口，如果你的电脑上已有其他程序占用该端口，则服务器无法启动。若找不到占用端口的程序，只需将 Web 服务器改为其他端口进行测试即可。

安装软件后，务必检查其是否正常工作以及开发环境的设置是否正确。最后，你需要在 Dreamweaver 中定义站点并指明它在哪里找到测试服务器。Dreamweaver CS5 已经简化了站点设置过程。

由于本书的安装程序可能随时间变化，最好遵循在线说明，因为它们会更新以反映任何变动。Windows 与 Mac OS X 的选项不同，我会分别说明。
