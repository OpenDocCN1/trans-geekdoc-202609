foreach ($result as $row) {  
  // 处理每一行  
}

在循环内部，你通过 [oken和`$row`数组通过列名（column name）来访问每个字段，例如：$row[‘user_id’]。

如果不使用循环，你需要指定子数组的下标（从0开始）来访问，例如：$result[0][‘user_id’]。
