### 创建主/明细集

主/明细集是Web开发中最常见的设计模式之一。主页显示相关项目的列表，通常包含每个项目的简要描述，并链接到描述该项目的单独页面。创建主/明细集的技术与在[Lesson 11](#ch11.html#ch11)中构建的更新页面相同。主页使用循环显示数据库查询的结果，而明细页面的链接使用唯一标识符——通常是记录的主键——通过查询字符串传递。当然，任何与记录关联的唯一值都可以。

function getPlacesByState($read, $state_name) {  

$sql = $read->quoteInto(‘SELECT name, description, link_name  

FROM places  

INNER JOIN states USING (state_id)  

WHERE state_name = ?  

ORDER BY name', $state_name);  

return $read->fetchAll($sql);  

}
