# 7. Summary

This chapter has presented an overview of electricity production and implementation of Smart Grids in the Arctic region, performed analysis of Smart grid security requirements and perspectives on integrating forensic techniques with the blockchain to ensure the cybersecurity and resilience of the energy infrastructure. The use of the blockchain enables to create a single shared information space for investigating incidents in the Smart Grid. Necessary conditions for this are the follow: all device must be authenticated (this device will generate this data); all attacks must be very expensive for an attacker; the information environment should be transparent as possible.

This technology is still in its early stages and faces immaturity, with problems of scalability, and transaction processing delays, as as trust issues. However, because blockchain has some proven applications in the financial industry, there are some grounds to believe that it has a high potential to be widely adopted in Smart Grids.
