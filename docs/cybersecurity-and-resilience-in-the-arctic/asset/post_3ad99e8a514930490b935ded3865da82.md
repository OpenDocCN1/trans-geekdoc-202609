
## Blockchain Architecture

Today, there are different ways to implement software systems. The main decision in the implementation process is the definition of the architecture (the scheme of the organization of its components and the relationship between them). There are two basic types of software architecture - centralized and distributed. [4] In centralized software systems, one central component is allocated, which individual peripheral components are connected with. In a distributed system, a network of interconnected elements is formed without identifying any central element with control and coordination functions. Peer-to-peer networks are a type of distributed systems consisting of individual computers (nodes whose computational capabilities are directly accessible to all other nodes without central control (coordination).

The main advantages of a distributed system:

- higher computing power (defined as the sum of all computing powers of computers in the system);
- higher reliability (no single point of failure - SPOF);
- the possibility of increasing computing power (the computing power of the system can be increased by connecting additional nodes to it).

However, there is also the problem of the security of using distributed systems. Information exchange in the network involves the transfer and sharing of data, which creates a problem of data protection since foreign objects can use the network to illegally access information. Any distributed system should be provided with reliable information. The fewer restrictions on the network where information is exchanged between distributed nodes, the greater the threat to the security of the distributed system.

To solve these problems, there is the possibility of opposing architectural systems. Two types of use of the integrated (hybrid) architectural systems include (1) the central position of one of the nodes in a distributed system, and (2) a distributed system as a control of a centralized system.

A blockchain is a technology built to ensure rules, a continuous chain of blocks containing information and ensuring the integrity of distributed systems. Most often, copies of chains are stored on many different nodes (computers) independently of each other. The main goal of the blockchain technology is to implement and maintain integrity in distributed systems consisting of an unknown number of participants with an unknown level of reliability and trust, [5]

Cryptography is the basis of the blockchain, which ensures the operation of the system. The architecture of the blockchain assumes that between the participants of the network is based on the principles of mathematics and economics, that is, it is formalized. Cryptography also guarantees security, moreover, based on the transparency and verification of all operations.

Modern cryptography ensures that the blockchain transaction log is immutable, solves the task of authentication, and controls access to the network and data in the blockchain as [8]. Hash functions in blockchain guarantee the "irreversibility" of the entire chain of transactions. Hashing transforms an input array of arbitrary length into an (output) bit of specified length and performed by a specific algorithm. The function that implements the algorithm and performs the conversion is called the "hash function".

The fact is that each new transaction block refers to the hash of the previous block in the registry. The hash of the block itself depends on all transactions in the block, instead of sequentially passing the transaction to the hash functions, they are collected into one hash value using a binary tree with hashes (Merkle tree). Thus, hashes are used as a replacement for pointers in data structures: linked lists and binary trees.

Through the use of hashes, the general state of the blockchain — all transactions ever performed and their secrecy — be expressed in one single number: the hash of the newest block. Therefore, the property of the immutability of the hash of one block guarantees the immutability of the entire blockchain [9].

The ideal cryptographic hash function includes five main properties:

- 1. Determinism. With the same input, the result of the hash function will be the same (the same message leads to the same);
2. High speed calculation of the hash value for any given message;
3. The inability to generate a message from its hash value, except for attempts to create all possible messages;
4. Presence of avalanche effect. A small change in messages should change the hash values so widely that the new hashes do not match the old hash values;
5. The inability to find two different messages with the same hash values.

The security of a hash function can be ensured by the complexity of a certain mathematical problem if there is evidence that attacks at violating the requirements for it are as complex as solving this problem. Some tasks are considered unsolvable in polynomial time and can be used to construct such functions:

- Discrete logarithm
- Finding a quadratic deduction
- Factorization of integers
- The task of the subsets

By using the cryptocurrency market as an example, we know that the most threat to the blockchain is the 51% attack, which occurs when more half of the blockchain hash rate is controlled by one miner or mining pool. This makes it possible to reorganize the blocks and create an alternative blockchain, which ultimately leads to double spending of assets. The 51% attack on the blockchains of popular cryptocurrencies requires large investments. According to the website Crypto51, the cost of a 51% attack costs $355,883, on the Ethereum network costs $982, and on the Ethereum Classic costs $4,534. The cost of an attack depends on the computing power of the network.

A smart contract is to automate and reliably execute contractual relationships in the blockchain. This is a computer algorithm designed to enter and maintain commercial contracts in blockchain technology. Party signs a smart contract using methods to sign the transfer of funds in existing cryptocurrency networks. After signing by the party, the contract comes into force. To ensure the automated fulfillment of contractual obligations, a living environment is certainly required, which allows you to fully automate the execution of contract clauses. All contract terms must have a mathematical description and clear execution logic. In this regard, smart contracts have the task of formalizing the simplest of relationships, consisting of a small number of conditions. Having unharmed access to the objects of the contract, the smart contract monitors the achievement or violation of points and makes independent decisions based on the specified conditions. Thus, the basic principle of a smart contract is to fully automate and reliably enforce contractual relationships.

## Conclusion

Using blockchain technology to implement and maintain integrity in distributed peer-to-peer systems consisting of an unknown number of participants with an unknown level of reliability and trust will provide:

- The trust of the parties. The register is not changed and is only open for addition - records can be added only to this database and never be deleted or changed. It can be updated only by consensus or agreement on the status of data among peers.
- Decentralization and transparency. The blockchain database is distributed between several computers (nodes) that store full or partial copies of this. This eliminates the monopoly and a single point of failure. Provides trust between parties
- Security and fraud prevention. Entries on the blockchain are protected by cryptography. Each transaction is signed with a digital signature. If the record is changed, the signature becomes invalid. A peer-to-peer network immediately learns something that has happened. The blockchain does not have a single point of failure and cannot be changed by one [10].
