The fact is that each new transaction block refers to the hash of the previous block in the registry. The hash of the block itself depends on all transactions in the block, instead of sequentially passing the transaction to the hash functions, they are collected into one hash value using a binary tree with hashes (Merkle tree). Thus, hashes are used as a replacement for pointers in data structures: linked lists and binary trees.

Through the use of hashes, the general state of the blockchain — all transactions ever performed and their secrecy — be expressed in one single number: the hash of the newest block. Therefore, the property of the immutability of the hash of one block guarantees the immutability of the entire blockchain [9].

The ideal cryptographic hash function includes five main properties:

+   1. Determinism. With the same input, the result of the hash function will be the same (the same message leads to the same);
2. High speed calculation of the hash value for any given message;
3. The inability to generate a message from its hash value, except for attempts to create all possible messages;
4. Presence of avalanche effect. A small change in messages should change the hash values so widely that the new hashes do not match the old hash values;
5. The inability to find two different messages with the same hash values.

The security of a hash function can be ensured by the complexity of a certain mathematical problem if there is evidence that attacks at violating the requirements for it are as complex as solving this problem. By using the cryptocurrency market as an example, we know that the most threat to the blockchain is the 51% attack, which occurs when more half of the blockchain hash rate is controlled by one miner or mining pool. This makes it possible to reorganize the blocks and create an alternative blockchain, which ultimately leads to double spending of assets. The 51% attack on the blockchains of popular cryptocurrencies requires large investments. According to the website Crypto51, the cost of a 51% attack costs $355,883, on the Ethereum network costs $982, and on the Ethereum Classic costs $4,534. The cost of an attack depends on the computing power of the network.
