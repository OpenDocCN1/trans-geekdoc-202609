

# S. Kirchner 等人 / 治理与政府

另一方面，气候变化作为塑造北极发展的驱动力，其作用远非那么简单。北极地区受到与全球化、市场力量以及文化和社会转型相关的多种经济、社会和环境因素的影响。对于许多发展和活动而言，全球变暖引起的变化并不必然是决定性的考虑因素。

此外，关于气候变化对北极的具体影响，存在着高度的不可预测性和变异性。尽管旨在理解和评估气候变化影响及其带来的适应需求的研究已层出不穷，但仍存在重大的不确定性。北极地区同时发生的多种影响，以及气候变化对全球和跨区域的影响，意味着目前尚不清楚预期的人类经济活动增长是否将会产生益处并最终获益。一些社区和参与者可能在短期内获利，但尚清楚长期来看这种积极收益是否会持续。到目前，观察到的经济活动增长并未达到五到十年前对快速扩张的预期。航线转移非常罕见，且大多具有测试航行的性质，北极路线不太可能在任何方面与主要海航道具有竞争力。北极资源的出口正在增长，但这主要归功于俄罗斯新的离岸天然气项目。其他发展也存在，但它们仍处于推迟规划的阶段。气候变化即使清晰可见，也是市场状况和其他考虑因素的次要驱动力（AACA 2017；Stephan 等人 2016）。

高度的不确定性和复杂性——加上治理缺陷以及与气候和发展相关的政治——意味着政策制定和规制北极面临着特别艰巨的挑战。这增加了在法律和政策制定中引入适应性元素和韧性的更一般的困难。法律系统的静态性质使得在当环境发生快速变化并影响到环境影响评估、活动开展或受保护生态系统和物种状态时，治理自然、生物多样性和资源变得尤为困难。不断变化的气候为建立风险管理框架或空间规划带来了挑战（AACA，2017；Garmamani and Craig 2014）。

# 3 北极国际治理的机构与工具

### 3.1. 北极理事

北极理事（AC）是由八个北极圈国家组成的论坛，其中五个是北极海洋国家。北极理事成立于1996年，其创建的核心理念是为北极国家之间的合作、协调和互动提供一个框架，并在北极土住民社区的参与下共同应对北极问题；特别是北极的可持续发展和环境保护问题。北极理事拥有广泛的授权，负责涉及环境保护和可持续发展的地区性问题，而军事安全方面一直被认为在其职责范围之外。这并不意味着北极理事完全不处理安全问题。在实践中，对“安全”的定义往往超出了安全作为军事关注的狭窄范围。随着时间的推移，安全的定义已经扩大到涵盖了军事关注以外的问题：人类和环境方面塑造了安全议程，以应对环境污染引发的重要政策问题，这些问题为该地区的人类社区带来了多重挑战。北极理事参与了许多属于广义理解的人类安全的问题——特别是在适应、环境变化影响和韧性的背景下——尽管通常会避免使用“安全”一词。

北极理事并非传统意义上的国际组织。相反，北极国家将北极理事定义为一个作为“高层论坛”的政府间合作机构（北极理事，1996）。与任何其他监管机构不同，北极理事拥有一个实体，通过其工作组产生技术建议、指南和具有影响力的科学评估。它提供了一个建立信任的机制，通过该机制各国能够持续发展北极治理，有助于防止紧张局势。在过去的十年里，北极理事还被用于谈判北极特定的国际协议（关于海事和航空搜索、关于油溢响应以及科学合作），并尝试就减少污染的承诺达成共识。北极理事参与了许多属于广义理解的人类安全的问题——特别是在适应、环境变化影响和韧性的背景下——尽管通常会避免使用“安全”一词。
