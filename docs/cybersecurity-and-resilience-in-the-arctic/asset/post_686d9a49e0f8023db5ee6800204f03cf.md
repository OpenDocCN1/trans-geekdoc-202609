Linear random process with discrete time first appeared reviewed in [7]. Further, theory of linear random processes was developed in papers [8-12]. It is necessary to remark that currently linear random processes with continuous time are represented as autoregressive-moving average process with continuous time (CARMA).

According to [13] linear stationary process in the strict sense with discrete time $\zeta_t$ is the process embedded on a discrete lattice $Z = \{...,-1,0,1,...\}$ by the equation

$$\zeta_t = \sum_{\tau=0}^{\infty} \varphi(\tau)\zeta_{t-\tau} (5)$$

where $\{\varphi(\tau), t \in Z\}$ is a kernel of the linear process $\zeta_t$. It is assumed that

$$\sum_{\tau=0}^{\infty} \varphi^{2}(\tau) < \infty, \varphi(\tau) \equiv 0 \text{ if } \tau < 0 . (6)$$

$$\zeta_{t}, t \in \mathbb{Z} - is random process with discrete time and independent increments. It has infinitely divisible distribution $P\{\xi_{0}=0\}=1$. The random process is often called generating process for the process $\xi_{t}$.$$

The linear stationary autoregressive process (AR), by definition, can be represented

$$\xi_{t} + a_{1}\xi_{t-1} + \dots + a_{p}\xi_{t-p} = \zeta_{t}, (7)$$

or

$$\xi_{t} = -\sum_{i=1}^{p} a_{i}\xi_{t-i} + \zeta_{t}, \quad t \in \mathbb{Z}, (8)$$

where $a_{j}, a_{p} \neq 0, j=1, a_{1},\dots,a_{p},$ are real-valued autoregressive parameters; $Z$ - is a set of integers; $p$ is the order of autoregressive; $\zeta_{t}, t \in \mathbb{Z},$ is a generating process.

Roots of the characteristic equation

$$\Psi(z) = a_{p}z^{p} + \dots + a_{1}z + 1 = (9)$$

lie under the unit circle has a unique stationary solution (5). Usually generating process $\zeta_{t}, t \in \mathbb{Z}$ of linear AR processes and autoregressive-moving averages (ARMA) are considered as a sequence of independent identically distributed random variables [11]. According to Slutskij, a real random process specified in some probabilistic space $\Omega, F, P$ is a random process $\xi(t)$, $t \in (-\infty, \infty)$ for which such $T>0$ exists that t finite dimensional vectors $\Xi_1 = \{\xi(t_1), \xi(t_2), \dots, \xi(t_n)\}$ and $\Xi_2 = \{\xi(t_1+T), \xi(t_2+T), \dots, \xi(t_n+T)\}$ are stochastically equivalent in a wide sense, sense for all $n > 0$, where $t_1, t_2, \dots$ is a set of the process $\xi(t)$. Recall that two random vectors are stochastically equivalent in wide sense if every integer $n>0$ their partial distributions are coinciding, i.e.
$P(\omega(\Xi_1) \in B) = P(\omega(\Xi_2) \in B)$, $\omega \in \Omega, B \in F$.

### 2.4. Linear ARMA field

One of the possible model with feedback which could be used as a mathematical model resilience of Arctic system is vector ARMA process. The model could be represented as

$$\xi(\vec{r}) = \zeta(\vec{r}) - \sum_{p \in \Gamma} \zeta(\vec{r}-\vec{p})a(\vec{p}) + \sum_{q \in \Gamma} \zeta(\vec{r}-\vec{q})b(\vec{q}) (13)$$

$\zeta(\vec{r})$ - is the generating vector process which defined on the set of spatial integers $Z^{n}$; n is the dimensionality of the set; $a(\vec{p})$ - are the autoregressive vector parameters; $b(\vec{q})$ - are the moving average vector parameters; $\Gamma$ - is the order summation indices, it has dimension $n$ $(\Gamma \in Z^{n})$; $\vec{p}$ is the vector of autoregressive order; $\vec{q}$ is the vector of moving average order; $\vec{r}$ is the vector of dimension $n$

$$\Psi(Z) = \sum_{p \in \Gamma} a(\vec{p})Z^{p} (15)$$
