*   **低估了数据的复杂性。** 如果有许多不同的工具处理过数据，数据很少以整齐的格式存在供扩展。在处理之前，通常需要一个清洗过程对数据进行净化。
*   **低估了工作模式中效率的价值。** 理解工具的快捷键并深入研究任何工具的功能会让使用户变得更加精通。在学习新工具时，孩子的奇心是正确的态度。
*   **低估了经验的价值。** 没有什么能比得上经验。在纸面上或理论上学习是不够的。试错是获得经验提高效率的关键。
*   **没有为工作选择合适的工具。** 任何分析工具的使用应该有一个明确的目的，即使是通用分析工具也是如此。
*   **对数据做出错误的假设。** 一个常见的错误是假设存在正态分布，而实际上并不存在。通过可视化检查数据的各个方面可能很有用。在这种情况下：使用直方图来检查该分布。如果我们需要，可以对数据进行修剪（排除数据）、转换数据（例如使用幂变换——这是一种稳定方差的有效技术，使数据更符合分布，或提高关联性测量的有效性）、缩尾处理（即减少极端离群值的影响）或数据插补（即用替代值替换缺失数据，通常为平均值）。
*   **工具没有显示预期的答案。** 对于此类疑虑，值得检查数据输入是否规范、是否对该数据输入做出了正确的判断（例如，我们是否假设了一个不存在的正态分布？）、工具的使用是否正确，最后（也许这可能是最不愿面对的），数据本身并不包含我们想要看到的答案（但我们看到的确实是正确的）。
*   **在可视化中不当且无理地使用视觉编码。** 变量的使用不当，或设计不符合常的颜色事实（例如，红色和绿色在靠近放置时并不互补，特别是盲人可能会混淆这两种颜色）。人们能够区分不同的颜色范围，但非常相似的颜色（尤其是用于小尺寸视觉变量的颜色）会降低用户快速区分变量的能力。
*   **3D 可视化总是比 2D 好。** 默认做出这种假设是危险的。并非所有数据都如此。在许多情况下，数据的 2D 表示是完全合适的，它可以最终投影到 2D 图像（显示器或投影仪）上；对于 3D 场景，数据可能会重叠，限制屏幕上可见的信息量。最后，必须确定可视化的目的，以及 3D 还是 2D 表示最符合逻辑。

## 3.5. 分析：实际关注问题

分析有其益处，但当我们使用分析时，有许多实际挑战需要克服——特别是当我们设想分析成为极地的核心时。这些可能包括：

*   **原始数据只能传达有限的信息。** 数据只告诉我们观察到了什么，很少告诉我们如何发生的。这必须通过推断或推理得出。目前允许此类推理的工具并不特别成熟。
*   **现实世界模型需要频繁更新。** 世界在不断变化，任何数据在到达分析师眼中时都可能过时。工具需要通过持续的情境感知更新来提高其理解数据的能力，这些更新在应对威胁或响应事件时是有意义的。
*   **知道何时通过更多观察来进一步评估状况。** 这在安全事件或自然力量，或观察现实世界中的潜在危险时尤其适用：我们可能会看到威胁持续，以便收集更多关于情况的的情报。然而，在某个阶段必须采取行动。
*   **知道何时以及缺少了什么。** 完整的情境感知是缺失的，但对于极地的任何任务，能够对何何放置传感器、部署多少种技术以及收集哪些传感器数据产生直觉，这是来自经验。随着物联网设备的普及，对于极地的任何任务，可以假设它们将得到部署。
*   **错误使用分析会导致误导信息。** 这一点与前述对数据做出错误假设相一致。使用机器学习算法或可视化会导致向分析者传递错误信息。
*   **数据点数量至关重要。** 极地非常广阔，传感器可能分布稀疏。拥有足够的数据点对于良好的情境覆盖是有益的。
*   **数据中的噪声。** 随着任何传感器从现实世界获取测量值，我们面临着获取噪声数据（不精确和不准确测量）的风险。这同样适用于产生误报的网络系统。
*   **分析的交付与响应。** 目前，大多数分析工具是定制的、深度集成到环境中的，或者是需要更有意义地使用的通用系统。
*   **并非一切都能被量化。** 这对许多人来说都是挑战性的。之前的工作在某些高级理论和方法目标方面取得了进展，但仍然缺乏进展。

## 4.1. 建议

分析工具的效用是否足以支持分析师、风险所有者决策者尚待确定。以下是调查建议的大纲。

*   **为韧性主题设定目标。** 任何可能路径的核心目标都是开发实用的解决方案，以提高主动和反应性的系统韧性，这在学术和科学研究上有坚实的基础。为了实现这一目标，需要在理论和工具实现方面取得基础性突破。一些目标可能包括：

*   **实证目标。** 识别哪些传感器和关键指标（KPI）最适用于极地景观分析，以及如何部署它们为决策创建实用的实证。有必要收集并评估不同类型的现实世界系统在异质空间中如何运作，它们在韧性需求上有何相似和不同之处，并识别影响性能的关键因素（包括可用性和功能关系）。

*   **理论目标。** 从实证中建立可靠的、公认的韧性理论。我们需要为支持韧性研究的方法开发建立可靠的理论基础。可以通过展示韧性的缺乏如何影响现实世界系统，以及新方法如何有效衡量、评估、改进和传播韧性来实现。可靠的理论可以促进知情决策，从远来看有助于最佳实践。

*   **方法论目标。** 测试假设和识别潜在风险的方法（来自理论）。我们需要开发一套基于可靠理论的模拟、红队演习、威胁建模、分析工具和政策制定，供决策者尝试新想法并模拟担忧，以识别任何假设是否有理由引起真正的关注。例如：如果提议了任何新的运输路线，我们希望运行初步
