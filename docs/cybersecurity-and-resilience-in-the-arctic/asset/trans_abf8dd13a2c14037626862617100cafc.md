# 治理与政府

## 1 引言

北极包括海洋区域（无论在国家管辖、主权还是主权范围内）以及北极国家的领土，其中一些国家是联邦制。北极地区居住着原住民，他们追求自决。几个世纪以来北极一直受到经济开发，各种地区、外部和全球参与者在此运营。因此，该地区在多个层面进行治理：全球、国家、省/州、市和社区层面。政府或市政府制定的规则与海岸法规以及国际标准相互作用。今天的国际法很大程度上体现在1982年《联合国海洋法公约》（UNCLOS），除美国外所有北极国家都遵循该公约。北极海洋反过来分为两类：1）属于国家主权的区域，例如经济区或大陆架；2）不受国家管辖的区域，例如公海和深海。在北极的情况下，这些区域一直难以进入，这种情况由于气候变化可能会发生改变。预计未来几十年内多年冰可能会消失（Wadhams, 2017: pp. 3等），这意味着未来的北极海洋将类似于波罗的海，“加冰船和破冰护送队在冬季可以安全运行”（Byers, 2010: para.5）。北极丰富的自然资源（特别是化石燃料，Byers, 2010: para.8）以及该地区由于气候变化而变得更容易进入的战略价值，也吸引了广泛的关注。
