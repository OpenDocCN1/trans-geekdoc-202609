# Blockchain Architecture

Today, there are different ways to implement software systems. The main decision in the implementation process is the definition of the architecture (the scheme of the organization of its components and the relationship between them). There are two basic types of software architecture - centralized and distributed. [4] In centralized software systems, one central component is allocated, which individual peripheral components are connected with. In a distributed system, a network of interconnected elements is formed without identifying any central element with control and coordination functions. Peer-to-peer networks are a type of distributed systems consisting of individual computers (nodes whose computational capabilities are directly accessible to all other nodes without central control (coordination).

The main advantages of a distributed system:

+   * higher computing power (defined as the sum of all computing powers of computers in the system);
* higher reliability (no single point of failure - SPOF);
* the possibility of increasing computing power (the computing power of the system can be increased by connecting additional nodes to it).

However, there is also the problem of the security of using distributed systems. Information exchange in the network involves the transfer and sharing of data, which creates a problem of data protection since foreign objects can use the network to illegally access information. Any distributed system should be provided with reliable information. The fewer restrictions on the network where information is exchanged between distributed nodes, the greater the threat to the security of the distributed system.

To solve these problems, there is the possibility of opposing architectural systems. Two types of use of the integrated (hybrid) architectural systems include (1) the central position of one of the nodes in a distributed system, and (2) a distributed system as a control of a centralized system.

A blockchain is a technology built to ensure rules, a continuous chain of blocks containing information and ensuring the integrity of distributed systems. Most often, copies of chains are stored on many different nodes (computers) independently of each other. The main goal of the blockchain technology is to implement and maintain integrity in distributed systems consisting of an unknown number of participants with an unknown level of reliability and trust, [5]

Cryptography is the basis of the blockchain, which ensures the operation of the system. The architecture of the blockchain assumes that between the participants of the network is based on the principles of mathematics and economics, that is, it is formalized. Cryptography also guarantees security, moreover, based on the transparency and verification of all operations.

Modern cryptography ensures that the blockchain transaction log is immutable, solves the task of authentication, and controls access to the network and data in the blockchain as [8]. Hash functions in blockchain guarantee the "irreversibility" of the entire chain of transactions. Hashing transforms an input array of arbitrary length into an (output) bit of specified length and performed by a specific algorithm. The function that implements the algorithm and performs the conversion is called the "hash function".
