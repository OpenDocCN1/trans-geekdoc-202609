## 4.3 日志与监控

在该领域，日志（Logging）被定义为网络组件使用的被动机制，它们定期或在满足某些条件时发布通知（日志消息）（NCSC, CSC）。监控（Monitoring）被定义为获取系统和网络状态信息的主动探测。

日志是网络和端点调查中最广泛使用的来源。它们包含了日志创建者处理或观察的特定应用程序或平台信息。日志广泛可用，并且可以在本地进行处理以供分析。需要进行解析以添加上下文。此外，如果日志尚未聚合，在开始分析之前，寻找特定的日志条目可能会花费大量的时间和精力。

日志本身不是用于检测攻击。与监控结合使用，可以在检测到已知模式时生成警报和通知。动态主机配置协议（DHCP）服务器日志记录分配的 IP 地址，Web 服务器日志存储有关 Web 服务器页面访问者的网络信息，网络日志存储网络流量元数据，如 IP 地址、连接日期和时间、使用的端口和协议。此外，大多数日志包含被视为个人信息的 IP 地址，因此它们应该受到保护，且保留时间不应超过严格需要。在调查期间，事件日志提供宝价值的信息，例如系统访问（特别是服务器日志）、启动和关闭时间、错误和问题、与网络功能的信息（如 DHCP 租约历史），或网络日志包含网络活动记录（如远程日志）。

## 4.4 智能电网中的取证问题

在取证过程中，可能会发生若干实际问题，应当考虑以下因素（Kotsiuba 等人，2019）：

- 应该提前准备好完整的取证工具包，以避免搜索和打印表单或擦除/覆盖媒体的必要时间。当所有媒体、工具和电缆都可用时，工具包就是备的。
- 为（日志）文件的存储选择合适的文件系统，考虑到 FAT16 和 FAT32 文件系统的最大大小分别为 2GB 和 4GB，而 Linux 和 OSX 格式几乎无法从 Microsoft Windows 访问。
- 考虑合格员工的可用性，他们能够复制或导出取证文件（日志文件）。
- 绝不要对原始证据工作。在检查之前，应制作一份用于取证分析的完整副本。这种保护是因为工作副本可能会出错错误，或者需要进行比较，将需要比较原始件和副本件。
- 确保对媒体进行取证清洁，以防止原始副本受损。
- 确保证据的安全存储。
- 禁止第三方访问证据。

此外，由于私有网的参与，智能电网系统不断演变。每天都可以添加新连接，改变配置和数据通道。
