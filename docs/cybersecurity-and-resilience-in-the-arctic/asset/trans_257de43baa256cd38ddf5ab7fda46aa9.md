# 情感团结任务

在寻找资源的同时，情感宣泄和情感共享是后创伤事件恢复阶段社会应对策略中的一个复合元素。集体情感发作的特殊之处在于，它们引发了情感反馈回路，其中集体参与、增强的社会归属感、价值观和亲社会态度与更高水平的团结表达相关，并预示了社区的社会韧性水平。[50] 在灾害防备模型中，纽带（bonding）、桥接（bridging）和链接（linking）是韧性社区内的主要资产[51]，在这些社区中，协调活动、连接感和共同身份认同构成了对社会韧性的关键贡献。[51]。在应对不利事件时，人们会寻求利用网络内他人的意见和情感，以建立主观的意义构建。相对于聚会点的积极群体形象（外群体认同动机），旨在维持内部身份认同动机。随后，这些群体认同过程解释了为什么道德情感表达往往会病毒式传播。

情感反应和团结表达与对灾害幸存者社会行为的线下研究一致，在研究中，提供协调的工具性社会支持是集体效能的关键中介和预测因素。[55] 计算机和互联网媒介的通信通过文本和视觉内容（例如表情符号、图像和视频）促进了情感分享。社交网络让志同道合的用户分享意见、信息和经验。

标签（Hashtags）和支持性平台如 #JesuisCharlie、#BringBackOurGirls、#MeToo 和 #BlacklivesMatter 是数字空间的良好例子，促进了愤怒、道德关注和集体团结的情感表达。标签行动主义（Hashtag activism）最早于 2017 年，指的是使用根据团结表达分类的即时 Twitter 标签，通过社交媒体平台对情感性目标事业的公共支持进行病毒式动员。在 2014 年巴黎《查理周》杂志和一家犹太杂货店遭到袭击后，标签 #JeuisCharlie 在高峰时期每分钟被使用 6,500 次，并在 24 小时内出现在 340 万条推文中[56]，包含了对袭击的情感控诉、绝望和决心[57]、对言论和表达自由的支持、同情和哀悼、恐惧和愤怒的表达、对宗教信仰的担忧以及对反恐怖主义的判断。[158]。#JeuisCharlie 发布后，许多模仿的 #Jeuis... 运动加入了其中。口号的作者 Joachim Roncin 发现他的口号之所以病毒式传播，是因为“当发生可怕的事情时，让我们聚在一起”。[59]

同样，#BringBackOurGirls 标签是另一种病毒式团结的表达，它是 2014 年博科哈拉斯叛组织（Boko Hamas）绑架 276 名奇比科克（Chibok）高中生后，阿布贾街头上的公共抗议和非正式对话。然而，公众抗议演变成了一场全球运动。尼日利亚社会深层的分裂跨越了代、性别、民族和宗教，这种全球团结回应作为尼日利亚活动人士的支持放大器，随后重新赢得了国际外交的关注并向尼日利亚政府施加压力。[60]。#BringBackOurGirls 的独特之处在于其有机性，它在奇比科克女孩父母绝望地带回他们的英雄的情况下，成为了公众公共抗议的宣泄口。随着当地和全球活动人士的持续坚持，该运动演变成了有效的公众动员工具，有助于追究尼日利亚政府的责任，并聚集国际关注以施加更大的外交压力。

许多研究致力于对线下背景下社会韧性的研究和理解，但对在线环境的研究较少。随着 ICT 的普及使用和新型混合威胁的出现，这是一种忽视。通过跨学科文献综述和实践案例，本文探讨了在线社区如何应对当代的出现威胁。识别出三种不同的行为模式：
1) 自组织、众筹、动员和数字工具包
2) 情感团结任务
3) 道德恢复

本文认为，观察到的在线模式产生了具有数字韧性的积极社会资本。由于技术的快速创新、ICT 的普及使用以及混合威胁的形式可能会持续，理解这些韧性实践的有效教训对于未来的政策制定和我们防御未来威胁的准备至关重要。
