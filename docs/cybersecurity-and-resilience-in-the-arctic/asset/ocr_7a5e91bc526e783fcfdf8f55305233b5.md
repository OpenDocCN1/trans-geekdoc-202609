One of the main issues in digital forensics is the evidence management. In this context, DLT is the perfect technology to make forensics widely used and to add datasets to a new property and application. Blockchain logs the truth; these datasets are entirely trustworthy. It allows utilities to monitor every instance of data structure created by an application and monitors accesses, when the situation is free, and when the memory in which it was stored was overwritten.
