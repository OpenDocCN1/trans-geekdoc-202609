# 3.3. Machine Analytics

Machine analytics means to use computers to do bulk processing of data to automatically discovering useful information in large data repositories, while machine learning deals with programs that automatically improve with experience. We can use these techniques and automation broadly to identify statistical information such as: what are the KPIs of a system, and is the system performing differently with some statistical significance? Or indeed, most of the metrics proposed by ENISA [20] could be computed, such as: mean to incident discovery, mean to patch, management coverage, vulnerability coverage over all metrics.
