# 2.4. Linear ARMA field

One of the possible model with feedback which could be used as a mathematical model resilience of Arctic cyber system is vector ARMA process. The model could be represented as

$\xi(\vec{r}) = \zeta(\vec{r}) - \sum_{p \in \Gamma} \zeta(\vec{r}-\vec{p})a(\vec{p}) + \sum_{q \in \Gamma} \zeta(\vec{r}-\vec{q})b(\vec{q})$ (13)$

$\zeta(\vec{r})$ - is the generating vector process which defined on the set of spatial integers $Z^{n}$; n - is the dimensionality of the set; $a(\vec{p})$ - are the autoregressive vector parameters; $b(\vec{q})$ - are the moving average vector parameters; $\Gamma$ - is the order summation indices, it has dimension $n$ $(\Gamma \in Z^{n}$); $\vec{p}$ is the vector of autoregressive order; $\vec{q}$ is the vector of moving average order; $\vec{r}$ is the vector of dimension $n$

Supposed to

$M_{\zeta}(\vec{r}) = 0, \quad \delta_{r_1,r_2} = \begin{cases} r_1 = r_2 \ r_1 \neq r_2 \end{cases}$ (14)$

If roots of the characteristic equation

$$\Psi(Z) = \sum_{p \in \Gamma} a(\vec{p})Z^{p}$ (15)$

lie inside the unit ball $|Z^{n}| < 1$ ($n$ is dimension of the equation) the equation has an unique solution.

We considered the general case of the generating random field. Generating field is a random field with multidimensional values in the case.
