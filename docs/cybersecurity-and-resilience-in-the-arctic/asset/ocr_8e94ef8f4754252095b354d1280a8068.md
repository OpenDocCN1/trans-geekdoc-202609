$$\zeta_{t}, t \in \mathbb{Z}$ - is random process with discrete time and independent increments. It has invisinitely divisible distribution $P{\xi_{0}=0\}=1$. The random process is often called generating process for the process $\xi_{t}$.$

The linear stationary autoregressive process (AR), by definition, can be represented

$$\xi_{t} + a_{1}\xi_{t-1} + \dots + a_{p}\xi_{t-p} = \zeta_{t},$ (7)$

or

$$\xi_{t} = -sum_{i=1}^{p} a_{i}\xi_{t-i} + \zeta_{t}, \quad t \in \mathbb{Z},$ (8)$

where $a_{j}, a_{p} \neq 0, j=1, a_{1},\dots,a_{p},$ are real-valued autoregressive parameters; $Z$ - is a set of integers; $p$ is the order of autoregressive; $\zeta_{t}, t \in \mathbb{Z},$ is a generating process.
