

## V. Zvaritch / 某些数学模型

在 $f_{\tilde{z}}(u,\tilde{r}) = \text{im}_{\tilde{z}} \sum_{q \in \Gamma} \phi(\tilde{r}) + \sum_{q \in \Gamma} \int_{-\phi}^{\infty} (e^{iux\phi(r)}}-1-iux\phi(r)) \frac{dK_{\tilde{z}}(x)}{x^2},$ (16)

其中参数 $m_{\tilde{z}}K_{\tilde{z}}(x)$ 定义为随机场 $\xi(\tilde{r})$ 的特征函数，$\phi(\tilde{r})$ 是线性随机场 $\xi(\tilde{r})$ 的核。$K_{\tilde{z}}(x)$ 是单调有界函数，满足 $K_{\tilde{z}}(-\infty)=0$。

正则随机场在随机场理论中起着重要作用。如果自回归随机场可以表示为，则称其为正则随机场：

$$\xi(\tilde{r}) = \sum_{q \in \Gamma} \phi(\tilde{q})\xi(\tilde{r}-\tilde{q})$$ (17)

如果自回归随机场 $\xi(\tilde{r})$ 是正则的，其相关函数可以表示为：

$$R(\tilde{s}) = \sigma^2 \sum_{0 \leq q} \phi(\tilde{q})\phi(\tilde{q}+\tilde{s}), \quad \tilde{s},\tilde{q} \in \Gamma$$ (18)

其中，$\sigma^2_{\xi} = M{\xi(\tilde{r})\xi(\tilde{r})}$。正则自回归场的相关函数满足 Yule-Walker 方程：

$$a(\tilde{p} \in \Gamma)R(\tilde{s}-\tilde{p}) = \begin{cases} \sigma^2_{\xi} \phi(\tilde{s}) & \text{if} \tilde{s} \geq 0 \\ 0 & \text{if} \tilde{s} < 0 \end{cases}$$ (19)

其中 $\tilde{W} = (\tilde{W}_1,...,tilde{W}_n)$ 是自回归阶数，定义如下 $\tilde{W}_j = \max_{\tilde{p}_j} |j_{\tilde{p}_{a,1,...,n}} \neq 0|$ $(j=1,2,...,n)$。

论文 [16] 中考虑了自回归场参数的某些方法。

大多数分析随机场的现有方法假设它们具有平稳性和同质性。实验场可能不是平稳的，在对真实场进行自回归分析之前，有必要通过实验评估其平稳性和同质性。

政府间气候变化专门委员会（IPCC）提供的证据表明，对长期影响进行规划最终将拯救更多生命，并比在灾害发生时才处理（以及随后的恢复）要好。这不仅涉及基础设施投资，还涉及更广泛的战略空间规划。

为了理解韧性（resilience）和恢复能力，首先了解一个国家和地区已拥有哪些信息是非常重要的 [19]。目前存在多种资源可以提供全球范围内风险水平、脆弱性、社会经济状况、气候波动和变化的影响及后果的概述。另一个独立的挑战是确保有足够的努力和相关工具来解释这些风险信息并进行建模以供决策；也就是说，风险信息的可用、现有信息的协调和通信也很重要，但具有挑战性 [17]。
