In $f_{\tilde{z}}(u,\tilde{r}) = \text{im}_{\tilde{z}} \sum_{q \in \Gamma} \phi(\tilde{r}) + \sum_{q \in \Gamma} \int_{-\phi}^{\infty} (e^{iux\phi(r)}}-1-iux\phi(r)) \frac{dK_{\tilde{z}}(x)}{x^2},$ (16)

where parameters $m_{\tilde{z}}K_{\tilde{z}}(x)$ is defined the characteristic function of the random field $\xi(\tilde{r})$, $\phi(\tilde{r})$ is the kernel of linear random field $\xi(\tilde{r})$. $K_{\tilde{z}}(x)$ is a non-decreasing bounded function that $K_{\tilde{z}}(-\infty)=0$.

Regular random field plays a significant role in the theory of random fields. An autoregressive random field is called regular if it can be represented as:

$$\xi(\tilde{r}) = \sum_{q \in \Gamma} \phi(\tilde{q})\xi(\tilde{r}-\tilde{q})$$ (17)

If autoregressive random field $\xi(\tilde{r})$ is regular, its correlation function can be represented as:

$$R(\tilde{s}) = \sigma^2 \sum_{0 \leq q} \phi(\tilde{q})\phi(\tilde{q}+\tilde{s}), \quad \tilde{s},\tilde{q} \in \Gamma$$ (18)

where, $\sigma^2_{\xi} = M{\xi(\tilde{r})\xi(\tilde{r})\}$. Correlation function of regular autoregressive field satisfies the equation of Yule-Walker:

$$a(\tilde{p} \in \Gamma)R(\tilde{s}-\tilde{p}) = \begin{cases} \sigma^2_{\xi} \phi(\tilde{s}) & \text{if} \tilde{s} \geq 0 \\ 0 & \text{if} \tilde{s} < 0 \end{cases}$$ (19)

where $\tilde{W} = (\tilde{W}_1,...,tilde{W}_n)$ is autoregressive order, which is defined as follows $\tilde{W}_j = \max_{\tilde{p}_j} |j_{\tilde{p}_{a,1,...,n}} \neq 0|$ $(j=1,2,...,n)$.

Some methods of the parameters of autoregressive fields are considered in paper [16].

Most existing methods for analyzing random fields assume their stationarity and homogeneity. Experimental fields cannot be stationary and before moving to an autoregressive analysis of a real field it is necessary to experimentally evaluate its stationarity and homogeneity.
