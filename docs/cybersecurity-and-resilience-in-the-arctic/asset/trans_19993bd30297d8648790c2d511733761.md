

# S. Kirchner 等人 / 治理与政府

网络和市场共同塑造了北极的发展。治理可以被理解为“参与到相互互惠依赖的复杂关系中的独立行动者的反思性自我组织”（Jessop 2003）。因此，它涵盖了在命令模式（通过层级政府）、对话模式（通过网络）和交换模式（作为市场的基础并受市场力量驱动）范围内发生的所有治理过程。虽然政府权威被赋予了责任和问责，但从治理的角度来看，它在现代世界受到了局限或转型。这正是因为了各种参与者的存在以及市场的运作，包括这些市场运行的自主规则。只有极权主义威权政权才声称有将所有治理限制在政府命令过程的能力。

上述北极治理格局的复杂性以及该地区发生的变化意味着今天有许多不同的参与者参与了北极治理。并非所有这些参与者都来自北极，也不符合上述多维特征。从治理的角度来看，国家政府是强大的行动者，但也被私营部门、市场力量以及参与互依赖网络的非国家者所加入。此外，不同国家之间的网络为长期国际合作奠定了进一步的基础。考虑到对该地区日益增长的兴趣以及北极国际合作的重要性，这并不意外。事实上，北极长期以来一直是和平合作的。国际合作的特征是西方与俄罗斯联邦之间明显的例外性。北极例外性的概念建立在各种北极国家和非共同利益的互依赖网络之上，以及对监管地区的价值之上（Byers 2017）。然而，正如一些作者（Käylä 和 Mikkola 2015）指出的，北极不能被视为一个封闭系统，因此感知到的例外性可能是表面的。在北极的极端环境中，国际合作保持着一种优先于地方考虑的合作方式。在两个领域中，北极国内政治的风险不应被忽视。2019年的北极理事会会议——作为北极国际治理和合作的关键论坛——在芬兰的罗瓦尼米举行，这是外部动态影响北极合作的潜力的一个良好例子。秘书长对中国在北极的存在以及将气候变化语言纳入文件的立场表达了关切。除了北极国家外，原住民在塑造北极未来方面也发挥着积极作用。这在北极理事会中是可见的，在那里原住民组织拥有独特地位——永久参与者，以及对北极日益增长的兴趣的外部。

北极的众多行动者与政府可以支配的一系列工具相对应。虽然政府可能关注国家、亚国家和国际层面的北极治理，非国家行动者可能发现为软法或技术标准的创建提供投入（通过《联合国海洋法公约》UNCLOS，参见 IMO 2014）。本章旨在为快速变化的多重挑战的北极治理提供介绍，以及政府可用的工具。为此，我们将从治理的角度观察机构。我们将关注现有国际合作。本章关注北极治理的国际层面。然而，北极的现实和发展主要由北极国家内的行动塑造。除了对国际治理的主要关注外，我们还讨论了在其他层次发生的动态，特别是与政策定的联系。

## 2 北极治理挑战

### 2.1. 法律在北极的有效性

Sheeban (2018) 强调，“北极人口面临的[众多]挑战不仅与现实政治理论所假设的军事力量有关，与更广泛的经济、环境和社会不安全感有关。”这在原则上也适用于北极的其他部分，而这些方面是本章治理有效性讨论的焦点。解决这些需要国际合作和北极治理，特别是通过使用条约法治理北极空间。法律作为监管工具面临着许多挑战。首先，在民主社会中，法律对社会的需求是反应性的，民主社会可能将其视为政府维持社会的工具。并非所有位于北极或对北极有重大利益的国家都是不仅在纸面上而且在实践中致力于法治和人权的民主国家。对法治和受监管影响的人的人权的不同程度的尊重，或者甚至完全缺乏保障的人权或法治，也表明同一种工具在所有情况下可能并不同样适用。由于国际条约需要共识，它们被利用得很少。虽然预防方法在（国际）环境法背景下在北极发挥着日益重要的作用，但北极基于条约的国际合作的预防维度是有限的。这意味着国际条约法缓解北极风险的能力是有限的。正如国际安全经验所示，国际法律的发展往往是由产生负面影响的特定事件触发的；这些事件凸显了进一步（法律约束性）监管的需求。此外，使用（国际）法律管理风险相关问题需要向规范创建过程注入技术专长。

### 2.2. 决策者对北极发展的了解

专业知识问题强调了跨学科合作和信息不间流动的需求。这特别适用于不同专业领域和不同知识体系（传统、通俗和科学知识）之间的信息交换。这种合作有助于提高意识并对国际法预期解决的环境、社会、经济、文化和其他其他方面的问题的理解。对问题本身以及个人视野的意识在北极特别相关，因为许多治理决策远离受这些决策影响的地方和人。城市中心与偏远定居点之间的距离不仅是地理上的，也是文化上的。例如，北极地区是决策者不熟悉的生计和土地。北极可能比世界其他部分、其他海域甚至北极的某些地区带来不同的挑战和不同的实践。在华盛顿、莫斯科、斯德哥尔摩或布鲁塞尔做出的决策（参见 2012 和 Stepien/Kivooura, 2017: 第16页及以后）极大影响了住在数千英外边缘的人的生活。位于权力中心的决策者缺乏专业和北极经验，需要通过北极专家和居民提供的投入来补偿。理想情况下，与北极权利持有者、利益相关者和专家接触将允许决策者更好地理解和考虑北极的多样性、北极的多重定义以及特定地区或城市面临的挑战。这样做让决策者意识到北极没有单一定义，而且在北极，城市环境提出的问题与偏远定居点不同。不同的监管方法被用于应对这些事实挑战，例如私人行动者参与标准的创建、不同北极国家不同集权化程度等。

### 2.3 应对气候变化

北极治理的另一个挑战是北极国家对今天北极面临问题的评估存在差异。气候变化不仅限于海洋，还影响生物圈和多年冻土，并对传统生计构成威胁（AACA, 2017）。然而，一些政府将北极可进入性的增加视为经济机会。
