必须考虑到北极的许多影响因素是周期性的。例如，冰层鸣响声取决于月相，海豹数量取决于极熊。

如果系统参数的估计是在等概率间隔内进行的（可以是小时、天、周、月），则应应用离散时间的概率数学模型。

离散时间线性随机过程最早出现在[7]中。此外，线性随机过程理论在论文[8-12]中得到了发展。需要指出，目前连续时间线性随机过程表示为连续时间自回归移动平均过程（CARMA）。

根据[13]，严格意义上的离散时间线性平稳过程 $\zeta_t$ 是通过方程嵌入离散晶格 $Z = \{...,-1,0,1,...\}$ 的过程：

$$\zeta_t = \sum_{\tau=0}^{\infty} \varphi(\tau)\zeta_{t-\tau} (5)$$

其中 $\{\varphi(\tau), t \in Z\}$ 是线性过程 $\zeta_t$ 的核。假设：

$$\sum_{\tau=0}^{\infty} \varphi^{2}(\tau) < \infty, \varphi(\tau) \equiv 0 \text{ if } \tau < 0 . (6)$$

$$\zeta_{t}, t \in \mathbb{Z} - 是具有独立增增的离散时间随机过程。它具有无限可分分布 $P\{\xi_{0}=0\}=1$。该随机过程通常被称为过程 $\xi_{t}$ 的生成过程。$$

线性平稳自回归过程 (AR) 根据定义可以表示为：

$$\xi_{t} + a_{1}\xi_{t-1} + \dots + a_{p}\xi_{t-p} = \zeta_{t}, (7)$$

或者

$$\xi_{t} = -\sum_{i=1}^{p} a_{i}\xi_{t-i} + \zeta_{t}, \quad t \in \mathbb{Z}, (8)$$

其中 $a_{j}, a_{p} \neq 0, j=1, a_{1},\dots,a_{p},$ 是实值自回归参数；$Z$ - 是整数集；$p$ 是自回归阶；$\zeta_{t}, t \in \mathbb{Z},$ 是生成过程。

特征方程

$$\Psi(z) = a_{p}z^{p} + \dots + a_{1}z + 1 = (9)$$

的根位于单位圆内，则具有唯一的平稳解 (5)。通常情况下，线性 AR 过程和自回归移动平均 (ARMA) 过程的生成过程 $\zeta_{t}, t \in \mathbb{Z}$ 被视为独立同分布随机变量的序列 [11]。当满足条件 (6) 时，比例式 (5) 对于生成过程 $\zeta_{t}, t \in \mathbb{Z}$ 是非等分布随机变量序列是有意义的。但该序列应当一致收敛于零（应依概率一致）[15]。满足以下条件：
$\forall \epsilon > 0, \quad P\{ |\xi_{t,n}| > \epsilon\} < \epsilon \text{ for } n \to \infty, t = 1,\dots,n.$

线性随机过程的其他性质见于 [6]。为了描述线性系统中的周期性过程，通常使用确定性方法，某些三角函数是任何线性系统的函数。Slutskiy 研究的随机周期过程可以定义如下。

根据 Slutskij，在某个概率空间 $\Omega, F, P$ 中指定的真实随机过程是随机过程 $\xi(t), t \in (-\infty, \infty)$，存在 $T>0$，使得 $t$ 有限维向量 $\Xi_1 = \{\xi(t_1), \xi(t_2), \dots, \xi(t_n)\}$ 和 $\Xi_2 = \{\xi(t_1+T), \xi(t_2+T), \dots, \xi(t_n+T)\}$ 在宽意义上随机等价，即对于所有 $n > 0$，其中 $t_1, t_2, \dots$ 是过程 $\xi(t)$ 的一组。回，如果两个随机向量在宽意义上随机等价，则意味着对于每一个整数 $n>0$，它们的边缘分布相同，即：
$P(\omega(\Xi_1) \in B) = P(\omega(\Xi_2) \in B)$,$\omega \in \Omega, B \in F$。

本文的主要目的是通过对过程的描述、定义和实际应用的详细数学研究，在无限可分类类中更深入地分析非参数随机过程。

对于限制意义上的白噪声值连续过程 $\xi(t), P(\xi(0)=0)=1, t \in (-\infty, \infty)$ 以及具有独立增量的过程 $\eta(t), t \in (-\infty, \infty)$ 通过以下方程相关：

$$\eta(t) = \int_0^t \xi(\tau)d\tau, \quad t \in (-\infty, \infty) (10)$$

而 $\xi(t)$ 与 $\xi(t)$ 随机等价。

在我们的情况下，$\eta(t)$ 是具有独立增量的非均匀亥尔伯特过程。对于过程 $\eta(t)$，存在一个 $T>0$，它是以下性质的基础：

$$d\kappa_1(t) = d\kappa_1(t+T), \quad d\kappa_2(t) = d\kappa_2(t+T); L(x,t) = L(x,t+T), \forall t \in (-\infty, \infty), (11)$$

其中 $\kappa_1(t)$ 和 $\kappa_2(t)$ 是过程 $\eta(t)$ 的累积量，而 $L(x,t)$ 是其在 Levi 公式中的泊松中断谱。$T$ 数被称为过程 $\xi(t)$ 的周期，即周期白。

使用具有独立增量的非均匀随机过程 $\eta(t)$，我们生成如下形式的随机过程：

$$\xi(t) = \int_{-\infty}^t \varphi(\tau,t)d\eta(\tau), \quad t \in (-\infty, \infty) (12)$$

其中 $\varphi(q,t) \in L_{2,\kappa}$ 是 $t$ 的实值非泛周期，使得：

$\int \varphi^{2}(r,t)d\kappa_{2}(r) < \infty$，在每个固定的 $t \in (-\infty, \infty)$，$\{\eta(r),\eta(0), t \in (-\infty, \infty)\}$ 是满足关系 (11) 的过程。泛而言，过程 $\xi(t)$ 是非平稳随机。扩展到复值情况可以通过通常方法进行。

具有周期结构的线性随机过程的其他性质见于 [6]。可用于韧性建模的其他数学模型——反馈系统描述如下。

### 2.4. 线性 ARMA 场

可以作为北极系统韧性数学模型的反馈模型之一是向量 ARMA 过程。模型可以表示为：

$$\xi(\vec{r}) = \zeta(\vec{r}) - \sum_{p \in \Gamma} \zeta(\vec{r}-\vec{p})a(\vec{p}) + \sum_{q \in \Gamma} \zeta(\vec{r}-\vec{q})b(\vec{q}) (13)$$

$\zeta(\vec{r})$ - 是定义在空间整数集 $Z^{n}$ 上的生成向量过程；$n$ 是集的维度；$a(\vec{p})$ - 是自回归向量参数；$b(\vec{q})$ - 是移动平均向量参数；$\Gamma$ - 是求和索引，其维度为 $n$ $(\Gamma \in Z^{n})$；$\vec{p}$ 是自回归阶向量；$\vec{q}$ 是移动平均阶向量；$\vec{r}$ 是 $n$ 维向量。

假设：

$$M_{\zeta}(\vec{r}) = 0, \ \delta_{r_1,r_2} = \begin{cases} 1 & r_1 = r_2 \\ 0 & r_1 \neq r_2 \end{cases} (14)$$

如果特征方程

$$\Psi(Z) = \sum_{p \in \Gamma} a(\vec{p})Z^{p} (15)$$

的根位于单位球内 $|Z^{n}| < 1$（$n$ 是方程的维度），则该方程有唯一解。

我们考虑了生成随机场的一般情况。生成场是多维值的随机场。
