

# 4. 结论

总而言，通过该框架可以清晰地看到 NotPety 攻击对马士克（Maersk）运营产生的涟漪效应，我们可以观察到网络事件发生前的要素未能与到来的威胁充分对齐，而必须投入大量资源来吸收该事件对马士克的影响。此外，此分析展示了以下优势：

- 关于网络攻击的数据被组织在不同的主题中，提供了一个结构。
- 该框架结构将有关公司和攻击的知识组织成从战术到战略的不同方面。
- 通过从攻击点向外部缓解层遵循该框架，可以理解攻击的演进过程。例如，市场地位对于马士克的生存至关重要，因为其缺乏“短期内的适应能力，以及在长期内支持该情景下广泛恢复管理措施的能力”。
- 通过识别每个层级的措施，可以创建一份最佳和最差实践的记录。
- 通过对措施的识别，可以设计一个涵盖从战略到运营不同网络韧性的多级流程。
