A HAPS system, working together with satellite systems, makes the deployment of 5G systems in the region where higher capacity mobile services in the Arctic region are needed. By implementing this solution, we would negate the need to install optical cable systems in the area, unless they are needed for some other reason. When we are installing submarine optical cable system in the Arctic regions, it is possible to connect the SOC (security operation center) and NOC (network operation center) in the different areas to also provide situational information to service providers and to co-operations in this area. This concept would also facilitate communication for more precise disaster planning and emergency response for public safety needs such as search and rescue as it is able to allocate resources more effectively between the different country’s security authorities. In addition, this concept could provide many opportunities to support scientific research supporting researchers’ access to information, ability to share scientific resources and instruments, and ability to collaborate virtually with colleagues around the world.

From this foundation, the data streams between the active nodes can be formed. These active nodes can be terminal devices that exchange data directly between themselves, Device-to-Device (D2D) traffic, wearables, HUBS using wireless technology as a part of active node communication, IoT devices, and for example, Machine-to-Machine (M2M) devices.
