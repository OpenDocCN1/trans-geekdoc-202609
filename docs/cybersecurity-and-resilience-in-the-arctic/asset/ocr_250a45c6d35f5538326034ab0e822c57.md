+   Raw data can only convey so much. Data only tells what has been observed, and rarely or how. This has to be deduced or inferred. Tools that allow for these types of reasoning are not particularly mature today.

+   Models of the real-world need to be updated frequently. The world continuously changes, and any data is subject to be out of date as it reaches an analyst's eye. It is necessary for tools to improve their ability to make sense of data, through constant situational awareness updates that makes sense when combating threats or responding to incidents.

+   Knowing when to observe more to assess a situation further. This is especially applicable in security incidents or natural forces, or observing potential dangers in the real world: we may see the threats continue in order to gather more intelligence about the situation. However, at some stage it will be necessary to take an action.

+   Knowing when and what is missing. Complete situational awareness is missing, but being able to have an intuition for where sensor to place, how many technologies to deploy and sensor data to collect for any type of mission in the arctic is something that comes from experience. With IoT devices becoming widespread, it is not unreasonable to assume they will also be deployed in the arctic moving forward.

+   Using analytics incorrectly will lead to misinformation. This point is in concert with the previous point about making incorrect assumptions about the data. Making use of machine learning algorithms or visualizations will lead to the incorrect message about the data being communicated to the analyst or decision maker.

+   Number of data points matters. The arctic is vast, and sensors can be placed sparsely. Having enough data points matters good coverage for situational awareness. Identifying where to place sensors is of benefit to anyone using an analytics tool.

+   Noise in the data. With any real-world sensors taking measurements from the physical world, we run the danger of acquiring noisy data (imprecise and inaccurate measurements) — especially in cold weather. This also applies to cyberspace in that alerting systems generate false positives.

+   Delivery of and response to the analytics. Currently, most analytics tools are either bespoke systems, heavily integrated into particular environments, or generic systems that are not specialised to be used meaningfully when consuming data about events taking place in the arctic.

+   Not everything can be quantified. This is challenging for many analysts. We often convert risk into a category of three levels (high, medium, low), but this shoehorning in a perception of risk into a number. This perception might not be correct, and the chance of being misperceived.
