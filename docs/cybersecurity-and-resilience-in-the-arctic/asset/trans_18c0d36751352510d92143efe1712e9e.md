## 6. 利用去中心化智能能源交易平台的展望

## 6.1. 基础组件

所提出的解决方案（见图 2）是一个去中心化的交易平台，包含了所有最新技术，如高级电表架构、分布式发电、需求侧管理等。除了能源市场中的金融交易外，它还涵盖了加密支付之外的其他用途，并可以扩展到执行表 3 中提到的任何智能电网取证任务。

平台的运行由计算节点管理。在实践中，每个节点都是运行在 Windows Server 2016 操作系统或 Red Hat Linux 操作系统下的计算机服务器，其中部署了“能源核心”（Energy Core）。网络被分为子网或网络。

系统由几种类型的节点组成：

- 全节点
全节点（ECore）部署在能源基础设施的核心对象上，例如发电厂；值得注意的是，我们需要大数据仓库来存储所有能源数据。剩余设施放置在轻级节点上。

- 能源核心（Energy Core）
能源核心是一组用于控制交易和存储信息的软件。它执行接收和验证交易的功能，然后通过私钥形成加密块，并发送到所有节点进行确认并存储在它们的数据仓库中。它还检测并连接到类似的网络节点，形成一个去中心化的信息能源平台，这是一个去中心化的虚拟机，允许基于智能合约管理网络节点，反过来为分布式硬件和应用程序创建了环境。目前，在需要从运行设备中获取数据的情况下，网络取证面临着巨大挑战，因为设备与网络的断开会影响电力及安全，导致进一步调查无法进行。区块链提供了实时管理和韧性能力，将提高调查自然灾害、网络恐怖活动和计算机欺诈期间网络犯罪和故障的速度。

该基础设施的每一个元素，从区块链节点到智能电网组件，都是潜在的信息源。以下是总方案（见图 1）中提到的某些示例及其在网络取证或灾难预测中的可能用途。

- 智能电子设备 (IED)
IED 是基于微处理器的工具，用于电力系统硬件的保护、自动化、控制和监控。它们能感知电压、电流或频率异常，并升高或降低电压水平以维持所需水平。

- 充电桩
来自充电桩的信息提供了充电时长（停留某点的时间）、连接的车辆以及支付信息。它还保存日志记录，可能包括有关危险、充电桩异常活动等的通知。

- 智能计数器
智能电表和 IED 提供细粒度的能源/需求数据。这些信息允许公用事业部门解释行为、工作计划、入住率（家里住了多少人）、家庭设备类型、制热/冷却系统。正如 El-Rokantanci 和 Mouftah (2013) 所提到的，对偷电事件的调查可能指示出大麻的种植。

- 相位测量单元 (PMU)
PMU 能够测量电压和电流波形的相位、幅值、频率和变化率。除了在电力系统中利用 PMU 进行保护外，它们还用于与电网中光伏发电调查相关的任务 (Vergara and Carpentieri, 2018)。

- 相位数据集中器 (PDC)
PDC 接收并同步来自多个 PMU 的相位数据以产生实时数据流。PDC 可以与所有位置的 PDC 交换相位数据。PDC 和 PMU 数据均可法证专家用于电网频率分析。他们利用长期高精度历史数据比较背景主网的频率变化。PDC 可以识别记录的创建时间，并帮助检测录制中的任何编辑。

## 6.2. 系统部署

与 SCADA 系统并行的，轻节点（网络节点）安装在对象上，并部署了本地数据存储器。从物理上讲，轻节点是一个独立的计算设备。

网络站点的设备将信息（交易）传输到 SCADA 系统；反之，SCADA 将数据存储在其本地存储器中。与 SCADA 系统并行的节点已直接与仓库工作，以确保系统安全。为了确保交易的真实性（设备有效/数据未被替换），它们根据 ZKP（零知识证明）产生。交易记录在块中并发送到通用区块链。

## 7. 总结

本章概述了北极地区的电力生产和智能电网的实施，分析了智能电网的安全需求以及将取证技术与区块链相结合以确保网络安全和韧性的展望。区块链的使用为调查事件创建单一的信息空间。必要条件是：所有设备必须经过认证（该设备将产生此类数据）；对于攻击者来说，攻击必须非常昂贵；信息环境应尽可能透明。

这项技术仍处于早期阶段并面临不成熟问题，如扩展性和交易处理延迟。然而，由于区块链在金融领域已有成功应用，我们有理由相信它将在智能电网中被采用。
