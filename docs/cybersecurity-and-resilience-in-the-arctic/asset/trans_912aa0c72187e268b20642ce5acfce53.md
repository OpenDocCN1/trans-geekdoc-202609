

# 438 H. Birge 等人 / 针对变化的北极的信息型韧性框架

使用大型多样化数据集的首要挑战是，研究人员通常没有意识到所有潜在的数据和信息来源。当研究跨越多个学科时（如远北地区的韧性研究），这个问题可能尤为突出。通常，一个学科的数据来源可能另一个学科并不知。我们建议调查人员识别所有相关的数据和信息来源，识别数据和信息的空白，并最终决定填补这些空白的方法，包括通过对原住民和其他当地社区进行额外的显性信息和知识征集。我们将“缺口”定义为关于特定数据源的数据集或辅助信息。在预测社会-生态结果时，数据和信息流的缺失是一个常见问题。例如，在研究由动物共患病引起的人类疾病时，我们很少拥有野生动物作为载体的数据。幸运的是，只需要少量的辅助信息就能结合数据集来生成有用的知识（例如 [38]）。当数据源难以、不可行或无法收集时，来自多元化合作者的专家信息通常可以满意地填补空白并减少不确定性 [39]。

这种方法非常适用于复杂系统，因为它允许从所有来源进行反馈和学习。例如，植被数据通常用于预测动物的位置。如果一个猎人收集了驼鹿的位置数据，她可以将植被数据纳入模型中，以预测其狩猎场内驼鹿的存在。栅图层中土地利用预测是基于这些数据的，但一旦模型和栅图层形成，它们就被认为是固定的（即不能迭代更改）。一旦驼鹿猎人找到了一个与数据相符的预测驼鹿存在的模型，过程就完成了。相比之下，整合模型“连接”了来自两个来源的模型。例如，获知某地发现了驼鹿，这提供了信息，让我们能够通过单向估计过程更准确地学习和预测，特别是当包括气候变化在内的变化驱动因素从根本上改变系统时。数据集成的另一个优势是，它能够实现从不同子系统进行迭代学习的过程，而这在其他情况下是无法测量的（见 [9] 第 25 章）。

这些活动均属于第 3 层，即使用定量和半定量信息描述和预测复杂系统。输出依赖于在第 1 层和第 2 层收集并组织的信息与知识，以及与原住民伙伴和其他当地社区成员的对话。完成第 3 层活动的步骤包括：

- (1) 盘点可用的大数据源情况，以及哪些信息和知识可以转换为数据；
- (2) 通过项目调查人员、原住民伙伴的专家征询识别并填补数据缺口；
- (3) 使用贝叶斯层次方法将其他多个模型和分析连接起来，以开发一个针对变化的北极的预测模型，该模型涵盖多个相互关联的系统特征。

一旦分层方法圆满完成，必须与所有相关利益者共享结果，包括参与者、原住民伙伴和其他当地社区成员、政策制定者和其他研究人员。传播可以通过科学报告、同行评审出版、基于社区的研讨会和其他活动、决策者简报以及相关专业会议上的演讲来进行。

# 5. 结论

尽管严酷条件是北极的特征，但预测性的下降和快速转型没有历史先例。理解并最终应对北极不确定且快速变化，需要一个在保持多样化信息线完整性的同时，对相关知识进行系统级综合的过程 [40]。这使得远北地区的利益者能够在系统转型的情况下重新获得控制权，提供了一条既接受又改变更具韧性、更理想结果的发展路径。
