# 3. 北极的网络安全

预计到2025年，全球互联网用户数量将增长超过40亿人，连接大多数发达国家和新兴国家。[78] 美国2019年国家情报战略中将网络威胁列为未来几年国家安全的挑战。[79] 关键基础设施、健康安全、经济繁荣和国家稳定都面临不确定的风险和不可预测的威胁。2016年，美国数据泄露的平均组织成本为700万美元。[80] 公共和私营部门开始优先投资于稳健的信息技术（IT）基础设施，以抵御网络威胁。[81]随着公众和立法者对网络威胁的意识不断增强，此类威胁对信息、通信网络和系统构成了关注。[81]遗憾的是，网络安全在北极是一个相对被忽视的问题。这种疏忽，特别是在治理、政策和立法方面，使多个北极和非北极参与者面临安全违露、安全危害以及可能破坏的地缘政治和外交关系的风险。网络安全挑战在远极可能会被放大和转化，那里基础设施偏远，气候恶劣，且北极应对气候变化和全球化等全球驱动因素正在快速变化，这些挑战容易被进一步放大和扭曲。
