# 8.3.4 Ontology and Pathway Analysis

Instead of a single gene, multiple genes collectively take part in a signaling pathway. These multiple genes are called correlated genes. We first identified genes that correlate with CALD1 in brain cancer using the UALCAN web. We then performed gene ontology (GO) and pathway enrichment analysis on the CALD1 along with the positively correlated genes via Enrichr web. The analysis shows that whereas the extracellular matrix organization is the primary biological process, cadherin binding is the main molecular function in the GO (Figure 8.4a,b). It also reveals that VEGFA-VEGFR2 signaling pathway is the key is the Wiki pathway, and protein processing in endoplasmic reticulum is the significant KEGG pathway (Figure 8.4c,d).
