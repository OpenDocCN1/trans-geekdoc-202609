# 13.2.5.2 ARM Cortex-M CPU

The ARM Cortex-M processor cores are a set of 32-bit RISC ARM processor cores. Cortex-M cores are commonly used as dedicated microcontroller chips, but they are often “hidden” within SoC chips as power management controllers, I/O controllers, system controllers, touch screen controllers, smart battery controllers, and sensors con. In the industry, the Cortex-M architecture is the most common and widely used processor family. Variation in the number of microcontrollers is now approaching 3000. CMSIS was created by ARM to be the fundamental library for communicating with ARM Cortex-based microcontrollers [26].

# 13.2.5.3 Data Storage and Data Security for Secure Transmission

Data Security: Data security is the protection system used to protect from unauthorized access and it is about keeping your data safe [27].
