One author [9] has defined those three sets. The training set is a set of examples used for learning, that is to fit the parameters of the classifier. The validation set is a set of examples used to tune the parameters of a classifier, for example, to choose the number of hidden units in a neural network. Finally, the testing set is a set of examples used only to assess the performance of a fully specified classifier.
