# ISO 27001

ISO (International Organization for Standardization) provides globally recognised and adopted standards. These are written, reviewed and approved under tight controls. The ISO/IEC 27000 group of standards focuses on the security of information assets. The main standard in this group for cyber security is ISO 27001, which provides “requirements for establishing, implementing, maintaining and continually improving an information security management system [ISMS]."*8

An ISMS is a system of people, processes and IT systems, with a risk assessment at its core, and is applicable regardless of organisation size. Each organisation should apply the Standard based on its needs and objectives, security requirements, the organisational processes used, and its size and structure. The Standard uses CIA introduced earlier in this book. The adoption of the Standard provides assurance that a risk management process has been applied and IT security risks (including cyber) are managed effectively. It can also be used as a basis for reviewing compliance with the organisation’s own requirements (e.g. as stated in the IT security policy).

There are several services available to implement ISO 27001 or to provide an independent audit of compliance.
