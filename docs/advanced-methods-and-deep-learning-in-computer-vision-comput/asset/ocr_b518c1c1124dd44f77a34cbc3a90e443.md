In the case of activity classification, the context-aware active learning method requires only about 18% manual annotation to reach almost the full-set performance. The other methods in the literature require about 40% manual annotation to obtain similar performance. Note that although we utilize the relationships between the action categories for this experiment, we can also utilize the context information imparted by the objects in the activities, which are especially important in human-object interaction related activities.
