Although Siamese trackers are impervious to model decay, this comes at the cost of possibly missing the target object in cases where appearance of the target changes significantly compared to the first frame. To address this problem, Siamese trackers with built-in invariances and equivariances, as well as hybrid Siamese trackers that rely on both offline and online learning, are proposed. These Siamese tracker variants can account for large variations in the appearance of the target object, while still exhibiting little model decay.
