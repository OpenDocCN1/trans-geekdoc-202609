This inspired latter works, such as the Fast R-CNN.

# 2.5 Fast R-CNN

The SPP-Net inherits the tedious multistage training procedure of R-CNN. This is significantly simplified in the Fast R-CNN. In this approach, the extraction of features, fine-tuning of the network to a new task, instance-wise classification and bounding-box regression are all integrated into a unified framework, enabling easy to use deep learning based object detection.
