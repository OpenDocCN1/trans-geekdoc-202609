# 2.5.2 RoI pooling

The RoI pooling operation is a simpler version of the spatial pyramid pooling of Fig. 2.5. Instead of pooling a RoI with height and width (h, w) to different spatial resolutions (1 × 1, 2 × 2 and 4 × 4) and concatenating them together, as in SPP, RoI pooling uses a single H × W resolution, e.g., 7 × 7. Given a RoI window of size h × w, RoI pooling divides it into H × W subwindows, each of size h/H × w/W. Max-pooling is then used inside each subwindow to extract the largest feature value. This process is applied independently to each feature map channel. Although RoI pooling is simpler than SPM, it can still effectively extract a powerful feature representation for proposals of arbitrary size and scale from the precomputed convolutional feature maps. This is the critical requirement for object detection.

# 2.5.3 Multitask loss

The Fast R-CNN is trained with two learning tasks: classification and bounding box regression. These are jointly optimized during training with recourse to a multitask loss function

$$L = L_{cls}(h(\mathbf{x}), y) + \lambda [y \ge 1] L_{loc}(f(\mathbf{x}, \mathbf{b}), \mathbf{g}), \qquad (2.5)$$

where λ controls the balance between the two requirements. [y ≥ 1] equals to 1 when y ≥ 1 and 0 otherwise, meaning that there is no bounding box regression loss for background class.

# Classification

The classifier is a function h(x) that assigns an image patch x to one of K + 1 classes, where class 0 contains background and the remaining classes the objects to detect. h(x) is a K + 1-dimensional estimate of the posterior distribution over classes, i.e., h_k(x) = p(y = k|x), where y is the class label.
