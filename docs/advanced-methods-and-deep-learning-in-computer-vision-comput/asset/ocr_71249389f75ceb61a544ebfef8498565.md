# 1.3 Part B – 2-D object location and recognition

# 1.3.1 The centroidal profile approach to shape analysis

2-D objects are commonly characterized by their boundary shapes. In this section we examine what can be achieved by tracking around object boundaries and analyzing the resulting shape profiles. Amongst the commonest type of profile used for this purpose is the centroidal profile—in which the object boundary is mapped out using an (r, θ) polar plot, taking the centroid C of the boundary as the origin of coordinates.
