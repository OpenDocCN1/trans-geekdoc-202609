# Multistyle transfer results

Thanks to the above decoupled two-branch design, one style is encoded in one specific set of convolutional filters and multiple styles can be learned in one network simultaneously. This is more friendly to real applications than previous single-style methods that usually train one independent network for each style. During inference, to apply one specific style, the corresponding filterbank is chosen and applied. As shown in Fig. 5.12, different styles are decoupled very well and the corresponding stylization results only consist of their own style patterns.
