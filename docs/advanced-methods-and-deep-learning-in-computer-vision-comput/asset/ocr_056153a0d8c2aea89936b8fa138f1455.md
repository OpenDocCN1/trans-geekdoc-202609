We also know that P1, P2 and C are coplanar, the condition of coplanarity being:

P2.C × P1 = 0 (1.83)

To progress, we need to relate the vectors P1 and P2 when these are expressed relative to their own frames of reference. If we take these vectors as having been defined in the C1 frame of reference, we now reexpress P2 in its own (C2) frame of reference, by applying a translation C and a rotation of coordinates expressed as the orthogonal matrix R. This leads to:

P2' = R P2 = R(P1 − C) (1.84)

so that:

P2 = R−1 P2' = R^T P2' (1.85)

Substituting in the coplanarity condition gives:

(R^T P2').C × P1 = 0 (1.86)

At this point it is useful to replace the vector product notation by using a skew-symmetric matrix Cx to denote C ×, where:

Cx = [ [0, −Cz, Cy], [Cz, 0, −Cx], [−Cy, Cx, 0] ] (1.87)
