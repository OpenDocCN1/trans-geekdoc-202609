For the stylizing branch, following the objective function in Johnson et al. (2016), a content loss ℒ_c, a style loss ℒ_s and a variation regularization loss ℒ_tv(O_i) are used as the stylization loss ℒ_K:

where I, S_i, O_i are the input content image, style image and stylization result (for the i-th style) respectively. ℒ_tv(O_i) is a total variation regularizer used in Johnson et al. (2016) to encourage smoothness. And ℒ_c and ℒ_s use the same definition as in Gatys et al. (2015):

ℒ_c(O, I) = Σ_{l∈l_c} ||F^l(O) − F^l(I)||²
ℒ_s(O, S) = Σ_{l∈l_s} ||G(F^l(O)) − G(F^l(S))||² (5.11)
where G(X) = X X^T
