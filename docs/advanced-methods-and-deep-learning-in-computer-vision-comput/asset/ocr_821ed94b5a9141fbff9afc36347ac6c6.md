# 7.1 Introduction

With the availability of web-scale data obtained from different devices and varied acquisition conditions, we are often faced with scenarios where the data used to train a classifier has some properties that are different from what is presented during testing. Instances like this arise very naturally in object recognition applications where the training and testing data are captured under different lighting conditions, in speech processing where a speaker model trained in a noise-free indoor setting needs to be deployed in more realistic outdoor environments, or in multimedia indexing where tagged Flickr photos or YouTube videos are readily available from which a user would want to automatically index his/her own photo/video collection harvested with a consumer camera. Domain adaptation (DA) refers to the class of techniques aimed to learn representations from a low-resource dataset by transferring knowledge from a related, yet shifted, resource-rich dataset.
