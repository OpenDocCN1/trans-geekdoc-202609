On the edge accelerator, the RL agent allocates less activation bits to the depthwise convolutions, which echoes that the depthwise convolutions are memory bounded and that the activations dominate the memory access. On the cloud accelerator, our agent allocates more bits to the depthwise convolutions and allocates less bits to the pointwise convolutions, as the cloud device has more memory bandwidth and high parallelism, so the network appears to be computation bounded.
