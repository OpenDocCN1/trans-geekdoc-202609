# Specialized models for different hardware

Given the high cost of building a new neural network model, it is common to deploy the same model for all hardware platforms. However, it is suboptimal, as different hardware platforms have different properties, such as the number of arithmetic units, memory bandwidth, cache size, etc. Using hardware-aware NAS techniques, it is possible to have a specialized neural network architecture for each target hardware.
