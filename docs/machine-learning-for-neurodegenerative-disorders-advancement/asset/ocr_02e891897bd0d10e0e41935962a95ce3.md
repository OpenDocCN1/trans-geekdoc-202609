# 10.3.1 EUROPEAN DATA FORMAT

The EDF is widely accepted standard for exchange of electroencephalogram and polysogram between different equipment and loads. A data file starts with a header record and contains data records. The variable-length header record identifies the patient and includes technical details of captured signals. The data records contain sequential fixed-duration epochs of the polygraphic recording.

For each signal, saves multichannel data for different samples. It consists of a header and one or more data records. The header is of variable length used to identify the patient and specific technical characteristics of the recorded signals. The data record contains fixed duration epochs of the polyography recording. The information on the whole recording, including sampling rate start time, contained in header and each signal, coded as ASCII characters. The data records contains as little integers. The EDF browser is used to convert EDF format to ASCII codes where multiple or single files can be converted in an automated environment. Different samples between the signals are supported. Four text files will be created for header, signals, data and annotations. Finally, the data in 2D space will be obtained.

Physiological data interchange and management are critically in the changing fields of biomedical research and therapeutic practice. An important development in this field is the EDF, which provides a standardized method for the recording and exchange of physiological signals like electromyography (EMG) and EEG.
