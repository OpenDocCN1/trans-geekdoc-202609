# 9.4.1.3 Precision

Precision is a performance metric that is the proportion of positive states of lesion to the total number of classified positive states (be it true or false). It is given by the following formula.

> Precision = \frac{t}{t + f} (9.8)

# 9.4.1.4 F-score

This F-score is another performance metric measuring the proposed model's accuracy determined by the earlier discussed protocols, such as sensitivity and precision. In terms of instances, the F-score can be formulated by the following formula.

> F-Score = \frac{t}{t + 0.5(f + f')} (9.9)

The model efficiency is found to be of higher value for this protocol. The F-score determined with the eight MRI images generates a plot (Figure 9.10) with values between 0.93 and 0.95, manifesting the performance of the proposal.

# 9.4.1.5 Dice Similarity Coefficient

This tests the similarity between the predictive class and the actual class, thus finding the overlap of values between the two images. This is presented by the formula:

> Dice Co-efficient = 2x \frac{t}{(t + f) + (t + f')} (9.10)
