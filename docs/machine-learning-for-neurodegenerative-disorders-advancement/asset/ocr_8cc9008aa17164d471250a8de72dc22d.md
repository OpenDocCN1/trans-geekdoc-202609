+   iii. **Recall**: Also known as sensitivity or the true positive rate, recall measures the model's ability to correctly identify all relevant instances. It is the ratio of true positives to sum of true positives and false negatives.

> $Recall = \frac{TP + FN}{TP}$$ (8.22)

+   iv. **F1-Score**: This metric represents harmonic mean of precision and recall, providing a balanced measurement of the overall performance. It is particularly useful when there is a need to strike a balance between false positives and false negatives.

> $F1 - Score = \frac{2 \times Precision \times Recall}{Precision + Recall}$$ (8.23)

+   v. **Kappa coefficient**: The kappa coefficient serves as a measure of agreement between predicted and actual classifications, adjusting for chance agreement. It refines accuracy by considering the possibility of random agreement between predictions and actual classifications.

> $Kappa = \frac{P_o - P_e}{1 - P_e}$$ (8.24)

where, $P_o$ = Relative agreement among rat, $P_e$ = Expected by chance.
