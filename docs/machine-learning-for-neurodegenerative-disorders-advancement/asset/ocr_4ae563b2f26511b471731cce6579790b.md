# 1.2.1.11 Feature Engineering

Feature engineering is the process of selecting, transforming, or creating features from the raw data to improve the performance of an ML model (Zheng et al., 2023). This involves the procedure of using domain knowledge to develop features or modifying existing ones to improve the performance of ML. It entails picking appropriate features, changing data, and producing features or polynomial functions. Techniques such as normalizing, standardizing, encoding specific variables, and handling missing values can dramatically improve accuracy and interpretability by selecting more helpful and discriminative attributes (Cakar & Yavuz, 2023). It is an essential step in the ML pipeline, typically requiring repetitive trial and domain expertise. Effective feature engineering can significantly impact the model's ability to learn meaningful patterns.

# 1.2.1.12 Prediction and Inference

Once trained, the model can make predictions or inferences on new, unseen data. The model applies the patterns learned during training to generate outputs, by predicting the probability of an event or classifying an input into specific categories (Curley et al., 2023). Prediction and inference are key objectives in ML. Prediction refers to the model's ability to accurately estimate the target value for new, unseen data based on learned patterns from the training data. Inference, on the other hand, involves understanding relationships between features and the target variable, providing insights into how the model makes decisions. Inference is essential for model interpretability and understanding the data-generating process (Strak et al., 2023). Both prediction and inference are critical for deploying ML models in real-world applications, where accurate forecasting and explainability are paramount. These core concepts provide the foundation for understanding how ML algorithms process data, learn from, and make predictions or decisions (Cakar & Yavuz, 2023). # 1.2.2.1.1 Linear Regression

Linear regression is a fundamental algorithm for regression tasks. It assumes that the input features and the continuous output are linearly related. Linear supervised learning algorithm used to predict a continuous target variable based on one or more features models a linear relationship between the inputs and the target, represented by the equation $y = \beta_0+\beta_1x_1+...+eta_nx_n$, where $y$ is the predicted value, $x_i$ are the input features and $eta_i$ are the coefficients that the model learns during training. The objective is to minimize the mean squared error (MSE) between the predicted and actual target values (Azad et al., 2023).
