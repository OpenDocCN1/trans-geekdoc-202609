# 9.3.1.1 Anisotropic Diffusion Filter

Similar to interference, noise manifests as an erratic granular pattern. The quality is reduced by this erratic fluctuation strength The body is the primary source of noise in the picture (RF emission from thermal motion). The MRI scanner’s entire measuring chain, including the coils and electronics, is another source of noise. Anomalies in the image that cannot be visually noticed may populate the recordings or the readings for further analysis. This unintentional and unwanted noise has to be eradicated for efficient processing of the image. An image processing filter has been applied to improve the image’s sharpness, smoothness, and edge enhancement. Rather than using any other filter, such as the Gaussian filter or mean filter, the anisotropic filter has been kept even when using a Gaussian filter reduces noise more effectively. Conversely, the image becomes fuzzy but retains its edge. Contrast to the Gaussian and mean filters, the median filter is extremely effective, but the image becomes fuzzy as a result. In order to eliminate image noise or artifacts, diffusion-based filtering is a technique that smooths the image without sacrificing the image’s edges. Similar to others or high-frequency properties. The process that forms a scale space, diffusion is the process by which an image produces a parameterized family of progressively blurry images. A 2D isotropic Gaussian filter, whose width increases with the parameter value, is used convolutionally create these images. This diffusion technique modifies the original image independently and linearly in space.

Anisotropic diffusion is a broader term for the diffusion process. The process generates a set of standardized images, where each image is a blend of the source and a filter that is deployed on the original image’s local features. As a result, the diffusion process itself transforms the original image in a “linear and space-invariant” manner, AD is a “non-linear and space-variant” manner.

An AD filter performs the denoising of the image, preserving its edges [6]. Moreover, an anisotropic filter reduces blur in images as compared to Gaussian and median filters. Visually, the results by Perona and Malik were highly striking: edges held steady for an extended period of time. This is because diffusion and edge detection are not considered two separate processes to be applied, but rather as two processes that interact in a single process.

Thus, this filter is robust and efficient, by blurring the inter-pixel values and without blurring the edges.

While isotropic diffusion is direction-independent, the diffusion of the image anisotropically implies the blurring across the four cardinal directions (North, East, West, and South). Therefore, the AD filter is a direction-dependent working in two dimensions as the medical image extracted is a 2D image.
