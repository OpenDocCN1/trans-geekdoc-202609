# 8.4.1 PERFORMANCE METRICS

The evaluation of the proposed VO-ADA model involves assessing its performance using key metrics such as accuracy, precision, recall, Fl-Score, and the kappa coefficient. Each metric serves a specific purpose:

+   i. **Accuracy:** This metric gauges the overall correctness of the model's predictions, calculated as the ratio of correctly predicted instances to the total instances.

$$Accuracy = \frac{TP + TN + FP + FN}{TP + TN} \quad (8.20)$

where TP = True Positives, TN = True Negatives, FP = False Positives, FN = False Negatives
ii. **Precision:** Precision evaluates the accuracy of positive predictions, indicating the proportion of true positive predictions among all positive predictions. It is the ratio of true positives to the sum of true positives and false positives.

$$Precision = \frac{TP + FP}{TP} \quad (8.21)$
