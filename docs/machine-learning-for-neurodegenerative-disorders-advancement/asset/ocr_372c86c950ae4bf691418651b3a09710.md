# 10.3.3 MACHINE LEARNING THROUGH A K-Means CLUSTERING ALGORITHM

K-Means clustering is a vector quantization method derived from signal processing that tries to split N observations into K clusters, with each observation belonging to the cluster with the nearest mean (cluster centers or centroid), which serves as the cluster's prototype. Unsupervised ML is the process of teaching a computer to use unlabeled, nameless material while allowing the algorithm to work on without supervision [27]. Without any prior data training, the machine's task in this situation is to arrange unsorted data based on parallels, patterns, and variances. K represents clustering; data points are assigned to one of the K clusters based on their distance from the cluster center. It is by randomly designating the cluster's centroid in space. The data points are then assigned to one of the clusters depending on their distance from the cluster's centroid. After assigning each point to a cluster, new clusters are created. This algorithm iterates until it finds a suitable cluster. In the study, we assume that the number of clusters is predetermined and we must allocate points to one of the groups.

For the KMC algorithm we define the clusters using cognitive state. Cognitive state refers to information processes of the brain, being conscious or unconscious depending on what an individual knows about the situation they are in. Cognition can be defined as the process by which someone's thoughts are organized, understood, and transformed into language with some degree of permanence. Cluster number is defined using five cognitive states, which are extremely sleepy, very drowsy, moderately sleepy, slightly sleepy, and alert. Alerts are given in the order they are mentioned so as to prioritize the contention of alert. Training data is obtained from the references. The KMC algorithm calculates the centroids and iterates until it finds the optimal centroid. Here K represents the number of clusters identified from data by algorithm.
