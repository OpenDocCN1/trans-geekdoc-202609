## 10.1 引言

疲劳检测一直是多种方法的关注点，包括视觉特征和生物信号。一方面，视频检测应用是有效的且对光线变化具有适应性；然而，与视觉特征相比，生物信号更为准确。因此，监控是一种安全手段。事实上，清醒与睡眠之间的过渡阶段（疲劳）是注意力下降的时期。这一阶段处于睡眠之前，其特征是几乎缺乏反射，且不适用于高警觉任务。
