# 8.3.3.1.3 Standardization and Normalization of Numerical Features

For numerical attributes like age and screening score, standardization or normalization can be applied.

+   - *Standardization of age*: Adjust the age to have a mean of 0 and standard deviation of 1.

```
$$\text{Age} = \frac{\text{Standardized - Age}}{\sigma_{\text{Age}}}$$ (8.6)
```

where $\mu$ Age is the mean age, and $\sigma$ Age is the standard deviation.

+   - *Normalization of screening score*: Rescale the screening score to a range [0, 1].

```
$$\text{Screening Score}_{\text{Normalized}} = \frac{\min(\text{Screening Score})}{\max(\text{Screening Score}) - \min(\text{Screening Score})}$$ (8.7)
```

# 8.3.3.1.4 Binary Encoding for Binary Responses

For attributes born with jaundice, family member with PDD, used the screening app before, and Question 1 to Question 10 answers, binary encoding is appropriate in the selected dataset, there are two attributes for a binary encoding is jaundice and another is family member with PDD. for the both if answer 'yes' it is mentioned as '1', if 'No' '0'.

```
$$\text{Binary Encoded} = \begin{cases} 1 & \text{if Yes or 1} \ 0 & \text{if No or 0} \end{cases}$$ (8.8)
```

# 8.3.3.1.5 Text Processing for Textual Attributes

Attributes like country residence and description may require text processing techniques.

+   - *Tokenization for country of residence*: Break down the text into smaller components.

+   - *Normalization or encoding for description*: For descriptions like "18 and more," this might be converted to a numeric form or a label.

```
$$\text{Age Category} = \begin{cases} 0 & \text{if 'Toddler'} \ \ 1 & \text{if 'Child'} \ \ 2 & \text{if 'Adolescent'} \ \ 3 & \text{if '18 and more'} \ \end{cases}$$ (8.10)
```

# 8.3.3.1.6 Target Variable Encoding

For the class/ASD attribute, which indicates the presence or absence of ASD,

```
$$\text{ASD Encoded} = \begin{cases} 1 & \text{if YES (ASD present)} \ \ 0 & \text{if NO (ASD absent)} \ \end{cases}$$ (8.11)
```

Each pre-processing step is crucial to prepare the dataset for machine learning or statistical analysis. By applying these formulas and techniques, the data becomes structured, standardized, and ready for model training and evaluation.
