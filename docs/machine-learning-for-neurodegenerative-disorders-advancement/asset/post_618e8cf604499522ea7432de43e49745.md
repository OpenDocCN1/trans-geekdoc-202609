### 7.2.1 PRE-PROCESSING

Audio pre-processing is a crucial step in getting audio data for analysis or processing. Numerous methodologies are employed to improve the caliber of audio signals, essential features, and noise reduction effect significantly reduces background and broadband noise, while signal quality is only slightly compromised. Historically, one of the earliest methods is spectral subtraction [15]. This method estimates the clean speech by subtracting the noisy speech spectrum from the noisy speech spectrum which is conducted during speech phases. In this article, we applied the spectral subtraction noise reduction method to the audio dataset. Then, we apply the Mel-frequency cepstral coefficient approach [16] to extract meaningful, important, or essential features. A group of coefficients known as MFCCs are used to represent the features of a sound signal's power spectrum. They are produced by using a filter such as the Discrete Fourier transform (DFT) to convert the unprocessed audio input into a frequency domain and then using the Mel to scale how the human ear perceives frequency. Lastly, the Mel-scaled spectrum is used to compute cepstral coefficients.

### 7.2.2 SMOTE-BASED OVERSAMPLING METHOD

An unbalanced dataset refers to a classification data set with unbalanced proportions. The majority of classes are those that comprise a sizable share of the dataset. Minority classes are those that include a smaller sample. For example, in a spam classification (corpus), we have the following data: Total samples = 1000, spam emails = 81, non-spam = 910, event rate = 8.1%. When faced with imbalanced datasets, the traditional model evaluation techniques cannot measure model performance effectively. In this research, we used the SVM-SMOTE [17] based oversampling approach to handle the issue of class imbalance. By oversampling the instances of borderline minority classes, the SVM-SMOTE approach is preferable for the imbalanced sets.

Another option is the voting-based FS. When creating a predictive model, FS [18] is an approach of minimizing the number of features or variables. Minimizing the number of variables is preferable if it can lower the model's computing cost and, in some situations, enhances the model's performance. Statistical-based FS algorithms choose the input variables with the highest correlation with each. Voting ensembles [19] is an ensemble technique used to train numerous models. The output is the result of the predictions from each model. In contrast to voting ensembles, models for bagging and boosting techniques use the same algorithm. Furthermore, unlike voting ensembles, the weights and aggregations are carried out here. On the other hand, ensemble techniques like stacking and blending include algorithms of risky models and methods.

In this research, we have created an ensemble-based statistical method. Here, different statistical k-based FS have been used: Chi-square (CSQ) [20], mutual information (MI) [21], variance threshold (VT) [22], sequential forward selection (SFS) [23], SVM-recursive feature selection (SVM-RFE) [24], and relief [25]. Relief is an algorithm that was created in 1992 by Kira and Rendell. It selects features using a filter-method approach and is very sensitive to sensitive attributes. It was initially used in binary classification involving discrete or continuous features. Relief gives a feature score, which is used to rank and the Chi-square test used to assess each feature's relevance to the target variable in the context of the work.

### 7.2.3 MCDM-BASED CLASSIER

After selecting the features, the MCDM method is used to perform the final classification. The goal of MCDM is to select the best solution based on multiple criteria. The steps are outlined below:

- **Determine the normalized performance**: The decision matrix $D$ is normalized to allow for comparison.
- **Combine ratings and weight**: Weights are assigned to each criterion based on their importance.
- **Select the best solution**: The alternative with the highest aggregate score is selected as the best model for the final classification.
