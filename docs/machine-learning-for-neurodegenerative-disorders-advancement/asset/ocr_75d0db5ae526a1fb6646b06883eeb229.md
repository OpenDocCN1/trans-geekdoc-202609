Early in the 1990s, the era of EDF was born of the necessity for a standard data format for\physiological monitoring. Researchers and physicians employed a variety of proprietary formats
 EDF, which caused problems with compatibility and data sharing. The European Federation
of Neurological Societies (EFNS) created EDF response to these difficulties by offering a stan-
dard for data interchange and archiving. Many of the interoperability issues were resolved in
t first release of EDF by providing a precise and standardized format. EDF has changed through
time, and its useless has been expanded with the release of EDF Plus (EDF+), which offers addi-	ional features such better metadata and annotations.

# 10.3.1.1 EDF Structure

The header and the data records are the two primary portions of an EDF file. To guarantee that data
is accurately stored and processed, each section is essential.

+   1. Header Section

+   * Version information: Provides the EDF version (as EDF or EDF+) that was uti-
lized, which is necessary for interpretation and compatibility.
* Patient information: consists of specifics like name, gender, patient ID, and
d demographic information. These data aid in the identification and contextualization of
t material.
* Recording information: Gives the duration of the recording, along with the start date
 time. For the temporal analysis, this information is essential.
* Signal details: Information about every channel.
* Channel labels: Names or identifiers for every channel that is recorded (e.g., EEG
channels labeled "Fp1" and "C3".
* Dimensions in physical terms: The signal measuring units (such as µV for EEG).
* Min/max digital and physical values: The scaling between real-world measurements
 and digital representations is defined by these numbers.
* Frequency of sampling: Shows the speed at what data samples were gathered, which
is essential for precise signal reconstruction.

+   2. Data Records

EDF files have data records that are made up of continuous signal data after the header.
 Typically, a fixed-length piece of the signal data from every channel makes up each record.
 Each in the time series format contains data points that correspond to the desig-
sampled frequency.

+   3. Data Representation

EDF files store signal data, which needs to be converted using the header informa-
back to its physical measurements. This procedure guarantees a precise reconstruction
 and analysis of the captured signals. For an EEG signal could be stored as a set of
dig values that reflect voltage variations. The scaling factors required to interpret these
values in microseconds are provided by the header.

+   4. EDF+ and Extended Features

The original EDF format has been expanded with EDF+ to provide more capabilities.
Among EDF+'s principal attributes are

+   * Annotations: Event markers and annotations can be added to data records using
 EDF+. These comments can indicate important things that happened throughout the
recording, including different stages of sleep, artifacts, or pertinent things.
* Extended header information: EDF+ allows for the addition of metadata fields to
 provide specific details about the patient's demographics, the conditions of the
recording, and other elements that might affect how the data is interpreted.
