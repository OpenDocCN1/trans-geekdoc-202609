# A Combination of Ensemble with MCDM Approach

+   **Identify optimum negative and positive solutions:**nThe positive and negative ideal solution sets (LR), represented by the symbols $X^+$ and $X^-$, respectively, can be identified from Eq. (7.6) as

```
$X^+ = [p_1^+, p_2^+, p_3^+, \dots, p_v^+] \quad (7.7)$
```

```
$X^- = [p_1^-, p_2^-, p_3^-, \dots, p_v^-] \quad (7.8)$
```

where

```
$p_v^+ = \begin{cases} \max p_{av}, \text{if } v \text{ is a benefit attribute} \ \min p_{av}, \text{if } v \text{ is a cost attribute} \end{cases} \quad (7.9)$
```

```
$p_v^- = \begin{cases} \min p_{av}, \text{if } v \text{ is a benefit attribute} \ \max p_{av}, \text{if } v \text{ is a cost attribute} \end{cases} \quad (7.10)$
```

+   **Obtain the separation values (SVs):**nThe SV, which is determined by using the Euclidean distance theory, is the distance between each option rating and the (positive, negative) ideal solutions. Eqs. (7.10) and (7.11) illustrate the steps in computing positive and negative separation, respectively.

```
$Q_u^+ = \sqrt{\sum_{v=1}^v (p_{av} - p_v^+)^2} \quad (7.11)$
```

```
$Q_u^- = \sqrt{\sum_{v=1}^v (p_{av} - p_v^-)^2} \quad (7.12)$
```

+   **Determine the total score for preferences:**nEq. (7.13) provides the overall preference score $S_u$ for every alternative $X_u$.Higher $S_u$ values are used to rank the alternatives.

```
$S_u = \frac{Q_u^+}{Q_u^+ + Q_u^-} \quad (7.13)$
```
