# Techniques for identifying disease entities

+   - **Rule-based approaches:** Using custom rules and dictionaries to recognize disease entities using patterns, regular expressions, or domain-specific lists. Utilizing conditional random fields (CRFs) and support vector machines (SVMs), which have been trained on labeled data, are supervised learning methods that can be used to identify disease entities.
- **Deep learning models:** Using neural network topologies for tasks like NER that need sequence labeling, as bidirectional short-term memory (BiLSTM) and transformer-based models.

For NER model training, it is essential to have high-quality labeled datasets with instances of illness entities and the categories to which they belong. An NER model's accuracy in classifying disease entities while limiting false positives and false negatives is measured by its precision, recall, and F-score. To determine how well a model generalizes, cross-validation and evaluation on outside datasets are necessary. The identification of disease entities using NER is a crucial NLP problem in biological research and healthcare, to drug development processes by precisely extracting disease entities from textual input [18]. Despite difficulties, the integration of rule-based, machine learning, and deep learning techniques, with high-quality labeled datasets, is boosting NER performance in the biomedical domain, leading to better disease understanding and patient care.

# 3.3.1 EXTRACTION OF RELATIONSHIPS BETWEEN BIOMARKERS AND PATHOLOGY

Biomarkers for neurodegenerative diseases

+   - **Parkinson's disease:** About 2%–3% of adults over 65—roughly 50 million people worldwide—have Parkinson's disease. A notable loss of dopaminergic neurons in the substantia nigra and Lewy body pathology is its hallmarks. After significant neuron loss, current treatments are less effective and provide only symptomatic relief. Biomarkers are necessary to enable early identification of Parkinson's disease, as early neuroprotective therapy is critical.
