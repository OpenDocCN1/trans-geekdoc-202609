# 6.2.2.3 Distribution of Dataset and Model Hyperparameter

The most common datasets used to study the detection of AD were Alzheimer’s Disease Neuroimaging Initiative (ADNI) and Open Access for Series of Imaging Studies (OASIS), combining MRI with biological and cognitive markers.

The performance of the detection of AD is greatly influenced by many parameters such as optimizer, learning rate, and loss function. Performing on the data with the right parameters helps in achieving the result. Using an optimizer helps reduce the overall loss and improve the accuracy. Optimizers such as Adaptive Moment Estimation (ADAM) use the optimization technique for gradient descent; stochastic gradient descent (SGD) uses the technique in optimizing the objective function with suitable properties; and RMSProp uses the technique to accelerate the overall optimization performance.
