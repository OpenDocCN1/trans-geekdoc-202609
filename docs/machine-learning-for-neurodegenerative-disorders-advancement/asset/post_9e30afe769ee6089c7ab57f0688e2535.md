## 1.2.1.7 Supervised Learning

Supervised learning is a type of ML where the model is trained on a labeled dataset, meaning that each training example is paired with an output label. The objective is to learn a mapping from inputs to outputs that can be generalized to new, unseen data. Common supervised learning tasks include classification and regression [Cakar & Yavuz, 2023]. Algorithms like linear regression, logistic regression, decision trees, and support vector machines are commonly used. The success of supervised learning depends on the availability of a large, high-quality, labeled dataset and choice of appropriate features. In supervised learning, the algorithm learns from a labeled dataset uses the input features and associated labels to learn the mapping between them [Cakar & Yavuz, 2023; Currey et al., 2023]. The objective is to create a model to predict for new, unseen data accurately.

## 1.2.1.8 Unsupervised Learning

Unsupervised learning involves training a model on data that does not have labeled responses. The goal is to uncover patterns or intrinsic structures within the data. Common tasks include clustering, where the model groups similar data points, and dimensionality reduction, where the model simplifies the data representation [Vdeai et al., 2023]. Algorithms such as k-means clustering, hierarchical clustering, and principal component analysis (PCA) are widely used. Unsupervised learning is useful for exploratory data analysis, anomaly detection, and preprocessing steps in supervised learning. It helps in discovering relationships and structures in the data without prior knowledge. The algorithm's task is to uncover hidden patterns, clusters, or structures within the data [Kawai et al., 2023]. Standard techniques include clustering and dimensionality reduction.

## 1.2.1.9 Semi-Supervised Learning

Semi-supervised learning combines elements of both supervised and unsupervised learning. Semi-supervised learning is a hybrid approach that is particularly useful when acquiring labeled data is expensive or time-consuming. A small amount of labeled data and an enormous amount of unlabeled data are used to improve the model's learning and generalization. Semi-supervised learning leverages the structure of unlabeled data to improve accuracy. Techniques like semi-training and graph-based methods are common [Jaison et al., 2023].

## 1.2.1.10 Reinforcement Learning

RL makes decisions by interacting with an environment. The agent receives feedback in the form of rewards or penalties. Problems are modeled as Markov Decision Processes (MDPs), where the agent's goal is to learn an optimal policy that maximizes cumulative rewards over time. Key algorithms include Q-learning, policy gradients, and deep techniques such as Proximal Policy Optimization (PPO) and Deep Q-Networks (DQN) [Turrisi et al., 2023].

## 1.2.1.11 Feature Engineering

Feature engineering is the process of selecting, transforming, or creating features from the raw data to improve the performance of ML. It involves using domain knowledge to develop features or modifying existing ones. Techniques such as normalizing, standardizing, encoding specific variables, and handling missing values can dramatically improve accuracy and interpretability by selecting more helpful and discriminative attributes [Zheng et al., 2023].

## 1.2.1.12 Prediction and Inference

Once trained, the model can make predictions or inferences on new, unseen data. Prediction and inference are key objectives in ML. Prediction refers to the model's ability to accurately estimate the target value for new, unseen data based on learned patterns from the training data. Inference, on the other hand, involves understanding relationships between features and the target variable, providing insights into how the model makes decisions. Inference is essential for model interpretability and understanding the data-generating process [Strak et al., 2023]. Both prediction and inference are critical for deploying ML models in real-world applications, where accurate forecasting and explainability are paramount. These core concepts provide the foundation for understanding how ML algorithms process data, learn from, and make predictions or decisions (Cakar & Yavuz, 2023). ## 1.2.2.1 Supervised Learning Algorithms

### 1.2.2.1.1 Linear Regression

Linear regression is a fundamental algorithm for regression tasks. It assumes that the input features and the continuous output are linearly related. Linear supervised learning algorithm used to predict a continuous target variable based on one or more features models a linear relationship between the inputs and the target, represented by the equation $y = \beta_0+\beta_1x_1+...+beta_nx_n$, where $y$ is the predicted value, $x_i$ are the input features and $\beta_i$ are the coefficients that the model learns during training. The objective is to minimize the mean squared error (MSE) between the predicted and actual target values (Azad et al., 2023). Linear regression is simple, interpretable, and computationally efficient, making it suitable for many real-world problems. However, it assumes linearity, homoscedasticity, and independence of errors, which may not hold in principle, limiting its applicability to more complex datasets (Cakar & Yavuz, 2023). The algorithm calculates the best-fitting line (slope and intercept) that minimizes the difference between the predicted and actual values.

### 1.2.2.1 Logistic Regression

Despite its name, logistic regression¹ is used for binary classification tasks. It models the probability that an input belongs to a specific class using the logistic function. It is a linear model used to estimate the probability that a given input belongs to a particular class. The model uses the logistic function $\sigma(z)=\frac{1}{1+e^{-z}}$, where $z$ is a linear combination of input features, to map predicted values to between 0 and 1. The logistic regression model aims to find parameters that maximize the likelihood of the observed data, using techniques such as gradient descent for optimization (Kawai et al., 2023). Logistic regression is interpretable and can handle large datasets easily in medicine, finance, and social sciences for tasks such as diagnosis, credit scoring, and survey analysis. However, it assumes a linear relationship between the input features and the logs of the outcome, which may not capture complex patterns. It calculates a decision boundary that separates the classes based on input features (Cascone et al., 2023).
