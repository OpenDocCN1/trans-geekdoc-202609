# 10.5 CONCLUSION AND FUTURE WORK

The drowsiness detection system is crucial for driver alertness and reducing accident risks. This study leveraged the K-Means ML algorithm effectively to categorize various levels of human activity. By comparing these levels with trained data, it significantly minimized the time required to detect drowsiness, achieving a remarkable computation time of 1.5 seconds. The system demonstrated an impressive accuracy of 97%, surpassing the performance of the CNN algorithm. This research's pivotal contribution lies in preventing overlaps with testing data, and enhancing road safety, especially in smart cities and highways. In the future, enhancing performance will integrate the K-means algorithm with a deep learning model. This advancement will require a dataset comprehensive information such as age, gender, address, and makeup (if the driver is identified as female) to further refine the detection system. This integration aims to improve accuracy and efficiency in detecting drowsiness.
