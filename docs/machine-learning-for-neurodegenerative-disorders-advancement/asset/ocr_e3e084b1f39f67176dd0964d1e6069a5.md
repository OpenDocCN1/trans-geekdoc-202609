# 1.2.1.5 Training

Training exposes the ML model to a dataset containing input features and corresponding labels. During training, the algorithm adjusts its internal parameters to learn the patterns and labels that enable accurate predictions or classifications (Jiang, 2023). The algorithm aims to generalize its learning to unseen data. During training, the model iteratively changes its criteria to lessen the mistakes between its predictions and the actual labels. This entails making use of a loss function to gauge the discrepancy and optimization, such as gradient descent, to upgrade the version's parameters. Training calls for a classified dataset (in supervised learning) and often splitting the data right into training and validation sets to review efficiency and avoid overfitting (Zarr & Brown, 2023). The goal is to create a design that generalizes well to new, hidden information patterns.
