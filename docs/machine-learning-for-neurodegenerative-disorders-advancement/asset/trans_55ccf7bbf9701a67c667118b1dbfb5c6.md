截至2023年12月底，对ClinicalTrials.gov的全面审查显示，有3,707项专注于帕金森病的研究项目，凸显了广泛的全球研究倡议（图 4.9）。北美处于领先地位，共有1,580项研究，其中美国占1,442项，加拿大占229项，墨西哥占15项。欧洲也做了巨大贡献，共有1,238项研究。研究工作在全球范围内广泛开展：东亚有389项研究（包括日本的65项），中东有205项研究。太平洋地区、南美洲和非洲分别参与了103项和42项研究。此外，北亚有45项，南亚44项，东南亚35项研究。这种广泛的全球参与强调了在增强理解和开发帕金森病治疗方法方面付出的积极且多样化的努力。

为了增强理解，ClinicalTrials.gov截至2023年12月29日的表4.6展示了帕金森病的III期临床试验，揭示了AI驱动药物发现和再利用的进展。NCT073689试验侧重于拉吉类（rasagiline），证明了其通过抑制单胺氧化酶B（MAO-B）增加大脑多巴胺水平并减轻症状，从而治疗帕金森病的有效性。NCT0525301研究了罗替戈汀（rotigotine），这是一种多巴胺激动剂，通过刺激多巴胺受体来改善运动症状。另一项试验NCT02610231考察了司曲替林（itradefeline）的长期效果，这是一种腺苷A2A受体阻滞剂，可以在不增加多巴胺产生的情况下增强运动功能。NCT1227265探索了普登（preladen）作为腺苷A2A拮抗剂增强运动症状方面的疗效。此外，NCT00627640研究了司非尼胺（safinamide）的使用，它作为选择性MAO-B抑制剂和钠通道阻滞剂，能增强多巴胺活性并调节谷氨酸释放。每项试验都代表了治疗帕金森病的创新方法，强调了向更具针对性、特定症状的疗法的转变，以应对疾病复杂的病理生理学。

## 4.5.3 AI在亨廷顿病研究中的应用

亨廷顿病是一种遗传性神经退行性疾病，由于其遗传性质以及对运动和认知功能的严重影响，面临着独特的挑战 [3]。AI正成为研究这种疾病的强有力工具，为理解和可能治疗该疾病提供了新方法 [138]。AI在通路分析方面显示出显著的有效性，特别是在理解亨廷顿病方面。这一过程涉及复杂的生物机制，例如亨廷舞蹈蛋白的正确折叠及其对许多细胞通路的影响。机器学习模型擅长分析这些生物通路，提供疾病分子水平进展的见解。通过处理大量的基因组学、蛋白质组学和代谢数据，这些模型可以识别亨廷顿病中改变的关键分子和通路 [139]。例如，AI算法可以分析细胞数据，以理解突变亨廷舞蹈蛋白如何影响基因表达、蛋白质合成和代谢过程等细胞功能。这种分析有助于识别药物可能改变疾病进展的干预点。详细阐明这些通路对于开发更有效减缓或停止疾病的靶治疗法至关重要 [14]。

预测建模是AI在亨廷顿病研究中的另一个应用。AI模型可以基于遗传信息、生物标志物和病史等临床数据，预测疾病的发病和进展。这些预测模型可以帮助临床医生做出护理决策，以及何时治疗或如何管理疾病进展 [62]。例如，AI模型可能会根据个人的遗传结构预测亨廷顿发病年龄，或根据早期症状预测进展速度。这些信息对于制定治疗和护理策略，以及向患者及其家属说明疾病进展的预期具有极高价值 [140]。
