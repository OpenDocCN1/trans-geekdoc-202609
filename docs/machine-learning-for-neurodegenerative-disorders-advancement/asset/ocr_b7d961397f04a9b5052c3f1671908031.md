# 5.4.1 MACHINE LEARNING

Machine learning has completely transformed gait analysis. FoG is a severe Parkinson's symptom leading to falls and healthcare burdens. Ahlrichs et al. introduced a FoG detector using a single waist-worn accelerometer and SVM classifier, achieving 98.7% accuracy while monitoring 20 Parkinson's patients in both medicated and unmedicated states [27]. Rodríguez-Martín et al. [28] introduced a FoG detection system using SVM classifier and a single waist-worn 3D accelerometer.
