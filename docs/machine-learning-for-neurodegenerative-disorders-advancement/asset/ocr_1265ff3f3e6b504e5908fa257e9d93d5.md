Performance evaluation is critical in determining the efficacy of models developed for detecting FoG in PD. The precision of the FoG classification-based predictive model is calculated by dividing the number of real positive predictions by the total number of positive predictions, represents the model's ability to avoid false alarms, which is crucial for patient safety. Sensitivity assesses the model's ability to identify true positive cases, which is critical for timely intervention. Specificity measures the model's ability to correctly classify negative cases, whereas the number of unnecessary alerts. The accuracy metric provides an overall measure of correct predictions, providing a robust evaluation metric. Root mean square error (RMSE) evaluates the model's predictive accuracy in continuous FoG severity estimation, whereas the AUC-ROC evaluates the model's ability to distinguish between FoG and non-FoG states. Score balances precision and recall, providing a comprehensive measure of model performance. Pearson correlation measures the linear relationship between predicted and observed FoG severity by allowing for the evaluation of prediction quality on continuous scales.
