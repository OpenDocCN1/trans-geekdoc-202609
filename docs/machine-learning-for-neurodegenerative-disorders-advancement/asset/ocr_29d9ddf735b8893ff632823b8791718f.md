Driver fatigue is a common cause of accidents on lengthy journeys. If a reliable and accurate technology for detecting tiredness is available, the driver will be alerted. Using this strategy will assist the driver in making wise choices and preventing collisions. This article uses a potent sensor to identify driver tiredness. It was first created by processing EEG signals after they were captured. Twelve subjects' EEG data was subjected to several ML algorithms in order to classify each segment as alert or sleepy. Pre-processing is used to extract the pertinent information from captured signal before the ML algorithms are applied. The techniques that are used are K-nearest neighbor, random forest analysis (RFA), naive Bayes (diagonal discriminant analysis), and support vector machines (linear and radial basis functions). It was discovered that several classifiers produced the best accuracy of 100% for all subjects taken consideration in this investigation, when signals were captured from just three electrodes. The EEG-based system is very accurate at detecting drivers' tiredness and lack of focus in real time, which makes it a viable and trustworthy solution for real-time applications.
