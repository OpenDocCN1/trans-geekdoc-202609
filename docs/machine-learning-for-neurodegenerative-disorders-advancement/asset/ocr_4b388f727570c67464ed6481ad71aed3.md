# 5.3.1 Data Pre-processing

Effective data pre-processing is crucial in the examination of FoG in PD, significantly contributing to the development of improved diagnostic systems and medical studies. Data cleaning includes outlier removal, noise reduction, and handling missing values, which critically ensures the generation of high-quality data for analysis. Data normalization is used to standardize data so that it can be compared across individuals and conditions. Furthermore, data transformation includes feature engineering to extract relevant variables. Dimensionality reduction techniques with feature selection reduce complexity and avoid overfitting. Sliding windows allow for more focused analysis on specific time intervals [19, 20]. Together, these pre-processing techniques (Figure 5.3) significantly improve the accuracy and effectiveness of modeling and analyzing of the FoG condition in Parkinson patients.

# 5.3.2 FEATURE EXTRACTION AND FEATURE SELECTION

Feature extraction and selection play a critical role in the analysis of various aspects of human health and behavior, particularly in the context of PD. In this, we highlight significant characteristics as illustrated in Figure 5.4 associated with quantitative spatiotemporal analysis, handwriting, kinematics, speed, kinetics, and frequency and time-domain analysis [21, 22].

+   a. Quantitative spatiotemporal features: These parameters include step length, walking speed, gait pattern, and cadence (steps per minute). The extraction of these features from gait provides valuable insights about the progressive increase of motor symptoms in individuals. The changes in these parameters may induce gait disturbances associated with the condition.

+   b. Handwriting features: PD frequently manifests as distinct changes in handwriting, such as micrographia, which is characterized by a decrease in letter size, as well as spiral drawings. Feature extraction entails quantifying the dimensions, contour, and uniformity of characters or spirals, allowing for an objective assessment of motor impairments.

+   c. Kinematics features: The kinematics of bodily movements relating to walking, turning, and hand movements illustrate significant information regarding the motor control and balance of the patients. These data are essential for monitoring the progression of gait-related symptoms and developing targeted interventions.
