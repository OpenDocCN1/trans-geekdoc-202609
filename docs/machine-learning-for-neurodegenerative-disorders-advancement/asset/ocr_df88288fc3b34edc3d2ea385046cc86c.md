Utilizing an MRI image as an input for processing, the initial step of the proposed methodology is image capture. Cranial images in the MRI format are 255 x 255 pixels in size when saved in MATLAB, and because their entry ranges are 0 to 1, they are displayed as RGB images in gray scale. In instance, the black stratum is denoted by 0 and the white image by 1. A difference in intensity from black is represented between 0 and 1.

Feature extraction is the process of converting unprocessed data into numerical features so that the information contained in the original data set may be processed.
First, the features are taken from the normalized MRI images, which are normalized to gray level values from 0 to 1. Normalization significantly simplifies feature extraction by reducing the fluctuating range of the intensity values.
Initially, the image is extracted from the framework by reading and transforming the image into a grayscale image.

> G(x) = 0.299 \times r + 0.587 \times g + 0.114 \times b

Here, r, g, and b are the pixel values of red, green, and blue intensities that are to be converted to a grayscale pixel value may lie between 0 and 255. This data acquisition process of reading the entire images every pixel of the image into grayscale pixels.
