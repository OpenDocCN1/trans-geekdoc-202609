# 9.4.1.1 Sensitivity

Sensitivity is the test that presents a positive report of illness for the subject who is actually ill. This validation measure of actual positives is given by the formula:

Sensitivity = \frac{t}{t + f'} (9.6)

# 9.4.1.2 Specificity

Specificity is the test that presents a negative report of illness for a sickness-free subject. This validation measure of actual negatives is given by the formula:

Specificity = \frac{t'}{t' + f} (9.7)
