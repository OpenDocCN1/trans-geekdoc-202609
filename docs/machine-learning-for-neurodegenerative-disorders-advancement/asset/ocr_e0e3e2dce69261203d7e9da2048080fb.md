# 1.2.1.7 Supervised Learning

Supervised learning is a type of ML where the model is trained on a labeled dataset, meaning that each training example is paired with an output label. The objective is to learn a mapping from inputs to outputs that can be generalized to new, unseen data. Common supervised learning tasks include classification and regression [Cakar & Yavuz, 2023]. Algorithms like linear regression, logistic regression, decision trees, and support vector machines are commonly used. The success of supervised learning depends on the availability of a large, high-quality, labeled dataset and choice of appropriate features. In supervised learning, the algorithm learns from a labeled dataset uses the input features and associated labels to learn the mapping between them [Cakar & Yavuz, 2023; Currey et al., 2023]. The objective is to create a model to predict for new, unseen data accurately.

# 1.2.1.8 Unsupervised Learning

Unsupervised learning involves training a model on data that does not have labeled responses. The goal is to uncover patterns or intrinsic structures within the data. Common tasks include clustering, where the model groups similar data points, and dimensionality reduction, where the model simplifies the data representation [Vdeai et al., 2023]. Algorithms such as k-means clustering, hierarchical clustering, and principal component analysis (PCA) are widely used. Unsupervised learning is useful for exploratory data analysis, anomaly detection, and preprocessing steps in supervised learning pipelines. It helps in discovering relationships and structures in the data without prior knowledge of the outcomes. The algorithm's task is to uncover hidden patterns, clusters, or structures within the data without labeled outcomes [Kawai et al., 2023]. Standard techniques include clustering and dimensionality reduction.

# 1.2.1.9 Semi-Supervised Learning

Semi-supervised learning combines elements of both supervised and unsupervised learning. Semisuvised learning is a hybrid approach that is particularly useful when acquiring labeled data is expensive or time-consuming. This method is when there is an abundance of unlabeled data [Cascone et al., 2023]. Semi-supervised learning leverages the structure of the unlabeled data to improve accuracy and generalization. Techniques like semi-training, co-training, and graph-based methods are common. The primary challenge is effectively utilizing the unlabeled data to complement the labeled data, which can significantly enhance the model's performance in scenarios with sparse labeled datasets. A small amount of labeled data and an enormous amount of unlabeled data are used to improve the model's learning and generalizability [Jaison et al., 2023].
