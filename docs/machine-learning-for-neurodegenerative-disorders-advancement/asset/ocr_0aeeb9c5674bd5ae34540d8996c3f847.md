# 1.2.2.1.4 Random Forest

Random forests are an ensemble learning method that combines multiple decision trees to improve predictive performance and robustness. Each tree in the forest is trained on a random subset of the training data and a random subset of features, introducing diversity among trees. The final prediction is obtained by aggregating the predictions of all individual trees, typically through majority voting for classification or averaging (Zheng et al., 2023). This process reduces variance and mitigates overfitting, leading to more accurate and stable predictions. Random forests can handle large datasets with high dimensional features and provide estimates of feature importance. They are widely used in various applications, including image and text classification, anomaly detection, and bioinformatics. Despite their disadvantages, random forests can be computationally intensive and less interpre than decision trees. Each tree makes an independent predictor, and the final result is determined by majority voting (classification) or averaging (regression) (Vedai et al., 2023). This ensemble technique reduces overfitting.

# 1.2.2.1.5 Support Vector Machines

The core idea is to find the hyperplane that separates the data into classes by maximizing the margin between the points of the classes, as known support vectors. Support vector machines (SVMs) can handle linear and nonlinear boundaries using kernel functions (for example, polynomial, radial basis function) to transform the input into higher-dimensional spaces where a linear separator can be found. This flexibility makes SVMs effective in high-dimensional spaces and when dealing complex, nonlinear relationships (Cakar & Yavuz, 2023). SVMs are prone to overfitting, predominantly in high-dimensional feature spaces, and are widely used in applications such as text classification, image recognition, and bioinformatics. However, they can be computationally expensive, especially for large datasets, and selecting the appropriate kernel and regularization parameters requires careful tuning. It can handle both linear and nonlinear classification using the kernel trick, mapping data to higher-dimensional spaces (Rajput, 2023).

# 1.2.3.1 K-Means Clustering

K-means clustering is a popular unsupervised learning algorithm used to partition data into k distinct clusters based on feature similarity. The algorithm begins by initializing k clusters randomly. Each data point is assigned to the nearest center, forming clusters. The centroids are updated by the mean of the data in each cluster. This process of assignment and update is repeated iteratively until convergence, when the centroids no longer change (Rutkowski et al., 2023). The objective is to minimize the sum of squared distances between data points and their respective centers, known as the within-cluster sum of squares. K-means is efficient and easy to implement but the number of clusters to be specified in advance and is sensitive to initial cluster placement and outliers (Ellwood, 2023). It performs well on spheres of similar sizes but struggles with more complex cluster shapes. The algorithm initializes cluster centers randomly, assigns data points to the nearest center, recalculates, and iterates until convergence (Kawai et al., 2023).
