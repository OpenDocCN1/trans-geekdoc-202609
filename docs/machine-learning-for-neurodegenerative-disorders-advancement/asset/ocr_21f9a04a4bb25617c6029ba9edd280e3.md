# 1.2.5.3 Gradient Boosting

Gradient Boosting²³ is an ensemble learning technique that builds a strong predictive model by combining the outputs of several weak learners, typically decision trees. The algorithm works iteratively, where each new tree corrects the errors made by the previous trees. It optimizes a loss function by using "gradient boosting." This approach allows the model to focus on the most difficult-to-predict instances, such as CatBoost,²⁴ and XGBoost,²⁵ known for their high performance and are widely used in ML competitions and practical applications. However, they handle different types of data, can model complex relationships, and provide robust predictions. However, they can be computationally intensive and sensitive to hyperparameter tuning, requiring careful care-validation to prevent overfitting (Jaison et al., 2023). # 1.2.5.4 Long Short-Term Memory (LSTM)

Long short-term memory (LSTM)²⁷ networks are a type of recurrent neural network (RNN)²⁸ designed to capture sequential dependencies in data. Traditional RNNs struggle with learning dependencies dependencies to the vanishing gradient problem. LSTM addresses this issue with a cell structure that includes three gates: the input gate, the forget gate, and the output gate. The gates regulate the flow of information, allowing the network to maintain and update a cell state over long sequence. The input gate controls what new information is added, the forget gate decides what information to discard, and the output gate determines the final output. This architecture allows LSTMs to effectively capture temporal patterns in data, making them ideal for tasks such as series forecasting, language modeling, and speech recognition. However, LSTMs require significant computational resources and careful tuning to achieve optimal performance. They excel in tasks that involve time series, sequences, and natural language processing due to their ability to handle vanishing gradient problems (Straka et al., 2023) (Figure 1.3).
