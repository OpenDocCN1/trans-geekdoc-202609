# 8.3.3.2 Feature Extraction

The process of feature extraction involves selecting and transforming significant attributes from pre-processed data to improve the accuracy and efficiency of predictive models. This process begins by identifying features, such as family history of PDD, screening scores, and specific question responses. These attributes are crucial as they provide essential information that can significantly contribute to predicting ASD. By focusing on these key features, the model can better understand patterns and relationships within the data, leading to more accurate predictions.

To select significant features from the pre-processed data, we identify the variables X that have a strong correlation with the target Y (ASD prediction). We suppose we have a dataset with n samples and m features, represented as X = {xl,x2,...,xm} and target Y. The selection of informative features can be framed as finding the X'⊆X that maximizes the correlation with Y.

# 8.3.3.2.1 Derived Feature Creation

In addition to selecting features, crafting derived features is a valuable aspect of feature extraction. Derived features can provide additional insights and enhance model performance. For instance, categorizing age into specific groups such as toddlers, children, adolescents, and adults can reveal trends and differences in ASD prediction across different ages. Similarly, defining relationships such as parent, self, or healthcare professional who completed the test can help contextualize the data, offering a deeper understanding of the individual's background and circumstances.

Derived features are created by applying transformations to selected features. For instance, if age is a feature, we can derive categories as:

> Age Category = \begin{cases} Toddler & if 0 \le Age < 3 \ Child & if 3 \le Age < 12 \ Adolescent & if 12 \le Age < 18 \ Adult & if Age \ge 18 \end{cases} \quad (8.12)

# 8.3.3.2.2 Redundant and Correlated Feature Removal

Another critical aspect of feature extraction is removing redundant or highly correlated features. Redundant features do not contribute new information and can unnecessarily complicate the model, while highly correlated features can distort the model's predictions by giving undue weight to certain aspects of the data. By eliminating these features, the model becomes much more streamlined and interpretable, reducing complexity without compromising predictive accuracy.

To remove redundant or highly correlated features, we compute the correlation matrix C for all features:

```
C_{ij} = \frac{Cov(Xi,Xj)}{\sigmaXi\sigmaXj} \quad (8.13)
```

Cov(Xi,Xj) is the covariance between features Xi and Xj, and σXi and σXj are the standard deviations. To remove one of the features Xi and Xj if |Cij| exceeds a threshold τ, indicating a high correlation.
