## 9.3.2 AI-BASED SEGMENTATION OF THE MRI BRAIN SLICE

In order help AI mimic learning processes and progressively increase its degree of precision, ML, a subfield of computational science and artificial intelligence (AI), focuses on leveraging data along algorithms [27]. Image segmentation technique is implemented to analyze the image and partition it into multiple regions based on the characteristics of the image pixels. The division of an image into several pieces is called image segmentation in computer vision. Changing an image's representation into something more pertinent and comprehensible is the aim of image segmentation. Location and boundary construction are its usual purposes.

Because many areas of an image might not contain any relevant information, processing a full image is not an ideal choice. As such, we can process the image by segmenting it so that only the major portions are used. A collection of predominated slices is all that makes up an image. Pixels with comparable characteristics are clustered together in image segmentation. Through the pixel-by-pixel boundaries for every element in a picture, image segmentation provides us with a more detailed and thorough understanding of the object – ROI.

As a consequence, the ROI along with its attributes can be extracted and studied for quantitative purpose. The KM clustering algorithm is implemented for a primary level of image segmentation [28] which acts as a powerful tool in clustering the image and a secondary segmentation by GT algorithm detailing the ROI's features, which in this case is the tumor in the MRI image.

### A Unique Machine Learning Approach

This unsupervised method of AI learning groups the pixels of the particular unlabeled image into several clusters which share similarities within the cluster and dis-similarities with the other clusters. This clustering algorithm predicting group similarities the findings of major concern in the MRI image, which should be the interior region of the cranium with the ROI and, the border region of the cranium, and the exterior region of the cranium, where the intensity of the pixels may vary. Although the noise in the image is effectively removed by the AD filter, some grainy appearance may be left to manipulate the ROI. KM algorithm is an efficient algorithm that eradicates the noisy features and pulls out the tumor to be studied.

This algorithm needs an initial assignment of cluster. In this study, the KM algorithm [17] is implemented with several regions of the image in the following fashion. The first cluster, C1 includes the vertices and the gray matter. The second cluster, C2 includes the exterior portion of the cluster. The third cluster, C3, is assigned to the white matter, and the final cluster, C4 is comprised of ROI, where the lesion and the left-out noisy pixels. This assignment of clusters is determined in advance by manually observing the intensity variation appearance in the MRI brain slide. Upon this determination of a number of clusters, the algorithm by KM can be implemented for efficient clustering. A generalized algorithm of KM clustering procedure defined below.

- Set the initial values of the KM at random for a specified number of iterations.
- Repeat each group or cluster.
- Determine which mean is closest to the item by comparing each mean's Euclidean distance to the group.
- Assign the cluster to represent the mean.
- Adjust the mean by moving it to the cluster's average value.

The following are the iterative steps in KM clustering algorithm.

1. Determine the data points (x1, y1), (x2, y2), ..., (xn, yn) in 2D space from the anisotropic-tropically diffused 2D image to generate differentiated clusters with its corresponding data points.
2. Learn and initialize the mid-value or the centroid value of the image in 2D space.
3. Assign the number of clusters, C=4 (i.e., C1, C2, C3, and C4) and decide four random seed points or the centroids in those particular clusters.
4. In the first iteration, determine the distance between each data point with the four seed points by means of Euclidean distance formula. Let the random seed points with respect to the four clusters be (A1, B1), (A2, B2), (A3, B3), (A4, B4). Euclidean distance, D for the first data point and the four seed points is given by

D=√((x1-A1)^2 + (y1-B1)^2) for C1
D=√((x1-A2)^2 + (y1-B2)^2) for C2
D=√((x1-A3)^2 + (y1-B3)^2) for C3
D=√((x1-A4)^2 + (y1-B4)^2) for C4

5. Calculate the cluster number by knowing the minimum value of Euclidean distance among the four distances calculated. If the distance in cluster C2 has the minimum value, then that cluster number is assigned to the particular data point (x1, y1).
6. Similarly, calculate the Euclidean distances for all data points to know the particular cluster in which each data point belongs and know the cluster number for each data point. C1, C2, C3, C4
7. In the second iteration, on the cluster number (i.e., C1, C2, C3, C4), determine the new seed points by calculating the centroid value. The data points of similar clusters are taken into account, and their average is the new centroid value. Suppose if (x1, y1), (x7, y7), (x20, y20), (x37, y37), (x91, y91), (x150, y150) have similar clusters C1; Then the new seed point and centroid value is calculated by (x1+x7+x20+x37+x91+x150)/6, (y1+y7+y20+y37+y91+y150)/6. In this way, new centroid values are calculated.
8. Similarly, determine the Euclidean distance [19] for each data point to the four clusters and know the cluster numbers by determining the minimum value of the distance.
9. Examine for movement of data points by performing a similarity check between the first iteration cluster numbers and the second iteration cluster numbers.
10. If there is a change in the sequence of cluster numbers, move to iteration three and repeat the same process of calculating the centroid values, Euclidean distance, and cluster numbers. Upon no change in the sequence of cluster numbers, the iterative loop can be terminated with the clusters being built with their respective data points.

Thus, Ai method of learning moves the data points into several classes based on the unsupervised algorithm, which clusters the medical brain image into four clusters, named C1, C2, C3, and C4.
