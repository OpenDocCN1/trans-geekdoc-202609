# 1.2.2.1 Logistic Regression

Despite its name, logistic regression¹ is used for binary classification tasks. It models the probability that an input belongs to a specific class using the logistic function. It is a linear model used to estimate the probability that a given input belongs to a particular class. The model uses the logistic function $\sigma(z)=\frac{1}{1+e^{-z}}$, where $z$ is a linear combination of input features, to map predicted values to between 0 and 1. The logistic regression model aims to find parameters that maximize the likelihood of the observed data, using techniques such as gradient descent for optimization (Kawai et al., 2023). Logistic regression is interpretable and can handle large datasets easily in medicine, finance, and social sciences for tasks such as diagnosis, credit scoring, and survey analysis. However, it assumes a linear relationship between the input features and the logs of the outcome, which may not capture complex patterns. It calculates a decision boundary that separates the classes based on input features (Cascone et al., 2023).

# 1.2.2.1. Decision Trees

Decision trees recursively split the data into subsets based on the values of the input features. Decision trees are a nonlinear supervised learning algorithm used for both classification and regression tasks. The model splits the data into subsets based on feature values, creating a tree-structure where each node represents a feature, each branch represents a decision rule, and each leaf node represents an outcome.
