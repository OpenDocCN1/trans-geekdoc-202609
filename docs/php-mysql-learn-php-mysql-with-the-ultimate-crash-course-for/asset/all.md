Chapter 1: Introduction to PHP 

 

PHP stands for PHP: Hypertext Preprocessor, an open source scripting language whose scripts are executed on the server. It is downloadable and available for free. It is ideal for web development and recommended for beginners. It can be embedded into HTML. In addition, it can be used for WordPress and Facebook.

A PHP file can contain HTML, JavaScript, CSS, PHP code, and text. What differentiates PHP from client-side JavaScript is that the codes are executed on the server, which generates the HTML that is sent to the client. After running the script, the client receives the results even if he does not know the underlying code. It is possible to configure the web server for the purpose of processing HTML files using PHP.

PHP is simple enough to be understood by newbies, but it also offers a lot of advanced features for advanced programmers. You can even start writing simple scripts within just a few hours. 

Note that although its creation is focused on server-side scripting, there is so much more you can do with it.

 

## Why You Should Learn PHP

 

You may think that learning PHP is no longer necessary if you are adept at using JavaScript. However, JavaScript is actually much limited compared to PHP. JavaScript runs in the client or browser, which means that it only knows what occurs in your browser and the websites that you visit.

On the other hand, PHP runs on the same computer or server as the website that you go to. It has access to every file and information on that computer, which enables it to create custom HTML pages that it sends to your browser, run tasks, perform calculations, and handle cookies from that website.

PHP can open, create, write, read, close, and delete files on the server. It can generate page content, collect form data, and send and receive cookies. It can also delete, add, and modify data in the database. In addition, it can encrypt data as well as control user access.

With PHP, you can output PDF files, images, and Flash movies. You are not limited to just HTML. You can even output texts, such as XML and XHTML. In other words, PHP can practically do anything. Since it is focused on server-side scripting, it can do anything that other CGI programs can do and more. 

PHP scripts are mainly used in the following areas:

*   Server-side scripting.

It is the primary target field for PHP. To make it work, you have to use a PHP parser, a web browser, and a web server. You can have to run the web server that has an installed PHP. You can use the web browser to access the PHP program and view the PHP page. If you have just started experimenting with PHP, you can do all of these on your computer.

 

*   Command line scripting.

 

Even if you do not have a browser or a server, you can still run PHP. You just need to have a PHP parser. It is recommended for scripts that are executed regularly using Task Scheduler for Windows or cron for Linux. You can also use these scripts for simple text processing.

 

*   Creating desktop applications

 

While it is true that PHP is not the number one choice for creating desktop applications with graphical user interfaces, you can still use it if you want to include advanced features in your applications. You can use PHP-GTK to create such client-side applications. Also, you can write cross-platform applications. PHP-GTK is actually a PHP extension and it is not available in the primary distribution.

You can use PHP on any major operating system, including Unix, Linux, Microsoft Windows, RISC OS, and Mac OS X. PHP is also supported by majority of the web servers that are popular today, such as Apache and IIS. Any web server that can use FastCGI PHP binary, such as nginx and lighttpd can also use PHP. PHP can serve as a CGI processor or a module.

You are free to choose any web server and operating system with PHP. Moreover, you can choose object oriented programming, procedural programming, or a combination of both. PHP can autogenerate your files and save them in your file system rather than printing them out.

One of the main advantages of PHP is that it supports a variety of databases. It is very easy to write a database-enabled web page using a database specific extension or an abstraction layer, such as PDO. You can also connect to a database that supports the Open Database Connection standard through the ODBC extension.

What’s more, PHP has support for communication with other services via protocols such as IMAP, LDAP, SNMP, POP3, NNTP, COM, and HTTP. You can even interact and open raw network sockets using a protocol of your choice. PHP supports Java installation as well as WDDX data exchange between all programming languages.

PHP also features text processing, including Perl Compatible Regular Expressions and other tools for parsing and accessing XML files. PHP standardizes XML extensions as well as adds XML Reader, XML Writer, and Simple XML support. PHP also has added PECL extensions, such as XDebug.

 

## Setting Up PHP on Your Computer

 

In order to begin using PHP, you have to look for a web host that supports MySQL and PHP. You can also install a web server and then install MySQL and PHP. However, if your server already supports PHP, then you no longer have to do the above instructions. You simply have to create .php files and put them in your direction. The server will then parse them automatically. There is no more need for you to compile or install anything. Majority of the web hosts today actually support PHP because it is free.

Chapter 2: MySQL 

 

MySQL is an open source Relational Database Management System (RDBMS) that is available for free. It makes use of Structured Query Language (SQL), which is the most commonly used language for accessing, managing, and adding content in databases. It is also known for its proven reliability, quick processing, flexibility, and ease of use. MySQL is a crucial part of nearly every open source PHP application. Some of the most popular PHP/MySQL-based scripts include Joomla, phpBB, and osCommerce.

 

## So What Is MySQL Exactly?

 

To understand what MySQL is, you have to know what a computer database is. Essentially, a computer database is a collection of data. MySQL and other specialized database software are simply programs that allow users to store and retrieve data efficiently.

Specialized database software programs are used to avoid experiencing problems with storing and retrieving data. For instance, if you save your files using no-brainer file names, such as a.doc, b.doc, and c.doc, you will have a hard time looking for your files when you need them. You need a more efficient method for data storage.

A database is a computer software program that is meant to store huge amounts of data. It is basically a structured collection of data that can be anything from picture galleries to shopping lists to corporate network information. With database software, you can keep lists that contain vital information. 

For instance, if you are running a store, using a database will help you keep everything organized. You can create a list of your customers and their addresses. If you need to obtain information from a particular customer, there is no more need for you to check your data one by one.

In order to access, process, and add data stored in your database, you need a database management system like MySQL Server. Because computers are efficient at handling huge amounts of data, you can greatly benefit from database management systems. They are ideal for computing, as part of applications, and as standalone units.

MySQL databases are also relational. They store data in separate tables instead of storing all of the data in a single storeroom. Logical models with objects such as tables, rows, columns, views, and databases offer flexible programming environments. As a user, you can create your own rules with regard to the relationships between data fields, including one-to-many, one-to-one, unique, optional, required, and pointers between tables. Your database then enforces such rules so your application does not see duplicate, inconsistent, mission, orphan, or outdated data.

SQL in MySQL actually stands for Structured Query Language. It is defined by the ANSI/ISO SQL Standard, which has been in existent since 1986. It is the most well-known standardized language for accessing databases. You may directly enter SQL to perform certain actions such as generating reports; embed SQL statements into codes that were created using other languages; or use language-specific application programming interfaces (APIs) that conceal SQL.

MySQL database servers are fast, scalable, and reliable. They are also easy to use, which is why they can be used by beginners. They can run well on desktops or laptops, alongside other web servers and applications. They do not require much attention, which make them easy to maintain. You can also adjust your settings to make the most of the available memory, I/O capacity, and CPU power if you use a machine specifically for MySQL.

 

## MySQL vs. PostgreSQL

 

When it comes to open source relational database management systems, a lot of people experience difficulty choosing between MySQL and PostgreSQL. MySQL is the most well-known and commonly used RDBMS while PostgreSQL is the most advanced open source objective RDBMS. Both are excellent solutions that are comparable to proprietary database software.

PostgreSQL, also referred to as Postgres, is an object-relational database management system (ORDBMS) that focuses on standards-compliance and extensibility. It stores data, supports the best practices, and allows for retrieval. It can also handle workloads, including single-machine applications and Internet-facing applications.

Many users presume MySQL to have fewers features yet faster than PostgreSQL. Conversely, they presume PostgreSQL to be densely featured and similar to Oracle. Developers prefer MySQL for software projects due to its ease of use and speed, but many developers who have a background on SQL Server and Oracle also use PostgreSQL.

MySQL has a couple of layers, a layer for several storage engines and an upper layer. PostgreSQL, on the other hand, has just one storage engine. Remember that storage engines mostly differ in terms of performance and functionality. Depending on what environment your database system runs in, you can optimize it.

Some of the most significant features of PostgreSQL include TOAST data compression, parameterized and static SQL executor, improved cache management, large scalability, asynchronous commit, and advanced cost-based optimizer. PostgreSQL has the ability to decompress and compress data using a speedy compression scheme that allows it to fit data into a specific disk space. Compressing data is great because it saves disk space as well as reads data faster.

Some of the core features of MySQL include a broad ANSI SQL 99 subset and extensions, table partitioning through LIST, SET, HASH, and RANGE, network protocol compression, built-in replication though row-change events or statements, triggers, SSL support, cursors, stored procedures, updateable views, and Unicode support.

If you are a webmaster who does not write programs for your website, you may not find the differences between MySQL and PostgreSQL to be such a big deal. Your concerns may be mainly about your web host having database software that you need for your application. In general, if you use CMS or any other popular software for blogging, you can expect it to be MySQL. Nearly all commercial web hosts have MySQL as part of their hosting packages.

 

## Do you need to learn MySQL? 

Average webmasters do not need to study SQL or MySQL because the software they use is most likely to do the storing and retrieving of data. They just have to learn how to use their software. Think of MySQL and similar databases as car engines. There is really no need for you to learn how to design car engines just to be able to use cars. Similarly, there is no need for you to learn how to directly read and write MySQL databases to be able to use blogging software.

On the other hand, if you are a programmer, you need to study SQL to be able to write computer programs that access MySQL and other SQL databases. Of course, you also need to learn a suitable programming language. If you are wondering if you have to be a programmer to become a webmaster, the answer is no. You can be a webmaster without knowing how to program. You can create a website by manually coding it in HTML.

## Syntax

 

You can place PHP scripts anywhere in you document. They generally begin with <?php and end with ?>:. Their file extension is .php and they normally contain PHP scripting codes and HTML tags. Do not forget to use a semicolon (;) to end a PHP statement.

Consider the following example of a PHP code:

<?php

echo “Testing code”;

?>

 

If you run this code, you will get an output of:

Testing code

 

 

## Comments

 

Comments are lines that are not executed or read as part of the program. Their sole purpose is to be read by users who may need additional information. You can include comments in your program if you want other people to gain a better understanding of it or you want to be reminded of what you did. In case you decide to look back at your program after a few years, your comments can be helpful. They can remind you about your thoughts during the time when you created your code.

Consider the following example:

<?php

\# This is a single line comment

//This is a single line comment

/\* 

This is a 

multiple line 

comment

\*/

//This is a comment that leaves out a part of a code line

$w = 2 /\* + 10 \*/ + 3;

echo $w;

?>

 

If you run this code, you will get an output of:

5

 

 

## Case Sensitivity

 

Functions, keywords, and classes are not case sensitive in PHP. 

Consider this example:

<?php

echo “Testing code ”;

ECHO “Testing code ”;

EcHo “Testing code ”;

?>

 

If you run this code, you will get an output of:

Testing code Testing code Testing code

 

However, variable names are case sensitive in PHP.

Take a look at this example:

<?php

$color = “blue”;

echo “The sky is ” . $color . “\\n“;

echo “The sky is “ . $coLOR . “\\n“;

echo “The sky is “ . $COLOR . “\\n“;

?>

 

If you run this code, you will get an output of:

The sky is blue 

The sky is 

The sky is

 

If you notice, the first statement is the only one that displays the value of the variable $color. This is because $color, $coLOR, and $COLOR are treated as different variables.

 

## New Line

To create a new line, you simply have to place \\n after your statement.

Take a look at this example:

<?php

echo “The sky is blue. \\n“;

echo “The rose is red. \\n“;

?>

 

If you run this code, you will get an output of:

The sky is blue.

The rose is red.

 

 

## Dealing with Forms

 

Amongst the greatest advantages of PHP is that it can deal with HTML forms. Take note that form elements are automatically available in PHP scripts.

Chapter 4: Arrays 

 

An array is a special variable that stores multiple values one at a time. It is basically a list of items. For instance, if you want to store a list of names, you can store them in single variables such as:

$name1 = “Wendy”;

$name2 = “Dawn”;

$name3 = “David”;

 

However, if you want to create a loop through these names, you need an array. Arrays can hold numerous values in one name and allow you to access these values when you refer to an index number.

To put it in a much simpler perspective, an array is like a grocery list. It lets you store more than one item in one variable. When you create your grocery list, you can use separate pieces of paper for every item that you have to buy. These items are like the variables that you store.

Using separate pieces of paper for your grocery items is unnecessary though. It is such a hassle and a total waste of paper. So, instead of doing this, you can just write down everything you need to buy in a single piece of paper. This single piece of paper is just like an array.

 

## How to Create an Array

 

The array ( ) function in PHP is used to create arrays. Any number of comma-separated key => value pairs can be used as arguments. For instance,

array (

              key1 => value1,

key2 => value2,

…

)

 

The last array may or may not have a comma. Single-line arrays are actually better off without commas. So instead of writing array (1, 2, ), you should write array (1, 2). Multi-line arrays, however, are preferred to have trailing commas because they make the addition of new elements easier.

There are actually three types of arrays: associative, indexed, and multidimensional. Associative arrays are arrays that have named keys. Indexed arrays are arrays that have a numeric index. Multidimensional arrays are arrays that contain one or more arrays.

The syntax for associative arrays is:

array (key => value, key => value, etc.);

For example:

<?php

$price = array (“cantaloupes” => “2”, “grapes” => “3”, “strawberries” => “4”);

echo “Cantaloupes cost “ . $price \[‘oranges’\] . “dollars each.”;

?>

 

The syntax for index arrays is:

array (value1, value2, etc.);

 

There are two ways on how you can write indexed arrays. You can allow the index to be automatically assigned or assign it manually.

Take a look at this example of an automatically assigned index:

$fruits = array (“apples”, “bananas”, “kiwis”);

And here is an example of a manually assigned index:

$fruits \[0\] = “apples”;

$fruits \[1\] = “bananas”;

$fruits \[2\] = “kiwis”;

 

As for multidimensional array, here is an example of a two-dimensional array:

<?php

$fruits = array (

array (“apples”, 10, 6),

array (“bananas”, 4, 5),

array (“kiwis”, 11, 10)

);

?>

 

 

In PHP 5.4, array ( ) can be replaced with \[ \]. This is called the short array syntax. For example:

<?php

$name = array (

              “Wendy” => “Dawn”,

              “Dawn” => “Wendy”,

);

 

can be written like this if you are using PHP 5.4:

 

<?php

$name = \[

              “Wendy” => “Dawn”,

              “Dawn” => “Wendy”,

\];

?>

 

A string or an integer can be the key. The value can also be of any type. In addition, these key casts are expected to occur:

Float. It is cast to an integer, truncating the fractional part. For example, the key 9.7 is going to be stored under 9.

String. A string that contains a valid integer is cast to the integer type. For example, the key 9 is going to be stored under 9 while the key 09 is not going to be cast since it is not a valid decimal integer.

Bool. It is also cast to an integer. For example, the key false is going to be stored under 0 while the key true is going to be stored under 1.

Null. It is cast to an empty string. For example, the key null is going to be stored under “ “.

Objects and arrays can never be used as keys. If you try to use them as keys, you will get an illegal offset type warning.

If you declare multiple elements with the same key, the last one is going to be used while the others are going to be overwritten.

Consider the following example:

<?php

$array = array (

              1 => “w”,

              “1” => “x”,

              1.5 => “y”,

              true => “z”,

);

var\_dump ($array);

?>

If you run this code, you will get an output of:

array (1)  {

              \[1\] =>

              string (1) “z”

}

 

This is the resulting output because all the keys are cast to 1. For every new element, the value is overwritten, which is why the value “z” is left. String and integer keys can be contained in PHP arrays all at once since PHP cannot differentiate associative and indexed arrays.

 

## The Square Bracket Syntax

The array \[key\] syntax can be used to access array elements. Both curly braces and square brackets can be used interchangeably if you want to access array elements. Since PHP 5.4, you can array deference the results of method calls and function calls directly. In the earlier versions, you can only array deference with the use of a temporary variable. Since PHP 5.5, you can already array deference array literals. Then again, take note that you cannot access array keys that have not been defined just as you cannot access any other undefined variables. If you do, you will get an E\_NOTICE-level error message and a NULL output.

When it comes to creating or modifying arrays using square bracket syntax, you can explicitly set values in them. You can do this by assigning values to the arrays. The keys should be specified in brackets or omitted to result in empty brackets (\[\]). If you wish to change a value, you can assign another value to the element through its key. If you wish to remove a value pair or key, you can use the unset ( ) function.

However, the array cannot be re-indexed. If you wish to remove and shift, you can use the array\_values ( ) function to re-index the array. Keep in mind that if you do not specify any key, the maximum integer indices will be taken. This will result in the new key being the maximum value plus one. If there are no integer indices, the key is going to be zero. The maximum integer key does not have to exist in the array currently though. It only has to exist in the array again after the array gets re-indexed.

Whenever you use a string literal array index, make sure that you do not forget to use quotes. Also, you should never write $foo\[bar\]. Instead, you should write $foo\[‘bar’\]. Even though it works, it is still wrong. If you notice, it uses an undefined constant instead of a string. Bar is the undefined constant while ‘bar’ is the string.

Chapter 5: Conditional Statements 

 

Conditional statements are used for performing various actions for various conditions. Oftentimes, when you write a code, you aim to perform actions for specific purposes. In PHP, you can use these conditional statements:

 

Switch statement – it lets you choose a block of code to execute

If statement – it lets you execute a code if the condition is true

If… Else If… Else statement – it lets you specific a new condition for testing if the previous condition is false

If… Else statement – it lets you execute a code if the condition is true, and another one if it is false

 

## The If Statement

 

As mentioned above, the if statement lets you execute a code if your condition is found to be true. Its syntax is:

if (condition)

{

              block of code;

}

 

Take a look at the following example:

<?php

$time = date (“Hour”);

If ($time < “10”)

{

              echo “Good morning!”;

}

?>

 

If you run this code, you will get an output of:

Good morning!

if and only if the hour or time is less than 10.

## The If… Else Statement

 

You can use the if… else statement to execute a code when the condition is found to be true, and then another code when the condition is found to be false. Its syntax is:

if (condition)

{

              block of code to execute if the condition is true;

}

              else 

{

              block of code to execute if the condition is false;

}

 

Consider the following example:

<?php

$time = date (“Hour”);

if ($time < “10”)

{

              echo “Good morning!”;

}

              else

{

# Chapter 6: Numbers and Mathematical Operations

 

The data types integer and float are numbers and can be stored in variables.

For example:

$intvar = 5;

$floatvar = 11.4;

 

In PHP, values are automatically stored as the appropriate data types. You can also perform mathematical operations. You simply have to indicate the mathematical operations by using a mathematical operator and two numbers.

For example, you can use the plus (+) sign operator.

2 + 3

You can also use variables.

$var2 + $var3;

 

If you want to use numbers in your mathematical operations, however, you should not enclose them in quotes when you assign them to variables. If you use quotes, you will set the numbers as character strings and you will not be able to perform mathematical operations on these character strings. Unlike other languages, PHP automatically converts strings to numbers.

Consider the following example:

$var1 = “2”;

$var2 = 4;

$total = $var1 + $var2;

 

It is obviously not possible to add the two given numbers because $var1 is a character string. Nevertheless, because string is automatically converted to a number in PHP, the numbers are added upon reaching the third statement. So if you use these statements, the strings will be converted and the numbers will be added.

$var1 = “y”;

$var2 = 4;

$total = $var1 + $var2;

Since y is not a number that can be converted in PHP, 0 is used in the addition process. Hence, the result of $total becomes 4. More often than not, such conversion is not what programmers expect. You should still be careful when you depend on the automatic conversion feature in PHP because there are times when you will not get the result that you expect, such as in the example given above.

In addition, you can get unexpected results because PHP does not understand human notation. If you use the following example, you can get an incorrect result:

$var1 = “3,000”;

$var2 = 3;

$total = $var1 + $var2;

 

You may understand commas and their function, but PHP does not. If you use a comma in your code, PHP will automatically stop reading at the comma. So if you execute the code given above, your $total will be read as 3 and not 3,000.

 

## Mathematical Operators 

\+ represents the addition process. It is used to add numbers.

\- represents the subtraction process. It is used to subtract the second number from the first one.

\* represents the multiplication process. It is used to multiply numbers.

/ represents the division process. It is used to divide the first number by the second number.

% is called the modulus. It identifies the remainder when you do the division process.

 

## The Order of Operations

 

It is possible to perform multiple mathematical operations all at once. Take a look at the following example:

 

$total = 2 + 3 \* 4 + 2;

 

Keep in mind that the order of your mathematical statement is crucial. You may get a different output. Hence, you have to be careful when you use mathematical operators in your code. In PHP, division and multiplication are performed first. Then, subtraction and addition are done. Also, PHP can start from the left towards the right if all other considerations are equal. 

 

If you run the code given above, you will get an output of:

16

 

You get 16 because PHP performs the multiplication process first. In $total = 2 + 3 \* 4 + 2, 3 \* 4 is done first. So multiplying 3 by 4, you get 12. Since the other operators for addition, PHP reads the code from the left. It adds 2 to 12, which is the result of 3 \* 4. Finally, it performs the last addition process. 2 + 12 is 14, and that is added to 2, so you get 16.

If you want to change the order of operations, you can use parentheses. When you use a parenthesis, whatever is inside it will be performed first. Take a look at the following example:

 

$total = (2 + 3) \* 4 + 2;

 

If you run this code, you will get an output of:

22

 

You get 22 because 2 + 3 is performed first since they are within the parenthesis. Adding 2 and 3 results in 5, which is then multiplied by 4. Your code practically becomes (5) \* 4 + 2. As mentioned earlier, the multiplication and division processes are performed first by default. However, since you have used a set of parenthesis, the operation inside it is performed first. Since you do not have any division process to be done, multiplication is performed. You get 20 + 2. Finally, you perform the last addition process. Adding 20 and 2 equals to 22.

It is also possible to use a set of parenthesis within another set of parenthesis. You can do this if you want to change the order of operations within that set of parenthesis. Ideally, if your mathematical statement has more than one answer, you should use parentheses where they are necessary.

There is another shortcut you can use to add a number to a certain variable. You can use +=1 to add 1 to that particular variable. You can also add any number to the variable through this shortcut. Likewise, you can use it to subtract, divide, or multiply. Take a look at the following example. Here are some of the statements you can use with the same format:

The above statements add the value of 3, subtract 2, multiply by 3, and divide by 2 with reference to $counter.

## Opening and Closing Files

 

In PHP, the function fopen ( ) is used to open files. It requires two arguments that state the file name and the mode in which it has to operate.

 

 
| File Mode || Purpose |
| --- | --- |
| r || It opens the file for the sole purpose of reading. It positions the pointer at the start of the file. |
| r+ || It opens the file both for reading and writing. It positions the pointer at the start of the file. |
| w || It opens the file for the sole purpose of writing. It positions the pointer at the start of the file, as well as truncates it to zero length. If there are no files, it tries to create one. |
| w+ || It opens the file for both reading and writing. It positions the pointer at the start of the file, as well as truncates it to zero length. If there are no files, it tries to create one. |
| a || It opens the file for the sole purpose of writing. It positions the pointer at the end of the file. If there are no files, it tries to create one. |
| a+ || It opens the file for both reading and writing. It positions the pointer at the end of the file. If there are no files, it tries to create one. |

 

The function fopen ( ) returns the value of false in case opening a file does not become successful. Otherwise, it returns a file pointer to write or read to that particular file.

Once you are done making changes to your file, you have to close it using the function fclose ( ). It requires a file pointer as an argument. It returns true if the closure is successful and false if it is not.

 

## Reading Files

 

After you open a file using the function fopen ( ), you can read it using the function fread ( ). It requires two arguments. It reads the length bytes from the file pointer referenced by the handle. It stops reading as soon as it has read the length bytes, reaches the end of the file, a socket timeout occurs, or a packet becomes available.  

You can use the function filesize ( ) to find the length of your file. It takes the file name as an argument and returns its size in bytes. It also returns false on failure or the read string. Take note that the function fread( ) reads from the current position of your file pointer. If you want to find the current position of the file pointer, you have to use the function ftell ( ). If you wish to rewind the position of the file pointer, you have to use rewind ( ).

Take a look at the following example:

<?php

$filename = “/testfile.txt”;

$file = fopen ($filename, “r”);

{

echo (“Opening File Error”);

exit ( );

}

$filesize = filesize ($filename);

$filetext = fread ($file, $filesize);

fclose ($file);

In the above example, the content of the text file testfile.txt is assigned to a variable and then displayed as the output.

 

## Writing Files

 

If you want to write a new file or append a text to an existing file, you can use the function fwrite ( ). It requires two arguments to specify the file pointer and the data string to be written. You can include a third integer argument if you want to specify the length of the data to be written. This third integer argument is optional, though. If you do not include any third argument, writing would stop upon reaching the specified length.

The function fwrite ( ) writes the contents of the string to the file stream pointed to by the handle. It returns false on error or the number of bytes. If you are using a system that differentiates between text files and binary files, such as Windows, you should open your file with ‘b’ included in the fopen ( ) mode parameter. Also, if the handle is opened in append mode, fwrite ( ) becomes atomic, except when the size of the string exceeds the block size of the file system. There is no more need to flock ( ) a resource before you call fwrite ( ). You can write all data without any interruption.

 

Take a look at the following example:

<?php

$file = fopen (“testfile.txt”, “w”);

echo fwrite ($file, “Testing sample!”);

fclose ($file);

?>

15
