### 7.4.1 Performance Metrics

The system of measurement used in the evaluation process were precision, recall, and F1-score. Precision is the ratio of the count of properly detected instances of sentiment polarity to the total number of detected instances. Recall is the fraction of count of correctly detected instances of sentiment polarity to the actual count of correct instances. F1-score is the geometric mean of precision and recall, which serves to achieve balance between the precision and recall.

### 7.4.2 Data Collection

The data required for model evaluation was obtained through the crawling of tweets on social media using the application programming interface (API) provided by Twitter. The steps involved in data collection from tweets using Python are presented below:

- Step 1: Create a Twitter developer account and design an app.
- Step 2: Install a Python library named Tweepy to access the API.
- Step 3: Authenticate the requests to the Twitter API.
- Step 4: Lift off the tweets using Tweepy.
- Step 5: Refine the tweets based on specific keywords like chatbots and bots, or filter by hashtags or product/service terms.

### 7.4.3 Evaluation

It is very important to evaluate the performance of the chatbot with respect to two parameters, namely, content evaluation and customer satisfaction [16]. The former is adopted from the research domains of information retrieval and NLP. It deals with the setting of the chatbot’s responses to customer service queries. Instead, customer satisfaction is the most commonly used parameter for chatbot performance evaluation because the responses may vary, and there is no single correct response. The chatbot’s performance is determined based on the contentment of the customer. The second parameter, customer satisfaction, is more suitable for assessing the performance because it is only for evaluation because it is on the customers’ end to decide whether the responses provided satisfy their requirements. ## 7.5 Conclusion

This chapter provides a better understanding of the methods that may be used to increase the competency of the customer care team by providing better responses to client inquiries from chatbots using sentiment analysis techniques. This chapter has covered the fundamentals of chatbots, sentiment analysis, and AutoNLP for pre-processing customer inquiry text, as well as a detailed sentiment analysis-based methodology for carrying out chatbot sentiment analysis to improve customer satisfaction with the chatbots’ responses. The proposed methodology discussed in this chapter attained a precision of 81%, a recall of 87%, and an F1 score of 84%. The performance improvement was possible as the polarity of the customer sentiment was measured in a fine-tuned manner using trilateral modifiers and the nonary scale of the proposed method.
