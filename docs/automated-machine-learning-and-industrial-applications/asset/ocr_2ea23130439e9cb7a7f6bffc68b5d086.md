Y = AX (8.15)

Consider $E(X) = 0, E(Y) = 0$, and the covariance matrix of $Y$ is:

RY = AR_X A^T (8.16)

Rx is the covariance matrix for X. It is obvious that examples are d-dimensional in node space if rows of A are eigenvectors of Rx utilizing this weight calculation; nonetheless, the primary goal of PCA transform is to create d-dimensional mapped samples that closely reflect X.

Reconstructing X as $X = A^T Y$ is possible. It is possible to project X rather than duplicate it using all of the eigenvectors; in this case, $^kX = A^T_K Y$, where k eigenvectors are used. The output nodes’ combined weight in this instance is:

$wgt = \sum_{i=1}^d \lambda_i - \sum_{i=1}^k \lambda_i = \sum_{i=k+1}^d \lambda_i$ (8.17)

Given a p.d. kernel and mapping such that $\Phi : S \to H (K)$, an RKHS exists.

$K(x, y) = \langle \Phi(x), \Phi(y) \rangle_{\mathcal{H}(K)}$
\(\cdot f(x) = \langle K_x, f \rangle_{\mathcal{H}(K)}\)
\(\text{span } \left\{ K_x := K(\cdot, x_j) \right\}\)

Concerning the H (K)-inner product:

\(\left\langle \sum c_i K_{x_i}, \sum d_j K_{x_j} \right\rangle_{\mathcal{H}(K)} := \Sigma c_{\max}\)
