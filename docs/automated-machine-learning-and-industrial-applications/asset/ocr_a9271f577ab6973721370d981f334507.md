# 3. Automated Data Augmentation

Data augmentation (DA) enhances model performance, especially with limited datasets, by increasing training data size and improving generalization. DA techniques apply to images [24], text [25], audio [26], and tabular data [27]. Figure 14.2 describes the data augmentation process applied to different data types.

# A. Image Data

Different data augmentation (DA) techniques, including object identification, image classification, and visual tracking can be used for image data. The following are some most common methodologies:

+   - Affine Transformations: Scaling, rotation, translation, and cropping.
+   - Elastic Transformations: Brightness, contrast, channel shifting, and blurring.
+   - Innovative Transformations: Random erasing, blending the images, cutout [28], mixup [29], and cutmix [30].

# B. Text Data

Techniques for augmenting textual data can improve training data and increase the diversity of text available. The following are a few most common strategies:

+   - Replacement of Synonyms: Replacing words with synonyms.
+   - Random Method of Insertion: Adding words randomly.
+   - Random Deletion: Removing words randomly.
+   - Back Translation: Translating text to another language and back.
+   - Random Swap: Shuffling word positions.
+   - OCR Noise: Introducing OCR-like errors [31].

# C. Audio Data

We can avoid overfitting and improve the model’s capacity to simplify unknown audio data by generating additional instances through transformations. Some of those techniques are as follows:

+   - Noise Injection: Adding Gaussian or random noise to the audio.
+   - Shifting: Shifting the audio left or right by random amounts.
+   - Speed Tuning: Changing the speed of the audio.
+   - Pitch Shifting: Randomly changing the pitch of the audio.
+   - Time Stretching: Stretching or compressing the audio duration.
