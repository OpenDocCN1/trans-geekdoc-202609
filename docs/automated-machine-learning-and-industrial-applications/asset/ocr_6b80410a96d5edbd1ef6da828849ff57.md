AutoML signifies an important leap forward in the world of robotics presenting an efficient and streamlined approach to crafting machine learning models and algorithms for robotic systems [16]. This creation minimizes the manual effort and expertise traditionally required in model development. In the context of robotics, AutoML involves automating various stages of the machine learning pipeline, encompassing data preprocessing, feature engineering, model selection, hyperparameter tuning, and even deployment.

# Types of AutoML

In a data science pipeline, various steps must be started by a data science team to create a predictive model. Even experienced teams of data scientists and ML engineers can find data with the improved speed and transparency given by AutoML. A data scientist typically starts the process with a hypothesis, acquires the appropriate dataset, creates data visualization, engineers additional features to store all available signals, and then follows to train a model with hyperparameters. For state-of-the-art deep learning, they also need to design an efficient architecture for a Deep Neural Network possibly leveraging a GPU if it is at their disposal [17]. The different types of AutoML are as follows:

+   1. Automated Feature Engineering
+   2. Automated Hyper Optimization
+   3. Neural Architecture Search
