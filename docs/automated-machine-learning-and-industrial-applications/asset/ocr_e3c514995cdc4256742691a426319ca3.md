# ### 7.3.5 Scoring

Scoring is done to assign a value to the sentiment-bearing term based on its positivity or negativity, accompanied by the modifier, if any. A sentiment score is a numerical representation of the polarity of the sentiment-bearing term. Existing works related to the task of scoring used a simple method to arrive at the value for a sentiment-bearing term. First, the score for the adjective or verb is obtained from a lexical resource such as SentiWordNet.
