# 11.9 Conclusion

The proposed mechanism appropriately associates a banknote’s denomination with the currency note. Those from outside India and those who are visually impaired frequently struggle to distinguish between different currency notes. Even though it might occasionally be challenging for Indians to recognize the same quantity of cash notes with new, distinct patterns are utilized, since the human eyes have some limitations as they occasionally fail to detect counterfeit currency. In this work, a detection model built using deep learning was evaluated against a variety of Indian currencies and with good accuracy. The developed mobile application for recognizing the currency note by using AutoML frameworks with CNN performs very well.
