## 7.3 Methodology for Chatbot Sentiment Analysis

The planned methodology for chatbot sentiment analysis involves three phases: subjectivity detection, trilateral modifier utilization, and chat-bot sentiment polarity detection. The first phase is subjectivity detection, which finds the subjective information from the user inquiry. The second phase searches for the presence of modifiers, if any, in the user inquiry, and the third phase aims at finding the actual sentiment expressed by the user on a fine-grained scale.

### 7.3.1 AutoML-Based Exploratory Data Analysis and Subjectivity Detection

AutoML can target various steps in machine learning, such as data preparation, feature engineering, model selection, hyperparameter optimization, etc. Among these stages of a machine learning process, in this chapter, we have applied AutoML in the form of AutoNLP for the data preparation stage. As the initial step, exploratory data analysis is carried out using AutoNLP, which is based on the concepts of AutoML. The text involved in the discussion between the user and the chatbot is subjected to pre-processing. In pre-processing, the text is converted to a suitable form that is ready for sentiment analysis. This involves case conversion (converting all upper case to lower case), removal of stop words (removing words that do not have any significant contribution in the analysis, such as “is”, “a”, etc.), tokenization (splitting the text into separate units or words), and stemming (bringing the words to their root forms; for example, words such as “walking” and “walked” are stemmed to the root form “walk”).

After carrying out these pre-processing tasks, the text is input to the subjectivity detection module, where the parts-of-speech (PoS) tagging technique is applied to tag each word of the text with its appropriate grammatical counterpart.
