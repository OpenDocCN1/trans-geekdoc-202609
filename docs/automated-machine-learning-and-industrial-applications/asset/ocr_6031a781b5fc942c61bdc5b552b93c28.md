# 6.3.2 AutoKeras

AutoKeras is dedicately focused on deep learning tasks distinguishing itself from systems that concentrate on the shallow models discussed earlier. The process known as neural architecture space (NAS) is applied to neural networks and entails identifying both the model architecture and the parameters that are utilized for model preparation. With AutoKeras you can perform AutoML for deep learning models using an open-source library. The TensorFlow tf.Keras API is used to conduct the search utilizing Keras models. It presents a simple and efficient strategy to automatically discover high-performing models across a diverse set of predictive tasks encompassing structure classification and regression dataset commonly referred to as tabular data.

It can select different parameters, like the number of layers, the number of neurons, and learning rate, along with other hyper-parameters such as optimization and loss functions.
