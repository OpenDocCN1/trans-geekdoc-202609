# 11.2.1 Scope

The proposed system can be extended toward coin detection and also for fake currency recognition. Second, implementation of this work will enable the detection of money automatically near toll plazas. This will reduce the waiting time of vehicles at the toll plazas. Stolen vehicles can also be identified with the help of the presence of an RFID tag in the vehicle. Third, because robots are increasingly being used in place of people in the workplace, it is important that all robots are able to distinguish between different currencies. Fourth, this system can be further implemented for foreign currencies like Dollars, Euros, Tanka, etc., i.e., the denomination of other countries other than India can be added and also compared between them.

# 11.2.2 Objectives

The main objectives of this application are as follows:

+   1. To recognize currency notes automatically by image processing with the help of mobile application.
+   2. To perform image processing on inserted image and match with a trained data set.
+   3. To develop an AutoML-driven deep learning that gives a faster and more accurate output when compared to the other techniques.
+   4. Finding clearly distinguishable components during feature extraction and then classifying the money to help in detection and identification is essential.
