A. Feature Selection: Feature selection involves choosing relevant features from a larger pool to enhance model performance, reduce complexity, and improve interpretability [39]. It minimizes noise, overfitting, and the dimensionality leading to better generalization and predictive capabilities. For large datasets, it also saves computing resources and training time. In AutoML, feature selection is automated using various algorithms like filter approaches, wrapper methods, and embedded methods [40]. AutoML's iterative procedure refines the feature subset to advance model performance, reducing overfitting and enhancing predictive power. The number of repetitions and stopping criteria depend on computational resources, time constraints, and desired model performance.

B. Feature Extraction: Feature extraction transforms raw data into expressive features for machine learning [41]. It reduces data dimensionality while preserving essential information improving model performance and computational efficiency. Techniques, like SIFT and HOG, are used for images, autoencoders, TF-IDF for text, and FFT and wavelet transform for signals [42]. AutoML platforms automate feature extraction using methods such as wavelet transforms and dimensionality-reduction algorithms (e.g., PCA, LDA) [43]. This automation identifies significant patterns, reduces redundancy, and enhances feature representation allowing users to focus on analyzing features and understanding data patterns.

# 5. Model Selection

Model selection is crucial in NAS and is divided into search space and architecture optimization.

A. Search Space: In AutoML, the search space aids to locate optimal architectures, minimize complexity, and boost search competence. It defines the possible architectures that can be represented. Common NAS search spaces include the following:

+   - Cell Based: Uses basic building blocks [44, 45].
+   - Entire Structured: Considers the whole network structure [46].
+   - Hierarchical: Organizes patterns across different levels [47, 48].
+   - Morphism Based: Focuses on transformations [49, 50].
