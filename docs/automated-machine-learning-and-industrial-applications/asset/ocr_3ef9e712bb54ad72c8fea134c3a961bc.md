Collectively, open-source AutoML tools have played a significant role in democratized machine learning by lowering entry barriers for users with diverse skill sets. They empower individuals with varying levels of expertise to leverage the potential of existing ones and eliminate the necessity for extensive domain knowledge. Some of the most used AutoML open source tools are the following [7]:

# Auto-Sklearn

For ML algorithms and data pre-processing, it is an extension of the Scikit-learn machine language package. It quickly determines the optimal model pipeline for the provided data-set by utilizing the Bayesian optimization search technique.

# AutoKeras

It is a Python library especially for AutoML, which is constructed on top of the popular deep learning frameworks Keras and Tensorflow. AutoKeras aims to simplify the machine learning model development process by automating the selection of neural architecture and hyper-parameters.

# Google Cloud

Despite being a part of a commercial cloud platform, it offers certain AutoML components as open source. This includes AutoML Tables and AutoML Vision Edge providing developers with the flexibility to tailor models for tabular and edge device-based ML tasks. This commitment to openness facilitates knowledge sharing and collaborative advancements within the developer community.

# TPOT

An open-source Python package created specifically for AutoML is called Tree-Based Pipeline Optimization Tool (TPOT). It takes a unique approach by utilizing genetic programming to optimize ML pipelines. Its flexibility and adaptability empower data scientists to explore a wide range of possibilities encouraging experimentation and iteration to find optimal solutions.

# H2O.ai

This is an automated platform designed to automate the process of creating and deploying ML models. It is particularly popular for its flexibility, scalability, and ease of use.
