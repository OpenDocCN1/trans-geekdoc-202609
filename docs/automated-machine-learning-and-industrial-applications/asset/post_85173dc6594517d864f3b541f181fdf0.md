## 10.4.3 The Diseased Leaf Identification

The chapter utilizes the diseased leaf dataset to train the E-ENet model for disease category identification in a simple background. This approach reduces the need for deep learning algorithms in hardware equipment by completing training quickly and performing disease identification in a straightforward environment. By utilizing the similarities between shallow networks across different learning objectives, the E-ENet algorithm makes it easier to adapt a shallow neural network from a source task to a target task. When it comes to convergences and final outcomes, E-ENet performs better than new learning in practice. It has two contents when the domain is set to D; feature space is represented by X, which holds all possible characteristic values. In the feature space, P(X) denotes a particular instance of feature sampling:

```
D_1 = X^i, P_1(X^i)
```

There are two parts to the task T_i; Y_i is a representation of the label space; it includes the vector space with all possible tags. The input data's features and labels are used as learning cues to derive the prediction function f(x).

T_1 = Y^i, f(X^i) (10.19)

Since 2012, the ImageNet dataset has employed more complicated designs leading to increased success. However, a significant number of these models exhibit low computational load. The E-ENet group comprises eight models denoted as B0 to B7 [72]. The E-ENet's architecture is focused on investigating smaller, more effective designs. Unlike other current state-of-the-art models, E-ENet systematically minimizes the depth, width, and resolution structure leading to improved performance results.

This investigation helps determine appropriate scaling parameters [72]. Compared to expansion layers, connections are integrated between bottlenecks with substantially fewer connections. The reason for this is that MBConv (MobileNetV2) blocks progressively widen and narrow channels. Compared to traditional layers, the deep separable convolutions in the design reduce computations by almost a factor of k_l, where k_l is the kernel size. The E-ENet algorithm's layout is shown in Figure 10.7. Equation 10.1 defines the compound coefficient μ, which is used to uniformly scale depth, width, and resolution in compound scaling.

The values for Depth D = a^u, width W = b^u, and Resolution R = c^u should be greater than 1. In the context of model scaling, the constants a, b, c are determined through grid search [72]. Commencing with Baseline EfficientNet-B0, the compound scaling method is applied in two steps:

- **Step 1:** Conducting a grid search with double the available resources, where μ = 1, optimal values for α_1, β_1, and γ_1 are identified.
- **Step 2:** The determined α_1, β_1, and γ_1 values are held constant, and the baseline network is scaled up to generate E-ENet-B1 to B7 using Equation 10.1 employing different μ values.
