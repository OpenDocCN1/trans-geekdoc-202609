# 2. Automated Data Preparation and Preprocessing

Data cleaning is a vital phase of data preparation and preprocessing to ensure data accuracy, consistency, and reliability. It involves techniques, like error detection, duplicate removal, normalization, and lost value imputation [17]. Traditional methods, such as Potter’s Wheel [18] and IntelliClean [19], require human skill and are time consuming. Automated tools, like Katara [20], Boost-Clean [21], and AlphaClean [22], streamline the process. Katara uses rule-based and machine-learning approaches, while Boost-Clean detects and repairs errors before model training. AlphaClean generates data-cleaning pipelines and learns from user feedback. Dynamic data cleaning is crucial for handling continuously generated data. Ilyas et al. [23] proposed a framework for continuous monitoring and cleaning, including a data quality model, executor, generator of cleaning plan, and feedback loop.
