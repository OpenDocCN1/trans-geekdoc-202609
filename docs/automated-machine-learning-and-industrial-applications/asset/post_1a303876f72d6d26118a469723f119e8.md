## Auto-Sklearn

Auto-Sklearn is an AutoML tool written in Python. The tool consists of 15 ML models, 14 feature preprocessing methods, and 4 data preprocessing methods. It selects the suitable algorithm and required hyperparameters to make the best model. The tool automatically solves classification, regression, and multi-label classification tasks. Auto-Sklearn has three major components: meta-learning, Bayesian optimization, and ensemble building. When a new dataset is supplied to the tool, it first extracts its meta-feature to discover the similar feature of the given input dataset with the available knowledge base depending on the meta-learning. The meta-learning process uses 140 pretrained datasets to identify the best combination of models and hyperparameters for a given dataset [3]. Meta-learning reduces the search space. Next, through Bayesian optimization [4], it identifies the best machine learning pipeline. Finally, the tool will choose the best ML workflow pipeline and will construct the ensemble model based on it. Auto-Sklearn works on the operating system Mac and Linux. It does not support Windows OS. It is easy to use if you are familiar with scikit-learn. It does not support GPU.

## TPOT (Tree-Based Pipeline Optimization Tool)

TPOT is an open-source tool developed using Python. TPOT routinely uses evolutionary algorithm [5] to design and improve the ML pipelines for a given problem [6, 7]. It is well suited for genetic problems. Various models and preprocessing techniques are utilized from the sklearn software. This tool uses tree-based algorithms [8] like Random Forest, XGBoost, or decision tree. Solutions based on tree-based algorithms are robust. This tool is good for unclean datasets or datasets with noise. It does not support GPU.

## AutoML-Docker

AutoML-Docker is an open-source tool developed at Kern. Classifiers based on only natural language can be created with the help of this tool. The tool accepts a data set as input, the entire text processing is automatic, and models are produced accurately. The CLI interface is used to create natural language classifiers. The tool provides full GPU support. Only text can be processed using this tool.

## AutoKeras

AutoKeras was developed by DATA lab. Google developed an API for applying neural networks. The tool is written in Python and can be operated both in the cloud and locally. This tool enables machine learning algorithms to be used by non-experts. It is used to create deep learning models [9] without requiring the user to define the architecture [10]. The main feature of AutoKeras is to automatically adjust the size of the neural architecture based on the available GPU memory size. It allows the user to define the layout of the layers and the number of neurons, as well as the characteristics of the hyperparameters [11, 12] such as optimization and loss functions. AutoKeras supports multiple backend neural network computation. It can be used for both classification and regression tasks.

## H2O

H2O AutoML algorithm was first released in H2O 3.12.0.1 on June 6, 2017 by Erin LeDell. This allows the tool to process large datasets efficiently. Simple data processing tasks can be done using this tool. The tool automatically trains large selections of models; it can tune the hyperparameters [13] of the models automatically and can also create one-layer stacked ensembled models using the bagging technique [14]. Individual models can be used with the cross-validation technique. This tool has been used in Kaggle forecast competitions [15].

## Light AutoML

Light AutoML is an open-source tool written in Python. It was developed and released by the automated ML team members at Sber AI Lab for a finance company in Europe to provide AutoML solutions [1]. The tool can handle tabular and text data efficiently. Using tabular data, it can solve binary or multiclass classification and regression. Pipeline creation can be easily done with Light AutoML. The tool will automatically handle data pre-processing, feature selection, optimal and speedy hyper parameter tuning, and time utilization. It will also generate automatic reports. The tool allows users to create their own pipelines using a modular scheme [16].

## MLBox

MLBox is an open-source tool for AutoML workflow [17]. It efficiently pre-processes data, selects features efficiently [18], and also effectively selects the model. It can solve a wide range of AI problems like regression, classification, and time-series forecasting. This tool also automatically tunes the hyper-parameters and enhances the performance of ML models. The significant features of the tool include cleaning and preprocessing datasets such as handling missing values, encoding definite variables, and normalizing numeric features. It automatically selects applicable features of the dataset and produces new columns based on data. It selects the best model automatically, tunes the hyper-parameters, and increases the performance of the model [19]. The tool allows the customer to create their own pipeline based on their requirements. This ML tool can be easily integrated with other ML libraries like scikit-learn and XGBoost.

## Pycaret

Pycaret is a free tool available for performing AutoML tasks [20]. It is an efficient tool for machine learning models covering everything from data preprocessing to hyperparameter tuning. The model is easily accessible to beginners as well as experts in machine learning. Due to modular design of Pycaret, it can be easily integrated with available ML pipelines. Various classification, regression and clustering ML algorithms can be solved using Pycaret [21]. The advantages of Pycaret include the requirement of fewer number of lines of code to build and deploy the model, non-programmers can easily use the tool, and the availability of documents with tutorials and projects.

## MLJAR

MLJAR is an open-source AutoML tool designed to provide optimized models for many real-time problems. It works only on tabular data. The tool pre-processes input tabular data, builds ML models, and also tunes the hyper-parameters automatically to find the finest model among all other models. The tool can work in four modes like Explain, Compete, Perform, and Optuna [22] depending on user necessities and accessible resources. The Explain mode will analyze the data and try to extract the important features in the dataset. It does use hyperparameter tuning. The Compete mode will automatically extract the new features from the available features and optimize the model automatically to increase the accuracy of the model. The Perform mode selects the best ML pipeline based on the prediction time. The Perform mode applies the cross-validation technique to produce an active and good model. The optimization technique combines random search with hill climbing to balance exploration and exploitation [23]. The Optuna mode develops an optimized model by tuning the hyper-parameters from the available variants of the model. The computational time can be longer for the optimized model. Finally, the tool can generate a markdown report from the analysis for all the models available in the MLJAR tool.

## Application of AutoML and XAI

## (AutoML-XAI) for Metabolomics: Improving Cancer Diagnostics

This involves a singular pathway for improving metabolomics study by fusing explainable AI (XAI) methods with AutoML [24]. They have considered two sets of data: serum metabolomics from ovarian cancer (OC) and urine metabolomics from renal cell carcinoma (RCC). Using Auto-Sklearn, AutoML was able to distinguish patients with OC and other gynecological cancers, as well as RCC and healthy controls, better than independent machine learning approaches.

## Predicting Pretreatment Methods on Methane Production From Sludge Anaerobic Digestion

For effective treatment of sludge and resource recovery, accurate methane production prediction in anaerobic digestion using different pretreatment procedures is crucial [25]. An innovative integrated system was applied to investigate the impacts of various preparatory procedures on methane production during sludge digestion using explainable analysis. The system used an ensemble Semi Supervised Learning (SSL)-automated machine learning (AutoML) model with partial variable inputs.

## Predicting Human Intestinal Absorption of Compounds With Serotonergic Activity

The pharmaceutical field's largest segment consists of oral medications. As the primary site of absorption for orally administered active pharmaceutical ingredients (APIs), the intestinal walls must be penetrated by a medicine to produce a therapeutic effect [26]. They have used both regression and classification prediction pathways and an AI-based method to predict HIA.
