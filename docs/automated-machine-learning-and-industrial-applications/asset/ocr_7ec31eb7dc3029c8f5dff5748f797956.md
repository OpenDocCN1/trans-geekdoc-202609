# AutoGluon

AutoGluon is an open-source tool that is used in the area of automated machine learning. It focuses on automated stack ensemble ML model, deep learning, and real-world applications. This open-source software can handle text dataset, image dataset, and also tabular data. It was developed by Amazon Web Services. This tool provides a high-level interface. The tool will train the data, then deploy the model.

# Strengths of AutoGluon

+   **User Friendly:** It provides an interface that could train a model using a single line of code, when all the default settings are done for the basic procedure.

+   **Highly Automated:** AutoGluon automates all the steps of ML, like data pre-processing, feature selection, hyper parameter tuning, and the design of artificial neural networks (ANN) [2]. It also provides information about the kind of data inferred, and it also deploys the model.

+   **Lots of Control:** The AutoGluon permits the user to configure many characteristics of the machine learning steps, such as data interpretation, feature extraction from the data set, model selection, choice of performance metrics, and consideration of hyper parameters. This is very useful for experts who use the ML models.
