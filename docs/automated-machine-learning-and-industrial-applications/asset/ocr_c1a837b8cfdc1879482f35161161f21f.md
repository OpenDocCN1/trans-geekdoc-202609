A linear superposition of Gaussians is utilized to represent a Gaussian mixture distribution in the form:

```
p(x) = \sum_{k=1}^K \pi_k p(x | \mu_k, \xi_k)
\hat{\pi}_c = \frac{n_c}{n},
\hat{\mu}_c = \frac{1}{n_c} \sum_{\{i | y_i = c\}} \mathbf{x}_i
\hat{\Sigma}_c = \frac{1}{(n_c - 1)} \sum_{\{i | y_i = c\}} (\mathbf{x}_i - \mu_c)(\mathbf{x}_i - \mu_c)^t
```

Given a specific value of z, conditional distribution of x is now a Gaussian:

```
p(x | z_k = 1) = p(x | \mu_k, \Sigma_k)
p(x | z) = \Pi_{k=1}^K p(x | \mu_k, \Sigma_k)^{z_k}
```

The marginal distribution of x is attained by summing the joint distribution of all potential states of z.

```
p(x) = \sum_z p(z) p(x | z) = \sum_{k=1}^K \pi_k p(x | \mu_k, \Sigma_k)
```

A significant derived quantity is “posterior probability” on a mixture component for a specific data vector [11]:

```
\gamma(z_k) \equiv p(z_k = 1 | x) = \frac{p(z_k = 1)p(x | z_k = 1)}{\sum_{j=1}^K p(z_j = 1)p(x | z_j = 1)} = \frac{\pi_k p(x | \mu_k, \Sigma_k)}{\sum_{j=1}^K \pi_j p(x | \mu_j, \Sigma_j)}
```

The output layer (y) then uses the input (h, latent space), \(x^{[\alpha]} \in \mathcal{R}^d\) and the hidden layer to recreate the input \(x^{[\alpha]}\). We all use the same superscript notation, *[ [\alpha] ], to refer to all of the individual parameters connected to the AE network using Equation 8.9.
