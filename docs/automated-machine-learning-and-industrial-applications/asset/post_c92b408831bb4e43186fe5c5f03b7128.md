## 2. Automated Data Preparation and Preprocessing

Data cleaning is a vital phase of data preparation and preprocessing to ensure data accuracy, consistency, and reliability. It involves techniques, like error detection, duplicate removal, normalization, and missing value imputation [17]. Traditional methods, such as Potter’s Wheel [18] and IntelliClean [19], require human skill and are time consuming. Automated tools, like Katara [20], Boost-Clean [21], and AlphaClean [22], streamline the process. Katara uses rule-based and machine-learning approaches, while Boost-Clean detects and repairs errors before model training. AlphaClean generates data-cleaning pipelines and learns from user feedback. Dynamic data cleaning is crucial for handling continuously generated data. Ilyas et al. [23] proposed a framework for continuous monitoring and cleaning, including a data quality model, executor, generator of cleaning plan, and feedback loop.

## 3. Automated Data Augmentation

Data augmentation (DA) enhances model performance, especially with limited datasets, by increasing training data size and improving generalization. DA techniques apply to images [24], text [25], audio [26], and tabular data [27]. Figure 14.2 describes the data augmentation process applied to different data types.

### A. Image Data

Different data augmentation (DA) techniques, including object identification, image classification, and visual tracking can be used for image data. The following are some most common methodologies:

- Affine Transformations: Scaling, rotation, translation, and cropping.
- Elastic Transformations: Brightness, contrast, channel shifting, and blurring.
- Innovative Transformations: Random erasing, blending the images, cutout [28], mixup [29], and cutmix [30].

### B. Text Data

Techniques for augmenting textual data can improve training data and increase the diversity of text available. The following are a few most common strategies:

- Replacement of Synonyms: Replacing words with synonyms.
- Random Method of Insertion: Adding words randomly.
- Random Deletion: Removing words randomly.
- Back Translation: Translating text to another language and back.
- Random Swap: Shuffling word positions.
- OCR Noise: Introducing OCR-like errors [31].

### C. Audio Data

We can avoid overfitting and improve the model’s capacity to simplify unknown audio data by generating additional instances through transformations. Some of those techniques are as follows:

- Noise Injection: Adding Gaussian or random noise to the audio.
- Shifting: Shifting the audio left or right by random amounts.
- Speed Tuning: Changing the speed of the audio.
- Pitch Shifting: Randomly changing the pitch of the audio.
- Time Stretching: Stretching or compressing the audio duration.

### D. Tabular Data

Techniques of data augmentation for tabular data are not the same as those for text or image augmentation. By enhancing the variety of training data, these approaches and technologies seek to advance model performance, which ultimately results in improved generalization. Some commonly used steps are as follows:

- Noise Addition: Adding random noise to numerical features.
- Data Shifting: Slightly shifting values of numerical features.
- SMOTE: Generating synthetic samples for minority classes [32].
- Random Missing Values: Introducing and then imputing missing values.
- Feature Mixing: Combining features from different rows to create new synthetic rows.
- Autoencoders: Using Denoising Autoencoders (DAE) [33] to reconstruct data with added noise.
- Data Synthesis: Generating new data points using models like GANs [34].

Automated tools like Katara, Boost-Clean, and AlphaClean streamline DA. AutoAugment uses reinforcement learning to automate DA policy search but is resource intensive.

## 4. Automated Feature Engineering

Feature engineering is a vital phase in the ML pipeline altering raw data into a plan appropriate for algorithms. It includes creating new features, selecting relevant ones, and modifying existing features to enhance model performance [35]. AutoML platforms automate this process exploring various feature engineering strategies [36] and optimizing the feature space. To identify the best-performing model, they experiment with various algorithmic combinations, feature engineering strategies, and preprocessing procedures, utilizing Bayesian optimization [37, 38] or evolutionary algorithms.

### A. Feature Selection

Feature selection involves choosing relevant features from a larger pool to enhance model performance, reduce complexity, and improve interpretability [39]. It minimizes noise, overfitting, and the dimensionality leading to better generalization and predictive capabilities. For large datasets, it also saves computing resources and training time. In AutoML, feature selection is automated using various algorithms like filter approaches, wrapper methods, and embedded methods [40]. AutoML's iterative procedure refines the feature subset to advance model performance, reducing overfitting and enhancing predictive power. The number of repetitions and stopping criteria depend on computational resources, time constraints, and desired model performance.

### B. Feature Extraction

Feature extraction transforms raw data into expressive features for machine learning [41]. It reduces data dimensionality while preserving essential information improving model performance and computational efficiency. Techniques, like SIFT and HOG, are used for images, autoencoders, TF-IDF for text, and FFT and wavelet transform for signals [42]. AutoML platforms automate feature extraction using methods such as wavelet transforms and dimensionality-reduction algorithms (e.g., PCA, LDA) [43]. This automation identifies significant patterns, reduces redundancy, and enhances feature representation allowing users to focus on analyzing features and understanding data patterns.

## 5. Model Selection

Model selection is crucial in NAS and is divided into search space and architecture optimization.

### A. Search Space

In AutoML, the search space aids to locate optimal architectures, minimize complexity, and boost search competence. It defines the possible architectures that can be represented. Common NAS search spaces include the following:

- Cell Based: Uses basic building blocks [44, 45].
- Entire Structured: Considers the whole network structure [46].
- Hierarchical: Organizes patterns across different levels [47, 48].
- Morphism Based: Focuses on transformations [49, 50].
