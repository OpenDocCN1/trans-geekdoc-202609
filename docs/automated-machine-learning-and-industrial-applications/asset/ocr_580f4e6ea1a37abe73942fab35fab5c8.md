# 7.1.8 Levels of Sentiment Analysis

Actually, sentiment analysis can be completed at three different levels: document level, sentence level, and aspect level [25, 26]. When sentiment analysis is performed at the document level, it brings out the overall opinion of the entire text [28, 29]. This approach does not consider what people prefer or dislike regarding the features of an entity (product or service). Of course, it provides only a coarser level of analysis. When sentiment analysis is carried out at the sentence level, the sentences present in the user text are classified as subjective and objective from which only subjective sentences are chosen for analysis [30]. The reason is that subjective sentences contain some sort of opinion expressed about a feature. So, in the sentence-level approach, the opinion present in every subjective sentence is determined, which is somewhat better than document-level analysis. But if a still more fine-grained level of analysis is required, we move on to aspect-level analysis, where the opinion associated with each feature is determined providing a more accurate form of sentiment analysis [17, 27].

Consider the following sample review about an iPhone:

> I bought an iPhone yesterday. It has a sleek and modern design, strong performance, and a fantastic camera. It is expensive.

At the document-level sentiment analysis, even though a negative opinion is expressed over the price of an iPhone, according to this approach, the overall opinion will be concluded to be positive, as the majority of the opinions expressed in the above review are positive.
