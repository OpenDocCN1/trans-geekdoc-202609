# 6.1.3 Machine Learning Pipeline (ML)

A machine learning (ML) pipeline is a series consisting of data preparation and modeling steps designed to transform raw data into a trained and deployable ML model. The pipeline organizes and automates the workflow making it easier to manage, reproduce, and iterate throughout the entire process. The typical steps include data preparation and cleaning, feature engineering, model selection, training, parameter tuning, evaluation, and deployment.
