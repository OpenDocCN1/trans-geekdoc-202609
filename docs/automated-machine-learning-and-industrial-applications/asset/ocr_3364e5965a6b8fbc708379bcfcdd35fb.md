# 6.3 Methodology

The primitive intention of this research work was to evolve an AutoML system for opinion mining aiming to enhance Customer Relationship Management. Additionally, the study involves evaluating both the AutoML approach and conventional code-based machine learning techniques. In the initial phase, the emphasis was on implementing the process, which included eliminating null values and special characters during pre-processing.

For the AutoML model, the AutoKeras package was utilized to generate the model through neural architecture search and hyper-parameter tuning. Following multiple trials, the best model was identified and exported. This model was then deployed on another customer review dataset. To facilitate a comparative analysis with AutoML, traditional ML models were also created using fundamental ML pipeline steps. The entire research work shown in Figure 6.5 was implemented using Python code within a Jupyter Notebook environment.
