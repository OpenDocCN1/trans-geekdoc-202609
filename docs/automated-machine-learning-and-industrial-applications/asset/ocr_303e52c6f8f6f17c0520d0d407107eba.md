# 3. Neural Architecture Search (NAS)

The most complicated and time-consuming method of deep learning is in structuring the neural architecture. Data science officials invest reasonable time in choosing appropriate sections and learning rates by mostly focusing on weights in models, especially proven in language models. Neural Architecture Search (NAS), stated as “making use of neural nets for designing neural nets,” reaches out as a major candidate for automation in the arena of machine learning.

NAS explores by finding architectures to learn, with the result determined by the metric against which every architecture is measured. Many algorithms can be used in a neural architecture group [19]. For example, if the required number of architectures is less, random options for testing can be done. Gradient-based approaches, transforming the discrete search space into a continuous illustration, have proven very effective. Alternatively, data science officials may practice with traditional algorithms, where architectures are measured and changes are slowly applied, developing more successful child architectures while reducing unsuccessful ones.

While neural architecture searches are a significant component of AutoML, using the democratization of AI, they frequently come with a considerable carbon footprint. An examination of these compromises is still pending, and an ongoing study in NAS methods is exploring optimization for environmental costs.
