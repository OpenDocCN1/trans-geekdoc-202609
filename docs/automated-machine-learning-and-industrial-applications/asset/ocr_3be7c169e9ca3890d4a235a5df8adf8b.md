commercial innovations, the real-world application of AutoML is expected to grow significantly. Our survey aims to foster this development, provided that newcomers to AutoML have access to a comprehensive overview. Without careful implementation, automation can have negative consequences. Therefore, there is a strong need for thoughtful design and deployment of AutoML systems to address these concerns. Modern frameworks allow domain specialists to create effective ML pipelines without needing extensive knowledge of ML or statistics.
