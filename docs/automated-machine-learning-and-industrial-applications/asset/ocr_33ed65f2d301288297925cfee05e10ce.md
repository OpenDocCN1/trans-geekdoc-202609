# AutoKeras

AutoKeras was developed by DATA lab. Google developed an API for applying neural networks. The tool is written in Python and can be operated both in the cloud and locally. This tool enables machine learning algorithms to be used by non-experts. It is used to create deep learning models [9] without requiring the user to define the architecture [10]. The main feature of AutoKeras is to automatically adjust the size of the neural architecture based on the available GPU memory size. It allows the user to define the layout of the layers and the number of neurons, as well as the characteristics of the hyperparameters [11, 12] such as optimization and loss functions. AutoKeras supports multiple backend neural network computation. It can be used for both classification and regression tasks.

# H2O

H2O AutoML algorithm was first released in H2O 3.12.0.1 on June 6, 2017 by Erin LeDell. This allows the tool to process large datasets efficiently. Simple data processing tasks can be done using this tool The tool automatically trains large selections of models; it can tune the hyperparameters [13] of the models automatically and can also create one-layer stacked ensembled models using the bagging technique [14]. Individual models can be used with the cross-validation technique. This tool has been used in Kaggle forecast competitions [15].

# Light AutoML

Light AutoML is an open-source tool written in Python. It was developed and released by the automated ML team members at Sber AI Lab for a finance company in Europe to provide AutoML solutions [1]. The tool can handle tabular and text data efficiently. Using tabular data, it can solve binary or multiclass classification and regression. Pipeline creation can be easily done with Light AutoML. The tool will automatically handle data pre-processing, feature selection, optimal and speedy hyper parameter tuning, and time utilization. It will also generate automatic reports. The tool allows users to create their own pipelines using a modular scheme [16].
