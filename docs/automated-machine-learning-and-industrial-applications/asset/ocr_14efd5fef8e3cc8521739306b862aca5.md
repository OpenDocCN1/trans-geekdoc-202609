# MLBox

MLBox is an open-source tool for AutoML workflow [17]. It efficiently pre-processes data, selects features efficiently [18], and also effectively selects the model. It can solve a wide range of AI problems like regression, classification, and time-series forecasting. This tools also automatically tunes the hyper-parameters and enhances the performance of ML models. The significant features of the tool include cleaning and preprocessing datasets such as handling missing values, encoding definite variables, and normalizing numeric features. It automatically selects applicable features of the dataset and produces new columns based on data. It selects the best model automatically, tunes the hyper-parameters, and increases the performance of the model [19]. The tool allows the customer to create their own pipeline based on their requirements. This ML tool can be easily integrated with other ML libraries like scikit-learn and XGBoost.

# Pycaret

Pycaret is a free tool available for performing AutoML tasks [20]. It is an efficient tool for machine learning models covering everything from data preprocessing to hyperparameter tuning. The model is easily accessible to beginners as well as experts in machine learning. Due to modular design of Pycaret, it can be easily integrated with available ML pipelines. Various classification, regression and clustering ML algorithms can be solved using Pycaret [21]. The advantages of Pycaret include the requirement of fewer number of lines of code to build and deploy the model, non-programmers can easily use the tool, and the availability of documents with tutorials and projects.

# MLJAR

MLJAR is an open-source AutoML tool designed to provide optimized models for many real-time problems. It works only on tabular data. The tool pre-processes input tabular data, builds ML models, and also tunes the hyper-parameters automatically to find the finest model among all other models. The tool can work in four modes like Explain, Compete, Perform, and Optuna [22] depending on user necessities and accessible resources.
