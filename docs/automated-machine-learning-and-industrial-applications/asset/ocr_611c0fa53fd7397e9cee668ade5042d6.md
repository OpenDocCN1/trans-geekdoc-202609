# 10.3.2.4 Inception V3

The third repetition in Google's DL Evolutionary Systems series is known as Inception V3 [71]. Following Szegedy's creation of the Inception V1 design, in Inception V2, batch normalization was introduced. Subsequently, Inception V3 implemented factorization. The primary objective of factorization is to minimize the number of parameters and connections without compromising the network's efficiency. The algorithm incorporates fully connected layers, convolutions, max pooling, average pooling, dropouts, concatenations, as well as symmetrical and asymmetrical building blocks (refer to Figure 10.5). The 42-layer Inception V3 architecture includes an input layer that can handle images up to 299 × 299 pixels in resolution. The Softmax function is incorporated into the last coat of the architecture.
