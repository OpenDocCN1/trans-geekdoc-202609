## 9.3 Ecosystem of AutoML

### 9.3.1 Data Preprocessing

Preparing raw data for model training requires a number of processes including data cleaning, feature engineering, and normalization, all of which are vital.

### 9.3.2 Model Selection

Both the properties of the dataset and the nature of the problem at hand are considered by AutoML algorithms, which then choose the machine learning model architecture or method that is the most suitable.

### 9.3.3 Hyperparameter Tuning

Hyperparameters refer to the central parameters that constitute the set up and performance of machine learning models [8]. AutoML tools practice machine learning to autonomously change hyperparameters to increase the functioning of the model.

### 9.3.4 Model Evaluation and Deployment

AutoML frameworks naturally provide procedures for evaluating the performance of a model after it has been completed and, additionally, provisions for arranging the model into production environments.

## 9.4 AutoML Frameworks

### 9.4.1 Google AutoML

Google AutoML is a group of tools that are made accessible by Google Cloud. These tools permit users to build machine learning models with minimal human interaction. AutoML Vision, AutoML Natural Language, and AutoML Tables are among the mechanisms encompassed under this framework catering to diverse types of data. Google AutoML leverages composite neural architecture search techniques to automatically optimize models. Its main characteristics are as follows:

- Classification of images and text
- Integration with Google Cloud Platform
- Tuning of the custom model

### 9.4.2 IBM Watson AutoAI

By automating processes, such as data preparation, feature engineering, and model selection, IBM Watson AutoAI contributes to automating the machine learning pipeline. The platform provides users with a collaborative setting through which they are able to construct, train, and then deploy machine learning models. Its notable characteristics are as follows:

- Automated model selection and hyperparameter tuning
- Collaboration and sharing capabilities
- Integration with IBM Watson Studio

### 9.4.3 Microsoft Azure AutoML

Azure AutoML is a significant part of the Microsoft Azure cloud ecosystem providing an easy-to-use interface for the design and development of machine learning models. Both classification and regression tasks are accommodated by this platform, which additionally offers automatic feature selection and hyperparameter tuning capabilities. Its prominent characteristics are as follows:

- Incorporation with Azure Machine Learning Studio
- Computerized model selection and tuning
- Extensive range of algorithms

### 9.4.4 H2O.ai

H2O.ai provides an open-source AutoML platform that is extensively used and is as well known as H2O AutoML. The software provides automated model selection, optimization of hyperparameters, and valuable insights into the interpretability of the model. The versatility of H2O AutoML allows its application in a wide range of applications, surrounding classification, and regression. Its notable characteristics are as follows:

- Open-source platform
- Automatic feature engineering
- Interpretability and explainability tools

### 9.4.5 DataRobot

DataRobot is a comprehensive AutoML platform that accelerates the machine learning process. The system accelerates the complete machine learning process starting from data preprocessing and ending with model deployment. Several kinds of strategies and optimization techniques are provided by DataRobot. Its prominent characteristics are as follows:

- Automated model building and selection
- Extensive algorithm library
- Model deployment options

### 9.4.6 Databricks AutoML

Majority of the key elements of the Databricks Unified Analytics Platform is Databricks AutoML, which streamlines the machine learning procedure by providing autonomous model tuning and selection capabilities. The computer program smoothly connects with several Databricks services resulting in a cohesive data and artificial intelligence platform.

Key Features:

- Integration with Databricks Workspace
- Distributed computing for model training
- Collaboration and sharing features

### 9.4.7 Tune

The open-source AutoML library Tune is dedicated to the optimization and customization of hyperparameters. The tool facilitates the customization of machine learning models enabling users to develop search areas as well as develop search algorithms. Its significant features are the following:

- Customizable hyperparameter search
- Scalable and distributed tuning
- Support for various machine learning libraries

### 9.4.8 AutoKeras

In the realm of deep learning models, the AutoKeras library is an open-source AutoML package that focuses on neural architecture search. The computer program facilitates the automation of neural network creation and optimization procedures. Its major traits are the following:

- Simplified deep learning model development
- Customizable search spaces
- TensorFlow and Keras integration

### 9.4.9 H2O Driverless AI

The powerful AutoML platform known as H2O Driverless AI is capable of automating machine learning activities and interpreting the output of models. Moreover, it provides explainability, model selection, and autonomous feature engineering. Its especially notable features are the following:

- Automatic feature engineering
- Interpretability and explainability tools
- Enterprise-grade platform

### 9.4.10 RapidMiner

For the purpose of constructing, deploying, and administering machine learning models, RapidMiner provides a user-friendly AutoML platform. The computer program provides automated capabilities including collecting data and simulation. Its prominent attributes are the following:

- Visual and code-based interface
- Extensive library of machine learning algorithms
- Model deployment and monitoring

### 9.4.11 Google Cloud AutoML Tables

Google Cloud AutoML Tables is a dedicated AutoML solution designed specifically for the processing of structured data. Automation is employed to facilitate the creation of predictive models for various tasks, such as regression and classification. Its important characteristics are as follows:

- Support for structured data
