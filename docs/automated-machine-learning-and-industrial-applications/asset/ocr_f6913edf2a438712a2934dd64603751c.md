Each entry in this dataset represents a client’s credit and credit card status every month. The credit registry database was approximately 1 TB, but we utilized a subset of this dataset with 1,000,000 rows for the study. These rows represent the status of 1,000,000 distinct loans for private clients only and their status on the scheduled completion date of the loan payment. The dataset does not have a characteristic indicating whether the client can reimburse the credit risky or not.
