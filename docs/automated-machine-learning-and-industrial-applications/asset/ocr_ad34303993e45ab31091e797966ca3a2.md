The encryption phase for the cover image consists of two steps. First, the cover image is separated into three 3 × 3 pieces that are non-overlapping. The blocks are then all reordered utilizing random sequence created by Key-I, which has a length equal to the total number of blocks in the image. Following block permutation, Key-II is used to create a secret stream. Then, every block of a picture is encrypted using Equation 2.26:

\( C = E(P, K) = K \oplus P \) (2.26)

Encryption function E() is an Exclusive-OR operation marked by “⊕.” Each block contains a unique 8-bit code segment, sequentially encrypted for every block. Since each block’s pixels are encrypted utilizing the same code segment, correlation between them is maintained.
