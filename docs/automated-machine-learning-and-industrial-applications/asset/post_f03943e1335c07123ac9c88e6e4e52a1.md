
For large datasets, hierarchical search spaces often perform better. Hierarchical genetic representation systems use modular designs to create complex topologies. They start with a flat architecture and build hierarchical structures with multiple levels.

Hierarchical Neural Architecture Search (HNAS) includes cell- and network-level search spaces. It uses normal cells to manage model capacity and up-sampling cells to enhance resolution. Mobile NAS (MNAS) [51] introduces a factorized hierarchy for CNN models independently searching processes and connections within each group. Global Local Image Transformer (GLiT) optimizes the supply of global and local sub-modules within each block [52].

### B. Architecture Optimization

Architecture optimization in deep learning includes selecting the best neural network architecture for a precise dataset [53]. This process requires modifying features like learning rate and weights to improve precision and reduce loss [54]. Common optimization algorithms include the following:

- a) Evolutionary Algorithm: Evolutionary Algorithms (EA) mimic natural selection using reproduction, mutation, recombination, and selection. It optimizes solutions starting with random solutions and evaluates them using a fitness function [55]. Genetic Algorithms (GA), a type of EA, use a population of solutions and three main operators: selection (based on fitness), mutation (random changes), and crossover (exchanging segments) [56]. Key parameters, like neuron count and learning rate, must be carefully set [57].

- b) Reinforcement Learning: Reinforcement learning (RL) is an ML field where an agent acquires and adapts through interactions in an unfamiliar situation [58]. The agent obtains rewards or penalties based on its actions guiding its learning in a trial-and-error manner. In RL, the agent perceives the situation, selects actions, and receives feedback. The main components are reward, action, and state. The agent's aim is to learn an action strategy that exploits the reward, represented by the following equation:

$$\Sigma_{i=0}^{\infty} \gamma^i Q_{t+i}, (0 < \gamma \le 1)$$ (14.1)

In Equation 14.1 γ, the discount factor and output action Q represent the expected reward of taking a certain action at a time (t + i) and following the optimal policy afterward. The key steps in the RL pipeline include specifying the reward function, selecting observations, and tuning hyperparameters. Automating RL involves updating hyperparameters and functions based on feedback from the environment [59].

- c) Bayesian Optimization: Bayesian optimization (BO) addresses optimization challenges like high dimensionality. It provisions point-wise evaluations without function derivatives making it a black-box method [60]. BO does not require prior information; it starts with a randomized population and selects promising candidates to construct a Bayesian network. New candidates are generated using joint distribution encoding and added to the population.

- BO uses the following two main approaches:
  - Gaussian Process (GP): Models uncertainty and forecast mean for any input point [61].
  - Acquisition Function (AF): Determines the next best point to evaluate based on GP’s uncertainty and mean [62].

- d) Gradient-Based Optimization: This method adjusts parameters by moving in the direction of the gradient. The step size is determined by the learning rate.

Gradient Descent: Minimizes an objective function by moving in the direction of the negative gradient. It starts with an initial guess and iteratively finds a local minimum [63].

Gradient Ascent: Maximizes a function by going in the direction of the positive gradient [64]. It iteratively finds a local maximum.
Gradient Min–Max: Solves min–max problems by alternating between gradient ascent and descent steps to get the minimum and maximum values of a function [65].
Automating these approaches with AutoML involves tuning hyperparameters to decrease training iterations and improve efficiency.

- A. Weight Sharing: This method reduces computational costs by allocating parameters among dissimilar models. For example, FairNAS [67] and Single-Path NAS [68] use weight sharing to cut exploration costs significantly.

## 14.3 AutoML Components

AutoML approaches can also be categorized into three main components as follows:

### 1. Search Space

The search space in machine learning describes all design choices, including learning algorithms and their hyperparameters. Hyperparameters can be categorical (e.g., kernel types for SVMs) or numerical (e.g., learning rates). The combined procedure selection and hyperparameter (CASH) problem treats algorithm choice as a hyperparameter and is tackled using hyperparameter optimization (HPO) techniques.

Categorical Hyperparameters: These take discrete values without any inherent order, like different kernel types in SVMs [70].

Numerical Hyperparameters: These are defined over a numeric range, such as learning rates or kernel widths [71].

Conditional Hyperparameters: Some hyperparameters depend on others. For example, kernel width is relevant only for kernels.

Hyperparameter optimization techniques handle these differently. For instance, log transformation can be applied to numerical hyperparameters to emphasize smaller values. Techniques, like weight sharing reduce computational costs, while early stopping prevents overfitting by halting training when performance plateaus [72].

### 2. Search Strategy

In AutoML, search strategy or algorithm refers to exploring the search space to find the best machine learning models and hyperparameters. The following are some common search strategies: i) Grid Search, ii) Random Search, iii) Bayesian Optimization, iv) Evolutionary Algorithms, v) Reinforcement Learning, and vi) Gradient-Based Optimization [73].

These strategies aim to automate and optimize the procedure of selecting and tuning machine learning models making high-performance models more reachable.

### 3. Performance Evaluation

In AutoML, performance evaluation refers to the procedures used to assess the efficiency of the models generated during the automated machine learning process. This step is vital for determining which models attain best on a given dataset. The following are the key features of performance evaluation in AutoML:

Evaluation Metrics: Metrics, such as accuracy, F1 score, precision, recall [74], and area under the ROC curve (AUC), are typically used to evaluate classification models. For regression models, metrics, like mean absolute error (MAE), mean squared error (MSE), and R-squared, are used.

Cross-Validation: This technique includes splitting the dataset into numerous folds and training the model on diverse subsets while validating on the remaining data. It guarantees that the model works consistently across various data splits.

Holdout Validation: A part of the dataset is set aside as a validation set, and the model is trained on the remaining data. The performance of the validation set is meant to assess the model [75].

Learning Curves: These plots uncover problems, such as overfitting or underfitting, by displaying the model's progress over time on the training and validation sets [76].

Hyperparameter Tuning: Finding the best model settings involves evaluating several hyperparameter setups via performance evaluation.

Model Comparison: AutoML systems often generate multiple models, and performance evaluation helps compare these representations to select the best one.
