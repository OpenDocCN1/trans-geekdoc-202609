# ## Abstract

The current paradigm of artificial intelligence (AI) is centered on developing algorithms that acquire extraordinary outcomes by learning directly from data, particularly in supervised deep learning. This has streamlined the machine learning systems by systematizing much of the learning process. In many different areas of our everyday life, machine learning (ML) is essential. However, developing effective ML applications typically requires skilled data scientists and subject matter specialists. Using automated machine learning (AutoML), domain experts may develop machine learning features without requiring extensive statistics or machine learning training. The area of AutoML is expanding quickly, with the goal of automating machine learning model development. By reducing tedious steps in the machine learning process—from selecting and fine-tuning algorithms to preparing data—it seeks to increase efficiency and productivity. This article outlines a review of AutoML methods and provides detailed explanations. It provides an indication of AutoML’s history and current state of this revolutionary technology. It starts by outlining the notion of AutoML, outlining the fundamental stages of every machine learning method, specifying the issues it aims to solve, and outlining the three main mechanisms of AutoML techniques. AutoML’s versatility and ongoing development applications and future scopes are also highlighted here. Overall, this comprehensive overview serves as an invaluable tool for machine learning scholars and practitioners, laying the groundwork for future advancements in AutoML.
