# 6.3.2.1 Neural Architecture Search and Hyper-Parameter Tuning

Automating architectural engineering is a next-level logical progression from automated machine learning, which lowers the complexity of manually constructed neural architecture. Since it has a lot in common with feature engineering, minimization of hyper-parameter, and Meta learning, NAS is regarded as a subset of AutoML. This means NAS can be divided into three aspects: scope of search, searching methodology, and techniques for performance computation [42–44].

The search space delineates the architecture that can theoretically be represented. It is possible to streamline the exploration process and reduce the search space by incorporating past knowledge about typical architectural characteristics suitable for a task. Nevertheless, this approach adds a weighted value physically. This might preempt the discovery of unique architecture components for progress entirely up to human cognition. AutoKeras uses Bayesian Optimization, Random search, Grid search, and hyper band tuner toward the direction of search for the neural structure framework. Additionally, it makes use of a tree-structured acquisition function for minimization and a neural network kernel to efficiently assess the search space. Let us consider NAS space to be S, the input as X is partitioned into X_train and X_val, and the cost function is Cf(). To determine the best neural network P ∈ S that could minimize the cost on dataset d, finding the optimal neural network should satisfy the following equation [4]:

```
P = \underset{\theta}{argmin} Cost(P(\theta^*), X_{val}) \quad (6.1)
```

```
\theta^* = \underset{\theta}{argmin} Cf(P(\theta), X_{train}) \quad (6.2)
```
