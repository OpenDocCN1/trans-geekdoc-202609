\theta(t + 1) = \theta(t) - \eta \nabla L(M(x(t); \theta(t)), y(t)) \quad (5.8)

Similarly, the auto-Sklearn process, which is an automated machine learning (autoML) tool designed to optimize machine learning workflows, particularly focusing on a model selection and hyperparameter tuning, is used for optimizing performance of this process.

Auto-Sklearn employs meta-learning to suggest initial configurations. Given a dataset \(D\), auto-Sklearn references a meta-dataset m containing performance data of various machine learning algorithms on numerous datasets and their samples. The similarity between \(D\) and each dataset in m is calculated, and the best-performing configurations on similar datasets are used as starting points. The similarity score \(s(D, M_i)\) for a meta-dataset instance \(m_i\) is quantified via Equation 5.9:

$$
S(D, M_i) = exp(-\gamma \cdot dist(D, M_i)) \quad (5.9)
$$

where dist(D, M_i) is a distance measure between the datasets, and \(\gamma\) is a scaling factor. Bayesian optimization is another core component of auto-Sklearn for hyperparameter tuning. It models the mapping from hyperparameters \(\theta\) to a performance metric \(P\) as a probabilistic model, and a Gaussian Process (GP), respectively. The acquisition function \(\alpha(\theta)\), such as expected improvement (EI), is used to select the next hyperparameters to evaluate via Equation 5.10:

$$
A(\theta) = E[max(P(\theta) - P(\theta +), 0)] \quad (5.10)
$$

where \(\theta+\) is the current best hyperparameters. After evaluating various models and configurations, auto-Sklearn builds an ensemble of the best-performing models. The ensemble weight \(w_i\) for model \(M_i\) is determined based on its performance on the validation set via Equation 5.11:

$$
w_i = \frac{exp(-\alpha \cdot err(M_i))}{\sum exp(-\alpha \cdot err(M_j))} \quad (5.11)
$$

where err(M_i) is the error rate of model \(m_i\), and \(\alpha\) is a scaling parameter used for tuning process. In edge computing scenarios, auto-Sklearn incorporates online learning to adapt models over temporal instance sets. The process adapts to changes in data over time by retraining or fine-tuning models on new data instances and samples. This adaptation can be formulated as a continual learning process where the model is periodically updated via Equation 5.12:

$$
\theta_{new} = Update(\theta_{old}, D_{new}) \quad (5.12)
$$

where \(\theta_{old}\) is the existing model parameters, \(D_{new}\) is the new data, and update is the retraining process. Thus, auto-Sklearn in edge devices for predictive maintenance represents a sophisticated autoML solution, incorporating meta-learning, Bayesian optimization, ensemble methods, and online learning to ensure optimal model performance and adaptability in dynamic industrial environments.

Similar to this, the proposed model also fuses TPOT with H2O for enhancing efficiency of the predictive maintenance process. The integration of TPOT (Tree-Based Pipeline Optimization Tool) and H2O autoML offers robust and automated solutions for machine learning model development and optimizations. These tools facilitate the adaptation and improvement of predictive models over temporal instance sets.

TPOT employs genetic programming to optimize machine learning pipelines, including data preprocessing, feature selection, and model selection process. The optimization can be represented as a search task over a space of possible pipelines P. each pipeline \(P_i\) is evaluated based on its cross-validation performance CV(\(P_i\)) levels. The objective is to find the pipeline \(P^*\) that maximizes performance represented via Equation 5.13:

$$
P^* = argmax_{P_i \in P} [CV(P_i)] \quad (5.13)
$$

The genetic programming in TPOT includes operations, such as selection, crossover, and mutation, applied to the population of pipelines. The selection operation is based on a pipeline's fitness, which is a function of its performance and is estimated via Equation 5.14:

$$
Fitness(P_i) = f(CV(P_i)) = \frac{P + A + R}{3} \quad (5.14)
$$

Crossover and mutation operations are applied to generate new pipelines. For instance, in crossover, parts of two pipelines are combined, and in mutation, a part of a pipeline is randomly altered, which assists in adding new solutions. Each pipeline is evaluated using a k-fold cross-validation scheme, where the mean score across all folds is calculated via Equation 5.15:

$$
CV(P_i) = \frac{1}{k}\sum Score(P_i, D_j) \quad (5.15)
$$

where \(D_j\) is the j-th fold of the data samples. After these updates, H2O autoML automates the process of training and tuning various models, including deep learning, ensemble methods, and gradient-boosting machines. The system evaluates a set of models m = {M1,M2,...,Mn} and selects the top-performing models based on validation metrics, which are represented via Equation 5.16:

$$
M^* = \{ M_i \mid Rank(CV(M_i)) \le k \} \quad (5.16)
$$

where Rank is the ranking function based on cross-validation performance CV, and k is the number of top models to select. H2O uses stacked ensembles to combine the predictions of individual models. The ensemble prediction y' for an input x is a weighted sum of predictions from individual models, and is represented via Equation 5.17:

$$
y'(x) = \sum w_i \cdot M_i(x) \quad (5.17)
$$

where \(w_i\) is the weight assigned to model \(m_i\)'s predictions. H2O utilizes randomized grid search and Bayesian optimization for hyperparameter tuning process.
