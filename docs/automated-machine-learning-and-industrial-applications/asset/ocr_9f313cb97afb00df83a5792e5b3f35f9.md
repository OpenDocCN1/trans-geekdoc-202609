+   • **Decide which models need to be produced.** In data science, the initial step is also the most crucial. +   • **Handling the human elements of the model's deployment.** Subject-matter specialists and management have been convinced that the model is better than the current solution. They list any potential weaknesses of the model and take steps to fix them.

These are the more basic skills of data scientists, and it will take some time before machines can solve these kinds of issues. That does not imply, however, that data scientists are especially equipped to tackle these problems.
