1. **Use Case Diagram:** - A use case is a set of steps in which the user interacts with a system and in which other parties may be involved.

2. **Sequence Diagram:** - Sequence diagrams are interaction diagrams that display the interdependencies and dependencies between processes, as well as the sequence in which they occur. Message Sequence Charts make up this structure. A sequence diagram is a graphical representation of the temporal progression of an event or series of events involving a set of objects. We can see the classes and objects that will be used, as well as the messages that will be sent back and forth between them as the scenario unfolds. In the Logical View of the system being developed, sequence diagrams are often linked to implementations of use cases. Sometimes referred to as “event diagrams” or “event scenarios,” sequence diagrams have several names. Different processes or objects that exist concurrently are represented by parallel vertical lines (lifelines) in a sequence diagram, and the messages sent between them are represented by horizontal arrows in the correct order.
