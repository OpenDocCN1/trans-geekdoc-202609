# 9.1 Introduction

The method of implementing machine learning to data is automated using the technology of Automated Machine Learning (AutoML) [2]. AutoML can be arranged to iterate through many data transformations, machine learning systems, and hyperparameters to get the best model for a given dataset. The field of machine learning and data science is experiencing a distinguished increase in the usage of Automated Machine Learning. The conventional manual method of developing machine learning models is gradually becoming time consuming and inefficient due to the increasing complexity and scale of data.

Automated Machine Learning (AML) is considerably revolutionizing the field of machine learning and data science by offering effective and scalable techniques for constructing the models. Despite the increasing complexity and volume of data, the predictable method of making machine learning models has been proven insufficient in terms of both time and efficiency. The AutoML framework offers a means to enhance efficiency in this process through the automation of method selection, feature engineering, model optimization, and hyperparameter tuning. In the future, the developers will offer a more inclusive examination of the diverse constituents and advantages of AutoML, while also examining its practical implementations in real-life situations.
