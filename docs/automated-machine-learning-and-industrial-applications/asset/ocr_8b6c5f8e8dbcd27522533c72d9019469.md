The author [29] explores how well AutoML performs on text classification work. It examines how models for text representation affect the standard of AutoML classifier together with the general efficacy of their tools in this setting. The study particularly emphasizes the role of text representation models revealing from benchmark evaluations that while basic mechanisms, like Bag-of-Words, yield insistent results, AutoML-generated self-operating text embeddings have yet to surpass the performance of manually crafted text representations. The Auto-ML System for Text Classification (ASTeC), proposed by [30], employs the Bootstrap Bias Corrected CV (BBC-CV) technique to assess the execution of the ML process. This system strategically combines Genetic Algorithms (GA), Bayesian Optimization (BO), and BBC-CV to identify optimal machine learning pipelines for text classification. The effectiveness of this approach is validated through comparisons with cutting-edge systems: for the Sentiment Analysis (SA) task, it is benchmarked against TPOT (Tree-Based Pipeline Optimization Tool) and the Google Cloud AutoML service, while for the Intent Recognition (IR) task, comparisons are made with TPOT and MLJAR AutoML.

By employing two distinct datasets featuring digits and fashion items, the researchers observed that all three AutoML libraries demonstrated a commendable accuracy rate exceeding 80% when applied to clean data [31].
