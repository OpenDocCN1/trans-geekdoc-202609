### Abstract

Automated Machine Learning (AutoML) acts as a key that accelerates the next-generation industries for automation process and algorithms. It simplifies the process involved in designing and deploying machine learning techniques by incorporating the accessibility feature to users in data science and machine learning models. AutoML implies the use of automated tools and techniques to expedite and automate the process of constructing, training, and deploying machine learning models. This chapter provides an insight of design and architecture of AutoML for data science in next-generation industries.

Keywords: AutoML, industries, data science, machine learning, model training, types of AutoML, feature selection, data scientist

### 1.1 Introduction

AutoML has gained popularity among researchers and industries due to its potential for democratizing machine learning models through the process of automation. The aim is to make ML frameworks more accessible and streamline the workflow by reducing the time for developing high-quality frameworks [1]. The techniques involved, such as data preprocessing, model evaluation, feature engineering, selection of model, and hyperparameter tuning through automation enable industrialists to effectively develop high-quality ML models without requiring a deep study of the algorithms. Automated machine learning system models focus on efficiency, scalability, robustness, and flexibility to manage and handle large datasets [2].

### 1.2 Modular Design

A modular design in AutoML is crucial for developing an extensible model that supports diverse requirements, data types, and procedures.

- **Component-Based Model**
  This component-based architecture is the process of dividing the system into individual components in which each subcomponent is responsible for performing specific work like preprocessing, feature engineering, parameter tuning, and model evaluation. Each component encompasses various functionalities enabling well-defined interactions among related components and supporting an effective interface for performing connections.

- **Flexibility**
  The model provides flexibility and reusability to achieve optimal results. The design components used across various models are capable of handling various types and sources of data with different sizes and formats. The abstraction layer is mainly used for decoupling the components enabling efficient substitution or extension for the functionality to evaluate the machine learning models without creating impact on the subsystems.

- **Dynamic Composition**
  Combining the components dynamically by supporting various tasks based on their system requirements is followed. The preferences and the type of components to be combined will be decided by the user for evaluating the model. Implementing the configuration mechanism to define custom pipelines of individual components is very effective.

- **Plug and Play Architecture**
  New components can be efficiently added into the existing hierarchy of the component system without modifying or reconfiguring the model. Defining standard interfaces for communicating the components enabling interoperability feature for effective utilization of individual components in an isolated manner.

- **Modular Testing and Validation**
  Designing and developing an efficient testing model for validating the functions involved and evaluating the performance metrics of each component effectively. Integration testing ensures that the components work together properly for large data sets.

- **Dependency Management**
  Managing dependency among various components is crucial to avoid conflicts and maintain consistency. Dependencies among various components are tested by various testing mechanisms and enable isolation mechanism to ensure the effectiveness of the model.

- **Scalability and Performance**
  The components that are designed should be scalable, especially for workflows with large datasets, by utilizing distributed or parallel processing mechanisms to dynamically leverage the required computing resources.

### 1.3 Data Handling

Data handling in AutoML is essential for managing and maintaining data flow throughout various phases of the machine learning pipeline as shown in Figure 1.1. Data ingesting support is required to fetch various sources of data like data lakes, cloud storage, databases, and external APIs. Connectors are implemented to combine various data sources in different formats. Data preprocessing is essential for machine learning model quality and to avail optimal results. Data cleaning is one of the preprocessing techniques used for handling missing data, duplication, and managing inconsistent data [3].

Data transformation is a preprocessing method that transforms the input for scaling, encoding, and normalizing and handles skewed distributions. AutoML supports automatic feature generation from existing data using various methods. Feature selection and scaling is important for selecting relevant features and ensuring uniformity to stabilize the features among various feature ranges. Data augmentation is very important for generating synthetic samples of data to train data sets and improve accuracy level. This plays a vital role when the available size of data is small. Data mirroring, cropping, rotating, and flipping are some of the techniques involved in augmenting the data samples. Tracking the lineage and maintaining version history of data sets are recommended to improve the reproducibility and auditability of various models [4].

Data quality assessment is one of the important methods that perform the quality checks of the data sources to mitigate various issues involved in addressing data issues like schema changes, anomalies, inconsistency, and data drift. Triggering alerts when deviations happen in the norms by monitoring qualitative metrics is essential. Streaming data processing support is required for real-time data ingestion, which deals with collecting data from various sources such as IoT devices and sensors. The captured data are sent to the repository for evaluation using streaming processing [5]. There are various effective stream processing frameworks available for handling high throughput and low latency data. Data privacy and security are among the most important components in data handling model to ensure compliance with standards and implement privacy regulations. Encryption and access control policies are widely used for preserving privacy and confidentiality of data. Data visualization provides various tools for exploring and analyzing the data set and to manage the relationships among various data sources.

### 1.4 Model Training and Selection

Model training and selection provide automatic exploration of various machine learning models, optimization of hyperparameters, and identification of the best model for the given datasets. Algorithm exploration is an essential technique that supports diverse machine learning algorithms that will be suitable for a given problem. Algorithms are represented as components for easy experimentation and integration. Hyperparameter selection is very crucial for the model performance. Configuring the hyperparameters based on the behavior of the algorithm improves accuracy results. Automatic hyperparameter optimization and parameter tuning are added advantages in AutoML [6].

Cross validation methods are used to assess the generalization process of various models by splitting the given data set into multiple folds and evaluating them to estimate the performance accurately. Ensemble learning is used to combine the predictions among various models to improve the performance. Bagging, boosting, and stacking are examples of ensemble methods used to combine predictions. Performance metrics are basic parameters used for testing a model. Various evaluation metrics are used to evaluate machine learning models in both the training and testing of datasets [7].

## AutoML in Data Science

AutoML refers to the structure guidelines and techniques to automate any or all of the steps in the machine intelligence process. It offers easily accessible components and tools to expedite and improve the machine process of learning. Understanding the machine learning pipeline is helpful before utilizing AutoML.

Data scientists might concentrate on more difficult jobs using AutoML for automating time-consuming testing, sparing them some of their burden and responsibility. It also ensures enhanced efficiency and usability in traditional predictive modeling frameworks [8].

Although data science is an extensive field, a data scientist involves several kinds of skills that are not completely represented by a single tool or software. The domain requires an exhaustive knowledge of the topic as well as the recognition and formalization of the problem in a specific way to discuss alternative solutions. Information from the real world is usually noisy and unstructured. It includes errors in spelling, mismatched labeling, missing values, replication, inconsistent units, and abnormalities. The data must be adequately prepared and treated before any mathematical calculations are carried out on it.

The AutoML techniques that have been examined, so far, have limitations to certain challenges such as classification and regression. It is not strong enough to handle unsupervised machine learning techniques. The objective of AutoML is to support data scientists in their roles, not to replace them. It is a good option for creating models and enabling people who are not experts to engage with machine learning. However, compared to data scientists, AutoML is unable to express business problems or use domain expertise for extracting useful features from the data.
