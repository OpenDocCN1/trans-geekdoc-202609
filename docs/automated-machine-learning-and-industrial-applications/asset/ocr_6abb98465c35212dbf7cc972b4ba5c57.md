Unless otherwise noted, we balance attack and regular data in every domain. In this scenario, the workload for body sensors is homogeneous and uniformly distributed. Every sensor makes 500 requests per second (i = 1,..., 200). We can see that as the number of body sensors improves, the mean system reaction time also rises. When this number exceeds 120 devices, the specified SLA latency is violated. It is required to increase computational resources (cloud and fog) to efficiently process health data from MIoT devices to prevent this SLA breach.
