# 1. Automated Feature Engineering

A data feature contains a segment of input data for a machine learning model, and feature engineering takes the transformative process wherein a data scientist finds new information from existing data. This process looks out as a crucial value-adding phase in a machine learning workflow, with the quality of features distinguishing between a model of performance and one that excels. These mathematically changed raw data form the core of the machine learning process. Automated feature engineering (AFE) is the consistent exploration of reasonable feature combinations in a mechanized, as opposed to manual.

Manual feature engineering, often compared to modern-day experiment, comes with a significant time cost—constructing a single feature can take hours, and the absolute number of features required for even a simple accuracy score, let alone a production-level baseline, can reach into the hundreds [17]. By automating the exploration of the feature space, AutoML dramatically minimizes the time a data science team spends on this process, from days to mere minutes.

The benefits of automated feature engineering spread beyond time savings for data scientists. The generated features are inherently interpretable. In regulated industries, like healthcare or finance, interpretability is vital, as it reduces barriers to AI adoption. Moreover, the simplicity of these features enhances the application and actionability of high-quality models for data scientists. Automatically generated features also have the potential to determine new key performance indicators (KPIs) for an organization to monitor and act upon. Following feature engineering, data scientists progress to optimize their models through planned feature selection.

# 2. Automated Hyper Optimization

Hyperparameters in machine learning algorithms can be compared to devices for fine-tuning model performance, where even small adjustments can have a substantial impact. In small-scale data science modeling, hyperparameters can be manually established and optimized through trial and error.

However, for deep learning applications, the number of hyperparameters rises exponentially increasing the feasibility of manual optimization within a reasonable timeframe for a data science team. Automated hyperparameter optimization (HPO) improves this challenge by permitting teams to explore and optimize across the full hyperparameter space in an automated manner allowing them to focus on iterating and experimenting with features and models [18].
