## Open-Source Tools in Automated Machine Learning

### Abstract

Explainable AI (XAI) is the current trend set that has a potential to allow the user to understand the prediction made by machine learning and deep learning models. The nature of transparency and accountability of XAI impose and attract the researchers and industries to adopt a responsible technological model for AI development. XAI has the potential to comprehend how the machine learning and deep learning models produce results in what basis the classification and prediction result is obtained. The interpretation of the results is made easy using XAI by overcoming the drawbacks of AI that is considered as a “black box” model. This chapter discuss the various open source tools in Automated Machine Learning.

Keywords: AutoML, open-source tools, XAI, AutoGluon, Auto-Sklearn, clinical outcomes, deep learning

There are many advantages of AI-based decision making models that led to a specific outcome in which XAI interprets the results and gives a clear understanding about a decision-making process in an efficient way. With XAI, industries can gain knowledge about the decision making of an AI-enabled system to improve user experience and satisfaction. XAI is also used to enhance the business process by improving the model’s performance. Stakeholders can understand and gain insights into the underlying model’s behavior, compare model predictions, identify risks, and optimize the performance of the model. Those who were working in the area of data science are benefited by the development of automated ML tools. AutoML tools simplify the machine learning process by automating each process in the machine learning like data preprocessing, hyper parameter tuning, algorithm selection, architecture selection, and performance metrics selection. The company will try to understand the market needs in a faster manner with the help of the tool. A non-expert person in ML also can use the tool. This tool makes difficult tasks easier and reduce the inefficiency in making the model. It handles large datasets in an effective way and also uses innovative ML techniques. ### AutoGluon

AutoGluon is an open-source tool that is used in the area of automated machine learning. It focuses on automated stack ensemble ML model, deep learning, and real-world applications. This open-source software can handle text dataset, image dataset, and also tabular data. It was developed by Amazon Web Services. This tool provides a high-level interface. The tool will train the data, then deploy the model.

### Strengths of AutoGluon

- **User Friendly:** It provides an interface that could train a model using a single line of code, when all the default settings are done for the basic procedure.

- **Highly Automated:** AutoGluon automates all the steps of ML, like data pre-processing, feature selection, hyper parameter tuning, and the design of artificial neural networks (ANN) [2]. It also provides information about the kind of data inferred, and it also deploys the model.

- **Lots of Control:** The AutoGluon permits the user to configure many characteristics of the machine learning steps, such as data interpretation, feature extraction from the data set, model selection, choice of performance metrics, and consideration of hyper parameters. This is very useful for experts who use the ML models.
