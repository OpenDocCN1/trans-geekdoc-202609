## 6.3.2 AutoKeras

AutoKeras is dedicatedly focused on deep learning tasks distinguishing itself from systems that concentrate on the shallow models discussed earlier. The process known as neural architecture space (NAS) is applied to neural networks and entails identifying both the model architecture and the parameters that are utilized for model preparation. With AutoKeras you can perform AutoML for deep learning models using an open-source library. The TensorFlow tf.Keras API is used to conduct the search utilizing Keras models. It presents a simple and efficient strategy to automatically discover high-performing models across a diverse set of predictive tasks encompassing structure classification and regression dataset commonly referred to as tabular data.

It can select different parameters, like the number of layers, the number of neurons, and learning rate, along with other hyper-parameters such as optimization and loss functions.

### 6.3.2.1 Neural Architecture Search and Hyper-Parameter Tuning

Automating architectural engineering is a next-level logical progression from automated machine learning, which lowers the complexity of manually constructed neural architecture. Since it has a lot in common with feature engineering, minimization of hyper-parameter, and Meta learning, NAS is regarded as a subset of AutoML. This means NAS can be divided into three aspects: scope of search, searching methodology, and techniques for performance computation [42–44].

The search space delineates the architecture that can theoretically be represented. It is possible to streamline the exploration process and reduce the search space by incorporating past knowledge about typical architectural characteristics suitable for a task. Nevertheless, this approach adds a weighted value physically. This might preempt the discovery of unique architecture components for progress entirely up to human cognition. AutoKeras uses Bayesian Optimization, Random search, Grid search, and hyper band tuner toward the direction of search for the neural structure framework. Additionally, it makes use of a tree-structured acquisition function for minimization and a neural network kernel to efficiently assess the search space. Therefore, search space refers to the selection of model classifier with corresponding hyper-parameters. The general neural architecture search will be defined as follows:

```
P = \underset{\theta}{argmin} Cost(P(\theta^*), X_{val}) \quad (6.1)
```

```
\theta^* = \underset{\theta}{argmin} Cf(P(\theta), X_{train}) \quad (6.2)
```

Let M be the machine learning technique with H hyper-parameters. The complete set of hyper-parameter configuration space is d = d_1 × d_2 × d_3 × ... d_n, and the scope belongs to the n-th parameter by d_n. A vector of hyper-parameters is denoted by V, which belongs to D. Hyper-parameter domains include real valued, integer valued, binary, and categorical [38]. Based on the above architecture search method, a text classifier-based AutoKeras, named AutoCRM, simplifies the creation of neural network architecture models with optimized parameters.

AutoModel combines model selection and optimized hyper-parameters to form the text classifier AutoKeras model. The search space is nothing but the model selection with corresponding parameters such as Max_trial, Overwrite, Objective, Tuner, Multilabel, Directory, Project_Name. etc.

- **Max_trials**
  Max_trials is a parameter that determines the upper limit on the number of distinct neural network architectures the system will evaluate in its quest to discover the optimal model. This parameter signifies the maximum count of unique combinations of hyper-parameters and architectures with techniques such Bayesian optimization, Random Search, etc. AutoKeras will perform up to the max_trial number. This search involves various combinations of layers, operations, and hyper-parameters to build and train different neural network architectures. Each trial corresponds to a different candidate model with a specific set of hyper-parameters such as block_type, classification head, dropout, optimizer, and learning rate. After reaching the maximum count, AutoKeras stops the search and returns the best model found during the trials.

- **Overwrite**
  It determines a true or false condition: whether to discard any previous results and start a new search process or to resume the search from where it left off.

- **Objective**
  The foremost goal of this parameter is to perceive the architecture that performs the best according to the specified objective metric. For text classification, it includes Val_accuracy and Val_Loss. The model is created with Val_accuracy, which is to strengthen the accuracy of the tasks.

- **Tuner**
  The model will be searched with various tuners, and the best model with a tuner will be selected for the classification. The AutoCRM model is created by choosing Bayesian optimization, random search; Hyperband or Grid search based on the computational resources and desired level of exploration in a hyper-parameter space.

- **Project_Name**
  The name of the directory used to save the Autokeras project.

- **Directory**
  The path to a directory where the search outputs are saved.
