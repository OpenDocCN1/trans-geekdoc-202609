B. Early Stopping: This regularization method stops overfitting by halting training when performance stops improving. # 14.3 AutoML Components

AutoML approaches can also be categorized into three main components as follows:

# 1. Search Space

The search space in machine learning describes all design choices, including learning algorithms and their hyperparameters. Hyperparameters can be categorical (e.g., kernel types for SVMs) or numerical (e.g., learning rates). The combined procedure selection and hyperparameter (CASH) problem treats algorithm choice as a hyperparameter and is tackled using hyperparameter optimization (HPO) techniques.

Categorical Hyperparameters: These take discrete values without any inherent order, like different kernel types in SVMs [70].

Numerical Hyperparameters: These are defined over a numeric range, such as learning rates or kernel widths [71].

Conditional Hyperparameters: Some hyperparameters depend on others. For example, kernel width is relevant only for kernels.

Hyperparameter optimization techniques handle these differently. For instance, log transformation can be applied to numerical hyperparameters to emphasize smaller values. Techniques, like weight sharing reduce computational costs, while early stopping prevents overfitting by halting training when performance plateaus [72].

# 2. Search Strategy

In AutoML, search strategy or algorithm refers to exploring the search space to find the best machine learning models and hyperparameters. The following are some common search strategies: i) Grid Search, ii) Random Search, iii) Bayesian Optimization, iv) Evolutionary Algorithms, v) Reinforcement Learning, and vi) Gradient-Based Optimization [73].

These strategies aim to automate and optimize the procedure of selecting and tuning machine learning models making high-performance models more reachable.
