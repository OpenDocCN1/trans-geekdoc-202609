## 6.1.3 Machine Learning Pipeline (ML)

A machine learning (ML) pipeline is a series consisting of data preparation and modeling steps designed to transform raw data into a trained and deployable ML model. The pipeline organizes and automates the workflow making it easier to manage, reproduce, and iterate throughout the entire process. The typical steps include data preparation and cleaning, feature engineering, model selection, training, parameter tuning, evaluation, and deployment.

## 6.1.4 Automated Machine Learning (AutoML)

ML is a branch of AI that offers a system geared toward learning automatically. As a result, ML has become a rapidly evolving field of application and research that is updated in a daily manner. Currently, AutoML is one of the most prominent and focused fields of machine learning. It holds the potential to significantly increase productivity for data scientists, ML engineers, and researchers in the field by minimizing recurrent functions with an ML pipeline [3].

The term AutoML refers to a collection of methods for automatically determining the best model for the available dataset. Traditional machine learning algorithms needed multiple steps to create a model such as data preparation; pre-processing; algorithm selection, learning, and evaluation; parameter tuning; and prediction.

It leads to complexity due to the lack of sufficient learning involved in implementing the machine learning model. Additionally, generating and comparing multiple models to choose the optimal one typically demands substantial domain expertise as shown in Figure 6.3. AutoML aims to alleviate these complexities, i.e., to automate the procedural development of an entire machine learning pipeline with minimal human involvement. There are two main steps in AutoML, they are as follows:

- 1. How to search for a new model
- 2. How to derive its optimal performance in an efficient way.

Despite the availability of numerous services of AutoML in the cloud environment, there are three factors that hinder the users during the implementation phase. First, utilizing cloud platform services comes at a cost making it potentially unaffordable for individuals seeking to employ AutoML techniques. Second, cloud-based AutoML often demands intricate configurations involving Docker containers and Kubernetes posing challenges for individuals without an extensive background in computer science. Third, AutoML service providers are commonly described as being “Honest but curious,” leading to concerns and uncertainties about the security and privacy of user data” [5]. An accessible solution to these challenges would be an open-source software that can be easily downloaded and executed locally, thereby making AutoML available to a broader audience. In addressing this, AutoKeras was implemented.

### 6.1.4.1 AutoML Core Goals

The core goals of AutoML include the following [6]:

- **Performance**—Achieving strong generalization performance involves the ability to perform well across diverse input data and various learning tasks.
- **Reduced Human Intervention**—Configurations for machine learning tools can be automated.
- **Optimal Computational Complexity**—The program can provide satisfactory output within predefined resource constraints.

### 6.1.4.2 AutoML Tools

AutoML tools represent a significant stride toward making machine learning accessible, transparent, and collaborative. These tools empower users to efficiently leverage the capabilities of machine learning models fostering a culture of knowledge sharing and innovation. As machine learning landscape continues to evolve, open-source AutoML tools are poised to remain at the forefront of shaping the future of automated machine learning.

Collectively, open-source AutoML tools have played a significant role in democratizing machine learning by lowering entry barriers for users with diverse skill sets. They empower individuals with varying levels of expertise to leverage the potential of existing ones and eliminate the necessity for extensive domain knowledge. Some of the most used AutoML open source tools are the following [7]:

### Auto-Sklearn

For ML algorithms and data pre-processing, it is an extension of the Scikit-learn machine learning package. It quickly determines the optimal model pipeline for the provided dataset by utilizing the Bayesian optimization search technique.

### AutoKeras

It is a Python library especially for AutoML, which is constructed on top of the popular deep learning frameworks Keras and TensorFlow. AutoKeras aims to simplify the machine learning model development process by automating the selection of neural architecture and hyper-parameters.

### Google Cloud

Despite being a part of a commercial cloud platform, it offers certain AutoML components as open source. This includes AutoML Tables and AutoML Vision Edge providing developers with the flexibility to tailor models for tabular and edge device-based ML tasks. This commitment to openness facilitates knowledge sharing and collaborative advancements within the developer community.

### TPOT

An open-source Python package created specifically for AutoML is called Tree-Based Pipeline Optimization Tool (TPOT). It takes a unique approach by utilizing genetic programming to optimize ML pipelines. Its flexibility and adaptability empower data scientists to explore a wide range of possibilities encouraging experimentation and iteration to find optimal solutions.

### H2O.ai

This is an automated platform designed to automate the process of creating and deploying ML models. It is particularly popular for its flexibility, scalability, and ease of use.

## 6.1.5 Objectives of this Research

Creating an Auto-CRM learning system using AutoML can be driven by various objectives to enhance customer interactions, optimize processes, and derive valuable insights. Some of the key objectives are as follows:

- 1. Customer Classification Based on Satisfaction Levels: Implement a classification system to categorize customers into distinct groups based on their levels of satisfaction, distinguishing between satisfied and dissatisfied customers.
- 2. Opinion Mining and Feedback Processing: Employ AutoML for sentiment analysis on customer feedback, reviews, and interactions. This can provide relevant insights into customer fulfillment, concerns, and preferences facilitating prompt responses and service improvements.
- 3. Continuous Model Improvement: Implement AutoML to enable the system to continuously learn and adapt. This involves regular retraining of models to incorporate new data and changes in customer behavior ensuring the system remains up-to-date and effective.
- 4. Comparison of Supervised ML Techniques: Evaluate and compare the functioning of diverse supervised ML techniques with AutoCRM automated machine learning model. Specifically, analyze their effectiveness in handling mixed text information using different approaches.

These objectives collectively aim to gain a deeper understanding of customer sentiments and satisfaction levels through the analysis of dataset employing advanced techniques in text analysis and machine learning for classification tasks.
