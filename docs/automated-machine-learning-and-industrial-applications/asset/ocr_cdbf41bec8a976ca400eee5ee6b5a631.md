# ## Abstract

With the increase in machine learning attention over the recent few years, the next focus is on Automated Machine learning (AutoML), which democratizes ML by automating model selection, tuning in the hyperparameters, and the feature engineering process as well. The work delves into the ecosystem of the AutoML, where the initial and basic tasks of ML are converted into a single step. The work focuses on the different frameworks on AutoML along with few open-source AutoML libraries like Auto-sklearn, TPOT, AutoKeras, MLBox, etc. The benefits, challenges, and limitations of incorporating AutoML are discussed in brief. Models, like Fully Automated, Human-in-the-loop, and Model Assisted are the major types of AutoML that are in practice. Though AutoML has a significant efficiency in automating the ML process, the challenges associated with it are quite noteworthy. The intricacy of the model increases with large datasets, along with minimal transparency in the framework. AutoML lacks customization of the models, with obscurity in the algorithms used, decision-making processes, and similar others. Flexibility is a great problem with AutoML since the ML pipeline is automated, and thus, it is quite challenging for the users who move from an ML to an AutoML platform.
