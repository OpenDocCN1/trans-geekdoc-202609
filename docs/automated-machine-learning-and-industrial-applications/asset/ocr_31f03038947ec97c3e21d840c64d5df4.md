The edge devices are equipped with autoML capabilities enabling the automatic selection and tuning of machine learning models for predictive maintenance. The autoML process involves several steps starting with data preprocessing followed by model selection, hyperparameter optimization, and model validation. Hyperparameter optimization can be approached using Bayesian optimization, where the objective function to be maximized is the cross-validation score of the model. This can be expressed via Equation 5.2:

```
$max\theta \in \Theta f(\theta)$
(5.2)
```

where $\theta$ represents the hyperparameters and $\Theta$ the hyperparameter space. In the context of predictive maintenance, the selected machine learning models are primarily used for anomaly detection and fault prediction. The data processed by the CNNs are fed into these models. For anomaly detection, unsupervised autoencoders are used in real-time scenarios. The autoencoder can be described by two functions: the encoder $h = f(x)$ and the decoder $r = g(h)$, where $x$ is the input, $hh$ is the encoded representation, and $r$ is the reconstruction of the input samples. The loss function, which is a measure of reconstruction error, could be represented as $L(x, g(f(x)))$, where $L$ is a mean squared error operation and is used to tune the model under real-time conditions. The autoML system's primary objective is to automate the process of model selection and tuning to optimize predictive performance for maintenance tasks. The autoML system begins with a model selection framework. Given a set of candidate models m = {M1,M2,...,Mn}, where each model represents a classifier, which is chosen from naïve Bayes, support vector machine, gradient-boosting machine, and k nearest neighbors, which assist in identification of faults. The system evaluates each model m/ based on a predefined performance metric, which is estimated via Equation 5.3:

```
$Mi = \frac{P + A + R}{3}$
```
