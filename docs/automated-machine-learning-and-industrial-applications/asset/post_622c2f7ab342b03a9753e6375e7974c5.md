In recent trends, deep learning has started wide application across diverse fields choosing amazing success in addressing complex AI problems [13]. The revolution moment occurred in 2012 when AlexNet outshined in the ImageNet Large Scale Visual Recognition Challenge (ILSVRC) processing traditional methods. However, more complex and deeper neural networks were introduced with models, like ResNet-50, featuring 50 layers and approximately 25.6 million parameters [1]. The architecture consists of steps with varying filter sizes, beginning with 64 filters in the initial stage and completing with 1,024 filters in the fifth stage. Each stage contains residual blocks, each of which contains two 3 × 3 convolutional layers and a crosscut connection.

The intensifying costs connected with model development have given a chance to a novel concept called the automation of the complete machine learning (ML) pipeline. Referred to as automated machine learning (AutoML), this approach improves the burden of development costs [14]. In modern times, AutoML systems can integrate many techniques making a straightforward and user-friendly end-to-end ML pipeline system. Our focus is to create a way of personalized AutoML methods directing to the development of the most comfortable AI system.

The AutoML workflow covers many stages like feature engineering, data preparation, model generation, and model evaluation as shown in Figure 1.2. The process of model processing can be divided into search space exploration and optimization methods. The basic design principles of ML models are consistent within the search space and divided into two types as follows: traditional ML models and neural architectures. For classification, optimization techniques can be classified into hyperparameter optimization (HPO) and architecture optimization (AO) [15]. HPO aims to optimize parameters related to training, such as learning rate and batch size, while AO aims to enhance parameters linked with the model itself. For example, the optimization of the number of layers in neural architectures and the number of neighbors in KNN are instances of parameters given in architecture optimization (AO) techniques.

## Types of AutoML

In a data science pipeline, various steps must be started by a data science team to create a predictive model. Even experienced teams of data scientists and ML engineers can find data with the improved speed and transparency given by AutoML. A data scientist typically starts the process with a hypothesis, acquires the appropriate dataset, creates data visualization, engineers additional features to store all available signals, and then follows to train a model with hyperparameters. For state-of-the-art deep learning, they also need to design an efficient architecture for a Deep Neural Network possibly leveraging a GPU if it is at their disposal [17]. The different types of AutoML are as follows:

- 1. Automated Feature Engineering
- 2. Automated Hyper Optimization
- 3. Neural Architecture Search

### 1. Automated Feature Engineering

A data feature contains a segment of input data for a machine learning model, and feature engineering takes the transformative process wherein a data scientist finds new information from existing data. This process looks out as a crucial value-adding phase in a machine learning workflow, with the quality of features distinguishing between a model of performance and one that excels. These mathematically changed raw data form the core of the machine learning process. Automated feature engineering (AFE) is the consistent exploration of reasonable feature combinations in a mechanized, as opposed to manual.

Manual feature engineering, often compared to modern-day experiment, comes with a significant time cost—constructing a single feature can take hours, and the absolute number of features required for even a simple accuracy score, let alone a production-level baseline, can reach into the hundreds [17]. By automating the exploration of the feature space, AutoML dramatically minimizes the time a data science team spends on this process, from days to mere minutes.

The benefits of automated feature engineering spread beyond time savings for data scientists. The generated features are inherently interpretable. In regulated industries, like healthcare or finance, interpretability is vital, as it reduces barriers to AI adoption. Moreover, the simplicity of these features enhances the application and actionability of high-quality models for data scientists. Automatically generated features also have the potential to determine new key performance indicators (KPIs) for an organization to monitor and act upon. Following feature engineering, data scientists progress to optimize their models through planned feature selection.

### 2. Automated Hyper Optimization

Hyperparameters in machine learning algorithms can be compared to devices for fine-tuning model performance, where even small adjustments can have a substantial impact. In small-scale data science modeling, hyperparameters can be manually established and optimized through trial and error.

However, for deep learning applications, the number of hyperparameters rises exponentially increasing the feasibility of manual optimization within a reasonable timeframe for a data science team. Automated hyperparameter optimization (HPO) improves this challenge by permitting teams to explore and optimize across the full hyperparameter space in an automated manner allowing them to focus on iterating and experimenting with features and models [18].

Automating the machine learning process also allows data scientists to shift their focus from the "how" of model creation to the "why." With huge amounts of available data and numerous questions to address, analytics teams can now concentrate on defining which aspects of the model to optimize for. For instance, they can address classic problems like minimizing false negatives in medical testing.

### 3. Neural Architecture Search (NAS)

The most complicated and time-consuming method of deep learning is in structuring the neural architecture. Data science officials invest reasonable time in choosing appropriate sections and learning rates by mostly focusing on weights in models, especially proven in language models. Neural Architecture Search (NAS), stated as "making use of neural nets for designing neural nets," reaches out as a major candidate for automation in the arena of machine learning.

NAS explores by finding architectures to learn, with the result determined by the metric against which every architecture is measured. Many algorithms can be used in a neural architecture group [19]. For example, if the required number of architectures is less, random options for testing can be done. Gradient-based approaches, transforming the discrete search space into a continuous illustration, have proven very effective. Alternatively, data science officials may practice with traditional algorithms, where architectures are measured and changes are slowly applied, developing more successful child architectures while reducing unsuccessful ones.

While neural architecture searches are a significant component of AutoML, using the democratization of AI, they frequently come with a considerable carbon footprint. An examination of these compromises is still pending, and an ongoing study in NAS methods is exploring optimization for environmental costs.
