# 12.2 Understanding Blockchain and AutoML

Blockchain era is a decentralized virtual ledger that offers a stable and
transparent manner to store and confirm transactions [5]. This present-day
generation incorporates a network of nodes that work collectively to val-
idate and hold data in a chain of blocks. Every block is cryptographically
related to the preceding block making it clearly no longer viable to alter or
delete any transaction data once the recording is done [6]. The decentral-
ized nature of Blockchain generation technique prevents intruders from
accessing or modifying transactions, which notably reduces the chance of
fraud and hacking. AutoML is an advanced artificial intelligence technolo-
gy that automates the process of selecting best machine learning algo-
rithms, feature selection and hyperparameter tuning [7]. This technology
allows organizations to analyze large datasets in real time, delivering faster
and more accurate insights. AutoML is tremendous as it makes it much less
complicated for companies to set up machine mastering models in produc-
tion, reducing the time and effort required via the use of statistics scien-
tists. By automating trained models, AutoML streamlines the assessment
of statistics enabling corporations to make better decisions and achieve a
competitive advantage [8].
