# Network Monitor

Environmental factors that affect the reward function might be excluded making transitioning from a single-agent method to a multi-agent strategy with partial observability of the environment more challenging. This hampers the agents’ capacity to link states to actions. The network state has a direct impact on a node’s performance and reward in a network. Other nodes in a network, networks that are physically close by, or the propagation environment are included. All of these variables fundamentally impact the capacity of the base station to decode a packet. Any of these effects results in the packet having an insufficient signal-to-noise ratio for its time on air. Therefore, “noise” can describe the consequences of these influences. To assist the agent in completing its environmental observations, the network monitor measures this noise and provides it to the agent.
