
## Predicting and Forecasting Bank Failures

Just Add Data (JAD) is an AutoML modern technology used for forecasting bank failures. The most important predictions are made using an automated feature selection process in JAD, and cautious predictions regarding performance generalization and confidence intervals are obtained by bootstrapping. According to the present research, JAD and AutoML tools generally could protect financial data analysts from fundamental statistical errors, boost their efficiency, and produce models that are at par with the most advanced analysis done by hand [27].

## Automated Traffic Analysis

Machine learning is used for investigating network traffic activities related to protection ranging from identifying intrusions to application classification. By automating numerous analyses of traffic processes, algorithms for machine learning can be applied to a broader range of traffic analysis activities. To create nPrintML, an open platform that essentially does away with feature extraction and simulation modification for a range of traffic monitoring tasks, they initially introduce nPrint, an application that creates a single packet-based illustration that is suitable for portrayal learning as well as model training [28]. Additionally, they combine nPrint with automated learning algorithms (AutoML).

## AutoML for Genome-Wide Association Studies

The processing of data from Genome-Wide Association Studies (GWAS) poses a number of computational and statistical issues, including interpretability, knowledge discovery, and clinical practice translation. By utilizing a set of gene variants that are significant for predictions (referred to as a biosignature), an assessment of the out-of-sample predictive ability, and AutoML tailored for genomic data, reliable predictive and diagnostic models are produced [29]. Additionally, it generalizes to new, unseen data.

## Development of Prediction Model for Diesel Engines

A model was developed using machine learning that reduces insignificant input features by employing the Random Forest technique to forecast nitrogen oxide emissions. A Base model was established with every feature for comparison. The dominating features were selected using the Shapley Additive Explanations method, which can demonstrate the impact of input information characteristics, and the Pearson Correlation Coefficient method, which can demonstrate the proportionate link with the output and input values [30]. By utilizing the Shapley Additive Explanations approach, the final model was developed to create a simple yet precise NOx prediction model by identifying the key features affecting NOx prediction.

## Conclusion

Automated Machine learning has become a popular technology trend that efficiently streamlines the progression to build and deploy machine learning models. AutoML tools are widely used to automatically analyze heterogenous data for predicting the outcomes in various applications. It is mainly used in applications like text classification, weather forecasting prediction, healthcare, sentiment analysis, business processing, and financial sectors. The role of AutoML includes identifying patterns, providing recommendations based on user behavior, optimizing clinical outcomes, and analyzing medical images for the decision-making process. AutoML tools are transforming the organizational approach to utilizing ML models by reducing the complexity and time needed to develop models for various applications.
