Subsequently, the image’s source is determined by incorporating the Dind auxiliary classifier into the discriminator network. The loss associated with the image translation technique is expressed in Equation 2.13:

```
L_\text{ind} = -\mathbb{E}_{x,t} \left[ \log \left( D_{\text{ind}} \left( t=01|x \right) \right) \right] - \mathbb{E}_{x,v,t} \left[ \log \left( D_{\text{ind}} \left( t=01|G(x,v,c) \right) \right) \right]\n\tag{2.13}
```

The image generation method significantly affects the decoding network (c) because it is a shared network, and several samples utilized in image translation are substantially fewer than those utilized in image synthesis. We incorporate paired adversarial loss as shown in Equation 2.14 to ensure that the picture translation approach fits more precisely:

```
L_{pis} = -\mathbb{E}_{x_a,x_p} \left[ \log \left( D_{pis} \left( x_0, x_v \right) \right) \right] - \mathbb{E}_{x,v<} \left[ \log \left( 1 - D_{pis} \left( x, G(x,v,c) \right) \right) \right]\n\tag{2.14}
```

