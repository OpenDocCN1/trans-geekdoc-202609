## 机器人

| 指令 | 说明 |
| :--- | :--- |
| **Robot** | |
| 如果机器人尝试移动到一个非开放的方格或超出网格边缘，机器人将停留在当前位置，程序将终止。 | |
| 文本：`MOVE_FORWARD()`<br>块：![Images](images/p0202-01.jpg) | 机器朝其面对的方向向前移动一格。 |
| 文本：`ROTATE_LEFT()`<br>块：![Images](images/p0202-02.jpg) | 机器人原地逆时针旋转 90 度（即原地左转）。 |
| 文本：`ROTATE_RIGHT()`<br>块：![Images](images/p0202-03.jpg) | 机器人原地顺时针旋转 90 度（即原地右转）。 |
| 文本：`CAN_MOVE(direction)`<br>块：![Images](images/p0202-04.jpg) | 如果机器人面对方向相对的某个方向上有一个开放的方格，则求值为 `"true"`；否则求值为 `"false"`。`direction` 的值可以是 `left`、`right`、`forward` 或 `backward`。 |

AP 考试中的机器人同时具有方向和位置。方向可以是朝左、朝右、朝上或朝下。机器人的位置是机器人当前所在的网格行和列。

如果要求机器人移出网格，机器人将结束任何程序。

机器人可以通过使用下表中列出的四个抽象来改变其方向和位置。

机器人问题可以包含过程和循环，这些在图形化和基于文本的编程语言中编码。

## 交换

![Images](images/f0218-03.jpg)

一种常见算法是交换。在上述动物数据结构中，我们想要交换羊和青蛙。当前列表内容如下：

```
animals[1] = sheep
animals[2] = bear
animals[3] = frog
```

如果交换成功，动物数据结构将交换羊和青蛙。

![Images](images/f0219-01.jpg)

成功交换后，列表内容将如下：

```
animals[1] = frog
animals[2] = bear
animals[3] = sheep
```
