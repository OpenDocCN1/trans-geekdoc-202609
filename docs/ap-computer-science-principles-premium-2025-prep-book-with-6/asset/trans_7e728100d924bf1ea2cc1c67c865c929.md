## 第55题

以下哪段代码执行以下操作？

步骤1：用户输入一个数字。
步骤2：如果数字在0到10之间（含），写单词Waffles。
步骤3：如果数字在11到20之间（含），写单词Novack。
步骤4：如果是任何其他数字，写单词Benji。

(A)
```
num ← input()
IF(num > 0 and num < 10)
    DISPLAY("Waffles")
IF(num > 10 and num < 20)
    DISPLAY("Novack")
ELSE
    DISPLAY("Benji")
```

(B)
```
num ← input()
IF(num ≥ 0 and num ≤ 10)
    DISPLAY("Waffles")
IF(num ≥ 11 and num ≤ 20)
    DISPLAY("Novack")
ELSE
    DISPLAY("Benji")
```

(C)
```
num ← input()
IF(num ≥ 0 and num ≤ 10)
    DISPLAY("Waffles")
ELSE(num ≥ 11 and num ≤ 20)
    DISPLAY("Novack")
DISPLAY("Benji")
```

(D)
```
num ← input()
IF(num ≥ 0 and num ≤ 10)
    DISPLAY("Waffles")
IF(num ≥ 11 and num ≤ 20)
    DISPLAY("Novack")
IF(num > 20)
    DISPLAY("Benji")
```
