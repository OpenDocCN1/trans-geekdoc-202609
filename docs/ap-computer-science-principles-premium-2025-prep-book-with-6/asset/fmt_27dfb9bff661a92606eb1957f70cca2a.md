### Question 3: Errors and Testing

Students should be prepared to respond to prompts about their program that assess any of the following learning objectives:

- Identify the error.
- Correct the error.
- Identify inputs and corresponding expected outputs or behaviors that can be used to check the correctness of an algorithm or program.

#### Type of Errors That Could Be Tested

- A **logic error** is a mistake in the algorithm or program that causes it to behave incorrectly or unexpectedly.

  Examples:
  - Misplacing the order of operations in a mathematical expression.
  - Creating loops with incorrect entry or exit conditions.

- A **syntax error** is a mistake in the program where the rules of the programming language are not followed.

  Examples:
  - Forgetting a semicolon in Java or a colon in Python.
  - Using incorrect capitalization for variable names.

- A **run-time error** is a mistake in the program that occurs during the execution of a program. Programming languages define their own runtime errors.

  Examples:
  - Attempting to divide by zero.
  - Accessing a list element with an index that exceeds the list bounds.

- An **overflow error** is an error that occurs when a computer attempts to handle a number that is outside of the defined range of values.

  Examples:
  - If a language uses 4 bits to store an integer the maximum value would be `2^n - 1 = 15`
  - If a language uses 6 bits to store an integer the maximum value would be `2^n - 1 = 63`
