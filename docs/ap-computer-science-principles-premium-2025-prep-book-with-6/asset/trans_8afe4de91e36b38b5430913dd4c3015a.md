## 答案解析

[1](#11_Chapter02.xhtml#que2-1). **(D)** 计算创新可以包含硬件组件，但计算创新关注的是软件，而非硬件。硬件的例子包括晶体管、显示器、主板等。软件的例子包括 TikTok、Snapchat、Facebook 等。计算创新可以是物理的（如自动驾驶汽车）、非物理计算软件（如图片编辑软件）或非物理计算（如电子商务）。

[2](#11_Chapter02.xhtml#que2-2). **(A)** 无论是秃鹫珍珠鸡的飞行、鲸鱼和海豚使用的声纳，还是白蚁建筑的宏伟本质，计算创新的灵感可以来自任何地方。虽然许多创新建立在先前技术之上，但有些创新是完全独特的。例如，互联网的发明及其带来的电子商务就是独特的，并颠覆了行业。

[3](#11_Chapter02.xhtml#que2-3). **(B)** 创新是由人创造的。公司和行业可以鼓励创新，但它们由人组成。先前的创新可以启发新的创新，但创造的主体是人。

[4](#11_Chapter02.xhtml#que2-4). **(C)** 协作不必在同一空间进行。协作可以在传统工作空间进行，也可以在虚拟团队中进行。在线协作工具（如 `Google Docs`）允许程序员从家里或任何地方协作，例如一名团队成员在佛罗里达州奥兰多工作，而另一名在阿拉斯加科尔德富特工作。人际交往技能，如沟通、建立共识、冲突解决和谈判，是大多数专业领域必备的技能。

[5](#11_Chapter02.xhtml#que2-5). **(A)** 程序的定义是：一组程序语句，当由计算机运行时执行特定任务。大多数计算机设备需要程序才能正常运行。计算机程序通常由计算机程序员用编程语言编写，然后转换为计算机能理解的机器代码。软件是用于操作计算机并执行特定任务的一组指令、数据或程序。

[6](#11_Chapter02.xhtml#que2-6). **(B)** 代码段的定义是：作为程序一部分的程序语句集合。程序由代码段组成。

[7](#11_Chapter02.xhtml#que2-7). **(D)** 程序可以有多个任意类型的输入。例如，手机可以使用其任意传感器作为输入，包括接近传感器、环境光传感器、环境白平衡传感器、带 OIS 的摄像头、加速度计、陀螺仪、指南针、气压计等。

在下面的 `findSum` 过程中，输入是一个名为 `list` 的数据结构，其中填充了数字。

`findSum` 过程也可以不接收 `list`，而是接收单独的数字，其中变量 `a`、`b` 和 `c` 代表整数。


[8](#11_Chapter02.xhtml#que2-8). **(B)** 计算事件是指程序识别并由某个动作触发的动作。鼠标点击、按键和计时器都是计算事件的例子。程序的顺序可以与事件相关联。程序输入也可以由事件设定。

[9](#11_Chapter02.xhtml#que2-9). **(A)** 虽然优雅的代码受人尊敬（在某些圈子里），但它不是一种调查工具。在实际编程之前，了解越多关于用户需求的信息，在大多数情况下都能写出更好的程序。调查、用户测试和直接观察是收集用户需求信息的几种技术。

[10](#11_Chapter02.xhtml#que2-10). **(C)** `list` 是一种数据结构，可以通过索引直接访问元素。AP 语言中的 `list` 从索引 1 开始（而非 0）。例如，如果一个 `list` 包含 4 个数字，则索引为 1、2、3 和 4。

```
list ← [3, 12, 62, 100]

index    1    2    3    4

list[1] = 3
list[2] = 12
list[3] = 62
list[4] = 100
```

尝试访问不可达的索引会导致运行时错误。

```
list[0] = 运行时错误
list[5] = 运行时错误
```

该程序试图访问一个在正确范围内没有索引的 `list` 元素。这种试图访问越界索引的错误会在运行程序时被发现。

(A) 逻辑错误是指程序能运行但给出错误结果。
(B) 语法错误是指程序中的错误，即未遵循编程语言的规则。
(D) 溢出错误发生在试存储一个超出分配内存位数容量的值时。例如，在 2 位系统中试图存储数字 5 将导致溢出错误。
