## ABSTRACT

This chapter proposes a novel framework for Human Activity Recognition (HAR) using deep learning to extract features from sensor data. The framework utilizes deep learning to address the challenges of classifying human actions in complex environments.

## INTRODUCTION

Human activity refers to any movement produced by the human body. Sensor-based systems have been developed to monitor these activities, particularly for elderly and chronically ill individuals. Early methods utilized accelerometers, gyroscopes, and magnetometers to provide information. However, these sensors often could not achieve significant results in isolation.

With the introduction of machine learning, vision-based techniques have followed. Several learning techniques have been applied to identify actions from video sequences, such as Support Vector Machine (SVM) and Hidden Markov Model (HMM). Initially, single cameras were used, but multiple fixed cameras have been employed to improve tracking accuracy. Smart systems like SafeDoor and Safety are examples of assisted living technologies.
