# 3. METHODOLOGY USED FOR SENTIMENTAL ANALYSIS

A text document can be converted into numerical data that a computer system can use using a natural language processing approach called Bag of Words (BOW). The most fundamental and popular approach uses a bag of words to numerically represent a document, and then machine learning methods are used to process the data. We must first convert text format into numerical representation before carrying out any additional processing for any Natural Language Processing operation. Using machine learning algorithms on unprocessed text requires first converting text into numerical representation. We call this process "text embedding."

To incorporate a text format, two methods are available: Word vectors and Document vectors. Individual words in the text can be represented as vectors using word vectors. The document is transformed into a series of word vectors throughout. Conversely, the entire document is in Document Vector.
