Another similar use of PHP is to dress up what is essentially CGI output: a large block of PHP surrounded by HTML so that the output of the code simply appears in a larger page. This is a similar approach offered by SSI (Server-Side Includes). An SSI tag may call a CGI and insert the output in its pages.

The approach is appropriate in situations where your site is mostly static, but key areas must be dynamic. The advantage is very low on the Web server. PHP is used when absolutely necessary. In Listing 20.2 the code generates information that doesn't change, but it is easy to imagine that code pulls quotes from a database.
