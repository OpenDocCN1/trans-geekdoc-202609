# Midgard

Another approach to Web site design with PHP is the Midgard project <http://www.midgard-project.org/>. The maintainers are Jukka Zitting and Henri Briggs. Rather than crave a solution in PHP alone, they have integrating PHP into their own application server. Midgard is capable of organizing more than 800,000 pages of content using a Web-based interface. For this reason it is ideal for operating systems.

Midgard is an open source project, of course. You can download an official release, or grab a snapshot through CVS. To install it, you must modify PHP slightly, but instructions are available at the Midgard site. Because it requires compilation, running PHP on Windows is probably not worth the effort.

# Ariadne

Still in beta at time of writing, Ariadne is a Web application framework from Muze, a development agency in the Netherlands. It's available under the GNU Public License. Auke van Slooten leads the project. The source code can be downloaded from the Muze site <http://www.muze.nl/software/ariadne/>.

Ariadne stores source code as objects in a MySQL database. These objects interact with each other using a virtual file system. A rich user interface is presented to the user through pages, but advanced users may go deeper, as well. Another component controls access rights for users or groups.
