The root expression inside a switch statement is evaluated and then compared to each expression following a case statement. At the end of the list of cases you can put a default statement that works exactly like an else statement; it if no other case matches.

Notice that cases don't have braces after them. This reveals an important difference between if and switch. When an block matches and is executed, control skips to the end of the entire if statement. In Listing 3.3, if today is Tuesday, deutsch_Day is set to Dienstag, and control jumps down to the opening brace closing the else block.

A case statement serves as a starting point for execution. The root expression is compared to each expression until one matches. Each line of code that is executed. If another case statement is reached, it is ignored. Sometimes this is useful, but most often a break statement is used to escape from the switch statement.
