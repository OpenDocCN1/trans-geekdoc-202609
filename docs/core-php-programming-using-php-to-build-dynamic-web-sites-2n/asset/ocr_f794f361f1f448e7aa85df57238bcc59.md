# Multidimensional Arrays

An array can be any type of data. You've seen numbers and strings, but you can put an array inside an array. An array of arrays is also called a multidimensional array. Imagine a ten-by-ten grid. You've got one hundred squares, each of which has its own value. One way to represent this in code is a two-dimensional array: a ten-element array of ten arrays, rows of ten columns.

To reference a single element, you use square brackets to pick the first dimension (row), then use a second pair of brackets to pick the second dimension (column). Row 3, column 7, would be written as $someArray[3][7].
