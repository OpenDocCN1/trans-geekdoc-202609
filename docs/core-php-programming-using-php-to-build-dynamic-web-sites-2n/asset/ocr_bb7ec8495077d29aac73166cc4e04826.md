Of course, you are not obliged to have an elseif or an else. Sometimes you might\want to build a simple statement as in Listing 3.2.

You can use if to build a series of checks that covers all possible cases. Just start by
checking for the first condition with an; then check for each following condition with
el elseif. If you put an else at the end, you will account for all possible cases.
Listing 3.3 uses this to print the day of the week in Germany. The script gets
today's name and compares it to the days Monday through Saturday. If none of these
match, it is assumed to Sunday.

# Listing 3.1 An if-elseif-else Statement

```
<?
if($name == "")
{
    print("You have no name.");
}
elif($name == "leon") OR ($name == "Leon")
{
    print("Hello, Leon!");
}
else
{
    print("Your name is '$name'.");
}
?>
```

# Listing 3.2 A Simple if Statement

```
<?
if(date("D") == "Mon")
{
    print("Remember to put the trash out.");
}
?>
```

# The ? Operator

PHP offers an abbreviated version of the if statement that borrows syntax from C. It
uses the question mark as a ternary operator. Figure 3-2 outlines the format.

> Figure 3-2. The ? operator.

```
conditional expression ? true expression : false expression;
```
