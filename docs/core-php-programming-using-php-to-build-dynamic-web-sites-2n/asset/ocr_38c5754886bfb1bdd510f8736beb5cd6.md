My experience has been that caches are enough to store URLs that appear to be ordinary HTML files, but not URLs that variables following a query mark. Your PHP may use variables in the URL, though. If the information on these pages changes frequently, you want to let the cache know.

RFC 2616 describes the HTTP 1.1 protocol, which offers several headers for controlling the cache. Listing 18.3 shows the headers to prevent a page from being cached. The Last-Modified header reports the last time a document was changed, and setting it to the current time tells the browser this version of the page is fresh. The Expires header tells the browser when this version of the document will become requested again. Again we use the current time, hopefully causing the browser to keep the document out. Perhaps the most important header, Cache-Control tells the browser to cache the page. In this situation, requesting the page for the benefit of older browsers that understand only HTTP 1.0.
