# sprintf(string format, ...)

The sprintf function operates identically to printf function, except instead of sending the assembled string to the browser, the string is returned. See the description of printf for a detailed discussion. This function offers an easy way to control the representation of numbers. Ordinarily PHP may print a double with no fraction

```php
<?php
$x = 3.00;

//print $x as PHP default
print($x . "<BR>\n");

//format value of $x so that
//it show it two decimals after
//the decimal point
$s = sprintf("%.2f", $x);
print($s . "<BR>\n");
?>
```

# integer strcmp(string first, string second)

The strcmp compares the first string to the second string. A number less than zero is returned if the first string is less than the second string. Zero is returned if they are equal. A number greater than zero is returned if the first string is greater than the second string. Comparisons are made by ASCII values. This function is safe for comparing binary data.

# integer strpos(string data, string substring, integer offset)

The strpos function returns the position of the substring argument in the data argument. If the substring argument is not a string, it will be treated as an ASCII code. If the substring appears more than once, the position of the first occurrence is returned. If the substring doesn't exist at all, FALSE is returned. The offset argument instructs PHP to begin searching after the specified position. Positions counted starting zero.

This function is a good alternative to ereg when you are searching for a simple string. It carries none of the overhead involved in parsing regular expressions. It is safe for use with binary strings.

```php
<?php
$text = "Hello, World!";
//check for a space
if(strpos($text, 32)) {
    print("There is a space in '$text<BR>\n");
}

//find where in the string World appears
```

# integer strrpos(string text, string character)

The strrpos function operates similarly to strpos. It returns the last occurrence of the second argument in the first. However, only the first character of the second argument is used. This function offers a very neat way of chopping off the last part of a path, as in the example below.

```php
<?php
//set test string
$path = "/usr/local/apache";

// find last slash
$pos = strrpos($path, "/");

//print everything after the last slash
print(substr($path, $pos+1));
?>
```

# string substr(string text, string substring)

The substr function returns the portion of the text argument starting from the first occurrence of the substring argument to the end. If the substring argument is not a string, it will be treated as an ASCII code. If the substring appears more than once, the position of the first occurrence is returned. If the substring doesn't exist at all, FALSE is returned. The offset argument instructs PHP to begin searching after the specified position. Positions counted starting zero.

This function is a good alternative to ereg when you are searching for a simple string. It carries none of the overhead involved in parsing regular expressions. It is safe for use with binary strings. The `strstr` function is a case-insensitive version of this function.

```php
<?php
$text = "Although this is a string, it's not long";
if (strstr($text, "it") != "") {
    print("The string contains 'it'");
}
?>
```

# string strtok(string line, string separator)

The `strtok` function pulls tokens from a string. The `line` argument is split into tokens by any of the characters in `separator` string. The first call to `strtok` must contain two arguments. Subsequent calls are made with just the `separator` argument, unless you wish to tokenize another string. Chapter 16, "Parsing and String Evaluation," discusses this function in depth.

```php
<?php
// create a demo string
$line = "leon@tatkinson@clearink.com";

// loop while there are tokens
for($token = strtok($line, "\t"); $token != ""; $token = strtok("\t"))
{
    print("token: $token\n");
}
?>
```

# string substr(string text, integer start, integer length)

Use the substr function to extract a substring from the text argument. A string is returned that starts with the character identified by the start argument, counting from zero. If start is negative, counting will begin at the last character of the text argument instead of the first and work backward.

The number of characters returned is determined by the length argument or the end of the string. If length is negative, the returned string will end with many characters from the end of the string. In any case, if the combination of start and length calls for a string of negative length, a single character is returned.

This function is safe for use with binary strings.

```php
<?php
$text = "My dog's name is Angus."
//replace with Gus
print(substr_replace($text, "Gus", 17, 5));
```

# string addslashes(string text, string characters)

The addslashes function returns the text after escaping characters in the style of the C programming language. Briefly, this means special characters are replaced with codes, such as \n replacing a newline character, and other characters ASCII 32-126 are replaced with backslash octal codes.

The optional characters argument may contain a list of characters to be escaped, which overrides the default of escaping all special characters. The characters are specified with octal notation. You may specify a range using two periods as in the example below.

```php
<?php
$s = addslashes($s, "0..\37");
```
