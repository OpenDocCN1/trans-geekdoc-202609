# boolean gzputs(int file_handle, string output, integer length)

The gzputs function writes data to a compressed file. It expects a file handle as returned by gzopen. It returns TRUE if the write was successful, FALSE if it failed. The optional length specifies a maximum number of bytes to accept. A side effect of specifying length is that the magic_quotes_runtime configuration setting will be ignored.

```
<?php // open file for writing
// use maximum compress and force
// Huffman encoding only
$myFile = gzopen("data.gz","wb9h");

// make sure the open was successful
if(!($myFile) {
    print("file could not be opened");
    exit;
}

for($index=0; $index<10; $index++) {
    // write a line to the file
    gzputs($myFile, "line $index\n");
}

// close the file
gzclose($myFile);
?>
```
