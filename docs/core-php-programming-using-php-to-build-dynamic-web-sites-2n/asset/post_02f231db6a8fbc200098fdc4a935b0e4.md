
## integer filetime(string filename)

When running on UNIX, filetime returns the last time a file was changed in standard timestamp format, the number of seconds since January 1, 1970. A file is considered changed if it is created or written to or if its permissions have been changed. When running on Windows, filetime returns the time the file was changed. If an error occurs, FALSE is returned.

Two other functions for getting timestamps associated with files are filetime and fileat.

## integer filegroup(string filename)

The filegroup function returns the group identifier for the given file, or FALSE when there is an error. This function always returns FALSE under Windows. Other functions that return information about a file are file-inode, fileowner, and fileperms. To change a file's group, use chgrp.

```php
<?php print(filegroup("data.txt")); ?>
```

## integer filetime(string filename)

The filetime function returns the last time a file was modified in standard timestamp format, the number of seconds since January 1, 1970. FALSE is returned if there is an error. A file is considered modified when it is edited or its contents change. Operation of this function is identical under any operating system. There are two other functions related to timestamps on files: fileat and filectime.

```php
<?php
$LastMod = filetime("data.txt");
print("Last modification was ");
print(date("l F d, Y", $LastMod));
?>
```

## integer fileowner(string filename)

The fileowner function returns the user identifier of the owner, or false if there is an error. This function always returns FALSE under Windows. If you need to change the owner of a file, you use chown. Similar functions for getting information about a file are filegroup, fileinode and fileperms.

```php
<?php
print(fileowner("data.txt"));
?>
```

## integer fileperms(string filename)

The fileperms function returns the permission number for the given file, or false when there is an error. If you are using UNIX, you may wish to refer to the man page for the stat system function. You may be surprised to find this number in octal, as is customary, consists six digits. The first three give you information about the file that doesn't actually refer to read/write/execute permissions. You may wish to filter information out, as I have in the example, by performing a logical AND operation. If you need to change the mode of a file, use chmod function.

```php
<?php
printf("%o", (fileperms("data.txt") & 0777));
?>
```

## integer filesize(string filename)

The filesize function returns the size of the given file in bytes.

```php
<?php
print(filesize("data.txt"));
?>
```

## string filetype(string filename)

The filetype function returns the type of the given file as a descriptive string. Possible values are block, char, dir, fifo, file, link, and unknown. This function is an interface to C's stat function, whose man page may be helpful in understanding the different file types.

```php
<?php
print(filetype("data.txt"));
?>
```

## boolean flock(integer file_handle, integer mode)

Use the flock to temporarily restrict access to a file. PHP uses its own system for locking, which works across multiple platforms. However, all processes must be using the same locking system, so the file will be locked for PHP scripts, but likely not for other processes.

The file_handle argument must be an integer returned by fopen. The mode argument determines others you obtain a lock that allows others to read the file (1), you obtain a lock that doesn't allow others to read the file (2), or release a lock (3). When obtaining a lock, the process may lock. That is, if the file is already locked, it will wait until it gets the lock to continue execution. If you prefer, you may turn off locking modes 5 and 6. Table 8.5 lists the modes in a table.

| Table 8.5. flock Modes | |
| :--- | :--- |
| Mode | Operations Allowed |
| 1 | Allow reads |
| 2 | Disallow reads |
| 3 | Release lock |
| 5 | Shared lock |
| 6 | Exclusive lock |

## Core PHP Programming

```php
<?php
$fp = fopen("data.txt", "r");
flock($fp, LOCK_SH); // lock shared lock
echo "Hello World!";
flock($fp, LOCK_UN); // release lock
fclose($fp);

$fp = fopen("data.txt", "w+");
if (flock($fp, LOCK_EX | LOCK_NB)) { // lock exclusive lock
    fwrite($fp, "Hello World!");
    fflush($fp); // flush output before releasing lock
    flock($fp, LOCK_UN); // release lock
} else {
    echo "File could not be locked";
}
fclose($fp);
?>
```
