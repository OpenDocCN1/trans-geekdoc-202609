# Core PHP Programming

Given a valid file handle, gztell returns the offset of PHP's internal pointer.

```
<?php
// open a file
if!($myFile = gzopen("data.gz", "r")))
{
    print("file could not be opened");
    exit;
}

$myLine = gzgets($myFile, 255);
print($myLine);

print("<HR>\n") . " " . gztell($myFile) . " bytes";

// close file
gzclose($myFile);
?>
```

The gzwrite function is an alias to gzputs.

# integer readgzfile(string filename, boolean use_include_path)

The readgzfile function operates identically to the readfile function, except that it expects the file to be compressed. The file is uncompressed on the fly and sent directly to the browser.

```
<?php
// dump uncompressed contents of
//data.gz to browser
readgzfile("data.gz");
?>
```
