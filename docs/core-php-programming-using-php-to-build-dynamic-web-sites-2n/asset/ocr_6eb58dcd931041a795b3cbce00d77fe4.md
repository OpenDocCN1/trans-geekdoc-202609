Addition, subtraction, multiplication, and division are familiar concepts. Using a string with an arithmetic operator causes the string to be converted to integers or doubles. Modulo division returns the integer remainder of a division. The - operator may also be used to swap the sign on a number or variable.

The increment and decrement operators are shorthand for adding or subtracting 1 from a variable. You might remember that we used it in Listing 2.3 inside the for loop. You may put an increment or decrement operator before or after a variable. If the variable is within an expression, you will get one of two behaviors. If an increment operator precedes the expression; the variable will be incremented prior to evaluation of the expression; the variable isn't updated until the value of the expression is computed. Listing 2.7 demonstrates this concept.

# Listing 2.7 Comparing Preincrement to Postincrement

```
$VisitorsToday = 1;

// prints 1
print($VisitorsToday++);

// VisitorsToday is now 2
print("<BR\n");

// prints 3
print(++VisitorsToday);

print("<BR\n");
```

In this first statement VisitorsToday still contains the value 1 when it is printed, because the increment operator isn't applied until the expression is evaluated. In the third print statement VisitorsToday is incremented before the expression is evaluated; therefore 3 is set to the browser.
