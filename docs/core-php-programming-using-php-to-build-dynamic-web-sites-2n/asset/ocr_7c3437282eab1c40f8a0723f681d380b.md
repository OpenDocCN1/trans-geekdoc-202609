# string msql_error()

Use msql_error to retrieve the last error message returned by an mSQL function. See msql_drop_db, above, for an example of use.

# array msql_fetch_array(integer result, integer type)

The msql_fetch_array function returns an array of the data for the current row. The result argument is returned as msql_query. By default, result columns are returned in two elements: one referenced by number and one referenced by field name. The optional type argument controls which elements are created. MSQL_NUM signals that only numbered elements are created. MSQL_ASSOC signals that only named elements are created. If you want both, you can explicitly request it with MSQL BOTH.

Compare this function to msql_fetch_row and msql_fetch_object.

```
?
$Link = msql_connect("msql.clearink.com");
msql_select_db("store", $Link);

$Query = "SELECT * FROM customer";
$Result = msql_query($Query, $Link);

//fetch each row
while($Row = msql_fetch_array($Result, MSQL_ASSOC)) {
    print($Row["FirstName"] . "<BR>\n");
}
msql_close($Link);
```
