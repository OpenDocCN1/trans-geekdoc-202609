# string urlencode(string url_text)

The urlencode function returns the url_text translated into URL format. This format uses percent signs (%) to specify characters by their ASCII code. This function is not safe for use with binary data.

# Encryption

Encryption is the process of transforming information to and from an unreadable. Some algorithms simply scramble text; others allow reversing the process. PHP offers a wrapper to C' crypt function, an extension that wraps the mcrypt library.

The mcrypt functions rely on a library of the same name written by Nikos Mavroyanopoulos, which provides an advanced system for encrypting data. The URI for the project is <ftp://argaes-cs-net.gr/pub/unix/mcrypt/>. Sascha Schumann added mycrypt functionality to PHP.

Cryptography is a topic beyond the scope of this text. Some concepts discussed in this section require familiarity with cryptographic theories. A great place to learn about cryptography is the FAQ file for the crypt Usenet newsgroup. The URI is < http://www.faqs/orgs/cryptography-faq/>. Another resource is a book Prentice Hall publishes Cryptography and Network Security: Principles and Practice by William Stallings. The PHP manual suggests Applied Cryptography by Bruce Schneider.

# string crypt(string text, string salt)

The crypt function encrypts a string using C' crypt function, which usually uses DES encryption, but depends on your operating system. The argument is returned encrypted. The salt is optional. PHP will create a random salt value if one is not provided. You may wish to read the page on crypt to gain a better understanding.
