# **integer strcspn(string text, string set)**

The strcspn function returns the position of the first character in the text argument that is part of the set argument. Compare this function to strcspn.

```
<?php
$text = "red cabbage";n$set = "abc";n$position = strcspn($text, $set);

// prints 'red '
print(substr($text, 0, $position));
?>
```
