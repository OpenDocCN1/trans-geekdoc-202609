# object apache_lookup_uri(string uri)

The apache_lookup_uri function evaluates a URI, or Universal Resource Identifier. This function is a wrapper and returns an object containing properties describing the URI. This function is for a function that's part of the Apache Web Server's API: sub_req_lookup_uri. Consequently, you must running PHP as an Apache module in order to use this function. The exact meaning of most of the returned object's properties is beyond this text. They mirror the properties of Apache's request_rec structure. The sub_req_lookup_uri function is contained in Apache's http_request.c source file, and the contents may satisfy the truly curious.

# string apache_note(string name, string value)

The apache_note function allows you to fetch and set values in Apache's note table. The current value of the named entry is returned. If the optional value argument is present, then the value of the entry will be changed to the supplied value. The notes table exists for the duration of the request made to the Apache Web Server and is available to any modules activated during the request. This function allows you to communicate with other Apache modules. One possible use of this functionality is the passing of information to the logging module.

Like apache_lookup_uri, the apache_note function deals with records inside the Apache API. And like apache_lookup_uri, this function is available only when PHP is run as an Apache module. This function is a wrapper for the table_get and table_set functions that are part of the Apache API.

```php
<?php
apache_note("session_id", $session_id);
?>
```

# array getallheaders()

The getallheaders function returns every header sent by both the server and the browser. Some of these are PHP script. are then turned into environment variables, which are made available as variables inside your PHP script. Since this function relies on the Apache API, it is available only when you run PHP as an Apache module.

# Aspell

The Aspell library is used to verify the spelling of a word. It is the result of an open source project run by Kevin Atkinson. The official Web site is http://metalab.unc.edu/aspell/. In order for PHP to use Aspell, the functions must be loaded as extension. At the time of this writing, no win32 extension exists for Aspell, so its functionality is available to UNIX users only. Mark Musone added Aspell to PHP.

# integer aspell_new(string dictionary, string personal_words)

Use aspell_new to load a dictionary into the system. An identifier is returned that must be used in subsequent calls to Aspell functions. The second argument is optional and specifies a personal dictionary.

```php
<?php
//create a test sentence
$text = "Thiss sentense haz some splling errors.";

//load dictionary
$aspell_link = aspell_new('english');

//tokenize sentence
for($word = strtok($text, ' '); $word != ''; $word = strtok(' ')) {
    //check for unrecognized words
    if(!aspell_check($aspell_link, $word)) {
        //try checking raw version
        if(!aspell_check_raw($aspell_link, $word)) {
            //word not recognized, get suggestions
            $suggestion = aspell_suggest($aspell_link, $word);

            print("<B>Unrecognized word:</B>\n$word<BR>\n");

                print("$word<BR>\n");
            }

}
?>
```

# boolean aspell_check(integer link, string word)

The aspell_check function returns true if the word argument is found in the dictionary specified by the link argument. This function attempts to trim extraneous characters before validating the spelling.

# boolean aspell_check_raw(integer link, string word)

This function behaves like aspell_check, except that it makes no attempt to trim extraneous characters.

# array aspell_suggest(integer link, string word)

The aspell_suggest function returns an array of spellings for a word. The link argument is an integer returned by the aspell_new function.
