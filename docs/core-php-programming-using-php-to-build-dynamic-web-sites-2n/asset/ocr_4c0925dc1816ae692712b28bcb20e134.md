
# sprintf(string format, ...)

The sprintf function operates identically to printf function, except instead of sending the assembled string to the browser, the string is returned. See the description of printf for a detailed discussion. This function offers an easy way to control the representation of numbers. Ordinarily PHP may print a double with no fraction

```
<?
$x = 3.00;

//print $x as PHP default
print($x . "<BR>\n");

//format value of $x so that
//it show it two decimals after
//the decimal point
$s = sprintf("%.2f", $x);
print($s . "<BR>\n");
?>
```
