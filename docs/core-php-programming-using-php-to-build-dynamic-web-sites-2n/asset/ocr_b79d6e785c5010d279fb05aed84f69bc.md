# Core PHP Programming

Theodbc_prepare function parses a query and prepares it for execution. A result identifier that may be passed toodbc_execute is returned. Preparing statements can be more efficient than having the driver repeat statements. This is usually the case where you have many rows to insert into the same table. To specify a value to be filled in, use a mark query.

```
// connect to database
$Connection = odbc_connect("store", "guest", "guest");

// prepare query
$Query = "INSERT INTO catalog (ID, Name, Price)";
$Query = "VALUES (?, ?, ?)";
$Result = odbc_prepare($Connection, $Query);

// insert
// 0, 2000 Calendar, 20.00
// 1, 2001 Calendar, 20.50
// 2, 2002 Calendar, 21.00
for($index=0; $index<2000; $index++) {
    $values[0] = $index-2000;
    $values[1] = "$index Calendar";
    $values[2] = 20.00 + (0.50 * ($index-2000));
}

odbc_execute($Result, $values);
```

# string odbc_result(integer result, string field)

Use odbc_result to get the value of a field for the current row. Fields may be referenced by number or name. If using numbers, start counting fields with 1. If you specify a field name, do not include the table name.

This function is affected by the settings controlled by odbc_binmode and odbc_longreadlen. An important fact to keep in mind is that while in most cases the value of the field will be returned, fields contain long data will be echoed to the browser instead. Use odbc_longreadlen to change this behavior.

```
// connect to database
$Connection = odbc_connect("store", "guest", "guest");

// execute query
$Query = "SELECT name, price";
$Query .= "FROM catalog";
```
