# Core PHP Programming

Use imagepslantfont to pitch the font forward and backwards. Sometimes this is referred as italics. The font identifier is an integer returned by imagesloadfont. The slant_factor operates similarly to the extension_factor in the imagepsextendfont. Values greater than one will cause the top of the font to pitch to the right. Values less than one will cause the top of the font to pitch to the left.

```
integer imagesloadfont(string filename)
```

Use imagesloadfont to load a PostScript font. A font identifier will be returned for use in the other PostScript functions. If the load fails, FALSE is returned. See imagepstext, below for an example.

```
array imagepstext(integer image, string text, integer font_identifier, integer size, integer foreground, integer background, integer x, integer y, integer spacing, integer double angle, integer antialias_steps)
```

The imagepstext function draws a string of text into an image using a PostScript font. The image argument is an integer returned by imagecreate or imagecreatefrompng. The font_identifier argument is a value returned by the imagesloadfont function. The size argument specifies the height in number of pixels. The foreground and background colors are identifiers. The x and y arguments specify the bottom-left corner where to begin. The spacing argument controls vertical spacing between lines of text. The letting argument controls horizontal spacing between characters. Both are expressed in units of 1/1000th of an em-square and are added to the default spacing or leading a font. They may be positive or negative. The angle argument specifies a number of degrees to rotate from normal left-to-right orientation. The antialias_steps argument how many colors to use when antialiasing, or smoothing. Two values are valid: 4 and 16. The last four arguments are optional.

The returned array contains two coordinates specifying the lower-left corner and upper-right corner of the bounding box, respectively.
