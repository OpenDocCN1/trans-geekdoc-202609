# array sybase_fetch_array(integer result)

The sybase_fetch_array function returns an array that contains the values of all the fields for the next row. Each call to sybase_fetch_array gets the next row in the result set, or returns FALSE if no rows remains.

Each field is returned in two elements. One is indexed by the field number, starting with zero. The other is indexed by the name of the field. Compare this function to sybase_fetch_object and sybase_fetch_row.
