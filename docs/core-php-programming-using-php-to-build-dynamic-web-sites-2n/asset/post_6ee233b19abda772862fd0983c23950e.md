**Listing 2.12** is a good test of how PHP will convert strings to numbers. All the commands will produce a number from the string, except the last. Since in the last line contains a letter, PHP gives up and treats it as zero. Notice that after the addition the script uses a concatenation operator. This causes the integer created inside the parentheses to be converted to a string for the purposes of printing. The concatenation operator forces both sides to be treated as strings.

**Listing 2.13** demonstrates the use of parentheses to force the order in which the expression is evaluated. The first line evaluates to 17, the second to 35. In addition to evaluation from left to right, operators execute in a specific precedence. For example, multiplication is resolved before addition.

A programming language must order all its operators, but in practice it is difficult for the programmer to keep it straight. The best policy is to use parentheses to explicitly force the precedence when complex expressions. Table 2.11 lists the operators in order of precedence. Operators on the same list are of equal precedence, therefore falling back to left-to-right precedence.

# Chapter 3. CONTROL STATEMENTS

Control statements allow you to execute blocks of code depending on conditions. They also allow you to allow you to repeat a block of code, which leads to simpler, more efficient scripts. This chapter will introduce you to the decision-making statements if and switch. You will also learn about loops for and while.

# True and False

As you remember from Chapter 2, PHP has the concepts of true and false. Zero and an empty string are considered to be false. Any numerical value or string is true. These concepts were discussed in regard to relational operators, but they are also used in control statements. Control statements like expect a boolean value, so any value they given will be converted to a boolean.

# The if Statement

Figure 3-1 lays out the form of an if statement.

> Figure 3-1. The form of an if statement.

```php
if(expression1)
    This block gets executed if expression1 is true.
elseif(expression2)
    This block gets executed if expression1
is is false and expression 2 is true.
else
    This block gets executed if both expression1
and expression2 are false.
```

The if statement executes a statement if the expression inside the parentheses evaluates to true; otherwise the code is skipped. It may be a single statement followed by a semicolon. Usually it's a compound statement surrounded by braces. An else statement may appear immediately after the statement and has a statement of its own. It, too, may be either single or compound. It is executed only when the previous statement is false. In between an if and else statement you may put as many elseif statements as you would like. Each elseif expression is evaluated in turn, and control skips those that are false. If an elseif statement evaluates to true, then the rest of the code in the greater if statement is skipped. That is to say, only one match will be made.

Listing 3.1 demonstrates an if-elseif-else statement.

Of course, you are not obliged to have an elseif or an else. Sometimes you might want to build a simple statement as in Listing 3.2.

You can use if to build a series of checks that covers all possible cases. Just start by checking for the first condition with an if; then check for each following condition with elseif. If you put an else at the end, you will account for all possible cases. Listing 3.3 uses this to print the day of the week in Germany. The script gets today's name and compares it to the days Monday through Saturday. If none of these match, it is assumed to Sunday.

# Listing 3.1 An if-elseif-else Statement

```php
<?
if($name == "")
{
    print("You have no name.");
}
elif($name == "leon") OR ($name == "Leon")
{
    print("Hello, Leon!");
}
else
{
    print("Hello, Leon!");
}
?>
```

# The ? Operator

PHP offers an abbreviated version of the if statement that borrows syntax from C. Figure 3-2 outlines the format.

> Figure 3-2. The ternary operator.

```php
conditional expression ? true : false
```

The ? operator can be confusing to read and is never necessary. On the other hand it allows you to write very compact code.

# The switch Statement

An alternative to if-else structures is the switch statement, which works on the assumption that you compare a single expression to a set of possible values. Figure 3-3 demonstrates the structure of the switch statement.

```php
switch(root-expression)
{
    case case-expression:
    default:
}
```

The root expression inside a switch statement is evaluated and then compared to each expression following a case statement. At the end of the list of cases you can put a default statement that works exactly like an else statement; it no other case matches.

A case statement serves as a starting point for execution. The root expression is compared to each expression until one matches. Each line of code that is executed. If another case statement is reached, it is ignored. Sometimes this is useful, but most often a break statement is used to escape from the switch statement.

# Listing 3.4 All Cases with switch

```php
<?php
// Get today's name
$english_Day = date("l");
// Find the today's German name
switch($english_Day)
{
    case "Monday":
        $deutsch_Day = "Montag";
        break;
    case "Tuesday":
        $deutsch_Day = "Dienstag";
        break;
    case "Wednesday":
        $deutsch_Day = "Mittwoch";
        break;
    case "Thursday":
        $deutsch_Day = "Donnerstag";
        break;
    case "Friday":
        $deutsch_Day = "Freitag";
        break;
    case "Saturday":
        $deutsch_Day = "Samstag";
        break;
    default:
        $deutsch_Day = "Sonntag";
        break;
}
print($deutsch_Day);
?>
```
