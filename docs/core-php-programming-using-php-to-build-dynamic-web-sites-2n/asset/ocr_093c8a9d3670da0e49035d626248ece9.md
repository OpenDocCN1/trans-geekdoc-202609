# string toupper(string text)

The toupper function returns the text argument with all letters changed to uppercase. Other characters are unaffected. Locale affects which characters are considered, and you may find letters with accents and umlauts are ignored. You may overcome this by using setlocale, discussed in Chapter 11.

```
<<?n  print(toupper("Hello World"));
?>
```

# string strtr(string text, string original, string translated)

When passed arguments, the strtr function returns the argument with characters matching the second argument changed to those in the third argument. original and translated aren't the same length, the extra characters are ignored.

At the time of writing a secure prototype for strtr was being planned that allows you to pass two arguments. The second argument must be an associative array. The indices specify strings to be replaced, and the values replacement text. If a substring matches than one index, the longer substring will be used. The process is iterative. Once, substrings are replaced, they are not further matched.

This function is safe to use with binary strings.

```
<<?n  $text = "Wow! This is neat.";
  $original = "!\";"
```
