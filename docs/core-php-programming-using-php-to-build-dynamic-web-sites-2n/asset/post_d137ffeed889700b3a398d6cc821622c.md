# integer imap_open(string mailbox, string username, string password, integer flags)

Use imap_open to begin a connection. The mailbox is usually formed with curly braces. Adding /pop causes the imap_open to connect to the POP server instead of IMAP server. The optional flags argument is a bitfield that uses constants listed in Table 14.8.

| Table 14.8. Constants Used by imap_open. | Description |
| :--- | :--- |
| ANONYMOUS | Don't use |
| DEBUG | Debug |
| EXPUN | Expunge |
| HALFOPEN | Open not delete |
| PROTOTYPE | Return prototype |
| READONLY | Open read-only |
| SECURE | Use secure |
| SHORT | Use short |
| SILENT | Don't use |

```php
<?php
$mailbox = imap_open("{mail.server.com}INBOX",

?>
```
