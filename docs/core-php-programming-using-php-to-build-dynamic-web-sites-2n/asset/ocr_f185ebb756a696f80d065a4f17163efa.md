# Core PHP Programming

The ocibindname function binds an Oracle placeholder to a PHP variable. You must supply a valid statement identifier as created by ociparse, the name of the placeholder, a reference to a PHP variable, and the maximum length of the bind data. You may use a value of -1 to use the length of the variable as the variable argument.

The optional type argument specifies a data type and is necessary if you wish to bind to an abstract data type. Use one of the following to set the data type: OCI_BLOB, OCI_CFILE, OCI_CLOB, OCI_B_FILE, OCI_BROWID. Make sure you use ocidewdescriptor for binding to an abstract data type. You also need to use -1 for the length argument.
