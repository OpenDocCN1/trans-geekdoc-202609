# double atan(double value)

The atan function returns the arc tangent of the value argument.

```
<?n// print asin values from -1 to 1
print("<TABLE ORDER=\"1\>\n");
print("<TR><TH x="x"></TH><atan(x)</TH></TR>\n");

for($index = -1; $index >= 1; $index += 0.25) {
    print("<TR>\n");
    print("<<td>\$index</TD>\n");
    print("<td>" . atan(\$index) . "</TD>\n");
    print("<TR>\n");
}

print("<TABLE>\n");
?>
```

# double atan2(double x, double y)

The atan2 function returns the angle portion in radians of the polar coordinate specified by the Cartesian coordinates.

```
<?n//print 0.40489178628508
print(atan2(3, 7));
?>
```
