# integer get_magic_quotes_runtime()

The get_magic_quotes_runtime function returns the magic_quotes runtime directive, which controls whether quotes are escaped automatically in data retrieved from databases. You can use set_magic_quotes_runtime to change its value.

```
<?
if(get_magic_quotes_runtime() == 1)
{
    print("magic_quotes_runtime is on");
} else
{
    print("magic_quotes_runtime is off");
}
?>
```

# string get_parent_class(object variable)

The get_parent_class function returns the name of the parent class for an object.

```
<?
class animal
{
    var $name;
}
class dog extends animal
{

$gus = new dog();
$gus->name = "Gus";
//Gus is of type dog, which is of type

?>
```
