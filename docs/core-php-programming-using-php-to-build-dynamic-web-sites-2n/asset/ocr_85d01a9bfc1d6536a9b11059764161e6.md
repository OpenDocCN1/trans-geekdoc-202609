# Listing 4.5 Using unset with a Default Argument

![](bbox=[0.217, 0.316, 0.453, 0.477])

```
<?
function myPrint($text, $size=NULL)
{
  if(isset($size))
    print("<FONT SIZE=\$size\>$text</FONT>");
  else else {
    print($text);
  }
}
myPrint("Test");
print("<BR\n");

myPrint("Test", 5);
print("<BR\n");
?>
```
