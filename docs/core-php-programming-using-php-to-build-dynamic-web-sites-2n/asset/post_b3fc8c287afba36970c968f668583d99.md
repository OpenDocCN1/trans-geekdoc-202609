# Listing 18.6 Sending Attachments

```php
<?php
/**
** Function: makeAttachment
** Input: ARRAY attachment
** Output: STRING
** Description: Returns headers and data for one
** attachment. It expects an array with elements
** type, name, and content. Attachments are naively
** base64 encoded, even when unnecessary.
*/
function makeAttachment($attachment) 
{
    //send content type
    $headers = "Content-Type: " . $attachment["type"];

    if($attachment["name"] != "") {
        $headers = "; name=\"" . $attachment["name"] . "\"";
    }

    $headers .= "\r\n";

    $headers .= "Content-Transfer-Encoding: base64\r\n";

    $headers .= "\r\n";

    $headers .= chunk_split(base64_encode($attachment["content"]));
    $headers .= "\r\n";

    return($headers);
}
```

The mail function assembles the parts that make up a MIME message. These parts are sent in the fourth argument of the mail function, which is generally used for headers. In the case of a MIME message, this is used for both headers and attachments. After sending the customary From headers, a MIME-Version header is sent. Unless only one attachment, a boundary string must be created. This is used to divide attachments from one another. Another way is to avoid using a boundary value that might appear in the image, so we use the uniqid function.

Each attachment is surrounded by the boundaries with two dashes. The attachment is prepared by the makeAttachment function. Each attachment requires Content-Type and Content-Transfer-Encoding headers. The type of content depends on the attachment. If an image file is being sent, it might be the image/jpg. These are the same codes discussed above with the HTTP protocol. For the sake of simplicity, this function always encodes attachments using base64, which can turn binary files into 7-bit ASCII. This prevents them from being corrupted as they travel through the network. As you might imagine, text files do not require encoding, and complete implementations encode attachments based on content type.

It may be instructive to see the assembled message in full. Try sending a message. On a UNIX operating system, you should be able to peek at the file inside /var/spool/mail before reading it, or perhaps inside ~/Mail/received afterward.

# Verifying an Email Address

It doesn't take much experience with email to discover what happens when it is misdirected. The email is returned to you. This is bounced email. Consider for a moment Web that allows users to fill out a form that includes an email address and sends a thank-you message. Many people will mistakenly type their addresses or purposely give a bad address. You can check the form of the address, of course, a well-formed address can fail to match a real mail box. When this happens, the mail bounces back to the user who sent the mail. Unfortunately, this is probably the Web server itself.

Reading through the bounced email can be interesting. An e-commerce site may be concerned about order confirmations that go undelivered.

# Listing 18.7 Verifying an Email Address

```php
/**
** Function: verifyEmail
** Input: address, error
** Output: BOOLEAN
** Description: Attempts to verify an email address by
** contacting a mail exchanger. Registered mail
** exchangers are requested from the domain
first, then the exact domain itself. The error argument would
** contain relevant text if the address could not
** verified.
 */

function verifyEmail($address, &$error)
{
    global $SERVER_NAME;

    list($user, $domain) = explode("@", $address, 2);

    //make sure the domain has a mail exchanger
    if(!checkdnsrr($domain, "MX")) {
        $error = "No MX records found for domain";
        return FALSE;
    }

    $fp = fsockopen($domain, 25, $errno, $errstr, 10);
    if(!$fp) {
        $error = "Could not connect to mail server";
        return FALSE;
    }

    $stopTime = time() + 10;
    $gotResponse = FALSE;

    while (TRUE)
    {
        //try to get a line from mail server
        $line = fgets($fp, 1024);

        if(substr($line, 0, 3) == "220")
        {
            //reset timer
            $stopTime = time() + 10;
            $gotResponse = TRUE;
        } elseif(($line == "") AND ($gotResponse))
        {
            break;
        } elseif(time() > $stopTime)
        {
            break;
        }
    }

    if(!$gotResponse)
    {
        $error = "Server did not respond";
        fclose($fp);
        return FALSE;
    }

    set_socket_blocking($fp, TRUE);

    //sign in
    fputs($fp, "HELO $SERVER_NAME\r\n");
    gets($fp, 1024);

    //set from
    fputs($fp, "MAIL FROM: <info@domain>\r\n");
    gets($fp, 1024);

    //try address
    fputs($fp, "RCPT TO: <$address>\r\n");
    $line = fgets($fp, 1024);

    if(substr($line, 0, 3) == "250") {
        fclose($fp);
        return TRUE;
    } else {
        $error = "Recipient rejected";
        fclose($fp);
        return FALSE;
    }
}
```
