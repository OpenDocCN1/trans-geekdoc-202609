# Core PHP Programming

The ibase_commit function commits the default transaction on the specified link, or the last link if none is specified.

# ibase_connect(string path, string user, string
password))

Use ibase_connect to connect to an InterBase database. You must specify a path to database file. The user and password arguments may be omitted. They default to those set in php.ini using ibase_default_user and ibase_default_password directives.

A connection identifier is returned by most of the other functions in this section. When the connection will be closed for you, but you can close it manually with ibase_close. A second connection to the same database as the same user will return the same connection identifier.

Compare this function to ibase_pconnect.

# ibase_errmsg()

Use ibase_errmsg to get the last error message. FALSE is returned when no error message is available.

# ibase_execute(integer query, value bind, ...)

Use ibase_execute to execute a query prepared with ibase_prepare. If the query contained ? placeholders, you must supply binding bind values following the query identifier. A result identifier is returned if executing a select query.

# ibase_fetch_object(integer result, integer blob)

The ibase_fetch_object function returns an object that contains a property for each column in the next result. The name of the property will match the name of the column. The blob argument is optional. If it is set to IBASE_TEXT, blob columns will be returned as text. Otherwise the blob identifier is returned. FALSE is returned when no rows remain.

# ibase_fetch_row(integer result, integer blob)

The ibase_fetch_row function operates identically to ibase_fetch_object except that an array is returned. Instead of being referenced by name, columns are referenced by number, starting with 0.
