### integer odbc_fetch_into(integer result, array fields)
odbc_fetch_into(integer result, integer row, array fields)

The odbc_fetch_into function gets the specified row for the specified result set and puts the columns into the fields array. The fields must be passed by reference. The number of columns in the result set is returned. The row argument may be omitted, in which case the next row in the set is returned.

```php
// connect to database
$Connection = odbc_connect("store", "guest", "guest");

// execute query
$Query = "SELECT name, price";
$Query .= "FROM catalog";
$Result = odbc_do($Connection, $Query);

while (odbc_fetch_into($Result, &$fields)) {
	$name = $fields[0];
	$price = $fields[1];
	print("$name: $price<BR>\n");
}

odbc_close($Connection);
```

### boolean odbc_fetch_row(integer result, integer row)

Use odbc_fetch_row to get a data from a result set. The data for the row is stored in internal memory, to be retrieved with the odbc_result function. The row argument is optional and, if left out, the next available row will be returned. FALSE will be returned when there are no more rows in the result set. See the odbc_result function for an example of use.

### integer odbc_field_len(integer result, integer field)

Use odbc_field_len to get the length of a field in a result set. Fields are numbered starting with one.

### boolean dbc_free_result(integer result)

Use dbc_free_result to free the memory associated with the result set. This is not strictly necessary, but it's a good idea if you are worried about running out of memory. If autocommit is disabled and you free a result set before calling dbc_commit, the transaction will be rolled back.

```php
<?php
// connect to database
$Connection = dbc_connect("store", "guest", "guest");

// execute query
$Query = "SELECT name, price ";
$Query = "FROM catalog";
$Result = dbc_do($Connection, $Query);

// free the result set
dbc_free_result($Result);

dbc_close($Connection);
?>
```

### boolean dbc_longreadlen(integer result, integer length)

Use dbc_longreadlen to set the maximum length for values of any columns of type long. This handles binary columns as longbinary. By default the maximum length is zero, which has the special meaning of causing fetched columns to be echoed to the browser. Any other positive number will cause returned values to be truncated to the specified length.

Note that it is not always perfect that a field is considered to be a long by the ODBC driver. For example a memo column in Microsoft Access is a long. Data appearing in the wrong place are a sign of fetching a long where you didn't expect it. One strategy to avoid these problems is to always dbc_longreadlen.

See dbc_binmode for an example of use.

### integer odbc_pconnect(string dsn, string user, string password)

The odbc_pconnect returns the number of rows in the set. The odbc_pconnect function operates similarly to odbc_connect. odbc_pconnect(DSN, user, password) returns a connection. The connection should be closed with odbc_close in the case where you have many rows.

```php
// connect to database
$Connection = odbc_connect("store", "guest", "guest");

// execute query
$Query = "SELECT name, price ";
$Query .= "FROM catalog";
$Result = odbc_do($Connection, $Query);
```

### integer odbc_prepare(integer connection, string query)

The odbc_prepare function parses a query and prepares it. The number of rows returned is by the driver. Preparing statements can be more efficient than having to execute them. The odbc_prepare is used when you need to insert into the table.

```php
// connect to database
$Connection = odbc_connect("store", "guest", "guest");

// execute query
$Query = "SELECT name, price ";
$Query .= "FROM catalog";
$Result = odbc_do($Connection, $Query);
```

### integer odbc_execute(integer result)

The odbc_execute executes a prepared statement. The number of rows affected is by the driver. The odbc_execute is used when you need to insert into the table.

```php
// connect to database
$Connection = odbc_connect("store", "guest", "guest");

// execute query
$Query = "SELECT name, price ";
$Query .= "FROM catalog";
$Result = odbc_do($Connection, $Query);
```

### string odbc_result(integer result, string field)

Use odbc_result to get the value of a field for the current row. Fields may be referenced by number or name. If using numbers, start counting with 1. This function is affected by the settings controlled by odbc_binmode and odbc_longreadlen. An important fact to keep in mind is that in most cases long data will be echoed to the browser. Use odbc_longreadlen to change this behavior.

```php
// connect to database
$Connection = odbc_connect("store", "guest", "guest");

// execute query
$Query = "SELECT name, price ";
$Query .= "FROM catalog";
$Result = odbc_do($Connection, $Query);
```

### integer odbc_result_all(integer result, string format)

The odbc_result_all function will dump all the rows for a result is returned. The number of rows will be formatted in a table. The field names will be printed in a header row with TH tags. The optional format argument will be inserted inside the initial table tag that you may set table attributes.

```php
<?php
// connect to database
$Connection = odbc_connect("store", "guest", "guest");

// execute query
$Query = "SELECT name, price ";
$Query .= " FROM catalog";
$Result = odbc_do($Connection, $Query);

// dump all results
odbc_result_all($Result, "BORDER=1");

odbc_close($Connection);
?>
```

### boolean odbc_rollback(integer connection)

Use odbc_rollback to abandon all pending transactions. By default all queries are automatically committed, but this behavior may be modified with odbc_autocommit. Not all databases support transactions.

```php
<?php
// connect to database
$Connection = odbc_connect("store", "guest", "guest");

// turn off autocommit
odbc_autocommit($Connection, FALSE);
```
