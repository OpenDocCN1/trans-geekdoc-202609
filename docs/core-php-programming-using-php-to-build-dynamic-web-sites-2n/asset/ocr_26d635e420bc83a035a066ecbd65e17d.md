# Core PHP Programming

gets the next row in the result set, or returns FALSE if no rows remain. Compare this function to sybase_fetch_array and sybase_fetch_object.

```
<?php
//connect
$Link = sybase_pconnect();

//use the store database
sybase_select_db("store", $Link);

//get all items
$Result = sybase_query("SELECT * FROM item");

print("<TABLE ORDER=\"1\">\n");

//get rows
while($Row = sybase_fetch_array($Result)) {
    print("<TR>\n");
    print("<TD>" . $Row[0] . "</TD>\n");
    print("<TD>" . $Row[1] . "</TD>\n");
    print("</TR>\n");
}

print("</TABLE>\n");
?>
```

# boolean sybase_field_seek(integer result, integer field)

The sybase_field_seek function moves the internal field pointer to the specified field. Fields are numbered starting with zero. If you leave out the field argument, the internal pointer will be moved to the next field. This is the same internal pointer used by sybase_fetch_field.

```
<?php
// go back to first field
sybase_field_seek($result, 0);
?>
```
