# Core PHP Programming

The is file function returns true if the given filename is neither a directory nor a symbolic link; otherwise it returns false. Similar functions are is_dir and is_link.

```
@CPO # above?
$filename = "data.txt";

if(is_file($filename)) {
    print("$filename is a file");
} else {
    print("$filename is not a file");
}?>
```
