# double cos(double angle)

The cos function returns the cosine of an angle expressed in radians.

```
<?php
//prints 1
print(cos(2 * pi()));
?>
```

# string decbin(integer value)

The decbin function returns a binary representation of an integer as a string.

```
<?php
//prints 1111111
print(decbin(255));
?>
```

# string dehex(integer value)

The dehex function returns the hexadecimal representation of the value argument as a string.

```
<?php
//prints ff
print(dehex(255));
?>
```
