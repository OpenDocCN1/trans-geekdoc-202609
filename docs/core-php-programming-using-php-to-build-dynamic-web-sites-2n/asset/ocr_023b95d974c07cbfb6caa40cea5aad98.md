PHP implements IMAP 4, the latest incarnation described in RFmessagesC 1730. More information may be obtained at <http://www.imap.org/>, the IMAP Connection.

IMAP support may be compiled directly into PHP or loaded as an extension. The extension has benefited from the work of many authors: Kaj-Michael Lang, Rasmus Lederford, Rex Logan, Mark Musone, Antoni Pamies Olive, Zeev Suraski, and Brian Wang.

# string imap_bit(string text)

The imap_bit function converts an 8-bit string into a quote-printable string.

```
<
  $qtext = imap_bit($text);
?>
```

# array imap_alerts()

The imap_alerts function returns all the alerts generated by IMAP functions as an array and clears the stack of alerts.

# integer imap_append(integer stream, string mailbox, string message, string flags)

The imap_append function appends a message to a mailbox. The stream argument is an integer returned by imap_open. The flags argument is optional.

```
<
```
