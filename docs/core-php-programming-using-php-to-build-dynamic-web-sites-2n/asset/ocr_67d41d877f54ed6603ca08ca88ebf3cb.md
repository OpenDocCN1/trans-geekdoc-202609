Use ociserverion to get a string describing the version of the server for a connection.

integer ocisetprefetch(integer statement, integer size)

The ociprefetch function sets the size of the buffer that Oracle uses to prefetch results into. The size will be multiplied by 1024 to set the number of bytes.

# string ocistatype(integer statement)

Use ocistatype to get a string that describes the type of the statement. The types you can expect are ALTER, BEGIN, CREATE, DECLARE, DELETE, DROP, INSERT, SELECT, UNKNOWN, and UPDATE.

# boolean ora_bind(cursor, string variable, string parameter, integer length, integer type)

The ora_bind function binds a PHP variable to a parameter in an Oracle query. This causes data to flow between the two entities. You must call ora_parse before binding any variables. The type parameter is optional. It specifies whether data may go into out of the Oracle parameter. By default, data may go both ways. The type may be defined using the following constants: ORA_BIND_IN, ORA_BIND_INOUT, ORA_BIND_OUT.
