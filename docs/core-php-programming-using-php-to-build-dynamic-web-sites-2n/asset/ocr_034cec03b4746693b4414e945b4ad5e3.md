# integer pclose(integer file_handle)

The pclose function closes a file stream opened by popen. The return value of the process called in the call to popen is returned.

# integer popen(string command, string mode)

The popen function opens a pipe to an executing command that may be read from or written to as if it were a file. A file handle is returned that is appropriate for use with functions such as fgets. Pipes work in one direction only, which means you can't use update modes with popen.

When you open a pipe, you are executing a program in the local filesystem. With the other functions that execute a command (exec, passthru, and system), you should consider both the high cost of starting a new process and the security risk if user input is included in the command argument. If you must pass user-supplied data to a command, pass the information through the escapeshellcmd command function.

```
/*
 ** see who's logged in
 */
$myPipe = popen("who", "r");

while(!feof($myPipe))
{
  print(nl2br(fgets($myPipe, 255)));
}

pclose($myPipe);
?>
```
