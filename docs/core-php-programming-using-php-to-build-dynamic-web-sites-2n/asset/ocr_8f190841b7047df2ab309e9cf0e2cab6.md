# Network I/O

The network I/O functions send information directly over the Internet Protocol, or they
fetch information over Internet hosts.

# boolean checkdnsnsr(string host, string type)

The checkdnsnsr function checks DNS records for a host. The type argument defines the
type of records to search. Valid types are listed in Table 8.16.

If type is not specified, checkdnsnsr checks MX records. You may wish to read the
man page for name, the Internet domain name server daemon.

```
?
if(checkdnsnsr("clearink.com", "MX")
{
  print("clearink.com is a mail exchanger");
}
?>
```

# integer fsockopen(string hostname, integer port, integer error_number, string error_description, double timeout)

The fsockopen begins a network connection as a file stream, returning a file descriptor
suitable for use by fputs, fgets, and other file-streams discussed earlier in this
chapter. A connection is attempted to the hostname at the given port. The hostname
al also be a numerical IP address. The hostname may be the path to a UNIX domain
socket, in which case port should be set to 0. Some operating systems, specifically
Windows, do not support UNIX domains.
