# Loops

Loops allow you to repeat lines of code based on some condition. You might want to repeat lines from a file until the end is reached. You might want to print a section of HTML code exactly ten times. You may even wish to attempt to connect to a database three times before giving up. You can do all of these with loops.

# The while Statement

The simplest of loops is the while statement. When first reached, the expression is evaluated. If false, the block is skipped. If true, the block is executed and control returns to the top again, the expression is evaluated. Figure 3-4 shows the structure of a while statement.

Figure 3-4. The while statement.

```
while(expression)
{
  Zero or more statements
}
```

A while loop is useful when you're not sure how many times you will need to iterate through the code—for example, when reading lines from a file or fetching rows from a database query. For the sake of a simple demonstration, let's examine some code that prints the days of the week between now and Friday.

But if the current date is not a Friday, a list item with the name of the day is printed and `currentDate` is advanced 24 hours. At that point, the end of the code block is reached, so control jumps back to the beginning of the loop.

# The break Statement

When a break statement is encountered, execution jumps outside the innermost loop or switch statement. You've seen that this is essential to the usefulness of switch statements. It also has some application for loops. There are cases when you need to leave a loop break in the middle. Listing 3.6 shows this in action.

# Listing 3.6 Leaving a Loop Using break

```php
<?php
while(true)
{
    print("This line is printed.");
    break;
    print("This line will never be printed.");
}
?>
```

# The continue Statement

The continue statement is similar to the break statement except that of stopping the loop entirely, only the current execution of the loop is stopped. Control is returned to the closing curly brace and the loop continues. For loops, described below, increments will occur just as if control reached the end of the loop otherwise.

As you might imagine, this function is used to skip parts of a loop when a condition is met. Listing 3.7 demonstrates this idea. Random numbers are generated inside a loop until ten numbers, greater than the previous, are produced. Most of the time the body of the loop is skipped due to the if statement that triggers a continue statement.

# The do...while Statement

You can rely the decision to continue executing a loop until the end by using a do...while statement. Listing 3.8 retools Listing 3.7. You will notice a difference unless you run the script on a Friday. On the Fridays it will print nothing in its list of days. The new version will put Friday in the list because the body of the loop is executed before the condition is tested.

# Listing 3.8 Using do...while to Print Day Names

```php
<?
/*
 ** get the current date in number of seconds
*/
$currentDate = time();
/*
** print some text explaining the order
*/
print("Days left before Friday:\n");
print("<OL>\n");
do {
    /*
    ** print day name
    */
    print("<LI>". date("l", $currentDate) . "\n");
    ** add 24 hours to currentDate */
    $currentDate += (60 * 60 * 24);
} while (date("l", $currentDate) != "Friday");
print("</OL>\n");
?>
```

# The for Statement

Strictly speaking, the for statement is unnecessary. Any for loop can be implemented as easily as a while loop. What for offers no new functionality, but it puts all the information needed for running the loop in one place. Figure 3-5. The for statement.

```
for(initialization; continue; increment)
{
  Zero or more statements
}
```

When first encountered, the initialization statement is executed. This traditionally takes the form of assigning a variable to 0. Then, as with a while statement, the boolean expression is evaluated. If false, control jumps to just after the block. Otherwise, the block is executed. Before the boolean expression is evaluated again, the increment statement is executed.

Imagine that you wanted to step through the numbers 1 through 10. Using while, you would first set a variable to 1. Then you would test if your counter is less or equal to 10. And the value is incremented each time the loop.

Most loops like Listing 3.9. They use a counter that increments by one each time through the loop. However, the for statement is not particular about what you put in the three slots. The initialization allows a comma-separated list of assignments. This can be used to assign values to two or more variables. You may also leave a slot blank.

# Listing 3.9 A Typical for Loop
