# Core PHP Programming

Use function_exists to test that a function is available, either natively or defined previously by PHP code.

```
<?php
$function = "date";
if (function_exists($function)) {
    print($function . " exists");
}?>
```

# object get_browser(string user_agent)

The get_browser function works with the browsercap.ini (browser capabilities) file to report the capabilities of a browser. The user_agent argument is the text browser identifies with during an HTTP transaction. If you leave out this argument, PHP uses HTTP_USER_AGENT, a variable created by PHP for you. The argument is matched against all the browsers in the browsercap.ini file When a match occurs, each of the capabilities becomes a property in the returned object.

The location of the browsercap.ini file is specified in php.ini using the browsercap directive. If the directive is not used, or PHP can't match a browser to an entry in your browsercap.ini file, However, the returned object will have no properties.

Microsoft provides a browsercap.ini file for use with its Web server, but it is not freely distributable. PHP has an official browsercap.ini file. It may be found at <http://php.netvision.net.ill/> and depends on contributions. At the time of this writing, it appeared to be abandoned. Alternatively, you may wish to get a browsercap.ini from Web developer CySpace <http://www.cyspace.com/asp/browsercap/>. Be aware you must register first.

```
<?php
$browser = get_browser();
print("You are using " . $browser . "<BR\n");
if ($browser->javascript) {
    print("Your browser supports JavaScript.<BR\n");
}?>
```
