# integer mysql_list_tables(string database, integer link)

The mysql_list_tables function returns a result identifier as the database was queried with mysql_query. For any of the functions for fetching rows or fields may be used to get the names of the fields. The link argument is optional. If left out, the last-opened connection will be used.

```
?
$Link = mysql_connect("mysql.clearink.com");
mysql_select_db("store", $Link);
$Result = mysql_list_tables("store", $Link);
while($row_array = mysql_fetch_row($Result)) {
    print($row_array[0]) . "<BR\n";
}
mql_close($Link);

```

# integer mysql_num_fields(integer result)

Use mysql_num_fields to get the number of fields in a result set.

```
?
$Link = mysql_connect("mysql.clearink.com");
mysql_select_db("store", $Link);
$Query = "SELECT FROM item i, SKU s ";
$Query .= "WHERE 1.SKU = s.ID";
$Result = mysql_query($Query, $Link);

print(mysql_num_fields($Result));
mql_close($Link);

```
