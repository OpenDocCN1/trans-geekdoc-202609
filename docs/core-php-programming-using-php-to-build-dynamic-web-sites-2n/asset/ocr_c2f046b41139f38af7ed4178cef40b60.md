# Sorting with a Comparison Function

The built-in sort functions are appropriate in the overwhelming majority of situations. If your problem requires a sort that performs better than the one in the built-in functions, you are faced with coding your own. If your problem is that you need to compare complex elements, as objects or multidimensional arrays, the solution is to write a comparison function and plug it into the usort function.

The usort allows you to sort an array using your own comparison function. Your comparison function must accept two values and return an integer. The two arguments are compared, and if a negative values is returned, then the values are considered to be in order. If zero is returned, then the values are equal. A positive number signifies that the numbers are out of order.

The byName function is a simple wrapper for strcmp. Names are ruled by ASCII code. The byTitle function assigns an integer value to each title and then returns the comparison of these integers.
