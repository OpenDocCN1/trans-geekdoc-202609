# Core PHP Programming

```
<?php
$Link = mysql_connect("msql.clearink.com");
msql_select_db("store", $Link);

$Query = "SELECT * FROM item i, s "
$Query .= "WHERE i.SKU = s.ID"
$Result = msql_query($Query, $Link);

$numRows = msql_num_rows($Result);

for($index = 0; $index < $numRows; $index++) {
    $item_ID = msql_result($Result, $index, "item.ID");
    $item_Name = msql_result($Result, $index, "item.Name");

    print("$item_ID: $item_Name<BR>\n");
}

mql_close($Link);
?>
```

# boolean msql_select_db(string database, integer link)

Use mysql_select_db to select the database against which to make queries. As with most mysql functions, the link identifier is not required.

# MySQL

MySQL is a relational database with a license that allows you to use it cost-free for most noncommercial purposes. It shares many features with MySQL because it was originally conceived as a faster, more flexible replacement. Indeed, MySQL has delivered on its goals. It easily outperforms commercial databases. Surprisingly, MySQL is the database of choice for many PHP developers.

To find out about MySQL, as well as obtain source code and binaries, visit the Web site at <http://www.mysql.com/>. There are plenty of mirrors to aid your download speed. Be sure to check out the online manual.

As with mysql, were MySQL functions in PHP2 that are still supported in PHP3, but their use is discouraged. I've chosen to leave these out of the reference. The functions I've left out are mysql, mysql_create atedb, mysql_dbname, mysql_dropdb, mysql_fieldflags, mysql_field-len, mysql_fieldname, mysql_fieldtable, mysql_fieldtype, mysql_freeserult, mysql_listdb, mysql_listfields, mysql_listtables, mysql_numfields, mysql_numrows, mysql_selectdb, mysql_tablename.

The MySQL extension was written by Zeev Suraski.
