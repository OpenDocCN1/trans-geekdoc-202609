The functions in this section do not fit neatly into any other section of the functional reference. They are not available by default when compiling PHP, and most of them require extra libraries. While none are essential to building PHP scripts, some are quite useful in the right context. Because you may not be familiar with all the technologies in this chapter, I've attempted to give a brief synopsis and links to Web sites where you can learn more.

The list of extensions is growing rapidly. A few did not make it into this edition of the book for several reasons. Some are very specialized, and perhaps not of general interest. Others are relatively immature, so I couldn't rely on them to change. Most of them are documented in the online manual, and people, included, are working on documenting the others. It is likely that several new extensions will be created between the time this text is finished and when they become available. The extensions that I know exist and have chosen not to cover: CyberCash, DAV, DOM, FDF, Hyperwave, ICAP, MCAL, NIS, PDF, Readline, Recode.
