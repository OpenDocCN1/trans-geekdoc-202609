The imagesetpixel function sets a single pixel to the specified color.

The imagestring function draws the given text at the specified point. The top-left part of the string will be at the specified point. The font argument may be a built-in font or one loaded by imageloadfont.

# array imagettfbbox(integer point_size, integer angle, string font, string text)

imagegettfbbox returns an array of points that describe a bounding box around text drawn by the imagettftext function. The points are relative to the leftmost point on the baseline. The array elements correspond to the lower-left, lower-right, upper-right, and upper-left corners, in order, as shown in Table 12.3.

# boolean imagettftext(integer image, integer point_size, integer angle, integer x, integer y, color font, string text)

The imagettftext function uses TrueType to draw a string of text. The x and y arguments refer to the leftmost point of the baseline. The text will radiate from that point at the given angle, which should be 0 to 360. An angle of zero represents right-to-left text. The font argument is the path to a .ttf file.

This function may not be available, depending on the libraries available when PHP was compiled.

```php
<?php
/** Draw text using a TrueType font
 ** Also, draw a box around the text.
 */

// parameters for text
$size = 40;
$angle = 30;
$startX = 50;
$startY = 100;

// create red square
$image = imagecreate(200, 200);
$colorRed = imagecolorallocate($image, 255, 0, 0);
$colorBlack = imagecolorallocate($image, 0, 0, 0);
imagefill($image, 10, 10, $colorRed);

// get bounding box
$Box = imagegettfbbox($size, $angle, "comic.ttf", "PHP");

// move box to starting point (100)
for($index=0; $index < count($Box); $index += 2) {
    $Box[$index] += $startX;
    $Box[$index+1] += $startY;
}

// draw bounding box
imagepolygon($image, $Box, count($Box)/2, $colorBlack);

//write the text
imagettftext($image, $size, $angle,
$startX, $startY, $colorBlack,
"comic.ttf", "PHP");

// send image
header("Content-type: image/jpeg");
imagejpeg($image);
?>
```

# boolean imagebmp(integer image, string filename)

The imagebmp function either sends an image to the browser or writes it to a file. If a filename is provided, a WAP (Wireless Application Protocol) bitmap file is created. Otherwise, the image is sent directly to the browser. This function is similar to imagepng and imagejpeg.
