# Core PHP Programming

The get_cfg_var function returns the value of the specified configuration variable. These are the variables specified in php.ini or Apache's configuration files. You can get a report on all configuration information by calling the phppinfo function.

```
<?nprint("Scripts are allowed to run " 
    get_cfg_var("max_execution_time") 
    " seconds");
?>
```

# string get_class(object variable)

The get_class function returns the name of the class for the given object.

```
<?nclass animal
{
    var $name;
}

gus = new animal;
print("Gus is of type " . get_class($gus) . "<BR>\n");
?>
```
