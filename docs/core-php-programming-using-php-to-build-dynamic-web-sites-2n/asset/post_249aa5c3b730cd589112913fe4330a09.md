# Configuration

The following functions affect the operation of PHP. Some of them alter configuration variables. Others cause a script to stop executing for a period of time.

# boolean bcscale(integer scale)

The bcscale sets the default scale for the functions that perform math on arbitrary-precision numbers. The scale is the number of digits after the decimal point. See the section on arbitrary-precision numbers in Chapter 10, "Mathematical Functions."

```php
// use ten digits
bcscale(10);
```

# clearstatcache()

Calling the stat function may take a considerable amount of time. To increase performance, PHP caches the results of each call. When you use a function that relies on stat, if information about a file changes often, you may need to clear the stat cache.

# Core PHP Programming

The functions that use the stat cache are: stat, file_exists, filemtime, filetime, inode, filegroup, fileowner, fileperms, filesize, filetype.

```php
// make sure info isn't cached
clearstatcache();

// get size of this file
print(filesize(__FILE__));
```

# define_syslog_variables

The define_syslog_variables function emulates the configuration directive of the same name. It causes the constants for use to be created as variables. The functions that interact with the system log are closelog, openlog, and syslog.

```php
define_syslog_variables();
```

# boolean dl(string extension)

Use the dl function to load a dynamic extension module. The function returns FALSE if the module could not be loaded. The path to these modules is set in php.ini, so you need to type only the name of the module file.

```php
// load windows mysql module
dl("php_mysql.dll");

// show diagnostics
phpinfo();
```

# integer error_reporting(integer level)

The error_reporting function sets the level of error reporting and returns the previous value. The level argument is a bitfield, so you use the bitwise OR operator (|) to put together the type of reporting you would like. By default PHP uses a level of seven, which is Errors, Warnings, and Parser Errors. Refer to Table 11.7, which lists error levels.

# Core PHP Programming

Table 11.7. Error Levels

| Value | Name | Description |
| :--- | :--- | :--- |
| 1 | Errors | Unrecoverable errors that cause execution of the script to halt. |
| 2 | Warnings | Recoverable errors when incorrect values are passed to functions, but script execution continues. |
| 4 | Parser Errors | Errors generated by the parser, halting execution. |
| 8 | Notice | A warning about a condition that may or not be an error, such as setting the value of a variable before setting it. |
| 16 | Core Error | Error conditions reported by the operating system |
| 32 | Core Warning | Warnings reported by the operating system. |

# boolean ignore_user_abort(boolean ignore)

The ignore_user_abort function determines whether the script should continue running if the user disconnects. The ignore argument is a boolean; if TRUE, the script will continue.

```php
<?php
ignore_user_abort(true);
?>
```


# set_time_limit(integer seconds)

The set_time_limit function sets the maximum time a script is allowed to run, which is usually set to 30 seconds inside php.ini. If this limit is reached, an error occurs and the script stops executing. Setting seconds argument to zero causes the time limit to be disabled.

```php
<?php
  // allow this script to run forever
  set_time_limit(0);
?>
```
