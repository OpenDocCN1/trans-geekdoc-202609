array imap_search(integer stream, string criteria, integer flags)

Use imap_search to get a list of messages based on search criteria. The criteria is a list of search codes separated by spaces. The codes are listed in Table 14.9. Some of them take an argument, which must be surrounded by double quotes. The optional flags argument may be set to SE_UID to cause returned instead of message numbers.

| Table 14.9. imap_search Criteria Codes |
| --- |
| ALL |
| ANSWERED |
| BCC "string" |
| BEFORE "date" |
| BODY "string" |
| CC "string" |
| DELETED |
| FLAGGED |
| FROM "string" |
| KEYWORD "string" |
| NEW |
| OLD |
| ON "date" |
| RECENT |
| SEEN |
| SINCE "date" |
| SUBJECT "string" |
| TEXT "string" |
| TO "string" |
| UNANSWERED |
| UNDELETED |
