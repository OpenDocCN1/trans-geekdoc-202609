## integer mysql_pconnect(string host, string user, string password)

The mysql_pconnect function operates like mysql_connect except that the connection will be persistent. That is, it won't be closed when the script ends. The connection will last as long as the server process lasts, so that if a connection is attempted later from the same process, the overhead of opening a new connection will be avoided.

A link identifier is returned. This identifier is used in many of the other functions in this section.

```php
<?php
//open persistent connection
$dbLink = mysql_pconnect("localhost", "freetrade", "");
?>
```

Open Database Connectivity (ODBC) has become an industry standard for communicating with a database. The model is simple. Client software is designed to use an ODBC API. Vendors write drivers that implement this API on the client side and talk natively to their database on the server side. This allows developers to write one application that can communicate with many databases by changing the driver, which is an external file.

The odbc_autocommit function sets whether queries are automatically committed when executed. The connection argument is an integer returned by the odbc_connect or odbc_pconnect functions. This function has to be used intelligently, as not all ODBC drivers support commits and rollbacks.

## boolean odbc_commit(integer connection)

Use odbc_commit to commit all pending actions for the connection. If automatic commit is turned on, this function has no effect. Also, make sure your driver supports transactions before using this function.

```php

?>
```
