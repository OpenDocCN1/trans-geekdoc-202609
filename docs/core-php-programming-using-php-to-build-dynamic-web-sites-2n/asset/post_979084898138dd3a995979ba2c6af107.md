# string msql_fieldflags(integer result, integer field)

The msql_fieldflags function returns all the flags turned on for the specified field. These may be primary key, unique, and not null.

```php
$Link = msql_connect("msql.clearink.com");
msql_select_db("store", $Link);

$Query = "SELECT * FROM item";
$Result = msql_query($Query, $Link);
print("Field 0 flags are " . msql_fieldflags($Result, 0));

msql_close($Link);
?>
```

# boolean mysql_free_result(integer result)

When a script ends, all results are freed. If memory is a concern your script is running, use mysql_free_result.

```php
<?
$Link = mysql_connect("mysql.clearink.com");
mysql_select_db("store", $Link);

$Query = "INSERT INTO store VALUES (0, 'Martinez')";
$Result = mysql_query($Query, $Link);

mysql_free_result($Result);

mysql_close($Link);
?>
```

# integer mysql_list_dbs(integer link)

The mysql_list_dbs function returns a result identifier as if the database was queried with mysql_query. Any of the functions for fetching rows or fields may be used to get the names of the databases. The link argument is optional. If left out, the last-opened connection will be used.

```php
<?
$Link = mysql_connect("mysql.clearink.com");
mysql_select_db("store", $Link);

$Result = mysql_list_dbs($Link);
while($row_array = mysql_fetch_row($Result))
{
    print($row_array[0] . "<BR>\n");
}

mysql_close($Link);
?>
```

# integer mysql_num_fields(integer result)

Use mysql_num_fields to get the number of fields in a result set.

```php
<?
$Link = mysql_connect("mysql.clearink.com");
mysql_select_db("store", $Link);
$Query = "SELECT * FROM item i, SKU s ";
$Query .= "WHERE i.SKU = s.ID";
$Result = mysql_query($Query, $Link);

print(mysql_num_fields($Result));
mysql_close($Link);
```

# integer msql_pconnect(string host)

The msql_pconnect function is identical to the msql_connect except that the connection will not be closed when the script ends. This has meaning only when PHP is compiled as an Apache module. These are persistent links because they live as long as the server process.

```php
<?
$Link = msql_pconnect("localhost");
?>
```

# integer msql_query(string query, integer link)

Use msql_query to execute a query. The database used will be the one specified in a call to the msql_select_db function. The link argument is optional. The last connection made will be used if it is left out.

# string msql_result(integer result, integer row, string field)

The msql_result function returns a single field value for the given row. The field argument can be interpreted in two ways. If it is a number, it will be used as a field offset, starting with zero. Otherwise, it will be considered a column name. The msql_result function is relatively slow. Its use should be avoided in favor of faster functions such as msql_fetch_array.

```php
<?php
$Link = msql_connect("msql.clearink.com");
msql_select_db("store", $Link);

$Query = "SELECT * FROM item i, s s";
$Query .= "WHERE i.SKU = s.ID";
$Result = msql_query($Query, $Link);

$numRows = msql_num_rows($Result);

for($index = 0; $index < $numRows; $index++) {
    $item_ID = msql_result($Result, $index, "item.ID");
    $item_Name = msql_result($Result, $index, "item.Name");

    print("$item_ID: $item_Name<BR>\n");
}

msql_close($Link);
?>
```
