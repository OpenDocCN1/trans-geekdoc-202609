# integer mysql_list_dbs(integer link)

The mysql_list_dbs function returns a result identifier as if the database was queried with mysql_query. Any of the functions for fetching rows or fields may be used to get the names of the databases. The link argument is optional. If left out, the last-opened connection will be used.

```
<?
$Link = mysql_connect("mysql.clearink.com");
mysql_select_db("store", $Link);

$Result = mysql_list_dbs($Link);
while($row_array = mysql_fetch_row($Result))
{
    print($row_array[0] . "<BR>\n");
}

mysql_close($Link);
?>
```
