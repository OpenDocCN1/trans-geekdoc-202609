# string hebrew(text, integer length)

Unlike English, Hebrew text reads right to left, which makes working with strings inconvenient at times. The hebre function reverses the orientation of Hebrew text, but leaves English alone. Hebrew characters are assumed to be in the ASCII range 224 through 251, inclusive. The optional length argument specifies a maximum length per line. Lines that exceed this length are broken.

```
<?php\print("Hebrew");
?>
```

# string hebrevc(text, integer length)

The hebrevc function operates exactly like hebrew, except that BR tags are inserted before-of-line characters.

# string htmlntities(string text)

The htmlntities function returns the text argument with certain characters translated into HTML entities. Table 9.5 lists entities supported.

This list conforms to the ISO-8859-1 standard. The nl2br function is similar: it translates lines to BR tags. You can use strip_tags to remove HTML tags altogether.

```
<?php
$text = "Use <HTML> to begin a document.";
print(htmlntities($text));
?>
```
