# ibase_rollback(integer link)

The ibase_rollback function causes a transaction to roll back. The default transaction on the specified link is rolled back. The last link will be used if no link is specified.

# ibase_timemtf(string format)

Use ibase_timemtf to set the format for datetime columns. The format string should follow the rules of strtotime. The default format is "%m/%d/%Y %H:%M:%S". The strtotime function is described in Chapter 11, "Time, Date, and Configuration Functions."

# integer_ibase_trans(integer flags, integer link)

The ibase_trans function returns a transaction identifier. The flags can be any combination of the constants listed in Table 13.5. Use | to combine them. IBA_DEFAULT matches InterBase read, write, snapshot, and wait properties. The last connection will be used if it's left out.

# mSQL

The functions in this section communicate with mSQL, a database that implements a subset of SQL. The official site is at http://www.hughes.com.au/. A supporting Windows versions of mSQL is http://blnet.com/msqlpc/.

There are a handful of mSQL functions that exist simply for backward compatibility. We have chosen to leave them. Only some of them are documented in the official PHP 3 manual. For reference they are msql, msql_createdb, msql_dbname, msql_dropdb, msql_freeresult, msql_listdbs, msql_list-fields, msql_listtables, msql_numfields, msql_numrows, msql_selectdb, msql_tablename.

# Core PHP Programming

Two MySQL extensions exist, one for MySQL version 1 and one for version 2. You must load the appropriate extension to enable the functions in this section. Zeev Suraski wrote both mSQL extensions.

# mysql_affected_rows(integer link)

The mysql_affected_rows function returns the number of rows involved in the previous query given on the link. The link argument must be an integer returned by mysql_connect or mysql_pconnect. For an example of use, see mysql_db_query, below.

# boolean mysql_close(integer link)

The mysql_close function closes the link to a database. If the link argument is left out, the last-opened link is closed. Only links opened by mysql_connect may be closed. Using this function is not strictly necessary, since all nonpersistent links are automatically closed when a script ends. For an example of use, see mysql_db_query, below.

# integer mysql_connect(string host, string username, string password)

The mysql_connect function attempts to connect to the MySQL server at the specified host. If the host argument is left out, the local host will be assumed. A link identifier is returned in the case where an open link exists, it will be returned rather than establishing a second link. The connection is automatically closed at the end of the script.

You may add a colon and a port number to the host argument.

# boolean mysql_create_db(string database, integer link)

The mysql_create_db function attempts to create a database. The link argument is optional. If left out, the last-opened link will be used.

```php
<?
$Link = mysql_connect("mysql.clearink.com");
mysql_create_db("store", $Link);
mysql_close($Link);
?>
```

# boolean mysql_data_seek(integer result, integer row)

Use mysql_data_seek to move the internal row pointer to the specified row in a result set. The result argument is returned by mysql_query.

```php

$Link = mysql_connect("mysql.clearink.com");
mysql_select_db("store", $Link);
```

```php
$Result = mysql_query("SELECT Name FROM customer", $Link);
```

# integer mysql_db_query(string database, string query, integer link)

The mysql_db_query function is identical to mysql_query except that it specifies the database rather than using the database with mysql_select_db. The query is executed in the specified database and a result is returned.

```php
<?
$Link = mysql_connect("mysql.clearink.com");
$Query = "DELETE FROM customer";
$Result = mysql_db_query("store", $Query, $Link);
$RowsAffected = mysql_affected_rows($Link);
print($RowsAffected . " rows deleted.");
mysql_close($Link);
?>
```

# boolean mysql_drop_db(string database, integer link)

The mysql_drop_db function removes an entire database from the server. The link argument is optional and if omitted, the connection opened will be used.

```php
<?
$Link = mysql_connect("mysql.clearink.com");
if(mysql_drop_db("store", $Link)) {
	print("Database deleted!");
} else {
	print("Database not deleted!");
}
print(mysql_error());
mysql_close($Link);
?>
```

# string mysql_error()

Use mysql_error to retrieve the last error message returned by a function. See mysql_drop_db, above, for an example of use.

# array mysql_fetch_array(integer result, integer type)

The mysql_fetch_array function returns an array of the data for the current row. The result argument is returned as query. By default, columns are returned in two elements: one referenced by number and one referenced by name. The optional type argument controls which elements are created. MYSQL_NUM signals that only numbered elements are created. MYSQL_ASSOC signals that only named elements are created. If you want both, you can explicitly request it with MYSQL_BOTH. Compare this function to mysql_fetch_row and mysql_fetch_object.

```php
?
$Link = mysql_connect("mysql.clearink.com");
mysql_select_db("store", $Link);

$Query = "SELECT * FROM customer";
$Result = mysql_query($Query, $Link);

//fetch each row
while($Row = mysql_fetch_array($Result, MYSQL_ASSOC)) {
    print($Row["FirstName"] . "\n");
}
mysql_close($Link);
?>
```

# object mysql_fetch_field(integer result, integer field)

The mysql_fetch_field function returns an object with properties that describe the specified field. The field argument may be left out, and the next unfetched field will be returned. The properties of the object are listed in Table 13.6.

```php
?
$Link = mysql_connect("mysql.clearink.com");
mysql_select_db("store", $Link);

$Query = "SELECT * FROM item i, s ";
$Query .= "WHERE i.SKU = s.id";
$Result = mysql_query($Query, $Link);

// get description of each field
while($Field = mysql_fetch_field($Result)) {
    print("Name: " . $Field->name . "\n");
    print("Table: " . $Field->table . "\n");
    print("Not Null: " . $Field->not_null . "\n");
    print("Primary Key: " . $Field->primary_key . "\n");
    print("Unique: " . $Field->unique . "\n");
    print("Type: " . $Field->type . "\n\n");
}
mysql_close($Link);
?>
```

Table 13.6. Properties of mysql_fetch_field Object

| Property | Description |
|---|---|
| name | Name of the column |
| not_null | TRUE if the column cannot be null |
| primary_key | TRUE if the column is a primary key |
| table | Name of the table the column is from |
| type | Datatype of the column |
| unique | TRUE if the column is a unique key |

# object mysql_fetch_object(integer result)

The mysql_fetch_object returns an object with a property for each column of the resulting row. Each call to mysql_fetch_object gets the next row from the results, or returns FALSE when there are none left.

```php
<?php
$Link = mysql_connect("mysql.clearink.com");
mysql_select_db("store", $Link);

$Query = "SELECT * FROM item";
$Result = mysql_query($Query, $Link);

while($Row = mysql_fetch_object($Result)) {
    print("$Row->ID: " . $Row->Name . "\n");
}
mysql_close($Link);
?>
```

# array mysql_fetch_row(integer result)

The mysql_fetch_row function returns an array with one element for each resulting column. FALSE is returned when no results are left. Columns are dereferenced by integers starting at zero. Compare this function to mysql_fetch_array and mysql_fetch_object.

```php
<?
$Link = mysql_connect("mysql.clearink.com");
mysql_select_db("store", $Link);

$Query = "SELECT * FROM customer";
$Result = mysql_query($Query, $Link);

while($Row = mysql_fetch_row($Result)) {
    print($Row[0] . ": " . $Row[1] . "\n");
}

mysql_close($Link);
?>
```
