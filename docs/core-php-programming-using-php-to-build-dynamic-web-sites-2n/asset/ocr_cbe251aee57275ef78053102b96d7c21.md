# object imap_mailboxmsginfo(integer stream)

Use imap_mailboxmsginfo to return information about the current mailbox. The object will have the properties listed in Table 14.7.

```
<?php
$mailbox = imap_open("mail.server.com",INBOX", "leon", "password");
$info = imap_mailboxmsginfo($mailbox);
print("Driver: " . $info->Driver);
imap_close($mailbox);
?>
```

# integer imap_num_msg(integer stream)

The imap_num_msg function returns the number of messages in the current mailbox.

```
<?php
$mailbox = imap_open("mail.server.com",INBOX", "leon", "password");
print("Number of Messages: " . imap_num_recent($mailbox));
imap_close($mailbox);
?>
```
