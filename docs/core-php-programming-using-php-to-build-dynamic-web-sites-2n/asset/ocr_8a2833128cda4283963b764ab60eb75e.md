# Core PHP Programming

# integer ora_do(integer connection, string query)

The ora_do function executes a query on the given connection. PHP takes care of creating, parsing the query, and executing it. A cursor identifier is returned.

The ora_error function returns a string that describes the error for the last command sent to the Oracle database. The identifier may be either a connection identifier or a cursor identifier.

The message takes form of XXX-NNNNN, where XXX tells you where the error came from and NNNNN tells you the error number. If you want to look up a description of the error, you can use Oracle's ora_exec command. See ora_exec for an example of use.

# integer ora_errorcode(integer identifier)

The ora_errorcode function returns the error number for the last command sent to the Oracle server. The identifier may be either a connection identifier or a cursor identifier. See ora_exec for an example of use.
