if($myFile = gzopen("data.gz", "r")) {

## stringgets(integer file_handle, integer length)

The gzgets returns a string from a compressed file specified by the file handle, which must have been created with gzopen. It will attempt to read as many characters specified by the length argument (presumably this PHP showing its C heritage). A linebreak is treated as a stopping point, as is the end of the file. Linebreaks are included in the return string.

```php
<?php
// open file and print each line
if($myFile = gzopen("data.gz", "r")) {
    while(!gzeof($myFile)) {
        $myLine = gzgets($myFile, 255);
        print($myLine);
    }

    gzclose($myFile);
}
?>
```

## integer gzopen(string filename, string mode, boolean use_include_path)

The gzopen is similar in operation to the fopen function, except that it operates on compressed files. If the use_include_path argument is TRUE, the include path specified in php.ini will be searched. Use gzgets and gzputs for examples of use.

The mode argument accepts a few extra parameters compared to fopen. In addition to the modes listed in Table 8.6, you may specify a compression level and a compression strategy if you are creating a new file. Immediately following the mode, you may place an integer between zero and nine that specifies the level of compression. Zero means no compression, and nine is maximum compression. After the compression level, you may use h for Huffman encoding only, or t to optimize for filtered input. Filtered data is defined by the zlib source code as being small values of somewhat random distribution. In all cases the default settings are a good choice and the extra mode settings are unnecessary.

It is possible to open an uncompressed file with gzopen. Reads from the file will operate as expected. This can be convenient if you do not know ahead of time whether a file is compressed.

## boolean gzputs(int file_handle, string output, integer length)

The gzputs function writes data to a compressed file. It expects a file handle as returned by gzopen. It returns TRUE if the write was successful, FALSE if it failed. The optional length specifies a maximum number of bytes to accept. A side effect of specifying length is that the magic_quotes_runtime configuration setting will be ignored.

```php
<?php // open file for writing
// use maximum compress and force
// Huffman encoding only
$myFile = gzopen("data.gz","wb9h");

// make sure the open was successful
if(!($myFile) {
    print("file could not be opened");
    exit;
}

for($index=0; $index<10; $index++) {
    // write a line to the file
    gzputs($myFile, "line $index\n");
}

// close the file
gzclose($myFile);
?>
```

## boolean gzrewind(integer file_handle)

The gzrewind function moves PHP's internal file pointer back to the beginning of a compressed file. It returns TRUE on success, FALSE if there is an error.

```php
<?php
/*
** print a file, then print the first line again
 */

// open a local file
if(!$myFile = gzopen("data.gz", "r"))
{
    print("file could not be opened");
    exit;
}

while(!gzeof($myFile))
{
    // read a line from the file
    $myLine = gzgets($myFile, 255);
    print("$myLine <BR>\n");
}

gzrewind($myFile);
$myLine = gzgets($myFile, 255);
print("$myLine <BR>\n");

// close the file
gzclose($myFile);
```
