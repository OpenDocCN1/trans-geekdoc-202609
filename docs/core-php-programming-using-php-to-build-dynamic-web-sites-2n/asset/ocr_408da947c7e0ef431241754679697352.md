# boolean ftp_delete(integer link, string path)

The ftp_delete function removes a file on the remote server. The link argument is as returned by ftp_connect. The path argument is the path on the remote server to the file to be deleted. See ftp_put for an example of use.

# boolean ftp_fget(integer link, integer file, string filename,
integer mode)

The ftp_fget copies a file into an open file stream. You must create a file resource using fopen or a similar function to pass as the second argument. The mode argument should be set with one of constants: FTP_ASCII or FTP_IMAGE. These are sometimes referred to as text or binary modes.
