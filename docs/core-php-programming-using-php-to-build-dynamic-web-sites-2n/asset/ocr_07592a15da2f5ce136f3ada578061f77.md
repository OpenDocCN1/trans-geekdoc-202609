# Core PHP Programming

input tag inside an HTML form with the type attribute file causes a text box and a button for browsing the local file system to appear on the Web page. Browsers that do not support uploads will likely render this as a text box, so it is best to prevent uploads only to capable browsers. The forms must use the post method to allow for uploads, and must also contain the enctype attribute with a value of multipart/form-data. A hidden variable, MAX_FILE_SIZE, must precede the file input tag. Its value is the maximum file size in bytes to be accepted.

When the form is submitted, PHP will detect the file. The file will be placed in a temporary directory on the server, such as /var/tmp. Several variables will be created based on the name of the file field. A variable with the same name as the file field will contain the complete path to the file in the local file system. A variable with name appended to the file field will contain the original file name provided by the browser. A variable with size appended to the file field name will contain the size of the file in bytes. Finally, a variable with type appended to the file field name will contain the MIME type of file, if it was offered by the browser.

If you plan on using the file later, move the new file into a temporary spot. If not, PHP will delete the file when it finishes executing the current page request. Listing 7.4 is an example script that accepts uploads and immediately deletes them.

File uploads are limited in size by a directive in php.ini, upload_max_filesize. It defaults to two megabytes. If a file exceeds this limit, your script will execute as if no file were uploaded. A warning will be generated, as well.

Like other fields, the upload form field is treated like setting the value of a variable. If you place brackets at the end of the field name, an array will be created. As you would expect, the size and type values will be placed in similarly arrays. You can take advantage of this to allow for multiple file uploads.
