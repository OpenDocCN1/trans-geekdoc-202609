The size of the memory segment defaults to a value defined when PHP is compiled. Minimum and maximum values for the size are dependent on the operating system, reasonable values to expect a 1-byte minimum and a 128K maximum. There are also limits on the number of shared memory segments. Normal limits are 100 total segments and 6 segments per process.

The permissions for a memory segment default to 0x666, which is read and write permission to all users. This value operates like to set file permissions.

As with semaphores, calling shm_attach for the same key twice will return two different identifiers, yet will both point to the same shared memory segment internally.

Keep in mind that shared memory does not expire automatically. You must free it using shm_remove.
