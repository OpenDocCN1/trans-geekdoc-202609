    print("Could not execute query: ");

    print("<BR\n");
    exit;

// loop over each row

# array pg_fetch_row(integer result, integer row)

The pg_fetch_row function returns the values of all the fields in a row. The fields are indexed by their field name, starting with zero. Each call to pg_fetch_object returns the next row, or FALSE when no rows remain. Compare this function to pg_fetch_array, and pg_fetch_object.
