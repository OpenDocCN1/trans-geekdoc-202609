# Core PHP Programming

Any of the examples in the previous section is an excellent first step toward introducing PHP into a Web site. Their impact in terms of server load is relatively low. I like to think of sites using similar approaches as PHP-enabled, as if they have a small injection of PHP that makes them extraordinary. The step beyond is what I think of PHP: a site made complex of PHP. In this approach every variety of output comes from PHP. The print (or echo or printf) function is used to send HTML tags. Every page is a script inside a single pair of PHP tags.

You might have noticed that most of the examples in the book take this approach. I have found that while this requires extra time, the code is more maintainable. Once information is put in a PHP variable, it's easy to add something dynamic to it. It also has the advantage of being more readable as the page becomes more complex. As a simple example, compare Listing 20.5 to Listing 20.6. The idea is to change the background color of the page depending on the time of day.

My experience has that having all the HTML inside the PHP script allows quick changes. I don't have to search for the opening and closing tags buried inside the HTML in Listing 20.5. It also allows me to break code into separate lines in the source code that appear as a single line in the output. The output is the header text. It can enhance the readability but not sacrifice the precision. This has become very handy when dealing with tables. Leaving any whitespace between a TD and an image causes an extra pixel to appear. In an HTML file, the solution is to wrap the whole thing under one line. Inside a PHP script I can make print calls and send an inline only in the last. The result is a single line in the output, but very readable source code.

The usefulness of these techniques, like that of others, increases with the size of the project. I've created 50-page Web applications using both approaches and can attest to the value of putting everything inside the PHP code.

# Listing 20.5 Mixing PHP and HTML

```
<HTML>
<HEAD>
<TITLE>Listing 20.5/TITLE>
</HEAD>
<?
$Hour = date("H");
$Intensity = round($Hour/24.0) * (0xFF);
$PageColor = dechex($Intensity) . 
dechex($Intensity) . 
dechex($Intensity);
?>
<BODY BGCOLOR="# print($PageColor); ??>
<h1>Listing 20.5</h1>
</BODY>
</HTML>
```
