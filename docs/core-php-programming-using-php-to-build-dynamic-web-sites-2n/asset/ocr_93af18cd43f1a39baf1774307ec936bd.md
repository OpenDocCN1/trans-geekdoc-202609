When support for Sybase is compiled for PHP, one of two libraries may be used. One is the older DB-Library. The other is its replacement, Client-Library. These two libraries are not compatible with each other, so PHP special code to adapt each of them into a single set of functions. Consequently, some of these are present when using DB-Library and not when using Client-Library. Also, it is possible to compile PHP for Windows using an MSSQL library. This library is really just the DB-Library, but the PHP extension creates only functions unavailable in the Sybase extension: `mssql_field_length`, `mssql_field_name`, and `mssql_field_type`.

Sybase's home page: <http://www.sybase.com/>. If you want to learn more about the libraries, check out the online documentation
