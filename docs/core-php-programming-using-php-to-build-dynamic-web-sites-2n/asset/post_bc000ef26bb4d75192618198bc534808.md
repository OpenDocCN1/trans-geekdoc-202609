The mysql_affected_rows function returns the number of rows affected by the last query made to the specified database connection link. If the link argument is omitted, the last-opened connection is assumed. If the last query was an unconditional delete, zero will be returned. If you want to know how many rows were returned by a select statement, use mysql_num_rows.

```php
<?
//connect to server as freerate user, no password
$dbLink = mysql_connect("localhost","freerate", "");

//select the 'freerate' database
mysql_select_db("freerate", $dbLink);

//update some invoices
$Query = "UPDATE invoice "
"SET Active = 'Y' "
"WHERE ID = 100";
$dbResult = mysql_query($Query, $dbLink);

//let user know how many rows were updated
$AffectedRows = mysql_affected_rows($dbLink);
print("$AffectedRows updated.<BR>\n");
?>
```

# boolean mysql_change_user(string user, string password, string database, integer link)

Use mysql_change_user to change the user for a database connection. The database and link arguments are optional. If left out, the current database and the link opened are used. If the user cannot be changed, the current connection remains open with the original user. This function requires MySQL version 3.23.3 or newer.

```php
<?
//connect to server as freerate user, no password
$dbLink = mysql_connect("localhost","freerate", "");

//select the 'freerate' database
mysql_select_db("freerate", $dbLink);

//switch to admin user
mysql_change_user("admin","secret","freerate", $dbLink);
?>
```

# boolean mysql_close(integer link)

Use mysql_close to close the connection to a database. The connect must have been opened with mysql_connect. Use of this function is not strictly necessary, as all persistent links are closed automatically when the script finishes. The link argument is optional, and if it's left out, the last opened connection is closed.

```php
<? // open connection
$Link = mysql_connect("localhost", "httpd", "");

// close connection
mysql_close($Link);
?>
```

# integer mysql_connect(string host, string user, string password)

The mysql_connect function begins a connection to a MySQL database at the specified host. If the database is on a different port, follow the hostname with a colon and a port number. You may alternatively use a colon and the path to the socket if connecting to localhost:/tmp/sockets/mysql.sock. All the arguments are optional and default to localhost, the name of the user executing the script, and an empty string. The user executing the script is typically httpd, the Web server.

Connections are automatically closed when a script finishes execution, though they may be closed earlier with mysql_close. If you attempt to open a connection that is already open, a second connection will not be made. The identifier of the previously open connection will be returned.

# boolean mysql_create_db(string database, integer link)

Use mysql_create_db to create a new database. Note that you must open a connection with an account that has permission to create databases. If you leave out the link argument, the last-opened connection will be used.

```php
<?php
// open connection
$dbLink = mysql_connect("localhost", "admin", "secret");

//create database
mysql_create_db("garbage", $dbLink);
?>
```

# boolean mysql_data_seek(integer result, integer row)

The mysql_data_seek function moves the internal row pointer of a result set to the specified row. Use this function with mysql_fetch_row to jump to a specific row. The result argument must have been returned from mysql_query or a similar function.

```php
<?php
//connect to server freetrade user, no password
$dbLink = mysql_pconnect("localhost", "freetrade", "");

//select the 'freetrade' database
mysql_select_db("freetrade", $dbLink);

//get states from tax table
$Query = "SELECT State FROM tax ";
$dbResult = mysql_query($Query, $dbLink);

//jump to fifth row
mysql_data_seek($dbResult, 4);

//get row
$row = mysql_fetch_row($dbResult);

//print state name
print($row[0]);
?>
```

# integer mysql_db_query(string database, string query, integer link)

The mysql_query function executes a query on the specified database and returns a new identifier. If the link argument is omitted, the last-opened link will be used, or a new one will be created if necessary.

```php
<?
//connect to server as freetrade user, no password
$dbLink = mysql_pconnect("localhost", "freetrade", "");

//truncate session table
$Query = "DELETE FROM session ";
$dbResult = mysql_query($Query, $dbLink);
?>
```

# boolean mysql_drop_db(string database, integer link)

Use mysql_drop_db to delete a database. If the link argument is omitted, the last-opened link will be used.

```php
<?
//open connection
$dbLink = mysql_connect("localhost", "admin", "secret");

//drop database
if(mysql_drop_db("garbage", $dbLink))
{
    print("Database dropped.");
}
else
{
    print("Database failed.");
}
?>
```

# integer mysql_errno(integer link)

The mysql_errno function returns the error number of the last query. If the link argument is omitted, the last-opened connection is used.

```php
<?
//connect to server
$dbLink = mysql_connect("localhost", "freerate", "");

//execute an invalid query
mysql_query("SELECT * FROM non_existent_table", $dbLink);

//get error number
$errno = mysql_errno($dbLink);
print($errno);
?>
```

# array mysql_fetch_array(integer result, integer type)

The mysql_fetch_array function returns an array that represents the fields of a row. The type argument determines how the array is indexed (MYSQL_ASSOC, MYSQL_NUM, or BOTH). If the type is omitted, MYSQL_BOTH is used.

```php
<?
//connect to server
$dbLink = mysql_connect("localhost", "freetrade", "");

//select the 'freetrade' database
mysql_select_db("freetrade", $dbLink);

//execute query
$Query = "SELECT State, Rate FROM tax ";
$dbResult = mysql_query($Query, $dbLink);

//get each row
while($row = mysql_fetch_array($dbResult, MYSQL_ASSOC)) {
    // print state and rate
    print("State: {$row['State']}, Rate: {$row['Rate']}<BR>\n");
}
?>
```


# array mysql_fetch_all(integer result)

The mysql_fetch_all function returns an associative array containing all rows in the result set.

```php
<?
//connect to server
$dbLink = mysql_connect("localhost", "freetrade", "");

//select the 'freetrade' database
mysql_select_db("freetrade", $dbLink);

//execute query
$Query = "SELECT State, Rate FROM tax ";
$dbResult = mysql_query($Query, $dbLink);

//get all rows
$rows = mysql_fetch_all($dbResult);
foreach($rows as $row) {
    print("State: {$row['State']}, Rate: {$row['Rate']}<BR>\n");
}
?>
```
