# boolean imagebmp(integer image, string filename)

The imagebmp function either sends an image to the browser or writes it to a file. If a filename is provided, a WAP (Wireless Application Protocol) bitmap file is created. Otherwise, the image is sent directly to the browser. This function is similar to imagepng and imagejpeg.
