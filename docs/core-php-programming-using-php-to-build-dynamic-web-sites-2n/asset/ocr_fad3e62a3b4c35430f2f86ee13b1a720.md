# Core PHP Programming

# integer ifx_query(string query, integer link, integer cursor_type, array blob_id)

The ifx_query function executes a query and returns a result identifier, which most of the other Informatics functions require. The link argument is as returned by ifx_pconnect, but if you leave out, the last link established will be used. If the query is a select, you may use the IFX_SCROLL and IFX_HOLD constants for the cursor type.

If performing an update or insert, you may use a ? in the query and match it to an entry in the blob id. Each entry must be a value returned by ifx_create_blob. Selects that return columns will return row identifiers by default, but you can override this functionality with ifx_textvarchar.
