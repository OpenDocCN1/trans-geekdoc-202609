# array pg_fetch_array(integer result, integer row)

The pg_fetch_array function returns an array containing every field value for the given row. The values are indexed by number, starting with zero, and by column name. Each call to pg_fetch_array returns the next row, or FALSE when no rows remain. Compare this function to pg_fetch_object and pg_fetch_row.
