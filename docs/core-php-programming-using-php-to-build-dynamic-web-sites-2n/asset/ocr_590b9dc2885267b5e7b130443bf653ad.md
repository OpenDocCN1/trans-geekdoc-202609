The dollar-sign operator is unique because it is executed when inside double quotes. This allows you to avoid the extra code to break from a string to insert the value of a variable. But dollar signs inside double quotes do not behave exactly like dollar signs inside double quotes. When two or more dollar signs appear together, all the last will be treated as any other character with no meaning. To use one variable to name another, use curly braces.
