# array imap_getmailboxes(integer stream, string reference,
string pattern)

The imap_getmailboxes function returns detailed information about mailboxes
of an array of objects. The reference argument is an IMAP server in
normal format: "{server:port}". The pattern argument controls which mailboxes are
returned. An asterisk (*) matches all mailboxes, and a percentage symbol (%) matches all
mailboxes at a particular level.

The returned objects contain three properties: name, delimiter, and attributes, a
jTextField that may be tested against the constants listed in Table 14.5.
