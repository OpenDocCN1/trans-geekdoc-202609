# Gettext

The Gettext functions are based on work by the GNU Translation Project. They aim to make it easier to write programs that send messages to users in their preferred language. You can read more about gettext on the GNU site <http://www.gnu.org/software/gettext/gettext.html>. The PHP functions are wrappers for the gettext library. Detailed documentation is available on the Web <http://www.gnu.org/manual/gettext/index.html>. The Gettext functions rely on translation tables. They are usually given .po or .mo extensions and are collected into directories. For global files, you can override that directory using bindtextdomain.

The Gettext functions were added to PHP by Alex Platznik.
