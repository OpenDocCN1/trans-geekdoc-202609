```php
//create query
$Query = "SELECT * ";
$Query .= "FROM item";

//execute query
if!($Result = pg_exec($Connection, $Query))
{
    print("Could not execute query: ");
    print($pg_errormessage($Connection));
    print("<BR>\n");
    exit;
}

//loop over each row
while($Row = pg_fetch_row($Result, $Row))
{
    print("$Row[0]<BR>\n");
}

// free the result and close the connection

?>
```

# boolean pg_fieldnull(integer result, integer row, string field)

The pg_fieldnull returns TRUE if the specified field is NULL. Fields are counted from 0. See pg_exec for an example of use.

# string pg_fieldname(integer result, integer field)

The pg_fieldname returns the name of the field in the result set specified by the field number, which starts counting at zero. See pg_exec for an example of use.

# integer pg_fieldnum(integer result, string field)

The pg_fieldnum returns the number of the field given by its name. Numbering begins with 0. If an error occurs, negative (-1) is returned.

# integer pg_fieldprlen(integer result, integer row, string field)

The pg_fieldprlen returns the length of a particular field value. You may specify the field either by number, starting at zero, or by name.

```php
<?php
print(pg_fieldprtlen($Result, $Row, 2));
?>
```

# integer pg_fieldsize(integer string, string)

The pg_fieldsize function returns the size of the field, which may be specified by name or number. Fields numbered from zero. See pg_exec for an example of use.

# string pg_fieldtype(integer result, string field)

The pg_fieldtype function returns the type of the specified field. The field argument may be a number or a name. Fields numbered starting with zero. See pg_exec for an example of use.

# boolean pg_freeresult(integer result)

The pg_freeresult function frees any memory associated with the result set. Ordinarily it is not necessary to call this function, as all memory will be cleared when the script ends. See pg_exec for an example of use.

# integer pg_getlastoid()

The pg_getlastoid returns the object ID (OID) of the last object inserted into a table if the last call to pg_exec was an INSERT statement. Negative one (-1) is returned if there is an error.

```php
<?php
//connect to database
$Connection = pg_connect("", "", "", "leon");

$Query = "INSERT INTO item (name, price) ";
$Query = "VALUES ('hammer', 15.00)";

$Result = pg_exec($Connection, $Query);

print("ID of inserted item: " . pg_getlastoid() . "<BR>\n");

pg_close($Connection);
?>
```

# pg_close(integer file)

The pg_clouse function closes a large object. The file argument is a file identifier returned by pg_looper. See pg_looper for an example of use.

# integer pg_locrate(integer connection)

The pg_locrate function creates a large object and returns the OID. The object is created with both read and write access.

```php
<?php
$Object = pg_locrate($Connection);
?>
```

# integer pg_looper(integer connection, integer object, string mode)

The pg_looper opens a large object. The object argument is a large object ID and the mode may be one of r, rw. A file identifier is returned.

```php
<?php
$Object = pg_locrate($Connection);
$File = pg_looper($Connection, $Object, "r");
pg_close($File);
?>
```

# string pg_loread(integer file, integer length)

The pg_load function returns the large object as a string. The length argument specifies a maximum length to return.

```php
<?php
$Object = pg_locrate($Connection);
$File = pg_looper($Connection, $Object, "r");
$Contents = pg_loread($File, 4096);
?>
```

# pg_loreadall(integer file)

# pg_lounclick(integer file, integer object)

Use pg_lounlink to delete a large object.

```php
<?php
$Object = pg_locreate($Connection);
$File = pg_looper($Connection, $Object, "r");

?>
```

# pg_lowrite(integer file, string buffer)

The pg_lowrite function writes the buffer to the large object.

```php
<?php
$Object = pg_locreate($Connection);
$File = pg_looper($Connection, $Object, "w");
pg_lowrite($File, "some text");
?>
```

# integer pg_connect(string host, string port, string options, string tty, string database)

The pg_connect function operates identically to pg_connect, except that a persistent connection is created. This connection will last as long as the server process, so it may be recycled. This saves the overhead time of opening a connection.

```php
<?php
$Connection = pg_connect("", "", "", "leon");
?>
```

# integer pg_port(integer connection)

The pg_port function returns the port number used in the pg_connect function. See pg_exec for an example of use.

# string pg_result(integer result, integer row, string field)

Use pg_result to get the value of a specific field in a result set. Rows and fields are numbered from zero, but fields may also be specified by name. See pg_exec for an example of use.

# string pg_tty(integer connection)

The pg_tty function returns the tty name used for debugging and supplied with the pg_connect function. See pg_exec for an example of use.

# Sybase

Sybase offers an industrial-strength database that stands among other big competitors like Oracle, Informix, and IBM's DB. Unlike these other databases, Sybase is more available to developers with small budgets because of partnerships with application vendors. InterShop's ecommerce server comes with a Sybase database. Microsoft's SQL Server 6.5 is a dressed-up version of Sybase. In fact, PHP's Sybase functions are able to connect to SQL Server databases. # Core PHP Programming

When support for Sybase is compiled for PHP, one of two libraries may be used. One is the older DB-Library. The other is its replacement, Client-Library. These two libraries are not compatible with each other, so PHP special code to adapt each of them into a single set of functions. Consequently, some of these are present when using DB-Library and not when using Client-Library. Also, it is possible to compile PHP for Windows using an MSSQL library. This library is really just the DB-Library, but the PHP extension creates only functions unavailable in the Sybase extension: `mssql_field_length`, `mssql_field_name`, and `mssql_field_type`.
