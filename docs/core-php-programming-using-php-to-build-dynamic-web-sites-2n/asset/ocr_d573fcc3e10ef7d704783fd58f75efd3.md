# object sybase_fetch_object(integer result)

The sybase_fetch_object function returns an object with a property for each of the fields in the next row. Each call to sybase_fetch_object gets the next row in the result, or returns FALSE if no rows remain. Compare this function to sybase_fetch_array and sybase_fetch_row.

Table 13.12. sybase_fetch_field Object Properties
| Property | Description |
|---|--|
 column_source | The name of the table column belongs to. |
 max_length | The maximum size of the field. |
 name | Name of the column. |
 numeric | If the column is numeric, this property will be true (1). |

```
// connect
$Link = sybase_pconnect();

// use the store database
sybase_select_db("store", $Link);

// get all items
$Result = sybase_query("SELECT * FROM item");

print("<TABLE ORDER=\"1\">\n");

// get rows
while ($Row = sybase_fetch_object($Result)) {
    print("<TD>$Row->Name</TD>\n");
    print("<TD>$Row->Price</TD>\n");
    print("</TR>\n");
}

print("</TABLE>\n");

```
