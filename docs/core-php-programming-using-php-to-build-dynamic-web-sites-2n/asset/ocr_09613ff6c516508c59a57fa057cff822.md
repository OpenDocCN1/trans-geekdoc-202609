# mcrypt_ofb(integer algorithm, string key, string data, integer mode, string initialization_vector)

The mcrypt_ofb function encrypts a string using output feedback. This method is another method to stream to ciphers. The algorithm argument is one of the constants listed in Table 9.8. The mode argument is either MCRYPT_DECRYPT or MCRYPT_ENCRYPT. An initialization vector is required. You must use the same one to decrypt.
