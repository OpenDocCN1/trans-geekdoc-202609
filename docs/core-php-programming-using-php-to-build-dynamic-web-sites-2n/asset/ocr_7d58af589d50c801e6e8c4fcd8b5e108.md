# boolean defined(string constantname)

The defined function returns TRUE if a constant exists, FALSE otherwise.

```
<?php
define("THERMOSTAT", "72 degrees");
if (defined("THERMOSTAT")) {
    print("THERMOSTAT is " . THERMOSTAT;");
}
?>
```

# double double(expression)

The double function returns its argument as a double. Chapter 2 discusses converting data types. Related functions are strval and intval. It is an error to pass an array or object to double.

```
<?php
$myNumber = "13.1cm";nprint(double($myNumber));
?>
```
