The ocicommit function commits all previous statements executed on the connection. By default, statements are committed when executed. You can override this functionality when you call ociexecute, by specifying a mode.

# boolean ocfinebyname(integer statement, string column, reference variable, integer type)

The ocfinebyname function associates a column with a PHP variable. When the statement is executed, the value of the column will be copied into the variable. The statement argument must be an integer returned by ocparse. The column name must be written in upper case, otherwise Oracle will not recognize it. Unrecognized names do not produce errors. Since the variable you pass in ocfinebyname will be modified, you need to pass it by reference. That preceding it with an ampersand (&).

The type argument appears to be necessary only if you are attaching to an abstract data type, such as a ROWID. Abstract data types require ocdescriptor to be used before ocfinebyname. If the type argument left out, the variable will be a null-terminated string.

```
//connect to database
$Connection = ocilogoff("scott", "tiger");

//assemble query
$Query = "SELECT ENAME, HIREDATE "
$Query = "FROM emp "
$Query = "WHERE JOB='CLERK' "

//parse query
$Statement = ocparse($Connection, $Query);

//associate two columns with variables
cidefinebyname($Statement, "ENAME", &&$EmployeeName);
cidefinebyname($Statement, "HIREDATE", &&$HireDate);

//execute query
ociexecute($Statement);

//fetch each row
while(ocifetch($Statement)) {
    print("$EmployeeName was hired $HireDate<BR>\n");
}

//free the statement
ocifreestestatement($Statement);

//close connection
ocilogoff($Connection);
```
