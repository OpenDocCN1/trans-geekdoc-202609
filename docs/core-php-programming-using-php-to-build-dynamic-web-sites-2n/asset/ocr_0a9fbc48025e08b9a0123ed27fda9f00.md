Since we aren't indexing the array with integers, we can't just pull each value starting at zero. If you've turned ahead briefly to skim the array functions in Chapter 9, you may have noticed functions like reset, next, and current. These functions offer one to step through an array and they are the best if you need to do more than simply step through the array in order. You can also use each function. However, PHP 4 added a new statement called foreach specifically for stepping through an array. The foreach statement is discussed in Chapter 3. It is like a for loop, but designed to pull elements from an array. You may wish to turn back and review it.
