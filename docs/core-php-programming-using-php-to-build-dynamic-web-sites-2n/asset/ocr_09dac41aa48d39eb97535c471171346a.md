# Editing Scripts

PHP scripts are just text files, and you can edit and create them just as would HTML files. Certainly, you can telnet to your Web and start creating files with vi. Or you can create files with notepad and ftp to upload them one by one. But these aren't ideal experiences. One feature of newer editors is built-in FTP. These editors can open files on a remote server as if they were on a local drive. A single click saves them back to the remote server. Another feature you may enjoy is syntax highlighting. This causes PHP keywords to be colored in order to help you read the code faster.

Everyone has a favorite editor for PHP scripts. I use UltraEdit <http://www.ultraedit.com/>. I know many Windows users prefer Macromedia's Dreamweaver <http://www.macromedia.com/software/dreamweaver/> and Allaire's HomeSite <http://www.allaire.com/products/homesite/> to edit PHP scripts. Systems offers a free package called PhpWeave that allows edit PHP scripts automatically <http://phpweave.quad-sys.com/> The Macintosh users I know prefer BbEdit <http://www.barebones.com/products/bbedit/bbedit.html>.

On a UNIX system, you may prefer editors or, vi. You might also consider nedit <http://ftp.fnal.gov/pub/nedit/>. A module for PHP is available in the contrib directory. The topic of which editor is best appears frequently on the PHP mailing list. Reading the archives can be informative <http://www.progressive-comp.com/Lists/?php3-general>.

# Algorithms

Whenever we interact with a computer, we are instructing it to perform some action. When you drag an icon into the waste basket on your desktop, when you write an HTML file, you are instructing the computer in the proper way to display some information. There are usually many incremental steps to process the computer you perform. It may first clear the screen with the color you specified in the body tag. Then it begins writing text in a particular color and typeface. As you use a computer, you may not be entirely aware of each tiny step it takes, but you are giving it a list of ordered instructions that you expect to follow.

Instructions for baking a cake are called a recipe. Instructions for a computer are called a program. Each of these is written in its own language, a realization of an abstract set of instructions. Borrowing from mathematics, computer science calls the abstract instructions algorithm.
