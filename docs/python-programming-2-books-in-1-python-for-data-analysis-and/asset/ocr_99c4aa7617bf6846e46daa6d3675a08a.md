+   • To delete a Python Dictionary in its entirety, the “del” keyword can also be used as shown in the example below:

```
dict = {
"key01": "value01",
"key02": "value02",
"key03": "value03",
}
del dict
print (dict)

OUTPUT – name ‘dict’ is not defined
```
