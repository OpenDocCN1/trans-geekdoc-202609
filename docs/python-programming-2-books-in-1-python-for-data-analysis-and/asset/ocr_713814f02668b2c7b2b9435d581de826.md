Arithmetic Operators can be utilized with numerical values to execute basic math calculations.

| Name | Operator | Sample |
|---|---|---|
| Add | + | P + Q |
| Subtract | - | P - Q |
| Multiply | * | P * Q |
| Divide | / | P / Q |
| Modulus | % | P % Q |
| Exponentiation | ** | P ** Q |
| Floor division | // | P // Q |

Assignment Operators can be utilized for assignment of values to a variable.

| Name | Sample |
|---|---|
| = | P = 5 |
| += | P += 3 |
| -= | P -= 3 |
| *= | P *= 3 |
| /= | P /= 3 |
| %= | P %= 3 |
| //= | P //= 3 |
| **= | P **= 3 |
| &= | P &= 3 |
| |= | P |= 3 |
