+   1. Variable names could be as short as single alphabets or more
+   descriptive words like height, weight, and more.
+   2. Variable names could only be started with an underscore
+   character or a letter.
+   3. Variable names must not start with numbers.
+   4. Variable names can contain underscores or alpha numeric
+   characters. No other special characters are allowed.
+   5. Variable names are case sensitive. For example, ‘weight,’
+   ‘Weight,’ and ‘WEIGHT’ will be accounted as 3 separate
+   variables.

# Assigning Value to Variables

In Python, multiple variables can be assigned DISTINCT values in a single
code line, as shown in the example below:

```
A, B, C = ‘violet,’ maroon, ‘teal’
print (A)
print (B)
print (C)
```

OR multiple variables can be assigned SAME value in a single code line, as
shown in the example below:

```
A, B, C = ‘violet’
print (A)
print (B)
print (C)
```
