# **Python Tuples**

In Python, Tuples are collections of data types that cannot be changed but
can be arranged in a specific order. Tuples allow for duplicate items and are
written within round brackets, as shown in the syntax below.

```
Tuple = ("string1", "string2", "string3")
print (Tuple)
```

Similar to the Python List, you can selectively display the desired string
from a Tuple by referencing the position of that string inside square bracket
