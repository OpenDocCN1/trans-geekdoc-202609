You can selectively display desired item value from a Dictionary by referencing to its key inside square brackets in the print command as shown below.

```
dict = {
"key01": "value01 ",
"key02": "value02",
"key03": "value03",
}
X = dict ["key02"]
print (X)
OUTPUT - value02
```
