
# 安全工具与渗透测试概述

## 开源漏洞扫描与渗透测试框架

*   **OpenVAS** (`openvas.org`) 是一款适用于 Linux 和 Windows 的开源漏洞扫描器，它是现已商业化的 Nessus 最后一个免费版本的分支。作为一个完整的漏洞管理解决方案，该工具使用 SCAP，可以执行多种网络漏洞测试 (NVT) 并查找常见漏洞和暴露 (CVE)。该产品有一定的学习曲线，但它是一款备受推崇且功能强大的工具，值得考虑。

*   **Metasploit** (`metasploit.com`) 是最流行的开源渗透测试框架之一。它适用于 Windows 和 Linux 环境。它通常用于识别和验证网络漏洞，包括模拟利用人为漏洞的攻击，如图 9.15 所示。Metasploit 还可用于对发现的网络漏洞的响应进行优先级排序。

    ![图 9.15 Metasploit 操作](images/c09f015.png)

    **图 9.15** Metasploit 操作

*   **浏览器利用框架** (`beefproject.com`) 是另一款著名的开源渗透测试工具，但它专注于通过 Web 浏览器进行的 Web 承载攻击。BeEF 适用于 macOS、Windows 和 Linux。

其他值得评估的安全产品包括 Nessus、Core Impact 和 Nexpose。还有专用的硬件解决方案，如 nGenius 的 Netscout，为监控网络服务和性能提供严肃的解决方案。每个网络都应始终启用某种形式的监控，每个网络管理员也都应有权访问可靠的数据包嗅探工具。

上述提到的软件工具对黑客和网络工程师同样有用。网络工程师可能会使用它们来发现其网络设备的各种问题。然而，对黑客而言，这些信息可能更具启示性。他们使用这些工具开始描绘网络的拓扑结构、哪些系统在使用哪些协议，甚至可能发现包含敏感信息的未加密数据。
