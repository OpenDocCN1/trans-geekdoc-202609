

# PLC 输入与输出

PLC 输入端连接传感器——温度、压力或位置开关——用于监测工艺变量。在等式的另一端，PLC 的输出端子连接执行器——继电器、电磁阀或机械定位器——这些是用于控制工艺变量的设备，如[图 1.6](#c01.xhtml#c01-fig-0006)所示。

该图描绘了 PLC 及其传感器和执行器的`点对点布线`方案。它还表明，PLC 与其设备之间的单独连接可通过遍布生产车间的布线架和接线盒来实现。然而，每个设备均通过一根专用电缆连接到输入或输出端子。

PLC 有不同的外形规格，包括紧凑型设备和通过`背板`系统连接并安装在公共`机架`中的模块化单元。[图 1.7](#c01.xhtml#c01-fig-0007)描绘了一款典型的紧凑型 PLC。它是一个独立的处理单元，其顶部边缘提供输入端子，底部边缘提供输出端子，左下角提供电源连接。该图还展示了该 PLC 型号通过其串行通信端子以及传统的以太网网络连接，与其他设备连接的预留接口。

## 常见 PLC 模块类型

常见的 PLC 模块类型包括以下几种：

*   **电源单元 (PSU) 模块**：该单元通过背板总线为 CPU 和 I/O 模块供电。PLC 电源通常为其组件提供 24Vac 电压。
*   **中央处理单元 (CPU) 模块**：这是相当于个人计算机主板的 PLC 核心部件。它包含微处理器、RAM 和 ROM 存储器、I/O 接口电路以及通信支持。
*   **输入模块**：可安装在 PLC 机架中的输入模块有两种基本类型：模拟量输入模块和数字量输入模块。
    *   **模拟量输入**：模拟量输入模块设计用于配合传感设备（如热电偶和压力传感器）工作，这些设备在最小值和最大值之间产生连续变化的输出值范围（如 0–10V）。由于基于微处理器的控制设备无法理解模拟信号，因此模块必须对信号执行 A/D 转换过程，以获得 CPU 可处理的测量模拟值的数字等效值。
    *   **数字量输入**：此类模块用于处理离散的数字量输入设备，如行程开关、光电开关、接近开关，以及任何提供两态输出的其他设备。这些模块可处理从 8 个设备多达 128 个设备。
*   **输出模块**：与输入模块一样，输出模块也有两种基本类型：模拟量和数字量。
    *   **模拟量输出**：这些输出提供模拟信号，可用于驱动模拟执行器，如阀门定位器。为了产生此类输出信号，模块必须在从 CPU 接收到的数值上执行 D/A 转换过程，然后才能将其应用于输出端子。
    *   **数字量输出**：这些模块提供开/关输出信号，用于控制两位置执行器。与数字量输入模块一样，数字量输出模块可提供从 8 到 128 个不同的输出连接。
*   **通信模块**：这些是允许 CPU 通过背板的 I/O 总线与其他智能设备通信的通信模块。历史上，这一直通过标准异步串行通信协议（如 RS-232 和 RS-485 通道）来完成。然而，更新的工业通信选项正被引入 PLC 通信中，包括不同的 IT 和电话协议，如基于以太网的 TCP/IP 通信、蓝牙和 Zigbee。

## 远程遥测单元

另一种常见的工业控制器是`远程遥测单元`，通常简称为 `RTU`。RTU 是部署在工艺过程或一组工艺过程中的选定位置的小型智能控制单元，用于从不同传感器收集数据并发送命令以控制继电器输出。[图 1.9](#c01.xhtml#c01-fig-0009)展示了一款典型的 RTU。

![FIGURE 1.9 An RTU controller](images/c01f009.png)

[**图 1.9**](#c01.xhtml#R_c01-fig-0009) RTU 控制器

与 PLC 一样，RTU 可以使用数字或模拟量输入传感器设备，旨在测量电流和电压、压力、光照度、流速、液位、浊度、pH 值、旋转速度等变量。模拟量输入接受给定范围内来自传感器的输入信号。常见的模拟量输入信号范围包括 0 到 1mA 或 4 到 20mA 电流范围，或 0 到 10Vdc 电压范围，以及 +/-2.5V 或 +/-5.0V 范围。对于产生超出这些参数信号范围的传感器类型，必须在传感器和输入端口之间安装某种信号电平转换接口设备。这些行业标准的信号传输方法和范围由不同的设备制造商根据不同应用中使用的传感器进行选择。

电压信号传输用于许多传感器应用，因为它的实现相对简单。然而，电压信号传输易受电气噪声干扰和传输距离限制的影响。电流信号标准历史上一直是传输传感器信息的公认方法，因为其响应比电压信号方法更线性，且提供更强的抗噪能力。

虽然曾出现过不同的电流环标准，但 4 到 20 mA DC 电流标准一直是工业传感器市场的首选标准。该标准提供线性信号响应、良好的抗噪能力、更长的传输距离，以及对人员和危险环境条件的本质安全性。

RTU 还可以提供模拟量和数字量输出，以配合各种不同的控制设备工作。然而，模拟量输出在 RTU 中不常用。数字量输出根据管理工艺的需要，为电路、电磁阀、灯、加热器等执行器提供开/关控制。确实提供模拟量输出通道的 RTU 可用于对阀门定位器和加热元件等设备提供连续变化的控制。

与 PLC 不同，RTU 并非设计为独立控制器。相反，它们更适合广泛分布式控制系统中的操作。虽然它们拥有内部存储器并能控制局部活动，但它们设计用于在分布式或基于 SCADA 的控制系统中与监控控制器协同工作。不过，它们也可以接收来自本地 IED 控制器的工艺数据。
