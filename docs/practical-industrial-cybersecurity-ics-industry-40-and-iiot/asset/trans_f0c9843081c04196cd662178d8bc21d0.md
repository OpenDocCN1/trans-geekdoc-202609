

# 交换机和 VLAN

交换机还可用于创建逻辑上安全的 `虚拟局域网` (`VLAN`)。`VLAN` 是一种安全拓扑，通过限制网络数据包的移动，使其仅在指定端口之间传递，从而限制网络流量的可见性。

网络交换机通常根据其配置选项分为两类。`非托管交换机` 是 `即插即用` (`PnP`) 设备，不包含任何用户配置选项。这些设备通常价格低廉，旨在用于家庭和小型办公室环境，因此极少在企业 IT 网络中发现。

另一类交换机称为 `托管交换机`。这些设备内置可编程管理功能，使管理员能够针对其将要使用的特定网络环境进行配置。因此，它们提供某种管理控制台供管理员设置参数。常见的管理接口包括以下几种：

*   **命令行编程**：此格式提供了一种直接的基于文本的方法来编程交换机的设置。命令行编程要求管理员了解可用于设置不同参数的 `指令集` 和参数变量。
*   **基于浏览器的界面**：这些界面提供了一种图形化的、菜单驱动的工具，用于设置关键交换机参数。使用 `简单网络管理协议` (`SNMP`) 工具，允许管理员通过远程客户端的 Web 浏览器访问交换机的参数。

# 路由器

`路由器` 是网络连接设备，其转发网络信息的方式与交换机类似。然而，与交换机不同的是，路由器可以跨不同网段转发信息，如 [图 3.13](#c03.xhtml#c03-fig-0013) 所示。这使路由器能够通过一种称为路由的过程将不同的网络连接在一起。例如，路由器通常用于将小型住宅网络连接到世界上最大的网络——互联网。

![图 3.13 网络路由器](images/c03f013.png)

[**图 3.13**](#c03.xhtml#R_c03-fig-0013) 网络路由器

路由器是基于微处理器的智能设备，用于控制网络间的数据流。微处理器是一种专用设备，经过优化可作为 `路由处理器` 运行。与其他基于微处理器的设备一样，路由器包含用于启动的 `ROM BIOS`、用于保存操作配置参数的 `NVRAM CMOS` 配置区，以及存储在闪存单元中的板载操作系统。

路由器还包含不同区段的 `DRAM` 内存，用于存放消息路由信息，并在其端口间缓冲数据流。路由信息存储并更新在一个称为 `路由表` 的逻辑内存表中。

每个网段均通过路由器的一个物理端口接口连接。这些接口可实现为不同类型的物理/逻辑接口规范，例如 `RJ45/8P8C` 以太网连接端口。

几乎所有路由器都具有一个物理接口，可用于连接外部控制台电缆以进行配置。它们还可能包含一个异步 `RS-232` 串行硬件端口，供管理员执行远程路由器管理功能。

在大型网络中，路由器使用 `路由协议` 与其他路由器通信，以构建和维护其路由表。这些表用于记录不同网络位置之间的最佳路由。与交换机中使用的 `MAC` 表不同，路由表存储设备间路径的地址和跳数信息。

# 安全分区模型

`安全区域` 是一个网段，根据网络资产（资源和数据）的安全漏洞或关键性，为其提供特定级别的安全性。其理念是将更有价值或更关键的网络资产置于提供更多保护的网段或安全结构中。`网络分段` 也称为 `分区`，安全计划的各个层称为 `安全区域`，如 [图 3.14](#c03.xhtml#c03-fig-0014) 所示。

`安全拓扑` 由组织的各个网络安全区域互联组成。安全拓扑超越了简单的网络拓扑，因为它们专门设计用于保护网络每个唯一网段内的关键资产。必须完整规划并实施互补的网络策略和安全拓扑，才能为组织资产提供有效的运行和安全性。

![图 3.14 网络分区](images/c03f014.png)

[**图 3.14**](#c03.xhtml#R_c03-fig-0014) 网络分区

良好的安全拓扑旨在将组织资产（如服务器、防火墙、路由器、交换机和客户端工作站）定位并连接在受保护的网段内，以防止未经授权的访问或攻击。

组织的安全拓扑必须基于其安全目标的总体意图。这些目标通常由产品安全官或系统信息安全官 (`CISO`) 确定。他们负责在网络的安全风险与预算限制之间取得平衡，将这些风险降低或最小化至可接受的水平。这需要周密的规划、部门协调、员工认同和管理层支持。

例如，某组织可能需要宽松的远程访问和互联网连接以有效开展业务。因此，在整个组织中严格限制远程访问和互联网访问将不是该组织可接受的选择。

然而，逻辑上需要受限访问的组织部门，如产品开发、会计、人力资源和高管部门，可通过实施网络分段来创建提供网络隔离的特殊安全区域，从而使其更加安全。

应创建可视化拓扑图，以显示服务器、防火墙、路由器、交换机和 `VLAN` 等关键资产，以及它们支持的子网、安全区域或部门。该图应清晰标识分段网络和采用静态 `IP` 地址配置的设备。将所有这些要素以图形格式显示后，设计缺陷应变得显而易见，从而允许将关键资源重新定位到更合适的区域或部门。

大多数 IT 网络分区的逻辑模型可视为类似于 [图 3.15](#c03.xhtml#c03-fig-0015) 所示的多层 `信任区域` 安排。在此示例中，有四个安全区域按安全要求递增的顺序呈环状排列。内部区域存放最安全的资产，受周围安全层的保护。同样，每个后续层为其相邻的环提供安全保护。

![图 3.15 分层区域](images/c03f015.png)

[**图 3.15**](#c03.xhtml#R_c03-fig-0015) 分层区域

通常，给定的安全区域将由具有共同安全特征的相似网络资产组成。这些特征包括共享的数据机密性和完整性要求、访问控制，以及审计、日志记录和监控要求。然而，每个区域可包含任意数量的子网，并覆盖任意数量的物理位置。通常用于创建区域间 `分区` 的技术包括交换 `VLAN`、防火墙或路由器等设备，如 [图 3.16](#c03.xhtml#c03-fig-0016) 所示。
