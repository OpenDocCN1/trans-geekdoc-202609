
# 密码攻击与无线攻击

## 暴力破解攻击

**暴力破解攻击**涉及使用工具（如 `John the Ripper`、`ophcrack` 或 `hydra`）针对用户登录运行密码列表。这些工具在企业环境中被合法用于测试员工密码，但攻击者也经常使用这些相同的工具进行同样的操作。

密码列表通常由各类安全人员生成，包含常用密码及其各种变体。在暴力破解攻击中，攻击者利用算力对提供的密码列表中的每个密码进行哈希计算。这可能耗费大量时间。因此，当预期目标使用短小、简单的密码时，这种攻击方法最为适用。

然而，**彩虹表**可提供一种更优雅高效的密码攻击方法。这些是预生成的表格，包含数百万个已哈希的密码。由于大多数主机系统都包含哈希密码文件，因此可以将其与彩虹表提供的哈希内容进行比对，以期找到匹配的密码。

## 密码捕获

**密码捕获**，有时也称为**凭据收集**，是一个非常直接的过程。攻击者必须以某种方式在密码发送过程中将其拦截。一种常见的实现方式是通过中间人攻击或网络钓鱼。

此类攻击最常用的工具是本章前面所述的社会工程学工具包软件。如[图 5.29](#c05.xhtml#c05-fig-0029)所示，该软件包含多种不同的模块，可用于执行不同类型的攻击。凭据收集模块使用简单。它通过克隆一个选定的热门网站（或使用提供的网站），然后利用 `Apache` 进行托管。

![FIGURE 5.29 The Social Engineering Toolkit](images/c05f029.png)

**[图 5.29](#c05.xhtml#R_c05-fig-0029) 社会工程学工具包**

当受害者被引导至攻击机器的 IP 地址时，他们将看到克隆的网站并输入用户名和密码，这些信息随即会显示在 SET 终端上。随后软件会将他们重定向到实际网站，使其看起来就像只是密码输入错误。与此同时，攻击者已获取其用户名和密码，可随意利用。

要进一步升级该攻击，可将凭据收集攻击与 DNS 投毒攻击结合，将网站的 DNS 查询定向至攻击机器。这种组合攻击可使用名为 **Ettercap** 的软件工具实现。

在这种组合攻击中，受害者每当输入 `mywebsite.com`（或所用的任何网站）时，都会被定向至攻击者的网站。若不使用 Ettercap，攻击者就需要设法将攻击机器的 IP 地址提供给受害者。

## 字典攻击

**字典攻击**就是一种系统性的暴力破解攻击，使用字典中的每个单词作为密码。互联网上有许多预编译的字典文件和彩虹表来源，提供可用于攻击目标的用户名/密码组合。某些黑客工具（如 `Kali Linux`）也提供准备好的用户名/密码列表，可编辑后直接针对指定目标使用。

目前可用的最大此类列表是**多次泄露汇编**（COMB）数据库文件，包含超过 32 亿组唯一的 UN/PW 凭据。这些数据收集自全球过去的账户泄露事件，约占当前全球在线人口的 70%。当然，厂商默认的 UN/PW 组合也包含在内，且人们会在不同账户间复用相同密码。该数据库还包含用于运行攻击、查询邮箱和管理数据的 `bash` 脚本。

通过限制给定时间段内的登录尝试次数，即可轻松防御此类攻击。此外，可在该时段内禁止超过特定尝试次数的用户 IP 地址，直到管理员解除封禁。

击败字典攻击的另一种方案是强制实施严格的密码策略，要求密码不仅仅是字典单词。垃圾邮件发送者常利用此类攻击猜测电子邮件账户密码，以获取账户访问权限并用于垃圾邮件分发。

互联网上有一些公开网站（如 Cybernews 个人数据泄露检查器 `https://cybernews.com/personal-leak-check`），提供已知泄露凭据的信息。应定期查询这些网站，以确保当前使用的 UN/PW 组合未被泄露。

如前所述，**会话劫持**是通过窃取用户合法互联网会话中的 Cookie 来获取其计算机未授权访问权限的方法。这些 Cookie 用于向远程服务器验证计算机身份，并常规存储在用户计算机上以提供网页快速访问。

攻击者可使用数据包嗅探器捕获网络传输中的 Cookie 来窃取。若能通过欺骗手段访问受害者 PC（使其误信接收的代码来自受信服务器），也可从中窃取 Cookie 信息。一旦攻击者获得 Cookie 信息，即可访问其他特权信息。

使用多因素认证技术和工具，可确保即使攻击者持有 UN/PW 凭据也无法进入系统。此外，使用密码管理器可采用强密码凭据，从而有效管理用户。

## 无线攻击

由于通信方式的特性，**无线攻击**可能与有线网络攻击截然不同。用户必须将设备物理连接到网络端口才能接入有线网络，因此物理上靠近网络介质至关重要。而对于无线网络，这种物理邻近性则不那么重要。攻击者和合法用户一样，都可以坐在大楼前的停车场连接无线网络。

这种距离变量可通过各种创造性方法放大，例如使用**罐天线**（自制铁罐波导天线），如[图 5.30](#c05.xhtml#c05-fig-0030)所示。该设备使无线客户端能连接到比 Wi-Fi 通信预期距离远得多的网络。攻击者可舒适地坐在车内，从安全距离发起攻击。

正如有线网络安全一样，无线网络安全至关重要。由于无线网络更容易遭到窃听和数据包捕获，加密和安全通信的需求更为迫切。此外，利用弱加密漏洞仅需几秒钟。以下章节将深入探讨无线通信常见的被利用方式。

### 战争驾驶

**战争驾驶**是在人口密集区域步行或驾车搜寻开放或弱加密无线网络的过程。这通常是道德黑客侦察阶段的首批活动之一。

许多组织不太担心无线网络信号覆盖其建筑物和园区边界之外。
