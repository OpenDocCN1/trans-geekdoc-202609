

# 报告结构

## 执行摘要
执行摘要的目标受众应为公司的高管团队。本部分旨在相对非技术性，以便高管了解发生了什么以及为何需要变更。请记住，高管大多关注数字和金额，因此他们会想了解风险以及为何应投资于安全。

## 工作范围
工作范围将包含公司提供的任何信息以及评估的实施方式。它还将详细说明测试的具体目标和渗透测试的禁区。建议包含测试前确立的交战规则，以便高管和 IT 人员理解报告中为何以及如何能够针对这些系统。

## 项目目标
此部分看似冗余，但请记住，参与本报告的某些高管可能是首次接触，因此重申目标非常重要，以确保所有人达成共识。请注意，许多人不“懂技术”，可能不理解为何他们会参与本报告。然而，报告理应帮助他们看到风险分析和涉及的资金，并理解安全是每个人的责任。

## 假设
由于客户可能在测试开始前提供技术信息，因此做出某些假设是可以接受的，以便受众理解您的思维过程及得出特定结论的方式。

## 时间线
时间线可视为交战规则的一部分，定义了测试窗口的开始和结束日期。它还能让 IT 人员大致了解何时可能发生事件；若事件发生在该窗口之外，则绝非渗透测试人员所为。

## 发现摘要
发现摘要是客户高管的得力工具。优秀的摘要应包含以下内容：
- 统计数据
- 影响
- 风险评估

## 详细发现
详细发现部分的目标受众为公司的顶级 IT 人员。后续部分的信息将包含任何有助于理解发现的要素，包括图表和图形。

## 漏洞
本部分应列出每个漏洞的以下信息：
- 漏洞（可以是名称或简短描述）
- 威胁等级
- 影响
- 风险
- 附带详细信息的分析
- 缓解漏洞的建议

## 解决方案与建议
本部分汇总详细发现以及整体漏洞列表的影响和风险。此信息可用于量化漏洞的影响，以防发生事件导致信息泄露。

## 结束语
结束语部分是作者添加最终想法、建议并总结整体测试的地方。

# 安全测试工具

在上一章中，您了解了安全评估（或风险识别）的漏洞扫描和评估阶段中常见的三项活动。回顾一下，它们包括：

- **数据包嗅探**：使用数据包分析器，白帽捕获网络中移动的数据包，记录它们，然后解码其原始数据。随后可分析这些数据，实际上是在监视网络用户。
- **端口扫描**：使用端口扫描工具，渗透测试人员探测网络服务器和设备的开放端口以寻找可利用之处。他们还可以识别主机上运行的服务以进行潜在利用。
- **漏洞扫描**：使用`网络漏洞扫描器`套件，渗透测试人员扫描组织网络中的各类常见漏洞，如系统错误配置和默认密码使用，以及生成畸形数据包以制造 DoS 攻击。

这些及其他网络测试工具使白帽能更轻松地审计网络，以了解其资源、评估风险、评估漏洞，并制定缓解（或利用）这些风险和漏洞的计划。

## 数据包嗅探器

`数据包嗅探器`（也称为`数据包分析器`或`协议分析器`）是一种软件监控工具，用于扫描通过它的网络流量。运行这些工具的计算设备通常插入网络，使网络流量流经它，从而实时捕获数据包，如[图 9.7](#c09.xhtml#c09-fig-0707)所示。当网络流量通过分析器时，分析器会“嗅探”数据包，寻找混杂活动或仅记录发生的情况。

数据包/协议分析器需要两个网络接口，以便在流量流经时检查网络活动。因为它们不需要巨大的 CPU 资源，支持两个以太网接口的旧笔记本电脑可能是理想选择。性能监控产品也可在旧硬件上运行，是利用闲置老旧计算机硬件的好方法。

## 网络枚举/端口扫描

无论遇到何种情况，优秀的安全从业者（或黑客）首先做的都是`枚举`网络。这意味着绘制网络图以确定网络上有什么，从而知道能发现哪些主机。

执行此操作可发现各类信息，包括网络上可能存在不应存在的设备。例如，假设您是医院的网络安全工程师，正在进行例行网络扫描。得益于映射和枚举软件，您发现网络上连接了一个`Raspberry Pi`，如[图 9.8](#c09.xhtml#c09-fig-0007)所示，这绝对不应该存在。

![图 9.8 网络枚举](images/c09f008.png)

**[图 9.8](#c09.xhtml#R_c09-fig-0007)** 网络枚举

因为您了解网络的设置，且三层交换机拥有特定的 DHCP 范围，所以能精准定位设备连接的交换机。您能迅速禁用交换机上的该端口。在本案例中，准确掌握网络资产使您察觉到一个严重的安全问题。

枚举网络的方法和工具多种多样。`Nmap`是最常见的此类工具之一，可用于扫描各种规模的网络，以查找不同类型的网络信息，如每个主机运行的操作系统、潜在的开放端口，或特定网络上的主机。

[图 9.9](#c09.xhtml#c09-fig-0008)展示了`Nmap`工具生成的输出，用于映射网络和收集信息。本例中，使用命令`nmap 10.0.0.0/24 -O`生成了网络扫描结果，并尝试揭示设备的操作系统。

![图 9.9 Nmap 输出](images/c09f009.png)

**[图 9.9](#c09.xhtml#R_c09-fig-0008)** Nmap 输出

如您所见，此次扫描发现一台运行 OS X 或 iOS 且开放多个端口的设备。从攻击者角度看，若您能在设备上安装`Nmap`并将其置于网络中，将获得极佳的网络视野。

以下是其他值得注意的网络枚举工具：

- **NBTscan**：一种基于 CLI 的信息枚举实用程序，可从目标网络检索用户列表、设备列表、共享列表、名称列表、组/成员列表和密码信息。
