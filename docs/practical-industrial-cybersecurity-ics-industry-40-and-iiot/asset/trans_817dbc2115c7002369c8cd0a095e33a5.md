

# 术语表

## R

**race condition**  
: 当攻击者利用多用户/多任务环境中连续事件的时序，在事件之间插入恶意代码到系统中时，就存在**竞争条件**。

**radio frequency identification (RFID)**  
: RFID 系统利用自供电的 RFID 标签，可用作信标来追踪位置或验证邻近性。

**rainbow tables**  
: 包含数百万个哈希密码的预生成表，用于通过比对来破解用户账户的密码。

**reconnaissance**  
: 黑客熟悉目标并开始寻找潜在途径进入目标关键基础设施的第一步，无论是手动还是数字化方式。黑客通常会花费更多时间对目标进行**侦察**和研究，而不是实际利用漏洞。

**red team**  
: 就渗透测试而言，这是一个独立小组，负责对指定组织的网络发起挑战或进行测试。

**reflection servers**  
: 用于 DDoS 攻击，发送伪造的回显请求，并将回显应答指向受害者。

**regress**  
: 就安全而言，该术语用于描述重新进入财产的合法权利。

**relay**  
: 一种机电开关设备，用于控制电路的运行。

**remote access control**  
: 一种设计特性，要求对试图从远程位置访问安全区域或计算机系统的用户身份进行认证。

**remote access monitoring**  
: 当事件或事故发生时，用于通知监督安全人员的系统。

**remote access trojan (RAT)**  
: 一种恶意软件程序，为系统提供后门，并可从远程位置授予管理控制权。

**Remote Authentication Dial In User Service (RADIUS)**  
: 一种网络协议，提供集中式 AAA 协议（认证、授权和审计）。

**remote monitoring**  
: 从远程位置或控制室对设备进行监控或测量。

**remote notification systems**  
: 当存在报警条件时，这组系统将协调并通知相关方。

**remote telemetry unit (RTU)**  
: 部署在流程或一组流程中的选定位置的小型智能控制单元，用于从不同传感器收集数据并发送命令以控制继电器输出。

**repeater**  
: 一种网络硬件设备，用于扩展网络的范围和覆盖距离。

**replay attack**  
: 一种网络攻击，攻击者重放或延迟已记录的传输以获取访问权限。

**rerouting attack**  
: 一种网络攻击，试图将流量从其有效目的地重定向（重新路由）到一个虚假目的地。

**reverse proxy server**  
: 一种处理 Web 资源公共请求，然后将其转发给一个或多个服务器的服务器。

**right**  
: 由公认的权威来源授予某人或某群体的合法特权或许可。

**risk**  
: 价值对象遭受损失的可能性。也可表示为与不确定性的故意交互。**风险**也可计算为一种可向组织内部和外部利益相关者传达的量化指标。

**risk assessment**  
: 一个系统性过程，包括了解风险事件在组织网络不同领域发生的可能性及其造成的影响。

**risk mitigation**  
: 采取必要步骤，降低风险敞口的程度和/或其发生的可能性。

**risk tolerance level**  
: 个人或企业认为可容忍的风险水平。

**role-based access control (RBAC)**  
: 一种使用工作角色来区分权限和特权的访问控制方法。

**rootkits**  
: 一种旨在在不被检测到的情况下获取计算机系统管理控制权的软件类型。Rootkit 可能存在于硬件或软件中，通过攻击 BIOS、引导加载程序、操作系统内核，有时还包括应用程序或库来实现。

**router flood attacks**  
: 路由器容易受到洪水攻击，此类攻击旨在耗尽其所有或大部分资源，从而使其失去功能。

**routers**  
: 网络连接设备，与交换机不同，可跨不同网段转发信息。这使路由器能够通过称为路由的过程将不同网络连接在一起。

**routing**  
: 选择在网络上或网络之间传输数据的最佳路径的过程。

**routing protocol**  
: 路由器用于确定数据传输的适当路径的一组规则。

**routing table**  
: 路由器用于存储和更新路由信息的数据库。

**RS-232 asynchronous serial communication standard**  
: 一种用于串行通信传输数据的标准。

**rule**  
: 在网络中，要移动数据包通过设备，必须在设备上显式创建一条规则，以将所需的协议端口转发（或映射）到局域网中的专用 IP 地址和端口。

**rule-sets**  
: 通常基于数据源和目标信息、数据类型或数据内容的规则。它们用于控制何种类型的信息可以在安全区域之间移动。

**rule-based access control (RBAC)**  
: 一种基于规则的访问控制模型，规则根据账户持有者在组织中的角色分配给账户。规则是角色的基本要素。规则定义角色可以执行的操作。也称为自动化配置。

**rule-based anomaly detection**  
: 一种检测方法，通过分析审计记录根据过去的使用模式生成规则。系统随后监控流量，寻找与创建的规则不匹配的模式。

## S

**safety instrumented system (SIS)**  
: 一种工业控制系统，旨在监控关键过程并对其进行控制，以安全为主要目标。

**sanitize**  
: 使硬盘驱动器上的数据不可恢复，方法是多次覆盖数据和/或物理销毁驱动器，使其无法重组。

**satellite communications**  
: 许多公司在其总部和现场站点之间采用极小口径终端 (VSAT) 卫星通信来传输监控数据。这些系统是自包含的，不涉及公共电话系统等第三方技术。

**script**  
: 一个命令列表，能够在无需用户交互的情况下执行。

**script kiddies**  
: 使用他人开发的现成脚本或程序攻击系统的个人。

**Secure Remote Password (SRP)**  
: 一种协议，是 PAKE 的增强形式，旨在规避现有专利。

**Secure Shell (SSH)**  
: 一种用于安全客户端-服务器连接的加密网络协议。旨在替代 Telnet 等不安全的 Shell 协议，SSH 采用公钥加密认证。

**Secure Sockets Layer (SSL)**  
: 一种用于管理客户端和服务器之间认证和通信的协议，同时使用公钥和私钥。SSL 使用套接字方法在客户端和服务器程序（通常是网站和浏览器）之间交换数据。

**security**  
: 建立一套对个人、系统、媒介、内容和对象进行排除和包含的科学、技术和艺术。

**security associations (SAs)**  
: 在两个网络设备之间建立共享属性，以支持安全连接。
