
# 术语表

## A

**authoritative name server**

: 提供对 DNS 查询的权威回答，而非来自缓存或通过向另一台名称服务器请求该信息的服务器。

**authorization**

: 用户有权访问的资源以及他们可以执行的操作。

**automated access control**

: 一种设计特性，要求对试图从远程位置访问安全区域或计算机系统的用户身份进行认证。

**automated provisioning**

: 一种类似于基于规则的访问控制的方法，其中规则是基本元素。规则定义了可以执行的操作。

## B

**backup media**

: 存储数据备份的介质，例如磁带或 DVD-R。

**backup policy**

: 定义备份什么、何时备份以及将备份存储在何处的策略。还包括谁拥有备份的授权以及如何制作备份。

**barriers**

: 阻碍入侵者从外围推进到内部区域的障碍物。也称为防撞柱。

**bastion host**

: 设计用于位于 DMZ 中的特定计算机，可以是防火墙、路由器、服务器或一组不受另一防火墙保护但可直接访问互联网的计算机。

**beacon frames**

: `802.11` 无线局域网中的管理帧，让附近的客户端知道它们正在广播什么网络。

**beacon interval**

: 广播信标帧之间指定的时间间隔。

**biometrics**

: 使用人体物理特征来验证个人身份的访问控制机制。利用一个人的独特身体特征（指纹、声纹和/或视网膜扫描）来提供身份识别和认证。

**BitLocker**

: 某些 Windows 操作系统上的原生实用程序，提供全磁盘级加密。

**black-hat hacker**

: 拥有广泛网络安全技能并将其用于绕过或突破网络安全结构以达到恶意或犯罪目的的个人。

**blacklisting**

: 一种仅拒绝符合给定标准（基于用户、软件、系统）的用户访问的方法。

**block cipher**

: 一种将算法应用于数据块而非单个比特的密码。

**Blowfish**

: 一种使用对称密钥加密的分组加密算法。

**blue team**

: 渗透测试中通常作为目标的团队。

**Bluetooth**

: 用于个人区域网络（PAN）的无线网络规范，将包括手机、数码相机、PC、笔记本电脑和打印机在内的个人设备组网在一起。

**bot herder**

: 控制僵尸网络的未授权人员。

**botnet**

: 由僵尸网络控制者控制的大量僵尸或机器人的集合。

**bots (zombie computers)**

: 由未授权人员控制的 PC、IoT 设备或其他智能可编程设备。

**bring-your-own-device (BYOD)**

: 授权员工使用自己的设备而非公司提供的设备进行业务相关活动。

**broadcast storm**

: 每个网络设备重新广播广播流量，最终导致流量传递失败。这会迅速使交换机和路由器过载并压垮网络。

**broadcast traffic**

: 向网络上所有可能的目标发送消息。

**Browser Exploitation Framework (BeEF)**

: 一个著名的开源渗透测试工具，专注于通过 Web 浏览器进行的 Web 攻击。

**brute-force attack**

: 攻击者使用应用程序基于已知列表或预测性数学方案系统地猜测密钥或密码。这可能涉及数百或数千次尝试。

**buffer overflow**

: 程序越过缓冲区边界的异常，导致行为异常、内存访问错误和/或系统崩溃。系统实际上被禁用，用户无法使用。

**buffer overflow attack**

: 旨在导致计算系统出现缓冲区溢出状况的攻击。

**Building Automation and Control Network (BACnet)**

: 由美国采暖、制冷与空调工程师学会开发的协议，用于将楼宇自动化设备联网在一起。

**business continuity plan**

: 描述组织在发生破坏性事件时的准备工作、增长计划和未来规划的文档。

**business-to-business (B2B)**

: 组织用于与其他受信任组织进行安全交易的网络渠道。

**bypass mode**

: 许多报警系统中可用的一种模式，旨在让人员通过报警区域而不触发报警。在不影响系统其余部分的情况下关闭或禁用传感器、设备或整个区域。

## C

**C2 channel**

: C2 通道（命令与控制）使攻击者能够直接与受损主机交互，这会使威胁变得非常危险，因为攻击者可以响应缓解威胁的尝试。

**cache poisoning**

: 攻击者建立一个流氓 DNS 服务器，然后利用该服务器向主 DNS 服务器反馈虚假信息，从而污染主 DNS 服务器的缓存资源。

**caching servers**

: 代理服务器使用缓存的网页，将已访问的网页从其缓存中提供给请求客户端，而无需访问互联网。

**caching web proxies**

: 缓存（存储）Web 资源以便更快访问的本地服务器。

**certificate chain**

: 证书列表，从根证书开始，随后是每个后续证书，其中一个证书的颁发者或签名者是下一个证书的主体。

**Challenge-Handshake Authentication Protocol (CHAP)**

: 使用三次握手（SYN、SYN-ACK、ACK）识别远程客户端的认证方法。`CHAP` 用于认证用户或网络——挑战、响应、成功或失败——它可防止重放攻击。

**chokepoints**

: 人员或其他交通必须通过的门户位置，例如大门、门口、走廊或通道/道路，可能导致单点故障。

**chroot**

: 一种基于 Linux 的命令，用于调整当前正在运行的进程的根目录位置。也可用于创建和管理操作系统的多个虚拟化副本。

**cipher**

: 在密码学中，密码是用于加密数据的算法。

**cipher locks**

: 当用户在密码锁键盘上输入正确的编程代码时，通过解锁磁性门锁来操作的锁。

**ciphertext**

: 经过加密密钥编码后的任何数据的文本。

**Cisco Discovery Protocol (CDP)**

: `CDP` 协议使思科设备能够与其他思科设备通信以交换信息。攻击者可以使用此协议收集网络上运行 `CDP` 的交换机和其他网络设备的信息。

**cleartext**

: 未加密的存储或传输数据。

**clickjacking attack**

: 采用欺骗性框架技术诱使用户点击其内容而非预期内容的攻击。

**client-server model**

: 基于集中式、控制型服务器设备的网络模型，该设备为连接到网络的若干客户端设备提供服务。

**cloud-based services**

: 具有特殊客户端应用程序软件的托管服务，可将用户的桌面或移动文件和数据存储扩展到互联网服务。
