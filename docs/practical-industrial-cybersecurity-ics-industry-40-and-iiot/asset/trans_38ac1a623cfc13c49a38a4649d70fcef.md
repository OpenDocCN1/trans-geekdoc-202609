

# 安全设备

集网关、防病毒、防火墙、入侵防御和检测服务于一体的安全设备。

# 通用即插即用 (UPnP)

一种零配置网络架构，可在不同品牌和类型的网络硬件之间带来一定程度的兼容性。虽然主要旨在帮助非专业的家庭网络用户，但一些非消费级硬件制造商也支持 UPnP。

# UNIX

UNIX 操作系统系列提供模块化、多任务、多用户的操作系统环境，最初是为在大型机和小型计算机上运行而开发的。UNIX 操作系统的专有版本包括多种 BSD（Berkeley Software Distribution，伯克利软件发行版）变体，以及 Apple 的 macOS 和 iOS 操作系统和 Google 的 Android 操作系统。

# UNIX 文件系统

这是为原始 UNIX 操作系统设计的第一种文件结构，至今仍在 UNIX 及其衍生版本中使用。该文件系统标准的结构呈现统一的树形结构，从称为根目录（`/`）的主目录开始。

# 解锁状态监控

状况监控系统可在特定大门或门被解锁（授予访问权限）时进行记录和发出信号，指示并记录授予了哪种类型的访问权限。

# 无标签数据包

未在数据包头部插入 VLAN ID 的数据包。

# 更新

提高操作系统可靠性、安全性或易用性的服务包或补丁。操作系统更新最可靠的来源是操作系统制造商。某些更新可能会使操作系统更方便，但不一定更安全。

## V

# 变焦镜头

包含多个可移动元件的光学组件，允许改变监控摄像头的有效焦距 (EFL)。与变焦镜头（zoom lens）不同，变焦镜头（varifocal lens）在每次变更时都需要重新聚焦。如果配备变焦镜头，可根据用户偏好在多个毫米设置下进行聚焦。

# 视频监控系统

大多数商业安全系统的重要组成部分。该系统利用摄像头进行预防和恢复。

# 虚拟访问控制列表 (VACL)

过滤进入 VLAN 的流量，以及过滤 VLAN 成员之间流动的流量的访问列表。

# 虚拟局域网 (VLAN)

在数据链路层进行隔离的软件配置网络。

# 虚拟专用网络 (VPN)

远程用户可以通过公共网络（如 Internet）连接到专用网络，然后进行身份验证并在专用网络上执行任务，就像直接连接一样。它使用户能够跨公共网络与另一台设备通信，就像在专用网络中一样，从而确保安全性。

# 病毒

旨在在本地计算机环境中复制和传播的恶意软件程序。这最常发生在用户从 Internet 下载程序或打开电子邮件附件时。

# 语音钓鱼

利用电话进行网络钓鱼攻击。

# VLAN 跳跃攻击

这些攻击也称为交换机欺骗攻击，涉及攻击者向交换机发送动态中继协议 (DTP) 请求，将攻击者的端口配置为中继连接。配置完成后，该连接会将所有 VLAN 中的流量路由给攻击者。

# VLAN 中继协议攻击

这些攻击针对思科的二层 VLAN 中继协议 (VTP)。该协议提供跨整个网络的交换机之间自动 ISL/802.1Q 中继配置，以便它们可以共享数据包。VTP 的自动化特性默认提供对网络所有 VLAN 的访问。它可用于从网络中添加或删除 VLAN。这使得带有中继端口的交换机容易受到攻击。

# 漏洞

可能允许攻击者访问网络资产的任何弱点。

# 漏洞评估

识别和确定网络或系统中已知漏洞优先级的过程。

# 漏洞模拟器

用于渗透测试的训练模拟器。

# 漏洞扫描器

基于数据库的工具，旨在搜索计算机中已识别并添加到数据库中的已知漏洞。它们旨在评估计算机系统、网络和应用程序。

## W

# 武器化阶段

将收集的信息应用于创建用于发动攻击的工具的阶段。

# Web 代理

代表主机或主机网络访问 Web 的计算机或服务器。

# Web 服务器

企业用于托管网页以在 Internet 上宣传其组织的服务器。这些是直接与 Internet 打交道的前端服务器。

# 鲸钓攻击

一种针对高知名度最终用户（如企业高管、政客或名人）的个性化网络钓鱼形式。就像任何网络钓鱼攻击一样，鲸钓攻击的目标是通过伪造的电子邮件和其他社会工程学手段，诱骗个人泄露个人或公司信息和数据。

# 白盒

一种渗透测试，其目标是模拟恶意内部威胁，此类威胁将深知客户的关键网络基础设施并拥有访问凭据，而非破坏其功能。

# 白帽黑客

利用其在攻破和渗透计算机网络及安全系统方面的专业知识，用于良好、道德且最重要的是合法目的的黑客。

# 白队

监督并了解渗透测试的小组。有时称为蓝队。

# 白名单机制

仅允许符合某些标准或通过身份验证的用户拥有访问权限的过程。

# 白名单

受信任拥有特定权限、服务或资产访问权的用户注册表。

# WiGLE

一个在线数据库，用户使用并贡献数据，以追踪和记录无线网络信息。

# WiMAX

全球微波接入互操作性；一种宽带无线接入标准，旨在跨大型地理区域（如城市、县，在某些情况下甚至是国家）提供 Internet 接入。

# 无线接入点 (WAP)

允许无线客户端连接到有线网络的网络连接设备。

# 无线网络

任何不使用传统布线方案连接的网络。它使用高频无线电波连接计算机节点。IEEE 组织在 IEEE-802.xx 旗下监督一组无线网络规范。

# Wireshark

一款开源且跨平台的网络协议分析器。这是最知名的协议分析器之一，支持几乎所有协议。

# 蠕虫

通过网络连接传播的恶意软件程序。蠕虫搜索应用程序中的漏洞以加以利用，一旦蠕虫利用了漏洞，它就会寻求复制到网络上的另一台计算机。有时被称为网络病毒。

## Z

# 零日攻击

利用零日漏洞的攻击。

# 零日漏洞

产品供应商未知的漏洞，因此没有可用的补丁来缓解其影响。

# Z-Force

一种数据包拦截和注入工具，用于攻破和利用 Z-Wave AES 加密。

# Zigbee

一种标准，即无线、网状组网的 PAN 协议，提供 10 米通信范围，数据传输速率为 250Kbps。Zigbee 标准已被智能家居自动化和工业控制社区，以及智能电网联盟的多个领域所采用。

# ZigBee 联盟

一个开放的非营利协会，致力于开发新的 ZigBee 标准。

# 僵尸主机
