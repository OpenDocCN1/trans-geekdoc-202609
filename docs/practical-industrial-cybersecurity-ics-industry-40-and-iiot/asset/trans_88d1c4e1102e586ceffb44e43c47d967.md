#### 中间人攻击

在中间人攻击中，攻击者监控网络，并根据预期攻击的性质执行不同活动。一种可能是攻击者使用 ARP 欺骗拦截本应发送给路由器的流量。当受害设备发出广播帧时，如[图 5.28](#c05.xhtml#c05-fig-0028)所示，攻击者接收该帧并回送自己的信息，导致受害者误以为攻击者才是信息的真实目的地。

当受害者将信息发送给其预期目的地时，攻击者会接收并收集该信息，随后要么将其转发给真实目的地（这也是其被称为“中间人”的原因），要么回送虚假信息。

![FIGURE 5.28 Man-in-the-middle attack](images/c05f028.png)

[**FIGURE 5.28**](#c05.xhtml#R_c05-fig-0028) 中间人攻击

从道德黑客的角度来看，中间人攻击可产出大量信息，因为此类攻击可收集并重定向数据。例如，*Linux 社会工程学工具包* *(SET)* 可用于复制一个网站，以协助收集访问该网站用户的凭证。SET 是 Kali Linux 中的预装工具，也可从 `https://github.com/trustedsec/social-engineer-toolkit` 下载。也可在 Microsoft Windows 机器上安装 SET 工具。

如果用户看到的似乎是他们打算登录的网站并输入了凭证，该虚假网站通常会将他们重定向到真实的登录页面。通常，用户会认为自己凭证输入有误，最终登录到真实网站。

与此同时，中间人已从虚假网站收集了他们的凭证，并利用这些凭证登录真实网站，破坏用户账户。使用 HTTPS 将提供安全通信通道，使攻击者无法收集用户凭证。尽管现代浏览器会在用户即将连接到 HTTP 网站时发出警报，但仍应培训用户留意识别 HTTPS 而非 HTTP。

*中间人* *(MITM)* 攻击，或*消防队攻击*，是一种会话劫持类型，涉及拦截或嗅探并修改用户间的通信。可将其视为一种网络窃听形式。因此，攻击者通常与其他双方处于同一网络或广播域中，并将代理双方通信，在此过程中插入或篡改数据。在 SSL 连接中，攻击者可能使用 ARP 欺骗将流量引向攻击者，而非正常的网络路由器。

#### 外来软件

你的软件里藏着什么？在生产软件中隐藏恶意内容的想法并不新鲜。你不难想象，商业软件公司可能提供掺杂了高级恶意软件的安全软件，这些恶意软件设计为在特定时间点激活。当然，该软件公司早已准备好恶意软件的“解药”，一旦其淹没安装了该软件的人员、企业和政府机构，便立即上市销售。

你也不难想象，政府和民族国家会与其本地软件生产商合作，在其商业产品中植入恶意软件。恶意软件可能潜伏不确定的时间，等待该政府的指令以执行攻击。

例如，如果一个政府想确保在与另一国家发生敌对行动时拥有优势，他们可能会在为工业过程控制和公用事业市场开发的商业 SCADA 软件中植入特洛伊木马、后门或其他恶意代码。一旦敌对行动开始，嵌入软件中的攻击即可发动，从另一国家的“棋盘”上移除宝贵资产。2010 年针对伊朗核工业的 Stuxnet 攻击和 2020 年针对美国联邦机构的 SolarWinds 信息收集攻击，便是此类网络战略的典型案例。

基于此原因，每个国家（及其工业和公用事业组织）都应将任何外国生产或受外国影响的软件视为潜在的国家安全威胁。从战略上讲，这意味着每个组织的采购流程必须评估外国生产软件相关风险，并与本国开发同类产品的经济性进行权衡。

在战术层面，建议由多名程序员对所有外来软件代码进行同行评审和测试。此外，应尽可能使用多种不同的扫描工具扫描这些软件包，以查找嵌入软件中的危险或不必要代码。Microsoft 提供安全代码分析工具包，而 Snyk 在 `https://snyk.io` 提供免费源代码检查器。最后，在评估信息安全时，应强制执行行业标准，例如 ISO 15408 *通用准则标准* (可在 `www.iso.org/standard/50341.html` 找到)。

### 未授权访问

*未授权访问*被定义为：使用未获许可的访问方法（如他人账户或攻击者创建的账户），获取对资产（建筑物、办公室、机器、服务器、网站、服务、文件夹或文件）的访问权限。在网络安全术语中，这也被称为*灰帽*或*黑帽黑客行为*。

未授权访问涉及外部和内部网络攻击方法。外部攻击涉及在网络上无合法权限的个人（尽管也涉及目标网络内部用户主动或被动串通发起的攻击）。最常见的外部访问攻击基于拥有或猜测有效用户的弱凭证、被盗凭证或丢失凭证。然而，基于通过恶意软件攻击获取的凭证的攻击也相当常见。远程访问、无线连接和调制解调器拨号攻击代表了另一种常见的外部访问攻击面。

另一方面，未授权内部访问攻击由拥有一定级别合法网络访问凭证的入侵者发起。这些访问可能由未获资产权限的 IT 人员、在网络中拥有高权限的非 IT 员工，或使用他人被盗凭证的合法人员发起。

本章以下各节将描述各种未授权访问攻击方法。

#### 密码攻击

*密码攻击*均属于*密码破解*、*密码填充*和*密码重用*这些统称范畴。密码破解的目标是在原本不知正确密码的情况下，成功通过密码提示进行身份验证。密码攻击可使用不同方法以多种方式执行：

*   暴力破解攻击
*   彩虹表
*   密码捕获
*   凭证填充
*   密码喷射
*   密码重用
