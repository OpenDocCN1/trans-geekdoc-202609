

## 安全控制与协议

### 安全基线
: 定义保护组织信息系统的机密性、完整性和可用性（CIA）以及这些系统处理、存储和传输的数据所需的最低安全要求的安全控制。

### 安全内容自动化协议 (SCAP)
: 一种使用各种开放标准来评估漏洞并衡量这些漏洞潜在影响的方法。

### 安全补丁
: 为纠正观察到的弱点以防止漏洞被利用而发布的更新。

### 安全策略
: 说明安全应如何在各级实施的文档。企业和组织制定全面的安全策略，定义谁被授权访问不同的资产，以及他们在访问这些资产时被允许做什么。

### 安全拓扑
: 考虑到安全要求和需求，给定网络上所有硬件设备的定义布局。

### 安全区域
: 为根据其安全漏洞或关键性为特定网络资产（资源和数据）提供特定安全级别而创建的网络段。其理念是将更有价值或更关键的网络资产放置在提供更多保护的段或安全结构中。

### 隔离
: 在网络中，物理或逻辑上的分离。常用于隔离个人、数据和其他资产。

### 传感器
: 这些设备将温度、流体流速或压力等测得的物理量值转换为控制系统可理解的相应信号（压力、电气、差压等）。

### 服务包
: 主要的操作系统更新和/或许多单独 Windows 更新的集合。

### 会话 Cookie
: 存储在临时内存中、在 Web 浏览器关闭时被擦除的 Cookie。

### 会话重放攻击
: 一种攻击，涉及攻击者窃取用户的会话 ID，然后获得授权用户在特定网站上能够执行的任何操作的访问权限。

### 设定点 (SP)
: 设定点可以是固定参考，例如安装在支柱上的简单液位传感器；也可以是可调参考，例如常见的恒温器，用户可以在其中设置要维持的期望温度。

### 七层网络安全模型
: 来自 SANS 研究所的分层七层网络安全模型，与七层 OSI 模型相关联。

### 偷窥
: 一种攻击，某人从毫无防备的受害者肩上瞥视，希望观察和/或记录他们输入的某些私人信息。

### 侧信道攻击
: 对虚拟机的攻击，其中一台虚拟机从运行在同一物理服务器上的另一台虚拟机获取私钥信息。

### 特征分析
: 将进出站流量与存储的特定代码模式（特征）数据库进行比较的过程，这些模式已被识别为恶意威胁。

### 单因素认证
: 仅需要持有一种验证形式的认证。这代表可用的最低安全级别。

### 单防火墙 DMZ
: 仅有一个关联防火墙的网络 DMZ。

### 单次损失期望值 (SLE)
: 被归类为一次性事件的安全事件。这些事件按一次性基础分配价格。

### 智能卡
: 通常类似于磁条卡的卡片设备。它们通常包含所有者的信息，如密码、个人识别号 (PIN)、网络密钥、数字证书和其他可用于认证过程的 PII。

### 智能电表
: 记录公用事业消耗并能传输信息以进行监控和计费的智能电子设备。

### 智能手机应用
: 专门在平板电脑和手机等移动设备上运行的应用程序。

### 短信钓鱼
: 短信钓鱼的简称，是一种诱使用户访问网站通过短信在智能手机或平板电脑上下载恶意软件的攻击。

### Smurf 放大器
: 被感染的网络计算设备，用于将攻击者的 ping 请求反射向指定目标，从而对目标构建 ICMP 洪水攻击。

### Smurf 攻击
: 一种用 ICMP 回复包淹没受害者的 DDoS 攻击。这种攻击在 ping 洪水攻击的基础上增加了反射属性。这种反射属性是通过在攻击中使用更多被称为 Smurf 放大器的参与者来创建的。

### Snort
: 一种开源、跨平台的入侵检测系统，提供实时流量分析、数据包记录和协议分析，以及对蠕虫、端口扫描和漏洞利用尝试的主动检测。

### 社会工程学
: 一种利用物理或心理操纵来利用人际互动、以期绕过正常安全措施的非技术方法。

### 套接字
: 双向通信的一个端点。套接字绑定到一个端口号。

### 软目标
: 因几乎没有内置安全功能且几乎没有添加安全功能的选项而容易受到破坏的设备。如果能被直接或虚拟访问，它们很容易被操纵。

### 社会工程学工具包 (SET)
: 渗透测试中使用的 Linux 软件包，可用于对目标执行高级攻击。

### 软件即服务 (SaaS)
: 基于订阅许可和交付的软件。软件托管在企业外部，通过瘦客户端在网络中访问。

### 软件漏洞利用
: 旨在利用软件产品、操作系统和应用程序中的漏洞或弱点的网络攻击。

### 软件防火墙
: 像其他应用程序一样安装在主机计算机上的防火墙。

### 软件定义网络 (SDN)
: 一种计算机网络方法，分析任意两个节点之间的连接，并可根据定义的策略过滤该连接。

### SolarWinds
: 一款提供极其强大的商业网络性能监控产品的软件产品。它可以监控正常运行时间、性能、流量和利用率，并提供大量报告、图表和通知选项。

### 生成树攻击
: 如果数据包仅在该拓扑中的二层交换机之间循环，其生存时间 (TTL) 设置永远不会递减，也永远不会消失——而是继续通过冗余链路循环。这会产生广播风暴，用流量淹没网络。

### 生成树协议 (STP)
: 一种为多路径网络中的交换机提供无环冗余链路的协议。它通过配置交换机端口，使其根据所连段的类型转发或阻塞流量来实现这一点。

### 定向钓鱼
: 一种针对特定组织或该组织内特定个人的攻击，试图获得对机密数据的未授权访问。

### 欺骗
: 伪造虚假身份的任何形式，从而获得对资产的访问。

### 欺骗攻击
: 基于更改设备的 MAC 或 IP 地址以改变其表面身份的攻击。

### 间谍软件
: 一种监控系统操作并收集用户名、密码、信用卡号和其他 PII 等信息的软件程序。

### SQL 注入
: 一种操纵网页上 SQL 输入字段框的攻击。通过字段框输入有效的 SQL 命令，导致 SQL 数据库透露输入框创建目的以外的信息。
