

# 事件日志记录

**事件日志记录**是指记录网络设备、服务器、客户端和智能网络连接设备的操作系统所执行的系统事件。操作系统日志通常记录各种不同类型的系统信息。其中相当一部分数据与管理和合规功能相关。

在讨论操作系统时，**审核**一词用于描述操作系统的一项安全功能，该功能支持将在计算机上执行的用户和操作系统活动记录在日志中（进行监控和跟踪）。然后可以使用这些信息来识别或分析潜在的不良活动，例如未经授权的入侵尝试。事件日志记录是在本地计算机层面设置的，而审核则是在服务器层面建立的。

在网络安全设备/系统识别出可疑活动后，通常会使用操作系统日志从特定设备获取更多信息。对于这些活动，需要考虑两种常见的操作系统审核记录类型：

*   **原生日志记录**—大多数现代多用户操作系统生成的事件记录。由于这些记录已由操作系统生成，因此始终可用，但它们可能不包含所需的事件，或不是易于使用的形式。
*   **检测专用审核记录**—为提供有关所需操作或事件的特定信息而生成的记录。这些操作或事件可以基于操作系统活动、应用程序事件或安全事件。

大多数操作系统可用的审核系统由两个主要组件组成：**审核策略**（或**审核规则**），它定义将要监控并添加到系统**安全日志**中的事件类型；以及**审核条目**（或**审核记录**），它们由发生受审核事件时添加到安全日志中的各个条目组成。系统管理员实施审核策略。

事件日志管理是监控 IT/OT 网络最重要的方面之一。在操作系统层面，**Windows 事件查看器**或 **Linux 安全审核框架**等简单实用程序为事件监控活动提供了第一道防线工具。

## Windows 审核工具

在 Microsoft Windows 环境中，审核条目保存在**安全日志文件**中。[图 10.2](#c10.xhtml#c10-fig-0001) 显示了 Windows 事件查看器实用程序中显示的典型安全日志。为了使审核成为有效的安全工具，应定期审查和归档安全日志。

在 Windows 中，审核必须既作为常规系统策略设置进行配置，也必须在每个需要审核的对象（文件、文件夹和打印机）上进行配置。考虑到这一点，在配置审核策略时，必须考虑该策略将对系统及其性能产生什么影响。如果要在系统中的每个文件、文件夹和打印机上设置审核，审核进程会给系统带来如此多的额外工作，以至于系统实际上可能会慢到停滞。

## Linux 审核

Linux 系统还具备安全审核功能，用于跟踪指定的安全事件。[图 10.5](#c10.xhtml#c10-fig-0004) 提供了 Linux 安全审核框架的通用表示。与其他审核系统一样，Linux 模块将计算机进程映射到用户 ID，以便管理员能够将攻击准确追溯到拥有该进程并在系统中执行潜在恶意活动的用户。

![FIGURE 10.5 Linux auditing system](images/c10f005.png)

[**图 10.5**](#c10.xhtml#R_c10-fig-0004) Linux 审核系统

系统的核心是**审核守护进程**，它与 Linux 内核的审核模块协同工作，记录相关事件并将其写入磁盘上的日志文件。审核规则在系统启动时执行的文件中进行配置。审核控制器实用程序使用这些规则中的参数来确定跟踪哪些系统事件以及如何将它们写入**审核事件日志文件**。

当应用程序遇到触发预配置审核事件的情况时，一条消息会呈现给内核的审核接口并传递给审核控制器。在审核控制器的指导下，审核守护进程将事件写入审核事件日志。

Linux 审核系统还包括一个报表生成工具，管理员可以使用它来生成自定义安全报表。它还可能包含一个搜索实用程序，以便快速/专门地检查特定事件的日志条目。

与 Windows 组策略配置一样，您必须考虑希望 Linux 审核系统在主机上执行的审核级别及其运营后果。

有一个非常优秀的审核工具可用于 Linux 和 MAC 系统，称为 **Lynis**。该工具可以从 GitHub 下载并安装在 Linux 平台上。安装并配置 Lynis 后，它可以扫描系统并提供报告、警告和缓解系统漏洞的建议。其他著名的审核工具包括 Qualio、AuditBoard、Hyperproof、Onspring、Audit Prodigy、Audits Management Software、HighBond、Standard Fusion 和 Benchmark ESG。

## 网络日志记录

来自网络设备（如托管交换机、路由器、防火墙和无线接入点）的日志，以及分布在整个网络中的 NSM 程序的日志，都可能包含与安全相关的信息。网络管理员主要将这些类型的日志用于管理和审核，而安全管理员则更关注来自不同来源的安全日志，以维护组织的网络安全目标。

## 安全日志记录

**安全日志**用于跟踪通过设备审核策略配置指定的安全相关活动或事件。虽然安全日志的配置主要是为了存储计算机安全信息，但还有许多其他日志（如操作系统日志和应用程序日志）通常也包含一些与安全相关的信息，以及各种其他事件文档。

审核条目保存在安全日志中，管理员可以查看。为了使审核成为有效的安全工具，应定期审查和归档安全日志。

组织通常运行多种基于主机和基于网络的软件工具来生成安全日志数据。最常见的软件类型包括但不限于以下各项（每个项目记录的内容不限于所述内容）：

*   **反恶意软件**—这些工具通常记录所有检测到的恶意软件遭遇实例。
*   **IDS/IPS 系统**—这些设备或工具通常记录网络中发生的异常或威胁活动。
*   **身份验证服务器**—这些设备记录身份验证尝试，并包含尝试的来源、日期/时间和用户名，以及成功或失败的指示。
