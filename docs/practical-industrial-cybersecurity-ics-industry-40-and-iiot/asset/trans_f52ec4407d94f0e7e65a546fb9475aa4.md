

# 生成树协议与网络欺骗

## 生成树协议

虽然可以通过分割网络来最小化广播风暴的风险，但创建 `spanning-tree protocol`（`STP`，生成树协议）是为了解决这一问题。STP 采用 `spanning-tree algorithm`（`STA`，生成树算法）来识别交换机可能与网络节点有多条通信路径，并管理最优路径，同时仍能回退到次要路径。任务关键型网络必须使用 STP 来最小化广播风暴。

第 2 层设备采用一种名为生成树协议 (STP) 的协议，为多路径网络（如 [图 5.13](#c05.xhtml#c05-fig-0013) 所示）中的交换机提供无环路、冗余的链路。它通过配置交换机端口来实现这一点，使其根据所连接的段类型转发或阻塞流量。

## 欺骗

字典将 `spoofing` 定义为“欺骗或恶作剧”。在网络安全领域，欺骗用于使设备看起来像另一台设备，且可以通过多种不同方式实现。许多网络漏洞侧重于以某种方式获取有效凭证。显而易见，攻击者伪造或欺骗网络身份并不难。`Masquerade attacks`（伪装攻击）可能源于窃取的凭证、欺骗的 IP 或电子邮件地址，或两者兼有。如果攻击者能诱使用户泄露其凭证，他们就能获得该用户的网络权限。多因素认证措施（涉及你知道的、你拥有的或你本身的特征）可以降低伪装攻击的效率，但这些解决方案并不总是切实可行。

### IP 欺骗

`IP header manipulation`（IP 头部操纵），或 `IP spoofing`（IP 欺骗），是一种通过更改 IP 或 TCP 网络数据包头部部分所含信息来隐藏网络身份的技术。此操作还用于执行多种其他攻击，如中间人 (MITM) 攻击和拒绝服务 (DoS) 攻击。

如果我们检查 [图 5.14](#c05.xhtml#c05-fig-0014) 中提供的示例 IP 头部，可以看到前 12 字节（顶部三行）数据包含关于数据包的各种信息，如长度、生存时间 (TTL) 和协议 (IPv4 或 IPv6)。接下来的 8 字节（第 4 行和第 5 行）包含源和目标 IP 地址信息。

![FIGURE 5.14 IP header](images/c05f014.png)

[**图 5.14**](#c05.xhtml#R_c05-fig-0014) IP 头部

使用互联网上可用的几种工具之一，攻击者可以轻松修改这些地址，特别是“源地址”字段，使其成为他们想要的任何内容。通过这样做，攻击者可以欺骗网络数据包的源地址，使其看起来像是来自与实际完全不同的位置。这可用于在攻击期间隐藏其身份，或者根据网络防御情况，可能用于从外部访问私有内部网络。

### 防御 IP 欺骗

幸运的是，有几种相当有效的方法可以防御 IP 欺骗：

*   在路由器处过滤网络流量
*   实施加密和认证

在边界网络路由器上同时实施 `ingress`（入站流量）和 `egress`（出站流量）过滤是防御欺骗攻击的起点。应实施访问控制列表，如 [图 5.15](#c05.xhtml#c05-fig-0015) 所示，以便阻止私有 IP 地址（包括组织的内部 IP 地址范围）在下游接口通过。

`downstream interface`（下游接口）是允许流量从互联网进入网络的接口。互联网是世界上最大的公共网络，因此没有正当理由允许私有和内部流量通过路由器的下游接口，因为这是攻击者试图绕过防火墙的常用手段。这也是创建 VPN 的原因。

路由器的 `upstream interface`（上游接口）允许流量流向不同的子网或互联网。该接口应限制为仅允许来自组织有效 IP 范围内的源地址通过。这有助于防止欺骗的网络数据包在互联网上传输。

![FIGURE 5.15 Perimeter network protection](images/c05f015.png)

[**图 5.15**](#c05.xhtml#R_c05-fig-0015) 边界网络防护

实施加密和认证也有助于防止欺骗攻击。这些功能包含在 IPv6 中，IPv6 旨在消除所有当前的欺骗攻击威胁。

网络内部还应消除基于主机的认证。基于主机的认证依赖信息（如 [图 5.16](#c05.xhtml#c05-fig-0016) 所示的 MAC 地址和主机名）向网络进行认证。这些信息不太安全，攻击者也可以轻易伪造。相反，应建立并通过安全的加密连接实施适当的认证措施。

### MAC 欺骗

`MAC spoofing`（MAC 欺骗）如 [图 5.17](#c05.xhtml#c05-fig-0017) 所示，是前几章介绍的另一种常见欺骗技术。由于许多安全设备和软件依赖 MAC 地址来控制对网络资源的访问，因此能够更改 MAC 地址非常方便。优秀的安全从业人员经常使用此技术来测试安全设备和其他防御措施。

![FIGURE 5.17 MAC spoofing](images/c05f017.png)

[**图 5.17**](#c05.xhtml#R_c05-fig-0017) MAC 欺骗

MAC 欺骗可用于多种目的。然而，最常见的场景之一涉及使用欺骗方法来欺骗网络环境中用于连接互联网的硬件的 MAC 地址。ISP 通常使用 MAC 地址注册其自己的设备并允许访问其网络。

如果客户购买了新的路由器/调制解调器设备并希望将其用于现有的互联网服务提供商，则必须向 ISP 注册该设备。客户选择不向 ISP 注册新设备的 MAC 地址，而是通过使用旧设备的地址代替新设备的地址来欺骗旧设备的 MAC 地址。通常，这违反了 ISP 与客户之间的 EULA（最终用户许可协议），并可能被视为非法行为。

### ARP 欺骗/投毒

要理解 `ARP spoofing`（ARP 欺骗），也常称为 `ARP poisoning`（ARP 投毒），我们需要了解为什么需要 ARP 以及它是如何工作的。地址解析协议 (ARP) 用于将 IP 地址映射到 MAC 地址。这样，设备就能通过第 2 层设备（如交换机）进行通信。当网络流量到达路由器时，它将使用帧中的 IP 地址信息将数据包从一个网络路由到另一个网络。

例如，设想一个简单的网络，其中两台设备仅由一台交换机隔开。第一台设备（我们称之为 Smith）的 IP 地址为 `10.0.0.10`，MAC 地址为 `AB:CD:EF:12:34:56`。它需要与第二台设备（称为 Jones）通信。我们恰好知道 Jones 的 IP 地址是 `10.0.0.20`。

由于以太网段仅需使用物理 MAC 地址进行通信，我们需要确定 Jones 的 MAC 地址。

Smith 将发送一个广播帧，其目标 IP 地址设置为 `FF:FF:FF:FF:FF:FF`。请记住，我们已经知道源 IP 地址 (`10.0.0.10`)、目标 IP 地址 (`10.0.0.20`) 和源 MAC 地址 (`AB:CD:EF:12:34:56`)。
