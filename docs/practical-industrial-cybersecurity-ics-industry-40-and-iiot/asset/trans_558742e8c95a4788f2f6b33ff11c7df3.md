# 附录 A

## GICSP 目标映射

`Global Industrial Cyber Security Professional (GICSP)` 考试是一项厂商中立的工业控制系统安全认证，旨在弥合 IT 网络安全与工业控制网络环境之间的差距。考试目标旨在评估候选人，确保其具备在运营技术/工业控制系统（`OT/ICS`）、工程、网络安全工作角色中成功履职所需的最低知识水平。该认证满足美国国防部（`DoD`）`8570.0.1` 信息保障劳动力改进计划的要求。它还被批准用于 `DoD` 的 `CND-A`、`CND-IS` 和 `IAT Level II` 劳动力类别。

考试由 `SANS` 研究所的认证机构 `Global Information Assurance Certification (GIAC)` 管理和交付，该组织专注于信息和网络安全培训。

`GICSP` 是一项包含 115 道题目的单一考试。完成考试的时间限制为三小时，及格最低分数为 71%。考试由受监考的 `Pearson VUE` 考试中心提供，必须提前预约。可使用以下网址的说明进行预约：

`www.giac.org/information/schedule_proctored_exam.pdf`

该认证有效期为四年，必须在到期前更新以保持有效。`GICSP` 考试涵盖的主题列于下一节。

`ICS410: ICS/SCADA Security Essentials` 课程由 `SANS` 提供，支持 `GICSP` 考试，为工业网络安全专业人员提供一套基础的标准化技能和知识。该课程旨在确保参与支持和保护工业控制系统的员工接受培训，以在当前和新兴网络威胁面前保持运营环境的安全、可靠和弹性。
