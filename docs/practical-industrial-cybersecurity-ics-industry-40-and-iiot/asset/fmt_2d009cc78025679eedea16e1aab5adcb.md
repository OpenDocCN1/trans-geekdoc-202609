
## 术语表

### M

**MAC 地址学习**

: 连接设备与连接到其物理端口的其他设备交互，并读取消息头以获取发送和接收设备的 MAC 地址的过程。此信息连同其端口信息一起记录在 CAM 表中。

**MAC spoofing**

: 一种用于更改网络上设备出厂分配的 MAC 地址的技术。

**malicious proxy servers**

: 用于多种目的的代理服务器，包括恶意软件投放、广告注入和简单的信息收集。虽然这些代理服务器可能不会传递你的 IP 地址，但它们会知晓你的 IP 地址，并可能将该信息用于其他目的。

**malware**

: 描述任意数量的侵入式软件程序的术语，旨在具有恶意性质。

**man-in-the-middle (MITM) attacks**

: 一种网络攻击，涉及攻击者创建到两个或多个受害者的链接，以拦截它们之间移动的消息。

**managed switches**

: 具有内置可编程管理功能的设备，使管理员能够为其配置特定的网络环境。

**mandatory access control (MAC)**

: 一种访问控制类型，利用操作系统来确定哪些用户或组可以访问文件、文件夹和其他资源。

**manipulated variable**

: ICS 正在控制的变量，如温度、压力、液位等。

**man-machine interface (MMI)**

: 界面的交互部分，为人工操作员提供屏幕工具以调整或覆盖控制指令。

**masquerade attack**

: 一种攻击，涉及攻击者假冒另一个系统的身份。

**MDK3**

: 一种渗透测试工具，用于利用常见的 802.11 协议弱点。

**meaningful use**

: 以可在质量和数量上显著衡量的方式使用经认证的 EHR 技术。

**mesh network**

: 一种去中心化的拓扑结构，其中每个节点都为网络中继数据。

**metadata**

: 描述或定义数据的信息。该术语用于描述所有可能被视为记录次要目的的数据。通常，metadata 被认为是自动生成的、通常嵌入的数据，由信息系统创建以补充甚至验证记录。

**Metasploit**

: 一种渗透测试框架，用于识别和验证网络漏洞，包括模拟利用人为漏洞的攻击。它是最流行的开源渗透测试框架之一。

**microcontroller**

: 位于单个集成电路上的小型计算机。

**Modbus TCP/IP**

: 带有 TCP 接口的 Modbus RTU 协议。

**Modbus**

: 互连智能工业控制设备的事实标准通信协议。Modbus 是一种串行通信协议，专门开发用于为工业控制应用提供网络功能。

**motion detectors**

: 一种检测移动物体的设备，通常集成在基础设施安全系统中。

**multifactor authentication (MFA)**

: 一种访问控制方法，要求以下至少两项：知识、持有和固有特征。

**MultiSpeak**

: 一项规范，是企业应用程序互操作性的关键行业通用标准。

### N

**Nagios**

: 最知名的网络监控工具之一，有助于确保系统、应用程序和进程正常运行。

**nation-state**

: 一个地理区域，包含在一个政府下生活、共享相同历史、语言或传统的一群人。

**National Institute of Standards and Technology (NIST)**

: 负责开发网络安全框架、医疗设备安全以及《工业控制系统 (ICS) 安全指南》的联邦技术机构。

**natural access control**

: 利用自然设计元素（如结构和景观）引导人们进出空间的过程。

**need-to-know policy**

: 一种限制员工对整个网络系统了解程度的过程。它类似于职责分离策略。

**neighborhood area network (NAN)**

: 常用于智能电表网络，NAN 可为一小组 WLAN 提供网络连接。

**Network Address Translation (NAT)**

: 将一个网络中使用的 IP 地址转换为另一个网络中已知的 IP 地址。

**network analyzer**

: 渗透测试人员用来监听网络流量的工具，查找以明文模式跨网络发送的密码和用户名，或信用卡等敏感财务信息等项目。也称为 packet sniffer。

**network-attached storage (NAS)**

: 一种虚拟化存储系统，在网络中提供存储和文件系统结构。

**network connectivity devices**

: 具有连接功能的设备，如 routers、hubs、switches 和 bridges。

**network firewall**

: 一种防火墙，通过授予或拒绝受信网络和非受信网络之间特定流量的访问权限，对整个网络执行安全防护。

**network hardening**

: 保护网络所涉及的所有过程和技术。

**network monitoring tools**

: 可用于确保服务器或其他设备正常启动并运行的任何工具。

**network packet**

: 在网络上路由的数据单元。

**network segmentation**

: 将网络分离或拆分为一个或多个子网的过程，使每个子网成为独立的网段。

**network topologies**

: 第 1 层物理（或逻辑）连接策略，分为四种基本配置：star、bus、ring 和 mesh。

**network virtualization**

: 创建基于软件的管理实体的过程，利用硬件和软件网络资源以及网络功能。

**network vulnerability scanner**

: 用于扫描网络中不同类型的常见漏洞，如系统错误配置和默认密码使用。

**Nikto**

: 一款开源 Web 服务器扫描器，可识别 Web 服务器上的问题。

**NIST 800-82 r2, “Guide to Industrial Control System (ICS) Security”**

: 一份为工业控制系统实施网络安全提供指南的文档。

**nmap**

: 一款流行的安全扫描工具，用于枚举网络。

**No eXecution (NX) bit**

: CPU 中用于将内存区域分离为不同用途区域的技术。例如，一块内存区域可专门留作存储处理器指令代码，而另一块区域可标记为仅用于数据存储。

**NTFS permissions**

: 新技术文件系统权限，可设置用户可对指定文件或文件夹执行的操作参数。

### O

**OAuth**

: 一种认证协议，允许应用程序代表用户行事，而无需共享密码。

**On/Off control**

: 仅基于测量变量与参考变量之间关系的控制方案。输出条件只能假设两种状态——完全开启或完全关闭。这种控制由 on/off 设备（如 relays 和 electrical switches）提供。

**open loop control**

: 一种不观察反馈输出以调整其所控制过程的过程。因此，在这些系统中，控制器没有机制通过调整输入电平来将过程变量的值控制在指定水平。

**Open Platform Communications (OPC)**
