# Chapter 2：ICS Architecture

## Introduction

在上一章中，您了解了典型工业/公用事业控制系统的基本组件。本章将以这些介绍性主题为基础，描述标准 ICS 架构。特别是，它将汇集与运营 OT 架构相关的四大知识领域：

*   Communication media（通信介质）
*   Field device architecture（现场设备架构）
*   Industrial network protocols（工业网络协议）
*   IT network protocols（IT 网络协议）

在上一章的介绍中，提到 OT 网络往往与企业和小型企业环境中发现的 IT 网络截然不同。例如，正如您已知，工业制造和公用事业网络中使用的许多连接和计算设备与企业网络中常见的设备有很大不同。特别是，工业/公用事业网络中使用的 OT 网络包含不同类型的过程控制设备，如 `programmable logic controllers` (`PLCs`) 和 `remote terminal units (RTUs)`。

这些环境在软件领域也差异巨大。在工业网络环境中，企业网络中运行在 Windows 和 Linux 操作系统上的业务应用程序已被提供 `supervisory control and data acquisition (SCADA)` 和 `man-machine interface (MMI)` 功能的过程控制应用程序所取代。

即使网络通信也可能与企业网络中遇到的截然不同。虽然 `CATx` 双绞线布线、Ethernet 协议和 `TCP/IP` 在企业环境中广泛使用，但其他协议和技术（如 `RS-485` 串行通信链路、Modbus 网络和 SONET 环形广域网）也存在，以及多种无线技术。

## Network Transmission Media

数字数据通过网络 `communication media` 从一个网络设备传输到另一个网络设备。用于在网络设备之间移动数据的传输介质基本上有三种通用类型：

*   Copper wire（铜线：双绞铜缆和同轴电缆）
*   Light waves（光波：光纤电缆和红外光）
*   Wireless radio frequency (RF) signals（无线射频 (RF) 信号：WiFi、WiMAX、Bluetooth、ZigBee、Z-Wave）

每种介质类型都提供优势，使其在特定条件下适用于联网。主要与介质相关的考虑因素包括其实施成本、最大数据传输速率和抗噪声特性。同样，每种介质类型在传输信息的能力方面也存在一些限制。

这一因素也包含在两个考量中——其 `bandwidth` 和其 `attenuation`。`Bandwidth` 是介质在给定实例下承载数据的总能力。`Attenuation` 是衡量信息跨越介质移动时发生多少信号损耗的指标。正如您将在以下部分看到的，某些介质类型实际上可以传输信号数英里，并仍能将其作为可识别的信息传递。

最后一个与介质相关的考量是其抗噪声能力。杂散电能（称为 `noise`）作为自然过程在大气中移动。电气机器和设备也会产生电子噪声。这些杂散信号会干扰有组织的数据信号，使其无法识别。因此，用于传输数据的电缆应具备一定的抗杂散信号能力。

### Copper Cabling

在 `copper cabling` 标题下，基本上有两类需要考虑：twisted-pair cabling（双绞线布线）和 coaxial cabling（同轴电缆布线）。双绞线布线由两对或多对绞合在一起的导线组成，以提供降噪。导线中的扭绞会使感应噪声信号相互抵消。在该类布线中，每英尺导线的扭绞数表示其相对抗噪声等级。

在讨论用于数据网络的双绞线布线时，有两种基本类型需要考虑：`unshielded twisted pair` (`UTP`) 和 `shielded twisted pair` (`STP`)。UTP 网络电缆包含四对单独绝缘的导线，如图 2.1 所示。

STP 电缆类似，不同之处在于它包含一个额外的箔层屏蔽，包裹着四对导线束。屏蔽层通过提供接地路径将感应电信号从电缆中的导体处引走，从而提供对感应电气噪声和串扰的扩展保护。这一额外特性使 STP 比 UTP 电缆更昂贵、更重、更难安装。然而，它也提供更高的数据速度和更强的抗噪声能力。

`Coaxial cable`（通常简称为 `coax`）作为将有线电视信号传入家庭的导体，为大多数人所熟悉。同轴电缆由绝缘的实心或绞合线芯组成，外围包裹介质绝缘层和实心或编织金属屏蔽层。导线和屏蔽层均包裹在外部保护绝缘护套中，如图 2.2 所示。

过去，同轴电缆广泛用于 Ethernet LAN 介质。然而，由于同轴电缆的粗度和刚性使其难以安装且耗时，网络行业和网络标准开发组织已放弃同轴电缆，转而采用非屏蔽双绞线布线。

### Fiber-Optic Cabling

`Fiber-optic cable` 是设计用于以光脉冲形式传输数字数据的塑料或玻璃电缆。信号由激光二极管引入电缆，并沿其内部反射传播，直到到达电缆末端，如图 2.3 所示。在末端，光检测电路接收光信号并将其转换回可用信息。

光在光纤电缆中传输时，衰减（能量损耗）速度不如电信号在铜导体中传输时快。因此，使用光纤布线时，发射器和接收器之间的线段长度可以长得多。在某些光纤应用中，最大电缆长度可达 2 公里。
