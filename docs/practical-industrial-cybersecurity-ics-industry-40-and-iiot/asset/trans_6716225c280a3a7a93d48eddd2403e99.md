

### 密码策略设置

*   **最大密码使用期限/最小密码使用期限**：这两个设置允许管理员设定密码在指定天数后过期，并防止用户在特定天数内更改密码。密码过期时，系统会提示用户更改，确保即使密码泄露，也会在短时间内更换以堵住安全漏洞。
*   **最小密码长度**：此选项用于指定密码可包含的最小字符数。这允许管理员强制用户使用更长、更难猜测的密码。对于安全系统，建议密码至少包含八个字符。
*   **密码必须符合复杂性要求**：管理员可使用此选项强制用户使用更安全、更复杂的密码，这些密码需包含小写字母、数字、符号和大写字母的某种组合。管理员通过在域控制器级别建立密码筛选器来设定复杂性级别。

### 建立资源控制

服务器操作系统提供为文件、文件夹/目录及其他系统资源指定单独*访问权限*的功能。管理员的工作是仔细设置访问控制，使其允许授权用户访问和使用指定的系统资源，并拒绝未授权用户的访问以防止安全漏洞。

通过将*最小权限原则*应用于这些配置（如前所述），管理员可以减少恶意和无意安全漏洞发生的机会。例如，拒绝对文件和目录的读取访问有助于保护信息的机密性，而拒绝不必要的写入（修改）访问有助于维护信息的完整性。

将大多数系统相关工具的执行权限限制在授权系统管理员范围内，可以防止用户进行可能降低安全性的配置更改。这也能限制攻击者利用这些工具攻击服务器或网络上其他主机的能力。

#### NTFS 权限

Windows 环境中使用的 NTFS 文件管理系统包含安全功能，允许将权限级别分配给磁盘上的文件和/或文件夹。*NTFS 权限*设定用户可对指定文件或文件夹执行的操作参数。它们可由管理员直接分配，也可通过组设置继承（如默认的 Everyone 组）。

NTFS 权限可配置为*允许*或*拒绝*选项。如果用户对特定文件夹或文件仅具有读取权限，但被分配到了一个对该文件夹或文件拥有更广泛权限的组，则该用户将通过该组获得额外权利。另一方面，如果用户被分配了针对特定权限级别的拒绝选项，则即使其所属的另一个组授予了该权限，也会被拒绝。在服务器环境中，文件的默认权限设置为“无访问权限”。

*标准 NTFS 文件夹权限*包括：

*   **读取**：允许用户或组查看父文件夹的文件、文件夹或子文件夹及其属性和权限。
*   **写入**：允许用户或组添加新文件或子文件夹、更改文件和文件夹属性、向现有文件添加数据，以及更改父文件夹内的显示属性。
*   **读取和执行**：允许用户或组更改子文件夹、显示属性和权限，并运行可执行文件类型。
*   **修改**：允许用户删除文件夹，并执行与写入、读取和执行权限相关的所有活动。
*   **列出文件夹内容**：允许用户或组查看文件夹内的文件和子文件夹。
*   **完全控制**：允许用户或组取得文件夹所有权并更改其权限，以及执行所有其他权限允许的活动。

*标准 NTFS 文件权限*包括：

*   **读取**：允许用户或组查看文件及其属性和权限。
*   **写入**：允许用户或组覆盖文件、更改其属性，并查看其所有权和属性。
*   **读取和执行**：允许用户或组运行和执行应用程序，以及拥有读取权限的所有选项。
*   **修改**：允许用户修改和删除文件，并执行与读取、写入、读取和执行权限相关的所有活动。
*   **完全控制**：允许用户或组取得文件所有权并更改其权限，以及执行所有其他权限允许的活动。

#### Linux 权限

Linux 操作系统也采用文件和目录权限来防止未授权访问。在 Linux（和 UNIX）系统中，除文档和可执行文件外的其他结构也被定义为文件。磁盘驱动器、光驱、调制解调器、输入输出设备和网络通信等其他系统资源也作为文件进行访问。

Linux 系统中的每个文件都分配有*所属用户*和*所属组*，以及针对每种所有者类型的访问权限。*权限*也针对*非特权用户*建立。可配置三种类型的访问权限：

*   **读取 (r)**：指定后，允许用户读取文件或目录的内容。
*   **写入 (w)**：指定给文件时，允许用户通过写入来修改文件。分配给目录时，写入权限允许用户在目录中创建或删除文件。
*   **执行 (x)**：允许用户执行具有此权限的文件和脚本。

每种权限均针对每个用户类别独立建立。典型的文件权限显示（如通过列表命令 `ls` 获取）将呈现以下格式：

```
drwxrwxrwx user group filesize Jan 01 08:00 filename
```

左侧列的每个 `rwx` 片段分别显示所属用户、所属组和其他用户的活动权限设置。本示例中出现所有三种权限类型，表明这三组均启用了所有权限。当某用户的特定权限被禁用时，其位置包含一个简单的破折号字符：

```
drwxrw-r-- user group filesize Jan 01 08:00 filename
```

在本示例中，所属用户仍拥有所有权限，但所属组权限降为读取和写入，而其他用户权限仅降为读取。

在 Linux 系统中创建目录或文件时，它会与其创建者关联，创建者默认成为其*所有者*。通常，Linux 用户会为其非可执行文件分配 `–rw-r--r--` 权限。此设置允许其他人读取其文件，但无法更改。同样，目录通常分配 `–rwxr-xr-x` 权限。这允许其他人浏览目录并执行，但无法在其中写入新文件或删除现有文件。
