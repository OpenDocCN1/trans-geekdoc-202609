
### 工具介绍

*   **DumpSec**：基于 GUI 的工具，提供目标文件系统的权限列表和审核设置，以及用户、组和复制数据。
*   **Legion**：基于 GUI 的实用程序，扫描 IP 地址范围以查找共享资源，如文件、目录、打印机等。
*   **Netcat**：基于 CLI 的计算机网络实用程序，执行枚举和端口扫描活动。除了枚举任务，`Netcat` 还可以使用 TCP 或 UDP 协议连接到目标主机的端口、监听指定端口以接受入站连接、跨网络传输文件以及在目标上执行脚本。一个名为 `Ncat` 的类似工具包含在 `NMAP` 实用程序套件中。虽然不是 `Netcat` 的衍生品，但 `Ncat` 的用法相似。

### 端口扫描

**端口扫描器** 是设计用于探测计算设备开放逻辑端口及其关联服务的软件工具。[图 9.10](#c09.xhtml#c09-fig-0009) 展示了攻击者用于定位并利用目标设备（如服务器或端点）漏洞的工具之一。

![图 9.10 端口扫描](images/c09f010.png)

[**图 9.10**](#c09.xhtml#R_c09-fig-0009) 端口扫描

端口扫描器通过网络连接向目标主机发送服务请求。这些请求被发送到一系列知名端口值，以识别目标上运行的网络服务。一种称为 **端口扫掠** 的端口扫描形式用于扫描网络环境中响应特定端口的设备，例如响应端口 530（*远程过程调用，RPC*）的计算机。

对于网络管理员而言，端口扫描应被视为攻击序列中可能的第一步。在刚才的示例中，如果黑客定位到此类端口，他们便可开始准备利用该端口的攻击，以利用与之关联的潜在漏洞。在端口扫描与漏洞扫描相结合的情况下，管理员应将后续攻击视为迫在眉睫。

### 漏洞扫描

**网络漏洞** 扫描器包用于扫描企业中的不同类型的常见漏洞（如系统错误配置和默认密码使用），如 [图 9.11](#c09.xhtml#c09-fig-0010) 所示。某些扫描器还能通过生成畸形数据包来创建拒绝服务（DoS）攻击。

![图 9.11 漏洞扫描](images/c09f011.png)

[**图 9.11**](#c09.xhtml#R_c09-fig-0010) 漏洞扫描

网络安全专业人员和黑客都使用这些工具来识别漏洞或获取未经授权的访问。它们在识别以下类型的漏洞方面尤为有价值：

*   网络上的活动主机（包括可能隐藏在网络中的主机）
*   易受攻击的活动端口和服务
*   与操作系统服务器应用程序相关的漏洞

所有漏洞扫描器都是数据库驱动的工具，旨在搜索计算机中已识别并添加到数据库中的已知漏洞。因此，它们的有效性仅取决于其最近一次更新。基于此原因，必须在使用前更新所有漏洞扫描器。

虽然使用漏洞扫描器耗时且消耗资源，但这却是持续安全的重要组成部分，因为它允许尽快解决发现的漏洞，理想情况下是在它们被发现并被利用之前。

有许多免费和商业产品，以及不断增长的服务行业可提供这些监控服务。免费产品是很好的起点，因为它们通常易于设置且不需要大量资源。以下是一些值得考虑的产品：

*   **Nagios** (`www.nagios.org`) 可能是最知名的仍有免费版本的网络监控工具，但它已发展为提供功能齐全的商业企业版。该项目的一个分支 `Icinga` 是一个开源替代品，其功能比 `Nagios` 免费版更全面。这两款产品都拥有大量监控、报告和通知选项，最适合正常运行时间监控，但也可监控性能。
*   **SolarWinds** (`www.solarwinds.com/network-performance-monitor`) 提供功能极其强大的商业网络性能监控产品（NPM），它是其 Orion 平台的一部分。虽然该产品价格略高，但功能强大，可监控正常运行时间、性能、流量和利用率，并提供大量报告、图表和通知选项。
*   **Microsoft Network Monitor** (`https://docs.microsoft.com/en-us/troubleshoot/windows-server/networking/network-monitor-3`) 是一款数据包分析器，可帮助您查看流量流并排查网络问题。正如您所料，该产品在与专有 Microsoft 协议交互方面表现出色，但也支持大多数常见公共协议。
*   **Wireshark** (`wireshark.org`) 是一款成熟的开源跨平台网络协议分析器。它可能是最知名的协议分析器，支持几乎所有协议，且可在几乎任何平台上运行。
*   **Wireshark**（如 [图 9.12](#c09.xhtml#c09-fig-0011) 所示）是一款用于捕获并随后分析流量以发现和排查网络问题的宝贵工具。它利用网络适配器的 **混杂模式** 功能工作。此模式使网络适配器能够监听通过线缆（或无线网络适配器的无线电波）传输的流量。分析器软件随后收集所有数据包并将其组织成图形化的有用系统，供用户筛选信息。

    ![图 9.12 Wireshark](images/c09f012.png)

    [**图 9.12**](#c09.xhtml#R_c09-fig-0011) Wireshark

    它可用于了解给定网络上使用的协议。该工具易于使用，但需要经验和实践才能准确分析其产生的结果。

*   **Snort** (`snort.org`) 是一个开源、跨平台的入侵检测系统，提供实时流量分析、数据包记录和协议分析，以及对蠕虫、端口扫描和漏洞利用尝试的主动检测。这对于实时监控网络非常有用。它非常适合识别探测和攻击，但也可充当网络嗅探器。`Snort`（如 [图 9.13](#c09.xhtml#c09-fig-0012) 所示）是具有公共服务的网络的优秀产品。

    ![图 9.13 Snort](images/c09f013.png)

    [**图 9.13**](#c09.xhtml#R_c09-fig-0012) Snort

*   **Nmap**（如 [图 9.14](#c09.xhtml#c09-fig-0013) 所示）是一个开源、跨平台的网络映射实用程序，用于网络发现操作、安全审计操作和创建网络资产清单。它还用于执行网络监控功能和跟踪升级计划。这是一款用于检查和分析网络以及发现端口和版本的优秀产品。

    ![图 9.14 Nmap 实用程序](images/c09f014.png)

    [**图 9.14**](#c09.xhtml#R_c09-fig-0013) Nmap 实用程序

*   **Nikto** (`https://cirt.net/nikto2`) 是一个开源 Web 服务器扫描器，可识别 Web 服务器上的问题。该工具可对 Web 服务器执行全面测试，检查 6,700 多种安全威胁。`Nikto` 预装在 Kali Linux 发行版的漏洞分析类别中，或可从 GitHub 站点 (`https://github.com/sullo/nikto`) 获取。
