
# 代理服务器

`proxy` 是一种屏障，可防止外部人员进入局域网，并防止内部人员直接连接到外部资源，如 [图 3.10](#c03.xhtml#c03-fig-0010) 所示。相反，它允许客户端建立通过它路由的间接网络连接。客户端连接到代理服务器，可能需要有意识的身份验证，也可能不需要，并请求来自另一台服务器的资源。代理服务器将通过从其自身的缓存副本返回请求的资源，或将请求转发给另一台服务器（在可能修改请求之后）来处理该请求。

![图 3.10 代理服务器的操作](images/c03f010.png)

[**图 3.10**](#c03.xhtml#R_c03-fig-0010) 代理服务器的操作

发送到互联网的所有寻址信息都将使用代理服务器的 IP 地址。由于未使用请求资源的客户端的 IP 地址，外部入侵者无法访问本地主机。

代理过滤是一个比数据包过滤复杂得多的过程。在此过滤过程中，每个数据包都会被拆解、评估并重新组装，这使得这种类型的连接比其他防火墙类型慢得多。代理过滤防火墙被配置为查看完整的数据包，以检查一致性、应用程序类型和适当的端口。试图通过这些端口传输到客户端的数据必须与代理过滤防火墙的预期相匹配，否则未知数据包将被丢弃，连接将中断。

如 [图 3.11](#c03.xhtml#c03-fig-0011) 所示，可以安装代理服务器，通过充当中介来隔离 OT 网络与企业网络产生的外部请求，从而提供边界保护。代理阻止了对 OT 网络的直接连接，并处理确定哪些被请求的资源应被处理的任务。

![图 3.11 使用代理服务器进行边界保护](images/c03f011.png)

`纵深防御策略` 是指包含多种不同的重叠安全机制，可将攻击者攻破单一机制的影响降至最低。在本章后续章节中，您将了解 IT 和 OT 环境中的安全分区概念。这些概念最终将构建成 `Purdue ISA-95 参考架构`。这些概念将扩展以包含 `IIoT` 和 `云服务` 变体。

除了这些示例中描述的 DMZ、路由器和防火墙外，IT 和 OT 网络都应采用下一节讨论的安全拓扑策略之一，以最大化整体纵深防御策略。

## 安全拓扑

如前所述，OT 和 IT 网络的意图和操作截然不同。OT 系统需要 `实时数据`，而 IT 网络则不需要。OT 网络关注可用性、完整性，然后是机密性 (AIC)，而 IT 网络旨在首先提供机密性，其次是完整性，最后是可用性 (CIA)。

同样，在这两个网络上进行的活动类型从根本上讲是相互对立的。IT 网络旨在创建、存储和操作数据，而 OT 网络旨在提供实时测量和控制功能。

当 IT 环境中发生延迟时（例如屏幕上显示 Windows 沙漏在旋转），用户生产力会下降。然而，如果类似的延迟发生在 OT 环境中，后果将不堪设想：

*   生产中断。
*   产品不符合质量标准，必须报废。
*   生产设备损坏或毁坏。
*   人员受伤或死亡。

IT 企业网络通常比其 OT 对应网络代表大得多的安全风险。OT 网络倾向于运行在比 IT 网络使用的更冷门的设备、操作系统、应用程序和网络上。此外，历史上 OT 网络从未以任何方式连接到公共互联网。

由于 OT 网络的 AIC 特性，必须小心不要向该网络部分引入会在需要时延迟数据移动和访问的安全功能。这包括添加防病毒/反恶意软件产品、缓慢的防火墙/代理服务，或入侵检测/防御 (IDS/IPS) 设备和服务等典型的企业措施。然而，有许多方法可以使连接网络的 IT 侧更安全，从而使 OT 网络更安全。

安全的 IT 网络设计通常将网络段组织成多层安全结构。刚才介绍的每种网络安全结构都可能是给定组织网络设计的一部分。此外，组织网络的某些部分（如其内部网）可能根据与每个段相关的安全需求细分为多个段。

连接到网络的所有智能设备都必须具有能够将设备连接到网络传输介质的 `网络接口适配器`。这包括提供插头和插座等物理连接方案，以及提供设备与跨传输介质（电缆或无线电波）传输的信号之间的电气兼容性。

此外，网络通常包含其他 `连接设备`，用于将网络的不同部分连接在一起并执行不同的网络管理功能。这些连接设备通常是交换机或路由器。在大型或复杂的网络中，您可能还会发现称为 `网桥` 的设备，用于互连网络的各个部分。

虽然每个设备都提供物理连接，但它们也各自具有特定的操作方法，使其适合用于特定的网络应用。在某些情况下，功能更多的设备可用于执行功能较少的设备的功能。

### 网络交换机

`网络交换机` 是在 OSI 模型第 2 层运行的连接设备。^(\*) 它们旨在将 `网络设备` 连接在一起以形成局域网。`企业网络` 通常采用交换机组合来分割网络并建立高效的数据流量。它们可以与其他网络连接设备结合使用，也可以通过主干布线直接连接到服务器室。

例如，一家跨越办公楼多层的公司可能会在每层楼使用单独的交换机，为该楼层的所有设备提供连接。各楼层的交换机也将通过交换机或路由器相互连接。[图 3.12](#c03.xhtml#c03-fig-0012) 显示了典型的网络交换机连接方案。

![图 3.12 网络交换机连接](images/c03f012.png)

[**图 3.12**](#c03.xhtml#R_c03-fig-0012) 网络交换机连接

交换机收集 MAC 地址信息以跟踪连接到它们的设备。当它们与这些设备交互时，会将其 MAC 信息记录在一个称为 `MAC 地址表` 的板载内存结构中。

当交换机在其某个 `端口` 接收到网络信息包时，如果知道接收者的地址，它可以将该信息定向发送给预期的接收者。如果地址未知，交换机将向其所有端口 `广播` 该信息。由于通过交换机传输的信息通常仅发送到预期端口，因此整个网络的性能得到了极大提高。
