**道德黑客**

: 任何用于测试或评估系统及其资源的黑客技术，前提是获得数据和网络所有者的同意，目的是评估任何弱点。由于不存在公认的道德标准，道德黑客实际上归结为合法黑客行为，即被渗透测试资产的所有者已给予测试人员合法的（合同约定的）授权以进行规定的测试。

**道德规范**

: 基于道德原则，在特定情境下判断何种行为是正确或错误的。

**Ettercap**

: 一款免费开源的软件工具，用于执行多种网络和安全分析。

**EV 证书**

: 扩展验证（EV）证书要求由证书颁发机构验证个人身份。这些证书通常用于使用 SSL/TLS 的网站。

**排除**

: 安全专业人员用于禁止、阻止或移除对被排除资产访问的方法、设备或系统。

**eXecute Disable (XD) 位**

: 内置于微处理器硬件中的一项功能，用于保护包含特定指令代码块（如内核）的特定内存区域。

**exFAT**

: 微软针对闪存设备推出的扩展文件分配表文件系统。

**退出延迟**

: 安全系统激活时的时间延迟，给予人员离开场所的时间，以免触发警报。

**漏洞利用代码/工具**

: 旨 in 利用计算机系统中特定漏洞或缺陷的软件程序或工具。

**出口级加密**

: 一种加密方法，其强度被设定为“足够好”但仍允许 NSA 解密美国境外的通信。NSA 在 20 世纪 90 年代末取消了这一出口限制，但这些密码套件仍保留在客户端和服务端库中。

**ext#**

: ext# 系列扩展文件系统是为 Linux 内核设计的主要文件管理系统。ext2 也广泛用于 SD 卡和其他基于闪存的存储设备。

**外联网**

: 一种授权外部用户（如企业合作伙伴）有限访问的内部网结构。换句话说，一种部分私有、部分公开的网络结构。

### F

**F2FS**

: 三星的闪存友好文件系统（版本 2）是一款面向闪存存储设备的开源 Linux 文件系统。

**故障安全/失效安全**

: 对特定类型的故障以一种将对人员或设备造成的伤害降至最低的方式进行响应的方法。也称为故障安全/失效安全。

**故障安全/失效安全**

: 对特定类型的故障以一种将对人员或设备造成的伤害降至最低的方式进行响应的方法。也称为故障安全/失效安全。

**故障软化/失效软化**

: 当发生硬件或软件故障时，将终止任何非必要处理的模式。

**失效模式与影响分析 (FMEA)**

: 一种定性分析工具，用于评估流程以识别其可能失效的位置和方式（失效模式），并评估不同失效的相对影响。该评估可用于识别最可能失效的流程组件，从而对整个系统进行创新改进。

**假阴性**

: 导致错误拒绝合法人员的报告，从而将本应有权进入的人员拒之门外。在日志记录或取证分析中，假阴性结果是指当特定条件或属性实际存在时，却错误地指示其缺失。

**假阳性**

: 错误地认证人员身份的报告，可能导致向本不应拥有访问权限的人员提供设备或数据访问权限。在日志记录或取证分析中，假阳性结果是指当特定条件或属性实际不存在时，却错误地指示其存在。在两类认证失败中，这是最严重的，因为它可能授予恶意人员访问权限。

**故障树分析 (FTA)**

: 一种分析系统安全性和可靠性的工程工具，用于确定流程如何失效，以及如何最好地降低与这些流程相关的风险。

**反馈**

: 从流程输出回馈到控制器的路径，控制器随后对流程输入施加适当的校正动作。

**现场总线网络**

: 这是对 PLC（可编程逻辑控制器）的流程输入和输出线路的统称。

**现场设备**

: 设计用于部署在受控流程附近的工业控制器。

**视野**

: 给定监控摄像头能够看到的范围。也称为视场。

**文件和文件夹级加密**

: 应用于单个文件和文件夹的加密。文件和文件夹级加密工具允许用户使用密钥加密存储在驱动器上的文件，只有指定用户（或授权的恢复代理）才能解密。这可以防止没有密码或解密工具的人窃取数据。该技术用于保护静态数据（存储中的数据）。

**FileVault**

: Apple OS X 操作系统自带的基于磁盘级别的数据加密服务。

**火警分队/中间人劫持攻击**

**防火墙**

: 通常由硬件和软件组合而成的设备，用于保护私有网络免受来自不受信任网络（如互联网）的未授权访问。

**防火墙规则**

: 防火墙用于确定将过滤哪些通信的规则。

**固件**

: 固件是已编程到只读存储器中的永久性软件。

**鱼眼镜头**

: 一种超广角镜头，牺牲直线透视以换取更大的可视区域。鱼眼镜头拍摄的图像边缘通常会畸变。

**定焦镜头**

: 焦距固定、无法像普通变焦镜头那样调节的镜头。

**扁平网络**

: 一种网络类型，它是一个网络段，所有设备无需连接设备（路由器和交换机）即可相互通信。

**Fraggle 攻击**

: 一种拒绝服务攻击，类似于 Smurf 攻击，攻击者向网络中的广播地址发送伪造的 UDP 数据包。
