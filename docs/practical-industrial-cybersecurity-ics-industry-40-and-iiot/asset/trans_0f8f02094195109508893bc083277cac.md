

### D

**dictionary attack**

: 使用字典中的每个单词作为给定用户名的密码，进行系统性的暴力破解攻击。

**digital certificates**

: 数字验证，用于确认加密消息的发送者就是其声称的身份。

**digital video recorders (DVRs)**

: 监控摄像头的首选录制系统类型（而非 VCR）。DVR 技术允许将 CCTV 图像传输到磁盘，减轻了劣质视频存储介质带来的负面影响。

**direct-attached storage**

: 一种通过 `USB` 或 `eSATA` 连接将额外的磁盘驱动存储设备直接连接到 DVR 的技术。

**directory harvest attacks (DHAs)**

: 垃圾邮件发送者猜测某域名下的电子邮件地址，然后连接到该域名的邮件服务器的过程。未被拒绝的地址被视为有效地址。

**directory traversal**

: 就攻击而言，目录遍历利用软件或 Web 应用程序访问本不应访问的文件。这是通过遍历到更高级别的文件夹或目录来完成的。

**disaster recovery plan (DRP)**

: 计划本身是为成功的灾难恢复做准备的第一要素。它应包含构成系统中每个网段的所有组件的完整清单，以及构成每台服务器和工作站的所有组件。这包括所有需要恢复的相关软件。

**discretionary access control (DAC)**

: 用户可自行决定谁有权访问其对象以及访问程度的配置。

**discretionary access control list (DACL)**

: 对象或用户对网络中特定资源拥有的权限列表。

**disk-level encryption**

: 使用技术加密整个磁盘结构的过程。该技术可保护磁盘上的所有内容免遭未经授权的访问，包括操作系统文件和结构（无论是静止状态还是传输状态）。

**distorting proxy**

: 隐藏或修改您的 IP 地址及相关信息的代理服务器。

**distributed control system (DCS)**

: 一种智能控制系统，它使用分布在整个过程中的多个自主控制器来处理许多控制回路，无需监控控制器的协调。不过，DCS 可与远程监控和监督系统协同运行。当流程过于复杂，单个控制器无法处理，或其组件在地理上分离时，就有必要将控制功能分配到多个控制器上以形成 DCS。

**distributed denial-of-service (DDoS) attacks**

: 同时使用多个远程系统对目标资源发起大规模 DoS 攻击的过程。

**Distributed Network Protocol (DNP3)**

: 一套工业通信协议，旨在为电网系统中的中央 SCADA 主站与不同类型的远程设备（控制器，如 IED、PLC 和 RTU）之间提供联网功能。

**Distributed Reflection and Amplification Denial of Service (DRDoS)**

: 一种网络攻击，攻击者利用相对较小的僵尸网络对反射服务器发起分布式攻击，反射服务器重定向接收到的查询，使其看起来像是反射服务器本身是实际攻击源。

**diversion**

: 旨在分散个人监视注意力的战术。通常制造干扰是为了让攻击者在不被发现的情况下查看敏感信息，或在不被盘问的情况下进入安全区域。

**domain**

: 一种计算机环境，网络中的所有成员共享一个通用的目录数据库，并被组织成不同的层级。域由唯一名称标识，并作为具有通用规则和程序的单一单元进行管理。

**domain controller**

: 控制域的对象、规则和程序的中心化服务器。

**Domain Name System (DNS) servers**

: 包含 DNS 数据库（`*.dns` 文件）的服务器，用于将计算机名解析为 IP 地址。这些服务器还包含完全合格域名（`www.marcraft.com`）与其所代表的 IP 地址之间的映射关系。

**double encapsulation VLAN hopping attack**

: 一种网络攻击，导致在原始帧上添加两个标头（双标记）。其中一个标记代表目标的 VLAN ID，另一个代表攻击者交换机的 VLAN ID。当数据包到达攻击者的交换机时，第一个标记被剥离，但第二个标记随数据包保留。随后数据包被转发到目标交换机，后者读取标记并将数据包转发给目标主机。

**dual-firewall DMZ**

: 一种网络配置，防火墙位于 DMZ 的两侧，用于过滤内部网与 DMZ 之间以及 DMZ 与互联网之间的流量。这些防火墙用于将公共流量路由到 DMZ，将内部网络流量路由到内部网。

**due care policy**

: 要求各级管理层采取措施，确保在整个组织中提供特定安全防护的政策。此类行动可降低设备损坏或人员及访客受伤的概率。

**dumpster diving**

: 在实体的垃圾中搜寻有用信息碎片的过程。信息包括但不限于电话记录、旧日历、组织架构图和笔记本。此行为属于网络攻击链的侦察阶段。

**dynamic ARP inspection (DAI)**

: 一种旨在阻止 MITM 攻击的配置功能。DAI 使用 DHCP Snooping 数据库来检查和验证 ARP 请求，以防止 ARP 欺骗攻击。

**Dynamic Trunking Protocol (DTP) request**

: 攻击者向网络交换机发送请求，将攻击者的端口配置为中继连接。

**dynamic variable**

: 可能因外部影响或内部影响而自发变化的物理参数。

### E

**eavesdropping**

: 未经当事人同意，秘密窃听私人对话的行为，通常是为了获取适用信息。

**eCryptfs**

: 主流 Linux 操作系统内置的软件包，提供文件系统级加密服务。此级别的加密允许将加密服务应用于单个文件或目录，而无需承担大量的磁盘管理开销。

**egress**

: 离开某地的动作，无论是物理上还是逻辑上。

**Encapsulating Security Payloads (ESP)**

: ESP 协议在 IPSec 协议套件中提供完整性、机密性和认证以及加密。ESP 在 ESP 标头中加密并封装整个 TCP/UDP 数据报，该标头不包含任何端口信息。

**Encrypting File System (EFS)**

: Microsoft Windows 的文件和文件夹级加密服务。

**encryption**

: 加密数据涉及获取数据（明文）并使用密钥代码（密码）对其进行处理，该代码定义了原始数据版本是如何被操作的（密文）。

**encryption key**

: 用于将明文转换为密文（反之亦然）的密钥或算法。

**entropy**

: 随机性的度量，或缺乏可预测性和秩序，导致一定程度的不确定性。

**entry delay**

: 安全区域可配置的延迟，给进入场所的人员留出时间，在警报激活前访问内部安全面板以解除警报。

**enumerate**

: 建立网络拓扑图，或确定可发现哪些设备和主机。

**error signals**
