
Wi-Fi 和蓝牙的传输范围均有限，但在这些范围内，黑客有可能拦截无线连接，或者至少干扰无线连接。当然，这些网络也带来了前文所述的所有漏洞，这使得它们对黑客更具吸引力。

除了无线技术向工业传感器和控制环境迁移之外，企业中也出现了一种日益增长的趋势，即允许员工自带笔记本电脑、平板电脑和智能手机等端点计算设备进入工作场所。在许多情况下，企业还提供 Wi-Fi 接入以适应这种 `自带设备` (`BYOD`) 环境。正如将 OT 网络连接到企业网络为外部人员利用此前相对更安全的 OT 环境开辟了新途径一样，连接到 OT 网络的 `BYOD` 设备敞开了更多的漏洞。

网络管理员和安全人员必须确定这种 `BYOD` 环境是否会给其网络造成安全缺口。例如，与特定 `BYOD` 端点（或其特定配置）相关的漏洞可能使未经授权的用户能够通过该设备访问网络，并利用该连接窃取专有或敏感数据。在这些情况下，组织必须在其风险评估中纳入这些额外的漏洞，以确定其对这类政策和做法的风险接受程度。

### 近场通信

`近场通信` (`NFC`) 是一种短距离无线连接协议标准，可用于在设备彼此靠近时发起通信。通信发起后，另一种无线技术（如蓝牙或 Wi-Fi）可能会接管以执行数据交换。这种高频技术非常适合某些安全应用，因为它要求标签（如 RFID 身份徽章）与读卡设备之间必须近距离接触。这种近距离要求非常重要，因为它可以最大限度地减少未经授权的访问尝试。许多低频（通常为 125 KHz）系统已被用于安全徽章系统。

虽然利用这些系统并非易事，但它们容易被拥有专用硬件和一定技能的人利用。黑客通过靠近佩戴 RFID 徽章的用户，利用自己的读卡器读取目标的徽章信息。一旦捕获到徽章数据，他们就可以制作自己的徽章以绕过访问控制。这可能发生在用户身处食堂、当地咖啡厅，甚至通过藏在办公室或生产设施中的小型 `IIoT 设备` 时发生。

在互联网上并不难找到制作攻击工具的方案，该工具可插入商用 RFID 读卡器（也很容易获取）。在支持任何 `NFC` 系统之前，网络管理和安全人员审查其安全机制至关重要，因为某些系统比其他系统更脆弱。

### 移动设备安全防护

虽然 `移动设备` 的安全顾虑在非 ICS 应用中当然更大，但所有移动用户在使用移动网络以及在工作场所使用移动设备时都应保持谨慎。

*   除非您正在与设备配对且需要此功能，否则请关闭蓝牙自动发现功能。也请留意蓝牙设备上的其他安全选项。
*   避免使用公共热点。但是，如果您确实使用它们，请注意潜在的恶意行为，并使用 `TLS/SSL` 连接，仅在受保护的系统中输入凭据。
*   关闭自动连接（重新连接）到 Wi-Fi 接入点的功能。
*   蜂窝网络不太可能被攻破；当需要高安全性时，请使用蜂窝网络。
*   如果实现了端到端加密，所有无线技术都会更安全。

## 操作系统安全/加固

`操作系统` 是旨在控制和协调计算机系统运行的程序。作为一类，它们无疑是有史以来设计得最复杂的程序之一。在所有基于微处理器的环境中，操作系统从程序或输入源（如计算机用户）接收命令并执行它们以执行某些所需操作。同样，操作系统在近乎同样复杂的软件应用程序和它们运行所在的计算机硬件之间充当中介。

正如 [图 4.8](#c04.xhtml#c04-fig-0008) 所述，操作系统充当应用程序与计算机硬件之间的桥梁。这些应用程序使用户能够创建与特定应用相关的数据文件，如文字处理、多媒体分发、远程数据通信、业务处理和用户编程语言。

由于操作系统是通往计算机应用程序和数据的电子网关的主要组成部分，您必须了解不同的操作系统通用类型，以及可用于保护它们的工具和技术。

### 文件系统安全

`文件管理系统` 在保护存储在磁盘、光盘或可移动存储设备上的数据的存在性和完整性方面极为重要。如果文件系统被破坏或损坏，数据将变得不可访问并丢失。此外，如果未经授权的用户获得了对文件系统及其存储数据的访问权限，他们就获得了破坏、销毁或窃取数据的机会。

保护文件系统及其数据的主要工具之一是使用 `访问控制列表` (`ACLs`)。文件系统使用 `ACLs` 向特定用户授予或拒绝对其不同文件的访问权限，并控制授予访问权限后个人可执行的活动类型。例如，在文件管理系统的控制下，您可能被赋予运行文件、读取文件、写入文件或对其执行其他操作的能力。

操作系统的 `ACLs` 还用于控制对其他对象的访问，如 `TCP/UDP` 端口以及 I/O 设备。它们的 `ACL` 表维护记录，标识每个用户对特定系统对象拥有的访问权利。

根据操作系统的不同，资源访问控制可以以 `强制访问控制` (`MAC`) 或 `基于角色的访问控制` (`RBAC`) 的形式实现。UNIX 和 Linux 系统通常提供 `MAC` 方法，而 Microsoft Windows 平台提供 `RBAC` 控制。

在 `MAC` 版本中，操作系统决定谁可以做什么以及可以做到什么程度。在 `RBAC` 下，系统根据用户的授权来限制或允许对对象的访问。`RBAC` 结构通常是大型企业采用的访问控制方法。

在 UNIX 和类 UNIX 操作系统中，开发了一套称为 `可移植操作系统接口` (`POSIX`) 的互操作性标准，以标准化 UNIX 版本的变体。符合 `POSIX` 的系统（UNIX、Linux 和 macOS 系统）支持某种类型的 `ACL` 来管理传统的 UNIX 文件访问权限。

在 Microsoft Windows 环境中，这些功能以 `权限` 的形式分配给文件夹和文件。权限也可以被定义为执行某项操作的特权。在基于 UNIX 和 Linux 的系统中，为用户分配文件的 `访问权限`。

保护数据的另一个工具是对其进行 `加密`，使其在没有解密密钥的情况下变得不可用。加密/解密过程可以在数据存储和从设备检索时执行，也可以在数据从一个位置移动到另一个位置时执行。
