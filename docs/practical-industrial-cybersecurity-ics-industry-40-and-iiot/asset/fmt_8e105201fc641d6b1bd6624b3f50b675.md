
# 术语表

## C

**云计算**

: 利用远程联网服务器获取资源。这些资源可能包括数据存储、数据处理等，从而减少了本地机器的硬件需求。

**Common Platform Enumeration (CPE)**

: 一种在网络上描述和识别操作系统、硬件设备及应用程序类别的标准化方法。

**Common Vulnerabilities and Exposures (CVE)**

: 一个用于引用公开已知漏洞的系统。由 MITRE Corporation 维护，并得到美国国土安全部的支持。

**Common Vulnerability Scoring System (CVSS)**

: 一个对 CVE 漏洞进行评分的系统，使相关风险更易于理解。

**Completely Automated Public Turing test to tell Computers and Humans Apart (CAPTCHA)**

: 一种表单输入请求，要求输入单词、短语、随机字符和数字组合，或执行一个无法轻易自动化的简单测试。

**复杂度**

: 就密码而言，复杂度是输入长度、宽度和深度的组合。

**Conficker**

: 一种针对拇指驱动器的蠕虫，一旦连接到活动的 USB 端口就会自动执行。

**机密性、完整性和可用性 (CIA)**

: 经典的信息安全模型。

**连接设备**

: 用于创建网络连接的设备，包括集线器、交换机和路由器。

**应急计划**

: 在灾难/紧急情况发生前进行的规划。

**控制模式**

: 控制器用于校正测量值 PV 与指定设定点 SP 之间差值的技术。

**控制器**

: 控制器是一种硬件设备或软件程序，负责接收输入信息，将该信息与预设条件或参考值进行比较，决定应采取的行动，最后向执行机构发送校正误差信号，以调节被操纵变量。

**Cookie**

: Web 服务器在其页面被访问时发送给 Web 浏览器的小文件。发送 Cookie 的目的是为了允许在 Web 页面或基于 Web 的应用程序的不同访问会话之间保留信息。

**破解**

: 利用软件循环猜测密码，直到获得访问权限。

**CRAM-MD5**

: 一种质询-响应认证机制，支持以哈希形式传输密码的电子邮件认证系统。

**凭据收集**

: 收集用户认证信息的任何方法。

**跨站脚本攻击 (XSS)**

: 一种允许将客户端脚本注入 Web 页面的攻击方法，该页面可能被其他毫无戒备的用户使用。

**crypt**

: 早期 UNIX 版本附带的原始加密实用程序。

**密码学**

: 用于将数据转换为秘密代码的程序、过程和技术。

**CryptoLocker**

: 一种勒索软件木马。

**密码术**

: 对密码学的研究。

**电流环**

: 流经某区域两个连接点之间的电流大小。

**Cyber Kill Chain®**

: 由洛克希德·马丁公司开发的一种流程，旨在通过一系列步骤追踪网络安全攻击的阶段，以应对威胁攻击：侦察、武器化、投递、利用、安装、命令与控制、目标行动。

**网络战**

: 一种虚拟冲突，涉及出于政治动机对对手的 IT 或 ICS 网络发动攻击。

**网络犯罪分子**

: 通常由贪婪驱动、寻求经济利益的个人。这类攻击者可能是最著名的黑客类型，因为他们往往引起最多的关注。

**网络安全**

: 在保护对财产、系统和设备端口的物理访问的同时，保护包括电子、光学和信息访问在内的系统数据和控制等无形资产。

**网络安全策略**

: 解释保护组织网络数据和计算机系统所需总体要求的公司策略。

**网络恐怖分子**

: 通常不以金钱为动机，而是为了推进政治议程或意识形态。目标是给公众造成伤害和混乱。也称为黑客活动家。

## D

**守护进程**

: 一个拥有执行程序（后台进程）权限的标准默认用户/组，这些程序无需用户指导即可运行。

**数据汇聚器**

: 数据收集设备，用于将多个智能电表分组，并聚合其数据传输以传送给中央办公室的公用事业服务器。这些设备是 AMI 运营中数据和能源管理的核心。

**数据二极管**

: 一种在具有不同安全级别分类的网络或网段之间创建单向连接的设备。

**Data Encryption Standard (DES)**

: 一种用于数据加密的对称密钥算法。

**Data Execution Prevention (DEP)**

: 一种沙箱机制，将给定程序隔离在特定内存区域，以保护系统其余部分免受潜在攻击。

**数据历史服务器**

: 负责记录和检索从 PLC 获取的数据的软件组件。

**动态数据**

: 通过有线或无线网络传输的数据过程。

**使用中的数据**

: 正在被创建、更新、检索或删除的数据。

**死区**

: IPC 设定点上下的不活动带。也称为中性区或死区。

**取消认证洪水攻击**

: 一种网络攻击，攻击者向接入点发送取消认证数据包，进而移除所有先前已认证的连接设备。

**解密**

: 将先前加密的数据转换回其原始形式的过程。使用相关密钥将加密的密文解锁为明文以便理解的过程。

**解密密钥**

: 用于解密秘密代码的密钥。

**专用控制系统**

: 一种独立的过程控制系统类型，采用单个控制器来监控和控制单个过程或一组紧密集成的过程。

**深度包检测 (DPI)**

: 检查 TCP/IP 数据包中的实际数据，搜索病毒、垃圾邮件和其他已定义威胁的迹象，以确定是否应转发该数据包的过程。

**纵深防御**

: 一种包含多种不同重叠安全机制的防御策略，可潜在地最小化攻击者攻破单一机制造成的影响。

**分界点**

: 公共交换线路结束并连接到客户网络起始处的点。

**非军事区 (DMZ)**

: DMZ 是一个独立的边界网络，将安全的内部网与外部世界隔离开来，同时允许公众访问面向外部的专用资源。

**拒绝服务 (DoS)**

: 旨在过度使用主机、服务器或网络资源，使其功能上停止提供服务的攻击。

**微分控制**

: 一种将变化率控制因子应用于差值测量百分比变化的控制方案。

**Dynamic Host Configuration Protocol (DHCP)**

: 一种自动寻址协议，使用一系列 IP 地址，可动态租借给请求的外部设备，租期为预配置的时间长度。

**DHCP 服务器**

: 使用网络协议分发网络参数（如 IP 地址）的服务器。参见 Dynamic Host Configuration Protocol。

**DHCP Snooping**

: 内置于操作系统中的一种安全技术，用于过滤和阻止被视为不可接受的入站（入站）DHCP 服务器消息。
