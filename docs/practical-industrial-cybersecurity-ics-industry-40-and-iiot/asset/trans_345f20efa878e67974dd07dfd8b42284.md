

该模型包含用于集成云服务和其他 WAN 通信通道的控制，以适应更大或广泛分布的站点。传统 Level 0-2 与 Level 3 之间的划分，通过在 Cloud/WAN 系统两侧设置的边界保护来强制执行。在 Level 0-2 侧建立次要执行边界，而在 Level 3 侧应用主要边界执行解决方案。组织的管理服务器、HMI、工程站、测试和预演系统、远程访问以及网络安全运营被划分到 Level 3 层的子层中。

与 Purdue 模型的更高级版本一样，DMZ 在 ICS410 模型中被战略性地部署，以提供 A 到 B 的推送和 B 到 C 的拉取，但在所有 IT 和 OT 层之间不提供 A 到 C 或 C 到 A 的通信路径。防火墙是该模型 Layer 3 和 Layer 4 之间的首选控制设备。这些防火墙应配置为阻止进出 OT 网络的所有流量，并为最小必要流量实施显式允许规则。Level 3 和 Level 4 之间，以及 Level 4 和 Level 5 之间也需要部署防火墙。

包括多因素认证在内的额外认证方法，应用于所有通往 OT 网络的访问路径。应对进出 OT 网络的所有文件执行恶意软件检查。同样，进出 OT 网络的所有流量都应被记录。最后，Level 4 以下不应允许互联网访问。

## 网络分段

*网络分段* 是一种子网划分技术，用于根据组织的职能划分将网络分成分层段。例如，处理高度机密信息的部门通常没有充分理由直接与其他非涉密部门联网。

通常，使用物理防火墙和路由器来创建网络分段，以控制网络层级（段）之间的流量流动。**图 3.25** 描绘了一个通用的分段业务网络。在该示例中，路由器配置为与互联网连接，并将 IP 地址在 134.141.x.x 范围内的所有数据包传递给本地网络内指定的子网。当数据包到达子网时，它会被地址中指定的第四个八位字节（0-254）的主机接受。

![FIGURE 3.25 A segmented network](images/c03f025a.png)

**图 3.25** 分段网络

就我们的目的而言，网络分段的主要优势是通过使段的内部结构对其他网络段和外部世界不可见，从而增加了安全性。分段网络将限制入侵企业网络的深度，并最小化攻击的传播。

然而，安全性增强并非网络分段的唯一优势。由于限制了来自其他段的流量，本地段内的性能水平也会提高。另一个优势是分段将局部故障隔离在段内，使其更易于检测、排查和修复。然而，分段也会影响网络的整体性能，并需要额外的管理。

在以下章节中，我们将探讨另外两种也可用于创建网络分段的方法：NAT 分段和使用第 2/3 层交换机的网络虚拟化。

### 网络地址转换分段

*网络地址转换 (NAT)* 是大多数路由器、服务器和防火墙的功能。虽然 NAT 的主要目的是将内部网络的 IP 地址对外部网络屏蔽，但它也提供了一种简单直接的方法来分割组织内部网的物理结构。**图 3.26** 说明了一个 NAT 分段网络。

![FIGURE 3.26 A NAT-segmented network](images/c03f026.png)

**图 3.26** NAT 分段网络

例如，在一个按功能分段的网络中，可以安装 NAT 防火墙为既需要最低安全性又需要互联网访问的部门提供分段，而不使用其他安全协议。

然而，NAT 并非安全万能药。它需要仔细配置，且提供的安全性有限。事实上，NAT 会妨碍您可能想在 LAN 上使用的许多其他安全协议。主要是，NAT 无法与任何加密 IP 信息的协议良好配合。这使得诸如 *点对点隧道协议 (PPTP)* 之类的隧道协议与 NAT 防火墙不兼容。

最流行的协议之一 *IPSec* 采用 *认证头 (AH)* 协议来防止传输中的数据包被篡改。由于 NAT 旨在更改源 IP 地址，如果在同一网段上使用，IPSec 认证将会失败。此外，IPSec 采用 *封装安全载荷 (ESP)* 在 *传输模式* 下检查 IP 地址，如果 NAT 转换了源 IP 地址，这也会失败。

任何将源 IP 地址与认证密钥绑定的协议，都将无法认证或协商会话，因为 NAT 会更改源 IP 地址。这对 *互联网密钥交换 (IKE)* 以及 *证书颁发机构 (CA)* 同样适用。同样，由于 *文件传输协议 (FTP)* 将源 IP 地址转换为 ASCII 文本，它也与同一网段上的 NAT 不兼容。

然而，可以使用一种称为 *NAT 穿越 (NAT-T)* 的 UDP 封装技术，跨 NAT 网关建立 IPSec 连接。如前所述，NAT 设备会改变导致数据包被丢弃的数据包真实性。NAT-T 添加一个未加密的 UDP 头来封装 IPSec ESP 头。这导致数据包被视为普通 UDP 数据包，从而通过网关。NAT-T 操作需要三个端口开放：UDP 端口 4500 (NAT-T)、UDP 端口 500 (IKE) 和 IP 协议 50 (ESP)。

### 网络虚拟化

并非所有网络结构都是表面看起来那样。*虚拟局域网 (VLAN)* 是覆盖在一个或多个物理 LAN 之上的逻辑局域网。可以使用虚拟化软件将一个物理 LAN 划分为多个逻辑 LAN，或将多个物理 LAN 组织成一个逻辑 LAN。在这两种情况下，虚拟 LAN 的组织和运行可能与其运行所在的实际硬件几乎没有相似之处。每个虚拟 LAN 由一个 *VLAN ID* 标识，例如 VLAN10。

VLAN（连同 VPN 和 VPLS）是 *基于协议的虚拟网络结构*。作为一种安全拓扑，VLAN 通过限制指定端口和分组之间的流量流动，限制了网络流量的可见性。这些结构通常使用第 2 层管理型交换机创建，沿逻辑或功能通信链分离网络段，而不管其物理位置如何。交换机上的物理端口被分配给特定用户组以创建其自己的段。这使得逻辑 VLAN 组能够跨越多个物理网络段，而无需使用防火墙。
