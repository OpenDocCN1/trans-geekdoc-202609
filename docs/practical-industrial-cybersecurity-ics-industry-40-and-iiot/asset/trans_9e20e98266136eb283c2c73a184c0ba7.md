

## 8. 移除不必要的软件包

从服务器中移除任何不必要的软件包或实用程序，包括远程访问程序、语言编译器和开发工具，以及任何系统和网络开发工具。

## 9. 移除或禁用不必要的网络协议

移除或禁用运行所不需要的任何网络协议（打开的 TCP/UDP 网络端口）。

这些步骤中的每一步都要求服务器管理员在安全需求与用户需求之间取得平衡。理想情况下，服务器应被严格锁定并仅服务于单一功能。然而，随着安全性的提高，功能性会降低。

## 逻辑服务器访问控制

网络管理员还负责通过确定谁有权访问网络服务器、网络连接设备和数据的操作来实施企业策略。在大多数组织中，这是通过网络操作系统的管理工具来实现的，这些工具控制谁有权访问网络及其资源，以及他们可以对这些资源执行什么操作。

管理员可用的标准网络访问控制策略有三种：

*   **强制访问控制 (MAC)**：系统确定哪些用户或组可以访问文件、文件夹和其他资源。
*   **自主访问控制 (DAC)**：这些是用户有自由裁量权决定谁可以访问其对象以及访问程度的配置。
*   **非自主、基于角色的访问控制 (RBAC)**：这基于每个用户在组织中的工作角色。

MAC 策略为网络对象（如文件和文件夹）分配敏感度标签，并根据用户的权限级别授予访问权，如[图 4.23](#c04.xhtml#c04-fig-0023)所示。

![FIGURE 4.23 Mandatory access control](images/c04f023.png)

[**图 4.23**](#c04.xhtml#R_c04-fig-0023) 强制访问控制

如[图 4.23](#c04.xhtml#c04-fig-0023)所示，每个用户的访问范围取决于其管理员授予的许可级别。拥有 `Top Secret`（绝密）许可级别的人员可以访问所有被分配了绝密标签的对象。此外，他们还被允许访问所有具有较低标签的对象，如 Secret（机密）和 Classified（秘密）对象。

自主访问控制涉及赋予用户自由裁量权以确定哪些对象应受限或共享。每个对象都有一个所有者，负责确定谁可以访问该对象。这就是在对等网络环境中分配权限的方式。

因为每个对象都受权限级别约束，所有者可以选择使某些对象比其他对象更安全。此外，在 DAC 下，访问控制策略可以通过 `identity-based`（基于身份）或 `user-directed`（用户导向）的方式提供。

RBAC 是一种旨在对所有网络对象和用户进行集中控制的策略。网络管理员被授予指定和实施明确安全策略的权力，以执行组织的指定策略。每个网络用户或组被分配一个或多个角色，如[图 4.24](#c04.xhtml#c04-fig-0024)所述。

![FIGURE 4.24 Role-based access control](images/c04f024.png)

[**图 4.24**](#c04.xhtml#R_c04-fig-0024) 基于角色的访问控制

每个角色被分配特定权限，例如对文档文件的 `read`（读取）或 `write`（写入），或对特定对象的 `execute`（执行）、`full control`（完全控制）或 `no access`（无访问权限）。服务器负责维护一个 `access control list (ACL)`（访问控制列表）数据库，该数据库跟踪每个用户账户，包括他们可能被分配到的组账户，以及他们对不同对象拥有的权利和权限，如下所示：

### 示例文件 A

*   个别所有者可以读取、写入和执行该文件。
*   组成员可以读取和写入该文件。
*   所有其他人只能读取该文件。

![](images/c04uf001.png)

### 示例文件夹 B

*   个别所有者可以读取和写入该文件夹。
*   组成员只能读取文件夹内容。
*   所有其他人被拒绝访问该文件夹的任何权限。

![](images/c04uf002.png)

在每种策略类型中，当通过权利和权限分配为用户提供对对象的访问时，应实施 `principle of least privilege access`（最小权限原则）。根据最小权限规则，每个用户仅被授予执行其工作角色所需的访问级别。始终如一地应用此原则将安全漏洞造成的损害限制在初始任务、进程或用户范围内。

## 加固网络连接设备

不同的 `network connectivity devices`（网络连接设备），如 `switches`（交换机）和 `routers`（路由器），依赖 MAC 地址作为构建和使用内部 `content addressable memory (CAM)`（内容可寻址存储器）`tables`（表）的基础。设备使用这些表根据预期接收者连接的硬件端口，将它们从一个网段接收到的消息路由到另一个网段上的位置。

许多连接设备通过 `MAC learning and discovery`（MAC 学习和发现）过程构建和维护其 CAM 表。当它们与连接到其物理端口的设备交互时，它们读取消息头以获取发送和接收设备的 MAC 地址，并将它们连同端口信息一起记录在 CAM 中。

通常针对网络 MAC 层的攻击有两种常见类型：`MAC spoofing`（MAC 欺骗）和 `MAC broadcast flooding`（MAC 广播泛洪）。虽然 MAC 地址最初旨在作为网络适配器的永久（烧录）唯一标识符，但有可用的软件工具可以用来更改硬件和操作系统之间的这些地址。

虽然能够操纵 IP 到 MAC 地址的关系是 `virtualization`（虚拟化）（如创建基于云的环境）的一个重要方面，但这也为恶意操纵 MAC 地址敞开了大门，这种攻击被称为 `MAC spoofing`（MAC 欺骗）——更改设备的 MAC 地址以改变其身份，如[图 4.25](#c04.xhtml#c04-fig-0025)所示。这些工具和攻击将在本章后面结合针对网络连接设备（如网络交换机）的攻击进行描述。

![FIGURE 4.25 MAC spoofing](images/c04f025.png)

[**图 4.25**](#c04.xhtml#R_c04-fig-0025) MAC 欺骗

交换机拥有监控端口，可收集关于其所有连接端口的信息，包括其 VLAN 端口。这使它们成为想要收集信息的攻击者的主要目标。他们只需识别其中一个连接的 VLAN 交换机即可获取所有其他端口连接的数据。

当前的交换机型号接口通常使用带有 GUI 的 SSH 或 HTTPS 连接进行配置。对于集中管理，应使用 `Terminal Access Controller Access-Control System (TACACS)`（终端访问控制器访问控制系统）、`Remote Access Dial-in User Service (RADIUS)`（远程拨号用户服务）或其他 `Authentication, Authorization and Accounting (AAA)`（认证、授权和审计）工具进行安全的远程访问控制。本地管理可以使用直接连接的控制台线缆来配置这些接口。

虽然交换机提供防嗅探的好处，但它们可能通过多种类型的第 2 层攻击被利用，例如 MAC、ARP、拒绝服务、中间人和欺骗攻击。

### 交换机端口安全

`Switchport security`（交换机端口安全）是内置于网络交换机中的一项管理功能，允许配置单个物理端口，以便通过该端口的流量可以限制为特定的 MAC 地址或 MAC 地址列表。这些地址可以通过三种不同的方式定义：

*   **Static secure（静态安全）**：当 MAC 地址（或地址）始终相同时，通常使用此指定。这假设同一设备始终连接到该端口且从不更改。
