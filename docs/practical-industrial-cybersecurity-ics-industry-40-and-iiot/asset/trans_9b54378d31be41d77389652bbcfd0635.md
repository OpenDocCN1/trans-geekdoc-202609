
当交换机接收到广播帧时，如[图 5.18](#c05.xhtml#c05-fig-0018)所示，它会将该帧发送回连接到交换机的所有其他设备。Jones 将接收到该帧，并识别出该广播帧是发给它的，因此它会使用广播帧的地址作为目标地址，发回一个 `反向 ARP` (`RARP`) 帧。

你可能会想知道的下一件事是：“是什么防止了监听网络的人接收广播帧并发回伪造的信息。” 事实是，几乎没有什么防范措施！ARP 欺骗更常见的用例之一是中间人攻击。

### DNS 欺骗

在计算机网络中，域名系统是一个分层的（即多级的）计算机命名系统，可以是集中式的，也可以分布在网络中，无论是私有网络还是公共互联网。DNS 的主要职责是将域名（如 `exampledomain.net`）转换为这些域在网络中所在位置的实际 IP 地址。

这样做的原因是域名比 IP 地址更容易让人类用户记忆。想象一下，如果每次想在互联网上通过 Google 搜索内容，你都必须记住并输入 `216.58.217.142`！你每天访问的所有其他收藏网站也是同理。

如果用于上网的主机计算机不知道所请求域名的 IP 地址，它必须联系 DNS 服务器并请求其帮助查找，如[图 5.19](#c05.xhtml#c05-fig-0019)所示。如前所述，DNS 由多个层级组成，所有层级负责域名的不同部分。

![FIGURE 5.19 DNS process](images/c05f019.png)

[**图 5.19**](#c05.xhtml#R_c05-fig-0019) DNS 过程

如果其中一台 `DNS 名称服务器` (`NSs`) 不知道所有请求的部分，它会继续将请求推送到系统中的下一个更高层级服务器。此过程持续进行，直到请求的域名被完整组装并找到 IP 地址。为了加快此过程，当主机计算机收到所请求域名的 IP 地址时，它会将该信息存储在其本地 DNS 缓存中，以便下次请求同一域名时立即使用。

假设 DNS 服务器从攻击者处接收到虚假信息，并将其缓存以供客户端系统未来请求使用。该 DNS 服务器现已被攻陷，被视为遭到投毒。因为 DNS 服务器被投毒，它会为请求的域名返回错误的 IP 地址，进而将流量发送到另一台通常属于攻击者的计算机。

攻击者可利用 DNS 欺骗向受害者发送欺骗性网站，例如虚假的银行网站或其他需要个人登录凭据以获取敏感信息访问权限的网站。这些页面通常设计得非常逼真，难以识别。

受害者将凭据输入登录提示后，网络数据包会被发回给攻击者，攻击者会收集受害者的凭据以备后用。视 DNS 欺骗的复杂程度而定，页面可能会实际将受害者重定向到他们最初寻找的合法网站和域名。或者，可能将他们转向其他预定域名。无论哪种情况，在受害者眼中这可能只是表现为一个“故障”。

尽管最初的 DNS 服务未作任何安全规定，但很快人们就发现它包含多个可被利用的漏洞。为缓解这些漏洞，开发了一套 `DNS 安全扩展` (`DNSSEC`) 来保护 DNS 记录。这些扩展基于一个称为 `区域签名` 的过程，即将扩展添加到 DNS 协议中，以提供来源授权、数据完整性和经过认证的不存在证明。这使得 DNS 攻击（如 DNS 欺骗）难以实施得多。

然而，恶意软件可利用 DNS 流量创建 DoS 攻击、执行命令与控制功能、从网络中窃取数据并执行 `DNS 隧道`。在将 OT 网络和 IT 网络相互隔离时，许多管理员并不禁止 DNS 流量。这使得 `DNS 隧道` 可被用于利用 DNS 查询和响应（针对属于攻击者的域名）向网络内外发送数据。据估计，超过 90% 的恶意软件依赖 DNS 来渗透和利用目标。

虽然拒绝 OT 网络的所有 DNS 流量是缓解 DNS 相关风险最彻底的解决方案，但在某些情况下需要本地 DNS。在这些情况下，应将 DNS 配置为拒绝涉及外部域的 DNS 请求。

另一方面，DNS 数据记录工作可用于分析模式并识别网络中的异常。这些技术在保护以极不安全著称的 SCADA 系统方面特别有帮助：其固件通常不安全，且其通信协议往往缺乏认证和加密组件。但所有连接 SCADA 的设备都必须拥有 IP 地址，这使得它们可以通过 DNS 过程进行监控。面向客户端的 DNS 防火墙/安全设备可用于监控活动、破坏攻击，并为基于 SCADA 的 OT 网络提供弹性。

### 拒绝服务

`拒绝服务` (`DoS`) `攻击` 是旨在过度使用主机、服务器或网络资源，以使其功能上停止提供服务的攻击。拒绝服务攻击如[图 5.20](#c05.xhtml#c05-fig-0020)所示。视攻击的确切性质而定，故障可能是暂时的，也可能是无限期的。`分布式拒绝服务` (`DDoS`) `攻击` 涉及使用多个远程系统同时对目标资源发起攻击。

#### DoS 攻击与 DDoS 攻击

DoS 和 DDoS 攻击特别令人头疼，因为它们非常容易实施，且没有办法完全使网络免疫于这些攻击。

最常见的 DoS 攻击类型涉及 `洪水攻击`，即用异常大量的"垃圾"外部通信请求（如 `ping` 命令生成的流量）淹没或过载目标服务器或其他网络资源。所有这些垃圾请求要么会将目标的响应速度拖慢到无法使用的地步，要么会阻止资源响应合法的网络流量资源请求。

DoS 攻击针对的实际资源可以是特定目标系统、该系统上的一个端口、计算机网络中的特定组件，或整个网络。DoS 攻击也可以设计为执行恶意软件，耗尽处理器等系统资源，这迟早会使任何系统瘫痪。DoS 攻击的最终目标是迫使系统不再像攻击前那样响应合法请求，无论服务是被严重限制还是完全拒绝。

大多数 DoS 攻击成本低廉且难以防御。由于其有效性，它们是脚本小子和技术熟练的黑客青睐的攻击类型。DoS 攻击经常源于对另一个个人或组织怀有怨恨的个人或组织。
