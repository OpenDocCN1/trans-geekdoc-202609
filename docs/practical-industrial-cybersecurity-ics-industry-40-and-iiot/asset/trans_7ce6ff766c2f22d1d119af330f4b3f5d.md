

# 跟踪端点及其操作系统和引擎版本

在 IT 网络中实施*端点检测和响应*（EDR）应用程序变得越来越普遍。EDR 会在网络的所有端点上部署端点数据收集代理，以对其进行监控并收集其运行数据。这些数据被汇总到一个集中的*安全运营中心*（SOC），在那里进行实时分析。

分析通常会检查每个端点上发生的活动量、与其的连接以及通过它传输的数据。这使得 EDR 能够*诊断*威胁，并根据威胁的性质及其配置参数自动触发响应。

当检测到威胁时，EDR 会采取行动*遏制*攻击。一旦采取了遏制行动并将威胁*沙箱隔离*后，EDR 随后会调查威胁的性质并采取行动*将其消除*。

## 反恶意软件：净化

大多数恶意软件以嵌入在标准文件格式（如 DOC、XLS、PDF、PPT 等）中的活动内容形式分发。攻击者只需将恶意代码（宏、脚本、Web 链接或二进制对象）隐藏在内容中，并通过电子邮件、Web 链接或可移动媒体将其传递给目标。恶意软件载荷通常设计为躲避防病毒和其他反恶意软件扫描。

您可能还记得，著名的*震网攻击*^(\*)使用了这些相同的要素，严重破坏了伊朗推进其核能力的努力。最近，一个被称为*“蜻蜓行动”*的类似行动针对 OT 网络发起。在此次攻击中，组织的网站被攻陷，来自受信任供应商的文件被感染。当管理员最终用户将这些文件作为受信任的软件执行时，该漏洞利用绕过了所有防火墙、白名单和防病毒安全控制。

反恶意软件厂商开发了新的文件*净化工具*，用于搜索附加在电子邮件中或通过 Web 链接、拇指驱动器和其他可移动媒体引入的文件中的此类对象。当在本不应包含这些对象的文件中发现它们时，工具会*净化*（剥离）文件整体内容中的可利用对象，并将文件的干净版本交付给用户。

净化与传统反恶意软件产品使用的检测/隔离/删除方法不同，后者通过将文件与病毒/恶意软件定义数据库进行比较，以确定标记或放行哪些文件给用户。在大多数情况下，净化与传统反恶意软件工作相结合，以交付真正受信任的净化文件，如[图 4.18](#c04.xhtml#c04-fig-0018)所示。

在这个三部分的过程中，文件首先通过传统的防病毒/反恶意软件解决方案进行处理，以消除那些明显受感染的文件。通过第一次检查的文件被引入文件净化器，其中会应用专门为指定文件类型设计的算法，以定位隐藏在文件结构中的任何恶意对象。如果检测到恶意代码，它会被从文件中剥离，而不会破坏其内容的完整性。最后，净化后的文件被交付给最终用户。

为了在不影响可用性的情况下保护 OT 网络，净化器通常以与传统 DMZ 相同的方式部署在企业网络和 OT 网络之间，如[图 4.19](#c04.xhtml#c04-fig-0019)所述。净化功能可以由 DMZ 中工作的服务器提供，或以 DMZ 内（或代替 DMZ）的网络设备形式提供。

# 嵌入式设备安全

*嵌入式设备*被定义为在更大系统中提供指定功能的计算设备。在 ICS 环境中，这包括控制器、PLC、RTU 和 IED 等设备，您在前面的章节中已了解过这些设备。然而，根据所讨论的 OT 网络的确切类型，可能还有其他类型的嵌入式设备需要考虑，例如分析仪、仪表和聚合器（汇聚器）。

工业网络中的计算和控制设备需要与其 IT 对应设备相同类型的本地安全。对工业控制设备（或 ICS 控制室）的物理访问可为攻击者提供破坏或损坏流程、系统或设备的手段。获得对控制室的物理访问也使攻击者处于更有利的位置，以获取对系统或其设备的逻辑控制。如果达到这种渗透级别，攻击者就有机会控制物理过程。如果他们获得对服务器或 ICS 主系统的访问权限，他们可能会控制整个 OT 系统。

OT 系统相对于企业网络的一个优势是，其计算和控制设备通常运行在专有操作系统和网络基础设施上，熟悉这些系统的人较少。因此，拥有这些软件和网络类型足够知识的潜在攻击者比企业环境中要少。这被称为*通过隐匿实现安全*。

然而，这也创造了一个环境，即负责这些系统的个人必须具备组件和软件的高级知识，以保持系统正确运行。虽然企业和公开分发的操作系统和应用程序具有相对简单的安装、设置和维护，但 OT 版本的管理可能要复杂得多。ICS 软件变更必须谨慎进行。

虽然 ICS 行业已经生产了具有原生安全工具的设备以及可添加到现有 OT 网络的安全设备超过 10 年，但仍有许多 OT 网络和设备在几乎没有或完全没有安全能力的情况下运行。在许多情况下，ICS 系统包含专门为执行特定任务而设计的组件，或者是在网络安全成为工业控制环境中的一个问题之前开发的组件。

由于 PLC 和 RTU 拥有的自我保护资源极少，因此通过加固其周围的边界来为这些设备提供保护变得非常重要。与企业网络设备一样，该边界的主要重点是通过执行以下操作来防止对 OT 资产的逻辑访问：

*   将 IT 和 OT 计算设备物理固定在基础设施上（扩展坞、锁定线缆、链条、可上锁的机柜）。
*   要求强访问控制（复杂密码）。
*   采用强身份验证方法（智能卡、生物识别扫描仪等）。
*   在组织的 ICS 部分的所有计算和控制设备上禁用或卸载可移动媒体驱动器和端口（CD/DVD 驱动器、USB/FireWire 端口、SD 卡插槽）。ICS 安全策略应禁止在 OT 中（或连接到 OT 的）任何计算/控制设备上使用任何未经授权的可移动媒体，以防止引入恶意软件或无意中丢失或窃取数据。
*   控制打印输出（处置和销毁策略、碎纸、焚烧）。
*   控制对备份数据和介质的访问（使用异地存储、上锁的机柜、防火保险柜）。如果攻击者能够访问 ICS 备份介质，他们可能会利用其内容。这些利用范围从从认证文件中提取密码到恢复可用于发起不同类型网络攻击的数据。
*   禁用电源按钮或防止其被未经授权的访问/使用。
