

# 术语表

## 通用术语

**硬化**  
: 使任何设备（硬件和软件）更安全的过程。通常涉及许多步骤和程序，同时考虑可接受的易用性。

**硬件防火墙设备**  
: 专门且仅设计用于作为防火墙运行的设备。

**硬件端口**  
: 各种计算机和网络设备之间的接口。

**硬件令牌**  
: 可提供身份验证的物理设备。也称为安全令牌。

**哈希表**  
: 使用哈希函数将键转换为哈希值，从而将键映射到值的查找表。也称为哈希映射。

**危险与可操作性研究**  
: 为揭示给定过程中存在的任何危险场景而进行的研究和分析。

**分层文件系统**  
: Apple 公司开发的专有文件系统，作为运行 macOS 的 Macintosh 系列计算机的主要文件系统。也用于 Apple 的 iPod 音乐设备系列。

**历史数据库**  
: 以控制点（称为标签）的形式存储历史数据的数据库管理系统。

**家庭局域网**  
: 由自动化电气设备控制器组成的专用局域网，通常位于住宅内或住宅附近。

**蜜罐**  
: 旨在将攻击者从真实网络引开的诱饵服务器、网络设备或网段。通过为攻击者提供对网络上诱饵系统的相对容易访问权限，并隐藏真正关键的系统来实现。

**基于主机的身份验证**  
: 一种依赖信息（如 MAC 地址和主机名）向网络进行身份验证的形式，而非依赖用户凭据。

**人机界面**  
: 使人工操作员能够观察不同工艺的运行参数，并接管工艺以更改参数或进行纠正的界面。

**虚拟机监控程序**  
: 托管其他客户操作系统的虚拟操作平台（类似于虚拟操作系统）。

## I

**Icinga**  
: 一款开源网络监控应用程序。

**ICMP**  
: 互联网控制报文协议，常用于测试从设备到网络的连通性。

**身份验证**  
: 将特定个人与现有身份关联并验证的过程。

**身份盗窃**  
: 通过欺骗手段获取他人各种身份证明文件的行为，通常为谋取经济利益。

**入侵检测系统/入侵检测与防御系统**  
: 入侵检测系统或入侵检测与防御系统，旨在主要监控系统（本地计算机或网络环境），记录关键事件和策略违规，并按指示报告。入侵检测与防御系统旨在监控技术环境（计算机或网络），记录关键事件和策略违规，报告并按指示阻止它们。类型包括**基于异常的 IDS/IDPS**，即使用异常分析来检测和防止未经授权的网络访问的入侵检测系统。分布式 IDS 系统是指连接到网络的本地主机安装了自己的 IDS 模块，此外，网络服务器上还安装了 IDS 管理模块，协调信息流向各个本地 IDS 模块。**基于主机的 IDS (HBIDS)** 是安装在单个系统上并保护该系统的入侵检测系统。**基于特征的 IDS/IDPS** 是通过查找内容中的特定模式（称为特征）来工作的系统。如果检测到已知的恶意模式，则采取适当措施保护主机。

**IEC/ISA 62443**  
: 一组国际自动化学会标准，定义了在工业自动化和控制系统环境中实施安全的程序。该标准以四个类别的形式存在，涉及通用安全概念度量、系统所有者策略和程序、安全系统设计（使用区域和管道方法实施安全）以及系统安全产品或组件。

**影响评估与分析**  
: 确定哪些单独威胁对组织构成危险的业务功能，以便实施适当的主动措施。

**带内**  
: 一种虚拟化方案，将设备置于存储服务器和磁盘阵列之间的直接路径上。此配置消除了在每台服务器上安装设备相关软件的需求，而带外配置则需要。

**事件响应策略**  
: 旨在为物理灾难、网络灾难或安全攻击情况下的人员职责、时间、地点提供指导的组织策略。

**工业过程控制器**  
: 根据其内部配置或编程，基于输入的当前状态产生输出条件的控制设备。这些设备可以是独立的或联网的，也可以是模拟或数字性质的。示例包括 PLC、RTU、IED、模拟控制器等。

**工业/公用事业风险评估**  
: 面向工业和公用事业流程的风险评估，包含许多与企业网络中使用的不同的风险分析工具。特别是，面向 OT 环境的风险评估必须包含过程危害分析 (PHA)。

**基础设施安全**  
: 应用于为企业、组织或社会运营所需的基本物理和组织结构提供安全保障的物理安全举措。

**入口权限**  
: 个人进入财产的权利。

**内部周界**  
: 通常涉及墙壁、门和窗户等物理屏障的周界——根据外部周界的背景，这些屏障可以是外部的，也可以是内部的。

**输入设备**  
: 用于将信息引入电子设备的设备。

**输入传感器**  
: 收集关于待控制系统信息的设备。

**输入/输出控制器**  
: 将输入和输出连接到中央控制设备（如微处理器或 CPU）的设备或系统。智能电表中负责在电表的其他系统组件与外部世界之间提供物理连接兼容性的部分。

**内部威胁**  
: 存在于网络内部的威胁类型，有时表现为员工。

**无形财产安全**  
: 保护非物理性质财产（如电子数据、专利和商标）的过程。

**积分控制**  
: 一种控制策略，应用基于微积分的算法于测量变量/设定点差值，以重置控制器的比例动作。

**智能电子设备**  
: 提供直接接口以监控和控制过程中的不同传感器和执行器，并能直接与监控控制器、本地 RTU 或其他 IED 通信的设备。

**智能传感器**  
: 将传感装置与 A/D 电路和嵌入式微处理器封装在一起，以便能直接与控制器、主控制器或其他类型的控制系统通信的传感器。

**控制中心间通信协议**  
: 全球公用事业用于 SCADA 主服务器之间、公用事业控制中心之间以及跨广域网的公用事业之间进行实时数据通信的协议。

**内部安全**  
: 基础设施安全的最内层；涉及监控内部周界内的区域。

**互联网号码分配局**  
: 负责监督 IP 地址分配和 DNS 根区域管理的组织。
