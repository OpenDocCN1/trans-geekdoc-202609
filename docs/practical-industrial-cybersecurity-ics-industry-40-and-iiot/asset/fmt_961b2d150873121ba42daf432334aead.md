
# 网络安全监控工具

*   **NetFlow** — 一种由 Cisco 开发的网络协议，用于收集 IP 流量信息并监控网络流量。当与 NetFlow 管理应用程序配合使用时，它可以将粒度数据转换为用户友好的图表和报告，以识别网络利用率。（参见 `www.solarwinds.com/netflow-traffic-analyzer`。）

*   **Pcap** — 一种 API 数据包捕获实用程序，旨在捕获网络流量。它通常用于异常分析，包括 ARP 欺骗、源自 ICS 的异常 DNS 流量，或识别格式错误的 Modbus 数据包。Pcap 实用程序可通过互联网上的许多渠道获得，并已集成到许多为特定用途设计的其他安全工具中。

*   **Zeek IDS**（前身为 Bro IDS）— 一种开源网络安全监控 IDS 工具。它提供全面的网络流量分析。它以日志的形式提供事务数据和提取的内容数据，汇总网络中移动的协议和文件。在 OT 网络中，它可以解析 DNP3 和 Modbus 协议。（参见 `www.zeek.org`。）

*   **Snort IDS** — 一种开源入侵防御系统（IPS），采用基于规则的方法来定义可接受/恶意的网络活动。它利用这些规则集来定位和识别不遵守规则的数据包，并为用户生成警报以供审查。它也可以配置为阻止这些数据包。Snort 还支持 DNP3 和 Modbus 预处理器，以及特定的 SCADA 包。（参见 `www.snort.org`。）

*   **Suricata IDS** — 一种开源威胁检测引擎。Suricata 将 IDS、IPS、NSM 和 Pcap 处理功能结合到一个产品中，旨在识别、阻止和评估网络攻击。Suricata 提供 DNP3 解析器和 ET SCADA 规则。（参见 `https://suricata.io`。）

*   **Syslog** — 一种行业标准的消息记录实用程序，它在知名或注册端口上监听网络，接收指示日志消息的协议请求，并将它们存储在 Syslog 服务器中。该工具通常用于系统管理和安全审计目的。它也广泛用于各种设备，包括网络、服务器和终端设备。（参见 `www.kiwisyslog.com`。）

## 安全监控

在关键 OT 环境中，组织可能需要实施一个或多个文档化的流程，以满足*安全事件监控*的特定要求。遵守这些要求涉及记录安全事件，并为组织确定需要警报的事件生成警报。

这些安全事件监控流程可能包括要求定期按给定间隔（例如，间隔不超过 15 个日历天）审查记录的安全事件样本或摘要，以识别网络安全事件。它们还可能包括要求保留安全事件日志一段规定的时间（例如至少连续 90 个日历天）。

在实施层面，安全监控涉及使用设备和工具来监控和报告网络或设备安全问题。在其最新的 SP800-137《联邦信息系统和组织的信息安全持续监控 (ISCM)》文档中，NIST 组织将持续安全监控定义为包括以下内容：

*   漏洞监控
*   应用监控
*   威胁监控

这些监控活动共同为 OT 安全管理员提供了对其系统、用户和活动的态势感知，以及针对其网络进行的可能攻击。通常有两类与这些活动相关的工具：

*   **主动工具** — 这些工具（如 IDS 和 SIEM）了解网络设备及其安全状态。这些工具帮助 ICS 安全管理员监控系统的多种不同类型问题，例如配置错误的设备、不正确的软件版本、设备固件缺陷、硬件故障、意外的内部和外部 IP 地址以及网络上的意外协议。然后，他们可以利用生成的信息来纠正设备配置，与供应商合作修复软件和固件问题，并加固其网络。

*   **检测工具** — 这些工具提供上下文感知的威胁监控、分析和警报功能。这些是持续的 NSM 工具，它们从网络设备和应用程序收集日志数据，分析网络流量，并向管理员提供威胁和高级问题的实时报告。OT 安全管理员可以使用这些工具来应对高级问题，例如零日恶意软件、命令与控制流量以及数据渗漏活动。

## 日志记录与审计

所有监控活动的工作产出都是针对特定事件或活动发生而产生的信息。为了使这些数据有用，必须保留它们直到可以被分析——无论是手动还是自动。网络管理员配置监控/审计工具以记录特定的网络活动或*事件*，然后在*审计日志*中跟踪其结果以供评估。*日志记录*是为了分析（审计）目的而记录和存储特定事件和事务的过程。如今几乎所有在用的计算和网络设备都以某种格式生成日志。

尽管审计日志通常提供多条信息，但组织主要使用审计日志来评估其网络的漏洞。因此，审计日志是每个管理员工作的重要组成部分，也是整体网络安全计划的关键。例行日志审计对于识别安全事件、策略违规、欺诈活动和操作问题至关重要。它也是事件发生后进行取证分析的关键。审计跟踪可能提供攻击者和入侵者的证据，无论他们来自本地网络内部还是网络外部。

在某些情况下，审计操作仅涉及筛选日志以查找错误或其他问题，这对网络管理员来说可能是一项艰巨的任务。然而，在企业和 OT 网络环境中审计日志的一个根本问题是网络内产生的海量日志数据。这往往导致日志仅以兼职或不规则的方式进行监控。

组织必须在有限的审计资源与持续产生的日志数据供应之间取得平衡。能够汇总甚至绘制该日志数据图表的软件工具是管理员极佳的生产力工具。

为了缓解监控和审计操作给网络安全团队带来的压力，许多*安全编排、自动化和响应 (SOAR)* 工具已进入 IT/OT 安全市场。这些是使组织能够自动化和标准化其安全运营和事件响应活动的软件工具。

这些安全工具收集安全数据，以识别、分析和应对来自不同攻击向量的威胁和漏洞。它们被设计为与网络中的其他安全工具协同工作，以检索和分析网络生成的安全信息。信息安全团队将称为*剧本* 的工作流指令集构建到 SOAR 中，以自动化其许多安全运营，从而减少重复性任务。

这类安全工具依赖人工智能和机器学习来自动化和微调组织的日常安全任务。可用的领先 SOAR 工具示例包括 Splunk Phantom、IBM Resilient、DFLabs IncMan、Insightconnect、RespondX、Exabeam、ServiceNow 和 SIRP。
