

# 术语表

## O

**open systems interconnection (OSI) model**

: 用于定义和描述网络环境中通信功能的主要网络模型。

**Open Vulnerability and Assessment Language (OVAL)**

: 一种安全社区标准，用于传达配置、漏洞、补丁级别等安全信息。OVAL 本质上是一组 XML 模式，描述了一种语言，提供评估网络资源安全漏洞所需的详细信息。

**open/close conditions**

: 报警传感器的状态或条件，指示“打开”为关闭状态，“关闭”为触发状态。

**OpenVAS**

: 开放漏洞评估系统，一个由多种服务和工具组成的开源框架，提供漏洞扫描和管理功能。

**outer perimeter**

: 给定区域或边界的第一道防线，可以是物理或逻辑性质的。

**out-of-band**

: 虚拟化设备安装在网络和存储系统之间的实际数据路径之外。一种发生在特定电信频带之外的通信方法。发送多信道消息或信令的另一种方式。

**overlay networks**

: 在另一个物理或底层网络之上构建网络的情况。

**owner**

: 资产的合法拥有者。

**owning group**

: Linux 权限术语，指共同拥有数据访问权限的一组用户。

**owning user**

: Linux 权限术语，指拥有数据控制权和访问权的个人。

## P

**packet analyzer**

: 用于分析网络流量的计算机程序。也称为数据包嗅探器。

**packet filtering**

: 基于源/目的地址、逻辑端口或协议，对网络数据包进行通过或阻止的过程。

**packet filtering firewall**

: 配置了数据包过滤规则的防火墙，根据源地址、目的地址或端口号等因素允许或拒绝客户端访问。

**packet sniffing attacks**

: 一种网络攻击，攻击者使用数据包嗅探器监听网络流量，寻找以明文模式跨网络发送的密码、用户名等项目，或信用卡等敏感财务信息。

**pairing process**

: 将两个蓝牙设备连接在一起的过程。

**panning**

: 使摄像头左右平移、上下倾斜或俯仰的过程。

**passive controls**

: 到位但不根据任何操作进行调整的控制措施。

**passive infrared (PIR) detector**

: 使用传感器外壳中的透镜机制，检测传感器覆盖的水平扇区内红外能量任何变化的探测器。这种探测器对静止物体不敏感，但会对视野内横向发生的快速变化做出反应。

**passive RFID tags**

: 由 RFID 读取器发射的电磁能量供电并允许进行认证的标签。

**passphrase**

: 用于控制访问的一系列文字，很像密码，但通常字符长度更长。

**password**

: 用作认证工具的秘密单词或随机字符串。

**password attacks**

: 任何在最初不知道正确密码的情况下，通过密码提示成功认证的密码尝试。

**Password Authentication Protocol (PAP)**

: 一种与 PPP 配合使用的认证协议，利用密码进行验证。

**password capturing**

: 一种在密码传输认证时查看并保存（捕获）密码的技术。

**password cracking**

: 为日后使用而尝试从存储的数据或传输中的数据恢复密码的过程。

**password encryption**

: 获取标准密码并对其应用算法，使其对嗅探器、破解者或其他窃听者变得无意义的过程。

**password management policy**

: 为管理网络环境中用户密码而制定的策略。

**password manager**

: 存储和组织用户密码的软件应用程序。

**password-authenticated key agreement (PAKE)**

: 一种交互式方法，允许两个或多个实体基于一方对密码的知识建立加密密钥。

**patches**

: 已发布分发的操作系统或应用程序的通用改进。许多补丁和更新纯粹是外观改进和便捷的附加功能，而其他则是针对特定病毒、发现的威胁或弱点而设计的关键安全升级。

**PathPing**

: 许多 Windows 系统中自带的一个实用程序，结合了 `ping` 和 `traceroute` 命令行工具。

**penetration test**

: 以发现安全弱点为目标对网络进行测试的过程。

**permissions**

: 对特定数据和资产的定义特权和授权。

**persistent cookie**

: 将保留在计算机硬盘上直到达到指定过期日期的 Cookie。也称为永久 Cookie。

**personal area network (PAN)**

: 一种结合 PDA、手机、数码相机、PC、笔记本电脑和打印机等个人设备的网络类型。

**pharming**

: 一种恶意活动，将不知情的用户重定向到伪造网站，以期获取个人信息。

**phishing**

: 一种社会工程学技术，通过伪装成可信组织来获取敏感信息（通常是登录凭证或信用卡数据）。这些攻击通常涉及引导用户访问看起来合法的虚假网站的电子邮件。

**photoelectric sensor**

: 一种检测可见或不可见光束并对接收光强度变化做出反应的光学控制装置。光电束装置利用此功能，将窄光束瞄准感兴趣区域（如停车场闸口）。当光束被中断时，光电装置会发出警报，或者在车库门安全系统的情况下，停止或反转自动车库门的升降电机。

**physical intrusion detection system**

: 旨在检测并发出入侵信号的任何系统，包括运动传感器、读卡器、摄像头和警报器。

**physical security**

: 关注保护物理边界和财产的任何过程或设备。

**piconet**

: 由最多八个设备组成的小型蓝牙网络。

**PII**

: 个人身份信息 (PII) 是任何能够识别个人身份的信息。PII 示例包括名和姓、家庭住址、社会安全号码、出生日期、指纹以及其他可将一个个体与另一个个体区分开的信息。

**piggybacking**

: 社会工程师要求目标“帮忙开门/刷卡”，从而在无需提供凭证的情况下进入受限区域的行为。

**ping**

: 用于评估能否到达另一个 IP 主机的网络实用程序。`ping` 实用程序将向目标主机发送互联网控制消息协议 (ICMP) 请求数据包并等待响应，测量往返时间和任何数据包丢失。

**ping flood attack**

: 一种简单的 DoS 攻击，攻击者用 ICMP 回显请求（ping）数据包淹没受害者。

**pinhole lens**

: 一个非常小的孔，可能由针制成，将光线强制成平行线以形成清晰图像的透镜。
