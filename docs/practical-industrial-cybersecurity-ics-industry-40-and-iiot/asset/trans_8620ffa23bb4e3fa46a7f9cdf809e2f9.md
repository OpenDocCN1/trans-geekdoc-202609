
# 物理安全控制与认证系统

## 安全策略与访问控制

一个将三个安全层级整合在一起的关键组件是设计良好且文档完善的`security policy`（安全策略），它规定了如何在每个层级实施安全。企业和组织制定全面的安全策略，定义谁被授权访问不同的资产，以及他们在访问这些资产时被允许做什么。

例如，允许员工和访客自由进入组织内的所有部门会带来各种安全风险。您需要维护访问控制，以创建一个减少人类贪婪本性诱惑的环境。如果每个人都可以在组织内部自由移动，就很难实施保护措施来防止他们访问或拿走物理或网络资产。

您还需要维护访问控制以防止意外事故。例如，您不希望销售代表不小心将咖啡洒在工程部门的生产服务器上。相反，应在每个层级制定一个连贯的`access control policy`（访问控制策略），为授权人员提供对选定资产的适当访问级别，同时阻止未授权人员访问资产。然后，根据需要使用正确类型和数量的访问控制设备（传感器、屏障、日志、ID 徽章或保安^(\*)）来强制执行这些策略。

通常，徽章或智能卡用于控制访问。当员工移动到 RFID 传感器的近程范围内时，也可以通过 RFID 应答器识别。应答器存储访问代码并使用无线电接收器和发射器。

这些访问控制技术、系统和设备将在本章剩余部分中详细讨论。

## 物理安全控制

强制执行访问控制措施最初可能包括在通往办公室的门上安装锁，并使用类似的`physical barriers`（物理屏障）隔离部门或网络区域。许多公司的前门或入口处设有接待员以控制访问，如[图 6.2](#c06.xhtml#c06-fig-0002)所示。在营业时间内，`receptionist`（接待员）充当物理屏障，询问客户来访的性质。

在某些机构中，访客可能需要由`escort`（陪同人员）陪同，以物理方式限制其在公司内的活动范围。为了增加访问控制，可以雇佣人工守卫来控制对特定受限内部区域（如实验室）或通往受限区域（如地下室）的电梯井的访问。

屏障可用于通过访问控制提供安全性。夜间，物理屏障可能只是一扇锁着的门。门也可能配备传感器和警报器。警报器可以是本地报警器（如警笛），也可以直接连接到外部监控系统或警察部门。

大多数安全边界的主要物理屏障是`lockable door`（可上锁的门）或`gate`（闸门），如[图 6.3](#c06.xhtml#c06-fig-0003)所示。门提供物理屏障，但它本身只能挡住诚实的人。另一方面，锁通过其钥匙提供屏障的认证功能。持有`key`（钥匙）意味着该人拥有或知道获得通过门访问所需的信息。

安全屏障有多种不同类型的锁。同样，也有多种不同类型的钥匙用于解除锁定机制。根据所使用的锁的类型，钥匙可以是物理的，也可以是逻辑的。

在大多数组织中，只有在特定办公室工作的选定人员才可能持有钥匙以进入其工作环境。保持严格的钥匙控制，并使用明确编码为不可复制的编号钥匙，有助于将锁门作为有效的物理屏障加以维护。

## 认证系统

`Authentication`（认证）是确定某人是其声称身份的过程。回顾一下，有效的访问控制涉及基于`authorization`（授权）控制对资产的入口、出口和回归。特别是，限制未授权人员访问重要资产是您可以采取的最基本安全步骤。因此，授权基于认证。认证涉及多个因素：

*   `Knowledge`（知识因素）：只有指定人员应该知道的东西（您知道的东西）
*   `Possession`（持有因素）：只有指定人员应该拥有的东西（您拥有的东西）
*   `Inherence`（固有因素）：只有指定人员才是的东西（您本身的东西）
*   `Location`（位置因素）：只有指定人员所在的地方（您所在的地方）

许多物理认证系统基于依赖持有因素的`single authentication factors`（单因素认证），例如持有可开锁的钥匙设备。钥匙可以是物理钥匙或虚拟钥匙，视需要而定，用于开启物理或虚拟锁定机制。

更智能有效的认证方法涉及`two-factor authentication`（双因素认证），这是一个需要两个因素才能授予授权的过程。这基于知识和持有因素。高级授权和认证方法包括`multifactor authorize and authentication systems`（多因素授权和认证系统）。在这些系统中，信息必须呈现给认证设备，后者将其传递给安全控制器的认证系统。访问控制系统中常用许多不同的认证设备。主要设备类型将在本章后续章节中介绍。

### 安全与识别工具

一个利用各种负担得起技术的安全产品新兴行业正在形成。这些技术使每位员工都能拥有某种物理设备，以提供其身份的数字保证。这些物理工具为认证提供`hard token`（硬件令牌），代表双因素认证中的“您拥有的东西”方面。

[图 6.4](#c06.xhtml#c06-fig-0004)展示了这些常见的认证设备：

*   Key fobs（钥匙扣）或其他专用无线设备
*   RFID badges and tags（RFID 徽章和标签）
*   Smart cards and magnetic swipe cards（智能卡和磁条刷卡）
*   Mobile device applications（移动设备应用程序，如手机应用等）
*   Biometric security devices（生物识别安全设备）

![FIGURE 6.4 Common security tools](images/c06f004.png)

[**图 6.4**](#c06.xhtml#R_c06-fig-0004) 常见安全工具

使用`near field communication`（`NFC`，近场通信）的`Key fobs`（钥匙扣）——一种短距离无线连接标准，可用于在设备靠近时启动设备间通信——正成为一种流行的急救医疗识别解决方案。在`initiator`（发起设备）和`target`（目标设备）之间启动通信后，可能会使用另一种无线技术（如蓝牙或 Wi-Fi）接管并执行数据交换。虽然这些设备显示出巨大潜力，但在此类医疗 ID 设备的标准理顺之前，它们的用途将继续受限。

钥匙扣的主要优势在于它可以附着在用户随身携带的物品上——至少大多数时间是这样。组织可以利用这项技术提供一个认证因素，同时将用户限制在给定的邻近范围内。例如，只要在钥匙扣的有效范围内，获得系统访问权限的员工可能只需将钥匙扣放在口袋里，并在访问面板上输入密码即可进行认证，如[图 6.5](#c06.xhtml#c06-fig-0005)所示。
