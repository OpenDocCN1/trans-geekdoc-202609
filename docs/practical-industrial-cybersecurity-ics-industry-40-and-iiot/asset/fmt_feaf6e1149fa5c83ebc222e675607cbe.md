
## 视频监控系统设计考量

### 显示清晰度要求
*   **需要何种级别的显示清晰度？** 标准视频显示是否满足当前视图需求，还是需要更高清晰度？标准清晰度系统最大的缺陷在于其无法提供足以让执法部门和法院在犯罪发生后确凿识别犯罪嫌疑人的信号。

### 信号处理与传输方式选择
*   **哪种信号处理和传输方式最适合该安装环境？** 如前所述，选项包括模拟、数字和 IP 摄像头。IP 摄像头因其电子化捕获和传输数据的能力，正逐渐超越其他类型摄像头而被广泛接受。

IP 摄像头提供的连接选项比传统模拟和数字摄像头更健壮。它们可直接与主机配合工作，无需额外硬件。此外，它们与无线网络选项的兼容性也优于其他摄像头技术。

### 视频存储需求规划
出于安全目的录制视频时，另外两个重要考量是：**需要存储多少视频？** 以及 **需要存储多长时间？** 这些问题的答案决定了组织的 *存储容量* 需求。

安全视频本质上需要大量的 *存储空间*。因此，存储成本与组织面临的风险之间始终存在权衡。单个视频监控摄像头一天就可能消耗数 GB 的存储容量。考虑到这一点，组织需要存储监控视频的时长成为一个关键决策点。根据组织性质及面临的风险类型，存储需求可能要求为每个安装的摄像头存储数周甚至数月的视频。

如前所述，大多数组织不会仅部署单个摄像头用于监控；他们可能部署数十甚至数百个摄像头。存储来自如此多摄像头的视频数据，轻松便可能需要数百 TB 的数据存储。

满足此类需求常采用以下三种常见视频存储类型：

*   **内部存储**：将视频信息存储在 DVR 的内部磁盘驱动器（或驱动器阵列）中。此方案仅适用于摄像头数量少、仅短期存储视频信息的小型组织。

*   **外围存储或直接附加存储（DAS）**：该技术采用通过 USB 或 eSATA 连接直接附加到 DVR 的额外磁盘驱动器存储设备，如 [图 6.29](#c06.xhtml#c06-fig-1029) 所示。直接附加存储不涉及使用 IP 地址将视频卸载到外部设备。

    ![图 6.29 DAS 视频存储](images/c06f029.png)

    **图 6.29** DAS 视频存储

*   **网络存储**：利用网络技术将基于 IP 的视频存储在远程计算机或视频服务器上。最常用的技术包括网络附加存储（NAS）和存储区域网络（SAN）技术，如 [图 6.30](#c06.xhtml#c06-fig-0029) 所示。

## ICS 物理安全

工业或公用事业环境中的第一道防线必须建立在物理层面。与所有其他网络环境一样，*物理安全* 涉及采取措施防止盗窃、防止物理损坏、维护系统完整性和服务、以及限制未经授权的信息泄露。

在工业和公用事业环境中，物理安全设备和措施的部署通常受多种因素制约，包括环境、安全、法规、法律及其他超出组织控制范围的要求。必须识别这些因素并将其纳入组织的整体安全计划。在许多情况下，该计划与组织的整体 *工厂安全计划* 紧密集成。

除了防范攻击者对设备的物理接触外，每项资产的运行环境必须与其设计规范相兼容。这包括提供合理的保护，防止丢失、火灾、盗窃、非故意泄露或环境损害。

除了在正常运行期间保护这些资产外，在资产运输和/或维护期间提供物理安全控制也至关重要。这涉及为所有 OT/IT 网络资产的运输、处理、存储、执行维护程序、以及退役/销毁工作制定并实施具体的政策和流程。

### 工业流程/发电设施

工业环境物理安全计划的主要目标之一，是在让人员远离危险环境的同时，仍使其能够胜任工作。当然，必须建立物理访问控制，以强制限制对生产流程物理组件和 OT 系统的访问。在 OT 环境中，这些措施用于防止多种不良活动，包括：

*   窃取、损坏、破坏、修改或操纵 OT 设备或系统，包括通信介质和接口
*   对关键或敏感资产进行视觉或摄影观察，包括不得拍照或通过其他方式创建流程图像
*   为硬件操纵、追踪、通信嗅探或窃听等目的，将未经授权的系统或设备引入 OT 系统

除了为 ICS 设备提供物理隔离外，还必须通过色码标记和标签清晰地标识这些设备为 ICS 设备。

传感器和执行器需要的保护程度与过程控制器和网络设备同等重要。如果输入设备在未被察觉的情况下被物理接触，则可能被操纵以伪造过程系统数据。后果可能导致对过程的完全失控，或在一段时间内微妙地产生有害影响。

### 控制中心/公司办公室

在控制中心或企业办公设施中，物理安全通常呈现出更多的企业安全特性。这些环境中的主要关注点在于限制对环境中任何信息资产的物理访问。

*   未经授权物理访问敏感区域，如服务器机房和安保办公室
*   未经授权物理访问服务器、SCADA 主站和历史服务器及其上的数据
*   未经授权物理访问用户计算机、交换机和路由器

与 IT 网络环境类似，OT 主站、服务器和历史服务器应位于上锁区域，用于这些位置身份认证的设备和机制也应受到保护。同样，OT 网络上的任何网络连接设备（网络交换机、路由器和介质）应位于安全区域，最好是仅授权人员可访问的区域。

#### 物理服务器访问控制

从最基本的层面来看，网络管理员必须掌控其物理服务器环境，以提供全面的安全设置。这通过严格限制对 *服务器* 的物理访问来实现。最常见的做法是将它们放置在受保护的 *服务器机房* 中，这些机房的门和计算机机箱均配有自动锁。
