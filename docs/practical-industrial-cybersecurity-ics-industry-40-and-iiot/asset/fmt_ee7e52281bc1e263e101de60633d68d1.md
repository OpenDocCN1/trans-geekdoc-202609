
这些单元通过一个称为**本地控制回路**的独立局域网（LAN）与控制器互连。[图 1.15](#c01.xhtml#c01-fig-0015) 描绘了一个带有本地控制网络回路的典型 ICS。这种类型的网络回路通常以基于 TCP/IP 的以太网网段形式实现。在 ICS 环境中，通常将此网段称为**运营技术（OT）网络**，以将其与组织的 IT 网络区分开来。

根据 ICS 的复杂程度，网络可能被划分为多个控制段或回路，如[图 1.16](#c01.xhtml#c01-fig-0016)所示。在此示例中，完整的网络结构由四个不同的网段和类型组成，如下所示：

*   **现场总线回路**：该回路提供本地现场设备与传感器及执行器之间的直接交互。现场总线常用于将 PLC 连接到各种输入传感器和输出执行器。它还可以连接到一个单独的人机界面控制台，用于显示工艺活动及其各种传感器的状态。
*   **本地控制/监控回路**：该回路提供本地现场设备与分布式控制系统组件（数据历史服务器、工程师站、HMI 和监控计算机）之间的直接交互。
*   **组织的局域网**：该回路提供组织 IT 网络与其 ICS 网络之间的连接。此连接代表组织 ICS 之外的一条路径，使网络面临组织内部非 ICS 人员可能的操纵风险。
*   **组织的 IT 网络**：该回路提供组织本地 IT 网络与其广域网连接之间的连接。它还在 ICS 与组织外部人员可能的操纵世界之间提供了一条路径。

网关设备用于在不同网络类型之间进行转换，例如特定的现场总线类型与基于 TCP/IP 的以太网网络。例如，前一个示例中将现场总线和本地控制 LAN 连接在一起的连接，必须在每个网段所基于的物理和逻辑协议之间进行转换。

### 以太网 I/O 模块

ICS 网络的现场总线和本地控制网络部分历史上一直通过异步串行网络拓扑实现，例如标准 RS-232 和 RS-485 串行总线连接。然而，工业控制领域已逐渐接受采用**以太网/IP 802.x 标准套件**进行控制和数据通信。这在工业控制环境中变得越来越流行。

自 1990 年代以来，以太网一直是 IT 网络的连接标准。它采用物理星型拓扑（集线器和辐射条），尽管实际运行为逻辑总线拓扑。完整的以太网标准套件可在多种不同介质类型上运行，包括双绞铜缆、光纤和无线 Wi-Fi 信道。

[图 1.17](#c01.xhtml#c01-fig-0017) 显示了标准硬连线以太网连接的物理连接。此连接使用双绞铜数据电缆，终端为 8P8C 模块化插头和插座（有时错误地称为 RJ-45）。在工业环境中，这些连接按照 TIA/EIA-568-BC 标准布线。

![图 1.17 以太网连接](images/c01f017.png)

**[图 1.17](#c01.xhtml#R_c01-fig-0017) 以太网连接**

采用以太网/IP 技术及相关技术促使组织企业网络与其工业控制网络对应部分融合。随着网络的两个部分集成为一个统一的数据通信载体，组织能够将实时生产数据应用于业务决策。

用于将 PLC 连接到以太网的模块历史上一直是独立的网络接口适配器，涉及 PLC 与以太网适配器之间的 RS-485 连接以及与网络其余部分的以太网连接。然而，较新的 PLC 型号包含内置以太网接口。[图 1.18](#c01.xhtml#c01-fig-0018) 说明了这两种方法的区别。

### 监控与数据采集系统

在某些过程中（如输油管道控制操作），工艺的不同控制组件可能相隔很远。在这种情况下，本地控制器必须通过无线电、电话、卫星或广域网等长距离通信技术连接到监控控制器。

顾名思义，**监控与数据采集（SCADA）系统**是一种分布式控制系统，提供两个不同的功能：数据采集（输入）和监控功能（输出）。正如您本章前面所见，PLC、RTU 或 IED 通常提供对其监控过程的本地控制。然而，它们还会打包**采集的数据**，并通过某种工业通信链路或网络连接将其传输到监控系统。

由于工业过程实时运行，分布式控制系统中各个本地控制器的操作必须相互同步。SCADA 控制器负责提供公共时钟信号，以协调不同控制器的动作。

SCADA 系统的**监控**部分监控从其本地控制设备接收的数据，并存储信息以供处理、分析和/或响应。SCADA 系统的响应通常保留用于执行监控干预或响应工艺中的报警条件（如电机过热、传感器读数超范围或冷却系统故障）。SCADA 系统还提供 HMI 界面，使人工操作员能够监控并直接控制过程控制系统。

从物理上讲，SCADA 系统是运行在某种计算机平台上的工业软件应用。这些单元称为**SCADA 服务器**或**SCADA 主站**。SCADA 主站传统上使用行业标准 ICS 协议和现场总线与其本地控制设备通信。这种布局如[图 1.19](#c01.xhtml#c01-fig-0019)所示。

![图 1.19 将 ICS 网段添加到网络](images/c01f019.png)

**[图 1.19](#c01.xhtml#R_c01-fig-0019) 将 ICS 网段添加到网络**

SCADA 服务器也能在组织的企业网络中运行。这是通过在标准 IT 网络基础设施上运行标准 IT 网络协议来实现的。

该软件应用的一部分是一个数据库管理系统，它以称为**标签**的控制点形式存储历史数据。标签基本由两个元素组成：一个数据点和一个时间戳。有了这两条信息，SCADA 系统可以生成用于图形显示或审计目的的跟踪和趋势数据。此数据库称为**历史服务器**。
