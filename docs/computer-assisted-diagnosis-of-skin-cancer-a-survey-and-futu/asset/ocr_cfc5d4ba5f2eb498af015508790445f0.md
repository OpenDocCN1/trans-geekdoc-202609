# Table 5
Summary of CNN architectures with advantages and disadvantages.

| Techniques | Contributors | Description | Pros | Cons |
| :--- | :--- | :--- | :--- | :--- |
| LeNet-5 | LeCun et al./1998 | It includes 60,000 parameters with 3 fully connected layers and two convolution layers. | Simple to Understand It works for Character recognition images | Difficult to generalize Slow learning Lack of depth |
| AlexNet | Krizhevsky et al./2012 | It has 8 layers: 3 fully connected and 5 convolutional with 60M parameters | Implement ReLUs as activation functions. Use of GPU for complex problems | Require more time for better result Higher filter size generates artifacts from the feature map |
| VGG Net | Simonyan et al./2014 | It features three fully connected and 13 convolutional layers and, with ReLu activation function. It contains 138M parameters. | Improvement in accuracy and speed Increase the number of layers to achieve better results | The problem of vanishing gradient Slower than ResNet |
| GoogLeNet | Szegedy et al./2014 | It has 22 convolutional layers i.e., a variant of Inception, and was developed by Google's researcher. It has5M parameters. | Faster than VGG Improve convergence rate | Difficult parameters customization |
| ResNet | He et al./2016 | It has 152 deep CNN layers which are 20 times faster than AlexNet and 8 times faster than VGG. | Reduce computational time Improve accuracy | Information on feature map degrade Complexity increases |
| ResNeXt | Xie et al./2017 | This is the upgradation of Inception Network by introducing carnality i.e., the size of the set of transformations. | Improve accuracy Cardinality improves performance Better generalization Excellent accuracy | Complexity High computational cost |
| Deep reinforcement learning | François-Lavet et al./2017 | It's a mixture of reinforcement and deep learning that uses fewer computer data and resources | Faster computation High performance | Efficiency Training stability |
| DenseNet | Huang et al./2017 | It is a feed-forward network in which each layer is directly linked to the layers within each dense block | Overcome the problem of vanishing gradient Reduce redundant feature map | Decrease parameter efficiency decrease computational efficiency |
| Xception | Chollet et al./2017 | It employs the notion of the depth-wise separable method of convolution. | Improve computational efficiency Improves upon the Inception V3 | High computational cost |
| SENet | Hu et al./2018 | It is being used to increase CNN's quality. | Simple to implement Better performance | Costly Increase complexity |
| RAN | Wang et al./2017 | RAN is a feedforward CNN that was developed by stacking layers and employing the attention component. | Overcome the problem of vanishing gradient | Increase complexity |
| INet | Wen et al./2021 | INet, which instead of downsampling expands receptive fields by gradually growing the size of the kernel in the convolution layer | Improves optimization. Suitable for biomedical image segmentation. | High computational cost Not suitable to maintain a high-resolution feature map |
| MultiResUNet | Ibtehaz et al./2020 | MultiResUNet is used to detect tissue from biomedical images. | Improve accuracy Improve the computation efficiency | Complexity Increases |
