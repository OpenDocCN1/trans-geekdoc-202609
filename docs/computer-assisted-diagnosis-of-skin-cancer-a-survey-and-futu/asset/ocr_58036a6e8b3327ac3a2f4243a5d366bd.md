# 5.1. Performance evaluation metrics

To analyze or compare the performance of different segmentation and classification systems, one should know a few terms, like Sensitivity (SEN), Specificity (SPE), Dice Coefficient (Dice), and Accuracy (ACC). These measures were used to assess the various models discussed in this article. They are outlined below:

+   True Positive (TP): The number of lesions classified as malignant that have been shown to be malignant.
+   True Negative (TN): The number of lesions classified as benign that have been shown to be benign.
+   False Positive (FP): The number of lesions classified as malignant that have been shown to be benign.
+   False Negative (FN): The number of lesions classified as benign that have been shown to be malignant

+   • Sensitivity (SEN): Sensitivity is defined as the ability to correctly recognize a skin lesion and it is the proportion of predicted positive results among individuals who have positive outcomes. It is computed as:
+   
+   $$Sensitivity = \frac{TP}{TP + FN}$$ (5)

+   
+   $$Specificity = \frac{TN}{TN + FP}$$ (6)
