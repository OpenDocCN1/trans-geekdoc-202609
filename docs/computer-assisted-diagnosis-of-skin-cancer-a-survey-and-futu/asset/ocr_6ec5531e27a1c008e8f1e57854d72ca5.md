+   ● **FCN:** With the use of a convoluted neural network, an FCN (completely convolutional network) converts visual pixels to pixel classes. FCN is a layered structure composed of convolution layers and pooling layers. To segment skin lesions, a multi-stage FCN technique based on parallel integration (PI) was employed to segment the lesions. This technique was utilized to improve the margins of the segmented skin lesion after they had been segmented. When evaluated on the ISBI 2016 dataset, the approach obtains a segmentation accuracy of 94.70% and a dice coefficient score of 92.03% for melanoma, an accuracy of 95.71%, and a dice coefficient score of 90.97% for nonmelanoma. DFRCN, which is a modified FCN for the segmentation of dermoscopy images that gives improved performance, is a type of FCN that was developed specifically for dermoscopy image segmentation. To train and segment skin lesions, convolutions were combined with an FCN network. This improves the visibility of the network’s receptive field. FCN models, on the other hand, tend to segment, which might result in coarse segmentation output with the dataset.

+   ● **CDCNN:** There are two parts to this model: the convolutional network path, which is similar to a CNN, it retrieves a hierarchy of the features of an image that range in complexity from 0 to 1. The second part is the deconvolutional network path, which runs in the opposite direction, and is called a deconvolution network. It changes the aggregated features and renovates the segmentation map resolution from 0 to 1. Both networks are used to extract distinguishing characteristics. The deconvolution layers are used to smooth the segmentation maps before producing the final output [4]. Dermoscopic skin lesion image segmentation can be done by using a network called RefineNet. This network has a lot of paths and a lot of dense convolutional layers. A CDCNN-based systems take more time to run. They still can not be very precise and limited when there is not enough training data. These methods have made it easier to segment and analyze skin lesions.
