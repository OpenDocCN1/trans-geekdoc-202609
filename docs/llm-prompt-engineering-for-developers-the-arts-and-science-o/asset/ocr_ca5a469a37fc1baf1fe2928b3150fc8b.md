# 22.7 - promptfoo

[promptfoo](https://github.com/promptfoo/promptfoo) is a robust tool crafted to optimize the testing and evaluation of Large Language Models. It promotes a test-driven approach for prompt engineering, replacing the conventional trial-and-error method.
Users benefit from features like systematic testing, side-by-side evaluation of LLM outputs, rapid evaluations through caching and concurrency, automatic scoring based on custom test cases, and flexibility in usage—ranging from Command Line Interface (CLI) to CI/CD pipelines. Furthermore, it boasts compatibility with numerous models and platforms, including OpenAI, Anthropic, Llama 2, Vicuna, and offers integration options for custom LLM API providers.
