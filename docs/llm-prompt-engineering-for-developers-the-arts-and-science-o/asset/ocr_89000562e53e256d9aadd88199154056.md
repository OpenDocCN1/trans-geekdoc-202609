Alternatively, you can also add the examples to a file (examples.json)

```
{
"_type": "few_shot",
"input_variables": ["word"],
"prefix": "Write a sentence using the word in the input",
"example_prompt": {
"_type": "prompt",
"input_variables": ["input", "output"],
"template": "input: {input}\\noutput: {output}"
},
"examples": "examples.json",
"suffix": "input: {word}\\noutput:"
}
```

The examples.json file looks like:

```
[
{ "input": "Clock", "output": "Why did the clock go to school? To le\\narn about tick-tock-o-logy!"},
{ "input": "Shoe", "output": "Why did the shoe go to school? To impr\\nove its sole!"},
{ "input": "Book", "output": "Why did the math book look sad? Becaus\\ne it had too many problems!"},
{ "input": "Pencil", "output": "Why did the pencil get an award? It \\
was sharp!"},
{ "input": "Beach", "output": "Why did the sand blush? Because the s\\nea-weed on the beach!"},
```
