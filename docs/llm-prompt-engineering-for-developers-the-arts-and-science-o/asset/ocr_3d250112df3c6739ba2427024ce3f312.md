# # 20 - Anatomy of a Prompt

When creating a prompt, it’s important to understand the different com-ponents that you may use in it. The following list describes the different components of a prompt:

+   - Role
- Instructions
- Input data
- Context
- Rules
- Output
- Examples

There is no official standard for creating prompts, but most prompts contain at least one of these components.
