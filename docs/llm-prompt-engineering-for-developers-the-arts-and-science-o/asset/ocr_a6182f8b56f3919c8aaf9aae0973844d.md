For example, if my prompt is “What is the capital of Argentina?” and the response is “Buenos Aires”, the total number of tokens used is 11, including spaces: 7 for the prompt and 3 for the response.

+   - **Cost per token:** The API typically has a fixed cost per token, depending on the model you are using. If you are calling “GPT-4”, the cost is $0.03 / 1K tokens, and if you are using “GPT-4-32k”, the cost is $0.06 / 1K tokens.
