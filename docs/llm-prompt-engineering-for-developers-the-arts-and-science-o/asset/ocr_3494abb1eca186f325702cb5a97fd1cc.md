# Prompt Flow connections

The same thing applies for the runtime, click on “Runtime”, start by adding a shared runtime. It is possible to create or use different types of runtimes, in this example, you can use a shared runtime. Before you consume the endpoint as runtime, you need to give the following permissions to the user-assigned identity:

+   * “AzureML Data Scientist” role to workspace
* “Storage Blob Data Contributor” permission, and “Storage Table Data Contributor” to the default storage of the workspace

Without adding these permissions, the endpoint runtime will lack the correct access to run the prompt flow. More details can be found here\(^{58}\).
