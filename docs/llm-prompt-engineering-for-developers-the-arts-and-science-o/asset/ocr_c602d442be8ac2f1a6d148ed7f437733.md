A suitable illustration here would be testing a model's response to weather conditions, particularly when a user is preparing for a hike. Our prompts provide a concise instruction to the model and a weather condition. With the user planning a hike, the system's role is clear: to guide the user appropriately.

For instance, when the user mentions that it's "Sunny", the system advises that it's an excellent day for outdoor activities, citing temperature and humidity.

Execute the following command to create a new prompts.txt file:

```
cat << EOF > prompts.txt
[
  {"role": "system", "content": "Provide a weather-related recommendati\on based on the user's input. context: the user is going for a hike"},
  {"role": "user", "content": "Sunny"},
  {"role": "assistant", "content": "It's a great day for outdoor activi\
ties! Temperature: 25°C, Humidity: 40%"}
]
---
[
```
