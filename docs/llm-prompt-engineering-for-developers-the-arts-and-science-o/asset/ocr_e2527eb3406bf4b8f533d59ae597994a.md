# 20.2 - Instructions

The instructions are the main part of the prompt and they provide the main task for the model. Instructions could be used to ask the model to perform a specific task or generate a specific type of output.

Here is an example:

Create a blog post titled "The Top 10 Movies of All Time".

Depending on the prompt type, the instructions could be explicit (e.g., a clear task) or implicit (e.g., a question or a conversation). We are going to learn more about the types of prompts in the next sections.

# 20.3 - Input Data

Input data is what we feed to the model. It could be anything from a few sentences, a list, or a long paragraph. Input data is used to provide the model with guidance on what and how to generate the output.

Let’s imagine you want to create a blog post about the top 10 movies of all time according to IMDB. You could assist the AI model by feeding it the following input:

+   1. The Shawshank Redemption
2. The Godfather
3. The Dark Knight
4. The Godfather Part II
5. 12 Angry Men
6. Schindler’s List
7. The Lord of the Rings: The Return of the King
8. Pulp Fiction
9. The Lord of the Rings: The Fellowship of the Ring
10. The Good, the Bad and the Ugly
