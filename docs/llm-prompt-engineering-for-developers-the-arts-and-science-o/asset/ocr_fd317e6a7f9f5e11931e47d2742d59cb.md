# # 14 - General Knowledge Prompting

# ## 14.1 - What Is General Knowledge Prompting?

This is one of the most useful techniques I learned through testing and experimenting with ChatGPT before using it in production. It’s a simple technique that can be used to improve the quality of the generated outputs.

In the paper [Generated Knowledge Prompting for Commonsense Reasoning⁵¹](https://arxiv.org/pdf/2110.08387.pdf) (Liu, J., Liu, A., Lu, X., Welleck, S., West, P., Bras, R. L., Choi, Y., & Hajishirzi, H. (2021)), the authors tried to determine if adding outside information aids in better understanding common sense while using trained language models. To test this, they created a method where they first generated knowledge from a model and then used that knowledge to answer questions. This method doesn’t require special training or a database. It improved performance in several tasks and showed that large language models can be flexible sources of extra information.

The method uses two main steps to do this.

+   1.  Knowledge generation: They used a language model to produce “knowledge statements” based on the given question. Think of these statements as pieces of information that can help answer the question.
2.  Knowledge integration: They then used these knowledge statements to help another language model pick the best answer from the choices. Without these statements, the model would just try to guess the answer based only on the question.
