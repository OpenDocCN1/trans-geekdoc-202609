## 12.4 - Hack the Prompt

With lower perplexity, the model performs better as the prompt is more familiar to it. But, how can we reduce the perplexity of a prompt?

What if we allow the model to generate the prompt for us? This technique could prove useful since the model is more familiar with the language it generates, as we learned in the previous section.

Suppose you want to ask the model the following question:

> **Write a blog post about aging gracefully.**

We can use the following prompt to request the model to create a prompt for us:

> **Write a list of prompts that I will use to write a blog post about aging gracefully.**

If you already have a list of prompts, you can ask the model to paraphrase them for you.
