# Using the stop parameter

When the parameter is encountered, the API returns the generated responses up to this point. This can be useful for generating shorter responses or limiting the number of answers.

# 4.13 - Chat

The chat endpoint^{17} is used for generating a conversation between two speakers. This endpoint uses two initial prompts: the "system" prompt (optional) and the "user" prompt (required).
Example of a "system" prompt:

```
You are a helpful assistant helping users with their questions about diet and nutrition. You are talking to a person who wants to build muscle and lose fat.
```

Remember that setting a role for AI is useful in helping it understand the context of the conversation.
