# ## 4.12 - Completion (Deprecated)

The completion endpoint$^{16}$ is used for generating text based on a given prompt. This is the most basic endpoint and it is used for generating text based on a single prompt.

Example of a prompt:

Once upon a time

Another example:

# Introduction

By engaging in this regular practice, you cultivate mindful attention to the present moment. Mindfulness meditation allows you to connect with yourself, calm the mental chatter, and find inner balance. ## How to Practice

Another example showing the use of the “stop” parameter:

The list of things I should not buy at the grocery store:

+   1.

If you want to have only 5 items in the list, you can use the “stop” parameter to stop the generation after the 6th item. You should set the “stop” parameter to “6.” (note the period at the end).
