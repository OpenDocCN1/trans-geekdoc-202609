# 17.1 - How and What to Evaluate in a Prompt

Assessing the effectiveness of a prompt involves evaluating how well it elicits the desired response. There are no universal metrics for prompt effectiveness, as it depends on the context and purpose of the application, the model, and the prompt itself. For instance, a prompt that’s effective at eliciting a response from a small group of participants may not be as effective with a larger group. Similarly, a prompt that’s effective at eliciting a response from a specific demographic group may not be as effective with a different group.

However, we can establish a few general guidelines for evaluating prompt effectiveness. Here are some methods to assess prompt effectiveness:
Continually modify the prompt based on feedback and results, then retest it. The prompt’s effectiveness should improve with each iteration.

An example of iterative testing for a prompt involves testing the prompt with different versions of the same purpose.

```
Version 1: Summarize the main idea of the article in 1-5 sentences.
Version 2: If this article was very short (1-5 sentences), how would you summarize its main idea?
Version 3: Create a short summary of each paragraph in the article. Connect the summaries to create a summary of the entire article. Do not exceed 5 sentences.
...
```
