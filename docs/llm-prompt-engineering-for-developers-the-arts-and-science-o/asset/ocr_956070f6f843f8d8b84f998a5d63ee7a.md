# ## 19.10 - Image Generation

Several text-to-image models have emerged in recent years, such as [DALL-E](https://openai.com/dall-e-2)^91, [Stable Diffusion](https://stablediffusionweb.com/)^92, and [Midjourney](https://www.midjourney.com/)^93. These models can create images from text prompts. Some of them require additional specific instructions to produce desired outputs.
