**Usage in model training:** When training language models, prompts are often used in combination with example responses to teach the model how to correctly respond to different inputs.

**Limitations:** It is worth noting that language models have limitations regarding the length of prompts. Models such as GPT have a maximum context length, and if a prompt is too long, it may be necessary to truncate or summarize it.

**Costs associated with API calls and prompts:** When using LLMs like GPT-4 via an API, the number of tokens in the prompt affects the cost of the API call, as providers typically charge based on the number of tokens processed.
