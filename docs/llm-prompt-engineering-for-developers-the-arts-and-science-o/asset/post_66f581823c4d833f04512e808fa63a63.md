## 16.12 - Using Prompts from a File

It is not a good idea to hard code tens or hundreds of few-shot examples in your code. While this will make your code unreadable, it will also make it difficult to maintain and update. Prompts can be stored in a file using the JSON or the YAML format. This way, you can easily add, remove, or update prompts without having to change your code. But how do you use these prompts in your code?

LangChain provides the `load_prompt` function, which loads a prompt from a file:

```python
from langchain.prompts import load_prompt
prompt = load_prompt("data.json")
formatted_prompt = prompt.format(word="happy")
```

This is the content of data.json:

```json
{
    "_type": "prompt",
    "input_variables": ["word"],
    "template": "Give me a synonym for \"{word}\"."
}
```

If the file were a YAML file, the content would be:

```yaml
_type: prompt
input_variables: [word]
template: Give me a synonym for "{word}".
```

The code above will work with both JSON and YAML files. It is also possible to use a JSON file to perform few-shot learning. This is how the data.json file would look:

```json
{
    "_type": "few_shot",
    "input_variables": ["word"],
    "prefix": "Write a sentence using the word in the input",
    "example_prompt": {
        "_type": "prompt",
        "input_variables": ["input", "output"],
        "template": "input: {input}\noutput: {output}"
    },
    "examples": [
```
