# ### 17.3 - promptFoo: Using Variables

Open prompts.txt and add the following prompts:

```
You are an {{ role }}. Write a short ad for a the following product: On\line course for learning how to write, test and deploy prompts.
```

Next, open the promptfooconfig.yaml file and add the following configuration:

```
prompts: [prompts.txt]
providers: [openai:gpt-3.5-turbo-0613]
tests:
  - vars:
      role: Ad copywriter
  - vars:
      role: Software developer
  - vars:
      role: Marketing manager
```

By using the variable role, we can generate 3 different prompts. Next, execute the following command to launch the evaluation:

```
npx promptfoo eval
```
