# ## 18.4.1 Adaptive Histogram Equalization Method

Adaptive histogram equalization (AHE) extends the old approach. It changes the intensity of picture values to increase contrast [51]. AHE improves visual contrast through computer image processing. The adaptive approach redistributes lightness levels by computing numerous histograms for each section of the image. It improves local contrast and edge definition in each image region. AHE tends to over-boost haze in homogeneous picture sections. Contrast-limited AHE restricts boosting to avoid the dehazing.

# ## 18.4.2 AHE Algorithm

Global histogram equalization will not function for photos with low-contrast bright or dark sections. Adaptive Histogram Equalization helps improve such photos. AHE contrast enhances only tiny regions based on their local cumulative distributive function. Each approach for implementing Adaptive Histogram Equalization has several versions [45]. Our suggested work implements Adaptive Histogram Equalization utilizing “tiled windows with interpolated mapping”.

The main steps performed by this function are:

+   1. Compute a grid-size using the image’s extreme measurement. The smallest grid-size is 32 pixels square.
+   2. Use the grid size for unspecified window sizes.
+   3. From the top-left corner, locate grid points. Pixels divide grid points.
+   4. Estimate the CDF of the window-sized section centered at each grid point.
+   5. Replicate steps 6–8 for every input image after computing grid point mappings.
+   6. Find the four nearest grid points around each pixel.
+   7. Use the CDFs to translate the pixel’s intensity value to the four grid points.
+   8. Interpolate these values for the current pixel mapping. Put this intensity in the output image between [min:max].
