IoT based LPG sensor have an LPG sensor which will be used in our module. we have implemented the LPG gas sensor interfacing with NodeMCU. The Signal from this sensor is sent to the microcontroller. ## 12.3.3.3 Power Consumption

In house, we use electrical appliances without considering the amount of power it consumes, only after the current bill is issued, we are concerned about the reduction in usage of the appliance [1]. Still, it is a question which electrical appliance consumes more, what can be done to reduce it and to find the reason why it was used more. So, we need to analyze certain factors through which we can finally come up with a solution. So, we designed an IOT based power consumption manager, which records, analyzes, and tells the average power we use on a daily basis.

## 12.3.3.4 Components Required

- 1. NodeMCU ESP8266
- 2. ACS712 (current sensor)
- 3. AWS account

![](img/07f0bb0f402fd4e2f1880bf37d1ea963_226_1.png)

## 12.3.4 Materials Description

### 12.3.4.1 NodeMCU ESP8266

As same in gas leakage system we use NodeMCU here. NodeMCU is a microcontroller which has a Wi-Fi module, which is the special thing about this chip. It can be programmed using Arduino IDE. Wi-Fi is nothing but a Wireless radio wave which can used to send and receive information. In this project, nodeMCU is used so that we can communicate with the user using Wi-Fi. In this project, the Wi-Fi system is used to communicate with the AWS webserver so that we can store the data in the server. The internet connection is needed to access the webserver.

### 12.3.4.1.1 AWS Account

AWS account (amazon web server) is needed to store the records and to further analyse the record.

### 12.3.4.1.2 ACS712 Sensor

The ACS712 is a fully integrated, hall effect-based linear current sensor. It is simply a current sensor that uses its conductor to calculate and measure the amount of current applied. In this project, it constantly monitors the power usage, it measures AC as well as DC so it can measure all kind of power usage by appliance.

### 12.3.4.1.3 Working of the System

The circuit diagram Figure 12.4 represents the model of the system. It contains two components such as acquiring the data and processing it. The sensor reads the power consumption and transmits the information to the AWS server through Wi-Fi network and the information is stored in the database and the data is processed with MySQL database management system.

The data processing system receives the data from the sensor attached with each electrical appliances through Wi-Fi. Further, this data is stored in the MySQL database and can respond to the requests from user. Now the system is ready to manage the power

## 12.3.5 Online Switch

In our houses we usually have a lot of appliances and have different switches for each of the appliances and it's our nature to be very careless that we may not switch off the appliances at some instance. So, we can make an online switch that can control the switches in home through our mobile phone. This helps to monitor all the appliances at home which results in power consumption.

### 12.3.5.1 Components Required

- 1. NodeMCU ESP8266
- 2. relay switch
- 3. Blynk app

### 12.3.5.2 Circuit Diagram

![](img/07f0bb0f402fd4e2f1880bf37d1ea963_230_0.png)

Figure 12.7 BLYNK online switch.

### 12.3.5.3 Materials Description

### 12.3.5.3.1 NodeMCU ESP8266

We have mentioned it a lot of times now, it is microcontroller with Wi-Fi module. So here it is used to connect with blynk server through which we can turn on and off the switches.

### 12.3.5.3.2 Relay Switch

Relay switch is used to control the main switch board using the microcontrollers. It gives connection without disturbing the main. Here we use it to connect all the electrical appliances in the house.

### 12.3.5.3.3 Blynk App

Blynk is an IoT platform that is used to control electronic devices via the Internet. It allows user to create an application through which we can on and off the appliances with blynk server.

### 12.3.5.3.4 Working of the System

The electrical appliance in the house is connected to the relay switches and the relay switch is connected to NodeMCU [7]. The blynk server is connected to NodeMCU which sends and receive the commands and status of the appliances respectively. The user can use the blynk application in android or iOS phones through which the user can get and send the status and commands respectively.

The switch can be used from anywhere as it is connected to server and the NodeMCU should be given with internet connection. Figure 12.7 gives the model.
