
## 6.3 Feature Extraction

Feature extraction is a critical method in the domains of machine learning and computer vision to locate and extract important characteristics from large data sets. The technique of extracting features from raw data so that they can be utilized to categorize or analyze the data is known as feature extraction. This method is essential to many applications, such as audio and image identification, natural language processing, and predictive modelling. Here, we'll go through the idea of feature extraction, why it’s important, and a few feature extraction strategies.

The most crucial elements in the data that can be utilised to create predictions or categorise the data are found and extracted using feature extraction in machine learning. Finding features that are most pertinent to the job at hand is a step in the feature extraction process. This can be achieved by looking at the data and finding trends or connections between various features. These features can be located and then extracted for use in additional analysis.

Many methods are frequently employed for feature extraction. Principal component analysis (PCA) is one of the most popular approaches. The most crucial features in a dataset can be found using the PCA method [14, 15]. It works by locating the set of linear features that best accounts for the variation in the data. By doing this, it is able to keep the most crucial properties while reducing the data’s dimensionality.

Linear discriminant analysis (LDA) is a different method that is frequently employed for feature extraction [15]. Finding the features that distinguish between several classes of data best is done using the LDA approach. It works by figuring out which linear feature combination maximises the distance between different data classes. This makes it possible to pinpoint the characteristics that are crucial for categorization tasks.

### 6.3.1 Principal Component Analysis

A set of correlated variables can be changed into a set of uncorrelated variables using the mathematical technique of principal component analysis (PCA) [15]. Identifying a new set of variables—referred to as principal components—that best capture the variation in the initial dataset is the main objective of PCA. These underlying components are linear combinations of the initial variables that were chosen to account for the majority of the data fluctuation.

### 6.3.1.1 Procedure

The following are the steps necessary to put PCA into practice.

### Step 1: Data Preprocessing

Preprocessing the data is the first step in putting PCA into practice. To prepare the data for analysis, this entails cleaning and standardizing it. Outliers, missing values, and anomalies must all be eliminated from the data because they can significantly affect PCA’s findings. The data should also be normalized to ensure that each feature has a unit variance and zero mean. By doing this, it is certain that the analysis will give each feature equal weight.

### Step 2: Covariance Matrix Calculation

The covariance matrix for the data is calculated next in the PCA process. The relationship between each pair of features in the dataset is depicted by the covariance matrix, which is a square matrix. The diagonal members of the covariance matrix reflect each feature's variance, while the off-diagonal elements indicate the covariance between each pair of features.

### Step 3: Eigenvector Calculation

The primary components of the data are represented by the covariance matrix's eigenvectors. The linear combinations of the initial attributes that account for the majority of the data variation are those. We must resolve the following equation in order to determine the eigenvectors:

```
C * v = λ * v
```

where v is the eigenvector, λ is the appropriate eigenvalue, and C is the covariance matrix.

This equation must be solved for each eigenvalue in order to determine the eigenvectors.

### Step 4: Eigenvalue Sorting

The order of the eigenvectors is determined by the distinct eigenvalue of each eigenvector. The eigenvector with the largest eigenvalue represents the first principal component, followed by the eigenvector with the second largest eigenvalue, and so on. This approach is crucial since it guarantees that the most crucial features are found first.

### Step 5: Principal Component Calculation

Calculating the principal components of the data is the last stage in putting PCA into practice. The original data matrix is multiplied by the eigenvectors that correspond to the desired number of primary components. The matrix that results is a projection of the data onto the new principal component space.

### 6.3.1.2 Implementation

Let us look at a straightforward example to show how PCA functions. Let's say we have a dataset with n observations and m variables per observation. This dataset can be shown as a n x m matrix, X. Let's assume that the mean of each variable is 0 for the sake of simplicity. The data can be centered if this is not the case by deducting the mean from each variable.

As the first stage in PCA, the covariance matrix of X must be constructed. The covariance between each pair of variables in the covariance matrix is represented by a m x m matrix. The covariance matrix's diagonal members reflect each variable's variance, and its off-diagonal elements display the covariance between each pair of variables. The mathematical representation of the covariance matrix is:

```
C = (1/n) X^T X
```

where X^T represents the transpose of X.

The eigenvectors and eigenvalues of the matrix can be ascertained after we have the covariance matrix. The eigenvalues reflect the variance explained by each principal component, while the eigenvectors represent the primary components of the data. Each consecutive principal component, provided it is orthogonal to all preceding principal components and follows the first principal component, which is the eigenvector that accounts for the bulk of the variance in the data, explains the most of the remaining variance in the data.

The process of eigenvalue decomposition can be used to identify the eigenvalues and eigenvectors of the covariance matrix. You may determine the matrix's eigenvalues and eigenvectors by resolving the following equation.

```
C v = λ v
```

where v is the eigenvector of C, and λ is the corresponding eigenvalue. This equation can be resolved using conventional linear algebra techniques like the QR algorithm or the power iteration method.

Once we have both, we may arrange the eigenvalues and eigenvectors in decreasing order based on the eigenvalues of each. The eigenvector with the largest eigenvalue represents the first principal component, followed by the eigenvector with the second largest eigenvalue, and so on.

The original data must then be projected onto the essential components as the next stage. The initial data matrix, X, is multiplied by the eigenvectors that correspond to the requisite number of principal components. A projection of the data onto the fresh principal component space yields the resulting matrix.

### 6.3.1.3 Advantages

- 1) Lowering the dimensions of the data: One of PCA’s biggest benefits is its capacity to do so while still preserving the majority of the crucial details. It can be difficult to display data in high-dimensional databases, and performing any analysis on the data might be computationally expensive. By reducing the dimensionality of the data, PCA can facilitate visualization and analysis.
- 2) Finding patterns in the data: Patterns that may be difficult to spot in the original high-dimensional dataset can be discovered using PCA. The most significant differences in the data are highlighted by translating the data into a lower-dimensional space in order to do this. This can aid in locating collections of observations that might be useful for additional investigation.
- 3) Removing noise: A further benefit of PCA is its capacity to eliminate noise from the data. Noise in the data may be introduced by measurement errors or other sources. By converting the data into a lower-dimensional space with less noise, PCA can identify the sources of noise and eliminate them. This may aid in increasing the accuracy of later data analysis.
- 4) Improving computational efficiency: PCA can be used to reduce the dimensions of a dataset, which can significantly improve computational efficiency. This is particularly important when dealing with large datasets that require extensive computations to analyze. By reducing the dimensions of the data, PCA can help in reducing the computational time required for analyzing the data.
