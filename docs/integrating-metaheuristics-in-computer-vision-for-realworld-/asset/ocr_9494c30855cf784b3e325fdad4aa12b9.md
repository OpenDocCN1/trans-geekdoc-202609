+   2. Fisher face algorithm: An extension of the Eigenface algorithm that employs Fisher’s linear discriminant analysis (LDA) to identify features that is most discriminative between face classes. The algorithm employs statistical techniques to maximize class separation while minimizing within-class variation. This algorithm is more resistant to lighting and poses variations than the Eigenface algorithm.

+   3. LBP: This algorithm examines an image’s texture by comparing the intensity of each pixel to the intensity of its neighbors. Based on the comparison, it generates a binary pattern. This algorithm is computationally efficient and resistant to lighting and poses variations.

+   4. Convolutional Neural Networks (CNNs): CNNs are deep learning algorithms inspired by the structure and function of the human brain. CNNs are made up of multiple layers of interconnected nodes that have been trained to recognize patterns in images. This algorithm is highly accurate and can handle complex lighting, pose, and expression variations.

+   5. Deep Face algorithm: This is a specific implementation of CNNs created by Facearticle’s AI research team. The algorithm is trained on a large image data-set to learn a rich set of features useful for facial recognition. The algorithm is highly accurate and can handle lighting, pose, and expression variations.

Finally, several algorithms are used in facial recognition, each with its own set of strengths and weaknesses. Some algorithms are more computationally efficient than others, but others are more accurate or resistant to changes in lighting, pose, and expression. The algorithm chosen will be determined by the specific application and resources.
