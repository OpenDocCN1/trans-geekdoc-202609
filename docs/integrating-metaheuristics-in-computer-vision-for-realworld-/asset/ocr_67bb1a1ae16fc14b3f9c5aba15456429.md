# 6.4.2 Unsupervised Learning

Machine learning techniques such as unsupervised feature learning [19] entail instructing algorithms to discover patterns and connections in a dataset without the need of explicit supervision or labeling. Unsupervised feature learning involves feeding a dataset to the algorithm, which then has to identify any underlying structures or patterns.

Several applications, including data compression, data visualization, and anomaly detection, can benefit from unsupervised feature learning. The usage of autoencoders [20], a type of neural network that learns to compress data into a lower-dimensional representation and then reconstruct it back to the original input, is one of the most widely used methods for unsupervised feature learning.
