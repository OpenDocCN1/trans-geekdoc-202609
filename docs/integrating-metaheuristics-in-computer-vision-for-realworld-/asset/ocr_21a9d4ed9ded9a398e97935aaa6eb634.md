# Step 2: Covariance Matrix Calculation

The covariance matrix for the data is calculated next in the PCA process. The relationship between each pair of features in the dataset is depicted by the covariance matrix, which is a square matrix. The diagonal members of the covariance matrix reflect each feature's variance, while the off-diagonal elements indicate the covariance between each pair of features.

# Step 3: Eigenvector Calculation

The primary components of the data are represented by the covariance matrix's eigenvectors. The linear combinations of the initial attributes that account for the majority of the data variation are those. We must resolve the following equation in order to determine the eigenvectors:

```
C * v = λ * v
```

where v is the eigenvector, is the appropriate eigenvalue, and C is the covariance matrix.

This equation must be solved for each eigenvalue in order to determine the eigenvectors.

# Step 4: Eigenvalue Sorting

The order of the eigenvectors is determined by the distinct eigenvalue of each eigenvector. The eigenvector with the largest eigenvalue represents the first principal component, followed by the eigenvector with the second largest eigenvalue, and so on. This approach is crucial since it guarantees that the most crucial features are found first.

# Step 5: Principal Component Calculation

Calculating the principal components of the data is the last stage in putting PCA into practise. The original data matrix is multiplied by the eigenvectors that correspond to the desired number of primary components. The matrix that results is a projection of the data onto the new principal component space.
