# 12.3.4 Materials Description

# 12.3.4.1 NodeMCU 8266

As same in gas leakage system we use NodeMCU here. NodeMCU is a microcontroller which has a Wi-Fi module, which is the special thing about this chip. It can be programmed using Arduino IDE. Wi-Fi is nothing but a Wireless radio wave which can used to send and receive information. In this project, nodeMCU is used so that we can communicate with the user using Wi-Fi. In this project, the WI-FI system is used to communicate with the AWS webserver so that we can store the data in the server. The internet connection is needed in to access the webserver.

# 12.3.4.1.1 AWS Account

AWS account (amazon web server) is needed to store the records and to further analyse the record.

# 12.3.4.1.2 ACS712 Sensor

The ACS712 is a fully integrated, hall effect-based linear current sensor. It is simply a current sensor that uses its conductor to calculate and measure the amount of current applied. In this project, it constantly monitors the power usage, it measures AC as well as DC so it can measure all kind of power usage by appliance.

# 12.3.4.1.3 Working of the System

The circuit diagram Figure 12.4 represents the model of the system. It contains two components such as acquiring the data and processing it. The sensor reads the power consumption and transmits the information to the AWS server through Wi-Fi network and the information is stored in the database and the data is processed with MySQL database management system.

The data processing system receives the data from the sensor attached with each electrical appliances through Wi-Fi. Further, this data is stored in the MySQL database and can respond to the requests from user. Now the system is ready to manage the power
