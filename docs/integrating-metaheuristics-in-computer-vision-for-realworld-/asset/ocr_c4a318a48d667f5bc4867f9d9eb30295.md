# 11.2.2.1 Sobel Edge Detected Operator

It is a precisely defined first order derivative. It is used to calculate luminance function. It is also called as the Sobel Feldman operator or Sobel filter used in image processing that reinforces edges [1]. Sobel operator performs 2-D spatial gradient on an image and emphasizes regions of high spatial frequency that corresponds to edges. It is used to find the approximate absolute gradient magnitude at each point in an input gray scale image as shown in Figure 11.2 [2].
