## 7.2 Overview of the Proposed System

The proposed system is developed to extract contour based and region based features and synthesize them using an effective similarity measure. The system works into two modes. In the first mode, offline database is constructed, which contains features set along with image information. The features are extracted by ZMs (magnitude and phase) and Hough transform (histograms) based approaches. In online mode, the features of test image are obtained and equated with that of all the images of training set. The compared images are tiered as per their relevance to the test image and presented to the user. A general procedure of feature extraction and similarity matching is given in Figure 7.1.

## 7.3 Proposed Hybrid-Shape Descriptors

The extraction of appropriate features is required for describing an image effectively. In the proposed system, we consider both global and local features to enhance the accuracy of the image retrieval system. The global features are intended to represent the entire configuration of the image shape, whereas local features determine the interior details of the image edge map. In our system, we utilize ZMs magnitude and phase coefficients to describe global features of images. Local features are described by detecting edge lines over the image contour using Hough transform.

### 7.3.1 Global Feature Extraction Using ZMs

Mathematically, the set of orthogonal ZMs for an image intensity function f(r, θ) with order p and repetition q are defined as [18]:

\(Z_{pq} = \frac{p+1}{\pi} \int_0^{2\pi} \int_0^1 f(r, \theta) R_{pq}(r) e^{-jp\theta} r dr d\theta\),

where \(p \ge 0, 0 \le |q| \le p, p - |q| = even\), \(j = \sqrt{-1}\), and \(\theta = \tan^{-1}(y/x)\). \(R_{pq}(r)\) are radial polynomials defined by

\(R_{pq}(r) = \sum_{k=0}^{(p-|q|)/2} (-1)^k \frac{(p-k)!}{k! \left(\frac{p+|q|}{2} - k\right)! \left(\frac{p-|q|}{2} - k\right)!} r^{p-2k}\)

If we rotate the image function \(f(r, \theta)\) by an angle \(\phi\), then the relationship between the ZMs of the original image \(Z_{pq}\), and that of the rotated image, \(Z_{pq}^r\), is given by

\(Z_{pq}^r = Z_{pq} e^{-jp\phi}\),

where \(\phi\) is the angle of rotation. The phase relationship is given by

\(\phi_{pq}^r = \phi_{pq} - q\phi + 2m\pi, m = 0, 1, 2, ..., \infty\).

Equation (7.4) yields q distinct solutions for the rotation angle \(\phi\) given as:

\(\phi = \left( \frac{\phi_{pq} - \phi_{pq}^r}{q} \right) + \left( \frac{2\pi}{q} \right) m, m = 0, 1, ..., q - 1\).

which leads to an ambiguity in determining the rotation angle as only one solution shall provide the correct rotation angle. Their magnitudes are, however, the same, i.e.,

\(|Z_{pq}^r| = |Z_{pq} e^{-jp\phi}| = |Z_{pq}|\)

It is clear that rotating an image by an angle does not affect magnitude of ZMs, whereas the phase would change with image rotation. Since phase coefficients capture important information of an image, ZMs based features without phase coefficients inadequately describe the image. Revaud et al. [35] describe a similarity measure which involves both ZMs magnitude and phase to determine similarity between two images. The method determines the rotation angle \(\phi\) between two images which minimizes the function:

$F(\boldsymbol{\phi})=d^2(\boldsymbol{\phi})=\sum_{p=0}^{p_{\max }} \sum_{q=-p}^{p} \frac{\pi}{p+1}\left|Z_{p q}-Z^{\prime}_{pq} e^{jq \boldsymbol{\phi}}\right|^2$ (7.7)

If two images are similar, that is one image is rotated version of the other, then \(d^2(\phi) = 0\). If the two images are different, then \(d^2(\phi)\) is expected to assume a high value. After simplification, Eq. (7.7) becomes [35].

\(F(\boldsymbol{\phi})=\sum_{p=0}^{p_{\max }} \sum_{q=-p}^{p} \frac{\pi}{p+1}\left[\left|Z_{p q}\right|^2+\left|Z^{\prime}_{pq}\right|^2-2\left|Z_{p q} Z_{p q}^r\right| . \cos (q \boldsymbol{\phi}+\boldsymbol{\phi}_{pq}^r-\boldsymbol{\phi}_{p q})\right].\) (7.8)

The minimum of \(F(\phi)\) lies in one of the intervals, \([\phi_n, \phi_{n+1}]\), where \(\phi_{n}=n \pi / 2 p_{max}, 0 \le n < 4p_{max}\). The method is simplified by finding the zeros of the following function:

\(F'(\boldsymbol{\phi})=0=\sum_{p=0}^{p_{\max }} \sum_{q=-p}^{p} \frac{2 \pi q}{p+1}\left|Z_{p q} Z_{p q}^r\right| \sin (q \boldsymbol{\phi}+\boldsymbol{\phi}_{p q}^r-\boldsymbol{\phi}_{p q})\) (7.9)

Therefore, after computing rotation angle \(\phi\) and making phase correction using Eq. (7.4) the phase coefficients are made rotation invariant and they are used as features along with magnitudes in the proposed approach. However, ZMs are computation intensive. The time complexity of ZMs is of the order \(O(N^2 p_{max}^3)\), if moments are computed up to order \(p_{max}\) (where \(p_{max}\) is the maximum order) over an image of size \(N \times N\) pixels. The order \(O(N^2 p_{max}^3)\) is very large when both \(N\) and \(p_{max}\) are large. For speeding up the computation of ZMs, we employ q-recursive method proposed by Chong et al. [38] and extended by Singh et al. [37].

### 7.3.1.1 Recurrence Relation for Radial Polynomials \(R_{pq}(r)\) [38, 39]

The following recursive steps reduce the time complexity of Zernike polynomials

- I. \(R_{pp}(r) = r^p\)
- II. \(R_{p,p-2}(r) = p r^p - (p-1)r^{p-2}\)
- III. \(R_{pq}(r) = K_1 R_{p,q+4}(r) + \left(K_2 + \frac{K_3}{r^2}\right) R_{p,q+2}(r), q = p - 4, p - 6, ..., 1 (\text{or } 0),\)
- (7.10)

where

\(K_3 = -\frac{4(q+2)(q+1)}{(p+q+2)(p-q)}\)
\(K_2 = \frac{K_3(p+q+4)(p-q-2)}{4(q+3)} + (q+2)\)
\(K_1 = \frac{(q+4)(q+3)}{2} - (q+4)K_2 + \frac{K_3(p+q+6)(p-q-4)}{8}\)

### 7.3.1.2 Recurrence Relation for Trigonometric Functions [39]

Evaluate \(\cos(q\theta)\) and \(\sin(q\theta)\) using recurrence relation and store them in two tables \(\cos \, t \,[M]\) and \(\sin \, t \,[M]\), where \(M\) is the total number of moments.

- I. Let

\(r = (x_i^2 + y_k^2)^{1/2}, \, a = C_0 = \frac{x_i}{r}, \, b = S_0 = \frac{y_k}{r}, \, \cos[t][0] = a, \sin[t][0] = b\)

- II. for \(q = 1 \text{ to } p_{\max}\)

C_q = aC_{q-1} - bS_{q-1}
S_q = aS_{q-1} + bC_{q-1}
\cos[t][q] = C_q \, \sin[t][q] = S_q
end for

The extra cost involved is the space required for the tables \(\sin \, t[p_{\max} + 1]\) and \(\cos \, t[p_{\max} + 1]\) with \(2(p_{\max} + 1)\) words.

### 7.3.3 Features Dimension

Since ZMs provide a large number of moments, optimal and effective set of features is an essential requirement for the satisfactory performance of a retrieval system. Very high or very low size of features set leads to over training or under training, respectively, which degrades the performance of the retrieval system. Normally higher is the order of moments, better should be the performance of ZMs features. However, the computation complexity increases rapidly and higher order moments lead to numerical instability and noise [44]. The selection of order \(p_{\max} = 12\) is a tradeoff between the computational complexity, numerical stability, and the descriptor performance [35, 36]. We demonstrate this through experimental evidence which is given in Figure 7.2a, which represents the average retrieval rate at different orders of moments. It is perceived that the difference in retrieval rate by using $p_{max} = 12$ and $p_{max} = 16$ is merely 1.17%. The CPU elapsed time shown in Figure 7.2b for the computation of moments up to $p_{max} = 16$ is 0.029 seconds and for $p_{max} = 12$ it is 0.018 seconds. The percentage time difference is 37.93%.
