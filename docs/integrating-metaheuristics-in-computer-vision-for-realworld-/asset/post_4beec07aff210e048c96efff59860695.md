- **camera**: Camera is used to monitor the room continuously. It sends the data to the computer via USB.

- **Relay Switch**: Relay switches are used to turn electrical appliances on and off when the signal from the processed image is negative.

- We have to train the system to detect human faces with the live feed of images from the camera, working in a shorter time to detect it.
- Next, we should process the images on the computer and send a signal to the relay switch.
- Finally, the relay switch should receive the signal and switch off the electrical appliances.
