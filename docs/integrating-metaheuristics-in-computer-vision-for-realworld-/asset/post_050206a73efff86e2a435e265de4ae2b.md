### 12.3.2 Smart Home Application Framework

To implement IoT in house appliance, the appliances need to communicate to each other, to communicate we need a web service. The web service has two classes. Simple Object Access Protocol (SOAP) and Representational State Transfer (REST). SOAP uses XML format to transfer data which contains tags and names which can be easily parsed. REST uses JavaScript Object Notation (JSON) format to transfer the data between the remote user and the mini web server. JSON is lightweight data interchange format which is more like a plain text so it can be easily transferred and parsed, which is better than the XML format. For example, if the lights need to be turned on, a request is sent to the server, and it is sent to the device and the light is switched on. We will discuss in brief in the following topics.

### 12.3.3 LPG Detecting System

LPG is common in use among the household and the commercial purposes like cooking, lighter, etc. LPG consists of Propane and Butane and some other gases which are highly inflammable. If there is a leakage in LPG gas in the house or any other area it will cause a fire accident, the area affected by it will be also in vast expense. An ethanol is added to the LPG so that most people can easily detect the leaks as it has odour. Though it may work if there are people in the house, what if no one is nearby. In these cases, a gas leak detector becomes vital and helps protect people from the dangers of gas leaks. So, with IoT we can make a security system which can detect, turn off the regulator, switch on the ventilation fans and send the user an emergency message.

### Components Required

- 1. NodeMCU ESP8266
- 2. MQ2 sensor
- 3. Buzzer
- 4. Relay
- 5. DC motor

### 12.3.3.1 Materials Description

### 12.3.3.1.1 NodeMCU ESP8266

NodeMCU is a microcontroller which has a Wi-Fi module, which is the special thing about this chip. It can be encoded using Arduino IDE. Wi-Fi is nothing but a wireless radio wave which can be used to send and receive information. In this project, NodeMCU is used so that we can communicate with the user using Wi-Fi. When the system senses the leakage, it needs to stop the leakage and alert the surrounding first. Then a message is sent to the user through Wi-Fi. The corresponding code must be loaded into the microcontroller, to which Wi-Fi is connected.

### 12.3.3.1.2 MQ2 Sensor

MQ2 sensor is highly sensitive to butane, propane, LPG, and smoke. So, it is used in this project. It is made up of SnO2 which is highly reactive to LPG gas. The sensor's conductivity is increased with an increase in concentration of gases. It gives analog output.

### 12.3.3.1.3 Buzzer

Buzzer is a device used to make noise; here it is used to make sound when the LPG is detected, which alerts the people.

### 12.3.3.1.4 Relay

A relay switch is used to control the main switchboard using the microcontrollers. It gives connection without disturbing the main. Here we use it to switch on the ventilation fan.
