# 11.6 Future Work

In the future, researchers can additionally increase PSNR and decrease MSE and time. Many algorithms and input parameters can be evolved to improve edge detection and evolve new techniques. The major defect in all types of operators is a high threshold misses important edges and low threshold returns false. To overcome these defects, threshold values can be made strong to produce effective results [13]. Strong edges and weak edges are examined and can be interpreted by advanced BLOB analysis. It will be a challenging task to improve [1] the edge detection accurately. These techniques can be applied in traffic control application to control traffic in metropolitan cities with respect to weather and also helpful to place sensors in an appropriate location to detect traffic through an edge detection advancement.
