## 6.4.2 Unsupervised Learning

Machine learning techniques such as unsupervised feature learning [19] entail instructing algorithms to discover patterns and connections in a dataset without the need of explicit supervision or labeling. Unsupervised feature learning involves feeding a dataset to the algorithm, which then has to identify any underlying structures or patterns.

Several applications, including data compression, data visualization, and anomaly detection, can benefit from unsupervised feature learning. The usage of autoencoders [20], a type of neural network that learns to compress data into a lower-dimensional representation and then reconstruct it back to the original input, is one of the most widely used methods for unsupervised feature learning.

The reconstructed data, which is the decoder network's output, is compared to the original input data using a loss function. ## 6.4.2.1 Procedure

- 1) Input data: In the first step, a dataset is fed into the unsupervised feature learning algorithm. This dataset could be anything from images to audio signals to text data.

- 2) Encoding: In the following step, an encoder network is used to convert the input data into a lower-dimensional representation. The encoder network takes the input data and trains to identify key features, compressing it into a smaller spatial dimension. The latent representation or code is the encoder's output.

- 3) Decoding: The decoder network takes over and learns to recover the original input from the latent representation once the data has been compressed into the latent representation. The data that has been rebuilt is the output of the decoder.

- 4) Training: The encoder and decoder networks are tuned during training to reduce the disparity between input and output data. This is frequently accomplished using a loss function, which determines the discrepancy between the input's original value and the output's result after reconstruction. The objective is to train the model to discover an accurate representation of the data that can be applied to jobs further down the line.

- 5) Feature Learning: The final step involves using the learned features for downstream tasks such as classification or clustering. The characteristics of the autoencoder can be applied to other models' training or to view the data in a lower-dimensional space.

## 6.4.2.2 Advantages

- 1) Data efficiency: Unsupervised feature learning is a potent method for data efficiency since it can be used to generate representations from enormous amounts of unlabeled data. This can be especially helpful when obtaining labeled data is difficult or expensive.

- 2) Generalization: Unsupervised feature learning, which may be used to train features that are resistant to fluctuations in the input data, can aid in improving the generalization of models. As a result, the models may be more reliable and capable of handling fresh, unforeseen data.

- 3) Finding hidden patterns: Data may contain hidden patterns or structures that are not immediately obvious. Unsupervised feature learning can reveal these patterns or structures. This might be helpful in a variety of applications when the underlying data structure is complex and challenging to analyze manually, such as picture or audio analysis.

- 4) Dimensionality reduction: Unsupervised feature learning can also be used to minimise the dimensionality of the data, which can facilitate later tasks like classification or clustering. The models may become simpler to understand and more computationally efficient as a result.

## 6.4.2.3 Disadvantages

- 1) Lack of interpretability: The inability to comprehend the learnt features is one of the key drawbacks of unsupervised feature learning. It can be difficult to understand what the learned features represent, which can make it challenging to debug or improve the model.

- 2) Overfitting: When the dimensionality of the latent space is sufficiently great, overfitting can occur in unsupervised feature learning. The model might then perform poorly in terms of generalization and be unable to handle brand-new, untested data.

- 3) Computing complexity: When working with huge volumes of data, unsupervised feature learning can be computationally complex. Due to this, scaling the models to larger datasets may be difficult.

- 4) Requires large amounts of data: Lots of unlabeled data are necessary for learning in order to learn useful characteristics. When labeled data is few or challenging to collect, this could be a drawback.

## 6.4.3 Deep Learning

Deep learning includes preparing a neural network to distinguish complex and abstract elements from incoming input automatically. Then, a range of tasks [21], such as speech recognition, object detection, picture classification, and natural language processing, can be performed using these recently discovered features.

## 6.4.3.1 Neural Network Architecture

Deep feature learning uses a neural network architecture that is built to automatically identify complicated and abstract features [16] from incoming data. It is composed of multiple interconnected layers of neurons that linearly transform input before activating it nonlinearly. In a hierarchical structure, the layers are organized with the lower layers learning straightforward traits and the upper layers learning more intricate and abstract features.

We can see a deep neural network with numerous layers in Figure 6.6. A common neural network architecture for deep feature learning has an input layer, many hidden layers [22, 23], and an output layer. When receiving raw input data, such as photos, audio waves, or text, the input layer preprocesses it into a numerical form so that the following layers can process it. The final output, such as a classification label, a regression value, or a series of tokens, is created by the output layer.

## 1) Hidden Layers

The primary elements of the neural network architecture for deep feature learning are the hidden layers. They are in charge of mastering the intricate and ethereal aspects that

characterize the input data. The number of hidden layers and the number of neurons in each layer are two hyperparameters that can be changed to improve the performance of the network.

The fully connected layer, sometimes referred to as the dense layer, is the kind of hidden layer that is most frequently employed in deep feature learning. The weighted total of each neuron's inputs, followed by a nonlinear activation function, determines each neuron's output in a fully connected layer. Every neuron in a layer that is fully connected is connected to every other neuron in the layer above it. The training phase involves learning the weights and biases of the neurons using back propagation.

Convolutional layers, which are utilized in deep feature learning, are another kind of hidden layer and are made to handle data having a grid-like layout [23], like photographs. Using a set of teachable filters to process the input data, convolutional layers are able to identify local patterns like edges, corners, and textures. A convolutional layer's output is a collection of feature maps showing the presence of these patterns across various input regions.

## 2) Pooling Layers

Pooling layers are used to downsample [24] the feature maps produced by the convolutional layers. This reduces the dimensionality of the input and strengthens the network's resistance to even the smallest changes in the input. The max pooling layer, which produces the greatest value in each local region of the input feature map, is the most widely used type of pooling layer. Additional types of pooling layers include average pooling and L2 pooling.
