# 12.3.3.2.1 Working of the System

IoT based LPG sensor have an LPG sensor which will be used in our module. we have implemented the LPG gas sensor interfacing with NodeMCU. The Signal from this sensor is sent to the microcontroller. The microcontroller is connected to a Motor, Buzzer, and relay. The IOT LPG leakage detector project is made with an ESP8266 chip which can be connected to Wi-Fi. This is a Wi-Fi module that is used for connecting microcontrollers to the Wi-Fi network and send data using its IP address. Figure 12.2 shows its connections.

Data sensed by these sensors is sent to the Cloud. The system then sends the data over to a website. The buzzer is turned ON once the gas leakage is detected. At the time, the buzzer is triggered. The Prerequisite for this LPG gas leakage detection for alerting the Wi-Fi module should be connected to a Wi-Fi hotspot. This project uses an online web service API by which an SMS is sent. Example for such API is Twilio. Then the relay switch on the ventilation fan through which the LPG is sent out of the house. Figure 12.3 shows the process.
