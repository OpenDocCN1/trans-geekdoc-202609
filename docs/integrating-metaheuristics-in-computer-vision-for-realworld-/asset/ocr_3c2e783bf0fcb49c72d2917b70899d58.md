# 12.3.6.4 Machine Learning Module

First, we are going to see Machine learning part. We are going to use Haar classifier to detect faces. Since OpenCV has this classifier by default it is easy for us to detect faces.

We going to collect set of positive image and negative image and save it as two separate descriptive files. We collect negative images to neglect all other objects in the room. We should save positive images with .vec format. Now we should train the Haar training algorithm.

```
Opencv -haartraining -data haar -vec vecfile.vec -bg negative.txt -nstages 30 -mem 2000 -mode all -w 30 -h 32
```

It is used to train the algorithm to detect the human faces we have inputted. Now we should .vec file to .xml file so that we can then process the signal.

```
convert_cascade size =30X32 data haarcascade _frontalface _alt.xml.
```

It will convert the .vec file to .xml file. Now the signal should be processed by the computer which gets the information from the DB-25 port.

This signal is transmitted to the relay switch which on respect to the signal switch on and off the appliances.
