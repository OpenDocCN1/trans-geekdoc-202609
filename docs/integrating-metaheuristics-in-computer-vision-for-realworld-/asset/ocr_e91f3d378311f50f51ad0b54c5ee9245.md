# 17.5.2 Root Mean Square Error

Root mean square error (RMSE) is used to compare two images, usually an original image and a treated image. The square root of the average of the squared deviations between the corresponding pixels of the two pictures is used to calculate RMSE. The RMSE can be written mathematically as:

# 17.5.3 Peak Signal to Noise Ratio

Peak Signal to Noise Ratio (PSNR) is a commonly used metric in image processing for evaluating the quality of an image compared to its original version. It is a measure of the ratio of a signal's maximal possible power to the power of corrupting noise that compromises the accuracy of image. PSNR in image enhancement is a quantitative indicator of the post-processing image quality improvement. The higher value of PSNR indicates better quality of enhanced image [14]. PSNR is calculated as follows:

```
PSNR = 10 * log10[(MaxI)^2/MSE]   (17.3)
```

where Max I is the maximum possible pixel value of the image (usually 255 for an 8-bit image), and MSE is the mean squared error between the original image and the enhanced image [15].
