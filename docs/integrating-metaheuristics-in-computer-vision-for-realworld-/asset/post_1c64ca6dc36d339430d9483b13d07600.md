
I(X;Y) = \sum_{x \in X,y \in Y} p(x,y)log\left(\frac{p(x,y)}{p(x)p(y)}\right)

As a result, X represents the feature and Y the desired result. P(x,y) is the joint probability distribution of X and Y, whereas there are p(x) and p(y) for the marginal probability distributions of X and Y, respectively.

### 6.2.1.1.3 Chi-Squared Test

Two category variables are tested for independence using this method. By contrasting the observed and anticipated frequencies, it determines the dependence between two categorical variables.

Making a contingency table, which displays the distribution of the dataset's two categorical variables, is the first stage in this procedure. The contingency table, which is a matrix, shows the number of observations for each grouping of the two variables. The contingency table would be a 3x3 matrix, for instance, if we had two variables, A and B, with three categories each.

On the basis of the presumption of independence between the two variables, the predicted frequencies of each category are then determined. The sum of the squared discrepancies between the observed and anticipated frequencies, normalised by the expected frequencies, is then used to generate the chi-squared statistic. It produces a statistic with a chi-squared distribution.

Thus, the above three techniques are common methods for calculating relevance scores.

### Step 3: Ranking Features

The features are then ranked according to the determined relevance ratings for each characteristic. The feature that received the greatest relevance score comes up on top, and so on.

### Step 4: Feature Selection

The top features are chosen in the last step based on relevance scores. The task and machine learning algorithm employed determine how many characteristics are chosen. Selecting the top k features—where k is either a predetermined number or is chosen via the use of cross-validation techniques—is a frequent strategy.

## 6.2.1.2 Advantages

The fact that feature selection can increase the precision of machine learning models [9] is one of its key benefits. The model can concentrate on the key elements that have the greatest influence on the target variable by choosing only the most pertinent attributes. Better prediction performance may result from this, especially if the dataset contains many features or noisy data.

It can boost the effectiveness of machine learning models, which is another benefit of feature selection. The model can be trained more rapidly and with less CPU resources if the dataset's feature count is decreased. This can be very useful when producing projections that are made in real time or very near to real time.

Furthermore, feature selection can make machine learning models easier to understand. The model can be made easier to understand by humans by choosing only the most pertinent attributes, which is beneficial in situations where accountability and transparency are essential. The most significant influences on the target variable can also be found through feature selection, which is helpful for making judgements or comprehending complex systems.

The capacity of feature selection to improve machine learning models’ generalizability. By only selecting the most relevant characteristics, the model can perform better on fresh, untested data by avoiding overfitting to the training set of data. In applications where the model must function well with a variety of inputs or when the training data is sparse or noisy, this can be very crucial.

## 6.2.1.3 Disadvantages

Like any technique, feature selection has some disadvantages that must be considered before its application. Firstly, feature selection can result in the loss of significant information. When features are removed from the dataset, some information may be lost, which could result in a reduction in the accuracy of the model. Moreover, certain features that may appear irrelevant may be crucial for the model’s performance, and their elimination may negatively impact the results [10].

Moreover, feature selection needs experience and domain understanding. The process of feature selection needs a thorough comprehension of the problem domain and the data being used. Without proper knowledge and expertise, the feature selection process may be inadequate, leading to a less accurate model.

Furthermore, feature selection can be computationally expensive. Identifying relevant features from a large dataset can be a time-consuming task, requiring significant computational power. In addition, choosing the best collection of features for the model can be a difficult task that often necessitates extensive testing.

Finally, the quality of the data may be a factor in feature selection. The accuracy of the model might be affected by the caliber of the data utilized for feature selection. If the data contains errors or missing values, the feature selection process may not produce optimal results, leading to a less accurate model.

## 6.2.2 Wrapper Method

The “Wrapper Method” is a feature selection strategy that selects a subset [10] of features from a dataset to enhance the performance of a machine learning model. It is a common strategy because it can deliver more accurate results than other feature selection strategies. Here, we’ll examine the Wrapper Method’s functionality, along with its benefits and drawbacks, and offer some visual aids to help explain the procedure.

The Wrapper Method chooses the feature subset that yields the best results after comparing several feature subsets. Each feature subset is assessed using a certain methodology, and each subset is given a score based on how well it performed. The final selection of features is then chosen by the algorithm using the subset with the best score.

### 6.2.2.1 Procedure

The wrapper method is an iterative algorithm that works as follows:

- 1) Initialize an empty set of selected features.
- 2) Train a model with all the available features and evaluate its performance using a validation set.
- 3) Add a feature to the set for each one that is absent from the chosen set, then train the model using both the chosen features and the new feature. Use the validation set to evaluate the model's effectiveness.
- 4) Add the feature to the chosen set that results in the greatest performance increase.
- 5) Continue performing steps 3 and 4 until a stopping criterion is reached.

As we can see, the wrapper approach chooses the feature that results in the greatest performance increase at each iteration. This is accomplished by contrasting the performance of the model with and without the additional feature. If performance increases, the feature is added to the predetermined set, and the procedure continues.

### 6.2.2.2 Advantages and Disadvantages

The wrapper method's consideration of the interplay between features is one of its key benefits. Since a validation set is used to assess the model's performance, it can capture how integrating a new feature with existing features influences the model's performance. Because of this, the wrapper method outperforms alternative feature selection techniques that depend on quantitative measurements of feature importance, such correlation or mutual information.

The wrapper method needs training and assessing a model for each group of features, which makes it computationally expensive as well. When dealing with feature-rich datasets, this might be extremely difficult.

The wrapper technique has undergone a lot of modifications, including the forward and backward selection methods, to get around this drawback.

### 6.2.2.3 Forward Selection Algorithm

The forward selection algorithm is a feature selection technique that iteratively adds one feature at a time to an empty set of features [11] based on how well it would enhance the performance of a model.

The forward selection algorithm has the following steps:

- 1) Initialization: Start with a feature set that is empty.
- 2) Feature evaluation: Use each characteristic independently to assess the model's efficacy. Any metric that is suitable for the task at hand, such as accuracy, F1 score, or mean squared error, can be used as the evaluation meter.
- 3) Feature selection: It is best to select the feature that performs the best on the evaluation metric.
- 4) Model training: Use the chosen feature along with the current collection of features to train a model.
- 5) Feature addition: Use every conceivable combination of the previously chosen attributes and the remaining features to gauge the model's performance. Add the feature to the current collection of features that produces the best performance on the evaluation criteria.
- 6) Termination: Up until a stopping requirement is fulfilled, repeat steps 4 and 5 as necessary. A maximum number of features, a minimum performance improvement, or a maximum number of iterations could all be included in this criterion.

Every machine learning model that can handle a variable number of features can apply the forward selection technique. It can be applied, for instance, to decision trees, neural networks, logistic regression, and linear regression. Moreover, it can be adjusted to handle features that are continuous, categorical, and binary.

The forward selection process could not always choose the best subset of features, which is a possible problem. It is possible that the forward selection method did not always select the best subset of features. However it frequently yields a decent approximation of the ideal subset of traits and is computationally effective.
