# 12.3.2 Smart Home Application Framework

To implement IoT in house appliance, the appliances need to communicate to each other, to communicate we need a web service. The webservice have two classes. Simple Object Access Protocol (SOAP) and Representational State Transfer (REST). SOAP uses XML format to transfer data which contains tags and names which can be easily parsed. REST uses JavaScript Object Notation (JSON) format to transfer the data between the remote user and the mini web server. JSON is lightweight data interchange format which is more likely a plain text so it can be easily transfer and parse which is better than the XML format. For example, If the lights need to be turned on a request is sent to the server, and it is sent to the device and the light is switched on. We will discuss in brief in the following topics.

# 12.3.2.1 Cloud Computing in IoT

To store the immense data, we need lot of memory, and we need to process it then. Thanks to clouds which enable us to store lot of data which may be personal or professional. The development of cloud computing enables us to transfer information from the system to server and server to user, so that we can get information from a long distance. And in reply to it we can send the instruction via the cloud.

Due to development in the IoT, Big data processing is also growing with it. The aspects of cloud computing are scale and speed which makes cloud computing more beneficial for IoT.
