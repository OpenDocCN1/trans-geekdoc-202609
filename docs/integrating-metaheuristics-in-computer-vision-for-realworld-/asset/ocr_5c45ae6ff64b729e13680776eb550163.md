There are several algorithms for object detection and recognition and features:

+   a. Haar Cascade Classifier: It is a prominent machine learning technique used for object recognition [2].
+   This strategy offers advantages, but it also has some disadvantages. These three issues with employing the Haar Cascade Classifier might arise:

+   o Large number of false positives: one of the primary problems with the Haar Cascade Classifier is that it is able to generate a lot of false positives, when the algorithm incorrectly recognizes things that are not even in the image. This can be hugely difficult if the false-positive resemble the targets of interest in terms of appearance.

+   o Sensitivity to lightening condition: the sensitivity of the Haar Cascade Classifier to illumination conditions is another possible drawback. Unreliable findings or missing detections may occur from inconsistent illumination in the picture.

Convolutional Neural Networks: It is a prominent sort of learning algorithm used for numerous computer vision applications, such as picture classification, object recognition, and segmentation [3]. While convolutional networks have shown amazing performance on various applications, they also have major limitations. Here are two typical examples:

+   • Limited view of context: CNNs operate by moving a filter across the input picture and learning local characteristics at each place. While this helps CNNs to catch local patterns and characteristics, it also implies that their view of the global environment is constrained. This can be a challenge for activities that need a deeper grasp of the visual, such as scene comprehension or object connection reasoning. Several academics have investigated adding attention processes or employing wider activation functions in CNN designs to overcome this issue.
