The gradient magnitude of the resulting gradient approximation coordinate is given by,

$|G| = \sqrt{Gx^2 + Gy^2}$

By the above, we can also calculate gradient direction by,

$\Theta = \text{atan2}(Gy, Gx)$, where $\theta$ is zero for a vertical edge which is darker on the right side.

# 11.2.2.3 Robert Cross Edge Detection Operator

The Roberts cross operator, as a differential operator [3], is designed to approximate the gradient of an image using discrete differentiation by computing the sum of the squares of the differences between diagonally adjacent pixels. It was initially proposed by Lawrence Roberts in 1963.
