# 15.3.1 Color

The perception of color is based on how human vision system reacted to light. Illuminant, surface spectral reflectance, and sensor sensitivity all contribute to it. In content-based picture extraction, color is employed vividness attributes. It is independent of image size and orientation and reasonably resistant to backdrop complexity. The color space, color quantization, and choice of similarity function are the main problems in color feature extraction. There have been several proposed studies on color perception and color spaces [21–23]. A point in a 3D color space can be used to represent each pixel of the image. The color space to utilise must be chosen before we can describe an image using its color characteristics. Several space models, including CIELAB, RGB, HSV, CIELUV, and opponent color, are available. The application's unique requirements will determine the optimal depiction.

# 15.3.1.1.1 RGB

Most widely used color space is called RGB, or RedGreenBlue. The primary colors of light Red, Green, and Blue make up this area. Any color in the visible spectrum can be created by combining different amounts of the three hues. This area is perceptually uneven and device dependent. This means that even while two colors are close to one another in the RGB space, the human eye may not always perceive them as being close. CRT monitors, scanners, television, and digitalized cameras typically employ RGB space. The additive primaries that make up the phosphor luminescence for a monitor allow us to easily parameterize all the colors using the coefficients such as C = n1R+n2G+n3B. Coefficients start from 0 to 1.
