# 19.3.3 Hybrid Pyramid Fusion Algorithm

A hybrid pyramid model as a group of lowpass/bandpass filter, each filter represents the same group of information with different scale [3-5]. Typically, images in the hybrid pyramid model will extent a bit of two smaller values because of its predecessor, and the higher extent will focus on the bottom spatial occurrence. Therefore, to recover back the original image the stored information is used by the hybrid model.

Initially, a Laplacian model constructed by the linear reversible image description which consists of a band-pass image placed with an interval, and an unutilized component of a low-frequency values. Let us assume, the parameter f(dot) – evaluation of down-sampling used to blur and decimate the i × i image I, so that f(I) is a new image of size i/2 * i/2. Also, let e(dot) – evaluation of up-sampling used to smoothen and expand the parameter I to be double the size, so e(I) is a new image of size 2i * 2i.

The coefficient h\(_k\) at all extent k of the Laplacian pyramid P(I) are built by producing the difference between adjacent levels in the Gaussian pyramid, and up-sampling the smaller one with e(dot) so that the sizes are united.

```
h\(_k\) = P(I) = G\(_k\)(I) - e(G\(_{k+1}\)(I)) = I\(_k\) - e(I\(_{k+1}\)) (19.4)
```

Basically, all the level captures the image at a specified scale. The end step of the Laplacian pyramid h\(_k\) is same as the captured image, but with an extra low-pitch value same as the final Gaussian pyramid step, i.e. h\(_k\)=I\(_k\). Finally, the coefficient value recovered by the Laplacian pyramid model [h\(_{1}\),...,h\(_{k}\)] will perform using the feed backward pitch data.

```
I\(_k\) = e(I\(_{k+1}\)) + h\(_k\) (19.5)
```

Equation (19.4) states that the low pitch value is same as the gaussian pyramid value and also the recovered back image I=I\(_0\). Then ’T’ is combined with the descent mask of input image.
