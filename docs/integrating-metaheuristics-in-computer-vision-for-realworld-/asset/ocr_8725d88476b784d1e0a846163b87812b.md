Light curves of a particular star is analyzed using machine learning to find exoplanets by detecting the dips in the star’s brightness [5]. Astronomers can automate the process of detecting exoplanets in massive datasets by teaching a machine learning algorithm to spot these dips. Other sorts of data, such as spectroscopic data, which may provide details about the chemical composition of an atmosphere on a planet, can also be analyzed using machine learning techniques. The application of machine learning in exoplanet detection can speed up the processing and analysis of massive volumes of data as well as the search for new exoplanets.

In this paper, a dataset, dataset1, of the fluxes of about 5000 stars from the NASA’s MIKULSKI [6] archive is utilised, obtained via the kaggle5. There are no null values in this pre-cleaned dataset. The dataset is highly imbalanced, with a 1:1000 ratio between classes 1 (non-exoplanet) and 2 (exoplanet). To address this issue in the exoplanet prediction project, the SMOTE (Synthetic Minority Oversampling Technique) [7] was employed to balance the data. SMOTE is a widely used method for oversampling the minority class in a dataset, and it works by generating synthetic samples of the minority class based on the existing minority class samples. By oversampling the minority class, bias towards the majority class can be mitigated and the overall performance of the model improved. In the project, the ratio between the two classes in the dataset was 1:1000, which is highly unbalanced. By using SMOTE to balance the data, the performance of the machine learning algorithms was improved and more accurate predictions about exoplanets were made. The use of SMOTE was a crucial step for prediction in this project. As well as a number of machine learning models such as Support Vector Machine, DecisionTree Classifier, Logistic Regression, RandomForest Classifier, K-Nearest Neighbors and XGB Classifier are used to predict the exoplanets in the dataset and to create a system that can precisely detect the presence of exoplanets in new observations. And model comparison is made with all the used models.
