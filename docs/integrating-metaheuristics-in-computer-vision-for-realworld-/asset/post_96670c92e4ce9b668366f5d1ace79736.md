
- e. Viola-Jones Algorithm: The Viola-Jones method is a well-known computer vision technique used to recognize faces in photographs [6]. Although the technique has shown to be quite efficient in many situations, there are several limitations to employing it:

  - Sensitivity to illumination and pose variations: the Viola-Jones method helps in detecting functionalities, such as edges, in an image and using these techniques to classify facial features. Nevertheless, it can be responsive to fluctuations in lighting and position, as these might alter the look of the attributes on which the algorithm is based. Faces that are heavily darkened or are not directly facing the camera, for example, may not have been detected accurately.

  - Limited detection of nonfacial objects: while the Viola-Jones technique was built primarily for face identification, it may also be used to detect various objects. Nevertheless, because the system is tuned to recognizing face traits, its efficacy in detecting nonfacial items may be limited. When applying the method for nonfacial object detection, this might lead to false positives or missing detections.

- f. The Local Binary Pattern: It is a prominent texture analysis tool in computer vision. But it has many benefits, there are some drawbacks to just using local binary pattern (LBP) [7]:

  - Sensitivity to noise: LBP compares the intensity distribution of nearby pixels to a center pixel and then assigns each pixel a binary code depending on whether its brightness is higher or lower than the center pixel. This technique, however, is sensitive to interference, as noise can induce changes in intensity levels, resulting in inaccurate binary codes. This can lead to erroneous texture analysis findings, limiting the use of LBP in noisy situations.

  - Limited discriminative power: although LBP captures local texture information well, it may not capture global texture information as well. This may restrict its discriminative power, since it may be unable to distinguish between textures with comparable local characteristics but distinct global structures. Nevertheless, LBP is a very simple texture analysis tool, and more advanced technologies, including such deep learning-based methods, may be able to catch more intricate texture information and perform better in some situations.

- g. Histogram of Oriented Gradient (HOG): HOG is a prominent feature extraction approach used in machine learning for image identification and recognition. Nevertheless, when used in convolutional approaches, HOG has several downsides.

  - One drawback of HOG is that it is responsive to fluctuations in lighting and shadows. HOG is based on calculating picture intensity gradients, which can be impacted by variations in lighting conditions. In object recognition and object tasks, this can lead to false positive or false negatives.

- h. **Fisherface:** Fisherface is a common face detection and recognition algorithm that collects characteristics from faces and utilizes them to categorize them [8].

  - The Fisherface algorithm's fundamental flaw is that, in order to attain high accuracy, it needs a lot of training photos for each category. That because Fisherface relied heavily on data analysis of the feature representation, and a large database is necessary to achieve that the predictive methods are accurate and subset of the population.

- i. **Eigen Face Algorithm:** Eigenface is a prominent face recognition technique that employs principal component analysis (PCA) to identify characteristics from faces and is using them for classification [9].

  - One of the key downsides of the Eigen algorithms is that it is aware of the differences in lighting and face expression. Specifically, Eigenface presumes that the light levels and facial gestures in the training data are comparable to those in the testing dataset. If there are large differences in lighting or face expression between both the training and testing datasets, the system may not perform effectively.

- j. **DeepFace Algorithm:** DeepFace method is a supervised neural face recognition technology designed by Facebook AI Technologies, able to identify and try to match faces in visual content with a reasonable level of accuracy.

  - One notable problem of the above algorithms is that it has been demonstrated to be biased towards some demographic groups, notably those with warm undertones. That is because the training set used to construct the algorithm was mostly made of photographs of lighter-skinned individuals. As a result, the system may have difficulties effectively detecting and comparing faces of persons with darker skin, resulting in inaccuracies and misidentifications.

- k. **Single-Shot Detector (SSD):** SSD is a machine learning object identification system that detects objects in the image or video with a single run of a neural network, eliminating the need for numerous area suggestions [10].

  - One possible disadvantage of the SSD in computer vision is that it may struggle to detect and localize objects that are extremely tiny or have complicated forms, that is because the SSD method predicts item placements using a predefined set of anchor boxes that might not be able to catch the entire variety of object sizes and forms in a given image. As a result, in some circumstances, the system may yield false-positive rate or miss detection systems for specific items.
