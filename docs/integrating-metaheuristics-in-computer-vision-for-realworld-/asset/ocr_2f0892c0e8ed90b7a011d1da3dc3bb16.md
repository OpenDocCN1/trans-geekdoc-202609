+   3. SIFT:
+   The SIFT algorithm is a feature-based object recognition system that can detect and characterize local characteristics in a picture. The SIFT method works by detecting critical spots in a picture that are insensitive to changes in size, rotation, and lighting. It then extracts a collection of characteristics centered on each key point that may be used to locate the item in a fresh picture

+   4. YOLO:
+   YOLO is a real-time object identification system that detects items in a picture using a single neural network. YOLO splits the input picture into cells and estimates the likelihood of each cell having an item, as well as the object's bounding box coordinates. As compared to previous object detection methods, this methodology allows YOLO to recognize many items in a single run. Object recognition algorithms are critical for a wide range of computer vision applications, including self-driving automobiles, security systems, and robots. The method used is determined by the unique application requirements, such as Accuracy, speed and complexity.

# 2.4 Face Detection

# 2.4.1 What is Face Detection

The method of recognizing and finding human faces in an image or video is known as face detection. It entails detecting the presence of faces in a picture and establishing their location and size. Typically, computer vision algorithms are used to examine the pixels in an image and seek for patterns that are suggestive of a face, such as the shape of the eyes, nose, and mouth. The face characteristics may then be isolated and extracted from the remainder of the picture, allowing for additional analysis or processing. Facial recognition has several uses, ranging from security and surveillance to social media and entertainment. It is frequently used as a foundation for more complex face recognition systems, which can identify and match specific persons based on their distinct facial traits.
