The fully connected layer, sometimes referred to as the dense layer, is the kind of hidden layer that is most frequently employed in deep feature learning. The weighted total of each neuron’s inputs, followed by a nonlinear activation function, determines each neuron’s output in a fully linked layer. Every neuron in a layer that is fully connected is connected to every other neuron in the layer above it. The training phase involves learning the weights and biases of the neurons using back propagation.

Convolutional layers, which are utilized in deep feature learning, are another kind of hidden layer and are made to handle data having a grid-like layout [23], like photographs. Using a set of teachable filters to process the input data, convolutional layers are able to identify local patterns like edges, corners, and textures. A convolutional layer’s output is a collection of feature maps showing the presence of these patterns across various input regions.

# 2) Pooling Layers

Pooling layers are used to downsample [24] the feature maps produced by the convolutional layers. This reduces the dimensionality of the input and strengthens the network’s resistance to even the smallest changes in the input. The max pooling layer, which produces the greatest value in each local region of the input feature map, is the most widely used type of pooling layer. Additional types of pooling layers include average pooling and L2 pooling.
