# ## 2.5.3 Algorithms

For identification and authentication, facial recognition algorithms analyze and compare images of human faces. There are several types of algorithms used in facial recognition, each with its own strengths and weaknesses. In this note, we will briefly explain some of the most commonly used facial recognition algorithms.

+   1. Eigen face algorithm: This algorithm represents a face as a linear combination of a set of basis images known as “eigenfaces” using principal component analysis (PCA). The algorithm analyses image variations to identify the most important features for facial recognition. This algorithm, however, is sensitive to lighting and poses variations and necessitates a large amount of training data.
