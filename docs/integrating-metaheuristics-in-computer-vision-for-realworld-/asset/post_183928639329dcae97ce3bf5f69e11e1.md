### 2.5.3 Algorithms

For identification and authentication, facial recognition algorithms analyze and compare images of human faces. There are several types of algorithms used in facial recognition, each with its own strengths and weaknesses. In this note, we will briefly explain some of the most commonly used facial recognition algorithms.

- 1. Eigenface algorithm: This algorithm represents a face as a linear combination of a set of basis images known as “eigenfaces” using principal component analysis (PCA). The algorithm analyses image variations to identify the most important features for facial recognition. This algorithm, however, is sensitive to lighting and poses variations and necessitates a large amount of training data.

- 2. Fisherface algorithm: An extension of the Eigenface algorithm that employs Fisher’s linear discriminant analysis (LDA) to identify features that is most discriminative between face classes. The algorithm employs statistical techniques to maximize class separation while minimizing within-class variation. This algorithm is more resistant to lighting and poses variations than the Eigenface algorithm.

- 3. LBP: This algorithm examines an image’s texture by comparing the intensity of each pixel to the intensity of its neighbors. Based on the comparison, it generates a binary pattern. This algorithm is computationally efficient and resistant to lighting and poses variations.

- 4. Convolutional Neural Networks (CNNs): CNNs are deep learning algorithms inspired by the structure and function of the human brain. CNNs are made up of multiple layers of interconnected nodes that have been trained to recognize patterns in images. This algorithm is highly accurate and can handle complex lighting, pose, and expression variations.

- 5. DeepFace algorithm: This is a specific implementation of CNNs created by Facebook’s AI research team. The algorithm is trained on a large image dataset to learn a rich set of features useful for facial recognition. The algorithm is highly accurate and can handle lighting, pose, and expression variations.

Finally, several algorithms are used in facial recognition, each with its own set of strengths and weaknesses. Some algorithms are more computationally efficient than others, but others are more accurate or resistant to changes in lighting, pose, and expression. The algorithm chosen will be determined by the specific application and resources.

## 2.6 Object Detection

### 2.6.1 Object Tracking

- 1. Object tracking is the technique of finding and following a particular object across time in a video clip. It is a crucial component in a variety of applications, including as robots, self-driving cars, and surveillance.

- 2. For object tracking, we will examine both conventional techniques and deep learning-based methods in this chapter.

- 3. Methods for tracking objects: Methods for tracking objects include mean-shift tracking, tracking via detection, tracking with kernelized correlation filters (KCF), and tracking with deep learning.

- 4. Mean-shift tracking is an established technique for object tracking that involves incrementally moving a window around the item to be tracked in order to maximize their similarity. Mean-shift tracking can adapt to changes in scale and orientation, but it is less resilient to occlusion and abrupt appearance changes.

- 5. Kernelized correlation filters (KCF): A traditional method for object tracking, KCF works by correlating the appearance of the target object with a kernelized template. KCF can handle scale, orientation, and illumination changes, but it is less resistant to occlusion and rapid changes in appearance.

- 6. Tracking by detection is an object tracking method that entails finding the target object in the first frame of the video sequence with an object detector and then following it over time with a tracker. The detector can be any object detection algorithm, including deep learning-based object detectors or Haar cascades. The tracker can be any object tracking algorithm, such as mean-shift tracking or KCF.

- 7. Training a neural network to monitor a particular object in a video series is the process of deep learning-based object tracking. By being trained on a sizable dataset of annotated video sequences, the network gradually learns to correlate the target object with its look. In comparison to conventional approaches, deep learning-based object tracking is more resilient to occlusion and abrupt changes in appearance and is capable of handling fluctuations in scale, orientation, and illumination.

- 8. Limitations and challenges in object tracking: Despite major advancements in object tracking technology, there are still a number of issues that need to be resolved. Occlusion handling, rapid changes in look, and changes in lighting and position are a few instances of these. Object tracking algorithms also need to be quick and effective in order to be applied in real-time applications. In the chapter that follows, object detection and tracking integration, including multi-object tracking and object detection and tracking in complicated scenarios, will be discussed [13].

The technique of finding and following a moving object in a series of frames recorded by a video camera is known as object tracking in computer vision. Despite variations in appearance, illumination, occlusion, and other challenging circumstances, the objective is to track the position and trajectory of the item in each frame of the video.

There are several approaches to object tracking in computer vision, including:

- 1. Template matching is the process of comparing the current frame of video to a previously captured template of the item to be tracked. A binary mask, edge map, or feature descriptor can be used as the template.
- 2. Optical flow: This includes tracking the movement of feature points in an image to estimate the migration of pixels between consecutive frames.
- 3. The Kalman filter is a tool used to calculate an object’s position and trajectory using a series of observations and predictions.
- 4. Deep learning methods use a neural network that has been trained to understand the characteristics of the object to be tracked and then make use of those characteristics to identify the object in a series of video frames.

Surveillance, robotics, autonomous driving, and augmented reality are just a few of the uses for object tracking. It is a difficult process that involves careful consideration of several elements, including the look of the item, its motion, and the features of the camera used to take the video.

### 2.6.2 Algorithms Used in Object Detection

In computer vision, the process of discovering and locating interesting objects in an image or video is referred to as object detection. Identifying numerous objects in the image with varying sizes, orientations, and locations is a more challenging task than object tracking.

Following are some popular object identification techniques in computer vision:

- (1) Haar Cascades: This method uses a set of traits to identify objects in photos. It involves putting a classifier through its paces on a sizable number of positive and negative samples of the target object.
- (2) HOG: Using information about the gradient orientation of the pixel values, this approach extracts information from an image. It then uses a sizable dataset of both positive and negative samples to train a classifier to recognize objects using these properties.
- (3) Region-based Convolutional Neural Network (R-CNN): This method identifies objects in images by fusing deep neural networks and region suggestions. It involves locating regions of interest in a deep neural network is used to process images to determine whether or not they include an object.
- (4) You Only Look Once (YOLO): Using a single neural network, this approach predicts the item classes and bounding boxes of a picture in real-time.
- (5) Single-Shot Detector: This algorithm recognizes objects by mixing convolutional feature maps of various sizes. It is similar to YOLO but has a different architecture.
