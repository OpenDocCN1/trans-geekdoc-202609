# 11.2.3.1.1.2 FINDING IMAGE INTENSITY GRADIENT

The Canny algorithm detects horizontal, vertical, and diagonal edges in a blurred image using four filters [8]. From the above Sobel, Prewitt and Robert gradient operators, the first derivative value is returned. By that, the edge gradient and direction is computed by,

$$\mathbf{G} = \sqrt{\mathbf{G}_x^2 + \mathbf{G}_y^2}$$

$$\Theta = \text{atan2} (\text{Gy}, \text{Gx})$$

where the edge direction angle is rounded [14] to one of four angles (0°, 45°, 90°, and 135°) representing the vertical, horizontal, and two diagonals and finally avoid unwanted responses, double threshold and track edges by hysteresis way.
