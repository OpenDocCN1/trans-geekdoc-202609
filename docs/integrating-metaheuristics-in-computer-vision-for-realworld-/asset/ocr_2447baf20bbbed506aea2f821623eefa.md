# 17.7 Conclusion

In this work, we are trying to restore old books and other historical documents that have been damaged due to various reasons such as bad paper, ink smearing or subsequent damage. In our solution, we have used segmentation and clustering techniques to classify and refine the original text. We used a combination of fuzzy logic and neutroscopic methods, the other being k-means integration and local thresholding. It was concluded that the combination of fuzzy logic and neutroscopic set provides better results in comparison to K-means and local thresholding based on MSE and PSNR parameters. On the other hand, K-mean provides better results than neutroscopic set + fuzzy logic and local thresholding based on NC parameters.
