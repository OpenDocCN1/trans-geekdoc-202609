## 18.6 Conclusion

The texture classification method, AH ESTBTC using Shearlet-transform, has been implemented in this work. In the proposed method, the directional filter characteristics and level of decomposition are changed. The proposed algorithm provides better classification accuracy for four decomposition levels with 48 directional filters. Classification accuracy obtained by our proposed method was 82.97% for the Brodatz-112 dataset, 92.86% for the KTH-TIPS dataset, 82.54% for the KTH-TIPS-2a datasets and 85.88% for the CUREt datasets by using Minimum Distance Classifier and 89.10% for Brodatz-112 dataset, 93.58% for KTH-TIPS dataset, 83.52% for KTH-TIPS-2a datasets, and 86.39% for CUREt datasets by using Support Vector Machine. The SVM classifier carry out superior than the MDC.

Other approaches can be investigated to increase the Classification accuracy with a minimum number of features. Multiresolution transform that is adopted for decomposing texture images can be investigated for capturing efficient feature descriptions with minimum computational complexity.
