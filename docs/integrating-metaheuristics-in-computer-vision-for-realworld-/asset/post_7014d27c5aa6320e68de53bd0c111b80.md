There are several algorithms for object detection and recognition and features:

- a. Haar Cascade Classifier: It is a prominent machine learning technique used for object recognition [2].
  This strategy offers advantages, but it also has some disadvantages. These three issues with employing the Haar Cascade Classifier might arise:
  - Large number of false positives: one of the primary problems with the Haar Cascade Classifier is that it is able to generate a lot of false positives, when the algorithm incorrectly recognizes things that are not even in the image. This can be hugely difficult if the false-positive resemble the targets of interest in terms of appearance.
  - Sensitivity to lighting condition: the sensitivity of the Haar Cascade Classifier to illumination conditions is another possible drawback. Unreliable findings or missing detections may occur from inconsistent illumination in the picture.

- b. Convolutional Neural Networks: It is a prominent sort of learning algorithm used for numerous computer vision applications, such as picture classification, object recognition, and segmentation [3]. While convolutional networks have shown amazing performance on various applications, they also have major limitations. Here are two typical examples:
  - Limited view of context: CNNs operate by moving a filter across the input picture and learning local characteristics at each place. While this helps CNNs to catch local patterns and characteristics, it also implies that their view of the global environment is constrained. This can be a challenge for activities that need a deeper grasp of the visual, such as scene comprehension or object connection reasoning. Several academics have investigated adding attention processes or employing wider activation functions in CNN designs to overcome this issue.
  - High computational cost: CNNs often have a large number of features, which can make training and running them computationally costly, especially on huge datasets or high-resolution pictures. This can restrict their usefulness in some situations, such as on asset machines or in practical systems, where speed is crucial. Several attempts to addressing this issue include using pruning techniques to minimize the number of parameters or building more efficient CNN models, such as MobileNet or EfficientNet.

- c. Scale-Invariant Feature Transform: The scale-invariant feature transform (SIFT) method is a popular computer vision approach for recognizing and characterizing local features in pictures [4]. Although SIFT has shown to be quite useful in many applications, it does have significant drawbacks:
  - Computationally expensive: SIFT entails the computation of several mathematical procedures, such as Gaussian smoothing, Gaussian difference, and orientation histograms. These processes are computationally demanding and can be sluggish, particularly when dealing with huge photos or real-time applications.
  - Sensitivity to image blur: SIFT is intended to be insensitive to scale changes, although it can be affected by picture blur. That is because the algorithm’s Gaussian smoothing can obscure out critical details of an image, making SIFT difficult to identify and match features effectively. Its sensitivity to blur might restrict SIFT’s utility in some applications, such as computed tomography or satellite photos analysis, where picture blur is common.

- d. You Only Look Once (YOLO): YOLO is a famous real-time object identification system that predicts boundary boxes and class label for many objects in an image using a single neural network [5]. While YOLO has numerous positives, it also has several disadvantages, which are as follows:
  - Limited accuracy: YOLO is a one-shot object identification technique, which means it produces recommendations relying on a personal neural network run. As contrasted to other computer vision algorithms that require numerous steps of processing, this might reduce its accuracy. YOLO may fail to recognize tiny, obstructed, or complicated objects, which might result in false negatives or erroneous bounding box predictions.
  - Training data bias: to learn how to recognize objects, YOLO largely relies on training data. Nevertheless, the individual’s accuracy may be reduced if the training set is skewed or unfair of the real-world settings, wherein YOLO will be applied. For example, YOLO may fail to recognize items in low-light or crowded surroundings if it is trained on photographs of objects in very well, clean backdrops. Also, YOLO may be unable to recognize items on which it has not been taught, limiting its adaptability.
