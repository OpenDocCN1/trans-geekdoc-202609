CBIR known as QBIC (query by image content) is a method of computer vision, to the retrieve picture or the task of finding for digital images in enormous databases. It searches through a large image library for relevant images using the visual content of the photographs. The search will look at the image’s actual contents rather than its supplementary metadata, such as its tags, keywords, and detailed descriptions, in accordance with the definition of the term “contentbased.” Colors, forms, textures, and any other information that can be inferred from the image itself are all considered to be content in this context.

The user may submit a query sample to extraction system while using online image retrieval to look for desired photographs. The calculation of feature database and ranking is updated using the distance between all the features in a vector. During extraction, an indexing technique is employed to provide a rapid way to search the picture dataset. The search results are sorted by the system based on how closely they resemble the query samples and displays those results. Figure 15.1 depicts a typical architecture for a CBIR system.
