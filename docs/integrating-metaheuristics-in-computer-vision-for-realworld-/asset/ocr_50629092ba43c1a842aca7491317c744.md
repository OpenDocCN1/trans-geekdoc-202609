**Exploration Phase** The exploration step involves using fundamental mathematical operators to search the entire region for the best possible solution. Equation 13.17 provides a mathematical description of the procedure.

\[ X_{i,j}(itr + 1) = \begin{cases} best(X_j) \div (MOP + \epsilon) \times ((ub_j - lb_j) \times Mu + lb_j), \ if \ r_2 < 0.5 \\ best(X_j) \times MOP \times ((ub_j - lb_j) \times Mu + lb_j), \ otherwise \end{cases} \] (13.17)

Where \( X_{i,j}(itr + 1) \) represents the \( ith \) solution for the next step, \( X_{i,j}(itr + 1) \) represents the \( jth \) position in the \( ith \) solution for the current step, and \( best(X) \) represents the \( jth \) place in the best-achieved result. \( \epsilon \) is a non-deterministic variable utilized to expand and explore spaces. In addition, the minimum and maximum values at the \( jth \) position are indicated by \( lb_j \) and \( ub_j \), respectively. While \( r2 \) is chosen at random, the control parameter \( Mu \) helps to fine-tune the search procedure.

As stated in equation 13.18, the Math Optimizer probability (MOP), is the function’s value at \( t - th \) iteration, \( MOP\ (itr) \) is a coefficient, \( itr \) represents the current step, while \( maxIt \) is the utmost number of iterations. It is the number of iterations that can be used. The sensitivity parameter \( alpha \) is defined. It is utilized for accuracy during the exploitation phase, and its value is maintained at 5. However, the density and dispersion rate of these operators makes it difficult to approach the target.

\[ MOP(itr) = 1 - \left( \frac{itr}{maxIt} \right)^{\frac{1}{alpha}} \] (13.18)

**Exploitation Phase** In this phase, mathematical operators are used to refining the result. This phase is determined by the MOA function value. As shown in Equation 13.19, the addition and/or subtraction search method is utilized for search refinements.

\[ X_{i,j}(itr + 1) = \begin{cases} best(X_j) \div (MOP + \epsilon) \times ((ub_j - lb_j) \times Mu + lb_j), \ if \ r_3 < 0.5 \\ best(X_j) \times MOP \times ((ub_j - lb_j) \times Mu + lb_j), \ otherwise \end{cases} \] (13.19)

Where \( r_3 \) is an integer generated at random by the procedure. If \( r_3 \) is less than 0.5, the subtraction is applied; otherwise, the addition operator is utilized. The stochastic parameter \( Mu \) is designed to circumvent problems with local minima. Additionally, it facilitates exploration throughout iterations.
