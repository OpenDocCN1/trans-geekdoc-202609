### 15.3.1 Color

The perception of color is based on how human vision system reacted to light. Illuminant, surface spectral reflectance, and sensor sensitivity all contribute to it. In content-based picture extraction, color is employed vividness attributes. It is independent of image size and orientation and reasonably resistant to backdrop complexity. The color space, color quantization, and choice of similarity function are the main problems in color feature extraction. There have been several proposed studies on color perception and color spaces [21–23]. A point in a 3D color space can be used to represent each pixel of the image. ### 15.3.1.1.1 RGB
