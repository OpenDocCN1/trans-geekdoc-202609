### 19.3.1 Preprocessing

In preprocessing, the first and foremost step is adaptive histogram equalization (CLAHE). The advantage of this method is to even up the image for better intensity. CLAHE is a form of adaptive histogram equalization (ALE) method. ALE method does the contrast stretching but the result is very narrow. Therefore, to diminish this problem of noise addition, CLAHE does histogram equalization in small patches or in small blocks with high precision and contrast limiting. After this step, lee filter is used to remove the speckle noise.

### 19.3.2 Noise Removal With Lee Filter

Lee filtering is a method used to find the range of error using filtering technique. This technique filters out the data based on the information which calculates the value inside the windows individually. Unlike a normal low-pass based smoothening filter, the Lee filter and other type of sigma filters save the image sharpness and details while extinguishing the noise. After this, the evaluated filtered pixel values are restored by a value planned by the accessible pixel values. It is one of the most common techniques to filter out the speckle noise from SAR images. Equation (19.1) gives the filter evaluation formula

```
I(t) = R(t)v(t) (19.1)
```

Note that, I(t) – Full noise image and R(t) – Noise free Image with basic backscatter property, v(t) - speckle noise and also it is not dependent on R(t).

```
R̂(t) = Ī(t) + W(t)(I(t) − Ī(t)) (19.2)
```

where W(t) – weighting function and it is given by

```
W(t) = 1 − Cv / Cl (19.3)
```

where \(\hat{R}(t)\) - filtered image data and it is also the approximated value of R(t), \(\bar{I}(t)\) - average value of filter evaluation, Cv = \(\sigma_v\) / v - quantity of the variation with the noise along with standard deviation, and C_l = \(\sigma_l\) / v - quantity of variance without the noise effect of local images with standard deviation.

Later, images get filtered, the results are given to the next component to fuse the image with hybrid pyramid algorithm which is explained below in detail.

### 19.3.3 Hybrid Pyramid Fusion Algorithm

A hybrid pyramid model as a group of lowpass/bandpass filter, each filter represents the same group of information with different scale [3-5]. Typically, images in the hybrid pyramid model will extent a bit of two smaller values because of its predecessor, and the higher extent will focus on the bottom spatial occurrence. Therefore, to recover back the original image the stored information is used by the hybrid model.

Initially, a Laplacian model constructed by the linear reversible image description which consists of a band-pass image placed with an interval, and an unutilized component of a low-frequency values. Let us assume, the parameter f(dot) – evaluation of down-sampling used to blur and decimate the i × i image I, so that f(I) is a new image of size i/2 * i/2. Also, let e(dot) – evaluation of up-sampling used to smoothen and expand the parameter I to be double the size, so e(I) is a new image of size 2i * 2i.

The coefficient h_k at all extent k of the Laplacian pyramid P(I) are built by producing the difference between adjacent levels in the Gaussian pyramid, and up-sampling the smaller one with e(dot) so that the sizes are united.

```
h_k = P(I) = G_k(I) - e(G_{k+1}(I)) = I_k - e(I_{k+1}) (19.4)
```

Basically, all the level captures the image at a specified scale. The end step of the Laplacian pyramid h_k is same as the captured image, but with an extra low-pass value same as the final Gaussian pyramid step, i.e. h_k = I_k. Finally, the coefficient value recovered by the Laplacian pyramid model [h_1, ..., h_k] will perform using the feed backward pyramid data.

```
I_k = e(I_{k+1}) + h_k (19.5)
```

Equation (19.4) states that the low pass value is same as the gaussian pyramid value and also the recovered back image I = I_0. Then T is combined with the detail mask of input image.
