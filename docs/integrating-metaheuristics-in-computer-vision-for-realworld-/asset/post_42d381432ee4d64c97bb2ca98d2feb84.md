### 4.2 Proposed Framework

The framework is divided into three major phases [5]:

- 1) Data Exploration: It involves processes like, loading the dataset, preprocessing on dataset, displaying the dataset and performing the graphing.
- 2) Data Preprocessing: It involves processes like, loading the dataset and removing outliers, splitting the dataset for training and testing.

![](img/07f0bb0f402fd4e2f1880bf37d1ea963_88_1.png)

Figure 4.2 Proposed framework for bank fraud detection.

- 3) Data Classification: It involves processes like, training the dataset, developing the classifier model, random forest and performing classification.

This program is designed to detect the fraud banking transactions using the concept of data analysis and data structure along with algorithms of machine learning. Firstly, the dataset was chosen and imported from Kaggle (a hub at the internet to access various data-sets of different domains and have access their data analysis). The key methodology used is exploratory data analysis (EDA) which helps in creating a classification based model which classifies a transaction into fraud class and valid class [5]. PCA dimensionality reduction is used which helps in reducing the n number of attribute columns into few columns (in this case, only 31) that creates less space and time complexity and also helps the machine learning model understand the dataset well and give maximum efficiency. The whole framework of the process is displayed through Figure 4.2. After the selection of the dataset, data normalization was performed to organize the data well in the database so that its analysis becomes easier and more accurate/productive. Then, the major step of importing various libraries of python; which include numpy as np for getting access of numerical python in order to make arrays, pandas is used for performing data analysis, matplotlib, and pyplot are used for making charts, graphs, etc., and seaborn is used for data visualization [15, 16].

Then a path is set for the dataset to be added in the code workplace. Then, a bit of information regarding the dataset is retrieved by letting the program describe about the various features of its attributes like the count, mean value of every column, minimum value of every column, minimum value of every column, above 25%, 50%, and 75% values of each column. Then the codes are set for the program by defining the class variables for valid and fraud transaction as 0 and 1, respectively, and whenever the class variable is observed to be as 1, it is an alarm for a fraud transaction. After the successful implementation of the code details of the amount of fraud as well as valid transactions were shown. A correlation matrix was also designed for the data points using a heat map which showed the relation or dependency of column variables on each other to express their importance toward analyzing our target variable. Then the data were split in a ratio 4:1 where 80% of the data were separated for training the model and 20% for testing the model. Afterward, the scores of the classifier were printed.
