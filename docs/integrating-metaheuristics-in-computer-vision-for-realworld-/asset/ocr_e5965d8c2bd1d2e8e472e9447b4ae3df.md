seen as solutions to problems like data clustering and classification used in fields like artificial intelligence (AI), machine learning (ML), and data mining (DM). A problem can often have numerous optimal solutions, and optimization is the process of determining which one is best. One or more objectives can be accomplished. Multiple constraints which either can be maximized (hard) or minimized (soft) are subject to optimization problems [13–21]. There are numerous influential factors. The change in their values will affect (improve or deteriorate) the “measurable performance” and the degree of “constraints” violation. It is undoubtedly helpful to formulate optimization questions to obtain some understanding of the issue, but finding the answer is not that much easy. It can be very challenging to solve many optimization problems; e.g. the arithmetic problem known as the traveling sales problem (TSP) involves determining the most efficient route between a set of points and destinations. TSP is known as the non-deterministic polynomial-time problem. Given this, it seems highly improbable that a polynomial-time algorithm exists that solves the TSP in all cases, and it is quite possible that no algorithm exists that solves the problem exactly in all cases. Therefore, approximation and heuristic approaches appear to be the primary choices [22].

# 13.2.1 Mathematical Formulation

Mathematically quoting, an optimization problem is one in which certain variables have to be determined to obtain the best-measured efficiency (objective function) within specified constraints which spans design space vectors, \(x = x_1, x_2, ... x_D\)

Several objective functions must be optimized in a multi-objective optimization problem. Then, these functionalities should either be maximized or decreased based on necessity. Some applications are found in Acharya and Saha and Kumawat et al. [23, 24]. MOPs have more constraints than a single objective function (SOP). Following equations can be used to express an optimization problem in a general form.

```
Maximize/Minimize \(f_n(x) =\) \hfill (13.1)
\(g_j(x) \le 0 \quad j = 1, 2, ... .M\) \hfill (13.2)
\(h_j(x) \le 0 \quad i = 1, 2, ... .N\) \hfill (13.3)
```

Where \(g_j\) and \(h_j\) are the known as equality and inequality constraints. It is possible to transform any maximization problem into a minimization problem by just inverting its sign. If \(f_x\), \(g_j\) and \(h_j\) are linear then it turns into a linear programming problem (LP). The simplex method makes it comparatively simple to solve linear programs. However, since the problem functions \(f_x\), \(g_j\) and \(h\) are typically all nonlinear, solving them can be difficult.

If the choice variable \(x_i\) is limited to discrete values, the optimization problem turns into a discrete task. When \(x_i\) admits only integer values, this form of optimization is known as integer programming. A hybrid integer program is generated when some variables are discrete while some are continuous. Programming with integers and programming with mixed integers are challenging combinatorial or discrete optimization problems.
