# ## 7.3.1 Global Feature Extraction Using ZMs

Mathematically, the set of orthogonal ZMs for an image intensity function f(r, θ) with order p and repetition q are defined as [18]:

\(Z_{pq} = \frac{p+1}{\pi} \int_0^{2\pi} \int_0^1 f(r, \theta) R_{pq}(r) e^{-jp\theta} r dr d\theta\),

where \(p \ge 0, 0 \le |q| \le p, p - |q| = even\), \(j = \sqrt{-1}\), and \(\theta = \tan^{-1}(y/x)\). \(R_{pq}(r)\) are radial polynomials defined by

\(R_{pq}(r) = \sum_{k=0}^{(p-|q|)/2} (-1)^k \frac{(p-k)!}{k! \left(\frac{p+|q|}{2} - k\right)! \left(\frac{p-|q|}{2} - k\right)!} r^{p-2k}\)

If we rotate the image function \(f(r, \theta)\) by an angle \(\phi\), then the relationship between the ZMs of the original image \(Z_{pq}\), and that of the rotated image, \(Z_{pq}^r\), is given by

\(Z_{pq}^r = Z_{pq} e^{-jp\phi}\),

where \(\phi\) is the angle of rotation. The phase relationship is given by

\(\phi_{pq}^r = \phi_{pq} - q\phi + 2m\pi, m = 0, 1, 2, ..., \infty\).

Equation (7.4) yields q distinct solutions for the rotation angle \(\phi\) given as:

\(\phi = \left( \frac{\phi_{pq} - \phi_{pq}^r}{q} \right) + \left( \frac{2\pi}{q} \right) m, m = 0, 1, ..., q - 1\).

which leads to an ambiguity in determining the rotation angle as only one solution shall provide the correct rotation angle. Their magnitudes are, however, the same, i.e.,

\(|Z_{pq}^r| = |Z_{pq} e^{-jp\phi}| = |Z_{pq}|\)

It is clear that rotating an image by an angle does not affect magnitude of ZMs, whereas the phase would change with image rotation. Since phase coefficients capture important information of an image, ZMs based features without phase coefficients inadequately describe the image. Revaud et al. [35] describe a similarity measure which involves both ZMs magnitude and phase to determine similarity between two images.
