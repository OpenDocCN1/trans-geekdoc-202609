# 12.3.5.4 Projects in Smart House Systems

+   - Automating plant watering system which waters the plant, and we can use soil moisture sensor to check the moisture in the soil, so we can water the plant accordingly.
+   - Soil fertility checking using NPK sensor which can be used even in agriculture, it checks soil nitrogen, potassium and phosphorous level.
+   - We can make a smart door which unlocks only if the persons face is identified as member of the family using AI. If not, permission is needed from the family user to unlock the door.
+   - Using ultrasonic sensor, we can switch on and off the motor without any overflow of water.
+   - Food management can be done as it can manage a record when a product is brought and what its expiry date and it can even list what are all the is out of stock in the house.
+   - Automatic air ventilating fan which drives away the air inside which tends to be more pollutant or oil.
+   - Smart lights which turn off during day and on when it senses there is not enough light.
+   - Smart house assistant which checks for any problem leakage in water pipes, gas leakage, drainage problem, repaired electrical appliances and get it into the sight of user and even contact the person who can take care of it respectively. Figure 12.8 shows the applications in a house.
