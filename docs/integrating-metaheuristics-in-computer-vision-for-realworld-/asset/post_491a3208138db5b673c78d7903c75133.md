## 15.3.3 Shape

Identifying an object's shape can frequently be very challenging. People often describe shape verbally or visually, using words like “elongated”, “rounded,” etc. Even very complex shapes must be accurately described for computer-based shape processing, and while there are numerous useful methods for doing so, there is no widely acknowledged approach to doing so. Shape is a crucial visual element and one of the basic elements used to describe the content of images. When an object's orientation or location are altered, all of its geometrical information is contained in the image and is often unaffected. ## 15.4.3 Relevance Feedback

Retrieval systems can be made more effective interactively by using relevance feedback (RF), a technique that is widely acknowledged. Generally, there are three steps to it: A user-supplied query pattern is first searched for by the system, which returns a limited number of photos. The system automatically reformulates the original question based on the user's relevance judgements once the user chooses which of the obtained images are useful (relevant). This procedure may be repeated until the user is satisfied. Because RF approaches give the CBIR system the ability to learn from user perceptions of images, the semantic gap problem is less of a problem. RF techniques often address the following issues: short training samples (normally less than 20 per round of contact), asymmetry in training samples (a few negative instances are typically supplied back to the system), and real-time requirements (RF algorithms should be quick enough to handle real-time user engagement). Designing and implementing learning processes is another crucial challenge. The most popular strategies employ support vector machines, genetic algorithms, Bayesian probabilistic techniques, and weight-based learning techniques.
