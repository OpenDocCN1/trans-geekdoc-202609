# 15.1 Introduction

Large collections of digital photographs are being produced in numerous sectors including business, government, academia, and healthcare. Many of these collections are the result of existing analogue collections of pictures, drawings, paintings, and prints being digitalized. Mostly, browsing and keyword indexing were the only ways to search these collections. Databases of digital images provide access to content-based searching. The technological components of the most recent content-based picture retrieval systems are surveyed in this work. The development of storage and digital image capturing technology has accelerated recently. Managing data properly and efficiently becomes more difficult as there are more photographs to store and manage. The vastness of the database makes it extremely challenging to manage and retrieve photographs. The process of creating tools and ways for obtaining photographs from the sizable database has advanced significantly. Any image can be retrieved by performing a search in the database by the help of a search engine. The search engine provides more images that are related to the search. The user’s primary challenge in this situation is finding pertinent image in this vast and diverse assortment. This issue is known as image retrieval problem. The two methods used for search and retrieval in an image database to address this issue are text-based and content-based.

The methods based on automatic picture annotation depend on a system’s ability to recognise color, edges, textures, spatial layout, and shape-related information accurately. Despite of research performed to increase automatic image annotation; retrieval process can be thrown off by differences in visual perception. The challenges mentioned above can be resolved using the CBIR framework, which is based on the content of query language for the visual analysis. The primary requirement for CBIR is that a query image can be provided as an input. It then assesses visually comparable images by analysing the visual elements from the query image with the photographs archived.

Feature vector serves as a foundation for locating images with related contents. The query in CBIR computes low-level visual attributes, such as color, shape, texture, and spatial arrangement, and matching of these features is done to sort the output. The amount of visual data that is available in digital form has grown exponentially in recent years. Every day, gigabytes of brand-new photographs and video clips are created and saved, creating a massive, dispersed, largely unstructured reservoir of multimedia data that can be accessed in large part via the Internet. Visual information can now be easily and affordably archived, compressed, and digitally preserved using a variety of tools and software that are readily available. There is still no appropriate commercial solution for the open challenge of efficiently searching and retrieving certain photographs. Basically, there are three ways to access previously saved visual data:

+   1. Free searching: Users search collection of image and files before stopping to locate the necessary information.
+   2. Content-based retrieval: The multimedia database allows users to do searches that provide information on the precise content of an image and/or video frame. Content-based engine translates this data so that it can query its database and provide the customers who are mostly satisfy users’ expectations. The first two methods suffer from scalability problems and serious shortcomings.
