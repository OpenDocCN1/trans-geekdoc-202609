layers in inception are 3x3 convolutional layers with a stalk and padding of 2 with dilation factor of 1. Link layers are 3x3 window linking layers with a branch of two. The set input image size in Inception-v3 is 299 x 299 for training data [18-21]. Then the linking layer size is minimized to some extent. The block diagram of the pre-trained convolution network is displayed in Figure 19.2.

Figure 19.2, selected attributes of thyroid multinodular is given to the first layer of the model. After the data goes into the network it realizes the relation and start comparing the features with their classes. The system utilizes the 1-vs-all (OVR) process to differentiate the data in the Long Short Time Memory (LSTM) layer with the hidden neurons. The hidden neuron uses a common threshold function. Finally, the results of the layers are combined and produce the end prognosis class levels by applying common threshold function.

After removing the deep features of all the thyroid nodule image using inception v3 model, L1 normalization is applied to the deep features which is a foremost plan to handle network difficulty and subset decision. In this work, L1-norm technique majorly used for subset decision. Deep narrowing plan is put in to the mean square error and adding the penalizing part by a direct degeneration method and allocate nullify value to all other unrelated features to avoid the repetitions in the system. To make the system complex free and stable the network consider only the non-zero coefficient values which in term minimize the error function. Equations 19.6 and 19.7 explains the concept to bring down the model complexity along with the penalty part. Also, these equations reduce weights to handle the model for accurate result for the given training data.

P = k \sum_{i=1}^a |w| \quad (19.6)
