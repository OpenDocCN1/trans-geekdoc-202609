# ## 7.2 Overview of the Proposed System

The proposed system is developed to extract contour based and region based features and synthesize them using an effective similarity measure. The system works into two modes. In the first mode, offline database is constructed, which contains features set along with image information. The features are extracted by ZMs (magnitude and phase) and Hough transform (histograms) based approaches. In online mode, the features of test image are obtained and equated with that of all the images of training set. The compared images are tiered as per their relevance to the test image and presented to the user. A general procedure of feature extraction and similarity matching is given in Figure 7.1.

# ## 7.3 Proposed Hybrid-Shape Descriptors

The extraction of appropriate features is required for describing an image effectively. In the proposed system, we consider both global and local features to enhance the accuracy of the image retrieval system. The global features are intended to represent the entire configuration of the image shape, whereas local features determine the interior details of the image edge map. In our system, we utilize ZMs magnitude and phase coefficients to describe global features of images. Local features are described by detecting edge lines over the image contour using Hough transform.
