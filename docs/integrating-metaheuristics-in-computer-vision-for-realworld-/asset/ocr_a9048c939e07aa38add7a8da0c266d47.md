# 17.5.5 Distance Reciprocal Distortion Metric

The Distance Reciprocal Distortion Metric (DRDM) is a metric used to quantify the quality of an image. The DRDM measures the degree of distortion between an input image and its corresponding output image. It takes into account the distortion caused by the image processing algorithm used for enhancement. The metric calculates the distance between the input and output images, and then computes the reciprocal of that distance [17]. The DRDM formula for enhancement of an image can be expressed as follows:

$$DRDM = \frac{1}{D}$$ (17.5)

where D is the distance measure between the input image I and its corresponding output image O after enhancement. The distance measure can be any standard measure of image distortion such as mean squared error (MSE), peak signal-to-noise ratio (PSNR), or Structural Similarity Index (SSIM). For example, if we use MSE as the distance measure, then the DRDM formula can be written as:

$$DRDM = \frac{1}{MSE(I,O)}$$ (17.6)

Similarly, if we use PSNR as the distance measure, then the DRDM formula can be written as:

$$DRDM = \frac{1}{PSNR(I,O)}$$ (17.7)

And if we use SSIM as the distance measure, then the DRDM formula can be written as:

$$DRDM = \frac{1}{SSIM(I,O)}$$ (17.8)

In all cases, a higher value of DRDM indicates a better quality enhancement, since it means that the distortion between the input and output images is lower.
