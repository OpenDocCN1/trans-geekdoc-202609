I(X;Y) = \sum_{x \in X,y \in Y} p(x,y)log\left(\frac{p(x,y)}{p(x)p(y)}\right)

As a result, X represents the feature and Y the desired result. P(x,y) is the joint probability distribution of X and Y, whereas there are p(x) and p(y) for the marginal probability distributions of X and Y, respectively.

# 6.2.1.1.3 Chi-Squared Test

Two category variables are tested for independence using this method. By contrasting the observed and anticipated frequencies, it determines the dependence between two categorical variables.

Making a contingency table, which displays the distribution of the dataset's two categorical variables, is the first stage in this procedure. The contingency table, which is a matrix, shows the number of observations for each grouping of the two variables. The contingency table would be a 3x3 matrix, for instance, if we had two variables, A and B, with three categories each.

On the basis of the presumption of independence between the two variables, the predicted frequencies of each category are then determined. The sum of the squared discrepancies between the observed and anticipated frequencies, normalised by the expected frequencies, is then used to generate the chi-squared statistic. It produces a statistic with a chi-squared distribution.

Thus, the above three techniques are common methods for calculating relevance scores.

# Step 3: Ranking Features

The features are then ranked according to the determined relevance ratings for each characteristic. The feature that received the greatest relevance score comes up on top, and so on.

# Step 4: Feature Selection

The top features are chosen in the last step based on relevance scores. The task and machine learning algorithm employed determine how many characteristics are chosen. Selecting the top k features—where k is either a predetermined number or is chosen via the use of cross-validation techniques—is a frequent strategy.

# 6.2.1.2 Advantages

The fact that feature selection can increase the precision of machine learning models [9] is one of its key benefits. The model can concentrate on the key elements that have the greatest influence on the target variable by choosing only the most pertinent attributes. Better prediction performance may result from this, especially if the dataset contains many features or noisy data.

It can boost the effectiveness of machine learning models, which is another benefit of feature selection. The model can be trained more rapidly and with less CPU resources if the dataset's feature count is decreased. This can be very useful when producing projections that are made in real time or very near to real time.
