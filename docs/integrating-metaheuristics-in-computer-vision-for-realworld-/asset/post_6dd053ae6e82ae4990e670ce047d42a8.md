
### 6.3.1.4 Disadvantages

- 5) Handling multicollinearity: Multicollinearity occurs when there is a significant relationship between two or more predictor variables in a model. This may result in unstable regression coefficients and inflated standard errors in the data analysis. PCA can be used to identify and deal with multicollinearity by transforming the data into a lower-dimensional space where the correlations between the variables are minimized.

- 6) Improving interpretability: PCA can also make the data easier to interpret. It may be simpler to comprehend the link between the variables and the observations by lowering the size of the data. This can aid in making data-based judgements that are better informed.

## 6.3.2 Linear Discriminant Analysis

To determine the linear combination of traits that best distinguishes between several classes in a dataset, linear discriminant analysis (LDA), a dependable and well-liked machine learning technique, is applied.

### 6.3.2.1 Concept

The fundamental objective of LDA is to identify a linear feature combination [15] that maximises the separation between different classes in a dataset. In other words, LDA looks for new features that outperform the original collection of features in differentiating across classes in a dataset.

The model can only be trained with labelled data because LDA is a supervised learning technique. LDA makes the assumption that the dataset has a normal distribution and that each class has its own mean and covariance matrix.

The basic objective of LDA is to project the data onto a lower-dimensional subspace that maximises the separation between different classes. The eigenvectors of the within-class scatter matrix and between-class scatter matrix are calculated to do this.

The distance between the means of several classes is calculated using the interclass scatter matrix. The within-class scatter matrix is used to compute the variance for each class. The data is then applied to these matrices' eigenvectors in order to map it onto a lower-dimensional subspace.

### 6.3.2.2 Implementation

The following stages can be used to divide up LDA implementation:

- 1) Data Preparation: The preparation of the data is the first step in adopting LDA. The dataset must be split into training and testing sets in order to accomplish this, and the data must then be annotated with the proper classes.
- 2) Calculate the mean vectors: The average of all the data points inside a class is used to calculate the mean vector for that class.
- 3) Determine the within-class scatter matrix: Add the covariance matrices for each class to get the scatter matrix within each class.
- 4) Calculate the between-class scatter matrix: The outer products of the mean vectors representing the differences between each class are added to produce the interclass scatter matrix.
- 5) Calculate the eigenvectors and eigenvalues: The inverse of the within-class scatter matrix times the between-class scatter matrix is used to get the matrix's eigenvectors and eigenvalues.
- 6) Choose the top k eigenvectors: A new matrix is created using the top k eigenvectors with the highest eigenvalues.
- 7) Transform the data: After being transformed, the data is then projected into the newly created subspace created by the chosen eigenvectors.
- 8) Train the model: Using the altered data, a classifier is lastly developed to forecast the class labels of fresh data points.

### 6.3.2.3 Advantages

- 1) Reduces dimensionality: LDA is a good way to make a dataset's dimensions less. LDA can streamline the data and make it simpler to analyze by projecting it onto a lower-dimensional subspace.

- 2) Improves accuracy: By minimizing the impact of unimportant features and maximizing the impact of pertinent features, LDA can increase the accuracy of a classification model.

- 3) Handles multicollinearity: LDA can handle multicollinearity, which is a common problem in multivariate analysis when two or more variables are highly correlated.

- 4) Handles small sample size: Small sample sizes, a typical issue in machine learning, can be handled via LDA. LDA can assist in preventing overfitting and enhancing the model's generalizability.

### 6.3.2.4 Disadvantages

- 1) Assumes normality: LDA takes the data's normal distribution for granted, which may not always be the case. The outcomes of LDA could not be accurate if the data are not regularly distributed.

- 2) Assumes linearity: LDA makes the assumption that there are linear links between the characteristics.

## 6.4 Feature Learning

Feature learning includes removing pertinent representations or features from the raw data in order to improve the performance of machine learning models. In traditional machine learning approaches, features are manually designed by experts in the field and are used as input to the model. However, with feature learning, the model learns these features from the raw data, thus automating the process of feature selection and design.

There are various kinds of feature learning methodologies [16], including deep learning approaches, supervised and unsupervised learning, and others.

### 6.4.1 Supervised Learning

The process of extracting features from labelled data is known as supervised feature learning. A model must be trained in order to determine a mapping function between the input features and the output labels. The learned features can then be fed into a different prediction classifier model.

Figure 6.3 serves as an illustration of supervised feature learning.

The approach begins with a dataset including both input features and output labels. A training set and a testing set are created from the dataset. The testing set is used to evaluate the feature learning model's performance after it has been trained using the training set.

Examples of feature learning models that use input features as input include convolutional neural networks (CNNs), which are trained to learn a mapping function between the input features and the output labels [17]. A set of learnt features that capture the crucial information in the data is the result of the feature learning model.

The taught features are then applied to a different classifier model, such as a support vector machine (SVM) [18], which is trained to forecast the output labels based on the learned characteristics. The output of the classifier model is the projected labels for the input data.
