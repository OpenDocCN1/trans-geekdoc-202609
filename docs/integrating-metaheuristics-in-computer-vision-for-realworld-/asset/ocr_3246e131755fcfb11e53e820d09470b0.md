The Robert Edge Detector should have the following characteristics:

+   - The resultant edges should be well defined
+   - Edges produced must of little noise
+   - The intensity of the edges must be relatively equal to the human perspective

The prevailing method of Robert operator proposes the following equations:

```
$$y_{i,j} = \sqrt{x_{i,j}}
z_{ij} = \sqrt{(y_{i,j} - y_{i+1,j+1})^2 + (y_{i+1,j} - y_{i,j+1})^2}$$
```

where x is the intensity value, z is the computed derivative and i,j denotes the location of an image.

# 11.2.2.3.1 Working Mechanism

Robert operator mechanism first process original image combined with two kernels.

```
$$\begin{bmatrix} +1 & 0 \\ 0 & -1 \end{bmatrix} \text{ and } \begin{bmatrix} 0 & +1 \\ -1 & 0 \end{bmatrix}.$$
```

Here, I(x,y) denotes the original image [3], Gx(x,y) is the point in the image convolve with first kernel and Gy(x,y) is the point convolve in the second kernel. The magnitude of the gradient is computed by,

```
$$\nabla I(x, y) = G(x, y) = \sqrt{G_x^2 + G_y^2}.$$
```

and the direction of the gradient is given by,

```
$$\Theta(x, y) = \arctan\left(\frac{G_y(x, y)}{G_x(x, y)}\right) - \frac{3\pi}{4}.$$
```

A vertical orientation with an angle of 0° means that the direction of maximum contrast from black to white runs from left to right on the image.

# 11.2.2.3.2 Robert Operator Architecture

Roberts’ operator is made up of two 2 x 2 convolution kernels that are orthogonal to each other [2]. These masks, one for each of the two perpendicular orientations, are designe-d to respond maximally to edges running at 45° to the pixel grid [8].
