# 19.3.1 Preprocessing

In preprocessing, the first and foremost step is adaptive histogram equalization (C-LAHE). The advantage of this method is to even up the image for better intensity. CLAHE is a form of adaptive histogram equalization (ALE) method. ALE method does the contrast stretching but the result is very narrow. Therefore, to diminish this problem of noise addition, CLAHE does histogram equalization in small patches or in small blocks with high precision and contrast limiting. After this step, lee filter is used to remove the speckle noise.

# 19.3.2 Noise Removal With Lee Filter

Lee filtering is a method used to find the range of error using filtering technique. This technique filters out the data based on the information which calculates the value inside the windows individually. Unlike a normal low-pass based smoothening filter, the Lee filter and other type of sigma filters save the image sharpness and details while extinguishing the noise. After this, the evaluated filtered pixel values are restored by a value planned by the accessible pixel values. It is one of the most common techniques to filter out the speckle noise from SAR images. Equation (19.1) gives the filter evaluation formula

```
I(t) = R(t)v(t) (19.1)
```

Note that, I(t) – Full noise image and R(t) – Noise free Image with basic backscatter property, v(t) - speckle noise and also it is not dependent on R(t).

```
R̂(t) = Ī(t) + W(t)(I(t) − Ī(t)) (19.2)
```

where W(t) – weighting function and it is given by

```
W(t) = 1 − Cv / Cl (19.3)
```
