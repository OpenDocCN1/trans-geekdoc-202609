# ### 18.3.5.1 Minimum Distance Classifier

The Minimum Distance Classifier (MDC) classifies unknown picture data into classes that minimize multi-feature space distance. The minimum distance equals the maximum similarity given by Equation (18.9)

\(\displaystyle D(i) = \sum_{j=1}^{p} abs[f_j(x) - f_j(i)]\) (18.9)

fj(x) denotes the jth characteristic of an unidentified image class (x), and fj(i) denotes the jth characteristic of the ith class image. P is the total number of attributes employed, and i = 1 to Q (Q denotes the total number of subclasses in the collection). # ### 18.3.5.2 SVM

The SVM algorithm sub-divides input samples into lines or hyperplanes. It solves classification and regression problems. Classification applications use it often. In this method, the coordinate measurement for every attribute is used to depict a point representing a data item in a space with n dimensions [42]. Then, the hyperplane that clearly differentiates the two classes was used to classify them. Hyperplanes in n-dimensional Euclidean spaces are flat, n-1-dimensional subsets that divide the space into two separate sections. SVM classifiers have two gamma parameters, “c” adjusts the smooth decision boundary versus training point classification tradeoff. A large “c” signifies more training points correctly. Gamma determines a training example’s impact. Gamma is low if every point has a far reach and high if every point has a near reach.
