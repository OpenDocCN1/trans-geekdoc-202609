+   3. Viola-Jones Algorithm:
+   This is a common face identification technique that identifies faces in images by combining Haar cascades with AdaBoost machine learning. It entails dividing the image into smaller windows and then using Haar cascades to analyze each window for face traits.

+   4. Local Binary Patterns:
+   This is a method for identifying local patterns of pixels in a picture, which may be used to recognize faces. It entails comparing the pixel values of adjacent pixels in a circular radius surrounding each pixel and then encoding these patterns into a feature vector.

+   5. HOG:
+   This approach examines the gradient of pixel intensities in a picture to extract features. It entails breaking down the picture into small cells and computing the gradient direction and magnitude inside each cell, which may then be utilized to identify faces based on their distinct texture and form [11].

+   a. Haar Cascades:
+   Haar cascade is a face identification system that is based on machine learning. Viola and Jones invented it in 2001, and it has since become a popular approach for recognizing objects in photos and movies. The Haar cascade technique analyses a picture at various sizes to look for patterns of characteristics that are indicative of the item being discovered. In the case of face detection, these characteristics are often the form of the eyes, nose, and mouth.
+   
+   The approach employs a collection of predefined classifiers that have been trained on positive and negative picture examples. The positive samples are photographs that include the object of interest, whereas the negative samples are images that do not. The algorithm moves a sliding window across the picture during the detection phase and evaluates each window for the existence of the item. The window is initially processed by a set of feature extraction filters, which collect the important feature patterns. The generated characteristics are then compared to the predefined classifiers to determine if the item is present in the window If the algorithm determines that a window has the item, it will go to the next window and repeat the procedure. Other strategies, such as nonmaximum suppression, may be used by the algorithm to refine the detection findings and eliminate duplicate detections. The Haar cascade technique is frequently utilized in domains like as surveillance, robotics, and computer vision because it is effective at recognizing objects in real-time applications.

+   b. Convolutional Neural Network:
+   A Convolutional Neural Network (CNN) is a deep learning neural network that is extensively used in image identification, object detection, and segmentation tasks in computer vision. It employs a number of convolutional layers to automatically learn features and patterns in pictures. A CNN's architecture is often made up of numerous layers, such as convolutional layers, pooling layers, and fully linked layers. A CNN receives an image as input, which is then processed by the network to extract features at various levels of abstraction. A CNN's first layer is often a convolutional layer that applies a collection of filters to the input picture to generate a set of feature maps.
