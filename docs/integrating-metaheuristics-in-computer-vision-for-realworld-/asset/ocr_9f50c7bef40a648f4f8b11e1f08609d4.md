# 15.4.2.1 Performance Metrics

An accurate performance measurement is required to compare various image retrieval techniques. Precision and recall can be used to assess how well CBIR performs.

# 15.4.2.1.1 Precision

The precision is a proportion of the total number of photos extracted to the relevant images. Every result returned by a search was meaningful if the precision value was 1.0.

# **Precision = (No. Of relevant Image Retrieved) / (Total No. Of Image Retrieved)**

The Graph makes it obvious that precision is increasing for every class after each repetition. After the second iteration, high precision for the class Flower of roughly 65% is attained. By considering that there were 12 total photos retrieved, the precision is determined. Figure 15.5 shows the precision calculation.

# 15.4.2.1.2 Recall

Recall is the proportion of relevant images that were successfully retrieved to all of the relevant images that were present in the database. When the search yielded a flawless Recall value of 1.0, all pertinent documents were located. Additionally, it assesses how quickly the CBIR system locates all pertinent images during a search for a query image.

# **Recall = (No. Of relevant Image Retrieval) / (No. Of relevant image in Database)**
