## 19.4.1 Classification Performance Evaluation

The performance metric is calculated using various parameters like recall, precision, accuracy, specificity, and F1 score and the results are compared with other network models as well. Based on the performance the system can set on the true positive, true negative, false positive, and false negative. The formula to calculate the parameters are given below Recall, precision, accuracy, and F1 score are defined as follows,

recall = \(\frac{TP}{TP + FN}\)

precision = \(\frac{TP}{TP + FP}\)

accuracy = \(\frac{TP + TN}{TP + FN + FP + TN}\)

specificity = \(\frac{TN}{FP + TN}\)

F1 Score = \(\frac{2TP}{2TP + FP + FN}\)

## 19.5 Conclusion

In the automatic classification technique removing unwanted noises and background is more difficult. In order to remove the artifacts and improve the accuracy, we proposed the L1-IDNN model. This method is used for classification technique for thyroid nodules in echography images. The proposed method employs inception v3 architecture and improved training method. Therefore, the proposed model compares the method with other networks and suggests that the proposed model produce very good accuracy and relevant parameters are compared to other networks effectively. Obtained accuracy value 96.85%, which is much higher than any other network. Also, precision and specificity are 100% with proposed L1-IDNN model with efficient deep features and inception v3 network.
