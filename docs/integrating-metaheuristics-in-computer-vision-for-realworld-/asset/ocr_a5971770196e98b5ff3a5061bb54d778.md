# 17.6.3 Distance Reciprocal Distortion Metric

DRDM is a metric used to measure image quality. DRDM measures the degree of distortion between an input image and an output image. It takes into account the distortions caused by the image processing algorithms used to develop it. This measure calculates the distance between the input and output image and then calculates the inverse of this distance. A higher DRDM value will perform better as it means less interference between the input and output images [17].
