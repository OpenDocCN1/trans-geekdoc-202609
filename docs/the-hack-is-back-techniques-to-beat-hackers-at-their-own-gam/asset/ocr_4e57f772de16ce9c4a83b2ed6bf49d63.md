One final thing to mention about the security on your Window’s devices regarding the Administrator account that might not be obvious. The built-in Administrator account cannot be locked out for obvious reasons, like losing your ability to access the system permanently. On the Windows client systems, like Windows 10 and 11, this account is disabled by default. However, in the server operating systems like Server 2019 and Server 2022, this account is active and can be exploited because it will accept hundreds and thousands of incorrect logins and still let you keep trying, In the example below, I tried 182,899 different passwords and then finally successfully got the administrator password of P@ssw0rd.
