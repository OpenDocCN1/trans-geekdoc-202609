# SELECTING AN EXPLOIT MODULE

Once the **msfconsole** window has appeared, we can search for specific exploits using the **search** command. For this example, we will search for the name of a program called ChurchInfo to identify if a module is available. The command to run in this instance is **search churchinfo** which returns one module.

![](bbox=[0.107, 0.701, 0.893, 0.815])

**FIGURE 6.5**  Searching for ChurchInfo shows that one module is available for use.

To use an exploit that we’ve identified with the search function, we can copy and paste the module’s name and select it with the “use” command, such as **use exploit/multi/http/churchinfo_upload_exec**. As noted in the information returned by Metasploit, we can also select a module from the search window to use with its number provided – this proves to be much faster and simpler than typing out the full name of the module. Instead, we can simply provide the module number within the “use” command such as **use 0**, which will select the module number 0 from our search results.
