Finally, we will take a look at the open ports on our Linux system and then close any ports that have unnecessary services that don’t need to be running. The tool nmap works on Windows but it was built and compiled for Linux, so it works best on Linux systems. It can be easily installed using apt-get or yum depending on the fork of Linux you are utilizing. Like with Windows, you can also use netstat to view the listening ports. Just use grep instead of the find command to parse the output of the command.

Run the following commands to see what ports are open on your Linux system:

```
nmap 127.0.0.1 -p 0-65535       -> checks to see what Transmission Control (TCP) Ports are open
netstat -tan | grep LISTENING  -> shows a list of open ports with the built-in netstat command
```
