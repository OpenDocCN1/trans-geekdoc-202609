

## 黑客卷土重来

以其人之道还治其人之身：击败黑客的技术

Jesse Varsalone and Christopher Haller

![](img/181571ad74cba0e6a2f38fcd2658651e_0_0.png)

你是否曾好奇，黑客和国家级行为者是如何侵入世界上一些最受保护的系统与网络，获取机密信息的？他们从哪里学到这些技术，又是如何不断磨练以实现其目的？我该如何进入网络安全行业并成功应聘？我们将探讨并举例说明黑客使用的一些恶意技术，并介绍攻击者如何在实际中运用这些方法。

《黑客卷土重来》既面向初学者，也面向有志于网络安全专业人士，帮助他们学习这些技术，以评估和发现计算机系统及网络中的风险。本书将有益于进攻导向的黑客（红队成员），也有益于专注于防御的人员（蓝队成员）。本书提供了真实案例、动手练习以及对黑客世界的内幕洞察，包括：

- 入侵我们自己的系统以学习安全工具
- 评估 Web 应用程序的弱点
- 识别漏洞并获取 CVE
- 在 Linux、Windows 以及 Active Directory 环境中提升权限
- 通过跨 TOR 网络路由进行欺骗
- 如何搭建一个逼真的黑客实验室
- 展示如何发现失陷指标
- 在网络安全领域获得聘用！

本书将为读者提供成为高效黑客所需的工具，同时介绍如何通过检查系统行为和痕迹来检测黑客。按照这些章节中详细而实用的步骤操作，读者将获得宝贵的经验，使自己成为更出色的攻击者和防御者。作者们曾在该领域工作、与网络团队竞赛并指导他们、担任导师、拥有多项认证，并且对网络安全领域充满热情，他们将在本书中演示各种攻防技术。
