# WADComs

The WADComs project is similar to the GTFO-bins project and provides a phenomenal reference for using various programs to evaluate a Windows environment. The sheet is available at https://wadcoms.github.io/ and is an exceptionally useful reference. By providing an interactive interface, users can browse how to leverage offensive security tools related to Windows and AD environments.

The cheat sheet is organized to allow interactive ways to determine how to use the resources based on the level of access, services, OS, and attack type. Starting with No Creds, we can determine what types of information or access we might be able to gain. Not only do we have a list of commands, but also a set of tags to help organize if these should be run from a Windows or a Linux machine.
