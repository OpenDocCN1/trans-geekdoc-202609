# ## Running the Exploit

Once the exploit and payload are configured, we can run the exploit with two different commands. These commands are **run** and **exploit**, which are functionally the same command. This runs the exploit modules with the options we have configured and notifies us how the module exploitation process occurs. Knowing that a vulnerable ChurchInfo program is available at the IP 192.168.1.72, we can run the exploit to see if we gain access.
