I recommend using VMware Workstation for Windows or Linux and VMware Fusion for Macs, software which is now free as of 2024. You can download it for Windows, Linux, or Mac, at the following link: https://www.vmware.com/products/desktop-hypervisor.html.html.html. Please note that It is only free for non-commercial use. The main reason I advise people to use it over Oracle Box is that a familiarization with VMware can be extremely beneficial if the IT Organization you work for has vSphere and Elastic Sky X Integrated (ESXi) servers. Being familiar with VMware Workstation (Player) networking and configuration can make it an easier transition to working with VMware vSphere in corporate environments.
