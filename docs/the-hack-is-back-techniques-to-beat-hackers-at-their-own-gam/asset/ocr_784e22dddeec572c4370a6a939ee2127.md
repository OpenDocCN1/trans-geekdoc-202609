Once we’re logged into the application, we’ll need to upload data to review it. This can be done by clicking the link on the initial page to be directed to the File Ingest page.

On the File Ingest page, we can click the UPLOAD FILE(S) button to open an upload page. Note that we cannot drag the entire ZIP file to upload it, but we must unzip the collected data first. Once unzipped, we can drag the extracted JSON files into the upload window.
