Finally, we will examine how to stop these services and prevent them from running automatically at startup. You can use the service command followed by the service name and stop, start, restart, or view the status of a service. You can use the update-rc.d command to enable or disable services at startup.

Run the following commands to stop services and stop them at system startup

```
service vsftpd stop              -> stops the service
update-rc.d vsftpd disable       -> disables the service at startup
```
