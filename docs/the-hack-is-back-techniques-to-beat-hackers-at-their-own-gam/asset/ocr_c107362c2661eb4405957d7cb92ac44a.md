When you boot to the installation media, you are able to access the command prompt without any type of authentication. You will know that you are in the right place, when you see an X:\Sources> prompt. At that prompt, you will type the following command to keep a copy of the legitimate file so you can replace it later if needed. `copy C:\Windows\System32\cmd.exe C:\Windows\System32\Utilman.1` Then, type `copy C:\Windows\System32\cmd.exe C:\Windows\System32\Utilman.exe`. Click Y to replace the file. After that, close your command prompt by clicking the red X in the top right corner and then click Continue to Windows.
