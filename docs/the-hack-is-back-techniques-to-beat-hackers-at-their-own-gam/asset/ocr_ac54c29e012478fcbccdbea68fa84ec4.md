# DISABLING ANTI-VIRUS

The next thing we are going to do is disable the built-in Windows Defender Antivirus. We will need to do this so we can dump the password hashes. To disable antivirus in Windows, perform the following steps:

+   1. Type Windows Security in the start search box and click open app (Figure 1.14).
+   2. Next, we will tweak the Virus and Protection Settings. Click Virus and Protection Settings, and then click Manage Settings under the Click Virus and Protection Settings (Figure 1.15).
+   3. It is very likely that Real-time Protection, Cloud-delivered Protection, and Automatic sample submission will all be turned on. We will need to turn all three of them off, as seen in Figure 1.16.
