**Brief of TFX Components:** A component handles a more complex process than just the execution of a single task. All machine learning pipeline components read from a Channel to get the input artifacts from the metadata store. The data is then loaded from the path provided by the metadata store and processed. The output of the component, the processed data, is then provided to the next pipeline components. The generic internals of a component are always as follows:

+   - Receive some inputs
+   - Perform an action
+   - Store the final result
