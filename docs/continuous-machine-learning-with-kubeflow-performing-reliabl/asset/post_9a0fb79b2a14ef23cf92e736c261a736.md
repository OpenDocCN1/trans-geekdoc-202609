Wandb offers to log the metrics for our training loss or accuracy as your model trains (in many cases, we provide the framework-specific defaults). It logs more complicated output or results like histograms, graphs, or images with

```
def train_logs():
```

### Save Files:

Anything which was saved in the **wandb.run.dir** directory, will be uploaded to Weights & Biases and saved along with our run when it completes training, which is convenient for saving the literal Weights & Biases for our trained model. By default, this will save to a new subfolder for the files associated with your run, created in **wandb.run.dir** (which is **./wandb** by default).

```
wandb.save("mymodel.h5")
```

We can pass the full path to the Keras or Tensorflow model API.

```
model.save(os.path.join(wandb.run.dir, "mymodel.h5"))
```
