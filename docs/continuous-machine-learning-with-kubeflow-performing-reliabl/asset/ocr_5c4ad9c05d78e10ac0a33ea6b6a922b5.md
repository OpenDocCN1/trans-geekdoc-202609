# 1.2.4 How do Kubernetes work?

A cluster is the foundation of **Google Kubernetes Engine** the Kubernetes objects that represent your containerized applications all run on top of a cluster. In GKE, a cluster consists of at least one control plane and multiple worker machines, called nodes. These control plane and node machines run the Kubernetes cluster orchestration system.
