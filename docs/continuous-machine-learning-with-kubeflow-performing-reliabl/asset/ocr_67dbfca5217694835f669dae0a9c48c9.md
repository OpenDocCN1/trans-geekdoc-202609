# Ephemeral Storage

Ephemeral data storage is different from Docker. In Kubernetes, the volume is taken into account in any containers that run within the pod, and the data is stored across the container. But, if the pods get killed, the volume is automatically removed.

# Persistent

The data remains for the lifetime. So, when the pod dies or it is moved to another node, that data will still remain
