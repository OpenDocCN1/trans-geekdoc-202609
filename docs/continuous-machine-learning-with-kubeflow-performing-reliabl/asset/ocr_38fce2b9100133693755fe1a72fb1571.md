# START RUNNING THE TENSORFLOW SERVING

This is where we start running the TensorFlow Serving and load our model. Once it loads, we can start making the inference requests using REST. There are some important parameters, which are as follows:

The port that you'll use for the REST requests.

You'll use this in the URL of the REST requests. It can be anything.

This is the path to the directory where you've saved your model. Note that this **base_path** should not include the model version directory, which is why we split it off as follows:

```
os.environ["MODEL_DIR"] = os.path.split(latest_pushed_model)[0]
%%bash --bg
nohup tensorflow_model_server \
--rest_api_port=8501 \
--model_name=online_news_simple \
--model_base_path="${MODEL_DIR}" >server.log 2>&1
!tail server.log
```
