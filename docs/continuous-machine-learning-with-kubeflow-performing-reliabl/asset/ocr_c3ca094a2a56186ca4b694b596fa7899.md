# 4.4.7.1 Fairness and TFMA Visualization

**TensorFlow Model Analysis** helps to get more detailed metrics than just those used during the model training. TFMA visualizes the metrics as the time series across the model versions, and it gives us the ability to view the metrics on the slices of a dataset. It also scales easily to large evaluation sets, thanks to the Apache Beam.

```
%%skip_for_export
context.show(evaluator.outputs['evaluation'])
```
