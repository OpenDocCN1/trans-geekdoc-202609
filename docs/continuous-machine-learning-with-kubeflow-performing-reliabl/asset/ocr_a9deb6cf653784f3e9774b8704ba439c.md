Pods also contain shared networking and storage resources for their containers:

Pods are automatically assigned unique IP addresses. Pod containers share the same network namespace, including the IP address and network ports. Containers in a Pod communicate with each other inside the Pod on localhost.

Pods can specify a set of shared storage volumes that can be shared among the containers.
