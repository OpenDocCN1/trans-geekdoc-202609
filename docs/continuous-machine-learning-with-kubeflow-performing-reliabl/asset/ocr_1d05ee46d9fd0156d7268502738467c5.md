Now, let’s deploy it with the command line; and first let’s fill the yaml file:

```
apiVersion: serving.kubeflow.org/v1alpha2
kind: InferenceService
metadata:

labels:
controller-tools.k8s.io: "1.0"
name: kfserving-wandb-lightgbm-model
namespace: kubeflow
spec:
default:
predictor:
custom:
container:
image: gcr.io//<_TAG>
imagePullPolicy: Always
name: user-container
```

Here, in the preceding yaml file, we gave the same name which we had provided in the lightgbm_wandb.py file; it will be and then we provided the namespace “kubeflow” where it is deployed. Next, we gave the Docker image a name for our Transformer model which we had created.
