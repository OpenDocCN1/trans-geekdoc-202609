**max_bin default = type = constraints: max_bin > 1** so, the maximum number of bins that feature values will bucket in, and the small number of bins will reduce the training accuracy but it may increase the general power (deal with over-fitting).

**boosting_type** is choosing the algorithm technique traditional Gradient Boosting Decision Tree.

**Num_leaves** it is the maximum number of leaves in one tree.

https://lightgbm.readthedocs.io/en/latest/Parameters.html
