STEP 3: In this step, we will write one heading with the st.write() function, and we will set some depreciation option. Next, we will upload the image in any format of jpg, png, and so on, so the st.file_uploader() object will be stored inside

```
st.write("This Web App is to help convert your photos to realistic images")
st.set_option('deprecation.showfileUploaderEncoding', False)
file_image = st.sidebar.file_uploader("Upload your Photos", type=['jpeg','jpg','png'])
st.set_option('deprecation.showfileUploaderEncoding', False)
```
