# 1.1 Docker understanding

Docker is a platform for the developers and system admins to build, run, and share the applications with the containers. The containers used to deploy the applications is called containerization. To deploy the applications, the containers are making things easier and flexible.

Containerization is increasingly becoming popular because the containers have the following features:

We can containerize the most complex applications as well.

We can distribute the container replica’s process across a data center automatically.

The containers make things more efficient than the Virtual machines by sharing and leveraging the host kernel.

Due it’s portable nature, we can build them locally, deploy to the cloud, and run it from anywhere.

**Loosely** They are highly independent and encapsulated, which allows us to replace or upgrade anyone without disrupting others.
