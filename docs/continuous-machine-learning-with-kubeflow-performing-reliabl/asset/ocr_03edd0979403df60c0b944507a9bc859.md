# 7.3.2 Create an Amazon SageMaker Notebook Instance

Navigate to the Amazon SageMaker console > Notebook instances > create notebook instance. The steps are as follows:

On the Create notebook instance page, provide the following information (if a field is not mentioned, leave the default values):

In the Notebook instance name section, type a name for your notebook instance.

Then, for the Instance type, choose This is the least expensive instance type and is the recommended type for the notebook instances support.
