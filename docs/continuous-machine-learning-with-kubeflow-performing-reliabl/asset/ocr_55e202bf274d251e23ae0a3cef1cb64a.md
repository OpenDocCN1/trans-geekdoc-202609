
In the constructor, you can specify the following parameters:

The AWS **Identity and Access Management** role that Amazon SageMaker can assume to perform tasks on our behalf (for example: it can read the training results, it can call the model artifacts from our S3 bucket, and it can write the training results to Amazon S3). This is the role that we got in during the creation of Notebook instance.

**train_instance_count** and So, think of the type and number of ML compute instances that we use for the model training; here, we have to use only a single training instance.

This is the size, in GB, of the **Amazon Elastic Block Store** storage volume which will attach to the training instance. It must be large enough to store our training data if you use the file mode, which is default.
