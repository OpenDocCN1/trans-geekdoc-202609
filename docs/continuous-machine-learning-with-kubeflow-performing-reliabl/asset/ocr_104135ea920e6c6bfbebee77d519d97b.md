# 7.3.1 Create an S3 Bucket

Now, the training of a model will produce the following:

The model training data which is transformed is stored in S₃.

Model artifacts, which the Amazon SageMaker generates during the model training.

We can save all these things in the **Amazon Simple Storage Service** bucket; we can store the datasets that we have used during our training data and the model artifacts that are the output of a training job in a single bucket or in two separate buckets.
