

## 研究步骤

| 步骤 | 描述 | 详细内容 |
| :--- | :--- | :--- |
| **1** | 利用现有理论选择潜在的直接和间接预测变量，用于安全合规行为研究。 | 确定了网络安全合规行为的一些潜在直接和间接变量，包括：安全合规行为、安全意识、一般安全取向、安全自我效能感和决策风格。 |
| **2** | 收集相关数据。 | **2.1 开发适当的数据收集工具**<br>1. **非 DSI 基础变量**：条目改编自先前研究，用于测量安全合规行为、安全意识、一般安全取向和安全自我效能感。这些构念采用反射性测量，基于 5 点李克特量表（1 = “强烈不同意”，5 = “强烈同意”）。<br>2. **DSI 基础变量**：采用了 [Rowe and Mason (1987)](#ch6.xhtml#ref6_73) 提出的 20 项标准决策风格量表（DSI）问卷，用于测量个体的决策风格。<br>**2.2 数据收集**<br>通过基于 Web 的调查从 105 名参与者处收集数据。 |
| **3** | 进行探索性因子分析。 | 探索性因子分析仅针对反射性测量的潜在预测变量进行。在四个网络安全相关的潜在预测变量（即安全合规行为、安全意识、一般安全取向和安全自我效能感）中，提取出五个因子，解释了原始变量中最大部分的方差，即：`password compliance behaviour`、`general security compliance behaviour`、`general security awareness`、`general security orientation` 和 `security self-efficacy`。 |
| **4** | 利用决策树诱导技术对给定数据集进行递归划分以生成规则集。从决策树诱导结果中归纳假设。使用 [Osei-Bryson & Ngwenyama (2011)](#ch6.xhtml#ref6_66) 提出的方法生成同胞规则假设。 | **4.1 每个因变量作为目标：**<br>1. 对每个因变量（即 `PWCB`、`GSCB`），进行决策树诱导（DTI），将该因变量作为目标变量，将所有其他非因变量（即 `SLEF`、`GSOR`、`GSAW`、`DomDS`、`DomOR`）作为潜在预测变量。<br>2. 基于生成的决策树，生成同胞规则假设并进行统计评估。<br>3. 为每个经统计分析支持的同胞规则假设生成一个暂定因果链接。<br>4. 仅为那些提供了合理逻辑解释的暂定因果链接，归纳相应假设以纳入模型。<br><br>**4.2 每个潜在中介变量作为目标：**<br>1. 每个非决策风格的潜在预测变量（即 `SLEF`、`GSOR`、`GSAW`）若非因变量，则视为暂定中介变量。进行决策树诱导（DTI），将各暂定中介变量作为目标变量（即 `DomDS`、`DomOR`），将决策风格基础变量作为潜在预测变量。<br>2. 基于生成的决策树，生成同胞规则假设并进行统计评估。<br>3. 为每个经统计分析支持的同胞规则假设生成一个暂定因果链接。<br>4. 仅为那些提供了合理逻辑解释的暂定因果链接，归纳相应假设以纳入模型。 |
| **5** | 包含先前提出的假设。 | 1. 利用现有理论识别相关假设及相应的因果链接，其中每种情况下的前因和后果均为非决策风格潜在预测变量（即 `SLEF`、`GSOR`、`GSAW`）或因变量。<br>2. 将每个此类假设纳入模型。 |
