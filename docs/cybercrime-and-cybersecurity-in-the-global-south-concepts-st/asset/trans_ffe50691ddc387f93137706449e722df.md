
# 全球南方：互联网增长与网络安全挑战

全球南方不仅被公认为互联网人口增长最快的地区之一，也是占据互联网用户绝大多数的地区。例如，据报道，全球南方的一个地区——拉丁美洲和加勒比地区（LAC），在2013年拥有1.47亿互联网用户，互联网人口增速位居世界首位，且此后每年持续增长（[美洲国家组织，2014](#ch1.xhtml#ref1_16)）。到2016年，国际电信联盟（ITU）报告称，全球南方经济体占据了绝大多数互联网用户，用户数达25亿，而发达国家为10亿（[国际电信联盟，2016a](#ch1.xhtml#ref1_9)）。这种加速且持续的增长归因于移动订阅量的巨大增加以及移动宽带渗透率的强劲增长（[国际电信联盟，2016b](#ch1.xhtml#ref1_10)，[2018b](#ch1.xhtml#ref1_12)）。虽然互联网通过信息通信技术（ICTs）的应用，使全球南方能够发展经济、改善生计、分享思想和文化、改进政府和社会服务、在教育、科学和艺术领域开展合作以及开展业务（[国际电信联盟，2018a](#ch1.xhtml#ref1_11)；[美洲国家组织，2016](#ch1.xhtml#ref1_17)），但不容忽视的是，随着对基于互联网的平台和服务的连接性和依赖性日益增强，网络安全（CS）威胁、攻击和漏洞的潜在风险也随之增加。行业媒体报道和学术文献（尽管极少）都证明了这些风险或威胁及其对政府、组织和公民的影响。例如，与2005年相比，2009年网络攻击增幅百分比排名前12位的国家中，有11个来自全球南方，如哥伦比亚749%、印度尼西亚675%和津巴布韦361%（[Kim等，2012](#ch1.xhtml#ref1_15)）。此外，仅在2016年1月至6月这一个六个月期间，电子诈骗就给牙买加经济造成了约5亿美元的损失（[Williams，2016](#ch1.xhtml#ref1_22)）；圣文森特和格林纳丁斯政府网站于2015年被自称当地“伊斯兰国”组织支持者的个人黑客攻击；同样在2015年，一场大规模勒索软件攻击针对税务机关，阻断用户访问系统并勒索钱财；2014年，黑客从牙买加诺瓦斯科舍银行窃取了1.5亿美元（[加勒比共同体，2016](#ch1.xhtml#ref1_3)）。在圣卢西亚的一次会议上，加勒比国家正式承认其未做好充分准备应对网络犯罪，并签署了一项区域网络行动计划（[Kentish，2016](#ch1.xhtml#ref1_14)）。根据该区域计划，“预防和打击网络犯罪需要制定战略、立法、刑事司法和ICT（信息通信技术）专业知识、提高意识以及国际合作，并涉及政治、私营部门和公民社会最高层面的领导力”（[Kentish，2016](#ch1.xhtml#ref1_14)）。尽管与全球南方相关的网络事件是一个关键问题，值得政府各级、组织、个人和学者共同关注，但专门针对全球南方组织和用户、旨在深化我们对这一现象理解的研究非常少。本书旨在填补这一空白。

## 全球南方的中小微企业：经济重要性与安全缺口

尽管全球南方的组织持续采用ICTs来提供服务和开展业务，但鲜有研究涉及情境化于这些发展中经济体的信息安全、网络安全和网络犯罪问题及策略。此外，关于全球南方中小微企业（MSMEs）安全相关关切的研究更是少之又少。根据经济合作与发展组织（OECD）的数据，中小微企业在世界各国经济中发挥着关键作用，创造就业并促进创新（[经济合作与发展组织，2017](#ch1.xhtml#ref1_19)）。更具体地说，中小微企业被认为是世界上最贫穷国家的关键支柱；它们作为经济增长的重要驱动力，占所有企业的大多数（[国际货币基金组织，2015](#ch1.xhtml#ref1_8)）。例如，在加勒比地区，中小微企业部门占私营企业的50%以上，对国内生产总值和就业的贡献均超过50%，并对社会发展做出贡献（[加勒比开发银行，2016](#ch1.xhtml#ref1_2)）。同样，据研究人员称，非洲中小微企业对全球经济至关重要，因为它们的存在和成功创造了“……一个拥有可支配收入的不断壮大的中产阶级，同时为新投资者创造了市场机会”（[de Sousa dos Santos，2015](#ch1.xhtml#ref1_4)）。

尽管做出了这些重大贡献，中小微企业仍 largely 缺乏支持，并继续面临若干主要制约，包括：用于投资和流动资金的金融资源获取不足；商业技能培训缺失；基础设施服务成本高昂；物理基础设施支持不足（例如仓储、厂房和商业空间、工业园等）；提高生产力的技术使用水平低；以及缺乏竞争力（[加勒比开发银行，2016](#ch1.xhtml#ref1_2)）。除了这些挑战，全球南方以及全球北方的中小微企业还面临来自信息和网络安全威胁的额外危险。最近的网络安全统计数据显示，针对小企业的网络攻击比例从2017年的61%上升至2018年的67%，小企业面临的网络安全风险与大公司日益相同（[Ponemon研究所，2018](#ch1.xhtml#ref1_18)）。另一份近期行业报告显示，2018年43%的数据泄露事件涉及小企业受害者（[Verizon，2019](#ch1.xhtml#ref1_20)）。
