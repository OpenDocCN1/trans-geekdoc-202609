
# BCH

BCH 是 Bitcoin Cash 的缩写或首字母缩略词。这也可以被视为其在中心化交易所（CEFI）或去中心化交易所（DEFI）上的加密货币代码。

# Bitcoiner

Bitcoiner 指的是对在投资组合中持有比特币非常自信且看涨的个人或人员。

# BTC

BTC 是 Bitcoin 的缩写或首字母缩略词。这也可以被视为其在中心化交易所（CEFI）或去中心化交易所（DEFI）上的加密货币代码。

# Bits

Bits 是计算中使用的基本单位；它们也用于指代比特币的子单位。一个比特币包含 100 万个 Bits。

# Bag

Bag 就像任何用于携带物品的普通袋子一样。它是加密世界的俚语，指某人或某个人在其投资组合中持有大量特定加密货币。

# Bag Holder

Bag Holder 直接指代投资者或个人，无论市场波动如何，都持有大量特定加密货币在其投资组合中。

# Blockchain

Blockchain 是由中本聪向世界引入的开源软件代码的创新技术，比特币运行于此技术之上。通俗地说，没有区块链就没有比特币、山寨币、NFT 和 DeFi。它由节点（即协同工作的计算机）以密码学方式保护，用于记录所有交易在数字账本中。

这个数字账本被复制并共享到全球各地的整个计算机网络中，任何人都可以验证。尽管它对验证是开放的，但代码通过密码学保护且不可更改。一旦一个区块通过计算机挖矿过程被完成或找到，它们就会被链接在一起，因此称为区块链。每种区块链技术都基于其密码学代码有所不同。

# Block

Block 是使用密码学创建数字交易的软件代码，这些交易被复制并共享到节点和计算机网络中。这些记录的交易存储在不可更改的数字账本中。

在比特币的情况下，区块由计算机和 ASIC 挖矿形成，利用称为工作量证明（P.O.W）的过程。一些山寨币遵循与比特币相同的方法，利用工作量证明来挖掘区块，并在区块完成或在其自身区块链原生币中找到时获得奖励。这些已确认的区块被链接在一起，因此称为区块链。

# Block Reward

Block Reward 正如其名，是为区块提供的奖励。矿工因找到区块而获得奖励。找到区块是指计算机对文件进行哈希或以密码学方式生成唯一代码的过程。每个哈希代码都永远不会相同且不可更改，这使得数据防篡改。每个区块奖励都是其自身区块链原生的币。

# Bitcoin Whitepaper

Bitcoin Whitepaper 是中本聪在 2008 年发明、设计和编写的原始计划和协议。比特币白皮书为世界提供了在处理电子支付时解决基于信任模型问题的答案。

# Bear

Bear 这个词通常指股市，关于资产价格及其价值的前景。它也被加密货币投资者采用，以表示认为加密货币市场价格正在下跌或接近看跌市场。

# Bear Market

Bear Market 指的是一个糟糕的市场，每种币都在失去价值。当投资者因不确定性而恐慌性抛售时，会触发金融市场的下跌，并将价格推至历史新低，形成更低的高点和更低的低点。Bull Market 是 Bear Market 的完全相反。

# BTD

BTD 是 Buy The Dip 的缩写或首字母缩略词。你会经常听到加密货币投资者，尤其是日内交易者使用这三个字母。买入低点有助于降低你在高位买入时的平均成本，并增加你的持仓量。

# Bull/Bullish

Bull/Bullish 是对市场价值（无论是股票还是加密世界）的乐观看法。这是一个比喻用法，描述公牛用角向上顶击的方式。当图表向上移动时，据说加密货币处于 Bull Market，这意味着正在获利。我对加密世界感到非常看涨。

# Bull Market

Bull Market 是好市场的标志，市场价格正在上涨或呈上升趋势。在加密货币中，Bull Market 意味着你的币值正在上升，这意味着你正在赚钱或获得利润。Bull Market 始终是 Bear Market 的完全相反。

# Cardano

Cardano 是一个以 15 世纪意大利博学者 Gerlamo Cardano 命名的山寨币区块链项目。由前以太坊联合创始人 Charles Hoskinson 于 2015 年创立，运行在其自身区块链上并在其代码中包含智能合约。它采用权益证明共识协议，被认为比工作量证明更环保。其原生加密货币称为 ADA，以 19 世纪被认为是第一位计算机程序员的女性数学家 Ada Lovelace 命名。

[https://cardano.org/](https://cardano.org/)

# CeFi

CeFi 是 Centralized Finance 的缩写或首字母缩略词。这是你典型的旧传统金融系统，如银行。比特币和山寨币的采用带来了加密世界中一些主要参与者的参与，以处理加密货币的兑换、交易和交易所。这种集中式金融的一个例子是 Coinbase 和 Crypto.com。通俗地说，这就是加密货币的银行业务。

# Cloud mining

Cloud mining 与云存储的概念相同，即上传到和下载自云端。这些是拥有可用计算硬件或服务器的远程数据中心，可用于挖掘加密货币。因此，任何人可以从世界任何地方登录此平台，支付一定费用，并可以使用云端挖掘任何类型的加密货币。

# Cold Storage

Cold Storage 被认为是存储加密货币钱包以防止在线黑客攻击的最安全方式。你可以将加密货币存储在硬件钱包中，将其下载到 USB 拇指驱动器上，或者将其写在纸上，也称为纸钱包。请记住将其安全、妥善保管，并知道你将其放在哪里。

# Cold Wallet

Cold Wallet 是一个冷加密货币钱包，意味着它未连接到互联网。这是典型的离线冷存储。

# Coin

Coin 或加密货币币是其自身区块链的原生币。不要将币与代币混淆。最重要的是，无论你如何使用它，你都不会受到惩罚，但为了学习和理解，你必须知道两者的区别。所以币有自己的区块链，而代币没有。

# CPU Mining

CPU Mining 是 Central Processing Unit 或 CPU 挖矿的缩写。这是中本聪在比特币区块链上挖掘前 50 个比特币的第一种方式。中央处理器在其计算能力内对算法编码的交易进行哈希处理的过程会产生大量热量，随着难度增加，这变得不适合 CPU 挖矿。它演变为 GPU 和 ASIC 挖矿，因为它们更快且能承受挖矿过程中的热量。使用 CPU 进行挖矿的山寨币加密货币的一个例子是 MONERO。
