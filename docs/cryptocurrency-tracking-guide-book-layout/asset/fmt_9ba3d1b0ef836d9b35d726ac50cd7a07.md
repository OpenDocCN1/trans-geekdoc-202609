
# Ethereum

Ethereum 是由 Vitalik Buterin 在 2013 年发布白皮书并推出的一种替代币（Altcoin），其联合创始人之一为 Joe Lubin，于 2015 年正式启动。它与比特币（Bitcoin）一样都利用了区块链技术，但在代码共识协议方面有很大不同。比特币的区块链最初仅设计用于作为价值存储的加密货币。

与之不同，Ethereum 被视为可编程区块链，开发者和程序员可以在其之上构建任何利用智能合约的去中心化金融（DeFi）应用协议。Ethereum 是一种为扩展加密货币、智能属性的视野，并将各类中心化应用转变为去中心化应用而设计的区块链。

Ethereum 区块链以其原生代币 Eth 奖励矿工，由于其智能合约应用，用户还可以创建、发布和货币化任何 DeFi DApp，从而允许他们将代币兑换为 Eth 代币，反之亦然。自诞生以来，它发展迅速，加密世界中大多数代币主要部署在 Ethereum 网络上。这些代币称为 ERC20 代币，与任何使用 Ethereum 钱包的人都兼容。

[https://ethereum.org/en/](https://ethereum.org/en/)

# ERC20

ERC20 是在 Ethereum 区块链网络上利用智能合约的去中心化应用协议创建的代币。它代表“Ethereum Request for Comment”，即任何在 Ethereum 区块链上利用智能合约开发新代币的新项目都应遵循的规则和指南。

所有符合 ERC20 标准的代币都受到 Ethereum 钱包的支持。ERC20 代币的示例包括 Basic Attention Token (BAT)、Maker (MKR)、Crypto.com (CRO)、HOGE 等。

# EVM

EVM 是 Ethereum Virtual Machine 的缩写或首字母缩略词。连接到 Ethereum 网络的所有节点都运行 Ethereum Virtual Machine。它们基本上是支持在 Ethereum 区块链上利用智能合约软件代码构建的所有 DApp 的图灵完备运行时环境。

# Exchange

交易所（Exchange）可以是中心化交易所（CEFI）或去中心化交易所（DEFI），用户可以在其中交易、出售或购买任何加密货币。一些交易所拥有其网站的移动应用程序版本，这使得任何个人都可以更方便地使用比特币、替代币或法定货币进行购买。一些交易所的示例包括 Coinbase、FTX、Crypto.com、Binance 等。

# F

## Flippening

Flippening 指的是一种新的加密货币按市场价格超越旧加密货币的现象，自 2017 年以来，投资分析师广泛将其用于比特币和以太坊之间的投机性口语。截至撰写本文时，比特币交易价格为 21k，而以太坊交易价格为 1.6k。投机投资者押注，一旦 Eth2.0 上线运行，Flippening 就会发生。

## Full Node

全节点（Full Node）是一台连接到互联网、拥有足够内存以支持和运行完整区块链软件代码副本的计算机。完整副本意味着它包含区块头和区块交易。它们通过强制执行共识规则来验证网络中的每一笔交易，并在将区块链在一起之前验证每个区块。

## FinTech

FinTech 是 Financial Technology 的缩写和首字母缩略词。随着金融领域新兴技术的快速变化和发展，适应更新、更高效方式的需求也随之增加。为了满足消费者不断增长的需求，传统金融机构反应迟缓且不愿适应，就像加密货币的例子一样。以下是一些进入加密世界以帮助满足消费者需求的新 FinTech 公司：Crypto.com、Coinbase、Robinhood 等。

## FOMO

FOMO 是 Fear Of Missing Out 的缩写和首字母缩略词。它通常发生在投资者或任何在 YouTube、新闻、博客文章或朋友口头传闻中看到文章而没有花时间进行 DYOR 的人身上，他们开始产生压倒性的情绪并立即投入。贪婪也是这些情绪的主要促成因素，是导致灾难的绝佳配方。

## FOMO Buying

FOMO Buying 也称为恐慌性购买，是由于贪婪等压倒性情绪以及无法控制此类情绪而引起的。这种 FOMO Buying 经常发生在新投资者身上，他们可能进入某种加密货币较晚，但现在想要在他们的持仓中增加更多。当其加密货币和持仓的价格开始下跌时，也会产生相反的情况，他们会恐慌性抛售并亏损。

# G

## Gas

Ethereum 区块链收取交易费，这些费用称为 Gas，并以 Gwei 计量。

## Gwei

Gwei 是以太币（Ether）的最小面额。这个混合词代表 G - giga 和 Wei - Wei Dai，后者是 B-money 的创始人，也是比特币的前身，带来了现代加密货币的概念。

## Genesis Block

创世区块（Genesis Block）是任何区块链平台的第一个区块。它也是零区块或区块零，指的是其前面没有区块。第一个创世区块属于比特币区块链，其中 Satoshi Nakamoto 在比特币创世区块中写道：“The Time 03/Jan/2009 Chancellor on brink of second bailout for banks”。

## GPU Mining

GPU Mining 是 Graphics Processing Unit（图形处理单元）的缩写或首字母缩略词，简单来说就是用于挖矿的显卡。GPU Mining 主要用于挖掘大多数替代币，因为其哈希处理速度比 CPU Mining 快得多。某些加密货币算法代码允许 GPU Mining 和 CPU Mining 同时进行，这对矿工来说可能是有利可图的。比特币挖矿的难度如此之高，以至于 GPU 矿工无法与 ASIC 矿工竞争。

如果你有兴趣学习如何挖矿，游戏电脑（Gaming PC's）是完美的挖矿电脑，因为它配备了一块可以完成工作的 GPU。你也可以构建一台配备三个或更多 GPU 的专用挖矿机器以获得最佳挖矿效果。请记住，加密货币挖矿并不便宜，不仅需要为构建矿机的组件花费大量资金，还需要考虑运行它所需的电力成本。在开始之前请先进行 DYOR。

# H

## Halving

减半（Halving）是挖矿奖励减半的过程。例如，矿工找到一个区块原本获得一百枚代币奖励，四年后发生减半，矿工只能获得五十枚代币。这写在区块链的源代码中，是不可更改的。随着寻找区块难度的增加，给予矿工的奖励越来越少。这也是控制进入加密世界的加密货币供应量的一种方式。

## Hard Fork

硬分叉（Hard Fork）是指旧协议源代码通过实施新代码更改而诞生新协议的过程。这可能与加密货币的开发者（DEVs）和矿工在如何推进项目方面存在分歧的结果有关。一些示例包括 Bitcoin Cash 和 Ravencoin，它们都是比特币的硬分叉。

Ethereum Classic 是 Ethereum 区块链的硬分叉示例。无需过多深入技术细节，重要的是要知道，当对旧区块链源代码进行新的永久更改且与原始共识规则不兼容时，就会发生硬分叉。

## Hash

通俗地说，哈希（Hash）是一种计算数学过程，将输入消息转换为固定输出消息。
