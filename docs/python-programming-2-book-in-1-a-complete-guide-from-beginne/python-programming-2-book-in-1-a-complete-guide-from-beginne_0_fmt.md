## Python 历史

Python 由荷兰的 Guido van Rossum 创立。1989 年感恩节期间，Guido 决定开发一种新的脚本解释器，作为 ABC 语言的继承者，以消磨圣诞节的无聊时光。之所以选择 Python 作为语言名称，是因为他是 BBC 电视剧《Monty Python's Flying Circus》（蒙提·派森的飞行马戏团）的粉丝。他想为编程语言营造一种神秘感，因此将其命名为 Python。

Python 诞生于 1989 年，但首个公开发行版发布于 1991 年。Python 2.0 于 2000 年 10 月正式发布，Python 3.0 于 2008 年 12 月正式发布，截至本书撰写时，最新版本为 Python 3.6.5。

Python 是一种面向对象的直译式计算机编程语言，也是一种功能强大的通用编程语言。它包含一组完善且易于理解的标准库，并得到大量第三方库的支持，可轻松完成许多常见任务。其语法非常简单清晰，与大多数其他计算机编程语言不同，它使用强制缩进来定义语句块。

## Python 的设计风格

Python 坚持清晰统一的设计风格，这使其成为一种易读、易维护、深受大量用户喜爱且用途广泛的语言。开发人员的总指导思想是：只要有最好的方法来解决特定问题，那就是最好的。Python 的设计哲学是优雅、清晰、简单和可读。

## 如何安装第三方库？

Python 拥有强大的标准库，Python 社区以类似标准库的方式提供大量第三方库。如果强大的标准库为 Python 的发展奠定了基础，那么第三方库则负责 Python 的持续发展。随着 Python 的持续更新，一些稳定的第三方库已被加入标准库。

安装 Anaconda 时，Python 的标准库和一些常用第三方库会随 Python 解释器一起安装。您可以在 Windows 提示符下输入 `pip list` 查看已安装的库。所有已安装的库将显示在输出屏幕上。如果要使用未安装的第三方库，必须使用下述安装方法进行安装。如果初学者觉得这部分内容过于繁杂难以专注，可以暂时跳过。您随时可以回到本节了解第三方模块的安装。

## 为什么 Python 很特别？

现在有数百种编程语言可供程序员入门。然而，根据哈佛大学计算机科学家的一项调查统计，Python 是初学者中的领先语言。我们将在本节讨论一些使 Python 成为新程序员易懂语言的原因。

1.  **语法简洁明了，代码可读性高。** Python 的语法强制要求缩进，这用于体现语句间的逻辑关系，并显著提高程序的可读性。

3.  **Python 可以真正跨平台**，例如，我们开发的程序可以在 Windows、Linux、macOS 系统上运行。这是它的可移植性优势。

4.  **拥有大量丰富的库或扩展。** Python 常被称为胶水语言。它可以轻松连接用其他语言（尤其是 C/C++）编写的各种模块。利用这些丰富的第三方库，我们可以轻松开发应用程序。

5.  **代码量少，在一定程度上提高了软件质量。** 由于用 Python 编写的代码量远少于其他语言，出错概率也低得多，这在一定程度上提高了所编写软件的质量。

## Python 是如何工作的？

Python 程序执行原理非常简单。我们都知道，用 C/C++ 等编译型语言编写的程序，需要将源文件转换为计算机使用的机器语言，然后由链接器链接形成二进制可执行文件。运行程序时，可以从硬盘将二进制程序加载到内存中运行。

然而，对于 Python，Python 源代码无需编译成二进制代码。它可以直接从源代码运行程序。Python 解释器将源代码转换为字节码，然后将编译后的字节码转发给 Python 虚拟机 (PVM) 执行。

当我们运行 Python 程序时，Python 解释器执行两个步骤。

### (1) 将源代码编译为字节码

编译后的字节码是 Python 特有的表达形式。它不是二进制机器码，需要进一步编译才能由机器执行。这也是 Python 代码运行速度不如 C/C++ 快的原因。如果 Python 进程在机器上拥有写入权限，它会将程序的字节码保存为扩展名为 `.pyc` 的文件。如果 Python 无法在机器上写入字节码，字节码将在内存中生成，并在程序结束时自动丢弃。构建程序时，最好授予 Python 在计算机上的写入权限，这样只要源代码未变，生成的 `.pyc` 文件就可以复用，从而提高执行效率。

### (2) 将编译后的字节码转发给 Python 虚拟机 (PVM) 执行。

PVM 是 Python Virtual Machine 的缩写。它是 Python 的运行引擎，也是 Python 系统的一部分。它是一个大循环，迭代运行字节码指令，依次完成操作。在此过程中，每个 Python 程序都会被执行，并给出可进一步分析和测试的结果，以便完全部署为新应用程序。

## 3. 启动 Python

Python 可以通过两种方式启动。

### 3.1 启动 Python 自带的 IDLE

如果您想运行 Python，可以点击 Windows 桌面上的“Start”（开始）按钮，在出现的搜索框中输入“IDLE”以启动一个 Python 桌面应用程序，快速提供“read-evaluate-print-loop”（读取-求值-打印循环）提示符。IDLE 是 Python 自带的简单 IDE（集成开发环境），是 Python 的图形界面编辑器。IDLE 可被视为集成开发环境的简易版。其功能看似简单，但有助于初学者学习 Python 语言本身。这里提供了一个 REPL 环境，即读取用户输入（“Read”）、求值计算（“Evaluate”）、然后打印结果（“Print”），接着出现提示符“Loop”，从而循环往复。

### 3.2 在 Windows 命令提示符下启动 Python

# 第 4 章：Python 数据类型

Python 和其他编程语言使用数据类型在内存中逻辑地存储值。区分带有值的数据有助于操作执行得更快。我们还将在本章讨论其他重要的编程概念，如标识符和保留关键字。

## 数据类型

对象支持的操作及其描述由数据类型决定。因此，了解数据类型对程序员非常重要。Python 语言提供了若干功能丰富的内置数据类型。在解释每种数据类型及其支持的操作之前，通常会检查对象的类型。Python 提供了一个特定的内置函数 `type()` 来执行这些操作。它返回一种称为类型对象的特殊类型，该类型可进一步细分为其他类型。

### 类型检测函数 `type()`

使用 `type()` 函数可快速检查变量的类型，或确定它们能执行的操作类型。

例如：

```
type(example)  # 其中 example = 8
```

我们将通过 `type()` 函数得到输出 `int`。`type()` 函数非常简单。它可以快速帮助我们检测对象的实际类型，无论是通过变量名还是值。

### 空对象 (`None`)

Python 中另一种特殊的类型称为空对象。它只是空的，可以容纳空值。

### 简单数值类型

#### 整数

整数类型 (`int`) 就是整数，用于表示整数，例如 `100`、`2016` 等。整数字面量有四种表示方式：十进制、二进制（以 `0B` 或 `0b` 开头）、八进制（以数字 `0` 开头）和十六进制（以 `0X` 或 `0x` 开头）。

Python 的整数可以表示有限范围，这与系统的最大整数一致。例如，32 位计算机上的整数是 32 位，可表示的数字范围是 `-2³¹` ~ `2³¹-1`。64 位计算机上的整数是 64 位，可表示的数字范围是 `-2⁶³` ~ `2⁶³-1`。

接下来，看一些整数代码示例，如下所示：

```
first = 231283
type(first)
# <type 'int'>
first
# 231283
```

在上述代码中，第 1 行变量 `first` 的值是一个十进制整数，属于 `int` 类型。这在接下来的几行中得到了验证。第 4 到 5 行直接输出 `first` 的值，结果为 `231283`。

十进制数可以使用指定函数转换为二进制、八进制或十六进制。示例代码如下：

```
bin(20)   # 将十进制 20 转换为二进制 '0b10100'
oct(20)   # 将十进制 20 转换为八进制 '0o24'
hex(20)   # 将十进制 20 转换为十六进制 '0x14'
```

#### 长整数

`Long` 是整数的超集，可以表示无限大的整数（实际上仅受计算机虚拟内存大小限制）。长整数字面量后跟字母 `l` 或 `L`（推荐使用大写 `L`）。长整数和整数的操作相同。示例代码如下：

```
first = 13798433 * 3749803498
# <type 'long'>
```

从长远来看，整数和长整数逐渐统一为整数类型。从 Python 2.3 开始，将不再报告整数溢出错误，结果将自动转换为长整数。现在这两种整数类型可以说是无缝结合了，长整数后缀 `L` 变成了可选的。

#### 浮点类型

`Float` 用于表示实数。例如，`3.14`、`9.19` 等都是浮点类型。浮点字面量可以用十进制或科学计数法表示。Python 中的科学计数法表示如下：

```
<实数> e 或 E <整数>
```

其中，`e` 或 `E` 代表以 10 为底，后面的整数代表指数，指数的正负用 `+` 或 `-` 表示，其中 `+` 可以省略。例如，`1.34E3` 表示 `1.34x10³`，`1.5E-3` 表示 `1.5x10^-3`。

示例代码如下：

```
>>> 1.2e5  # 浮点数为 1.2×10⁵
# 120000.0
```

#### 布尔类型

布尔类型可视为一种特殊的整数。布尔数据只有两个值：`True` 和 `False`，分别对应整数的 `1` 和 `0`。每个 Python 对象天生就具有布尔值（`True` 或 `False`），随后可用于布尔测试（如 `if`、`while`）。如果定义了方法 `__nonzero__()` 或 `__len__()` 并返回 `0` 或 `False`，用户定义的类实例返回 `False`。除上述对象外，所有对象的布尔值均为 `True`。本节涉及大量后续讲解的知识。此处你只需知道布尔值只能是 `True` 和 `False`。

#### 复数类型

复数类型用于表示数学中的复数。例如，`5+3j` 和 `-3.4-6.8j` 都是复数类型。Python 中的复数类型是一般计算机语言中没有的数据类型。它具有以下两个特征：

1. 复数由实数和虚数组成，表示为 `real+imagj` 或 `real+imagJ`。
2. 复数的实部和虚部 `imag` 均为浮点类型。

应注意，复数必须包含代表虚部的 `j` 或 `J`，例如 `1j` 和 `1J` 是复数，而 `0.0` 不是复数。即使实部为 `1`，代表虚部的实部也不能省略。

复数的示例代码如下：

```
sample = 6+2j
sample
# (6+2j)
sample.real          # 实部
# 6.0
type(sample.real)
# <class 'float'>
sample.imag          # 虚部
# 2.0
type(sample.imag)
# <class 'float'>
```

## 标识符和关键字

### 标识符

在现实生活中，人们经常用一些名称来标记事物。例如，每种水果都有名称来标记。同样，如果想在程序中表达某事物，需要开发者自定义一些符号和名称，称为标识符。例如，变量名、函数名等都是标识符。

Python 中的标识符由字母、数字和下划线 `_` 组成，其命名方法需遵循特定规则，如下所示：

1. 标识符由字母、下划线和数字组成，且不能以数字开头。

   示例代码如下：

   ```

   From#12       # 非法标识符。标识符不能包含 # 符号。
   2ndObj        # 非法标识符。标识符不能以数字开头。
   ```

2. Python 中的标识符区分大小写。例如，`andy` 和 `Andy` 是不同的标识符。

3. Python 中的标识符不能使用关键字。例如，`if` 不能用作标识符。

此外，为规范标识符的命名，对标识符的命名提出以下建议：

1. **见名知意**：给出有意义的名称，力求一眼就能看出标识符的含义，从而提高代码的可读性。例如，用 `name` 表示定义的名称，用 `student` 表示定义的学生。

2. 命名变量时，许多计算机语言建议使用驼峰命名法。但是，Python 中不推荐使用驼峰命名法（首选 snake_case）。

在 Python 中，具有特殊功能的标识符称为关键字。关键字已被 Python 自身使用，开发者不允许定义与关键字同名的标识符。Python 中的关键字各代表不同的含义。如果想查看关键字信息，可以输入 `help()` 命令进入帮助系统查看。

## 变量

在现实生活中，当我们在超市购买东西时，通常需要使用购物车来存放商品。毕竟，商品购买后，我们可以在收银台结账。让我们想象一下，如果你想在程序中对多个数据求和，你需要先存储数据，然后再将数据相加。在 Python 中，需要变量来存储数据。变量可以理解为在超市购物时使用的购物车，它们的类型和值在赋值的那一刻就被初始化了。变量的赋值用等号表示，示例代码如下。我们将在下一章详细讨论赋值操作。

Python 中的字符串被定义为一组用引号括起来的字符，引号可以是单引号、双引号或三引号（三个连续的单引号或双引号）。字符串有索引规则，第一个字符的索引是 0，第二个字符的索引是 1，依此类推。以下是字符串的示例代码：

在上面的代码中，变量 `Sample` 是字典类型，存储了两个元素，第一个元素的键是 name，值是 Rob。第二个元素的键是 age，值是 67。

## Python 赋值语句

学习 Python 中的赋值语句，能让学习其他语句变得更容易。学习 Python 赋值语句主要是为了掌握并理解其逻辑。



### 1. 赋值语句

Python 中赋值语句的本质是创建一个对对象的引用。赋值主要有以下几种方法。

#### a) 基本赋值方法

`first = 5`

这等同于创建一个变量 `first`，使其指向内存中存储的对象 `5`。`first = 5` 是一条赋值语句。执行赋值操作后，您可以随意打印或显示 `first` 的值。

#### b) 理解赋值逻辑

在声明变量时，至少包含两部分：一是用于存储变量名的变量表，二是内存存储区。当声明 `first = 5` 时，系统首先在内存区开辟一个存储空间，存入值 `5`，然后让变量 `first` 指向内存中存储的对象 `5`，这相当于在内存存储区先有了对象 `5`。接着 `first` 出现在变量表中，并指向 `5`。这种指向也可以称为“引用”。

虽然赋值语句的语法很简单，但请仔细理解 Python 中的赋值逻辑。这种赋值逻辑影响 Python 的方方面面。如果您理解了赋值逻辑，就能更好地理解和编写 Python 程序。如果您有 C 语言编程经验，您会知道 C 程序中的变量存放的是值，而 Python 中的变量指向一个值。变量仅以引用关系存在，不再具有存储功能。在 Python 中，每个数据都占据一块内存空间，数据在 Python 中被称为对象。整数 `5` 是一个 `int` 对象，`'hello'` 是一个字符串对象，`[1, 2, 3]` 是一个列表对象。在 Python 中，您可以使用全局内置函数 `id(obj)` 来获取对象的 id，即对象在内存中的存储地址。全局内置函数直接使用，无需引用任何包。

> **注意：** 变量 `first` 前后地址的变化表明变量指向了对象！对象一旦创建，就不能被直接销毁。因此，在上述示例中，变量 `a` 先指向对象 `5`，然后继续执行 `a = a + 5`，这会产生一个新对象 `10`。由于对象 `5` 无法被销毁，让 `a` 指向新对象 `10`，而不是用对象 `10` 覆盖对象 `5`。代码执行完毕后，内存中仍然存在对象 `5` 和 `10`，但变量 `a` 指向了新对象 `10`。如果没有变量指向对象 `5`（即无法被引用），Python 将使用垃圾回收机制来决定是否回收它（这是自动的，不需要程序员操心）。Python 内部有一套垃圾回收机制。垃圾回收机制检测到如果在特定时间内没有变量引用某个对象，该对象将被回收，释放其占用的资源。Python 内部有一个引用计数器，垃圾回收机制根据引用计数器判断对象是否有引用，以决定是否自动释放对象占用的资源。垃圾回收机制针对 Python 中无引用的对象，并根据引用计数器得出的结果进行推断。这种理解也非常重要。当我们将来谈到列表等数据类型时，将再次看到正确理解变量指向对象的重要性。

# 第 7 章：Python 中的交互性

## 模块如何提供交互性？

在 Python 中，可以使用 `import` 关键字来导入模块。例如，可以导入 `math` 模块，使用 `import math`。使用 `import` 导入模块的基本格式如下：

```
import firstmodule, secondmodule...
```

此时，如果模块位于同一位置，将会自动导入该模块。如果要调用模块中的函数，必须这样引用：`模块名.函数名`。调用模块中的函数时要加上模块名，因为多个模块中可能存在同名函数。此时，如果仅使用函数名调用，解释器无法知道该调用哪个函数。因此，如果按上述方式导入模块，调用函数时必须加上模块名。具体示例如下：

```
import math
# 这被认为是错误的
print(math.sqrt(12))
# 只有这种方式才能正确输出结果
print(math.sqrt(12))
```

有时我们只需要使用模块中的某个函数，只需导入该函数。此时，可以应用以下格式：

```
from 模块名 import 函数名1, 函数名2 ...
```

为便于您理解，这里有一个实例：

```
from fib import fib
```

以这种方式导入函数时，调用函数时只能给出函数名，不能给出模块名，但当两个模块包含同名函数时，后导入的会覆盖先导入的。也就是说，如果模块 A 中有函数 `function`，模块 B 中也有函数 `function`。如果先导入 A 中的函数，再导入 B 中的函数，则调用函数时，执行的是模块 B 中的函数。

您也可以使用以下语句一次性导入所有内容：

```
from module_name import *
```

应当注意的是，虽然 Python 提供了一种导入模块中所有项目的简单方法，但您也应该使用其他的导入语句。

当我们使用 `import` 导入模块时，Python 解释器如何找到对应的文件？这涉及 Python 的搜索路径，它由一系列目录名组成，Python 解释器会依次从这些目录中搜索导入的模块。搜索路径在 Python 编译或安装时确定，安装新库时也应进行修改。可以使用 `sys` 模块中的 `path` 变量进行搜索操作，通过以下代码验证：

```
import sys
print(sys.path)
```

现在，在解释器的当前目录或 `sys.path` 中的某个目录下创建一个 `fibo.py` 文件，包含以下示例代码：

```
# 斐波那契数列模块
def fib(n): # 定义斐波那契数列直到 n
    first, second = 0, 1
    while second < n:
        print(second, end=' ')
        first, second = second, first + second
    print()

def fib2(n): # 返回斐波那契数列直到 n
    result = []
    first, second = 0, 1
    while second < n:
        result.append(second)
        first, second = second, first + second
    return result
```

然后进入 Python 解释器，使用以下命令导入该模块：

```
import fibo
```

这样做，直接定义在 `fibo` 中的函数名称不会写入当前符号表，但模块名称 `fibo` 会被写入。您可以使用模块名来访问函数，示例代码如下：

```
import fibo
fibo.fib(1000)
fibo.fib2(100)
fibo.__name__
```

如果您打算频繁使用某个函数，可以将其赋值给一个局部名称。示例代码如下：

```
fib = fibo.fib
fib(500)
```

## 什么是列表？

之前学习的字符串数据类型可用于存储单条字符串信息。但假设一个班级有 100 名学生。如果你想存储该班所有学生的姓名，你需要定义 100 个变量，每个变量存储一名学生的姓名。然而，如果有 1,000 名学生或更多，该怎么办？你很幸运，因为列表等结构可以解决上述问题。

列表是 Python 中的一种数据结构，可以存储不同类型的数据。创建列表的方法非常简单：只需使用方括号将用逗号分隔的不同数据项括起来。示例代码如下：

```
A = [1, 'Tom', 'a', [2, 'b']]
```

与字符串的索引一样，列表索引从 0 开始。我们可以通过下标索引访问列表中的值。

为了更高效地输出列表的每个数据，我们可以使用 `for` 和 `while` 循环来遍历输出列表。以下是一个案例研究，说明如何使用 `for` 和 `while` 循环遍历列表。

### 1. 使用 `for` 循环遍历列表

使用 `for` 循环遍历列表的方法非常简单；只需在 `for` 循环表达式中将列表作为序列进行遍历。接下来，将通过一个案例来理解此场景。

```
getdetails = ['Sam', 'Tom', 'Ram']
for name in getdetails:
    print(name)
```

在本示例中，当使用 `for` 循环遍历列表时，由于列表本身就是一个序列，因此可以直接将 names 列表用作 `for` 循环表达式的序列，逐个获取列表中的元素。

### 2. 使用 `while` 循环遍历列表

要使用 `while` 循环遍历列表，首先需要获取列表的长度，并将获取的列表长度作为 `while` 循环的条件。接下来，将展示一个案例，如下例所示。

#### 示例：使用 `while` 循环遍历列表

```

length = len(getdetails)
first = 0
while first < length:
    print(getdetails[first])
    first += 1
```

在本示例中，当使用 `while` 循环遍历列表时，因为 `while` 循环需要指定遍历次数，所以有必要使用 `len()` 函数获取列表的长度，即要遍历的元素数量。

# 第 9 章：Python 中的函数

## 什么是函数？

函数是有组织的、可复用的代码段，用于实现单一或相关联的功能，能够提高应用的模块性和代码的复用率。Python 提供了许多内置函数，例如 `print()`。同时，我们也可以创建自己的函数，即自定义函数。

接下来，请看一段代码：

```
// display(" * ")
// display(" *** ")
// display(" ***** ")
```

如果需要在程序的不同部分输出上述图形，每次都使用 `print()` 函数输出是不可取的。为了提高编写效率和代码复用性，我们可以将具有独立功能的代码块组织成一个小模块，这被称为函数。

## 定义函数

我们可以定义一个函数来实现所需的功能。Python 定义函数以 `def` 开头，定义函数的基本格式如下：

```
def function_name(parameters):
    """docstring"""
    function_body
    return expression
```

请注意，如果参数列表包含多个参数，默认情况下，参数值和参数名按照函数声明中定义的顺序进行匹配。

接下来，定义一个能够完成打印信息功能的函数，如下例所示。

### 示例：打印信息的函数

```python
# 定义一个可以打印信息的函数
def Useforprint():
    print('------------------------------------')
    print('life is short, I use python')
    print('------------------------------------')
```

## 调用函数

定义函数后，相当于拥有了一段具有特定功能的代码。要使这些代码可执行，需要调用它。调用函数非常简单，可以通过 `function_name()` 来调用。

例如，调用上一节中 `Useforprint` 函数的代码如下：

```python
# 函数定义后不会自动执行，需要调用
Useforprint()
```

## 函数的参数

在介绍函数参数之前，我们先解决一个问题。例如，要求定义一个用于计算两个数之和并打印计算结果的函数。将上述需求转化为代码。示例代码如下：

```python
def thisisaddition():
    result = 62 + 12
    print(result)
```

上述函数的功能是计算 62 和 12 的和。此时，无论调用多少次该函数，结果始终相同，且只能计算两个固定数字的和，这使得该函数非常受限。

为了使定义的函数更加通用，即计算任意两个数的和，可以在定义函数时添加两个参数，这两个参数可以接收传递给函数的值。接下来，通过一个案例演示函数如何传递参数。

### 示例：函数传递参数

```python
# 定义一个接收 2 个参数的函数
def thisisaddition(first, second):
    third = first + second
    print(third)
```

在上面的示例中，定义了一个能够接收两个参数的函数。其中 `first` 是用于接收函数传递的第一个值的第一个参数；`second` 是第二个参数，用于接收函数传递的第二个值。

此时，如果要调用 `thisisaddition` 函数，需要向函数的参数传递两个数值。示例代码如下：

```python
# 调用带参数的函数时，需要在括号中传递数据。
thisisaddition(62, 12)
```

应当注意的是，如果函数定义了多个参数，则调用函数时，传递的数据应与定义的参数一一对应。

## 默认参数

定义函数时，可以为其参数设置默认值，这称为默认参数。调用函数时，因为默认参数在定义时已赋值，可以直接忽略，而其他参数必须传入值。如果默认参数没有传入值，则直接使用默认值。如果默认参数传入了值，则使用新传入的值替换。

接下来，我们通过一个案例演示默认参数的使用。

### 示例：默认参数

```python
def getdetails(input, time=35):
    # 打印任意传入的字符串
    print("Details:", input)
    print("Time:", time)

# 调用 printinfo 函数
getdetails(input="sydney")
getdetails(input="sydney", time=2232)
```

在示例中，第 1-4 行定义了带有两个参数的 `getdetails` 函数。其中，`input` 参数没有默认值，而 `time` 已设置默认值作为默认参数。

调用 `getdetails` 函数时，因为只传入了 `input` 参数的值，程序使用了 `time` 参数的默认值。当再次调用 `getdetails` 函数时，同时传入了 `input` 和 `time` 参数的值，因此程序将使用传递给 `time` 参数的新值。

## 什么是判断？

判断意味着只有当满足特定条件时，才允许执行某项操作；而当条件不满足时，则不允许执行。例如在现实生活中，过马路取决于红绿灯。如果是绿灯，你可以过马路；否则，你需要停下来等待。判断不仅用于生活中，也用于程序开发。例如，当用户登录时，只有用户名和密码均正确时，才允许其登录。Python 提供了多种判断语句。在下一节中，我们将详细解释这些判断语句。

## If 语句

`if` 语句是最简单的条件判断语句。它可以控制程序的执行流程。其格式如下：

```
If criteria:
    Things to do when you meet the first condition.
    Things to do when you meet the second condition
    ...
    Things to be done when conditions are not met at all
```

在上述格式中，只有满足判断条件时，才能执行后续语句。

为了帮助大家更好地理解 `if` 语句的用法，接下来我们将通过两个案例演示 `if` 语句的功能，如下所示。

**注意：**

1. 每个 `if` 条件后使用冒号（`:`），表示满足条件后要执行的后续语句。

# 第 12 章：Python 面向对象编程

现实世界中存在各种形式的事物，这些事物之间也存在各种联系。在程序中，使用对象来映射现实事物，利用对象之间的关系来描述事物之间的关系。这种思想就是面向对象范式。

当我们谈论面向对象编程时，自然会想到面向过程编程。面向过程编程是分析解决问题的步骤，然后在使用不同方法时，用函数逐一实现这些步骤。面向对象编程是将解决问题的实体分解为多个对象，建立对象的目的不是为了逐一完成，而是为了在解决整个问题的过程中描述事物的行为。

以下通过一个五子棋的例子来说明面向过程和面向对象编程的区别。

首先，使用面向过程范式：

1. 开始游戏
2. 玩家 1 先行
3. 绘制画面
4. 判断结果
5. 玩家 2 回合
6. 绘制画面
7. 判断结果
8. 返回步骤 2
9. 输出最终结果

上述步骤分别由函数实现，使用面向过程范式解决问题。

面向对象设计从另一种思维方式解决问题。当使用面向对象思维实现五子棋时，整个五子棋游戏可以分为三类对象，如下所示。

1. 黑白双方：代表两名玩家
2. 棋盘系统：负责绘制画面
3. 规则系统：负责判断犯规、胜负等事项

在上述三类对象中，第一类对象（黑白双方）负责接收用户输入并通知第二类对象（棋盘系统）在棋盘上绘制棋子，而第三类对象（规则系统）对棋盘进行判断。

面向对象编程保证了功能的统一性，从而使代码更易于维护。例如，如果我们现在想在面向过程范式中添加悔棋功能，那么输入、判断、显示的一系列步骤都需要改动。甚至步骤之间的循环都需要大规模调整，非常麻烦。如果使用面向对象开发，只需修改棋盘对象即可。棋盘对象保存了黑白双方的棋谱，只需简单回溯，无需修改显示和规则。同时，整个对象函数的调用顺序不会改变，其变化仅是局部的。因此，与面向过程相比，面向对象编程更便于后期的代码维护和功能扩展。

## 类和对象

在面向对象编程中，最重要的两个核心概念是类和对象。对象是现实生活中具体的事物，它们看得见、摸得着。例如，你手中的这本书就是一个对象。与对象相比，类是抽象的，它是对一群具有相同特征和行为事物的统称。例如，小时候母亲对我说：“儿子，你要以那种人为榜样！”这里的“那种人”指的是一群成绩优秀、有礼貌的人。他们具有相同的特征，所以被称为“同类”人。

### 类与对象的关系

俗话说“物以类聚，人以群分”，我们将具有相似特征和行为的事物的集合统称为类，如动物、飞机等。例如，玩具模具可以看作是类，每个玩具看作是对象，因此玩具模具与玩具的关系可以看作是类与对象的关系。

类用于描述多个对象的共同特征，是对象的模板。对象用于描述现实中的个体，它是类的实例。由此可见，对象是根据类创建的，一个类可以对应多个对象。

### 类的定义

在日常生活中，要描述一类事物，需要说明其特征以及用途。例如，描述人类这类实体时，通常需要给这类事物一个定义或名称。人的特征包括身高、体重、性别、职业等。人的行为包括跑步、说话等。人的特征与行为的结合可以完整地描述人类。

面向对象程序的设计思想基于此设计，在类中包含事物的特征和行为。其中，事物的特征作为类的属性，事物的行为作为类的方法，对象是类的实例。因此要创建对象，首先需要定义类。

类由 3 部分组成。

1. **类名**：类的名称，首字母必须大写，例如 `Person`。
2. **属性**：用于描述事物的特征，例如人具有姓名、年龄等特征。
3. **方法**：用于描述事物的行为，例如人具有说话、微笑等行为。

在 Python 中，可以使用 `class` 关键字声明类，基本语法格式如下：

```
class {此处输入实体名称}:
    # 这是类的属性
    # 类的方法
```

以下是示例代码：

```
class Vehicle:
    # attribute
    # Method
    def drive(self):
        Print ("-drivinf Automobile--")
```

在上例中，使用 `class` 定义了一个名为 `Vehicle` 的类，其中包含一个 `drive` 方法。从示例可以看出，方法的格式与函数相同。主要区别在于方法必须显式声明一个 `self` 参数，并位于参数列表的开头。`Self` 代表类的实例（对象）本身，可用于引用对象的属性和方法。`self` 的具体用法将在后面结合实际应用介绍。

### 从类创建对象

```

```

例如，创建驾驶类的对象 `Vehicle`，示例代码如下：

```

```

## break 语句

`break` 语句用于一次性结束整个循环（当前循环体）。它前面带有一个逻辑判断。例如，下面是一个普通的循环：

执行上述循环语句后，程序将按顺序输出 0 到 9 的整数。程序将不会停止运行，直到循环结束。此时，如果您希望程序仅输出 0 到 2 的数字，则需要在指定时间结束循环（执行完第三次循环语句后）。接下来，演示使用 `break` 结束循环的过程。

**示例：break 语句**

```

    end+=1
    print("-------")

    print(end)
```

在示例中，当程序进行到第三次循环时，因为 `end` 的值为 3，程序将停止并打印截至此时的循环。

## continue 语句

`continue` 的作用是结束本次循环，然后执行下一次循环。它将查看逻辑值并继续执行流程。接下来，通过一个案例演示 `continue` 语句的用法。

**注意：**

1. `break`/`continue` 只能在循环中使用，否则不能单独使用。

## 异常处理

Python 处理异常的能力非常强大。它能准确反馈错误信息，帮助开发者精准定位问题的位置和原因。Python 使用 `try-except` 语句处理异常。其中 `try` 语句用于检测异常，`except` 语句用于捕获异常。

### 捕获简单异常

`try-except` 语句定义一段用于监控异常的代码，并提供处理异常的机制。最简单的 `try-except` 语句格式如下：

```
try:
    # Here is the place where logic goes
except:
    # Here we enter the error details
```

当 `try` 块中的语句发生错误时，程序将不再继续执行 `try` 块中的后续语句，而是直接执行 `except` 中处理异常的语句。

为便于读者理解，以下示例演示如何使用简单的 `try-except` 语句捕获两数相除可能引发的异常。

**示例：Simple Exceptions.py**

```
try:
    print("-"*64)
    first = input("You should enter the first entity")
    second = input("You should enter the second entity")
    print(int(first)/int(second))
    print("-"*64)
except ZeroDivisionError:
    print("Number 64 cannot be divided")
```

在该示例中，`try` 子句中的 `input` 函数接收用户输入的两个值，其中第一个值作为被除数，第二个值作为除数。如果除数为 0，程序将抛出 `ZeroDivisionError` 异常。此时 `except` 子句将捕获该异常并打印异常信息。

运行程序并在控制台输入第一个数 64、第二个数 5，结果将显示。通过仔细分析，你将理解异常处理的工作原理。从结果可以看出，当程序出现异常时，程序不会终止，而是会根据自定义的消息提醒用户。

注意：只要监控到错误，程序就会执行 `except` 语句，不再执行 `try` 中未执行的语句。

### 捕获异常的描述信息

一个 `except` 子句可捕获多个异常。将示例中的两个错误合并到一个 `except` 子句如下：

```
try:
    first = input("Enter the first entity")
    second = input("Enter the second entity")
    print(int(first)/int(second))
except (ZeroDivisionError, ValueError):
    print("Get a value")
```

此时，无论上述两个异常中的任意一个发生，都会打印 `except` 内的语句。但仅打印一条错误信息无助于区分不同错误。可使用 `as` 关键字获取系统反馈的错误信息。

### 捕获所有异常

即使程序能处理多个异常，也无法穷尽所有异常，仍可能有异常未被捕获。在示例中，若编写程序时将 `num1` 误写为 `nmn1`，将获得类似以下的错误信息：

```
NameError: name 'nmn1' is not defined
```

此种情况下，可在原有基础上捕获 `SyntaxError` 异常。若程序中有数十个错误，逐个捕获非常麻烦。为解决此问题，`except` 子句可不指定异常类型，从而处理任意类型的异常。

为便于读者理解，此处添加捕获所有异常的功能示例。

**示例：Captures All Exceptions**

```
# captures all exceptions
try:
    first = input("Use this as first entity")
    second = input("Use this as second entity")
    print(int(first)/int(second))
except:
    print("You got this error")
```

在该示例中，`except` 语句未指定异常类型，程序所有可能的错误均在该语句中统一处理。从两次运行结果可见，所有异常的提示信息相同。

捕获所有异常的另一种方式是在 `except` 语句后使用 `Exception` 类。由于 `Exception` 类是所有异常类的父类，因此可捕获所有异常。

### 未捕获异常时的处理

在 `if` 语句中，当所有条件均不满足时执行 `else` 语句。同理，若 `try` 语句未捕获任何错误信息，则不执行任何 `except` 语句，而是执行 `else` 语句。

为便于读者理解，我们在上述示例基础上添加 `else` 语句。

**示例：else statement.py**

```
try:
    first = input("Use this as first entity")
    second = input("Use this as second entity")
    print(int(first)/int(second))
except:
    print("You got this error")
else:
    print("The program runs normally and no exception is caught")
```



在该示例中，当 `try` 语句检测到错误时，将执行 `except` 中的打印语句并输出异常描述信息。当无错误时，将执行 `else` 中的打印语句。

# 第 16 章：Python 中的文件管理

Python 是一种通常涉及大量文件操作的编程语言。它拥有一个专门的库来处理文件管理功能。本章将全面介绍 Python 中所有可用的文件管理方法。我们还提供了 Python 编程代码语句供您进一步分析。让我们开始吧！

## 文件的打开与关闭

让我们想象一下，如果您想使用 Word 文档编写简历，流程应该是怎样的？

1. 打开一个文件或创建一个新文件。
2. 读取/写入数据。
3. 关闭文件。

接下来，我们将分别介绍文件的打开与关闭。

### 文件的打开

在 Python 中，使用 `open` 方法打开文件，语法格式如下：

```
open(文件名 [访问模式信息])
```

在上述格式中，文件名必须填写，而访问模式信息是可选的（访问模式将在本章后面详细描述）。例如，使用以下示例代码打开一个名为 "country.txt" 的文件：

```
entity = open('country.txt')
```

需要注意的是，如果使用 `open` 方法打开文件时未指定访问模式，则必须保证文件存在，否则将报告以下异常信息。

```
FileNotFound {
    // 我们无法找到指定的文件
}
```

### 文档模式

如果使用 `open` 方法仅提供文件名来打开文件，则我们只能读取该文件。如果打开的文件允许写入数据，则必须指明文件的模式。Python 中有许多文件访问模式。`RB`、`WB` 和 `AB` 模式均以二进制模式操作文件。通常，这些模式用于处理二进制类型的文件，如声音或图像。

### 文档的关闭

始终使用 `close` 方法关闭打开的文件。即使程序退出后文件会自动关闭，但考虑到数据安全，每次使用文件后都应使用 `close` 方法将其关闭。否则，一旦程序崩溃，文件中的数据可能无法保存。`close` 方法使用非常简单，具体示例如下：

```
# 创建一个名为 country.txt 的新文件
sample = open('country.txt', 'w')
# 关闭该文件
sample.close()
```

文件最重要的能力是接收数据或提供数据。文件的读写无非是将数据写入文件或从文件中读取数据。接下来，本节将分别解释文件的读取与写入。

### 写入文档

向文件写入数据需要使用 `write` 方法完成。在操作文件时，每次调用 `write` 方法，写入的数据都将追加到文件末尾。

**示例：向文件写入数据**

```
f = open('data.txt', 'w')
f.write('This is an example for writing data')
f.close()
```

程序运行后，程序所在路径下将生成一个名为 `data.txt` 的文件。打开该文件，可以看到数据已成功写入。

> **注意：** 向文件写入数据时，如果文件不存在，系统会自动创建文件并写入数据。如果文件已存在，原文件的数据将被清空并重写新数据。

### 读取文档

从文件读取数据时，可以通过多种方式获取，如下所示。

#### 1. 使用 read 方法读取文件

`read` 方法可从文件读取数据，其定义语法如下：

```
read(size)
```

在上述方法中，`size` 表示从文件读取的数据长度，单位为字节。如果未指定 `size`，则读取文件的所有数据。

**示例：使用 read 方法读取文件**

```
example = open('data.txt', 'r')

```

#### 2. 使用 readlines 方法读取文件

如果文件内容很少，可以使用 `readlines` 方法一次性读取整个文件的内容。`readlines` 方法返回一个列表，列表中的每个元素为文件中的每一行数据。假设文件 `data.txt` 包含三行数据，则使用 `readlines` 方法读取文件的方式如下例所示。

**示例：使用 readlines 方法读取文件**

```
sample = open('data.txt', 'r')
entity = f.readlines()
```

在之前的学习中，文档的读写都是按顺序进行的。然而，在实际开发中，可能需要从文件的特定位置开始读写。此时，我们需要定位文件的读写位置，包括获取文件当前的读写位置和定位文件指定的读写位置。在下一节中，将详细介绍这两种定位方法。

```
os.rename(src, dst)
```

```
import os
```

```
        return result(example-1)+result(example-2)
```

**程序解释：**

在上述程序中，我们使用递归函数根据你的输入查找斐波那契数列。以下是我们遵循的步骤列表：

1.  首先，我们使用 `def` 保留关键字、函数名称以及一个参数创建了一个函数。
2.  该函数使用单个参数 `example`，用于表示需要在序列中生成的斐波那契数的数量。
3.  在下一步中，我们创建了一个控制流条件语句，用于检查某个数字是否满足斐波那契数列。
4.  在条件语句中，结果始终通过函数返回。
5.  在下一步中，我们使用递归机制重复函数逻辑并打印结果。
6.  函数中的最后一步是在满足参数后通知结束递归函数。

这就是 Python 使用函数式编程生成结果的方式。Python 还支持用于高级操作的高阶函数，如 `Lambda`。

## 简单代码的实现

如前所述，要远程重启或关机，Python 首先必须能在本地控制计算机重启或关机。以下是该功能的实现。首先，仅让 Python 控制本地计算机重启或关机。此次开发也称为第一次开发，可作为小软件开发过程中第一个版本的简单程序。

如果想控制本地计算机重启或关机，可以使用 `os.system()` 方法并传入相关的 Shell 指令。可以通过 Shell 命令 `shutdown` 控制计算机关机，也可以通过 Shell 命令 `shutdown -r` 控制计算机重启。

以下是 Python 代码：

```python
import os

# shutdown the system
os.system("shutdown -s -t 1")
```

执行上述代码后，计算机将自动关机。如果想用 Python 代码控制本地计算机重启，可以通过以下 Python 代码实现：

```python
import os

# restart the system
os.system("shutdown -r -t 1")
```

执行上述代码后，计算机将自动重启。因此，简单版本的代码如下：

```python
import os

result = input("Please enter what you want to do: shutdown input 1, restart input 2")
# Note: 1 enclosed in double quotation marks. Because the input is a string instead of the number
if result == "1":
    # shut down
    os.system("shutdown -s -t 1")
    print("shutdown instruction is ready")
elif result == "2":
    # Restart
    os.system("shutdown -r -t 1")
    print("restart instruction is ready")
else:
    print("no operation performed")
```

执行上述程序后，我们将被提示输入所需操作，如下所示：

```text

```

如果我们想关机，可以输入 `1` 并按回车。如果想重启，可以输入 `2` 并按回车。如果输入其他信息并按回车，则不执行任何操作。例如，输入 `3` 并按回车键将输出以下信息：

成功打包的可执行程序可以在 `D:/dist` 目录中找到。`sample` 文件夹是刚才打包生成的与 `project.py` 程序相关的软件文件夹。


# 第 13 章：如何在 Python 中创建类？

面向对象编程是 Python 编程语言的一项基本特性。即使 Python 中存在函数式编程范式，许多开发人员仍倾向于使用面向对象机制来开发程序。有很多原因促使开发人员选择面向对象编程而非函数式编程。在处理算法时，机器学习专家应当非常了解对象和类的创建。本章将全面介绍面向对象编程的基础知识。让我们开始吧！

## 它与过程式编程有何不同？

过程式编程是一种范式，它使用称为函数的可复用代码段来解决问题。向已创建的代码中插入新的逻辑或数据通常很困难。在机器学习环境中，自动重新排列代码段以获得最佳结果往往很重要。这就是为什么机器学习爱好者应当实现相关资源，以便在需要时能够扩展为面向对象模型。

## 面向对象是如何工作的？

面向对象编程采用了一种不同的理念，将志同道合的对象分离到不同的类别中。利用这些类别，你可以单独更改所需的功能。除了更容易维护代码外，它们还可用于保持函数的统一性。我们现在将从数据科学家的角度详细讨论类和对象。

## 什么是类和对象？

从程序员的角度来看，类是为了方便处理对象而开发的**蓝图**。在一个类中，我们通常会将志同道合的变量、方法和构造函数分组，以便于操作它们。在处理小型项目时，过程式编程技术是可行的。然而，随着项目规模的扩大，我们需要编写大量从不同角度做同一件事的代码。为了解决这个问题，开发出了类和对象，通过它们我们可以轻松继承父类并在项目中使用它们。

## 类由什么组成？

类由能够执行特定任务的方法组成。类中有全局变量和局部变量，可根据情况使用。程序员可以将所有这些方法和变量作为对象实例来使用。

## 如何定义类？

在 Python 中，与 Java 不同，你需要使用 Python 文件来存储类。在 Java 编程语言中，程序员通常将单独的类文件保存为 `.class` 扩展名。然而，Python 通过使用相同的 `.py` 格式使事情变得简单。在下一节中，我们将使用一个示例来帮助你理解在 Python 中创建类的过程。要掌握面向对象编程，我们首先需要了解面向对象编程的基本理论和概念。本节将详细介绍面向对象编程的基本理论和概念。

## 现实生活中的面向对象场景

在我们生活的世界中，任何具体的事物都可以被视为一个对象，每个对象都能处理某些事情或拥有某些静态特征。例如，每个具体的人都可以被视为一个对象。这个对象可以处理一些事情，如吃、唱、写等。该对象实现的某些功能可以称为该对象的**方法**。同样，这个对象也有一些静态特征，如头发、手臂、身体等。你可以将该对象的静态特征称为该对象的**属性**。因此，方法是动态的，属性是静态的。

如果将 Tony 视为对象 A，Christopher 视为对象 B，Tony 和 Christopher 可以进行通信并传递一些信息。在面向对象的思维方法中，对象之间也可以传递和通信消息，从而使每个对象形成一个强大而复杂的网络，进而实现某些复杂的架构和功能。

根据自然界中各种对象的共性，可以将对象抽象为类，任何对象都必须属于某个类。对象是具体的，类是抽象的。例如，现在有以下对象：

- 对象 A：Tony 是一个人。
- 对象 B：Tony
- 对象 C：一个具体的橙子
- 对象 D：一个具体的苹果

根据对象 A 和对象 B 之间的共性，可以将对象 A 和对象 B 抽象为人类，简称 human。根据对象 C 和对象 D 之间的共性，可以将对象 C 和对象 D 抽象为水果类。因此，对象 A、B、C、D 都有各自的类。当然，对象 A、对象 B、对象 C 和对象 D 之间的共性也可以被提取并抽象为生物类。

在面向对象编程中，我们可以根据需求将复杂的软件划分为各种所需的类，然后编写各种方法和属性。在具体使用时，可以直接根据类实例化为具体的对象，然后实现相关功能。实例化的过程是将抽象事物转化为具体事物的过程。实例化后，可以使用相关对象实现软件相对复杂的架构和功能。可见，通过面向对象思维进行编程可以使程序开发更贴近现实世界，更方便地实现复杂的功能和架构。

## 进阶概念

通过以上介绍，相信大家对面向对象的基本思想有了简单的了解，本节将具体介绍如何将面向对象方法应用于程序设计。例如，要实现一个大型项目，可以将项目划分为不同的组件，将每个不同的组件视为每个类，然后分别对这些组件进行编程，最后将各个组件组装成一个大型项目。这种方法可以整体控制项目，使项目开发更加高效。

面向对象编程不同于面向过程编程。面向过程编程是根据该项目的具体过程编写程序。这种方法适合编写中小型程序，而对于较大的项目，可以用面向对象的思维来处理。如果大型项目也按照面向过程编程的思想进行开发，效率会较低，而采用面向对象编程思想进行开发，只需将项目划分为各种类（即大型项目各部分的抽象形式），然后开发各种类，再将各种类组合起来。当需要使用时，可以直接根据类创建具体对象，然后通过各个对象实现相应的具体功能。

类是面向对象中一个比较重要的概念，对象也是面向对象中一个比较重要的概念。类和对象的概念通常一起提及，本节将向你展示如何使用 Python 实现类和对象。

## 如何创建类？

类是某些对象之间共性的抽象。通俗地说，类是许多相同事物的综合。例如，一首好歌、一幅书法和一本好看的小说都是对象。你可以思考这些事物的共性是什么，用什么来概括它们？它们可以用一个称为“文学艺术”的类来概括。文学艺术不代表任何具体的事物，它是一个抽象概念。简而言之：类是对象的抽象，对象是类的具体表现，也称为类的**实例**。例如，正如我们刚才介绍的，一首优美的歌曲、书法、一本优美的小说这些对象可以抽象出文学艺术这一类别。当我们说文学艺术时，它必须是抽象的，所以类别是对象的抽象。

## Python 中类的使用

在 Python 中，如果你想实现面向对象编程，首先需要划分相应的类，然后编写具体的代码来实现这些类。如果你想在 Python 中创建一个类，可以使用以下格式：

```
Class Name ():
    { Enter the implementation procedure here }
```

例如，如果你想创建一个 human 类，可以按照以下代码进行：

```
class man:
    pass
```

这里，`pass` 语句没有实际意义，但被称为**占位符语句**，用于确保程序的完整性。运行上述程序后，我们可以进行如下输入：

```
>>> print(man)
```

正如你所见，当前对应的输出结果是 "class ……"，表明此时 man 是一个类。

## 对象的应用示例

一般来说，类不能直接用于实现相关功能和操作，因为类是抽象的。此时，通常会将相应的类实例化为相应的对象，然后通过相应的对象实现相关功能和操作。在 Python 中，将类实例化为对象的格式如下：

```
Object {Enter the name here} = Class Name (You can enter your parameters here)
```

正如你所见，如果你想实例化类，只需在类名后加上括号即可。例如，上面定义的类 `man` 可以通过以下代码实例化为 vehicle 对象：

```
class man:
    pass
vehicle = man()
```

正如你所见，实例化时只需遵循上述描述的相应格式。运行上述程序，然后进行如下调试输入：

```
>>> print(vehicle)
# This is an object
# "A36FA90"
```

可以发现，输出 vehicle 时，结果是 "…object…"，其中 object 表示 vehicle 已被初始化，而上述输出结果中的 "A36FA90" 是 vehicle 的具体存储空间。值得注意的是，同一个类下可能有多个对象，即可以基于一个类实例化多个不同的对象。几个不同的对象可能具有一些共同的特征和功能，但它们代表不同的个体。例如，在 human 类下，不仅可以实例化 vehicle 对象，还可以实例化 car 和 bus。虽然 vehicle、car 和 bus 具有一些共同的特征或方法，例如具有进食功能、具有头发、身体等特征（因为它们是基于同一个类实例化的），但这些对象代表不同的个体且是不同的。修改 vehicle 对象不会影响 car 和 bus 等其他对象。

我们不妨跟随上述程序运行并输入以下代码进行演示：

```
>>> vehicle = man()
>>> car = man()
>>> print(car)
>>> print(vehicle)
```

因此，这两个对象属于不同的个体，两个对象之间可以通信，但没有必然的影响。至此，我们完成了 Python 中类的简要介绍。在下一章中，我们将详细讨论循环。请继续关注！

# 第 14 章：如何在 Python 中创建循环？

机器学习通常依赖于重复执行任务，直到其成为查询的完美样本。要在 Python 中显著实现这些结果，我们需要有效地使用循环。Python 在其库中提供了多种循环结构。在本章中，我们将通过示例详细讨论各种循环。

## 什么是循环？

简单来说，循环是一种编程结构，可以根据需要重复执行任务任意次数。您可以使用不同的逻辑判断来控制结构循环的次数。在本章中，我们将结合示例详细讨论 `for` 和 `while` 循环。

在详细讨论循环之前，我们建议您充分理解控制流语句中判断的概念。判断是一个通俗的概念，仅当条件满足时才处理逻辑实体。如果条件不满足，程序将停止或自行终止。

在现实生活的例子中，我们可以用红绿灯来帮助您理解理解循环结构所必需的这一基本概念。当红灯亮起时，您不能过马路，因为这是必须遵守的条件。判断也本质上用于条件语句和情况语句。然而，在本章中，我们将只讨论循环结构。

## `while` 语句

Python 中的 `while` 语句主要用于控制语句的重复执行。`while` 语句的基本用法格式如下：

```
while (输入逻辑值):
    输入语句;
```

其中，如果不需要，`else` 子句部分可以省略。

### 如何使用 `while` 语句？

`while` 语句非常方便。例如，您想反复输出 "I like This programming language!"。此类内容可以通过以下过程实现：

```
instance = True
while instance:
    print("I like This programming language!")
```

当然，该程序是一个死循环程序。所谓死循环是指循环不会终止，而是会继续运行。这种死循环程序通常不推荐，此处仅用于演示。

可以看出，执行程序后，将反复显示以下内容作为输出：

```
I like This programming language!
I like This programming language!
I like This programming language!
I like This programming language!
...
```

此时，读者已经学会了编写不带 `else` 子句的简单 `while` 循环语句。下面是另一个使用 `else` 子句解释 `while` 循环的语句：

```
instance = False
while instance:
    print("I like this programming language")
else:
    print("This is not a good language")
```

在该程序中，因为条件为假，它将进入 `else` 子句部分执行相应内容，程序的输出结果将为：

```
This is not a good language
```

在 Python 中，您可以在 `while` 语句下使用 `if` 语句，也可以在 `if` 语句下使用 `while` 语句。这种在某一语句下使用当前语句或其他语句的方式称为嵌套使用。

例如，如果您希望程序循环 10 次，前 5 次输出 "even"，后 5 次输出 "odd"，可以按如下方式编写：

```
first = 0
while first < 10:
    if first < 5:
        print("even")
    else:
        print("odd")
    first = first + 1
```

此时，`if` 语句位于 `while` 语句之下。`if` 语句主要判断是前 5 次输出还是后 5 次输出，变量 `first` 主要用于控制循环次数。

当前程序的输出为：

```
even
even
even
even
even
odd
odd
odd
odd
odd
```

可以看出，所需功能已成功实现。

## `for` 循环

Python 中的 `for` 语句是另一种循环语句，使用非常广泛。`for` 语句按以下格式执行：

```
for 变量 in 集合:
    执行此部分
```

可以看出，Python 中的 `for` 语句主要通过依次遍历集合中的元素来实现。相关的集合不是 `set` 数据类型，而是由多个元素组成的对象，可以是 `list`、文件对象或其他包含多个元素的对象。

### 如何使用 `for` 循环？

如果您需要依次输出列表中的所有元素，可以轻松使用 `for` 循环。例如，您需要按顺序输出列表 `list = ["Python", "Java", "Internet", "Deep learning", "Hadoop"]` 的以下元素，可以通过以下代码实现：



```
list = ["Python", "Java", "Internet", "Deep Learning", "Hadoop"]
for instance in list:
    print(instance)
```

在该代码中，首先定义了 `list`，然后通过 `for` 语句循环依次遍历 `list` 中的每个元素。程序中的 `instance` 相当于一个变量，每次迭代变量时都可以获得 `list` 中当前循环取到的元素。`instance` 只是一个变量名，可以替换为其他名称，如 `entity`、`result` 等。

该程序的结果如下：

```
Python
Java
Internet
Deep learning
Hadoop
```

正如您所见，列表中的每个元素都已成功依次访问。

`for` 语句经常与 `range()` 函数一起使用。`range(a, b)` 函数可以生成从数字 `a` 到数字 `b` 的一系列序列数据，因此它可以控制循环次数和循环期间 `i` 的值。

例如，如果您想输出 1 到 20 的数字，可以通过以下过程实现：

```
for extra in range(0, 20):
    print(extra + 1)
```

在该程序中，通过 `range(0, 20)` 生成 `0 ~ 19`，变量 `extra` 每次将加 1。由于此循环中 `extra` 的值为 `0 ~ 19`，而要输出的数据为 `1 ~ 20`，因此只需在输出时直接输出 `extra + 1` 即可。

可以看出，`range()` 函数生成的数据是按顺序生成的。如果要生成的数据间隔不是 1，而是 3、5、-1 等数字，只需设置 `range()` 的步长即可。通常，步长在 `range()` 的第三个参数中指定。

例如，您可以输入以下程序：

```
for example in range(1, 10, 3):
    print(example)
```

此时的输出为：

```
1
4
7
```

可以看出，数据的间隔是设定的步长 3。

接下来，让我们看一个带有嵌套的 `for` 语句。例如，如果需要依次判断 1 到 10 的每个数字是偶数还是奇数并输出判断结果，可以通过以下过程实现：

```
for instance in range(1, 11):
    if instance % 2 == 0:
        print(str(instance) + " even")
    else:
        print(str(instance) + " odd")
```

程序通过取余运算判断该数字能否被 2 整除。如果能整除，则表示该数字为偶数；否则为奇数。可以看出，通过显示的输出，相关功能已经可以实现。

## 中断机制

在程序执行过程中，例如在循环结构中，当希望满足某个条件或程序执行到某个位置时，允许循环或程序中断执行。即不执行循环体后面的程序或相应程序块后面的程序，可以通过程序执行的中断机制来实现相应功能。

一般来说，中断机制常用于循环体中，以更好地实现循环的退出和使用。循环体中的中断机制一般分为两种结构：`break` 语句结构和 `continue` 语句结构。这两种中断语句的应用场景不同，将分别介绍。

### `break` 语句

`break` 语句可以强制停止循环执行。`break` 语句用于循环语句中。如果发生 `break`，循环的执行将直接停止。`break` 语句的功能正如其名，是打破程序的执行。

`break` 语句常用于循环结构中。当 `break` 语句出现在循环结构中时，可以强制停止循环，然后退出循环。

#### `break` 语句用于 `while` 循环

如果 `break` 语句出现在 `while` 循环中，它将退出 `while` 循环并继续执行后续代码。

例如，如果您想使用 `while` 循环按顺序输出 1 到 9 的数字，可以按如下方式编写：

```
first = 1
while first:
    print(first)
    first = first + 1
    if first == 10:
        break
```

可以看出，如果上述程序中没有 `if` 语句，程序将永远执行而不会停止，即会发生死循环。添加一个 `if` 语句，然后在 `if` 语句中使用 `break` 语句，这意味着如果 `if` 语句中的条件得到满足，则执行 `break` 语句，执行 `break` 语句后，退出 `while` 循环。

在上述程序中，`first` 每个循环将加 1。当 `first` 加到 10 时，顶部的输出刚好是 9，也就是说，不需要再次循环，可以退出循环的执行。

#### `break` 语句用于 `for` 循环

除了在 `while` 循环中中断外，也可以在 `for` 循环中中断。在 `for` 循环中，您可以使用以下语句轻松输出 5 到 8 的数字：

```
for i in range(5, 9):
    print(i)
```

如果您想在不更改上述程序的情况下输出 5 到 7 的数字，可以添加以下 `break` 语句进行中断控制：

```
for first in range(5, 9):
    print(first)
    if first > 6:
        break
```

在上述程序中，当循环中的 `i` 执行到 7 时，输出 7 后需要中断循环的执行，因此通过 `if first > 6` 判断当前 `i` 是否已执行到 7。如果满足此条件，此时 `first` 已达到 7，可以通过 `break` 语句中断循环。

上述程序的最终输出如下：

```
5
6
7
```

### `continue` 语句

`continue` 语句是另一种中断结构语句，其功能是强制停止循环中当前迭代的执行，直接跳转到下一次执行，这与 `break` 语句的功能不同。`continue` 语句是放在循环语句中以结束当前迭代的语句。

首先，我们应该知道循环被分为许多次迭代，`continue` 语句终止的是当前迭代，而不是整个循环。

同样，让我们给您一些 `continue` 语句应用的示例。这是一个示例：

```
if i == 22:
    print("Enter the statements")
    continue
```

在上述示例中，仅当条件满足时才会执行该语句。如果条件不满足，它将继续执行其他现有语句。
