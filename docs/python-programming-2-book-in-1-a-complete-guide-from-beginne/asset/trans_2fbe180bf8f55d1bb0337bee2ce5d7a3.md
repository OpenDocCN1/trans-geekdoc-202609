## 什么是语句？

当声明变量时，表达式被用来创建和处理对象。如果加入了一些逻辑控制，就形成了语句。也可以说语句包含表达式，因此语句是 Python 程序最基础的基础设施。

## Python 赋值语句

学习 Python 中的赋值语句，能让学习其他语句变得更容易。学习 Python 赋值语句主要是为了掌握并理解其逻辑。

### 1. 赋值语句

Python 中赋值语句的本质是创建一个对对象的引用。赋值主要有以下几种方法。

#### a) 基本赋值方法

`first=5`

这等同于创建一个变量 `first`，使其指向内存中存储的对象 `5`。`first=5` 是一条赋值语句。执行赋值操作后，您可以随意打印或显示 `first` 的值。

#### 2) 理解赋值逻辑

在声明变量时，至少包含两部分：一是用于存储变量名的变量表，二是内存存储区 [4,6]。当声明 `first=5` 时，系统首先在内存区开辟一个存储空间，存入值 `5`，然后让变量 `first` 指向内存中存储的对象 `5`，这相当于在内存存储区先有了对象 `5`。接着 `first` 出现在变量表中，并指向 `5`。这种指向也可以称为“引用”。

虽然赋值语句的语法很简单，但请仔细理解 Python 中的赋值逻辑。这种赋值逻辑影响 Python 的方方面面。如果您理解了赋值逻辑，就能更好地理解和编写 Python 程序。如果您有 C 语言编程经验，您会知道 C 程序中的变量存放的是值，而 Python 中的变量指向一个值。变量仅以引用关系存在，不再具有存储功能。在 Python 中，每个数据都占据一块内存空间，数据在 Python 中被称为对象。整数 `5` 是一个 `int` 对象，`'hello'` 是一个字符串对象，`[1, 2, 3]` 是一个列表对象。在 Python 中，您可以使用全局内置函数 `id(obj)` 来获取对象的 id，即对象在内存中的存储地址。全局内置函数直接使用，无需引用任何包。

> **注意：** 变量 `first` 前后地址的变化表明变量指向了对象！对象一旦创建，就不能被直接销毁。因此，在上述示例中，变量 `a` 先指向对象 `5`，然后继续执行 `a=a+5`，这会产生一个新对象 `10`。由于对象 `5` 无法被销毁，让 `A` 指向新对象 `10`，而不是用对象 `10` 覆盖对象 `5`。代码执行完毕后，内存中仍然存在对象 `5` 和 `10`，但变量 `A` 指向了新对象 `10`。如果没有变量指向对象 `5`（即无法被引用），Python 将使用垃圾回收机制来决定是否回收它（这是自动的，不需要程序员操心）。Python 内部有一套垃圾回收机制。垃圾回收机制检测到如果在特定时间内没有变量引用某个对象，该对象将被回收，释放其占用的资源。Python 内部有一个引用计数器，垃圾回收机制根据引用计数器判断对象是否有引用，以决定是否自动释放对象占用的资源。垃圾回收机制针对 Python 中无引用的对象，并根据引用计数器得出的结果进行推断。这种理解也非常重要。当我们将来谈到列表等数据类型时，将再次看到正确理解变量指向对象的重要性。

在介绍其他 Python 语句之前，让我们先看看 Python 过程控制中的顺序执行以及基本输入和输出。顺序执行是过程控制中默认的代码执行方式，相对简单。其基本原则是代码执行的顺序与程序代码编写的顺序一致。程序执行顺序与编写顺序一致。上述程序中的数据是固定在程序中的，但有时可能需要程序员或软件用户在程序运行过程中向程序输入一些数据，这需要输入函数。

## `input()` 函数

控制台输入通过全局函数 `input()` 实现。`input()` 函数接收用户从控制台输入的信息。默认类型为 `str` 字符类型，可根据需要转换为特定的数据类型。如果您想在用户输入数据时给予一些提示，可以在 `input()` 函数中传入一个带有提示信息的参数！

## `eval()` 函数

`eval()` 函数将 `str` 字符数据作为有效表达式进行求值并返回结果。简单来说，就是去掉字符串左右两端的引号。

## `print()` 函数

此处的 `print()` 函数仅输出对象或变量的值。`print()` 函数有一些常用参数，在实际开发中使用非常灵活。如果您想用一行特殊字符来分隔前后行的输出，例如用 20 个 "=" 来分隔前后行的输出，可以使用 `print("="*20)` 来实现。

### 1) 一行输出多个变量，默认以空格分隔

在一行中输出多个以逗号分隔的内容，分隔符为空格。

### 2) 一行输出多个变量，并更改它们之间的分隔符

如果您希望输出用其他分隔符分隔，可以编写分隔符语句。此处可以使用任意字符作为分隔符，即 `print()` 函数可以手动指定分隔符。

### `print()` 函数多行输出在一行

在 `print()` 函数的参数表中，有一个参数 `end` 用于指定终止符。默认情况下为换行符，即 `end='\n'`。因此，通过指定终止符，可以使多条 print 语句的输出在同一行。

`print()` 函数的默认分隔符为空格，终止符为换行符 `\n`。理解上述内容后，在实际开发中输出的灵活性将大大提高。

## 数字打印格式

通过格式化字符串指定输出数字的格式或位数。

### 1) 输出指定位数的小数

在打印格式中，花括号中的 `:` 表示当前位置出现的值将被格式化，`.2f` 表示后续值按浮点数输出，但仅保留 2 位小数，第三位四舍五入。

### 2) 输出固定宽度的值

如果您想指定整体数字输出的宽度，形式如下：`width {输入值}`

> **注意：** `{:12, .2f}` 表示总宽度，默认右对齐，位数不足时前面补空格；`,` 表示千位分隔符；`.2f` 表示保留 2 位小数。

因为有时需要在控制台输出多行内容，且每行有多列，但每行长短不一。如果想排版更整齐，这时可以使用这种方法。关于 `print()` 函数的更多用法，请通过 `help(print)` 命令查阅。
