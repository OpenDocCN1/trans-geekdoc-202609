In this chapter, we are going to discuss various types of functions in detail. We will also discuss user-made functions with the help of an example.

According to whether there are parameters and return values, functions can be roughly divided into four types:

1.  Functions that have no parameters and no return value.
2.  Functions that have no parameters but return a value.
3.  Functions that have parameters but do not return a value.
4.  Functions that have parameters and return values.

Next, the four types will be explained in detail.

### What is a user-made function?

A user-made function is a function that creates a function with its parameters and logic. We usually have system functions such as `print()`, `math()` to solve a lot of day-to-day problems. User-made functions are usually used for repetitive tasks.

In the next section, we will introduce you to a business card manager application that uses various user-made functions. Follow along to understand the essence of functions in programming.

# Get the information entered by the user

After the `while` loop prints the menu, call the `useinput()` function to obtain the information entered by the user, as follows.
