
# 第 3 章：Python 的不同版本？

Python 是一门编程语言，由各路程序员通过协作不同资源持续开发而成。1984 年，Python 的首个版本发布，多年来它不断更新，增加了各种功能。在本章中，我们将讨论各种 Python 版本及其能力。

## 大多数程序员使用哪个版本？

截至撰写本文时，Python 程序员主要依赖 Python 2.x 版本进行应用开发。即使发布 10 年后，由于函数的复杂实现，Python 3.x 版本在社区中仍未被广泛使用。然而，Python 3.x 版本也为高级机器学习应用提供了许多新特性。鉴于本书专注于机器学习，我们建议您尝试使用 Python 3.x 版本进行应用开发。

## 为什么版本很重要？

当一门编程语言被开发时，往往存在 Bug 和安全问题的隐患，这可能会毁掉其声誉。这是编程语言经常更新至兼容性更好的新版本的原因之一。Python 开发者于 2008 年开始提供具有高级功能的 Python 3.x 版本，但伴随着语法和实现格式的变更。程序员们已经习惯了 2.x 版本的功能，因此未能跟上这一变化。然而，随着岁月流逝，Python 3.x 有了巨大改进，现在已成为一个具有高级特性的高效 Python 版本。Python 下载主页提供所有这些版本的下载，只需点击即可。您只需理解并分析哪个软件版本符合您的需求。在下一节中，我们将提供所有已发布的主要 Python 版本的完整特性。

## Python 版本历史

### a) Python 1 版本

Python 的第一个版本于 1984 年开发并发布。当时，C 语言很流行，占据了编程市场的很大份额。到 1995 年，Python 开发者已在包中加入了 `lambda` 和 `maps` 等高阶函数。从编程角度来看，Python 的第一个版本是一个巨大的成功。然而，由于不同的兼容性原因，它仍未成为程序员的最爱。

### b) Python 2 版本

Python 2 版本改变了 Python 在编程界的影响力。此版本引入了列表推导式和函数式编程等许多新特性。此外，版本 2 使 Python 函数声明变得更加容易。引入了垃圾回收机制和运算符重载等许多新概念，使该版本更易于操作和维护。直到 2020 年，Python 开发者将继续维护版本 2 的 Python。

### c) Python 3 版本

Python 3 版本初次推出时在编程领域表现不佳。初次发布时，许多程序员抱怨函数声明的问题。然而，随着时间的推移，随着版本的更新，Python 在编程界展现了其影响力。许多高级科学应用开始使用 Python 3 中引入的系统函数来实现其程序。Python 3 还对类型声明进行了许多更改，并已成为最成功的 Python 版本之一。

## 您应该选择哪个 Python 版本？

选择哪个版本取决于程序员个人更舒服的那个。不过，这里有经验丰富的程序员给初学者的建议。

> “请始终根据您的需求选择 Python 版本。如果您想开发一个简单的爬虫应用，那么使用旧版本是合理的。如果您试图构建一个涉及各种新功能的高级应用，我们建议您尝试较新的版本。”

## 哪个版本最适合数据科学家？

在本书中，我们主要讨论 Python 3 版本。该版本对机器学习库的支持更好，且包含大量列表操作。由于我们要处理大量数据，操作列表项是一项必不可少的任务。因此，我们建议您尝试使用 Python 3 版本开发机器学习项目。

## 哪个版本最流行？

截至目前，许多 Web 和移动应用程序都是使用 Python 2 版本开发的。然而，Python 将于 2020 年后正式停止支持 Python 2，此后我们将看到使用 Python 3 的程序员数量反弹。根据哈佛大学最近的一项研究，Python 2 是有史以来最简单、最直观的 Python 版本之一。至此，我们已在本章中完成了 Python 版本的简要介绍。在下一章中，我们将详细讨论函数式编程。请继续跟随学习！
