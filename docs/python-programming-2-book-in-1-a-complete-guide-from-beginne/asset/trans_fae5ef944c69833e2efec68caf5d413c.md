
# 第 8 章：Python 中的结构

Python 是一门结构化语言，并提供各种结构来存储和操作数据以执行操作。在本章中，我们将详细讨论列表等结构。本章大部分内容为理论性质，需要理解之前解释的各种概念。让我们开始吧！

## 什么是列表？

之前学习的字符串数据类型可用于存储单条字符串信息。但假设一个班级有 100 名学生。如果你想存储该班所有学生的姓名，你需要定义 100 个变量，每个变量存储一名学生的姓名。然而，如果有 1,000 名学生或更多，该怎么办？你很幸运，因为列表等结构可以解决上述问题。

列表是 Python 中的一种数据结构，可以存储不同类型的数据。创建列表的方法非常简单：只需使用方括号将用逗号分隔的不同数据项括起来。示例代码如下：

```
A = [1, 'Tom', 'a', [2, 'b']]
```

与字符串的索引一样，列表索引从 0 开始。我们可以通过下标索引访问列表中的值。

### 示例：使用索引访问列表元素

```
A = ['Tom', 'Sam', 'Ram']
print(A[0])
print(A[1])
print(A[2])
```

在本示例中，使用索引来访问列表中的元素，其中第一个元素的索引为 0，第二个元素的索引为 1，依此类推。

为了更高效地输出列表的每个数据，我们可以使用 `for` 和 `while` 循环来遍历输出列表。以下是一个案例研究，说明如何使用 `for` 和 `while` 循环遍历列表。

### 1. 使用 `for` 循环遍历列表

使用 `for` 循环遍历列表的方法非常简单；只需在 `for` 循环表达式中将列表作为序列进行遍历。接下来，将通过一个案例来理解此场景。

```
getdetails = ['Sam', 'Tom', 'Ram']
for name in getdetails:
    print(name)
```

在本示例中，当使用 `for` 循环遍历列表时，由于列表本身就是一个序列，因此可以直接将 names 列表用作 `for` 循环表达式的序列，逐个获取列表中的元素。

### 2. 使用 `while` 循环遍历列表

要使用 `while` 循环遍历列表，首先需要获取列表的长度，并将获取的列表长度作为 `while` 循环的条件。接下来，将展示一个案例，如下例所示。

#### 示例：使用 `while` 循环遍历列表

```
getdetails = ['Sam', 'Tom', 'Ram']
length = len(getdetails)
first = 0
while first < length:
    print(getdetails[first])
    first += 1
```

在本示例中，当使用 `while` 循环遍历列表时，因为 `while` 循环需要指定遍历次数，所以有必要使用 `len()` 函数获取列表的长度，即要遍历的元素数量。

## 列表常用操作

### 向列表添加元素

向列表添加元素有多种方法，如下所示：

1.  可以通过 `append()` 向列表添加元素。
2.  `extend()` 允许你将另一个列表中的元素逐个添加到列表中。
3.  通过 `insert(index, object)` 在指定位置索引之前插入元素对象。

接下来，我们将通过以下案例研究演示这些方法的用法。

#### 1. 通过 `append()` 向列表添加元素

使用 `append()` 添加到列表的元素位于列表的末尾。接下来，我们将通过一个案例进行演示，如下例所示。

```
# 提示并添加元素
temp = input('please enter the name of the student to be added:')
A.append(temp)
```

在该示例中，程序使用 `append()` 在列表末尾添加元素，并分别在添加元素前后使用 `for` 循环遍历列表，以验证列表中的元素是否添加成功。

#### 2. 通过 `extend()` 向列表添加元素

使用 `extend()` 将一个列表的所有元素添加到另一个列表中。接下来，将展示一个案例。

#### 示例：使用 `extend()` 添加列表元素

```
first = [1, 2]
second = [3, 4]
first.append(second)
print(first)
first.extend(second)
print(first)
```

在本示例中，`append()` 用于将列表 `second` 添加到列表 `first` 的末尾，然后 `extend()` 用于将列表 `second` 的所有元素添加到列表 `first` 中。

#### 3. 通过 `insert()` 向列表添加元素

使用 `insert()` 在列表的指定位置添加元素。接下来，将展示一个案例，如下例所示。

#### 示例：使用 `insert()` 向列表插入元素

```
sample = [0, 1, 2]
sample.insert(1, 3)
print(sample)
```

在本示例中，第二行代码使用 `insert()` 在索引 `1` 处向列表添加元素 `3`。

### 在列表中查找元素

所谓的查找是查看指定元素是否存在。下面解释了 Python 中用于查找的常用运算符。

1.  `in`（存在）：如果存在，结果为 `True`；否则为 `False`。
2.  `not in`：如果不存在，结果为 `True`，否则为 `False`。

接下来，使用一个案例演示如何在列表中查找元素。

#### 示例：在列表中查找元素

```
findName = input('please enter the name you want to find:')
# 查找是否存在
if findName in {Enter entity details here}:
    # ...
```

在该示例中，通过遍历列表，查明指定元素是否存在于列表中。程序运行后，将产生两种结果。

### 从列表中删除元素

在现实生活中，如果学生转班，则应删除该转班学生的信息。删除功能在开发中经常使用。列表元素有三种常见的删除方法，如下所示：

1.  `del`：根据下标删除。
2.  `pop()`：取出末尾元素。
3.  `remove()`：根据元素的值删除。

接下来，我们将通过以下案例演示上述三种删除方法的用法。

#### 1. 使用 `del` 删除列表

`del` 可用于删除整个列表或特定元素。接下来，我们将通过一个案例进行演示。

#### 示例：使用 `del` 删除列表中的元素

```
del movieName[2]
```

#### 2. 使用 `pop()` 删除列表元素

`pop()` 可用于删除列表的最后一个元素。接下来，将展示一个案例。

```
movieName.pop()
```

#### 3. 使用 `remove()` 移除列表元素

使用 `remove()` 移除列表的指定元素。接下来，我们将通过一个案例进行演示。

```
movieName.remove('lord of the rings')
```

### 列表的排序操作

如果你想重新排列列表中的元素，可以使用 `sort()` 或 `reverse()` 方法。其中，`sort()` 方法按特定顺序重新排列列表中的元素。`reverse()` 方法用于反转列表。接下来，使用一个案例演示这两种方法的用法。

#### 示例：列表的排序操作

```
sample = [1, 4, 2, 3]
sample.reverse()
sample.sort()
print(sample)
```

在该示例中，第二行代码将列表按逆序排列，第四行代码将列表按升序排列，第六行代码打印排序后的列表。
