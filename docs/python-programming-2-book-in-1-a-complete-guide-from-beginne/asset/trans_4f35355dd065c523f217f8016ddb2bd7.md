

# 第 4 章：函数式编程与推导式

函数是一种数学概念，可用于以确定的方式重复任务。传统编程语言在编程中采用了这一概念，以实现重复性任务的自动化。然而，随着时间的推移，开发者开始部署各种系统函数，使编程语言更加直观和易用。在本章中，我们将通过大量示例详细讨论函数式编程提供的各种功能。

## 函数式编程的特征

与普遍看法相反，函数式编程既可以与命令式范式协作，也可以与面向对象范式协作。以下是一些需要记住的目标，以便重新评估一门编程语言是否支持完整的函数式范式：

1.  **函数也是对象。** 它们可以执行对象能够执行的每一项任务。它们可以用于在函数内部调用另一个函数。
2.  **使用递归进行循环。** 许多函数式编程范式使用递归来循环结构。某些范式仅提供递归来执行循环任务。
3.  **列表处理。** 函数式编程也适用于列表。它们常被用来处理和遍历列表。
4.  **表达式优于语句。** 函数式编程不太擅长处理语句。然而，它们可以非常有效地用于求值那些包含逻辑实体的表达式。
5.  **高阶函数。** 函数式编程还提供精确的高阶函数。

Python 遵循上述所有特征，被称为一门纯函数式语言。在下一节中，我们将详细讨论在 Python 中使用函数的方法。

## 什么是函数？

函数是一种可复用的代码片段，可根据指定需求一次性重复执行任务。例如，观察以下模式：

```
' {}'
'{}{}'
'{}{}{}'
```

根据我们的需求，我们需要在一行中显示 100 组这样的配对。你可以在大量辛苦工作后使用 `print` 函数来显示结果。然而，这种方法不可行，也不是程序员所推崇的。在这里，可以使用函数来封装该模式，并根据需要随时随地调用任意次数。你可以使用循环语句将该模式循环 100 次。在下一节中，我们将使用 Python 中的函数来实现这一结果。

## 如何定义函数？

函数的定义应遵循 Python 语言所具备的特定规范。以下是 Python 中函数使用的格式：

```
def {输入函数名称} [ 在此输入参数 ]
```

这是一个示例：

```
def sum(a,b)
```

定义函数后，你只需为函数体创建一个分步的逻辑表达式即可。

## 如何调用函数？

定义函数后，你需要知道在需要时调用它的过程。在 Python 中，可以使用以下格式实现函数调用：

```
函数名称()
```

### 练习 1：使用函数打印 100 行 '{}' 模式

这是 Python 代码：

```
def funpattern() {
    for (i=100;i++) {
        print ( " {}")
        i++;
    }
}

Print( " Here is the result")
funpattern()
```

## 函数参数

参数对于函数定义默认值是必需的。变量通常指向函数中的参数，且对于逻辑执行是必要的。通常存在定义函数本质的默认参数。格式如下：

```
[ 函数参数 1, 函数参数 2 ...... 函数参数 n ]
```

重要的是要记住，函数参数的数量可以是动态的。你通常可以使用这些参数来返回值。在下一节中，我们将给出一个示例，帮助你详细理解递归。

## 什么是递归？

递归是一种数学现象，即函数调用自身直到满足条件。递归可以非常有效地减少程序的代码长度。许多程序员认为递归函数是从程序中获得完整性能的简便方法。这是一个示例：

```
def result(example):
    if example == 0:
        return 0
    elif example == 1:
        return 1
    else:
        return result(example-1)+result(example-2)
```

**程序解释：**

在上述程序中，我们使用递归函数根据你的输入查找斐波那契数列。以下是我们遵循的步骤列表：

1.  首先，我们使用 `def` 保留关键字、函数名称以及一个参数创建了一个函数。
2.  该函数使用单个参数 `example`，用于表示需要在序列中生成的斐波那契数的数量。
3.  在下一步中，我们创建了一个控制流条件语句，用于检查某个数字是否满足斐波那契数列。
4.  在条件语句中，结果始终通过函数返回。
5.  在下一步中，我们使用递归机制重复函数逻辑并打印结果。
6.  函数中的最后一步是在满足参数后通知结束递归函数。

这就是 Python 使用函数式编程生成结果的方式。Python 还支持用于高级操作的高阶函数，如 `Lambda`。

## 函数式编程为何对机器学习至关重要？

学习 Python 中的函数式模块是强制性的，因为许多第三方机器学习支持库（如 `Pandas`）使用函数来生成算法和图表。如果你不了解如何定义自定义函数，为数据集生成无监督和有监督算法将变得麻烦。此外，使用函数将你的逻辑思维转化为编程代码也很容易。为了提高你对函数模块的了解，我们建议你阅读各种第三方库的文档。

## 高阶函数

Python 支持高阶函数。版本 3 提供了许多高阶函数，如 `Lambda`、`filter`、`reduce`。本节将详细描述其中许多函数。

### 什么是高阶函数？

其工作方式与递归相同。在高阶函数中，参数也是函数。你可以使用 `n` 个函数作为参数，并获得一个函数作为结果。高阶函数使用可迭代概念来分析不同类型的函数。Python 默认提供 `map()` 和 `reduce()` 函数。然而，所有其他高阶函数都应手动导入才能工作。许多数据科学应用使用高阶函数以获得完美的结果。

#### a) Map

`map` 是一个 Python 高阶函数，可用于转换数据集的位置。在机器学习中，数据点的转换是一种常见现象，对于开发回归算法至关重要。格式如下：

```
map (在此输入数据集的坐标, 迭代点)
```

#### b) Filter

`filter` 是一个 Python 高阶函数，可用于根据给定场景预测数据点。该高阶函数广泛用于预测算法。许多视频流网站（如 YouTube 和 Netflix）使用 `filter` 存储用户信息以推荐类似视频。格式如下：

```
filter (预测分析, 迭代)
```

#### 3) Compose

`Compose` 是一个 Python 高阶函数，可以按重要顺序输入函数作为参数。它甚至可以使用循环作为控制流语句来维持程序的逻辑流程。`Compose` 常用于高级数据分析应用。格式如下：

```
compose(在此输入高阶函数) {
    // 在此输入逻辑语句
}
```

> **注意：** 高阶函数可以使用与其余编程组件相同的操作模块操作。

#### 4) Decorators

高阶函数通常在语法上被安排为函数参数。然而，装饰器用于在语法上正确地按顺序排列高阶函数（如 `lambda` 函数）。装饰器可以接受高阶函数作为参数并输出实例。格式如下：

```
Decorator(输入高阶函数 1, 输入高阶函数 2)
```

装饰器还可以用于实现协程，并开发可将协程作为函数参数的复杂应用。在处理任何调试和运行时错误时，装饰器也非常方便。为了开发机器学习应用，始终建议深入学习不同的高阶函数及其可以调节表达式的参数。你可以查阅 Python 文档以了解可用的不同类型的高阶函数。
