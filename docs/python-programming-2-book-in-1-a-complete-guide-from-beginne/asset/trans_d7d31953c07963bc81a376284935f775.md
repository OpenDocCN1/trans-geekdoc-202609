

# 第 1 章：什么是 Python？

本章全面介绍 Python 基础及其能力。我们将从简短的历史开始，然后深入探讨其他复杂主题。建议您将本书既作为参考资料，也作为学习材料。

Python 是一种解释性、面向对象且具有动态语义的高级编程语言。它可用作真正的跨平台语言（可在 Linux、macOS 和 Windows 上运行），其强制缩进语法使代码简洁易读。

## Python 的应用

Python 比其他编程语言更易于使用。因为 Python 拥有大量第三方库，使用 Python 开发应用项目更高效、更快捷。Python 广泛应用于系统管理。工业光魔等跨国公司使用 Python 为高预算电影制作特效。Yahoo! 使用它（以及其他技术）管理讨论组。Google 用它实现网络爬虫和搜索引擎中的许多组件。Python 还用于计算机游戏和生物信息等各个领域。随着人工智能的快速发展，Python 的应用得到了更好的普及。

## Python 历史

Python 由荷兰的 Guido van Rossum 创立。1989 年感恩节期间，Guido 决定开发一种新的脚本解释器，作为 ABC 语言的继承者，以消磨圣诞节的无聊时光。之所以选择 Python 作为语言名称，是因为他是 BBC 电视剧《Monty Python's Flying Circus》（蒙提·派森的飞行马戏团）的粉丝。他想为编程语言营造一种神秘感，因此将其命名为 Python。

Python 诞生于 1989 年，但首个公开发行版发布于 1991 年。Python 2.0 于 2000 年 10 月正式发布，Python 3.0 于 2008 年 12 月正式发布，截至本书撰写时，最新版本为 Python 3.6.5。

Python 是一种面向对象的直译式计算机编程语言，也是一种功能强大的通用编程语言。它包含一组完善且易于理解的标准库，并得到大量第三方库的支持，可轻松完成许多常见任务。其语法非常简单清晰，与大多数其他计算机编程语言不同，它使用强制缩进来定义语句块。

## Python 的设计风格

Python 坚持清晰统一的设计风格，这使其成为一种易读、易维护、深受大量用户喜爱且用途广泛的语言。开发人员的总指导思想是：只要有最好的方法来解决特定问题，那就是最好的。Python 的设计哲学是优雅、清晰、简单和可读。

## Python 的面向对象哲学

Python 是一种支持面向对象编程范式的编程语言。它拥有许多技术能力，使其比现有的过程式语言成为更好的编程语言。Python 开发者的哲学是用一种方法，最好只用一种方法，来做一件事。这与大多数其他编程语言不同。当您在 Python 编程时面临许多选择，Python 开发者通常会拒绝那些花哨的方法，选择清晰、极少或无歧义的语法。这些标准就是我们通常所说的 Python 格言。

您可以查看 Tim Peters 撰写的一篇关于 Python 基础的著名文章。它介绍了编写优美 Python 程序时需要注意的一些重要原则，以理解 Python 的设计哲学。此外，您还可以参考相关网站了解 Python 的设计哲学。

在下一节中，我们将讨论在 Python 语言中安装第三方库。这是 Python 程序员在处理硬核编码技能之前必须学习的基本技能。它非常基础，对初学者非常有用。让我们详细了解一下。

## 如何安装第三方库？

Python 拥有强大的标准库，Python 社区以类似标准库的方式提供大量第三方库。如果强大的标准库为 Python 的发展奠定了基础，那么第三方库则负责 Python 的持续发展。随着 Python 的持续更新，一些稳定的第三方库已被加入标准库。

安装 Anaconda 时，Python 的标准库和一些常用第三方库会随 Python 解释器一起安装。您可以在 Windows 提示符下输入 `pip list` 查看已安装的库。所有已安装的库将显示在输出屏幕上。如果要使用未安装的第三方库，必须使用下述安装方法进行安装。如果初学者觉得这部分内容过于繁杂难以专注，可以暂时跳过。您随时可以回到本节了解第三方模块的安装。

### 1) 源码安装

许多第三方库是开源的，几乎都可以在 GitHub 或 PyPI 上找到。大多数找到的源代码以 zip、tar.zip、tar.bz2 格式的压缩包形式提供。解压这些压缩包后，通常会看到一个 `setup.py` 文件。打开 Windows 命令行窗口并进入该文件夹。运行以下命令进行安装：

```
run setup.py
```

> 这是通常使用的命令

### 2) 包管理器

许多编程语言现在都有包管理器，例如 Ruby 的 `gem` 和 Node.js 的 `npm`。Python 当然也不例外。`pip` 和 `conda` 可用于安装第三方库。

#### (1) pip 管理 Python 库

您应该记得，在之前介绍 Python 安装时，提供的选项之一是安装 `pip` 包管理器。当然，如果选择安装 Anaconda，应注意包管理器已自动安装。如果已安装 `pip` 包管理器，在命令行输入 `pip` 并按回车，可以看到结果。

```
pip {Enter the third-party name}
```

使用 `pip` 安装模块安装第三方库时，系统将自动下载安装文件。例如，使用以下命令安装 Flask 框架：

```
pip install flask
```

**卸载已安装第三方库的命令**

```
pip uninstall {Enter third party name here}
```

如果要查看已安装的库（包括系统自带和手动安装的），只需执行命令 `pip all`。在命令行界面输入 `pip` 可查看更多 `pip` 参数和功能。

#### (2) Conda 对 Python 库的管理

Conda 可通过安装 Miniconda 或 Anaconda 来安装，后者是 Python 的简化版，仅包含 conda 及其依赖。Conda 对 Python 库的管理与 `pip` 大同小异。目前主要可用的命令是安装、卸载和查看已安装的库。

```
conda {Enter the command here}
```

有关 `conda` 使用的更多信息，感兴趣的读者可在线查阅相关资料学习。
