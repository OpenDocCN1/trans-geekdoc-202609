
# Python 编程：Python 机器学习、数据科学与工具的完整初学者指南

## 简介

Python 是一门常被推荐给初学者的编程语言，让他们尝试“搞砸事情”并爱上编程。Python 广受欢迎的主要原因之一在于其简洁性，以及用更少的代码实现功能的强大能力。即使在过去十年里出现了数十种编程语言，Python 依然魅力不减，我们非常有信心它将长盛不衰。本书以通俗易懂、简明扼要的方式，为大众提供了 Python 编程概念的经典入门介绍。所有概念均附带示例程序，以便读者领会主题的精髓。

## 什么是 Python？

Python 是一门相当著名的编程语言，拥有非常慷慨的社区，定期为计算机科学的各个分支（如数据挖掘、机器学习和深度学习）产出高质量项目。它是一门古老的编程语言，却依然能完美解决现代问题。本书并非参考手册，而是一本以轻松方式引领你入门 Python 的智能指南。我们尝试用通俗易懂的语言解释所有概念，以便读者能将编程概念内化于心，并用它们创造出一些非常有创新性的项目。
