# 简介

机器学习是本十年发展最快的计算机技术之一，预计到 2025 年将占据主流行业。许多行业正在开发应用程序和算法以利用机器学习功能。例如，Google 正在开发一种机器学习算法来验证搜索结果的质量。我们可以使用 Python、R 和 Java 等不同语言来实现机器学习功能。然而，从数据科学家的角度来看，Python 被认为能提供出色的结果。在本模块的上一本书中，我们讨论了 Python 编程语言。本书从数据科学家的角度解释了 Python 进阶概念。我们将讨论的许多主题将让您清楚地了解其在机器学习环境中的重要性。

## 我们为什么要写这本书？

提供与提升机器学习技能所需的 Python 相关的宝贵知识的资源较少。我们写这本书是为了帮助初学者掌握复杂的 Python 主题，以便将它们用于实现机器学习算法。Python 拥有许多第三方库，可以帮助数据科学家提高技术能力。然而，要使用这些第三方库，掌握 Python 进阶编程至关重要。仅为此原因，我们编写了这本书，让您轻松理解各种 Python 主题。

## 如何使用本书？

本书是一本全面的 Python 指南，也包含各种编程示例。我们建议您在系统中安装 Python 并亲自运行 Python 代码以查看结果。独立处理错误将帮助您理解编程语言的本质。有很多书可以帮助您精通 Python 编程，但只有极少数书能帮助您像程序员一样思考。本书就是其中之一。祝一切顺利，拥有愉快的学习体验。让我们开始吧！
