
# 第 6 章：Python 中的交互与生成

在前几章中，我们讨论了有助于你创建基础程序的 Python 编程概念。函数和运算符是 Python 编程的基础。然而，要创建基础的机器学习项目，你需要更深入地钻研 Python。本书包含三章的这一部分将帮助你详细了解交互、迭代和生成器。这些概念中有很多对于创建有效的机器学习模型至关重要。请继续阅读以了解更多信息。

## 什么是交互？

通常，Python 由变量组成，它们将值存储在内存位置中以便在需要时使用。交互是一种特殊实体，它帮助你创建代码，当一组变量改变时，可以改变另一组变量。你可以使用可用的 `SciPy` 库在 Python 中实现交互。交互的灵感源于形式统计学。

## 什么是推导式？

推导式是一种 Python 编程概念，可以帮助你有效地创建列表序列，如字典和列表。使用推导式，你可以自动创建多种范围的列表值。推导式是处理复杂情况的动态方式。它们使用键和值来表示生成的实例。

## 交互在 Python 中如何使用？

Python 使用交互和推导式来处理复杂的列表程序。许多开源软件使用交互来开发暴力破解工具，以实现更快的字典攻击。然而，就本书的范围而言，我们将在下一节深入讨论交互在机器学习项目中的用法。

## 什么是生成器？

生成器用于自动处理高阶函数。它们可以修饰函数，并帮助你使用简单的值迭代 map 和 hash 函数。生成器表达式通常用于高级 Python 表达式。它们可以通过 Python 中的 `yield` 关键字来使用。

# 第 7 章：Python 中的迭代

在本章中，我们将详细向你解释 Python 中的迭代语句。许多初学者会混淆迭代和循环的区别。请始终记住，循环是迭代语句的一个分支。我们将在本书的最后一章详细讨论循环结构。在本章中，我们将窥探 Python 所具备的迭代语句。请继续关注！

## 什么是迭代？

通俗地说，迭代就是支持重复的编程对象。迭代可用于在不同的编程组件和结构（如元组和字典）中实现循环。它们通常被误认为是 for 循环。然而，它们代表 `for - in` 循环。

## 如何创建迭代？

Python 是一门有效支持迭代的编程语言。它使用各种高阶函数来维持迭代的流程。此外，请记住，许多迭代原则只有在遵循特定原则时才能实现。

### a) 初始化迭代器

通常，迭代器借助对象进行初始化。`__iter__` 方法在 Python 中被用作迭代器的初始化机制。许多机器学习模型会自动调用此方法来初始化迭代因子。

### b) 在迭代器中使用 next

正如最初所解释的，迭代器是复杂的操作，通常需要能够转发数据的过程。`next` 是一个函数，它可以借助不同的迭代原则预处理信息。我们可以使用 `for in` 循环来有效协调迭代器中存在的信息。如果你对程序的性能不满意，可以使用 `StopIteration()` 方法来结束操作。以下是一个程序：
