## What are generators?

Generators are very similar to functions in Python. The only difference between functions and generators is that the latter uses the `yield` keyword to return values. So, as a simple rule, just remember that whenever you see a `yield` keyword in a Python programming example, it is automatically a generator function.

Here is the format:

```
def {Enter the function name here}
    yield
```

## What are the generator objects?
