
# 第 10 章：如何创建自定义函数？

在本章中，我们将详细讨论各种类型的函数。我们还将通过示例讨论用户自定义函数。

根据是否有参数和返回值，函数大致可分为四类：

1.  无参数且无返回值的函数。
2.  无参数但有返回值的函数。
3.  有参数但无返回值的函数。
4.  有参数且有返回值的函数。

接下来将详细解释这四种类型。

## 无参数且无返回值的函数

无参数且无返回值的函数既不能接收参数，也不能返回值。接下来，通过一个打印提示信息的函数来演示此类函数的用法，如下例所示。

**示例：无参数且无返回值的函数**

```
def printresults():
    # This is your place to choose
    # display('Order your items here')
    { Now enter the output required for the entities}
printresults()
```

## 无参数但有返回值的函数

此类函数不能接收参数，但可以返回某些数据。通常，在收集数据时会使用此类函数。接下来，我们将通过示例进行演示。

**示例：无参数但有返回值的函数**

```
# This will give temperature
def result():
    # Here are some processing procedures for obtaining temperature.
    # For the sake of simplicity, the simulation returns a data first.
    return 54

usage = useresults()
print('This is your body result', usage)
```

## 有参数但无返回值的函数

在实际开发中，有参数但无返回值的函数很少使用。因为将函数作为功能模块并传入参数时，大多数情况下都期望使用返回值。在此，大家可以了解一下有参数但无返回值的函数。示例代码如下：

```
# function
def send(usecase1, usecase2):
    result = usecase1 + usecase2
    print('calculated as: %d' % result)
```

## 有参数且有返回值的函数

此类函数不仅可以接收参数，还可以返回特定数据。通常，此类函数可用于处理数据并需要结果的应用程序。接下来，我们将通过一个案例进行演示。

**示例：有参数且有返回值的函数**

```
# calculates the cumulative sum of 1 ~ num
while i <= usetheresult:
    result = result + i
    i += 1
```

在下一节中，我们将描述用户自定义函数，并将通过一个详尽的示例进一步解释用户自定义函数的概念。

### 什么是用户自定义函数？

用户自定义函数是指创建一个带有其参数和逻辑的函数。我们通常有 `print()`、`math()` 等系统函数来解决许多日常问题。用户自定义函数通常用于重复性任务。

在下一节中，我们将向您介绍一个使用各种用户自定义函数的名片管理器应用程序。请跟随学习，以理解编程中函数的本质。

## 函数案例：名片管理器

名片管理器是一款实用的生活软件，用于帮助管理手机中的所有名片。为了帮助人们学习如何在实际应用中选择这四种类型的函数，我们开发了一个名片管理器。该案例需要使用函数来完成各项功能，并根据键盘输入选择相应的函数来完成这些功能。

名片管理菜单中有六个功能，通过接收用户键盘输入的序号来响应用户选择的功能。一旦用户输入“6”，将退出名片管理系统。

首先，创建一个项目并创建一个名为“Business Card Management System”的 Python 文件。具体实现步骤如下。

### 1. 输出名片管理器的菜单

考虑到该功能仅用于输出信息且输出内容固定，因此定义了一个无参数且无返回值的函数 `displayMenu()`，如下所示。

```
def display():
    print("-" * 60)
    { Enter the menu entities here}
    print("-" * 60)
```

使用 `while` 循环不间断地输出菜单信息。为了尽快测试上述菜单函数，将循环次数限制为 1，如下所示。

```
first = 0
while first < 1:
    # Print menu
    display()
```

运行程序，控制台将输出上述菜单信息。

### 2. 获取用户输入的信息

菜单显示后，用户根据提示输入要执行的序号。`input()` 函数从键盘接收用户的选择并返回选定的序号，因此定义了一个无参数但有返回值的函数 `useinput()`，如下所示。

```
# Get the information entered by the user
def useinput():
    storedvalue = input("please enter the selected serial number:")
    return int(storedvalue)
```

`while` 循环打印菜单后，调用 `useinput()` 函数获取用户输入的信息，如下所示。

```
# Waiting for User Selection
present = useinput()
```

运行程序，控制台将输出信息。

### 3. 通过获取序号执行不同功能

获取序号后，根据序号执行相应操作。在 `while` 语句末尾，使用 `if-elif` 语句根据用户选择的序号完成相应功能，如下所示。

```
if present == 1:
    pass
elif present == 2:
    {Use the remaining conditional entities here}
print("Incorrect input, please re-enter ..." )
```

接下来，将在每个条件下处理对应序号的功能。此处仅介绍“添加名片”和“查询名片”的功能。

### 5. 查看所有名片信息

用户选择了序号 5。此时，应从列表中获取所有姓名信息并按固定格式打印。因此，我们定义了一个有参数但无返回值的函数，如下所示。
