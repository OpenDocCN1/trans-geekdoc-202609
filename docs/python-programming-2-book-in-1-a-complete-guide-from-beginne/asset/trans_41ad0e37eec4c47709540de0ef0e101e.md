
# 第 5 章：Python 中的 operator 模块

运算符是一种数学实体，通常用于组合表达式和语句。在常规数学表达式中，运算符可以改变将要获得的结果。Python 还提供了一个 `operator` 模块，可以显式影响将要获得的结果。在本章中，我们将详细讨论最新版本 Python 中可用的各种运算符。

## 数学运算符

每当我们学习一门编程语言时，掌握数学运算符都是必不可少的，因为许多程序使用数学计算来执行操作。例如，在照片查看器软件中旋转图像时，程序员会使用数学矩阵的转置。众所周知，数学有标准运算，称为加法、减法、乘法和除法。Python 还提供了取模运算符，用于获取数学运算的余数。在下一节中，我们将通过各种示例解释这些数学运算。

### 加法运算符 `+`

```
first = 2
second = 3
result = first + second
# 结果将输出 5
```

### 减法运算符 `-`

```
first = 3
second = 2
result = first - second
# 结果将输出 1
```

### 乘法运算符 `*`

```
first = 2
second = 3
result = first * second
# 结果将输出 6
```

### 除法运算符 `/`

```
first = 6
second = 2
result = first / second
# 结果将输出 3
```

### 取模运算符 `%`

```
first = 7
second = 6
result = first % second
# 结果将输出 1
```

除了这些基本数学运算外，Python 还提供了指数运算符 `**`。

### 指数运算符 `**`

```
first = 5
second = 3
result = first ** second
# 结果将输出 125
```

> **注意：** Python 遵循层级规则来执行数学运算。Python 还提供了运算符优先级，以维护运算的结构化组织。这就是为什么你需要使用括号来明确地对运算符进行分组的唯一原因。

## 运算符优先级

在处理复杂逻辑表达式时，运算符优先级是编程语言中的一个基本概念。Python 赋予指数运算符最高优先级，其次是乘法、除法和取模运算符。加法和减法属于运算符优先级的最底层。在下一节中，我们将深入解释常用于确定表达式逻辑的比较运算符。在处理复杂的机器学习数据时，机器需要使用这些简单的比较运算符对数据进行分类和判断。

## 比较运算符

比较运算符用于组合语句和创建逻辑表达式。有许多比较运算符可以帮助你轻松地为许多数学函数创建逻辑。在下一节中，我们将详细讨论各种比较运算符。我们有四个比较运算符。提供了一个示例程序来帮助你理解比较运算符的工作原理。

### a) 大于 `>`

这是一个帮助你理解大于运算符的示例：

```
first = 5
second = 3
if (first > second):
    print("This is the greater perspective")
else:
    print("This is the lower perspective")
# 结果将输出第一条语句
```

### b) 小于 `<`

这是一个帮助你理解小于运算符的示例：

```
first = 5
second = 3
if (first < second):
    print("This is the lower perspective")
else:
    print("This is the greater perspective")
# 结果将输出第二条语句
```

### c) 等于 `==`

这是一个帮助你理解等于运算符的示例：

```
first = 5
second = 3
if (first == second):
    print("These two are the same")
else:
    print("These two are not the same")
# 结果将输出第二条语句
```

### d) 不等于 `!=`

这是一个帮助你理解不等于运算符的示例：

```
first = 5
second = 3
if (first != second):
    print("These two are not the same")
else:
    print("These two are same")
# 结果将输出第一条语句
```

至此，我们完成了比较运算符的简要介绍。在下一节中，我们将详细讨论对执行高级数据科学操作非常重要的逻辑运算符。

## 逻辑运算符

在处理复杂程序时，逻辑是一个重要的组成部分。许多 Python 程序由带有逻辑运算符的条件语句和循环语句组成。从根本上说，有三个逻辑运算符，我们现在将详细讨论它们。

### a) `and`

这是一个逻辑运算符，当你希望在两个语句都满足时打印表达式时可以使用它。它由 `and` 表示。这是一个示例：

```
first = 2
second = 3
third = 5
if (first == 2 and second == 5):
    print("This is right")
else:
    print("This is wrong")
```

现在，程序将检查 first 和 second 是否都具有相同的值。由于第二个变量不满足条件，`This is wrong` 将作为结果显示。

### b) `or`

这是一个逻辑运算符，当你希望在两个语句中任意一个满足时打印表达式时可以使用它。它由 `or` 表示。这是一个示例：

```
first = 2
second = 3
third = 5
if (first == 2 or second == 5):
    print("This is right")
else:
    print("This is wrong")
```

现在，程序将检查 first 和 second 中是否有任意一个具有相同的值。由于第一个变量满足条件，`This is right` 将作为结果显示。

### c) `not`

这充当否定运算符。也就是说，当条件不满足时它将执行打印。它通常由 `not` 表示。

至此，我们完成了对 Python 中运算符的详细解释。在下一章中，我们将开始讨论与迭代和推导式相关的高级概念。
