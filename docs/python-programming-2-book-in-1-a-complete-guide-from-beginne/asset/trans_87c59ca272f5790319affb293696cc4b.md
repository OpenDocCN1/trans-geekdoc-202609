

# 第 2 章：如何在电脑上安装 Python？

在上一章中，我们讨论了 Python 的重要性及其重要特性。在本章中，我们将讨论在各种操作系统中安装 Python。我们还将讨论使用各种包管理器在 Python 中安装第三方模块。让我们开始吧！

## 检查 Python 版本

通常，在 Linux 和 Mac OS 操作系统中，Python 默认已安装。不过，建议使用命令提示符检查 Python 版本。Windows 用户需要从 Python 官网下载安装包。

### 如何检查 Python 版本？

根据您的系统打开终端或命令提示符，以检查 Python 是否已安装。请始终尝试使用管理员权限打开终端，以获得准确的结果。输入以下命令格式：

```
python
python 2
python 3
```

如果系统已安装 Python，您将得到一个显示已安装 Python 版本的结果。它还将提供各种选项，这对初学者了解管理 Python 程序的常用命令非常有用。但是，如果系统中没有 Python 安装文件夹的痕迹，终端将返回错误。请在您的操作系统中使用上述命令进行检查，如果终端返回命令错误，则是时候按照下面的指南安装 Python 了。请跟随操作！

## 如何在 Windows 中安装 Python？

**步骤 1：** 首先，选择您愿意在系统中安装的版本很重要。我们建议您查看下一章，以了解不同的可用 Python 版本。您也可以查看 Python 在线文档，根据您的需求选择合适的 Python 版本。

**步骤 2：** 选择 Python 版本后，访问官方网站下载该版本。您需要选择 32 位或 64 位选项，下载可无错误安装的版本。您可以根据意愿下载 `.msi` 安装包或 `.exe` 应用程序。下载安装文件后，您只需使用管理员权限打开该文件即可。

**步骤 3：** 开始安装后，您将看到一个要求输入 Python 安装目录的界面。您可以使用默认目录安装 Python，也可以根据要求更改目录。

> **注意：** 请确保目录名称中没有空格，因为有时 Python 安装会因此报错。

**步骤 4：** 在安装的最后一步，您需要更新环境变量，以便 Python 能在系统的命令提示符中运行。安装完成后，您可以使用前面解释的过程交叉检查安装是否成功。

至此，我们已经了解了在系统中安装基本 Python 包的方法。在下一节中，我们将讨论开发复杂 Python 程序所需的各种 Python 模块。

### 有哪些其他替代方案？

Python 用户应记住，有几种 Python 的复制品解释器可以安装在 Windows 系统上。其中一些是 `CPython`、`Pypy`，它们以定制能力著称。不过，我们建议您尝试原版 Python，以获得高级使用能力和更快的处理速度。

## 如何在 Mac OS 中安装 Python？

Mac 操作系统默认已安装 Python 2.x 版本。Mac 操作系统使用 Python 来控制各种系统操作。但是，如果您热衷于更新 Python 版本以开发程序，请遵循下面的部分。

**步骤 1：** 在第一步中，您需要访问 Python 官方下载页面。该网站将自动确定您的系统配置，并列出一个供您下载的 `.dmg` 包安装程序。下载前请仔细核对版本名称。

**步骤 2：** 点击 `.dmg` 包安装程序后，出于安全原因，系统会要求您输入操作系统认证详细信息。安装程序还会询问默认目录位置。

**步骤 3：** 在下一步中，您需要输入自定义选项。您也可以使用自动选项，让安装程序根据您的系统配置给出最佳结果。安装完成后，建议重启系统，并使用终端检查 Python 版本，如前几节所述。

### 对终端操作不感兴趣？

通常，Python 程序在命令行解释器或终端中编译。通常，程序员需要使用文本编辑器保存 Python 脚本，并从终端编译它。然而，许多开发人员不习惯处理命令行操作。对于更倾向于图形用户界面的程序员，Python 提供了一个可在系统上安装的 GUI 包。该包称为 `Tkinter` 应用程序，可从 Python 官方网站下载。安装后还可以添加插件来自定义您的图形界面。

## 在 Linux 中安装/升级 Linux

Linux 是大多数程序员和技术爱好者用来执行任务和开发程序的操作系统。与 Windows 和 Mac 不同，Linux 主要依赖命令行操作。通常，Python 在许多 Linux 发行版中预装。如果您不确定，可以直接检查 Python 版本，并按照下面给出的进一步安装过程进行操作。

**步骤 1：** 您可以从 Python 官方网站下载 Python `.deb` 包。您可以使用 `sudo` 操作在系统中安装该包。如果您技术水平不足以使用 `sudo` 操作安装，也可以使用 `RPM` 等包管理器来安装 Python 包。

**步骤 2：** 安装包后，您只需在终端输入 `python` 并查看获得的结果。您还可以通过更改 Python 安装文件夹中存在的构建脚本，将 Python 升级到更新版本。在 Linux 中，您可能会在同一系统中使用两个不同版本的 Python 时面临冲突。因此，请始终确保您已从系统中卸载了之前的 Python 版本。

## 使用 REPL

`REPL` 是运行算术操作所需的最基本 Python 组件。该组件负责输入值并输出结果。它就像 Python 的词法分析工具。您可以使用 `REPL` 模式检查 Python 是否已安装。以下是一些可执行的操作，以确认系统中的 Python 安装：

**a) 进行算术运算**

在命令行上运行以下命令：

```
>>> 4747+3737
>>> 3424*242
>>> 63634/27
```

如果您获得结果且无错误，则 Python 已成功安装在系统中。

**b) 赋值变量**

变量是一个可以存储值并在我们需要时重复它们的实体。这是一个示例：

```
>>> r = 446
```

现在尝试打印赋值的变量

```
>>> r
```

如果您得到 446 作为结果，则可以确认 Python 已成功安装在您的系统中。

## 了解 Help 命令

Python 提供了一个 `help` 命令，它将告知您解释器可以执行的各种操作。您也可以查看在线文档，以了解更多关于系统函数和库的信息。格式如下：

```
>>> help
```

使用此命令，您可以按顺序打印出所有函数提示。`Help()` 函数可以了解不同系统函数的详细信息。每个 IDE 还包含一个帮助文件夹，可用于调节信息。

## 使用 pip

Python 是一种使用模块和包来开发高效程序的编程语言。许多模块需要从 GitHub 等网站下载到系统中。为了使此过程变得简单，Python 开发了一个 `PyPI` 索引，列出了所有合格的 Python 模块。学习如何使用 `pip` 是程序员的基本技能。`pip` 可以使用 `Sudo` 命令安装。在尝试使用 `pip` 安装模块之前，我们建议您查看 Python 模块索引。输入模块名称后，`pip search` 模块将开始从不同资源批量搜索该模块。如果找到该模块，则使用下载模块将其安装在您首选的目录中。命令如下：

```
sudo pip install {enter the package name here}
```

`pip` 可用于所有可用的操作系统。您只需要系统中有受支持的 Python 版本。

## 使用 easy_install

`easy_install` 是安装不同模块直接到系统的另一种 `pip` 替代方案。使用 `easy_install`，您可以直接更改设置脚本，以自动对正在下载的包进行更改。然而，与 `pip` 不同，它不够简单，需要高级学习能力才能掌握。我们建议您查看 `easy_install` 文档以了解更多信息。

## 其他可下载的 IDE

在本章中，我们讨论了 Python 自带的默认 Python 解释器。通常建议初学者使用它，使事情看起来更简单，而不是用不同的功能让他们困惑。但是，如果您感兴趣，可以查看不同的 IDE 来开发 Python 程序。我们推荐 `Pycharm` IDE 来了解 Python 的不同复杂功能。`Pycharm` IDE 还提供各种调试功能，使程序开发变得容易。

## 如何运行 Python 脚本？

安装完每个必要组件后，现在是时候了解如何在命令行环境中运行 Python 脚本了。

**步骤 1：** 首先，打开您选择的文本编辑器，创建一个扩展名为 `.py` 的文件。在该文本文件中输入脚本，并将其保存在您想要的文件夹中。

**步骤 2：** 现在在终端中使用 `python` 命令启动 Python 解释器。进入 Python 实例后，您需要输入以下命令来运行程序。

```
>>> python filename.py
```

如果程序中没有错误，您的文件将根据您的要求运行。但是，如果存在任何运行时错误和警告，您的程序将停止并显示结果。

至此，我们完成了在不同操作系统中安装 Python 的简要介绍。重要的是将本章作为参考，以安装将在本书后续章节中介绍的不同模块。在下一章中，我们将讨论不同的 Python 版本。如前所述，根据您的需求选择最佳版本非常重要。让我们开始吧！
