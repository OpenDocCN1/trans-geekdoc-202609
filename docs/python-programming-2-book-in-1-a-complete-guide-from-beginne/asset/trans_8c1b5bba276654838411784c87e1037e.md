
# 第 1 章：什么是 Python？为什么选择 Python？

Python 是一种编程语言，被公认为最适合初学者学习的编程语言之一。除了其简单的语法和直观的功能外，丰富资源的可用性也是 Python 在大众中取得成功的原因之一。Python 是 GitHub 上最流行的语言，拥有数千个开源项目和第三方库，可帮助你创建复杂的软件。Python 也是热衷于数据科学的人士推荐的学习语言。机器学习作为计算机科学的一个著名分支，依赖 Python 库来分析数据。在本书中，我们将从机器学习的角度探讨 Python 的功能。在下一节中，我们将结合有效的技术信息讨论 Python 的功能。

## 为什么 Python 如此著名？

如今，有 100 多种编程语言可供计算机程序员和计算机科学家使用。在所有语言中，Python 因其活跃的社区而占据了显要地位，该社区始终致力于修复漏洞并更新新功能。一项研究提出了 Python 在程序员中流行的原因。在本节中，我们将讨论其中一些使 Python 成为程序员最爱的原因。以下是有效理由：

### 1) 质量
当你使用 Python 创建程序时，它们通常具有高质量。用户遇到的漏洞较少，且使用不同的 Python 模块很容易更新程序。Python 支持多种编程范式，如过程式和面向对象编程，以有效地复用代码。由于缩进技术，它也很容易阅读。编程语法的这种高质量让程序员爱不释手。

### 2) 生产力
Java 和 C 等其他编程语言是静态类型语言，即使处理极少量的数据也需要大量代码。Python 简化了编写代码的过程，与其他语言相比，仅需一半的编程代码量。这提高了生产力，并能显著提升所开发应用程序的质量。

### 3) 可移植性
与仅在存在 JVM 时才能运行应用程序的 Java 不同，Python 可以在任何平台上运行软件应用程序。你只需添加几行代码即可让软件在其他平台上运行。只需稍微更改代码，Python 应用程序也可以部署在 Web 和数据库环境中运行。所有这些可移植性优势使开发人员在开发跨平台应用程序时将 Python 作为首选语言。

### 4) 第三方库
Python 标准库中有大量默认函数。其中包含可用于开发数据科学应用的数学和统计函数。然而，标准库函数往往不足以开发复杂软件。这时第三方库的概念就派上用场了，它们可以轻松导入到 Python 项目中。借助第三方库，你可以使用 Python 开发复杂和先进的软件。

### 5) 乐趣
正如其简单直观的特性一样，Python 的成功也取决于它给开发者带来的乐趣程度。它易于维护，且比其他编程语言少得多的麻烦。Python 拥有各种可以自动化任务的模块。所有这些优势结合在一起，使 Python 成为一种令人愉悦的编程语言。

基于上述技术原因，Python 在编程社区中变得著名，并扩大了其用户群。在下一节中，我们将描述 Python 在日常生活中的一些应用。

## Python 的应用

根据统计，Python 被约 150 万开发者使用。大量网站、API 和软件都是以 Python 为主要语言开发的。Python 的这种成功也归功于其开源特性，这让程序员可以随心所欲地使用该语言。这也是为什么 Python 被许多黑客用作脚本语言的原因。然而，仅凭这一点就称 Python 为脚本语言是不准确的。我们认为 Python 是一种多用途语言，可服务于许多领域和用户。

以下是一些在其产品中使用 Python 的跨国公司：

*   **Google** 广泛使用 Python 来构建和更新其搜索引擎爬虫。
*   **YouTube** 最初是用 Python 编写的。许多 YouTube 集成服务仍在使用 Python。
*   **Netflix** 的推荐算法使用 Python 来有效调配资源。
*   **Dropbox** 这一著名的存储服务使用 Python 来加密文件。

除了这些示例外，Python 还用于 **iRobot** 以开发机器人。

以下是 Python 被广泛使用的一些技术领域：

### a) 系统编程
这是计算机科学的一个分支，我们可以在其中开发系统管理工具，如编译器、解释器和 Shell 工具，它们能在内核级别与系统交互。Python 非常适合这一计算机科学分支，因为它拥有多个可扩展库，有助于创建高效的程序。

### b) 互联网
Python 是创建小型互联网脚本的简易语言。许多“脚本小子”使用 Python 开发的程序来破解账户密码。许多暴力破解工具也使用 Python 来对经过身份验证的服务器自动执行字典攻击。Python 还因开发可存储敏感信息的 Web 应用程序而闻名。许多网络爬虫和 Web 分析服务使用 Python 来整理信息。

### c) 集成系统
许多硬件组件（如 **Arduino**）只有在被编程后才能有效工作。通常，嵌入式系统适配传统的结构化语言，如 C 和 C++。Python 拥有许多库，可以帮助将已编写的 Python 代码集成到嵌入式系统中。

### d) 数据库编程
数据库是存储和操作信息的基本实体。有许多数据库查询语言可用于存储和查询数据。然而，许多数据库管理员使用 Python 来持续监控可用的入侵检测系统。有许多 Python 库可以帮助开发者自动检查病毒并将备份存储在远程服务器中。

### e) 机器学习
机器学习是一个蓬勃发展的计算机科学领域，我们可以在其中分析现有的信息和数据。Python 拥有诸如 **SciPy** 和 **Pandas** 等库，能以重要方式维护数据。本书将列出各种 Python 特性，助你精通机器学习。

除了这些领域，Python 还被黑客、恶意软件逆向工程师和计算机科学家用于进行各种分析实验。在下一节中，我们将讨论 Python 相对于其他可用语言的优势。让我们开始吧！

## Python 的优势是什么？

资深程序员建议初学者学习 Python，因为它有助于你理解每种编程语言都使用的所有基础知识。Python 通常是所有编程范式的混合体。我们将在下文为你清晰地阐述这一点。

### a) 同时支持函数式和面向对象
Python 不同于 Java 和 C++，它将函数式编程与面向对象范式结合使用。这为初学者学习这两种技术提供了空间。在学习 Python 的过程中，将涵盖多态、继承和函数等许多核心概念。

### b) 开源
Python 由来自世界各地的热情贡献者开发。创建和分发程序是免费的。这种开源特性让程序员能够试验代码并创建一些创新应用。

### c) 强大
与其他流行编程语言相比，它非常强大。它支持动态类型，且在编译程序前无需声明变量和列表大小。Python 使用垃圾回收机制，将所有无用的系统变量转储。这以指数级的方式提高了程序的性能。

### d) 默认工具
Python 提供了许多非常有用的系统工具。它可以使用这些默认工具轻松执行大量字符串操作。了解这些模块对于使用 Python 更好地执行操作也很重要。

### e) 易于使用
与 C 和 C++ 等传统编程语言不同，Python 易于使用。C 和 C++ 提供不同的范式，可能会让开发者感到困惑。Python 使用较少的缩进，且代码易于维护。Python 也优于 Java，因为它不是静态类型语言。在 Java 中，你需要引入不同的无用变量来维护程序结构的流程。然而，在 Python 中，你只使用你需要的东西。这是 Python 被认为是开发机器学习应用的更好语言的原因之一。

Python 拥有一个慷慨的社区，分享大量资源和示例项目，鼓励初学者理解 Python 的重要性和魅力。本书也是一种真诚的尝试，旨在帮助你理解 Python 的所有中级主题，以便在开发人工智能和数据科学应用时实现它们。我们建议你查看一个开源项目，通过不断实践本书所学主题来理解其逻辑精髓。
