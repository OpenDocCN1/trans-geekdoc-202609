
# 语音转文本和文本转语音

您可以使用语音转文本服务将录制的音频或流式音频转换为文本。这是一项用于为视频录制和流式视频创建字幕的热门服务。这也通常与翻译服务结合使用，以生成多种语言的字幕。有关更多详细信息，请参阅 `https://cloud.google.com/speech-to-text#section-10`。

## 文本转语音

客户使用文本转语音服务提供具有类人语调的逼真语音。这基于 DeepMind（Google 的 AI 子公司）最先进的语音合成专业知识。它目前支持 40 多种语言和变体中的 220 多种语音。您可以创建一个独特的语音，以在所有接触点代表您的品牌。有关支持的语言列表，请参阅此处：`https://cloud.google.com/text-to-speech/docs/voices`。

# AutoML

AutoML（自动化机器学习）是自动化模型训练耗时任务的过程。AutoML 适用于流行、易懂且切实可行的机器学习问题，如图像分类、文本分类、翻译等。作为用户，您只需提供数据并配置一些设置，其余的训练过程将实现自动化。您可以利用易于使用的 Web 控制台，或使用 Python、Java 或 Node.js SDK 来启动 AutoML 训练作业。

针对许多数据类型和用例都提供了 AutoML 训练。我们可以将它们大致分为四类：

*   结构化数据
*   图像/视频
*   自然语言
*   推荐 AI/零售 AI

## 面向表格或结构化数据的 AutoML

结构化数据是指符合明确定义的模式且通常呈矩形表格形式的数据。针对表格，有两种训练模型的方法：

*   **BigQuery ML：** 这是一种基于 SQL 的模型训练方法。如果您是数据分析师且擅长编写 SQL 查询，可以使用此方法。您可以使用 BigQuery 进行训练和预测，并自动将预测结果添加到表中。这是一种用于机器学习训练和预测的无服务器方法。我们将在[第 14 章](#c14.xhtml)“BigQuery ML”中详细介绍这一点。
*   **Vertex AI Tables：** 这是训练机器学习模型的第二种方法，可使用 Python、Java 或 Node.js，或使用 REST API 触发。Vertex AI Tables 为您提供了在端点上部署模型并通过 REST API 提供预测服务的能力。

我们将在[表 4.1](#c04.xhtml#c04-tbl-0001)中介绍可用的 AutoML Tables 算法。

[**表 4.1**](#c04.xhtml#R_c04-tbl-0001) Vertex AI AutoML Tables 算法

| 数据类型 | 机器学习问题 | 指标 |
| --- | --- | --- |
| 表格 (IID) | 分类 | AUC ROC, AUC ROC, Logloss, Precision at Recall, Recall at Precision |
| 表格 (IID) | 回归 | RMSE, RMSLE, MAE |
| 时间序列数据 | 预测 | RMSE, RMSLE, MAPE, 分位数损失 |

在配置 AutoML 作业时，从硬件角度来看有几个相关事项。“预算”是 Web 控制台中的最后一步，您可在其中指定允许作业运行的最长小时数（请参阅[图 4.3](#c04.xhtml#c04-fig-0003)）。如果训练作业未在预算内完成，AutoML 将使用在预算内训练出的最佳模型。下图中还有一个名为“启用提前停止”的设置，如果识别出模型训练已完成，则会结束训练作业，在这种情况下，您将仅为使用的节点小时数付费。

![图 4.3 Vertex AI AutoML，提供“预算”](images/c04f003.png)

[**图 4.3**](#c04.xhtml#R_c04-fig-0003) Vertex AI AutoML，提供“预算”

您为 AutoML 作业提供的预算有最小值。例如，对于目标检测 AutoML，最小值为 20 小时。另一个需要记住的重要方面是，虽然所有 AutoML 作业都要求您为预算提供节点小时数，但并非所有节点小时都相同。不同 AutoML 作业类型的每个节点小时价格不同，因为不同 AutoML 作业使用的硬件不同。

从模型类型角度来看，预测是一种特殊情况。Vertex AI 为预测提供三种模型训练方法：

*   **AutoML：** 这是内置模型，适用于各种预测用例。
*   **Seq2seq+：** 这种模型接收一个序列并生成另一个序列。当数据集大小小于 1 GB 时，此模型非常有效。
*   **时序融合变换器：** 这是一种深度神经网络模型，也使用了注意力机制。它旨在为广泛的用例生成高准确性和可解释性。

## 面向图像和视频的 AutoML

直到最近，图像和视频数据上的机器学习问题对机器学习专家来说仍然繁琐且耗时。Vertex AI AutoML 使构建此类问题的模型变得极其简单。[表 4.2](#c04.xhtml#c04-tbl-0002) 简明扼要地总结了这些数据类型的所有可用 AutoML 算法。

[**表 4.2**](#c04.xhtml#R_c04-tbl-0002) AutoML 算法

| 数据类型 | 机器学习问题 | AutoML 详情 |
| --- | --- | --- |
| 图像 | 图像分类（单标签） | 从训练期间用户提供的标签列表中预测一个正确标签。 |
| 图像 | 多类分类 | 预测您想要分配给图像的所有正确标签。 |
| 图像 | 目标检测 | 预测您感兴趣的所有目标的位置。 |
| 图像 | 图像分割 | 预测带有标签的图像逐像素区域。 |
| 视频 | 分类 | 获取整个视频、镜头和帧的标签预测。 |
| 视频 | 动作识别 | 识别视频中的动作时刻。 |
| 视频 | 目标跟踪 | 获取您想要在视频中跟踪的目标的标签、轨迹和时间戳。 |

与硬件相关的 AutoML 另一个考量因素是 AutoML Edge 模型。这些模型将部署到边缘设备，因此模型经过训练和配置，以使用更少的内存和低延迟。目前支持的边缘设备包括 iPhone、Android 手机（Google Pixel、Samsung Galaxy 等）和 Edge TPU 设备，随着 Google 支持更多设备，此集合将继续增加。

当您选择 AutoML Edge 模型时，有可用选项可帮助您在准确性和延迟之间找到合适的权衡。对于 Edge TPU，我们看到[图 4.4](#c04.xhtml#c04-fig-0004) 中显示的选项。

## 面向文本的 AutoML

现在文本的机器学习模型也已被充分理解，您可以使用 Vertex AI AutoML 文本轻松构建自己的模型。使用 AutoML 解决了四个常见问题，包括分类和情感分析。[表 4.3](#c04.xhtml#c04-tbl-0003) 显示了完整列表。

[**表 4.3**](#c04.xhtml#R_c04-tbl-0003) 使用 AutoML 解决的问题

| 数据类型 | 机器学习问题 | AutoML 详情 |
| --- | --- | --- |
| 文本 | 文本分类 | 预测您想要分配给文档的一个正确标签。 |
| 文本 | 多标签分类 | 预测您想要分配给文档的所有正确标签。 |
| 文本 | 实体提取 | 识别文本项中的实体。 |
| 文本到文本 | 翻译 | 将文本从源语言转换为目标语言。 |
