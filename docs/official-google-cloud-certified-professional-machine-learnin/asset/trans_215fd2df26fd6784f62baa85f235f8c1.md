# 第 5 章：架构 ML 解决方案

在上一章中，我们讨论了在 Google Cloud 中运行工作负载的各种选项。在本章中，我们将讨论如何使用我们的人工智能/机器学习 (AI/ML) 服务栈，在 Google Cloud Platform (GCP) 上设计可靠、可扩展且高可用的 ML 解决方案的最佳实践。我们将介绍 Google AI/ML 栈，并讨论如何根据你的易用性需求和 AI/ML 技能水平，从栈中为 ML 用例选择合适的服务。然后我们将讨论在 GCP 上进行 ML 时，用于收集和管理数据的各种服务。之后，我们将讨论如何使用 GCP AI/ML 流水线自动执行数据准备、数据转换、训练、调优和部署等各个步骤。最后，你将了解一些在生产环境中托管或部署 ML 模型以提供请求服务的最佳实践。

## 设计可靠、可扩展且高可用的 ML 解决方案

要设计高度可靠、可扩展且可用的 ML 解决方案，你需要考虑如何自动化和编排 AI/ML 流水线的各个步骤。

你的 ML 流水线包含以下步骤：

1.  数据收集
2.  数据转换
3.  模型训练
4.  模型调优
5.  模型部署
6.  模型监控

此外，这是一个迭代过程，因为你可能需要根据评估指标（准确率、置信度得分等）重新训练模型。

你需要一个可扩展的存储解决方案来管理和存储数据——例如 `Google Cloud Storage`。然后你需要一个可扩展的基础设施来运行转换作业，例如在 `Google Cloud Dataflow` 上运行 `PySpark` 转换作业。数据转换完成后，你需要可扩展的算力来训练模型。要创建无法在笔记本电脑中容纳的大型模型，你需要分布式训练。

对于自定义模型训练（`TensorFlow`、`Scikit`、`PyTorch` 或其他框架），你可以使用 `Vertex AI Training`，因为你无需担心为训练启动基础设施，也无需管理该基础设施以在训练结束时停止。如果你不使用 `TensorFlow`、`Scikit` 或 `PyTorch` 进行自定义训练，你也可以选择使用 `Vertex AI AutoML` 和 `Vertex AI APIs`。训练结束后，你可能想通过运行 100 个此类训练作业（这些作业包含来自搜索空间的各种超参数组合）来调整模型的各种超参数。这就是你可以使用 `Vertex AI Hyperparameter Tuning` 以可扩展的方式自动运行多个训练作业的地方。你还希望以托管、可扩展且可靠的方式跟踪这些变量和多次训练结果。这就是 `Vertex AI Experiments` 可以帮助跟踪训练运行的参数和结果的地方。既然你能跟踪实验，这将有助于更快地选择模型。

最后，一旦你选出了准确率最高的最佳训练作业，你就必须考虑在生产环境中部署此模型。你还需要担心生产模型的扩缩容；`Vertex AI Prediction` 可以帮助你以全托管方式在生产环境中扩缩容预测端点。

模型部署到生产环境后，你需要考虑监控托管模型以检查是否存在任何模型漂移。这就是 `Vertex AI Model Monitoring` 可以提供帮助的地方。你还需要考虑如何复现从数据收集到模型部署的完整流水线，因为 ML 是一个迭代过程。`Vertex AI Pipelines` 可以在此提供帮助。

Google Cloud ML 服务和解决方案根据易用性和实现难度分为三层，如图 5.1 所示。

![图 5.1：Google AI/ML 栈](images/c05f001.png)

### 图 5.1：Google AI/ML 栈

顶层是 AI 解决方案，例如 `Document AI`、`Contact Center AI` 和 `Enterprise Translation Hub`。这些是托管的软件即服务 (SaaS) 产品，无需代码即可更轻松地实现和管理。AI 解决方案构建在中间层的 `Vertex AI` 服务之上。

中间层由 `Vertex AI` 组成，包含以下内容：

*   **Vertex AI 预训练 API**，适用于视觉、语言、对话和结构化数据中最常见的用例。这些 API 是无服务器且可扩展的。
*   **Vertex AI AutoML**，用于利用你自己的数据丰富 Vertex AI API 用例，以创建针对你业务用例的特定模型。例如，你可以通过提供一些公司徽标的示例来训练 `AutoML Vision` 模型，以检测道路上带有你公司徽标的卡车图像。
*   **Vertex AI Workbench**，这是整个数据科学工作流的开发环境。这可以涵盖从数据标注、训练、调优、部署到监控你自己的自定义模型，这些模型不适合使用 AI 服务和 AutoML 的任何用例。一个例子是构建文本摘要模型。

底层由基础设施组成，例如计算实例和容器（`Google Kubernetes Engine`），可选择 TPU、GPU 和存储。你需要自行管理基础设施以实现可扩展性和可靠性。

Google Cloud 提供 `BigQuery ML` 和 `Vertex AI AutoML` 来帮助自动创建针对某些常见问题领域的自定义模型。`Vertex AI` 提供的其余工具帮助你为任何问题领域构建完全自定义的模型。我们将在第 14 章“BigQuery ML”中详细介绍 `BigQuery ML`。表 5.2 讨论了何时使用 AutoML 与 BigQuery ML 与 Vertex AI 自定义模型。
