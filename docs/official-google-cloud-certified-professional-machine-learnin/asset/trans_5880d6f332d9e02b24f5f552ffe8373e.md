

## 特定实体预测

特定实体预测是指基于 ID（如 `customerid` 或 `deviceid`）或特定的输入特征组合，针对单个实体进行预测。如果实体过多（基数高），则很难在有限的时间内预先计算预测结果。一个例子是按商品预测日销量，此时您拥有数十万甚至数百万种商品。在这种情况下，您可以按照架构图采用混合方法，为排名前 N 位的实体（如最活跃的客户或浏览量最高的产品）预先计算预测结果。然后，您可以直接使用模型对其余实体进行在线预测。

## 特定输入特征组合

特定输入特征组合用于判断匿名或新客户是否会在您的网站上购买商品。当您拥有一组输入特征时，您需要创建一种哈希方法，其中键是所有可能输入特征的哈希组合，值则是预测结果。

## Google Cloud 服务选项

在 Google Cloud 中，您可以部署模型以进行在线预测或批量预测。您可以对 AutoML 模型和自定义模型同时执行批量预测和在线预测。在以下章节中，我们将介绍如何使用 Vertex AI 设置在线和批量作业。

### 在线预测

要设置实时预测端点，您可能会遇到以下两种用例：

*   **使用 Vertex AI 训练在 Vertex AI 中训练的模型：** 这可以是 AutoML 模型或自定义模型，详见[第 8 章](#c08.xhtml)“模型训练与超参数调优”。
*   **在其他地方训练的模型（本地部署、其他云或本地设备）：** 如果您已在其他地方训练好模型，则需要在部署和创建端点之前将模型导入 Google Cloud。

如果您是作为预构建容器导入，请确保您的模型工件文件名与以下示例完全匹配：

*   **TensorFlow SavedModel：** `saved_model.pb`
*   **scikit-learn：** `model.joblib` 或 `model.pkl`
*   **XGBoost：** `model.bst`、`model.joblib` 或 `model.pkl`

如果您是导入自定义容器，则需要创建一个容器镜像，并根据自定义容器托管的要求，可能需要使用 `Cloud Build` 将镜像推送到 `Artifact Registry`。

对于这两种选项，您都需要遵循以下步骤来设置 Vertex AI 预测：

1.  将模型资源部署到端点。
2.  进行预测。
3.  如果端点未被使用，则取消部署模型资源。

#### 部署模型

当您使用 Vertex AI 预测端点部署模型时，您需要为端点的容器（TensorFlow、scikit-learn 或 XGBoost）指定自动扩缩配置。Vertex AI 会自动配置容器资源并为您的端点设置自动扩缩。您可以将多个模型部署到一个端点，也可以将一个模型部署到多个端点。有两种方式可以部署模型：使用 API 和使用 Google Cloud 控制台。

##### 使用 API 部署模型

您可以通过在 `Model` 资源上调用 Vertex AI `deploy` 函数来部署模型。`deploy` 方法将创建一个端点，并将您的模型部署在该端点上。您需要提供流量分配、机器类型、GPU 和最小节点数来设置 `deploy` 方法。以下 `deploy` 函数返回一个 `Endpoint` 对象。

```
Endpoint = model.deploy(
     deployed_model_display_name=DEPLOYED_NAME,
     traffic_split=TRAFFIC_SPLIT,
     machine_type=DEPLOY_COMPUTE,
     accelerator_type=DEPLOY_GPU.name,
     accelerator_count=DEPLOY_NGPU,
     min_replica_count=MIN_NODES,
     max_replica_count=MAX_NODES,
 )
```

上述 Vertex AI 函数接受以下参数：

*   `deployed_model_display_name`：已部署模型的可读名称。
*   `TRAFFIC_SPLIT`：流向该模型的端点流量百分比，以一个或多个键值对字典的形式指定。
    *   如果只有一个模型，则指定为 `{ "0": 100 }`，其中 `"0"` 指代正在上传的此模型，100 表示 100% 的流量。
    *   如果端点上存在现有模型且流量将被分配，则使用 `model_id` 指定为 `{ "0": percent, model_id: percent, ... }`，其中 `model_id` 是已部署端点上现有模型的模型 ID。百分比之和必须为 100。
*   `machine_type`：用于训练的机器类型。
*   `accelerator_type`：硬件加速器类型。
*   `accelerator_count`：附加到每个工作副本的加速器数量。
*   `starting_replica_count`：最初预配的计算实例数量。
*   `max_replica_count`：扩缩的最大计算实例数量。在本教程中，仅预配一个实例。

您可以使用上述 API 或 Google Cloud 控制台来部署模型。

##### 使用 Google Cloud 控制台部署模型

如果您使用 GCP 控制台，可以通过前往模型注册表来部署模型。模型注册表是一个集中式的位置，用于跟踪 AutoML 和自定义模型的版本。您还可以选择要部署的版本。Vertex AI 训练的 AutoML 和自定义模型会自动出现在模型注册表中。您可以选择模型和版本，点击三个点，然后选择“部署到端点”来部署您的模型。

当您在模型注册表中点击“部署到端点”时，您将被重定向到定义端点的页面，如[图 10.5](#c10.xhtml#c10-fig-0005)所示。在“模型设置”部分，您可以定义流量分配、计算资源和自动扩缩选项；在“模型监控”部分，您可以启用选项以监控生产环境中的模型是否存在偏移。

#### 进行预测

在通过端点运行数据之前，您需要对其进行预处理，以匹配您的自定义模型在 `task.py` 中定义的预期格式。使用 `Endpoint` 对象的 `predict` 函数，该函数接受以下参数：

*   您将在每个预测的输出中看到该预测的置信度。

    ```
    predictions = endpoint.predict(instances=x_test)
    ```

    您将获得一个 REST 端点 ID，您可以将其嵌入网站、API 网关或 App Engine 中，以创建用于实时预测的 ML 网关。

*   如果您使用预构建容器通过 TensorFlow、scikit-learn 或 XGBoost 提供预测服务，您的预测输入实例需要格式化为 JSON。
*   如果您的模型使用自定义容器，您的输入必须格式化为 JSON，并且有一个额外的参数字段可供您的容器使用。

前往 Vertex AI GCP 控制台中的“端点”页面，选择端点，然后点击“示例请求”。您将获得关于如何预处理数据以使用端点进行 REST 和 Python 预测的说明，如[图 10.6](#c10.xhtml#c10-fig-0006)所示。

#### 模型不同版本的 A/B 测试

A/B 测试对比机器学习中两个版本模型的性能，以查看哪一个更吸引访问者/观看者。它测试对照版本 (A) 与变体版本 (B)，根据您的关键指标衡量哪一个最成功。
