# 简介

当客户遇到业务问题时，例如在图像中检测对象，有时可以使用机器学习非常好地解决。Google Cloud Platform（`GCP`）提供了一套广泛的工具，用于构建能够完成此任务的模型，并将其部署用于生产环境。本书将涵盖许多不同的用例，例如使用销售数据预测下一季度的业绩、识别图像或视频中的对象，甚至从文本文档中提取信息。本书帮助工程师构建安全、可扩展、有弹性的机器学习应用，并使用最新技术实现整个流程的自动化。

本书旨在帮助您通过最新版本的 Google Cloud 专业机器学习工程师（`PMLE`）考试。即使您已经参加并通过了 `PMLE` 考试，本书仍应作为一本有用的参考书，因为它涵盖了机器学习基础、`BigQuery ML`、`Vertex AI` 平台和 `MLOps`。

## Google Cloud 专业机器学习工程师认证

专业机器学习工程师利用 Google Cloud 技术和经过验证的 ML 模型及技术，设计、构建和生产化 ML 模型以解决业务挑战。ML 工程师在整个 ML 开发过程中考量负责任的 AI，并与其他职角色紧密协作，确保模型的长期成功。ML 工程师应精通模型架构、数据管道交互和指标解读的各个方面。ML 工程师需要熟悉应用开发、基础设施管理、数据工程和数据治理的基础概念。通过理解训练、重新训练、部署、调度、监控和改进模型，ML 工程师设计并创建可扩展的解决方案以实现最佳性能。

### 为什么要成为专业 ML 工程师（PMLE）认证人员？

获得 `PMLE` 认证有几个充分的理由。

*   **提供专业成就的证明** 认证正迅速成为计算机服务行业的身份象征。包括计算机服务行业成员在内的各类组织，都已认识到认证的益处。

*   **提高您的就业竞争力** 根据《福布斯》（`www.forbes.com/sites/louiscolumbus/2020/02/10/15-top-paying-it-certifications-in-2020/?sh=12f63aa8358e`）报道，要求具备 `GCP` 认证的职位已连续第二年成为薪酬最高的 IT 职位，平均年薪达 175,761 美元。因此，许多工程师都有获证需求。在 `GCP` 提供的众多认证中，AI/ML 认证工程师是一项新认证，仍在不断发展中。

*   **提供晋升机会** IDC 的研究（`www.idc.com/getdoc.jsp?containerId=IDC_P40729`）表明，虽然 AI/ML 采用率正在上升，但成本、缺乏专业知识和缺乏生命周期管理工具是大规模实现 AI 和 ML 的前三大阻碍因素。

*   本书是市场上第一本介绍 Google Cloud AI/ML 工具和技术、涵盖 2022 年 2 月 22 日发布的最新专业机器学习工程师认证指南的书籍。

*   **彰显 Google 在开源和 AI 领域的领导地位** Google 是许多开创性开源软件的主要贡献者，这些软件极大地改变了 AI/ML 的格局，包括 `TensorFlow`、`Kubeflow`、`Word2vec`、`BERT` 和 `T5`。尽管这些算法属于开源领域，但 Google 拥有通过 Google Cloud Platform（`GCP`）将这些开源项目推向市场的独特能力。在这方面，其他云服务提供商经常被视为落后于 Google 的产品。

*   **增强客户信心** 随着 IT 社区、用户、小企业主等对 `PMLE` 认证专业人士的了解加深，他们将越来越多地意识到，与非认证人员相比，`PMLE` 专业人士更有资格在 Google Cloud 环境中设计安全、具成本效益且可扩展的 ML 解决方案。

### 如何获得认证

您无需为特定公司工作。这不是一个秘密组织。参加此考试没有先决条件。不过，建议拥有 3 年以上行业经验，包括 1 年以上使用 Google Cloud 设计和管理解决方案的经验。

考试时长为 2 小时，包含 50-60 道多项选择题。

您可以通过两种方式注册参加此考试：

*   参加在线监考考试，随地随时（如在家）均可。您可以在 `www.webassessor.com/wa.do?page=certInfo&branding=GOOGLECLOUD&tabs=13` 查看在线考试要求。

*   在考试中心参加现场监考考试。

我们通常倾向于选择现场考试，因为我们喜欢监考环境下的专注时间。我们所有的认证考试都是在考试中心参加的。您可以在 `www.kryterion.com/Locate-Test-Center` 查找并定位您附近的考试中心。

本书旨在帮助学生、开发人员、数据科学家、IT 专业人员和 ML 工程师精通 Google Cloud Platform 上的 ML 技术，并参加 `专业机器学习工程师` 考试。本书意在引导读者完成机器学习流程，从数据开始，经过特征工程、模型训练，直到在 Google Cloud 上部署。它还指导读者了解在何种最佳实践下应选择自定义模型、AutoML 或预训练模型。通过真实场景展示 Google Cloud AI/ML 技术，说明 IT 专业人员如何设计、构建和运行安全的 ML 云环境，以实现应用现代化和自动化。
