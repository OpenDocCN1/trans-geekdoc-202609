## 27. 以下哪项*不是*使用 Vertex AI Feature Store 的理由？

1.  它是一项托管服务。
2.  它从图像和视频中提取特征并存储它们。
3.  所有数据均为时间序列，因此你可以跟踪特征值随时间的变化。
4.  特征工程团队创建的特征在训练时可用，但在服务时不可用。这有助于弥合这一差距。

## 28. 你是一个拥有数千名保险代理人的组织中的数据分析师，你被要求预测每位代理人下个季度的收入。你拥有过去 10 年的历史数据。你熟悉 Google Cloud 上的所有 AI 服务。最高效的方法是什么？

1.  构建 Vertex AI AutoML 预测模型，部署模型，并使用 REST API 进行预测。
2.  构建 Vertex AI AutoML 预测模型，将模型导入 BigQuery，并使用 BigQuery ML 进行预测。
3.  使用 BigQuery 中的数据构建 BigQuery ML ARIMA+ 模型，并在 BigQuery 中进行预测。
4.  构建 BigQuery ML 预测模型，将模型导出到 Vertex AI，并在 Vertex AI 中运行批量预测。

## 29. 你是 Vertex AI Pipelines、Vertex AI 训练、Vertex AI 部署和监控方面的专家。数据分析师团队构建了一个高度准确的模型，并将其交给你。你的经理希望你使用该模型进行预测并使用这些预测结果。你该怎么做？

1.  在 Vertex AI 上使用相同数据重新训练模型，并将模型作为持续部署 (CD) 的一部分部署在 Vertex AI 上。
2.  在 BigQuery ML 上运行预测，将预测结果导出到 GCS，然后加载到你的流水线中。
3.  将模型从 BigQuery 导出到 Vertex AI 模型存储库，并在 Vertex AI 中运行预测。
4.  下载 BigQuery 模型，将其打包到 Vertex AI 自定义容器中，并在 Vertex AI 中部署。

## 30. 关于 Vertex AI 和 BigQuery ML，以下哪项陈述是**不正确**的？

1.  BigQuery ML 支持无监督和有监督模型。
2.  BigQuery ML 具有很强的可移植性。Vertex AI 支持所有在 BigQuery ML 上训练的模型。
3.  Vertex AI 模型监控和日志数据存储在 BigQuery 表中。
4.  BigQuery ML 也有用于预测用户推荐的算法。
