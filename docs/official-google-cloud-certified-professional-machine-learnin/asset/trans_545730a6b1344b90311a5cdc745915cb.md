

## 网络和安全

**托管笔记本：** 您可以在同一项目的 VPC 中运行此项。共享 VPC 控制目前尚不支持托管笔记本。

**用户管理的笔记本：** 对于有特定网络和安全需求的用户，用户管理的笔记本可能是最佳选择。您可以使用 VPC Service Controls 在服务边界内设置用户管理的笔记本实例，并实现其他内置的网络和安全功能。

这两种笔记本选项均预装了 JupyterLab，并预装了一套深度学习包，如 TensorFlow 和 PyTorch 框架，以及 R、Spark 和 Python 等其他包。您可以使用仅 CPU 或启用了 GPU 的实例。这两种笔记本实例也都与 GitHub 集成，因此您可以将笔记本与 GitHub 代码库同步。

首先，我们将介绍托管笔记本和用户管理的笔记本之间的一些功能差异，然后介绍如何创建和使用这些笔记本进行模型开发。

接下来，我们将通过在 Vertex AI GCP 控制台中创建笔记本来探索每种笔记本的功能。

### 创建托管笔记本

转到 Vertex AI 并选择**启用所有 API**。默认情况下，在 GCP 中，所有服务 API 均处于停用状态。启用 API 后，点击 **Workbench（工作台）**，转到 **Managed Notebooks（托管笔记本）** 标签页，然后选择 **New Notebook（新建笔记本）**。点击 **Create（创建）** 按钮，使用默认设置创建笔记本（请参阅[图 8.4](#c08.xhtml#c08a-fig-0001)）。

![FIGURE 8.4 创建托管笔记本](images/c08f004.png)

[**图 8.4**](#c08.xhtml#R_c08a-fig-0001) 创建托管笔记本

请注意，右侧显示了运行笔记本的月度账单预估。

过一段时间后，您会发现笔记本已创建完成，**Open JupyterLab（打开 JupyterLab）** 按钮已启用（请参阅[图 8.5](#c08.xhtml#c08a-fig-0002)）。点击 **Open JupyterLab** 按钮进入您托管的 JupyterLab 环境。

![FIGURE 8.5 打开托管笔记本](images/c08f005.png)

[**图 8.5**](#c08.xhtml#R_c08a-fig-0002) 打开托管笔记本

### 探索托管 JupyterLab 功能

点击 **Open JupyterLab** 后，您将被重定向到[图 8.6](#c08.xhtml#c08a-fig-0003) 所示的屏幕。您会发现此环境中提供了所有可用的框架，包括 Serverless Spark 以及本地安装的 PySpark。Serverless Spark 功能用于在笔记本内运行 Dataproc 集群。

![FIGURE 8.6 探索托管笔记本中可用的框架](images/c08f006.png)

[**图 8.6**](#c08.xhtml#R_c08a-fig-0003) 探索托管笔记本中可用的框架

在 tutorials（教程）文件夹中，您将找到现有的笔记本，帮助您开始在此 JupyterLab 环境中构建和训练模型。JupyterLab 还附带终端选项，可在整个笔记本上运行终端命令。

接下来，让我们探索此类笔记本支持的功能。

### 数据集成

点击左侧导航栏上的 **Browse GCS（浏览 GCS）** 图标（请参阅[图 8.7](#c08.xhtml#c08a-fig-0004)），以浏览并从 Cloud Storage 文件夹加载数据。

![FIGURE 8.7 托管笔记本中与 Google Cloud Storage 的数据集成](images/c08f007.png)

[**图 8.7**](#c08.xhtml#R_c08a-fig-0004) 托管笔记本中与 Google Cloud Storage 的数据集成

### BigQuery 集成

如[图 8.8](#c08.xhtml#c08a-fig-0005) 所示，点击左侧的 **BigQuery** 图标，从您的 BigQuery 表中获取数据。该界面还提供 **Open SQL editor（打开 SQL 编辑器）** 选项，可在不离开 JupyterLab 界面的情况下查询这些表。

![FIGURE 8.8 托管笔记本中与 BigQuery 的数据集成](images/c08f008.png)

[**图 8.8**](#c08.xhtml#R_c08a-fig-0005) 托管笔记本中与 BigQuery 的数据集成

### 扩展或缩减计算资源的能力

点击 `n1‐standard‐4`（请参阅[图 8.9](#c08.xhtml#c08a-fig-0006)）。您将获得修改 Jupyter 环境硬件的选项。您也可以在不离开环境的情况下为此实例附加 GPU。

### 用于团队协作的 Git 集成

点击左侧导航栏的分支图标，您将进入集成现有 git 代码库或克隆代码库以进行项目协作的屏幕（请参阅[图 8.10](#c08.xhtml#c08a-fig-0007)）。或者，您可以使用终端并运行命令 `git clone <your‐repository name>` 来克隆您的代码库。

![FIGURE 8.9 从托管笔记本扩展硬件](images/c08f009.png)

[**图 8.9**](#c08.xhtml#R_c08a-fig-0006) 从托管笔记本扩展硬件

![FIGURE 8.10 托管笔记本中的 Git 集成](images/c08f010.png)

[**图 8.10**](#c08.xhtml#R_c08a-fig-0007) 托管笔记本中的 Git 集成

### 安排或执行笔记本代码

点击 **Python**，输入“hello world”，然后点击 **run cell（运行单元格）**，使用黑色三角形箭头手动执行单元格。为了自动执行此笔记本，请如[图 8.11](#c08.xhtml#c08a-fig-0008) 所示点击 **Execute（执行）**。

![FIGURE 8.11 在笔记本中安排或执行代码](images/c08f011.png)

[**图 8.11**](#c08.xhtml#R_c08a-fig-0008) 在笔记本中安排或执行代码

点击 **Execute** 后，您将看到[图 8.12](#c08.xhtml#c08a-fig-0009) 所示的屏幕：**Submit notebooks to Executor（提交笔记本给执行器）**。此功能主要用于设置或触发 Vertex AI 训练作业，或部署 Vertex AI Prediction 端点的调度，而无需离开 Jupyter 界面。

![FIGURE 8.12 提交笔记本以供执行](images/c08f012.png)

[**图 8.12**](#c08.xhtml#R_c08a-fig-0009) 提交笔记本以供执行

向下滚动到 **Type（类型）** 选项，以安排笔记本运行，如[图 8.13](#c08.xhtml#c08a-fig-0010) 所示。

![FIGURE 8.13 安排笔记本以供执行](images/c08f013.png)

[**图 8.13**](#c08.xhtml#R_c08a-fig-0010) 安排笔记本以供执行

我们介绍了托管笔记本的所有功能，例如与 Cloud Storage/BigQuery 的集成、扩展或缩减笔记本硬件的能力、Git 集成，以及安排笔记本进行一次性运行或按计划时间运行的能力。

### 创建用户管理的笔记本

使用用户管理的笔记本时，您需要在创建笔记本期间选择执行环境，如[图 8.14](#c08.xhtml#c08a-fig-0011) 所示。

![FIGURE 8.14 选择 TensorFlow 框架以创建用户管理的笔记本](images/c08f014.png)

[**图 8.14**](#c08.xhtml#R_c08a-fig-0011) 选择 TensorFlow 框架以创建用户管理的笔记本

您需要从 Python 3、TensorFlow、R、JAX、Kaggle、PyTorch 等选项中选择特定的框架。让我们按照[图 8.14](#c08.xhtml#c08a-fig-0011) 所示的路径，继续创建一个不带 GPU 的 TensorFlow 笔记本。然后点击 **Create（创建）** 以创建用户管理的笔记本（请参阅[图 8.15](#c08.xhtml#c08a-fig-0012)）。

![FIGURE 8.15 创建用户管理的 TensorFlow 笔记本](images/c08f015.png)

[**图 8.15**](#c08.xhtml#R_c08a-fig-0012) 创建用户管理的 TensorFlow 笔记本

您可以看到，用户管理的笔记本带有高级选项，可配置与共享 VPC 的网络。

笔记本处于活动状态后，您将看到 **Open JupyterLab（打开 JupyterLab）** 选项。点击它以探索笔记本（请参阅[图 8.16](#c08.xhtml#c08a-fig-0013)）。

![FIGURE 8.16 探索网络](images/c08f016.png)

[**图 8.16**](#c08.xhtml#R_c08a-fig-0013) 探索网络

此笔记本预装了 TensorFlow。您可以使用用户管理的笔记本中的 Git 集成和终端访问。

您可以使用托管笔记本和用户管理的笔记本，通过 Vertex AI Python SDK 触发 Vertex AI 训练，或使用 Vertex AI Training Python SDK 运行预测。
