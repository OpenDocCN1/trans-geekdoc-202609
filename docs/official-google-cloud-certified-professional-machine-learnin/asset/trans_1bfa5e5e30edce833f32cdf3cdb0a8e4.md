
# 第 2 章：数据可视化、质量与验证

在本章中，我们讨论了为什么需要可视化数据以及可视化数据的各种方法，例如使用箱线图、折线图和散点图。然后我们介绍了统计基础知识，如平均值、中位数、众数和标准差，以及它们在发现数据离群值时的相关性。此外，你还学习了如何使用折线图检查数据相关性。

你了解了各种数据清洗和归一化技术，例如对数缩放、缩放、裁剪以及使用 z-score 来提高数据质量。

我们还讨论了建立数据约束，以及为什么在 ML 流水线中定义数据架构很重要，还有验证数据的必要性。我们介绍了使用 `TFDV` 大规模验证数据，以及为什么需要 `TFDV` 来验证大规模深度学习系统的数据架构。然后我们讨论了拆分数据所用的策略，并讲述了针对不平衡数据集的数据拆分策略。我们介绍了基于时间的拆分方法（用于在线系统）和聚类数据拆分。

最后，我们介绍了处理缺失数据和数据泄露的策略。

## 考试要点

*   **能够可视化数据。** 理解为什么需要可视化数据以及各种可视化方法，例如使用箱线图、折线图和散点图。
*   **理解统计术语的基础知识。** 能够描述平均值、中位数、众数和标准差，以及它们在发现数据离群值时的相关性。还要知道如何使用折线图检查数据相关性。
*   **确定数据质量、可靠性或可行性。** 理解为什么需要没有离群值的数据，什么是数据倾斜，并了解各种数据清洗和归一化技术，例如对数缩放、缩放、裁剪和 z-score。
*   **建立数据约束。** 理解为什么在 ML 流水线中定义数据架构很重要，以及验证数据的必要性。此外，你需要理解用于大规模验证数据的 `TFDV`。
*   **组织和优化训练数据。** 你需要理解如何将数据集拆分为训练数据、测试数据和验证数据，以及如何在拥有聚类数据和在线数据时应用数据拆分技术。还要理解拥有不平衡数据时的采样策略。
*   **处理缺失数据。** 了解处理缺失数据的各种方法，例如删除缺失值；用平均值、中位数或众数替换缺失值；或使用 ML 来生成缺失值。
*   **避免数据泄露。** 了解数据泄露和标签泄露在数据中发生的各种方式以及如何避免它们。

## 复习题

1.  你是公司的数据科学家。你有一个包含信用卡交易的数据集，其中 1% 的信用卡交易是欺诈性的。哪种数据转换策略可能会提高分类模型的性能？
    1.  将数据写入 `TFRecords`。
    2.  对所有数值特征进行 Z-score 归一化。
    3.  对所有分类特征使用独热编码。
    4.  对欺诈交易进行过采样。

2.  你是一名研究科学家，正在利用医疗记录构建癌症预测模型。模型特征包括患者姓名、医院名称、年龄、生命体征和检测结果。该模型在保留的测试数据上表现非常好，但在新患者数据上表现不佳。原因是什么？
    1.  特征“医院名称”与预测结果之间存在强相关性。
    2.  在所有可用特征之间随机拆分数据。
    3.  特征“医院名称”和“年龄”中存在缺失值。
    4.  特征“医院名称”与“年龄”之间存在负相关性。

3.  你的团队训练并测试了一个准确率为 99% 的深度神经网络模型。模型部署六个月后，由于输入数据分布的变化，模型表现不佳。应该如何解决输入数据分布问题？
    1.  创建警报以监控倾斜并重新训练模型。
    2.  执行特征选择并重新训练模型。
    3.  在超参数调优后重新训练模型。
    4.  每月重新训练模型以检测数据倾斜。

4.  你是一名构建和管理销售预测生产系统的 ML 工程师。模型准确度很重要，因为生产模型必须跟上市场变化。生产一个月后，模型未改变但模型准确度下降了。导致模型准确度下降的最可能原因是什么？
    1.  准确度因数据质量差而下降。
    2.  缺乏模型重新训练。
    3.  验证集、测试集和训练集的数据拆分比例不正确。
    4.  训练数据缺失。

5.  你是一家制造公司的数据科学家。你被要求根据传感器读数调查生产线故障。你意识到 1% 的数据样本是故障传感器读数的正例。你将如何解决类别不平衡问题？
    1.  使用类别分布生成 10% 的正例。
    2.  对多数类数据进行降采样并加权以创建 10% 的样本。
    3.  删除负例直到正负例数量相等。
    4.  使用带有 softmax 激活函数的卷积神经网络。

6.  你是气象部门的数据科学家，受命构建模型预测日温度。你随机拆分数据，然后转换训练集和测试集。用于模型训练的温度数据每小时上传一次。测试期间，模型准确率达 99%；然而，在生产环境中，准确率下降到 70%。如何提高模型在生产环境中的准确率？
    1.  基于时间而非随机拆分训练集和测试集，以避免泄露。
    2.  将训练集和测试集的数据归一化作为两个独立的步骤。
    3.  向数据集添加更多数据，以获得公平的分布。
    4.  在拆分前转换数据，并进行交叉验证以确保转换同时应用于训练集和测试集。

7.  你正在从事一个基于神经网络的项目。提供给你的数据集包含不同范围的列和大量缺失值。在为模型训练准备数据时，你发现梯度优化在移动权重时遇到困难。你应该怎么做？
    1.  使用特征构造来组合最强特征。
    2.  使用归一化技术转换数据。
    3.  通过删除含缺失值的特征来改进数据清洗步骤。
    4.  更改超参数调优步骤以减小测试集维度并扩大训练集。

8.  你是一名致力于将模型投入生产的 ML 工程师。你的模型在训练数据上表现良好。然而，模型在生产环境中性能下降，且模型出现过拟合。可能的原因是什么？（选择三项。）
    1.  对整个数据集应用归一化特征（如移除离群值）
    2.  目标变量与特征之间存在高相关性
    3.  删除含缺失值的特征
    4.  将目标变量作为特征添加
