

## Vertex AI 超参数调优配置

```yaml
studySpec:
  metrics:
  - metricId: METRIC_ID
    goal: METRIC_GOAL
  parameters:
  - parameterId: HYPERPARAMETER_ID
    doubleValueSpec:
      minValue: DOUBLE_MIN_VALUE
      maxValue: DOUBLE_MAX_VALUE
trialJobSpec:
  workerPoolSpecs:
  - machineSpec:
      machineType: MACHINE_TYPE
    replicaCount: 1
    containerSpec:
      imageUri: CUSTOM_CONTAINER_IMAGE_URI
```

**配置参数：**

*   `METRIC_ID`：要优化的超参数指标的名称。您的训练代码在运行时必须报告此指标。
*   `METRIC_GOAL`：超参数指标的目标，为 `MAXIMIZE`（最大化）或 `MINIMIZE`（最小化）。
*   `HYPERPARAMETER_ID`：要调优的超参数的名称。您的训练代码必须解析一个具有此名称的命令行标志。在本示例中，该超参数必须接受浮点值。
*   `DOUBLE_MIN_VALUE`：您希望 Vertex AI 为此超参数尝试的最小值（数字）。
*   `DOUBLE_MAX_VALUE`：您希望 Vertex AI 为此超参数尝试的最大值（数字）。
*   `MACHINE_TYPE`：用于训练的虚拟机类型。
*   `CUSTOM_CONTAINER_IMAGE_URI`：包含您训练代码的 Docker 容器镜像的 URI。

> **注意：** 您也可以指定搜索算法。如果未指定，Google Cloud 默认会选择贝叶斯算法。

### 创建超参数调优作业

在与 `config.yaml` 文件相同的目录下，运行以下 Shell 命令以创建自定义作业来启动超参数调优：

```bash
gcloud ai hp-tuning-jobs create \
    --region=LOCATION \
    --display-name=DISPLAY_NAME \
    --max-trial-count=MAX_TRIAL_COUNT \
    --parallel-trial-count=PARALLEL_TRIAL_COUNT \
    --config=config.yaml
```

**命令参数：**

*   `LOCATION`：您要在其中创建 HyperparameterTuningJob 的区域。
*   `DISPLAY_NAME`：您选择的显示名称。
*   `MAX_TRIAL_COUNT`：要运行的最大试验次数。
*   `PARALLEL_TRIAL_COUNT`：要并行运行的最大试验次数。

您可以在 Vertex AI 控制台的 Vertex AI 训练中跟踪此作业的进度。

## Vertex AI Vizier

Vertex AI Vizier 是一项黑盒优化服务，可帮助您调整复杂机器学习模型中的超参数。以下是使用 Vertex AI Vizier 训练机器学习模型的标准：

*   Vertex AI Vizier 没有已知的目标函数来进行评估。
*   使用目标函数评估 Vertex AI Vizier 的成本太高，通常是由于系统的复杂性。
*   Vertex AI Vizier 优化机器学习模型的超参数，但也可以执行其他优化任务，例如调整模型参数，并适用于任何可评估的系统。

您可以使用 Vertex AI Vizier 进行超参数调优的一些示例或用例如下：

*   优化神经网络推荐引擎的学习率、批量大小和其他超参数。
*   通过测试不同的用户界面元素排列来优化应用程序的易用性。
*   通过确定理想的缓冲区大小和线程数来最小化作业的计算资源。
*   优化配方中配料的用量，以制作出最美味的版本。

### Vertex AI Vizier 与自定义训练的区别

Vertex AI Vizier 是一项用于优化具有许多参数的复杂模型的独立服务。它可用于机器学习和非机器学习用例。它可与训练作业或其他系统（甚至多云环境）一起使用。自定义训练的超参数调优是一项内置功能，它使用 Vertex AI Vizier 进行训练作业。它有助于确定机器学习模型的最佳超参数设置。默认情况下，它使用贝叶斯优化。

如需了解详情，请参阅 `https://cloud.google.com/vertex-ai/docs/training/using-hyperparameter-tuning#aiplatform_create_hyperparameter_tuning_job_python_package_sample-gcloud`。

### 交互式 Shell

使用交互式 Shell 检查您的训练容器，可以帮助您调试训练代码或 Vertex AI 配置方面的问题。您可以在 Vertex AI 上运行的每个预构建容器或自定义容器中浏览文件系统并运行调试实用程序。您可以使用交互式 Shell 运行跟踪和分析工具、分析 GPU 使用情况，并检查容器可用的 Google Cloud 权限。您可以通过在以编程方式设置自定义作业时将 `enableWebAccess` API 字段设置为 `true`，或在 Vertex AI 控制台训练流水线中勾选**启用训练调试**，来为自定义训练资源启用交互式 Shell，如[图 8.23](#c08.xhtml#c08-fig-0010) 所示。

### TensorFlow Profiler

Vertex AI TensorBoard 是 TensorBoard 的企业级托管版本。Vertex AI TensorBoard Profiler 通过帮助您了解训练操作的资源消耗，让您监控并优化模型训练性能。这可以定位并修复性能瓶颈，从而更快、更经济地训练模型。从 Google Cloud 控制台访问 Vertex AI TensorBoard Profiler 信息中心主要有两种方式：

*   从自定义作业页面
*   从实验页面

要捕获分析会话，您的训练作业必须处于 `RUNNING` 状态。

TF Profiler 允许您按需分析远程 Vertex AI 训练作业，并在 Vertex TensorBoard 中可视化结果。有关详细信息，请参阅使用 Profiler 分析模型训练性能：`https://cloud.google.com/vertex-ai/docs/experiments/tensorboard-profiler`。
