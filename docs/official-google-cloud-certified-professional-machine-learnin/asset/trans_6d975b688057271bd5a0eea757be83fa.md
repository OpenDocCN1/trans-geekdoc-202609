## 5. A

## 6. D
选项 A 错误，因为 `n1-standard-2` 对于 GPU 来说太小了；选项 B 错误，因为它仍在使用 CPU。选项 D 更好，因为选择 1 个 TPU 优于 8 个 GPU，特别是在你没有任何手动放置策略的情况下。

## 7. D
“为您推荐”适用于主页，旨在根据当前趋势和用户行为吸引用户关注最可能感兴趣的产品。“相似商品”仅基于产品信息，帮助客户在相似产品中进行选择。“猜您喜欢”是基于用户浏览历史记录展示内容的正确选择。“常被一起购买”旨在结账时展示，以便客户快速将更多商品加入购物车。

## 9. A
当你希望客户“参与度更高”时，意味着你希望他们在网站/应用上花费更多时间浏览产品。“常被一起购买”旨在结账时展示，以便客户快速将更多商品加入购物车。“为您推荐”适用于主页，并吸引用户关注最可能感兴趣的产品；“相似商品”仅基于产品信息，帮助客户在相似产品中进行选择。“猜您喜欢”是基于用户浏览历史记录展示内容的正确选择。

## 10. C
当你没有浏览数据或“用户事件”时，必须仅基于产品目录信息创建推荐。列表中唯一不需要“用户信息”的模型是“相似商品”，它展示与用户当前正在查看的商品相似的产品。

## 11. B
“点击率”目标基于用户点击并跟进链接的次数，而“每单收入”衡量结账时推荐的有效性。

## 12. D
选项 A 错误，因为目前尚无可用的 AutoML 解决方案。目前 GCP 上也没有可用的预训练 API 来实现此功能。Vertex AI 自定义作业是最合适的选择。

## 13. B
选项 A 错误，因为 Natural Language API 不接受语音输入。虽然选项 C 和 D 也是正确的，但这些是自定义模型，需要花费时间进行训练。

## 14. C
TPU 不支持自定义 TensorFlow 操作。GPU 是此处的最佳选择。

## 15. A
只有 A2 和 N1 机器系列支持 GPU。选项 C 错误，因为一个实例中不能安装 3 个 GPU。

## 16. A
在没有硬件支持的情况下将大型模型推送到 Android 设备可能会显著降低设备性能。使用安装了 Edge TPU 的设备是此处的最佳答案。

## 17. A, C
你不能在单个实例中同时拥有 TPU 和 GPU。通常也不会选择 TPU VM 集群。

## 18. C
如果你有稀疏矩阵，TPU 将无法提供必要的效率。

## 19. C
TPU 不用于高精度预测。

## 20. C, D
选项 A 和 B 在未识别根本原因的情况下增加实例规模。题目提到模型已部署在大型实例（32 核）上。下一步应该是识别延迟的根本原因，因此选项 C 是正确的选择。此外，检查代码是否为单线程也是正确的，因为这不总是硬件问题；可能是配置问题，也可能是代码为单线程导致的软件问题。

# 第 5 章：构建 ML 解决方案架构

## 1. B
题目询问的是最简单的解决方案，因此我们不需要 Memorystore 和 Bigtable，因为延迟要求是 300ms@p99。处理此问题的最佳且最简单的方法是使用 App Engine 部署应用并调用 Vertex AI Prediction 上的模型端点。

## 2. B
Bigtable 专为超大数据集的极低延迟读取而设计。

## 3. A
你将使用 Dataflow 进行数据预处理，然后使用 Vertex AI 平台进行训练和服务。由于这是一个推荐用例，Cloud BigQuery 是管理此用例大规模存储并降低延迟的推荐 NoSQL 存储。

## 4. A
由于你希望将基础设施开销降至最低，可以使用 Vertex AI 平台进行分布式训练。

## 5. A, C
借助 Document AI，你可以快速上手，因为它是构建在 AI 技术栈顶层的解决方案产品，你几乎不需要进行基础设施搭建。Cloud Storage 是创建文档数据湖的推荐数据存储解决方案。

## 6. A
当问题询问重新训练时，要寻找能够自动化和编排任务的流水线。Kubeflow Pipelines 是此处唯一能帮助自动化重新训练工作流的选项。

## 7. D
Kubeflow Pipelines 是唯一自带实验跟踪功能的选项。请参阅 `www.kubeflow.org/docs/components/pipelines/concepts/experiment`。

## 8. C
你可以使用 Cloud Storage 触发器向 Pub/Sub 主题发送消息，并创建一个 Cloud Function 来触发 GKE 训练作业。请参阅 `https://cloud.google.com/architecture/architecture-for-mlops-using-tfx-kubeflow-pipelines-and-cloud-build#triggering-and-scheduling-kubeflow-pipelines`。

## 9. A
使用 Kubeflow 实验进行训练和执行实验。

## 10. A
你可以使用批量预测功能，因为数据在一天结束时聚合，不需要近实时预测。

## 11. B
TensorFlow 的 BigQueryClient 使用 Storage API 高效地直接从 BigQuery 存储中读取数据。`tf.data.datasetreader` 用于创建输入数据流水线，而不是用于将数据从 BigQuery 高效加载到 TensorFlow 中。

## 12. A, B, C
你可以使用这三种连接器中的任意一种连接到 BigQuery 中的各种框架数据集。请参阅本章的表 5.3。

## 13. A
Vertex AI 托管数据集是在 Vertex AI 平台上组织和管理训练及预测数据的最佳方式。

## 14. A, B
由于延迟问题，你应该避免将数据存储在块存储和文件存储中用于 ML 用例。
