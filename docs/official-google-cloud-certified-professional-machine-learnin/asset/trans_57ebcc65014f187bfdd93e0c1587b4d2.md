
# 特征工程

*特征工程*是将来自各种来源（如日志文件和气象读数）的原始数据转换为用于模型训练的有用特征的过程。特征可以是数值型或类别型。让我们了解数据转换的主要原因。

## 为数据兼容性而转换

数据由数值特征和非数值特征组成。您的模型无法对字符串类型的数据执行数学计算。这就是为什么将此类特征转换为模型能够理解的向量或数值表示非常重要。

您还需要调整输入数据的大小，以匹配模型中的输入节点；例如，线性模型和前馈神经网络具有固定数量的输入节点。因此，您的输入数据必须始终保持相同的大小。

## 为数据质量而转换

这种类型的转换有助于模型表现得更好。例如，将文本特征转换为小写可以提高性能，分词或在模型训练前归一化数值特征也能起到同样的作用。

现在您已了解特征工程为何重要，让我们在下一节讨论在模型训练或模型预测阶段何时应用特征转换。

# 一致的数据预处理

一致的数据预处理是必要的，因为您可以在磁盘上生成数据时或在模型内部应用转换。让我们讨论这些方法：

## 训练前数据转换

这意味着在完整数据集上进行模型训练*之前*执行数据转换。您的转换代码独立于您的机器学习模型。这种方法的优点是计算仅执行一次，并且它可以查看整个数据集以确定转换。

这种方法的一些缺点是：在预测时需要重现相同的转换，如果预测时的数据发生变化，可能会导致偏差，尤其是在在线服务或预测的情况下。另一个挑战是更新转换。如果您想更新数据转换，就必须在整个数据集上重新运行转换，导致迭代缓慢和计算时间增加。

## 模型内数据转换

在这种方法中，转换是模型代码的一部分，因为模型接收未转换或原始数据作为输入，并在训练前在模型内部对其进行转换。这种方法的优点之一是易于将数据和转换解耦。即使您的转换技术发生变化，您仍然可以使用相同的数据。由于转换是模型的一部分，您在训练和服务期间也使用相同的转换。这种方法的缺点是，如果转换规模大或计算量大，会增加模型延迟。转换是按数据批次完成的，如果您试图使用数据批次而不是整个数据集来设置均值以归一化数据，这可能会成为一个问题。

这可以通过 `tf.Transform` 解决，我们将在本章后面的“TensorFlow Transform”部分介绍。

# 编码结构化数据类型

一个好的特征应该与业务目标相关、在预测时已知、具有数值大小的数值型，并拥有足够的样本。让我们看看我们将在本章中使用的特征工程中的各种数据类型。

## 类别数据

这种数据类型定义类别，且数据仅取有限数量的值——例如，数据列中的是/否类型数据、性别类别中的男/女值等。

## 数值数据

这表示标量值或连续数据形式的数据，如观测值、记录和测量值。

### 映射数值

整数和浮点数据不需要特殊编码，因为它们可以乘以数值权重。您可能需要对数值数据应用两种转换：归一化和分桶。

#### 归一化

我们在[第 2 章](#c02.xhtml)“探索数据和构建数据管道”的数据清洗部分介绍了缩放、对数缩放、Z 分数和裁剪等归一化技术。您会在两种情况下对数值数据执行归一化：

*   **具有截然不同范围的数值特征（例如年龄和收入）：** 在这种情况下，由于数据范围各异，模型梯度下降可能会减慢收敛。这就是 `AdaGrad` 和 `Adam` 优化技术能提供帮助的原因，因为它们为每个特征创建单独的学习率。
*   **覆盖宽范围的数值特征（如城市）：** 如果不归一化，此类数据集模型将生成 `NaN` 数据错误。在这种情况下，即使是 `Adam` 和 `AdaGrad` 等优化器，也无法在单个特征中存在宽范围值时防止 `NaN` 错误。

#### 分桶

分桶是将数值数据转换为类别数据。例如，纬度可以是浮点值，而在预测房价与位置的关系时，很难表示它。分桶有两种方法：

*   **创建等间距边界的桶：** 您创建一系列桶，某些桶可能比其他桶拥有更多的数据点。例如，为了表示降雨量，您可以按范围分桶（0–50 厘米，50–100 厘米）；在降雨强度较小的地区，您可能在 0–50 厘米的降雨量范围内拥有更多数据点。
*   **分位数边界的桶：** 每个桶拥有相同数量的点。边界不是固定的，可能包含窄或宽的值跨度。

### 映射类别值

有多种方法可以将您的类别数据转换为数值数据，以便您的模型能够理解。

#### 标签编码或整数编码

在标签编码中，您将使用词汇表进行索引。如果数据字段的类别数量较少，例如犬种或一周中的日期，您可以为每个类别创建一个唯一特征并分配一个整数值。例如，评分可以分配为“满意”= 1，“良好”= 2，“最佳”= 3。仅当类别代表有限范围或有序值时，才能应用整数评分。

#### 独热编码

独热编码是创建哑变量的过程。此技术用于顺序无关的类别变量。当特征为名义型（没有任何顺序）时，使用独热编码技术。让我们先讨论类别数据中的有序关系是什么；例如，有序变量可以是社会经济地位（低收入、中等收入、高收入）、教育水平（高中、学士、硕士、博士）、收入水平（低于 5 万、5 万–10 万、10 万以上）、满意度评分（极其不喜欢、不喜欢、中立、喜欢、极其喜欢）。对于不存在这种有序关系的类别变量，整数编码是不够的。

在独热编码中，为每个类别特征创建一个新变量。这是一个将类别变量转换为整数编码或整数值的二进制表示的过程。让我们看看[表 3.1](#c03.xhtml#c03-tbl-0001)所示的两种颜色的示例。每种颜色都可以用二进制值表示。

**表 3.1** 独热编码示例

| 类别值 | 整数编码或创建词汇表映射 | 独热编码 |
| --- | --- | --- |
| 红色 | 0 | 00 |
| 蓝色 | 1 | 01 |

有时您有巨大的二进制空间需要表示，这可能会导致包含大量 0 的稀疏表示。
