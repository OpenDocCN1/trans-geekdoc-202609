

解决此问题的一种方法是通过哈希将这个高基数变量转换为低基数域。这在 BigQuery 中可以非常轻松地完成，如下所示：

```
ABS(MOD(FARM_FINGERPRINT(zipcode), numbuckets))
```

这使用了一个名为 FarmHash 的哈希函数，它是一系列哈希算法，具有确定性、分布良好，且可在多种编程语言中使用。

### 转换

有时在将输入送入模型之前，会对模型的输入进行修改、增强或构建，就像哈希示例那样。应用于输入的转换中包含有价值的信息。应用于训练数据集输入的转换，如果模型部署在生产环境中，也必须应用于输入。因此，转换代码是在进行预测时流水线的一部分。BigQuery 有一个优雅的解决方案来解决这个问题，称为 `TRANSFORM` 子句，它是 `CREATE_MODEL` 函数的一部分：

```
CREATE OR REPLACE MODEL m
  TRANSFORM(ML.FEATURE_CROSS(STRUCT(f1, f2)) as cross_f,
            ML.QUANTILE_BUCKETIZE(f3) OVER() as buckets,
            label_col)
  OPTIONS(model_type='linear_reg', input_label_cols=['label_col'])
AS SELECT * FROM t
```

在前面的示例 SQL 中，我们正在对 f1 和 f2 创建一个“特征交叉”转换，第二个转换是对特征 f3 进行分位数分桶。这些转换将应用于输入字段 f1、f2 和 f3，以创建名为“cross_f”和“buckets”的新特征。BigQuery ML 将自动将此转换代码添加到构建的模型中。因此，在预测期间，当你传递输入 f1、f2 和 f3 时，它将在将输入发送到模型之前自动执行这些转换。

BigQuery 提供了许多此类有用的转换，如 `POLYNOMIAL_EXPAND`、`FEATURE_CROSS`、`NGRAMS`、`QUANTILE_BUCKET`、`HASH_BUCKETIZE`、`MIN_MAX_SCALER` 和 `STANDARD_SCALER`。

有关 `TRANSFORM` 子句的更多详细信息，请参阅文档：

`https://cloud.google.com/bigquery-ml/docs/reference/standard-sql/bigqueryml-preprocessing-functions`

此设计模式的注意事项是，带有转换的模型将无法在 BigQuery ML 之外工作，例如，如果你将模型导出到 Vertex AI。

## 总结

BigQuery 是一项重要的服务，它彻底改变了 SQL 社区中 ML 的使用方式。BigQuery ML 实现了机器学习的民主化，使其可供更多人使用。

在本章中，我们了解了如何使用 SQL 执行 ML 流水线的所有操作。我们还学习了如何直接使用 SQL 对输入值应用转换，从而减少创建模型的时间。虽然 BigQueryML 是一项独立的服务，但它与 Vertex AI 高度互操作。最后，我们还看到了一些 BigQuery ML 独有的有趣设计模式。

## 考试要点

*   **理解 BigQuery 和 ML。** 了解 BigQuery 的历史以及将机器学习引入数据仓库、数据分析以及任何熟悉 SQL 人员的创新。学习如何使用 SQL 进行训练、预测和提供模型解释。

*   **能够解释 BigQuery ML 和 Vertex AI 之间的区别以及它们如何协同工作。** 这些服务提供相似的功能，但面向不同的用户设计。BigQuery ML 面向分析师和任何熟悉 SQL 的人设计，而 Vertex AI 面向 ML 工程师设计。了解使这两项服务之间无缝协作的各种集成点。

*   **理解 BigQuery 设计模式。** BigQuery 拥有解决机器学习中反复出现问题的优雅方案。哈希、转换和无服务器预测很容易应用到你的 ML 流水线中。

## 复习题

1.  你在一家拥有全球鞋类品牌的公司的大型数据分析师团队中工作。该公司在南亚制造，并在全球范围内分销。其销售在 COVID-19 大流行期间受到影响，分销也是如此。你的团队被要求利用关于疾病传播的新数据和恢复计划，按国家预测销售额。目前你的数据在本地，销售数据每周来自世界各地。你将使用什么进行预测？

    1.  使用 Vertex AI AutoML Tables 预测销售额，因为这是一个分布式案例。
    2.  使用带有自定义模型的 Vertex AI AutoML Tables，因为由于 COVID-19 这是一个特殊案例。
    3.  使用 BigQuery ML，尝试 TensorFlow 模型和 DNN 模型以找到最佳结果。
    4.  使用带有 `ARIMA_PLUS` 的 BigQuery ML，并使用 BigQuery COVID-19 公共数据集获取趋势。

2.  你是一家自行车租赁初创公司的成员，你想根据当前位置和用户 ID 预测自行车将被使用的时长和行驶距离。你是一个小型数据分析师团队的一员，目前所有数据都位于数据仓库中。你的经理要求你快速创建一个机器学习模型，以便他们评估这个想法。你的经理想向 CEO 展示这个原型以提高销售额。你会选择什么？

    1.  在 Vertex AI Tables 上使用 TensorFlow 模型来预测时间和距离。
    2.  使用 Google Maps 中的高级路径预测算法。
    3.  使用 BigQuery ML。
    4.  使用 Vertex AI 自定义模型以获得更好的结果，因为输入包含地图坐标。

3.  你是一个大型视频分享网站的数据分析师。该网站有数千名用户为视频提供 5 星评分。你被要求为每个用户提供推荐。你会使用什么？

    1.  使用 BigQuery 分类 `model_type`。
    2.  使用 Vertex AI 自定义模型构建协同过滤模型并在线提供服务。
    3.  使用 BigQuery ML 中的矩阵分解模型，利用显性反馈创建推荐。
    4.  使用 Vertex AI AutoML 进行矩阵分解。

4.  你是一名数据分析师，你的经理给了你一个 TensorFlow SavedModel 用于分类。你需要快速获得一些预测，但不想设置任何实例或创建流水线。你的方法是什么？

    1.  使用 BigQuery ML 并选择 TensorFlow 作为模型类型来运行预测。
    2.  使用 Vertex AI 自定义模型，并使用 TensorFlow SavedModel 创建自定义容器。
    3.  TensorFlow SavedModel 只能在本地使用，因此将数据下载到 Jupyter Notebook 并在本地预测。
    4.  使用 Kubeflow 创建预测。

5.  你在金融行业担任数据科学家，法规要求收集和存储每个机器学习预测的解释。你被要求提供一个初始机器学习模型来对良性贷款和违约贷款进行分类。你提供的模型将首先被使用，并预计将由数据分析师团队进一步改进。你的解决方案是什么？

    1.  使用 Kubeflow Pipelines 创建带有解释的 Vertex AI AutoML Table。
    2.  使用 Vertex AI Pipelines 创建带有解释的 Vertex AI AutoML Table 并将它们存储在 BigQuery 中，供分析师处理。
    3.  使用 BigQuery ML，选择“分类”作为模型类型并启用解释。
    4.  使用带有解释的 Vertex AI AutoML Tables 并将结果存储在 BigQuery ML 中供分析师使用。

6.  你是一名数据科学家，构建了大量使用 Vertex AI AutoML Tables 的 Vertex AI Pipelines。你的经理要求你使用 BigQuery 中的数据构建一个新模型。你打算如何进行？

    1.  创建一个 Vertex AI 流水线组件，将 BigQuery 数据集下载到 GCS 存储桶，然后运行 Vertex AI AutoML Tables。
    2.  创建一个新的 Vertex AI 流水线组件，在 BigQuery 数据上训练 BigQuery ML 模型。
    3.  创建一个 Vertex AI 流水线组件，通过直接导入 BigQuery 数据集来执行 Vertex AI AutoML。
    4.  创建一个计划查询在 BigQuery 中训练模型。
