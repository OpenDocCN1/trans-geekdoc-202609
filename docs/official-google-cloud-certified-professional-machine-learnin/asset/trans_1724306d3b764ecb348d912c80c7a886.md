

# Dataprep by Trifacta

**Dataprep by Trifacta** (`https://cloud.google.com/dataprep`) 是一款无服务器的智能工具，用于以可视化方式探索、清洗和准备结构化及非结构化数据，以便大规模进行分析、报告和机器学习。无需部署或管理基础设施。此外，由于它是无服务器且基于 UI 的，因此无需管理基础设施，也无需编写代码。它会建议您的下一步数据转换，并随每次 UI 输入进行预测。

## 概要

在本章中，我们讨论了特征工程，以及为什么转换数值特征和类别特征对于模型训练和服务至关重要。

随后，我们讨论了转换数值特征的各种技术，例如分桶和归一化。我们还讨论了转换类别特征的技术，如线性编码、独热编码、词表外处理、哈希和嵌入。

您了解了为什么特征选择很重要，以及一些降维技术，如 PCA。然后我们介绍了类别不平衡，以及精确率和召回率如何影响分类。对于不平衡类别，AUC PR 比 AUC ROC 更有效。

我们还讨论了为什么特征组合很重要以及特征组合的好处。

我们介绍了如何使用 `tf.data` 表示 TensorFlow 的数据，随后介绍了 `tf.Transform` 以及如何在 Google Cloud 上使用 `tf.Transform` 处理流水线。您了解了一些 Google Cloud 数据处理和 ETL 工具，如 Cloud Data Fusion 和 Cloud Dataprep。

## 考试重点

*   **使用一致的数据处理。** 了解何时转换数据，无论是在训练前还是在模型训练期间。还要了解训练前转换数据的优缺点。

*   **了解如何编码结构化数据类型。** 理解转换数值和类别数据的技术，如分桶、归一化、哈希和独热编码。

*   **理解特征选择。** 了解为什么需要特征选择以及一些特征选择技术，如降维。

*   **理解类别不平衡。** 理解分类问题中的真阳性、假阳性、准确率、AUC、精确率和召回率，以及如何在类别不平衡的情况下有效衡量准确率。

*   **知道在何处以及如何使用特征组合。** 您需要理解为什么特征组合很重要以及在哪些场景中需要它。

*   **理解 TensorFlow Transform。** 您需要理解 TensorFlow Data 和 TensorFlow Transform，以及如何使用 BigQuery 和 Cloud Data Fusion 在 Google Cloud 上构建 `tf.Transform` 流水线。

*   **使用 GCP 数据和 ETL 工具。** 知道如何以及何时使用 Cloud Data Fusion 和 Cloud Dataprep 等工具。例如，如果您正在寻找一种无代码解决方案来清洗数据，您将使用 Dataprep 进行数据处理；如果您正在寻找一种无代码且基于 UI 的 ETL（提取、转换、加载）解决方案，您将使用 Cloud Data Fusion。

## 复习题

1.  您是公司的数据科学家。您有一个数据集，其中所有特征均为类别特征。您使用某些算法训练了模型。某些算法对此数据效果良好，但更换算法后性能下降。哪种数据转换策略可能会提高模型性能？

    1.  将数据写入 TFRecords。
    2.  使用类别特征创建特征组合。
    3.  对所有类别特征使用独热编码。
    4.  对特征进行过采样。

2.  您正在从事一个基于神经网络的项目。提供给您的数据集包含不同范围的列。在为模型训练准备数据时，您发现梯度优化难以将权重移动到最优解。您应该怎么做？

    1.  使用特征构造来组合最强特征。
    2.  使用归一化技术。
    3.  通过去除缺失值的特征来改进数据清洗步骤。
    4.  更改分区步骤以减小测试集维度并获得更大的训练集。

3.  您在一家信用卡公司工作，被要求使用 AutoML Tables 基于历史数据创建一个自定义欺诈检测模型。您需要优先检测欺诈交易，同时将误报降至最低。训练模型时应使用哪个优化目标？

    1.  使对数损失最小化的优化目标。
    2.  在召回率为 0.50 时使精确率最大化的优化目标。
    3.  使精确率-召回率曲线下面积 (AUC PR) 最大化的优化目标。
    4.  使接收者操作特征曲线下面积 (AUC ROC) 最大化的优化目标。

4.  您是一名数据科学家，正在处理一个带有时间序列数据的分类问题，仅经过几次实验就在训练数据上实现了 99% 的接收者操作特征曲线下面积 (AUC ROC)。您尚未探索使用任何复杂算法，也未花费任何时间进行超参数调优。为了识别并修复问题，您的下一步应该是什么？

    1.  通过使用复杂度较低的算法来解决模型过拟合问题。
    2.  通过在模型训练期间应用嵌套交叉验证来解决数据泄露问题。
    3.  通过移除与目标值高度相关的特征来解决数据泄露问题。
    4.  通过调整超参数以降低 AUC ROC 值来解决模型过拟合问题。

5.  您正在 Vertex AI 上使用 TPU 训练 ResNet 模型，以直观地对汽车发动机缺陷类型进行分类。您使用 Cloud TPU 性能分析器插件捕获训练配置文件，并观察到其高度受输入限制。您希望减少瓶颈并加快模型训练过程。您应该对 `tf.data` 数据集进行哪些修改？（选择两项。）

    1.  使用 interleave 选项读取数据。
    2.  将 prefetch 选项设置为等于训练批次大小。
    3.  减少 repeat 参数。
    4.  减少转换中的批次大小参数。
    5.  增加 shuffle 的缓冲区大小。

6.  您受命为一个 ML 训练模型开发输入流水线，该模型以低延迟处理来自不同来源的图像。您发现输入数据无法放入内存。按照 Google 推荐的最佳实践，您应如何创建数据集？

    1.  创建 `tf.data.Dataset.prefetch` 转换。
    2.  将图像转换为 TFRecords，将图像存储在 Cloud Storage 中，然后使用 `tf.data` API 读取图像进行训练。
    3.  将图像转换为 `tf.Tensor` 对象，然后运行 `Dataset.from_tensor_slices()`。
    4.  将数据转换为 TFRecords。

7.  加利福尼亚州的不同城市房价差异巨大。假设您必须创建一个模型来预测房价。以下哪组特征或特征组合可以学习 roomsPerPerson 与房价之间的城市特定关系？

    1.  两个特征组合：`[分桶纬度 x 分桶 roomsPerPerson]` 和 `[分桶经度 x 分桶 roomsPerPerson]`
    2.  三个单独的分桶特征：`[分桶纬度]`、`[分桶经度]`、`[分桶 roomsPerPerson]`
    3.  一个特征组合：`[分桶纬度 x 分桶经度 x 分桶 roomsPerPerson]`
    4.  一个特征组合：`[纬度 x 经度 x roomsPerPerson]`
