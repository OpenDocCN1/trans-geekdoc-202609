

# BigQuery ML

BigQuery ML（以前称为 BQML）允许您使用标准 SQL 查询创建机器学习模型。您可以仅使用 SQL 查询创建模型，并对模型进行训练、测试、验证和预测。您无需编写任何 Python 代码即可在 BigQuery 中使用机器学习。此外，它完全无服务器。

## 模型训练

要创建模型，使用的关键字是 `CREATE MODEL`。此语句类似于 `CREATE TABLE DDL` 语句。当您运行包含 `CREATE MODEL` 语句的查询时，会生成一个查询作业并处理该查询。与 `CREATE MODEL` 类似，您还可以使用 `CREATE MODEL IF NOT EXISTS` 和 `CREATE OR REPLACE MODEL`，这些命令名称直观易懂，方便我们复用模型名称。

```
CREATE MODEL modelname1
   OPTIONS(model_type='linear_reg', input_label_cols=['label_col'])
AS SELECT * FROM table1
```

在前面的 SQL 命令中，关键字之后，您必须提供两个选项：`model_type` 和 `input_label_cols`。模型类型指定您尝试构建哪种模型。可供您选择的有回归、分类和时间序列模型。有关当前可用模型的完整列表，请参见[表 14.1](#c14.xhtml#c14-tbl-0001)。第二个选项是 `input_label_cols`，用于标识所提供数据中的目标列。

最后，SQL 命令的最后一部分（`SELECT * FROM table1`）标识您将用于训练的表。请注意，它显示为一个简单的选择查询，这意味着查询结果被传递给了训练作业。在这一行中，您可以选择某些列、选择某些行、连接多个表以生成结果等，以创建您的训练数据集。唯一的限制是确保目标列存在，并且有足够的行来训练模型。

我们为小型数据集创建了一个模型，几分钟内就完成了：

```
CREATE OR REPLACE MODEL 
    `test.creditcard_model1` 
OPTIONS(model_type='logistic_reg', 
        input_label_cols=['defaultpaymentnextmonth'])
AS 
SELECT * FROM `test.creditcardtable`
```

当我们训练分类模型时，可以查看训练结果、迭代过程以及评估指标，包括聚合指标、分数阈值、ROC 曲线、PR 曲线和混淆矩阵。这些都是自动计算的。

## 模型评估

不过，建议使用模型未见过的独立数据集，通过关键字 `ML.EVALUATE` 对模型进行评估。

```
SELECT * FROM 
ML.EVALUATE(MODEL `projectid.test.creditcard_model1`, 
  (SELECT * FROM `test.creditcardtable`))
```

这在几秒钟内给出了[图 14.4](#c14.xhtml#c14-fig-0004) 所示的结果，Web 界面中显示了查询及其下方的结果。

## 预测

`ML.PREDICT` 函数用于 BigQuery ML 中的预测。您可以传递整个表进行预测，输出将是一个包含所有输入列且行数相同的表，外加两个新列：`predicted_<label_column_name>` 和 `predicted_<label_column_name>_probs`。此处的 `<label_column_name>` 是训练数据中标签列的名称。存在一些差异。

以下是使用我们创建的模型进行预测的示例 SQL：

```
select * from 
 ML.PREDICT (MODEL `dataset1.creditcard_model1`,
       (select * FROM `dataset1.creditcardpredict` limit 1))
```

这里我们指定了之前创建的模型 `creditcard_model1`，从名为 `creditcardpredict` 的表中选择一行并将其传递给 `ML.PREDICT` 函数。第一行中的 `select` 允许我从输出中仅选择特定列。

以下是仅选择预测结果的相同示例：

```
select 
       predicted_defaultpaymentnextmonth, 
       predicted_defaultpaymentnextmonth_probs
  from 
ML.PREDICT (MODEL `dataset1.creditcard_model1`,
    (select  * FROM `dataset1.creditcardtable` limit 1))
```

前面查询的结果如[图 14.5](#c14.xhtml#c14-fig-0005) 所示。请注意，每个标签的预测概率均已显示。

## BigQuery ML 中的可解释性

可解释性对于调试模型和提高透明度非常重要，在某些领域甚至是法规要求。在 BigQuery 中，您可以在模型级别获取全局特征重要性值，也可以获取每个预测的解释。这些也通过 SQL 函数访问。

要在全局级别获得解释，您必须在训练期间设置 `enable_global_explain=TRUE`。以下是我们前一个示例的样本 SQL：

```
CREATE OR REPLACE MODEL 
       `model1`
  
OPTIONS(model_type='logistic_reg',
        enable_global_explain=TRUE,
        input_label_cols=['defaultpaymentnextmonth']) AS SELECT 
  * 
FROM `dataset1.creditcardtable`
```

模型训练完成后，您可以查询模型的全局解释，这些解释以表的形式返回（[图 14.6](#c14.xhtml#c14-fig-0006)）；每一行包含输入特征及代表重要性的浮点数。

```
SELECT  *
FROM  
ML.GLOBAL_EXPLAIN(MODEL `model1`)
```

特征旁边的数字代表该特征对预测的影响。归因值越高，与模型的相关性越高，反之亦然。但请注意，归因值未归一化（它们的总和不等于 1）。请参见[表 14.2](#c14.xhtml#c14-tbl-0002)。
