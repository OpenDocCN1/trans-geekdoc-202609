
*   用于训练的数据未经过清洗。
*   模型具有高偏差。

过拟合模型的性能在训练数据集中未见过的样本上变化很大。以下是一些减少欠拟合的方法：

*   增加模型复杂度。
*   通过特征工程增加特征数量。
*   从数据中移除噪声。
*   增加轮数或延长训练时长以获得更好的结果。

## 过拟合

模型过度学习了训练数据，导致在新的未见样本上，甚至在训练数据集样本中添加统计噪声时，性能变化很大。过拟合模型具有低偏差和高方差。针对过拟合模型主要有两种处理思路：

*   通过在更多样本上训练网络来减少过拟合。
*   通过改变网络结构和参数的复杂度来减少过拟合。

以下是一些避免过拟合的方法：

*   正则化技术：下一节将详细解释。
*   `Dropout`：训练期间以概率方式移除输入。
*   `Noise`：训练期间向输入添加统计噪声。
*   `Early stopping`：监控模型在验证集上的性能，当性能下降时停止训练。
*   数据增强。
*   交叉验证。

参考此链接了解避免过拟合的 10 种方法：`www.v7labs.com/blog/overfitting`。

## 正则化

正则化发挥作用，将学习到的估计值向 0 收缩。换句话说，它通过添加惩罚项来调整损失函数，防止系数过度波动，从而降低过拟合的风险。

L1 和 L2 是两种常见的正则化方法。当你试图减少特征时使用 L1，当你寻求稳定模型时使用 L2。[表 7.3](#c07.xhtml#c07-tbl-0003) 总结了这两种技术的区别。

**表 7.3** L1 与 L2 正则化的区别

| L1 正则化 | L2 正则化 |
| --- | --- |
| L1 正则化，也称为 L1 范数或套索（在回归问题中），通过将参数向 0 收缩来对抗过拟合。这会使某些特征变得多余。因此，如果你有大量特征，这非常适合特征选择。 | L2 正则化，或 L2 范数或岭回归（在回归问题中），通过强制权重变小但不使其恰好为 0 来对抗过拟合。 |
| L1 正则化惩罚权重绝对值之和。 | L2 正则化惩罚权重平方和。 |
| L1 正则化内置特征选择功能。 | L2 正则化不执行特征选择。 |
| L1 正则化对异常值具有鲁棒性。 | L2 正则化对异常值不具鲁棒性。 |
| L1 正则化有助于特征选择和减小模型规模，从而得到更小的模型。 | L2 正则化始终能改善线性模型的泛化能力。 |

本节介绍了正则化。接下来我们将介绍训练神经网络时反向传播可能出错的常见方式及正则化对策：

*   **梯度爆炸：** 如果网络中的权重非常大，则较低层的梯度将涉及许多大项的乘积，导致梯度过大而无法收敛。批量归一化和降低学习率有助于防止梯度爆炸。
*   **ReLU 单元死亡：** 线性整流激活函数，简称 `ReLU`，是一种线性函数，如果输入为正则直接输出输入，否则输出 0。隐藏层使用整流函数的网络称为整流网络。一旦 `ReLU` 单元的加权和低于 0，该单元可能会卡住。它输出 0 激活值，不对网络输出做任何贡献，且在反向传播期间梯度无法再通过它流动。由于梯度来源被切断，`ReLU` 的输入可能永远无 longer 变化足以使加权和重新回到 0 以上。降低学习率有助于防止 `ReLU` 单元死亡。
*   **梯度消失：** 较低层（更接近输入层）的梯度可能变得非常小。当较低层的梯度向 0 消失时，这些层训练得非常慢，或者根本不训练。`ReLU` 激活函数有助于防止梯度消失。
*   **Dropout 正则化：** 这种正则化类型对神经网络很有用。它通过在单个梯度步骤中随机“丢弃”网络中的单元激活值来工作。丢弃得越多，正则化越强：
    *   `0.0` = 无 Dropout 正则化。
    *   `1.0` = 丢弃所有内容。模型什么也学不到。
    *   `0.0` 和 `1.0` 之间的值 = 更有用。

损失目前表现良好，但如果你想进一步降低训练损失，可以尝试以下技术：

*   增加神经网络的深度和宽度。
*   如果特征相对于现有特征没有增加信息量，尝试不同的特征。
*   降低学习率。
*   增加层的深度和宽度（以增强预测能力）。
*   如果你有大量数据，使用留出的测试数据。
*   如果你数据很少，使用交叉验证或自助法。

你训练的模型未收敛且在震荡。这可能是由于以下原因：

*   特征可能没有预测能力。
*   原始数据可能不符合定义的模式。
*   学习率似乎过高，需要降低它。
*   减少训练集至少量样本以获得极低的损失。
*   从一两个已知具有预测能力的特征（和一个简单模型）开始，看看模型是否优于你的基线。
