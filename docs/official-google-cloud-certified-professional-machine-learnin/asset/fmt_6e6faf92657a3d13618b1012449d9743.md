## 预训练模型

当您尝试使用机器学习解决问题时，第一步是查看是否有预训练模型可用。预训练模型是在超大规模数据集上训练的机器学习模型，在基准测试中表现优异。这些模型由庞大的工程和研究团队支持，并会频繁重新训练。

作为客户，您可以通过 Web 控制台（或 CLI、Python、Java 或 Node.js SDK）在几分钟内开始使用这些模型。

任何试图使用机器学习解决问题的开发者，都应首先检查 Google Cloud 平台上是否有可用的预训练模型，如果有，则应使用它。

Google Cloud 提供多种预训练模型：

*   Vision AI
*   Video AI
*   Natural Language AI
*   Translation AI
*   Speech-to-Text 和 Text-to-Speech

除了预训练模型，Google Cloud 还提供针对特定问题的解决方案平台，这些平台包含预训练模型，并支持对现有模型进行调优：

*   Document AI
*   Contact Center AI

### Vision AI

Vision AI 为您提供便捷的 ML 算法访问权限，用于处理图像和照片，无需构建完整的机器学习基础设施。使用此服务，您可以执行图像分类、检测物体和人脸，以及通过光学字符识别 (OCR) 识别手写文字。

您也可以在浏览器中通过 `https://cloud.google.com/vision` 快速试用该服务。在生产环境中，通常将图像上传到服务或指向图像 URL 进行分析。

当您使用浏览器试用服务时，会获得四种类型的预测，如 [图 4.2](#c04.xhtml#c04-fig-0002) 所示。首先，您会看到照片中检测到的物体。

其次，您会获得图像的一组标签；在我们的示例中，获得的标签包括 Table、Furniture、Plant、Houseplant、Cabinetry、Wood 等。第三，您会获得这些图像的主要颜色，可用于基于调色板整理图像。最后，您会获得“安全搜索”分类，即图像是否属于以下类别之一：Adult（成人内容）、Spoof（恶搞）、Medical（医疗）、Violence（暴力）和 Racy（低俗）。这些分类可用于标记图像，适用于需要限制共享特定类型图像的场景（例如避免向青少年展示成人内容）。

### Video AI

此 API 拥有预训练的机器学习模型，可识别视频中的物体、地点和动作。它适用于存储的视频，也适用于流式视频（实时返回结果）。

您可以使用此服务识别视频中 20,000 多种不同的物体、地点和动作。您可以将结果作为视频中的元数据，用于从视频目录中搜索视频。例如，您可以使用该服务标记体育视频，并具体识别运动类型。您还可以处理直播流；例如，如果您有一个监控交通的街道摄像头，可以统计通过路口的汽车数量。

以下是 Video AI 的几个用例示例：

*   **用例 1：** 此 API 可用于构建视频推荐系统，利用 API 生成的标签和用户的观看历史。这使您能够基于视频内部细节（而不仅仅是外部元数据）进行推荐，从而极大地提升用户体验。

*   **用例 2：** 另一个用例是利用 API 的元数据为视频档案创建索引。这非常适合拥有 PB 级未索引数据的大众媒体公司。

*   **用例 3：** 插入视频中的广告有时可能与视频内容完全无关。这是另一个用例，您可以通过比较视频内容的时间段特定标签和广告内容来改善用户体验。

### Natural Language AI

Natural Language AI 使用预训练的机器学习模型从非结构化文本中获取洞察。其提供的主要服务包括实体提取、情感分析、语法分析和通用分类。

实体提取服务可识别人名、组织名、产品名、事件、地点等实体。如果找到相关链接，该服务还会用 Wikipedia 文章链接等额外信息丰富实体。尽管实体提取听起来像个简单问题，但它是一项非同小可的任务。例如，在句子 “Mr. Wood is a good actor” 中，需要相当的理解能力才能判断 “Mr. Wood” 是一个人名，而不是一种木材。

情感分析为每个句子、每个实体和整段文本提供带幅度的正面、负面或中性评分。语法分析可用于识别词性、词间依存关系、词 lemma 和文本形态。最后，它还将文档分类到 700 多个预定义类别之一。详情请参阅 `https://cloud.google.com/natural-language`。

以下是 Natural Language AI 的一些用例：

*   **用例 1：** 衡量客户对特定产品的情感。使用实体分析从电子邮件、聊天记录和社交媒体等文档中查找重要详情，并对这些实体进行情感分析，以了解客户对特定产品的看法。

*   **用例 2：** 使用 Healthcare Natural Language API 理解医疗文本特有的详情，如临床记录或医疗研究文档。您可以用它提取药物、剂量和病症等医疗洞察，构建强大的医疗应用。注意：Healthcare Natural Language API 独立于 Google 的 Natural Language AI。

### Translation AI

使用 Translation AI 可检测 100 多种语言（从 Afrikaans 到 Zulu），并翻译列表中任意语言对。它采用 Google 神经机器翻译 (GNMT) 技术，该技术由 Google 率先开发，现已成为行业标准。详情请参阅 `https://ai.googleblog.com/2016/09/a-neural-network-for-machine.html`。

此服务分 Basic 和 Advanced 两个级别。两者有很多区别，但主要区别在于 Advanced 版本可以使用 *glossary*（源语言到目标语言的术语映射字典），还可以翻译整个文档（PDF、DOC 等）。价格也有差异。

您可以翻译 ASCII 或 UTF-8 格式的文本。此外，还可以使用 Media Translation API 实时翻译音频，通常用于流媒体服务。

Media Translation API（独立于 Translation API）可直接将源语言音频翻译为目标语言音频。这有助于低延迟流式应用并快速扩展。
