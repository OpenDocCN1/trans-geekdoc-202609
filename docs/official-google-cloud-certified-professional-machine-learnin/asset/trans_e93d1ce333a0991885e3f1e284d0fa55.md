

# Vision API 产品搜索

Vision API 产品搜索（Vision AI 下的一项服务）可以基于您产品目录中的参考图片进行训练，随后可使用图片进行搜索。

# Recommendations AI

该解决方案的第三部分是 Recommendations AI，它能够理解客户行为、上下文和 SKU 背后的细微差别，以便通过相关推荐在各渠道提升互动率。

在该解决方案中，客户上传包含每个产品详细信息、照片和其他元数据的产品目录。随后，客户输入“用户事件”，例如客户点击、浏览和购买的内容。Recommendations AI 利用这些数据创建模型。客户需为训练模型付费，这些模型会持续微调以纳入“用户事件”数据的更新。

此外，当推荐结果被调用并产生数百万次点击时，客户需为每 1,000 次请求付费。这是一种无服务器的资源配置方式，客户无需操心后台的确切硬件配置。

Recommendations AI 提供了易于使用的自动化机器学习训练方法。它提供了多种不同的模型，服务于在线零售业务的多种目的。从考试角度来看，理解[表 4.4](#c04.xhtml#c04-tbl-0004)非常重要，该表描述了不同的推荐类型。

# Document AI

当您想要从文档中提取详细信息时，例如旧印刷文档、书籍或表格的数字化扫描图片，可以使用 Document AI。这些页面可能包含段落格式的文本，也可能包含表格和图片。其中部分文本可能是印刷体，有时也可能是手写体。这也是政府办公室（如车管所 DMV）常见的文档类型，人们需要在表格上填写信息。

表格包含印刷文本和供人们填写详细信息的空白栏。这些内容可能用不同类型的墨水书写（蓝笔或黑笔等），且人们书写时有时会出错。因此，ML 模型需要理解文档的结构（在哪里期望出现“姓名”和“地址”），并对手写文本具有一定的容错能力。

另一个例子是政府文件，如护照、驾驶执照和纳税申报单。这些文档结构较好，但仍存在一些差异。

如果我们能从表格中提取重要详细信息（如“名”、“姓”、“地址”等），就得到了结构化数据，这些数据现在可以存储在数据库中并进行分析。这就是提取阶段。

Document AI 是一个理解文档并帮助您执行以下操作的平台：

*   检测文档质量。
*   矫正倾斜。
*   提取文本和布局信息。
*   识别并提取键值对。
*   提取并规范化实体。
*   拆分和分类文档。
*   审核文档（人工介入）。
*   存储、搜索和整理文档（Document AI Warehouse）。

Document AI 有两个重要概念：`processors` 和 `Document AI Warehouse`。

Document AI 处理器是文档与机器学习模型之间的接口，用于执行相关操作。有通用处理器、专用处理器（采购、身份、贷款和合同文档）和自定义处理器。您可以通过提供训练数据集（标记过的文档集）来训练自定义处理器以满足您的自定义需求。有关处理器类型的完整列表，请访问 `https://cloud.google.com/document-ai/docs/processors-list`。

Document AI Warehouse 是一个用于存储、搜索、整理、治理和分析文档及其结构化元数据的平台。

# Dialogflow 和 Contact Center AI

Dialogflow 是 Google Cloud 提供的对话式 AI 产品，提供聊天机器人和语音机器人。它集成到电话服务和其他服务中，为您提供 Contact Center AI (CCAI) 解决方案。让我们看看该解决方案提供的服务。

## 虚拟代理

您可以快速开发面向企业的高级虚拟代理，它们能够处理话题切换和补充问题，并提供 7x24 小时多渠道支持。其设计应确保虚拟代理能够处理大多数情况。复杂的通话将转接给人工代理。

## 代理辅助

当人工代理处理通话时，代理辅助可以通过识别意图、提供来自集中式知识库的即时回复和答案，以及实时转录通话来提供支持。

## 洞察

该服务使用自然语言处理来分析通话驱动因素并衡量情绪，帮助管理层了解呼叫中心运营情况，从而改善结果。

## CCAI

Contact Center AI 平台是一个完整的云原生平台，支持客户与代理之间的多渠道通信。

尽管 Dialogflow 和 CCAI 使用了先进的机器学习技术（尤其是在自然语言方面），但这些技术大多对机器学习工程师是隐藏的。深入了解 CCAI 超出了本次考试的范围。

# 自定义训练

当您选择自定义训练时，您可以完全灵活地选择各种硬件选项来训练模型。

图形处理单元 (GPU) 可以加速深度学习模型的训练过程。用于自然语言、图像和视频的模型需要计算密集型操作（如矩阵乘法），这些操作可通过在 GPU 等大规模并行架构上运行而受益。

如果在单个 CPU 上训练深度学习模型，可能需要数天、数周甚至数月才能完成。但是，如果您能将繁重的计算卸载到 GPU，可以将时间缩短一个数量级。以前需要数天的任务可能只需几小时即可完成。

为了了解专用硬件的优势，让我们先看看 CPU 的工作原理。

## CPU 的工作原理

CPU 是一种可以运行通用工作负载的处理器，包括软件应用、数据应用等。CPU 设计得非常灵活，支持大量操作。

CPU 从内存加载数据，对值执行某些操作，然后将结果存回内存，每个操作都如此。这种架构非常适合通用软件应用。然而，CPU 串行执行计算，当需要进行数万亿次计算时（这在使用大型数据集训练 ML 模型时非常典型），这种方式效率极低。

## GPU

GPU 提供了额外的强大算力。图形处理单元 (GPU) 是一种专用芯片，旨在快速处理内存中的数据以创建图像；它最初用于处理电影和渲染视频游戏中的图像。GPU 不单独工作，它是一个协助 CPU 完成某些任务的协处理器。
