# 第 14 章：BigQuery ML

BigQuery 是 Google Cloud 的旗舰数据仓库产品。它是一项全托管的无服务器服务，可处理 PB 级数据。BigQuery 于 2011 年 11 月发布（正式上线）。10 多年来，这项广受欢迎的服务在用户群和功能数量上都有了显著增长。

你可能已经注意到，在前面的许多章节中都提到了 BigQuery ML。虽然当前的考试指南（截至本书撰写时）没有单独的章节介绍它，但这是 ML 认证最重要的主题之一。

在 BigQuery 中，数据是使用 SQL 进行分析的，包括创建和训练模型。我们将通过一个示例解释 BigQuery 的用法。假设我们有一个包含信用卡客户数据的数据集，目标是判断客户是否拖欠了信用卡付款。

BigQuery ML 彻底改变了行业，因为它对现状进行了根本性的变革。传统上，机器学习只对编写代码（如 Python）的专家机器学习工程师开放。BigQuery ML 使得熟悉 SQL 的数据分析师也能利用 ML 工具。

在很大程度上，BigQuery ML 实现了机器学习的普及，让更多人能够使用它。这导致机器学习的使用发生了快速变化，特别是针对结构化数据。
