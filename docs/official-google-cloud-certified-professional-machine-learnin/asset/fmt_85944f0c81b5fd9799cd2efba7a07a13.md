
# 箱线图

箱线图有助于将观测值划分为称为**四分位数**的定义区间，并将其与整体观测值进行比较。它将数据表示为第 25、50 和 75 个四分位数。它由主体（即四分位距，IQR）组成，大多数观测值集中于此。须线或直线代表最大值和最小值。位于须线之外的点将被视为**异常值**。

# 统计学基础

在统计学中，我们有三种集中趋势度量：平均数、中位数和众数。它们帮助我们描述数据，并可用于从统计学角度清洗数据。

## 平均数

当数据中不存在任何异常值时，平均数是描述数据的准确度量。

## 中位数

如果数据集中存在异常值，则使用中位数。您可以通过将数据值从低到高排列来找到中位数。

如果数据个数为偶数，中位数是中间两个数的平均值；如果为奇数，中位数是中间的值。例如，在数据集 1, 1, 2, 4, 6, 6, 9 中，中位数是 4。对于数据集 1, 1, 4, 6, 6, 9，中位数是 5。取 4 和 6 的平均值，即 `(4+6) / 2 = 5`。

## 众数

如果存在异常值且大部分数据相同，则使用众数。众数是数据集中出现频率最高的值或值。

例如，对于数据集 1, 1, 2, 5, 5, 5, 9，众数是 5。

## 异常值检测

平均数是受异常值影响的集中趋势度量，进而影响标准差。

例如，考虑以下小型数据集：

*   `[15, 18, 7, 13, 16, 11, 21, 5, 15, 10, 9, 210]`

肉眼可见，210 是一个远大于其他值的异常值。

正如[表 2.1](#c02.xhtml#c02-tbl-0001)所示，与中位数和众数相比，添加异常值导致平均数发生了显著变化。**方差**是数据与平均数的平方差的平均值。

[**表 2.1**](#c02.xhtml#R_c02-tbl-0001) 用于异常值检测的平均数、中位数和众数

| 含异常值 | 不含异常值 |
| --- | --- |
| 平均数: 12.72 | 平均数: 29.16 |
| 中位数: 13 | 中位数: 14 |
| 众数: 15 | 众数: 15 |

## 标准差

标准差是方差的平方根。标准差是识别异常值的绝佳方法。距离平均数超过一个标准差的数据点可被视为异常。

## 相关性

相关性仅仅是协方差的标准化形式。相关系数的值范围从 -1 到 +1。相关系数也称为皮尔逊相关系数。

*   **正相关** 当一个变量的值增加时，另一个变量的值相应增加，这称为**正相关**。
*   **负相关** 当一个变量的值增加时，另一个变量的值相应减少，这称为**负相关**。
*   **零相关** 当一个变量的值变化对另一个变量没有实质性影响时，称为**零相关**。

# 数据质量与可靠性

模型的质量取决于数据的质量和可靠性（或可行性）。模型质量还取决于训练数据的规模。

**可靠性**是您能信任数据的程度。如果数据不可靠，意味着它包含缺失值、重复值和不良特征；您可以将其视为脏数据。如果在脏数据上训练模型，不太可能获得有用的预测。为确保数据可靠，您可以执行以下操作：

*   检查标签错误，因为有时由人工标注，难免出错。
*   检查特征中的噪声，例如 GPS 测量值。
*   检查异常值和数据倾斜。

在收集数据时，拥有具体的质量定义非常重要。我们将在以下章节讨论数据质量的几个参数。

## 数据倾斜

**数据倾斜**是指当正态分布曲线不对称时，数据呈现倾斜。这意味着数据中存在异常值或数据分布不均匀。

正态分布的偏度为 0。

数据可以是右偏或左偏（参见[图 2.4](#c02.xhtml#c02-fig-0004)）。您可以通过了解数据集的统计度量（如平均数、中位数和标准差）来分析偏度。

![图 2.4 数据倾斜](images/c02f004.png)

[**图 2.4**](#c02.xhtml#R_c02-fig-0004) 数据倾斜

对于右偏数据，现实中的例子可以是收入数据，因为大多数人的收入平均，只有 0.01% 的人收入高于其余人口（如杰夫·贝佐斯等亿万富翁），导致出现异常值或右偏。

倾斜数据不利于模型工作，因为极端异常值会影响模型的预测能力。通过对数变换和归一化等多种变换，您可以通过去除异常值将倾斜分布转换为正态分布。如果目标变量存在偏度，可以使用合成少数类过采样技术（SMOTE）、欠采样或过采样。

## 数据清洗

归一化的目标是将特征转换为相似的尺度。这能提高模型的性能和训练稳定性。（参见 `https://developers.google.com/machine-learning/data-prep/transform/normalization`。）

## 缩放

缩放是指将浮点特征值从其自然范围转换为标准范围——例如，从 1,000–5,000 转换为 0 到 1 或 -1 到 +1。当特征集包含多个特征时，缩放非常有用。它具有以下优势：

*   在深度神经网络训练中，缩放后的特征比未缩放的特征能使梯度下降收敛得更好。
*   缩放消除了“NaN 陷阱”的可能性，因为每个数值都被缩放到一个数值范围内。
*   如果不缩放，模型会过分重视数值范围较宽的特征。

## 对数缩放

当部分数据样本符合幂律分布或数值极大时，使用对数缩放。例如，当部分样本为 10,000 而另一些在 0–100 范围内时，您会使用对数缩放。

取对数会将它们带到同一范围。例如，`log(100,000) = 100` 而 `log(100) = 10`。因此，您的数据将通过对数缩放调整到 0 到 100 的范围。

## Z-Score

这是另一种缩放方法，其中的值计算为距离平均数的标准差倍数。当您有少量异常值时，按如下方式计算 Z-Score：

*   `Scaled value = (value − mean) / stddev`

例如，给定

*   `Mean = 100`
*   `Standard deviation = 20`
*   `Original value = 130`

缩放后的值为 1.5。Z-Score 位于 -3 到 +3 之间，因此超出该范围的任何值都将是异常值。
