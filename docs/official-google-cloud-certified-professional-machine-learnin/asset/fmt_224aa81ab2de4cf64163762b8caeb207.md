## 9. AutoML Tables 预测结果导出至 BigQuery 进行公平性测试

## 11. 在 Vertex AI Pipeline 中复用 BigQuery ML 模型

你是一名数据科学家，你的团队大量使用 Vertex AI AutoML Tables 和 Pipelines。另一个分析师团队在 BigQuery ML 上构建了一些高度准确的模型。你也想将这些模型作为 Pipeline 的一部分使用。你的解决方案是什么？

1. 在 BigQuery 中运行预测，并将预测数据从 BigQuery 导出到 GCS，然后加载到你的 Pipeline 中。
2. 使用相同的数据和超参数在 Vertex AI Tables 上重新训练模型。
3. **将模型加载到 Vertex AI Model Registry 中，并在 Vertex AI 中运行批量预测。**
4. 下载模型并为 Vertex AI 自定义模型创建容器，然后运行批量预测。

## 12. 处理高基数分类特征

你是一名数据分析师，正在处理结构化数据。你正在探索不同的机器学习选项，包括 Vertex AI 和 BigQuery ML。你发现模型准确率受到一个分类特征（zipcode）的影响，该特征具有高基数。你不确定该特征是否导致了该问题。如何解决？

1. **在 BigQuery 中使用哈希函数 `(ABS(MOD(FARM_FINGERPRINT(zipcode),buckets))` 进行分桶。**
2. 移除输入特征并在没有它的情况下训练。
3. 不要更改输入，因为它会影响准确率。
4. Vertex AI Tables 会自动处理这个问题。
