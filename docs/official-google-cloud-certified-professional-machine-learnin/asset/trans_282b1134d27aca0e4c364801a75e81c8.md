

# 考试大纲

## 了解如何将各种文件类型引入训练
理解各种文件类型，例如结构化（如 `CSV`）、非结构化（如文本文件）和半结构化（如 `JSON` 文件）。了解这些文件类型如何在 GCP 中存储并引入 AI/ML 工作负载。理解文件如何通过 Google Cloud 数据分析平台引入 Google Cloud，经历收集、处理、存储和分析等阶段。对于收集数据到 Cloud Storage，可以使用 `Pub/Sub` 和 `Pub/Sub Lite` 收集实时数据，以及使用 `BigQuery Data Transfer Service` 和 `Datastream` 将数据从第三方来源和数据库迁移到 Google Cloud。在处理阶段，理解如何使用 `Cloud Dataflow`、`Cloud Data Fusion`、`Cloud Dataproc`、`Cloud Composer` 和 `Cloud Dataprep` 等服务转换数据或运行 Spark/Hadoop 作业进行 ETL。了解如何使用常见框架使用 `Vertex AI Workbench` 环境：理解托管笔记本和用户管理笔记本支持的功能差异和框架。理解何时应使用用户管理笔记本与托管笔记本。理解如何创建这些笔记本以及它们开箱即支持的功能。

## 了解如何使用常见框架使用 Vertex AI Workbench 环境
理解托管笔记本和用户管理笔记本支持的功能差异和框架。理解何时应使用用户管理笔记本与托管笔记本。理解如何创建这些笔记本以及它们开箱即支持的功能。

## 了解如何在不同环境中将模型作为作业进行训练
理解 `Vertex AI` 训练选项，如 `AutoML` 和自定义训练。然后理解如何使用预构建容器或自定义容器通过 `Vertex AI` 训练以及架构执行自定义训练。理解使用训练管道与自定义作业在 `Vertex AI` 中设置训练的区别。`Vertex AI` 训练支持 `scikit-learn`、`TensorFlow`、`PyTorch` 和 `XGBoost` 等框架。此外，理解如何使用 `Vertex AI` 自定义作业设置分布式训练。

## 能够对模型训练和服务进行单元测试
理解为什么以及如何对机器学习的数据和模型进行单元测试。理解模型端点更新后如何测试 API 更新，以及如何测试算法正确性。

## 理解超参数调优
理解超参数调优及各种搜索算法，如网格搜索、随机搜索和贝叶斯搜索。理解何时使用哪种搜索算法以加快性能。了解如何使用自定义作业设置超参数调优。最后，还要理解 `Vertex AI Vizier` 以及它与设置超参数调优有何不同。

## 在训练期间跟踪指标
可以使用 `Interactive shell`、`Tensorflow Profiler` 和 `What-If tool` 在模型训练期间跟踪指标。

## 进行重新训练/重新部署评估
理解训练神经网络时的偏差-方差权衡。然后需要理解处理欠拟合的策略和处理过拟合的策略，如正则化。了解 `L1` 和 `L2` 正则化的区别以及何时应用哪种方法。

# 复习题

## 问题 1
你是一家金融公司的数据科学家，正在开发一个对客户支持邮件进行分类的模型。你在本地系统上使用小数据集和 `TensorFlow Estimators` 创建了模型，但现在需要使用大数据集训练模型以确保高性能。你将模型移植到 Google Cloud，并希望最大限度地减少代码重构和基础设施开销，以便更轻松地从本地迁移到云端。你应该怎么做？

1. 使用 `Vertex AI` 自定义作业进行训练。
2. 在 `Dataproc` 上创建集群进行训练。
3. 使用 `Vertex AI` 训练创建 `AutoML` 模型。
4. 创建具有自动扩缩功能的实例组。

## 问题 2
你是一名数据工程师，正在构建一个使用 `Dataflow` 在模型训练和预测前预处理原始数据的生产需求预测管道。在预处理期间，你对存储在 `BigQuery` 中的数据执行 Z-score 标准化并将其写回 `BigQuery`。由于每周都会添加新的训练数据，为了使流程更高效，最大限度地减少计算时间和人工干预，你应该怎么做？

1. 将标准化算法转换为 SQL 以便与 `BigQuery` 一起使用。
2. 使用 `Dataproc` 的 `BigQuery` 连接器，通过 `Apache Spark` 标准化数据。
3. 使用 `TensorFlow Data Transform` 标准化数据。
4. 通过在 `Google Kubernetes Engine` 集群中运行作业来标准化数据。

## 问题 3
你是一家时装服饰公司的 ML 工程师，正在设计一个定制的深度神经网络，使用 `Keras` 根据客户的购买历史预测其购买行为。你想要使用多种模型架构探索模型性能，存储训练数据，并在作业运行时比较评估指标。你应该怎么做？

1. 使用 `AutoML Tables` 创建多个模型。
2. 在 `Kubeflow Pipelines` 中创建实验以组织多次运行。
3. 在启用了 `Interactive shell` 的情况下，在 `Vertex AI` 平台上运行多个训练作业。
4. 在 `Vertex AI` 平台上使用超参数调优运行多个训练作业。

## 问题 4
你是一名数据科学家，已使用 `Vertex AI` 自定义作业创建了带有超参数调优作业的 ML 管道。你的一个调优作业耗时比预期长，延迟了下游流程。你希望在不显著降低其有效性的情况下加快调优作业。你应该采取哪些措施？（选择三项。）

1. 减少并行试验次数。
2. 将搜索算法从网格搜索更改为随机搜索。
3. 减少浮点值的范围。
4. 将算法更改为网格搜索。
5. 将早停参数设置为 `TRUE`。

## 问题 5
你是一名数据工程师，使用 `PySpark` 数据管道在 Google Cloud 上大规模进行数据转换。然而，你的管道运行时间超过 12 小时。为了缩短管道运行时间，你不想管理服务器，并且需要一个可以运行 SQL 的工具。你已经将原始数据移至 `Cloud Storage`。如何在 Google Cloud 上构建管道，同时满足速度和处理要求？

1. 使用 `Data Fusion` 的 GUI 构建转换管道，然后将数据写入 `BigQuery`。
2. 将 `PySpark` 命令转换为 `Spark SQL` 查询以转换数据，然后在 `Dataproc` 上运行管道，使用 `BigQuery Spark` 连接器将数据写入 `BigQuery`。
3. 将数据从 `Cloud Storage` 引入 `BigQuery`，将 `PySpark` 命令转换为 `BigQuery SQL` 查询以转换数据，然后将转换写入新表。
4. 将数据引入 `Cloud SQL`，将 `PySpark` 命令转换为 `Spark SQL` 查询以转换数据，然后使用来自 `BigQuery` 的 SQL 查询进行机器学习。

## 问题 6
你是一名首席数据科学家经理，管理一个使用基于云的系统提交训练作业的数据科学家团队。该系统变得非常难以管理。你合作的数据科学家使用许多不同的框架，如 `Keras`、`PyTorch`、`Scikit` 和自定义库。在 Google Cloud 中运行作业的最托管方式是什么？

1. 使用 `Vertex AI` 训练自定义容器，使用任意框架运行训练作业。
2. 使用 `Vertex AI` 训练预构建容器，使用任意框架运行训练作业。
3. 配置 `Kubeflow` 在 `Google Kubernetes Engine` 上运行并通过 `TFJob` 接收训练作业。
4. 在 `Compute Engine` 上使用 `GKE` 创建容器化镜像并将这些镜像推送到集中式存储库。
