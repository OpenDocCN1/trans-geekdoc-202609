

## 流水线组件

流水线组件是执行流水线工作流中某一部分的独立代码集合，例如数据预处理、数据转换和模型训练。

您可以构建自定义组件，也可以复用预构建组件。要在流水线中使用 Vertex AI 的功能（如 AutoML），请使用 Google Cloud 流水线组件。您可以在 `https://cloud.google.com/vertex-ai/docs/pipelines/build-pipeline#google-cloud-components` 了解更多关于在流水线中使用 Google Cloud 流水线组件的信息。

## Apache Airflow

Apache Airflow 是一个用于数据工程流水线的开源工作流管理平台。它于 2014 年 10 月在 Airbnb 诞生，旨在解决该公司日益复杂的工作流管理问题。

Airflow (`https://airflow.apache.org/docs/apache-airflow/stable/concepts/overview.html`) 是一个允许您构建和运行工作流的平台。工作流表示为有向无环图 (DAG)，并包含称为*任务* 的独立工作单元，这些任务经过依赖关系和数据流的考虑进行排列。它自带 UI、调度器和执行器。

## Cloud Composer

Cloud Composer 是一个基于 Apache Airflow 构建的全代管式工作流编排服务。

通过使用 Cloud Composer 而不是 Apache Airflow 的本地实例，您可以在无需安装或管理开销的情况下享受 Airflow 的所有优势。Cloud Composer 可帮助您快速创建 Airflow 环境并使用 Airflow 原生工具（如功能强大的 Airflow Web 界面和命令行工具），以便您专注于工作流而非基础设施。Cloud Composer 旨在编排数据驱动的工作流（特别是 ETL/ELT）。

Cloud Composer 最适合能够容忍任务执行之间几秒钟延迟的批处理工作负载。您可以使用 Cloud Composer 编排数据流水线中的服务，例如触发 BigQuery 中的作业或启动 Dataflow 流水线。

## 组件、参数、触发器和计算需求的识别

我们在**第 10 章**“生产环境中的模型扩展”中介绍了如何配置触发器和流水线计划，特别是关于调度训练作业方面。在本章的这一部分，我们将介绍如何触发 MLOps 流水线。您可以自动化 ML 生产流水线，以使用新数据重新训练模型。您可以按需、按计划、在新数据可用时、在模型性能下降时、在数据统计属性发生重大变化时或基于其他条件触发流水线。

新数据的可用性是重新训练 ML 模型的一个触发器：

*   要使用新数据训练新的 ML 模型，将执行先前部署的持续训练 (CT) 流水线。不会部署新的流水线或组件；仅在流水线结束时提供新的预测服务或新训练的模型。
*   要使用新实现训练新的 ML 模型，将通过 CI/CD 流水线部署新的流水线。

### 使用 Kubeflow Pipelines 调度工作流

让我们看看 Kubeflow Pipelines 的 CI/CD 是如何工作的。请参见**图 11.10**。

![FIGURE 11.10 CI/CD with Kubeflow Pipelines](images/c11f010.png)

**图 11.10** 使用 Kubeflow Pipelines 进行 CI/CD

Kubeflow Pipelines 提供了一个 Python SDK，用于使用 `kfp.Client` 以编程方式操作流水线。通过使用 Kubeflow Pipelines SDK (`www.kubeflow.org/docs/components/pipelines/v1/sdk/sdk-overview`)，您可以使用以下服务调用 Kubeflow Pipelines：

*   按计划调度，您可以使用 Cloud Scheduler。
*   响应事件，您可以使用 Pub/Sub 和 Cloud Functions。例如，事件可以是 Cloud Storage 存储桶中有新数据文件可用。
*   作为更大的数据和流程工作流的一部分，您可以使用 Cloud Composer 或 Cloud Data Fusion。
*   Kubeflow Pipelines 还提供了一个内置调度器 Argo，用于 Kubeflow Pipelines 中的定期流水线。
*   作为使用 Cloud Build 的替代方案，您可以使用其他构建系统，如 Jenkins。Google Cloud Marketplace 上提供了现成的 Jenkins 部署。
*   您可以使用 Apache Airflow（一种流行的编排和调度框架）用于通用工作流，您可以使用全代管式 Cloud Composer 服务运行它。有关如何使用 Cloud Composer 和 Cloud Build 编排数据流水线的更多信息，请参考 `https://cloud.google.com/architecture/cicd-pipeline-for-data-processing`。
