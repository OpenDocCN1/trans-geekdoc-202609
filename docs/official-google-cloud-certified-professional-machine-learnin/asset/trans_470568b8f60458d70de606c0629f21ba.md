

# 特征交叉

*特征交叉*，或称合成特征，是通过将两个或多个特征相乘（交叉）而创建的。它可以是将同一特征与自身相乘 [`A * A`]，也可以是将多个特征的值相乘，例如 [`A * B * C`]。在机器学习中，特征交叉通常在独热编码特征上执行——例如，`binned_latitude × binned_longitude`。（更多信息请参阅 `https://developers.google.com/machine-learning/crash-course/feature-crosses/video-lecture`。）

使用特征交叉主要有两种方式：

*   当单个特征本身的预测能力不如组合特征时，会使用特征交叉。例如，我们有一个模型需要预测在一天中的某个时刻，基于街道位置的人群拥挤程度。如果我们从这两个特征构建特征交叉，[`location (market, curbside) × time of the day`]，那么我们将获得比单独使用任一特征强得多的预测能力。例如，如果周二晚上有农贸市场，人群会更拥挤。如果周二晚上没有农贸市场，人群会较少。

*   在具有高度复杂模型的线性问题中，特征交叉用于通过将两个或多个特征相乘（交叉）来在线性模型中表示非线性。线性学习器可很好地扩展到海量数据。在海量数据集上使用特征交叉是学习高度复杂模型的一种高效策略。让我们看一个例子。如 [图 3.1](#c03.xhtml#c03-fig-0001) 所示，圆点代表患病者，矩形代表健康者。很难用直线或线性方法将它们分开。

# TensorFlow Transform

提高 TensorFlow 模型性能需要高效的输入流水线。首先我们将讨论 TF Data API，然后介绍 TensorFlow Transform。

## TensorFlow Data API (tf.data)

高效的数据输入流水线可以通过减少设备空闲时间，大幅提高模型执行速度。请考虑采纳 `here` 中详述的以下最佳实践，使您的数据输入流水线更加高效：

*   使用预取转换来重叠预处理和训练步骤的模型执行。此转换将数据生成的时间与数据消费的时间解耦。`tf.data` API 提供了 `tf.data.Dataset.prefetch` 转换。

*   `tf.data.Dataset.interleave` 转换可并行化数据读取。通过使用 interleave 转换，您可以减轻各种数据提取开销的影响。

*   使用缓存转换在第一个 epoch 期间将数据缓存在内存中。`tf.data.Dataset.cache` 转换可以缓存数据集，无论是在内存中还是在本地存储上。这将节省一些操作（如文件打开和数据读取）在每个 epoch 中重复执行。

*   在一批数据集上向量化用户定义函数。数据集被传递给 map 转换。

*   在应用 interleave、prefetch 和 shuffle 转换时减少内存使用量。

## TensorFlow Transform

TensorFlow Transform 库是 TensorFlow Extended (TFX) 的一部分，它允许您在训练模型之前执行转换，并生成一个 TensorFlow 图，该图在训练期间复现这些转换。使用 tf.Transform 可避免训练-服务偏差。在 Google Cloud 中，您可以使用 Cloud Dataflow 创建转换流水线。TF Transform 在训练和服务期间进行转换的一些步骤包括分析训练数据、转换训练数据、转换评估数据、生成元数据、馈送模型和服务数据，如 [图 3.4](#c03.xhtml#c03-fig-0004) 所示。

![图 3.4 TensorFlow Transform ¶ 来源：改编自 Google Cloud](images/c03f004.png)

[**图 3.4**](#c03.xhtml#R_c03-fig-0004) TensorFlow Transform ¶ 来源：`Adapted from Google Cloud`

您可以使用 Cloud Dataflow 和 BigQuery 运行上述流水线：

1.  从 BigQuery 读取训练数据。
2.  使用 tf.Transform Cloud Dataflow 分析和转换训练数据。
3.  将转换后的训练数据作为 TFRecords 写入 Cloud Storage。
4.  从 BigQuery 读取评估数据。
5.  在 Cloud Dataflow 中使用步骤 2 生成的 `transform_fn` 转换评估数据。
6.  将转换后的训练数据作为 TFRecords 写入 Cloud Storage。（注：原文此处为 "training data"，根据上下文应为评估数据，但此处严格翻译原文）
7.  将转换工件写入 Cloud Storage，用于创建和导出模型。

# GCP 数据和 ETL 工具

我们将在 [第 8 章](#c08.xhtml) "模型训练和超参数调优" 中详细介绍完整的数据分析生态系统，从数据收集到存储。以下是两个有助于在 Google Cloud 中进行数据转换和 ETL 的工具：

*   **Cloud Data Fusion** 是一个无代码、基于 Web UI 的托管服务，有助于从各种数据源构建和管理提取、转换、加载 (ETL) 或提取、加载、转换 (ELT) 流水线。Web UI 可帮助您在无需基础设施管理的情况下清理和准备数据。它还支持 Cloud Dataproc，后者是另一项在 Google Cloud 上运行和管理 Hadoop 与 Spark 工作负载的服务。使用 Dataproc 作为执行环境，Cloud Data Fusion 允许您运行 MapReduce 和 Spark 流式处理流水线。请参考此链接了解更多信息：`https://cloud.google.com/data-fusion#section-9`。
