## 移除敏感数据的最佳实践

根据数据集的结构，移除敏感数据需要不同的方法，如[表 6.2](#c06.xhtml#c06-tbl-0002)所示。

**表 6.2** 处理敏感数据的策略

| 数据类型 | 使用的策略 |
| --- | --- |
| 数据仅限于结构化数据集中的特定列。 | 您可以创建一个不提供对相关列访问权限的视图。数据工程师无法查看数据，但同时数据是实时的，且不需要人工干预即可对其进行去标识化以用于持续训练。 |
| 敏感数据是非结构化内容的一部分，但可以使用已知模式或正则表达式识别。 | 您可以使用 Cloud DLP 来处理此类数据。 |
| 敏感数据存在于图像、视频、音频或非结构化自由格式数据中。 | 使用 NLP API、Cloud Speech API、Vision AI 和 Video Intelligence API 即开即用地识别电子邮件和位置等敏感数据，然后对其进行遮盖或移除。 |

有关更多详情，请参阅 `https://cloud.google.com/architecture/sensitive-data-and-ml-datasets`。

保护多列数据的方法之一是使用 ML 算法（如主成分分析 (PCA)）或其他降维技术来组合多个特征，然后仅对生成的 PCA 向量进行 ML 训练，详见 `https://medium.com/lizuna/beacon-the-use-of-principal-components-analysis-to-mask-sensitive-data-in-machine-learning-7904b01445d0`。例如，给定年龄、吸烟者（用 1 或 0 表示）和体重这三个不同字段，数据可能会被浓缩为单个 PCA 列，并使用以下公式：

*   `1.5age + 30smoker + 0.2 * body‐weight`

一位 20 岁、吸烟、体重 140 磅的人会生成 88 这个值。一位 30 岁、不吸烟、体重 215 磅的人生成的值也是 88。

这种方法非常稳健，因为即使识别出在某些方面独一无二的个体，如果没有 PCA 向量公式的解释，也很难确定是什么使他们独一无二。

粗化是另一种用于降低数据粒度的技术，旨在使数据集中的敏感数据更难被识别，同时仍能提供与使用粗化前数据训练的模型相比可媲美的效果。[表 6.3](#c06.xhtml#c06-tbl-0003) 中的字段特别适合这种方法。

**表 6.3** 处理数据中敏感字段的技术

| 字段 | 说明 |
| --- | --- |
| IP 地址 | 将 IPv4 地址的最后一个八位字节归零（如果使用 IPv6，则为最后 80 位）。 |
| 数值 | 数字可以分箱，使其不太可能识别出个人；例如，年龄和生日可以转换为范围。 |
| 邮政编码 | 可以粗化为仅包含前三位数字。 |
| 位置 | 使用城市、州或邮政编码等位置标识符，或使用较大范围来混淆某一行的独特特征。 |

## 摘要

在本章中，我们讨论了在 Google Cloud 中用于管理机器学习数据的一些安全最佳实践，例如静态加密和传输中加密。

我们还简要介绍了 IAM 以及如何使用 IAM 为您的数据科学团队提供和管理对 Vertex AI Workbench 的访问权限。我们介绍了一些安全 ML 开发技术，例如联邦学习和差分隐私。

最后，我们介绍了如何使用 Cloud DLP 和 Cloud Healthcare API 管理 PII 和 PHI 数据。我们还介绍了一种架构模式，说明如何大规模扩展 PII 识别和去标识化。

## 考试要点

*   **构建安全的 ML 系统。** 了解 Google Cloud 的静态加密和传输中加密。知道静态加密和传输中加密如何用于在 Cloud Storage 和 BigQuery 中存储机器学习数据。知道如何设置 IAM 角色来管理 Vertex AI Workbench，以及如何为 Vertex AI Workbench 设置网络安全。最后，了解差分隐私、联邦学习和令牌化等概念。

*   **理解数据使用和收集的隐私影响。** 了解 Google Cloud Data Loss Prevention (DLP) API 以及它如何帮助识别和遮盖 PII 类型的数据。此外，了解 Google Cloud Healthcare API 以识别和遮盖 PHI 类型的数据。最后，了解移除敏感数据的一些最佳实践。

## 复习题

1.  您是一家银行的 ML 安全专家，该银行拥有一个移动应用程序。您被要求为该应用构建一个基于 ML 的指纹身份验证系统，根据客户的指纹验证其身份。指纹无法下载到银行数据库中并存储。您应该推荐哪种学习策略来训练和部署此 ML 模型，并确保指纹的安全和受保护？

    1.  差分隐私
    2.  联邦学习
    3.  令牌化
    4.  Data Loss Prevention API

2.  您在一个不断壮大的团队中工作，该团队有 50 多名数据科学家，他们都使用 Vertex AI Workbench。您正在设计一种策略，以整洁且可扩展的方式组织作业、模型和版本。哪种策略管理程度最高且工作量最小？

    1.  在 Vertex AI 平台笔记本上设置限制性 IAM 权限，以便只有单个用户或组可以访问给定实例。
    2.  将每位数据科学家的工作分离到不同的项目中，以确保每位数据科学家创建的作业、模型和版本仅对该用户可访问。
    3.  使用标签将资源组织到描述性类别中。对每个创建的资源应用标签，以便用户在查看或监控资源时可以按标签筛选结果。
    4.  为 Cloud Logging 日志设置 BigQuery 接收器，并适当过滤以捕获有关 AI Platform 资源使用情况的信息。在 BigQuery 中，创建一个将用户映射到其正在使用的资源的 SQL 视图。

3.  您是一家金融科技公司的 ML 工程师，正在从事一个创建文档分类模型的项目。您有一个包含大量 PII 的大数据集，无法分发或披露。您被要求用特定的替代字符替换敏感数据。以下哪种技术最适合使用？

    1.  格式保留加密或令牌化
    2.  K-匿名性
    3.  替换
    4.  遮盖
