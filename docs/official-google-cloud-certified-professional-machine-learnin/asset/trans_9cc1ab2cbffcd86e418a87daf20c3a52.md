

# 将业务用例转化为机器学习问题

## 简介

例如，通用翻译器是一种设备，能够近乎实时地将文本或语音从一种语言翻译成另一种语言；这曾是旧科幻电影中的常见主题，如今已成为现实。另一个用例是通过展示图像而非使用关键词来搜索图像中的物体，称为“以图搜图”。您可能使用过邮件的“智能回复”功能，这在 Android 手机上为您节省了输入邮件回复的时间和精力。虽然该用例可能仅节省几分钟时间，但像 `AlphaFold` AI 系统这样的创新却能节省数年时间，它通过从氨基酸序列预测蛋白质的 3D 结构来加速研究，而无需依赖物理实验室手段。

全球各地的企业已开始拥抱 AI 和机器学习。这些企业并非“罕见的创新者”，而是涵盖所有领域，跨越农业、医疗、交通、零售和制造等众多行业。可以肯定地说，任何领域都能通过识别合适的用例从机器学习中受益。

您到处都能看到用例，创新的动机可能多种多样。一些行业可能试图解决关键问题，如理解冠状病毒的蛋白质结构；其他行业可能在寻找提高效率的方法。有时机器学习能解决以前无法解决的问题，而在其他情况下，它可能只是为现有状况提供渐进式的改进。有时这些创新具有竞争性，一家企业因创新而迅速增长，给其他所有企业带来压力；而在其他情况下，所有企业可能都在试图共同解决一个问题。了解一个行业的历史有助于您理解之前解决问题的努力和探索新方法的尝试。

所有创新最初都作为简单的用例出现，随后被转化为机器问题，再由机器学习工程师加以解决。识别这些用例并评估机器学习影响的能力，是您迈向认证旅程的第一步。

## 将业务用例转化为机器学习问题

本章的目标是帮助您首先识别用例的影响、成功标准和可用数据。然后，将其与机器学习方法（一种算法和一种指标）相匹配，如[图 1.1](#c01.xhtml#c01-fig-0001)所示。我们将探讨如何将 ML 项目纳入预算和时间线。

现在，假设您被指派使用 ML 来解决一个问题。您首先需要识别用例并将其拟合为一个机器学习问题。

例如，假设您试图预测房价，可以使用回归模型。模型的性能要求将由业务决定。

假设您已与关键人员讨论并理解了用例；现在您需要识别关键 `stakeholders`（利益相关者），即与用例相关的人员。利益相关者可以是高管、首席财务官、数据工程师、可能需要批准项目继续进行的技术支持人员。这些利益相关者中的每一位对该 ML 项目可能有截然不同的期望，您传达价值的能力可能会决定项目是获批还是被拒。高管关注业务影响，首席财务官通常关心解决方案的预算，经理可能看重时间线，而数据管理者可能关注数据隐私和安全。如果您能理解这五个方面，您的审批之路将一帆风顺。

利益相关者将帮助您衡量该用例对贵公司和最终用户的`impact`（影响）。影响可以是增加利润、减少欺诈、提高生活质量，甚至挽救生命。影响很可能是用例中最重要的要素。

例如，假设贵公司拥有一个学习管理系统（LMS），一个学生订阅课程的平台。您拥有学生的活动数据，并希望利用机器学习改善体验。您可以做以下几件事：

*   创建推荐引擎，为学生推荐新课程。
*   流失预测，判断学生是否会退课。
*   流失预测，判断教师是否不会回归。
*   识别什么让课程对学生更有吸引力（样题、更多图片、更多表格、短视频等）。
*   识别学生偏好的学习类型（听觉型、视觉型或动觉型）。

哪个影响最大，这个问题只能由业务所有者来回答。

一旦您确定了对业务影响最大的用例，就需要确定机器学习解决方案的结果。简而言之，如果您实施了您的解决方案，会发生什么？有时，您的模型会做出准确的预测，但环境可能会以适得其反的方式对这些预测做出反应。这是因为环境很少是静态的；用户可能会适应，或者可能会对预测的行为感到困惑。

例如，假设贵公司拥有一个视频分享网站，拥有数百万视频。您正试图构建一个 ML 模型向用户推荐视频。您可以从以下方案中选择：

*   一个推荐热门创作者未看视频的 ML 模型。问题在于这不够个性化。如果用户不喜欢其中一些创作者怎么办？
*   一个推荐点击量大的视频的 ML 模型。但如果这些只是标题党，人们点击后后悔浪费时间怎么办？
*   一个推荐相似用户看完的视频的 ML 模型。这将改善用户体验。

在该示例中，您需要对用例、总体目标和最终用户有良好的理解，才能找到合适的切入点。

接下来，弄清楚该问题是否甚至可以用机器学习来解决。业务领导者在媒体上听到企业用 ML 解决问题的鼓舞人心的故事，听起来很神奇，他们也想用它来解决自己的业务问题。他们需要像您这样的专家来判断用 ML 解决他们的问题甚至是否可行。这听起来不像那么容易；这取决于多个因素，如现有技术、可用数据和预算。例如，自然语言处理已取得长足进步，使得几年前不可能的事情成为可能，例如使用 ML 根据一段文本回答问题。熟悉自然语言处理的最新进展将帮助您识别更简单、更快、更好的 ML 方法来解决业务问题。

作为下一步，您将需要识别适合您用例的 ML 学习方法。

## 机器学习方法

许多机器学习问题已得到充分研究并拥有优雅的解决方案，但有些算法并不完美，有些问题可以用多种方式解决。有时，用例将完美契合 ML 框架，有时则不然。您需要了解 ML 问题的全貌。机器学习方法有多种途径。其中一些方法已被研究数十年，而另一些则相对较新。应用机器学习技术的方法有成百上千种。为了帮助我们掌握这些方法的广度，我们将它们组织成几个类别（也称为方法、类型、途径或问题）。每种方法解决一类特定的问题，由数据类型、预测类型等区分。
