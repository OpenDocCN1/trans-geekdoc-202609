
# 处理分类数据异常值

对于分类数据包含异常值的情况，你可以为所有异常值创建一个名为 `out of vocabulary` 的单一类别，而不是给它们唯一的表示，因为它们在数据集中出现的频率非常低。当你使用这种方法时，ML 系统就不会浪费时间在每个罕见异常值上进行训练。

## 特征哈希

哈希通过将 `hash function`（哈希函数）应用于分类特征，并直接使用其哈希值作为索引，而不是查找词汇表。哈希经常导致冲突，这就是为什么对于重要术语，哈希可能比选择词汇表效果更差。哈希的优势在于，当特征分布随时间发生剧烈变化时，它不需要你组装词汇表。

## 哈希与词汇表的混合方法

在这种方法中，你可以对数据中最重要的类别使用词汇表，并用哈希类别替换超出词汇表范围的类别。这种方法的优势在于，每个超出词汇表的类别都用哈希表示，模型仍然能学习词汇表之外的类别。

## 嵌入

嵌入是将分类特征表示为连续值特征。深度学习模型经常将索引从索引转换为嵌入。嵌入主要用于文本分类或文档分类，此时你拥有词袋或词语文档。

# 特征选择

**特征选择** 是指选择特征子集或减少输入变量的数量，保留对模型预测目标变量最有用的特征。

**降维** 是减少特征数量最流行的技术之一。其优势在于减少数据中的噪声和过拟合问题。数据维度降低意味着训练时间和计算资源减少，并提高机器学习算法的整体性能。这可以通过两种方式实现：

*   **仅保留最重要的特征**：使用的技术包括向后选择和随机森林。
*   **寻找新特征的组合**：使用的技术包括主成分分析（PCA）和 t 分布随机邻域嵌入（t-SNE）。

# 类别不平衡

我们在[第 2 章](#c02.xhtml)中介绍了数据类别不平衡，在本节中，我们将讨论特定于分类模型的类别不平衡。

分类模型依赖于我们在[第 1 章](#c01.xhtml)“构建 ML 问题”中介绍的一些关键结果：

*   **真阳性** 是指模型正确预测正类的结果；例如，接受检测的患者确实感染了病毒。
*   **真阴性** 是指模型正确预测负类的结果，即接受检测的患者结果为阴性，且他们实际上并未患病。
*   **假阳性** 是指模型错误预测正类的结果，意味着患者实际上未患病，但检测预测他们患病。
*   **假阴性** 是指模型错误预测负类的结果，意味着患者患病，但检测判定他们未患病。

在这种情况下，假阴性是个问题，因为你不希望生病的患者被识别为未生病。因此，你需要致力于在分类模型中最小化假阴性结果。

## 带有精确率和召回率的分类阈值

为了将逻辑回归值映射到二元类别，你需要定义一个 **分类阈值**（也称为 **决策阈值**）。这是一个由人类选择的值，而非模型训练选择的值，通常在大多数情况下，该阈值假定为 0.5。逻辑回归模型输出 0 到 1 之间的值。假设人类设定的分类阈值为 0.6，模型预测值为 0.7，则模型预测为正类。分类阈值的选择强烈影响假阳性和假阴性的数量。分类阈值大多取决于具体问题，必须进行微调。精确率-召回率曲线表明模型预测正类的效果如何。精确率是指真阳性数量除以正预测总数，而召回率也称为真阳性率（TPR）。召回率是指机器学习模型正确识别为感兴趣类别（即“正类”）的数据样本百分比，占该类别总样本数的比例。

精确率和召回率对于评估模型都很重要。然而，如果你提高精确率，会降低召回率，反之亦然。

如果你想最小化假阳性，则提高分类阈值。对于这些问题，精确率对你非常重要。例如，你宁愿模型将垃圾邮件分类为非垃圾邮件，也不愿将非垃圾邮件分类为垃圾邮件。当你更关注正类而非负类时，应使用精确率。

如果你想最小化假阴性，则降低分类阈值。对于这些问题，召回率对你非常重要。换句话说，你倾向于让模型将未患病患者分类为患病，但如果将患病患者识别为未患病则会是个问题。在这类场景中，如果你更关注负类而非正类，应使用召回率。

召回率回答的问题是：在所有可能的正样本中，模型正确识别了多少？

## 曲线下面积 (AUC)

在本节中，我们将介绍分类问题中两种类型的曲线下面积。

*   **AUC ROC**：用于分类问题中的平衡数据集，即我们试图预测的两个类别拥有相同数量的样本。
*   **AUC PR**：用于分类问题中的不平衡数据集，例如信用卡交易中的欺诈识别。假设你有 10,000 笔信用卡交易，欺诈数据可能是每 1,000 笔交易中只有 1 笔。

### AUC ROC

ROC 曲线（受试者工作特征曲线）是一张展示分类模型在所有分类阈值下性能的图表。该曲线绘制两个参数：真阳性率和假阳性率。你可以参考此链接查看图表外观：

`https://developers.google.com/machine-learning/crash-course/classification/roc-and-auc`

AUC ROC（ROC 曲线下面积）测量整个 ROC 曲线下方的二维面积。它指的是一个 0.0 到 1.0 之间的数字，代表二元分类模型将正类与负类分开的能力。

AUC 越接近 1.0，模型区分类别的能力越强。当类别平衡，或当你希望赋予正负类预测能力同等权重时，使用 AUC ROC 曲线。

### AUC PR

PR 曲线是一张以精确率值为 y 轴、召回率值为 x 轴的图表。PR 曲线关注少数类，使其成为不平衡二元分类模型的有效诊断工具。

精确率-召回率曲线下面积（AUC PR）测量 PR 曲线下方的二维面积。在类别不平衡的情况下，对于高度偏斜的领域，推荐使用精确率-召回率曲线（PR 曲线）。AUC PR 更关注少数类。它可以结合我们在[第 2 章](#c02.xhtml)中介绍的欠采样或过采样一起使用。
