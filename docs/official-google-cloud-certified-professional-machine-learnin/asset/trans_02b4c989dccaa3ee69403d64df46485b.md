

| BigQuery 连接器 | | 您可以使用 BigQuery 连接器启用对 BigQuery 的编程读/写访问。由于未公开命令行访问，这是处理存储在 BigQuery 中的数据的理想方式。BigQuery 连接器是一个库，可让 Spark 和 Hadoop 应用处理来自 BigQuery 的数据并将数据写入 BigQuery。BigQuery Spark 连接器用于 Spark，BigQuery Hadoop 连接器用于 Hadoop。 |

| BigQuery Spark 连接器 | | 适用于 Google BigQuery 的 Apache Spark SQL 连接器。该连接器支持将 Google BigQuery 表读取到 Spark 的 DataFrames 中，并将 DataFrames 写回 BigQuery。这是通过使用 Spark SQL Data Source API 与 BigQuery 通信来完成的。 |

## Cloud Composer

创建、运行和管理工作流的方式有多种，例如运行 Cron 任务、使用 Cron 作业、编写脚本和创建自定义应用。每种方法都有利弊。更重要的是，上述所有方法都存在管理开销。这就是我们推出 Cloud Composer 的原因，它是一项全代管式数据工作流编排服务，允许您编写、调度和监控流水线。Cloud Composer 基于 Apache Airflow 构建，流水线使用 Python 配置为有向无环图 (DAG)。

它支持混合云和多云架构，无论工作流流水线位于本地、多个云中，还是完全在 Google Cloud 内部，均可对其进行管理。

Cloud Composer 提供与 Google Cloud 产品的端到端集成，包括 BigQuery、Dataflow、Dataproc、Datastore、Cloud Storage、Pub/Sub 和 Vertex AI Platform，让用户能够完全自由地编排其流水线。

## 使用常见框架在 Vertex AI Workbench 中开发模型

在本节中，我们将介绍如何创建 Jupyter Notebook 环境，以使用 Vertex AI Workbench 训练、调优和部署模型。

Vertex AI Workbench 是一个基于 Jupyter Notebook 的开发环境，面向整个数据科学工作流。您可以从 Vertex AI Workbench 实例的 Jupyter Notebook 内部与 Vertex AI 和其他 Google Cloud 服务进行交互。我们在[第 6 章](#c06.xhtml)“构建安全的 ML 流水线”中介绍了 Vertex AI Workbench，当时我们介绍了创建实例的安全性方面以及两种笔记本类型：

*   **用户管理的笔记本** Vertex AI 平台中最早版本的 Jupyter Notebook（以前称为 AI Platform）。与托管笔记本相比，它们提供更多控制权但功能较少。请参阅[表 8.3](#c08.xhtml#c08a-tbl-0001) 了解功能差异。

*   **托管笔记本** 最新推出的产品。这些笔记本具有自动关机、与数据存储集成以及按计划执行笔记本等功能。

[**表 8.3**](#c08.xhtml#R_c08a-tbl-0001) 托管笔记本与用户管理的笔记本的区别

| 托管笔记本 | | 用户管理的笔记本 |
| --- | --- | --- |
| **闲置实例自动关机：** 选择托管笔记本将在 Jupyter Notebook 闲置时将其关闭。此功能有助于节省成本，因为实例会在闲置时自动关闭。 | | **闲置实例自动关机：** 默认不支持此功能。不过，您可以使用 Cloud Monitoring 和 Cloud Functions 创建监控器来查看实例何时闲置，并在不使用时将其关闭。 |
| **界面与 Cloud Storage 和 BigQuery 集成：** 在托管笔记本实例的 JupyterLab 导航菜单中，您可以使用 Cloud Storage 和 BigQuery 集成来浏览您有权访问的数据和其他文件，并将数据加载到笔记本中。 | | **界面与 Cloud Storage 和 BigQuery 集成：** 没有界面集成。不过，您可以使用 BigQuery 连接器通过代码连接到 BigQuery 数据，也可以使用 BigQuery 魔术命令 (`%%`) 在 Jupyter Notebook 上运行 BigQuery SQL 命令。对于 Cloud Storage，您可以在用户管理的笔记本中使用 `gsutil` 命令读写数据。 |
| **笔记本自动运行：** 您可以设置笔记本按定期计划运行。即使您的实例已关闭，Vertex AI Workbench 也会运行您的笔记本文件并保存结果，供您查看和与他人共享。 | | **笔记本自动运行：** 不支持此功能。您可以使用 Cloud Scheduler 来调度训练作业或笔记本。 |
| **自定义容器：** 您可以向托管笔记本 Jupyter 实例添加自己的自定义容器镜像。 | | **自定义容器：** 您可以选择添加自定义容器。 |
| **Dataproc 或 Serverless Spark 集成：** 您可以通过在 Dataproc 集群或 Serverless Spark 上运行笔记本来快速处理数据。此功能目前处于私有预览阶段。设置好集群后，您无需离开 JupyterLab 界面即可在其上运行笔记本文件。 | | **Dataproc 或 Serverless Spark 集成：** 不支持此功能。 |
| **框架：** 创建托管笔记本时，所有框架均已预装。创建托管笔记本后，您可以选择任何受支持的框架。 | | **框架：** 您只能从所有受支持的框架中选择创建一种框架。例如，用户管理的笔记本支持 TensorFlow、R 和 PyTorch，但在创建时，您只能为 JupyterLab 环境选择一种框架。 |
