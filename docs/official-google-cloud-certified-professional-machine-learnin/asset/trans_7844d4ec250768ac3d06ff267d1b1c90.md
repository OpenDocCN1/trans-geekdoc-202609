## 为什么超参数很重要

超参数的选择对神经网络架构的成功至关重要，因为超参数会严重影响所学习模型的行为。例如，如果学习率设置得太低，模型将错过数据中的重要模式；但如果设置得太大，模型将过于容易地在偶然的巧合中发现模式。寻找良好的超参数涉及解决两个问题：

*   **如何高效地搜索可能的超参数空间：** 有一些算法可帮助进行超参数搜索空间优化。Vertex AI 默认算法应用贝叶斯优化以得出最优解。[表 8.5](#c08.xhtml#c08-tbl-0004) 总结了 Vertex AI 超参数调优支持的搜索算法。

*   **如何管理大量用于超参数调优的实验：** 如果没有像 Vertex AI 超参数调优这样的自动化技术，您将需要在许多训练运行过程中手动调整超参数，以得出最优值。超参数调优使确定最佳超参数设置的过程更轻松、不那么繁琐。超参数调优利用 Google Cloud 的计算基础设施，在训练模型时测试不同的超参数配置。它可以为您提供超参数的优化值，从而最大化模型的预测准确性。

## 加速超参数优化的技术

有几种技术可以加速超参数优化：

*   如果您有大型数据集，请使用简单的验证集代替交叉验证。与 k 折交叉验证相比，这将使速度提高约 k 倍。如果您没有足够的数据，这种方法效果不好。
*   通过使用带有超参数优化的分布式训练，将问题并行化到多台机器上。每台机器可以使用不同的超参数选择来拟合模型。对于 n 台机器，这将使速度提高约 n 倍。
*   通过预先计算或缓存可为后续模型拟合重用的计算结果，避免冗余计算。
*   如果使用网格搜索，请减少您愿意考虑的超参数值的数量。由于组合总数按乘法方式扩展，这可能会带来潜在的巨大加速。

## Vertex AI 超参数调优的工作原理

超参数调优通过运行您训练应用的多次试验来工作，在这些试验中使用您指定并在限制范围内设置的超参数值。超参数调优需要 Vertex AI 与训练应用之间的通信。训练应用定义模型所需的所有信息。您定义要调整的超参数（变量）以及用于评估每次试验的目标变量。超参数调优会优化您指定的目标变量，称为超参数指标。指标必须是数值型的。

配置超参数调优作业时，您需要定义每个指标的名称和目标。目标指定您是希望调整模型以最大化还是最小化该指标的值。

请按照以下步骤使用带有自定义作业的 `gcloud` CLI 命令配置超参数调优作业：

1.  对于自定义容器，请在 Dockerfile 中安装 `cloud-ml hypertune` Python 软件包。
2.  在 `trainer/task.py` 中，在主函数中添加超参数调优代码，并按如下所示添加参数。

    ```python
    def main():
        args = get_args()
        train_data, validation_data = create_dataset()
        model = create_model(args.num_units, args.learning_rate, args.momentum)
        history = model.fit(train_data, epochs=NUM_EPOCHS, validation_data=validation_data)

        # 定义指标
        hp_metric = history.history['val_accuracy'][-1]

        hpt = hypertune.HyperTune()
        hpt.report_hyperparameter_tuning_metric(
            hyperparameter_metric_tag='accuracy',
            metric_value=hp_metric,
            global_step=NUM_EPOCHS)
    ```

3.  构建并将此容器推送到 Artifact Registry。设置训练后，您可以使用训练流水线或自定义作业配置超参数调优作业。
