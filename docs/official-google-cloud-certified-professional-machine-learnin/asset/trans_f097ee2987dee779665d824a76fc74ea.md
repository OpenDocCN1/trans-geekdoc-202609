# 作者简介

**Mona Mona** 是 Google Public Sector 的 AI/ML 专家。她是《Natural Language Processing with AWS AI Services》一书的作者，也是一位演讲者。在加入 Google 之前，她曾担任 AWS 高级 AI/ML 专家解决方案架构师。她拥有 14 项认证，并为 AWS AI/ML 认证专业考试创建了备考课程。她撰写了 17 篇关于 AI/ML 的博客，并合著了一篇关于 AWS CORD‐19 Search 的研究论文：一款用于 COVID‐19 文献的神经搜索引擎，该论文在人工智能促进协会（AAAI）会议上获奖。可通过 `monasheetal3@gmail.com` 联系她。

**Pratap Ramamurthy** 善于利用机器学习解决问题。目前他是 Google Public Sector 的 AI/ML 专家。此前他在 AWS 担任合作伙伴解决方案架构师，帮助构建 Amazon SageMaker 的合作伙伴生态系统。后来他担任 H2O.ai 的首席解决方案架构师，该公司致力于结构化数据和自然语言的机器学习算法。在此之前，他是一名开发人员和研究员。他发表了多篇关于网络、服务器分析技术、遗传算法和光电子学的研究论文。他持有三项与云技术相关的专利。业余时间，他喜欢用现代桌游教学 AI。可通过 `pratap.ram@gmail.com` 联系他。
