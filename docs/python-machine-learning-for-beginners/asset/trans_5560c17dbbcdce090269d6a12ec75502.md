## PyViz 目标

PyViz 的一些重要目标包括：

*   重点应放在任何规模的数据上，而非编码
*   完整的功能和交互性应直接在浏览器中可用（而非桌面端）
*   重点应更多地关注 Python 用户，而非 Web 程序员。
*   同样应更多地关注 2D 可视化而非 3D。
*   利用 Python 用户已经熟悉的通用 SciPy/PyData 工具。

除此之外，PyViz 核心工具可以与 `HoloViews` 和 `Plotly` 等库无缝协作。
