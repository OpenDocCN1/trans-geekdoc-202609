
# 2018年人工智能回顾：从炒作降温到务实落地

## 概况

2017年大概是人工智能恐慌论与炒作的分水岭（正如我在[去年的回答](https://www.quora.com/What-are-the-most-significant-machine-learning-advances-in-2017/answer/Xavier-Amatriain)中提到的），而2018年似乎成为了我们开始冷静下来的一年。虽然有些知名人士继续推销AI恐慌论，但他们可能忙于其他议题，未将其作为议程重点。同时，媒体和大众似乎已接受这样一个观点：自动驾驶汽车等技术虽将到来，但不会一蹴而就。尽管如此，仍有声音主张[我们应该监管AI](https://www.theverge.com/2017/7/17/15980954/elon-musk-ai-regulation-existential-threat)，而非专注于监管其结果。

今年值得欣慰的是，关注点似乎已转向可解决的具体问题。例如，关于公平性的讨论很多，不仅有多个相关会议（参见[FATML](http://www.fatml.org/)或[ACM FAT](https://fatconference.org/)），甚至还有谷歌推出的[在线课程](https://www.blog.google/technology/ai/new-course-teach-people-about-fairness-machine-learning/amp/)。

## Generation Unlimited

沿着这条思路，今年被广泛讨论的其他问题还包括可解释性、解释方法和因果性。从因果性开始，因果性之所以重回聚光灯下，主要归功于Judea Pearl的《因果推断之书》出版。作者不仅决定撰写其首部“通俗易懂”的著作，还在Twitter上推广因果性讨论。大众媒体也将其报道为对现有AI方法的“挑战”（例如[The Atlantic的这篇文章](https://www.theatlantic.com/technology/archive/2018/05/machine-learning-is-stuck-on-asking-why/560675/?single_page=true)）。甚至ACM Recsys会议的最佳论文奖也颁给了探讨如何在嵌入中引入因果性的论文。尽管如此，许多其他作者认为因果性某种程度上是理论上的干扰，我们应重新聚焦于可解释性或解释方法等更具体的问题。说到解释方法，该领域的亮点之一可能是[Anchor](https://github.com/marcotcr/anchor)论文及代码的发布，这是同一作者知名的[LIME](https://homes.cs.washington.edu/~marcotcr/blog/lime/)模型的后续工作。

尽管关于深度学习作为最通用AI范式仍存疑问（我属于提出质疑的一方），而我们继续略过Yann LeCun与Gary Marcus关于此话题的第N轮讨论，但显然深度学习不仅将长期存在，且在其能提供的能力方面远未达到瓶颈。更具体地说，今年深度学习方法在视觉以外的领域取得了前所未有的成功，范围涵盖语言到医疗保健。

## NLP领域的突破

今年最有趣的进展可能出现在NLP领域。若我必须评选年度最令人印象深刻的AI应用，两者皆为NLP（且均来自谷歌）。第一个是[谷歌超实用的Smart Compose](https://ai.googleblog.com/2018/05/smart-compose-using-neural-networks-to.html?m=1)，第二个是他们的[Duplex](https://ai.googleblog.com/2018/05/duplex-ai-system-for-natural-conversation.html)对话系统。

今年语言模型思想的普及加速了许多此类进展。我们随之看到了其他（且改进的）方法，如Allen的[ELMO](https://arxiv.org/abs/1802.05365)、[OpenAI的Transformers](https://blog.openai.com/language-unsupervised/)，或最近谷歌的[BERT](https://github.com/google-research/bert)，后者一经发布即打破多项SOTA结果。这些模型被描述为NLP领域的“ImageNet时刻”，因为它们通过提供开箱即用的预训练通用模型（亦可针对特定任务微调），展示了迁移学习在语言领域的实用性。除了语言模型，还有许多其他有趣的进展，如[Facebook的多语言嵌入](https://code.fb.com/ml-applications/under-the-hood-multilingual-embeddings/)。有趣的是，我们也看到这些及其他方法如何迅速集成到更通用的NLP框架中，如[AllenNLP](https://github.com/allenai/allennlp/releases/tag/v0.7.2)或Zalando的[FLAIR](https://github.com/zalandoresearch/flair)。

## 框架之战与强化学习

说到框架，今年“AI框架之战”愈演愈烈。令人惊讶的是，就在[PyTorch 1.0发布](https://developers.facebook.com/blog/post/2018/05/02/announcing-pytorch-1.0-for-research-production/)之际，PyTorch似乎正在追赶TensorFlow。虽然在生产环境使用PyTorch的情况仍不理想，但PyTorch在该方面追赶的速度，似乎快于TensorFlow在易用性、文档和教育方面的追赶速度。有趣的是，[Fast.ai](http://fast.ai/)库选择PyTorch作为实现框架，这很可能发挥了重要作用。尽管如此，谷歌对此心知肚明，并通过将[Keras](https://www.tensorflow.org/guide/keras)作为一等公民纳入框架，以及引入[Paige Bailey](https://dynamicwebpaige.github.io/info/)等关键开发者导向领导者，朝正确方向推进。最终，我们都能从获取这些优秀资源中受益，请继续保持！

有趣的是，框架领域另一个取得有趣进展的方向是强化学习。

虽然我认为RL研究进展不如往年令人印象深刻（仅近期DeepMind的[Impala](https://arxiv.org/pdf/1802.01561.pdf)工作令人印象深刻），但令人惊讶的是，在短短一年内，所有主要AI参与者都发布了RL框架。谷歌发布了用于研究的[Dopamine框架](https://github.com/google/dopamine)，DeepMind（同样隶属谷歌）发布了某种程度上竞争的[TRFL](https://deepmind.com/blog/trfl/)框架。Facebook推出了[Horizon](https://research.fb.com/publications/horizon-facebooks-open-source-applied-reinforcement-learning-platform/)，微软发布了[TextWorld](https://www.microsoft.com/en-us/research/blog/textworld-a-learning-environment-for-training-reinforcement-learning-agents-inspired-by-text-based-games/?OCID=msr_blog_textworld_icml_tw)，后者更专注于基于文本游戏的训练智能体。希望这些开源成果能助力我们在2019年见证大量RL进展。

最后，在框架方面，我欣喜地看到谷歌最近在TensorFlow之上发布了[TFRank](https://ai.googleblog.com/2018/12/tf-ranking-scalable-tensorflow-library.html)。排序是极其重要的ML应用，近期可能未获得应有的关注。

## 结语

深度学习似乎消除了对数据精心设计的需求，但事实远非如此。
