```
    running_loss = 0.0

    for inputs, labels in trainloader:
        inputs, labels = inputs.to(device), labels.to(device)

        optimizer_ft.zero_grad()

print("Finished Fine-tuning")
```

### Model inferencing in transfer learning

In transfer learning, inferencing is the final stage where a pre-trained and fine-tuned model predicts outcomes on new data. This process is essential for evaluating the model’s real-world performance on previously unseen samples. The inferencing stage for transfer learning involves loading the test dataset, setting the model in evaluation mode (to disable training-specific operations like dropout), and running predictions. These predictions allow for comparison of the model's output against true labels to determine accuracy and effectiveness. In transfer learning, a model (e.g., ResNet) is pre-trained on a large dataset (such as ImageNet) and fine-tuned on a smaller, domain-specific dataset. The fine-tuned model is then used for inferencing, where its predictions are compared with a simpler baseline model’s (e.g., a basic CNN). By analyzing and visualizing predictions, transfer learning shows how pre-trained models, when fine-tuned, achieve more accurate results, especially when resources are limited for extensive training on smaller datasets.

The code below performs model inferencing and evaluates two models—a simple CNN and a fine-tuned ResNet. The `infer` function is defined to perform inference on any given model, loading images from `data_loader` and returning predicted and true labels for evaluation. In inference mode (`torch.no_grad()`), the model processes images without calculating gradients, which is faster and saves memory. Predictions for each model are stored in lists (`all_preds` and `all_labels`). The code then runs this inference function for both models, calculates accuracy, and outputs results.

After inferencing, the `visualize_predictions` function displays sample predictions from each model. This function accepts images, true labels, and predicted labels, showing them with their labels to help evaluate model performance visually. For each image, it displays the actual and predicted classes side by side, giving a qualitative sense of the model’s strengths and weaknesses. This visualization highlights the differences in performance between the simple CNN and fine-tuned ResNet:

# Model Inferencing for both models

```
def infer(model, data_loader, device):

    model.eval()

    all_preds = []

    all_labels = []

    with torch.no_grad():

        for images, labels in data_loader:

            images = images.to(device)

            labels = labels.to(device)

            outputs = model(images)

            _, predicted = torch.max(outputs, 1)

            all_preds.extend(predicted.cpu().numpy())

            all_labels.extend(labels.cpu().numpy())

    return all_labels, all_preds
```
