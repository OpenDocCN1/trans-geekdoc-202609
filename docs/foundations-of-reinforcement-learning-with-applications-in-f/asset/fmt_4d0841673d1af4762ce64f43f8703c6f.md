
$$\\begin{array}{r} {U(\\mathbf{\\mathbf{p}}) = SGD(x,y)(\\mathbf{\\mathbf{p}})\\ominus\\mathbf{\\mathbf{p}} = \\alpha\*(e(\\mathbf{\\mathbf{p}})\*G(x)(\\mathbf{\\mathbf{p}}))} \\\\ \\end{array}$$  

for all `p` ∈ 𝒫.

So, we can conceptualize the parameters change function `U` as the product of:

*   Learning rate `α` ∈ ℝ^+

*   Prediction error function `e`:𝒫→ℝ

*   Gradient operator `G`(`x`):𝒫→𝒢

Note that the product of functions `e` and `G`(`x`) above is point-wise in their common domain 𝒫 = `D`\[ℝ\], resulting in the scalar (ℝ) multiplication of vectors in 𝒢.

Updating vector `p` to vector `p` ⊕ `U`(`p`) in the Parameters Space 𝒫 results in updating function `I`(`p`):𝒳→ℝ to function `I`(`p`⊕`U`(`p`)):𝒳→ℝ in the Delegator Space ℛ. This is rather convenient since we can view the ⊕ operation for the Parameters Space 𝒫 as effectively the ⊕ operation in the Delegator Space ℛ.

## F.8 SGD UPDATE FOR LINEAR FUNCTION APPROXIMATIONS

In this section, we restrict to linear function approximations, i.e., for all `x` ∈ 𝒳,

$$\\begin{array}{r} {f(x,\\mathbf{\\mathbf{p}}) = \\mathbf{\\mathbf{\\Phi}}{(x)}^{T} \\cdot \\mathbf{\\mathbf{p}}} \\\\ \\end{array}$$  

where `p` ∈ ℝ^(*m*) = 𝒫 and `Φ`:𝒳→ℝ^(*m*) represents the feature functions (note: `Φ`(`x`)^(*T*) ⋅ `p` is the usual inner-product in ℝ^(*m*)).

Then the gradient function `G`:𝒳→(ℝ^(*m*)→ℝ^(*m*)) can be written as:

$$\\begin{array}{r} {G(x)(\\mathbf{\\mathbf{p}}) = \\nabla\_{\\mathbf{\\mathbf{p}}}(\\mathbf{\\mathbf{\\Phi}}{(x)}^{T} \\cdot \\mathbf{\\mathbf{p}}) = \\mathbf{\\mathbf{\\Phi}}(x)} \\\\ \\end{array}$$  

for all `x` ∈ 𝒳, for all `p` ∈ ℝ^(*m*).

When SGD-updating vector `p` to vector `p` ⊕ (*α* \* ((*y* − `Φ`(`x`)^(*T*) ⋅ `p`) \* `Φ`(`x`))) in the Parameters Space 𝒫 = ℝ^(*m*), applying the affine map `I`:ℝ^(*m*)→ℛ correspondingly updates functions in ℛ. Concretely, a linear function approximation `g`:𝒳→ℝ defined as `g`(`z`) = `Φ`(`z`)^(*T*) ⋅ `p` for all `z` ∈ 𝒳 updates correspondingly to the function `g`^((`x`, `y`)):𝒳→ℝ defined as `g`^((`x`, `y`))(`z`) = `Φ`(`z`)^(*T*) ⋅ `p` + *α* ⋅ (*y* − `Φ`(`x`)^(*T*) ⋅ `p`) ⋅ (`Φ`(`z`)^(*T*) ⋅ `Φ`(`x`)) for all `z` ∈ 𝒳.

It's useful to note that the change in the evaluation at `z` ∈ 𝒳, i.e., `g`^((`x`, `y`))(`z`) − `g`(`z`), is simply the product of:

*   Learning rate `α` ∈ ℝ^+

*   Prediction Error *y* − `Φ`(`x`)^(*T*) ⋅ `p` ∈ ℝ for the updating data (`x`, `y`) ∈ 𝒳 × ℝ

*   Inner-product of the feature vector `Φ`(`x`) ∈ ℝ^(*m*) of the updating input value `x` ∈ 𝒳 and the feature vector `Φ`(`z`) ∈ ℝ^(*m*) of the evaluation input value `z` ∈ 𝒳.

# Appendix G Conjugate Priors for Gaussian and Bernoulli Distributions

DOI: [10.1201/9781003229193-G](https://doi.org/10.1201/9781003229193-G)

The setting for this Appendix is that we receive data incrementally as `x`[1], `x`[2], … and we assume a certain probability distribution (e.g., Gaussian, Bernoulli) for each `x`[*i*], `i` = 1, 2, …. We utilize an appropriate conjugate prior for the assumed data distribution so that we can derive the posterior distribution for the parameters of the assumed data distribution. We can then say that for any `n` ∈ ℤ^+, the conjugate prior is the probability distribution for the parameters of the assumed data distribution, conditional on the first `n` data points (`x`[1], `x`[2], …`x`[*n*]) and the posterior is the probability distribution for the parameters of the assumed distribution, conditional on the first `n` + 1 data points (`x`[1], `x`[2], …, `x`[*n* + 1]). This amounts to performing Bayesian updates on the hyperparameters upon receipt of each incremental data `x`[*i*] (hyperparameters refer to the parameters of the prior and posterior distributions). In this appendix, we shall not cover the derivations of the posterior distribution from the prior distribution and the data distribution. We shall simply state the results (references for derivations can be found on the Conjugate Prior Wikipedia Page).

## G.1 CONJUGATE PRIOR FOR GAUSSIAN DISTRIBUTION

Here we assume that each data point is Gaussian-distributed in ℝ. So when we receive the `n`-th data point `x`[*n*], we assume:

$$\\begin{array}{r} {\\left. x\_{n} \\right.\\sim\\mathcal{N}(\\mu,\\sigma^{2})} \\\\ \\end{array}$$  

and we assume both `μ` and `σ`² are unknown random variables with Gaussian-Inverse-Gamma Probability Distribution Conjugate Prior for `μ` and `σ`², i.e.,

$$\\begin{array}{r} {\\left. \\mu|x\_{1},\\ldots,x\_{n} \\right.\\sim\\mathcal{N}(\\theta\_{n},\\frac{\\sigma^{2}}{n})} \\\\ \\end{array}$$  

$$\\begin{array}{r} {\\left. \\sigma^{2}|x\_{1},\\ldots,x\_{n} \\right.\\sim IG(\\alpha\_{n},\\beta\_{n})} \\\\ \\end{array}$$  

where `IG`(`α`[*n*], `β`[*n*]) refers to the Inverse Gamma distribution with parameters `α`[*n*] and `β`[*n*]. This means $\\frac{1}{\\sigma^{2}}|x\_{1},\\ldots,x\_{n}$ follows a Gamma distribution with parameters `α`[*n*] and `β`[*n*], i.e., the probability of $\\frac{1}{\\sigma^{2}}$ having a value `y` ∈ ℝ^+ is:

$$\\begin{array}{r} \\frac{\\beta^{\\alpha} \\cdot y^{\\alpha - 1} \\cdot e^{- \\beta y}}{\\Gamma(\\alpha)} \\\\ \\end{array}$$  

where `Γ`( ⋅ ) is the Gamma Function.

`θ`[*n*], `α`[*n*], `β`[*n*] are hyperparameters determining the probability distributions of `μ` and `σ`², conditional on data `x`[1], …, `x`[*n*].

Then, the posterior distribution is given by:

$$\\begin{array}{r} {\\left. \\mu|x\_{1},\\ldots,x\_{n + 1} \\right.\\sim\\mathcal{N}(\\frac{n\\theta\_{n} + x\_{n + 1}}{n + 1},\\frac{\\sigma^{2}}{n + 1})} \\\\ \\end{array}$$  

$$\\begin{array}{r} {\\left. \\sigma^{2}|x\_{1},\\ldots,x\_{n + 1} \\right.\\sim IG(\\alpha\_{n} + \\frac{1}{2},\\beta\_{n} + \\frac{n{(x\_{n + 1} - \\theta\_{n})}^{2}}{2(n + 1)})} \\\\ \\end{array}$$  

This means upon receipt of the data point `x`[*n* + 1], the hyperparameters can be updated as:

$$\\begin{array}{r} {\\theta\_{n + 1} = \\frac{n\\theta\_{n} + x\_{n + 1}}{n + 1}} \\\\ \\end{array}$$  

$$\\begin{array}{r} {\\alpha\_{n + 1} = \\alpha\_{n} + \\frac{1}{2}} \\\\ \\end{array}$$  

$$\\begin{array}{r} {\\beta\_{n + 1} = \\beta\_{n} + \\frac{n{(x\_{n + 1} - \\theta\_{n})}^{2}}{2(n + 1)}} \\\\ \\end{array}$$  

## G.2 CONJUGATE PRIOR FOR BERNOULLI DISTRIBUTION

Here we assume that each data point is Bernoulli-distributed. So when we receive the `n`-th data point `x`[*n*], we assume `x`[*n*] = 1 with probability `p` and `x`[*n*] = 0 with probability 1 − `p`. We assume `p` is an unknown random variable with Beta Distribution Conjugate Prior for `p`, i.e,

$$\\begin{array}{r} {\\left. p|x\_{1},\\ldots,x\_{n} \\right.\\sim Beta(\\alpha\_{n},\\beta\_{n})} \\\\ \\end{array}$$  

where `Beta`(`α`[*n*], `β`[*n*]) refers to the Beta distribution with parameters `α`[*n*] and `β`[*n*], i.e., the probability of `p` having a value `y` ∈ \[0, 1\] is:

$$\\begin{array}{r} {\\frac{\\Gamma(\\alpha + \\beta)}{\\Gamma(\\alpha) \\cdot \\Gamma(\\beta)} \\cdot y^{\\alpha - 1} \\cdot {(1 - y)}^{\\beta - 1}} \\\\ \\end{array}$$  

where `Γ`( ⋅ ) is the Gamma Function.

`α`[*n*], `β`[*n*] are hyperparameters determining the probability distribution of `p`, conditional on data `x`[1], …, `x`[*n*].

Then, the posterior distribution is given by:

$$\\begin{array}{r} {\\left. p|x\_{1},\\ldots,x\_{n + 1} \\right.\\sim Beta(\\alpha\_{n} + \\mathbb{I}\_{x\_{n + 1} = 1},\\beta\_{n} + \\mathbb{I}\_{x\_{n + 1} = 0})} \\\\ \\end{array}$$  

where `𝕀` refers to the indicator function.

This means upon receipt of the data point `x`[*n* + 1], the hyperparameters can be updated as:

$$\\begin{array}{r} {\\alpha\_{n + 1} = \\alpha\_{n} + \\mathbb{I}\_{x\_{n + 1} = 1}} \\\\ \\end{array}$$  

$$\\begin{array}{r} {\\beta\_{n + 1} = \\beta\_{n} + \\mathbb{I}\_{x\_{n + 1} = 0}} \\\\ \\end{array}$$
