理解上述证明的方法是从**B**^(*π*[*D*]^′)的每次进一步应用如何改进值函数的角度来思考。阶段 0 是指你拥有值函数 **V**^(*π*)，在整个 MDP 中执行策略 *π*。阶段 1 是指你拥有值函数 **B**^(*π*[*D*]^′)(**V**^(*π*))，从每个状态 *s* 开始，在 *s* 之后的第一个时间步执行策略 *π*[*D*]^′，然后对所有后续时间步执行策略 *π*。这使得值函数从阶段 0（**V**^(*π*)）改进到阶段 1（**B**^(*π*[*D*]^′)(**V**^(*π*))）。阶段 2 是指你拥有值函数 (**B**^(*π*[*D*]^′))²(**V**^(*π*))，从每个状态 *s* 开始，在 *s* 之后的前两个时间步执行策略 *π*[*D*]^′，然后对所有后续时间步执行策略 *π*。这使得值函数从阶段 1（**B**^(*π*[*D*]^′)(**V**^(*π*))）改进到阶段 2 ((**B**^(*π*[*D*]^′))²(**V**^(*π*)))。依此类推……每个阶段将策略 *π*[*D*]^′ 用于多一个时间步，而不是策略 *π*，这使得值函数得到改进。请注意，“改进”意味着 ≥（实际上意味着值函数对于*任何*状态都不会变差）。这些阶段只是策略评估算法（使用策略 *π*[*D*]^′）的迭代，起始值函数为 **V**^(*π*)，构建了一个非递减的值函数序列 \[(**B**^(*π*[*D*]^′))^(*i*)(**V**^(*π*))|*i* = 0, 1, 2, …\]，这些值函数越来越接近，直到收敛到值函数 **V**^(*π*[*D*]^′)，且 **V**^(*π*[*D*]^′)  ≥ **V**^(*π*)（因此，术语*策略改进*）。

策略改进定理得出了我们的第一个动态规划算法（称为*策略迭代*）来解决 MDP 控制问题。策略迭代算法由罗纳德·霍华德（Ronald Howard）提出（[Howard 1960](#bib01.xhtml#refbib_32)）。

## 5.7 策略迭代算法

策略改进定理的证明向我们展示了如何从值函数 **V**^(*π*)（针对策略 *π*）开始，执行贪婪策略改进以创建策略 *π*[*D*]^′ = *G*(**V**^(*π*))，然后执行策略评估（使用策略 *π*[*D*]^′），起始值函数为 **V**^(*π*)，从而得到值函数 **V**^(*π*[*D*]^′)，它是对我们开始时的值函数 **V**^(*π*) 的改进。现在请注意，我们可以再次执行相同的过程，从 *π*[*D*]^′ 和 **V**^(*π*[*D*]^′) 进入改进的策略 *π*[*D*]^(′′) 及其相关的改进值函数 **V**^(*π*[*D*]^(′′))。我们可以继续这样做，创建进一步改进的策略及其相关值函数，直到没有进一步改进为止。这种以迭代方式（如[图 5.1](#chapter5.xhtml#fig5_1)所示）将策略改进与使用改进策略的策略评估相结合的方法论，称为策略迭代算法（如下所示）。

*   从任意值函数 **V**[**0**] ∈ ℝ^(*m*) 开始

*   对 *j* = 0, 1, 2, … 进行迭代，在每次迭代中计算：

    $$\\begin{array}{r} {\\text{~确定性策略~}\\pi\_{j + 1} = G(\\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{j}}})} \\\\ \\end{array}$$  

    $$\\begin{array}{r} {\\text{~值函数~}\\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{j}} + \\mathbf{1}} = \\lim\\limits\_{i\\rightarrow\\infty}{(\\mathbf{\\mathbf{B}}^{\\pi\_{j + 1}})}^{i}(\\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{j}}})} \\\\ \\end{array}$$  

*   当 *d*(**V**[**j**], **V**[**j** + **1**]) = max[*s* ∈ 𝒩]|(**V**[**j**] − **V**[**j** + **1**])(*s*)| 足够小时停止算法。

因此，当值函数没有进一步改进时，算法终止。当这种情况发生时，以下条件应成立：

$$\\begin{array}{r} {\\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{j}}} = {(\\mathbf{\\mathbf{B}}^{G(\\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{j}}})})}^{i}(\\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{j}}}) = \\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{j}} + \\mathbf{1}}\\text{~对于所有~}i = 0,1,2,\\ldots} \\\\ \\end{array}$$  

特别是，该方程对于 *i* = 1 应成立：

$$\\begin{array}{r} {\\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{j}}}(s) = \\mathbf{\\mathbf{B}}^{G(\\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{j}}})}(\\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{j}}})(s) = \\mathcal{R}(s,G(\\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{j}}})(s)) + \\gamma{\\sum\\limits\_{s^{\\prime} \\in \\mathcal{N}}\\mathcal{P}}(s,G(\\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{j}}})(s),s^{\\prime}) \\cdot \\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{j}}}(s^{\\prime})\\text{~对于所有~}s \\in \\mathcal{N}} \\\\ \\end{array}$$  

根据方程 (5.3)，我们知道对于每个 *s* ∈ 𝒩，*π*[*j* + 1](*s*) = *G*(**V**[**j**])(*s*) 是最大化 $\\left\\{ \\mathcal{R}(s,a) + \\gamma{\\sum\\limits\_{s^{\\prime} \\in \\mathcal{N}}\\mathcal{P}}(s,a,s^{\\prime}) \\cdot \\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{j}}}(s^{\\prime}) \\right\\}$ 的动作。因此，

$$\\begin{array}{r} {\\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{j}}}(s) = \\max\_{a \\in \\mathcal{A}}\\left\\{ \\mathcal{R}(s,a) + \\gamma{\\sum\\limits\_{s^{\\prime} \\in \\mathcal{N}}\\mathcal{P}}(s,a,s^{\\prime}) \\cdot \\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{j}}}(s^{\\prime}) \\right\\}\\text{~对于所有~}s \\in \\mathcal{N}} \\\\ \\end{array}$$  

但这实际上是 MDP 状态-值函数贝尔曼最优性方程，这意味着 **V**[**j**] = **V**^(\*)，即，当 *V*[*j* + 1] 与 *V*[*j*] 相同时，策略迭代算法已收敛到最优值函数。策略迭代算法收敛时的相关确定性策略（*π*[*j*]:𝒩→𝒜）是一个最优策略，因为 **V**^(*π*[*j*]) = **V**[**j**] ≊ **V**^(\*)，这意味着使用确定性策略 *π*[*j*] 评估 MDP 可以实现最优值函数（如[图 5.2](#chapter5.xhtml#fig5_2)所示）。这意味着策略迭代算法解决了 MDP 控制问题。这证明了以下定理：
