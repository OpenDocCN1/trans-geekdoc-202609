

在介绍这 4 个模块中的章节内容之前，本书首先以 2 个预备章节开篇。其中第一个预备章节就是 `this chapter`（即你正在阅读的这一章），它作为 `Overview`，涵盖了学习强化学习（RL）（以及更广泛的应用数学）的教学方面、本书将要获得的学习内容概要、阅读本书所需的背景知识、随机控制、MDP、值函数、贝尔曼方程、DP 和 RL 的高层次概述，最后是本书章节大纲。第二个预备章节名为 `Programming and Design`。由于本书大量使用 Python 代码来开发数学模型和实现算法，我们将在本章中介绍所需的 Python 背景知识（具体来说，就是我们在 Python 代码中使用的设计范式）。需要说明的是，本章并非完整的 Python 教程——读者预期已经具备一定的 Python 基础。它是 Python 中一些关键技术和实践的教程（许多本书的读者可能不习惯这些技术），我们在本书中大量使用这些技术，它们在应用数学更广泛的编程领域也高度相关。我们将介绍 `Classes`、`Inheritance`、`Abstract Classes`、`Static Types`、`Generic Programming`、`Dataclasses`、`Immutability`、`First-class Functions`、`Lambdas`、`Iterators` 和 `Generators`。

本书剩余章节按照我们上面列出的 4 个模块进行组织。

## 模块 I：过程与规划算法

本书的第一个模块涵盖了马尔可夫决策过程（MDP）、动态规划（DP）和近似动态规划（ADP）的理论，内容跨越 [第 3 章](#chapter3.xhtml) – [第 6 章](#chapter6.xhtml)。

为了理解 MDP 框架，我们从 [第 3 章](#chapter3.xhtml) 中的 `Markov Processes`（有时也称为马尔可夫链）的基础知识开始。马尔可夫过程没有奖励或动作，只有状态和状态转换。我们认为，花大量时间研究这个简化的马尔可夫过程框架，是进入 MDP 之前的绝佳准备。[第 3 章](#chapter3.xhtml) 接着在马尔可夫过程的基础上引入奖励（但不包括动作）的概念——引入奖励后形成的框架被称为马尔可夫奖励过程。有了马尔可夫奖励过程，我们就可以讨论值函数和贝尔曼方程，这为以后在 MDP 的背景下理解值函数和贝尔曼方程提供了良好的准备。[第 3 章](#chapter3.xhtml) 通过股票价格的例子和一个简单的库存示例来阐释这些概念，该示例既作为马尔可夫过程，也作为马尔可夫奖励过程。本章还包含大量编程内容，以培养对这些概念的熟悉度和深度。

[第 4 章](#chapter4.xhtml) 关于 `Markov Decision Processes` 奠定了 RL 的基础理论——即用于表示在不确定性下处理序列最优决策问题的框架（马尔可夫决策过程）。你将学习马尔可夫决策过程与马尔可夫奖励过程之间的关系，以及值函数和贝尔曼方程。同样，本章包含大量编程练习。对这一理论的深入投入加上动手编程实践，将使你处于非常有利的位置，能够以非常清晰和快速的方式学习后续章节。

[第 5 章](#chapter5.xhtml) 关于 `Dynamic Programming` 介绍了动态规划（DP）的规划技术，这是一类重要的基础算法，如果 MDP 不太大或不太复杂，它可以作为 RL 的替代方案。此外，学习这些算法为更深入地理解后续 RL 算法提供了重要基础。到本章结束时，你将了解几种重要的 DP 算法，并了解为什么 DP 在实践中变得困难，这引出了 RL 的动机。同样，我们介绍了大量快速实现的编程练习，这将大大有助于内化这些概念。最后，我们强调一种特殊算法——后向归纳——用于求解有限时域马尔可夫决策过程，这是本书所涵盖的金融应用的场景。

[第 5 章](#chapter5.xhtml) 中介绍的动态规划算法面临着所谓的两个“诅咒”：维度灾难和建模诅咒。这些诅咒可以通过采样和函数近似的结合来治愈。模块 III 介绍采样治疗方法（使用强化学习）。[第 6 章](#chapter6.xhtml) 关于 `Function Approximation and Approximate Dynamic Programming` 涵盖了函数近似的主题，并展示了一种中间治疗方法——近似动态规划（无采样的函数近似）——通常相当可行，并可适用于某些问题。作为本章的一部分，我们实现了线性函数近似和基于深度神经网络的近似（前向和反向传播算法），以便我们可以在近似动态规划算法以及后来的 RL 中使用这些近似方法。

## 模块 II：金融应用建模

本书的第二个模块涵盖了效用理论的背景知识以及随机控制的 5 个金融应用，内容跨越 [第 7 章](#chapter7.xhtml) – [第 10 章](#chapter10.xhtml)。

我们从 [第 7 章](#chapter7.xhtml) 开始本模块，该章关于 `Utility Theory`，涵盖了一个非常重要的经济学概念，它是后续章节中我们所涵盖的大多数金融应用的先决条件。这是风险厌恶的概念（即人们希望如何因承担风险而获得补偿）以及相关的风险溢价和效用函数概念。本模块中剩余的章节不仅涵盖了 5 个金融应用，还详细介绍了如何将它们建模为 MDP、开发 DP/ADP 算法来求解它们，并编写大量代码来实现这些算法，这有助于很好地内化所学内容。请注意，在实践中，这些金融应用可能变得相当复杂，DP/ADP 算法的扩展性不佳，这意味着我们需要借助 RL 算法来求解它们。因此，当我们在模块 III 中介绍 RL 算法时，将重新回顾这些金融应用。

[第 8 章](#chapter8.xhtml) 标题为 `Dynamic Asset Allocation and Consumption`。本章介绍了 5 个金融应用中的第一个。这个问题涉及如何根据金融市场的变化调整个人财富在各种投资选择中的分配。该问题还涉及在一生中每个时间段应消费多少财富，以便从财富消费中获得最佳效用。因此，这是一个关于在一段时间内将财富动态分配给金融资产并适当消费个人财富的联合问题。这个问题最好在默顿 1969 年的里程碑式论文的背景下理解，他在其中提出并求解了这个问题。本章主要集中在使用动态规划对默顿问题的数学推导上。你还将学习如何在简单环境下使用近似后向归纳（[第 6 章](#chapter6.xhtml) 中介绍的一种 ADP 算法）来求解资产分配问题。
