
$$\\begin{array}{r} {\\mathbf{\\mathbf{w}}^{\*} = {(\\mathbf{\\mathbf{\\Phi}}^{T} \\cdot \\mathbf{\\mathbf{D}} \\cdot \\mathbf{\\mathbf{\\Phi}})}^{- 1} \\cdot \\mathbf{\\mathbf{\\Phi}}^{T} \\cdot \\mathbf{\\mathbf{D}} \\cdot \\mathbf{\\mathbf{V}}} \\\\ \\end{array}$$  

Since `Π[Φ](V) = Φ ⋅ w*`, we henceforth denote and treat Projection Operator `Π[Φ]` as the following `n × n` matrix:

$$\\begin{array}{r} {\\mathbf{\\mathbf{\\Pi}}\_{\\mathbf{\\mathbf{\\Phi}}} = \\mathbf{\\mathbf{\\Phi}} \\cdot {(\\mathbf{\\mathbf{\\Phi}}^{T} \\cdot \\mathbf{\\mathbf{D}} \\cdot \\mathbf{\\mathbf{\\Phi}})}^{- 1} \\cdot \\mathbf{\\mathbf{\\Phi}}^{T} \\cdot \\mathbf{\\mathbf{D}}} \\\\ \\end{array}$$  

### 13.7.3 Vectors of Interest in the `Φ` Subspace

In this section, we cover 4 Value Function vectors of interest in the `Φ` subspace, as candidate linear function approximations of the Value Function `V*(π)`. To lighten notation, we will refer to the `Φ`-subspace Value Function vectors by their corresponding weights `w`. All 4 of these Value Function vectors are depicted in [Figure 13.6](#chapter13.xhtml#fig13_6), an image we are borrowing from Sutton and Barto's RL book ([Richard S. Sutton and Barto 2018](#bib01.xhtml#refbib_62)). We spend the rest of this section going over these 4 Value Function vectors in detail.

![Figure 13.6 Value Function Geometry (Image Credit: Sutton-Barto's RL Book)](images/fig13_6.jpg)

[Figure 13.6](#chapter13.xhtml#b13fig13_6) Value Function Geometry (Image Credit: Sutton-Barto's RL Book)

The first Value Function vector of interest in the `Φ` subspace is the Projection `Π[Φ] ⋅ V*(π)`, denoted as `w[π] = arg min[w] d(V*(π), V[w])`. This is the linear function approximation of the Value Function `V*(π)` we seek because it is the Value Function vector in the `Φ` subspace that is “closest” to `V*(π)`. Monte-Carlo with linear function approximation will (slowly) converge to `w[π]`. [Figure 13.6](#chapter13.xhtml#fig13_6) provides the visualization. We've learnt that Monte-Carlo can be slow to converge, so we seek function approximations in the `Φ` subspace that are based on Temporal-Difference (TD), i.e., bootstrapped methods. The remaining three Value Function vectors in the `Φ` subspace are based on TD methods.

We denote the second Value Function vector of interest in the `Φ` subspace as `w[BE]`. The acronym `BE` stands for `Bellman Error`. To understand this, consider the application of the Bellman Policy Operator `B*(π)` on a Value Function vector `V[w]` in the `Φ` subspace. Applying `B*(π)` on `V[w]` typically throws `V[w]` out of the `Φ` subspace. The idea is to find a Value Function vector `V[w]` in the `Φ` subspace such that the “distance” between `V[w]` and `B*(π) ⋅ V[w]` is minimized, i.e. we minimize the “error vector” `BE = B*(π) ⋅ V[w] − V[w]` ([Figure 13.6](#chapter13.xhtml#fig13_6) provides the visualization). Hence, we say we are minimizing the `Bellman Error` (or simply that we are minimizing `BE`), and we refer to `w[BE]` as the Value Function vector in the `Φ` subspace for which `BE` is minimized. Formally, we define it as:

$$\\begin{aligned} \\mathbf{\\mathbf{w}}\_{BE} & {= \\text{arg}\\,\\text{min}\_{\\mathbf{\\mathbf{w}}}d(\\mathbf{\\mathbf{B}}^{\\pi} \\cdot \\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{w}}},\\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{w}}})} \\\\ & {= \\text{arg}\\,\\text{min}\_{\\mathbf{\\mathbf{w}}}d(\\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{w}}},\\mathcal{R}^{\\pi} + \\gamma\\mathcal{P}^{\\pi} \\cdot \\mathbf{\\mathbf{V}}\_{\\mathbf{\\mathbf{w}}})} \\\\ & {= \\text{arg}\\,\\text{min}\_{\\mathbf{\\mathbf{w}}}d(\\mathbf{\\mathbf{\\Phi}} \\cdot \\mathbf{\\mathbf{w}},\\mathcal{R}^{\\pi} + \\gamma\\mathcal{P}^{\\pi} \\cdot \\mathbf{\\mathbf{\\Phi}} \\cdot \\mathbf{\\mathbf{w}})} \\\\ & {= \\text{arg}\\,\\text{min}\_{\\mathbf{\\mathbf{w}}}d(\\mathbf{\\mathbf{\\Phi}} \\cdot \\mathbf{\\mathbf{w}} - \\gamma\\mathcal{P}^{\\pi} \\cdot \\mathbf{\\mathbf{\\Phi}} \\cdot \\mathbf{\\mathbf{w}},\\mathcal{R}^{\\pi})} \\\\ & {= \\text{arg}\\,\\text{min}\_{\\mathbf{\\mathbf{w}}}d((\\mathbf{\\mathbf{\\Phi}} - \\gamma\\mathcal{P}^{\\pi} \\cdot \\mathbf{\\mathbf{\\Phi}}) \\cdot \\mathbf{\\mathbf{w}},\\mathcal{R}^{\\pi})} \\\\ \\end{aligned}$$  

This is a weighted least-squares linear regression of `ℛ*(π)` against `Φ − γ𝒫*(π) ⋅ Φ` with weights `μ[π]`, whose solution is:

$$\\begin{array}{r} {\\mathbf{\\mathbf{w}}\_{BE} = {({(\\mathbf{\\mathbf{\\Phi}} - \\gamma\\mathcal{P}^{\\pi} \\cdot \\mathbf{\\mathbf{\\Phi}})}^{T} \\cdot \\mathbf{\\mathbf{D}} \\cdot (\\mathbf{\\mathbf{\\Phi}} - \\gamma\\mathcal{P}^{\\pi} \\cdot \\mathbf{\\mathbf{\\Phi}}))}^{- 1} \\cdot {(\\mathbf{\\mathbf{\\Phi}} - \\gamma\\mathcal{P}^{\\pi} \\cdot \\mathbf{\\mathbf{\\Phi}})}^{T} \\cdot \\mathbf{\\mathbf{D}} \\cdot \\mathcal{R}^{\\pi}} \\\\ \\end{array}$$  

The above formulation can be used to compute `w[BE]` if we know the model probabilities `𝒫*(π)` and reward function `ℛ*(π)`. But often, in practice, we don't know `𝒫*(π)` and `ℛ*(π)`, in which case we seek model-free learning of `w[BE]`, specifically with a TD (bootstrapped) algorithm.

Let us refer to

$$\\begin{array}{r} {{(\\mathbf{\\mathbf{\\Phi}} - \\gamma\\mathcal{P}^{\\pi} \\cdot \\mathbf{\\mathbf{\\Phi}})}^{T} \\cdot \\mathbf{\\mathbf{D}} \\cdot (\\mathbf{\\mathbf{\\Phi}} - \\gamma\\mathcal{P}^{\\pi} \\cdot \\mathbf{\\mathbf{\\Phi}})} \\\\ \\end{array}$$  

as matrix `A` and let us refer to

$$\\begin{array}{r} {{(\\mathbf{\\mathbf{\\Phi}} - \\gamma\\mathcal{P}^{\\pi} \\cdot \\mathbf{\\mathbf{\\Phi}})}^{T} \\cdot \\mathbf{\\mathbf{D}} \\cdot \\mathcal{R}^{\\pi}} \\\\ \\end{array}$$  

as vector `b` so that `w[BE] = A^(-1) ⋅ b`.

Following policy `π`, each time we perform an individual transition from `s` to `s′` getting reward `r`, we get a sample estimate of `A` and `b`. The sample estimate of `A` is the outer-product of vector `ϕ(s) − γ ⋅ ϕ(s′)` with itself. The sample estimate of `b` is scalar `r` times vector `ϕ(s) − γ ⋅ ϕ(s′)`. We average these sample estimates across many such individual transitions. However, this requires `m` (the number of features) to be not too large.

If `m` is large or if we are doing non-linear function approximation or off-policy, then we seek a gradient-based TD algorithm. We defined `w[BE]` as the vector in the `Φ` subspace for which the Bellman Error is minimized. But Bellman Error for a state is the expectation of the TD error `δ` for that state when following policy `π`. So we want to do Stochastic Gradient Descent with the gradient of the square of expected TD error, as follows:

$$\\begin{aligned} {\\Delta\\mathbf{\\mathbf{w}}} & {= - \\alpha \\cdot \\frac{1}{2} \\cdot \\nabla\_{\\mathbf{\\mathbf{w}}}{(\\mathbb{E}\_{\\pi}\\lbrack\\delta\\rbrack)}^{2}} \\\\ & {= - \\alpha \\cdot \\mathbb{E}\_{\\pi}\\lbrack r + \\gamma \\cdot \\phi{(s^{\\prime})}^{T} \\cdot \\mathbf{\\mathbf{w}} - \\phi{(s)}^{T} \\cdot \\mathbf{\\mathbf{w}}\\rbrack \\cdot \\nabla\_{\\mathbf{\\mathbf{w}}}\\mathbb{E}\_{\\pi}\\lbrack\\delta\\rbrack} \\\\ & {= \\alpha \\cdot (\\mathbb{E}\_{\\pi}\\lbrack r + \\gamma \\cdot \\phi{(s^{\\prime})}^{T} \\cdot \\mathbf{\\mathbf{w}}\\rbrack - \\phi{(s)}^{T} \\cdot \\mathbf{\\mathbf{w}}) \\cdot (\\phi(s) - \\gamma \\cdot \\mathbb{E}\_{\\pi}\\lbrack\\phi(s^{\\prime})\\rbrack)} \\\\ \\end{aligned}$$
