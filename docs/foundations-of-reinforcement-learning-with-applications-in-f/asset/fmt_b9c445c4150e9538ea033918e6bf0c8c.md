
$$\\begin{array}{r} {\\Delta\\mathbf{\\mathbf{\\theta}} = \\alpha\_{\\mathbf{\\mathbf{\\theta}}} \\cdot \\gamma^{t} \\cdot (\\nabla\_{\\mathbf{\\mathbf{\\theta}}}\\log\\pi(S\_{t};A\_{t};\\mathbf{\\mathbf{\\theta}})) \\cdot (R\_{t + 1} + \\gamma \\cdot V(S\_{t + 1};\\mathbf{\\mathbf{v}}) - V(S\_{t};\\mathbf{\\mathbf{v}}))} \\\\ \\end{array}$$

where `α`[`θ`] is the learning rate for the Policy Mean function approximation.

The updates after each atomic experience to parameters `v` of the State-Value function approximation and parameters `θ` of the policy mean function approximation are given by:

$$\\begin{array}{r} {\\Delta\\mathbf{\\mathbf{v}} = \\alpha\_{\\mathbf{\\mathbf{v}}} \\cdot (R\_{t + 1} + \\gamma \\cdot V(S\_{t + 1};\\mathbf{\\mathbf{v}}) - V(S\_{t};\\mathbf{\\mathbf{v}})) \\cdot \\mathbf{\\mathbf{E}}\_{\\mathbf{\\mathbf{v}}}} \\\\ \\end{array}$$

where `λ`[`v`] and `λ`[`θ`] are the TD(`λ`) parameters respectively for the State-Value Function Approximation and the Policy Mean Function Approximation.

## 14.7 Overcoming Bias with Compatible Function Approximation

We've talked a lot about reducing variance for faster convergence of PG Algorithms. Specifically, we've talked about the following proxies for `Q`^(`π`)(`s`, `a`) in the form of Actor-Critic algorithms in order to reduce variance.

*   `Q`(`s`, `a`; `w`)

*   `A`(`s`, `a`; `w`, `v`) = `Q`(`s`, `a`; `w`) − `V`(`s`; `v`)

*   `δ`(`s`, `s`^′, `r`; `v`) = `r` + `γ` ⋅ `V`(`s`^′; `v`) − `V`(`s`; `v`)

However, each of the above proxies for `Q`^(`π`)(`s`, `a`) in PG algorithms have a bias. In this section, we talk about how to overcome bias. The basis for overcoming bias is an important Theorem known as the Compatible Function Approximation Theorem. We state and prove this theorem, and then explain how we could use it in a PG algorithm.

This proof originally appeared in the famous paper by Sutton, McAllester, Singh, Mansour on Policy Gradient Methods for Reinforcement Learning with Function Approximation (R. [Sutton et al. 2001](#bib01.xhtml#refbib_63)).

This means if the compatibility assumption of the Theorem is satisfied, we can use the critic function approximation `Q`(`s`, `a`; `w`[`θ`]^(\*)) and still have exact Policy Gradient (i.e., no bias due to using a function approximation for the Q-Value Function). However, note that in practice, we invoke the spirit of GPI and don't take `Q`(`s`, `a`; `w`) to convergence for the current `θ`. Rather, we update both `w` and `θ` frequently, and this turns out to be good enough in terms of lowering the bias.

A simple way to enable Compatible Function Approximation is to make `Q`(`s`, `a`; `w`) a linear function approximation, with the features of the linear function approximation equal to the Score of the policy function approximation, as follows:

$$\\begin{array}{r} {Q(s,a;\\mathbf{\\mathbf{w}}) = {\\sum\\limits\_{i = 1}^{m}\\frac{\\partial\\log\\pi(s,a;\\mathbf{\\mathbf{\\theta}})}{\\partial\\theta\_{i}}} \\cdot w\_{i}\\text{~for~all~}s \\in \\mathcal{N},\\text{~for~all~}a \\in \\mathcal{A}} \\\\ \\end{array}$$

which means the feature functions `η`(`s`, `a`) = (`η`[1](`s`, `a`), `η`[2](`s`, ` a`), …, `η`[`m`](`s`, `a`)) of the linear function approximation are given by:

$$\\begin{array}{r} {\\eta\_{i}(s,a) = \\frac{\\partial\\log\\pi(s,a;\\mathbf{\\mathbf{\\theta}})}{\\partial\\theta\_{i}}\\text{~for~all~}s \\in \\mathcal{N},\\text{~for~all~}a \\in \\mathcal{A},\\text{~for~all~}i = 1,\\ldots,m} \\\\ \\end{array}$$

This means the feature functions `η` is identically equal to the Score. Note that although here we assume `Q`(`s`, `a`; `w`) to be a linear function approximation, the policy function approximation `π`(`s`, `a`; `θ`) can be more flexible. All that is required is that `θ` consists of exactly `m` parameters (matching the number of number of parameters `m` of `w`) and that each of the partial derivatives $\\frac{\\partial\\log\\pi(s,a;\\mathbf{\\mathbf{\\theta}})}{\\partial\\theta\_{i}}$ lines up with a corresponding feature `η`[`i`](`s`, `a`) of the linear function approximation `Q`(`s`, `a`; `w`). This means that as `θ` updates (as a consequence of Stochastic Gradient Ascent), `π`(`s`, `a`; `θ`) updates, and consequently the feature functions `η`(`s`, `a`) = ∇[`θ`]log `π`(`s`, `a`; `θ`) update. This means the feature vector `η`(`s`, `a`) is not constant for a given (`s`, `a`) pair. Rather, the feature vector `η`(`s`, `a`) for a given (`s`, `a`) pair varies in accordance with `θ` varying.

If we assume the canonical function approximation for `π`(`s`, `a`; `θ`) for finite action spaces that we had described in [Section 14.3](#chapter14.xhtml#sec14_3), then:

$$\\begin{array}{r} {\\mathbf{\\mathbf{\\eta}}(s,a) = \\phi(s,a) - {\\sum\\limits\_{b \\in \\mathcal{A}}\\pi}(s,b;\\mathbf{\\mathbf{\\theta}}) \\cdot \\phi(s,b)\\text{~for~all~}s \\in \\mathcal{N}\\text{~for~all~}a \\in \\mathcal{A}} \\\\ \\end{array}$$
