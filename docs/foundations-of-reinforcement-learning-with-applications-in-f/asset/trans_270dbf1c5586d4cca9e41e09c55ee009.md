

# Module III：强化学习算法

Module III 介绍了强化学习算法。Module III 首先阐述了强化学习（RL）的必要性。在现实世界中，我们通常无法获取状态-奖励转移概率模型。通常，我们只能访问一个环境，该环境在 AI 智能体与环境交互的每一步中，根据当前状态和动作提供下一个状态和奖励。环境可以是真实环境，也可以是模拟环境（后者来自对环境的学习模型）。用于预测/控制的 RL 算法通过与环境交互获取足够数据（`atomic experiences`）来学习所需的值函数/策略。这是一种“试错”学习，通过优先选择似乎能获得良好奖励的动作，并降低似乎能获得较差奖励的动作的优先级来实现。具体来说，RL 算法的任务是学习近似 Q-值函数，即对任何给定状态下任何给定动作的预期回报的估计。RL 算法的成功不仅取决于其通过与环境交互以增量方式学习 Q-值函数的能力，还取决于其使用适当的函数近似（通常使用深度神经网络，在这种情况下我们称之为深度 RL）对 Q-值函数进行良好泛化的能力。大多数 RL 算法都基于贝尔曼方程，而所有 RL 控制算法都基于 `Generalized Policy Iteration` 的基本思想。

## Chapter 11：RL 预测算法

在 [Chapter 11](#chapter11.xhtml) 中，我们介绍了 RL 预测算法。具体来说，我们介绍了用于预测的蒙特卡洛（MC）和时序差分（TD）算法。本章的一个关键收获是 MC 与 TD 之间的偏差-方差权衡。另一个关键收获是，虽然 MC 预测学习观察到的回报的统计均值，但 TD 预测学习的是“更深层”的东西——TD 从观察到的数据中隐式估计一个 MRP，并生成隐式估计的 MRP 的值函数。我们强调从“自举”和“体验”的角度来看待 TD 与 MC 与 DP。我们通过介绍 `λ`-回报预测和 TD(`λ`) 预测算法结束了本章，这些算法通过调整 `λ` 参数，为我们提供了一种在 MC 到 TD 的光谱上权衡偏差与方差的方法。TD 等同于 TD(0)，而 MC “等同于” TD(1)。

## Chapter 12：RL 控制算法

在 [Chapter 12](#chapter12.xhtml) 中，我们介绍了 RL 控制算法。我们再次强调，RL 控制基于广义策略迭代（GPI）的思想。我们解释了策略评估是针对 `Q`-值函数（而不是状态值函数）进行的，并且改进的策略需要具有探索性，例如 `ϵ`-贪婪。接下来，我们描述了一个重要概念——`无限探索下的极限贪婪`（GLIE）。我们的第一个 RL 控制算法是 GLIE 蒙特卡洛控制。接下来，我们介绍了两个重要的 TD 控制算法：SARSA（在策略）和 Q-Learning（非在策略）。我们简要介绍了重要性采样，这是一种不同的非在策略算法实现方式。我们以对 RL 预测和 RL 控制算法收敛性的一些评论结束了本章。我们强调了遇到收敛问题的情况的一个强烈模式——即当 [`Bootstrapping`, `Function Approximation`, `Off-Policy`] 这三者同时进行时。我们已经看到，这三者各自都有益，但当三者结合在一起时，就变成了“好事过多”，从而导致收敛问题。这三者的结合被称为 `致命三重奏`（例如，带有函数近似的 Q-Learning 就是一个例子）。

## Chapter 13：高级 RL 算法

在 [Chapter 13](#chapter13.xhtml) 中，我们介绍了更微妙的 RL 算法，超越了我们在 [chapters 11](#chapter11.xhtml) 和 [12](#chapter12.xhtml) 中介绍的普通 MC 和 TD 算法。我们首先介绍了 `批量 RL` 和 `经验回放` 的新颖思想。接下来，我们介绍了最小二乘蒙特卡洛（LSMC）预测算法和最小二乘时序差分（LSTD）算法，后者是批量 TD 的直接（无梯度）解。接下来，我们介绍了非常重要的深度 Q 网络（DQN）算法，它使用经验回放和固定 Q 学习目标，以避免时间相关性和变化的 TD 目标的陷阱。接下来，我们介绍了最小二乘策略迭代（LSPI）算法，它是一种非在策略、使用经验回放的控制算法，使用 LSTDQ 进行策略评估。然后，我们展示了如何使用 LSPI 和深度 Q 学习算法来解决美式期权的最优行权问题。在本章的后半部分，我们通过将值函数视为向量，更深入地探讨了 `致命三重奏` 问题，以便在几何直觉和数学严谨性之间平衡地理解值函数向量变换，为开发 RL 算法所使用的各种传统损失函数的收敛性问题提供了洞察。最后，这种将值函数视为向量的处理方法引导我们通过定义适当的损失函数来克服致命三重奏，计算其梯度可提供一组更强健的 RL 算法，称为梯度时序差分（Gradient TD）。

## Chapter 14：策略梯度算法

在 [Chapter 14](#chapter14.xhtml) 中，我们介绍了策略梯度（PG）算法，这些算法基于 GPI，将策略改进作为使用策略函数近似的 `预期回报目标` 的随机梯度上升。我们从策略梯度定理开始，该定理为我们提供了一个简单的公式，用策略函数近似的得分来表示预期回报目标的梯度。我们的第一个 PG 算法是 REINFORCE 算法，这是一种无偏差但高方差的蒙特卡洛策略梯度算法。我们展示了如何使用 REINFORCE 来解决最优资产配置问题。接下来，我们展示了如何通过使用评论家以及使用优势函数的估计来代替 Q-值函数，从而减少 PG 算法中的方差。接下来，我们展示了如何基于 `兼容函数近似定理` 来克服 PG 算法中的偏差。最后，我们介绍了两种在实践中效果良好的专用 PG 算法——自然策略梯度和确定性策略梯度。我们还介绍了进化策略，它们从技术上讲不是 RL 算法，但与 PG 算法相似，有时在解决 MDP 控制问题方面可能非常有效。

# Module IV：探索、利用以及学习与规划的融合

在 Module IV 中，我们通过详细介绍探索与利用以及学习与规划的融合这两个主题，提供了一些收尾内容。在 [Chapter 15](#chapter15.xhtml) 中，我们对多臂老虎机（MAB）问题的算法进行了大量介绍，该问题提供了一个简单的环境，以便理解和欣赏探索与利用困境的细微差别，而我们通常需要在 RL 控制算法中解决这一困境。我们从简单的方法开始，例如天真探索（例如，`ϵ`-贪婪）和乐观初始化。接下来，我们介绍了基于 `面对不确定性的乐观` 广泛方法的方法（例如，上置信界）。接下来，我们介绍了概率匹配（例如，汤普森采样）这一强大且在实践中有效的方法。然后，我们还介绍了梯度老虎机算法，以及通过形成信息状态空间 MDP（纳入信息价值）来平衡探索与利用的一种有纪律的方法，通常通过将其视为贝叶斯自适应 MDP 来求解。最后，我们指出，上述 MAB 算法可以很好地扩展到情境老虎机和 RL 控制。
