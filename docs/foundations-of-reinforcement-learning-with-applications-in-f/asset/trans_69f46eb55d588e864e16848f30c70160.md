

# Chapter 9

[Chapter 9](#chapter9.xhtml) 涵盖了数学金融中一个非常重要的主题：*衍生品定价与对冲*。对衍生品定价与对冲进行全面且严谨的覆盖是一个相当复杂且高级的主题，超出了本书的范围。但我们提供了一种方法，通过考虑一个非常简单的设置——即单期、离散结果且没有对冲再平衡的设置（这在一般理论中很典型）来理解理论。在涵盖基础理论之后，我们涵盖了美式期权最优行权问题以及在*不完备市场*中衍生品最优定价/对冲问题（这两个问题都建模为 MDP）。在本章中，你将学习一些非常重要的金融基础，例如套利、复制、市场完备性以及至关重要的风险中性度量等概念。你将学习在这个简单设置下资产定价两大基本定理的证明。我们还提供了一般理论的概述（超出这个简单设置）。接下来，你将学习如何将最优停止的一般问题建模为 MDP，并特化到美式期权最优行权的情况。你将学习如何使用后向归纳（我们在 [Chapter 5](#chapter5.xhtml) 中学习的一种 DP 算法）来解决这个问题，前提是状态空间不太大。最后，你将学习如何通过将此问题建模为 MDP 来对衍生品定价/对冲中包含现实世界摩擦。在本章结束时，你将在定价和对冲复杂衍生品方面发展出显著的专业知识，这是金融行业中非常抢手的技能。

# Chapter 10

[Chapter 10](#chapter10.xhtml) 关于 *订单簿算法* 涵盖了剩余的两个金融应用，涉及算法交易领域。算法交易的当前做法是采用基于规则和启发式的技术。然而，算法交易正在迅速转变为基于机器学习的算法。在本章中，你将首先了解交易订单下放的机制（市价单和限价单），然后了解一个非常重要的现实问题——如何通过拆分要交易的股票并最优地安排拆分时机来提交大规模市价单，以克服“价格冲击”并获得最大收益。你将学习基于动态规划的经典方法。接下来，你将学习市场摩擦以及需要用 RL 来解决它们。在本章的后半部分，我们涵盖了最优执行问题的算法交易对应问题——即做市商需要提交动态变化的买入和卖出限价单，以便她能获得最大收益。你将了解做市商（一个庞大且蓬勃发展的行业）是如何运作的。然后你将学习如何将此问题建模为 MDP。我们将对 Avellaneda 和 Stoikov 的经典动态规划解决方案进行彻底的覆盖。最后，你将接触到此问题的现实世界细微差别，因此，需要使用市场校准的模拟器和 RL 来解决。

## 1.9.3 Module III: Reinforcement Learning Algorithms

本书的第三个模块涵盖了 [Chapters 11](#chapter11.xhtml) – [14](#chapter14.xhtml) 中的强化学习算法。

# Chapter 11

[Chapter 11](#chapter11.xhtml) 关于 *蒙特卡洛和时序差分用于预测* 开启了本书的新阶段——我们进入 RL 算法的世界。为了理解 RL 的基础知识，我们在本章开始时将 RL 问题限制在一个非常简单的问题中——即状态空间小且可作为表格枚举来管理（称为表格 RL）且我们只需要计算固定策略下的值函数（这个问题称为预测问题，与称为控制问题的优化问题相对）。限制于表格预测很重要，因为它使得在这个简化设置中更容易理解蒙特卡洛（MC）和时序差分（TD）的核心概念。本章的后半部分将表格预测扩展到带函数近似的预测（利用我们在 [Chapter 6](#chapter6.xhtml) 中在 ADP 背景下开发的函数近似基础）。剩余章节将基于本章，添加更多复杂性和细微差别，同时保留本章开发的许多关键核心概念。一如既往，你将通过从头开始编写大量 MC 和 TD 算法来学习。

# Chapter 12

[Chapter 12](#chapter12.xhtml) 关于 *蒙特卡洛和时序差分用于控制* 从预测自然扩展到控制，同时最初保持在表格设置中。在 [Chapter 11](#chapter11.xhtml) 中对 MC 和 TD 核心概念的理解投资在这里得到了回报，因为 SARSA 和 Q-learning 等重要控制算法现在可以以极大的清晰度来学习。在本章中，我们将在 Python 中从头开始实现 SARSA 和 Q-Learning。本章还介绍了一个对 RL 在现实世界中未来成功非常重要的概念：非策略学习（Q-Learning 是最简单的非策略学习算法，并且在各种应用中取得了良好的成功）。本章的后半部分将表格控制扩展到带函数近似的控制（利用我们在 [Chapter 6](#chapter6.xhtml) 中开发的函数近似基础）。

# Chapter 13

[Chapter 13](#chapter13.xhtml) 关于 *批量 RL、经验回放、DQN、LSPI、梯度 TD* 从基础和更传统的 RL 算法转向 RL 中的最近创新。我们从本章开始介绍 *批量 RL* 和 *经验回放* 的重要思想，这通过在数据到来时存储数据并在算法的学习过程中分批重复使用它，从而更有效地利用数据。我们强调了创新的深度 Q 网络算法，它利用经验回放和深度神经网络进行 Q-Learning。我们还强调了一种简单但重要的批量 RL 技术，使用线性函数近似——预测问题的算法称为最小二乘时序差分，其解决控制问题的扩展称为最小二乘策略迭代。我们在模块 II 的一个金融应用背景下讨论了这些算法。在本章的后半部分，我们提供了支撑 RL 算法的核心数学的更深入洞察（回到贝尔曼方程的基础）。理解 *值函数几何* 将使你在真正理解是什么让某些算法在某些情况下成功而在其他情况下失败方面处于非常有利的地位。本章还解释了如何摆脱所谓的致命三元组（当引导、函数近似和非策略一起使用时，RL 算法往往会失败）。最先进的梯度 TD 算法抵抗致命三元组，我们深入研究其内部工作原理以了解如何以及为什么。
