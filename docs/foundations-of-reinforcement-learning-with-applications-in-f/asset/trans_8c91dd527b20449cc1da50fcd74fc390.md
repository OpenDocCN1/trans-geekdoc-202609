## 12.8 RL 算法的收敛性

现在我们对 RL 算法的收敛性进行概述。让我们从 RL 预测开始。[图 12.14](#chapter12.xhtml#fig12_14) 提供了 RL 预测的概述。如您所见，无论是 On-Policy 还是 Off-Policy，无论是 Tabular 还是带有函数近似（即使是非线性函数近似），蒙特卡洛预测都具有收敛保证。然而，时序差分预测可能会出现收敛问题——其核心原因在于 TD 更新不是真正的梯度更新（如我们在 [第 11 章](#chapter11.xhtml) 中解释过，它是 `semi-gradient` 更新）。如您所见，尽管我们对带有线性函数近似的 On-Policy TD 预测有收敛保证，但对于带有非线性函数近似的 On-Policy TD 预测则没有收敛保证。对于 Off-Policy TD 预测，情况更糟——即使是线性函数近似也没有收敛保证。

![图 12.14 RL 预测算法的收敛性](images/fig12_14.jpg)

[图 12.14](#chapter12.xhtml#b12fig12_14) RL 预测算法的收敛性

我们想强调 RL 算法中出现收敛问题的一个共性模式。作为经验法则，如果我们同时做以下三件事，就会遇到收敛问题。

*   Bootstrapping，即使用涉及当前值函数估计的目标进行更新（如时序差分的情况）

*   Off-Policy

*   值函数的函数近似

因此，\[`Bootstrapping`, `Off-Policy`, `Function Approximation`\] 被称为 `Deadly Triad`，这一术语由 Richard Sutton 在多篇出版物和讲座中强调和推广。我们应该强调，`Deadly Triad` 现象不是定理——相反，它应被视为一种粗略的模式和经验法则。所以为了实现收敛，我们应避免上述三者中的至少一个。我们已经看到，\[`Bootstrapping`, `Off-Policy`, `Function Approximation`\] 中的每一项都有其好处，但当三者结合在一起时，我们就会遇到收敛问题。根本问题是，半梯度 bootstrapping 不遵循 *任何* 目标函数的梯度，这导致 TD 在离策略运行和使用函数近似时发散。

由于现实问题的规模，函数近似在现实问题中通常是不可避免的。因此，我们考虑避免半梯度 bootstrapping 或避免离策略。请注意，半梯度 bootstrapping 可以通过将 TD `λ` 参数调整到足够高的值来缓解。然而，如果我们想从根本上解决这个问题，可以通过使用一种称为 `Gradient Temporal-Difference`（或简称 `Gradient TD`）的方法来执行 *真梯度*，从而避免半梯度 bootstrapping 的核心问题。我们将在 [第 13 章](#chapter13.xhtml) 中详细介绍 Gradient TD，但目前，我们只想分享：Gradient TD 使用适当损失函数的实际梯度（而非半梯度）来更新值函数近似的参数，且梯度公式涉及 bootstrapping。因此，它既能享受 bootstrapping 的优势，又能避免半梯度的劣势（我们在 [第 11 章](#chapter11.xhtml) 中戏称为“作弊”）。[图 12.15](#chapter12.xhtml#fig12_15) 在 [图 12.14](#chapter12.xhtml#fig12_14) 的基础上，加入了 Gradient TD 的收敛特性。

![图 12.15 RL 预测算法的收敛性，包括 Gradient TD](images/fig12_15.jpg)

[图 12.15](#chapter12.xhtml#b12fig12_15) RL 预测算法的收敛性，包括 Gradient TD

现在让我们转向控制算法的收敛性。[图 12.16](#chapter12.xhtml#fig12_16) 提供了相关图示。（✓）表示它并未完全达到最优值函数，而是在最优值函数附近波动。Gradient Q-Learning 是 Q-Learning 与 Gradient TD 的结合。因此，该方法是离策略的，是 bootstrapped 的，但避免了半梯度。这使得它在线性函数近似下能够收敛。然而，当与非线性函数近似一起使用时，它会发散。因此，对于控制问题，即使有 Gradient TD，致命三元组 \[`Bootstrapping`, `Off-Policy`, `Non-Linear Function Approximation`\] 的组合仍然存在。在 [第 13 章](#chapter13.xhtml) 中，我们将介绍 DQN 算法，这是一种创新且在实践中有效的方法，用于绕过 RL 控制中的致命三元组。

## 12.9 本章要点

*   RL 控制基于广义策略迭代（GPI）的思想：

    *   基于 `Q`-值函数的策略评估（而非状态值函数 `V`）

    *   改进的策略需要具有探索性，例如 `ϵ`-greedy

*   On-Policy 与 Off-Policy（例如 `SARSA` 与 `Q-Learning`）

*   致命三元组：= \[`Bootstrapping`, `Off-Policy`, `Function Approximation`\]
