

# TD 与 MC 学习内容的概念差异

我们之前讨论了 TD 学习与 MC 学习在“如何”学习方面的区别。在本小节中，我们将重点转向 TD 学习和 MC 学习分别学习“什么”内容，以揭示 TD 与 MC 之间深刻的概念差异。我们通过一种特殊设置来阐明这一差异——我们拥有一个固定的有限轨迹经验集（与本章迄今考虑的通常设置不同，后者拥有“无尽”的轨迹经验流）。代理可以无限次地利用这个固定的有限轨迹经验集，即 MC 或 TD 预测 RL 代理确实可以消费无尽的经验流，但该流中的所有经验最终都必须来源于给定的固定有限轨迹经验集。这意味着我们将反复利用轨迹经验（或其组成的原子经验）。我们将这种重复使用先前遇到的经验数据的技术称为 *Experience Replay*。我们将在 [Chapter 13](#chapter13.xhtml) 中更详细地介绍 Experience Replay 技术，但目前，我们将通过在固定有限轨迹经验集的 *Experience Replay* 上运行算法，来揭示 MC 和 TD 学习内容之间的关键概念差异。

$$
\begin{array}{r}
\mathcal{P}_{R}(s,r,s^{\prime}) = \frac{\sum\limits_{i = 1}^{N}\mathbb{I}_{S_{i} = s,R_{i + 1} = r,S_{i + 1} = s^{\prime}}}{\sum\limits_{i = 1}^{N}\mathbb{I}_{S_{i} = s}}
\end{array}
$$

(11.12)

其中固定有限的原子经验集为 `[(S[i], R[i + 1], S[i + 1]) | 1 ≤ i ≤ N]`，`𝕀` 表示指示函数。

因此，我们的 TD 预测算法并不完全匹配数据隐含 MRP 的值函数，但它很接近。结果表明，TD 预测算法的一个变体与数据隐含 MRP 的值函数完全匹配。我们不会在本章中实现这个变体，但将在此简要描述。该变体如下：

* 值函数不是在每个原子经验后更新，而是在每个 *原子经验批次* 结束时更新。
* 每个原子经验批次由给定固定有限数据集中每个原子经验的单次出现组成。
* 在每个批次结束时执行的值函数更新会在每个原子经验后累积在缓冲区中，缓冲区的内容仅在批次结束时用于更新值函数。具体来说，这意味着方程 (11.10) 的右侧在每个原子经验结束时计算，这些计算值会累积在缓冲区中，直到批次结束，此时缓冲区的内容用于更新值函数。

TD 预测算法的这种变体称为 *Batch Updating*，更广泛地说，在批次结束时更新值函数的 RL 算法被称为 *Batch Methods*。这与 *Incremental Methods* 形成对比，后者是指在每个原子经验后（在 TD 的情况下）或在每个轨迹经验结束时（在 MC 的情况下）更新值函数的 RL 算法。我们在本章前面实现的 MC 和 TD 预测算法是 Incremental Methods。我们将在 [Chapter 13](#chapter13.xhtml) 中详细介绍 Batch Methods。
