

# 二项期权定价模型

二项期权定价模型作为一种离散时间、有限时域、有限状态的近似方法，用于模拟该连续时间过程，本质上是我们之前针对单一基本风险资产所介绍的单期模型的扩展。我们之前学到，在单一基本风险资产的单期情况下，要构成完整市场，需要恰好有两个随机结果。我们基本上将这种“两个随机结果”的模式扩展到每个时间步的每个结果，通过生长出一棵“二叉树”来实现。但有一个注意事项——使用二叉树，在 `i` 个时间步后，我们会得到指数级（`2^i`）数量的结果。为了控制这种指数增长，我们构建一棵“重组树”，这意味着“上涨”后跟随“下跌”最终得到的基础价格结果与“下跌”后跟随“上涨”相同（如 [图 9.3](#chapter9.xhtml#fig9_3) 所示）。因此，在这棵“重组树”中，`i` 个时间步后会有 `i + 1` 个价格结果。我们将升序排列的 `i + 1` 个价格结果序列概念化为（时间步 `= i`）的状态 `S[i] = {0,1,…,i}`（因为价格波动构成一个离散时间、有限状态的马尔可夫过程）。由于我们建模的是对数正态过程，我们将离散时间价格波动建模为对价格的乘法。我们将 `S[i, j]` 表示为在状态 `j` 下经过 `i` 个时间步后的价格（对于任何 `i ∈ ℤ[≥ 0]` 和任何 `0 ≤ j ≤ i`）。因此，由 `S[i, j]` 产生的两个随机价格为 `S[i + 1, j + 1] = S[i, j] ⋅ u` 和 `S[i + 1, j] = S[i, j] ⋅ d`，其中 `u` 和 `d` 为某些常数（已校准）。重要的是，`u` 和 `d` 在时间步 `i` 之间以及每个时间步 `i` 的各个状态 `j` 之间保持不变（如 [图 9.3](#chapter9.xhtml#fig9_3) 所示）。

设 `q` 为“上涨”的概率（通常，我们使用 `p` 表示现实世界概率，使用 `q` 表示风险中性概率），因此 `1 − q` 为“下跌”的概率。就像 `u` 和 `d` 一样，`q` 的值在时间步 `i` 之间以及每个时间步 `i` 的各个状态 `j` 之间保持不变（如 [图 9.3](#chapter9.xhtml#fig9_3) 所示）。`q`、`u` 和 `d` 需要被校准，使得经过 `i` 个时间步后的对数价格比率 `{log(S_{i,0}/S_{0,0}), log(S_{i,1}/S_{0,0}), …, log(S_{i,i}/S_{0,0})}` 的概率分布（每个时间步间隔为 `T/n`，给定到期时间 `T ∈ ℝ^+` 且固定时间步数 `n ∈ ℤ^+`）能够很好地近似 `N((r - σ²/2) * iT/n, σ²iT/n)`（我们知道这是连续时间过程中 `log(S_{iT/n}/S_0)` 的风险中性概率分布，该过程由方程 (9.19) 定义，并在 [附录 C](#appC.xhtml#appC) 的 [第 C.7 节](#appC.xhtml#secC_7) 中推导），适用于所有 `i = 0, 1, …, n`。请注意，该离散时间近似过程的起始价格 `S[0, 0]` 等于连续时间过程的起始价格 `S[0]`。

对 `q`、`u` 和 `d` 的这种校准可以通过多种方式进行，并且确实存在几种二项期权定价模型的变体，它们对 `q`、`u` 和 `d` 的校准方式有不同的选择。我们将实施在 Cox、Ross、Rubinstein 的开创性论文 ([Cox, Ross, and Rubinstein 1979](#bib01.xhtml#refbib_23)) 中提出的原始二项期权定价模型所做的选择。他们的选择最好分两步来理解：

*   作为第一步，忽略对数正态过程的漂移项 `r ⋅ S[t] ⋅ dt`，并假设基础价格遵循鞅过程 `dS[t] = σ ⋅ S[t] ⋅ dz[t]`。他们选择 `d` 等于 `1/u`，并校准 `u`，使得对于任何 `i ∈ ℤ[≥ 0]`，对于任何 `0 ≤ j ≤ i`，两个等概率随机结果 `log(S_{i + 1,j + 1}/S_{i,j}) = log(u)` 和 `log(S_{i + 1,j}/S_{i,j}) = log(d) = -log(u)` 的方差等于任何 `t ≥ 0` 的正态分布随机变量 `log(S_{t + T/n}/S_t)` 的方差 `σ²T/n`（假设过程 `dS[t] = σ ⋅ S[t] ⋅ dz[t]`）。这得出：

    $$
    \begin{array}{r}
    \left. \log^{2}(u) = \frac{\sigma^{2}T}{n} \Rightarrow u = e^{\sigma\sqrt{\frac{T}{n}}} \right. \\
    \end{array}
    $$

*   作为第二步，`q` 需要被校准以考虑风险中性概率度量下对数正态过程中的漂移项 `r ⋅ S[t] ⋅ dt`。具体来说，`q` 被调整，使得对于任何 `i ∈ ℤ[≥ 0]`，对于任何 `0 ≤ j ≤ i`，两个随机结果 `S_{i + 1,j + 1}/S_{i,j} = u` 和 `S_{i + 1,j}/S_{i,j} = 1/u` 的均值等于任何 `t ≥ 0` 的对数正态分布随机变量 `S_{t + T/n}/S_t` 的均值 `e^{rT/n}`（假设过程 `dS[t] = r ⋅ S[t] ⋅ dt + σ ⋅ S[t] ⋅ dz[t]`）。这得出：

    $$
    \begin{array}{r}
    \left. qu + \frac{1 - q}{u} = e^{\frac{rT}{n}} \Rightarrow q = \frac{u \cdot e^{\frac{rT}{n}} - 1}{u^{2} - 1} = \frac{e^{\frac{rT}{n} + \sigma\sqrt{\frac{T}{n}}} - 1}{e^{2\sigma\sqrt{\frac{T}{n}}} - 1} \right. \\
    \end{array}
    $$

这种对 `u` 和 `q` 的校准确保，当 `n→∞`（即时间步间隔 `T/n → 0`）时，经过 `i` 个时间步后的二项分布的均值和方差与连续时间过程中（由方程 (9.19) 定义）正态分布随机变量 `log(S_{iT/n}/S_0)` 的均值 `(r - σ²/2) * iT/n` 和方差 `σ²iT/n` 匹配，适用于所有 `i = 0, 1, … n`。请注意，`log(S_{i,j}/S_{0,0})` 遵循一个随机游走马尔可夫过程（让人联想到 [第 3 章](#chapter3.xhtml) 中的随机游走示例），状态空间中的每个移动都按 `log(u)` 的因子缩放。

因此，我们拥有完全指定二项期权定价模型的参数 `u` 和 `q`。现在我们来看这个模型的应用。我们有兴趣使用这个模型来对美式期权进行最优行权（从而定价）。这与黑-舒尔斯偏微分方程形成对比，后者只能让我们对在固定时间点具有固定收益的期权进行定价（例如，欧式看涨期权和看跌期权）。当然，美式期权的一个特例确实是欧式期权。重要的是要注意，这里我们正在解决美式期权理想行权时机这一更难的问题——二项期权定价模型非常适合用于此。
