# 11.3.1.1 IoT Layer

The functioning of this layer involves perceiving the data from the surroundings. Such data is accessed by the user in real time or by using the cloud-based platform. Major sensor security issues are booting attacks, sleep deprivation attacks, eavesdropping and interference, node impersonation attack, flooding, and false data injection attack.

# 11.3.1.2 Network Layer

It collects the data from perception layer and transfers it to the upper layers. This layer involves data collection and transmission by various technologies such as WiFi, Sigfox, LoRa, ZigBee, NB-IoT, Bluetooth, and protocols as IPv4, IPv6, and MQTT. The major security concerns at this layer are denial of service (DoS) attacks, access attacks, routing attacks, network intrusion, and eavesdropping, etc.

# 11.3.1.3 Middleware Layer

The functioning of this layer involves a reliable and secure IoT framework. The major use of this is to process and transport the data to the application layer. The major threats at this layer include eavesdropping attacks, false data injection attacks, signature wrapping attacks, and cloud malware injection attacks.

# 11.3.1.4 Application Layer

Futuristic applications include intelligent homes, smart meters, smart parking, smart wearables, etc. Fingerprint and timing-based attacks (FATS) are the popular at this layer. The major security concerns at this layer are mutual authentication, information privacy data threats, and privacy issues.

# 11.3.2 IoT TECHNOLOGIES

As IoT connect heterogeneous applications, there have been several different technologies that provide support for long-range and short-range communication. For massive IoT connectivity, low-power area (LPWA) technologies are popular and provide area coverage, high energy efficiency, data rate, and power consumption. LPWA supports long-range connectivity using technologies such as Sigfox, LoRa, WiFi, ZigBee, and NB-IoT. Such technologies are easily accessed through 5G, with unlicensed or unused spectrum bands. 4G will not be sufficient with the tremendous growth rate in IoT by 25% annually and is expected to reach 80 billion device by 2030. 5G extensive connectivity support enhanced mobile broadband (eMBB), enhanced machine type communications (eMTC), and critical communications (URLLC). Such massive connectivity allows machine type communications (MTC) to be a smart city and smart transportation. However, the major concern is to ensure security as these applications generate diverse forms of traffic.
