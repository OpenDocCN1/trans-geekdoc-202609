## Edge Computing-Based Design for IoT Security

Computing, however, has drawbacks, including high bandwidth requirements and high expenses. Traditional cloud-based services lead to latency. This issue is particularly important in IoT where rapid response is critical.

### INTRODUCTION

IoT systems have issues due to the rising volume of data produced by IoT devices, the demand for quick processing and analysis, security concerns, and other factors. Edge computing (EC) addresses resource issues by shifting computation to the edge. EC provides data processing and storage closer to the end user, lowering the cost, bandwidth, and latency of data uploads. Implementing relevant security locally improves data privacy and prevents leakage. There has been research on EC and suggested architectures for IoT, but more complex edge-based designs are required.

### MOTIVATION

The growing adoption of IoT produces enormous amounts of data that need analysis. Traditional cloud computing faces limitations, such as bandwidth constraints and latency. EC is essential for IoT deployments because it offers real-time processing and improves data privacy.

### CONTRIBUTION

The chapter explains how the growing Internet of Things requires security solutions. It also highlights how EC enhances resource efficiency, guards against attacks, and ensures legal compliance.

### CLOUD COMPUTING

Cloud providers like Google, IBM, Microsoft, and Amazon supply robust computing, storage, and networking infrastructure through visualisation techniques. It offers a pays-as-you-go pricing structure that gives customers access to remote computing capacity and data management services at a reasonable price. However, some essential applications require extremely low latency, which cloud-based apps cannot provide. EC allows computer models to operate close to the source.
