# 17.6 CASE STUDIES

IoT has made it possible for different products and services to connect to the Internet, creating new opportunities for both businesses and people. Yet, the growth of IoT has rapidly increased the number of connected devices, raising the risk of cyberattacks [19, 20]. This section will examine how EC might improve IoT security in a case study. It is found that nowadays, various devices are connected to the Internet, which is exposed to the world without security. In IoT devices, data is generated continuously which will be transferred to servers securely. In this situation, a gateway device that serves as a bridge between IoT devices and the cloud server, processing data locally before transmitting pertinent data to minimize cyberattack risks. Its security components allow access control and encryption. This strategy provides several additional advantages, such as:

+   i. Reduce Latency: Since the processing is done locally, there is less latency, which leads to quicker reaction times.
ii. Improved Reliability: The devices will continue to operate even if the Internet connection is lost because the gateway device is in charge of processing data.
iii. Reduced Bandwidth Usage: Only pertinent information is sent to the cloud server, lowering bandwidth utilisation and costs.
