The IDS proposed in [23] utilizes the Sequential Probability Ratio Test (SPR) and a dynamically adjustable threshold to detect forwarding attacks. It is composed of two modules. The first module makes decisions at the root node. The second module operates on a routing node through random routes. Monitoring nodes deliver data to the root node. The root examines SPRT data and assigns each node a maliciousness probability. A threshold identifies malicious nodes. The root executes a DODAG global repair to isolate adversaries and alerts non-malicious nodes of their presence. The evaluation demonstrates the system's effectiveness and resource use. CoSec-RPL [24] addresses the combination of both flooding and relay attacks or "copycat attacks.\ Additionally, it identifies IDS flooding, DAO insider, and wormholes. The system uses a customized form of the Inter quantile Range (IQR) Outlier Detection (OD) method that utilizes the median rather than mean and is easier to implement. CoSec-RPL identifies nodes exhibiting abnormal behavior. CoSec-RPL is activated every time a message is received and checks the interval between messages. When measurements surpass specific criteria, the state of a node becomes "suspected.\ During this phase, contact with the node is indeed possible; if a second threshold is met, the node is judged malicious and "blocked"; no communication is allowed.
