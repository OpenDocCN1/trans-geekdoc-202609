# 8.1.1 NEED FOR NETWORK OPTIMIZATION IN MEDICAL IoT

The massive volumes of data created by medical devices and the requirement for this data to be delivered securely and effectively to healthcare professionals create the demand for network optimization in the medical IoT. Managing and configuring the network infrastructure to make it quick, dependable, and secure is known as network optimization. Making sure the network can manage the enormous amounts of data generated by medical devices and other IoT-related devices is one of the main goals of network optimization in the medical industry.
