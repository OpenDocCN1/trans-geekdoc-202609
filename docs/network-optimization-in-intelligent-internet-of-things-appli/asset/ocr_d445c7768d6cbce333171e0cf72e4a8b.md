# 18.7 CONFIGURATION

Before assembling all the hardware components in the box, firstly we need to program the NODEMCU which will be done using Arduino IDE. The step-by-step procedure to program NODEMCU is as follows:

+   a. Install, setup, and open the Arduino IDE in the system.

+   b. Initially, ESP8226 is not installed in the application. So, we need to first install it in IDE. It can be installed in our application by simply copying URL "http://arduino.esp8226.com/package/esp8226_com_in.json" in the "Additional Boards Manager URLs’s" section under the File tab and click Ok.

+   c. Install the ESP8226 package.

+   d. Click on the Packages>esp8226>2.0.0>hardware>esp8226>2.0.0>tools>sdk>Include.

+   e. In the folder, open user_interface.h with Notepad++ for copying the changes at the end.

+   f. Open esp8226_deauth-master>esp8226_deauth.ino (the program we need to flash into our device).

+   g. Connect the NODEMCU to the system using micro-USB cable.

+   h. Click on “Tools"> Board and locate the NODEMCU 0.9 (ESP-1.2 Module).

+   i. Again, click on “Tools” and select “ArduinoISP".

+   j. Upload the code to the device.

In the beginning of the code, the SS ID and password have been given which can be reset.
Now, the code has been successfully flashed to the NODEMCU and it is ready to use. In the next section, working and attacks performed by the device are mentioned.

# 18.8.1 DEAUTH ATTACK

In this, DeauthPacket function takes into input the Message Authentication Code (MAC) address of the target device and access point. It creates a deauthentication packet using the DeauthPacket function and then sends the packet using the send Packet function.

The createDeauthPacket allocates memory for the packet, sets the packet type to “deauthentication”, sets the target and access MAC addresses, and sets the reason code for the deauthentication. The sendPacket function sends the packet over the wireless interface.

The algorithm for deauth attack has been discussed in Algorithm 18.1.
