

# 物联网中的轻量级加密算法

用于紧凑型实现。在攻击与防御措施方面，讨论了主要物联网应用的安全性评估。我们还提出了一种新型架构，可为物联网通信框架提供数据机密性和身份验证。然而，随着轻量级加密（LWC）技术的增长，许多网络攻击也随之出现。此外，LWC 技术基于在未来的计算机面前是不安全的数学结构。因此，安全算法的进步以及随之增加的网络攻击为网络安全领域以及轻量级加密与认证领域的研究人员开启了大门。
