## 11.1 INTRODUCTION

The Internet of Things (IoT) is going to be an integral part of our lives in the next few years. The IoT includes heterogeneous devices that gather all the data using sensors, actuators, and gateways. IoT is envisioned to provide uninterrupted and accurate functioning of smart applications. The smart applications include automated vehicles, smart agriculture, healthcare, and surveillance systems. With the development and innovation of IoT communication, E-healthcare, automated cars, virtual reality, and Unmanned Aerial Vehicle (UAVs), security and surveillance cases become possible. IoT applications are beneficial. However, these applications are vulnerable to attacks, as an attacker can take control of automated vehicle by blocking traffic lights. Sending fraudulent messages. The open internet connectivity and physical systems increase the exposure to attacks such as data breaches, side-channel attacks, irregular/no updates of malware and ransomware, Man-in-the-Middle (MITM), and impersonation attacks. These heterogeneous IoT applications generate, process, store, and transfer huge amounts of critical data. The deployment of large-scale IoT applications is possible only when we can utilize these applications to make critical decisions. The challenging task is to ensure the confidentiality, data security, and user authenticity.

The aforementioned issues motivated our discussions to analyze security concerns, requirements, solutions, and challenges for the IoT communication framework. The classical security mechanisms which are PC-based face many challenges due to the resource-constrained nature of IoT with low memory power, limited battery, limited computational power, and real-time data access. To address these issues, lightweight cryptographic schemes need to be designed. The lightweight cryptographic schemes can be executed on IoT platforms like Radio Frequency Identification (RFID) and wireless sensor network (WSN). The lightweight schemes mainly consider small code measures, little block sizes, limited block sizes, and smaller key sizes. The major part involving the lightweight schemes is the hash function, distribution, and block cipher.

In this chapter, we provide an in-detail discussion of the security schemes of IoT architecture applications and the different technologies involved. Concerning the above-mentioned issues in this work, we reviewed lightweight algorithms for securing resource-constrained IoT. But for IoT, the major challenges are the implementation of these schemes as (1) depending on the application identifying the best cryptographic solutions, (2) implementing a symmetric key onto the device, (3) handling and distribution of secure key, and (4) ensuring mutual authentication with variety and diversity of devices. Our research helps other researchers to find the best suitable lightweight cryptographic solutions for secure IoT communication frameworks.

#### 11.3.1.1 IoT Layer

The functioning of this layer involves perceiving the data from the surroundings. Such data is accessed by the user in real time or by using the cloud-based platform. Major sensor security issues are booting attacks, sleep deprivation attacks, eavesdropping and interference, node impersonation attack, flooding, false injection attack.

#### 11.3.1.2 Network Layer

It collects the data from perception layer and transfers it to upper layers. This layer involves data collection and transmission by various technologies such as WiFi, Sigfox, LoRa, ZigBee, NB-IoT, Bluetooth, and protocols as IPv4, IPv6, and MQTT. The major security concerns at this layer are denial of service (DoS) attacks, access attacks, routing attacks, network intrusion, and eavesdropping, etc.

#### 11.3.1.3 Middleware Layer

The functioning of this layer involves a reliable and secure IoT framework. The major use of this is to process and transport the data to the application layer. The major threats at this layer include eavesdropping attacks, false injection attacks, signature wrapping attacks, and cloud malware attacks.

#### 11.3.1.4 Application Layer

Futuristic applications include intelligent homes, smart meters, smart parking, smart wearables, etc. Fingerprint and timing-based attacks (FATS) are the popular at this layer. The major security concerns at this layer are mutual authentication, information privacy data threats, and privacy issues.

## 11.3.2 IoT TECHNOLOGIES

As IoT connect heterogeneous applications, there have been several different technologies that provide support for long-range and short-range communication. For massive IoT connectivity, low-power area (LPWA) technologies are popular and provide area coverage, high energy efficiency, data rate, and power consumption. LPWA supports long-range connectivity using technologies such as Sigfox, LoRa, WiFi, ZigBee, and NB-IoT. Such technologies are easily accessed through 5G, with unlicensed or unused spectrum bands. 4G will not be sufficient with the tremendous growth rate in IoT by 25% annually and is expected to reach 80 billion device by 2030. 5G extensive connectivity support enhanced mobile broadband (eMBB), enhanced machine type communications (eMTC), and critical communications (URLLC). Such massive connectivity allows machine type communications (MTC) to be a smart city and smart transportation. However, the major concern is to ensure security as these applications generate diverse forms of traffic.
