考虑一个函数 $f(n)$，其中 $f(n)$ 的定义如下：
```
f(n) = 1，如果第 n 个程序在 n 步内停机
f(n) = 0，否则
```
现在定义另一个函数 $g(n)$，其中 $g(n)$ 的定义如下：
```
g(n) = 1 - f(n)
```
这个构造证明了 $g$ 是不可计算的。如果 $g$ 是可计算的，那么将存在一个程序 $P$ 来计算 $g$。假设 $P$ 是第 $k$ 个程序，那么 $P(k)$ 应该等于 $g(k)$。根据定义，$g(k) = 1 - f(k)$。如果 $f(k) = 0$，意味着第 $k$ 个程序在 $k$ 步内没有停机，此时 $P(k)$ 应该输出 $1$。但由于 $P$ 是第 $k$ 个程序且它在 $k$ 步内停机了，根据定义 $f(k)$ 应该是 $1$，这产生了矛盾。同理，如果 $f(k) = 1$，意味着第 $k$ 个程序在 $k$ 步内停机了，此时 $P(k)$ 应该输出 $0$，但根据定义 $g(k) = 1-1=0$，这同样产生了矛盾。因此，$g$ 不是可计算的。

对于任何命题 $\phi$，如果 $\phi$ 是可证明的，那么存在一个证明。我们可以定义一个函数 $H(\phi, n)$，当 $n$ 是 $\phi$ 的一个证明时，$H(\phi, n) = 1$，否则 $H(\phi, n) = 0$。这个函数是可计算的。

现在定义一个函数 $A(n)$，其中 $A(n)$ 的定义如下：
```
A(n) = 1，如果存在某个 m 使得 H(G(n), m) = 1
A(n) = 0，否则
```
其中 $G(n)$ 是第 $n$ 个公式的编码。如果 $A$ 是可计算的，那么存在一个程序 $P$ 来计算 $A$。假设 $P$ 是第 $k$ 个程序。现在考虑公式 $G(k)$。如果 $G(k)$ 是证明的，那么 $A(k) = 1$，那么根据定义，$P(k)$ 应该输出 $1$。如果 $G(k)$ 是不可证明的，那么 $A(k) = 0$，那么根据定义，$P(k)$ 应该输出 $0$。

然而，$G(k)$ 的含义是“第 $k$ 个程序不停机”。如果 $G(k)$ 是证明的，那么第 $k$ 个程序不停机，但 $P(k)$ 输出 $1$ 却意味着第 $k$ 个程序停机了，产生矛盾。如果 $G(k)$ 是不可证明的，那么 $A(k)=0$，$P(k)$ 输出 $0$ 意味着第 $k$ 个程序停机，这与 $G(k)$ 的含义（不停机）矛盾。因此，$G(k)$ 在系统内是不可证明的。这就是哥德尔不完备性定理在逻辑系统中的体现。

### 2. 公理系统

我们将在这里将注意力限制在两个系统上：

考虑一个公理系统。对于每一个自然数 $n$，我们定义一个命题 $\phi_n$：“第 $n$ 个程序在 $n$ 步内不停机”。这个命题是可判的。但是，考虑命题 $\Psi$：“对于所有 $n$，第 $n$ 个程序在 $n$ 步内不停机”。这个 $\Psi$ 是不可判的。

更进一步地，对于任何包含算术的公理系统，都存在一个命题 $G$，它在系统内既不能被证明，也不能被证伪。这就是哥德尔不完备性定理。

在物理学中，这意味着对于任何足够复杂的物理理论，都存在某些物理问题在该理论框架内是不可判定的。例如，我们可能无法在一个给定的物理模型中判定某个系统是否永远会达到某种特定的状态。这正是哥德尔现象在科学领域中的体现。
