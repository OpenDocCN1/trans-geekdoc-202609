## Appendix L. A wild idea: the cardinals?

We conjecture: the existence of some of those fast-growing functions is dependent on inaccessible cardinals. Recall that an inaccessible cardinal $\lambda$ satisfies:

- (1) $\lambda > \omega$.
- (2) If $\alpha$ is a cardinal and $\alpha < \lambda$, then $2^\alpha < \lambda$.
- (3) For every family $\eta_i, i \in \iota, \iota < \lambda$, and for each $i$, $\eta_i < \lambda$, then $\sup(\eta_i) < \lambda$.

$Consis(T)$ mean the (usual) sentence that asserts that the theory $T$ is consistent. $Card(\lambda)$ mean that $\lambda$ is a cardinal, and let $Inac(\lambda)$ mean that $\lambda$ is inaccessible for theory $T$. Finally, $F$ be the fast-growing, partial function that appears in the exotic formulation:

### Proposition L.1. There is $\lambda_F$ so that: $(ZFC + [F \text{ is total}]) \vdash Card(\lambda) \wedge Inac_{ZFC}(\lambda)$. Tentative sketch of proof, to be developed.

- (1) As we suppose that $Consis(ZFC + [F \text{ is total}])$ holds, then it has a model $M$.
- (2) Now, $ZFC + [F \text{ is total}] \vdash Consis(ZFC)$.
- (3) It is a theorem of ZFC that: $Consis(ZFC) \leftrightarrow \exists x[x \models ZFC]$. (We can also take this as a definition for $Consis(T)$).
- (4) Given that $ZFC + [F \text{ is total}] \vdash Consis(ZFC)$, there is a set $x \in M$ that is a model for ZFC.
- (5) Write $V_\lambda = M - x$.
- (6) Since $V_\lambda$ is nonempty and the axiom of choice holds, there are ordinals in it.
- (7) Therefore, there is at least one cardinal in $V_\lambda$.
- (8) Pick the smallest of such cardinals; note: $\lambda$: One sees that for each cardinal $\alpha \in V$, $\lambda$ is different from $2^\alpha$. Also for sequence $\eta_i$, $\lambda$ is different from $\sup \eta_i$. (Both conditions hold if not, $\lambda$ would be in $V$.)
- (9) Finally for all $\alpha \in V, \lambda > \alpha$. If not, there would be a $\beta \in V, \lambda < \beta$, and $\lambda$ would be in $V$.

This also means that $V$ is in fact a set $V$. This argument doesn't show that existence of this particular $\lambda$ proves $P < NP$; it only shows (or purports to show) that our extended theory $ZFC + [F \text{ is total}]$ implies the existence of an inaccessible cardinal. One must now show that $f^*(\aleph_0)$ can be interpreted as an inaccessible cardinal, and that it implies $P < NP$. We would then have $\lambda \leq f^*(\aleph_0)$.
