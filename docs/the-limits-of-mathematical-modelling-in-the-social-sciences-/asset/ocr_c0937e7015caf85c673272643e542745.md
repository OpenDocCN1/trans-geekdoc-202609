Let B be a sufficiently large algebra of functions and let P(x) be a nontrivial predicate. If \xi is any word in that language, we write |\xi| for its complexity, measured by the number of letters from ZFC's alphabet in \xi. We define the complexity of a proof Z_{ZFC}(\xi) of \xi in the language of ZFC to be the minimum length that a deduction of \xi from the ZFC axioms can have, as measured by the total number of letters in the expressions that belong to the proof.

Proposition 12.11. If ZFC is arithmetically sound, then:

+   1) There is an h \in B so that neither ZFC \⊄ ¬P(h) nor ZFC \⊄ P(h), but N \models P(h), where N makes ZFC arithmetically sound.
2) There is a denumerable set of functions h_m(x) \in B, m \in w, such that there is no general decision procedure to ascertain, for an arbitrary m, whether P(h_m) or ¬P(h) is provable in ZFC.
3) Given the set K = {m : ZFC \⊨ \phi(m)}, and given an arbitrary total recursive function g : \omega \to \omega, there is an infinite number of values for m so that C_{ZFC}(P(m)) > g(P(m)).

Proof. Let \theta be as above. Let f_0, g_0 satisfy our conditions on P, that is, ZFC \⊨ P(f_0) and ZFC \⊨ ¬P(g_0). Then define:

```
h(m,x) = \theta(m,x)f_0 + (1 - \theta(m,x))g_0.
```

This settles (2). Now we let \theta so that the corresponding Diophantine equation p = 0 is never solvable in the standard model for arithmetic, while that we form, for such an indicator function,

```
h = \thetaf_0 + (1 - \theta)g_0.
```

This settles (1). Finally, for (3), we notice that as K is recursively enumerable but not recursive, it satisfies the conditions in the Gödel-Ehrenfeucht-Mycielski theorem over the length of proofs.
