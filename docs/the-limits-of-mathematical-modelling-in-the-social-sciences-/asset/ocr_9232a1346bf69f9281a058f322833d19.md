# The Limits of Mathematical Modeling in the Social Sciences

Stability analysis shows that the equilibrium state $x_0, y_0, z_0 
eq 0$ is unstable. One considers the equilibria $x_0, y_0 
eq 0; z_0 = 0$ (no warrior class) or $x_0 = 0; y_0, z_0 
eq 0$ (no middle class). Condition for the survival of the middle class is

```
$\kappa(N_0 - y_0 - z_0) - \delta - ho z_0 > 0.$
```

Since $z_0$ is small, the $x$ will vanish if either the workers $y_0$ are a large-sized population or if the warriors are very aggressive $(ho \gg 0$) against the middle class $x$.

Recall that the Lotka-Volterra (LV) system,

```
$\dot{x} = -x + \alpha y$\n$\dot{y} = +y - \beta x y,$
```

which describes two interacting populations, the predators $(x)$ and preys $(y)$, can be made equivalent through a simple variable change,

```
$$u = \log x$\n$\v = \log y,$
```

which is derived from a Hamiltonian function $H$ (not made explicit here; see Nicolis and Prigogine, 1977), so that we have:

```
$\dot{u} = -\partial H/\partial v$\n$\dot{v} = +\partial H/\partial u.$
```

Moreover, since $H$ is a first integral in that system, and since the LV system has only closed orbits, we may transform it into a harmonic oscillator system through a canonical transformation:

```
$\xi = -\eta$\n$\dot{\eta} = +\xi.$
```

Those results will be our starting point.
