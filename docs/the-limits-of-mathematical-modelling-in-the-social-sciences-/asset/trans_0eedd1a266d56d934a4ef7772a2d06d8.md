## **定理 1。** 如果 $P$ 和 $Q$ 是由粒子 ' '、$\&$、$\rightarrow$ 等构成的两个等价复合连接词，那么对于任何命题 $p,q,\dots$：

$\mu(P(p,q,\dots)) = \mu(Q(p,q,\dots))$。

## **定理 2。** 在通常符号中，我们有以下模态表：

| $p$ | $p'$ | | $p$ | $q$ | $p\&q$ |
|---|---|---|---|---|--|
| $+$ | | | $+$ | $+$ | **0** |
| **0** | | | **0** | **0** | **0** |
| $-$ | $+$ | | **0** | $*$ | **0** |
| | | | | | $-$ |
| | | | | **0** | **0** 或 $-$ |

$=$ 符号 $+、$0$、$-$ 中的任意一个。

## **定理 3。** 疑定命题对最多有七类。如果 $\mu(p) = \mu(q) = \mu_0$，那么 $p\&q$、$p'\&q'$、$p'\&q$、$p'\&q'$ 的模态具有以下七个元组中的之一：

| $p\&q$ | $p'\&q'$ | $p'\&q$ | $p'\&q'$ | $p$ 和 $q$ 的关系 | 符号 |
|---|---|---|---|---|---|
| $-$ | 0 | 0 | 0 | 不兼容 | piq |
| $-$ | | 0 | 0 | 矛盾 | pcq |
| **0** | | 0 | 0 | 备选 | paq |
| **0** | | 0 | $-$ | $p$ 弱于 $q$ | pwq |
| **0** | | 0 | 0 | $p$ 强于 $q$ | psq |
| **0** | | | | 等价 | peq |
| **0** | | | 0 | 无关 | puq |

## **定理 4。** 令 $P = (p\&q')\&(p'\&q')$且 $Q = (p'\&q')\&(p\&q')$。如果命题 $p$ 和 $q$ 中恰好有一个是疑定的，则命题 $P$ 和 $Q$ 均为疑定。如果 $p$ 和 $q$ 都是疑定的，则有：

| | piq | pcq | paq | pwq | psq | puq |
|---|---|---|---|---|---|---|
| P | 0 | + | 0 | 0 | | 0 |
| Q | 0 | | 0 | 0 | + | 0 | 0 |

其中

- + piq = 交集为空但并集不是全集的集合对；
- pcq = 交集为空但并集是全集的集合对；
- paq = 交集不为空且并集是全集的集合；
- pwq = 第二个集合是第一个集合的真子；
- psq = 第一个集合是第二个集合的真子；
- peq = 相同的集合；
- pwq = 交集不为空且互不为对方子集，且并集不是全集的集合。

根据门格尔的观点，关于愿望和命令的精确理论是数学方法处理伦理问题的有效且适当的工具。

尽管马利（Mally）在该方向进行了首次尝试，引入了“lp” = $p$ 应当（Mally, 1926），但门格尔认为，马利犯了一个错误：他将系统建立在二值逻辑之上，这并不适用于愿望和命令，因为它们是疑定的。马利建立了五个公理：

- (1) $[(p \rightarrow !q)\&(q \rightarrow r)] \rightarrow (p \rightarrow !r)$；
- (2) $[(p \rightarrow !q)\(!q\&r)] \rightarrow [p \rightarrow !(q\&r)]$；
- (3) $(p \rightarrow !q) \leftrightarrow(p \rightarrow q)$
- (4) $u$；即存在命题 $u$ 使得 $!u$ 成立；
- (5) $(!v)$；即存在命题 $v$ 使得 $!v$ 成立。

从这些假设中推导出 50 个定理后，马利得出结论：
$p \leftrightarrow !p$。

因此，根据门格尔的观点，引入符号 $!$ 是多余的，因为它可以在任何公式中取消或插入。门格尔强调了用 $n$ 值逻辑代替二值逻辑的重要性，他的结论是：

- (A) 愿望（$Dp$）和命令（$Cp$）的对象既不是必要的也不是可能的。因此，命题既不被断言也不被否定：它们是疑定的。马利的错误可能在于他使用了二值逻辑。
- (B) “命令”和“愿望”这两个词彼此不同。
- (C) 日常语言中的“愿望”表述是不完全且歧义的。
- (D) 愿望理论应当考虑到经济理论的一些结果，特别是以下：
- 某些类商品对的区别，例如互补品；或可以相互替代且没有它也可以想要的商品。
- 对于每个个人，商品的组合构成了一个由偏好关系部分偏序的集合，使得偏好的缺失具有传递性；即，如果 $M$ 和 $N$ 是两种商品组合，那么要么 $N$ 优于 $M$，要么 $M$ 优于 $N$，或者两者都不优于对方。在最后一种（缺乏偏好），$I$ 对 $M$ 和 $N$ 是中立的，我们可以应用逻辑的属性。

这些说明如何应用于门格尔系统中的愿望逻辑？即使是最基本的愿望在某些方面也预设了至少正常条件；而条件的数量是有限的。
