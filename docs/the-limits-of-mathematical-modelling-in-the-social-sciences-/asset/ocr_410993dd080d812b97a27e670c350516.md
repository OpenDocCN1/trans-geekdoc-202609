# Undecidability and incompleteness

**Lemma 12.8.** There is a Diophantine set $D$ so that

```
$m \in D \Leftrightarrow \exists x_1, \dots, x_n \in \omega p(m, x_1, \dots, x_n) = 0$,
```

$p$ a Diophantine polynomial, and $D$ is recursively enumerable but not recursive.

**Corollary 12.9.** For an arbitrary $m \in \omega$ there is no general decision procedure to check whether $p(m, x_1, \dots) = 0$ has a solution in the positive integers.
