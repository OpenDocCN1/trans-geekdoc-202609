Recall that a BGS machine is a Turing machine $M_n(x)$ coupled to a clock that stops when the machine makes for $|x|^p + p$ steps, where $x$ is the binary input to the machine and $|x|$ is its length in bits; $p$ is an integer $\geq 1$. Of course, the coupled system is a Turing machine. All machines in the BGS set are poly machines, and any poly machine, there will be a corresponding machine in BGS with the same output as the original poly machine.

Again, $f_c$ is the recursive counterexample function to $P = NP$. To get it:

+   - Enumerate all BGS machines in the natural order (one can do it, as the BGS is recursive).
- For BGS machine $P_n$, $f_c(n)$ equals the first instance of SAT, which is input to $P_n$ and fails to output a satisfying line for that instance of SAT.

O'Donnell’s algorithm is very simple: we list in the natural ordering of all BGS machines. Given a particular instance $x \in$ SAT, we input it to $P_1, P_2, \dots$ up to the moment when the output is a satisfying line of truth values. When we compute the time bound to procedure, we see that it is near polynomial, that is, the whole operation is bounded by a very slow-growing exponential.
