# Appendix F. An example

As an example recall that $P < NP$ is given by a $\Pi_2$ arithmetic sentence, it is, sentence of the form “every $x$ there is an $y$ so that $P(x,y)$,” where $P(x,y)$ is primitive recursive. Given our theory $S$ with enough arithmetic in it, $S$ proves a $\Pi_2$ sentence $\xi$ if and only if the associated Skolem function $f_\xi$ is proved to be total recursive by $S$. For $P < NP$, the Skolem function is what we have been calling the counterexample function.

**Remark F.1.** However, there are infinitely counterexample functions we may make. Why is it so? For many adequate, reasonable theories $S$, we can build a recursive (computable) *scale of functions*$^{14}$ $f_0, f_1, \dots, f_k, \dots$ with an infinite set of $S$-provably total recursive functions so that $f_0$ is dominated by $f_1$ which is dominated by $f_2, \dots$, and so on.

Given each function $f_k$, we can form a BGS-like set $BGS^k$, where clocks in the time-polynomial Turing machines are bounded by a polynomial:

$|x|^{f_k(n)} + f_k(n),

where $|x|$ denotes length of the binary input $x$ to the machine. We can consider the recursive set:

$$\bigcup_{k} BGS^k$

of all such sets. Each $BGS^k$ contains representatives of all poly machines (time polynomial Turing machines). Now, what happens if there is no such an $g$, but there are functions $g_k$ which dominate each particular $f_k$, while the sequence $g_0, g_1, \dots$ is unbounded in $S$, that is, grows as the sequence $F_0, F_1, \dots$ in $S$.

$^{14}$Such a “scale of functions” exists and can be explicitly constructed.
