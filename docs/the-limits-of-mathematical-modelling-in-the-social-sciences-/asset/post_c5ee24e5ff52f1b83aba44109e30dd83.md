# **The full counterexample function, intuitive ideas**

The full counterexample function f is defined as: let $\omega$ code an enumeration of The Turing machines. Similarly code by a standard code SAT onto $\omega$:

- $n \in \omega$ isn't a poly machine, $f(n) = 0$.
- $f(n)$ = first instance $x$ of SAT so that the machine fails to output a satisfying line for $x$, plus 1, that is $f(n) = x + 1$.

Otherwise $f(n)$ is undefined, that is, if $P = NP$ holds for $n$.

$f$ will also turn out to be at least fast growing as Busy Beaver function, since in its peaks it stops all recursive functions. The idea in proof of that fact goes as follows:

- Use the $s-m-n$ theory to obtain Gödel numbers for infinite family of “quasi-trivial machines” to be defined. The table for those Turing machines involves very large numbers, and the goal is to get compact code for that value in each quasi-trivial machine so that their Gödel numbers are in sequence $c(0), c(1), c(2), \dots$, where $c$ is primitive recursive.
- Add then the required clocks in the BGS sequence of poly machines, and get Gödel numbers for pairs. We can embed the sequence into the sequence of all Turing machines.
- Notice that subsets of poly machines we dealing with (intuitive) recursive subsets of the set of all Turing machines. More precisely, if we formalize everything in $S$, then the formalized version of the sentence “the set of Gödel numbers for these quasi-trivial machines is a recursive subset of the set of all Gödel numbers for Turing machines” holds for standard model for arithmetic in $S$, and vice versa. However, $S$ may not be able to prove or disprove that assertion, that is to say, such assertions will sometimes be independent. We define counterexample functions over desired set of poly machines, and compare them to fast-growing total recursive functions over similar restrictions.

**Definition C.1.** For $f, g : \omega \rightarrow \omega$, $f \text{ dominates } g \Leftrightarrow_{\text{Def}} \ y \forall x (x > y \rightarrow f(x) \geq g(x))$. We write $f \succ g$ for $f$ dominates $g$.

# Quasi-trivial machines: intuitions

The counterexample function is highly oscillating. Since it collects counterexamples for a problem in the class $NP$, out of natural listing of poly machines, there will be cases where counterexample takes a long time to reveal itself, while the very next poly machine outputs a counterexample in the first trials. So the idea here is to construct a family of poly machines, which produce counterexamples that can be seen as part of fast-growing functions; a function which grows as fast as one wishes. So, we construct a family of poly machines that fits our purpose:

- Consider an exponential algorithm for the problem we are dealing — it will settle all instances, albeit in exponential time. Call it E.
- Build the following algorithm A:
  $A = E$ for any input up to $k$.
  $A = 0$ for all inputs $> k$.
- $A$ is a poly machine, and the value of the counterexample at (the Gödel number of) $A$ is $k+1$.
- Now make $k$ as large as one wishes. Notice that $k$ requires about $\log k$ bits to be described. As such, a value must be coded in our machine’s Gödel number, which will be very large for large $k$. However, we need a kind of controlled growth in Gödel numbers for the A-machines family. So, instead of encoding encoding $k$ as a numerical, we use it as the value of a function; we put $k=g(i)$, for a fast-growing function $g$. The $s-m-n$ theorem comes handy and ensures that the modified $A$’s Gödel numbers will always grow as a primitive recursive function, but not beyond it.

# Quasi-trivial machines: formal treatment

Recall the operation time of a Turing machine is given as follows: given that $x$ is the Turing machine’s input (in binary form) and $|x|$ is its length, if M stops over an input $x$, then then we have the following definition.

# Definition C.2. The operation over $x$

$t_M = |x| + \text{number of cycles of the machine until it stops}$.

# Example C.3.

- First trivial machine. Note it O. O inputs $x$ and stops.
  $t_0 = |x| + \text{moves to halting state} + stops$.
- Second trivial machine. Call it O'. It inputs $x$, always outputs 0 (zero) and stops. So, operation time of O has a linear bound. Again, operation time of O' has a linear bound.
- Quasi-trivial machines. A quasi-trivial machine Q operates for: for $x \le x_0$, $x_0$ a constant value, $Q = R$, $R$ an arbitrary total machine. For $x > x_0$, $Q = O$ or $O'$. This machine has also a linear bound.
