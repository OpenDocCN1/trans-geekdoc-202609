Now a weaker version of Proposition 13.6 is as follows.

**Proposition 13.8.** If $T$ is arithmetically sound, there is a polynomial expression over $Z$ $p(x_1, \dots, x_n)$ such that $\mathbf{N} \models \forall x_1, \dots, x_n \in \omega \ p(x_1, \dots, x_n) > 0$,

```
$T \not\models \forall x_1, \dots, x_n \in \omega \ p(x_1, \dots, x_n) > 0$
```

and

```
$T \not\models \exists x_1, \dots, x_n \in \omega \ p(x_1, \dots, x_n) = 0$.
```

**Proof.** If $p(m, x_1, \dots, x_n)$, $m = \tau(q, r)$, is an universal polynomial with $\tau$ being Cantor’s pairing function (see Rogers, 1967), then $\{m : \exists x_1 \dots \in \omega \ p(m, x_1, \dots) = 0\}$ is recursively enumerable but not recursive. Therefore there must be an $m_0$ such that $\forall x_1 \dots \in \omega (p(m_0, \dots))^2 > 0$.

**Proposition 13.9.** If $PA$ is consistent and $\mathbf{N} \models \text{PA}$ is standard, and if $P$ is nontrivial then there is a term-expression $\zeta \in \mathcal{L}_{\text{PA}}$ such that $\mathbf{N} \models P(\zeta)$ while $PA \not\models P(\zeta)$ and $PA \not\models \neg P(\zeta)$.

**Proof.** $\zeta = \xi + r(x_1, \dots, x_n)_v$, for $r = 1-(q+1)$, $q$ as in Proposition 13.6 (or as $p$ in Proposition 13.8).

**Remark 13.10.** Therefore, every nontrivial arithmetical $P$ in theories from formalized arithmetic turns out to be undecidable. We can generalize that result to encompass other theories $T$ that include arithmetical; see below.
