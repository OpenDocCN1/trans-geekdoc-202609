The idea in the proof of that fact goes as follows:

+   Use the $s-m-n$ theory to obtain Gödel numbers for an infinite family of “quasi-trivial machines” soon to be defined. The table for those Turing machines involves very large numbers, and the goal is to get a compact code for that value in each quasitrivial machine so that their Gödel numbers are in a sequence $c(0),c(1),c(2),\dots$, where $c$ is primitive recursive.

+   Add then the required clocks in the BGS sequence of poly machines, and get the Gödel numbers for the pairs machine + clock. We can embed the sequence we obtain into the sequence of all Turing machines.

+   Notice that the subsets of poly machines we are dealing with (intuitive) recursive subsets of the set of all Turing machines. More precisely, if we formalize everything in theory $S$, then the formalized version of the sentence “the set of Gödel numbers for these quasi-trivial Turing machines is a recursive subset of the set of Gödel numbers for Turing machines” holds for the standard model for arithmetic in $S$, and vice versa.

However, $S$ may not be able to prove or disprove that assertion, that is to say, such assertions will sometimes be formally independent of $S$.
