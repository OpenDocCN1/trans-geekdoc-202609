# **Class structures**

We consider three interacting populations where the number of individuals in each is denoted by the variables $x, y, z > 0$ (see Nicolis and Prigogine, 1977, p. 460). The dynamics of the model is given:

```
$$\dot{x} = \kappa x(N_0 - x - y - z) - \delta x - \rho xy,\n$\dot{y} = \kappa y(N_0 - x - y - z) - \delta y - f(x, y),$\n$\dot{z} = f(x, y) - \delta z$. (6)
```

Here $f(x,y) = \alpha_1z(y - \alpha_2z)$ is a Verhul term. Greek letters represent positive real constants; $N_0$ is a maximum level of resources for the competing populations. $y+z$ is to be understood as a population split between a “working class” $y$ and a (small-sized) “warrior class” $z$; $x$ is a “middle class”, which is preyed upon by the “warriors” since it competes within the same ecological niche with the coalescing “warriors” and “workers.”
