# Will the middle class survive?

Section 20, equation (6), describes a beautiful model (elaborated by Prigogine) for the interaction of three coupled populations, $x, y, z$, where $z$ is a small-sized “upper” or “warrior” class, $y$ is a “lower” or “working” class, and $x$ is a “middle class.” The model predicts two stable equilibria: in the first, the “middle class” vanishes; in the second, the “warrior” class vanishes while “workers” and the “middle class” thrive. The “middle class” will grow to a steady state value if

```
$\kappa(N_0 - y_0 - z_0) - \delta - ho^*z_0 > 0$
```

$ho$ is a measure of the aggressiveness of the “upper class” against the “middle class,” and $N_0$ measures the total value of the ecological niche; $y_0, z_0$ are constant values obtained of the system’s parameters, like $\delta$ (see Section 20).

We now write $ho^* = etaho' + (1-eta)ho'$, where $ho' \gg ho'$, and $ho'$ doesn’t satisfy the preceding condition, while $ho'$ satisfies it. Then, of

```
$\kappa(N_0 - y_0 - z_0) - \delta - ho^*z_0 > 0$
```

the sentences “The middle class will thrive” and “The middle class will fade away” are both undecidable in $T$.
