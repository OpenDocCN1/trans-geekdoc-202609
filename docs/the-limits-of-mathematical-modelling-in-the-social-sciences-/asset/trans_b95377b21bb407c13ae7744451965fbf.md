# 结构

我们考虑三个相互作用的种群，每个种群的数量由变量 $x, y, z > 0$ 表示（参见 Nicolis and Prigogine, 1977, p. 460）。该模型的动力学给出：

```
$\dot{x} = \kappa x(N_0 - y - z) - \delta x,$
$\dot{y} = \kappa y(N_0 - y - z) - \delta y,$
$\dot{z} = f(x, y) - \delta z. (6)$
```

这里 $f(x,y) = \alpha z(y - z)$ 是一项。希腊字母代表正系数；$N_0$ 是资源的最大水平。$y+z$ 被理解为在“工作类”$y$ 和（小尺寸的）“战士类”$z$ 之间，$x$ 是“中间类”，被“战士”在同一个生态位内捕食。

稳定性分析显示平衡态 $x_0, y_0, z_0 = 0$ 是不稳定的。考虑 $x_0, y_0=0; z=0$（没有战士类）或 $x_0=0; y_0=0$（没有中间类）。中间类生存的条件是：

```
$\kappa(N_0 - y_0 - z_0) - \delta > 0.$
```

由于 $z_0$ 是很小的，如果工人 $y_0$ 是大尺寸种群或者战士非常有攻击性（$z_0 \gg 0$），则 $x$ 将消失。记得 Lotka-Volterra (LV) 系统

```
$\dot{x} = -x + \alpha y,$
$\dot{y} = +y - \beta x,$
```

描述了两个相互作用的种，可以通过简单的变量替换等价：

```
$u = \log x$
$v = \log y,$
```

源自哈密顿函数 $H$（此处未显式；参见 Nicolis and Prigogine, 1977），使得有：

```
$\dot{u} = -\partial H/\partial v,$
$\dot{v} = +\partial H/\partial u.$
```

此外，由于 $H$ 是系统的的第一积分，由于 LV 系统只有闭轨道，我们可以通过正则变换将其谐振子系统：

```
$\xi = -\eta$
$\dot{\eta} = +\xi.$
```

这些结果将是我们的起点。
