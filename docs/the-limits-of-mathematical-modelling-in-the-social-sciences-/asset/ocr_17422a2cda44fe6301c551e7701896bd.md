# Undecidability and incompleteness in the theory of finite games

We start from the usual mathematical definitions in game theory.

**Definition 17.1.** A noncooperative game is given by the von Neumann triplet $\Gamma = \langle N, S_i, u_i \rangle$, with $i = 1, 2, \dots, N$, where $N$ is the number of players, $S_i$ is the strategy set of player $i$ and $u_i$ is the real-valued utility function $u_i : S_i \to R$, where each $s_i \in S_i$.

**Definition 17.2.** A strategy vector $s^* = \langle s_1^*, \dots, s_k^* \rangle \in S_k$ is a Nash equilibrium vector for a finite noncooperative game $\Gamma$ if for all strategies and $i$,

$u_i(s^*) = u_i((s_1^*, \dots, s_k^*, \dots)) \ge u_i((s_1^*, \dots, s_k, \dots)),$$

for $s_k \neq s_k^*$.

The main result goes as follows: we suppose game theory has been formalized through Suppa predicate within our theory $T$; therefore, when we talk about games in $T$, we discuss objects that can be formally proved to explicitly defined games in $T$.

# Proposition 17.3.

+   (1) Given nontrivial property $P$ of finite noncooperative games, there is an infinite denumerable family of finite games $\Gamma_m$ such that for $m$ with $T \vdash$,$P(\Gamma_m)$$\$, for an arbitrary total recursive function $g : \omega \to \omega$, there is an infinite number of values for $m$ such that the shortest length of a proof of $\Pi_m$ in $T$, $C_T(\\Pi_m) > g(|\Pi_m|)$.$$

+   (2) Given nontrivial property $P$ of finite noncooperative games, there is one of those games $\Gamma$ such that $T \vdash$,$P(\Gamma)$$\$, if and only if $T \vdash$,$Fermat's Conjecture.$

+   (3) There is a noncooperative game $\Gamma$ where each strategy set $S_i$ is finite but that we cannot compute its Nash equilibrium.

+   (4) There is a noncooperative game $\Gamma$ where each strategy set $S_i$ is finite and such that the computation of its equilibria is T-arithmetically expressible as a $\Pi_{m+1}$ problem, but not to any $\Sigma_k$ problem, $k \le m$.
