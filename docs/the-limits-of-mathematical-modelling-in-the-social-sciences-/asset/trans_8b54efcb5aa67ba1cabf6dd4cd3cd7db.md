# 第一个例子

我们在这里展示一个直接源于 $F$ 的元性质的不完备性首例。BGS 集合 $S = \langle M_m, |F^{(n)} + F(n)| \rangle, n = 0, 1, 2, \dots$ 具有以下两个属性，以及许多其他感兴趣的属性（细节请参见 *Belly* 章节）：

- 它是一个图灵机 $M_m$ 的集合，受一个时钟限制，在 $|x^{(n)} + F(n)|$ 个计算步后停止，其中 $x$ 是机器的输入，$|x|$ 是 $x$ 的二进制长度。
- 它是标准模型中的多项图灵机（poly Turing machines）集合。
- 句子“S 是图灵多项机集合”对于理论 $S$ 的算术标准模型是真的。
- “S 是图灵多项机集合”在理论 $S$ 中是不可判定的。

# 希尔伯特第六问题

物理公理的数学处理。

对几何基础的研究提出了一个问题：以相同的方式，通过公理来处理那些在其中起着重要作用的物理科学；其首位的是概率论和力学。

关于概率论的公理，我认为对其进行逻辑研究应当伴随着对数学物理中平均值方法的严谨且满意的开发，特别是在气体动力学中。

物理学家对力学基础的重要研究已在指日程：我指的是马赫（Mach）……赫尔兹（Hertz）……玻尔兹曼（Boltzmann）……以及沃尔克曼……因此，让数学家也参与力学基础的讨论是非常理想的。玻尔兹曼关于力学原理的工作暗示了数学上开发极限过程的问题，那些仅被指示的、从原子观点通向连续体定律的极限。相反，人们可以尝试通过一个基于“连续填充空间的材料上具有连续变化的条件”这一思想的公理系统，通过极限过程来推导刚体的运动定律，这些条件由参数定义。对于不同公理系统之间的等效性问题始终具有重大的理论意义。

如果几何要作为处理物理公理的模型，我们将首先尝试用少量公理包含尽可能多的可能现象，然后通过添加新公理逐步得出更特殊的理论。同时，莱（Lie）的划分原理或许可以从无限变换群的深刻理论中推导。数学家不仅必须考虑到接近现实的理论，还要像几何学那样考虑所有逻辑上可能的理论。我们必须时刻警惕，以获得从假设的公理系统中推导出的所有结论的完整调查。

# “有意义”的不可判定句

让我们引用一个特定的查询，混沌系统的判定问题（Hirsch, 1985）：

- 在几个意义上，混沌的一个例子是由著名的洛伦兹系统（Lorenz System）提供的……这是对流体力学系统的极端简化。通过计算机模拟，洛伦兹发现轨迹似乎在两个状态之间往返，以随机、不可预测的方式。起始接近的轨迹最终会发散，长期行为之间没有关系。

但这种混沌行为尚未被证明。据我所知，关于这个特定系统几乎没有理论证明。Guckenheimer 和 Williams 证明了在严格意义上确实存在许多具有这种动力学的系统；但尚未证明洛伦兹系统就是其中之一。由于缺乏答案，这对动力学家来说是一个严峻的挑战，考虑到对该系统的关注，这简直是一桩丑闻。

洛伦兹系统是（未经证实的）混沌动力学的一个例子；大多数轨迹并不趋于静态或周期轨道，且这种特征在微扰下是持续的。

# 4. 作为科学原型的物理

物理学作为一种数学科学原型的路线图中脱颖而出，更准确地说，作为一种数学科学原型的路线图，自 18 世纪以来就存在一种数学化的形式。

# 社会科学建模的局限性

物理学在其中确立的是一种变分形式。其起点是变分原理：

$$ \int_{a}^{b} Ldt = 0 $$

$$ \int_{Domain} \mathcal{L}d\sigma = 0 $$

其中 $L$ 是拉格朗日量，$\mathcal{L}$ 是拉格朗日密度。这是哈密顿原理；作用量算子 $\delta$ 作用的积分，这是一种最小作用量原理。物理系统通过最简单的路径运动。这种运动通过 $L$ 或 $\mathcal{L}$ 来衡量，让我们说，是系统在运动中可用的“自由能”。
