# Definition C.2. The operation over $x$

$t_M = |x| + number of cycles of the machine until it stops.

# Example C.3.

+   - First trivial machine. Note it O. O inputs $x$ and stops.
  $t_0 = |x| + moves to halting state + stops.
- Second trivial machine. Call it O'. It inputs $x$, always outputs 0 (zero) and stops.
  So, operation time of O has a linear bound.
  Again operation time of O' has a linear bound.
- Quasi-trivial machines. A quasi-trivial machine Q operates for: for $x \le x_0$, $x_0$ a constant value, $Q = R$, $R$ an arbitrary total machine. For $x > x_0$, $Q = O$ or $O'$.
  This machine has also a linear bound.

emark C.4. Now let H be any fast-growing, superexponential total machine. $H'$ be a Turing machine. Form the following family Q... of quasi-trivial machines with subroutines H and H'

+   (1) If $x > H(n)$, $Q^{H,H',n}(x) = H'(x)$
(2) If $x > H(n)$, $Q^{H,H',n}(x) = 0$.

Proposition C.5. There is a function $R_{g(n,|H|,|H'|)}(x) = Q^{H',n}(x)$, where $g$ is primitive recursive, and $|H|, |H'|$ denotes the Gödel number of H and $H'$.

Proof. By the composition theorem and the $s-m-n$ theorem.
