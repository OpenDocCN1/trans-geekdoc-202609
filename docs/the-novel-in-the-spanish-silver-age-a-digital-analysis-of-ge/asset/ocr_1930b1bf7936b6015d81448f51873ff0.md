The fact that subgenres as reguerarias, dialogue, modernist, or epic novel are among those that best map the clusters suggests smaller categories (subgenres with fewer texts) rather than larger ones being recognized. To test this, I run a correlation test between the ARI achieved and the number of texts that populate each subgenre (for example, there are nine dialogue novels in the analyzed corpus, and this subgenre obtains a median ARI of 0.77). The outcome of a Pearson's r test is a negative correlation (-0.41***), i.e. the fewer texts subgenre contains, the more likely it is to be represented in a cluster. This is an interesting effect that gives insight into the characteristics of the clusters that the algorithm proposes: groups with few texts. This tendency of the algorithm is similar to what literary scholars tend to do: find small subgenres with many shared features, populated with few instances. As I will show in Section 7.2.3, similar effects can be observed in the classification results.
