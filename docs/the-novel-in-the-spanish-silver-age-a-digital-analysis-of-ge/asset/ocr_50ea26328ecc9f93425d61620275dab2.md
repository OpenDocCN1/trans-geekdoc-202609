# 3.3.6 Binary Prediction of Genre of Disputed Texts

Now that the model has been trained, the next step is to apply it to the texts where there is no certainty on whether they are novels or not. The most basic way to do this is to choose the best combination of parameters and predict the genre of each text object. However, this strategy presents different shortcomings. First, the corpus is under-sampled every time, so every time the algorithm actually learning what features of the genres are from different cases; consequently, the algorithm can choose a different genre every time.
