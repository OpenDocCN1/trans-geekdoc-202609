I expect some of these combinations of features to outperform the option of the raw tokens, although probably some of them lack information (e.g. lemata and semantic annotation do not contain any grammatical information), or the split of information will create too many features correlating with each other, resulting in useless features.

For this experiment, I choose to apply logistic regression as a classifier since it is one of the best algorithms for this task (as will be shown in Section 6.1.4), it is notably fast and has been used by other researchers for similar tasks (Riddell and Schoch 2014; Underwood 2014). Every transformation presented in Chapter 4.2 has been applied in each combination of features: relative frequency, log, logio, t-idf, binary, z-scores, log10-zscores, tfidf-zscores, language-zscores and authorial-zscores.
