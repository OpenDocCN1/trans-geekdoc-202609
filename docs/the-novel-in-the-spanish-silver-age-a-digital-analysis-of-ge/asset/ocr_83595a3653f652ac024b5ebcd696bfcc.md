# 5.1.7 Consistent Labels across Sources

After analyzing how the sources classified the texts, the focus now changes to the labels themselves, and the question of which labels are assigned with a minimal consistency by several institutions is asked. This will also establish which terms are applied without any human agreement, being randomly assigned.

To observe the consistency of the labels, I calculate the Kappa-value for each label in all 15 possible combinations of sources. This gives a table with 109 columns for the semantic-labels and 15 rows for the pairwise combinations of sources. If a column contains only zeros, no pair of sources uses the label in a minimally consistent manner. In other words, there is no evidence that they were not assigned randomly. This is the case for 77 semantic-labels of all 109 labels: The different institutions treat the labels without any shared understanding on which texts should be included.
