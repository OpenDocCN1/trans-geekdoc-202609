# The Novel in the Spanish Silver Age

These annotations do not have to agree on the tokenization. Consequently, the idea of standoff markup for identifying tokens and adding annotation in other elements does not seem ideal.

I choose to encode the annotation of each tool in parallel elements as TCF would do. In contrast to this format, I retain the text of the tokens in each element. For this, I customize the TEI schema of the project, creating the element anno *orig* ('annotation') as a third option of the element choice, which normally contains *orig* ('origin') and *nrg* ('regularization') with their exact same properties. In the next example, the annotation contains a very simple paragraph in direct speech with only one sentence: “— ejemplo tú.” First, the primary text is to be found in the *orig* element. *several anno elements contain the annotation from several tools and flavors.* To keep the example short, I use the ellipsis to represent further attributes or elements:

```
<p>
<seg type="direct-speech">
<s>
<choice>
<orig>—Por ejemplo tú.</orig>
<anno source="freeling" type="tokens">
<w cligs:form="-" lemma="-\-" cligs:tag="Fg" cligs:pos="punctuation" type="hyphen"/>
<w cligs:form="Por" lemma="por" cligs:tag="SP" cligs:pos="adposition" type="preposition"/>
<w cligs:form="ejemplo" lemma="ejemplo" cligs:tag="NMSOO" cligs:pos="noun" cligs:gen="common" cligs:num="singular" cligs:wn="05820620-n"/>
<w cligs:form="tú" lemma="tú" cligs:tag="Pp2CSNo" cligs:pos="pronoun" type="personal" cligs:person="2" cligs:gen="common" cligs:num="singular" cligs:case="nominative"/>
<w cligs:form="." lemma="." cligs:tag="Fp" cligs:pos="punctuation" type="period"/>
</anno>
<anno source="freeling" type="multiwords">
<w cligs:form="-" lemma="-\-" tag="Fg" pos="ejemplo" cligs:tag="RG" cligs:pos="adverb" type="general" cligs:wn="00159040-r" cligs:wnlex="adv.all"/>
```
