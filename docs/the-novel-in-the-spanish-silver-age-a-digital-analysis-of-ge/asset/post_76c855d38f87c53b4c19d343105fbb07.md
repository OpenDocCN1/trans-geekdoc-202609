## 7.1.5 Subgenres as Linguistic and Literary Categories

Literary phenomena encoded as metadata have, until now, played a small role in the analysis of genre in Digital Literary Studies. Some researchers have added some information to the algorithms (Riddell and Schöch 2014; Underwood 2016; Wilkens 2016). The reason for not using more metadata is probably not a lack of interest, but rather the cost of encoding it relatively large corpora. Researchers use frequencies of linguistic features as an easy but efficient proxy for more complex phenomena: Exotic settings should be expressed through verbs related to boats and names about plants, animals, or food, a child protagonist should be verbalized to a certain degree with vocabulary siblings and school, etc. (Allison et al. 2011, 24; Jokers 2013, 92; Underwood 2016; Schöch 2016).

In this section, I use the metadata available in the corpus to improve the classification of subgenres. The features used for this task are linguistic features and metadata. The linguistic features are the frequencies of tokens and grammatical tags, while the metadata includes categorical, ordinal, and interval fields:

-   Categorical fields: narrator, gender and profession of the protagonist
-   Ordinal fields: size of the setting, chronological period, sociological level of the protagonist, type of ending
-   Interval fields: chronological span in days

The goals of this section are to:

1. Evaluate whether literary metadata used as features can yield higher results than linguistic features.
2. Observe whether subgenres are correctly classified with linguistic features.
3. Establish whether there is less variance in the classification when using metadata.

To process the metadata, I first convert all fields into numerical values. The ordinal fields, originally alphabetical strings, were recorded as numerical values. For example, clearly sad ends were encoded as zero (0), while clearly happy ends were encoded as four (4). The categorical fields were transformed using one-hot encoding process (VanderPlas 2016, 376), in which each value of each field becomes a new column, assigning each one or zero to text. In this step, the categorical column of the protagonist becomes three columns, one for each different: female, male and other. When a text has a male protagonist, it contains one in the male column and zeros in the female and other columns. The interval information of the chronological span of the action does not require transformation since it was originally encoded as a numerical value.

From the steps described in the previous paragraph, all metadata fields now contain only numerical values. Nevertheless, there was an extreme divergence in the ratios that would affect the results of classifiers: While many are between zero and one, others achieve values of four, and the span of the action achieved around 25,550 for novels whose actions last 70 years. To homogenize these values, a min-max transformation was applied to each column, converting all maximum values to one, and all minimum values to zero. The one-hot transformation for categorical metadata multiplies the number of columns since every category is replaced by new ones. Especially in fields without a closed list of possible values, this number explodes into hundreds of new columns, producing, in this case, 409 new data features.
