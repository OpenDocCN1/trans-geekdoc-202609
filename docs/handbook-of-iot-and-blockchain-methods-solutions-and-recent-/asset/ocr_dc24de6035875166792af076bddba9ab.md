Therefore, the hash is very useful when you want to detect changes to intersections. If the fingerprint of a block changes, it does not remain the same block.
Each block has

+   1. Data
+   2. Hash
+   3. Hash of the previous block

Consider the following example, where we have a chain of three blocks. The first block has no predecessor. Hence, it does not contain a hash of the previous block.
Block 2 contains a hash of block 1, while block 3 contains a hash of block 2.
