Let us use the term *colname* to indicate a column name, and *col* to indicate a column specification (either by name or number). The syntax of that portion of the **select** statement so far covered may be summarized in EBNF as follows. Although a column alias can be introduced immediately after a *select* item without using **as**, it is better to include **as** in such cases because it aids readability.

```
select [all | distinct] * | colname | constant [[as] column-alias] [,...]
from tablename
where condition
order by col [asc | desc] [...]
```
