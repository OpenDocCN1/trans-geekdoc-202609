FIG. 18.23 Declaring some fact types in (a) ORM and (b) OWL (Manchester syntax).

The single statement using DisjointClasses is equivalent to the lengthier approach of using DisjointWith to declare disjointness between each pair. The Domain and Range specifications restrict the predicates to the object types indicated.

Given the following statements:

+   Individual: Adam Types: Man
+   Individual: Eve Types: Woman
+   DisjointClasses: Man, Woman

we may infer:

+   Individual: Adam DifferentFrom: Eve

In Manchester syntax, the SubPropertyOf predicate may be used to declare that all (subject, object) instances of one predicate must be instances of another. Once a resource is declared, you can list all its properties in one go. For example, you could declare the fatherhood predicate along with its superproperty, domain, and range together, thus:

+   ObjectProperty: isFatherOf
+   SubPropertyOf: isaParentOf
+   Domain: MalePerson
+   Range: Person

In Manchester syntax, the DisjointWith predicate may be used to indicate that the populations of binary predicates must be mutually exclusive. This is equivalent to a pair-exclusion constraint in ORM. For example, the exclusion constraint that no person authored and reviewed the same book may be specified as follows:

+   ObjectProperty: authored
+   Domain: Person
+   Range: Book
+   ObjectProperty: reviewed
+   Domain: Person
+   Range: Book
+   DisjointWith: authored
