XML and JSON will continue to coexist for the foreseeable future because one is not a direct replacement for the other. It's tempting to caricature XML as heavyweight and JSON as lightweight solutions to data structuring outside of a data store, but this blurs some of the important features of each. It's certainly true that there is a large middle ground where either could be employed effectively, and any choice between them would be made on factors other than their data structuring capabilities.

# Chapter Notes

The SQL standard has been adopted by the International Standards Organization (ISO) as ISO/IEC 9075. Copies can be ordered from ISO or via national standards organizations such as ANSI. Because of its size (several thousand pages in total), the standard is split into several parts. Part 2 (Foundations) and Part 14 (SQL/XML) are the most relevant to this chapter.

The relevant XML standards are being progressed through the W3C. Full details, including the current versions of the standards themselves, can be found at www.w3c.org. The standards documents are not particularly easy to read, but a large amount of more readable tutorial information is available. XQuery especially is still relatively unfamiliar to many database practitioners, but it seems likely to become progressively more important in utilizing heterogeneous data. Useful introductions can be found in Walmsley (2015) and Melton and Buxton (2006).

JSON arrived as a data format later than XML, but it is now established as an essential component in data management. A short introduction to JSON can be found in Basset (2015). Because of its origins in JavaScript, its standardization falls under ECMA, the same body responsible for the specification of the JavaScript language (now sometimes referred to as ECMAScript). A comprehensive description of JavaScript is given in Flanagan (2020). Copies of standards and further details can be found at www.ecma-international.org. JavaScript and JSON are covered in standards ECMA-262 and ECMA-404, respectively. The latter has also been adopted as an ISO standard (ISO/IEC 21778). JSON Schema is still a work in progress, but the latest status can be found at www.json-schema.org. For further details on JSONPath, see Gössner and Bormann (2021).

XML and JSON functionality is now included in major relational databases but because of variations between different implementations, the vendor's documentation is often the most useful resource. Most commercial systems provide online help that can be searched in various ways.
