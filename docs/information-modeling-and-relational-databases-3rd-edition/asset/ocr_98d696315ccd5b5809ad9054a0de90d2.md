For recent coverage of SQL fundamentals as well as how to use SQL with different DBMSs such as Oracle, MySQL, PostgreSQL, and SQL Server, see Taylor (2018) and Zhao (2021). For comprehensive coverage of Oracle up to version 11 g, see Greenwald et al. (2013).

SQL Server is covered in many books, such as Syverson and Murach (2023). SQL Server Pro Magazine (formerly called “SQL Server Magazine”) is a good source of technical articles on SQL Server (www.sqlmag.com).
