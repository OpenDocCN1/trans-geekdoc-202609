Two subjects may have the same title. For each subject, we record its title and credit. Some subjects might not be studied (e.g., PY205 might be a newly approved subject to be introduced in the following year).

This schema applies to a one-semester period only, so we can ignore the possibility of a student repeating a subject. Subject enrollments are entered early in the semester, and ratings are assigned at the end of semester (so rating is optional). Formulate each of the following as a single relational algebra expression.

```
Student ( studentNr, studentName, degree, gender, birthYear )
Enrollment ( studentNr, subjCode, [rating] )
Subject ( subjCode, title, credit )
```
