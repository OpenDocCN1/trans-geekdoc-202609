In the ORM model, it is optional whether we record birthcountry, Social Security number, or passport number. This is captured in UML by appending [0..1] to the attribute name (each employee has 0 or 1 birthcountry, and 0 or 1 Social Security number). This is an example of an attribute multiplicity constraint. The main multiplicity cases are shown in Table 9.2. If the multiplicity is not declared explicitly, it is assumed to be 1 (exactly one). If desired, we may indicate the default multiplicity explicitly by appending [1..1] or [1] to the attribute."
