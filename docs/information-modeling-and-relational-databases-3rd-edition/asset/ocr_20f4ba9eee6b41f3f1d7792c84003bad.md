```
create assertion LineItem_itemCode_itemTitle_pair in_Item
check (not exists
    (select * from LineItem
    where itemCode not in
        (select itemCode from Item
    where itemTitle = LineItem.itemTitle)))
```

In most DBMSs, assertions are not supported, so this constraint would normally be coded with triggers. The subset constraint needs to be checked whenever items are deleted from or renamed (code or title) in the Item table, or inserted or renamed in the LineItem table. Because items are rarely deleted or renamed, the main overhead for the subset constraint involves validating insertions to the LineItem table. For some applications, the additional update overhead may be a price well worth paying to improve the query performance.
