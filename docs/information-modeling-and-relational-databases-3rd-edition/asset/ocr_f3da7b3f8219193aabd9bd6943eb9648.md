Derived roles may be optional. For example, if either the test or the exam role in Fig. 5.13 is optional, the total score role is also optional (but is still unique).

With large schemas, an object type may play so many roles that it is awkward to connect a single shape for the object type to all its roles. To solve this problem, object types may be duplicated on a schema. In this case, the rule to implicit mandatory disjunctive roles applies to the union of all the duplicate shapes for the object type.

Large schemas are often divided into pages, and the same object type or fact type may appear on many pages and may also be duplicated on the same page. To indicate that an object type or fact type is duplicated in the same model, either on the same page or on a different page, the NORMA tool adds a shadow to the shape.

In Fig. 5.14, the object type Date is duplicated on the same page of the model. The fact type Member has MemberName is duplicated on another page (not shown here) of the global schema diagram.

With large projects involving multiple models, there may sometimes be a need to import elements such as object type or fact type into a model from another model in which the element is defined. Currently, the NORMA tool has no graphical notation to indicate that a model element is defined externally. However, various mechanisms are currently being investigated for the NORMA tool to support management of external references as well as partitioning of a model.
