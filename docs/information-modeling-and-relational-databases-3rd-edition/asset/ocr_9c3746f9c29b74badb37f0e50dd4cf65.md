# Table 12.17 Main laws for the relational operators.

| Law | Expression 1 | Operator | Expression 2 |
|---|---|---|---|
| Commutative laws: | A ∪ B | = | B ∪ A |
| | A ∩ B | = | B ∩ A |
| Associative laws: | A ∪ (B ∪ C) | = | (A ∪ B) ∪ C |
| | A ∩ (B ∩ C) | = | (A ∩ B) ∩ C |
| | A ⋈ (B ⋈ C) | = | (A ⋈ B) ⋈ C |
| | A ⋈ (B ⋈ C) | = | (A ⋈ B) ⋈ C |
| Distributive laws: | A ∪ (B ∩ C) | = | (A ∪ B) ∩ (A ∪ C) |
| | A ∩ (B ∪ C) | = | (A ∩ B) ∪ (A ∩ C) |
| | (A ∪ B) where c | = | A where c ∪ B where c |
| | (A ∩ B) where c | = | A where c ∩ B where c |
| If A, B are compatible: | (A ∪ B) [p] | = | A [p] ∪ B [p] -- false for ∩ |
| Exportation: | A where c1 where c2 | = | A where c1 and c2 |
| Delayed Projection: | A [p] where c | = | (A where c) [p] |

SQL:1999 added user-defined types, row types, reference types, and arrays. SQL:2003 added support for multiset (bags) as a collection type, and bigint and xml data types.

SQL:2016 added support for row pattern matching, polymorphic table functions, and operations on JSON data stored in character string fields. SQL:2019 added support for multidimensional arrays (MDarray type and operators).

The SQL:2023 (https://www.iso.org/standard/76584.html) revision added many optional features (null values in unique constraints, string padding functions, etc.), deeper support for JSON, and support for property graph queries (SQL/PGQ).

The SQL select statement used for queries has the following basic syntax.

```
select [all | distinct] * | expression [[as] column-alias] [,...]
from table [[as] alias]
[. | cross join table [[as] alias]
| natural [inner | left | right | full] [outer]] join table [[as] alias]
| [inner | [left | right | full] [outer]] join table [[as] alias]
{ on condition | using (col-list) }
| union join table [[as] alias]
[,...]]
[where col-condition]
[group by colname [,...]
[having group-condition]]
[union | intersect | except ...]
[order by col [asc | desc] [,...] ]
```
