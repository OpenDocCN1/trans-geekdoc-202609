As an example with a union domain, the following declaration of the isAsOldAs predicate asserts that each Person, each Cat, and each Dog is as old as itself.

```
ObjectProperty: isAsOldAs
Domain: Person or Cat or Dog
Characteristics: Reflexive
```

A ring predicate R is irreflexive if and only if no individual can bear the relation R to itself. For example, the parenthood relation is irreflexive because nothing can be a parent of itself. OWL object property expressions are declared irreflexive by characterizing them as irreflexive properties. To do this in Manchester syntax, we declare “Irreflexive” as a characteristic. For example, the isaParentOf predicate is declared irreflexive as follows. Any assertion that someone is his/her own parent would then render the OWL ontology inconsistent.

```
Class: Person
ObjectProperty: isaParentOf
Domain: Person
Range: Person
Characteristics: Irreflexive
```

A ring predicate R is symmetric if and only if ∀x∀y(xRy → yRx); that is, for each individual x and y (not necessarily distinct), if xRy then it is also the case that yRx. For example, the siblinghood relation is symmetric because if one person is a sibling (brother or sister) of another, then the second person is a sibling of the first.

OWL object property expressions are declared symmetric by characterizing them as symmetric properties. In Manchester syntax, we declare “Symmetric” as a characteristic, for example, isaSiblingOf may be declared to be symmetric in OWL as shown below. For completeness, the irreflexive nature of the predicate is also declared.

```
Class: Person
ObjectProperty: isaSiblingOf
Domain: Person
Range: Person
Characteristics: Symmetric, Irreflexive
```
