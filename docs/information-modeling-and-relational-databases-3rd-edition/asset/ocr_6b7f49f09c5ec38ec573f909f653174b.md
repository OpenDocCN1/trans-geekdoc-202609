If a fact type is elementary, all its FDs are the result of its UCs. If another FD exists, then semantically underlying this FD is another fact type, which is the target of a pair-subset constraint from the original fact type. If this is expressed at the conceptual level, we know the original fact type is not elementary, and we should remove the relevant role (as in Fig. 14.72).

The ternary in Fig. 14.72 matches this pattern, but has an additional UC across its last two roles (for each course, a student has only one lecturer). To preserve this constraint after removing the role, an external UC must be added between the course and student roles in the new schema (see Fig. 14.73).
