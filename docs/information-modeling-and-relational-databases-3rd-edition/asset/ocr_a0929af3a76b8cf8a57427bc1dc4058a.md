Like XML, a JSON file can be described precisely with a schema. The JSON Schema specification describes the structure, constraints, and validation rules for JSON documents. JSON Schema is itself written in a JSON format. It uses JSON objects to describe the structure of the data it validates. This means that JSON Schema documents themselves can be validated. The expected properties of an object can be defined, each property with its own validation rules and data types. This includes maximum and minimum values for numeric properties, maximum and minimum and lengths for strings, regular expression patterns, and special formats such as email or URL. Array properties can be specified with data types and maximum and minimum numbers of items. JSON Schema includes many other features that we will not cover here. The specification is constantly reviewed and updated and is freely available. There are many tools available for validation of JSON against a specific schema, generating a JSON schema, generating code from a schema, and so on. As with XML Schema, we will not delve into the full details here.
