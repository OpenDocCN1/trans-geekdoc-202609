The machine has a reset button: if this is pushed before vending, money already inserted is refunded and the machine returns to its initial condition (state 0). Once sufficient money has been inserted, the machine automatically delivers the item and resets ready for the next customer. We will ignore various practical issues such as running out of gum, jamming of the mechanism, timing out if an attempt to purchase is abandoned before completion, and so on.
