We can have multiple nodes with the same Suburb label but with different names. This allows a channel to be located in multiple suburbs, and multiple channels to be located in the same suburb. Similarly, a suburb can have multiple department kinds, and the same department kind can be in multiple suburbs. Fig. 17.14 shows a small example.
