If the property does not exist, it will be created. An existing property can be deleted completely by removing it. This is equivalent to setting the relevant table cell to null in a relational database.

```
match ( c:Customer { companyName: "Tamale Spice" } )
remove c.country
```

A complete node (or set of nodes) can be deleted along with all associated properties using appropriate filter conditions.

```
match ( c:Customer )
where c.country = "Mexico"
delete c
```

This will have the effect of deleting all data for Customers located in Mexico, and of course:

```
match ( x ) delete x
```

could delete all nodes in the database, so it's important to get the filtering conditions correct.
