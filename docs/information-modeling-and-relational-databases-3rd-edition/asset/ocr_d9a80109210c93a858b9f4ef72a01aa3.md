Except for delimited (quoted) identifiers or string constants, the case (upper or lower) in which letters are written has no significance. We'll use lowercase most of the time, but start table names with a capital letter. Many organizations have their own detailed standards on the use of uppercase or lowercase.

If the chosen columns do not include a key, then duplicate rows may occur in the result. For example, the query in Fig. 12.33(a) returns a bag (multiset) rather than a set because (“M”, “Gemini”) appears twice. This operation may be called a bag projection.
