# ## Fact-oriented modeling tools

+   NORMA (ORM2 tool). https://ormsolutions.com/ or https://sourceforge.net/projects/orm. For details on installing and using NORMA, see the Resources page at www.orm.net.
+   NORMA Pro has additional features such as multipage relational schemas and formal support for derivation rules. For details, contact Matt Curland at mcurland@live.com.
+   Most of the ORM schema diagrams in this book were drawn using the Visio stencil and template available at www.orm.net/ORM2_Draw2v25.zip. These files are free, but they require the standard or professional version of Microsoft Visio to run.
+   CaseTalk (FCO-IM tool). https://www.casetalk.com.
+   iKnow tools based on CogNIAM. www.pna-group.com.
+   ActiveFacts (ORM 2 tools). http://dataconstellation.com/ActiveFacts/.
+   Boston. https://www.factengine.ai/.
