The following shows an abbreviated version of our movie data example expressed in YAML.

```
# This is a YAML document
movies:
  - movieNr: 1
    title: Cosmology
    released: '2006'
    director: Lee Lafferty
  - movieNr: 2
    title: Kung Fu Hustle
    released: '2004'
    director: Stephen Chow
    stars:
      - name: Stephen Chow
        gender: M
  - movieNr: 5
    title: The Da Vinci Code
    released: '2006'
    director: Ron Howard
    stars:
      - name: Tom Hanks
        gender: M
      - name: Ian McKellen
        gender: M
      - name: Audrey Tautou
        gender: F
...
```

YAML is a popular choice for relatively short documents where data structure needs to be explicitly represented. Two examples are configuration files containing application data and the interchange of structured messages. It is not widely used for large data collections. Its ease of use is partly due to automated decisions about the intention behind a data value, which can lead to unexpected consequences. For example, some parsers may interpret the unquoted value **No** as the Boolean value *false*, which may not have been the original intention.

The most familiar markup language is probably *HTML*, used to define the structure of web pages. Unlike XML, the tags in HTML are predefined and have specific meanings defined in the HTML standard. In the early days of web usage, HTML was also used as a rather weak method of identifying some aspects of data structure, but this was clearly unsatisfactory.
