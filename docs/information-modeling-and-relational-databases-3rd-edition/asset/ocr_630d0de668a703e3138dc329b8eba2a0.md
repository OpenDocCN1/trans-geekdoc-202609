# 16.3 JSON

JSON stands for JavaScript Object Notation, which describes its origin and function very clearly. Like XML, JSON is a text-based format that makes it very easy to interchange data between different systems. Each system can store the data in its own internal form for efficient processing, but these internal representations do not need to be the same. JSON was first defined by Douglas Crockford in the early 2000s as a format for data interchange, but it subsequently became widely adopted as a convenient way of expressing data structure and is supported in most programming languages. An early “informational” standard (Crockford, 2006) was followed by the first international standard (ECMA-404) in 2013. The syntax of JSON is very simple and is a slightly modified version of JavaScript syntax. There are two main structural elements.

+   1. Sets of key-value pairs. A colon character separates the key and the value, as in:
+   “givenName” : “Alan”,
+   “familyName” : “Turing”

The key is enclosed in double quotes. Successive items are separated by a comma character and the set is enclosed in braces. The order of items in the set is not significant. Such sets are termed “objects” from their JavaScript origins.
