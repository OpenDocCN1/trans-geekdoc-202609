As a shortcut when the minimum and maximum cardinalities are the same, the value may be assigned to the cardinality property. So, setting owl:cardinality to 0 means forbidden, and setting it to 1 means exactly one.

# # OWL Syntaxes

From now on, our discussion of OWL relates to OWL 2, Table 18.2 lists the five concrete syntaxes proposed for expressing an OWL 2 ontology in textual form. RDF/XML is the only syntax that is required to be supported by OWL 2 conformant tools, but it is awkward to read and onerous to write. OWL/XML is also designed for processing by XML tools, so it too is painful to read and write. The Functional Syntax is designed to expose the formal structure of an OWL ontology, and is readable by technical users.

For general readability purposes, the *Manchester syntax* (see https://www.w3.org/TR/ owl2-manchester-syntax) and the *Turtle* (Terse RDF Triple Language) syntax (see https:// //www.w3.org/TeamSubmission/turtle/) are far easier for non-technical people to use than the other three syntaxes. Though popular, Turtle is not a product of the OWL working group. The Manchester syntax is typically a little easier to read than Turtle syntax, and is structured in a way to facilitate specifying a large list of OWL statements in one go.

# **Table 18.2 Concrete syntaxes for OWL 2.**

| OWL Syntax | Status | Purpose |
| :--- | :--- | :--- |
| RDF/XML | Required | Interchange between tools |
| OWL/XML | Optional | Facilitate processing by XML tools |
| Manchester Syntax | Optional | Facilitate reading/writing OWL DL ontologies |
| Functional Syntax | Optional | Expose the formal structure of ontologies |
| Turtle | Optional, and unofficial | Facilitate reading/writing RDF triples |

As a simple example of all five syntaxes, the statements in Table 18.3 can be used to assert that Biden is a politician (i.e., the individual thing referenced in the current document as Biden is an instance of the class referenced in the current document as Politician) and that each politician is a person (i.e., the Politician class is a subclass of the Person class).

Overall, we consider the Manchester Syntax to be the most convenient of the five syntaxes for communicating typical ontologies to non-technical people. From now on, we’ll typically phrase the OWL examples in terms of Manchester syntax. We now discuss some basic features of OWL 2 using Manchester syntax.

Namespace prefixes may be declared as abbreviations, using a prefix command of the form Prefix: *namespacePrefix*: *IRI*. The prefixes “rdf:”, “rdfs:”, “owl:”, and “xsd:” are predefined. Each user-defined prefix used in an ontology document must have exactly one prefix declaration in the ontology document, such as Prefix: owl: Prefix: gup: https://www. galacticUni.edu/programs#. If no prefix is supplied, the current document is assumed to be the namespace.
