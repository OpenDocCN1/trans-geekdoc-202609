In step 3, we map unaries to Boolean attributes or to subclasses. The example in Fig. 9.58 assumes the usual CWA interpretation for the unary, so anyone not explicitly asserted to smoke is understood to be a nonsmoker. With an *open world approach* (OWA), failure to assert that a given person smokes means it is unknown whether that person smokes.

FIG. 9.58 Step 3: Map unaries to Boolean attributes or subclasses (CWA approach).

If we need to explicitly record that an employee is a smoker or is a nonsmoker, and this might be unknown for some employees, the UML class diagrams are modified so that the smokes attribute has a multiplicity of [0..1] and the {complete} constraint is changed to {incomplete}.

One way to model this situation in ORM is to replace the unary with the binary fact type Employee has SmokerStatus, where the first role has a uniqueness constraint but no mandatory role constraint, setting the data type of the SmokerStatus value type to Boolean. To do this in NORMA, edit the Properties sheet for the value type to Logical: True or False.

In step 4, the remaining fact types are mapped to associations. Any m:n associations should normally remain that way. In the example in Fig. 9.59, the n:1 fact type is retained as an association because it relates two entity types that become classes in the mapping. Even if the m:n association did not apply, we would normally retain Country as a class because now or later, we are likely to record details for it (e.g., country name).

If an object type in a ternary fact type should not map to a class (typically an m:n:1 uniqueness pattern with it outside the uniqueness constraint), then objectify the rest of the association as an association class, and map its role as an attribute. Objectified associations map to association classes, as shown earlier in Fig. 9.18. Some cases of coreference could be mapped into qualified associations, but mapping to separate attributes or associations supplemented by a textual composite uniqueness constraint offers a more general solution.
