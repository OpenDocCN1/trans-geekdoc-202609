Here, the resulting object for each group has a member for each item in the group. This differs from json_object, which would give a separate object for each item.

Creating an aggregating array works similarly but requires only the identification of the value to be listed. This gives an array with an element for each item in the group.

```
select empNr, json_arrayagg(projName)
from Project group by empNr
```

Result:

```
101 ["Mallard", "Grebe"]
232 ["Grebe", "Plover", "Bittern"]
```

To meet our aim of a comprehensive Agent object, the json_arrayagg constructor looks the most appropriate. This can be integrated into the larger query by nesting it within a projects member of the main object structure.

To create the required final JSON structure, the rows containing the above elements can be aggregated together to form a list of agents within an enveloping object, as shown in the following query.

```
select json_object ('Agents', json_arrayagg(
    jsonObject(
    'empNr' value nr,
    'name', json_object('given' value givenName, 'family' value familyName),
    'phone', json_array(
    json_object('work' value workPhone),
    json_object('home' value homePhone))),
    'office', case when office is not null then office else 'varies' end,
    'projects', (select json_arrayagg(projName)
    from Project p where p.empNr = a.nr group by p.empNr))))
from Agent a
```
