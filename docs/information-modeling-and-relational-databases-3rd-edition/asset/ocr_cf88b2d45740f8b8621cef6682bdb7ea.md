| Construct and Examples | Description/Notes |
| :--- | :--- |
| **Role value constraint**<br>Person(.Name) has Age(Y): {0..}<br>{0..140} | As for object type value constraints, but connected to the constrained role. Here, an age of a person must be at most 140 years. |
| **Subset constraint**<br>is cancer prone<br>enrolled in<br>Person Course Grade<br>smokes ... for ... obtained ... | The arrow points from the subset end to the superset end (e.g., if a person smokes then that person is a cancer prone).<br>The role sequences at both ends must be compatible.<br>A connection to the junction of two roles constrains that role pair. |
| **Join subset constraint**<br>speaks Language(Name) is often used in<br>Advisor.(Nr) Country.(Code)<br>serves in | The constrained role pair at the superset end is projected from a role path that involves a conceptual join on Language. The constraint declares that if an advisor serves in a country, then that advisor must speak a language that is often used in that country. |
| **Exclusion constraint**<br>is married Person authored Book<br>is widowed reviewed | These exclusion constraints mean that no person is both married and widowed, and no person reviewed and authored the same book.<br>Exclusion may apply between two or more compatible role sequences, possibly involving joins. |
| **Exclusive-or constraint**<br>is male Academic is tenured Date<br>is female is contracted till<br>Spouse<br>is a husband of / is a wife of | An exclusive-or constraint is simply the conjunction of an inclusive-or constraint and an exclusion constraint. The first two examples say that each academic is male or female but not both, and is tenured or contracted until some date but not both.<br>The third example says each spouse is a husband or wife of a spouse but not both.<br>The 1:1 nature of the fact type assumes monogamy. |
