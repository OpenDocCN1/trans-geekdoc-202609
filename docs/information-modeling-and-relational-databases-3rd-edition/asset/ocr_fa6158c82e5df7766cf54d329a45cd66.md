Assume that we need to know the names of all customers who have ordered the product “Tofu”. In the relational case, we can express this in SQL using the following query:

```
select distinct customerName from Customers
join Orders on Customers.customerId = Orders.customerId
join OrderDetails on Orders.orderId = OrderDetails.orderId
join Products on OrderDetails.productId = Products.productId
where Product.productName = "Tofu"
```

Here, the distinct keyword is used to avoid duplicates if the same customer has ordered the product more than once. The equivalent query in Neo4j can be expressed in the Cypher language as follows:

```
match ( c:Customer ) - [ :PURCHASED ] -> ( :Order ) - [ :ORDERS ] -> ( p:Product )
where p.productName = "Tofu"
return distinct c.companyName
```

In the Cypher query, the variables c and p are bound to nodes with labels Customers and Products, respectively. No bindings are required for Orders nodes or the two relationships.
