Unlike XML and XQuery, JSON has no special query language. Instead, the general features of a host programming language are used to process data. We need to bear in mind that once a JSON file is loaded it is no longer JSON, but instead is a structure that is meaningful in the context of the host language. To provide some concrete examples of extracting required data values, we can use the same queries as in the previous XML example, shown in Table 16.2. Here we will use Python to express the queries, but other languages follow a similar approach. The first step is to load the JSON file into a Python dictionary with the aid of a presupplied json library.

```
import json
# Open JSON file
theFile = open('movies.json')

# load JSON object into Python dictionary
data = json.load(theFile)
```
