De Morgan's laws, named after the famous logician Augustus De Morgan, are shown below. Here, p and q denote any proposition or logical condition.

```
not (p and q) ≡ not p or not q
not (p or q) ≡ not p and not q
```

These laws hold in both two-valued and three-valued logic, so they are safe to use with null values. Using the second of these laws, it is easy to see that the query in Fig. 12.13(c) is equivalent to the query in Fig. 12.13(a).
