Assuming appropriate translations between the predicates, the uniqueness constraint in schema (a) translates to the exclusion constraint in schema (b), and the top uniqueness constraint in (b) is implied.

The lower uniqueness constraint in (b) declares that each project has at most one supervisor. This cannot be expressed as a graphical constraint on the ternary because it is a restricted uniqueness constraint (as discussed in Section 7.4). To ensure equivalence, this is added to the left-hand schema as the textual constraint Each Project uses at most one Employee in Position 'S'.

If Project plays other functional roles, the binary approach of the right-hand schema would normally be preferred because its relational version simplifies the enforcement of this supervision constraint. If Project has no other functional roles, the ternary approach might be preferred because it maps to a single table.

Because schema transformation theorems are typically applied to subschemas within some global schema, care must be taken to preserve any mandatory role constraints (implicit or explicit).

For example, in Fig. 14.4, if Country plays no other role, then its role in schema (a) and the disjunction of its roles in (b) are implicitly mandatory. If Country plays another role in the global schema, and at least one medal result must be recorded for it, then these simple and disjunctive mandatory role (inclusive-or) constraints must be explicitly shown (see Fig. 14.11).
