# 7.1.4 Global attention

Here, the context vector $c_t$ is computed as a weighted sum of the *full list* of annotations $\tilde{h}_i$ of the source sentence (i.e., the hidden states of the encoder). There are $T_x$ annotations. Each one is a vector of size the number of units in the hidden layer of the encoder. $c_t$ has same size as any annotation. The size of the alignment vector $\alpha_t$ is equal to the size $T_x$ of the source sentence, so it is *variable*.

$c_t = \sum_{i=1}^{T_x} \alpha_{t,i} \tilde{h}_i$ (18)

The alignment vector $\alpha_t$ is computed by applying a softmax to the output of an *alignment* operation ($\textbf{score()}$) between the current target hidden state $h_t$ and all source hidden states $\tilde{h}_i$'s:

$\alpha_{t,i} = \frac{\exp(\textbf{score}(h_t, \tilde{h}_i))}{\sum_{i'=1}^{T_x} \exp(\textbf{score}(h_t, \tilde{h}_{i'}))}$ (19)

In other words, $\alpha_t$ is a probability distribution over all source hidden states (its coefficients are all between 0 and 1 and sum to 1), and indicates which words in the source sentence are the most likely to help in predicting the next word. **score()** can in theory be any comparison function. Luong et al. [20] experimented with the dot product ($\textbf{score}(h_t, \tilde{h}_i) = h_t^\top \tilde{h}_i$), a more general formulation with a matrix of parameters ($\textbf{score}(h_t, \tilde{h}_i) = h_t^\top W_a \tilde{h}_i$), and a fully connected layer. They found that *dot* works better for global attention while *general* is superior for local attention. A summary of global attention is provided in Fig. 12.
