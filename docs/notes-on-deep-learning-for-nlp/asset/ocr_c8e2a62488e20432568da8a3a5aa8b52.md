# 3 IMDB Movie review dataset

# 3.1 Overview

The task is to perform binary classification (positive/negative) on reviews from the Internet Movie Database (IMDB) dataset⁵, which is known as sentiment analysis or opinion mining. The dataset contains 50K movie reviews, labeled by polarity. The data are partitioned into 50% for training and 50% for testing. The imdb\_preprocess.py script on my GitHub cleans the reviews and put them in a format suitable to be passed to neural networks: each review is a list of word indexes (integers) from a dictionary of size V where the most frequent word has index 1.

# 3.2 Binary classification objective function

The objective function that our models will learn to minimize is the log loss, also known as the cross entropy. More precisely, in a binary classification setting with 2 classes (say 0 and 1) the log loss is defined as:

```
logloss $= -\frac{1}{N} \sum_{i=1}^{N} \left( y_i \log p_i + (1-y_i) \log(1-p_i) \right)$ (1)
```
