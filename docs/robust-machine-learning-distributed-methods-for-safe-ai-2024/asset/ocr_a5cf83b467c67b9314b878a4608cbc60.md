# Corollary 3.1

Suppose Assumptions 3.1 and 3.2. Consider T iterations of the DMGD algorithm with batch-size b ∈ [1, m). Let Δ be a real value such that 2 (ℒ(θ₁) − ℒ*) ≤ Δ, and set

γₜ = γ = min { 1/L, √(nbΔ / (σ² L T)) }, ∀ t ∈ [T].  (3.16)

Then, as soon as T ≥ nbΔ / σ², the following holds true:

1/T ∑_{t=1}^T 𝔼[‖∇ℒ(θₜ)‖²] ≤ 2 √(Δ L σ² / (n b T)).  (3.17)

# Proof

Note that by definition of γ, we have γₜ = γ ≤ 1/L for all t ∈ [T]. Thus, by Theorem 3.1, we have

1/T ∑_{t=1}^T 𝔼[‖∇ℒ(θₜ)‖²] ≤ 2(ℒ(θ₁)−ℒ*)/(T γ) + L σ²/(n b) γ.

Let us assume that T ≥ nbΔ / σ². In this case, 1/L ≥ √(nbΔ / (σ² L T)), hence γ = √(nbΔ / (σ² L T)). Plugging this γ in the above, we obtain that

1/T ∑_{t=1}^T 𝔼[‖∇ℒ(θₜ)‖²] ≤ 2√(L σ²)(ℒ(θ₁)−ℒ*)/√(Δ n b T) + √(Δ L σ² / (n b T)).

Recall that 2(ℒ(θ₁)−ℒ*) ≤ Δ. This concludes the proof.
