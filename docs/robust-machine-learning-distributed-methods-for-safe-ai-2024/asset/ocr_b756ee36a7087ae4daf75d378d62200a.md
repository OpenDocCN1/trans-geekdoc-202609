Thus, as $|H| = n - f$, due to Assumption 4.1, we have, for all $t$,

$C_t^H \le \left(\sum_{k=1}^t \beta^{t-k}\right) \sum_{k=1}^t \beta^{t-k} \frac{1}{|H|} \sum_{i\in H} \|\nabla \mathcal{L}_i(\theta_t) - \nabla \mathcal{L}_H(\theta_t)\|^2 \le \left(\sum_{k=1}^t \beta^{t-k}\right)^2 \zeta \le \frac{\zeta}{(1-\beta)^2}. \tag{6.14}$

The last inequality in the above follows from the fact that $\beta < 1$.

**Concluding Step.** Applying total expectation $\mathbb{E}[\cdot]$ on both sides in (6.9), we have

$\mathbb{E}\left[\frac{1}{|H|}\sum_{i\in H}\|\mathbf{m}_t^{(i)} - \mathbf{m}_t^H\|^2\right] \le 3(1-\beta)^2 \times \left(\mathbb{E}[A_t^H] + \mathbb{E}[B_t^H] + \mathbb{E}[C_t^H]\right).$

Substituting from (6.12), (6.13), and (6.14) in the above, we obtain that

$\mathbb{E}\left[\frac{1}{|H|}\sum_{i\in H}\|\mathbf{m}_t^{(i)} - \mathbf{m}_t^H\|^2\right] \le 3\left(\frac{1+\beta}{1-\beta}\right)\left(1+\frac{1}{n-f}\right)\frac{\sigma^2}{b} + 3\zeta.$

This concludes the proof. $\square$

*Note that $B_t^{(i)}$ is independent on $i$, but we use this notation for consistency.*
