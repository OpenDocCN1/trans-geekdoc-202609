# Theorem 3.2

Suppose Assumptions 3.1, 3.2, and 3.3. Consider an arbitrary iteration $t$ of the DMGD algorithm with batch-size $b \in [1, m)$ and learning rate $\gamma_t \le \frac{1}{L}$. Then, the following holds true:

$\mathbb{E}[\mathcal{L}(\theta_{t+1}) - \mathcal{L}^*] \le (1 - \mu \gamma_t) \mathbb{E}[\mathcal{L}(\theta_t) - \mathcal{L}^*] + \frac{L \sigma^2}{2 n b} \gamma_t^2. \quad (3.18)$

# Proof

Similar to (3.14) in the proof of Theorem 3.1, we obtain that

$\mathbb{E}[\mathcal{L}(\theta_{t+1})] \le \mathbb{E}[\mathcal{L}(\theta_t)] - \gamma_t \left(1 - \frac{L}{2} \gamma_t\right) \mathbb{E}[\|\nabla \mathcal{L}(\theta_t)\|^2] + \frac{L \sigma^2}{2 n b} \gamma_t^2.$

Let us denote $U_t := \mathbb{E}[\mathcal{L}(\theta_t) - \mathcal{L}^*]$. Then, the above is equivalently written as

$U_{t+1} \le U_t - \gamma_t \left(1 - \frac{L}{2} \gamma_t\right) \mathbb{E}[\|\nabla \mathcal{L}(\theta_t)\|^2] + \frac{L \sigma^2}{2 n b} \gamma_t^2.$

As $0 < \gamma_t \le \frac{1}{L}$, we have $1 - \frac{L}{2} \gamma_t \ge \frac{1}{2}$. Using this in the above, we obtain that

$U_{t+1} \le U_t - \frac{\gamma_t}{2} \mathbb{E}[\|\nabla \mathcal{L}(\theta_t)\|^2] + \frac{L \sigma^2}{2 n b} \gamma_t^2.$

Due to Assumption 3.3, we have $\mathbb{E}[\|\nabla \mathcal{L}(\theta_t)\|^2] \ge \mathbb{E}[2\mu (\mathcal{L}(\theta_t) - \mathcal{L}^*)] = 2\mu U_t$. Hence, from the above, we obtain that

$U_{t+1} \le (1 - \mu \gamma_t) U_t + \frac{L \sigma^2}{2 n b} \gamma_t^2.$

This concludes the proof.
