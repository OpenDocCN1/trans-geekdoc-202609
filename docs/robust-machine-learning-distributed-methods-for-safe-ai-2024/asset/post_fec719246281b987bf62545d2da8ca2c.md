
Upon substituting $A_t$ (from (4.17)) in the above, we obtain that

$$\mathbb{E}_t\left[\left\|\mathbf{g}_t^{(i)} - \mathbf{g}_t^H\right\|^2\right] \le 2\mathbb{E}_t\left[\left\|\mathbf{g}_t^{(i)} - \nabla\mathcal{L}_i(\boldsymbol{\theta}_t)\right\|^2\right] + 2\mathbb{E}_t\left[\left\|\nabla\mathcal{L}_H - \mathbf{g}_t^H\right\|^2\right]$$

$$+ \mathbb{E}_t\left[\left\|\nabla\mathcal{L}_i(\boldsymbol{\theta}_t) - \nabla\mathcal{L}_H(\boldsymbol{\theta}_t)\right\|^2\right].$$

Recall, from the proof of Theorem 3.1, that under Assumption 3.2, we have $\mathbb{E}_t\left[\left\|\mathbf{g}_t^{(i)} - \nabla\mathcal{L}_i(\boldsymbol{\theta}_t)\right\|^2\right] \le \frac{\sigma^2}{b}$. Consequently, as the honest nodes compute independently their local gradients, and $|H| = n - f$, we have $\mathbb{E}_t\left[\left\|\nabla\mathcal{L}_H - \mathbf{g}_t^H\right\|^2\right] \le \frac{\sigma^2}{(n-f)b} \le \frac{\sigma^2}{b}$. Using these observations in the above, we obtain that

$$\mathbb{E}_t\left[\left\|\mathbf{g}_t^{(i)} - \mathbf{g}_t^H\right\|^2\right] \le \frac{4\sigma^2}{b} + \mathbb{E}_t\left[\left\|\nabla\mathcal{L}_i(\boldsymbol{\theta}_t) - \nabla\mathcal{L}_H(\boldsymbol{\theta}_t)\right\|^2\right].$$

The above holds true for each node $i \in H$. Therefore,

$$\frac{\sum_{i \in H} \mathbb{E}_t\left[\left\|\mathbf{g}_t^{(i)} - \mathbf{g}_t^H\right\|^2\right]}{n - f} \le \frac{4\sigma^2}{b} + \frac{\sum_{i \in H} \mathbb{E}_t\left[\left\|\nabla\mathcal{L}_i(\boldsymbol{\theta}_t) - \nabla\mathcal{L}_H(\boldsymbol{\theta}_t)\right\|^2\right]}{n - f}.$$

Due to Assumption 4.1, $\frac{1}{n-f} \sum_{i \in H} \mathbb{E}_t\left[\left\|\nabla\mathcal{L}_i(\boldsymbol{\theta}_t) - \nabla\mathcal{L}_H(\boldsymbol{\theta}_t)\right\|^2\right] \le \zeta$. Thus, from above we obtain that

$$\frac{1}{n-f} \sum_{i \in H} \mathbb{E}_t\left[\left\|\mathbf{g}_t^{(i)} - \mathbf{g}_t^H\right\|^2\right] \le \frac{4\sigma^2}{b} + \zeta.$$

Applying the conditional expectation $\mathbb{E}_t[\cdot]$ on both sides in (4.16) and then substituting from the above concludes the proof. $\square$

The above upper bound for $\delta_t$ plays a crucial role in the following analyses on the convergence of robust DSGD. We begin by considering the case where the loss function is a non-convex function, as we did in Chap. 3. Some of the results derived for this case later prove useful, when dealing with strongly convex loss function.

## 4.4.2 Case of Non-convex Loss Function

In this section, we consider the Robust DMGD algorithm with robustness parameter f, i.e., we assume that n - f (out of n) nodes are honest. We first analyze, in Theorem 4.1, below the convergence of the algorithm to a stationary point of the average loss function for the honest nodes. Then, we will deduce the (f, epsilon)-stationary resilience property obtained at the completion of T iterations of the method, corresponding to the specific aggregation rules described in Sect. 4.1.3. Recall that, for a non-empty set S subseteq [n], L_S denotes the average loss function for S, i.e.,

L_S(theta) := 1/|S| sum_{i in S} L_i(theta).

We let L_S^* := min_{theta in R^d} L_S(theta). Recall also that E[.] denotes the total expectation over the randomness in Algorithm 5 after T iterations, i.e., E[.] = E1[ ... ET[.] ].

Theorem 4.1 Suppose Assumptions 3.1, 3.2, and 4.1. Consider T iterations of the Robust DMGD algorithm with batch-size b in [1, m) and a constant learning rate, i.e., gamma_t = gamma <= 1/(4L) for all t in [T]. If the aggregation F is an (f, kappa)-robust averaging, then, for any H subseteq [n] comprising n - f honest nodes, the following holds true:

1/T sum_{t=1}^T E[||nabla L_H(theta_t)||^2] <= 4(L_H(theta_1)-L_H^*)/(gamma T) + 4L sigma^2/((n-f)b) gamma + 3 kappa (4 sigma^2 / b + zeta).

Proof Consider an arbitrary t in [T], and an arbitrary set H subseteq [n] comprising n - f honest nodes. Similar to (3.8) in the proof of Theorem 3.1, Lipschitz smoothness of the pointwise loss function, i.e., Assumption 3.1, in conjunction with the definition of theta_{t+1} in Robust DMGD, implies that

E_t[ L_H(theta_{t+1}) ] <= L_H(theta_t) - gamma_t <nabla L_H(theta_t), E_t[hat g_t]> + L/2 gamma_t^2 E_t[||hat g_t||^2]. (4.20)

Recall, from (4.14), that

hat g_t = F( g_t^{(1)}, ..., g_t^{(n)} ) = g_t^H + delta_t. (4.21)

As $\mathbb{E}_t\left[\mathbf{g}_t^{(i)}\right] = \nabla \mathcal{L}_i(\boldsymbol{\theta}_t)$ for each honest node $i \in H$, we have $\mathbb{E}_t\left[\mathbf{g}_t^{H}\right] = \nabla \mathcal{L}_H(\boldsymbol{\theta}_t)$. Thus,

$$\mathbb{E}_t\left[\widehat{\mathbf{g}}_t\right] = \nabla \mathcal{L}_H(\boldsymbol{\theta}_t) + \mathbb{E}_t\left[\boldsymbol{\delta}_t\right]. \tag{4.22}$$

Next, using the triangle inequality in (4.21), and the fact that for real values $a_1, a_2$, we have $(a_1 + a_2)^2 \le 2a_1^2 + 2a_2^2$, we obtain that

$$\mathbb{E}_t\left[\left\|\widehat{\mathbf{g}}_t\right\|^2\right] \le 2\mathbb{E}_t\left[\left\|\mathbf{g}_t^H\right\|^2\right] + 2\mathbb{E}_t\left[\left\|\boldsymbol{\delta}_t\right\|^2\right]. \tag{4.23}$$

Substituting from (4.22) and (4.23) in (4.20), we obtain that

$$\begin{aligned}\mathbb{E}_t\left[\mathcal{L}_H(\boldsymbol{\theta}_{t+1})\right] &\le \mathcal{L}_H(\boldsymbol{\theta}_t) - \gamma_t\left\|\nabla \mathcal{L}_H(\boldsymbol{\theta}_t)\right\|^2 + L\gamma_t^2\mathbb{E}_t\left[\left\|\mathbf{g}_t^H\right\|^2\right] \\ &- \gamma_t\langle\nabla \mathcal{L}_H(\boldsymbol{\theta}_t), \mathbb{E}_t\left[\boldsymbol{\delta}_t\right]\rangle + L\gamma_t^2\mathbb{E}_t\left[\left\|\boldsymbol{\delta}_t\right\|^2\right]. \end{aligned} \tag{4.24}$$

**Upper Bound on** $\mathbb{E}_t\left[\left\|\mathbf{g}_t^H\right\|^2\right]$. Note that

$$\mathbb{E}_t\left[\left\|\mathbf{g}_t^H\right\|^2\right] = \mathbb{E}_t\left[\left\|\mathbf{g}_t^H - \nabla \mathcal{L}_H(\boldsymbol{\theta}_t)\right\|^2\right] + \left\|\nabla \mathcal{L}_H(\boldsymbol{\theta}_t)\right\|^2.$$

Recall from the proof of Lemma 4.1 above that under Assumption 3.2, $\mathbb{E}_t\left[\left\|\mathbf{g}_t^H - \nabla \mathcal{L}_H(\boldsymbol{\theta}_t)\right\|^2\right] \le \frac{\sigma^2}{(n-f)b}$. Therefore,

$$\mathbb{E}_t\left[\left\|\mathbf{g}_t^H\right\|^2\right] \le \frac{\sigma^2}{(n-f)b} + \left\|\nabla \mathcal{L}_H(\boldsymbol{\theta}_t)\right\|^2.$$

Substituting from the above in (4.24), we get

$$\begin{aligned}\mathbb{E}_t\left[\mathcal{L}_H(\boldsymbol{\theta}_{t+1})\right] &\le \mathcal{L}_H(\boldsymbol{\theta}_t) - \gamma_t(1 - L\gamma_t)\left\|\nabla \mathcal{L}_H(\boldsymbol{\theta}_t)\right\|^2 + \gamma_t^2\frac{L\sigma^2}{(n-f)b} \\ &- \gamma_t\langle\nabla \mathcal{L}_H(\boldsymbol{\theta}_t), \mathbb{E}_t\left[\boldsymbol{\delta}_t\right]\rangle + L\gamma_t^2\mathbb{E}_t\left[\left\|\boldsymbol{\delta}_t\right\|^2\right]. \end{aligned} \tag{4.25}$$

**Lower Bound on** $\langle\nabla \mathcal{L}_H(\boldsymbol{\theta}_t), \mathbb{E}_t\left[\boldsymbol{\delta}_t\right]\rangle$. Due to the Cauchy-Schwarz inequality, and the fact that for real values $a_1, a_2$ we have $2a_1a_2 \le a_1^2 + a_2^2$, we obtain

that

$$\langle \nabla \mathcal{L}_H(\theta_t),\mathbb{E}_t[\delta_t]\rangle \ge -\|\nabla \mathcal{L}_H(\theta_t)\|\,\|\mathbb{E}_t[\delta_t]\|$$
$$\ge -\frac{\|\nabla \mathcal{L}_H(\theta_t)\|^2+\|\mathbb{E}_t[\delta_t]\|^2}{2}.$$

Substituting from the above in (4.25), we get

$$\mathbb{E}_t[\mathcal{L}_H(\theta_{t+1})]\le \mathcal{L}_H(\theta_t)-\gamma_t\left(\frac{1}{2}-L\gamma_t\right)\|\nabla \mathcal{L}_H(\theta_t)\|^2+\gamma_t^2\frac{L\sigma^2}{(n-f)b}$$
$$\qquad +\frac{\gamma_t}{2}\|\mathbb{E}_t[\delta_t]\|^2+L\gamma_t^2\mathbb{E}_t\left[\|\delta_t\|^2\right].$$

Note that, due to the triangle inequality, $\|\mathbb{E}_t[\delta_t]\|\le \mathbb{E}_t[\|\delta_t\|]$. Combining this with the Jensen’s inequality, we have $\|\mathbb{E}_t[\delta_t]\|^2\le \mathbb{E}_t[\|\delta_t\|^2]$. Using this in the above, we obtain that

$$\mathbb{E}_t[\mathcal{L}_H(\theta_{t+1})]\le \mathcal{L}_H(\theta_t)-\gamma_t\left(\frac{1}{2}-L\gamma_t\right)\|\nabla \mathcal{L}_H(\theta_t)\|^2+\gamma_t^2\frac{L\sigma^2}{(n-f)b}$$
$$\qquad +\gamma_t\left(\frac{1}{2}+L\gamma_t\right)\mathbb{E}_t\left[\|\delta_t\|^2\right]. \tag{4.26}$$

From Lemma 4.1, we recall that when the aggregation $F$ is an $(f,\kappa)$-robust averaging, and Assumptions 3.2 and 4.1 hold true, $\mathbb{E}_t[\|\delta_t\|^2]\le 4\kappa\frac{\sigma^2}{b}+\kappa\zeta$. Using this in (4.26), we obtain that

$$\mathbb{E}_t[\mathcal{L}_H(\theta_{t+1})]\le \mathcal{L}_H(\theta_t)-\gamma_t\left(\frac{1}{2}-L\gamma_t\right)\|\nabla \mathcal{L}_H(\theta_t)\|^2+\gamma_t^2\frac{L\sigma^2}{(n-f)b}$$
$$\qquad +\gamma_t\left(\frac{1}{2}+L\gamma_t\right)\left(4\kappa\frac{\sigma^2}{b}+\kappa\zeta\right). \tag{4.27}$$

**Concluding Step.** Upon taking the total expectation $\mathbb{E}[\cdot]$ on both the sides in (4.27), and rearranging the terms, we obtain that

$$\left(\frac{1}{2}-L\gamma_t\right)\mathbb{E}\left[\|\nabla \mathcal{L}_H(\theta_t)\|^2\right]\le \frac{\mathbb{E}[\mathcal{L}_H(\theta_t)]-\mathbb{E}[\mathcal{L}_H(\theta_{t+1})]}{\gamma_t}$$
$$\qquad +\gamma_t\frac{L\sigma^2}{(n-f)b}+\left(\frac{1}{2}+L\gamma_t\right)\left(4\kappa\frac{\sigma^2}{b}+\kappa\zeta\right).$$
