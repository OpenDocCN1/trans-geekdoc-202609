This appendix presents the derivations for the robustness coefficients of the robust aggregation rules presented in Chap. 4. # C.1  Limitation on Robust Averaging

Considering the scalar case, i.e., assuming $d = 1$, we obtain the following necessary condition (lower bound) for $(q,\kappa)$-robust averaging. This lower bound, denoted by $\kappa_o$, on the robustness coefficient in the lemma below is tight, i.e., there exist aggregation rules (e.g., CWTM) that are indeed $(q,\kappa)$-robust for $\kappa \in O_\star(\kappa_o)$.

**Lemma C.1**  For any integer $q < n$, an aggregation rule $F : (\mathbb{R})^n \to \mathbb{R}$ is an $(q,\kappa)$-robust averaging only if $q < \frac{n}{2}$ and $\kappa \geq \frac{q}{n-2q}$.

**Proof**  The necessity for $q < n/2$ is easy to show. Also, as $\kappa \geq 0$ by definition of robust averaging, the assertion is trivially true when $q = 0$. Hereafter, we will assume that $q > 0$. We employ proof by contradiction. Let us assume that the following assertion holds true:

**Assertion A:** For $0 < q < n$ and $\kappa < \frac{q}{n-2q}$, there exists an aggregation rule $F : (\mathbb{R})^n \to \mathbb{R}$ that is $(q,\kappa)$-strong averaging.

¹ We write $\phi(a) \in O_\star(\psi(a))$ if there exists a constant $c \in \mathbb{R}^{+}$ such that $\phi(a) \leq c\psi(a)$ for all $a \in \mathbb{R}^{+}$.
