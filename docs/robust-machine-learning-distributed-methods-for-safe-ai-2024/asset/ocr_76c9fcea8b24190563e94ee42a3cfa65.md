# Corollary 3.2

Suppose Assumptions 3.1, 3.2, and 3.3. Let $T > 2$ be an even number. Consider $T$ iterations of the DMGD algorithm with batch-size $b \in [1, m)$. Set the learning rate

$\gamma_t = \begin{cases} \gamma_o & , t < T/2 \\ \dfrac{2}{\mu\big(s_o + t - T/2\big)} & , t \ge T/2 \end{cases}$ ,

where $\gamma_o$ and $s_o$ are positive real values such that $\gamma_o = \dfrac{2}{\mu s_o} < \dfrac{1}{L}$. Then,

$\mathbb{E}\big[\mathcal{L}(\theta_{T+1}) - \mathcal{L}^*\big] \le \Delta_o \dfrac{e^{-\frac{\mu \gamma_o}{2}(T-2)}}{T^2} + \dfrac{2 K_{\mathcal{L}} \gamma_o (s_o - 1)^2}{T^2} \dfrac{\sigma^2}{n b} + \dfrac{4 K_{\mathcal{L}} \sigma^2}{\mu T} \dfrac{1}{n b}$ ,

where $\Delta_o$ is a real value such that $4(s_o - 1)^2 (\mathcal{L}(\theta_1) - \mathcal{L}^*) \le \Delta_o$ and $K_{\mathcal{L}} := \dfrac{L}{\mu}$ is referred as the condition number of the loss function $\mathcal{L}$.

**Proof** As $\gamma_o < \dfrac{1}{L}$ and $\gamma_t \le \gamma_o$ for all $t$, we have $\gamma_t \le \gamma_o < \dfrac{1}{L}$ for all $t \in [T]$. Therefore, owing to Theorem 3.2, for an arbitrary $t \in [T]$, we have

$\mathbb{E}\big[\mathcal{L}(\theta_{t+1}) - \mathcal{L}^*\big] \le (1 - \mu \gamma_t) \mathbb{E}\big[\mathcal{L}(\theta_t) - \mathcal{L}^*\big] + \dfrac{L \sigma^2}{2 n b} \gamma_t^2.$

Setting $U_t := \mathbb{E}\big[\mathcal{L}(\theta_t) - \mathcal{L}^*\big]$, the above can be equivalently written as

$U_{t+1} \le (1 - \mu \gamma_t) U_t + \dfrac{L \sigma^2}{2 n b} \gamma_t^2. \tag{3.21}$

At this point, we would like to invoke Lemma 3.1 to obtain a convergence result for the sequence $(U_t)_{t \in [T+1]}$. For doing so, we need to verify that all the conditions of the lemma hold true. We choose $\alpha_1 = \mu$, $\alpha_2 = \dfrac{L \sigma^2}{2 n b}$, and $\alpha_3 = 0$. First, note that the condition for the sequence $(U_t)_{t \in [T+1]}$ in (3.21) reduces to that in Lemma 3.1. Second, since $\mu = \alpha_1$ and $\mu \le L$ when Assumptions 3.1 and 3.3 hold true simultaneously (shown in Appendix A.2), we have

$\gamma_o = \dfrac{2}{\mu s_o} = \dfrac{2}{\alpha_1 s_o} < \dfrac{1}{L} \le \dfrac{1}{\mu} = \dfrac{1}{\alpha_1}.$
