# Strongly Convex Case

We first discuss the case of strongly convex loss functions. The loss function $\mathcal{L}$ is said to be $\mu$-strongly convex if, for any $\boldsymbol{\theta}$, $\boldsymbol{\theta}' \in \mathbb{R}^d$, the following holds true.

$$\mathcal{L}(\theta') \ge \mathcal{L}(\theta) + \langle \nabla \mathcal{L}(\theta), \theta' - \theta \rangle + \frac{\mu}{2} \| \theta' - \theta \|^2 , \tag{2.11}$$

where the $\mu$, a.k.a., the *convexity parameter*, is a positive real value. Essentially, there exists a quadratic lower bound on the growth of the loss function. Note that a strongly convex function is also convex, specifically (2.11) implies the convexity condition: $\mathcal{L}(\theta') \ge \mathcal{L}(\theta) + \langle \nabla \mathcal{L}(\theta), \theta' - \theta \rangle$ for all $\boldsymbol{\theta}$, $\boldsymbol{\theta}' \in \mathbb{R}^d$. The converse, however, is not true, i.e., a convex function need not be strongly convex. Recall from the discussion in Sect. 2.2 that the convexity of $\mathcal{L}$ means that if $\boldsymbol{\theta}^*$ is a minimum of $\mathcal{L}$, then $\nabla \mathcal{L}(\theta^*) = \mathbf{0}$. This particular observation, in conjunction with (2.11), implies that function $\mathcal{L}$ has a *unique minimum point*. Specifically, if $\boldsymbol{\theta}^*$ is a minimum of $\mathcal{L}$, then $\mathcal{L}(\theta) > \mathcal{L}(\theta^*)$ for all $\theta \ne \theta^*$. An example of a strongly convex function mapping $\mathbb{R}^2$ to $\mathbb{R}$ is shown below in Fig. 2.4.

In the context of gradient-descent methods, when the loss function $\mathcal{L}$ is strongly convex, we can bound the *suboptimality gap*, i.e., the difference between the actual value of the loss function and its minimum value, by a decreasing function of the number of iterations. Specifically, given a gradient-descent method discussed above, there exists a decreasing positive function $\phi : \mathbb{R} \to \mathbb{R}$ such that upon $T$ iterations of the method, we have

$$\mathbb{E}\big[\mathcal{L}(\theta_{T+1}) - \mathcal{L}^*\big] \le \phi(T), \tag{2.12}$$
