# Notation

We use bold lowercase to denote vectors and functions with multi-dimensional outputs and standard lowercase letters to denote scalars and real-valued functions. Depending on the context, we use either a calligraphic font or uppercase letters to denote ensembles: most of the time calligraphic font, sometimes uppercase letters to denote subsets or elements of a set of sets. The cardinality of a finite set S is denoted by |S|. For a positive integer N, we denote by [N] the set {1, . . . , N}. The set of real values and d-dimensional real-valued vectors are denoted by ℝ and ℝ^d, respectively. Furthermore, we denote by ℝ^+ and ℝ_+^* the sets of non-negative and strictly positive real values, respectively. For a real value v ∈ ℝ, |v| denotes its absolute value, and ⌈v⌉ denotes the smallest integer greater than or equal to v. For a vector v ∈ ℝ^d, we denote its k-th coordinate (or element) by [v]_k for all k ∈ [d] and its transpose by v^T. The inner product of two vectors v1, v2 ∈ ℝ^d is denoted by ⟨v1, v2⟩ := v1^T v2. The Euclidean norm of a vector v ∈ ℝ^d is denoted by ‖v‖ := √⟨v, v⟩.

For a (differentiable) real-valued function L : ℝ^d → ℝ, its gradient at any point θ ∈ ℝ^d is denoted by ∇L(θ). Whenever necessary, we write ∇_θ to specify that the gradient is with respect to the argument θ. For a function φ : ℝ^+ → ℝ^+, we use O_a(·) to denote the Bachmann–Landau notation for describing the infinite behavior of φ. Specifically, we write φ(a) ∈ O_a(ψ(a)) if lim_{a→∞} φ(a)/ψ(a) < ∞. We extend O_a(·) to O_{a1,a2}(·) for describing the asymptotic behavior when both a1 and a2 approach infinity. Lastly, we use the notation O_*(·) and Ω_*(·) to describe behavior of φ up to a multiplicative constant. Specifically, we write φ(a) ∈ O_*(ψ(a)) if there exists a constant c ∈ ℝ^+ such that φ(a) ≤ c ψ(a) for all a ∈ ℝ^+, and φ(a) ∈ Ω_*(ψ(a)) if there exists constant c such that φ(a) ≥ c ψ(a) for all a ∈ ℝ^+.
