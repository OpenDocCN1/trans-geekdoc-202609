
$$+ z\kappa (1 - \beta_t)^2 \frac{\sigma^2}{b} + z(1 - \beta_t)\kappa \zeta$$
$$- \gamma_{t-1} \left( \frac{1}{2} - 2\gamma_{t-1}L \right) \mathbb{E} \left[ \|\nabla \mathcal{L}_H(\boldsymbol{\theta}_{t-1})\|^2 \right]$$
$$+ 8Lz\gamma_{t-1}\beta_t^2 \mathbb{E} \left[ \|\nabla \mathcal{L}_H(\boldsymbol{\theta}_{t-1})\|^2 \right].$$

Recall that, due to Assumption 4.2, $\|\nabla \mathcal{L}_H(\boldsymbol{\theta}_{t-1})\|^2 \geq 2\mu \left( \mathcal{L}_H(\boldsymbol{\theta}_{t-1}) - \mathcal{L}_H^* \right)$. Using this and rearranging the terms, we obtain that

$$\mathbb{E}[V_t] \leq \left( 1 - 2\mu\gamma_{t-1}\left( \frac{1}{2} - 2\gamma_{t-1}L - 8Lz\beta_t^2 \right) \right) \mathbb{E} \left[ \mathcal{L}_H(\boldsymbol{\theta}_{t-1}) - \mathcal{L}_H^* \right]$$
$$+ \left( 2\gamma_{t-1} + z(1 + 6L\gamma_{t-1})\beta_t^2 \right) \mathbb{E} \left[ \|\boldsymbol{\xi}_{t-1}\|^2 \right]$$
$$+ z(1 - \beta_t)^2 \left( \kappa + \frac{1}{n-f} \right) \frac{\sigma^2}{b}$$
$$+ \kappa \left( 2\gamma_{t-1} + z4L\beta_t^2\gamma_{t-1} + z\beta_t \right) \mathbb{E} \left[ M_{t-1}^H \right] + z\kappa(1 - \beta_t)\zeta. \quad (6.53)$$

Let us denote

$$A_t := 2\gamma_{t-1} + z(1 + 6L\gamma_{t-1})\beta_t^2, \quad \text{and} \quad B_t := 2\gamma_{t-1} + z4L\beta_t^2\gamma_{t-1} + z\beta_t.$$

Substituting from above in (6.53), we can rewrite

$$\mathbb{E}[V_t] \leq \left( 1 - 2\mu\gamma_{t-1}\left( \frac{1}{2} - 2\gamma_{t-1}L - 8Lz\beta_t^2 \right) \right) \mathbb{E} \left[ \mathcal{L}_H(\boldsymbol{\theta}_{t-1}) - \mathcal{L}_H^* \right]$$
$$+ A_t \mathbb{E} \left[ \|\boldsymbol{\xi}_{t-1}\|^2 \right] + B_t\kappa \mathbb{E} \left[ M_{t-1}^H \right] + z(1 - \beta_t)^2 \left( \kappa + \frac{1}{n-f} \right) \frac{\sigma^2}{b}$$
$$+ z(1 - \beta_t)\kappa\zeta.$$

Note that, as $z = \frac{1}{64L}$, $\beta_t \leq 1$, and $\gamma_{t-1} \leq \frac{1}{144L}$, we have

$$\frac{1}{2} - 2\gamma_{t-1}L - 8Lz\beta_t^2 \geq \frac{1}{2} - 2\gamma_{t-1}L - \frac{1}{8} \geq \frac{1}{8}.$$

Therefore, from the above, we obtain that

$$\mathbb{E}[V_t] \le \left(1 - \frac{\mu}{4}\gamma_{t-1}\right)\mathbb{E}[\mathcal{L}_H(\theta_{t-1}) - \mathcal{L}_H^*] + A_t\mathbb{E}[\|\xi_{t-1}\|^2] + B_t\kappa\mathbb{E}[M_{t-1}^H] + z(1 - \beta_t)^2\left(\kappa + \frac{1}{n - f}\right)\frac{\sigma^2}{b} + z\kappa(1 - \beta_t)\zeta. \quad (6.54)$$

### Upper Bound on $A_t$

Recall that $A_t := 2\gamma_{t-1} + z(1 + 6L\gamma_{t-1})\beta_t^2$. Substituting $z = \frac{1}{64L}$, we obtain that $A_t = z\left(128L\gamma_{t-1} + (1 + 6L\gamma_{t-1})\beta_t^2\right) = z\left(128L\gamma_{t-1} + \beta_t^2 + 6L\gamma_{t-1}\beta_t^2\right)$. As $\beta_t \le 1$, we have $\beta_t^2 \le \beta_t$ and $6L\gamma_{t-1}\beta_t^2 \le 6L\gamma_{t-1}$. Using these above, we obtain that $A_t \le z\left(134L\gamma_{t-1} + \beta_t\right)$. Upon substituting $\beta_t = 1 - 144L\gamma_{t-1}$ and using the fact that when Lipschitz smoothness (i.e., Assumption 3.1) and strong convexity (i.e., Assumption 4.2) satisfy simultaneously, we have $L \ge \mu$ (see Appendix A.2), and we obtain that

$$A_t \le z\left(1 - 10L\gamma_{t-1}\right) \le z\left(1 - 10\mu\gamma_{t-1}\right) \le z\left(1 - \frac{\mu}{4}\gamma_{t-1}\right). \quad (6.55)$$

### Upper Bound on $B_t$

Recall that $B_t := 2\gamma_{t-1} + z4L\beta_t^2\gamma_{t-1} + z\beta_t$. Similarly to $A_t$ above, we obtain that

$$B_t \le z\left(132L\gamma_{t-1} + \beta_t\right) = z\left(1 - 12L\gamma_{t-1}\right) \le z\left(1 - \frac{\mu}{4}\gamma_{t-1}\right). \quad (6.56)$$

Substituting from (6.55) and (6.56) in (6.54), we obtain that

$$\mathbb{E}\left[V_t\right] \le \left(1-\frac{\mu}{4}\gamma_{t-1}\right)\left(\mathbb{E}\left[\mathcal{L}_H\left(\boldsymbol{\theta}_{t-1}\right)-\mathcal{L}_H^*\right] + z\mathbb{E}\left[\left\|\boldsymbol{\xi}_{t-1}\right\|^2\right] + \kappa z\mathbb{E}\left[M_{t-1}^H\right]\right) + z\left(1-\beta_t\right)^2\left(\kappa+\frac{1}{n-f}\right)\frac{\sigma^2}{b} + z\left(1-\beta_t\right)\kappa\zeta.$$

Recall that, by definition of $V_t$ in (6.49), $\mathbb{E}\left[\mathcal{L}_H\left(\boldsymbol{\theta}_{t-1}\right)-\mathcal{L}_H^*\right] + z\mathbb{E}\left[\left\|\boldsymbol{\xi}_{t-1}\right\|^2\right] + \kappa z\mathbb{E}\left[M_{t-1}^H\right] = \mathbb{E}\left[V_{t-1}\right]$. Therefore, the above can be written as

$$\mathbb{E}\left[V_t\right] \le \left(1-\frac{\mu}{4}\gamma_{t-1}\right)\mathbb{E}\left[V_{t-1}\right] + z\left(1-\beta_t\right)^2\left(\kappa+\frac{1}{n-f}\right)\frac{\sigma^2}{b} + z\left(1-\beta_t\right)\kappa\zeta.$$

Substituting $\beta_t = 1-144L\gamma_{t-1}$ and $z = \frac{1}{64L}$ in the above concludes the proof. $\square$

## Convergence Result

Note that the growth of the sequence $(\mathbb{E}\left[V_t\right])_{t \in [T+1]}$ presented in Theorem 6.2 corresponds to that of $(U_t)_{t \in [T+1]}$ in Lemma 3.1 with $U_t := \mathbb{E}\left[V_t\right]$ and $\alpha_1, \alpha_2, \alpha_3$ set as follows:

$$\alpha_1 := \frac{\mu}{4}, \alpha_2 := 324L\left(\kappa+\frac{1}{n-f}\right)\frac{\sigma^2}{b} \text{ and } \alpha_3 := \frac{9}{4}\kappa\zeta. \qquad (6.57)$$

Upon observing that $\mathcal{L}_H\left(\boldsymbol{\theta}_t\right)-\mathcal{L}_H^* \le V_t$ for each iteration $t$, owing to Theorem 6.2 above, we can thus obtain the sublinear convergence of Algorithm 6 in the strongly convex case similar to that of Algorithm 5. Essentially, upon combining the result of Theorem 6.2 with that of Lemma 3.1, we obtain the following corollary. For simplicity, we will state the corollary in terms of parameters $\alpha_2$ and $\alpha_3$ defined above in (6.57).

**Corollary 6.2** *Suppose Assumptions 3.1, 3.2, 4.1, and 4.2. Let $T$ be an even integer greater than 2. Consider $T$ iterations of Algorithm 6 with batch-size $b \in [1, m]$, an $(f, \kappa)$-robust aggregation rule $F$, a sequence of learning rates $(\gamma_t)_{t \in [T]}$ defined by*

$$\gamma_t = \begin{cases} \gamma_o & , \ t < T/2 \\ \frac{8}{\mu(s_o+t-\frac{T}{2})} & , \ t \ge T/2 \end{cases}, \qquad (6.58)$$

*where $\gamma_o$ and $s_o$ are positive real values such that $\gamma_o = \frac{8}{\mu s_o} \le \frac{1}{144L}$, and a sequence of momentum coefficients $(\beta_t)_{t\in[T]}$ defined by (6.47) with $c = 144L$. Then, the following holds true:*

$$\mathbb{E} \left[ \mathcal{L}_H (\theta_{T+1}) - \mathcal{L}_H^{\star} \right] \le \frac{\Delta_o e^{-\frac{\mu}{8}\gamma_o (T-2)}}{T^2} + \frac{16(\alpha_2 \gamma_o + \alpha_3)(s_o - 1)^2}{\mu T^2}$$
$$+ \frac{128\alpha_2}{\mu^2 T} + \frac{8\alpha_3}{\mu},$$

*where $\Delta_o$ is a positive real value such that*

$$4(s_o - 1)^2 \left( \mathcal{L}_H(\theta_1) - \mathcal{L}_H^{\star} + \frac{1}{64L} \left( \left( \kappa + \frac{1}{n-f} \right) \frac{\sigma^2}{b} + \kappa \zeta \right) \right) \le \Delta_o,$$

*and constants $\alpha_2, \alpha_3$ are defined in (6.57).*

*Proof* Similarly to Corollary 3.2 and Theorem 4.2, we make use of Lemma 3.1 presented in Chap. 3. First, consider the sequence of learning rates $(\gamma_t)_{t\in[T]}$ defined in (6.58). As $\mu \le L$ when Assumptions 3.1 and 4.2 hold true simultaneously, we have $\frac{1}{144L} \le \frac{1}{\mu} \le \frac{4}{\mu}$. This implies that setting $\alpha_1 := \frac{\mu}{4}$, we have

$$\gamma_o = \frac{8}{\mu s_o} = \frac{2}{\alpha_1 s_o} \le \frac{1}{144L} \le \frac{4}{\mu} = \frac{1}{\alpha_1}.$$

From the above, we note that the sequence $(\gamma_t)_{t\in[T]}$ satisfies the condition stated in Lemma 3.1.

Second, recall from Theorem 6.2 that for $t \in [T]$, we have

$$\mathbb{E} \left[ V_t \right] \le \left( 1 - \frac{\mu}{4} \gamma_{t-1} \right) \mathbb{E} \left[ V_{t-1} \right]$$
$$+ 324L \left( \kappa + \frac{1}{n-f} \right) \frac{\sigma^2}{b} \gamma_{t-1}^2 + \frac{9}{4} \kappa \zeta \gamma_{t-1}.$$

Similar to Theorem 6.1, note that the above is true even for $t = T + 1$, once we apply the definitions of local stochastic gradients and the corresponding momentum vectors in Algorithm 6 also to $t = T + 1$. Let us denote $U_t := \mathbb{E} \left[ V_t \right]$. The above implies that, for all $t \in [T]$,

$$U_{t+1} \le \left( 1 - \frac{\mu}{4} \gamma_t \right) U_t + 324L \left( \kappa + \frac{1}{n-f} \right) \frac{\sigma^2}{b} \gamma_t^2 + \frac{9}{4} \kappa \zeta \gamma_t.$$
