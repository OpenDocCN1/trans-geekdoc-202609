# C.4 Geometric Median

The *geometric median* of **v**₁, …, **v**ₙ ∈ ℝᵈ, denoted by GeoMed, is defined to be a vector that minimizes the sum of the Euclidean distances to these vectors. Specifically,

GeoMed(**v**₁, …, **v**ₙ) ∈ argmin_{**y**∈ℝᵈ} ∑_{i=1}^n ‖**y** − **v**ᵢ‖.

**Proposition C.3** *Let n ∈ ℕ* and q < n/2. Geometric median is (q, κ)-robust with κ = 4 (1 + q/(n−2q))².*

*Proof* Let us denote by **v*** := GeoMed(**v**₁, …, **v**ₙ) the geometric median of the input vectors. Consider any subset S ⊆ [n] of size |S| = n − q. Due to the triangle inequality, for all i ∈ S, we have

‖**v*** − **v**ᵢ‖ ≥ ‖**v*** − **\bar{v}**ₛ‖ − ‖**v**ᵢ − **\bar{v}**ₛ‖. (C.10)

Similarly, for any i ∈ [n] \ S, we obtain

‖**v*** − **v**ᵢ‖ ≥ ‖**v**ᵢ − **\bar{v}**ₛ‖ − ‖**v*** − **\bar{v}**ₛ‖. (C.11)

Summing up (C.10) and (C.11) over all input vectors, we obtain

∑_{i∈[n]} ‖**v*** − **v**ᵢ‖ ≥ (n − 2q) ‖**v*** − **\bar{v}**ₛ‖ + ∑_{i∈[n]\S} ‖**v**ᵢ − **\bar{v}**ₛ‖ − ∑_{i∈S} ‖**v**ᵢ − **\bar{v}**ₛ‖.
