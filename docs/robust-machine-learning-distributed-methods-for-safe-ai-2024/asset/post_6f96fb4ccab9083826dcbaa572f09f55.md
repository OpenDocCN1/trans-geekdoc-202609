
Note that we can rewrite the above as

$$\mathbb{E}_t\Big[\big\|\mathbf{m}_t^{(i)} - \mathbf{m}_t^{(j)}\big\|^2\Big] \le \beta_t \big\|\mathbf{m}_{t-1}^{(i)} - \mathbf{m}_{t-1}^{(j)}\big\|^2 + (1 - \beta_t)\big\|\nabla\mathcal{L}_i(\boldsymbol{\theta}_t) - \nabla\mathcal{L}_j(\boldsymbol{\theta}_t)\big\|^2 + 2(1 - \beta_t)^2\frac{\sigma^2}{b}. $$

Applying Jensen’s inequality, from the above, we obtain that

$$\mathbb{E}_t\Big[\big\|\mathbf{m}_t^{(i)} - \mathbf{m}_t^{(j)}\big\|^2\Big] \le \beta_t \big\|\mathbf{m}_{t-1}^{(i)} - \mathbf{m}_{t-1}^{(j)}\big\|^2 + (1 - \beta_t)\big\|\nabla\mathcal{L}_i(\boldsymbol{\theta}_t) - \nabla\mathcal{L}_j(\boldsymbol{\theta}_t)\big\|^2 + 2(1 - \beta_t)^2\frac{\sigma^2}{b}. $$

Taking the total expectation $\mathbb{E}[\cdot]$ on both sides, we have

$$\mathbb{E}\Big[\big\|\mathbf{m}_t^{(i)} - \mathbf{m}_t^{(j)}\big\|^2\Big] \le \beta_t \mathbb{E}\Big[\big\|\mathbf{m}_{t-1}^{(i)} - \mathbf{m}_{t-1}^{(j)}\big\|^2\Big] + (1 - \beta_t)\mathbb{E}\Big[\big\|\nabla\mathcal{L}_i(\boldsymbol{\theta}_t) - \nabla\mathcal{L}_j(\boldsymbol{\theta}_t)\big\|^2\Big] + 2(1 - \beta_t)^2\frac{\sigma^2}{b}. $$

Recall that $i$ and $j$ in the above are chosen arbitrarily from $H$. Therefore, by taking the average on both sides over all the pairs $(i, j) \in H$, we obtain that

$$\frac{1}{|H|^2}\sum_{i,j\in H}\mathbb{E}\Big[\big\|\mathbf{m}_t^{(i)} - \mathbf{m}_t^{(j)}\big\|^2\Big] \le \beta_t\frac{1}{|H|^2}\sum_{i,j\in H}\mathbb{E}\Big[\big\|\mathbf{m}_{t-1}^{(i)} - \mathbf{m}_{t-1}^{(j)}\big\|^2\Big] + (1 - \beta_t)\frac{1}{|H|^2}\sum_{i,j\in H}\mathbb{E}\Big[\big\|\nabla\mathcal{L}_i(\boldsymbol{\theta}_t) - \nabla\mathcal{L}_j(\boldsymbol{\theta}_t)\big\|^2\Big] + 2(1 - \beta_t)^2\frac{\sigma^2}{b}. $$

Recall, from Remark 4.5, that for a set of $m$ vectors $\mathbf{v}_1,\dots,\mathbf{v}_m$, we have $\sum_{i,j\in[m]}\|\mathbf{v}_i - \mathbf{v}_j\|^2 = 2m\sum_{i\in[m]}\Big\|\mathbf{v}_i - \frac{1}{m}\sum_{j\in[m]}\mathbf{v}_j\Big\|^2$. Using this in the

above, we obtain that

$$\frac{1}{|H|}\sum_{i\in H}\mathbb{E}\left[\|\mathbf{m}_t^{(i)} - \mathbf{m}_t^{H}\|^2\right] \le \beta_t \frac{1}{|H|}\sum_{i,j\in H}\mathbb{E}\left[\|\mathbf{m}_{t-1}^{(i)} - \mathbf{m}_{t-1}^{H}\|^2\right]$$

$$+ (1 - \beta_t)\frac{1}{|H|}\sum_{i\in H}\mathbb{E}\left[\|\nabla \mathcal{L}_i(\theta_t) - \nabla \mathcal{L}_H(\theta_t)\|^2\right] + (1 - \beta_t)^2\frac{\sigma^2}{b}.$$ 

Due to Assumption 4.1, we have $\frac{1}{|H|}\sum_{i\in H}\mathbb{E}\left[\|\nabla \mathcal{L}_i(\theta_t) - \nabla \mathcal{L}_H(\theta_t)\|^2\right] \le \zeta$. Using this in the above concludes the proof. $\square$

## Varying Momentum Coefficients and a New Lyapunov Function

From the above analysis, we remark that, in order to obtain a diminishing effect of gradient noise on the aggregation error (similar to the non-convex case), we must choose $1 - \beta_t$ proportional to the learning rate $\gamma_t$ that itself can be chosen to be diminishing. Specifically, while ensuring that $\gamma_t \le \frac{1}{c}$ for the entire iterative procedure, where $c$ is a positive real value, we choose

$$\beta_t = 1 - c\gamma_{t-1}, \quad \forall t. \tag{6.47}$$

For the first iteration, we choose $\beta_1 = 0$. The varying of the momentum coefficients, under a scheduled diminishing learning rate, makes it rather difficult to obtain a useful uniform bound for the aggregation error. To overcome this issue, we consider a different Lyapunov function in order to analyze the convergence of Robust DMHB in the strongly convex case. Specifically, we consider the following Lyapunov function:

$$V_t := (\mathcal{L}_H(\theta_t) - \mathcal{L}_H^*) + \frac{1}{64L}\left(\|\xi_t\|^2 + \kappa \frac{1}{|H|}\sum_{i\in H}\|\mathbf{m}_t^{(i)} - \mathbf{m}_t^{H}\|^2\right). \tag{6.48}$$

Recall that $\xi_t := \mathbf{m}_t^{H} - \nabla \mathcal{L}_H(\theta_t)$. Observe that in comparison to the Lyapunov function used in the non-convex case, we also include the drift between the momentum vectors, i.e., $\frac{1}{|H|}\sum_{i\in H}\|\mathbf{m}_t^{(i)} - \mathbf{m}_t^{H}\|^2$, whose instantaneous growth for a changing rate of momentum was analyzed above in Lemma 6.6. In Theorem 6.2, we analyze the growth of this particular Lyapunov function.

### Theorem 6.2
Suppose Assumptions 3.1, 3.2, 4.1, and 4.2. Consider Algorithm 6 with an $(f,\kappa)$-robust averaging $F$, a batch-size $b \in [1,m)$, $\gamma_t \le \frac{1}{144L}$ for all $t$, and momentum coefficients defined by (6.47) with $c = 144L$. Then, for $V_t$ defined
in (6.48), for all $t > 1$, we have

$$\mathbb{E}[V_t] \le \left(1 - \frac{\mu}{4}\gamma_{t-1}\right)\mathbb{E}[V_{t-1}] + 324L\left(\kappa + \frac{1}{n - f}\right)\frac{\sigma^2}{b}\gamma_{t-1}^2 + \frac{9}{4}\kappa\zeta\gamma_{t-1}.$$

$$M_t^H = \frac{1}{|H|}\sum_{i\in H}\left\|\mathbf{m}_t^{(i)} - \mathbf{m}_t^H\right\|^2.$$

Consider an arbitrary iteration $t > 1$. By definition of $V_t$ in (6.48), we have

$$V_t = \left(\mathcal{L}_H(\theta_t) - \mathcal{L}_H^*\right) + z\left(\|\xi_t\|^2 + \kappa M_t^H\right). \tag{6.49}$$
