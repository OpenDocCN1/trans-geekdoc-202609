
## 2. Strongly convex case:
Under Assumption 3.3, we have

$\mathcal{L}(\theta_{T+1}) - \mathcal{L}^* \in O_T\left(e^{-\mu\gamma T}\right).$

Substituting $\gamma = \frac{1}{L}$ above, we obtain the best possible convergence guarantee, i.e., $\mathcal{L}(\theta_{T+1}) - \mathcal{L}^* \in O_T\left(e^{-\frac{1}{\kappa_{\mathcal{L}}}T}\right)$. Recall that $\kappa_{\mathcal{L}} := \frac{L}{\mu}$ is the condition number of the loss function $\mathcal{L}$.

### Proof
We divide this proof into two parts. In the first part, we analyze the non-convex case. In the second part, we consider the strongly convex case:

- 1. **Non-convex case:** Consider an arbitrary $t \in [T]$. Similar to (3.8) in the proof of Theorem 3.1, noting that $\theta_{t+1} = \theta_t - \gamma \nabla\mathcal{L}(\theta_t)$, we obtain that

$\mathcal{L}(\theta_{t+1}) \le \mathcal{L}(\theta_t) - \gamma\langle\nabla\mathcal{L}(\theta_t),\nabla\mathcal{L}(\theta_t)\rangle + \frac{L}{2}\gamma^2\|\nabla\mathcal{L}(\theta_t)\|^2.$

Rearranging the terms on the right-hand side yields the following:

$\mathcal{L}(\theta_{t+1}) \le \mathcal{L}(\theta_t) - \gamma\left(1 - \frac{L}{2}\gamma\right)\|\nabla\mathcal{L}(\theta_t)\|^2.$ (3.22)

which can equivalently be written as

$\left(1 - \frac{L}{2}\gamma\right)\|\nabla\mathcal{L}(\theta_t)\|^2 \le \frac{\mathcal{L}(\theta_t) - \mathcal{L}(\theta_{t+1})}{\gamma}.$

The last inequality follows from the fact that $\mathcal{L}(\boldsymbol{\theta}_{\mathbf{T}+1}) - \mathcal{L}^* \geq 0$. This concludes the proof for the non-convex case.

- 2. **Strongly convex case:** Recall, from (3.22) above, that for all $t \in [T]$,

$$\mathcal{L}(\boldsymbol{\theta}_{t+1}) \leq \mathcal{L}(\boldsymbol{\theta}_t) - \gamma \left(1 - \frac{L}{2}\gamma\right) \|\nabla \mathcal{L}(\boldsymbol{\theta}_t)\|^2.$$

Under Assumption 3.3, $\|\nabla \mathcal{L}(\boldsymbol{\theta}_t)\|^2 \geq 2\mu\left(\mathcal{L}(\boldsymbol{\theta}_t) - \mathcal{L}^*\right)$. Using this in the above, and also recalling that $1 - \frac{L}{2}\gamma \geq \frac{1}{2}$, yields

$$\mathcal{L}(\boldsymbol{\theta}_{t+1}) \leq \mathcal{L}(\boldsymbol{\theta}_t) - \gamma \mu \left(\mathcal{L}(\boldsymbol{\theta}_t) - \mathcal{L}^*\right).$$

Upon subtracting $\mathcal{L}^*$ from both sides in the above, we obtain that

$$\mathcal{L}(\boldsymbol{\theta}_{t+1}) - \mathcal{L}^* \leq (1 - \mu\gamma) \left(\mathcal{L}(\boldsymbol{\theta}_t) - \mathcal{L}^*\right).$$

Recall that $\mu \leq L$ when Assumptions 3.1 and 3.3 hold true simultaneously. This implies that, as $\gamma \leq \frac{1}{L}$, $1 - \mu\gamma \geq 1 - \frac{\mu}{L} \geq 0$. Therefore, upon applying the above inequality recursively from $t = T$ to $t = 1$, we obtain that

$$\mathcal{L}(\boldsymbol{\theta}_{\mathbf{T}+1}) - \mathcal{L}^* \leq (1 - \mu\gamma)^T \left(\mathcal{L}(\boldsymbol{\theta}_1) - \mathcal{L}^*\right).$$

As $(1 - \mu\gamma)^T \leq e^{-\mu\gamma T}$, the above implies that

$$\mathcal{L}(\boldsymbol{\theta}_{\mathbf{T}+1}) - \mathcal{L}^* \leq e^{-\mu\gamma T} \left(\mathcal{L}(\boldsymbol{\theta}_1) - \mathcal{L}^*\right).$$

The above concludes the proof.

### Remark 3.4
For the bounding factor $e^{-\mu\gamma T}$ to attain the lowest possible value, for a given $T$, we must use $\gamma$ to be as large as possible, i.e., $\gamma = \frac{1}{L}$. The resulting convergence rate is then given by $\exp\left(-\frac{T}{\mathcal{K}_L}\right)$, where recall that $\mathcal{K}_L := \frac{L}{\mu}$ is the condition number of the loss function $\mathcal{L}$. Expectedly, we observe that smaller the condition number faster the gradient-descent method can converge to the minimum, and vice versa.

Note that, unlike DSGD and DMGD, the convergence rate of DGD is identical to that of its centralized counterpart, i.e., we do not have an acceleration when using multiple nodes. This comes from the fact that, at every step in DGD, each node computes, and sends to the server, the full gradient of its local loss function. Hence, we do not obtain the same “variance reduction” property as in (3.13). However, DGD still reduces the computational burden per node compared to the centralized GD. In particular, at every step, each node computes only \(m\) point-wise gradient locally, instead of \(m n\), if the data points were collected at a single machine. Thus, the computational cost per node is indeed divided by \(n\).
