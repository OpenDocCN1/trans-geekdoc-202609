# Variance Reduction

Lemma 5.1, presented below, allows us to demonstrate the variance-reduction property of NNM. Specifically, we consider arbitrarily a vector **u** ∈ ℝ^d, a set of n vectors {**v₁**, …, **vₙ**} from ℝ^d, and a subset S ⊆ [n] comprising n − f elements. We then obtain an upper bound on the (Euclidean) distance between the average **v̄_S** of vectors **v_i**, i ∈ S and the average of n − f vectors in {**v₁**, …, **vₙ**} that are nearest neighbors of **u**. The bound suggests that NNM leads to a reduction in the (empirical) variance, as we elaborate immediately after presenting Lemma 5.1 (and its proof).

# Lemma 5.1

Consider an arbitrary vector **u** ∈ ℝ^d and an arbitrary collection of n vectors **v₁**, …, **vₙ** ∈ ℝ^d. Let N_u ⊆ [n] be a set of indices representing n − f nearest neighbors of **u** in the set {**v₁**, …, **vₙ**}. Then, for any S ⊆ [n] such that |S| = n − f, the following holds true:

$$ \|\mathbf{z_u} - \bar{\mathbf{v}}_S\|^2 \le \frac{4f}{(n - f)^2} \sum_{i \in S} \|\mathbf{v_i} - \mathbf{u}\|^2 , $$

where **z_u** := $\frac{1}{n-f} \sum_{i \in N_u} \mathbf{v_i}$ and **v̄_S** := $\frac{1}{n-f} \sum_{i \in S} \mathbf{v_i}$.

**Proof** Consider an arbitrary S ⊆ [n] such that |S| = n − f. Recall that N_u ⊆ [n] is a set of indices of n − f nearest neighbors of **u** in {**v₁**, …, **vₙ**}. Then, by definition of **z_u** and **v̄_S**, we obtain that

$$ \|\mathbf{z_u} - \bar{\mathbf{v}}_S\|^2 = \left\| \frac{1}{n - f} \sum_{i \in N_u} \mathbf{v_i} - \frac{1}{n - f} \sum_{i \in S} \mathbf{v_i} \right\|^2 = \frac{1}{(n - f)^2} \left\| \sum_{i \in N_u} \mathbf{v_i} - \sum_{i \in S} \mathbf{v_i} \right\|^2 . $$

Further simplifying the difference in the right-hand side, we get

$$ \|\mathbf{z_u} - \bar{\mathbf{v}}_S\|^2 = \frac{1}{(n - f)^2} \left\| \sum_{i \in N_u \setminus S} \mathbf{v_i} - \sum_{i \in S \setminus N_u} \mathbf{v_i} \right\|^2 . $$
