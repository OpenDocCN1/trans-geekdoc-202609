# Non-convex Case

Although reasoning on convex loss functions greatly helps us measure the quality of an optimization algorithm, in practice, however, the loss function ℒ need not be convex. For example, when training deep neural networks for image classification. In that case, solving the ERM problem (2.8) is NP-hard in general. A more reasonable goal is to compute a stationary point of ℒ, i.e., θ_stat such that ∇ℒ(θ_stat) = 0.

In theory, a stationary point can represent a local minimum, a local maximum, or a saddle point of the loss function. Verifying that θ_stat is a local minimum, in general, requires the second-order information of the loss function. Specifically, θ_stat is a local minimum of ℒ if the gradient ∇ℒ(θ_stat) = 0 and the Hessian ∇²ℒ(θ_stat) ≽ 0 (i.e., positive semi-definite).⁴ Nevertheless, in the context of gradient descent, especially in the stochastic case, it is unusual for the method to converge to a local maximum or a saddle point.
