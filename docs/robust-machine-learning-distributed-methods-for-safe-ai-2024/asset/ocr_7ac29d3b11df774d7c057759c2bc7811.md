# 4.4.2 Case of Non-convex Loss Function

In this section, we consider the Robust DMGD algorithm with robustness parameter f, i.e., we assume that n - f (out of n) nodes are honest. We first analyze, in Theorem 4.1, below the convergence of the algorithm to a stationary point of the average loss function for the honest nodes. Then, we will deduce the (f, epsilon)-stationary resilience property obtained at the completion of T iterations of the method, corresponding to the specific aggregation rules described in Sect. 4.1.3. Recall that, for a non-empty set S subseteq [n], L_S denotes the average loss function for S, i.e.,

L_S(theta) := 1/|S| sum_{i in H} L_i(theta).

We let L_S^* := min_{theta in R^d} L_S(theta). Recall also that E[.] denotes the total expectation over the randomness in Algorithm 5 after T iterations, i.e., E[.] = E1[ ... ET[.]].

Theorem 4.1 Suppose Assumptions 3.1, 3.2, and 4.1. Consider T iterations of the Robust DMGD algorithm with batch-size b in [1, m) and a constant learning rate, i.e., gamma_t = gamma <= 1/(4L) for all t in [T]. If the aggregation F is an (f, kappa)-robust averaging, then, for any H subseteq [n] comprising n - f honest nodes, the following holds true:

1/T sum_{t=1}^T E[||nabla L_H(theta_t)||^2] <= 4(L_H(theta_1)-L_H^*)/(gamma T) + 4L sigma^2/((n-f)b) gamma + 3 kappa (4 sigma^2 / b + zeta).

Proof Consider an arbitrary t in [T], and an arbitrary set H subseteq [n] comprising n - f honest nodes. Similar to (3.8) in the proof of Theorem 3.1, Lipschitz smoothness of the pointwise loss function, i.e., Assumption 3.1, in conjunction with the definition of theta_{t+1} in Robust DMGD, implies that

E_t[ L_H(theta_{t+1}) ] <= L_H(theta_t) - gamma_t <nabla L_H(theta_t), E_t[hat g_t]> + L/2 gamma_t^2 E_t[||hat g_t||^2]. (4.20)

Recall, from (4.14), that

hat g_t = F( g_t^{(1)}, ..., g_t^{(n)} ) = g_t^H + delta_t. (4.21)
