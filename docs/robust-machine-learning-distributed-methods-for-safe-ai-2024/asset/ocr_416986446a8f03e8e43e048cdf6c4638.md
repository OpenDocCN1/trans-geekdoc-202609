2. **Strongly convex case:** Under Assumption 3.3, we have

$\mathcal{L}(\theta_{T+1}) - \mathcal{L}^* \in O_T\left(e^{-\mu\gamma T}\right).$

Substituting $\gamma = \frac{1}{L}$ above, we obtain the best possible convergence guarantee, i.e., $\mathcal{L}(\theta_{T+1}) - \mathcal{L}^* \in O_T\left(e^{-\frac{1}{\kappa_{\mathcal{L}}}T}\right)$. Recall that $\kappa_{\mathcal{L}} := \frac{L}{\mu}$ is the condition number of the loss function $\mathcal{L}$.

**Proof** We divide this proof into two parts. In the first part, we analyze the non-convex case. In the second part, we consider the strongly convex case:

+   1. **Non-convex case:** Consider an arbitrary $t \in [T]$. Similar to (3.8) in the proof of Theorem 3.1, noting that $\theta_{t+1} = \theta_t - \gamma \mathcal{L}(\theta_t)$, we obtain that

$\mathcal{L}(\theta_{t+1}) \le \mathcal{L}(\theta_t) - \gamma\langle\nabla\mathcal{L}(\theta_t),\nabla\mathcal{L}(\theta_t)\rangle + \frac{L}{2}\gamma^2\|\mathcal{L}(\theta_t)\|^2.$

Rearranging the terms on the right-hand side yields the following:

$\mathcal{L}(\theta_{t+1}) \le \mathcal{L}(\theta_t) - \gamma\left(1 - \frac{L}{2}\gamma\right)\|\nabla\mathcal{L}(\theta_t)\|^2.$ (3.22)

which can equivalently be written as

$\left(1 - \frac{L}{2}\gamma\right)\|\nabla\mathcal{L}(\theta_t)\|^2 \le \frac{\mathcal{L}(\theta_t) - \mathcal{L}(\theta_{t+1})}{\gamma}.$
