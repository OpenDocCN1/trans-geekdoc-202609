# 3.2.1 Assumptions and Notation

First, as stated below, we assume that the point-wise loss function $\ell(h_{\pmb{\theta}}(\mathbf{x}),y)$ is Lipschitz smooth with respect to the vector $\pmb{\theta}$ at any data point $(\mathbf{x},y)$. In the following, $\nabla$ by default denotes the gradient with respect to $\pmb{\theta}$.

**Assumption 3.1 (Lipschitz Smoothness)** There exists a real value $L > 0$ such that for all $\pmb{\theta}, \pmb{\theta}' \in \mathbb{R}^d$, the following holds true:

$$\left\| \nabla \ell(h_{\pmb{\theta}}(\mathbf{x}),y) - \nabla \ell(h_{\pmb{\theta}'}(\mathbf{x}),y) \right\| \leq L \left\| \pmb{\theta} - \pmb{\theta}' \right\|.$$

Second, as stated below, we assume that for each node $i$, the point-wise gradients, i.e., $\nabla \ell(h_{\pmb{\theta}}(\mathbf{x}),y)$, $(\mathbf{x},y) \in \mathcal{S}_i$, have a uniformly bounded covariance trace. Recall that, by definition of $\mathcal{L}_i(\pmb{\theta})$ in (3.1), $\nabla \mathcal{L}_i(\pmb{\theta}) = \frac{1}{m} \sum_{(\mathbf{x},y) \in \mathcal{S}_i} \nabla \ell(h_{\pmb{\theta}}(\mathbf{x}),y)$ for all $\pmb{\theta}$.

**Assumption 3.2 (Bounded Covariance Trace)** There exists a real value $\sigma$ such that for all $i \in [n]$ and $\pmb{\theta} \in \mathbb{R}^d$, the following holds true:

$$\frac{1}{m} \sum_{(\mathbf{x},y) \in \mathcal{S}_i} \left\| \nabla \ell(h_{\pmb{\theta}}(\mathbf{x}),y) - \nabla \mathcal{L}_i(\pmb{\theta}) \right\|^2 \leq \sigma^2.$$

When imposing these assumptions, we consider two main types of loss functions for which we analyze the convergence of DMGD below: non-convex (in Sect. 3.2.2) and strongly convex loss functions (in Sect. 3.2.3). Due to the stochastic nature of the update procedure when using random batches, we characterize the convergence of DMGD in expectation. Specifically, we denote by $\mathcal{P}_t$ the transcript or the history of the algorithm, until the $t$-th iteration. This history is defined as follows:

$$\mathcal{P}_t := \{\pmb{\theta}_1, \dots, \pmb{\theta}_t\}. \tag{3.6}$$

We denote by $\mathbb{E}_t[\cdot]$ the conditional expectation $\mathbb{E}[\cdot | \mathcal{P}_t]$. Thus, upon executing $T$ iterations of DMGD, the expectation over the randomness of the algorithm, denoted by $\mathbb{E}[\cdot]$, is defined by the nested conditional expectations over the iterations, i.e., $\mathbb{E}[\cdot] = \mathbb{E}_1[\cdots \mathbb{E}_T[\cdot]]$.
