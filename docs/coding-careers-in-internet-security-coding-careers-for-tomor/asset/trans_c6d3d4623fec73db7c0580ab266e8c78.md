
作为一种反击，黑客开发了新的方法来加密和解密恶意软件。其中一种方法涉及使用**多态代码**。多态代码包含多个解密器，每个解密器都能解密恶意软件。当恶意软件运行时，它会随机选择其中一个解密器。拥有多个解密器使得反恶意软件软件更难以检测其签名。

其他方法包括**变态代码**和**变形代码**。在这两种代码中，解密器在代码运行时会发生变异（尽管变异方式略有不同）。这使得反恶意软件程序几乎无法检测其签名——这意味着新的检测方法是必要的。

## NEXT-GENERATION MALWARE-DETECTION METHODS

在二十一世纪，专注于网络安全的程序员开发了多种新的恶意软件检测方法。这些方法常被称为**下一代方法**。

一种下一代方法是**通用解密**。在通用解密中，反恶意软件程序将所有新程序文件加载到模拟器中。模拟器就像一个与“常规”计算机在同一物理机器内的第二个虚拟计算机，但它与常规计算机的硬盘和其他关键资源隔离。模拟器扫描并运行每个新程序以检测恶意软件签名，或与恶意软件行为一致的特征。如果模拟器判断程序是恶意软件，它会停止并删除该程序。由于模拟器与常规计算机隔离（尽管它们在同一物理机器内），恶意软件无法传播。

![](Images/page_33-1.jpg)

加密在某些消息中是重要的工具。

一些反恶意软件程序采用类似的方法，但它们在云端的沙箱中加载新程序，而不是在用户计算机上的模拟器中加载。沙箱是用于测试软件的隔离虚拟空间。云端指的是互联网上托管软件和服务的计算机。用户可以连接云端，从这些计算机运行软件或服务，而不是从自己的计算机。

其他下一代方法使用诸如**机器学习（ML）**等技术。机器学习涉及开发算法或模型，使机器能够随时间学习。程序员将机器学习模型纳入反恶意软件程序，以检测使用变态或变形代码的恶意软件。这些模型通过观察程序是否包含异常代码或行为可疑来检测恶意软件。机器学习还能通过识别代码中的特定模式，帮助识别恶意软件的创建者，从而为执法机构提供打击网络犯罪的帮助。

不出所料，黑客也开始使用机器学习。有时他们使用它来构建更隐蔽的恶意软件程序。其他时候，他们设计它来欺骗或混淆反恶意软件程序中使用的机器学习模型，导致其出错。这被称为**对抗性机器学习**。

## COMMON CODING LANGUAGES

程序员通过在计算机文件中输入用编程语言编写的程序指令来构建计算机程序（包括恶意软件和反恶意软件）。这些程序指令被称为**源代码**。大多数源代码会通过一个特殊的计算机程序——**编译器**——进行处理。编译器将源代码中的编程语言翻译成计算机可以读取的**机器语言**。（有些源代码设计为跳过这一步，这类代码被称为**解释型**。）机器语言由一系列**0和1**组成，这些0和1的顺序决定了程序的行为。包含这些机器语言的代码被称为**目标代码**。

事实上，编程语言数量数以千计。不同的编程语言具有不同的特性。一些编程语言是**低级语言**，这意味着它们与机器语言相似。它们对人类来说更难阅读和学习。另一些是**高级语言**，这意味着它们通常使用类似人类语言的元素（如单词），具有固定结构，并可能自动化某些编程功能，使其更易学习和使用。其他编程语言的特性还包括其是**通用目的**还是**特定用途**；是**imperative**（包含实现特定结果的操作序列）还是**declarative**（指定期望结果但不指定实现步骤）等。

## More on Machine Learning

许多人将**人工智能（AI）**和**机器学习**互换使用。但实际上它们并不完全相同。人工智能指的是构建所谓“智能”机器的科学与工程。例如，亚马逊的数字个人助理**Alexa**使用AI。另一个例子是某些网站上用于客户服务的**聊天机器人**。相比之下，机器学习描述的是机器通过经验随时间学习的能力。因此，机器学习是实现人工智能的一种方式。

机器学习代表了**网络安全**的前沿，也是对抗恶意软件的最强防御手段——尤其是当与其他安全方法（如在模拟器或云端扫描签名）结合使用时。机器学习特别适合处理与打击恶意软件相关的工作：它能够**快速执行常规任务**（如扫描文件）并处理**海量数据**（以识别和分类互联网上数百万种恶意软件样本）。这些工作的效率和速度远超人类。

专注于网络安全的程序员不需要研究每种编程语言——这不可能。但他们应该学习几种关键语言。以下是其中一些：

• **JavaScript**：JavaScript 是一种**解释型**、**imperative**（包含实现特定结果的操作序列）、**高级**编程语言。它常用于构建交互式网页，并在大多数现代网站的源代码中出现。它是使用最广泛的编程语言之一。

• **HTML**：几乎所有网站都包含HTML代码。因此，专注于网络安全的程序员必须了解HTML。该语言极易学习。

• **Python**：与JavaScript类似，Python 是一种**解释型**、**imperative**、**高级**编程语言。与HTML一样，它易于学习。Python 模仿人类语言，因此在不太经验丰富的恶意软件制作者中非常流行。

• **C 和 C++**：C 于1970年代开发，至今仍是流行的通用编程语言。C 被视为高级语言，但不如Python等语言那么高级。C++ 是C的更新版本，编译更快且性能更好。

## THE MOVEMENT TO OPEN SOURCE CODE

在20世纪90年代后期，一些软件开发人员开始从构建**专有软件**（由特定个人或组织所有）转向使用**开源模式**。开源软件的源代码对公众开放，可供研究或修改。自其发展以来，开源软件已获得广泛 popularity。这种开发模式鼓励协作。由于更多人审查和修改开源代码，它几乎总是比专有代码更强大且更安全。例如，**Linux 操作系统**（开源）比**Windows**和**MacOS**（专有）更安全。
