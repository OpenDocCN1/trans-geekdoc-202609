
第二种恶意软件感染方式是一种名为“特洛伊木马”（Trojan horse）或“特洛伊”（Trojan）的机制。黑客通过诱骗用户安装特洛伊木马来传播它们。一些特洛伊木马伪装成无害或甚至有用的程序；其恶意属性仅在用户安装后才显现。其他特洛伊木马通过电子邮件传播。这些信息警告用户出现某种问题，并指示他们点击信息中的链接以了解更多。当然，当用户点击链接时，他们会下载特洛伊木马。这种战术被称为“网络钓鱼”（phishing）。

恶意软件是一个严重的问题。反恶意软件公司卡斯珀斯基实验室在2017年检测到超过十五百万份恶意代码，影响了近30%的电脑。专家预测，由于恶意软件及其他网络犯罪行为，每年的财务损失将在2021年达到6万亿美元。这取决于专注于网络安全的计算机代码专家来阻止制作恶意软件的罪犯。

早期恶意软件攻击示例

大多数早期恶意软件并非旨在损坏或利用计算机系统。相反，它们是计算机代码编写者实验的产物。

1971年，计算机代码编写者开发了一个名为“Creeper”的蠕虫程序作为实验。它的目的是展示计算机程序如何自我复制，并在网络上从一台电脑传播到另一台电脑。Creeper未损害它感染的电脑，仅向用户显示一条消息。

另一个实验性例子是“莫里斯蠕虫”。一位名叫罗伯特·莫里斯的年轻计算机程序员构建了该蠕虫，旨在揭示ARPANET的安全漏洞。然而，代码中的缺陷导致蠕虫瘫痪了网络。

Creeper和莫里斯蠕虫没有恶意意图（尽管莫里斯蠕虫确实造成了损害）。这与1974年释放的另一种恶意软件程序——兔子病毒（Rabbit 或 Wabbit）不同。该病毒被设计为在计算机系统上快速自我复制，直到机器变得缓慢并崩溃。1986年释放的另一种恶意软件程序也具有恶意意图。黑客们将该程序伪装成更新版的流行免费文字处理程序PC-Write。当用户在机器上安装该程序时，它会删除系统上的所有文件。该程序是已知的第一个特洛伊木马。

莫里斯构建了已知的最早几种恶意软件之一，它被称为莫里斯蠕虫。

这些早期的恶意软件示例很有效。然而，它们并未造成广泛损害。有三个主要原因：第一，当时很少有人拥有个人电脑（PCs）；第二，很少有组织拥有计算机网络；第三，互联网（更准确地说是ARPANET）主要由政府官员和学术人员使用。

这在1990年代发生了改变。正是在这一时期，公司开始向普通消费者建造并销售个人电脑，计算机网络在企业和其他组织中变得更为流行，互联网以及诸如网页浏览器和电子邮件程序等相关软件也向公众开放。

随着更多人上网，电子邮件迅速成为黑客传播恶意软件的流行方式。一个例子是1999年席卷互联网的Melissa病毒。它的工作方式是：一名电脑用户收到一封带有Microsoft Word文档附件的电子邮件。当用户打开文档时，它会在用户的电脑上感染病毒。病毒随后扫描受感染的系统，判断是否安装了Microsoft Outlook电子邮件程序。如果有，病毒会在Outlook通讯录中找到五十个用户的联系人并将其复制到这些联系人。虽然Melissa病毒并未直接损害受感染的电脑，但它产生了大量网络流量——足以导致许多网络瘫痪。

一年后，另一种恶意软件程序——I Love You病毒——引发了更严重的问题。它的工作方式与Melissa病毒相同，但它并未仅将自身转发给感染机器的Outlook通讯录中的前五十个联系人，而是转发给所有人，并随即删除随机文件。I Love You病毒迅速感染了约五千万台机器，造成全球约50亿美元至150亿美元的损失。

现代恶意软件攻击

21世纪出现了更具破坏性的恶意软件攻击。其中之一发生在2017年，使用的恶意程序名为WannaCry。它利用某些版本的Microsoft Windows操作系统的安全漏洞，锁定全球范围内的电脑。攻击背后的黑客要求受影响的用户支付赎金以恢复数据，否则将永久丢失数据。幸运的是，Microsoft迅速发布了针对该安全漏洞的补丁。补丁是用于修复或“补丁”操作系统或其他计算机程序安全漏洞的代码片段。软件开发商通过发布更新向用户分发补丁。更重要的是，安全专家还发现了该恶意程序中的“关闭开关”，用于阻止其传播。这有助于限制受影响的电脑数量和造成的损害——尽管损害仍然相当严重。

另一个2017年的恶意软件攻击——NotPetya——则证明更加毁灭性。NotPetya利用与WannaCry相同的安全漏洞，但缺乏关闭开关。它被设计为快速传播。一位安全专家称其为“我们所见过的最快传播的恶意软件”。但这还不全部。NotPetya感染系统后，会极其迅速地将其禁用。它仅用四十五秒就使一家乌克兰大银行的整个网络瘫痪！起初，NotPetya看似与WannaCry类似，因为它显示了要求赎金的界面。然而，调查人员很快意识到其目的在于永久破坏它感染的每个系统上的内容。调查人员还发现，它很可能是由俄罗斯作为网络战手段释放，针对乌克兰及其盟友，开启了“新的战争时代”，涉及“削弱民主、摧毁关键基础设施的生计以及武器化信息”，英国国防大臣加文·威廉森（Gavin Williamson）如是说。

正如讨论过的，并非所有恶意软件攻击都涉及破坏计算机系统。一些黑客制作恶意软件的目的是窃取被入侵系统上的数据。这可能包括私人客户信息、企业系统的商业机密，或政府系统的机密信息。2016年，一个名为“影子联盟”（Shadow Brokers）的黑客组织入侵了美国国家安全局（NSA）维护的机器——该机构负责美国的网络安全。Shadow Brokers随后窃取了该机构开发的顶级黑客工具，并将其在暗网上公开。暗网是互联网的一个角落，允许完全匿名的通信，主要流通非法商品，包括恶意软件。这些工具可以“削弱许多主要政府和企业网络的安全性，无论国内还是国外”，一位安全专家表示。

新型恶意软件攻击被称为“加密劫持”（crypto-jacking）。这涉及在机器上安装恶意软件，该恶意软件秘密地“矿工”数字货币，即加密货币。当某人花费加密货币时，交易会记录在名为区块链（blockchain）的安全账本中。区块链通过复杂的算法（需要大量处理能力）来批准交易。为了增加区块链可用的处理能力，人们可以将电脑连接到区块链以换取少量加密货币支付。这种做法称为加密矿工（crypto-mining）。因此，加密劫持的恶意软件会在用户机器上连接该机器到区块链，但将支付发送给安装恶意软件的黑客。如果黑客感染足够多的机器，这可以相当有利可图。
