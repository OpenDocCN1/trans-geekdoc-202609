
在线零售商店和银行是黑客的另外两个主要目标——自互联网早期以来如此。

有显而易见的原因：这类企业维护着包含私人客户数据以及金融交易信息的庞大数据库。不出所料，大多数这些组织在努力保护自己免受黑客攻击方面已经走在前列。不过，它们仍然持续需要在职员中拥有网络安全专业人员。

许多制造工厂依赖计算机进行运营——这使它们成为网络攻击的潜在目标。

Getting Involved

计算机编码人才的短缺意味着具备编码技能的人士需求极大。这一点在专精于互联网安全的编码人士中尤为明显。该领域的职位远多于能够胜任的人员。

WHERE TO START

如果你想在互联网安全领域工作，现在就应开始为该角色做准备。幸运的是，有多种资源可供帮助。这些资源包括在线工具（部分专为女孩设计）以学习编程、面向中学生和高中生的计算机科学课程，以及面向编码者的夏令营。

高中毕业后，你可以完成大学课程以提升成为专精于互联网安全的计算机编码人才的就业机会。你也可以获得专业认证。

ONLINE CODING RESOURCES

要在互联网安全领域工作，你首先必须会编程。针对想学习编程的儿童的在线教学资源非常丰富。以下是其中一些：

• `Code Avengers` ([https://www.codeavengers.com](https://www.codeavengers.com)): `Code Avengers` 提供包括 HTML、JavaScript 和 Python 等计算机语言在内的强大编程教学——部分课程免费，其余需要付费订阅。

• `Codecademy` ([https://www.codecademy.com](https://www.codecademy.com)): `Codecademy` 提供多个在线编程教程，操作简便且能即时反馈。与 `Code Avengers` 类似，`Codecademy` 也提供部分免费课程和付费订阅课程。

• [`Code.org`](http://Code.org) ([https://code.org](https://code.org)): `Code.org` 是一家非营利组织，使命是让每个学生都有机会在学校学习计算机科学，就像学习生物、化学或代数一样。为了实现这一目标，`Code.org` 为学校开发课程并提供免费在线编程课程和项目。

• `Khan Academy` ([https://www.khanacademy.org/computing/computer-programming](https://www.khanacademy.org/computing/computer-programming)): `Khan Academy` 的使命是“为任何人、任何地方提供免费的世界级教育”。作为使命的一部分，它提供免费的计算机编程课程，包括 JavaScript 和 HTML 等语言。

• `Scratch` ([https://scratch.mit.edu](https://scratch.mit.edu)): 由麻省理工学院（MIT）媒体实验室提供，`Scratch` 为 8 至 16 岁的孩子提供大量免费教程和项目，帮助他们掌握编程概念。

• `Tynker` ([https://www.tynker.com](https://www.tynker.com)): `Tynker` 提供面向儿童的自aced、动手式在线课程，帮助他们在家学习编程。孩子们先通过可视化代码块玩耍，这些块代表关键编程概念，随后逐步过渡到 JavaScript 和 Python 等编程语言。

CODING RESOURCES FOR GIRLS

研究显示，75% 的高中女生对 STEM 领域（包括编程）感兴趣。然而，仅有 0.4% 的女大学新生计划主修计算机科学。2010 年代，多个组织成立以鼓励更多女孩和女性成为编码者。以下是几个例子：

• `Girls Who Code` ([https://girlswhocode.com](https://girlswhocode.com)): `Girls Who Code` 的使命是缩小技术领域的性别差距。该组织已教授基础编码技能给美国超过九万名女孩。“我们正在构建美国未来最大的女工程师管道，”创始人 Reshma Saujani 于 2012 年创立该组织时表示。显然，该组织的方法有效，因为它“正朝着 2027 年实现计算机科学性别平等的目标前进”，Saujani 报告称。

• `Made with Code` ([https://www.madewithcode.com](https://www.madewithcode.com)): `Made with Code` 由 Google 于 2014 年推出。它将在线活动与现实事件相结合，鼓励女孩学习编程。网站还设有涉及编码职业的女性访谈。

• `Black Girls Code` ([http://www.blackgirlscode.com](http://www.blackgirlscode.com)): 女性和女孩在涉及编码的职业中比例较低，非裔女孩和女性更是如此。为改变这一现状，一位非裔电气工程师 Kimberly Bryant 于 2011 年创立 `Black Girls Code`。该组织的使命是“向世界证明各色女孩都有能力成为未来的程序员”，并“到 2040 年培训 100 万名女孩”。

CODING CLASSES IN MIDDLE SCHOOLS AND HIGH SCHOOLS

专家预测，未来计算机相关工作将是高薪职业之一。然而，2016 年 Google 的一项调查显示，仅有四分之一的学校开设计算机编程课程。即便学校提供此类课程，它们也可能不计入学生的毕业要求，这 discourages 许多学生选修。尽管如此，如果你对成为专精于互联网安全的编码人才感兴趣，仍应探索学校提供的相关课程。

如果学校没有提供课程，可考虑与学校管理层会面，建议增加课程——例如，与非营利编码组织 [`Code.org`](http://Code.org) 合作。`Code.org` 为学校提供免费编码资源，包括 K–12 年级的课程、教师工作坊等。（更多信息请参见 [`https://code.org/yourschool`](https://code.org/yourschool)。）你也可以发起计算机编码俱乐部或类似组织。

除了学校内的课程外，还可以通过线上或线下方式参加教师指导的编码课程。例如，`Code Wizards HQ` 和 `Coding with Kids` 等组织提供在线教师领导课程。`Sylvan Learning` 和 `CoderSchool` 则提供课后课程。

CODING CAMP

多个组织提供夏令营，教导孩子们编程。例如，自 2014 年以来，国家安全局（NSA）与国家科学基金会（NSF）合作，推出名为 NSA GenCyber 夏令营的系列夏季日营。这些营队面向对编程普遍感兴趣且特别关注网络安全的 K–12 年级儿童，在全国多个地点提供，并且对所有参与者免费。（更多信息请参见 [`https://www.gen-cyber.com`](https://www.gen-cyber.com)。）除此以外，Codeverse 和 iD Tech 等组织也提供付费的编程夏令营。
