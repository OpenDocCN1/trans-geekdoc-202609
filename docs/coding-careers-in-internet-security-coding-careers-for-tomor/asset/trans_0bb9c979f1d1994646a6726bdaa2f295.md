
安全审计由安全审计师和漏洞评估员进行。这些角色识别系统或网络中的安全漏洞——不是像渗透测试员那样破坏系统，而是通过检查系统并运用对常见安全漏洞的了解来识别可能的弱点。类似地，源代码评估员会检查组织计算机系统背后的源代码，寻找错误或其他安全弱点。

随着职业生涯的发展，安全经理、安全主管和首席信息安全官（CISO）等职位也在不断涌现。这些职位的从业者更关注制定安全策略和管理团队，而不是使用自己的编码技能。

对于雇佣了所有这些角色的人员的组织来说，网络攻击或安全漏洞的可能性较低，但并非不可能。这就是事件响应人员和取证专家介入的地方。事件响应人员（也称为入侵分析员）就像网络消防员。他们在安全事件发生时负责扑灭火灾。取证专家是数字侦探。他们在计算机系统、网络和设备遭受攻击后，收集并分析电子证据，以确定攻击的类型和来源。一些取证专家在大型组织内工作，其他则受雇于政府或执法机构。

## 与互联网安全相关的行业

精通互联网安全的程序员在众多行业中都有需求，包括政府、医疗保健、制造业、零售业和金融业。

在政府工作的网络安全专业人员的工作可能特别有成就感。一方面，这些政府职位通常稳定，意味着人们不太可能失去工作。它们还提供良好的福利和在职培训。此外，这些职位让网络安全专家有机会为国家服务。然而，政府和军事职位的薪酬可能低于同类企业或组织中的职位。

多家美国机构雇佣网络安全专业人员，包括国家安全局（NSA）、中央情报局（CIA）、国土安全部（DHS）和联邦调查局（FBI）。网络安全专业人员也在四大军事分支——美国空军、美国陆军、美国海军陆战队和美国海军——工作。此外，为美国政府提供合同服务的企业也雇佣网络安全专业人员，例如通用动力、宝马集团、雷神公司和Endgame, Inc.。

鉴于联邦政府中网络安全专业人员的短缺，这些机构急于招聘人才。根据DHS网站的内容，其“最高优先事项之一是获取、培养和保留网络安全领域最有才华的人才”。但这并不意味着他们会雇佣所有人。大多数职位需要申请人通过背景审查，一些职位甚至要求具备安全许可。安全许可赋予持有者访问机密甚至机密级信息的权限。

美国军方为精通互联网安全的程序员提供大量工作机会，并且会在岗位上对他们进行培训。

另一个日益增长的网络安全专业需求行业是医疗保健。事实上，今天，医疗保健行业是黑客攻击的首要目标。主要原因是越来越多的医疗机构开始使用电子健康记录。这些记录不仅包含患者的健康信息，还包含识别信息，如姓名、地址、出生日期和社会安全号码。据一位安全专家所说，这些记录“都是个人可识别信息的宝库，这使得医疗机构及其合作伙伴成为网络罪犯的 irresistible 目标”。黑客通常攻击电子健康记录以窃取患者身份。但他们也可能篡改记录以物理伤害患者——例如，通过更改处方药的剂量。

## 国家安全局（NSA）

国家安全局（NSA）成立于1952年，用于情报通信跟踪，这被称为信号情报（SIGINT）。如今，NSA 还致力于打击网络犯罪。为实现此目标，NSA 雇佣的网络安全专业人员数量多于美国任何其他组织。其主要职责是保护和捍卫国家计算机安全系统，包括包含机密信息的网络。其工作方式之一是开发新的信息加密方法，即发明新的秘密代码和密码。通过保护机密信息，NSA 的程序员帮助确保国家的安全。

NSA 也被认为为网络战开发恶意软件。例如，2010 年发现的“棱镜”蠕虫（Stuxnet worm）就是一个案例。据称，该蠕虫由以色列和美国政府的程序员开发。NSA 之外的安全专家表示，该蠕虫感染了伊朗运行该国核反应堆的计算机。蠕虫内部的代码导致反应堆的离心机转速过快，导致数千台离心机损坏。据一位专家称，Stuxnet 将伊朗建造核武器的进程推迟了两年。“这几乎和军事打击一样有效，”专家说，“但更好的是没有死亡和全面战争。”

对 NSA 这类岗位感兴趣的学生可以申请实习。 （更多信息请参见 [https://www.intelligencecareers.gov/nsa/nsastudents.html](https://www.intelligencecareers.gov/nsa/nsastudents.html)。）

尽管存在这些危险，医疗保健机构仍在加强系统安全，部分原因是许多系统老旧过时。这也解释了为何 2009 年至 2015 年间，医疗机构经历了超过 1,300 次安全漏洞，导致超过 1.5 亿电子健康记录暴露给黑客——这几乎相当于美国总人口的一半！保护患者私人信息（以及患者健康）的压力无疑会促使医疗机构迅速适应，这意味着需要聘请精通互联网安全的程序员，以开发保护医疗系统的方法。

除了加大对医疗机构的攻击，黑客还增加了对制造设施的攻击。事实上，制造业是黑客攻击的第二大目标。针对制造设施的攻击可能不会让黑客获得用于身份盗窃的大量私人信息，但可能导致商业机密或知识产权（如蓝图）被盗，黑客可以将其出售给竞争对手或用于制作假冒产品，或者窃取其他敏感信息。攻击还可能破坏任何计算机化的生产设备，导致设备关闭或生产缺陷甚至危险的产品。这可能导致昂贵的召回、声誉受损，甚至造成人员伤亡——例如，如果计算机化的生产设备发生爆炸或生产缺陷产品导致用户受伤或死亡。没有任何制造商能承受此类攻击，因此他们必须聘请网络安全专业人员来防范。
