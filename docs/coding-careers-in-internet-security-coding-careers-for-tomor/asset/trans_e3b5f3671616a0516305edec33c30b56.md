## THE DANGERS OF BUGS

恶意软件对安全构成了最严重的威胁。但它并不是唯一的威胁。其他威胁来源于计算机漏洞，即问题。

一些漏洞为恶意软件进入系统提供了通路。然而，其他漏洞会导致不同的安全问题。一个例子是1999年的Y2K漏洞。早期程序员经常用两位数字表示年份（例如06/17/88），而不是四位（06/17/1988）。当2000年（通常称为Y2K）临近时，人们担心计算机可能错误地解读两位数字的年份输入。例如，他们担心计算机会将日期01/01/00解读为1900年1月1日。他们担心这会导致一些计算机和网络崩溃。专家警告说，如果这发生在管理航空交通或电力网络的计算机系统中，后果将是灾难性的。有人甚至预测这会导致社会完全崩溃，甚至引发世界末日。幸运的是，得益于全球计算机程序员的 feverish（费尽周折且昂贵）努力修复该漏洞，其影响极小。

## EARLY EFFORTS TO SECURE THE INTERNET

早期计算机用户对互联网安全很少有思考，因为当时很少人使用互联网，或者不了解它如何被滥用。

1971年Creeper蠕虫的发布为互联网上的潜在安全问题提供了早期线索。它还催生了人们认为是第一个反恶意软件程序——Reaper。Reaper由与发布Creeper的计算机程序员共同构建。它在机器之间移动，以在网络上查找并删除所有Creeper的实例。（有趣的是，Reaper在技术上是一种病毒，但它是为好事而设计的。）

随着恶意软件变得更加复杂和先进，反恶意软件工具也随之发展。许多工具是在1980年代末由互联网安全公司的程序员开发的。至今仍存在的几家安全公司正是在此期间成立的，包括`Symantec`、`Sophos`、`McAfee`、`Avast`和`Panda Security`。这些公司雇佣（并继续雇佣）计算机程序员来对抗网络犯罪。

与此同时，非正式的程序员群体也形成以对抗恶意软件。其中一个是在线群体`VIRUS-L`，它始于1988年。其成员包括当今互联网安全领域的知名人物，如`Eugene Kaspersky`，他于1997年创立了`Kaspersky Lab`。该群体讨论新病毒及可能的检测和消除方法。更正式的组织如`计算机防病毒研究组织（CARO）`和`欧洲计算机防病毒研究所（EICAR）`开始对恶意软件及其他安全话题进行进一步研究。

## Contributions of Computer Coders to Secure Internet Shopping

在1990年代之前，人们通常在居住附近的商店购买物品。如果需要的物品在当地商店没有，他们可能会从印刷目录中订购，或者干脆放弃。更常见的情况是，他们直接放弃，寻找其他满足需求的东西。

互联网改变了一切。20世纪中叶，企业家推出了电子商务网站，让人们可以在网上购买和出售商品。像`Amazon`和`eBay`（均于1995年推出）这样的网站使得人们几乎可以从任何地方研究、定位并购买几乎任何商品——通常花费更少。

离不开那些专注于互联网安全的计算机程序员。他们开发了工具，使买家和卖家之间的连接安全。这防止了黑客拦截支付信息（如信用卡号码）。没有安全的连接，任何形式的电子金融交易都不可能实现。所以，下次你在网上购物时，请感谢一位计算机程序员！

## INTERNET SECURITY TODAY

技术进步为专注于互联网安全的计算机程序员带来了新挑战。例如，移动技术、云计算和物联网（IoT）的创新为黑客创造了新的攻击途径。安全程序员必须管理这些威胁，同时继续防御传统目标的攻击。

仅仅应对攻击已经不够了。作为一个日益连接和依赖技术的社会成员，互联网安全专家需要主动出击——预判攻击并在此发生前阻止它们。只有在威胁尚未造成损害之前主动阻断，才能确保“好人”获胜。

## The Internet Security Arms Race

每当“恶”计算机程序员在互联网上释放新的恶意软件程序时，“好”计算机程序员会迅速推出解药。如果没有这些“好”程序员来帮助对抗恶意软件，互联网及其连接的数百万台计算机很可能会停止运行。然而，这一不断的攻防循环已经演变成一种军备竞赛。每一次攻击和反击，局势都会升级。恶意程序员释放更具破坏性的恶意软件，以产生更大的影响。

这一挑战还因恶意软件的开发和分发可能非常有利可图而变得更加复杂。根据`Carbon Black`（一家网络安全公司）的数据，一些恶意软件开发者每年从暗网销售软件的收入超过`$100,000`，而平均 legitimate software developers（合法软件开发人员）每年仅赚`$69,000`。`Federal Bureau of Investigation (FBI)`估计，2016年黑客仅通过勒索软件的赎金收款就收到了`$1 billion`。

“有一个‘坏人’行业，”一位安全专家说，“它非常有利可图。”因此，“‘好人’行业必须比他们更好。”这对专注于互联网安全的好程序员来说是一项挑战：必须比构建恶意软件的坏程序员做得更好。

## Coding to Combat Cybercrime

1987年，著名计算机科学家`Fred Cohen`指出“没有能够完美检测所有可能的计算机病毒的算法”。计算机算法是一系列步骤或公式，用于让计算机完成任务或解决问题。Cohen是正确的。这解释了为什么反恶意软件程序在检测和消除恶意软件时采取不同的方法。

## TRADITIONAL MALWARE-DETECTION STRATEGIES

大多数传统反恶意软件程序通过在计算机文件或传输中搜索签名来识别恶意软件。签名是代码中的一段信息，可以用来识别代码（类似指纹）。许多恶意软件程序具有独特的签名。当反病毒程序检测到这些签名时，它知道应该删除该代码。

为了防止反恶意软件软件检测签名，一些黑客加密了他们的代码。这被称为`obfuscation`（混淆）。在加密代码能在目标机器上运行之前，它必须先被解密。通常用于解密恶意代码的代码被称为解密器（decryptor），它本身也有独特的签名。因此，虽然反恶意软件软件可能无法检测加密代码的签名，但它有时可以检测到解密器的签名。
