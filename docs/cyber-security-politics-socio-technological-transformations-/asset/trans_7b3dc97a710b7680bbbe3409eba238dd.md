
Dunn Cavelty 2022) 突出了本书各章节中浮现的四个主要问题。第一个重点在于网络行动的有限战略效用。与其明显具有升级性质或导致大国之间现有权力平衡的可见变化，网络行动主要被用作颠覆和轻微破坏的工具。第二个问题涉及新兴技术与网络安全政治未来之间的动态关联，强调私营主体、技术竞赛动态是网络威胁感知的驱动力，同时制度因素在塑造新兴技术对进攻与防御平衡的影响方面发挥作用。第三个问题在于在多维不确定性下维护战略稳定的挑战，章节讨论了在不确定和模糊性下可能推动升级的决策微观动态、作为可信威慑威胁前提的归因模糊性，以及情报在网络空间中日益增长的作用。第四个问题探讨如何克服权威和问责碎片化的问题。

**Conclusion**

数字技术正以快速的速度转变社会和政治生活的许多方面，同时这些技术本身也受到政治决策和治理安排的塑造，这些决策和安排旨在在最佳方式上平衡机遇与风险。技术与政治的这种相互依赖与相互塑造在本卷所有章节中均发挥作用。研究它时，作者们敏锐地认识到社会技术系统和组合的复杂且非确定性运作，而非陷入技术决定论。

事实是，关于技术发展速度和范围的不确定性为研究、评估、建模和预测新技术可能性的研究提出了新的需求。作为社会科学家，我们需要理解技术日益显著的政治和社会层面，这些层面将影响政治和社会在国家及国际层面的合作与冲突模式。但社会科学家也需要越来越擅长与各种技术学科进行交流。至少，我们需要通过专家出版物 familiarize ourselves，最好是与技术科学同事建立定期对话。
