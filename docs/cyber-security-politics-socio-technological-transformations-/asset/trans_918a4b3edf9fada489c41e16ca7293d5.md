
-   “被发射”的网络行动，例如分布式拒绝服务（DDoS）攻击。

-   也可以轻易雇佣“雇佣兵”黑客组织（例如 Dark Basin）来执行各种黑客攻击（Scott‑Railton 等 2020）。与此同时，参与基础网络行动和网络影响行动所需的技术知识也相对较低。例如，只需具备对广泛可得的编辑软件（如表情包编辑器、推特生成器或深度伪造）以及社交媒体的基本了解即可（Chesney 和 Citron 2018）。

-   关于成本，David Sanger（2018）指出，用于网络行动的网络武器如今“开发成本低廉且隐藏容易”，因此极具吸引力。事实上，参与低到中等复杂度网络行动的准入成本也相对较低，尤其与其他传统军事手段相比。这一点在网络影响行动中尤为明显，这些行动仅需要互联网连接、能联网的设备以及访问免费基于账户的应用程序即可进行虚假信息或宣传活动。不过，这些网络武器的维护成本可能有所不同（Smeets 2018）。同时，通过优化以及使用更高级的工具和技术（如自动化机器人），执行成本和时间也能进一步降低。

-   从案例观察来看，第一个发现是网络行动倾向于更具破坏性（影响 cyberspace 的逻辑层或人格层）而非破坏性（影响 cyberspace 的物理层）。这种倾向部分是因为破坏性网络行动比破坏性行动更难实施。破坏性网络行动更为复杂，需要更多资源进行开发和策划，如 Stuxnet 所示。此外，破坏性网络行动的升级潜力也高于破坏性行动，使得后者更适合灰色区域冲突。在本案例中，国家和国家赞助行为体在国际紧张局势加剧的背景下，仍表现出对网络行动的克制（Gomez 2018；Valeriano 和 Jensen 2019）。除 Stuxnet 以及针对乌克兰电网的 2015、2016 年攻击等高价值目标外，网络行动的影响仍然有限（Cherepanov 2017；Dragos Inc. 2017）。

-   这种克制可能源自以下两点。第一，国家在开放冲突（如乌克兰）中也愿意保持紧张局势仅停留在灰色区域。这种克制表明国家认识并尊重某些“红线”，以避免升级（Gomez 2018）。因此，国家明白其在 cyberspace 的行为会影响国际规范的话语，希望在战争阈值以下保持行为，以避免产生先例。第二，克制可能与进行网络行动本身的固有困难有关。这些行动需要巨大的成本和时间投入，难以控制，其效果不确定且难以衡量，且工具往往只能在特定时间段内使用（Gomez 2018）。所有这些因素使得国家倾向于在最需要时（如战争时期）才使用最具破坏性的网络行动。从成本‑收益角度看，物理攻击可能比网络攻击更简单、更便宜且更具震慑力。

-   第二个观察来自案例研究：一些国家在灰色区域也进行网络犯罪活动，这进一步证明 cyberspace 适合在战争阈值以下开展各类活动。最能体现这种特殊性的国家是朝鲜民主主义人民共和国（DPRK）。事实上，DPRK 通过网络犯罪为其政权、核程序以及规避国际制裁提供资金（Carlisle 和 Izenman 2019；Kim 2018；Sanger 2018）。2019 年发布的联合国报告指出，DPRK 政府通过网络犯罪活动（如针对外国银行和加密货币交易所）约获得 20 亿美元的收入（Finkle 2017；Guerrero‑Saade 和 Moriuchi 2018；Nichols 2019；Solon 2017）。

-   这些 DPRK 的行动明显区别于其他国家，后者很少包含网络犯罪。中国和俄罗斯之间网络犯罪与国家赞助行动的界限模糊或至少是可渗透的——这是灰色区域冲突的典型特征。这些国家经常雇佣的承包商在不与政府签约时也可能从事网络犯罪。

-   例如，APT41 为中国国家安全部（MSS）工作，白天进行网络间谍活动，晚上从事网络犯罪活动。

-   然而，FireEye 发现这些夜间活动通常在普通中国工作时间之外进行，这表明它们可能并未得到国家的知晓，或者仅得到国家的容忍，但很可能并非基于国家合同（FireEye Inc. 2019）。在此例子中，国家并未从这些网络犯罪活动的财务收益中获益，反而可能因不必要的关注而受损。

-   *灰色区域的网络行动* 23

-   ***操作上具有吸引力且有效***  
    一个使网络行动在灰色区域尤为具吸引力的假设是，网络技术能够实现快速且可扩展的效果，这两点提升了其效能，因为它们带来惊讶、过载和目标瘫痪（Harknett 和 Smeets 2020；Warner 2019；Wirtz 2017）。在实践中，互联网的几乎即时传输特性以及所有信息通信技术的互连性，消除了攻击发射与影响之间的执行时间。关于网络影响行动，数字技术大幅缩短了信息传播所需时间，并提供了广泛的平台和格式灵活性。与此同时， cyberspace 在一定程度上消除了传统的物理和国家障碍，为操作者提供了更大的可扩展性、灵活性和安全性。这同样适用于网络影响行动：新的数字信息传播方式摆脱了传统信息门卫，极大地扩大了影响活动的覆盖范围和规模。

-   因此，本案例研究的一个观察是：网络行动确实在提升战略优势方面日益被使用，尤其是通过网络间谍行动，如中国发起的 Operation Aurora 或美国海军 Sea Dragon 项目的被黑客攻击（Nakashima 和 Sonne 2018）。这意味着，根据文献中的一种观点，网络行动更多被用作灰色区域竞争的传统竞争手段，而非全新的工具。除了网络行动的操作优势外，这也部分可以解释为网络间谍活动不受国际法规约束，使国家能够相对自由地开展此类活动。然而，一些国家（如美国）区分经济间谍与国家安全间谍。虽然两者均可在灰色区域冲突中使用，美国将前者视为非法，而后者则被容忍（Harris 2016；《经济学人》2013）。
