*不确定性及其他塑造因素* 177

早期的国家战略是`Cross-Cutting Strategy`（2008-2013）。不确定性也是该战略的基本假设：“随着信息技术的快速发展及其渗透至社会几乎所有活动领域，对安全可靠服务的需求日益凸显”（第36页）。该战略还承诺与不同行为体合作，包括“其他国家和国际机构、民间社会和信息社会领域的私营部门”（第36页），并指出国家行政机构将“与民间社会和私营实体合作”（第39页）。

另一个重要的公共文件是`Policy Paper`（2015-2017）关于`Cyber Security`，旨在协调所有参与维护安全网络空间的行为体的职责与责任。该文件的一个重要战略目标是加强与各负责方的合作。文件详细描述了与不同利益相关方的合作领域，如与互联网服务提供商就处理网络事件及阻断非法内容网站的措施加强合作；与民间社会就儿童网络安全加强合作；与学术界就开设专门的网络安全学习项目加强合作；以及与银行业合作，根据该文件，银行业应在网络安全领域的任何法律或技术倡议中得到代表。该政策文件的不确定性假设再次出现：“信息通信技术的快速发展及其在社会几乎所有活动领域的广泛使用，凸显了对安全可靠服务的需求”（第8页）。该不确定性假设也出现在政策文件的下一句：“在信息技术每日变化的背景下，发展网络安全需要公共机构特别关注”（第29页）。

对于该政策文件，私营部门被接受为除国家之外的参考对象：“通信使用的增加为国家的经济和社会发展带来附加价值，但同时也使其面临针对国家和私营实体的网络攻击风险”（第8页）。在本政策文件中，网络安全不是某一机构、公共机构、私营部门或公民的问题，而是影响所有生活和社会领域的问题，因此需要所有信息通信技术（ICT）和网络空间使用者采取必要的安全措施（第19页）。它呼吁与公共和私营部门进行密切合作，并与学术界合作（第20页）。私营部门也是关键信息基础设施的“所有者”之一：“鉴于这些系统不仅是公共系统，也可能属于私营部门，因此将鼓励与私营部门进行信息交流与合作，以确保这些系统的基础安全”（第24页）。

`National Security Strategy` 2014-2020 将网络攻击归类为一级风险，即最高重要性风险。根据该策略，威胁包括“国家或非国家行为体的网络攻击”（第25页）。因此，网络安全被提升至国家政策层面。

阿尔巴尼亚将网络空间视为对国家主权的威胁。因此，将网络空间提升至国家安全层面是由于网络攻击带来的风险增加：虽然更广泛的通信是国家经济和社会发展的附加价值，但同时也使国家面临国家行为和非国家行为体带来的网络风险。网络攻击有潜力严重破坏公共机构、电信以及金融银行系统的信息交换，导致关键服务中断。

(p. 23)

随后发布的网络安全文件和战略在将网络威胁纳入国家安全战略方面保持一致。公众普遍支持并认同将网络威胁提升至国家威胁层级的决定，因为其对该威胁的感知与之相符。鉴于该国尚未发生针对关键信息基础设施的大规模事件，阿尔巴尼亚将网络威胁纳入国家安全战略遵循了预防性逻辑，即担忧可能对关键基础设施造成破坏性网络攻击的风险。因此，升级至国家威胁层级并非源自国内或国家先前的任何威胁事件。阿尔巴尼亚的应对措施受到其他国家（如爱沙尼亚、格鲁吉亚、英国和美国）的事件影响（Guitton 2013）。阿尔巴尼亚正经历日益紧密相连的安全环境，安全威胁不再像过去那样遥远，这体现在其对网络安全的表述中。

另一个重要的国家网络安全战略是`Cyber Defense Strategy` 2014-2017。不确定性再次是该战略的基本假设。该战略指出：“网络罪犯可以利用计算机技术获取个人数据，或利用互联网进行剥削或恶意目的”（第5页）。它还指出，网络空间是“任何人都可以在无时间和空间限制的使用环境中，非对称地为恶意攻击者提供优势”（第9页）。

`Cyber Defense Strategy` 也为除国家以外的其他行为体参与保护网络空间提供了空间，指出减少网络安全威胁和脆弱性的努力将包括负责的结构（如国防部/武装部队）与其他政府及私营部门的协同努力，通过协作活动识别并修复严重的网络漏洞和 breaches。
