
-   [预测性建模](https://example.org)产生了关于置信度程度以及威胁情报实践如何应对新颖性的重要问题。假设事件已正确与入侵集关联，该入侵集如何与特定行为者关联？诸如共同语言、特定小时的活动、目标选择以及复杂程度等信息通常用于将事件组与特定威胁行为者关联。但这种归因超出了纯技术关联的范畴。某些TTP的重用会使归因复杂化。例如，漏洞EternalBlue据称由NSA开发，但后来被俄罗斯、朝鲜和伊朗（Segal 2018）利用。

-   归因概念框架帮助数字取证结构化收集的信息并与已知入侵集进行比较。例如，Caltagirone和Pendergast（2013）开发的入侵分析金字塔模型，以及Rid和Buchanan（2015）开发的“Q模型”。

-   金字塔模型和Q模型都承认归因需要非技术维度。在金字塔模型中，非技术维度描述为受害者与对手之间的关系。Q模型的战略维度描述为“取决于政治利益所涉及的内容”（Rid和Buchanan 2015）。

-   归因的政治维度可能被量化，但本质上是关系性的，更多源自政治学或情报研究，而非计算机科学。随着制裁或其他威慑手段用于惩罚攻击性网络行动，我们可能会预期网络行动会通过掩饰身份来调整。例如，泄露的CIA“马布尔框架”（Marble Framework）被描述为能够将源代码语言从英语改为俄语或法语等其他语言（Burgess 2017）。

-   一个国家开发的网络工具正被另一个国家重用，这表明取证专家与反取证掩饰之间存在技术竞赛。虽然掩饰在短期内可能对强国有利，但长期来看并不能减轻攻击性网络攻击的持久损害。此外，国家归因能力的不平等也存在。这被认为在联合国关于信息和通信技术在国际安全背景下的政府专家小组（UN GGE）的解体中发挥了作用（Schmitt和Vihul 2017）。
