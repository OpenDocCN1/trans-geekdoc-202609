***Output***

就产出而言，技术公司所开展的以规范为导向的网络安全减缓措施相对成功。自2017年联合国政府专家组（UN GGE）未达成共识的结果之后，技术公司发布了可观的候选规范数量及相应的倡导措施。无论是实质性条款还是制度承诺，包括微软（Microsoft）、西门子（Siemens）、电信公司（Telefónica）以及卡斯佩斯基实验室（Kaspersky Lab）在内的企业都为促进虚拟领域的全球和平与安全作出了重要贡献。

这些企业与行业同行、非政府利益相关者以及政府的互动，使它们能够提出广受支持且具战略意义的规范性理念，例如呼吁更大程度的供应链和产品透明度，或对关键基础设施和个人进行广泛防护。
