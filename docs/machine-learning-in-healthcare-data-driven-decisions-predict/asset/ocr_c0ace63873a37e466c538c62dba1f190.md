The computation of a linear combination of the input features is the initial step in LR:

```
= \(\beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_n x_n = \beta^T x\) \quad (1)
```

In eq. (1) \(x = [x_1, x_2, \dots, x_n]\) are the input features, \(\beta = [\beta_0, \beta_1, \dots, \beta_n]\) are the coefficients and \(\beta_0\) is the intercept (bias term).
