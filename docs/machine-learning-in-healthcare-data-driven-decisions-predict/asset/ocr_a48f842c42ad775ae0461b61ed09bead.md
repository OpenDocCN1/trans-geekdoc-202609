The synthetic minority oversampling technique (SMOTE), which generates synthetic examples by interpolating between given instances of minority classes, is employed to compensate for the problem. Alternatively, in order to focus more on decision boundary hard-to-learn samples, adaptive synthetic sampling (ADASYN) can be employed. Through equal treatment of both classes, the classifier is more accurate at detecting earlier signs of CKD without overtraining on more common patterns. Mean/mode imputation of missing data, encoding categorical features, min-max scaling of numeric features, and SMOTE-based oversampling for solving class imbalance are all part of the preprocessing pipeline. With around 400–500 samples and 35–40 features, the above preprocessing transforms the original noisy raw clinical data into a clean, balanced, and machine-learning-friendly dataset, readying a solid foundation for the efficient functioning of the proposed HRAB algorithm.

# 3.2 Feature Selection Using Regularization

In order to reduce redundancy, increase interpretability, and reduce the incidence of overfitting, the CKD dataset (post-SMOTE balancing) of approximately 500 samples is now approximately 35–40 samples (due to one-hot encoding) and undergoes an important feature selection phase following preprocessing. The features may be redundant, collinear, or at most weakly informative in the case of the clinical context of the data; having such features leads to a higher-error model as well as a greater computational load. L1-regularized logistic regression or least absolute shrinkage and selection operator (Lasso) is used as a feature selection method based on regularization to tackle this. Because it both selects variables and regularizes, this process is very effective with high-dimensional data.

The Lasso model is trained using the preprocessed dataset, where the objective is to minimize the binary classification loss function (log loss) subject to an L1 penalty on the magnitude of feature coefficients. The optimization problem is represented as

```
\min_w \left( \frac{1}{n} \sum_{i=1}^n \log \left( 1 + e^{-y_i(w^T x_i)} \right) + \lambda \|w\|_1 \right)
```

where w is the vector of feature weights, yi is the class label, xi is the feature vector, and λ is the regularization hyperparameter that controls the degree of sparsity. A higher value of λ forces more coefficients toward zero, effectively removing unimportant features.
