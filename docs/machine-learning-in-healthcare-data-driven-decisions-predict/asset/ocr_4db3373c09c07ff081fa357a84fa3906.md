Closeness centrality estimates the efficiency of a node in reaching all other nodes in the network. It is determined in the network by calculating the average distance between a node and all other nodes. A node with strong proximity centrality has a short average route length to all other nodes. Closeness centrality is particularly pertinent in scenarios where effective communication or information dissemination is vital. A high proximity centrality indicates effective transmission of information or communication.

```
CC_i = \frac{1}{\text{average shortest path length from node } i \text{ to all other nodes}}
```

# ## 4.5 Eigenvalue Centrality

Eigenvalue centrality is a significant metric in the field of complex network statistics. The centrality metric is derived from the primary eigenvector of the adjacency matrix of a network. The adjacency matrix is a \( n \times n \) matrix that encodes the connections between nodes in a network.

The calculation of eigenvalue centrality is as follows:

+   1. Adjacency matrix (AM): The adjacency matrix AM for a graph G with \( n \) individual elements (vertices/nodes) is a \( n \times n \) matrix. The value AM\(_{ij}\) = 1 if there is an edge between nodes \( i \) and \( j \), otherwise AM\(_{ij}\) = 0.
+   2. Degree matrix (DM): The degree matrix DM is a diagonal matrix in which DM\(_{ii}\) represents the degree of individual element (vertex/node) \( i \) (the number of edges connecting to node \( i \)).
+   3. Laplacian matrix (LM): The Laplacian matrix LM is calculated as the difference between the degree matrix DM and the adjacency matrix AM, denoted as LM = DM – AM.
+   4. Eigenvalue centrality: The eigenvalue centrality of a node is determined by the \( i \)th component of the primary eigenvector of the Laplacian matrix LM.

Let \( \delta_1 \) represent the minimum eigenvalue of the Laplacian matrix LM, whereas \( v_1 \) is the eigenvector that corresponds to this minimum eigenvalue. The eigenvalue centrality (EC) of node \( i \) is calculated as follows:

```
EC_i = \frac{1}{|\delta_1|} \times |v_1(i)|^2
```

In the above equation, \( |v_1(i)|\) represents the \( i \)th element of the eigenvector \( v_1 \), whereas \( |\delta_1|\) refers to the magnitude of the lowest eigenvalue.
