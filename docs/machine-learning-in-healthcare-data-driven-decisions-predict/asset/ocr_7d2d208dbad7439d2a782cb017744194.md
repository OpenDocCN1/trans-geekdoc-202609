# 2.5 Optimized Depression Classification

Depression is a common and disabling psychiatric illness that requires early and proper diagnosis in an effort to provide helpful intervention and treatment. Electroencephalography (EEG) has also been indicated as an effective noninvasive method to investigate neural signatures of depression and can provide useful assistance in clinical diagnosis. In this study, a methodology for diagnosing depressive disorders through EEG on publicly available multimodal open dataset for mental-disorder analysis is presented. EEG signals were recorded from 55 subjects with merely three electrodes in rest condition. Twelve temporal features were extracted from the gathered data by dividing the EEG signals into nonoverlapping segments of 10 s. A new FS technique was utilized to select the most discriminative features to distinguish depressing patients from healthy controls. The parameters that were detected were tested with three classifiers: Best-First (BF) Tree, kNN, and AdaBoost. BF-Tree classifier provided the best accuracy of 96.36% using a 12-feature vector that surpasses the current depression detection techniques. Notably, the system reported here has good classification performance with minimal EEG setup and hence is realistic and cost-effective. The model promises to be useful for application in psychiatric practice, offering clinicians a useful tool for assisting the diagnosis of depressive disorders [17].
