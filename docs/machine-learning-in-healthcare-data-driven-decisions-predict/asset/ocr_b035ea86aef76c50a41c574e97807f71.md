P(y = 1|x) = σ(z) = 1 / (1 + e^-z)

The model uses a threshold, usually 0.5, to predict class labels:

ŷ = { 1, if σ(z) ≥ 0.5; 0, if σ(z) < 0.5 }

Reduce the log loss (cross entropy) as follows in order to train the model:

L(β) = -1/m Σ [y^(i) log(ŷ^(i)) + (1 - y^(i)) log(1 - ŷ^(i))]

where m is the number of training samples, y^(i) is the true label, and ŷ^(i) = σ(β^T x^(i))

# 3.4.3 Random Forest

RF consists of multiple DTs trained over random subsets of data and features [26]. RF avoids overfitting and increases accuracy and stability and is therefore a strong performer in medical prediction tasks. The dataset is given as follows:

D = [(x1, y1), (x2, y2), ..., (xm, ym)}

The RF builds T number of DTs:

h1(x), h2(x), ... hT(x)

A random selection of features not all features is taken into account at each tree split. For classification (e.g., diabetic or nondiabetic). Each tree ht(x) predicts the class label. The final prediction is the majority vote:

ŷ = mode({h1(x), h2(x), ..., hT(x)})

For regression, each tree predicts a numeric output, and the result is the mean of all the trees:

ŷ = 1/T Σ ht(x)

Trees often employ the Gini impurity at each node to determine the optimal split:

Gini = 1 - Σ p_i^2
