# 3.4 Stacking

Stacking or stacked generalization is an advanced ensemble learning method that combines multiple models to improve the accuracy of the classification. Unlike other ensemble methods like bagging and boosting, where the same type of base learner is used and combined to form a single powerful model, stacking allows meta models that learn to combine many base models [27].

The main idea of stacking is to use the positives of many models and introduce a secondary model called a meta learner to learn from the output. This approach can often outperform individual models and other ensemble methods because this approach recommends the optimal combination of models.

There are two layers in the stacking:

+   1. Layer 1 – Base learners: There are multiple models used. Each model is trained using the same training data.
+   2. Layer 2 – Meta learner: This layer contains a model that assigns weights to the output of the models. The input of the meta learner has no features, but the output of all the base learners.
