# 4.1 Dataset Description

The Wisconsin BC (diagnosis) dataset contains 569 instances, derived from a digitized image of fine needle samples of breast masses. Each example consists of 30 real properties. The properties are calculated as mean, standard error, and “the average of the three worst maximum characteristics for each characteristic”, resulting in a high-dimensional profile of the morphology of the cell nucleus. The target function is a binary function that indicates whether tumor malignant (M) or benign (b) has 212 malignant and 357 benign records. This data record is suitable for training and observation of the performance of ML algorithms in binary classification problems. With its well-designed structure and precisely defined capabilities, it is an ideal choice for the use of algorithms such as XGBoost and is a research benchmark dataset for the diagnosis of BC.
