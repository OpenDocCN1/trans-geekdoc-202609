where the precision and recall is given as follows:

```
\(\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}, \text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}\) (24)
```

Mean absolute error (mRS prediction): It calculates the average absolute error between the mRS scores that were anticipated and those that were obtained:

```
\(\text{MAE} = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|\) (25)
```

where \(y_i\) is the actual mRS score, \(\hat{y}_i\) is the predicted mRS score, and \(n\) is the number of samples.

QWK (mRS prediction): It compares the ground truth to a model or two raters’ agreement for ordinal classifications such as mRS scores:

```
\(k = 1 - \frac{\sum_{ij} w_{ij} O_{ij}}{\sum_{ij} w_{ij} E_{ij}}\) (26)
```

where \(O_{i,j}\) is the observed agreement matrix, \(E_{i,j}\) is the expected agreement matrix, and \(w_{l,i,j}\) is the quadratic weight and it is specified as follows:

```
\(w_{l,i,j} = \frac{(i - j)^2}{(k - 1)^2}\) (27)
```

As an example, mRS scores from 0 to 6 \(\rightarrow k = 7\), where \(k\) is the number of categories. The QWK scale goes from -1 (total disagreement) to 1 (perfect agreement), where 0 denotes agreement at the chance level.
