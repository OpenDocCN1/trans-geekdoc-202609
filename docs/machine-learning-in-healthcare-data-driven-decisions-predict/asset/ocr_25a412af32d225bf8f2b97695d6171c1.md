```
Z_{\text{fused}} = [Z_{\text{img}} || Z_{\text{clin}} || Z_{\text{ml}}] \in \mathbb{R}^{d_1 + d_2 + d_3} \quad (17)
```

Next, a MLP with dropout and batch normalization is applied to this fused vector:

```
h_1 = ReLU(BN_1(W_1 Z_{\text{fused}} + b_1)) \quad (18)
h_1^{\text{drop}} = Dropout(h_1, p) \quad (19)
h_2 = ReLU(BN_2(W_2 Z_{\text{fused}} + b_2)) \quad (20)
```

where \(W_1, W_2\) are the weight matrices, \(b_1, b_2\) are the biases, \(BN_1, BN_2\) are the batch normalization functions, and \(p\) is the drop out probability. During the multitask learning phase, final predictions are made using this MLP output \(h_2\)

# 3.3.5 Multitask Learning

The proposed architecture features a two-task learning process between two task-specific output layers which have the capability of optimizing two clinically useful goals concurrently. Risk stratification is associated with the first output layer that specifies low, medium, or high risk levels for the patients through a softmax activation. This is able to enable the model to produce class probabilities so class probabilities may be outputted by the model for more understandable risk estimations. The second output layer for mRS score prediction is handled as an ordinal regression task to honor the ordered nature of the mRS. Methods like CORAL (cumulative ordinal regression) or deep ordinal regression are used to learn from this ordinal output in an efficient way. The ultimate training goal is guided by an aggregate loss function, expressed as follows:

```
\mathcal{L} = \alpha . \mathcal{L}_{\text{risk}} + \beta . \mathcal{L}_{\text{outcome}} \quad (21)
```

Here, \(\alpha\) and \(\beta\) are hyperparameters that can be tuned to adjust the two-task contribution. The model is capable of leveraging shared representations and task-specific learning at the same time by optimizing the two tasks jointly, and accordingly the better generalization and prediction performance will be achieved for risk classification and functional outcome prediction [27].
