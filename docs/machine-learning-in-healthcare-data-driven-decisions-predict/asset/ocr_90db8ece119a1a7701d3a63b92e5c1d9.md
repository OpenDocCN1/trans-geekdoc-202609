# 5.2 Algorithm Categories and Applications in Stress Detection

Classical Supervised Learning Algorithms: SVM, RF, DT, and KNN fall into this category and are commonly applied to binary or multi-class stress classification (e.g., low, medium, high stress). These methods are well-suited when the dataset is of moderate size and labeled with obvious class differentiation. Interpretability and feature importance (particularly with RF and DT) are essential in healthcare environments where explainability is critical [20].

Boosting Techniques: Gradient Boosting: models like XGBoost and LightGBM have gained popularity for their high accuracy and capability to work with imbalanced datasets – which is prevalent in stress datasets where low stress or neutral states predominate. They are best suited for competition or production use where high precision is crucial.

Ensemble and Hybrid Approaches: Hybrid models blend several classifiers with methods such as voting, stacking, or blending. This model avoids the collective vulnerabilities of base models, providing improved generalization and robustness to noisy data.

Deep Learning Models: CNNs can handle spatial patterns (e.g., feature maps of EEG/ ECG signals), while LSTMs are strongest for time-series data, e.g., longitudinally recorded HR or respiration over hours or days.

ANNs: General purpose and form the basis for more sophisticated architectures. Deep models are being used more and more in wearable based monitoring systems for real-time processing.

# 5.3 Model Selection Considerations

Selecting the right algorithm depends on multiple factors as shown in Table 8:

Table 8: Dependency of algorithms on different factors.

| Factor | Preferred algorithms |
|---|---|
| Small dataset | SVM, KNN, decision tree |
| Large dataset | Random forest, gradient boosting, deep learning |
| Temporal/sequential data | LSTM, RNN, GRU |
| Need for real-time processing | KNN (with optimized indexing), shallow ANN |
| Need for interpretability | Decision tree, random forest (with feature importance) |
| Highly nonlinear data | Gradient boosting, neural networks |
