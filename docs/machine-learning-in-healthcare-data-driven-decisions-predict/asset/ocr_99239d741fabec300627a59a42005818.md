5. Feature Integration and Emotion Selection: We merge the newly derived features with the customized dataset. We notice that certain emotions very rarely occur in the dataset. For example, sadness, fear, and anger appear only 61, 1, and 2 times, respectively. Therefore, we exclude those emotions from our dataset. As a result, six emotions remain in our dataset: alert, happy, neutral, rested/relaxed, tensed/anxious, and tired.
