# 4.4 Neural Network Models

In this section, we explore the neural network (NN) models in time-domain features to further improve the accuracy of the emotion classification model. We use two NN models: FNN and BiLSTM.

The FNN model initially gives 77.47% testing accuracy. Similarly, BiLSTM gives 72.23%. Then we try a different approach where we first balance the dataset using the random oversampling method. After that, we train the ML and NN models. We observe that only LightGBM improves its accuracy using random oversampling, but other ML models show degrading results compared to their previous performance. The detail about the accuracy is shown in Figure 11. Figure 12 shows a model-wise comparison of accuracy performance. XGBoost recorded an accuracy of 81.01%, which is the highest among the machine learning models. Among the neural network models, the Feedforward Neural Network (FNN) is the best performer with an accuracy of 97%.

The detailed NN model approach is given below:

**Preprocessing:** We do the necessary preprocessing before fitting the data into the models. We remove unnecessary columns from the dataset before feature selection and encode the target columns into numeric values using LabelEncoder. Then, we use StandardScaler to normalize the features. It helps the model run faster during the training time. We use SelectKBest with a score function (f_classif) to select the top 60 features from the dataset for feature selection. We split the data into training, validation, and testing parts.

**Feedforward Neural Network (FNN):** We build the FNN architecture with three hidden layers containing different neurons. The first hidden layer contains 512 neurons, the second layer contains 256, and the third hidden layer contains 128 neurons. In the first hidden layer, we use the leaky ReLU activation function, and on the output layer, we choose the Softmax activation function. We use the Adam optimizer with a learning rate of 0.00005 and categorical cross-entropy as the loss function. We define a very low learning rate so that it helps smooth convergence during training. If for 10 consecutive epochs there is no improvement, then we automatically run early stopping. We run different epochs from 100 to 1,000 to know their accuracy. This model gives the highest accuracy at 600 epochs, 97%.

**Bidirectional Long Short-Term Memory (BiLSTM):** The BiLSTM model performs best when we use a two-hidden-layer configuration, where the first hidden layer contains 128 neurons and the second hidden layer contains 64 neurons. We set a 50% dropout rate to avoid overfitting. We get the best accuracy at 800 epochs, which is 96.12%.
