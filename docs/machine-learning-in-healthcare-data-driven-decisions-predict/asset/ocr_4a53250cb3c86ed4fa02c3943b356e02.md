Precision: The ratio of all positive predictions to true positives. It matters when false positives (e.g., incorrect diabetes diagnosis when the patient is not diabetic) are expensive:

\(\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}\) (26)

Recall: The ratio of all real positives to true positives. It matters when false negatives (e.g., not detecting a diabetic patient) are very expensive:

\(\text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}\) (27)

\(F_t\)-Score: A harmonic mean of recall and precision gives equal weight, particularly for datasets that are not balanced:

\(F1\text{ - score} = \frac{2 \text{ * Precision * Recall}}{\text{Precision + Recall}}\) (28)
