Accuracy measures the percentage of correctly classified instances out of the total predictions made. Higher accuracy indicates better general performance:

Accuracy = \frac{TP + TN}{TP + TN + FP + FN} (22)

The F1-score strikes a balance between recall and precision. It is essential for unbalanced data, such as mental health classifications, where clinical repercussions may result from overpredicting (false positive) or missing a case (false negative):

F_1-score = 2 * \frac{Precision * Recall}{Precision + Recall} (23)

Precision = \frac{TP}{TP + FP} (24)

Recall = \frac{TP}{TP + FN} (25)

AUC-ROC – The model's capacity to distinguish between classes across all thresholds is gauged using ROC-AUC. Better discrimination is shown by a number near 1.0, whilst a random guess is represented by a value of 0.5:

AUC = \sum_{i=1}^{n-1} (FPR_{i+1} - FPR_i). \frac{TPR_{i+1} + TPR_i}{2} (26)

TPR = \frac{TP}{TP + FN} (27)

FPR = \frac{FP}{FP + TN} (28)

Matthews Correlation Coefficient (MCC): In binary classification, the MCC is a balanced metric that is especially useful in datasets that are unbalanced. It takes into account both true and false positives as well as negatives. Perfect prediction is represented by a value of +1, no better than chance by a value of 0, and total disagreement by a value of -1.
