## 3.2 Feature Selection Using Regularization

In order to reduce redundancy, increase interpretability, and reduce the incidence of overfitting, the CKD dataset (post-SMOTE balancing) of approximately 500 samples is now approximately 35–40 features (due to one-hot encoding) and undergoes an important feature selection phase following preprocessing. The features may be redundant, collinear, or at most weakly informative in the case of the clinical context of the data; having such features leads to a higher-error model as well as a greater computational load. L1-regularized logistic regression or least absolute shrinkage and selection operator (Lasso) is used as a feature selection method based on regularization to tackle this. Because it both selects variables and regularizes, this process is very effective with high-dimensional data.

The Lasso model is trained using the preprocessed dataset, where the objective is to minimize the binary classification loss function (log loss) subject to an L1 penalty on the magnitude of feature coefficients. The optimization problem is represented as

```
\min_w \left( \frac{1}{n} \sum_{i=1}^n \log \left( 1 + e^{-y_i(w^T x_i)} \right) + \lambda \|w\|_1 \right)
```

where w is the vector of feature weights, yi is the class label, xi is the feature vector, and λ is the regularization hyperparameter that controls the degree of sparsity. A higher value of λ forces more coefficients toward zero, effectively removing unimportant features.

The feature coefficients are ranked by absolute value after model fitting. Features with coefficients precisely zero or very close to zero (e.g., <0.01) are excluded because they are deemed to have little to contribute to CKD prediction. Features with weak predictive power in this database, for example, sugar or specific gravity, can be excluded irrespective of their clinical importance in some cases. Highly weighted attributes, for example, albumin, hemoglobin, SC, blood urea, and red blood cell count, have larger coefficients, which confirms their clinical importance in the detection of early CKD. The Lasso-based filtering appears to keep only those features that give a high signal to the learning algorithm and hence shrink the feature space from 35 to 40 to a more manageable and informative 15–20 features.

Apart from speeding up the training and inference process, this dimensionality reduction also improves model interpretability, something of paramount importance in the context of healthcare applications. A model where a small number of known biomarkers are used for prediction is beneficial to clinicians. Furthermore, the model will not overfit when the noisy and redundant variables are removed, something important when working with small and imbalanced datasets like CKD. Finally, the critical HRAB classifier is then supplied with the selected features such that the ensemble is working on a statistically valid and clinically relevant set of the original data.

## 3.3 Base Learner Setup

After preprocessing and feature selection operations, the resultant dataset, normalized, balanced, and dimensionally compressed to around 15–20 meaningful features are provided as input to the base learners of the HRAB algorithm. The HRAB algorithm is specifically designed to use the relative strengths of light, efficient, and regularized learners in order to achieve high generalization ability, computational lightness, and robustness against overfitting. Unlike the traditional ensemble models, which would most likely utilize homogeneous learners (e.g., an ensemble of decision trees), HRAB maximally leverages heterogeneous base learners, each of which possesses inherent regularization and noise tolerance properties. Such heterogeneity introduces diversity among the learners, which is crucial in reducing the correlation of the individual errors and improving the overall generalization of the ensemble.

From Table 1, regularized decision trees are used as the base class of learners. They are shallow trees with a maximal depth (fixed typically at 3 or 4) and minimal samples per leaf (such as 10 or more). These limits are such that they keep the trees from overfitting noise, which is an issue with small, unbalanced clinical datasets like CKD. The simplicity of the tree ensures quick execution and interpretability without being unable to model important, nonlinear relations in the data. Penalized logistic regression (L2 regularization) is the second learner type. The classifier is trained with respect to loss function under penalty on squared magnitude of coefficients, which prevents model variance and overfitting. In CKD, where lab values are strongly correlated (e.g., SC and blood urea), L2 regularization prevents feature importance from runaway oscillation and enforces stability on weights. The third learner is naïve Bayes, specifically with Laplace (add-one) smoothing, that addresses the zero probabilities problem of categorical features never occurring in any class. For example, some CKD predictors like pus cell clumps or bacteria might never occur in normal patients, causing sparsity in training data. Laplace smoothing guarantees that such rare but clinically important events receive nonzero predictive probabilities, maintaining predictive integrity. These three classifiers work together to make sure that the ensemble is robust against noise, feature correlation, and sparse data while capturing both linear and nonlinear patterns. In order to ensure that misclassified samples are given more weight in the subsequent round, each base learner contributes to the HRAB ensemble proportionate to its own classification error (adaptive boosting concept).

Together with learner diversity, this error-focused re-weighting creates a potent ensemble that can produce high accuracy (e.g., > 98% in internal validation) while preserving efficiency and interpretability. HRAB successfully overcomes the difficulties presented by clinical data, including noise, small sample size, and associated characteristics by including a varied collection of regularized base learners. In addition to improving prediction performance, the strategic design provides a dependable and expandable method for early CKD identification.

## 3.4 Integration of Regularization in Boosting

HRAB’s framework uses regularization penalties during the boosting, bringing an added control over normal AdaBoost that solely adjusts weights by classification error. In clinical use cases such as CKD prediction early, where overfitting and learner instability will heavily damage generalizability as well as clinician trust, this modification is needed. Each boosting step in HRAB considers both the basic learner’s misclassification rate and an instance-specific regularization penalty that accounts for the model complexity and error profile.

The core mechanism of HRAB involves computing a penalty score (§§) for each base learner at iteration i, which is defined as a function of two key components:

- Error rate (εᵢ) – the weighted classification error of the base learner.
- Complexity index (Cᵢ) – a structural measure that varies depending on the learner type. For example:
  - For decision trees: depth or total number of leaf nodes.
  - For logistic regression: number of nonzero coefficients (sparsity).
  - For naïve Bayes: variance in probability estimates.
