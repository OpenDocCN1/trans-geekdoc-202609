# Table 7: Overview of machine learning algorithms for stress detection and prediction.

| Algorithm | Description | Advantages | Limitations | Use case |
| :--- | :--- | :--- | :--- | :--- |
| Support vector machine (SVM) | Separates classes by identifying the optimal hyperplane in a high dimensional space. Effective in binary and multi class classification. | Works well on small and medium datasets; handles high dimensional data. | Less effective on large datasets; requires careful kernel selection. | Detecting binary stress states (e.g., stressed vs. relaxed). |
| Random forest (RF) | An ensemble learning method using multiple decision trees. Aggregates outputs for classification or regression. | Handles nonlinear features; provides feature importance; robust to overfitting. | May be computationally expensive; less interpretable than single trees. | Multilevel stress classification using physiological data. |
| Decision tree (DT) | Simple, interpretable tree structure for classification based on feature thresholds. | Easy to interpret and visualize; fast training and testing. | Prone to overfitting; poor generalization on noisy data. | Initial modeling and feature selection. |
| k-Nearest neighbor (KNN) | Instance based method that assigns class based on the majority label of k nearest neighbors in feature space. | Simple; no training phase required | Computationally intensive on large datasets; sensitive to feature scaling. | Real-time mobile stress classification with small datasets. |
| Gradient boosting (GB) | Builds models in a stage wise fashion, each focusing on minimizing the errors made by the previous one (e.g., XGBoost, LightGBM). | High accuracy; handles missing data and unbalanced classes well. | Sensitive to hyperparameters; longer training time. | Predictive modeling with fine-tuned accuracy requirements. |
| Hybrid/ensemble models | Combine predictions from multiple algorithms (e.g., RF + SVM or stacking) to improve generalization and robustness. | Reduces bias and variance; improves performance on diverse data types. | Complex implementation; increased computational cost. | Aggregated stress monitoring in heterogeneous sensor environments. |
| Deep learning models | Includes CNNs (convolutional neural networks), LSTMs (long short-term memory), and ANNs (artificial neural networks) for hierarchical learning. | Captures complex temporal/spatial patterns; scalable to big data. | Requires large datasets and high computational resources. | Time-series stress prediction from continuous physiological signals. |
