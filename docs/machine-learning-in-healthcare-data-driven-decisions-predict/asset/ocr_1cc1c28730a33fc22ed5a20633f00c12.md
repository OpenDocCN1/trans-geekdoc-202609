where $P_{k,j}(x_i)$ is the predicted probability of class $k$ from the $jth$ base learner for input instance $x_i$ and $\hat{P}_k(x_i)$ is the aggregated probability. The goal is to maximize the ROC-AUC score of the ensemble on a validation fold by adjusting weights $w_1, w_2, w_3$ for ELM, PNN, and CatBoost, respectively. The objective function is to maximize the following:

$AUC_{Ensemble} = w_1 * P_{ELM} + w_2 * P_{PNN} + w_3 * P_{CatBoost}$

subject to constraints

$0 \le w_i \le 1, \sum w_i = 1$

The final prediction is made by selecting the class with the highest predicted probability:

$\hat{y}_i = (\hat{P}_k(x_i))$

This yields the class $\hat{y}_i$ that corresponds to the highest averaged probability across all base learners.

Optimized Soft Voting Using Particle Swarm Optimization (PSO): While soft voting merely assigns equal weight to the prediction of each base learner, obtain optimal weight of each learner's contribution from how well each performs on a validation set. PSO is a population-based optimization algorithm that replicates the social bird flocking or fish schooling phenomenon [30]. Every particle in the swarm corresponds to a candidate solution, that is, the weights given to the base learners of the ensemble. The weights are updated at each iteration depending on their own best and the global best position discovered by the swarm. Let $w_j$ represents the weight assigned to the $jth$ base learner and let the weight vector be $w = [ w_1, w_2, ..., w_M ]$, where $M$ is the number of base learners. Initially the weights are set randomly. The goal of PSO is to find the optimal weights $w$ that minimizes the loss function or maximize performance of the ensemble on the validation set. The fitness function $L(w)$ is defined as

$L(w) = \frac{1}{N} \sum_{i=1}^N L_i(w, x_i, y_i)$

where $N$ is the number of validation instances and $L_i(w, x_i, y_i)$ is the loss for the $i$th validation instance such as cross-entropy loss:

$L_i(w, x_i, y_i) = - \sum_{k=1}^C y_{i,k} \log(\hat{P}_k(x_i, w))$

where $C$ is the number of classes, $y_{i,k}$ is the one-hot encoded true label, and $\hat{P}_k(x_i, w)$ is the repeated probability for class $k$ for the $i$th instance calculated using the weighted sum:
