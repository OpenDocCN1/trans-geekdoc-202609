Table 1: Three primary base learners used in HRAB.

| Base learner | Regularization mechanism | Justification |
| :--- | :--- | :--- |
| Regularized decision trees | Max-depth and min-sample splits | Controls model complexity; prevents overfitting to noisy CKD data |
| Penalized logistic regression | L2 regularization (ridge) | Ensures small, smooth weights; stabilizes decision boundaries |
| Naïve Bayes | Laplace smoothing | Handles sparse feature distributions and prevents zero probability |
