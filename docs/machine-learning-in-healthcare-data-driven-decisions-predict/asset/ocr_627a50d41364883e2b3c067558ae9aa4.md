# 4 Results and Findings

Performance of the hybrid model is strictly tested on stratified fivefold cross-validation so that there is an even class distribution of outcomes for training and validation splits. In the task of risk stratification, performance is measured with AUC-ROC, a threshold-independent assessment of the capacity of the model to discriminate between classes, and $F_1$-score, which optimizes precision and recall to express classification accuracy in imbalanced scenarios. For predicting mRS score, mean absolute error (MAE) measures the average size of prediction errors, indicating precision of the model in functional outcome estimation. QWK also assesses the concordance between predicted and real mRS scores considering ordinal scale and penalizing greater discrepancies more. Overall, these measures supply a complete valuation of the model’s discriminability, predictive performance, and clinician usability.

+   **AUC-ROC (risk stratification)**

It assesses how well the model can differentiate across classifications such as low and high risk. The true positive rate (TPR) versus false positive rate (FPR) is given by

```
TPR = \frac{TP}{TP + FN}, FPR = \frac{FP}{FP + TN} (22)

The ROC curve’s integral, or AUC, is usually calculated mathematically (e.g., by applying the trapezoidal rule).

**$F_1$-score (risk stratification):** It strikes a balance between classification accuracy and recall (used here for risk categorization). It is computed as follows:

```
$F_1 - score = 2 * \frac{Precision \times Recall}{Precision + Recall} (23)$
