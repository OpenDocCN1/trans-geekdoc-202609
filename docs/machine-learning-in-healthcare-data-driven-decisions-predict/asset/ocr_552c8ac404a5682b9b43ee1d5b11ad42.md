# 5 Conclusion

In this work, we have analyzed and predicted emotional states using various physiological data collected using commercial smartwatches. We have utilized the LifeSnaps public dataset, which contained physiological sensor data and psychological survey data collected from 71 volunteers from different demographic areas using commercially available Fitbit Sense smartwatches between May 2021 and January 2022. We have analyzed the dataset and have performed a correlation-based study between the physiological data and self-reported emotional states to establish the feasibility of the current research. From the correlation, we have found that bpm, resting hr, filteredDemographicVO2max, and calories have shown a higher correlation with emotions. We have adjusted the weights according to the correlation strength. We have applied six different ML algorithms (SVM, LR, DT, LightGBM, XGBoost, and RF) and have achieved the highest accuracy of 78.75% using RF. Then, we have used signal domain features and have utilized recursive feature elimination with two proposed methods, the selective feature-based approach and the holistic feature-based approach, to select the optimal features for the classification model. We have found that out of 164 features, 96 features have best suited the classification model and from those features, our prediction accuracy has increased from 78.75% to 81.01%. Next, we have applied the neural network-based method to predict emotions and have achieved the highest accuracy of 97% using the deep neural network. So, our proposed approach has systematically helped remove irrelevant and redundant features. Our research has shown that commercially available smartwatches can monitor an individual's emotional state using a smartwatch.

In the future, we will evaluate whether our proposed method can work effectively in commercially available smartwatches to monitor mental health. Second, since most real-world datasets will contain missing or noisy data, we will develop an improved algorithm to handle missing and noisy data accurately.
