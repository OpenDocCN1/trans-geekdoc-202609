Efficiency of the proposed MSAG-DFE model was significantly enhanced by the preprocessing pipeline employed for the ChestX-ray14 dataset. All the chest radiographs were resampled from 1,024 × 1,024 pixels to 224 × 224 pixels, which improved computational efficiency while preserving vital diagnostic information. During training of the model, steady gradient flow was maintained by normalizing pixel intensity between the range [0, 1]. Detailed feature extraction demands the visualization of subtle anatomical boundaries, which CLAHE further enhanced, especially in low-contrast or underexposed images. Lesion contours and structural borders were maintained while high-frequency noise was reduced by applying a Gaussian blur filter with a standard deviation of 0.5. The model’s ability to generalize was improved with real-time data augmentation that corrected class imbalance and introduced randomness through random flipping, minor rotations, zooming, and brightness adjustments.

A cleaner and more regular set of data was achieved by implementing histogram-based intensity thresholding to eliminate overexposed or underexposed images caused by acquisition issues. These preprocessing techniques collaborated to enhance the accuracy of the MSAG-DFE model’s deep, attention-focused feature extraction. The sensitivity of the model was enhanced, especially for rare diseases, because the attention mechanisms were able to focus more intently on pathologically important regions. A robust and scalable solution was achieved by combining this stringent preprocessing pipeline with the MSAG-DFE architecture. This provided good generalization across different classes of illness, accelerated convergence during training, and superb diagnostic performance. This demonstrates how the MSAG-DFE architecture can be applied clinically to diagnose thoracic disease in real-world applications using large chest X-ray datasets.
