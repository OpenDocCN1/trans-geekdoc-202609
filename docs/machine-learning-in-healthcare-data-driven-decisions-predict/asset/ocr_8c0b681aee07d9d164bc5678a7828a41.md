# ## 3.1 Data Preprocessing

The HRAB model is a trained and cross-validated CKD dataset of the UCI Machine Learning Repository. This dataset consists of 400 cases and 26 variables with 1 class label to indicate the presence or absence of CKD and 25 features (numerical and categorical). For ensuring the reliability of the ML model, the dataset is preprocessed well because there is a high percentage of missing values generated by the clinical nature of the dataset. Preprocessing starts with missing value treatment, where missing values occur in more than 20% of the dataset. Specifically, there are some missing values in variables such as SC, albumin, red blood cells, blood pressure (BP), and blood glucose random (BGR).

Mean of the same attribute is used to replace the missing value for continuous numerical variables such as age, BP, blood glucose, SC, and blood urea. For instance, if the mean SC of the dataset mean is 1.48 mg/dL, it is used as the imputation value for missing values for this attribute. The mode (most common category) is used to impute categorical variables like RBC (red blood cells), PC (push cell), HTN (hypertension), DM (diabetes mellitus), and appet (appetite). For example, all such missing values for this attribute are replaced by “normal” whenever “normal” is the mode in RBC. In a manner that causes no statistical bias, the algorithm helps to ensure the integrity and distribution of original data.

Coding of categorical attributes to make them machine readable follows missing value imputation. There are roughly 12 categorical attributes like RBC (Red Blood Cells), PC (Packed Cell), PCC (Pus Cell Count), BA (Bacteria), HTN (Hypertension), DM (Diabetes Mellitus), CAD (Coronary Artery Disease), appet (Appetite), PE (Pedal Edema), and ANE (Anemia) in the CKD dataset. On the basis of the number of categories, one-hot encoding along with label encoding is employed collectively to convert them. Label encoding is applied for binary categorical variables like HTN (“yes”/“no”) or appet (“good”/“poor”), with “yes” being mapped as 1 and “no” as 0. One-hot encoding is employed to get separate columns for each category of multiclass variables like RBC (“normal” and “abnormal”), adding the dimensionality without making the model incompatible. Based on the number of unique categories present in each categorical feature, the dataset stretches from 26 features to about 35–40 features after encoding.

The numerical features of the dataset, including age, BP, BGR, BU, SC, and SOD, are subsequently scaled using Min–Max scaling. This type of transformation normalizes all numeric features to a value between 0 and 1 in a bid to avoid any individual feature overpowering the learning process. BP is between 50 and 180 mmHg and SC between 0.4 and 15 mg/dL. Without normalization, features with larger magnitudes would overwhelm the gradient updates in training and warp the results. Finally, class imbalance is an important problem for the CKD dataset.
