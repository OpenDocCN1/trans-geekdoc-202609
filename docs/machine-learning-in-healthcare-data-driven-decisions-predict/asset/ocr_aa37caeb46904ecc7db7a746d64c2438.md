# 3.3 Feature Selection and Engineering

FS will then be used to select the most significant predictors from among the vast pool of data. The individual significance of the continuous features and the categorical features, respectively, will first be measured using univariate statistical tests such as ANOVA and chi-square. RFE will next be used to build most important features iteratively based on model performance. Moreover, Ridge and Lasso regression will be used to impose feature regularization through removal of duplicate features through the penalization of the coefficients. Model-based FS will further be used using the importance score of the features generated by ensemble algorithms such as random forest or gradient boosting capable of nonlinear and interaction relationships.

Feature engineering will be utilized to refine the model further in order to find complex patterns. New composite features will be created through concatenation of existing features so that more useful relations are revealed and predictability is improved. To reduce high-dimensional data dimension, dimension-reduction techniques will be utilized for data exploration as well as removal of noise from data. Furthermore, sequence and genomic data will be investigated using embedding techniques for representation as dense vector representations that capture biological or time underlying patterns in raw genomic sequences or time-series clinical data. The feature engineering and selection methodologies described are intended to achieve optimal model performance and best use of pertinent information for accurate predictions [30].

# 3.4 Machine Learning Model Development

(i) Structured Data: A robust gradient boosting algorithm, XGBoost, will be utilized for structured data including clinical data, genomic data, and biomarker data. XGBoost is highly appreciated for its performance and efficiency in processing tabular data with a combination of numerical and categorical variables, which makes it a perfect candidate for predictive modeling in oncology. At the center of XGBoost lies an additive tree ensemble model that has been trained using a regularized objective function optimized by minimizing

```
Obj(θ) = \sum_{i=1}^{n} l(y_i, \hat{y}_i^{(t)}) + \sum_{k=1}^{t} \Omega(f_k)
```
