## 3.2 Data Preprocessing

To ensure data consistency and enhance the performance of deep learning models, a rigorous preprocessing pipeline was implemented to address the image quality, scale, and lighting variations in the ChestX-ray14 dataset. To ensure compatibility with popular CNN architectures such as ResNet and DenseNet, all the images were initially downsampled uniformly from their original resolution of 1,024 × 1,024 pixels to 224 × 224 pixels. This lowered the computational load without sacrificing desirable diagnostic characteristics. To encourage faster convergence and uniform gradient flow through training, pixel intensities were subsequently scaled to the [0, 1] interval using division by 255.

Contrast limited adaptive histogram equalization (CLAHE) was employed to enhance contrast and render fine anatomical structures more visible; this method is particularly effective for low-contrast or underexposed radiographs. During training, a robust data augmentation method was employed in real time to address class imbalance and prevent overfitting. The model’s ability to generalize to unseen data was greatly improved by these augmentations, which comprised random horizontal flipping, minor rotations (±10°), translations, zooming (±10%), and brightness changes. Moreover, to reduce high-frequency noise while preserving essential edge and lesion details, a Gaussian blur filter with a standard deviation (σ) of 0.5 was applied. To eliminate images that were either overexposed or underexposed, which is often due to acquisition issues, outlier filtering was ultimately performed using histogram-based intensity thresholding. This preprocessing operation successfully normalized the dataset and prepared it for solid and accurate feature extraction in the next tasks.

## 3.3 Proposed Feature Extraction

MSAG-DFE is a robust, modular, and hierarchical feature extraction technique that combines the advantages of attention mechanisms with multi-scale convolutional learning to produce more discriminative and relevant features. Figure 2 shows the multi-scale fusion and Figure 3 depicts the attention mechanism framework.

**Step 1:** Load the input chest X-ray image \( I \in \mathbb{R}^{224 \times 224} \) from the preprocessed NIH ChestX-ray14 dataset.

**Step 2:** Initialize three parallel convolutional branches with kernel sizes 3×3, 5×5, and 7×7 to extract features at different scales.

**Step 3:** Pass the image through each branch to obtain multi-resolution feature maps:

```
\( F_k = \text{ReLU}(W_k \star I + b_k), k \in \{3, 5, 7\} \) (1)
```

![](img/106ef0dba620d314f9842503e8ef40c8_302_0.png)

Figure 2: Multi-scale fusion proposed framework.

Step 4: Concatenate the outputs from the three branches to form the combined multi-scale representation:

```
$F_{multi} = Concat(F_3, F_5, F_7)$
(2)
```

Step 5: Compress each channel of $F_{multi}$ to a scalar using global average pooling:

```
$z_c = \frac{1}{H \times W} \sum_{i=1}^H \sum_{j=1}^W F_{multi}^{(c)}(i,j)$
(3)
```

Step 6: Apply two fully connected layers to compute channel-wise attention weights:

```
$s = \sigma(W_2 \cdot ReLU(W_1 \cdot z))$
(4)
```

Step 7: Scale the feature maps using the learned weights:

```
$F_{cam}^{(c)} = s_c \cdot F_{multi}^{(c)}$
(5)
```

Step 8: Compute average-pooled and max-pooled features across the channel dimension:

- Attention Mechanism (Contribution *)
- Spatial Attention (Local importance)
- Channel Attention (Semantic enhancement)
- Attention Fusion (Weighting Features)
- Feature Fusion + Hierarchical Learning
- Classifier Layer (Sigmoid)
- Epoch Loop: Backpropagation + Optimization
- If Not Converged
- Validation & Early Stopping (AUC Monitoring)
- If Converged
- Test Evaluation: AUC, Accuracy, F1, Recall
- Predicted Labels for 14 Diseases

Figure 3: Attention mechanism proposed framework.

\( F_{avg} = \text{AvgPool}(F_{cam}), F_{max} = \text{MaxPool}(F_{cam}) \)

**Step 9:** Concatenate and convolve with a \( 7 \times 7 \) kernel to generate spatial attention:

\( F_{spatial} = \sigma(\text{Conv}_{7 \times 7}([F_{avg}; F_{max}])) \)

**Step 10:** Multiply the channel-attended feature map with the spatial attention map:

\( F_{attn} = F_{cam} \otimes F_{spatial} \)

**Step 11:** Fuse the attended features with the original multi-scale output:

\( F_{final} = F_{multi} + F_{attn} \)

**Step 12:** Apply global average pooling on \( F_{final} \) to obtain a 1D feature vector:

\( f = \text{GAP}(F_{final}) \)

**Step 13:** Apply dropout to prevent overfitting and encourage generalization:

\( f_{drop} = \text{Dropout}(f) \)

**Step 14:** Feed the dropout-regularized features into a fully connected layer with Softmax activation:

\( y = \text{Softmax}(W_{cls} \cdot f_{drop} + b_{cls}) \)

**Step 15:** Output the final probability vector \( y \in \mathbb{R}^{14} \) corresponding to the 14 thoracic disease classes.

Efficiency of the proposed MSAG-DFE model was significantly enhanced by the preprocessing pipeline employed for the ChestX-ray14 dataset. All the chest radiographs were resampled from 1,024 × 1,024 pixels to 224 × 224 pixels, which improved computational efficiency while preserving vital diagnostic information. During training of the model, steady gradient flow was maintained by normalizing pixel intensity between the range [0, 1]. Detailed feature extraction demands the visualization of subtle anatomical boundaries, which CLAHE further enhanced, especially in low-contrast or underexposed images. Lesion contours and structural borders were maintained while high-frequency noise was reduced by applying a Gaussian blur filter with a standard deviation of 0.5. The model’s ability to generalize was improved with real-time data augmentation that corrected class imbalance and introduced randomness through random flipping, minor rotations, zooming, and brightness adjustments.

A cleaner and more regular set of data was achieved by implementing histogram-based intensity thresholding to eliminate overexposed or underexposed images caused by acquisition issues. These preprocessing techniques collaborated to enhance the accuracy of the MSAG-DFE model’s deep, attention-focused feature extraction. The sensitivity of the model was enhanced, especially for rare diseases, because the attention mechanisms were able to focus more intently on pathologically important regions. A robust and scalable solution was achieved by combining this stringent preprocessing pipeline with the MSAG-DFE architecture. This provided good generalization across different classes of illness, accelerated convergence during training, and superb diagnostic performance. This demonstrates how the MSAG-DFE architecture can be applied clinically to diagnose thoracic disease in real-world applications using large chest X-ray datasets.
