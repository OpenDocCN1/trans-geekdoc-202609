**Spatiotemporal Disease Modeling Module:** The spatiotemporal disease modeling module aims to shed light on the complex spatial and temporal dynamics of disease spread between geographical locations. It applies a GNN to represent spatial relations in which nodes are used to record individual geographic positions like districts or cities and edges are used to record true relations like human movements and transport networks. In order to effectively model temporal change, the GNN is coupled with a TCN [20] or a transformer so that the system can learn patterns of disease progression between fine-grained time steps (hourly or per day). The dual architecture allows the learning of dynamic spatiotemporal correlations that allow the model to make predictions about how diseases spread through space and time correctly. This dual strategy allows proactive public health actions by revealing burgeoning hotspots and predicting outbreaks to come. Let the disease spread network be represented by a graph

```
G = (V, E, A)
```

In eq. (1) \( V = \{v_1, v_2, \dots, v_n\} \) is the set of nodes each representing a geographic unit, \( E \) is the set of angles representing mobility or interaction, and \( A \in R^{N \times N} \) is the adjacency matrix, where \( a_{ij} \) reflects the strength of connection. Each node \( v_i \) is associated with feature vector at time \( t \). For example, cumber of cases, population density, and hospital load.

The GNN or graph attention network to capture spatial dependencies. A common GCN update rule at layer \( l \)

```
H^{(l+1)} = \sigma(AH^{(l)} W^{(l)})
```

where \( A \) is the normalized adjacency matrix with self-loops, \( H^{(l)} \in R^{N * d_t} \) are the node features at layer \( l \) and \( W^{(l)} \) are the learnable weight matrix and \( \sigma \) is the nonlinear function. The output is given by

```
H_{\text{spatial}} = \text{GNN}(X^{(t)}, A)
```

A TCN applies to 1D convolutions over the temporal axis per node is given by

```
H_{\text{temporal}} = \text{TCN}(H_{\text{spatial}}^{1:T})
```

Each node's time series is processed as

```
h_i^{(t)} = f_{\text{TCN}}(h_i^{(t-k+1)}, \dots, h_i^{(t)})
```

In eq. (12) \( k \) is the receptive field and \( f_{\text{TCN}} \) is a stack of dilated casual convolutions.
