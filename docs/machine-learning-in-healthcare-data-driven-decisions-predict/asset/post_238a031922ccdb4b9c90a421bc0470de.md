For handling the imbalance problem and enhancing the robustness of the model towards different imaging conditions, these techniques are applied to minority classes specifically. To ensure computational efficiency, all images are resized to 256 x 256 pixels upon preprocessing. Pixel intensity values are normalized to bring them within the range of [0, 1]. The existence of single-cell segmentation masks is an essential element of this dataset, allowing it to be applied to detection and segmentation-based approaches in conjunction with classification. The Herlev dataset provides a solid foundation for developing and contrasting cervical cancer classification systems based on contextual and morphological information due to its richness.

## 3.2 Proposed Algorithms

### Algorithm 1: Dual-Branch Multi-scale Convolutional Feature Extraction (DB-MSFE)

The objective of the algorithm as shown in Figure 2 is to capture robust morphological and contextual features from cervical cytology images by leveraging multi-scale convolutional branches.

- Step 1: Input cytology image \( I \in R^{H \times W \times C} \).
- Step 2: Normalize pixel intensities to [0, 1] range:

\( I_{\text{norm}} = \frac{I - \min(I)}{\max(I) - \min(I)} \) (1)

- Step 3: Apply standard convolution in Branch A:

\( F_A^{(1)} = \delta(\text{Conv}_{3 \times 3}(I_{\text{norm}})) \) (2)

- Step 4: Apply dilated convolution in Branch B:

\( F_B^{(1)} = \delta(\text{DilatedConv}_{5 \times 5, r=2}(I_{\text{norm}})) \) (3)

- Step 5: Add depth-wise separable convolution to reduce parameters:

\( F_A^{(2)} = \delta(\text{DepthSepConv}_{3 \times 3}(F_A^{(1)})) \) (4)

### Figure 2: Proposed Algorithm 1.

- Step 6: Integrate spatial dropout for regularization:

```
F_B^{(2)} = SpatialDropout(F_B^{(1)}, p=0.3)
```

- Step 7: Concatenate the two branches:

```
F_concat = [F_A^{(2)}; F_B^{(2)}]
```

- Step 8: Apply 1 x 1 convolution for dimensionality alignment:

```
F_aligned = Conv_{1 x 1}(F_concat)
```

- Step 9: Batch normalization and pooling:

```
$$F_{pooled} = \left( MaxPool_{2 \times 2} \left( F_{aligned} \right) \right)$$
```

- Step 10: Output feature map $F_0 \in R^{\frac{H_1}{2} \times \frac{W_1}{2} \times D}$ used for the next stage.

### Algorithm 2: Hierarchical Cross-Fusion Block (HCFB)

The main objective of algorithm 2 as shown in Figure 3 is to fuse features from multiple resolutions using cross-level and intra-level attention to enhance discriminative capacity.

- Step 1: Receive features from multiple encoder levels: $\{F_1, F_2, F_3, ..., F_n\}$

- Step 2: Resize all features to a common spatial size \( H' \times W' \)

```
$$\hat{F_i} = Upsample(F_i), \ i = 1, ..., n$$
```

- Step 3: Compute global average pooling (GAP) for channel descriptors:

```
$$g_i = GAP\left(\hat{F_i}\right) \in R^C$$
```

- Step 4: Apply channel-wise attention:

```
$$CA_i = \sigma(W_2 \cdot \delta(W_1 \cdot g_i))$$
```

- Step 5: Reweight channels using attention:

```
$$F_i^{CA} = CA_i \odot \hat{F_i}$$
```

- Step 6: Perform self-attention spatial encoding:

```
$$SA_i = Softmax\left(Q_i K_i^T / \sqrt{d} \right) V_i$$
```

where \( Q_i = F_i^{CA} W_Q, K_i = F_i^{CA} W_K, V_i = F_i^{CA} W_V \)

- Step 7: Apply spatial attention enhancement:

\(F_i^{SA} = BN(SA_i + F_i^{CA})\) (14)

- Step 8: Fuse adjacent levels:

\(F_i^{fusion} = \alpha_i F_i^{SA} + \beta_i F_{i+1}^{SA} + \gamma_i F_{i+1}^{SA}\) (15)

- Step 9: Residual connection across all fused levels:

\(F_{res} = \sum_{i=1}^n (F_i^{fusion} + F_i^{'})\) (16)

- Step 10: Output fused hierarchical representation:

\(F_{fused} = Conv_{3 \times 3}(F_{res})\) (17)

### Algorithm 3: Class-Aware Feature Reweighting and Loss Optimization (CA-FRLO)

The main objective of algorithm 3 as shown in Figure 4 is to address class imbalance and improve sensitivity to minority classes during training.

- Step 1: Let dataset \(D = \{(x_i, y_i)\}_{i=1}^N\), with \(y_i \in \{1, ..., K\}\) (18)

- Step 2: Compute class frequencies:

\(f_k = \frac{1}{N} \sum_{i=1}^N I(y_i = k)\) (19)

- Step 3: Compute class-aware weights:

\(w_k = \frac{1}{\log(\delta + f_k)}\), where \(\delta = 1.02\) (20)

- Step 4: Predict class probabilities from logits \(\{z_k\}_{k=1}^K\)

\(p_k = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}}\) (21)

- Step 5: Compute class-weighted cross-entropy loss:

\(L_{CE} = - \sum_{i=1}^N w_{y_i} \log (p_{y_i})\) (22)
