

- Step 15: The output from both forward and backward LSTM layers is concatenated

```
\(h(t) = [h_{\text{forward}}(t); h_{\text{backward}}(t)]\)
```

This concatenated output is passed to the fully connected layer for prediction.

- Step 16: The concatenated output is passed through a fully connected layer to predict the output:

```
\(y^{\wedge}_{Bi-LSTM} = \sigma(W_f h(t) + b_f)\)
```

where \(W_f\) and \(b_f\) are the weight and bias for the fully connected layer.

- Step 17: The output from both models (random forest and Bi-LSTM) is combined. The final prediction \(y^{\wedge}_{final}\) is computed as

```
\(y^{\wedge}_{final} = \alpha \cdot y^{\wedge}_{RF} + (1 - \alpha) \cdot y^{\wedge}_{Bi-LSTM}\)
```

where \(\alpha\) is a hyperparameter that decides the contribution of each model.

- Step 18: Ten-fold cross-validation is applied to ensure generalizability.

- Step 19: A mobile app prototype is developed. This is used to provide teleconsultation, medication reminders, and appointment booking. React native is applied for cross-platform development.

- Step 20: User interaction logs are analyzed to measure engagement. This is applied using

```
\(\text{Engagement rate} = \frac{\text{Active users}}{\text{Total users}} \times 100\)
```

Wait time reduction is measured by logging time between appointment request and consultation.

- Step 21: Model retraining is applied every 30 days using new data from patient logs. This ensures that diagnostic predictions remain accurate and adapt to seasonal or demographic changes.

## 4 Experimentation Results

Simulations were conducted on a workstation with an Intel Core i9 processor, 64 GB RAM, and an NVIDIA RTX 3090 GPU, run in Python with TensorFlow and Scikit-learn to benchmark the performance of the proposed DigiCare framework. Synthetic time-series sensor data was produced in order to simulate IoMT streaming conditions, and sampled structured clinical data was drawn from the MIMIC-III dataset. The Scikit-learn optimized ensemble library was employed for random forest execution, while Keras with GPU backend was employed to execute the Bi-LSTM component.

Three models that are most commonly used were chosen for comparison: CNN-LSTM, SVM, and logistic regression (LR). CNN-LSTM was chosen since it is better than the other two models in spatiotemporal modeling of healthcare data, while LR and SVM were chosen since they are most frequently used in baseline classification issues. For verifying the improved ability of the proposed hybrid model, these models were compared to it (random forest + Bi-LSTM). Evaluation was done using accuracy, precision, recall, F1-score, and area under the receiver operating characteristic curve (AUC-ROC). To further quantify the ability of the model to distinguish between high-risk and low-risk patients at different threshold settings, AUC-ROC was added.
