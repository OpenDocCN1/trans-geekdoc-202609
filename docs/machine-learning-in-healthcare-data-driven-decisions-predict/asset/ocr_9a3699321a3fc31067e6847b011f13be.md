Logistic Regression: It is applicable for binary classification cases. The presence or absence of a disease, for instance, is predicted.

Support Vector Machines: They are highly beneficial, especially in high-dimensional space, for both linear and nonlinear classification [6].

Decision Trees: Derived from above, they are tree-like structures that break down data according to values of features, leading to a diagnosis at the leaf node.

Random Forests: When many decision trees are provided with an ensemble, the trees can be grown quite accurately, but this reduces the tendency to overfit [7].

Gradient Boosting Machines (GBMs): Another algorithm in this line is where an ensemble combines several weak learners to form one strong predictive model.

Neural Networks: These are complex models inspired by the human brain that learn complicated patterns through large datasets, particularly image and text analysis.

Unsupervised Learning: These learning algorithms work with unlabeled data [8]. The performance or effectiveness of said learning algorithms is seen in the hidden and/or discovered patterns and structures within that data.

Clustering: Algorithms like k-means clustering can be used to cluster the same data points into several groups and help in identifying distinct d patients into subtypes, based on the differences in their data and features.

Dimensionality Reduction: Techniques like principal component analysis help reduce the number of variables in a data set while retaining the more essential elements for easy analysis and better model performance [9].

Deep Learning: It refers to one of the subfields of ML that attempts to learn from artificial neural networks. It has numerous stacked layers (deep neural networks) and is used mostly for learning complex representations from data. The greatest impact of deep learning has been in analyzing medical images and natural language processing for understanding clinical text.

CNNs: These types of neural networks are made for medical image analysis, X-ray, MRI, CT scan, etc.

Recurrent Neural Networks: These are mainly made for temporal data like health records from electronic or wearable devices, which track data over a period of time [10].

Transformers: They are a relatively new class of neural network that has shown much promise in natural language processing and is increasingly being used in other types of medical data.
