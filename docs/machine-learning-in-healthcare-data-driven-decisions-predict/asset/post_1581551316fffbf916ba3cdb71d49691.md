#### 4.1.1 Correlation Between Emotional States and Physiological Parameters

In our customized dataset, there are a total of 80 features, where ID and date are removed in the correlation. When we find the correlation between physiological data and emotions, it looks very messy and does not provide any good insight, so we only show the most significant features correlated with the emotions in Table 2. We take the correlation range from -0.4 to 0.6 for better and clearer visibility of patterns among the data. From Table 2, we observe that FilteredDemographicVO2max and resting heart rate show the highest correlation. ### 4.1.2 Machine Learning Models

We present our results related to emotional state prediction from physiological and survey data. The ML algorithms that we use are: (I) SVM, (II) LR, (III) DT, and (IV) RF. After that, to improve the accuracy, we propose a (v) hybrid machine learning model that combines the predictive strengths of four classifiers. We first apply feature weighting based on the correlation as in Table 2. From the correlation, we find that FilteredDemographicVO2max and resting_hr show the highest correlation. Features with weaker correlation are either left unweighted or assigned a lower weight. Next, we divide the dataset into three parts: training, validation, and testing, with a ratio of 60:20:20. Below, we provide details about all the ML algorithms we apply.

- **(I) SVM**: The SVM classifier uses to evaluate its effectiveness in classifying the dataset. The model achieves a testing accuracy of 72.56%.

- **(II) LR**: Using the LR class from the sklearn library with the liblinear solver, the model trains on the dataset and achieves an accuracy of 74.11%.

- **(III) DT**: Initially, the DT model provides a test accuracy of 72.43%. To enhance its performance, we adjust the maximum depth of the tree. A plot of training and validation curves reveals that they align closely up to a maximum depth of 4 (as shown in Figure 7). Setting the tree's maximum depth to 4 yields an improved accuracy of 74.92%.

- **(IV) RF**: The RF model initially achieves a test accuracy of 78.01%. To further enhance performance, we conduct hyperparameter tuning using RandomizedSearchCV. This process explores a variety of parameters, including the number of estimators (n_estimators), maximum depth (max_depth), minimum samples required for splits (min_samples_split), minimum samples per leaf (min_samples_leaf), and others. After tuning, the model's accuracy improves slightly to 78.75%.

The details about the hyperparameter tuning appear below:

**Hyperparameter Tuning**: We hyper-tune the model using grid search and randomized search to optimize the model's performance. Grid search exclusively searches over a set of predefined hyperparameters to find the best combination, while randomized search samples from a range of values, offering faster tuning with less computational cost. The tuning process also involves k-fold cross-validation (here we use 5-fold) to maintain the class distribution. The hyperparameter tuning does not affect the LR, SVM, and LightGBM improvements.
