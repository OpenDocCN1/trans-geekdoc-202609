## 2 Related Works

Ramteke and Maidamwar [6] use three machine learning models such as XGBoost, support vector machine (SVM), and k-nearest neighbor (kNN) to make an ensemble model. XGBoost can determine complex relations from the training data, and SVM can detect boundaries in nonlinear domains. kNN is a simple model that uses the neighbors for classification. The abovementioned strengths are combined to make a powerful ensemble classification method. The ensemble classification produces an accuracy of 88.52%. The study proves that integrating multiple models can be achieved in powerful, reliable models.

The detection of disease in a patient needs more powerful medical devices, which sometimes come at a high price, and this makes many small hospitals difficult to purchase. The use of machine learning models can detect disease without the need for powerful devices. However, these machine learning models face another problem called the class imbalance problem. A class imbalance problem is one where the number of instances in one class is relatively greater than the number of instances in another class in the training set. This problem reduces the ability of a machine learning classification model to identify patterns in the dataset. The use of ensemble learning overcomes the class imbalance problem and outlier detection [7].

AlJame et al. [8] use XGBoost as an ensemble learning approach. The missing values in the dataset are imputed using the kNN method, the outliers are fixed using the isolation forest method. The number of instances in the positive and negative classes in the dataset of 5,644 instances is 5,085 and 559, which indicates that the dataset is a pure imbalance dataset. The SMOTE method is used to create a new balanced dataset with an equal number of instances in both classes. The proposed ensemble method, XGBoost, outputs an accuracy of 99.9%. The authors compared their work with the other works in their literature and concluded with promising results.

Senthilkumar and Prabhusundhar [9] use a recursive feature elimination technique to improve classification performance. The imbalanced dataset is converted to a proper dataset with an even number of instances in all classes using the modified SMOTE method. Many classification models were used by the authors, and they found that XGBoost is the one that produces the best results with an accuracy of 95.6%.

## 3 Background

In this section, we briefly talk about the four methods of ensembling used in classification, which are bagging, boosting, voting, and stacking.

### 3.1 Voting

The voting-based ensemble method is the simplest way to combine multiple models to create a powerful single model [10]. The output of different classifiers is used for aggregation to reach a consensus prediction [11]. There are two types of voting known as hard voting and soft voting [12].

Hard voting is also called majority voting. In this method, each base model is trained independently, and all the models predict a class for the input instance. The final class for the input instance is determined by taking the majority vote [13]. This method does not rank any model and treats all the model predictions equally, irrespective of the accuracy or confidence level. For example, if there are three models A, B, and C, and the predictions of the models are class 0, class 1, and class 0, respectively, then class 0 is selected as it has the majority vote [14].

In soft voting, each model predicts an output probability distribution over all classes rather than predicting a single class [15]. Soft voting is generally better than the hard voting because the confidence of base models is different [16].

- The voting ensemble method has the following benefits:
  - 1. By aggregating multiple models, the accuracy of the combined model may be greater than the individual models.
  - 2. If any one model is weak for a specific dataset, the voting ensemble method becomes less sensitive to it, as the other models can compensate for the weakness.
  - 3. This method is very simple to use and does not require any complex methods such as boosting or stacking.
  - 4. Any model can be used in voting without any restrictions, making this method very flexible and versatile.

For example, if there are three models: random forest (RF), kNN, and decision tree (DT). Let us say the accuracy of the models is 81%, 85%, and 82%, respectively, then after voting ensemble is applied, the accuracy of the combined model may be increased to 88%.

### 3.2 Bagging Methods

Bootstrap aggregating, also known as bagging, is a powerful ensemble method used to increase the performance and stability of machine learning-based algorithms. It is particularly effective in classification and regression-based works. Bagging combines multiple base learners and reduces the overall variance of a model. In this method, each model is trained on a different subset of the training data so that the models learn most of the patterns and relationships in the dataset. This method is particularly used for high variance and low bias models like DTs [17].

The main concept behind the bagging methodology is to create multiple variations of classifiers and use them all to get the final classification result. In classification, the final consolidation is done by a majority vote, where each model casts a vote for a class, and finally, when all the models complete the voting process, the class is selected as the final result based on the majority vote.
