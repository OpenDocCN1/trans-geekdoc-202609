```
\sum_{k=1}^K \Delta w_t^k = \sum_{i=1}^K \sum_{i=1}^M s_i^k
```

As long as a subset of shares (less than _M_) cannot reconstruct \(\Delta w_t^k\), the client's data remains secure. The aggregation is done without reconstructing individual updates and its privacy is preserved. To increase generalization across clients with varied patient populations and data distributions, PFL is used.

PFL accounts for heterogeneity in client data distributions, which frequently occurs in multi-institutional clinical research. In PFL, each client fine-tunes the shared global model on its local dataset after global model training is finished. The model is able to learn from the shared global knowledge, while also adapting the model performance towards the clients' specific data characteristics, such as population demographics or disease prevalence. In this manner, PFL achieves generalization while maintaining privacy. PFL is especially useful in healthcare where patient populations differ greatly across different institutions. Let W_T represent the final global model after T rounds of FL. Client _k_ performs the local fine-tuning by minimizing a personalized objective:

```
w_T^{k, PFL} = \arg[F_k(w) + \lambda ||^2]
```

Here, \(F_k(w)\) is the local empirical loss on client _k_’s data, \(\lambda ||w - w_T||^2\) is a regularization term to prevent overfitting and retain global knowledge. This is also known as local regularization and is a common PFL technique.

**Clustering-Based Aggregation**: Clustering-based aggregation is implemented to significantly improve model speed and capacity when non-IID data is present. Using characteristics like label distribution, gradient similarity, or update distance, this technique creates clusters of clients with comparable data distributions. Within each cluster, models are aggregated separately, creating multiple semi-specialized models instead of a single global model. This strategy reduces the negative impact of aggregating highly dissimilar updates and improves training efficiency and accuracy for clients with aligned data characteristics. Assume the clients are portioned into C clusters \(\{C_1, ... C_c\}\) based on a similarity metric sim \((k_i, k_j)\). For each cluster _C<sub>v</sub>_, the server performs a cluster-wise model update:

```
w_{t+1}^{(c)} = \sum_{k \in C_c} \frac{n_k}{\sum_{j \in C_c} n_j} w_t^k
```

Each client in cluster _C<sub>c</sub>_ receives its corresponding cluster-specific model \(w_{t+1}^{(c)}\) for the next training round. Clustering can be based on cosine similarity of gradient updates or distributional divergence between client datasets [24].
