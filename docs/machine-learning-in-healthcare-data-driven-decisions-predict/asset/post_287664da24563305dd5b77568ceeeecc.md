
This process continues iteratively until all features are either confirmed or rejected based on statistical significance using a two-sided binomial test. The strength of complementing Boruta with a light neural network is that it can capture complex nonlinear relations and interactions between variables, which is especially useful in datasets where there are structured clinical predictors and high-dimensional, dense text embeddings. By choosing features with persistently strong importance alone, this approach not only improves model performance but also limits overfitting risks and enhances model interpretability.

## 3.3 Proposed Ensemble Framework: Triple Neuro-probabilistic Ensemble (TNPE)

The model is built from three various base learners, which were chosen because they possess complementary learning paradigms and decision boundaries:

- (i) Extreme Learning Machine (ELM): ELM is a single-hidden layer feedforward neural network with random initial weights between the input layer and the hidden layer that are not updated during training [27]. The only learnable parameters are those between the hidden layer and the output layer, hence computationally more efficient. For an input feature vector

```
X = [x1, x2, ..., xd]^T
```

where d is the number of features and g(.) is typically a sigmoid or ReLU activation function. The inputs X are mapped to the hidden layer through a random weight matrix:

```
W = R^{N*d}
```

Here, N is the number of hidden nodes. The hidden layer output is computed using a nonlinear activation function g(.):

```
H = g(Wx + b)
```

where b is the bias term and g(.) is typically a sigmoid or ReLU activation function. The output layer is computed using a weight vector ∈ R^N, which is learned using a linear regression approach by minimizing the least squares error. The output ŷ is given as follows:

```
ŷ = H^T β
```

The weights \(\beta\) are determined by solving the following optimization problems:

```
\(\beta = (H^T H)^{-1} H^T y\) (8)
```

In eq. (8) y is the vector of target outputs.

- (ii) Probabilistic Neural Network (PNN): The PNN is a radial basis function (RBF) network designed for probabilistic pattern classification. It works by estimating the conditional probability distribution of the output class given the input data [28]. PNNs are particularly useful in classification tasks where probabilistic outputs and uncertainty quantification are needed, such as in medical decision-making. Let an input vector \(x \in R^d\), the PNN computes the output class probability \(P(C_k|x)\) for each possible class \(C_k\) using the following steps:

  - (i) Radial basis function (RBF): The hidden layer applies an RBF kernel to compute the similarity between the input vector X and every training sample \(x_i\)

  ```
  \(\phi_i(x) = \exp \left( - \frac{||x - x_i||^2}{2\sigma^2} \right)\) (9)
  ```

  where \(\sigma\) is the width of the RBF kernel, controlling the smoothness of the decision boundary.

  - (ii) Class Probability Calculation: The output for class \(C_k\) is calculated by summing the contribution of each training sample \(x_i\) for that class, weighted by the RBF output:

  ```
  \(P(C_k|x) = \frac{\sum_{iy_i=C_k} \phi_i(x)}{\sum_{i=1}^n \phi_i(x)}\) (10)
  ```

  where \(y_i\) is the class label of the training sample and the denominator normalizes the output to ensure the sum of probabilities across all classes equals 1. PNNs are especially strong in medical decision-making due to their potential to offer each class's probability estimate, thus being interpretable and beneficial for clinical risk assessment.

- (iii) CatBoost: It is an algorithm of gradient boosting tailored for processing categorical features efficiently. Unlike regular gradient boosting algorithms such as XGBoost and LightGBM, CatBoost is built to process categorical variables natively without deep preprocessing like one-hot encoding or label encoding being necessarily required. CatBoost also has methods to prevent overfitting and is particularly suited for small and mixed-type data. The CatBoost algorithm is a type of gradient boosting DTs, where each next tree is learned to reduce the residual of the previous trees. The model output in each iteration is given by

```
\(\hat{y}^{(t)} = \hat{y}^{(t-1)} + \eta h_t(x)\) (11)
```

where \(\hat{y}^{(t-1)}\) is the prediction from the previous iteration, \(\eta\) is the learning rate, and \(h_t(x)\) is the output of the \(t\)th tree. CatBoost incorporates ordered boosting, which helps prevent overfitting by using only past data points (without leakage from future data) to calculate the splits during the training process. In the case of categorical features, CatBoost applies a specific encoding strategy known as ordered target encoding to transform categorical variables into numeric values. This method computes the mean target per category without overfitting using an ordered strategy to avoid target leakage. The encoding of a category c can be computed as

> \(\text{Enc}(c) = \frac{1}{N_c} \sum_{i \in C} y_i \quad (12)\)

where \(C\) denotes the collection of data points belonging to category \(c\), and \(N\) denotes the number of data points that fall into category \(c\). CatBoost is particularly well-suited for datasets that contain mixed-type features (categorical and numerical) since it minimizes the requirement for heavy preprocessing and prevents overfitting by virtue of its ordered boosting and target encoding mechanisms.

## 3.4 Ensemble Integration: Optimized Soft Voting

In this study, the ultimate prediction for detecting depression and anxiety is achieved when the predictions of a number of base learners are combined by means of an optimized soft voting mechanism [29]. Soft voting is a probability-based approach in which each prediction of the base learners is combined by averaging their probability outputs. The output with the maximum averaged probability is chosen to be the final output. Yet, in order to enhance the performance of the ensemble model, PSO is used to dynamically adjust the weights of each base learner’s contribution toward the soft voting. The adaptive weighting is useful in enhancing the prediction accuracy of the ensemble by placing greater emphasis on the base learners performing well in the validation set.

Soft Voting Model: Let there be M base learners, each of which outputs a probability distribution over the potential classes. Let the predicted probability distribution of class \(k\) for the \(i\)th instance by the \(j\)th base learner be denoted as \(P_{k,j}(x_i)\), where \(x_i\) is the input feature vector.

Predicted Probability for Every Class: In soft voting, the predicted probability for class \(k\) for the whole ensemble is calculated by averaging the probabilities of all \(M\) base learners:

> \(\hat{P}_k(x_i) = \frac{1}{M} \sum_{j=1}^M P_{k,j}(x_i) \quad (13)\)

where $P_{k,j}(x_i)$ is the predicted probability of class $k$ from the $j$th base learner for input instance $x_i$ and $\hat{P}_k(x_i)$ is the aggregated probability. The goal is to maximize the ROC-AUC score of the ensemble on a validation fold by adjusting weights $w_1, w_2, w_3$ for ELM, PNN, and CatBoost, respectively. The objective function is to maximize the following:

$AUC_{Ensemble} = w_1 * P_{ELM} + w_2 * P_{PNN} + w_3 * P_{CatBoost}$

subject to constraints

$0 \le w_i \le 1, \sum w_i = 1$

The final prediction is made by selecting the class with the highest predicted probability:

$\hat{y}_i = (\hat{P}_k(x_i))$

This yields the class $\hat{y}_i$ that corresponds to the highest averaged probability across all base learners.

Optimized Soft Voting Using Particle Swarm Optimization (PSO): While soft voting merely assigns equal weight to the prediction of each base learner, obtain optimal weight of each learner's contribution from how well each performs on a validation set. PSO is a population-based optimization algorithm that replicates the social bird flocking or fish schooling phenomenon [30]. Every particle in the swarm corresponds to a candidate solution, that is, the weights given to the base learners of the ensemble. The weights are updated at each iteration depending on their own best and the global best position discovered by the swarm. Let $w_j$ represents the weight assigned to the $j$th base learner and let the weight vector be $w = [ w_1, w_2, ..., w_M ]$, where $M$ is the number of base learners. Initially the weights are set randomly. The goal of PSO is to find the optimal weights $w$ that minimizes the loss function or maximize performance of the ensemble on the validation set. The fitness function $L(w)$ is defined as

$L(w) = \frac{1}{N} \sum_{i=1}^N L_i(w, x_i, y_i)$

where $N$ is the number of validation instances and $L_i(w, x_i, y_i)$ is the loss for the $i$th validation instance such as cross-entropy loss:

$L_i(w, x_i, y_i) = - \sum_{k=1}^C y_{i,k} \log(\hat{P}_k(x_i, w))$

where $C$ is the number of classes, $y_{i,k}$ is the one-hot encoded true label, and $\hat{P}_k(x_i, w)$ is the repeated probability for class $k$ for the $i$th instance calculated using the weighted sum:
