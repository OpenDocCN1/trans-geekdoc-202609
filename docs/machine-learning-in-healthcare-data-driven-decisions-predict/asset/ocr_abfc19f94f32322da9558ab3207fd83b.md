Moreover, Bayesian data fusion methods are applied to resolve inconsistencies and uncertainties between data modalities in order to generate a coherent, probabilistically consistent representation of the integrated information. This facilitates stronger downstream analytics and model performance, especially in public health surveillance and early warning systems. Let the input be

$D = \{D_1, D_2, \dots, D_N\}$ (1)

where \(D_i\) denotes the set of data sources that correspond to different modalities. For example, \(D_1\) represents the EHRs, denotes the social media, \(D_3\) is the search engine queries, \(D_4\) is the mobility and environmental data, \(D_5\) is the official health notifications, and \(D_6\) represents wearables/IoT sensor data. Let \(X_i \in \mathbb{R}^{d_i}\) represent the observed data vector form source \(D_i\) and \(z \in \mathbb{R}^k\) be the latent fused representation integrating all modalities. The Bayesian data fusion framework aims to infer the posterior distribution over the latent representation z give all observed modalities:

\(P(z|x_1, x_2, \dots x_N) \propto P(z) \prod_{i=1}^{N} P(x_i|z)\) (2)

where \(P(z)\) denotes the latent fused state and \(P(x_i|z)\) is the observed data from source I conditioned on z. This model allows handing of missing modalities. The example likelihood models for structured data (EHRs) are as follows:

\(P(x_1|z) = N(W_1z + b_1, \Sigma_1)\) (3)

For categorical or text data

\(P(x_2|z) = \text{Categorical (softmax}(W_2z + b_2))\) (4)

For time series data

\(P(x_i^{(t)}|z, x_i^{(<t)}) = N\left(f_\theta(z, x_i^{(<t)}), \sigma^2 I\right)\) (5)

The inference via variational Bayesian inference to approximate the posterior:

\(q_\mathcal{O}(z|x_1 \dots x_N) \approx P(z|x_1, \dots x_N)\) (6)

To optimize the evidence lower bound (ELBO)

\(\mathcal{L}(\theta, \mathcal{O}) = E_{q_\mathcal{O}}(z|.)[\sum_{i=1}^{N} \log P_\theta(x_i|z] - KL(q_\mathcal{O}(z)||P(z))\) (7)

The fusion output for downstream tasks, the latent vector z can then be passed to downstream tasks such as

+   - forecasting models
+   - classification tasks
+   - anomaly detection
