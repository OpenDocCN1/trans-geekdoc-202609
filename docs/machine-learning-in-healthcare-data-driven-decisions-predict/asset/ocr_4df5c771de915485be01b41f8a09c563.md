A modified version of the federated averaging (FedAvg) algorithm [20] is adopted to enhance secure aggregation and privacy-preserving mechanisms. The overall goal is to optimize a global model collaboratively across multiple decentralized clients without exposing their raw data. Let K be the number of clients, w_t denote the global model parameters at round t, w_t^k denote the local model parameters for client k at round t, η be the local learning rate, D_k be the local dataset at client k with size n_k, and n = \sum_{k=1}^K n_k is the total number of data points across all clients.

**Initialization:** The first step in the training process is for the central server to initialize a global ML model with an architecture, model, and set of parameters. This model is then sent to all participating client institutions. All clients obtain a copy of this model so that they are all initialized in the same way at the beginning of the training process. The choice of the model architecture will generally depend on the specific clinical task which the FL process is addressing, such as classifying diseases or predicting risk. The central server initializes the global model parameters and then sends this model to all the participating clients:

```
w_o \leftarrow \{ w_o^1, w_o^2 ... w_o^K \} (1)
```

**Local Training:** When each client receives the global model, it then conducts local training on its private dataset. The training must consist of data preprocessing tasks, initially; standardization or normalization, to ensure consistency in input features.
