This work presents a novel hybrid model for classifying strokes from EEG data, which is a time-series with frequency content, by combining DL with meta-heuristic optimization. A CNN and a bidirectional gated recurrent unit (BiGRU) are used in the model to effectively collect time and space information. The CNN-BiGRU model outperformed the harmony search (HS) algorithm, which is excellent at handling frequency data, when it was applied to feature extraction. The multivariate optimization (MVO) approach outperformed the other algorithm when hyperparameter tuning was used. In comparison to previous studies employing portable EEG, the CNN-BiGRU-HS-MVO model achieved a remarkable prediction accuracy of 99.991% when verified using EEG data acquired from Al Bashir Hospital using the MUSE-2 portable equipment. # 2.3 Hybrid Classifier with Feature Selection

Brain stroke is a serious medical condition that needs to be predicted on time and in a suitable manner for appropriate treatment and prevention. A hybrid approach that involves FS methods with ML classifier algorithms has been proposed for improved prediction of brain stroke. The Stroke Prediction Dataset provided in Kaggle has been used, wherein imbalance in the data was handled through the synthetic minority oversampling technique (SMOTE). Five classifiers, naïve Bayes, SVM, RF, adaptive boosting (Adaboost), and extreme gradient boosting (XGBoost), were compared with three FS methods: mutual information, Pearson correlation, and feature importance (FI). The performance was compared in terms of accuracy, sensitivity, specificity, precision, and F-measure using k-fold cross-validation. The best performance was obtained by the hybrid model with FI as the FS method and RF as the classifier. It decreased the features by 36.3% and had an accuracy of 97.17%. The high-dimensional reduction along with a strong classification method allowed the model to make accurate predictions for brain stroke. The results highlight the benefit of this hybrid system to enable early detection of stroke and prevention, with healthcare specialists having a useful tool with which to make timely and targeted interventions toward better patient outcomes and the reduction of complications from stroke [15].
