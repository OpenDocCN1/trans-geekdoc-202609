where \( f_{LGBM} \) is the trained model that outputs class probabilities through an ensemble of decision trees. The probability vector \(\hat{p}\) is transformed using a learnable linear transformation to create a dense embedding vector, which is then used to integrate the ML output with DL components:

```
\( Z_{ml} = \sigma(W_{ml}\hat{p} + b_{ml}) \in \mathbb{R}^k \) (13)
```

where \( W_{ml} \in \mathbb{R}^{k*C} \) is the learnable weight matrix, \( b_{ml} \in \mathbb{R}^k \) is the bias term, and \( \sigma \) is the activation function (ReLU or tan \( h \)). In the hybrid feature fusion layer, the resultant vector \( Z_{ml} \in \mathbb{R}^k \) becomes the conventional ML-derived latent representation, prepared for concatenation.

# ### 3.3.4 Hybrid Feature Fusion Layer

The combined representation employs complementary data modalities and combines spatial, relational, and hand- designed features in a shared latent space. The subsequent vector is then input to a multilayer perceptron (MLP) with dropout regularization and batch normalization. Dropout avoids overfitting by randomly removing neurons during training, and batch normalization stabilizes and accelerates training by normalizing layer inputs. This hybridization technique of merging various forms of features allows the network to integrate various forms of features in a seamless manner to generate stronger and more precise predictions for risk stratification and outcome prediction of function.
