# 3.4.4 Support Vector Machine (SVM)

SVM is an effective classifier that maximizes the margin between classes to determine the optimal hyperplane for class separation. With the use of kernel functions (such as the RBF kernel), SVM can even handle non-linear correlations and performs well with high-dimensional data. SVMs can be computationally costly for big datasets, but they perform well with datasets that have clearly defined boundaries for classes and are robust to outliers [27]. For binary classification, suppose the data is given by

```
D = \{(x_i, y_i)\}_{i=1}^m, x_i \in \mathbb{R}^n, y_i \in \{-1, +1\}
```

SVM tries to find a hyperplane

```
W^Tx + b = 0
```

In this way, the difference between the two classes is maximized. The margin is \frac{2}{||w||}. The goal is to minimize

```
\min_{w, b} \frac{1}{2} ||w||^2
```

Subject to the constraints

```
y_i(W^T x_i + b) \ge 1, \forall i
```
