## 3 System Methodology

### 3.1 Problem Formulation

Let the healthcare decision-making process be modeled as a Markov decision process, defined by the tuple $(S, A, P, R, \gamma)$:

- $S$: set of states representing patient conditions and healthcare environment
- $A$: set of actions corresponding to clinical decisions (e.g., treatment options)
- $P: S \times A \times S \to [0, 1]$: state transition probability
- $R: S \times A \to R^m$: vector-valued reward function with objectives
- $\gamma \in (0, 1)$: discount factor for future rewards

#### 3.1.1 Multi-objective Reinforcement Learning (MORL)

In multi-objective settings, the reward at each step is a vector

```
$r_t = \left( r_t^{(1)}, r_t^{(2)}, \dots, r_t^{(m)} \right)$
```

where each $r_t^{(i)}$ corresponds to an objective such as treatment effectiveness, cost efficiency, or side effect minimization.

The goal is to learn a policy $\pi_\theta(a|s)$, parameterized by $\theta$, which maximizes the expected discounted vector reward

```
$J(\theta) = E_{\pi_\theta} \left[ \sum_{t=0}^{\infty} \gamma^t r_t \right] = \left( J^{(1)}(\theta), J^{(2)}(\theta), \dots, J^{(m)}(\theta) \right)$
```

However, since objectives conflict, we seek the Pareto optimal policy set $\Pi^*$, such that no policy improves one objective without degrading another.
