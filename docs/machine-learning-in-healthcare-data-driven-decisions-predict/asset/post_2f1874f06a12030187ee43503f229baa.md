
## 3.5 Machine Learning Models Used

In this section, we give a brief overview of the machine learning models used in the experiment. The models used in the experiments are:

- 1. **kNN**: kNN is a simple instance-based machine learning model that can be used for classification and regression. It classifies the instances based on the majority label of the instances that are nearest to it in the feature space. The value of k determines how many neighbors need to be considered. The distance between the points is calculated using one of the various distance metrics, such as Euclidean distance or Manhattan distance, or Minkowski distance [28].

- 2. **Random Forest (RF)**: RF is an ensemble learning method that uses multiple DTs and aggregates the results to increase the accuracy. Each tree is trained on a different subset of the data using bootstrapping, and a random subset of features is considered for splitting [29].

- 3. **SVM**: This is a powerful supervised learning algorithm that works by creating an optimal hyperplane that separates classes. The high-dimensional data mapping is done by kernel functions like RBF and polynomial. This is a computationally expensive machine learning model [30].

- 4. **DT**: This is a tree-like machine learning model that splits the dataset based on features to create multiple branches to decide the final class. DTs are easy to visualize, but there is a huge possibility of overfitting [31].

- 5. **Logistic Regression (LR)**: LR is a linear model that is mainly used for binary classification. If the classes are linearly separable, LR is very efficient in classification. LR is highly interpretable [32].

## 4 Experiment and Results

To test and validate the various ensemble models, we use the PIMA Indian diabetes dataset publicly available from Kaggle. The National Institute of Diabetes and Digestive and Kidney Diseases constructs this dataset. There are 768 instances, out of which 500 are normal healthy patients, and the remaining 268 patients have diabetes. All the patients in the dataset are females at least 21 years old. There are nine features in the dataset, and the description of the features is given below.

The Pregnancies feature contains 17 unique values, ranging from 0 to 17. A mean value of 4 was used for imputation, though there were no missing values to address. The Glucose feature includes 136 unique values within a range of 0–199. A mean of 121 was applied for imputation, with no missing values present. The BloodPressure feature has 47 unique values, spanning from 0 to 122. A mean value of 69 was used to impute two missing entries. The SkinThickness feature consists of 51 unique values ranging from 0 to 99. The mean value of 21 was employed to fill in 27 missing values.

The Insulin feature contains 186 unique values between 0 and 846. Although a mean value of 80 was specified for imputation, there were no missing values. The BMI feature has 248 unique values, with a range of 0.0–67.1. A mean value of 32 was used to handle seven missing entries. The DiabetesPedigreeFunction feature shows 517 unique values ranging from 0.078 to 2.42. The Age feature comprises 52 unique values, ranging from 21 to 81. A mean value of 33 was used to impute 21 missing values. Finally, the outcome feature is a binary target variable.

### 4.1 Experimental Setup

The mean imputation is carried out to resolve missing values, and the data is split into 70–30%, where 70% belongs to the training set and 30% belongs to the testing set. To measure the performance, there are four metrics used, which are accuracy, precision, recall, and F1 score.

Accuracy tells the proportion of total predictions that were correct, and precision tells how many positive predictions are correct, recall talks about how many positives are correctly predicted, and finally, the F1 score is the harmonic mean of precision and recall. The formula for calculating the metrics is given below:

```
Accuracy = (TP + TN) / (TP + TN + FP + FN) (1)
Precision = TP / (TP + FP) (2)
Recall = TP / (TP + FN) (3)
F1 = 2 × Precision × Recall / (Precision + Recall) (4)
```
