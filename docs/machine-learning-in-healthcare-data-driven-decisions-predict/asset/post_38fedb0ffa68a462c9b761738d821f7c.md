
\hat{P}_k(X_i, w) = \frac{\sum_{j=1}^M w_j P_{k,j}(x_i)}{\sum_{j=1}^M w_j} (19)

In PSO, each particle $w_t$ represents a possible solution (weight vector) at iteration $t$. The position and velocity of each particle are updated as follows:

$v_{j,t+1} = w v_{j,t} + c_1 r_1 (P_{j,t} - w_{j,t}) + c_2 r_2 (g_t - w_{j,t})$ (20)

$w_{j,t+1} = w_{j,t} + v_{j,t+1}$ (21)

where $v_{j,t}$ is the velocity of the $j$th particle at iteration $t$, $w$ is the inertia weight of the previous velocity, $c_1$ and $c_2$ are cognitive and social coefficients, $r_1$ and $r_2$ are the random numbers between 0 and 1, $P_{j,t}$ is the personal best position of particle $j$, and $g_t$ is the global best position found by the swarm. The velocity update pushes every particle toward its local best solution and the swarm's global best solution discovered so far, trading off exploration and exploitation to converge towards the optimal weight vector. This is a highly adaptive, flexible ensemble that can adjust the base learner weights in terms of the validation data to achieve better generalization performance.

## 4 Results and Findings

The study was carried out in Python 3.11, a powerful and dynamic testing and developing environment for ML models. A selection of libraries was employed in the development and testing of the models. The PNN and the ELM models based on neural network-inspired models were trained using TensorFlow/Keras. CatBoost was used as the gradient boosting algorithm in efficiently dealing with categorical features, particularly for small-to-medium-sized data. For dealing with the issue of class imbalance, ADASYN was used on the data to balance it before training the model. Boruta_py was used for FS to keep only the most important features from the dataset. pyswarm was used in the implementation of PSO in the optimization of weights of base learners in the ensemble model. Secondly, the implementation of techniques such as LIME and SHAP to model explainability and interpretability was implemented in an effort to better understand the decision process of the models. Lastly, Scikit-learn was utilized to assess model performance using several evaluation measures in order to have a better understanding of the models' overall efficacy.

A number of significant measures that characterize classification accuracy and the model's capacity to handle class imbalance were used to evaluate the model's performance. The model's overall ratio of accurate predictions was calculated using accuracy as a minimal metric. To provide a more balanced assessment, especially for imbalanced datasets, the $F_1$-score was employed. ROC-AUC, a trustworthy measure of model performance, was employed to evaluate the model's capacity to distinguish between positive and negative categories at all levels. MCC, which is especially well-suited for binary classification issues with class imbalance, was used as a balanced metric that accounts for true and false positives as well as negatives. In order to measure the degree of agreement between the expected and actual labels, Cohen's kappa was finally estimated. These several evaluation criteria provided a comprehensive study of the model's performance, enabling it to successfully address the difficulties presented by the mental health prediction tasks. The suggested model (TNPE) is compared with kNN, DT, and NB in the table.

Accuracy measures the percentage of correctly classified instances out of the total predictions made. Higher accuracy indicates better general performance:

Accuracy = \frac{TP + TN}{TP + TN + FP + FN} (22)

The F1-score strikes a balance between recall and precision. It is essential for unbalanced data, such as mental health classifications, where clinical repercussions may result from overpredicting (false positive) or missing a case (false negative):

$F_1$-score = 2 * \frac{Precision * Recall}{Precision + Recall} (23)

Precision = \frac{TP}{TP + FP} (24)

Recall = \frac{TP}{TP + FN} (25)

AUC-ROC – The model's capacity to distinguish between classes across all thresholds is gauged using ROC-AUC. Better discrimination is shown by a number near 1.0, whilst a random guess is represented by a value of 0.5:

AUC = \sum_{i=1}^{n-1} (FPR_{i+1} - FPR_i) \frac{TPR_{i+1} + TPR_i}{2} (26)

TPR = \frac{TP}{TP + FN} (27)

FPR = \frac{FP}{FP + TN} (28)

Matthews Correlation Coefficient (MCC): In binary classification, the MCC is a balanced metric that is especially useful in datasets that are unbalanced. It takes into account both true and false positives as well as negatives. Perfect prediction is represented by a value of +1, no better than chance by a value of 0, and total disagreement by a value of -1. TP, TN, FP, and FN are all taken into consideration by this balanced metric:

MCC = \frac{(TP \times TN) - (FP \times FN)}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}} (29)
