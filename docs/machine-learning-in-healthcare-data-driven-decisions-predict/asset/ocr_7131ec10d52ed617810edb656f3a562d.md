In eq. (1) $n$ denoted the data points, l indicates the loss function, $\hat{y}_i^{(t)}$ is the prediction for instance I at boosting iteration $t$, and $\Omega(f_k)$ is the regularization for each tree $f_k$. The regularization term controls the complexity of the model to avoid overfitting:

$$\Omega(f) = \gamma T + \frac{1}{2} \lambda \sum_{j=1}^T w_j^2$$ (2)

In eq. (2), $T$ = number of leaves in the tree, $w_j$ is the score weight on leaf $j$, and $\gamma$ is the regularization of the number of leaves. At each iteration $t$, a new function $f_t(x)$ is added to minimize the loss:

$$\hat{y}_i^{(t)} = \hat{y}_i^{(t-1)} + f_t(x_i)$$ (3)

To effectively optimize, a second-order Taylor expansion of the loss around the current prediction is used:

$$l(y_i, \hat{y}_i^{(t-1)}) \approx l(y_i, \hat{y}_i^{(t-1)}) + g_i f_t(x_i) + \frac{1}{2} h f_t(x_i)^2$$ (4)

where

$$g_i = \frac{\partial l(y_i, \hat{y}_i^{(t-1)})}{\partial \hat{y}_i^{(t-1)}} = \text{first-order derivative (gradient)}$$

$$h_i = \frac{\partial^2 l(y_i, \hat{y}_i^{(t-1)})}{\partial (\hat{y}_i^{(t-1)})^2} = \text{second-order derivative}$$

(ii) Image-Based Data: For image-based cancer detection, CNNs will be used. CNNs are good at extracting hierarchical patterns from images and are thus best suited for applications such as tumor detection, segmentation, and classification in medical imaging (e.g., MRI, CT, and histopathological images). The capacity of CNNs to learn spatial features from raw image data automatically provides the capability for identifying subtle tumor features that would otherwise be undetectable with traditional approaches. Assume the input to be an image:

$$X \in R^{H*W*C}$$ (5)

In eq. (5) $H$, $W$, and $C$ are the height, width, and number of channels in an image. A convolutional layer applies a set of learnable filters $K$. For a filter $K \in R^{k_h * k_w * C}$, the convolution operation at position $(i, j)$ is given as follows:

$$Y_{ij}^{(f)} = \sigma \left( \sum_{m=0}^{k_h-1} \sum_{n=0}^{k_w-1} \sum_{c=0}^{C-1} K_{mn,c}^{(f)} X_{i+m, j+n, c} + b^{(f)} \right)$$ (6)
