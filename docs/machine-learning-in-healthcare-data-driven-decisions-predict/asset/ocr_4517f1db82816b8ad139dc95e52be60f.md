| Feature | Traditional feature extraction (e.g., VGG, ResNet, and DenseNet) | Proposed MSAG-DFE framework |
|---|---|---|
| Scale adaptivity | Fixed kernel sizes limit detection of multi-scale features | Multi-kernel convolutions enable scale-adaptive learning across lesions |
