This survey reports on the latest advances in privacy-preserving FL solutions in several medical disciplines including innovative techniques such as DP, transfer learning, HE, and decentralized systems. These developments indicate encouraging improvement in model performance, robustness, and scalability with confidentiality of patients maintained in multi-institutional data sharing. FL is a novel breakthrough in health AI that enables jointly trained models without breaching patient privacy. Interaction with state-of-the-art privacy-protection technologies such as DP, HE, and adaptive aggregation safeguards the data with robust diagnostic performance and solid models. Additional collaboration and exploration of FL platforms can have a huge impact on precision medicine, facilitate better patient care, and promote responsible collaboration in health centers in multiple jurisdictions around the world.

# 3 Methodology

To address the issues of privacy, data heterogeneity, and compliance with data governance issues in clinical machine learning, we present a unique FL framework to core-create machine learning models in a multi-institutional healthcare setting. Our framework proposes that ML models can be corecreated by multiple healthcare institutions without the need for patient data to be centralized by any institution, achieving data security, patient privacy, and data governance using secure protocols and model personalization, thereby increasing privacy and model performance.

# 3.1 System Architecture

System architecture is built to promote secure and collaborative model cocreation from a number of decentralized sources of clinical data. It has multiple local clients which can be any healthcare or research center, such as hospitals and clinics, that are independent data silos, that fully control their private datasets, like EHRs or medical imaging. Clients will cocreate ML models through FL by training them locally using their private datasets. A central coordinating server facilitates the learning process by initializing and distributing a global model to all clients. It then collects privacy-preserving model updates from each institution, aggregates them securely, and redistributes the updated global model.
