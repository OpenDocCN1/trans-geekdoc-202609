# 4 Proposed Algorithm

To facilitate accurate and personalized treatment suggestions, we introduce CareRec-Net, a patient-oriented treatment suggestion system integrating knowledge-enhanced attention with deep sequence models. The model is designed to abstract domain relationships between medical concepts, learn temporal patterns from longitudinal EHR data, and provide explanations that are evidence-based and interpretable. The architecture supports improved representation learning of unstructured and structured clinical information by integrating an attention-augmented knowledge graph embedding module (AKGEM) together with a bidirectional long short-term memory (BiLSTM) network for temporal learning.
