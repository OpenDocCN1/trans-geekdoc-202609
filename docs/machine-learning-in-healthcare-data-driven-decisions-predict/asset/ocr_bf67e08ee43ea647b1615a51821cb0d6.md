# 3.1.3 Breast Cancer Wisconsin Diagnostic Dataset (WBCD)

The third dataset provided was the Wisconsin Breast Cancer Diagnostic (WBCD) dataset, consisting of digital images of fine needle aspirates (FNAs) of breast tumors and 569 breast cancer biopsy cases. A binary classification problem is formed by the tagging of each sample as benign (357 cases) or malignant (212 cases). These groups are the thirty numeric attributes calculated from an image of a breast mass: Mean values are radius, texture, area, perimeter, smoothness, compactness, concavity, symmetry, and fractal dimension; standard error for all the above aspects; worst values: maximum value across the entire FNA image for each feature. After normalization, each feature has a real value ranging from 0 to 1. Since there were no missing values in the raw dataset, preparation proceeded smoothly. For class balancing, the dataset was split into 70% training, 15% validation, and 15% test sets by stratifying it. Table 3 shows the WBCD dataset features.

# Table 3: WBCD dataset features.

| Feature name | Description | Type | Value range/categories |
|---|---|---|---|
| Radius (mean) | Mean of distances from center to points on perimeter | Numeric | ~6 to ~30 |
| Texture (mean) | Standard deviation of gray-scale values | Numeric | ~10 to ~40 |
| Perimeter (mean) | Mean size of tumor perimeter | Numeric | ~40 to ~200 |
| Area (mean) | Mean size of tumor area | Numeric | ~150 to ~2,500 |
| Smoothness (mean) | Local variation in radius lengths | Numeric | ~0.05 to ~0.2 |
| Compactness (mean) | Measure of compactness of cell | Numeric | ~0.02 to ~0.35 |
| Concavity (mean) | Severity of concave portions of contour | Numeric | ~0.0 to ~0.4 |
| Concave points (mean) | Number of concave portions | Numeric | ~0.0 to ~0.2 |
| Symmetry (mean) | Symmetry of tumor | Numeric | ~0.1 to ~0.3 |
| Fractal dimension (mean) | “Roughness” of the contour | Numeric | ~0.05 to ~0.1 |
| ... | (Similar 10 features for SE and worst values) | Numeric | Varies by feature |
| Diagnosis (Target) | Breast cancer diagnosis | Binary | M = Malignant, B = benign |

When hyperparameter tuning and model training were performed, fivefold cross-validation was utilized to ensure consistency across the datasets and prevent information leakage.
