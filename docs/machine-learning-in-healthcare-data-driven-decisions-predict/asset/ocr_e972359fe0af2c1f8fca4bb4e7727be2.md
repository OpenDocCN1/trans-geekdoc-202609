Clinicians should be able to use an analytic system with confidence, which requires that the model's process, testing, and drawbacks are explained. Clinicians may find it challenging to make sense of the results provided by many data models. Statistics needed for confidence intervals, risk scores, and likelihood ratios is not commonly understood by most people using the tool. If data is misinterpreted, there is a risk of people either using it too much or not using it enough, each situation having negative effects. The issue of ethics is connected to situations of uncertainty. Using information or data that is uncertain can put one's belief in justice, and a patient's rights and risk assessment at risk. Contingency calls for using clinical experience, patient wishes, and understanding the environment and data in combination. Healthcare providers should create interpretative tools that can display explanations, express how uncertain a result is, and are simple for doctors to use. Clinicians should also receive training in handling and managing uncertainty. For data-driven decisions to be more secure and trustworthy, the efforts of data scientists, clinicians, and ethicists should be brought together (Figure 6).

Barriers in the present bring chances for changes that may greatly impact healthcare in the future.
