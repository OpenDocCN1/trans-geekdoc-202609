
P(y = 1|x) = σ(z) = 1 / (1 + e^-z)

The model uses a threshold, usually 0.5, to predict class labels:

ŷ = { 1, if σ(z) ≥ 0.5; 0, if σ(z) < 0.5 }

Reduce the log loss (cross entropy) as follows in order to train the model:

L(β) = -1/m Σ [y^(i) log(ŷ^(i)) + (1 - y^(i)) log(1 - ŷ^(i))]

where m is the number of training samples, y^(i) is the true label, and ŷ^(i) = σ(β^T x^(i))

### 3.4.3 Random Forest

RF consists of multiple DTs trained over random subsets of data and features [26]. RF avoids overfitting and increases accuracy and stability and is therefore a strong performer in medical prediction tasks. The dataset is given as follows:

D = [(x1, y1), (x2, y2), ..., (xm, ym)]

The RF builds T number of DTs:

h1(x), h2(x), ... hT(x)

A random selection of features not all features is taken into account at each tree split. For classification (e.g., diabetic or nondiabetic). Each tree ht(x) predicts the class label. The final prediction is the majority vote:

ŷ = mode({h1(x), h2(x), ..., hT(x)})

For regression, each tree predicts a numeric output, and the result is the mean of all the trees:

ŷ = 1/T Σ ht(x)

Trees often employ the Gini impurity at each node to determine the optimal split:

Gini = 1 - Σ p_i^2

where C represents the number of classes and pi is the proportion of samples of classes i at the node. The split with the lowest impurity is chosen. Approximately one-third of the data is excluded (out-of-bag) since each tree employs a random sampling. Without using cross-validation, these can be used to measure model performance. ### 3.4.4 Support Vector Machine (SVM)

SVM is an effective classifier that maximizes the margin between classes to determine the optimal hyperplane for class separation. With the use of kernel functions (such as the RBF kernel), SVM can even handle non-linear correlations and performs well with high-dimensional data. SVMs can be computationally costly for big datasets, but they perform well with datasets that have clearly defined boundaries for classes and are robust to outliers [27]. For binary classification, suppose the data is given by

```
D = \{(x_i, y_i)\}_{i=1}^m, x_i \in \mathbb{R}^n, y_i \in \{-1, +1\}
```

SVM tries to find a hyperplane

```
W^Tx + b = 0
```

In this way, the difference between the two classes is maximized. The margin is \frac{2}{||w||}. The goal is to minimize

```
\min_{w, b} \frac{1}{2} ||w||^2
```

Subject to the constraints

```
y_i(W^T x_i + b) \ge 1, \forall i
```

$$ \min_{w, b, \xi} \frac{1}{2} ||w||^2 + C \sum_{i=1}^m \xi_i $$

Subject to

$$ y_i(W^T x_i + b) \ge 1 - \xi_i, \xi_i \ge 0 $$

In eq. (14), C is the regularization parameter.

SVM uses a kernel \( K(x_i, x_j) \) to translate input characteristics into a higher-dimensional space for nonlinear data without directly calculating the transformation. The common kernels are as follows:

$$ K(x, z) = x^T z \, (\text{linear}) $$

$$ K(x, z) = (X^T z + 1)^d \, (\text{polynomial}) $$

$$ K(x, z) = \exp \left( - \frac{||x - z||^2}{2\sigma^2} \right) \, (\text{RBF}) $$

After training, a new input x is classified as follows:

$$ f(x) = \text{sign} \left( \sum_{i=1}^m \alpha_i y_i K(x_i, x) + b \right) $$

In equation \((\alpha_i)\) are the Lagrange support vector weights.

### 3.4.5 Gradient Boosting (e.g., XGBoost)

It is an ensemble approach that constructs the models sequentially one after the other such that each subsequent model improves on the mistakes of the previous models [28]. XGBoost is a computationally efficient variant that is favored by many due to having good regularization properties to prevent overfitting, and it has the capability of learning complex, nonlinear relationships. It can frequently achieve best-in-class results in structured/tabular data such as medical records. Consider a dataset with the input features X

$$ X = \{x_1, x_2, \dots, x_n\} $$

The corresponding Y labels are

$$ Y = \{y_1, y_2, \dots, y_n\} $$

The objective is to predict \(\hat{y}^{(t)}\) for each instance \(x_i\). The prediction at iteration \(t\) is

```
\hat{y}^{(t)} = \sum_{k=1}^t f_k(x_i), f_k \in F
```

where $f_k$ is the prediction function and $t$ is the current iteration. The objective function to minimize the regularized loss is as follows:

```
L^{(t)} = \sum_{i=1}^n l(y_i, \hat{y}_i^{(t)}) + \sum_{k=1}^t \Omega(f_k)
```

where $l$ is a differentiable loss function and $\Omega(f_k) = \gamma T + \frac{1}{2} \lambda ||w||^2$ is the regular term to penalize complexity. The regularization parameters are $\gamma$ and $\lambda$, the leaf weights are $w$, and the number of leaves is $T$. XGBoost approximates the loss in each iteration using second order Taylor expansion:

```
L^{(t)} \approx \sum_{i=1}^n \left[ g_i f_t(x_i) + \frac{1}{2} h_i f_t(x_i)^2 \right] + \Omega(f_t)
```

Here, $g_i$ and $h_i$ are given as follows:

```
g_i = \frac{\partial (y_i, \hat{y}_i)}{\partial \hat{y}_i} \quad h_i = \frac{\partial^2 (y_i, \hat{y}_i)}{\partial \hat{y}_i^2}
```

Next, the model determines the $f_t$ that minimizes this estimated goal.

## 4 Results and Findings

After data preprocessing and FS have been done, model training and validation are performed. Data are divided first into test and training sets. The 80/20 split, in which 80% of the data is used for training the model and 20% is used for testing, is probably the method that is most commonly employed. To improve the model, hyperparameter tuning is conducted using GridSearchCV or RandomSearchCV techniques. GridSearchCV iterates over a fixed list of hyperparameters, and RandomSearchCV samples hyperparameters randomly from a given range. Both the procedures help to determine the optimal model parameters and thereby the overall improvement. Some of the most important evaluation criteria are used to assess the model's performance after it has been trained are as follows.

- Accuracy: True predicted divided by all predicted. It is a simple measure but misleading in imbalanced datasets:

    ```
    \text{Accuracy} = \frac{(TP + TN)}{(TP + FP + TN + FN)}
    ```

- Precision: The ratio of all positive predictions to true positives. It matters when false positives (e.g., incorrect diabetes diagnosis when the patient is not diabetic) are expensive:

  \(\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}\) (26)

- Recall: The ratio of all real positives to true positives. It matters when false negatives (e.g., not detecting a diabetic patient) are very expensive:

  \(\text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}\) (27)

- F1-Score: A harmonic mean of recall and precision gives equal weight, particularly for datasets that are not balanced:

  \(F1\text{-score} = \frac{2 \text{ * Precision * Recall}}{\text{Precision + Recall}}\) (28)
