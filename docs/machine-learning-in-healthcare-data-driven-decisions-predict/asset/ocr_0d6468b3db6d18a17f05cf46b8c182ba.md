# 5 Analytical Methods for Evidence-Based Decision Making

Healthcare is taking a more data-driven and analytics-based approach, as it now relies on analytics to extract useful insights from a huge amount of data. In healthcare, using analysis methods is key to transforming data into evidence used for making decisions that are best for patients. This part explains important analytical procedures – descriptive, predictive, and prescriptive analytics – and discusses how machine learning, artificial intelligence, and decision-support systems improve healthcare by transforming it.
