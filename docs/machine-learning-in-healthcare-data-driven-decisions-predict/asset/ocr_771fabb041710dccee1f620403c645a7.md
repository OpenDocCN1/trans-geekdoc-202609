# Step 3: Knowledge-Attentive Feature Fusion

For each time step t, the temporal representation h_t is augmented with knowledge graph-derived embeddings e_t using an attention mechanism:

```
a_t = softmax(h_t^T W_a e_t) (10)
z_t = a_t \cdot e_t + (1 - a_t) \cdot h_t (11)
```

Here, W_a is a trainable weight matrix. The final fused feature z_t captures both patient dynamics and medical knowledge context.

# Step 4: Treatment Recommendation via Multilayer Perceptron (MLP)

The concatenated patient representation over all time steps is passed through a fully connected network to predict the treatment class:

```
Z = [z_1, z_2, ..., z_T] \in R^{T \times d} (12)
y = softmax(W_out \cdot ReLU(W_fc \cdot Flatten(Z) + b_fc) + b_out) (13)
```

where W_fc, W_out: learned weights, b_fc, b_out: biases, \(\hat{y} \in R^k\): probability distribution over k treatment categories

The model is trained using categorical cross-entropy loss:

```
L_{CE} = - \sum_{i=1}^k y_i \log (\hat{y}_i) (14)
```

where y_i \in {0, 1} is the ground truth label.
