To approximate $P$, the system integrates an evolutionary multi-objective algorithm (e.g., NSGA-II) that evolves a population of policy parameters $\{	heta_i\}_{i=1}^N$ based on dominance and diversity criteria.

# 3.2.1 Fitness Function

The fitness for individual $i$ with policy $\pi_{\theta_i}$ is calculated using dominance rank $r_i$ and crowding distance $d_i$

\(\text{Fitness}(\theta_i) = r_i + \frac{1}{d_i + \epsilon}\) (4)

where $\epsilon$ is a small constant to avoid division by zero.

# 3.3 Proximal Policy Optimization (PPO)

PPO is employed as the policy optimization engine within the evolutionary framework. PPO improves policy stability by limiting the update magnitude via a clipped surrogate objective.

The PPO objective for a single objective $i$ is

\(L^{(i)}(\theta) = E_t [ \min ( r_t^{(i)}(\theta) A^{\hat{(i)}}_t, \text{clip}( r_t^{(i)}(\theta), 1-\epsilon, 1+\epsilon ) A^{\hat{(i)}}_t ) ]\) (5)

where
\(r_t^{(i)}(\theta) = \frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_{\text{old}}}(a_t|s_t)}\) is the probability ratio,
\(A^{\hat{(i)}}_t\) is the advantage estimate for objective $i$,
\(\epsilon\) is the clipping parameter.

For multi-objective PPO, the overall objective is a weighted combination

\(L(\theta) = \sum_{i=1}^m w_i L^{(i)}(\theta)\) (6)

where weights $w = (w_1, w_2, ..., w_m)$ are adaptively updated to explore different regions of the Pareto front.
