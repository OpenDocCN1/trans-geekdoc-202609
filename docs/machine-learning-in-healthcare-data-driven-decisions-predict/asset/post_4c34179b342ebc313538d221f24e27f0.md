
The first step is called bootstrap sampling, where N sub-datasets are created. These new datasets are called bootstrapped datasets. The sampling used in each sub-dataset will be done using replacement. Each sub-dataset may also contain duplicate datasets due to the replacement method. The training process starts for each sub-dataset independently. A base classifier is chosen for each sub-dataset; this classifier is called a weak learner (e.g., a DT). These classifiers are purposefully left unpruned to increase diversity among them. The final step is to classify the instance into a class. Once all the classifiers complete the training stage, they are used to predict the given instance, with the results of all the models being recorded, and the final class is decided by the majority vote among all the classifiers [18].

The bagging method will reduce the variance of the model [19]. Each model will have different variances as they are trained using completely different training data; the combined model will have lower variances due to averaging. The following lists the advantages of bagging ensemble learning:

- 1. There is less chance of overfitting as the bagging will combine multiple models, which tends to reduce the chance of overfitting. The bagging is used specifically in a few models with high variance by nature, for example, DTs.

- 2. The combined model produces higher accuracy than a single model, as the aggregated model reduces the data from becoming noisy or complex by distributing it across the models.

- 3. The combined model is more robust, and it makes it less sensitive to noise.

- 4. The training of the bagging ensemble model is easy, as all the independent base learners can be trained in parallel, which makes the computational resource usage optimal.

A good example of a bagging ensemble model is RF, where each DT is trained on the bootstrapped datasets. Bagging will primarily reduce the variance but not the bias. Bagging models are less interpretable, for some applications where transparency is required, than the bagging model will fail to provide explanations.

## 3.3 Boosting-Based Ensemble Model

Boosting is also an ensemble method that converts a set of weak learners into a single strong learner that is designed to improve the overall accuracy of the machine learning classification task. It is completely different from bagging, where bagging allows models to train independently, but boosting trains the model sequentially. At each step, one model is trained, and the errors made by the model are noted. When training the next model, these errors are corrected. Boosting is used for reducing both bias and variance; hence, it is more popular than the bagging method, and this is suitable for a wide range of applications in classification and regression problems [20].

The work of the boosting algorithm is to rank instances by weights. Initially, all the instances are given a uniform weight. Then a sequence of models is selected. Initially, all the data points are used to train the first model. The instances that are misclassified by the first model are given additional weights, which makes the misclassified instances more important for the next sequential model. The next model will focus more on these misclassified instances. The final prediction is made by combining the outputs of all the models using a weighted majority vote (for classification problems) or weighted average (for regression problems) [21].

Below are some of the popular boosting algorithms:

- 1. AdaBoost (also known as adaptive boosting): This method was introduced in the 1990s. The boosting process updates weights in each iteration and assigns weights to instances. The iteration continues until the desired accuracy is achieved or the maximum threshold of iterations is reached. The AdaBoost method uses multiple stumps as base learners. A stump is a one-level DT. The main problem with AdaBoost is that it increases noise sensitivity because misclassified instances are given more weight, and the upcoming stumps will learn more about outliers and noise. AdaBoost is widely used in classification, and more powerful boosting methods than AdaBoost have been developed in research such as XGBoost [22].

- 2. Gradient boosting: Instead of updating weights of instances, gradient boosting focuses on residual errors (gradients) of the previous model. At each iteration, the model tries to minimize the loss function such as the mean square error. This method is more flexible, and it supports even custom loss functions. Gradient boost works well on structured data and gives good performance [23].

- 3. XGBoost (also known as extreme gradient boosting): This is a high-performance tuning of the gradient boosting. This is much faster and more powerful in terms of accuracy. This method uses some optimization, such as tree pruning, L1 and L2 regularization, and parallel processing to prevent overfitting. These methods also reduce the computation time required for training the models. XGBoost can be used for both classification and regression tasks by handling data efficiently. This model becomes more popular in the research area, and it is used in wide applications including research competitions and the real world. The method allows early stopping, where the process can be stopped if the desired accuracy is reached. This is a robust and more flexible method that allows facilities like missing value handling [24].

- 4. CatBoost is also a variant of the gradient boosting method. This type of variant is specially designed to handle categorical features efficiently without the need for particular preprocessing. It uses ordered boosting to reduce overfitting of data in training. This method incorporates symmetric trees for faster training. CatBoost does the encoding of categorical variables automatically, and it can be used both for classification and regression tasks. The CatBoost is a user-friendly model as it needs only a minimum of hyperparameter tuning. The model can scale well even if it has a larger number of categorical variables. CatBoost is one of the methods that is used when the data is more complex [25].

- 5. LightGBM (light gradient boosting machine) is developed by Microsoft, and this is a very fast and efficient gradient boosting framework. This model gives high performance when large datasets with many features are used. The reason behind LightGBM being fast during training is the use of a histogram-based approach for splitting the data, which reduces memory usage. Leaf-wise tree growth method is used to increase accuracy. LightGBM allows training on a GPU and parallel processing [26].

There are some suggested methods for boosting techniques to use:

- 1. If there are many categorical features, then CatBoost can be used.
- 2. If a large dataset is used, then LightGBM can be used.
- 3. If speed and accuracy should be balanced, then XGBoost can be used.
- 4. If parameter tuning should be minimal, then CatBoost can be used.
- 5. If GPU acceleration is required, then LightGBM or XGBoost can be used.
- 6. If there are many sparse or missing data, then XGBoost or LightGBM can be used.

## 3.4 Stacking

Stacking or stacked generalization is an advanced ensemble learning method that combines multiple models to improve the accuracy of the classification. Unlike other ensemble methods like bagging and boosting, where the same type of base learner is used and combined to form a single powerful model, stacking allows meta models that learn to combine many base models [27].

The main idea of stacking is to use the positives of many models and introduce a secondary model called a meta learner to learn from the output. This approach can often outperform individual models and other ensemble methods because this approach recommends the optimal combination of models.

There are two layers in the stacking:

- 1. Layer 1 – Base learners: There are multiple models used. Each model is trained using the same training data.

- 2. Layer 2 – Meta learner: This layer contains a model that assigns weights to the output of the models. The input of the meta learner has no features, but the output of all the base learners.
