Each client $k$ will perform local updates on its dataset $D_k$. The client minimizes a local objective function:

```
$F_k(w) = \frac{1}{n_k} \sum_{i=1}^{n_k} l(w; x_i^k, y_i^k)$ \tag{2}
```

Equation (1) is the loss function and $x_i^k, y_i^k \in D_k$. The local model is updated using gradient descent for $E$ epochs:

```
$w_t^k \leftarrow w_t^k - \eta \nabla F_k(w_t^k)$ \tag{3}
```

**Model Update Sharing:** After completing local training, clients do not share any raw patient data. Instead, they extract and encrypt only the updated model parameters such as weight matrices or gradient values. These encrypted updates are securely transmitted to the central server. This ensures that sensitive health information never leaves the local site, thus preserving patient privacy and complying with data protection regulations. The client $k$ sends its updated model $w_t^k$ or the difference $\Delta w_t^k = w_t^k - w_t$ to the server. To preserve privacy, the update is encrypted:

```
$\hat{w}_t^k = \text{Encrypt}(w_t^k)$ \tag{4}
```

**Secure Aggregation:** The central server receives encrypted updates from multiple clients and performs secure aggregation. Techniques such as HE or SMPC are used to combine the updates without decrypting them, preventing any single party including the server itself from accessing individual client data. This layer of security ensures that even the model updates cannot be reverse-engineered to infer sensitive information. The server performs secure aggregation of encrypted updates using protocols such as HE and SMPC [21].

```
$\hat{w}_{t+1} = \text{Aggregate}(\{ \hat{w}_t^1, \dots, \hat{w}_t^K \})$ \tag{5}
```

After decryption, the server computes the new global models as a weighted average:

```
$w_{t+1} = \sum_{k=1}^K \frac{n_k}{n} w_t^k$ \tag{6}
```

**Global Model Update:** Once aggregation is complete, the server computes a new version of the global model by averaging or otherwise combining the encrypted client updates. This updated model reflects knowledge learned from the collective datasets of all clients, enhancing its generalizability.
