# 1. 引言

由于电力需求与建设之间的不平衡，电力负荷预测是竞争性经济性业务中的一个重要研究领域。负荷预测是为系统中的交易市场决策、实时智能调度、智能电网自动化和控制提供电力支持的首要任务 [1]。为了实现电力系统的稳定和高效运行，负荷预测应产生准确的结果。为了满足电力需求，电力需求波动很大，因此应该在需求时发电。如果能够提前知道需求，就可以满足发电的所有运行要求。电力系统有几个目标：根据需要按时提供稳定安全的电力、节省运行成本、维持维护成本、确保电力系统的可靠性并平衡发电与负荷动态变化的平衡 [5,2]。高估或低估会导致电力系统产生复杂的财务影响 [7]。

负荷的不确定性和波动性，以及负荷数据中不完整、非均匀、冗余和无关信息的存在使得难以实现准确预测。天气信息对负荷需求影响很大。考虑季节和天气信息的负荷预测可以产生准确的结果 [9,10]。预测可以按小时、每天、每月或每年进行。负荷需求与外部因素（如湿度、温度、风速、压力、降雪、云以及用户对家电的使用）相关 [12]。在学习过程中，只有高质量的输入且只有相关信息被作为输入到学习和预测过程中。特征选择是降维技术之一，它根据特征的统计特性从原始特征列表中选择相关特征 [13]。因此，它保留了特征的原始性。

# 3. 提出的 RMR-HFS-LSTM 预测模型

## 3.1. R-HFS 的意义

包含不相关、无关和无信息特征的数据集可能会增加数据集维度，从而强制模型过拟合。它也会导致预测模型在泛化模式方面变得复杂。使用过多特征训练的模型可能无法产生准确稳健的结果。还观察到冗余特征会降低准确率。数据集可能具有许多特征。它们有相关特征、高度相关且冗余特征、弱相关且非冗余特征以及强相关特征。无关特征会降低准确率。这些特征不应该贡献于预测准确率，相反，会识别过拟合并降低准确率。另一方面，强相关和弱相关特征有助于预测。应该识别并移除冗余特征。

在本文中，引入了递归消除信息混合特征选择（`RMR-HFS`），通过使用过滤特征选择方法来改进短期负荷预测。应用基于信息过滤特征选择和基于递归的特征选择封装方法（wrapper）来识别特征子集。特征选择方法并不适用于所有情况。提出的方法使用了 `RLeeff` 和信息论互信息特征选择来消除冗余特征。`RLeeff` 过滤用于特征选择。`RLeeff` 方法通过每个特征与目标特征之间的关系识别相关和无信息特征。`RLeeff` 不考虑特征之间的关系。

尽管 `RMR` 和 `MI` 选择了所有特征，但相关特征列表包含许多冗余特征。选择具有识别冗余特征的能力。因此，提出的方法可以通过递归 `RFE` 提高准确率并避免过拟合。过滤和封装方法提供了特征选择的优势。最佳特征子集用于深度学习负荷预测模型。

## 3.2. RMR-HFS-LSTM 架构

提出的基于深度学习的模型 `RMR-HFS-LSTM` 包含三个阶段：数据预处理、混合特征选择和预测。在第一阶段，小时电负荷和天气数据被视为单个数据集，进行清洗和归一化以准备进一步处理。消除了离群值和样本。然后应用 `RLeeff` 和信息论互信息特征选择来识别相关特征。所选的 M 和 Rleff 特征结合（COMPS）以找到最相关的特征。然而，调优的封装选择改进过滤方法产生了最佳特征子集。在第三阶段，构建并训练 LSTM 预测模型。在验证数据上使用时间序列交叉验证调整参数。最后，提出的 R-HFS-LSTM 在所有特征下与多个基准模型在 `MAPE` 和 `MAE` 等误差指标上进行了比较。结果所示。

方向预测器。它利用过滤法进行特征子集划分，并利用学习模型评估子集。最初，利用原始特征集构建学习模型。之后，计算每个特征的特征分。然后，从列表中移除得分较低的特征并重构子集。此过程重复进行，直到没有更多特征或达到用户定义。选择性能较高或误差更低的子集作为最优子集。在递归特征消除（RFE）中，为了获得更好的性能，需要考虑的最终特征列表中特征数量的数量，以及用于选择子集的算法。

它们是输入门和输出门。输出门用于决定显示的信息。输入门决定从输入中提取哪些信息用于旧的细胞状态或新的细胞状态。门决定了来自输入 `[u_t, h_{t-1}]` 的信息的包含。时间 `t` 处的隐藏状态和细胞状态分别为 `h_t` 和 `c_t`，在时间 `t-1` 处它们为 `h_{t-1}`、`c_{t-1}` 和 `o_{t-1}`。遗忘门、输入门和输出门为：

```
$i_t = \sigma(W_i[h_{t-1}, x_t])$
```

```
$\tilde{c}_t = \tanh(W_c[h_{t-1}, x_t])$
```

```
$c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$
```

```
$f_t = \sigma(W_f[h_{t-1}, x_t])$
```

```
$o_t = \sigma(W_o[h_{t-1}, x_t])$
```

```
$h_t = o_t \odot \tanh(c_t)$
```

### 3.2.2 深度预测

深度学习是处理时间序列数据的一种新兴技术。时间序列数据具有时间依赖性，并且对于相同的时间点具有不可预测的行为。通常，电力具有反复和波动的性质。某些方法对于处理时间序列是有效的，但在某些时刻无法产生准确的预测 [44, 45]。深度学习可以通过自动学习输入和输出序列之间的映射来处理复杂性。深度学习能够很好地处理时间序列数据，并比传统方法提供更高的精度。

其中 `c_t, h_t` 和 `o_t` 代表细胞状态、新状态和输出门的值。`W_f, W_i, W_c` 和 `W_o` 代表遗忘门、输入门和输出门的权重矩阵。`b_f, b_i, b_c` 和 `b_o` 分别代表偏置权重。

使用 2000 年 1 月 1 日至 2012 年 12 月期间波兰和瑞典的电力数据和天气数据用于实验。天气为预测负载提供了重要信息，因此将负载天气数据集整合到一个格式中。负载数据包含 31,848 行。数据集的特征为：`f_1` 温度、`f_2` 湿度、`f_3` 降水量、`f_4` 总降水量（高，有限范围）、`f_5` 总降水量（低）、`f_6` 总云覆盖率、`f_7` 低云覆盖率、`f_8` 中云覆盖率、`f_9` 照时长、`f_10` 短波辐射、`f_11` 风速（10 mph）、`f_12` 风向、`f_13` 风阵、《`f_{14}` 风速（低 mph）、`f_15` 风速 [90 mph]、`f_16` 风向 [90 mph]、`f_17` 风需求 [90 mph]。

论文随后介绍了数据集的特征、LSTM、GRU 以及作为最先进的循环神经网络 MLP。RNN 和 MLP 是用于预测、时间序列预测和回归问题最合适的方法。在本文中，使用短记忆网络基于电力和天气数据进行负载预测。接下来的章节讨论了 LSTM 的工作原理。

### 3.2.4 短记忆网络

短期记忆是 RNN 的扩展。它是一种特殊的网络，旨在克服 RNN 在长时间记忆方面的局限性。它通过随反向传播更新隐藏状态，有效地处理了 RNN 的梯度消失和爆炸问题。在这里，它通过在细胞状态中使用门来保留序列信息。这使得时间序列数据实现了更好的预测性能。它具有理解 LSTM 非线性时间数据中序列依赖性和时间依赖性的潜力。LSTM 单元由三个门组成。

预测模型的性能可以通过许多方式进行评估。`MAPE` 和 `RMSE` 被用作预测方法的额外评估指标。`MAPE` 和 `RMSE` 的计算如下：

```
$$MAPE = \frac{100}{n} \sum_{t=1}^{n} \left| \frac{Y_t - F'_t}{Y_t} \right| ; \quad (12)$$
```

```
$RMSE = \sqrt{\frac{1}{n} \sum_{t=1}^{n} [Y_t - F'_t]^2} ; \quad (13)$
```

其中 `n` 代表实例数量，`$Y_t$` 代表观测时间的实际值，`'$F'_t$'` 代表该时间的预测值。

# 5. 结论

深度神经网络是研究人员自动学习输入输出之间复杂映射的一种不确定工具。电力负载具有不确定性和非线性特征。因此，利用深度学习方法可以实现未来负载的准确预测。通过提供关键特征和相关的输入数据可以增强深度学习的性能。因此，在此处，过滤器和特征选择的结合是通过针对数百个欧洲电力负载进行的实验确定的。此外，这些因素可能会影响未来的性能。其他的深度学习技术也可以提高准确性。
