# 摘要

- 关键词：
- 深度学习
- 混合特征选择
- 长期负荷记忆
- 电力系统
- 循环神经网络

电力系统的可靠且经济运行依赖于对短期负荷的准确预测。本文中对比了基于混合特征选择的深度学习长短期记忆（LSTM）模型 RMR-HFS-LSTM。本研究的目标是减少负荷预测误差。RMR-HFS 是过滤式（filter）和包装式（wrapper）特征选择的结合，用于选择特征的最优子集。利用基于信息理论的互信息过滤选择，通过发现和消除无关特征来降低多样性维度。所选的特征通过递归特征消除（RFE）进行测试。结果显示，LSTM 通过不确定性实验改进了负荷数据的准确性和负荷数据处理。在欧洲天气和负荷数据上对所提方法的性能进行了测试，并将其与多层感知器（MLP）和递归神经网络（RNN）进行了对比。结果表明，提出的 RMR-HFS-LSTM 优于其他模型。

# 1. 引言

由于电力需求与建设之间的不平衡，电力负荷预测是竞争性经济性业务中的一个重要研究领域。负荷预测是为系统中的交易市场决策、实时智能调度、智能电网自动化和控制提供电力支持的首要任务 [1]。为了实现电力系统的稳定和高效运行，负荷预测应产生准确的结果。为了满足电力需求，电力需求波动很大，因此应该在需求时发电。如果能够提前知道需求，就可以满足发电的所有运行要求。电力系统有几个目标：根据需要按时提供稳定安全的电力、节省运行成本、维持维护成本、确保电力系统的可靠性并平衡发电与负荷动态变化的平衡 [5,2]。高估或低估会导致电力系统产生复杂的财务影响 [7]。

负荷的不确定性和波动性，以及负荷数据中不完整、非均匀、冗余和无关信息的存在使得难以实现准确预测。天气信息对负荷需求影响很大。考虑季节和天气信息的负荷预测可以产生准确的结果 [9,10]。预测可以按小时、每天、每月或每年进行。负荷需求与外部因素（如湿度、温度、风速、压力、降雪、云以及用户对家电的使用）相关 [12]。在学习过程中，只有高质量的输入且只有相关信息被作为输入到学习和预测过程中。特征选择是降维技术之一，它根据特征的统计特性从原始特征列表中选择相关特征 [13]。因此，它保留了特征的原始性。

另一方面，包装式特征选择根据学习模型选择特征子集 [15,14]。特征选择技术从提供给学习过程的输入数据中消除无信息、无关和冗余信息，可以提高分类器的性能。

过去研究人员利用基于统计和人工智能的机器学习方法。现在使用深度学习方法以以最小的努力实现效率。基于深度学习的模型通过在输入层和输出层之间堆叠许多层，具有学习序列数据复杂性以及时空依赖关系的能力。例如，神经网络可以处理序列数据的非线性映射。但它面临梯度消失和梯度爆炸问题。神经网络利用反向传播生成导数 [21]。当梯度很小时，学习变得变慢；而当梯度很大时，就会产生梯度爆炸问题。因此，使用 RNN LSTM 通过引入门控机制解决了这些问题。识别重要特征的重要性、最优滞后和任何最小层数将保证减少过拟合问题。LSTM 可以通过考虑多个特征来捕捉大量高维数据。

提出的 RMR-HFS-LSTM 包含了预处理、混合特征选择和深度预测。该深度学习模型通过考虑多个特征来捕捉大量高维数据。

所提方法的 RMR-HFS-LSTM 在 MAPE 和 RMSE 指标上与 RNN 和 LSTM 进行了对比预测预测。RLEf、互信息和递归特征选择的混合特征选择通过消除无关和非信息特征，利用统计特性识别相关特征。

# 2. 相关工作

本节探讨了各种研究人员的相关工作。在 [71] 中，Marin 等人识别了一种新型长短期记忆生成器用于预测负荷。作者使用 LSTM 解码器通过 CRFM 和 FCBM 模型对每小时和分钟级负荷进行预测。未讨论结果中的离值问题。[24] 中提出的 CNN 深度学习网络在预测方面运行良好，与 ANN 模型相比取得了更好的性能。该模型使用了深度提升框架。Ku 和 Hu 提出了一种使用随机森林、DEC 和 LSTM 的 CNN 能量模型。结果显示 CNN 能量模型优于其他方法。模型的性能受离值影响。缺少对依赖性的考虑。
