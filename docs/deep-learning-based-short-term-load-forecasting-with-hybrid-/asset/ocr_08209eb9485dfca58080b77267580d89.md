The statistical and artificial intelligence based machine learning methods were utilized by researchers in the past. Now the deep learning methods are used for achieving efficiency with minimum effort. The deep learning based model has an ability of learning complexities, and spatial and temporal dependencies of the series data by stacking number of layers between input and output layers. For example, neural networks can handle non-linear mapping of series data. But, it suffers from the vanishing and the exploding gradients problem. The neural network utilizes backpropagation for generating the derivative [21]. While the gradients are small the learning becomes slow, and when they are large it creates the exploding gradients problem. So the use of RNN LSTM solves these problems by introducing gating mechanisms. The identification of importance of important feature, optimal lag and any minimum number of layers will guarantee the reduction of an overfitting issue. LSTM can capture large volume of high-dimensional data by considering multiple features.

The proposed RMR-LSTM deep learning prediction model consists of preliminary data processing, hybrid feature selection and deep prediction.

+   - The pre-processing stage handles the hourly time series electricity load and the associated weather data, by replacing the missing values with the past data, and reducing the data using min-max normalization.

The hybrid feature selection finds the relevant features by using of clustering, and wrapper feature selection. The RLLEf and mutual information feature selection identifies the features by removing the irrelevant and non-informative features with statistical characteristics. The approach reduces redundant and tunes the features selected by the feature selection SVR as the feature evaluator and finds the optimal subset of features

+   - The deep prediction phase predicts the load by using LSTM. The proposed deep learning model RMR-LSTM is compared against RNN and LSTM in terms of MAPE and RMSE metrics.

# 2. Related works

The review of related works investigated by various researchers is explored in this section. In [71], Marin et al. identified a novel long short term memory sequence generator for predicting the building load. The authors used an LSTM decoder model to approach the forecasting of both hourly and minute level load by CRFM and FCBM models. The results and consideration of the outliers in the results are not discussed. The CNN-based deep learning network presented in [24] worked well in forecasting and achieved better performance compared to ANN models like regression and ARIMA. The model is compared using a deep gradient boosting framework. Ku and Hu proposed a CNN deep energy load model for forecasting using random forest tree, DEC and LSTM. The result showed that the CNN deep energy load model outperformed other methods. The performance of the model was reduced by outliers. The consideration of the temporal dependency characteristics is missing.
