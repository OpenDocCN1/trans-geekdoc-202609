# 3.2.1. Feature selection

The feature selection is one of the important method to improve the performance of short term load forecasting. When the number of features increases the performance of prediction, but, when the data has a large number of features there is a chance of including irrelevant and non-important features and it may degrade the performance of prediction. The irrelevant features do not yield any useful information for prediction, instead, it confuses the learning algorithm and may be cause of dimensionality problem will be encountered. Hence, the performance of the learning algorithm is improved. There are two categories of feature selection, filter and wrapper feature selection. The filter selection method works far better by considering

the statistical characteristics of each feature and target with the maximal relevant feature [27,38], but it does not guarantee an accurate prediction. On the other hand, the wrapper selection considers all the features and evaluates each subset of features by using the method evaluator. As a result the wrapper selection result is much better than the filter method [39,46]. The following section discusses Rleff, MI and R wrapper feature selection.

# 3.2.1.1. Rleff

The Recursive Regression (Rleff) feature selection is an advanced version of algorithm to help the reliability of features. It is the type of feature selection that has capacity of providing quality features in regression problems which are continuous. The Rleff instance based feature selection utilizes the kind of finding features in different orders [29,41]. The Rleff algorithm randomly selects and removes features from the original instance. Then, it selects k number of features using the variance function. After that, it calculates the weights for different subsets, different attributes and different orders.

```
P(A|B) = P(difference|nearest instances)
```

```
P(AG) = P(difference|nearest instances)
```

```
P(AG|ABC) = P(difference|difference of A and nearest instances)
```

```
W[A] = P(AG|ABC) * (1 - P(A|ABC)) / (1 - P(A)
```

The feature with the highest weight is considered as the best feature among other features. The Rleff has the same time complexity as that of simple regression.

# 3.2.1.2. Mutual information selection

The mutual information is a non linear correlation filter feature selection that calculates the correlation between two or more of features. The features have common information with other feature is called a dependent feature [22,23]. On the other hand, the features with no common information are called independent features. The mutual information method utilizes the dependency between the features related to the target as a base for finding the relevant feature. The amount of information shared between features is called mutual information. If there are two features, then the mutual information between them is measured as I(A;B). When the 'A' and 'B' are independent, the mutual information I(A;B) is 0. The data is in continuous. For continuous random variables, the mutual information of the feature 'A' is calculated as

```
I(A;B) = sum p(A,B) * log (p(A,B)/(p(A)p(B))) dB
```

where 'a' and 'b' represents the number of values in 'A' and 'B'. Then, the P(a,b) is the joint probability density of 'A' and 'B'. The pa and pb are marginal probability density function of 'A' and 'B'.
