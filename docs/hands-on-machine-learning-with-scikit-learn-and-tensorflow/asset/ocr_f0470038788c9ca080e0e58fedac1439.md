Keras does not include a depth-wise max pooling layer, but TensorFlow's low-level Deep Learning API does: just use the tf.nn.max_pool() function, and specify the kernel size and strides as 4-tuples. The first three values of each should be 1: this indicates the kernel size and stride along the batch, height and width should be 1. The last value should whatever kernel size and stride you want along the depth dimension, for example 3 (this must be a divisor of the input depth; it will not work if the previous layer outputs 20 feature maps, since 20 is not a multiple of 3):

```
output = tf.nn.max_pool(images,
ksize=(1, 1, 1, 3),
strides=(1, 1, 1, 3),
padding="VALID")
```

If you want to include this as a layer in your Keras models, you can wrap it in a Lambda layer (or create a custom Keras layer):

```
depth_pool = keras.layers.Lambda(
\lambda X: tf.nn.max_pool(X, ksize=(1, 1, 1, 3), strides=(1, 1, 1, 3),
padding="VALID")
```

One type of pooling layer that you will see in modern architectures is the global average pooling layer. It works very differently: it computes the mean of each feature map (it's like an average pooling layer using a kernel with the same spatial dimensions as the input). This means it outputs a single number per feature map and instance. Although this is of extremely destructive (most of the information in the feature map is lost), it can be useful as the output layer, as we will see later in this chapter. To create such a layer, simply use the keras.layers.GlobalAvgPool2D:

```
global_avg_pool = keras.layers.GlobalAvgPool2D()
```

It is actually equivalent to using this Lambda layer, which computes the mean over the spatial dimensions (height and width):

```
global_avg_pool = keras.layers.Lambda(lambda X: tf.reduce_mean(X, axis=[1, 2]))
```
