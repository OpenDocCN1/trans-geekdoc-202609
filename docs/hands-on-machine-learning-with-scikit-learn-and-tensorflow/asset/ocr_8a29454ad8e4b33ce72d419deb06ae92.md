# Evaluate Your System on the Test Set

After tweaking your models for a while, you eventually have a system that performs
sufficiently well. Now is the time to evaluate the final model on the test set. There
nothing special about this; just get the predictors and the labels from your
test set, run your final_pipeline to transform the data (call transform()), not
fit_transform(), you do not want to fit the test set!), and evaluate the final model
on the test set:

```
final_model = grid_search.best_estimator_

X_test = strat_test_set.drop('median_house_value', axis=1)
y_test = strat_test_set(['median_house_value']).copy()

X_test_prepared = full_pipeline.transform(X_test)

final_predictions = final_model.predict(X_test_prepared)

final_mse = mean_squared_error(y_test, final_predictions)
final_rmse = np.sqrt(final_mse)  #= evaluates to 47,738.2
```
