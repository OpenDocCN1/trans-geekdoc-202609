# # Implementing MLPs with Keras

Keras is a high-level Deep Learning API that allows you to easily build, train, evaluate and execute all sorts of neural networks. Its documentation (or specification) is available at https://keras.io. The reference implementation is simply called Keras as well, to avoid any confusion we will call keras-team (since it is available at https://github.com/keras-team/keras). It was developed by François Chollet as a research project¹ and released as an open source project in March 2015. It quickly gained popularity owing to its ease-of-use, flexibility and beautiful design. To perform the heavy computations required by neural networks, Keras relies on a computation backend. At the present, you can choose from three popular source deep learning libraries: TensorFlow, Microsoft Cognitive Toolkit (CNTK) or Theano.

Moreover, since late 2016, other implementations have been released. You can now run Keras on MXNet, Apple’s Core ML, Javascript or Typescript (to run Keras in a web browser), or PlaidML (which runs on all sorts of GPUs, not just Nvidia). TensorFlow itself comes bundled with ours, but it has the advantage of offering some very extra features (see Figure 10-10): for example, it supports TensorFlow's Data API which makes it easy to load and preprocess data efficiently. For this reason, we will use tf.keras in this book. However, in this chapter we will not use any of the TensorFlow-specific features, so the code should run fine on other Keras implementations as well (at least in Python), with only minor modifications, such as changing the imports.
