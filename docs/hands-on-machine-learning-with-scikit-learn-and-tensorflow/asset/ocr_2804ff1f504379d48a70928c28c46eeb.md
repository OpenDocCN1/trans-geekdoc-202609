# Data Cleaning

Most Machine Learning algorithms cannot work with missing features, so let's create a few functions to take care of them. You noticed earlier that the total_bedrooms attribute has missing values, so let's fix this. You have three options:

+   - Get rid of the corresponding districts.
- Get rid of the whole attribute.
- Set the values to some value (zero, the median, the mean, etc.).

You can accomplish this easily using DataFrame's dropna(), drop(), and fillna():

```
housing.dropna(subset=['total_bedrooms']) # option 1
housing.drop(['total_bedrooms'], axis=1) # option 2
median = housing['total_bedrooms'].median() # option 3
housing['total_bedrooms'].fillna(median, inplace=True)
```

If you choose option 3, you should compute the median value on the training set, and use it to fill the missing values in the training set, but also don't forget to save the median value that you computed. You will need it to replace missing values in the test set when you evaluate your system, and once the system goes live to replace missing values in new data.

Scikit-Learn provides a handy class to take care of missing values: SimpleImputer. Here is how to use it. First, you need to create a SimpleImputer instance, specifying what you want to replace each attribute's values with the median of that attribute:

```
from sklearn.impute import SimpleImputer

imimputer = SimpleImputer(strategy="median')
```

Since the median can only be computed on numerical attributes, we need to create a copy of the data with the test attribute ocean_proximity:

```
housing_num = housing.drop('ocean_proximity', axis=1)
```

Now you can fit the imputer instance to the training data using the fit() method:

```
imputer.fit(housing_num)
```

The imputer has simply computed the median of each attribute and stored the result in its statistics_ variable. Only the total_bedrooms attribute had missing values, but we cannot be sure that there are not missing values in new data after the system goes live, so it is safer to apply the imputer to all numerical attributes:

```
>>> imputer.statistics_
array([-118.51, 34.26, 29. , 2119.5, 433. , 1164. , 408. , 3.5409])
```
