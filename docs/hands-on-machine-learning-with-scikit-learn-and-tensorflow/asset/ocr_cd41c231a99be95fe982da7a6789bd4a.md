```
v[:, 2].assign([0, 1.]) # = [[2., 42., 0.], [8., 10., 1.]]
v.scatter_nd_update(indices=[[0, 0], [1, 2]], updates=[100., 200.])
# = [[100., 42., 0.], [8., 10., 200.]]
```

In practice you will rarely have to create variables manually, since
Keras provides an add_weight() method that will take care of it
as we see. Moreover, model parameters will generally be
updated directly by the optimizers, so you will rarely need to
update variables manually.

# # Other Data Structures

TensorFlow supports several other data structures, including the following (please see
the notebook or ??? for more details):

+   * Sparse tensors (tf.SparseTensor) efficiently represent tensors containing mostly
Os. The tf.sparse package contains operations for sparse tensors.
* Tensor arrays (tf.TensorArray) are lists of tensors. They have a fixed size by
default, but can be made dynamic. All tensors must have the
same shape and data type.
* Ragged tensors (tf.RaggedTensor) represent lists of lists of tensors, where
every tensor has the same shape and data type. The tf.ragged package contains
operations for ragged tensors.
* String tensors are regular tensors of tf.string. These actually represent by
strings, not Unicode strings, so if you create a string using a Unicode
string (e.g., a regular Python 3 string like "café") then it will be encoded to
UTF-8 automatically (e.g., b\xc3\xa9"). Alternatively, you can represent
Unicode strings using type=int32, where each item represents a
Unicode codepoint (e.g., [99, 97, 102, 233]). The tf.string package (with
s) consists of byte strings and Unicode strings and to convert into one
the other).
* Sets are just represented as regular tensors (or sparse tensors) containing one or
more sets, and you can manipulate them using operations from the tf.sets
package.
* Queues, including First In, First Out (FIFO) queues (FIFOQueue), queues that can
prioritize some items (PriorityQueue), queues that shuffle them (Random
ShuffleQueue), and queues that can batch items of different shapes by padding
(PaddingQueue). These classes are all in the tf.queue package.

With tensors, operations, variables and various data structures at your disposal, we
are now ready to customize your models and training algorithms!
