Now that we have a nice TFRecord file containing a serialized Example, let's try to load it.

# # Loading and Parsing Examples

To load the serialized protobufs, we will use tf.data.TFRecordDataset once again, and we will parse each Example using tf.io.parse_single_example(). This is a TensorFlow operation so it can be included in a TF Function. It requires at least two arguments: a string tensor containing the serialized data, and a description of each feature. The description is a dictionary that maps each feature name to a either tf.io.FixedLenFeature descriptor indicating the feature's shape, type and default value, or a tf.io.VarLenFeature descriptor indicating only the type (if the length may vary, such as for the "emails" feature). For example:

```
feature_description = {
    "name": tf.io.FixedLenFeature([])
```

```
for serialized_example in tf.data.TFRecordDataset(['my_contacts.tfrecord]):
    parsed_example = tf.io.parse_single_example(serialized_example,
        feature_description)
```

The fixed length features are parsed as regular tensors, but the variable length features are parsed as sparse tensors. You can convert a sparse tensor to a dense tensor using tf.sparse.to_dense(), but in this case it is simpler to access its values:

```
>>> tf.sparse.to_dense(parsed_example['emails'], default_value=b"")
<tf.Tensor: [...] dtype=string, numpy=array([b'a@b.com', b'c@d.com', [...]])])
>>> parsed_example['emails'].values
<tf.Tensor: [...] dtype=string, numpy=array([b'a@b.com', b'c@d.com', [...]])])
```

A Byteslist can contain any binary data, including any serialized example. For example, you can use tf.io.encode_jpeg to encode an image as JPEG, and format this data into a Byteslist. When your code reads the TFRecord, it will start by parsing the Example, then you will need to call tf.io.decode_jpeg() to parse the data and get the original image (or you can use tf.io.decode_image(), which can decode any BMP, GIF, JPEG or PNG image). You can also store any tensor you use in a Byteslist by serializing the tensor using tf.io.serialize_tensor(), then putting the resulting byte string in a Byteslist feature. When you parse the TFRecord, you can parse this data using tf.io.parse_tensor().
