If you want to regularize a self-normalizing network based on the SELU activation function (as discussed earlier), you should use AlphaDropout: this is a variant of dropout that preserves the mean and standard deviation of its inputs (it was introduced in the same paper as SELU, as regular dropout would break self-normalization).

# # Monte-Carlo (MC) Dropout

In 2016, a paper by Yarin Gal and Zoubin Ghahramani added more good reasons to use dropout:

+   - First, the paper establishes a profound connection between dropout networks (i.e., neural networks using a dropout layer before every layer) and approximate Bayesian inference, giving dropout a solid mathematical justification.
- Second, they introduce a powerful technique called MC Dropout, which can boost the performance of any trained dropout model, without having to retrain or even modify it at all!
- Moreover, MC Dropout also provides a much better measure of the model’s uncertainty.
- Finally, it is amazingly simple to implement. If this sounds like a “one weird trick” advertisement, take a look at the following code. It is the full implementation of MC Dropout, boosting the model we trained earlier, without retraining it:

```
with keras.backend.learning_phase(1): # force training mode = dropout
    y_probas = np.stack([model.predict(x_scaled) for sample in range(100)])
```

Since dropout is on, all predictions will be different. Recall that predict() returns a matrix with one row per instance, and one column per class. Since there are 10,000 instances in the test set, and this is a matrix of shape [10000, 10]. We stack 100 matrices, so y_probas is an array of shape [100, 10000, 10]. Once we average the first dimension (axis=0), we get y_proba, an array of shape [10000, 10], which we would get with a single prediction. That’s all! Averaging
