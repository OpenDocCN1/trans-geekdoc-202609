Figure 4-17 shows Ridge models trained on some linear data using different a value. On the left, plain Ridge models are used, leading to linear predictions. On the right, the first is expanded using PolynomialFeatures(degree=10), then it is scaled using a StandardScaler, and finally the Ridge models are applied to the resulting features: this is Polynomial Regression with Ridge regularization. Note how increasing a value leads to flatter (i.e., less extreme, more reasonable) predictions; this reduces the model's variance but increases its bias.

As with Linear Regression, we can perform Ridge Regression either by computing a closed-form equation or by performing Gradient Descent. The pros and cons are the same. Equation 4-9 shows the closed-form solution (where A is the $(n+1) \times (n+1)$ identity matrix) except with a in the top-left cell, corresponding to the bias term.
