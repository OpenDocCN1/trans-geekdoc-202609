

-   使用一种迭代优化方法，称为梯度下降（Gradient Descent, GD），它通过逐渐调整模型参数来使训练集上的代价函数最小，最终收敛到与第一方法相同的一组参数。我们将介绍梯度下降的几种变体，这些将在第二部分学习神经网络时反复使用：批量梯度下降（Batch GD）、小批量梯度下降（Mini-batch GD）和随机梯度下降（Stochastic GD）。

## 线性回归

在第 1 章中，我们查看了一个简单的生活满意度回归模型：life\_satisfaction = $\theta_0 + \theta_1 \times \text{GDP\_per\_capita}$。

该模型是输入特征 GDP\_per\_capita 的线性函数。$\theta_0$ 和 $\theta_1$ 是模型的参数。

更通地说，线性模型通过计算输入特征的加权和，加上一个称为偏置项（bias term，也称为截距项）的常量来进行预测，如方程 4-1 所示。

> 方程 4-1. 线性回归模型预测

```
$$\hat{y} = \theta_0 + \theta_1x_1 + \theta_2x_2 + \dots + \theta_nx_n$$
```

-   $\hat{y}$ 是预测值。
-   $n$ 是特征的数量。
-   $x_i$ 是第 $i^{th}$ 个特征值。
-   $\theta_j$ 是第 $j^{th}$ 个模型参数（包括偏置项 $\theta_0$ 和特征权重 $\theta_1, \theta_2, \dots, \theta_n$）。

可以使用向量形式更简洁地写，如方程 4-2 所示。

### 方程 4-2. 线性回归模型预测（向量化形式）

```
$\hat{y} = h_\theta(x) = \theta \cdot x$
```

-   $\theta$ 是模型的*参数向量*，包含了偏置项 $\theta_0$ 和特征权重 $\theta_1$ 到 $\theta_n$。
-   $x$ 是实例的*特征向量*，包含 $x_0$，其中 $x_0$ 始终等于 1。
-   $\theta \cdot x$ 是向量 $\theta$ 和 $x$ 的点积，它显然等于 $\theta_0x_0 + \theta_1x_1 + \theta_2x_2 + \dots + \theta_nx_n$。
-   $h$ 是假设函数，使用模型参数 $\theta$。

![](img/0684d2da98e09085c0a622d4fd69aaad_140_0.png)

在机器学习中，其他项通常表示为列向量，即具有单列的 2D 数组。如果 $\theta$ 和 $x$ 是列向量，那么预测为 $\hat{y} = \theta^T x$，其中 $\theta^T$ 是 $\theta$ 的转置（行向量而非列向量），$\theta^Tx$ 是 $\theta^T$ 和 $x$ 的矩阵乘法。预测结果显然是相同的，只是被表示为单单元矩阵而不是标量值。在书中我们将使用这种符号来避免在点积和矩阵乘法之间切换。

好了，以上是线性回归，现在我们如何训练它呢？回想，训练模型意味着设置其参数，使模型最好地拟合训练数据。为了这个目的，我们首先需要一个衡量模型拟合训练数据好坏（或差）的标准。在第 2 章中，我们看到回归模型最常见的性能衡量是均方根误差（RMSE）（方程 2-1）。因此，为了训练线性回归模型，你需要找到使 RMSE 最小的 $\theta$ 值。在实践中，最小化均方误差（MSE）比最小化 RMSE 更简单，且产生相同的结果。

线性回归在训练集上的 MSE 函数 $h_\theta$ 是使用方程 4-3 计算的。

方程 4-3. MSE

```
$MSE(h_\theta)=\frac{1}{m}\sum_{i=1}^{m} (y^{(i)} - h_\theta(x^{(i)}))^2$
```

通常情况下，我们使用正规方程来直接求解 $\theta$。正规方程（Normal Equation）提供了 $\theta$ 的解析解，见方程 4-4：$\theta=(X^T X)^{-1} X^T y$。

方程 4-4. 正规方程

```
$$\theta = (X^T X)^{-1} X^T y$$
```

正规方程 $X^T X$ 是可逆的，前提是特征之间不是线性相关的。如果特征是线性相关的，则 $X^T X$ 将不可逆。在这种情况下可以使用梯度下降法来求解 $\theta$。

正规方程的优点是它不需要选择学习率，也不需要迭代。但它的缺点是当特征数量 $n$ 很大时，计算 $(X^T X)^{-1}$ 非常耗时（复杂度为 $O(n^3)$）。因此在实际应用中，我们更多使用梯度下降法。

线性回归在训练集上的 MSE 函数 $h_\theta$ 是使用方程 4-3 计算的。

如图 4-1 所示，我们来生成一些线性数据：

```python
import numpy as np
X = np.array([[200, 3.5], [220, 1.2], [240, 1.0], [240, 3.2], [260, 1.1], [280, 1.0]])
y = np.array([7.1, 0.9, 0.5, 1.5, 1.2, 0.8])
```

我们可以使用 matplotlib 来绘制这些数据：

```python
import matplotlib.pyplot as plt
plt.scatter(X[:, 0], y, color='blue')
plt.xlabel("GDP per capita")
plt.ylabel("Life satisfaction")
plt.show()
```

现在我们使用正规方程来求解 $\theta$：

```python
X_b = np.c_[np.ones((6, 1)), X] 
theta_best = np.linalg.inv(X_b.T.dot(X_b)).dot(X_b.T).dot(y)
print(theta_best)
# 输出: [6.05263158 -0.02486842]
```

我们可以对新数据进行预测：

```python
X_new = np.array([[250, 1.0], [300, 1.0]])
X_new_b = np.c_[np.ones((2, 1)), X_new]
predictions = X_new_b.dot(theta_best)
print(predictions)
# 输出: [5.55394737 4.30263158]
```

我们可以绘制预测结果：

```python
plt.scatter(X[:, 0], y, color='blue')

plt.xlabel("GDP per capita")
```

我们可以使用梯度下降法来求解 $\theta$：

```python
def gradient_descent(X, y, learning_rate=0.01, n_iterations=1000):
    theta = np.random.randn(X.shape[1])
    for iteration in range(n_iterations):
        gradients = 2/len(X) * X.T.dot(X.dot(theta) - y)
        theta = theta - learning_rate * gradients
    return theta

theta_best_gd = gradient_descent(X_b, y)
print(theta_best_gd)
# 输出: [6.05263158 -0.02486842]
```

可以看到，梯度下降对学习率和迭代次数非常敏感。

```python
theta_best_gd = gradient_descent(X_b, y, learning_rate=0.1, n_iterations=1000)
theta_best_gd = gradient_descent(X_b, y, learning_rate=0.0001, n_iterations=100000)
```

通过特征缩放可以使梯度下降更快收敛：

```python
X_mean = np.mean(axis=0)
X_std = np.std(axis=0)
X_scaled = (X - X_mean) / X_std
X_b_scaled = np.c_[np.ones((6, 1)), X_scaled]
theta_best_gd = gradient_descent(X_b_scaled, y)
```

最后，我们可以使用正则化来防止过拟合：

```python
from sklearn.preprocessing import Ridge
X_scaled = (X - X_mean) / X_std
ridge_reg = Ridge(alpha=1)
ridge_reg.fit(X_scaled, y)
print(ridge_reg.intercept_)
print(ridge_reg.coef_)
```
