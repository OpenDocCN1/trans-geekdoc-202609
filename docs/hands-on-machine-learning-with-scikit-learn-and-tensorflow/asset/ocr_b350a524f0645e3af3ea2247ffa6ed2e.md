The algorithm takes longer if you require a very high precision. This is controlled by the tolerance hyperparameter $e$ (called tol in Scikit-Learn). In most classification tasks, the default tolerance is finite.

The SVC class is based on the libsvm library, which implements an algorithm that supports the kernel trick.^2$ The training complexity is usually $O(m^2 \times n)$ and $O(m^3 \times n)$. Unfortunately, this means it grows dreadfully slow when the number of instances gets large (e.g., hundreds of instances). This algorithm is perfect for complex but or small training sets. However, it scales well with the number of features, especially with sparse features (i.e., when each instance has nonzero features). In this case, the algorithm scales roughly with the average number of nonzero features per instance. Table 5-1 compares Scikit-Learn's SVM classification classes.

# # SVM Regression

As mentioned earlier, the SVM algorithm is quite versatile: not only does it support linear and nonlinear classification, it also supports linear and nonlinear regression. The trick is to reverse the objective: instead of trying to find the largest street between two classes while limiting margin violations, SVM Regression tries to fit as many instances as possible on the street while limiting margin violations (i.e., instances off the street). The width of the street is controlled by a hyperparameter $e$.
