A node's attribute counts how many training instances it applies to. For example, 100 training instances have a petal length greater than 2.45 cm (depth 1, right), among which 54 have a petal width smaller than 1.75 cm (depth 2, left). A node's value attribute tells you how many training instances of this class applies to: for example, the bottom-right node applies to 0 Iris-Setosa, 1 IrisVersicolor, and 45 Iris-Virginica. Finally, a node's gini attribute measures its impurity; if all training instances it belongs to the same class, for example, a node is "pure" (gtni=0) since the depth-1 node applies only to Iris-Setosa training, it is pure and its gini score is 0. Equation 6-1 shows how the training algorithm computes the gini score $G_i$ of the $i^{th}$ node. For example, the depth-2 node has a gini score equal to 1 - $(0/54)^2 - (49/54)^2 - (5/54)^2 = 0.168$. Another impurity measure is discarded shortly.

# Equation 6-1. Gini impurity

```
$G_i = 1 - \sum_{k=1}^{n} p_{i,k}^2$
```

+   $p_{i,k}$ is the ratio of class $k$ instances among the training instances in the $i^{th}$ node.
