# # Making Predictions

Let's see how the tree represented in Figure 6-1 makes predictions. Suppose you find an iris flower and you want to classify it. You start at the root node (depth 0, at the top): this node asks whether the flower's petal length is smaller than 2.45 cm. If it is, you move down to the root's left child node (depth 1, left). In this case, it is a leaf node (i., it does not have any children), so it not asks any questions: you can simply look at the predicted class for that node and the Decision Tree predicts that your flower is an Iris-Setosa(class=setosa).

Now suppose you find another flower, but this time the petal length is greater than 2.45 cm. You must move down to the root's right child node (depth 1, right), which is not a leaf node, so it asks another question: is the petal width smaller than 1.75 cm? If it is, your flower is most likely an Iris-Versicolor (depth 2, left). If not, it is likely an Iris-Virginica (depth 2, right). It's really simple.

> One of the many qualities of Decision Trees is that they require very little data preparation. In particular, they don't require scaling or centering at all.
