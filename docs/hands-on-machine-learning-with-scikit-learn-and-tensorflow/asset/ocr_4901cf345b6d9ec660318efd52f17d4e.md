# Custom Activation Functions, Initializers, Regularizers, and Constraints

Mosteras functionalities, as losses, regularizers, initializers, metrics, activation functions, layers and even full models can be customized in very much the same way. Most of the time, you will just need to write a simple function, with appropriate inputs and outputs. For example, here are examples of a custom activation function (equivalent to keras.activations.softplus or tf.nn.softplus), a custom Glor initializer (equivalent to keras.initializers.glot_normal), a custom regularizer (equivalent to keras.regularizers.l1(0.01)) and a custom constraint that ensures weights are all positive (equivalent to keras.constraints.nonneg() or tf.nn.relu).

```
def my_softplus(z): # return value is just tf.nn.softplus(z)
return tf.math.log(tf.exp(z) + 1.0)
```

```
def my_lorot_initializer(shape, dtype=float32):
stddev = tf.sqrt(2. / (shape[0] + shape[1]))
return tf.random.normal(shape, stddev=stddev, dtype=dtype)
```

```
def my_l1_regularizer(weights):
return tf.reduce_sum(abs(0.01 * weights))
```

```
def my_positive_weights(weights): # return value is just tf.nn.relu(weights)
return tf.where(weights < 0, tf.zeros_like(weights), weights)
```

As you can see, the arguments depend on the type of custom function. These custom functions can then be used by them, for example:

```
layer = keras.layers.Dense(30, activation=my_softplus,
kernel_initializer=my_lorot_initializer,
kernel_regularizer=my_l1_regularizer,
kernel_constraint=my_positive_weights)
```

The activation function will be applied to the output of the next layer. The layer's weights will be initialized using the value returned by the initializer. At each training step the weights will be passed to the regularization function to compute the regularization loss, which will be added to the main loss to get the final loss for training. Finally, the constraint function will be called after each training step, and the layer's weights will be replaced by the constrained weights.

If a function has some hyperparameters that need to be saved with the model, then you will need to subclass the appropriate class, such as keras.regularizers.Constraint, keras.initializers.Initializer or keras.layers (for any layer, including activation functions).
