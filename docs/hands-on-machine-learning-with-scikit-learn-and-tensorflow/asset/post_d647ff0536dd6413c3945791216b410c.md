Next, TF Transform allows you to apply this preprocess() function to the whole training using Apache Beam (it provides an AnalyzeAndTransformDataset class that you can use for this purpose in your Apache pipeline). In the process, it will also compute all the necessary statistics over the whole training set: in this example, the mean and standard deviation of the housing_median_age feature, and the vocabulary for the ocean_proximity feature. The components that compute these statistics are called analyzers.

Importantly, TF Transform will also generate an equivalent TensorFlow Function that you can plug into your model. This Function contains all the necessary statistics computed by Apache Beam (the mean, standard deviation, and vocabulary), simply included as constants.

At the time of this writing, TF Transform only supports TensorFlow-1. Moreover, Apache Beam only has partial support for Python 3. That said, both these limitations will likely be fixed by the time you read this.

Each item in the dataset is a dictionary containing both features and the labels. Keras expects each item to be a tuple containing 2 elements (again, the features and labels). You can transform the dataset using the map() method, like this:

```python
mnist_train = mnist_train.repeat(5).batch(32)
mnist_train = mnist_train.map(lambda items: (items["image"], items["label"]))
mnist_train = mnist_train.prefetch(1)
```

## The Architecture of the Visual Cortex

David H. Hubel and Torsten Wiesel performed a series of experiments on cats in 1958 and 1959 (and a few years later on monkeys), getting crucial insights into the structure of the visual cortex (the authors received the Nobel Prize in Physiology and Medicine in 1981 for their work). In particular, they showed that many neurons in the visual cortex have a small local receptive field, meaning they react to visual stimuli in a limited region of the visual field (see Figure 14-1, the receptive fields of five neurons are represented by dashed circles). The receptive fields of different neurons may overlap, and together tile the whole visual field. Moreover, others showed that some neurons react only to horizontal lines, while others react to lines with different orientations. They also noticed that some neurons have larger receptive fields, and react to more complex patterns that are combinations of the lower-level patterns. These observations led to the idea that the higher-level neurons are based on the outputs of neighboring lower-level neurons (in Figure 14-1, notice that each neuron is connected only to a few neurons from the previous layer). This powerful architecture is able to detect all sorts of complex patterns in any area of the visual field.
