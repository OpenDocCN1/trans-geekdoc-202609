# Classification and Localization

Localizing an object in a picture can be expressed as a regression task, as discussed in Chapter 10: to predict a bounding box around the object, a common approach is to predict the horizontal and vertical coordinates of the object's center, as well as its height and width. This means we have 4 numbers to predict. It does not require much to change the model, we just need to add a second output layer with 4 units (typically on top of the global average pooling), and it can be trained using the MSE loss:
