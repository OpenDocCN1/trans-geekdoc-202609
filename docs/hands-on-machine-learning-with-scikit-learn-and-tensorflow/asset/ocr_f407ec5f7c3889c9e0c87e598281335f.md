```
>>> ridge_reg.predct([[1.5]])
array([[1.550871465]])
```

And using Stochastic Gradient Descent:14

```
>>> sgd_reg = SGDRressor(penalty="l2")
>>> sgd_reg.fit(X, y.ravel())
>>> sgd_reg.predct([[1.5]])
array([[1.470125888]])
```

The penalty hyperparameter sets the type of regularization term to use. Specifying "l2" indicates that you want SGD to add a regularization term to use the cost function equal to half the square of the $\ell_2$ norm of the weight vector: this is simply Ridge Regression.

# Lasso Regression

Least Absolute Shrinkage and Selection Operator Regression (simply called Lasso Regression) is another regularized version of Linear Regression: just like Ridge, it adds a regularization term to the cost function, but it uses the $\ell_1$ norm of the weight vector instead of half the square of the $\ell_2$ norm (see Equation 4-10).

Equation 4-10. Lasso Regression cost function

$J(\theta) = MSE(\theta) + \alpha\sum_{i=1}^n |theta_i|$

Figure 4-18 shows the same as Figure 4-17 but replaces Ridge models with Lasso models and smaller $\alpha$ values.
