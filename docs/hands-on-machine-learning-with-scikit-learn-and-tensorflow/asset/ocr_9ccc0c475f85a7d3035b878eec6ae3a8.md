```
y_pred = model(y_batch)
main_loss = tf.reduce_mean(loss_fn(y_batch, y_pred))
loss = tf.add_n([main_loss] + losses)
grads = tape.gradient(loss, model.trainable_variables)
optimizer.apply_gradients(zip(grads, model.trainable_variables))
```

Congratulations, now you know how to build pipelines using the Data API! After we have CSV files which are common, simple and convenient, but they are not really efficient, and they do not support large or complex structures very well, such as image or audio. So let's use TFRecords instead.

# # TFRecord Format

The TFRecord format is TensorFlow's preferred format for storing large amounts of data and reading it efficiently. It is a very simple binary format that contains a sequence of binary records of varying sizes (each record has a length, a CRC checksum to check that the length was not corrupted, the actual data, and finally you easily create a TFRecord using the tf.io.TFRecordWriter

```
with tf.io.TFRecordWriter("my_data.tfrecord") as f:
    f.write(b"This is the first record")
    f.write(b"And this is the second record")
```

And you can use a tf.data.TFRecordDataset to read one or more TFRecord files:

```
filepaths = ["my_data.tfrecord"]
dataset = tf.data.TFRecordDataset(filepaths)
for item in dataset:
    print(item)
```

This will output:

```
tf.Tensor(b'This is the first record', shape=(), dtype=string)
tf.Tensor(b'And this is the second record', shape=(), dtype=string)
```

![](bbox=[0.163, 0.78, 0.243, 0.865])

By default a TFRecordDataset will read files one by one, but you can make read multiple files in parallel and interleave their records by setting num_parallel_reads. Alternatively, you could obtain the same result using list_files() and interleave() as we discussed earlier to read multiple CSV files.
