Specifically, a neuron located in row $i$, column $j$ of the feature map $k$ in a given convolutional layer $l$ is connected to the outputs of the neurons in the previous layer $l-1$, located in $i 	imes s_h$ to $i 	imes s_h + f_h - 1$ and columns $j 	imes s_w$ to $j 	imes s_w + f_w - 1$, across all feature maps (layer $l-1$). Note that all neurons located in the same row and column $j$ but in different feature maps are connected to the outputs of the exact same neurons in the previous layer.
