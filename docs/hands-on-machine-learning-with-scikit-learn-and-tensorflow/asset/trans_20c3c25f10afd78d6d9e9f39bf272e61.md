# 混淆矩阵

评估分类器性能的一种更好方法是查看混淆矩阵。通用思想是统计将类别 A 的实例分类为类别 B 的次数。例如，若想知道分类器将 5 的图像与 3 的图像混淆的次数，你需要查看混淆矩阵的第 5 行第 3 列。

要计算混淆矩阵，你首先需要一组预测值，以便它们与实际目标进行比较。你可以在测试集上进行预测，但我们先保持其不变（记住，你希望在项目的最后才使用测试集，那时你已经准备好了一个运行的分类器）。相反，你可以使用 `cross_val_predict()` 函数：

```python
from sklearn.model_selection import cross_val_predict
```

```python
y_train_pred = cross_val_predict(sgd_clf, X_train, y_train_5, cv=3)
```

就像 `cross_val_score()` 函数一样，`cross_val_predict()` 执行的是 K 折交叉验证，但它返回的不是评估分数，而是每个测试折上生成的预测。这意味着你为训练集中的每个实例获得了一个“干净”的预测（“干净”意味着该预测是由一个在训练期间从未见过这些数据的模型生成的）。

现在你准备好使用 `confusion_matrix()` 函数来获取混淆矩阵了。只需传入目标类别（`y_train_5`）和预测类别（`y_train_pred`）：

```python
>>> from sklearn.metrics import confusion_matrix
>>> confusion_matrix(y_train_5, y_train_pred)
array([[53857, 1522],
       [ 1325, 4096]])
```

混淆矩阵的每一行代表一个真实类别，每一列代表一个预测类别。该矩阵的第一行考虑了非 5 图像（负类）：其中 53,057 个被正确分类为非 5（它们是真阴性），而剩余的 1,522 个被错误分类为 5（假阳性）。第二行考虑了 5 的图像（正类）：1,325 个被错误分类为非 5（假阴性），而剩余的 4,096 个被正确分类为 5（真正性）。一个完美的分类器的主对角线（从左上到右下）上只有真正性的非零值：

```python
>>> y_train_perfect_predictions = y_train_5 # 假设我们达到了完美状态
>>> confusion_matrix(y_train_5, y_train_perfect_predictions)
array([[54579, 0],
       [ 0, 5421]])
```

混淆矩阵为你提供了很多信息，但有时你可能更倾向于更简洁的指标。一个值得关注的有趣点是正预测的准确率；这被称为分类器的**精确率**（公式 3-1）。

### 公式 3-1. 精确率
$$precision = \frac{TP}{TP + FP}$$
TP 是真正性的数量，FP 是假阳性的数量。获得完美精确率的一种简单方法是只做单次预测并确保它是正确的（精确率 = 1/1 = 100%）。这并没有什么用，因为分类器会忽略除一个实例之外的所有实例。因此，精确率通常与另一个指标**召回率**一起使用，它也称为敏感性或真正率（TPR）：这是被分类器正确检测到的正实例的比例（公式 3-2）。

### 公式 3-2. 召回率
$$recall = \frac{TP}{TP + FN}$$
FN 当然是假阴性的数量。如果你对混淆矩阵感到困惑，图 3-2 可能会有帮助。![](img/0684d2da98e09085c0a622d4fd69aaad_119_0.png) 图 3-2 混淆矩阵图
