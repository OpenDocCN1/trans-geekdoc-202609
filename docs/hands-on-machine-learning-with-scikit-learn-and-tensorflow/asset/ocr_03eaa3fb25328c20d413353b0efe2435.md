Moreover, callbacks can also be used during evaluation and predictions, you should ever need them (e.g., for debugging). In this case, you should implement on_test_begin(), on_test_end(), on_test_batch_begin(), or on_test_batch_end() (called by evaluate()), or on_predict_begin(), on_predict_end(), on_predict_batch_begin(), or on_predict_batch_end() (called by predict()).

# Visualization Using TensorBoard

TensorBoard is a great interactive visualization tool that you can use to view the learning curves between multiple runs, visualize the computation graph, analyze training statistics, view images generated by your model, visualize complex multidimensional data projected out to 3D and automatically clustered for you, and more! This tool is installed automatically when you install TensorFlow, so you already have it!

To use it, you must modify your program so that it outputs the data you want to visualize in binary logs called event files. Each binary data record is recorded as a summary. The TensorBoard server will monitor the directory, and it will automatically pick up the changes and update the visualizations. this allows you to visualize live data (with a short delay), as well as learning curves during training. In general, you want to point the TensorBoard server to a log directory, and configure your program so that it writes to a different subdirectory every time it runs. This way, the same TensorBoard instance will allow you to visualize and compare data from multiple runs of your program, without getting everything up.

So let's begin by defining the log directory we use for our TensorBoard logs, plus a small function to generate a subdirectory path based on the current date and so, that it is different every run. You might want to include extra information in the log directory name, as hyperparameter values that you are testing, to make it easier to know what you are looking at in TensorBoard:

```
root_logdir = os.path.join(os.curdir, "my_logs")
ndef get_run_logdir():
    import time
    run_id = time.strftime("run_%Y%m%d-%H_%M-%S")
    return os.path.join(root_logdir, run_id)
```
