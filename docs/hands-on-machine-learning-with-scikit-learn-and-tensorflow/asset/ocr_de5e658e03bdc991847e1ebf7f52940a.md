You might wonder how to select the landmarks. The simplest approach is to create a landmark at the location of each and every instance in the dataset. This creates many dimensions and thus increases the chances that the transformed training set will be linearly separable. The downside is that a training set with m instances and n features gets transformed into training set with m instances and m features (assuming you drop the original features). If your training set is very large, you will end up with an equally large number of features.

# Gaussian RBF Kernel

Just like the polynomial features, the similarity features method can be useful with any Machine Learning algorithm, but it may be computationally expensive to compute all the additional features, especially on large training sets. However, once the kernel trick does its SVM magic: it becomes possible to obtain a similar result as if you had added many similarity features, without having to add them. Let's try the Gaussian RBF kernel using the SVC class:

```
rbf_kernel_svm_clf = Pipeline([
  ('scaler', StandardScaler()),
  ('svm_clf', SVC(kernel='rbf', gamma=5, C=0.001))
])
rbf_kernel_svm_clf.fit(X, y);
```

This model is represented on the bottom left of Figure 5-9. The other plots show models trained with different values of hyperparameters gamma and C. Increasing gamma makes the bell-shape curve narrower (the left plot of Figure 5-8), and as each instance's range of influence is smaller: the decision boundary ends being more irregular, wriggling around individual instances. Conversely, a small gamma value makes the bell-shaped curve wider, so instances have a larger range of influence, and the decision boundary ends up smoother. So gamma acts as a regularization hyperparameter: if your model is overfitting, you should reduce it, and if it is underfitting, you should increase it (similar to the C hyperparameter).
