in_test_set = ids.apply(lambda id: test_set_check(id, test_ratio))

Unfortunately, the housing dataset does not have an identifier column. The simplest
solution is to use the row index as the ID:

```
housing_with_id = housing.reset_index(0)  # adds an 'index' column
train_test_set = split_train_test_by_id(housing_with_id, 0.2, "index")
```

If you use the row index as a unique identifier, you must make sure that data
ends to the end of the dataset, and no row ever gets deleted. If it is not\possible, you can try to use the most stable features to build a unique identifier.
For example, a district's latitude and longitude are guaranteed to be stable for a few
y, you could combine them into one ID like:

```
housing_with_id['id'] = housing['longitude'] * 1000 + housing['latitude']
train_test_set = split_train_test_by_id(housing_with_id, 0.2, "id")
```

Scikit-Learn has a few functions to split datasets into subsets in various
ways. The simplest function is train_test_split, which does pretty much the same
th the function split_train_test defined earlier, with a couple of additional\features. First there is a random_state parameter that allows you to set the random
generator as seed previously, and then you can pass multiple datasets
an identical number of rows, and it will split them on the same indices (this is
very useful, for example, if you have a separate DataFrame for labels):

```
from sklearn.model_selection import train_test_split
```

```
train_test_set = train_test_split(housing, test_size=0.2, random_state=42)
```

So far we have considered random sampling methods. But what if
your dataset is large enough (relative to the number of attributes), but if it
is not, you run the risk of introducing a significant sampling bias. When a survey
decides to call 1000 people to ask them a few questions, they don't just pick
1000 people randomly in a phone book. They try to ensure that these 1000
are representative of the whole population. For example, the US population is com-
ned of 51.3% female and 48.7% male, so a well-conducted survey in the US would
t to maintain this ratio in the same: 513 female and 487 male. This is called strati-
fied sampling: the population is divided into homogeneous subgroups each stratum,
to guarantee that the nt test set is representative of the overall population. If they used purely random-
pling, there would be about 12% chance of sampling a skewed test set with less
than 49% female or more than 54% female. Either way, the results would be
significantly biased.
