To avoid these issues it is feasible to use a more flexible model. The objective is to find a balance between keeping the street as large as possible and limiting the margin violations (i.e., instances that end up in the middle of the street or even on the wrong side). This is called soft margin classification.

In Scikit-Learn's SVM classes, you can control this balance using the C hyperparameter: a smaller C value leads to a wider street but more margin violations. Figure 5-4 shows the decision boundaries and margins of two soft SVM classifiers on a nonlinearly separable dataset. On the left, using a low C value the margin is quite large, but many instances end up on the street. On the right, using a high C value the classifier makes fewer margin violations but ends with a smaller margin. It seems likely the first classifier will generalize better: in fact even this training it makes fewer prediction errors, some of the margin violations are actually on the correct side of the decision boundary.
