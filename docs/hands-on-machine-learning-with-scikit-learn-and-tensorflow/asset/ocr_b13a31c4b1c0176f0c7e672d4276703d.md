Ensemble methods work best when the predictors are independent from one another as possible. One way to get diverse classifiers is to train them using very different algorithms. This increases the chance that they will make different types of errors, improving the ensemble's accuracy.

The following code creates and trains a voting classifier in Scikit-Learn, composed of three classifiers (the training set is the mne dataset, introduced in Chapter 5):

```
from sklearn.ensemble import RandomForestClassifier
from sklearn.ensemble import VotingClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.svm import SVC

log_clf = LogisticRegression()
rnd_clf = RandomForestClassifier()
svm_clf = SVC()

voting_clf = VotingClassifier(
    estimators=[('log_clf', log_clf), ('rf', rnd_clf), ('svc', svm_clf)],
    voting='hard')
voting_clf.fit(X_train, y_train)
```

Let's look at each classifier's accuracy on the test set:

```
>>> sklearn.metrics import accuracy_score
>>> clf in (log_clf, rnd_clf, svm_clf, voting_clf):

    y_pred = clf.predict(X_test)

```

If all classifiers are able to estimate class probabilities (i.e. they have a dict_proba() method), you can tell Scikit-Learn to predict the class with the highest class probability, averaged over all the classifiers. This called soft voting often achieves higher performance than hard voting because it gives more weight to highly confident voters. All you need to do is replace voting='hard' with voting='soft' and ensure that all classifiers can estimate class probabilities.
