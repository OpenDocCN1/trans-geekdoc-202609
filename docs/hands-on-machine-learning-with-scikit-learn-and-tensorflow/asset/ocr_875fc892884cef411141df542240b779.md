# Creating an Isolated Environment

If you would like to work in an isolated environment (which is strongly recommended so can work on different projects without conflicting library versions), install virtualenv by running the following pip command (again, if you want virtualenv to be installed for all users on your machine, remove --user and run with administrator rights):

```
$ python3 -m pip install --U virtualenv
Collecting virtualenv
[...
Successfully installed virtualenv
```

Now you can create an isolated Python environment by typing:

```
$ cd $ML_PATH
$ virtualenv env
Using base prefix '[...'
New Python executable in [...]/ml/env/bin/python3.6
Also creating executable in [...]/ml/env/bin/python
Installing setuptools, pip, wheel...done.
```
