Equation 9-1. Bayesian information criterion (BIC) and Akaike information criterion (AIC)

```
BIC = log(m) - 2 log (\hat{L})
AIC = 2p - 2 log (\hat{L})
```

+   - m is the number of instances, as always.
- p is the number of parameters learned by the model.
- \hat{L} is the maximized value of the likelihood function for the model.

Both the BIC and AIC penalize models that have more parameters to learn (e.g., more clusters), and reward models that fit the data well. They often end up selecting the same model, but when they differ, the model selected by the BIC tends to be simpler (fewer parameters than the one selected by the AIC, but it does not fit the data well as this is especially true for larger datasets).
