Somewhat surprisingly, the DBSCAN class does not have a predict() method, although it has a fit_predict() method. In other words, it cannot predict which cluster a new instance belongs to. The rationale for this decision is that several algorithms could make sense here, and it is easy enough to train one, for example a KNeighborsClassifier:

```
from sklearn.neighbors import KNeighborsClassifier
```

```
knn = KNeighborsClassifier(n_neighbors=50)
knn.fit(dbscan.components_, dbscan.labels_[dbscan.core_sample_indices_])
```

Now, given a few instances, we can predict which cluster they most likely to be, and even estimate a probability for each cluster. That we only trained them on the core instances, but we could also have trained them on all the instances, or all the anomalies: this choice depends on the final task.

```
>>> X_new = np.array([[0.5, 0], [0, 0.5], [1, -0.1], [2, 1]])
>>> knn.predict(X_new)
array([1, 1, 1, 0])
>>> knn.predict_proba(X_new)
array([[0.18, 0.82],
       [0.12, 0.88],
       [1., 0.]])
```

The decision boundary is represented on Figure 9-15 (the crosses represent the 4 instances in X_new). Notice that there is no anomaly in the KNN's training set, the classifier chooses a cluster, even when cluster is far away. However, it is fairly straightforward to introduce a maximum distance, in which case the two instances that are far away from clusters are classified as anomalies. To do this, we can use the neighbors() method of the KNeighborsClassifier: given a set of instances, it returns the distances and the indices of the k nearest neighbors in the training set (two matrices, with k columns):

```
>>> y_dist, y_pred_idx = knn.neighbors(X_new, n_neighbors=1)
>>> y_pred = dbscan.labels_[dbscan.core_sample_indices_][y_pred_idx]
>>> y_pred[y_dist > 0] = -1
>>> y_pred.ravel()
array([-1, 0, 1, -1])
```
