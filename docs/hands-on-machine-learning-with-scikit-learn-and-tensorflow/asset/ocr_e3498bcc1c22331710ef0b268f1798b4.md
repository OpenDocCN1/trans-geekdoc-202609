```
>>> X_new = np.array([[0, 2], [3, 2], [-3, 3], [-3, 2.5]])
>>> kmeans.predict(X_new)
array([[1, 1, 2, 2]], dtype=int32)
```

If you plot the cluster's decision boundaries, you get a Voronoi tessellation (Figure 9-3, where each centroid is represented with an X):

Figure 9-3. K-Means decision boundaries (Voronoi tessellation)

The vast majority of the instances were clearly assigned to the appropriate cluster, a few instances were probably mislabeled (especially near the boundary between the top left cluster and the central centroid). Indeed, the K-Means algorithm does not behave well when the blobs have very different diameters since it cares about when assigning an instance to a cluster is the centroid.

Instead of assigning each instance to a single cluster, which is called *hard clustering*, it can be useful to give each instance a score per cluster: this is *soft clustering*. For example, the score should be the distance between the instance and the centroid, or it can be a similarity score (or affinity) such as the Gaussian Radial Basis Function (introduced in Chapter 5). In the K-Means class, the transform() method measures the distance from each instance to every centroid:

```
>>> kmeans.transform(X_new)
array([[2.8109363, 0.3295317, 2.904234, 1.4943934, 2.8863901],
       [5.8708532, 0.8209275, 5.8473923, 4.4759332, 5.84263531],
       [1.2147352, 2.3993768, 0.2940896, 1.6913663, 1.7108683],
       [0.7258141, 3.2180637, 0.3615948, 1.5480873, 2.21567622]])
```

In this example, the first instance in X_new is located at a distance of 2.81 from the first centroid, 0.33 from the second centroid, 2.90 from the third centroid, 1.49 from the fourth centroid and 2.87 from the fifth centroid. If you end up with a *k-dimensional* dataset: this can be a very efficient non-linear dimensionality reduction technique.
