# Semantic Segmentation

In semantic segmentation, each pixel is classified according to the class of the object it belongs to (e.g., road, car, pedestrian, building, etc.), as shown in Figure 14-26. Note that different objects of the same class are not distinguished. For example, the bicycles on the right side of the segmented image end up as one big lump of pixels. The main difficulty in this task is that when image goes through a regular CNN, they lose their spatial resolution (due to the layers with strides greater than 1): so a regular CNN may end up knowing that there's a person in the image, somewhere in the bottom left of the image, but it will not be more precise than that.

Just like object detection, there are many different approaches to tackle this problem, some quite complex. However, a fairly simple solution was proposed in a 2015 paper by Jonathan Long et al. They start by taking a pretrained CNN and turning it into an FCN. The CNN applies a stride of 2 to the input overall (i.e., if you add all strides greater than 1), meaning the last layer feature maps are 32 times smaller than the input. This is clearly too coarse, so they add a upsampling layer that multiplies the resolution by 32. There are several solutions available for upsampling (increasing the size of an image), such as bilinear interpolation, but it only works well up to x4 or x8. Instead, they use a transposed convolutional layer¹¹ it is equivalent to first stretching the image by inserting empty rows and columns (full of zeros), then performing a regular-ish convolution. Alternatively, some people prefer to think of it as a regular convolutional layer that uses fractional strides, it will learn better during training.

¹¹This type of layer is sometimes referred to as deconvolution layer, but it does not perform what mathematicians call deconvolution, so this name should be avoided.

![](img/0684d2da98e0985c0a62d4fd69aaad_505_0.png)

In a transposed convolution layer, the stride defines how much the input will be stretched, not the size of the filter, so the larger the stride, the larger the output (unlike for pooling layers).

# TensorFlow Convolution Operations

TensorFlow also offers a few other kinds of convolutional layers:

- keras.layers.Conv1d creates a convolutional layer for 1D inputs, such as time series or text (sequences of words).
- keras.layers.Conv3d creates a convolutional layer for 3D inputs, such as 3D scans.
- Setting the dilation_rate hyperparameter of any convolutional layer to a value of 2 or more creates an atrous convolutional layer (“atrous” is French for “with holes”). This is equivalent to using a regular convolutional layer with a filter dilation by inserting rows and columns of zeros (i.e., holes). For example, a 1 × 3 filter may be dilated with a dilation rate of 4, resulting in a dilated filter [[1, 0, 0, 0, 2, 0, 0, 3]]. This allows the convolutional layer to have a larger receptive field at no computational price and using extra parameters.
- tf.nn.depthwise_conv2d() can be used to create a depthwise convolutional layer (but you need to create the variables yourself). It applies every filter to every individual channel independently. Thus, if there are $f_H$ filters and $f_W$ input channels, then this will output $f_H \times f_W$ feature maps.

This solution is okay, but still imprecise. To do better, the authors added connections from lower layers: for example, they upsampled the output image by a factor of 2 (instead of 32), and they added the output of a lower layer that had this double resolution. Then they upsampled the result by a factor of 16, leading to a total upsampling factor of 32 (Figure 14-28). This recovered some of the spatial resolution that was lost in pooling layers. In their best architecture, they used a similar skip connection to recover even finer details from a lower layer: in short, the output of the original CNN goes through the following extra steps: upscale x2, add the output of a lower layer (of the appropriate scale), upscale x2, and finally upscale x8. It is even possible to scale up beyond the size of the original image: this can be used to increase the resolution of an image, which is a technique called super-resolution.
