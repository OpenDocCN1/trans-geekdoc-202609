# Ridge Regression

Ridge Regression (also called Tikhonov regularization) is a regularized version of Linear Regression: a regularization term equal to $\alpha\sum_{i}\theta_i^2$ is added to the cost function. This forces the learning algorithm to not only fit the data but also keep the model weights as small as possible. Note that the regularization term should only be added to the cost function during training. Once the model is trained, you may want to evaluate the model's performance using the unregularized performance measure.

It is common for the cost function used during training to be different from the performance measure used for testing. After regularization, another reason why they might be different is that a good training cost function should have optimization-friendly derivatives, while the performance measure used for testing should be as close as possible to the final objective. A good example of this is a classifier trained using a cost function such as log loss (discussed in a moment) but evaluated using precision.

The hyperparameter a controls how much you want to regularize the model. If a = 0 then Ridge Regression is just Linear Regression. If a is very large, then all weights end up very close to zero and the result is a flat line following the data's mean. Equation 4-8 presents the Ridge Regression cost function.

> Equation 4-8. Ridge Regression cost function
$J(\theta) = MSE(\theta) + \alpha\frac{1}{2}\sum\theta_i^2$

Note that the bias $\theta_0$ is not regularized (the sum starts at $i=1$, not 0). We define $\mathbf{w}$ as the vector of features ($\theta$ to $\theta$), while the regularization term is simply equal to $\frac{1}{2}|\mathbf{w}||^2$, where $|\mathbf{w}||$ represents the $\ell_2$ norm of the weight vector. For Gradient Descent, add $\alpha\mathbf{w}$ to the MSE gradient vector.

It is important to scale the data (e.g., using a StandardScaler) before performing Ridge Regression, as it is sensitive to the scale of the input features. This is true of regularized models.
