The authors of the BN paper argued in favor of adding the BN layers before the activation functions, rather than (as we did). There is some debate about this, as it seems to depend on the task. So that's one thing you can experiment with to see which option works best on your dataset. To add the BN layers before the activation functions, we must move the activation function from the hidden layers. Moreover, since a Batch Normalization layer includes one offset parameter per input, you can recover the bias term from the previous layer (just pass use_bias=False when creating it):

```
model = keras.Sequential([
    keras.layers.Flatten(input_shape=[28, 28]),
    keras.layers.BatchNormalization(),
    keras.layers.Dense(300, kernel_initializer="he_normal", use_bias=False),
    keras.layers.BatchNormalization(),
    keras.layers.Activation("elu"),
    keras.layers.Dense(100, kernel_initializer="he_normal", use_bias=False),
    keras.layers.Activation("relu"),
    keras.layers.BatchNormalization(),
    keras.layers.Dense(10, activation="softmax")
])
```

The BatchNormalization class has quite a few hyperparameters you can tweak. The defaults will usually be fine, but you may occasionally need to tweak the momentum. This hyperparameter is used when updating the moving averages: a new value v (i.e., a vector of input means or standard deviations over the current batch), the running average 	ilde{v} is updated using the following equation:

> \$\tilde{v} \leftarrow \tilde{v} \times \text{momentum} + v \times (1 - \text{momentum})$$\

A good momentum is typically close to 1—for example, 0.9, 0.99, or 0.999 (you want more 9s for larger datasets and smaller mini-batches).

Another important hyperparameter is axis: it determines which axis should be normalized. It defaults to -1, meaning that by default it will normalize the last axis (using the means and standard deviations computed over the other axes). For example, when the input is 2D (i.e., the shape is [batch size, features]), this means each input feature is normalized based on the mean and standard deviation computed across all instances in the batch.
