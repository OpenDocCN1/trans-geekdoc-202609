We will cover many of the packages and functions of the TensorFlow API, but it is impossible to cover them all so you should really take time to browse through the API: you will find that it is quite rich and well documented.

At the lowest level, each TensorFlow operation is implemented using highly efficient C++ code. Many operations (or ops for) have multiple implementations, kernels; each kernel is dedicated to a specific device type, such as CPUs, GPUs, or TPUs (TensorFlow Processing Units). As you may know, TPUs can dramatically speed up computations by splitting computations into many chunks and running them in parallel across many GPUs. You can run your own GPU devices, for now, TensorFlow only supports Nvidia devices with CUDA Compute Capability 3.5+, but TPUs are only available on Google Cloud Learning Engine (see ???).
