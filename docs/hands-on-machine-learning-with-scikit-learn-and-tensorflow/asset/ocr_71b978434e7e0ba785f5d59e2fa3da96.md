Now let's look at ResNet's architecture (see Figure 14-17). It is actually surprisingly simple. It starts and ends very deep like GoogLeNet (except a dropout layer), and in between is a very deep stack of simple residual units. Each residual unit is composed of two convolutional layers (and no pooling layer!), with Batch Normalization (BN) and ReLU activation, with 3 × 3 kernels and preserving spatial dimensions (stride 1, 2, SAME padding).
