RGB image (three channels), then the number of parameters is (5 × 5 × 3 + 1) × 200 = 15,200 (the +1 corresponds to the bias terms), which is fairly small compared to a fully connected layer. However, each of the 200 feature maps contains 150 × 100 neurons, each of these neurons needs to compute a weighted sum of 5 × 5 × 3 = 75: thus is a total of 225 million multiplications. Not as a fully connected layer, but still quite computationally intensive. Moreover, if the feature maps are represented as 32-bit floats, the convolutional layer's output will occupy 200 × 150 × 100 × 32 = 96 million bits (12 MB) of RAM. And that's just for one instance! If a training batch contains 100 instances, this layer will use up 1.2 GB of RAM!

During inference (i.e., when making a prediction for a new instance) the RAM occupied by one layer can be released as soon as the next layer has been computed, so you only need much RAM as required by two consecutive layers. While training everything during the forward pass must be preserved for the reverse pass, the amount of RAM needed is (at least) the total amount of RAM required by all layers.

If training crashes because of an out-of-memory error, you can try reducing the mini-batch size. Alternatively, you can try reducing dimensionality with a stride; removing a few layers. Or you can using 16-bit floats instead of 32-bit floats. Or you could distribute the CNN across multiple devices.

Now let's look at the second common building block of CNNs: the *pooling* layer.

# # Pooling Layer

Once you understand how convolutional layers work, the pooling layers are quite easy to grasp. Their goal is to subsample (i.e., shrink) the image order to reduce the computational load, the memory usage, and the number of parameters (thereby limiting the risk of overfitting).

Just like convolutional layers, each neuron in a pooling layer is connected to the outputs of a limited number of neurons in the previous layer, located within a small rectangular field. You must define its size, stride, and the padding type, just like before. However, a pooling layer has no weights; all it does aggregate the inputs using an aggregation function such as the max or mean.
