```
message Feature {
  Bytes bytes_list = 1;
  Floatlist float_list = 2;
  Int64 int64_list = 3;
}

message Features { map<string, Feature> features = 1 };
message Example { Features features = 1 };
```

The definitions of BytesList, FloatList and Int64List are straightforward enough ([packed = true] for repeated numerical fields, for a more efficient encoding). A feature contains a BytesList, a FloatList or an Int64List. A Features (with an s) contains a dictionary that maps a feature name to the corresponding feature. Finally, an example contains a Features object. Here is how you could code a tf.train.Example representing the same person as earlier, and write it to TFRecord file.

```
from tensorflow.train import BytesList, FloatList, Int64List
from tensorflow.train import Example, Features, Example
```

```
person_example = Example(
  features={
    "name": Feature(bytes_list=BytesList(["Alice"]),
    "id": Feature(int64_list=Int64List([123]))),
    "emails": Feature(bytes_list=BytesList(["b@b.com"]))
  }
)
```

The code is a bit verbose and repetitive, but it's rather straightforward (and you could easily wrap it in a smaller helper function). Now we can serialize it by using the SerializeToString() method, which will return the result data to a TFRecord file:

```
with tf.io.TFRecordWriter("my_contacts.tfrecord") as f:
  f.write(person_example.SerializeToString())
```

Normally you would write more than just one example! Typically, you would create a conversion script that reads from your format (say, CSV files), creates an Example protobuf for each instance, serializes them and saves them to several TFRecord files, deuffling them in the process. This requires a bit of work, so once again make sure it is really necessary (perhaps your pipeline works fine with CSV files).
