The MSE of a Linear Regression hypothesis $h_	heta$ on a training set X is calculated using Equation 4-3.

Equation 4-3. MSE cost function for a Linear Regression model

```
$MSE(X,h_\theta)=\frac{1}{m}\sum (\theta^T X^{(i)}-y^{(i)})^2$
```

Most of these notations were presented in Chapter 2 (see “Notations” on page 43). The only difference is that we write $h$ instead of $j$ in order to make it clear that the model is parametrized by the vector $\Theta$. To simplify notations, we will write $MSE(\Theta)$ instead of $MSE(X, h_	heta)$.

# The Normal Equation

To find the value of $	heta$ that minimizes the cost function, there is a closed-form solution - in other words, a mathematical equation that gives the result directly. This is called the Normal Equation (Equation 4-4).²

Equation 4-4. Normal Equation

```
$$\hat{\theta}=(X^T X)^{-1} X^T y$
```

+   - $\hat{	heta}$ is the value of that minimizes the cost function.
- $y$ is the vector of target values containing $y^{(1)}$ to $y^{(m)}$.
