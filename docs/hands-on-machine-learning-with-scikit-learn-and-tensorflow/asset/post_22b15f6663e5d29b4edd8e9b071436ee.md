Equation 9-1. Bayesian information criterion (BIC) and Akaike information criterion (AIC)

```
BIC = log(m) - 2 log (\hat{L})
AIC = 2p - 2 log (\hat{L})
```

- m is the number of instances, as always.
- p is the number of parameters learned by the model.
- \hat{L} is the maximized value of the likelihood function for the model.

Both the BIC and AIC penalize models that have more parameters to learn (e.g., more clusters), and reward models that fit the data well. They often end up selecting the same model, but when they differ, the model selected by the BIC tends to be simpler (fewer parameters than the one selected by the AIC, but it does not fit the data well as this is especially true for larger datasets).

Consider a one-dimensional mixture of two Gaussian distributions centered at -4 and +1. For simplicity, this model has a single parameter $\theta$ that controls the standard deviations of both distributions. The top left contour plot in Figure 9-20 shows the entire model $f(x)$ as a function of both $x$ and $\theta$. To estimate the probability distribution function $f(x)$, we set the model parameter $\theta$. For example, if you set $\theta=1.3$ (the horizontal line), you get the probability density function $f(x; \theta=1.3)$ shown in the lower left. If you want to estimate the probability that $x$ will fall between -2 and +2, you must calculate the integral of the PDF on this range (i.e., the area of the shaded region). On the other hand, if you have observed a single instance $x=2.5$ (the vertical line in the upper left), you get the likelihood function $l(\theta;x=2.5)$ represented in the upper right.

In short, the PDF is a function of $x$ (with fixed $\theta$) while the likelihood function is a function of $\theta$ (with fixed $x$). It is important to understand that the likelihood function is not a probability distribution: if you integrate a probability distribution over all possible values of $x$, you always get 1, but if you integrate the likelihood function over all possible values of $\theta$, the result can be any positive value.

Figure 9-20. A model parametric function (top left), and some derivatives: a PDF (lower left), a likelihood function (top right) and a log likelihood function (lower right)

Given a dataset **X**, a common task is to estimate the most likely values for the model parameters. To do this, you must find the values that maximize the likelihood function, given **X**. In example, if you observed a single instance $x=2.5$, the *maximum likelihood estimate* (MLE) of $\theta$. If a prior probability distribution $g$ over $\theta$, it is possible to take it into account by maximizing $l(\theta)g(\theta)$ rather than just maximizing $l(\theta)$. This is called maximum a-posteriori (MAP) estimation. Since MAP constraints the parameter values, you can think of it as a regularized version of MLE.

Notice that it is equivalent to maximize the likelihood function or to maximize its logarithm (represented in the lower right hand side of **Figure 9-20**); indeed, the logarithm is a strictly increasing function, so if $\theta$ maximizes the log likelihood, it maximizes the likelihood. It turns out that it is much easier to maximize the log likelihood, if you observed independent instances $x^{(1)}$ to $x^{(n)}$, you would need to find the value of $\theta$ that maximizes the product of the individual likelihood functions. It is equivalent, and much simpler, to maximize the sum (not product) of the log likelihood functions, thanks to the magic of the logarithm which converts products into sums: $\log(ab)=\log(a)+\log(b)$.

Once you have estimated $\theta$, the value of $\theta$ that maximizes the likelihood function, then you are ready to compute the AIC and BIC: $L = l(\theta, \mathbf{X})$. This is the value which is used to compute of it as a measure of how well the model fits the data.

To compare the AIC and BIC, just call the $bic(\cdot)$ or $aic(\cdot)$ methods:

```
>>> gm.bic(X)
8189.74345832983
>>> gm.aic(X)
8102.51878214792
```

### Bayesian Mixture Models

Rather than manually searching for the optimal number of clusters, it is possible to use the BayesianMixture class which is capable of giving weights automatically. For example, let's set the number of clusters to 10 and see what happens:

```python
from sklearn.mixture import BayesianMixture
bgm = BayesianMixture(n_components=10, random_state=42)
bgm.fit(X)
print(bgm.weights_)
```

In this model, the parameters (means and covariances) are not treated as fixed, but as random variables.

| | Instances |
|---|---|
| Likelihood | $D_{KL}(q||p)$ |
| Weights | $p(z)$ |
| Concentration | $\alpha$ |

The prior distribution of the parameters can be encoded in the prior. For example, if we use "spherical" rather than "full", then the model has fewer parameters, but it does not fit the data as well.

The likelihood function is a function of $\theta$ (with fixed $x$). It is important to understand that the likelihood function is not a probability distribution: if you integrate a probability distribution over all possible values of $x$, you always get 1, but if you integrate the likelihood function over all possible values of $\theta$, the result can be any positive value.

Bayes' theorem (Equation 9-2) tells us how to update the probability distribution after we observe $X$. It computes the posterior distribution $p(z|X)$:

```
$p(z|X) = \frac{p(X|z)p(z)}{p(X)}$
```

Unfortunately, in a Gaussian mixture (and many other problems), the denominator $p(X)$ is intractable, it requires integrating over all possible values of $z$.

```
$p(X) = \int p(X|z)dz$
```

This is one of the central problems in statistics, and there are several approaches to solving it. One of them is variational inference, which picks a family of distributions $q(z; \lambda)$, then optimizes these parameters to make $q(z)$ a good approximation of $p(z|X)$. This is achieved by picking the value of $\lambda$ that minimizes the KL divergence from $q(z)$ to $p(z|X)$. The KL divergence is seen in (Equation 9-4), and it can be rewritten as the log of the evidence $(\log p(X))$ minus the evidence lower bound (ELBO). Since the evidence does not depend on $q$, it is a constant term, so minimizing the KL divergence requires maximizing the ELBO.

Equation 9-4. KL divergence from $q(z)$ to $p(z|X)$

```
$D_{KL}(q||p) = E_{q}[\log \frac{q(z)}{p(z|X)}]
= E_{q}[\log q(z) - \log p(z | X)]
= E_{q}[\log q(z) - \log \frac{p(z,X)}{p(X)}]
= E_{q}[\log q(z) - \log p(z,X) + \log p(X)]$
= E_{q}[\log q(z)] - E_{q}[\log p(z,X)] + E_{q}[\log p(X)]$
= \log p(X) - ELBO$
where ELBO = $E_{q}[\log p(z,X)] - E_{q}[\log q(z)]$
```
