Building, evaluating and using a regression MLP using the Sequential API to make predictions is quite similar to what we did for classification. The main differences are that the output layer is a single neuron (since we use no activation), and the loss function is the mean squared error. Since the dataset is noisy, we just use a single hidden layer with fewer neurons than before, to avoid overfitting:

```
model = keras.models.Sequential([
    keras.layers.Dense(30, activation='relu', input_shape=X_train.shape[1]),
    keras.layers.Dense(1)

history = model.fit(X_train, y_train, epochs=20,
                   validation_data=(X_valid, y_valid))
```
