> If you plan to purchase a GPU card, its processing power and its memory size are of very important (in particular, a large RAM is crucial for computer vision), but its memory bandwidth is just as important as the processing power to get good performance: this is the number of gigabytes of data it can get out of per second.

With that, you can now build efficient pipelines to load and preprocess data from multiple text files. We have discussed the most common dataset methods, but there are a few more you may want to look at: concatenate(), zip(), window(), reduce(), cache(), shard(), flat_map() and padded_batch(). There are also couple more classes: from_generator() and from_tensor(), which create a new dataset from a Python generator or a list of tensors respectively. Check the API documentation for more details. Also note that there are experimental features available in tf.data.experimental which will likely make it to the core API in future releases (e.g., check out the CsvDataset class and the SqlDataset classes).
