A closely related task is novelty detection: it differs from anomaly detection in that the
alg is assumed to be trained on a "clean" dataset, uncontaminated by outliers,
whereas anomaly detection does not make this assumption. Indeed, outlier detection
is often precisely used to clean up a dataset.

> Gaussian mixture models try to fill all the data, including the out-
ers if you have too many of them, this will bias the model's view
of "normality": some outliers may wrongly be considered as normal. If this happens, you can try to fill the model once, use it to
detect and remove the most extreme outliers, then fit the model
again on the cleaned dataset. Another approach is to use robust
cariance estimation methods (the EllipticEnvelope class).
