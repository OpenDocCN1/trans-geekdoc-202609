outliers are exponentially rare (like in a bell-shaped curve), the RMSE performs very well and is generally preferred.

# Check the Assumptions

Lastly, it is good practice to list and verify the assumptions that were made so far (by you or others); this can catch serious issues early on. For example, the district prices that your system outputs are going to be fed into a downstream Machine Learning system, and we assume that these prices are going to be used as such. But what if the downstream system actually converts these prices into categories (e.g., "cheap," "medium," or "expensive") and then uses categories instead of the prices themselves? In this case, getting the price right is not important at all; your system just needs to get the category right. If that's so, the problem should have been framed as a classification task, not a regression task. You don't want to find this after working on a regression system for months.

Fortunately, after talking with the team in charge of the downstream system, you are confident that they do need the actual prices, not just categories. Great! You're set, the lights are green, and you can start coding now!
