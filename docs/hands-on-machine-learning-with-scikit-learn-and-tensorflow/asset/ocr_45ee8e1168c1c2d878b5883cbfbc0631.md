# Performance scheduling

Measure the validation error by a factor of $N$ steps (just like early stopping) and
reduce the learning rate by a factor of $\lambda$ when the error stops dropping.

A 2013 paper² by Andrew Senior et al. deing the performance of some of the
most popular learning schedules when training deep neural networks for speech recognition
using Momentum optimization. The authors concluded that, in this setting,
both performance scheduling and exponential scheduling performed well.
 favored exponential scheduling because it was easy to tune and it converged slightly
faster to the optimal solution (they also mentioned that it was easier to implement
than performance scheduling, but in Keras both are options).

Implementing power scheduling in Keras is the easiest option: just set the decay
hyparameter when creating an optimizer. The decay is $s$ (the number
of steps to divide the learning rate by one unit), and Keras assumes
at $c$ is equal to 1. For example:

```
optimizer = keras.optimizers.SGD(lr=0.01, decay=1e-4)
```

Exponential scheduling and piecewise decay are quite simple too. You first need
to define a function that takes the current epoch and returns the learning rate. For
example, let's implement exponential scheduling:

```
def exponential_decay_fn(epoch):
    return 0.1 * 0.1**(epoch / 20)
```

If you do not want to hard-code $\eta_0$ and $s$, you can create a function that returns a
configured function:

```
def exponential_decay(lr0, s):
    def exponential_decay_fn(epoch):
        return lr0 * 0.1**(epoch / s)
    return exponential_decay_fn
```

```
exponential_decay_fn = exponential_decay(lr0=0.01, s=20)
```

Next, create a LearningRateScheduler, giving the schedule function,
and pass this to the fit() method:

```
lr_scheduler = keras.callbacks.LearningRateScheduler(exponential_decay_fn)
history = model.fit(X_train_scaled, y_train, [..], callbacks=[lr_scheduler])
```
