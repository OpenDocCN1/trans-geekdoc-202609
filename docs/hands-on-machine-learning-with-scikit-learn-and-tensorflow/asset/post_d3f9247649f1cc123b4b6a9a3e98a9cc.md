# Performance Measures

Evaluating a classifier is significantly trickier than evaluating a regressor, so we will spend a large part of this chapter on this topic. There are many performance measures, but the most common is accuracy. For example, if a classifier is 99% accurate, it might be because 99% of the data belongs to one class and the classifier simply predicts that class all the time. In this case, accuracy is a misleading metric. We need other measures like precision, recall, and the F1-score.

- Precision: what proportion of predicted positive instances were actually positive?
- Recall: what proportion of actual positive instances were correctly identified?
- F1-score: the harmonic mean of precision and recall.

Let's use a confusion matrix to visualize the performance. A confusion matrix is a table where the rows represent the actual class labels and the columns represent the predicted classes:

```python
>>> from sklearn.metrics import confusion_matrix
>>> confusion_matrix(y_test, logreg.predict(X_test))
array([[9717,   283],
       [  95,   605]])
```

In this matrix, the top-left element is the number of true negatives (correctly predicted non-5), the top-right is the number of false positives (non-5 predicted as 5), the bottom-left is the number of false negatives (5 predicted as non-5), and the bottom-right is the number of true positives (correctly predicted 5s).

Now we can calculate the precision, recall, and F1-score:

```python
>>> from sklearn.metrics import precision_score, recall_score, f1_score
>>> precision_score(y_test, logreg.predict(X_test))
0.9733373337333734
>>> recall_score(y_test, logreg.predict(X_test))
0.8695652173913043
>>> f1_score(y_test, logreg.predict(X_test))
0.9154515451545155
```

The accuracy of the classifier is high, but the recall is much lower. This is because the classifier misses a lot of the actual 5s.
