# # Unsupervised Pretraining

Suppose you want to tackle a complex task for which you don't have much labeled training data, but unfortunately you cannot find a model trained on a similar task. Don't lose all hope! First, you should of course try to gather more labeled training data, but if this is too hard or expensive, you may still be able to perform *unsupervised training* (see Figure 11-5). It is often cheaper to gather unlabeled training examples, but quite expensive to label them. If you can get plenty of unlabeled training data, you can train the layers one by one, starting with the lowest and then going up, using an unsupervised feature detector algorithm as *Restricted Boltzmann Machines* (RBMs); or autoencoders (see ???). Each layer is trained on the output of the previously trained layers (all layers except the one being trained). Once all layers have been trained this way, you can add the output layer for your task, and fine-tune the final network using supervised learning (i.e., with the labeled training examples). At this point, you can unfreeze the pretrained layers, or just some of the upper ones.

This is a long and tedious process, but it works well; in fact, is this technique that Geoffrey Hinton and his team used in 2006 and which led to the revival of neural networks and the success of Deep Learning.
