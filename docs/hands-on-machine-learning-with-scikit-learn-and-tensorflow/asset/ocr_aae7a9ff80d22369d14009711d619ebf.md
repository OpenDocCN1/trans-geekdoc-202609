# Number of Neurons per Hidden Layer

Obviously the number of neurons in the input and output layers is determined by the type of input and output your task requires. For example, the MNIST task requires 28 x 28 = 784 input neurons and 10 output neurons.

As for the hidden layers, it used to be a common practice to size them to form a pyramid, with fewer and fewer neurons at each layer—the rationale that many low-level features coalesce into far fewer high-level features. For example, a typical neural network for MNIST may have three hidden layers, with 300 neurons, the second with 20, and the third with 100. This practice has been largely abandoned, as it simply using the same number of neurons in all hidden layers performs as well in most cases, or even better, and there is just one hyperparameter to tune instead of one layer—for example, all hidden layers could have simply 150 neurons. However, depending on the dataset, it can help to make the first hidden layer bigger than the others.

Just like the number of layers, you can try increasing the number of neurons until the network starts overfitting. In general you will get more bang for the buck by increasing the number of layers than the number of neurons per layer. Unfortunately, as you can see, finding the perfect amount of neurons is somewhat of a dark art.

A simpler approach is to pick a model with more layers and neurons than you actually need, then early stopping to prevent from overfitting (and regularization techniques, such as dropout, as we see in Chapter 11). This has been dubbed the "stretch pants" approach:17 instead of wasting time looking for pants that perfectly match your size, use large stretch pants that will shrink down to the right size.
