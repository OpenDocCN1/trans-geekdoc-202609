To implement max-norm regularization in Keras, just set every hidden layer's nel_constraint to a max_norm() constraint, with the appropriate max value, for example:

```
keras.layers.Dense(100, activation="elu", kernel_initializer="he_normal", kernel_constraint=keras.constraints.max_norm(1))
```

After each training iteration, the model's fit() method will call the object returned by max_norm(), passing the layer weights and getting clipped weights in return, which then replace the layer's weights. As we will see in Chapter 12, you can define your own custom constraint function if you need to, and use it as the nel_constraint. You can also constrain the bias terms by setting the bias_constraint argument.

The max_norm() function has an axis argument that defaults to 0. A Dense layer usually has weights of shape [number of inputs, neurons], so using axis= means that the max norm constraint will independently apply to each neuron's vector. If you want to use max-norm with convolutional layers (see Chapter 14), make sure to set the max_norm() constraint's axis argument appropriately (usually axis=[0, 1, 2]).
