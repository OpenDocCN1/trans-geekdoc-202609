from sklearn.datasets import load_sample_image

```
# Load sample images
china = load_sample_image("china.jpg") / 255
flower = load_sample_image("flower.jpg") / 255
images = np.array([china, flower])
batch_size, height, width, channels = images.shape
```

```
# Create 2 filters
filters = np.zeros((7, 7, channels, 2), dtype=np.float32)
filters[:, :, 3, 0] = 1 # vertical line
filters[:, :, 3, 1] = 1 # horizontal line
```

```
outputs = tf.nn.conv2d(images, filters, strides=1, padding="SAME")

plt.imshow(outputs[0,:,:,1], cmap='gray') # plot 1 image's 2nd feature map
plt.show()
```

Most of this code is self-explanatory, but the tf.nn.conv2d() line serves a bit of explanation:

+   - images is the input mini-batch (a 4D tensor, as explained earlier).
- filters is the set of filters to apply (also a 4D tensor, as explained earlier).
- strides is equal to 1, but it could also be a 1D array with 4 elements, where the two central elements are the vertical and horizontal strides ($s_v$ and $s_h$). The first and last elements currently be equal to 1. One day may be used to specify a stride (to skip some instances) and a channel stride (to skip some of the previous layer's feature maps or channels).
- padding must be either "VALID" or "SAME":

+   - If set to "VALID", the convolutional layer does not use zero padding, and may ignore some rows and columns at the bottom and right of the input image, depending on the stride, as shown in Figure 14-7 (for simplicity, only the horizontal dimension is shown here, but of course the same logic applies to the vertical dimension).
- If set to "SAME", the convolutional layer uses zero padding if necessary. In case, the number of output neurons is equal to the number of input neurons divided by the stride, rounded up (in this example, 13/5=2.6, rounded up to 3). Then zeros are added as evenly as possible around the inputs.
