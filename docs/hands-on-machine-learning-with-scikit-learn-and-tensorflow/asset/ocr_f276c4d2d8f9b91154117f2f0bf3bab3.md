```
"ocean_proximity_id": ocean_proximity_id
}
```

Next, TF Transform allows you to apply this preprocess() function to the whole training using Apache Beam (it provides an AnalyzeAndTransformDataset class that you can use for this purpose in your Apache pipeline). In the process, it will also compute all the necessary statistics over the whole training set: in this example, the mean and standard deviation of the housing_median_age feature, and the vocabulary for the ocean_proximity feature. The components that compute these statistics are called analyzers.

Importantly, TF Transform will also generate an equivalent TensorFlow Function that you can plug into your model. This Function contains all the necessary statistics computed by Apache Beam (the mean, standard deviation, and vocabulary), simply included as constants.

At the time of this writing, TF Transform only supports TensorFlow-1. Moreover, Apache Beam only has partial support for Python 3. That said, both these limitations will likely be fixed by the time you read this.

With the Data API, TFRecords, the Features API and TF Transform, you can build highly scalable input pipelines for training, and also benefit from fast and portable data preprocessing in production.

But what if you wanted to use a standard dataset? Well in that case, things are much simpler: just use TFDS!

# # The TensorFlow Datasets (TFDS) Project

The TensorFlow Datasets project makes it trivial to download datasets, from small ones like MNIST or Fashion MNIST, to huge datasets like ImageNet1¹ (you will need a bit of disk space!). The list includes image datasets, text (including translation datasets), audio and video datasets. You can visit https://tensorflow.info/tfds to view the full list, with a description of each dataset.

TFDS is not bundled with TensorFlow, so you need to install the tensorflow-datasets library (e.g., using pip). Then all you need to do is call the tfds.load() function, and it will download the data you want (unless it already downloaded earlier), and return the data as a dictionary of Datasets (typically one for training).

+   At the time of writing, TFDS requires you to download a few files manually for ImageNet (for legal reasons), but this will hopefully get resolved soon.
