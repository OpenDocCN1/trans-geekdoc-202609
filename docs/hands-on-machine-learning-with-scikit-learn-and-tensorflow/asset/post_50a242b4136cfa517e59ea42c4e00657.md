Just like Inception-v4, it also merges the ideas of GoogleNet and ResNet, but it replaces the inception modules with a special type of layer called depthwise separable convolution (or separable convolution for short⁴). These layers were used before in some CNN architectures, but they were not as central as in the Xception architecture. While a regular convolutional layer filters that to simultaneously capture spatial patterns and cross-channel patterns (e.g., oval) and (mouth + nose + eyes = face), a separable convolutional layer makes the strong assumption that spatial patterns and cross-channel patterns can be modeled separately (see Figure 14-19). This is composed of two parts: the first part lies a single spatial filter for each input feature map, then the second part looks exclusively for cross-channel patterns—it is just a regular convolutional layer with 1x1 filters.

![](img/0684d2da98e09085c0a622d4fd69aaad_485_0.png)

Figure 14-19. Deepwise Separable Convolutional Layer

Since separable convolutional layers only have one spatial filter per input channel, you should avoid using them after layers that have too few channels, such as the input layer (granted, that is what Figure 14-19 represents, but it is just for illustration purposes). For this reason, the Xception architecture starts with 2 regular convolutional layers, but then the rest of the architecture uses only separable convolutions (34), plus a few max pooling layers and the usual final layers (a global average pooling layer, and a dense output layer). You might wonder why Xception is considered a variant of GoogNet since it contains no inception module at all? Well, as we discussed, an Inception module contains convolutional layers with 1x1 filters: these use exclusively for cross-channel patterns. However, the convolution layers that sit on top of them are regular convolutional layers that look both for spatial and cross-channel patterns. You can think of an Inception module as an intermediate between a regular convolutional layer (which considers spatial and cross-channel patterns jointly) and a separable convolutional layer (which considers them separately). In practice, it seems separable convolutions perform better.

They used an ensemble of many different techniques, including a sophisticated object-detection system called GBP-Net to achieve a top-5 error rate below 3%. Although this result is unquestionably impressive, the complexity of solution contrasted with the simplicity of Resets. ## SENet

The winning architecture in the ILSVRC 2016 challenge was the Squeeze-Excitation Network (SENet). This architecture extends existing architectures such as inception networks or Resets, and boosts their performance. This enabled SENet to win the competition with an astonishing 2.25% top-5 error rate! The extended version of inception networks and ResNet are called SE-Inception and SE-ResNet respectively. The boost comes from the fact that SENet adds a small neural network, called a SE Block, to every unit in the original architecture (i.e., every inception module or every residual unit), as shown in Figure 14-20.

> ¹⁹ “Crafting GBP-Net for Object Detection,” X. Zeng et al. (2016).
> ²⁰ “Squeeze-Excitation Networks,” Jie Hu et al. (2017)

![](img/0684d2da98e09085c0a622d4fd69aaad_487_0.png)

Figure 14-20. SE-Inception Module (left) and SE-ResNet Unit (right)

A SE Block analyzes the output of the unit it is attached to, focusing exclusively on the depth dimension (it does not look for any spatial pattern), and it learns which features are most active. It then uses this information to recalibrate the feature maps, as shown in Figure 14-21. For example, a SE Block may learn that mouths, noses and eyes usually appear together: if you have a mouth and a nose, you should expect to see eyes as well. So if a SE Block sees a strong activation in the mouth and nose feature maps, but only mild activation in the eye feature map (more accurately, it will reduce irrelevant feature maps). If the eyes were somewhat confused with something else, this feature map recalibration will help resolve the ambiguity.

![](img/0684d2da98e09085c0a622d4fd69aaad_488_0.png)

Figure 14-21. An SE Block Performs Feature Map Recalibration

An SE Block is composed of just 3 layers: a global average pooling layer, a hidden dense layer using the ReLU activation function, and a dense output layer using the sigmoid activation function (see Figure 14-22):

![](img/0684d2da98e09085c0a622d4fd69aaad_488_1.png)

Figure 14-22. SE Block Architecture

As earlier, the global average pooling layer computes the mean activation for each feature map: for example, if its input contains 256 feature maps, it will output 256 numbers representing the overall level of response for each filter. The next layer is where the "squeeze" happens: this layer has less than 256 neurons, 16 times less than the number of feature maps (e.g., 16 neurons), so the 256 get pressed into a small vector (e.g., 16 dimensional). This is a low-dimensional vector representation (i.e., an embedding) of the distribution of features. This bottleneck steps the SE Block to learn a general representation of the feature combinations (we will see this in action when we discuss encoders). Finally, the output layer takes this recalibration vector containing one number per feature map (e.g., 256), which is between 0 and 1. The feature maps are then multiplied by this recalibration vector, so irrelevant features (with a low recalibration score to 0) get scaled down while relevant features (with a recalibration score to 1) are left alone.

## Implementing a ResNet-34 CNN Using Keras

Most CNN architectures described so far are fairly straightforward to implement (although you could use a pretrained network instead, as we will do). To illustrate the process, let's implement a ResNet-34 from scratch using Keras. First, we create a ResidualUnit:

```
DefaultConv2D = partial(keras.layers.Conv2D, kernel_size=3, strides=1,
                          padding="SAME", use_bias=False)
```

class ResidualUnit(keras.layers.Layer):
    def __init__(self, filters, strides=1, activation='relu', **kwargs):
        super().__init__(**kwargs)
        self.main_layers = [
            DefaultConv2D(filters, strides=strides),
            keras.layers.BatchNormalization(),
            DefaultConv2D(filters),
            keras.layers.BatchNormalization(),
        ]
        self.activation = keras.layers.Activation(activation)
        if strides != 1:
            self.skip_layers = [
                DefaultConv2D(filters, kernel_size=1),
                keras.layers.BatchNormalization(),
            ]
        else:
            self.skip_layers = []

    def call(self, inputs):
        Z = inputs
        for layer in self.main_layers:
            Z = layer(Z)
        skip_Z = inputs
        for layer in self.skip_layers:
            skip_Z = layer(skip_Z)
        return self.activation(Z + skip_Z)
```

```
model = keras.models.Sequential()
model.add(DefaultConv2D(64, kernel_size=7, strides=2, input_shape=[224, 224, 3]))
model.add(keras.layers.BatchNormalization())
model.add(keras.layers.Activation('relu'))
model.add(keras.layers.MaxPooling2D(pool_size=3, strides=2, padding='same'))
prev_filters = 64
for filters in [64] * 3 + [128] * 4 + [256] * 6 + [512] * 3:
    strides = 1 if filters == prev_filters else 2
    model.add(ResidualUnit(filters, strides=strides))
    prev_filters = filters
model.add(keras.layers.GlobalAvgPooling2D())
model.add(keras.layers.Flatten())
model.add(keras.layers.Dense(10, activation='softmax'))
```

It is quite amazing that with less than 40 lines of code, we can build the model that the ILSVRC 2015 challenge demanded! It demonstrates the elegance of the ResNet model, and the expressiveness of the Keras API. Implementing the other CNN architectures is not much harder. However, Keras comes with several of these architectures built in, why not we use them instead?

## Using Pretrained Models From Keras

In general, you will have to implement standard models like GoogNet or ResNet manually, using pretrained networks are readily available with a single line of code, in the keras.applications package. For example:

```
model = keras.applications.resnet50(weights='imagenet')
```
