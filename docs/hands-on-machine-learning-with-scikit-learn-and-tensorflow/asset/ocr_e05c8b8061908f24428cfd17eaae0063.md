An improvement to the K-Means algorithm, called K-Means+, was proposed in a 2006 paper by David Arthur and Sergei Vassilitskii; they introduced a smarter initialization step that selects centroids that are distant from one another, and makes the K-Means algorithm much less likely to converge to a suboptimal solution. They showed that the additional computation required for the smarter initialization step is worth it as it makes possible to drastically reduce the number of times the algorithm needs to run to find the optimal solution. Here is the K-Means++ initialization algorithm:

+   * Take one centroid c(¹), chosen uniformly from the dataset.

+   * Take a new centroid c⁰, choosing an instance x⁰ with probability: D(x⁰)² ∑ⱼ=1¹ D(x⁰)⁵ where D(x⁰) is the distance between the instance x⁰ and the closest centroid that was already chosen. This probability distribution ensures that instances further away from already chosen centroids are much more likely to be selected.

+   * Repeat the process step until all k centroids have been chosen.

The KMeans actually use this initialization method by default. If you want to force it to the original method (i.e., picking k instances randomly to the initial centroids), you can set the init hyperparameter to “random”. You will rarely need to do this.
