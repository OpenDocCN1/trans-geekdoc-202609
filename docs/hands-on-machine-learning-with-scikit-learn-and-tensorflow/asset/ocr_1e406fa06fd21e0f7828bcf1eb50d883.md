# Under the Hood

This section explains how SVMs make predictions and how their training algorithms work, starting with linear classifiers. You can safely skip it and go straight to the exercises at the end of this chapter if you are just getting started with Machine Learning, and come back later when you want to get a deeper understanding of SVMs.

First, a word about notations: in Chapter 4 we used the convention of putting all the model parameters in one vector $	heta$, using the bias term $	heta_0$ and the input feature weights $	heta_i$ to $	heta_n$, and adding a bias $x_0=1$ to all instances. In this chapter, we use a different convention, which is more convenient (and more modern) when we are dealing with SVMs: the bias term will be called $b$ and the feature weights will be called $w$. No bias feature will be added to the input features.

# Decision Function and Predictions

The Linear SVM model predicts the class of a new instance $x$ by simply computing the decision function $w^T x + b = w_1x_1 + \dots + w_nx_n + b$; if the result is positive, the predicted class $\hat{y}$ is the positive class (1), or it is the negative class (0); see Equation 5-2.

```
Equation 5-2. Linear SVM classifier prediction
$$
\hat{y} = \begin{cases} 0 & \text{if } w^T x + b < 0 \ 1 & \text{if } w^T x + b \geq 0 \end{cases}
$$
```
