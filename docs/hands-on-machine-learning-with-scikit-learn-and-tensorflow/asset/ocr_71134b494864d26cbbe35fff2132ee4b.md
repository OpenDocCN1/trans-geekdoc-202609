Note when there are multiple features, Polynomial Regression is capable of finding relationships between features (which is something a plain Linear Regression model cannot do). This is made possible by the fact that Polynomial also adds all combinations of features up to the given degree. For example, if there are two features $a$ and $b$, PolynomialFeatures with degree $3$ would not add the features $a^2$, $b^2$, and $b^3$, but the combinations $ab$, $a^2b$, and $ab^2$.

PolynomialFeatures(degree) transforms an array $n$ features into an array containing $\frac{(n+d)!}{d!n!}$ features, where $n!$ is factorial of $n$, equal to $1 	imes 2 	imes 3 	imes \dots 	imes n$. Beware of the combinatorial explosion of number of features!
