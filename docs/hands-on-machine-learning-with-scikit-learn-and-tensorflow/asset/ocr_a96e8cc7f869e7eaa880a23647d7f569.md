Althought most of the applications of Machine Learning today are based on unsupervised learning (and as a result, which is most of the investments we go to), the vast majority of the available data is actually unlabeled: we have the input features X, but we do not have the labels y. Yann LeCun famously said that “if intelligence was a cake, unsupervised learning would be the cake, supervised learning would be the icing on the cake, and reinforcement learning would be the cherry on the cake”. In other words, there is a huge potential in unsupervised learning that we have barely started to sink our teeth into.

For example, say you want to create a system that will take a few pictures of each item on a manufacturing production line and detect which items are defective. You can easily create a system that will take pictures automatically, and this might give you thousands of pictures every day. In just a few weeks. But wait, there are no labels! If you want to train a regular binary classifier that will predict whether an item is defective or “normal”, you will need to label every single picture as “defective” or “normal”. This will go through all the pictures. This is a long, costly and tedious task, so it will usually be done on a small subset of the available pictures. As a result, the labeled dataset will be quite small, and the classifier’s performance will be disappointing.
