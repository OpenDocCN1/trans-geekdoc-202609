# # Adding Similarity Features

Another technique to tackle nonlinear problems is to add features computed using a similarity function that measures how much each instance resembles a particular landmark. For example, let the one-dimensional dataset discussed earlier and add two landmarks to it at xi = -2 and xi = 1 (see the plot in Figure 5-8). Next, let's define the similarity function to be the Gaussian Radial Basis Function (RBF) with y = 0.3

Equation 5-1. Gaussian RBF

```
$\phi_y(\mathbf{x}, \ell) = \exp(-|\mathbf{x} - \ell||^2)$
```

It is a bell-shaped feature varying from 0 (very far away from the landmark) to 1 (at the landmark). We are now ready to compute the new features. For example, let's look at the instance, xi = -1: it is a distance of 1 from the first landmark, and 2 from the second landmark. Therefore its new features are x2 = exp(-0.3 × 1²) = 0.74 and x3 = exp(-0.3 × 2²) = 0.30. The plot on the right of Figure 5-8 shows the transformed dataset (dropping the original features). As you can see, it is linearly separable.
