# Installing TensorFlow 2

Assuming you installed Scumpy and Scikit-Learn by following the installation instructions in Chapter 2, you can simply use pip to install TensorFlow. If you created an isolated environment using virtualenv, you first need to activate:

```
cd $ML_PATH # Your ML working directory (e.g., $HOME/)
# source env/bin/activate # on Linux or macOS
# \env\Scripts\activate # on Windows
```

Next, install TensorFlow 2 (if you are not using a virtualenv, you need to admin rights, or to add the --user option):

```
python -m pip install --upgrade tensorflow
```

> For GPU, you need to install tensorflow-gpu instead of tensorflow, and there are other libraries to install. See https://tensorflow.org/install/gpu for more details.

To test your installation, open a Python shell or a Jupyter notebook, import TensorFlow and tf.keras, and print their versions:

```
>>> import tensorflow as tf
>>> from tensorflow import keras
>>> tf.__version__
'2.0.0'
>>> keras.__version__
'2.2.4-tf'
```
