## Soft Margin Classification

If we strictly enforce that all instances are off the street and on the right side, this is called hard margin classification. There are two main issues with hard margin classification. First, it only works if the data is linearly separable, and second it is sensitive to outliers: outlier on the left, it is impossible to find a hard margin, and on the right the decision boundary ends up very different from the one we saw in Figure 5-1 without the outlier, and it will probably not generalize as well.

![](img/0684d2da98e09085c0a622d4fd69aaad_182_0.png)

To avoid these issues it is feasible to use a more flexible model. The objective is to find a balance between keeping the street as large as possible and limiting the margin violations (i.e., instances that end up in the middle of the street or even on the wrong side). This is called soft margin classification.

In Scikit-Learn's SVM classes, you can control this balance using the C hyperparameter: a smaller C value leads to a wider street but more margin violations. Figure 5-4 shows the decision boundaries and margins of two soft SVM classifiers on a nonlinearly separable dataset. On the left, using a low C value the margin is quite large, but many instances end up on the street. On the right, using a high C value the classifier makes fewer margin violations but ends with a smaller margin. It seems likely the first classifier will generalize better: in fact even this training it makes fewer prediction errors, some of the margin violations are actually on the correct side of the decision boundary.

![](img/0684d2da98e09085c0a622d4fd69aaad_182_1.png)

Figure 5-4. Large margin (left) versus fewer margin violations (right)

![](img/0684d2da98e09085c0a622d4fd69aaad_182_2.png)

If your SVM model is overfitting, you can try regularizing it by reducing C.

The following Scikit-Learn code loads the Iris dataset, scales the features, and then trains a SVM model (using the LinearSVC class with C = 1 and the hinge loss function, described shortly) to detect Iris-Virginica flowers. The resulting model is represented on the left of Figure 5-4.

```python
import numpy as np
from sklearn import datasets
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import LinearSVC
```

```python
iris = datasets.load_iris()
X = iris['data'][:, [2, 3] # petal length, petal width
y = (iris['target'] == 2).astype(np.float64) # Iris-Virginica
```

```python
svm_clf = Pipeline([
    ('scaler', StandardScaler()),
    ('linear_svc', LinearSVC(C=1, loss="hinge")),
])
```

Then, as usual, you can use the model to make predictions:

```python
>>> svm_clf.predict([[5.5, 1.7]])
array([1])
```

![](img/0684d2da98e09085c0a622d4fd69aaad_183_0.png)

Unlike Regression classifiers, SVM classifiers do not output probabilities for each class. Alternatively, you could use the SVC class, with SVC(kernel="linear", C=1), but it is much slower, especially with large training sets, it is not recommended. Another option is to use the SGDClassifier class, with SGDClassifier(loss="hinge", alpha=1). This applies Stochastic Gradient Descent (see Chapter 4) to train a linear classifier. It does not converge as fast as the LinearSVC class, but it can be useful to handle large datasets that do not fit in memory (out-of-core training), or handle online classification.

![](img/0684d2da98e09085c0a622d4fd69aaad_183_1.png)

The LinearSVC class regularizes the bias term, so you should center the training set by subtracting its mean. This is automatic if you scale the data using the StandardScaler. Moreover, make sure you set the loss hyperparameter to "hinge", as it is not the default. Finally, for better performance you should set the dual hyperparameter to False, unless there are more features than training instances.

## Nonlinear SVM Classification

Although linear SVM classifiers are efficient and work surprisingly well in many cases, many datasets are not even close to linearly separable. One approach to handling nonlinear datasets is to add more features, such as polynomial features (as you did in Chapter 4); in some cases this can result in a linearly separable dataset. Consider the left plot in Figure 5-5: it represents a simple dataset with one feature $x_1$. This dataset is not linearly separable, as you can see. If you add a second feature $x_2 = (x_1)^2$, the resulting 2D dataset is perfectly separable.

## Polynomial Kernel

Adding polynomial features is simple to implement and can work great with all sorts of Machine Learning algorithms (not just SVMs), but at a low polynomial degree it cannot deal with complex datasets, and with a high polynomial degree it creates a huge number of features, making the model too slow.

Fortunately, when using SVMs you can apply any miraculous mathematical technique called the kernel trick (it is explained in a moment). It makes it possible to get the same result as if you added many polynomial features, even with very high-degree polynomials, without having to add them. So there is no combinatorial explosion of the number of features since you actually add none. This trick is implemented by the SVC class. Let's test it on the moons dataset:

```python
from sklearn.svm import SVC
poly_kernel_svm_clf = Pipeline([
    ('scaler', StandardScaler()),
    ('svm_clf', kernel='poly', degree=3, coef0=1, C=5),
])
poly_kernel_svm_clf.fit(X, y)
```

This code trains an SVM classifier using a 3rd-degree polynomial kernel. It is represented on the left of Figure 5-7. On the right is another SVM classifier using a 10th-degree polynomial kernel. Obviously, if your model is overfitting, you might want to reduce the polynomial degree. Conversely, if it is underfitting, you can try increasing it. The hyperparameter coef0 controls how much the model is influenced by high-degree polynomials versus low-degree polynomials.

![](img/0684d2da98e09085c0a622d4fd69aaad_186_0.png)

Figure 5-7. SVM classifiers with a polynomial kernel

A common approach to find the right hyperparameter values is to use grid search (Chapter 2). It is often faster to do a very coarse grid search, then a finer grid search around the best values found. Having a good sense of what each hyperparameter actually does can help you search in the right part of the hyperparameters.

## Adding Similarity Features

Another technique to tackle nonlinear problems is to add features computed using a similarity function that measures how much each instance resembles a particular landmark. For example, let the one-dimensional dataset discussed earlier and add two landmarks to it at $x_i = -2$ and $x_i = 1$ (see the plot in Figure 5-8). Next, let's define the similarity function to be the Gaussian Radial Basis Function (RBF) with $y = 0.3$

Equation 5-1. Gaussian RBF

```
$\phi_y(\mathbf{x}, \ell) = \exp(-|\mathbf{x} - \ell||^2)$
```

It is a bell-shaped feature varying from 0 (very far away from the landmark) to 1 (at the landmark). We are now ready to compute the new features. For example, let's look at the instance, $x_i = -1$: it is a distance of 1 from the first landmark, and 2 from the second landmark. Therefore its new features are $x_2 = \exp(-0.3 \times 1^2) = 0.74$ and $x_3 = \exp(-0.3 \times 2^2) = 0.30$. The plot on the right of Figure 5-8 shows the transformed dataset (dropping the original features). As you can see, it is linearly separable.
