```
for _ in range(s):
    self.out = keras.layers.Dense(output_dim)

def build(self, batch_input_shape):
    n_inputs = batch_input_shape[-1]
    self.reconstruct = keras.layers.Dense(n_inputs)
    super().build(batch_input_shape)

def call(self, inputs):
    Z = inputs
    for layer in self.hidden:
        Z = layer(Z)
    reconstruction = self.reconstruct(Z)
    recon_loss = tf.reduce_mean(tf.square(reconstruction - inputs))
    self.add_loss(0.05 * recon_loss)
    return self.out(Z)
```

Similarly, you can add a custom metric based on models by computing it in any way you want, as long the result is the output of a metric object. For example, you can create a keras.metrics.Mean() object in the constructor, then call it in the call() method, passing it the recon_loss, and finally add it to the model by calling the model's _add_metric() method. When you train the model, keras will display the mean loss over each epoch (the loss is the sum of main loss 0.05 times the reconstruction loss) and the mean reconstruction error over each epoch.
