As earlier, the global average pooling layer computes the mean activation for each feature map: for example, if its input contains 256 feature maps, it will output 256 numbers representing the overall level of response for each filter. The next layer is where the "squeeze" happens: this layer has less than 256 neurons, 16 times less than the number of feature maps (e.g., 16 neurons), so the 256 get pressed into a small vector (e.g., 16 dimensional). This is a low-dimensional vector representation (i.e., an embedding) of the distribution of features. This bottleneck steps the SE Block to learn a general representation of the feature combinations (we will see this in action when we discuss encoders (???). Finally, the output layer takes this recalibration vector containing one number per feature map (e.g., 256), which between 0 and 1. The feature maps are then multiplied by this recalibration vector, so irrelevant features (with a low recalibration score to 0) get scaled down while relevant features (with a recalibration score to 1) are left alone
