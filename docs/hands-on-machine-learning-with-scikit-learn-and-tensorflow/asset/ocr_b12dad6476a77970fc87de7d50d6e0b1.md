```
skip_Z = layer(skip_Z)
return self.activation(Z + skip_Z)
```

As you can see, this code matches Figure 14-18 closely. In the constructor, we create all the layers with we need: the main layers are the ones on the right side of the diagram, and the skip layers are the ones on the left (only needed if the stride is greater than 1). In the call() method, we make the inputs go through the main layers, and the skip layers (if any), then we add both outputs and apply the activation function.

Next, we can build the ResNet-34 using a Sequential model, since it is really a long sequence of layers (we treat each residual unit as a single layer that we have the ResidualUnit class:

```
model = keras.models.Sequential()
model.add(DefaultConv2D(64, kernel_size=7, strides=2,
                           input_shape=[224, 224, 3]))
model.add(keras.layers.Normalization())
model.add(keras.layers.Activation('relu'))
model.add(keras.layers.MaxPooling2D(pool_size=3, strides=2, padding='SAME\'))
prev_filters = 64
for filters in [64] * 3 + [128] * 4 + [256] * 6 + [512] * 3:
    strides = 1 if filters == prev_filters else 2
    model.add(ResidualUnit(filters, strides=strides))
    prev_filters = filters
model.add(keras.layers.GlobalAvgPooling2D())
model.add(keras.layers.Flatten())
model.add(keras.layers.Dense(10, activation='softmax'))
```

The only tricky part of this code is that the ResidualUnit layers to the model: as explained earlier, the first 3 RUs have 64 filters, the next 4 have 128 filters, and so on. We set the strides to 1 when the number of filters is the same as the previous RU, or we set it to 2. We add the ResidualUnit, and finally update prev_filters.

It is quite amazing that with less than 40 lines of code, we can build the model that the ILSVRC 2015 challenge demanded! It demonstrates the elegance of the ResNet model, and the expressiveness of the Keras API. Implementing the other CNN architectures is not much harder. However, Keras comes with several of these architectures built in, why not we use them instead?
