+   tf.nn.depthwise_conv2d() can be used to create a depthwise convolutional layer (but you need to create the variables yourself). It applies every filter to every individual input channel independently. Thus, if there are $f_H$ filters and $f_W$ input channels, then this will output $f_H 	imes f_W$ feature maps.

This solution is okay, but still imprecise. To do better, the authors added connections from lower layers: for example, they upsampled the output image by a factor of 2 (instead of 32), and they added the output of a lower layer that had this double resolution. Then they upsampled the result by a factor of 16, leading to a total upsampling factor of 32 (Figure 14-28). This recovered some of the spatial resolution that was lost in pooling layers. In their best architecture, they used a similar skip connection to recover even finer details from an lower layer: in short, the output of the original CNN goes through the following extra steps: upscale x2, add the output of a lower layer (of the appropriate scale), upscale x2, and finally upscale x8. It is even possible to scale up beyond the size of the original image: this can be used to increase the resolution of an image, which is a technique called super-resolution.*.
