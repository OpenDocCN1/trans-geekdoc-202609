So far we have used only TensorFlow's high level API, tf.keras, but it already got us pretty far: we built various neural network architectures, including regression and classification nets, with as Batch Normalization, dropout, learning rate schedules, and more. Using all sorts of techniques, such as deep nets and self-normalizing nets, in fact, 95% of the cases you will not require anything else than tf.keras and tf.data, see Chapter 13. Now it's time to dive deeper into TensorFlow and take a look at its lower-level Python API. This will be useful when you need extra control, to write custom functions, custom metrics, models, initializers, weight constraints and more. May you ever need to fully control the training loop itself, for example to apply special transformations or constraints to the gradients (beyond clipping them), or to use multiple optimizers for different parts of the network. We will cover all these cases in this chapter, then we will also look at how you can boost your custom models and training algorithms using TensorFlow's automatic graph generation feature. But first, let's take a tour of TensorFlow.
