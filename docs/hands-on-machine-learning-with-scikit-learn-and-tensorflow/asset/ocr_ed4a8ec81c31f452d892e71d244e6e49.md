A pooling layer typically works on every input channel independently, so the output depth is the same as the input depth.

Other than reducing computations, memory usage and the number of parameters, a max pooling layer also introduces some level of *invariance* to small translations, as shown in Figure 14-9. We assume that the bright pixels have a lower value than dark pixels, and we consider 3 images $(A, B, C)$ going through a max pooling layer with a $2 \times 2$ kernel and stride 2. Images B and C are the same as image A, shifted by one and two pixels to the right. As you see, the outputs of the max pooling layer for images A and B are identical. This translation invariance means However, for image C, the output is different: it is shifted by one pixel to the right (but there is still 75% invariance). By inserting a max pooling layer every few layers in a CNN, it is possible to get some level of translation invariance at a larger scale. Moreover, max pooling also offers a small amount of rotational invariance and a slight scale invariance. Such invariance (even if it is limited) can be used in cases where the prediction should not depend on these details, such as in classification tasks.
