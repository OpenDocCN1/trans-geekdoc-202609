**Support Vectors:** Support vectors are the data points closest to the hyperplane, influencing its position. Removing other points won't affect the hyperplane.

**Handling Non-linear Boundaries:** SVM can handle non-linear classification using kernel functions, mapping data into a higher-dimensional space to separate non-linearly separable classes.
