# 18.3.5 Hybrid attention DCNN-BiLSTM model

The proposed network's framework incorporates a spatial attention mechanism to improve the sensitivity of important spatial qualities on the input image. The traditional data's spatial features are fed into the spatial attention layer, which produces an output by assigning weights to those attributes. The $n$-dimensional feature vector at the time step $s$ is the hidden state, with $y_s = [y_{s,1}, y_{s,2}, \dots, y_{s,n}]$. The following is an expression for the spatial attention weights:
