# 14.4.6 Blood pressure sensor

Figure 14.8 shows a blood pressure monitoring module designed to measure systolic and diastolic blood pressure, as well as heart rate.

# 14.4.6.1 Key features

+   **Display Functionality:** The module displays systolic and diastolic blood pressure, along with heart rate, providing immediate feedback for cardiovascular health monitoring.
**Data Transmission:** The module sends measurements to an Arduino microcontroller via serial communication, enabling integration into broader health monitoring systems for further analysis.
**Wearable Design:** The wrist-wearable design allows continuous monitoring, improving user compliance for regular health checks, especially for individuals with cardiovascular conditions.
This module is essential for real-time health tracking and proactive healthcare management.
