
$z^{(l+1)} = W^{(l)} z^{(l)} + b^{(l)} \quad (3.7)$

where $W^{(l)}$ is the weight matrix and $b^{(l)}$ is the bias vector. For classification tasks, the final layer often uses a softmax function to produce class probabilities:

$$\hat{y}_i = \frac{e^{z_i}}{\sum_{j=1}^C e^{z_j}} \quad (3.8)$$

where $C$ is the number of classes and $\hat{y}_i$ is the anticipated probability for class $i$. For classification tasks, the cross-entropy loss is typically used:

$L = -\sum_{i=1}^C y_i \log(\hat{y}_i) \quad (0.9)$

where $y_i$ is the actual label. The weights are updated using gradients during backpropagation, typically using an optimiser like Adam or SGD:

$W^{(i)} \leftarrow W^{(i)} - \eta \frac{\partial L}{\partial W^{(i)}} \quad (3.10)$

where $\eta$ is the learning rate, and $\frac{\partial L}{\partial W^{(i)}}$ is the gradient of the loss concerning. This mathematical framework forms the basis of the CNN model for ARTISIS detection, with further modifications depending on the specific dataset and task.

### 3.4.3 Long short-term memory (LSTM) for eye disease

Creating a LSTM (long-term memory) model for eye disease detection using deep learning steps. The input to an LSTM model is typically a sequence of vectors over time (or a sequence of images in the case of temporal data). Let $X_t \in R^d$ be the input vector at time step $t$, where $d$ is the number of features. An LSTM contains multiple gates: the forget gate, input, and output. These gates control the flow of information through the cell. Each gate represents exactly which information should be discarded from the cell state:

$f_t = \sigma(W_f \cdot [h_{t-1}, X_t] + b_f)$

Where $W_f$ are the weights associated with the forget gate, $h_{t-1}$ is the hidden state from the previous time step, $\sigma$ is the sigmoid activation function, and $b_f$ is the biased term for the forget gate. The input gate regulates the rate of data addition to the cell state:

$i_t = \sigma(W_i \cdot [h_{t-1}, X_t] + b_i)$

$\widetilde{C}_t = \tanh(W_C \cdot [h_{t-1}, X_t] + b_C)$

Where $i_t$ is the input gate activation, $\widetilde{C}_t$ is the candidate cell state, $W_i$ and $W_C$ are the weights of input gate and candidate cell state, respectively, and $\tanh$ is the hyperbolic tangent activation function. The function is:

$C_t = f_t * C_{t-1} + i_t * \widetilde{C}_t$

Where $C_t$ is the updated cell state at time step $t$ and $C_{t-1}$ is the cell state from the previous time step. The next concealed state is determined by the output gate:

$o_t = \sigma(W_o \cdot [h_{t-1}, X_t] + b_o)$

$h_t = o_t * \tanh(C_t)$

Where $o_t$ is the output gate activation, $h_t$ is the hidden state at time step $t$, and $W_o$ is the weight matrix for the output gate.
