# 3.7.3 Data augmentation

When obtaining high-quality data is difficult in any machine learning application, data augmentation extends its reach. It can also aid in enhancing the performance and resilience of models in all academic domains. Model reproducibility can be increased because the model can perform better on bright images rather than dark images, so we can collect more low-light training data.

Since augmentations are CPU-constrained processes, training time can be reduced. Since augmentations are CPU-limited processes, less is spent on training. To deal with an imbalanced dataset, several methods have been put forth to address the unbalanced dataset issue, which may be divided into two groups: developing resampling algorithms and preprocessing data to provide new samples [22]. One technique for balancing a dataset's distribution is to resample. To do this, samples are either oversampled in the minority class, which has a smaller number of data, or undersampled into the majority class, where the number of data is more in order to balance the data. Nonetheless, a popular method for creating free data samples to supply the image in a different format is called data augmentation.

The process of applying augmentations to already-existing photos in our dataset is called image augmentation. By going through this procedure, the model will be able to generalize and perform better on unknown pictures.

+   1. Geometric Transformations: These randomly flip, chop, rotate, stretch, and zoom photos using geometric transformations. We need to apply many changes carefully to the same picture because it may cause the model to perform less well.

+   2. Color Space Transformations: These randomly alter the brightness, contrast, and RGB color channels
