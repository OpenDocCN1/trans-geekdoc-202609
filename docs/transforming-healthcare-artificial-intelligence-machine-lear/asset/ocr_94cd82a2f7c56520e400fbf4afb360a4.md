
$d$ describes the output of an individual BiLSTM cell determined using the old cell state $k_u$ as well as the future cell state $k_{u+1}$ separately, and $F_k, F_t, F_g$ are the coefficients that correspond to those matrices. $k_u, \delta_t, \delta_g, \delta_\epsilon$ and $k_u$ represent the input gate, output gate, updated gate, cell state, and forget gate, respectively. While $B_k, B_t, B_g$ and $B_\epsilon$ are the pertinent bias vectors. $\pi$ and $f$ stand for the sigmoid function and the Softmax function, respectively.
