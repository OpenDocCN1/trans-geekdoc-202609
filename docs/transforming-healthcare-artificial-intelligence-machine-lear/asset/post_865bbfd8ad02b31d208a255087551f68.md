## 9.5 METHODOLOGY

The project was implemented using a multi-stage approach. The first stage involved acquiring and curing appropriate datasets containing images of PPE items and worker falls. Following data collection, meticulous preprocessing techniques were applied to guarantee the data’s quality and suitability for training the object detection model. Finally, a powerful 194 Transforming Healthcare YOLOv9 model was chosen for its ability to achieve accurate real-time detection of PPE and falls within workplace environments. The dataset for training the YOLOv9 model was sourced from Roboflow, a platform known for providing high-quality computer vision datasets. The dataset consists of 1,613 images for PPE kit detection.

- **Phase 1 – Collection**: Images are gathered from diverse sources, encompassing various environments, lighting conditions, and angles
- **Phase 2 – Annotation**: Continuous labeling of images with precise bounding boxes.
- **Phase 3 – Model Training**: Training of advanced object detection models.
- **Class Types**: The PPE dataset includes annotated images across four primary PPE categories:
    - **Boots**: Safety footwear, comprising steel-toe and insulated boots.
    - **Person**: Individuals with and without PPE to enhance person detection alongside low-light PPE recognition.
    - **Vest**: High-visibility vests and reflective safety gear for visibility in low-light conditions (Figure 9.1).

### 9.5.1 Preprocessing data

Building a robust computer vision model for workplace safety requires meticulous attention to data preparation. This includes strict adherence to the annotation guidelines. It's crucial to verify that all images within the Roboflow dataset are annotated with the designated classes: “helmet,” “boots,” “vest,” and “person.” Each object should be precisely delineated by bounding boxes.

Data cleaning and augmentation techniques enhance dataset quality, while preprocessing steps like auto-orientation and resizing to 640x640 standardize the data. Subsequently, from total 1,613 images, the data is divided into three subsets: a 70% training set (1,126 images), a 20% validation set (326 images) for monitoring training progress and preventing overfitting, and a 10% test set (161 images) for evaluating the model's performance (Figure 9.2).

Roboflow: Platforms like Roboflow offer valuable tools for managing and preparing computer vision datasets. Uploading data to Roboflow initiates a process that simplifies the tasks of bounding box creation and image labeling. The platform integrates and streamlines the annotation process, allowing you to directly label each object of interest within your images. This user-friendly approach facilitates the creation of a well-annotated dataset that can be readily used to train your computer model (Figure 9.3). Once the training process is complete, Roboflow enables you to deploy the trained model. Image data annotated with different color bounding boxes for classes such as helmets, vests, boots, and persons will be utilized to create a detection model. Annotations are tailored to match the study’s class requirements, distinguishing workers wearing PPE from those who are not.
