### 3.4.4 Support vector machine for tumor detection

In this setup, a CNN or other deep learning network extracts features from images which are then fed into SVM for classification. Let $X \in R^{m \times n}$ represent an image, where $m \times n$ are the dimensions of the image and $c$ is the number of channels, 3 for RGB or 1 for grayscale. The deep learning model (e.g., CNN) extracts features $F$ from the image:

$F = \text{CNN}(X; W) \quad (18)$

where $F \in R^d$ is the feature vector, and $W$ represents the parameters of CNN. After extracting features $F_i$, the SVM performs classification. The SVM finds a hyperplane that maximises the margin between tumor and non-tumor classes in the feature space. The support vector machine's decision algorithm

$f(F) = w \cdot F + b \quad (19)$

where $w \in R^d$ is the weight vector, $F \in R^d$ is the feature vector (from the deep learning model), and $b$ is the bias term. For classification, the SVM solves the following optimisation:

$$\min_{w, b} \frac{1}{2} |w|^2 + C \sum_{i=1}^{N} \max(0, 1 - y_i \cdot (w \cdot F + b)) \quad (20)$$

where $C$ is the regularisation parameter, $y_i \in \{-1,1\}$ represent the true labels (e.g., +1 for tumor and -1 for non-tumor), $F_i$ is the feature vector for the $i$-th sample, and $\max(0, 1 - y_i \cdot (w \cdot F + b))$ is the hinge loss function, ensuring a large margin between classes. The sign of the decision function makes the final classification:

$$\hat{y} = \text{sign}(f(F)) = \text{sign}(w \cdot F + b) \quad (21)$$

If $\hat{y} > 0$, the model predicts tumor. If $\hat{y} < 0$, the model predicts no tumor. The CNN is first trained to extract features which the SVM is trained on these features. Alternatively, the entire model (CNN+SVM) can be trained end-to-end using backpropagation, where the SVM's objective function is integrated into the loss function of the deep learning model.
