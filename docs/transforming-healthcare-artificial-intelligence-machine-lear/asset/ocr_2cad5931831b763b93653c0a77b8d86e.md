This section outlines the proposed framework's experimental setup, performance assessment methods, evaluation datasets, and experiment results. The ISIC 2019 dataset is taken into account by the framework, which uses MATLAB. Intel(R) Core (TM) i5-3570 CPU @ 3.40GHz, with 8 GB installed Windows 10 Pro RAM, used to implement this research. The performance of a proposed system is validated by comparison to the existing models using precision, accuracy, F-measures, and recall. The proposed model is evaluated against existing methods such as ResNet, MobileNet, VGG-16, Inception V3, and Inception ResNet.

**ISIC 2019 dataset:** HAM, MSK, and BCN_20000 datasets are the components of the ISIC 2019 dataset. There are 25331 photos from squamous carcinoma (SCC), vascular lesions (VASC), melanocytic nevus (NV), actinic keratosis (AK), basal cell carcinoma (BCC), benign keratosis (BKL), and dermatofibroma (DF). In addition, the 8238 test images were unpublished labels.

Accuracy, precision, recall, and F1-score are essential for melanoma detection as they thoroughly evaluate the model's performance. Every indicator evaluates a different aspect of the model's capacity to detect and categorise cases of melanoma accurately. Comprehending and harmonising these measures is essential for creating an efficient and dependable detection system.
