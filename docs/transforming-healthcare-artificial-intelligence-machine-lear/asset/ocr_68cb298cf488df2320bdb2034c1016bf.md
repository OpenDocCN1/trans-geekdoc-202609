# 8.4.8.5 Reinforcement learning (RL) for real-time adaptation

8.4.8.5.1 RL state representation

The state $S_t$, at time $t$ represents the current configuration of the network slices, including the KPI values and environmental factors like user demand or network connection:

```
$S_t = [L, T_b, R, A, U, M, S_t, J, T_c, Q, D_r, F_t]$ (8.17)
```

# 8.4.8.5.2 Action space

The action $A$ is a set of adjustments to be applied to the slice configurations at time $t$:

```
$A_t = [\Delta L, \Delta T_b, \Delta R, \Delta A, \Delta M]$ (8.18)
```

+   - where $\Delta L$ is the change in latency and $\Delta T_b$ is the change in throughput.
- RL dynamically adjusts slices in real time based on feedback from network KPIs. The RL agent operates in an environment where the state is the current network configuration, the action is a modification to the slice, and the reward is a function of how well the new configuration satisfies KPIs.

The Q-Learning algorithm is used, where the agent learns the optimal policy $Q(s,a)$ by updating the value of each action $a$ taken in state's based on the reward $r$:

```
$Q(s,a) \leftarrow Q(s,a) + d[r + \gamma Q(s',a') - Q(s-a)]$ (8.19)
```

where $a$ is a learning rate, $\gamma$ is the discount factor, $s'$ is the new state after action $a$, and $r$ is the immediate reward based on updated KPI performance.

The proposed GA-RL-based 5G orchestrator optimizes network slicing for healthcare by combining GA for provisioning and optimizing slices based on predicted traffic, latency, and jitter with RL for real-time QoS adaptation.
