# 7.4.2.1 Data preprocessing

Preprocessing is a vital stage for cleaning image data and making it ready before they are used in a computer vision model. It is considered essential for both technical and performance reasons. The dataset is involved in preprocessing step prior to being utilized in our model, since it is a crucial step in cleaning up picture data and it is necessary for performance as well as technical reasons. The model will not function as expected if it is not using same size images. To get a more efficient model, images of the same size need to be used; otherwise, errors will occur.

Our dataset has unbalanced samples in all classes. In order to create significant variance in the dataset and data augmentation techniques have assisted to enhance the performance of our model by creating fake pictures. We used the data augmentation techniques of horizontal and vertical flip, zoom, and rotation in our research. After data augmentation, dataset contained 5000 images. Eighty percent of data was taken for training, 10% of dataset samples were taken for validation, and 10% of dataset samples was taken for testing. The compressed image dataset is created using encoder network of CAE model, and the output is sent to CNN model, which is trained and tested.

# 7.5.1 Evaluation metrics

Confusion matrix is used to show the summary of a model's performance on data. Depending on the model's predictions, it shows the number of accurate and erroneous corrections. The binary classification model's standard is given in Table 7.3.

True Positive (TrPo): A model predicts a positive value accurately when the actual result is also positive.

True Negative (TrNe): A model predicts a negative value accurately when the actual result is also negative.

False Positive (FIPo): Here, a model predicts a positive value inaccurately as negative.

False Negative (Flne): Here, a model predicts a negative value inaccurately as positive.

# Table 7.3 Confusion matrix

| | Positive | Negative |
|---|---|---|
| **Actual Value** | TP | TN |
| **Negative** | FP | TN |
| **Predicted Value** | Positive | Negative |

For assessing the effectiveness of our proposed model, the following measures are used:

Accuracy (Acc): The percentage of properly identified values in a confusion matrix relative to the number of values in the dataset is known as accuracy.

```
Acc = \frac{TrPo + TrNe}{TrPo + TrNe + FlPo + FlNe} (7.1)
```

Precision (Pr): The proportion of accurate positive predictions is as follows:

```
Pr= \frac{TrPo}{TrPo + FlPo} (7.2)
```

Recall (Rc): It assesses how successfully a model can detect true positives.

```
Rc=TrPo/(TrPo + FlNe) (7.3)
```

F1-Score: It is measured using both Pr and Rc values and is defined as follows:

```
F1-Score = 2* \frac{Pr * Rc}{Pr + Rc} (7.4)
```
