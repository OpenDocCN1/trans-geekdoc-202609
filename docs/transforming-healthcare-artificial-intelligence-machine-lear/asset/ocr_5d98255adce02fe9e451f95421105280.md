Draw the hand landmarks on a frame, examine how the fingers bend, and loop through them. It transmits data to Arduino by updating the hand state based on finger bending. Pressing the "ESC" key causes the program to end. Servo motors and LEDs are controlled by the Arduino code, which receives commands from Python using serial communication. It starts serial communication at a baud rate of 9,600 and defines servo objects and LED pins. For every servo motor, there are five servo objects that are produced.

The pins that servo motors are attached to are specified by constants. The setup function initiates serial communication at a 9,600 baud rate and initializes the servo objects. The loop function receives incoming input and breaks it down into individual finger states, continuously. For debugging reasons, the code takes the hand state string and are then output to the serial monitor. The received finger states are used to adjust the servo motors. Revision A servo function uses the received finger status to modify and regulate a servo motor's position. High-performance real-time hand gesture recognition from camera inputs is made possible by the combination of the OpenCV and Mediapipe packages.
