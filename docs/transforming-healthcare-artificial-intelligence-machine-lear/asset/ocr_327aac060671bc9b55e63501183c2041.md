# Transforming Healthcare

Bahukhandi and Gupta [5] proposed a Real-Time Yoga Pose Detection System tailored for home use, which is particularly relevant during the pandemic. Their methodology involves dataset collection via web scraping, manual cleaning, and landmark detection using MediaPipe. Classic classification algorithms were tested, with Gradient Boosting achieving the high accuracy of approximately 98%. The system includes a user-friendly interface created with HTML, CSS, and JavaScript for interaction and webcam-based pose estimation. Parashar et al. [6] presented a Yoga Pose Framework utilizing the MoveNet model for human pose estimation and keypoint detection using MediaPipe. Their method employs the large and diverse yoga (LDY) dataset, covering five pose categories: Downdog, Goddess, Plank, Tree, and Warrior. The framework achieves a high accuracy of 99.50%, surpassing existing techniques, and incorporates preprocessing steps such as contrast histogram equalization to enhance image quality.

Sunney [7] developed a Real-Time Yoga Pose Detection system using the Blazepose model and XGBoost allows real-time yoga detection from webcam input, showcasing the effectiveness of machine learning algorithms in real-time applications. Verma et al. [8] focused on Enhancing Yoga Practice through Real-Time Pose Detection and Correction using AI. Their approach integrates CNNs, LSTMs, and transfer learning models such as VGG16 and MobileNet, leading to significant improvements in posture accuracy. The study highlights AI's potential in offering precise and personalized guidance, especially in scenarios lacking-person instruction.

Mane et al. [9] proposed a Smart Yoga Assistant using an SVM-based system for real-time yoga pose detection and correction. Their system computes computer vision and machine learning to provide instant feedback for pose alignment and injury prevention, achieving 87% accuracy. It features user-friendly interface developed with Python and MediaPipe. The study emphasizes AI's role in personalizing yoga practice and suggests areas for further research to enhance pose correction. Swain et al. [10] introduced a Yoga Pose Monitoring System that deep learning techniques, including CNNs and LSTMs, for real-time pose recognition and correction. By processing video input with MediaPipe, the system accurately extracts keypoints and classifies poses, delivering feedback through text or speech. With an impressive accuracy of 99.53%, this system bridges the accessibility gap in yoga training.
