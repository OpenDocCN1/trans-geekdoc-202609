A stack of 2D convolutions is built, starting big and then growing smaller, to create the encoder. Next to every convolution is a 2D Max-Pooling layer. The ReLU activation is applied throughout. CAE is constructed with 6 convolutional layers, 4 pooling layers, and a bottleneck layer. CNN model is constructed with 3 convolutional and 3 pooling layers. For optimization, the Adaptive Moment Estimation (Adam) method is used. Softmax Activation function is used in the last layer of the CNN model. # 7.4.1 Dataset description

In our research, we have used the APTOS 2019 dataset for DR detection and prediction. The 3,662 samples in the Asia Pacific Tele-Ophthalmology Society 2019 Blindness Detection (APTOS 2019 BD) collection were arranged by India's Aravind Eye Hospital. The fundus images were taken in various settings and from several rural India participants. Later, a trained medical professionals examined them. They identified the samples using the International Clinical Diabetic Retinopathy Severity Scale (ICDRSS). The APTOS 2019 BD [23] samples have been categorized into five groups according to the system: no DR, mild DR, moderate DR, severe DR, and proliferative DR, which are shown in Table 7.2, and its visual representation is shown in Figure 7.5.
