The Adaptive-Network-based Fuzzy Inference System (ANFIS) forms the basis for constructing a set of fuzzy if-then rules, incorporating suitable membership functions. This architecture is fundamental to the suggested work.

#### 10.3.3 Fuzzy if-then rules

Fuzzy if-then rules, also known as conditional statements, are expressed in the form "IF A then B," where A and B represent labels of fuzzy sets defined by appropriate membership functions. For instance, in the statement "If pressure is high, then volume is small," pressure and volume are linguistic variables, and “high” and “small” are linguistic variables characterized by membership functions.

Another type of fuzzy if-then rule, such as "Force = k*(velocity)^2" holds true for high velocities, highlights a linguistic label with a membership function in the premise section, while the consequent component describes a nonfuzzy equation of the input variable.

These fuzzy if-then rules are widely applied in control systems and modelling tasks. They encapsulate "rules of thumb" effectively by utilizing membership functions and linguistic labels. Each rule serves as a local description of the system under study, contributing to the overall fuzzy inference system's functionality.

#### 10.3.4 Hybrid approaches

Certain state-of-the-art approaches to SS combine traditional signal processing methods with deep learning. For example, DL models can be used to extract features from the received signals, and traditional methods such as ED or cyclostationary feature analysis can be used to determine the final SS choice. To improve performance, these hybrid leverage the benefits of both traditional methods and deep learning.
