Correlation: It calculates the linear dependence among two pairs of pixels, which indicates how closely two pixels are related to one another. A high correlation suggests that two pixels are highly dependent on one another.


# 5.4.2 AlexNet for classification

CNNs like AlexNet were created with the classification of pictures in consider. Max pooling, deep layers, and convolutions make up AlexNet. For convolutions, it employs $11\times11$, $5\times5$, and $3\times3$ kernels: for max pooling, it uses $3\times3$ kernels. In the ILSVRC, AlexNet considerably outperformed the runner-up model by learning the top-5 error rate from 26.2% to 15.3%. AlexNet can categorize images into 1,000 different item categories using a pretrained version [25].

This design was the first to leverage GPU acceleration to improve training efficiency. Five convolution layers, three max-pooling layers, two fully linked layers, a convolution filter and a non-linear activation function known as $\ReLu$ make up each convolution layer. Because there are fully connected layers in the pooling layers, the max-pooling function is carried out, and the input size is fixed. Although the input size is stated as $224\times224\times3$ because of some padding. Overlap, there are more than 60 million parameters in AlexNet. The following are AlexNet's salient characteristics:

+   - Rather than "tanh," "\ReLu$\$ is utilized as an activation function.
- Batch size: 128.
- Learning algorithm using SGD momentum.
- Data augmentation through turning jerking, trimming, color normalization, etc.; AlexNet was trained on a GTX 580 GPU with just 3 GB of memory, which was insufficient to accommodate the network's total capacity. Thus, the network was divided into two GPUs, with each GPU housing half of the neurons.
