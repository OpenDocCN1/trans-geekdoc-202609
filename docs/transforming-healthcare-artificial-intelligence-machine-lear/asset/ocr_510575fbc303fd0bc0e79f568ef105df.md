Subsequently, from total 1,613 images, the data is divided into three subsets: a 70% training set (1,126 images), a 20% validation set (326 images) for monitoring training progress and preventing overfitting, and a 10% test set (161 images) for evaluating the model's performance (Figure 9.2).

Roboflow: Platforms like Roboflow offer valuable tools for managing and preparing computer vision datasets. Uploading data to Roboflow initiates a process that simplifies the tasks of bounding box creation and image labeling. The platform integrates and streamlines the annotation process, allowing you to directly label each object of interest within your images. This user-friendly approach facilitates the creation of a well-annotated dataset that can be readily used to train your computer model (Figure 9.3).

Once the training process is complete, Roboflow enables you to deploy the trained model. This allows you to visualize the model's detection results, giving valuable insights into its performance and effectiveness
