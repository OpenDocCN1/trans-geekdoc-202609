## 1.4.3 Feature extraction

MFCC detects cepstral coefficients from lung sounds using many methods. Start with a pre-emphasis filter to increase high frequencies. To limit spectral leakage, we split the signal into small frames and multiply by a window function. The Fast Fourier Transform converts time to frequency. Each frame's power spectrum is filtered through Mel-scale-aligned filters. Filter bank energies are normalized to approximate human loudness. The Discrete Cosine Transform (DCT) decorrelates coefficients and extracts the most important information. The final MFCC coefficients are selected and stored in a feature matrix as lower-order DCT coefficients (cepstral coefficients).

## 1.4.4 Sound and disease classification

CNN and GRU networks form the new hybrid deep-learning model for categorization, as shown in Figure 1.6. The CNN network helps to identify signal patterns. GRU employs fewer parameters and effectively leverages pattern-long temporal relationships, unlike LSTMs. CNN has two pairs of convolution, max-pooling, and dropout layers. The 64-hidden unit GRU network uses a fully connected layer with five neurons for five classes. The softmax layer converts the fully connected layer output into class probabilities.

CNN learns kernel functions via backpropagation using convolution, pooling, and fully connected layers. Figure 1.6 shows that the recommended model uses two CNN layers. Flattened obtained attributes are forwarded to the GRU network.

LSTM networks experience the vanishing gradient problem. Cho et al. proposed the Gated Recurrent Unit (GRU) [115]. As demonstrated, the GRU can capture long-term dependencies. As input is processed sequentially, these gates update the network’s hidden state at each time step. The reset gate adaptively decides which previous data to keep and which to erase, solving the vanishing gradient problem. ### 1.5.2 Evaluations criteria

Model performance was measured by accuracy, recall, precision, and F1-score. With the confusion matrix, predictions are assigned to the data's original classifications. DL classification effectiveness may be assessed using the confusion matrix. The confusion matrix created during DL classification training on a dataset reveals the model's classification accuracy for each record and possible issues. The matrix rows show the training dataset labels, while the matrix columns help evaluate algorithm performance whether output is positive or negative or or no. Each table has four cells with various projected and actual data. Four outcomes are possible:

- * True Positive (TP): This phrase denotes the success of a forecast. We sometimes refers to it as a sensitivity.
- * True Negative (TN): This denotes the realization of a negative prediction. This is known as specificity.
- * False Positive (FP): When a value is predicted to be positive but turns out to be negative, it's called a mistake of the time.
- * False Negative (FN): The actual figure was positive though the prediction was negative.

The mathematical definitions of accuracy, recall, precision, and F1-score are:

$$\text{Precision} = \frac{\text{True Positive}}{\text{True Positive} + \text{False Positive}}$$

$$\text{Recall} = \frac{\text{True Positive}}{\text{True Positive} + \text{False Negative}}$$

$$\text{Accuracy} = \frac{\text{True Positive} + \text{True Negative}}{\text{True Positive} + \text{True Negative} + \text{False Positive} + \text{False Negative}}$$

$$\text{F1 score} = 2 * \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$$

### 1.5.3 Performance of the proposed hybrid CNN-GRU model in the classification of lung sounds

Table 1.3 shows that the hybrid CNN+GRU model outperforms solo CNN and GRU models in identifying lung disease. The hybrid model has the greatest accuracy (97% across all disease categories). The hybrid model classifies COPD with 97% accuracy, 96% precision, 95% recall, and 95.5% F1-score, beating the CNN and GRU models, which had 86% and 89% accuracy, respectively. The CNN+GRU model diagnoses Bronitis with 96% accuracy, whereas CNN and GRU alone achieve 85% and 87%. The hybrid model has high accuracy, recall, and F1-scores for healthy lung sounds and respiratory diseases including Bronchi and URTI. This shows that the CNN+GRU model improves by combining the strengths of both models, making lung diagnosis more accurate. The hybrid model's improved recall and F1-scores for illnesses like pneumonia and bronchiectasis shows its capacity to recognize and categorize difficult cases. These results show that the hybrid model can automate lung sound analysis for respiratory illness, indicating therapeutic applications.
