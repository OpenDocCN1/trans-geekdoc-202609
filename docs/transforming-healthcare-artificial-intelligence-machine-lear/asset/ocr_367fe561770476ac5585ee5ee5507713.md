# 3.4.3 Long short-term memory (LSTM) for eye disease

Creating a LSTM (long-term memory) model for eye disease detection using deep learning several steps. The input to an LSTM model is typically a sequence of vectors representing features over time (or a sequence of frames/images in the case of temporal data). Let $X_t \in R^d$ be the input vector at time step $t$, where $d$ is the number of input features. An LSTM contains multiple gates: the forget gate, input, and output. These gates control the flow of information through the cell. Each gate represents exactly which information should be discarded from the cell state:

```
$f_t = \sigma(W_f \cdot [h_{t-1}, X_t] + b_f)$
```

Where $W_f$ are the weights associated with the forget gate, $h_{t-1}$ is the hidden state from the previous time step, $\sigma$ is the sigmoid activation function, and $b_f$ is the biased term for the forget gate. The input gate regulates the rate of data addition to the cell state:

```
$i_t = \sigma(W_i \cdot [h_{t-1}, X_t] + b_i)$
```

```
$\widetilde{C}_t = \tanh(W_C \cdot [h_{t-1}, X_t] + b_C)$
```

Where $i_t$ is the input gate activation, $\widetilde{C}_t$ is the candidate cell state, $W_i$ and $W_C$ are the weights of input gate and candidate cell state, respectively, and $	anh$ is the hyperbolic tangent activation function. The function is

```
$C_t = f_t * C_{t-1} + i_t * \widetilde{C}_t$
```

Where $C_t$ is the updated cell state at time step $t$ and $C_{t-1}$ is the cell state from the previous time step. The next concealed state is determined by the output gate:

```
$o_t = \sigma(W_o \cdot [h_{t-1}, X_t] + b_o)$
```

```
$h_t = o_t * \tanh(C_t)$
```
