# 8.4.2 Mathematical relationship between KPIs

The KPIs interact in complex ways. For instance:

+   - Latency (L) inversely affects throughput ($T_t$) and traffic capacity ($T_c$).
- Reliability (R) is directly related to packet loss rate and impacts QoS adherence (Q).
- Resource Utilization (U) impacts availability (A) and fault tolerance ($F_t$).
To model these interactions, we can define the following relations:
- Latency-Throughput Relation:

```
$L = rac{C}{T_b} + J$
```

Where C is the constant dependent on network infrastructure.

+   - Reliability–QoS Relation:

```
$Q = 1 - R$
```

QoS adherence decreases as reliability drops.

+   - Resource Utilization–Availability Relation:

```
$U = rac{1}{A}$
```
