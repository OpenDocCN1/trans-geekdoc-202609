Collected sensor data is uploaded to the cloud using the ThingSpeak, requiring an account for data uploads. Doctors can access a shared webpage link for monitoring and prescribing based on the patient's health status. The data is also used for real-time health prediction by feeding it into a pre-trained SVM classifier.

The system labels inputs as “normal” if values fall within standard medical ranges: 36°C temperature, 70-90 bpm heart rate, 120/80mmHg blood pressure, and 80–100mmHg oxygen level. It can also detect conditions like fever, hypertension, and lung disease based on trained data.

# 14.3.2 Flowchart explanation

In Figure 14,2, the methodology flowchart is presented. The steps are explained as follows:

+   1. First, the Raspberry Pi and Arduino be powered up using USB cable, which provides an appropriate supply to the sensors.
2. Place the sensors on the patient’s body surface.
3. If the sensor is not correctly placed, the system shows “PLACE THE SENSORS PROPERLY” on the serial monitor.
4. After correct sensor placement, the patient’s vital parameters (body temperature, oxygen level of blood, heartbeat rate, and blood pressure) are collected using biomedical sensors.
5. The collected information will be displayed on an LCD and a serial monitor.
6. Collected parameters will be shared with the doctor through IOT using ThingSpeak Cloud.
7. The collected data was applied to the SVM classifier as testing data.
8. Here, the real-time data is taken from the patient. The SVM model created using the heart disease dataset was taken from Kaggle. This four-class dataset has temperature, blood pressure, oxygen, and heart rate values.
9. If the person average medically defined values, this system shows the status as “NORMAL”. Otherwise, it moves to the next class.
10. If the patient’s body temperature is high, the system will show “FEVER” as an output.
11. In the next class, if the heartbeat rate and blood pressure are high per medically defined values, the system will display the patient’s status in “HYPERTENSION”.
