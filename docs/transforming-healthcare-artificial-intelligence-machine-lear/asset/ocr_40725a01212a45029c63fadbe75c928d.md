Retinal disorders are identified and diagnosed using OCT images' segmentation and wideness of retinal layers. Any disease-related changes to the retinal layers are rare, and evaluating the results is difficult to without a designated baseline method. Conventional image processing techniques for identifying anomalies in the retinal layer have several shortcomings, including the need for extensive topic knowledge and a lengthy processing time. The approach for automatic processing is also challenging to generate [15]. As a result of technological advancements and the development of AI, more researchers are now using CNNs for deep learning to identify retinal disorders in OCT pictures.

In order to automate and accurately detect CSRs in OCT pictures, Hassan et al. [16] developed a system that uses pre-trained deep CNNs. The authors employed convolutional neural network (CNN) models for classification, using GoogleNet, ResNet-18, and AlexNet. Statistical parameter assessment was used to examine the efficacy of deep CNNs; AlexNet achieved an accurate classification of 99.64% of OCT Image Database. Subramanian et al.'s [17] analysis of the most recent deep learning-based approaches for DR detection and classification focused on these techniques. This effort makes use of a number of classification methods, including binary, lesion-based, and vessel-based identification. Using accessible DR datasets have been made available.
