Through this procedure, unprocessed visual data is converted into numerical features that allow for processing without losing any important information. These characteristics are essential for a number of subsequent tasks, including matching images, identifying objects, and categorization. A type of statistical method called Gray-Level Co-occurrence Matrix (GLCM) is employed to identify the spatial relationships between individual pixels in an image. It calculates how frequently pairs of pixels appear in an image at particular ranges and directions. Through the examination of these pixel pairings, GLCM is able to derive texture features that offer details on the image's texture attributes, including contrast, correlation, energy, and homogeneity. When evaluating textures with distinct patterns and structures, GLCM works especially well. The statistical technique GLCM has shown to be effective in removing textural elements from [24].

Several indicators can be obtained from the calculated GLCM to describe the texture and structure of the image. A few typical characteristics are listed below:

- **Contrast/Inertia**: It quantifies the image's local variances, which expresses how the amount of various pixels in a picture fluctuates denotes less variation in pixel intensity, whereas high contrast shows a great deal of variance in pixel intensity.

$$Contrast = \sum_{i,j} (i-j)^2 P(i,j) (5.1)$$

- **Entropy**: It is a metric for determining how intricate an image's texture or information is. Greater data complexity or texture is indicated by higher entropy.

$$Entropy = -\sum_{i,j} P(i,j) * \log(P(i,j)) (5.2)$$

- **Homogeneity**: It represents how the GLCM diagonal and the element distribution are related. Elevated homogeneity values imply a more homogeneous texture since they show that the elements are concentrated along the diagonal. The degree to which the matrix elements are near the GLCM matrix's diagonal is indicated by this metric. If the high-value matrix components are close to the diagonal, the homogeneity will be significant.

$$Homogeneity = \sum_{i,j} \frac{P(i,j)}{1+(i-j)^2} (5.3)$$

- **Energy (or Angular Second Moment)**: It symbolizes the image's uniformity or orderliness. If the values of the matrix's members tend to be the similar or homogeneous, the energy value will be large.

- **Correlation**: It calculates the linear dependence among two pairs of pixels, which indicates how closely two pixels are related to one another. A high correlation suggests that two pixels are highly dependent on one another.
