## 13.2.1 Data collection

In this phase, the system captures real-time keypoint data from users performing various yoga poses using PoseNet. PoseNet is a pre-trained model that detects and estimates points on the human body from video frames. These key points include joints and other significant points, which are recorded as x and y coordinates. The data collection process is performed using a webcam and is facilitated by ml5.js, which simplifies the integration of PoseNet into the web application. This raw data is essential for training the neural network to recognize and classify different yoga poses.

## 13.2.2 Data preprocessing

Preprocessing may also involve data augmentation techniques to increase the diversity of the training data and make the model more robust to variations in pose presentation. Normalization is a fundamental technique used to scale input data to a standard range, typically [0, 1]. This process helps the learning model to learn more effectively by ensuring that the data is on a comparable scale, speeding up convergence and improving performance. In this case, min-max normalization is employed. The minimum and maximum values for each of the 34 input features, which represent the coordinates of keypoints, are specified in the JSON data. The normalization formula used is

```
$$X_{norm} = \frac{x - inputMin}{inputMax - inputMin} \quad (13.1)$$
```

### 13.2.2.1 Categorical encoding

Categorical encoding is crucial for transforming output labels into a format suitable for classification tasks. In the proposed model, one-hot encoding is utilized. This method converts categorical labels, representing different yoga poses, into binary vectors. The JSON data provides a legend that maps each pose to a unique binary vector. For instance, Pose “1” is encoded as [1, 0, 0, 0, 0, 0], Pose “2” as [0, 1, 0, 0, 0, 0], and so forth. This approach allows the to treat the output as distinct categories rather than ordinal values, making it suitable for multiclass classification tasks.

### 13.2.2.2 Scaling

Scaling often complements normalization. Standard scaling, which involves transforming data to a zero mean and unit variance, may be used. The formula for


### 13.2.2.3 Fine-tuning parameters

Fine-tuning involves adjusting the training parameters to optimize the model's performance. Key parameters include the learning rate, number of epochs, batch size, and the optimization algorithm. The learning rate controls how much to adjust the model weights with each update, while the number of epochs determines how many times the model will pass through the entire dataset. The batch size specifies the number of samples processed before updating the model weights. Techniques such as grid search or random search may be used to find the optimal parameter values.

### 13.2.2.4 Developing a model

In this step, the architecture of the custom neural network is designed for classification task. The model typically consists of input, hidden, and output layers. For pose classification, the input layer receives the normalized keypoints data, while the hidden layers process this data through various activations. The output layer produces predictions for different poses. Techniques used in developing the model including activation functions, defining the number of layers and neurons, and choosing the loss function, such as categorical cross-entropy, for multiclass classification.

The story begins with the input layer, 34 keypoints' coordinates (x and y for 17 keypoints) are fed into the model. This layer is like the gateway for raw data, capturing the pose of the user and transforming it into a format the model can understand.

- Shape: The input tensor holds 34 features (representing the 34 keypoints).
- Description: It collects the raw keypoint data detected from the user's pose, setting the stage for the model's interpretation.

The data is passed to the first dense layer, where a transformation begins. This layer takes the raw coordinates and starts molding them into meaningful activations.

- Units: 16 neurons in this layer act as processors for the input data.
- Activation Function: The sigmoid function is like a filter, ensuring that all values are compressed between 0 and 1.
- Kernel Initializer: To set the initial state of the network weights, the model uses Variance Scaling (which follows a normal distribution).
- Bias Initializer: The biases are initialized to zeros, making sure there's no initial bias in the predictions.
- Input Shape: The input data here is a tensor of shape [34], corresponding to the 34 keypoints.
