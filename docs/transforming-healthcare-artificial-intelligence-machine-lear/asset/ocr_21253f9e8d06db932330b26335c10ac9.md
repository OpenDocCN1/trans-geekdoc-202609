# 13.2.1 Data collection

In this phase, the system captures real-time keypoint data from users performing various yoga poses using PoseNet. PoseNet is a pre-trained model that detects and estimatespoints on the human body from video frames. These key points include joints and other significant points, which are recorded as x and y coordinates. The data collection process is performed using a webcam and is facilitated by ml5.js, which simplifies the integration of PoseNet into the web application. This raw data is essential for training the neural network to recognize and classify different yoga poses.

# 13.2.2 Data preprocessing

Preprocessing may also involve data augmentation techniques to increase the diversity of the training data and make the model more robust to variations in pose presentation. Normalization is a fundamental technique used to scale input data to a standard range, typically [0, 1]. This process helps the learning model to learn more effectively by ensuring that the data is on a comparable scale, speeding up convergence and improving performance. In this case, min-max normalization is employed. The minimum and maximum values for each of the 34 input features, which represent the coordinates of keypoints, are specified in the JSON data. The normalization formula used is

```
$$X_{norm} = \frac{x - inputMin}{inputMax - inputMin} \quad (13.1)$
```

# 13.2.2.1 Categorical encoding

Categorical encoding is crucial for transforming output labels into a format suitable for classification tasks. In the proposed model, one-hot encoding is utilized. This method converts categorical labels, representing different yoga poses, into binary vectors. The JSON data provides a legend that maps each pose to a unique binary vector. For instance, Pose “1” is encoded as [1, 0, 0, 0, 0, 0], Pose “2” as [0, 1, 0, 0, 0, 0], and so forth. This approach allows the to treat the output as distinct categories rather than ordinal values, making it suitable for multiclass classification tasks.
