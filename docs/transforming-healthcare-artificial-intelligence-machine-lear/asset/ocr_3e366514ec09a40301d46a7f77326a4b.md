# 7.3.1 Convolutional autoencoder (CAE)

One kind of neural network that may minimize noise in data is the CAE, which works by understanding the underlying structure of the input. The typical architecture of CAE [19] is shown in Figure 7.2. It consists of three components: a bottleneck that picks key characteristics, an encoder that compresses input while maintaining valuable features, and a decoder that reconstructs the data. Using a dataset, the CAE model may be used to generate new pictures and produce an unsupervised classifier. In order to reconstruct the pictures and comprehend the latent space of the data, this model employs an encoder-bottleneck-decoder architecture.
