# 14.5.4 Snippet of VNC viewer IDE

In Figure 14.16, the VNC viewer IDE is shown. VNC viewer is an open-source IDE platform that controls a computer remotely. VNC is abbreviated as “Virtual Network Computing”. It uses the RFB protocol to transfer screen pixel data over the network from one to another. The Raspberry Pi and the desktop must connect to the same Wi-Fi network. Only the Raspberry Pi should be accessed. The VNC viewer and the PI are connected using the Wi-Fi network's IP address. Figure 14.17 shows the coding (for Raspberry Pi in Python) and the serial monitor output. The serial monitor shows the output as “NORMAL”. So, the tested person is in a normal state.
