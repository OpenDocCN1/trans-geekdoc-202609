Wang and colleagues [68] tested a CNN model using the ICBHI 2017 lung sound dataset, which included normal and pathological recordings. They studied CNNs for SVMs. Categorization accuracy was assessed using lung sound length, frame overlap, and features (spectrogram or MFCC). The dataset was balanced using pitch shifting, stretching, and white noise. The findings showed how parameters affect classification. Higher frames overlap improved. Spectrogram features, 128 frames, and 75% overlap worked. Performance was OK without memory or storage.

Woo Kim et al. [69] enhanced respiratory sound classification using cross-domain adaptability. This study uses ICBHI dataset sound recordings from multiple electronic stethoscopes. For cross-domain sound classification, researchers recommended using DL. Guided supervised learning and domain adversarial training cross-domain adaptation and reduce-related disparities. The ICBHI trials show that these methods work. Stethoscope-guided supervised learning exceeded baseline by 2,16% with 61,71% ICBHI. Electronic stethoscope and data limitations may affect respiratory sound classification. Many cross-domain adaptation strategies enhance categorization and eliminate domain-related inconsistencies. One way is stethoscope-guided contrastive learning.
