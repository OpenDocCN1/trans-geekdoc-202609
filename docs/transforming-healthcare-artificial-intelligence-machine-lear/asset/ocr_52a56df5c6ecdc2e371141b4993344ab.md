# 2.4.1.4 ECG waveform

To test the function of heart, it is required to do an electrocardiogram test for which it is necessary to place the ECG electrodes in various parts of the patient's body in order to capture the electrical activity of the heart. These electrodes can detect various heart abnormalities by indicating an abnormal ECG waveform showing elevated or depressed electrical impulses from the human heart.

ECG waveform is captured by electrodes and the electrical impulses can be represented in various waveform patterns which include P-component, QRS-complex, and T-component. Hence, if there is any abnormality, it can be of P-wave abnormality, QRS-complex abnormality, and T-wave abnormalities.
