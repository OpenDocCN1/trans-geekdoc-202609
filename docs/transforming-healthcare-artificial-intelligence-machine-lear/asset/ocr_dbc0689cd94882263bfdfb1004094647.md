# 7.6 CONCLUSION AND FUTURE ENHANCEMENT

DR is an eye-related disease caused by diabetes. At first, DR may only cause a slight vision impairment or no symptoms at all. However, blindness may be the result. Both type 1 and type 2 diabetics can produce the possibilities to develop the disease. It is necessary to find, treat, and prevent vision loss in people with diabetes. This paper proposes a deep learning-based model using CAE and CNN, which creates the combined methodology for detecting DR with high accuracy of 99%. The performance is compared with the existing methodologies. Our model outperforms the existing methodologies. The APTOS 2019 dataset has imbalanced classes of data. Using data augmentation, the size of the dataset is increased. In future, other techniques will be used for data augmentation.
