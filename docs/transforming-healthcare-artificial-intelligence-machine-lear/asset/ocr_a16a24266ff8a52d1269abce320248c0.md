# 14.3.1 Baseline system

Figure 14.1 shows the ML architecture used in this study. The process begins in the software section, where various ML algorithms are tested to find the best fit for the dataset.

The dataset includes 200 samples across four classes: regular (51), fever (48), hypertension (55), and lung disease (47). The objective is to accurately classify health conditions into these categories.

Four ML algorithms were used: Decision Tree, K-Nearest Neighbor (KNN), Gaussian Naive Bayes, and Support Vector Machine (SVM), each offering unique features and decision-making approaches.

**Decision Tree Classifier** creates a model that predicts the value of a target variable by learning simple decision rules inferred from data features. This algorithm is known for its ease of interpretation but may suffer from overfitting if not properly tuned.

**K-Nearest Neighbor (KNN)** is a non-parametric algorithm that classifies data based on the closest training examples in the feature space. It makes predictions by calculating the distance between data points, which can make it computationally expensive for large datasets.

**Gaussian Naive Bayes Classifier** is based on Bayes' theorem, assuming that the features are normally distributed. It works well for small datasets and performs efficiently in cases where the features are independent.

**Support Vector Machine (SVM)** Classifier is a robust algorithm that constructs a hyperplane in a high-dimensional space to separate the classes. SVM proved to be the most effective among the four algorithms, achieving the highest accuracy in classifying health conditions into four categories. Its success is likely due to its ability to handle high-dimensional spaces and complex feature feature relationships, especially when the right kernel is used.

After completing the ML algorithm, the system transitions to the hardware component, which includes biosensors, controllers, and cloud storage. Real-time data is collected using a DHT11 temperature sensor, a blood pressure sensor, and a pulse oximeter for heart rate and oxygen
