## 13.2.2 Real-time pose estimation and recognition

The initial phase is dedicated to capturing live video streams of users forming yoga poses. This phase leverages PoseNet, a deep learning model implemented through ml5.js, for real-time pose estimation. PoseNet applies CNNs to process video frames from a webcam. These CNNs are designed to detect and estimate keypoints on the human body, as the positions of joints and limbs, with high accuracy. PoseNet's CNN architecture consists of multiple convolutional layers that extract features from the video frames, followed by fully connected layers that predict the coordinates of keypoints. This process provides a detailed map of the user's pose, including the location of keypoints in the x and y dimensions. The data from this stage is crucial for subsequent pose classification and tracking, as it establishes the foundation upon which all further analysis is built. p5.js is utilized to handle video capture and display, seamlessly integrating PoseNet's output into the user interface and providing real-time visual feedback [11].

## 13.2.3 Real-time pose classification and tracking

In the second phase, the project focuses on classifying and tracking yoga poses using the keypoint data obtained from PoseNet. This is achieved with a custom-trained neural network and developed using ml5.js. The neural network uses fully connected layers to process the input keypoint data and classify it into one of several predefined yoga poses: Mountain, Tree, Downward Dog, Warrior II, and Chair. The network is trained on a labeled dataset, where each set of keypoint coordinates is associated with a specific pose yoga. During classification, the network predicts the pose patterns on the keypoint data.

Kalman Filtering is a mathematical technique used for real-time tracking and noise reduction. It is employed to enhance tracking accuracy by smoothing out the detected keypoint positions and reducing noise. Kalman filters predict the future positions of keypoints by their past movements, ensuring stable and reliable tracking despite potential fluctuations. The integration of ml5.js for classification and Kalman filtering for tracking ensures each detected pose is consistently and accurately classified. p5.js is used to render the tracking results on the canvas, providing users with visual feedback and real-time updates.

## 13.2.4 Pose correction and feedback mechanism

The final phase of the YogAI project involves managing the practice timer based on the detected poses, with distinct requirements for each mode: Learn Mode and Practice Mode. In Learn Mode, users must hold each pose for a duration of 10 seconds while referring to images. The system continuously monitors the user's alignment using the pose data. If misalignment is detected, the timer momentarily pauses to allow the user to correct their posture. If misalignment persists for an extended period, the timer resets, giving the user additional time to adjust their pose before resuming. This feedback mechanism ensures that users achieve and maintain correct posture.

In Practice Mode, users are required to hold each pose for a longer duration of 30 seconds without reference images. The system monitors pose accuracy and pauses the timer if incorrect. If the incorrect pose continues for a prolonged duration, the timer resets to ensure the user can achieve the correct form. Both modes use p5.js for managing the visual display of the timer and feedback messages, providing an interactive and user-friendly experience. ml5.js plays a crucial role in real-time pose classification and feedback, helping users maintain proper form and enhance their yoga practice.

## 13.2.5 PoseNet

PoseNet is a computer vision model designed to estimate human poses by detecting body points, including limbs from images or video. It identifies 17 keypoints, such as the nose, eyes, shoulders, elbows, and knees, and constructs a skeletal framework of the person's posture. This model operates in real time, making it well-suited for applications that require continuous tracking.

In the proposed model, PoseNet is utilized to identify postures like “Mountain,” “Tree,” Warrior II [12].

## 13.2.6 Architecture overview

The architecture of PoseNet can be outlined as follows:

i. **Input Layer:** Here, the input could be varied in size, yet it is standardized to 257×257 or 353×353 pixels. The input is shown in RGB with three channels.

ii. **Backbone Network:** The backbone of PoseNet is based on MobileNet. MobileNet is a highly efficient and lightweight CNN for low-resource environments. The encoder of PoseNet is made up of several layers of depthwise convolutions, followed by batch normalization and ReLU activations.

iii. **Head Keypoints:** This is an output layer that predicts the locations of keypoints. The output is represented as heatmaps, which are essentially probability distributions over the possible locations. These heatmaps are directly derived from high-level feature maps produced by the backbone network. This is called heatmap regression, where the network connects offsets for every keypoint to refine their location.

iv. **Output Layer:** The final output layer renders the predicted coordinates for each keypoint with an associated confidence score. The coordinates are the x and y locations for the keypoint in the image, while the confidence score is the keypoint likelihood of being found in that location.

v. **Post-Processing:** Applications of Non-Maximum Suppression (NMS) are made to eliminate the redundant keypoints and overlapping detections. NMS suppresses the lower-confidence detections and retains only the highest-probability set of keypoints related to each person detected in the image. This filter will ensure that the final keypoint predictions are not only non-redundant as well.
