# 12.2.3 V-REP model

V-REP (Virtual Robot Experimentation Platform), a 3D robot simulation program with an integrated development environment, allows any robot or robotic system to be modelled, modified, programmed, and simulated. Several scene components or elemental objects are combined in a hierarchy resembling a tree in V-REP simulation environment. Elements with any degrees of freedom connect multiple scenes together are called joints (prismatic, revolute, screw-like, or spherical). They have the ability to function in multiple modes, such as inverse kinematics mode and force mode. Triangular meshes are called shapes, and they are employed in rigid body visualization and simulation. As a collection of convex shapes, they can be tuned for quick dynamic collision reaction calculations (e.g., proximity sensors, dynamics, and mesh-distance calculation module). Force sensors are inflexible connections between shapes that have the ability to measure forces and torque to break conditionally upon exceeding a predetermined threshold. A wide range of predefined or bespoke data streams are recorded by graphs. Next, data streams can be shown directly (as a time graph of a specific data type) or combination with one another to show 3D curves or X/Y graphs. When a camera is connected to a viewport, scene visualization is made possible. Lights have an immediate impact on cameras or vision sensors by illuminating a scene or specific objects inside it.

Scene objects are used in isolation; instead, they work with other scene objects, such as a proximity sensor that can identify forms. Furthermore, V-REP provides a number of calculation modules that can be used directly on one or more scene objects. The kinematics module enables forward and inverse kinematics calculations for all kinds of mechanisms, including redundant, nested-looping, closed, branched, and more. It can handle weighted, damped/damped, and conditional resolution. The dynamics module use the Bullet Physics Library and the Open Dynamics Engine to handle the computation and interaction of rigid body dynamics (collision reaction, gripping, etc.). Since dynamics-based simulations are still in their infancy and frequently rely on approximations, it's critical to use many physics engines to evaluate findings. On this writing, a third approach using Vortex Dynamics provides high-quality physics support is being developed. A collision detection module makes it possible to quickly check for interference between any form or group of shapes. This module operates independently of the dynamics module. For accelerations, it makes use of data structures built on a binary tree of oriented boxes. By using a temporal coherency approach, impotment is accomplished.
