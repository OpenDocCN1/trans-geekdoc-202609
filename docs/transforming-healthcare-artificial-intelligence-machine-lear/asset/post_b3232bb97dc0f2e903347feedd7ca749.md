## 14.4.8 Support vector machine classifier

Figure 14.10 illustrates the hyperplane in SVM classification. The goal of SVM is to find a hyperplane in an N-dimensional space that separates different classes of data points.

## 14.4.8.1 Key concepts

**Hyperplane Definition:** A hyperplane is a flat subspace of one dimension less than its ambient space. In 2D, it's a line; in 3D, it's a plane.

**Classification Objective:** SVM seeks to find the optimal hyperplane that maximizes the margin between data points from different classes. Maximizing this margin improves generalization to unseen data, reducing classification errors.

## 14.5.2 Serial communication protocol

Figure 14.14 illustrates serial communication between a Raspberry Pi and Arduino microcontroller using the I2C protocol, which connects multiple devices efficiently.

## 14.5.2.1 Key features of serial communication via I2C

**Master–Slave Architecture:** The Raspberry Pi acts as the master, controlling communication with the Arduino, the slave device. This setup ensures efficient data transfer, with the master initiating communication.

**Data Transmission:** From the Arduino, such as sensor readings, is sent to the Raspberry Pi for processing, decision-making, or cloud storage.

**Multiple Device Connection:** I2C connects multiple devices to a single master using just two wires (SCL for clock and SDA for data), making it ideal for various sensors.

**Real-Time Data Processing:** I2C supports fast communication, which is essential for timely data analysis in healthcare monitoring systems.

**Simplicity and Flexibility:** I2C is easy to implement and adaptable to various devices, allowing developers to expand their systems with minimal redesign.

In summary, Figure 14.14 shows how I2C enables efficient data exchange between the Raspberry Pi and Arduino, enhancing real-time data processing and system functionality.
