CNN is a popular spectrogram-based acoustics technique. CNN neural connections resemble animal visual brains, making them biological. One neuron cannot respond to the whole visual field. CNNs that categorize features and forecast respiratory state using audio signal spectrograms are promising [48]. Transformer is a sequential modeling architecture for course-based COVID-19 identification like RNN [49,50,51,52,53]. Audio spectrogram components are Transformer tokens. Transformer uses attention to learn a weighted blend of characteristics from close and far away spectrograms to find biomarkers in audio streams. The Transformer-based model beats all DL algorithms in the INTERSPEECH 2021 Computational Paralinguistics Challenge (ComPare) using COVID-19 Sounds data.

# 1.2.2 Using ICBHI database

Experiments support CNN advancements. With almost 95% accuracy, it was found that CNN models categorized lungs as wheeze, squawk, stridor, and crackle. 53 CNN variations like VGish [55] and ResNet [4,56] can identify crackling, COPD, and COVID-19. In the ICBHI 2017 challenge, this model achieved an accuracy of 52.26%, surpassing other models by 2%–12.7%.

RNN and its derivatives classify respiratory sounds using DL [57,58]. CNNs employ 2D convolutional neural networks to treat frequency and time identically, whereas RNNs use recurrent mechanisms to infer sequential patterns from audio data's temporal context. RNNs improve cross-time and long-distance correlation modeling by addressing CNNs' small visual field. Tiwari et al. [59] created a bidirectional RNN model using ICBHI 2017 data to identify abnormal respiratory cycles with above 80% accuracy. RNN and CNN can enhance spatial-temporal respiratory sound classification [60,61].
