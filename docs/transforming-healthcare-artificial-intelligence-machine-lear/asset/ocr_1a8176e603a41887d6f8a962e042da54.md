The first conv layer involves 32 filters, with a kernel size of 3×3 and a ReLU activation function with the same padding. The layer is designed so that the output will have the exact spatial dimensions as its input. Then, the output of this layer is fed to a MaxPooling layer of 2×2, which is half the spatial size of the image in the layer's dimension. The second convolutional layer employs the 64 filters built around the same dimensions 3×3 and uses ReLU and the same padding. This layer, in particular, helps to capture more deep features from the image that can be used for classification tasks. Another MaxPooling layer of size 2x2 is used to apply further downsampling of the last layer. This is the layer where the input image is encoded or represented in compressed form.

The structure of the former stage, the encoder, is similar to that of the latter stage, but in the opposite direction, and the purpose is to get the original input form with the help of an encoder vector. The first layer from the layers in the decoders is a 32 kernel “filters” convolutional layer with a three-dimensional kernel with kernels three pixels in three and upsampling, which increases the spatial dimension of the image by two. A 32 filter is next used, by an identical convolutional layer and a sampling layer to resize the image to its actual dimensions. The final layer of the decoder is the last convolutional layer with only 1 filter with a single 3×3 kernel size and sigmoid activation. The filter is simply a single filter that works on a single channel (white images), and the output of that single filter is constrained within 0 and 1 through the sigmoid function.

Once trained, the autoencoder enables to obtain the encoder, which encapsulates relevant image contents. These encoded features are then used for classification purposes. We use the encoder in a fully connected layer with 128 ReLU neurons dedicated to learning additional features for classification. After all the classification layers have been added up, the last one is a binary layer with 2 neurons. This layer uses the activation function of softmax to determine the likelihood range for each class.
