The mathematical definitions of accuracy, recall, precision, and F1-score are as follows:

```
Precision = \frac{True Positive}{True Positive + False Positive} (1.1)
```

```
Recall = \frac{True Positive}{True Positive + False Negative} (1.2)
```

```
Accuracy = \frac{True Positive + True negative}{True Positive + False Negative + True Negative + False Positive} (1.3)
```

```
F1 score = \frac{2 * Precision * Recall}{Precision + Recall} (1.4)
```
