# ## 13.4.2 Practice Mode

Figure 13.7 represents the Practice Mode page which is for skill refinement and practice. In Practice Mode, users must hold each yoga pose for 30 seconds without visual references or guidance. The system continuously monitors the user's posture and pauses the timer if it detects any misalignment. If the incorrect posture persists for too long, the timer resets, ensuring that users only progress once they have correctly held each pose for the required duration, promoting accuracy and mastery.
