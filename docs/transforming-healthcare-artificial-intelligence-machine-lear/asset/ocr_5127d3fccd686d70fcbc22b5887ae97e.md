# 1.5 RESULTS AND DISCUSSION

# 1.5.1 Hyperparameters settings and device configurations

This PC contains an Intel(R) Core (TM) i7-7700HQ CPU @ 2.80GHz, Nvidia K80s GPU (24GB DDR5 Type), 36 GB of RAM, a 250 GB SSD HDD, and 550 and 520 MB/s read and write speeds. TensorFlow 2.4.0 and MATLAB created the experimental setup. Cross entropy and the Adam optimizer [68] were utilized for loss and optimization functions. The batch size, epoch, and learning rate hyperparameters were 8, 500, and 3e-4. Learning rate schedules modified model learning rates. Fivefold cross validation verified the dataset. Every comparison model utilized the same hyperparameter criteria. The dataset was randomly divided among 20% testing and 80% training.

# 1.5.2 Evaluations criteria

Model performance was measured by accuracy, recall, precision, and F1-score. With the confusion matrix, predictions are assigned to the data's original classifications. DL classification effectiveness may be assessed using the confusion matrix. The confusion matrix created during DL classification training on a dataset reveals the model's classification accuracy for each record and possible issues. The matrix rows show the training dataset labels, while the matrix columns help evaluate algorithm performance whether output is positive or negative or or no. Each table has four cells with various projected and actual data. Four outcomes are possible:

+   * True Positive (TP): This phrase denotes the success of a forecast. We sometimes refers to it as a sensitivity.
* True Negative (TN): This denotes the realization of a negative prediction. This is known as specificity.
* False Positive (FP): When a value is predicted to be positive but turns out to be negative, it's called a type-I mistake most of the time.
