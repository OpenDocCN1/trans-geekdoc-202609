# 286 Transforming Healthcare

Cai Y et al. developed an IoT-based cardiac monitoring system using biomed sensors and cloud data transmission [1]. Chavda P et al. proposed a cloud-based clinical support framework for chronic kidney disease prediction [2], while Ghanbari-Adivi F and M Moslesh group a real-time patient monitoring system using modern sensors [3].

A system for monitoring chronic diseases like diabetes and renal disorders using wireless sensors was presented in [4]. A student monitoring system focused on heart health was proposed in [5], with chronic illness trends analyzed monthly [6]. In [7], a real-time monitoring system for students and the elderly improved emergency services.

Behavioral monitoring via biosensors and digital devices was explored in [8]. A soldier's health and tracking system used IoT and GPS to transmit data to a control room [9]. In [10], a cardiac prediction system employed to analyze cardiac data, while [11] proposed a Raspberry Pi-based monitoring system that sensed biosensor data via IoT.

Real-time systems for elderly and ill patients were presented in [12] and [13], measuring vital parameters and using cloud services. Health data collection through biosensors and a mobile IoT application was developed in [14], while [15] introduced wearable biosensors for access across locations.

An ICU-supportive system using Arduino and mobile apps was detailed in [16], and a monitoring system using Raspberry Pi and cameras for remote feedback was introduced in [17]. A wireless system using GSM sent sensor data directly to doctors' phones, reducing hospital load [18].

In [19], biosensor data was processed with Raspberry Pi and stored in the Cloud. Health metrics like glucose and heart rate were monitored using ECG data in [20]. Emergency response was enhanced in [21] with IoT-based monitoring that alerted doctors and ambulance services.

A low-cost e-health system using a mobile app and Raspberry Pi was proposed in [22]. Sleep apnea detection via ECG and SVM classification was addressed in [23]. A body area network for faster diagnosis collected vital parameters, including full detection, in [24].

An Android-based e-health system enabled real-time tele-monitoring for home and hospital patients in [25]. Continuous observation of vitals using cloud data was proposed in [26], while [27] focused on psychological monitoring using biosensors. A rehabilitation system with cognition-controlled wireless networks was developed in [28].
