# 14.1 INTRODUCTION

Many factors contribute to unhealthy lifestyles today, including poor eating habits, lack of exercise, and inadequate diets. Busy routines often leave little time for health management. While various health monitoring systems exist, many rely on analog devices and CRO displays, requiring ADC and DAC conversions. The proposed system uses a Raspberry Pi as a minicomputer to overcome these limitations. It collects data from multiple patients using Internet of Things (IoT), sending results to a doctor's webpage. An integrated machine learning (ML) model predicts diseases, enhancing emergency response and coordinated care.

# 14.1.1 Background and motivation

Despite technological advancements, many people still lack access to medical facilities due to issues like limited medication availability, transportation, and distant hospitals. The proposed system aims to improve healthcare access using IoT technology.
IoT-based health monitoring tracks vital signs—heart rate, blood pressure, oxygen levels, and body temperature—in real time. This data is sent to healthcare providers via the cloud, allowing timely interventions even in remote or underserved areas.
By enabling continuous monitoring and prompt action, this system helps to bridge the gap between patients and medical care.

# 14.2 LITERATURE REVIEW

Numerous studies have focused on patient monitoring systems, with health data increasingly stored in the Cloud to improve doctor–patient communication. IoT and ML have enhanced the effectiveness and reliability of remote health monitoring.
