## 11.5.1 Evaluation metrics

The evaluation metrics describe the performance of the model. The calculation of various evaluation metrics including accuracy, recall, specificity, precision, and F1-score is shown in the following equations:

```
ACC = \frac{TP}{TP + TN + FN} (11.4)
```

```
Recall = \frac{TP}{TP + FN} (11.5)
```

```
Specificity = \frac{TN}{TN + FP} (11.6)
```

```
Precision = \frac{TP}{TP + FP} (11.7)
```

```
F1-Score = 2 \times \frac{Precision \times Recall}{Precision + Recall} (11.8)
```

## 11.6 CONCLUSION AND FUTURE SCOPE

The DBCT employs residual convolutional blocks to extract the required local attributes, and the features are reshaped before fed into the transformer blocks for gathering the global attributes from the preprocessed images. The implementation of the residual convolutional model improves the performance of the proposed model and in turns offers accuracy in comparison with the existing CNN architectures. The proposed DBCT offers better accuracy over the existing CCT. The combination of residual connection of convolutional layers and dense block layers performs the existing combination of convolution and transformer models. The spatial attention mechanism in the self-attention layers of transformers provides highest accuracy over the prevailing works. The proposed model offers an accuracy of 97.8% in the classification of lung cancer. The proposed model is tested for the binary classification of lung cancer as cancerous or non-cancer. The five distinct classes of lung cancer are classified with better classification accuracy. The system further focuses on the severity analysis of the lung cancer by predicting the benign and malignant stages of cancer. In the proposed work, the parameters are immensely reduced in comparison with the existing works. It offers better performance with Transforming Healthcare with the minimal number of datasets and in less time with reduced computational complexity. The future work will focus on the transformer blocks and deploy the work on the web applications.
