# 8.4.8.1 Optimization

The optimization for the GA-RL combo is

```
$$\Minimize \sum_{i=1}^{n} w_i \cdot \text{KPI}_i \text{(Slice Configuration)} - R(t) \quad (8.13)$
```

$W_i$ is the weight assigned to each KPI (importance level), KPI, is the predicted KPI value using the Erlang, Poisson, and Gaussian distributions, and $R(t)$ is the real-time reward provided by the RL agent based on feedback.

# 8.4.8.2 Reinforcement learning reward function

The RL agent's reward function is

```
$r_t = \alpha \cdot Q(t) - \beta \cdot (L(t) + J(t)) + \gamma \cdot T(t) \quad (8.14)$
```

$\alpha$, $eta$, and $\gamma$ are weights based on the importance of QoS adherence, latency minimization, and throughput maximization.

# 8.4.8.3 Genetic algorithm fitness function

The GA fitness function uses KPI distributions to ensure slice configuration meets requirements:

```
$$\text{(Chromosome)} = \sum_{i=1}^{n} w_i \cdot \text{KPI}_i, \text{(Slice)} \quad (8.15)$
```

+   where KPI, uses Erlang for latency, Poisson for traffic, and Gaussian for jitter.

# 8.4.8.4 Optimizing via genetic algorithm

The GA optimizes network slices by simulating natural selection processes. It uses fitness functions to evaluate solutions based on KPI values (latency, bandwidth, and jitter). The GA works by:

Population Initialization: Each individual represents a possible slice configuration. Fitness Evaluation: The fitness function is computed using weighted KPI parameters:

```
$F = w_1 \left( \frac{1}{L+0.1} \right) + w_2 \cdot T + w_3 \left( \frac{1}{J+0.1} \right) \quad (8.16)$
```
