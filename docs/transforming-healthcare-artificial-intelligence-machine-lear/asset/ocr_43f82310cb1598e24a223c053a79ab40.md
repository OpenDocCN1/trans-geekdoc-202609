# 13.2.2.3 Fine-tuning parameters

Fine-tuning involves adjusting the training parameters to optimize the model's performance. Key parameters include the learning rate, number of epochs, batch size, and the optimization algorithm. The learning rate controls how much to adjust the model weights with each update, while the number of epochs determines how many times the model will pass through the entire dataset. The batch size specifies the number of samples processed before updating the model weights. Techniques such as grid search or random search may be used to find the optimal parameter values.

# 13.2.2.4 Developing a model

In this step, the architecture of the custom neural network is designed for classification task. The model typically consists of input, hidden, and output layers. For pose classification, the input layer receives the normalized keypoints data, while the hidden layers process this data through various activation functions, such as sigmoid. The output layer produces predictions for different poses. Techniques used in developing the model including activation functions, defining the number of layers and neurons, and choosing the loss function, such as categorical cross-entropy, for multiclass classification.

The story begins with the input layer, 34 keypoints' coordinates (x and y for 17 keypoints) are fed into the model. This layer is like the gateway for raw data, capturing the pose of the user and transforming it into a format the model can understand.

+   - Shape: The input tensor holds 34 features (representing the coordinates of the keypoints).
- Description: It collects the raw keypoint data detected from the user's pose, setting the stage for the model's interpretation of this input.

The data is passed to the first dense layer, where a transformation begins. This layer takes the raw coordinates and starts molding them into meaningful activations.

+   - Units: 16 neurons in this layer act as processors for the input data.
- Activation Function: The sigmoid function is like a filter, ensuring that all values are compressed between 0 and 1.
- Kernel Initializer: To set the initial state of the network weights, the model uses Variance Scaling (which follows a normal distribution).
- Bias Initializer: The biases are initialized to zeros, making sure there's no initial bias in the predictions.
- Input Shape: The input data here is a tensor of shape [34], corresponding to the 34 keypoints.
