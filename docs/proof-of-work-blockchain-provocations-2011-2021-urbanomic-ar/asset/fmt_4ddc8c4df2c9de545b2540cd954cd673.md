
# 术语表

## A

**CC (Creative Commons)**
A copyright reform nonprofit and its eponymous alternative copyright licences (including the copyleft `CC-BY-SA`) and copyright waiver (`CC0`).

## C

**Cryptoeconomics**
The combination of cryptographic systems and the theory of game-theoretic economic incentives.

**Crypto Wars**
The legal and legislative battles of the 1990s, waged to ensure that the public could access and use effective cryptography without government backdoors.

**Cypherpunk**
A member of the eponymous ‘cypherpunks’ mailing list in the 1990s, or someone who holds to their principles of techno-anarchism pursued through cryptography.

## D

**DAO (Decentralised Autonomous Organisation)**
A blockchain corporation or co-operative, the technological equivalent of a charitable trust.

**DApp (Distributed App)**
A complete, usable Ethereum application comprising smart contracts and a web-based user interface.

**Dark Forest**
Science fiction author Cixin Liu’s novelistic universe in which the game theory of first contact with alien races makes any interstellar communication an existential risk. This means that you must either hide perfectly from everyone else in the universe, or destroy them completely as soon as you become aware of them before they can move to destroy you based on the same logic.

**Dark Forest Strike**
A world- or star-system-destroying attack on one (potentially) interstellar species by another based on the existential risk analysis logic of the dark forest.

**DDoS (Distributed-denial-of-service attack)**
Using many, often hacked, computers to flood a server with so many network requests that it is unable to respond to them all, effectively taking it offline.

**Digging**
The Dogecoin equivalent of mining.

**Discrete Log Problem**
Public-key cryptography relies on ‘trapdoor functions’ that provide results that are easy to calculate but impractically difficult to reverse. The function used to derive public keys from private keys, point multiplication on an elliptic curve, can be calculated easily enough. But, although it has not been mathematically proven to be impossible, there is no known method for calculating its inverse, point division on an elliptic curve. This is known as the discrete log problem.

**Doge**
A dog. Probably a Shiba Inu.

**Dogecoin**
The first ‘memecoin’, a fork of Bitcoin’s code with a faster block time and different mining algorithm, but mostly lots of doge memes.

**Dogeparty**
A fork of CounterParty’s code to run atop the Dogecoin blockchain rather than the Bitcoin blockchain.

**Dump**
To sell off a coin or token that has been pumped, crashing the market for it.

## E

**Ethereum**
A blockchain supporting general-purpose code execution rather than Bitcoin’s limited transaction scripts.

**Ether**
The native cryptocurrency token used on Ethereum.

**ERC (Ethereum Request For Comment)**
The `ERC-20` standard defines ‘fungible tokens’, essentially new cryptocurrencies that operate on the Ethereum blockchain. `ERC-721` defines ‘non-fungible tokens (NFTs)’.

**Exchange**
Cryptocurrency exchanges allow you to swap between different coins/tokens.

**Exploit**
A means of hacking a piece of software.

## F

**Fees**
Cryptocurrency transaction fees paid to miners for inclusion in a block.

**Fiat**
The act of declaring something to be so by the arbitrary exercise of power—state power, in the case of fiat currency such as paper notes that are not backed by precious metals.

**FIFO (First-in-first-out)**
A data structure like a pile of documents where the topmost one is always the first one to be removed.

**Fork**
A split in a project. Either of the source code for a program which has been developed into two different versions, or of one cryptocurrency chain into two rival ones.

**Fungible/Non-Fungible**
Fungibility is substitutability. Two things are fungible if you can swap one for the other without meaningful difference. Like two coins of the same denomination. Non-Fungibility is the quality of uniquely identifiable or meaningfully different things, like two different paintings in the same series.

## G

**Gas**
Ether used to pay for the execution of code by Ethereum.

**Genesis Block**
The first block mined for a particular blockchain.

**GitHub/Git**
`git` is a program that keeps track of changes and versions of a project’s software source code and other resources in a decentralised manner. It uses cryptographic hashing to keep track of this in a repository or ‘repo’, consisting of a series of ‘commits’ of groups of changes. It looks a lot like a blockchain, with the proof of work algorithm using software developers rather than mining rigs. GitHub is Microsoft’s walled garden for centralising software development, not to be confused with the underlying `git` version control system (VCS).

**GNU (GNU’s Not Unix)**
A project to create a free-as-in-freedom operating system for all computer users. Producers of the eponymous `GNU GPL` copyleft licence for software.

## H

**Hash**
A unique, algorithmically generated, unguessable identifier for a piece of data. As a verb, the act of applying that algorithm.

**Hodl**
To hold cryptocurrency, named after a typo on a Bitcoin message board.

## I

**ICO (Initial Coin Offering)**
A sale of cryptographic tokens to fund a project.

**Iota**
An early ‘internet of things’ post-blockchain project.

**IPv6**
Most recent version of the Internet Protocol (IP) launched in 2012 as an improved and more scalable replacement for the long-standing IPv4, which suffered from various limitations including potential address exhaustion.

## K

**Keys**
The pair of very long numbers or other mathematical entities that make up the public and private part of a modern cryptographic identity.

## L

**Layer Two Network**
A faster system for using an existing cryptocurrency using additional, more complex, software and cryptoeconomic incentive structures.

**LOIC (Low Orbit Ion Cannon)**
A DDoS tool.

## M

**MAST (Merkleized Abstract Syntax Tree)**
A Merkle tree containing different code or data at different branches, allowing the sender to commit to them now and use one of them later without having to reveal any of the others.

**Markov Chain**
A table of lists of elements that are likely to follow one another, allowing a representative sequence to be built up using random choices from them. Popular for creating variations on themes before the advent of generative adversarial networks (GANs).

**Merkle Tree**
A computer science ‘tree’ structure in which the leaves are data and each branch is the cryptographic hash of those below it. A compact and immutable representation of data. Txes in a blockchain block are arranged in a Merkle tree.

**Mining**
Validating blocks in return for rewards including mining fees.

**Mining pool**
Hardware or people sharing in the work and rewards of mining blocks.

## N

**NameCoin**
The first Bitcoin fork, which added support for publication of name/value pairs to create a decentralised equivalent to the Internet Domain Name system.

**net art / net.art**
1990s internet art. Add the dot to name a particular movement of that period.

**NFT (Non-Fungible Token)**
A cryptographic digital asset that can be uniquely identified within its smart contract.

## O

**OG (Original Gangster)**
An appropriated honorific indicating respect for someone who has successfully played the market longer than oneself.

**Onchain/Offchain**
Information or events that occur within blocks of a blockchain, or out in the real world.

**One-Time Pad**
The only perfect form of encryption. A unique series of random numbers used to encode each piece of information in a secret message. Only a recipient with the same unique series of numbers can hope to decrypt it.

**OpenCV**
An image-processing and image-recognition software library.

**Oracle Problem**
The problem of establishing onchain that an asserted fact holds true offchain with any degree of confidence.

## P

**Patch**
An incremental modification to a piece of software.

**PostScript**
Adobe’s ‘page description language’. A 2D graphics programming language used most recognisably in laser printers and industrial printing presses.
