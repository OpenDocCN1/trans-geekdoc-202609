
We could map operators onto cards randomly to ensure that there is no temptation to see the iconography of the Tarot and P′′ as related. Or we could take the opposite approach and carefully map each operator onto each Tarot card in a way that can be meaningfully explained.

Both approaches introduce interesting new concepts and resonances. They would require custom decks to be usable, as memorizing the mappings for seventy-eight cards would be very difficult for the average person. Doing so would be part of a deeper journey into this domain.

## 4 How To Read P′′ Tarot

You will need:

*   A table or other flat working area for laying out cards.
*   A tarot deck.
*   A flat glass bead, a coin, or other small marker.
*   A sheet of lined paper or a notebook, and a pencil or pen.
*   Optionally: the mapping you are using, written on an index card.

The suggested layout of the working area is to have the draw pile to the right, the discard pile to the left, the piece of paper in the middle, and the row of memory cells above the paper.

The memory cells start at zero in the middle, going up to the right (`1`, `2`, `3`) and down to the left (`-1`, `-2`, `-3`). If you are not familiar with negative numbers just start with cell ten in the middle and count up or down from there.

![](image/workspace.png)

To begin:

1.  Shuffle the Tarot deck very well while performing any usual rituals such as repeating the question to be asked. This is to ensure that there is a good mix of operators rather than long runs of `]` or `>` for example.
2.  Place the Tarot deck face down as the draw pile.
3.  Place the marker in the middle of the area you will be using for memory cells.

To proceed:

1.  Draw a card from the draw deck. This is the current instruction card.
2.  Write down the operator (`+`, `-`, `<`, `>`, `[`, `]`) from the card on a new line of the paper.
3.  Perform the operation specified by the operator for the current instruction card:
    1.  If the operator is a `<` or a `>`, write down the new cell number on that line. Then move the cell marker left or right one card’s worth of space. It should be possible to judge this visually, or you can draw a grid on a larger piece of paper. If there is already a card in this position, put the marker on top of it.
    2.  If the operator is a `+`, draw a card from the draw pile and place it face up on top of the current cell (under the marker, on top of any cards already in that position). The value of the cell is the number of cards stacked in it, make a note of this on the paper.
    3.  If the operator is a `-`, remove the topmost card from the current cell and place it face down on the discard pile. If there is not a card in that position, do nothing. The value of the cell is the number of cards stacked in it, make a note of this on the paper.
    4.  If the operator is a `[`:
        *   When the current memory cell is zero, draw instruction cards until you draw a `]`, writing down the operators but not acting on them. After drawing and writing down a `]`, continue from 1 as normal.
        *   When the current memory cell is greater than zero, proceed as normal until you draw a `]`, then follow the instructions for that operator. Make doubly sure to write down the operators you draw in the meantime, you’ll need to refer to them when you draw the `]`.
    5.  If the operator is a `]`:
        *   When the current memory cell is zero, do nothing and go on to the next instruction.
        *   When the current memory cell is greater than zero, jump back to the instruction after the matching `[` and rather than drawing an instruction card follow the instruction you wrote down. While following the written instructions do not draw instruction cards, only draw cards if required to increase the value in the current cell.
4.  Place the current instruction card face down on the discard pile.
5.  Repeat again from 1 until you reach a finish condition.

To finish, choose one of the following either before starting or when you feel it is appropriate to finish:

*   When you have enough cards in total in the cells to use for the layout you wish to use (one card, three card, Celtic Cross, etc.).
*   When you have enough cards on top in the cells to use for the layout (if you need three cards and have four cards in one cell and two in another, getting one card in another cell will satisfy this).
*   When following a jump instruction results in an endless loop.
*   When you have no more cards remaining in the draw pile.

If you run out of cards in the draw pile when pursuing a finish condition other than running out of cards, shuffle the discard pile thoroughly and use it as the new draw pile.

Once you have enough cards in the memory cell positions to use for a reading, you can move them in order into the layout that you chose. Where that layout is a simple line of cards, just use the memory cell area as the layout. If you have more cards than you need, owing to the finish condition you used, discard the surplus.

## 5 Notes

We use the number of cards in a memory cell as the value of that cell rather than substituting a card with a lower or higher printed value (e.g. incrementing the four of cups to give the five of cups) as the search required to find the next valued card would be time consuming and once more than a few memory cells have values in them the next valued card might be in use elsewhere.

We use the Tarot as is rather than adding more cards to allow an equal number of cards for each operator, or creating a new iconography to use the operators directly as meaningful symbols as well as instructions, in order to provide a familiar territory on which to deploy unfamiliar ideas and make them more easily learnable and usable.

Combining the instruction and data function in a single deck of cards is done to make the deck self-animating. Earlier prototypes used a separate ‘control deck’. Combining values and operations requires that we not create any rules that would affect whether specific cards will end up in memory cells in a given draw, as otherwise this would mean that (as with some dice Tarot and other systems) some combinations of cards and indeed some cards would never end up in the finished layout.
