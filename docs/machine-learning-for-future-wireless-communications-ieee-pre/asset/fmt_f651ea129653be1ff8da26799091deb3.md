
# Neural Network

A `NN` is a function ![images](`images/c20-i0050.png`)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>g</mi><mo stretchy="false">(</mo><mo>&#183;</mo><mo stretchy="false">)</mo></mrow></math> that maps an ![images](`images/c20-i0051.png`)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>N</mi></mrow></math>‐size input vector to an ![images](`images/c20-i0052.png`)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>M</mi></mrow></math>‐size output vector, i.e. ![images](`images/c20-i0053.png`)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>g</mi><mo>:</mo><msup><mi mathvariant="double-struck">R</mi><mi>N</mi></msup><mo>&#8594;</mo><msup><mi mathvariant="double-struck">R</mi><mi>M</mi></msup></mrow></math>. Function ![images](`images/c20-i0054.png`)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>g</mi><mo stretchy="false">(</mo><mo>&#183;</mo><mo stretchy="false">)</mo></mrow></math> is implemented as the cascade of multiple functions that can be represented by a graph where nodes (*neurons*) are the functions whose input and output are represented by the connecting edges (*connections*).

Neurons are organized in ![images](`images/c20-i0055.png`)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>L</mi></mrow></math> layers, the first layer being defined as the *input* layer, the last as the *output* layer, and all other layers as *hidden layers*. The neurons of layer ![images](`images/c20-i0056.png`)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>&#8467;</mi></mrow></math> are connected only to those of the two adjacent layers, and we focus on an implementation of the `NN` without loops, as shown in [Figure 20.2](`#c20.xhtml#c20-fig-0002`).

All neurons of layer ![images](`images/c20-i0059.png`)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>&#8467;</mi></mrow></math> implement the same function. In particular, at neuron ![images](`images/c20-i0060.png`)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>n</mi></mrow></math> of layer ![images](`images/c20-i0061.png`)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>&#8467;</mi></mrow></math>, the elements of output vector ![images](`images/c20-i0062.png`)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msup><mi mathvariant="bold-italic">y</mi><mrow><mo stretchy="false">(</mo><mi>&#8467;</mi><mo>&#8722;</mo><mn>1</mn><mo stretchy="false">)</mo></mrow></msup></mrow></math> of the previous layer are linearly combined with weights ![images](`images/c20-i0063.png`)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msubsup><mrow><mi mathvariant="bold-italic">w</mi></mrow><mrow><mi>n</mi></mrow><mrow><mo stretchy="false">(</mo><mi>&#8467;</mi><mo>&#8722;</mo><mn>1</mn><mo stretchy="false">)</mo></mrow></msubsup></mrow></math>, and then a scalar bias ![images](`images/c20-i0064.png`)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msubsup><mi>b</mi><mi>n</mi><mrow><mo stretchy="false">(</mo><mi>&#8467;</mi><mo>&#8722;</mo><mn>1</mn><mo stretchy="false">)</mo></mrow></msubsup></mrow></math> is added. During training, weights ![images](`images/c20-i0068.png`)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msubsup><mrow><mi mathvariant="bold-italic">w</mi></mrow><mrow><mi>n</mi></mrow><mrow><mo stretchy="false">(</mo><mi>&#8467;</mi><mo stretchy="false">)</mo></mrow></msubsup></mrow></math> and biases ![images](`images/c20-i0069.png`)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msubsup><mi>b</mi><mi>n</mi><mrow><mo stretchy="false">(</mo><mi>&#8467;</mi><mo>&#8722;</mo><mn>1</mn><mo stretchy="false">)</mo></mrow></msubsup></mrow></math> are selected in order to minimize a suitably chosen *loss function* over the *training set*. The parameters optimization is typically based on gradient algorithms. Usually the *activation functions* are sigmoids, which generate a single output.
