
一种直接的规则用于将 DP 分配给小区，被称为 `maximum receive power allocation`，旨在最小化每个连接单独带来的负载，这通过将每个 DP 分配给提供最强信号的小区来实现（Siomina and Yuan, [2012a](#c05.xhtml#c05-bib-0056)）。然而，这会降低网络性能，因为它使通常功率较低的 SC 未得到充分利用。`Range expansion` 可以缓解此问题（3GP, [2012](#c05.xhtml#c05-bib-0002)；Siomina and Yuan, [2012b](#c05.xhtml#c05-bib-0057)；Ye et al., [2013](#c05.xhtml#c05-bib-0063)）。在范围扩展中，来自小区 ![images](images/c05-i0034.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>k</mi></mrow></math> 的总接收功率 ![images](images/c05-i0033.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi>p</mi><mi>k</mi></msub><msub><mi>g</mi><mrow><mi>k</mi><mi>m</mi></mrow></msub></mrow></math> 使用加权因子 ![images](images/c05-i0035.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi>&#952;</mi><mi>k</mi></msub></mrow></math> ![images](images/c05-i0036.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mo stretchy="false">(</mo><msub><mi>&#952;</mi><mi>k</mi></msub><mo>&#8805;</mo><mn>1</mn><mo stretchy="false">)</mo></mrow></math> 进行缩放，该因子即为 `bias value`，由此得到的偏置总接收功率用于 DP ![images](images/c05-i0037.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>m</mi></mrow></math> 的基站分配决策。每个 DP 的分配规则可表述如下：
