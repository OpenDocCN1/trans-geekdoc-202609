## 16.4 经典信道预测

依靠传统统计方法，可以形成一个具有若干参数的预测模型来近似衰落信道的动态特性。给定当前和过去 `CSI` 的知识，这些参数可以被估计，然后通过该模型外推未来的 `CSI`。现有的基于模型的信道预测主要分为两类，即 `AR` 和参数化。它们的基本原理、建模、参数估计方法以及约束条件将在本节中简要讨论。
