An association period is defined as a succession of `coherence intervals (CIs)` during which the association matrix is essentially constant; see [Figure 3.1](#c03.xhtml#c03-fig-0001). In that sense, we assume that association is done over a longer time period (many `CIs`) compared to beamforming, which has to be done during each `CI`. Such an assumption is natural due to the high overhead incurred by reassociation. To simplify the presentation, we further assume that each `BS` can simultaneously serve all of its associated users (in multi‐user MIMO fashion).
