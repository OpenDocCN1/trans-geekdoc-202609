### 15.2.4 置信传播译码

[图 15.2](#c15.xhtml#c15-fig-0002)a 演示了在 `P(8,5)` 的因子图表示上的 BP 译码。消息通过位于每个阶段的 BP 处理单元 (`BPPEs`) (Arıkan, [2010](#c15.xhtml#c15-bib-0004)) 迭代传播。每次更新迭代从右向左的消息传递开始，该传递将 `LLR` 值从信道（最右侧）阶段传播到信息位（最左侧）阶段，并以左向右的消息传递结束，后者按相反顺序进行。[图 15.2](#c15.xhtml#c15-fig-0002)b 说明了具有其对应软消息的 `BPPE`，其中 `r_{t,s}` 表示第 `t` 个位索引在阶段 `s` 的左向右消息，而 `l_{t,s}` 表示右向左消息。也可以将 BP 译码应用于展开的极化码因子图 (Doan et al., [2018b](#c15.xhtml#c15-bib-0012))；因此在此设置中 BP 迭代是顺序执行的。图 [15.2](#c15.xhtml#c15-fig-0002)c 和 [15.2](#c15.xhtml#c15-fig-0002)d 说明了在展开因子图上 `BPPE` 的右向左和左向右消息更新的输入和输出消息，其中上标 `i` 表示迭代次数。右向左消息的更新规则 (Arıkan, [2010](#c15.xhtml#c15-bib-0004)) 对于 `BPPE` 是
