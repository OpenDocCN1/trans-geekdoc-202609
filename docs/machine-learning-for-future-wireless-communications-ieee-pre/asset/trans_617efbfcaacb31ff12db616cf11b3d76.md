
我们还通过利用 (Liang et al., [2018](#c15.xhtml#c15-bib-0025), Bennatan et al., [2018](#c15.xhtml#c15-bib-0006)) 中提出的思想来研究联合解码器和信道均衡器解码系统。我们将联合解码系统记为 `BP5-MLP-BP5` 和 `BP5-LSTM-BP5`，其中 `MLP` 和 `LSTM` 分别指使用全连接 `NNs` 和堆叠 `LSTM` 网络的噪声估计模型。注意，`DL` 基于噪声估计器的网络架构和参数取自 (Bennatan et al., [2018](#c15.xhtml#c15-bib-0006))。
