
`RNNs` 也可以使用针对 `DNN`‐ 和 `CNN`‐ 基均衡器的训练方法进行训练，分别描述于 [第12.4.2节](#c12.xhtml#c12-sec-0020) 和 [第12.4.3节](#c12.xhtml#c12-sec-0023)。此外，可采用 `L2(·)` 损失函数以及具有前向/后向传播的随机梯度下降算法来获得合适的网络参数。

## 12.5 采用神经网络基均衡化的 OFDM 系统性能

在本节中，我们研究采用深度学习技术，包括 `CNN` 和 `DNN`，进行信道均衡的 `OFDM` 系统性能。在给出仿真性能之前，让我们先描述用于本次性能研究的系统模型和网络结构。

### 12.5.1 系统模型和网络结构

[图12.12](#c12.xhtml#c12-fig-0012) 说明了采用 `NN` 基均衡器的 `OFDM` 系统结构。基带 `OFDM` 系统与传统系统相同（E. Dahiman and Skold, [2014](#c12.xhtml#c12-bib-0016)）。在发送端，用于信道估计的导频相关的已发射 `QAM` 调制符号首先被转换为并行数据表示。之后，逆快速傅里叶变换（`IFFT`）模块将数据从频域转换到时域。然后插入循环前缀（`CP`）以避免块间干扰。最后，经过并串转换后，信号通过通常为色散的信道传输。

设离散采样间隔的多径信道表示为 `{h(n)}`_{n=0}^{N-1}，其中复随机变量 `h(n)` 为时刻 `n` 的信道增益。则离散接收信号可表示为

(12.38) `y(n) = h(n) ⋆ x(n) + w(n) , n = 0,1,...`

![图12.12 采用 DNN 或 CNN 基均衡器的 OFDM 系统模型。](images/c12f012.jpg)
[图12.12](#c12.xhtml#R_c12-fig-0012) 采用 DNN 或 CNN 基均衡器的 OFDM 系统模型。

其中 `⋆` 表示循环卷积，`x(n)` 为发射时域信号，`w(n)` 为 `AWGN`。

如 [图12.12](#c12.xhtml#c12-fig-0012) 所示，在接收端，经过串并转换并去除循环前缀后，快速傅里叶变换（`FFT`）将接收信号从时域转换到频域。因此，在所考虑的 `OFDM` 系统中，`DNN` 或 `CNN` 基均衡器在频域工作。最后，如 [图12.12](#c12.xhtml#c12-fig-0012) 所示，接收信息通过基于均衡器输出的解调来恢复。

### 12.5.2 DNN 和 CNN 网络结构

对于 `OFDM` 系统，[图12.13](#c12.xhtml#c12-fig-0013) 描述了 `DNN` 的具体结构，其由六层组成，其中四层为标记为 `ELU` 的隐藏层。在我们的研究中，各层的神经元数量分别设置为 256、600、400、300、200 和 128。网络的输入数量为包含导频块和数据块的 `OFDM` 帧的实部数量和虚部数量之和。相比之下，输出数量等于从数据块中提取的数据符号的实部数量加上虚部数量。

在我们的性能研究中，指数线性单元（`ELU`）函数（Goodfellow et al., [2016](#c12.xhtml#c12-bib-0024)）用作除最后一层外的所有层的激活函数。`ELU` 函数为

(12.39) `f(α, x) = f_ELU(α, x) = { α(e^x - 1), x < 0 ; x, x ≥ 0 }`
