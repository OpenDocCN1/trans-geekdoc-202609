
然而，如果实际信道不符合信道模型，则基于 `SVM` 的盲均衡效果不佳 (Perez‐Cruz et al., [2001](#c12.xhtml#c12-bib-0044))。为了提高基于 `SVM` 的盲均衡算法的性能，(Wang et al., [2016](#c12.xhtml#c12-bib-0057)) 提出将支持向量回归器 (`SVR`) 的传统代价函数与误差函数的概率密度函数 (`PDF`) 相结合。因此，均衡器输出信号的 `PDF` 被表述为使其能够匹配接收端已知的星座图的 `PDF`。仿真结果表明，在考虑 `ISI` 信道上的通信时，该均衡方法优于传统的算法，例如 `PDF` 算法和 `SVR` 算法。然而，在基于 `SVM` 的均衡器中，超参数必须预先指定或通过交叉验证进行估计。此外，基于 `SVM` 的均衡器需要较长的训练序列，因此复杂度较高。因此，实际上，基于 `SVM` 的均衡器通常只能通过交叉验证调整一个或两个超参数。

为了解决这些问题，(Perez‐Cruz et al., [2008](#c12.xhtml#c12-bib-0045)) 中提出了一种根据 `GPR` 设计的非线性信道均衡器。与基于 `SVM` 的方法相比，`GPR` 算法具有基于最大似然优化核超参数的优势。这使得在短训练序列的情况下性能显著提升，从而使基于 `GPR` 的均衡器优于基于 `SVM` 的均衡器。相反，在使用长训练数据集的情况下，超参数仅轻微影响解，因此基于 `SVM` 和 `GPR` 的均衡器达到相似的性能。为了进一步提高基于 `GPR` 的均衡器的性能，(Olmos et al., [2010](#c12.xhtml#c12-bib-0033)) 将非线性信道均衡与低密度奇偶校验 (`LDPC`) 码相结合 (Yang et al., [2015](#c12.xhtml#c12-bib-0063))。该设计促使使用短训练序列来获得 `LDPC` 码的准确后验概率估计，而不是直接针对 `LDPC` 解码的误码率进行处理，而后者是之前研究中考虑的内容。

在概述了所有基于 `NN` 和 `ML` 的信道均衡解决方案之后，接下来我们将通过考虑算法设计、复杂度分析和性能比较，更详细地讨论这些技术。首先，让我们介绍信道均衡和相关信号检测的原理和问题表述。
