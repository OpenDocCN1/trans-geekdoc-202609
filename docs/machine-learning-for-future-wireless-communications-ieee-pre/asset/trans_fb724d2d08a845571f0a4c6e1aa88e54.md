## 21.6 应用于支持 D2D 通信的单小区网络

### 21.6.1 实验设置
现在，我们展示了在启用 D2D 通信的单小区网络模型中，缓存启用 UE 的缓存仿真结果。在本节中，我们将 DRL 框架的性能与以下缓存算法进行比较：
* `Naive caching policy`: 在此策略中，假设每个用户的对文件的偏好为缓存启用的移动设备所知，并且设备缓存了 ![images](images/c21-i0154.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>C</mi></mrow></math> 最流行的文件。
* `Probabilistic caching policy`: 在此策略中，我们假设用户请求特定文件的概率是已知的，并且每次相应的缓存智能体做出决策时，它都会考虑该流行度分布，即对文件进行概率缓存。
