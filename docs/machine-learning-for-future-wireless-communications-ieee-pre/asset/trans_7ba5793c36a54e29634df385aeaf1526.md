
[表 17.1](#c17.xhtml#c17-tbl-0001) 显示，与 `PH` 和 `ACC-PH` 相比，`MIMO RV FTDNN` 建模所需的参数更少，而后者的系数数量随天线数量呈指数增长。本文作者提供了丰富的实验结果，比较了 `COMPM`、`PH` 和 `ANN` 方案在 `2×2` 和 `3×3` 配置下的建模性能，功率放大器工作频率为 `2.14 GHz`，并由 LTE 载波聚合信号激励，带宽分别为 `5 MHz` 和 `10 MHz`（即 LTE 101 总带宽分别为 `15 MHz` 和 `30 MHz`）。测试设置在 PA 的输入和输出端包含多个耦合器，以在两根或三根 Tx 天线之间产生相等和不相等的交叉耦合，分别为 `-15 dB` 和/或 `-20 dB`（即在不相等条件下，强和弱交叉耦合将被组合以演示 `ANN` 逆建模的泛化或有效性）。采用基于仪器的 Tx 硬件以控制 I 和 Q 不平衡并设置任意期望的 `IRR` 值（即 `4-degree` 相位不平衡，以及相对于主信号的 `-20 dB IRR` 和 DC 偏移）。针对 `2×2` 和 `3×3` 配置，在有无 I/Q 调制器缺陷的情况下并考虑 `-15 dB` 耦合进行了多次测试。当不考虑 I/Q 损伤并使用 `COMPM`、`PH` 和 `MIMO RV FTDNN` 模型时，每个模型都比前一个模型在 `NMSE` 上优 `2 dB`，在 `ACPR` 上优 `3 dB`（按从差到好的性能列出），因此 `COMPM` 与 `MIMO RV FTDNN` 之间存在 `4 dB NMSE` 和 `6 dB ACPR` 的差异。当存在 I/Q 调制器缺陷时，`COMPM` 和 `PH` 在所有水平上均表现出不可接受的性能。`MIMO RV FTDNN` 在 `NMSE` 和 `ACPR` 方面均比 `ACC-PH` 高出约 `3–4 dB`，在 `IRR` 方面高出 `1–2 dB`，同时采用显著更少的 HW 资源（即 `2×2` 时系数减半，`3×3` 时为十分之一）。

## BPLA 算法比较
考虑到先前提出的 BPLA 技术分类以及单天线 `RV FTDNN`，Rawat 等人在 ([2010](#c17.xhtml#c17-bib-0095)) 中还评估了算法在 `50 epochs` 后的建模性能，衡量指标为 `MSE`。结果显示，标准数值优化技术（`LM`、`BFG` 和 `CGB`）显著优于传统的梯度下降方法（`RP`、`GDX`、`GDA` 和 `GDM`）。`LM` 无疑是最好的选择，也是达到最高建模性能值（即低于 `-65 dB MSE`）所需 epoch 最少的算法（即约 `15` 个）。在 `50 epochs` 时，`LM` 其后是 `BFG`（`MSE` 恶化超过 `10 dB`）和 `CGB`（`MSE` 恶化超过 `20 dB`）。除非将 epoch 数大幅增加从而消耗无法承受的时间，否则传统的梯度下降方法无法提供足够好的建模性能（即在 `50 epochs` 训练时与 `LM` 相比 `MSE` 恶化 `30` 至接近 `50 dB`）。Mkadem 和 Boumaiza ([2011](#c17.xhtml#c17-bib-0075)) 中所示的另外两个可评估参数是学习率和动量率。首先，应用不同的恒定学习率以获得以 `NMSE` 表示的建模性能。随后评估动态学习率，将初始值与递增率和递减率结合。确定最佳学习率策略后，对动量项进行类似测试以再次选择最佳选项。所报告的结果显示 `NMSE` 差异约为 `1–2 dB`，但未说明选择不同选项时对训练周期长度的影响，而这也是需要考虑的另一个因素。

## 训练信号
在 Rawat 等人 ([2010](#c17.xhtml#c17-bib-0095)) 中，考虑了不同的 `WCDMA` 信道聚合组合。在信号带宽或频谱占用可能随时间变化的场景中，使用合适的训练信号训练 `ANN` 很重要。例如，在使用 `5 MHz` 带宽信道且 `WCDMA` 中最多聚合四个信道时（即 `1111` 等价于聚合四个 `5 MHz` 带宽信号，总带宽为 `20 MHz`），使用较低带宽信道聚合的 `WCDMA` 信号训练网络会导致逆模型建模变差（即在 DPD 应用中）。正如预期的那样，总体带宽越高，在带内噪声越高，`MSE` 指标越低；然而，取决于训练信号的频率或带宽占用，特定的验证信号配置可能导致逆建模性能在 `MSE` 上相差高达 `5 dB`。使用 `WCDMA 1111` 训练并用 `WCDMA 1` 验证会得到良好结果，但使用 `WCDMA 1` 训练并用 `WCDMA 1111` 验证会导致建模性能下降（意味着会变差但不一定不足）。Jaraut 等人 ([2018](#c17.xhtml#c17-bib-0049)) 还证明了训练信号长度与用于验证的长度相比可能对逆建模结果产生影响，因为更大的训练信号更能代表待建模的物理现象。在该参考文献中，比较了使用 `40000` 个采样波形训练时的逆建模性能，不同验证信号长度均大于训练长度。在这种情况下，验证信号长度与训练时相同以及验证信号大三倍的实验，仅带来 `1 dB NMSE` 的差异。这是因为训练信号已足够好地捕捉了动态非线性现象。如果比较采用更短长度的训练信号，结果可能会有更大差异。

## 激活函数
Mkadem 和 Boumaiza ([2011](#c17.xhtml#c17-bib-0075)) 中的作者展示了在对第一和第二隐藏层组合不同激活函数时，所研究 `ANN` 的一些 `NMSE` 结果。第一隐藏层使用线性函数和对称饱和线性函数（再次注意，在此情况下 `RV RNN` 被重新表述为 `FNN`），而第二层使用 `log-sigmoid` 和 `hyperbolic tangent sigmoid`。将对称饱和线性函数与 `hyperbolic tangent sigmoid` 结合可获得最佳 `NMSE`（比其他组合高 `3.5 dB`）。
