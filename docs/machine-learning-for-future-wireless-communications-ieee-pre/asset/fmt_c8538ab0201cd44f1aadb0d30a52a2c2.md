
The link establishment has enabled the agent to collect environment information including the past and the current channel states, extracted network features, and so on. Although the environment state can be determined by various features, as an example of one possible solution, the received `SNR` averaged over all subcarriers is used to determine the state of the environment (Leite et al., [2012](#c09.xhtml#c09-bib-0014)). Due to the constraint that the state value should belong to a finite set, we consider `SNR` values in the range from ‐2–20 dB with step of 1 dB to avoid dealing with an infinite number of states. As a result, a total of ![images](images/c09-i0340.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>n</mi><mo>=</mo><mn>23</mn></mrow></math> states are used to determine the environment. At each single state ![images](images/c09-i0341.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>s</mi></mrow></math>, the agent chooses one action from a finite action set, and different actions lead to different expected rewards. Since the channel link may be time‐varying, the agent must continually track and update the value of ![images](images/c09-i0342.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>Q</mi><mo stretchy="false">(</mo><mi>s</mi><mo>,</mo><mi>a</mi><mo stretchy="false">)</mo></mrow></math>, embodying the real‐time compatibility of the `RL` approach. To maximize the achievable throughput, the agent must search and find the optimal `MCS` for a given state of the channel environment.
