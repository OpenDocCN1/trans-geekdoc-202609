
频谱感知在认知无线电系统中具有重要意义，因为它用于预测给定通信频道的可用性，并在主用户（授权用户，PUs）未通信时允许次级（未授权）用户（SUs）接入频段。因此，频谱感知能够协商网络资源，缓解频谱的未充分利用（Shokri‐Ghadikolaei et al., [2012](#c06.xhtml#c06-bib-0035)）。然而，这种感知能力在许多场景中会消耗相当多的能量，因为主用户的活动可能高度动态。因此，能效 EE 技术变得非常必要（Li, [2010](#c06.xhtml#c06-bib-0026)）。基于此，本节概述基于机器学习 ML 的认知无线电系统的能效资源分配技术。

机器学习 ML 为无线通信系统中的资源分配管理提供了一个有吸引力的选择，因为传统功率分配算法的主要缺点之一是对瞬时信道状态信息 CSI 的需求，有时这可能不切实际。与此同时，例如神经网络 NNs 的使用具有无需关于环境的先验知识或假设即可进行优化的优势，仅使用先前收集的数据即可。例如，频谱感知场景中的一个关键权衡与次级用户的发射功率有关。一方面，发射功率越高，次级用户可获得的性能越好。另一方面，主用户和邻近次级用户的干扰也会增加（Chen et al., [2013](#c06.xhtml#c06-bib-0010); Ghasemi and Sousa, [2008](#c06.xhtml#c06-bib-0021)）。

在此背景下，（Chen et al., [2013](#c06.xhtml#c06-bib-0010)）的工作采用强化学习 RL 方法以在认知无线电网络中分配功率。奖励函数设计为最小化能量消耗，因此算法能够提高网络能效 EE。也属于强化学习领域，（Al‐Rawi et al., [2014](#c06.xhtml#c06-bib-0002)）中作者尝试提高认知无线电网络的路由效率并最小化干扰。虽然大多数频谱感知方案侧重于为次级用户选择最佳路由，但这项工作侧重于通过选择主用户与次级用户之间干扰最小的路由来改善主用户网络。所提出的方法通过最小化干扰量提高了能效 EE。此外，（Tumuluru et al., [2010](#c06.xhtml#c06-bib-0038)）还提出了一种旨在最小化干扰的神经网络解决方案，使频谱利用率提高了超过 60%，与不允许频谱感知的情形相比，感知能量减少的百分比最高可达 51%。

## 6.4 未来趋势与挑战

本节讨论机器学习技术在未来无线网络能效提升应用中的一些趋势和挑战。

### 6.4.1 深度学习

深度学习算法是机器学习工具的重要分支（Goodfellow et al., [2016](#c06.xhtml#c06-bib-0022)）。深度学习与其他机器学习技术的区别在于所采用的神经网络非常密集，输入层和输出层之间有许多神经元层。此外，结合这种复杂的计算结构，可以处理大量数据以训练神经网络。因此，对于无线通信网络而言，此类技术的兴趣最近有所增长，因为密集的 5G 场景可能拥有大量可用数据，这为深度学习算法提供了丰富的训练来源，从而能够开发强大的监督方法（Zappone et al., [2018b](#c06.xhtml#c06-bib-0048)）。

例如，（Wang et al., [2017](#c06.xhtml#c06-bib-0040)）是首批采用基于深度神经网络模型对城市规模的蜂窝流量进行预测并使用大规模真实世界数据集的研究之一。实验结果表明，所提出的方法在预测性能方面优于传统方法，如 ARIMA、长短期记忆 LSTM、聚合蜂窝流量 GNN-A 和朴素预测模型，而空间依赖性和因素的相互作用在流量预测的准确性和鲁棒性中发挥着重要作用。这表明在未来，随着移动互联网的爆炸式增长和不断演变的流量模式，将出现新的挑战和机遇。Zappone et al.（[2018b](#c06.xhtml#c06-bib-0048)）还提出了一种深度学习方法以最大化无线网络的能效 EE。结果将该方案与分析最优解进行了比较，表明使用深度学习方法可实现接近最优的结果——在能效 EE 方面接近最优值的 95%——但计算复杂度要低得多。
