
In the gradient descent algorithm, the cost of calculating the partial derivatives is ![images](images/c12-i0115.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>O</mi><mo stretchy="false">(</mo><mi>M</mi><mo stretchy="false">)</mo></mrow></math>, with the result that the loss function is related to all the training examples. This may be expensive when the training set is large, which is necessary for good generalization. To reduce the complexity, the stochastic gradient descent algorithm (Goodfellow et al., [2016](#c12.xhtml#c12-bib-0024)) has been developed as a variant of the gradient descent algorithm. In the stochastic gradient descent algorithm, ![images](images/c12-i0116.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msup><mi>M</mi><mo>&#8242;</mo></msup></mrow></math> uniformly chosen examples are used to estimate the whole data set, where ![images](images/c12-i0117.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msup><mi>M</mi><mo>&#8242;</mo></msup></mrow></math> is called the *minibatch size* and is usually much smaller than ![images](images/c12-i0118.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>M</mi></mrow></math>. In this way, we may fit a training set with millions of examples using updates computed from a smaller number of examples, while the cost of calculating the partial derivative is reduced to ![images](images/c12-i0119.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>O</mi><mo stretchy="false">(</mo><msup><mi>M</mi><mo>&#8242;</mo></msup><mo stretchy="false">)</mo></mrow></math> instead of ![images](images/c12-i0120.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>O</mi><mo stretchy="false">(</mo><mi>M</mi><mo stretchy="false">)</mo></mrow></math>.

Another drawback of the gradient descent algorithm is that it may be trapped at a local minimum. However, (Goodfellow et al., [2016](#c12.xhtml#c12-bib-0024)) argued that many ML models can work well when they are trained with the gradient descent algorithm. Furthermore, the authors pointed out that even though it's not guaranteed to find the global minimum within a reasonable time, the algorithm can usually quickly find the value of the loss function, which is low enough for practical purposes. Hence, this property makes the gradient descent algorithm practically useful.
