## 3.2 System Model and Problem Formulation
The model presented here is generic and embraces distinct model elements for the network, the association scheme, the antenna and channel models, and models for beamforming and coordination.

### 3.2.1 Models

#### 3.2.1.1 Network Model
We consider a general multi‐user, multi‐cell, multi‐operator network. The network consists of ![images](images/c03-i0016.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>Z</mi></mrow></math> operators, each operating a (sub)set ![images](images/c03-i0017.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mrow><mi mathvariant="script"> B</mi></mrow><mi>z</mi></msub></mrow></math> of the BSs in the network, where it is assumed that each BS belongs to an operator, and no BS is shared among operators. The set of all UEs is denoted by ![images](images/c03-i0018.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi mathvariant="script"> U</mi></mrow></math>, and ![images](images/c03-i0019.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mrow><mi mathvariant="script"> U</mi></mrow><mi>z</mi></msub></mrow></math> is the set of all UEs of operator ![images](images/c03-i0020.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>z</mi></mrow></math>. Finally, we let ![images](images/c03-i0021.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>W</mi></mrow></math> be the total bandwidth available in the network and ![images](images/c03-i0022.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi>W</mi><mi>z</mi></msub></mrow></math> be that of operator ![images](images/c03-i0023.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>z</mi></mrow></math>.
