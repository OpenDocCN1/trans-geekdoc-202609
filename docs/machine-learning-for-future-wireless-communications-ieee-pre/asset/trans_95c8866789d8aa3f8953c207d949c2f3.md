
# 时空移动性预测框架

## 引言

请注意，时空序列预测问题与传统的时间序列预测问题不同，因为前者的预测目标是一个包含空间和时间结构的序列。

## 框架概述

为了解决这个问题，时空移动性预测框架在 [图 7.11](#c07.xhtml#c07-fig-0011) 中给出，主要包含预处理模块和时空预测模块。
