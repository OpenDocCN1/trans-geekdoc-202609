
其中 `W` 为总系统带宽，单位为 Hz，而 `η_BW` 为对应所选调制与编码方案的带宽效率。为满足 DP `m` 的数据需求，小区 `k` 至少需要利用其可用资源的 `d_m / R_km` 分数。DP 到小区的分配以下述二值矩阵 `A` ∈ `{0,1}^{K×M}` 表示，其元素定义为

(5.3)
```
A_km = { 1 if DP m is allocated to cell k
         0 otherwise. }
```

小区 `k` 的资源消耗 `Φ_k` 是衡量小区为服务其分配的所有 DP 的需求所消耗的总资源比例的指标。其定义为

(5.4)
```
Φ_k = Σ_{m ∈ M} A_km * d_m / ( η_BW * W * log2(1 + γ_km) )
```

当资源消耗超过一时，小区 `k` 被认为过载，即 `Φ_k ≥ 1`。该条件对小区 `k` 的违反表明，小区可用的时频资源总量不足以服务其所有用户需求。如果可用的时频资源超过满足用户需求所需的资源，小区可以降低所有资源上的发射功率，或在选定的资源子集上静默传输。这会降低网络中的干扰。此外，根据用户分配，可能存在不为任何 DP 提供服务的小区。在这种情况下，整个基站可以被静默，从而完全消除该小区在数据和控制信道上引起的干扰。在本章中，为简化起见，我们考虑文献中常用的最坏情况设计（Majewski and Koonert, [2010](#c05.xhtml#c05-bib-0044); Caballero et al., [2017](#c05.xhtml#c05-bib-0014)），其中做出以下最坏情况干扰假设：

* **(A1)** **始终激活：** 假设小区始终处于激活状态，因此不考虑小区的开/关切换。

* **(A2)** **满载：** 我们假设 DP 缓冲区已满并且始终使用其所有可用资源。

在假设 (A1) 和 (A2) 下，小区对网络中 DP 产生的干扰与基站的负载无关。*始终开启* 假设例如是 LTE 和 LTE-A 基站的要求，即即使在没有用户连接的情况下也需要传输控制信道。细胞可以开关的更复杂的干扰模型已在类似框架下得到研究（Bahlke et al., [2018](#c05.xhtml#c05-bib-0012)）。满载假设也简化了模型，其动机在于希望获得一种稳健的最坏情况设计，为信道条件和网络流量的瞬时波动留下足够的裕度。非满载情况已在文献中研究（You and Yuan, [2017](#c05.xhtml#c05-bib-0064); Siomina and Yuan, [2012a](#c05.xhtml#c05-bib-0056)）。需要注意的是，基于监督学习的资源分配方法可以扩展到更不保守的网络运行设计中，在这些设计中，最坏情况干扰假设 (A1) 和 (A2) 不适用。
