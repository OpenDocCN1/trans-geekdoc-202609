在性能分析中，我们假设无线信道 ![images](images/c09-i0083.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi mathvariant="bold">H</mi><mi>n</mi></msub></mrow></math> 经历准静态块衰落，即信道状态在一个数据包内的所有 OFDM 符号上保持恒定，但对不同数据包是独立的。除此假设外，(Daniels et al., [2008](#c09.xhtml#c09-bib-0006)) 中提出的以下假设也在我们的分析中采用：

* `Fixed packet length`: 所有数据包均设为 128 字节。因此，对于给定的误码率，所有数据包具有相同的期望 PER。
* `Perfect synchronization`: 所有数据包在时域和频域均实现完美同步。因此，任何时间和频率偏移均可忽略。
* `Estimation`: 与 (Daniels et al., [2008](#c09.xhtml#c09-bib-0006)) 不同，我们假设噪声功率和信道估计在接收端进行。对应于 IEEE 802.11n，传统长训练域 (L-LTF) 符号用于估计噪声功率，而高速吞吐量长训练域 (HT-LTF) 用于估计信道状态。
* `Linear equalization`: 接收端采用线性零迫 (ZF) 等化器来对抗符号间干扰 (ISI)。
