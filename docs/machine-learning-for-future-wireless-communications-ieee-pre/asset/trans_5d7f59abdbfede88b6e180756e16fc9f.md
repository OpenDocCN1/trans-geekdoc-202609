# 前言

由于其强大的非线性映射和分布处理能力，基于深度神经网络的机器学习技术正被视为应对无线通信与网络面临的巨大挑战的非常有前景的工具，该挑战源于容量、覆盖范围、延迟、效率（功率、频谱和其他资源）、灵活性、兼容性、体验质量以及硅集成等方面需求的爆炸性增长。主要分为监督学习、无监督学习和强化学习，各种机器学习（ML）算法可用于在毫米波和太赫兹频段提供更好的信道建模和估计；在大规模多输入多输出（MIMO）技术中选择更自适应的调制（波形、编码率、带宽和滤波结构）；设计更高效的前端和射频处理（用于功率放大器补偿的预失真、波束成形配置和峰值因子降低）；为全双工传输和设备到设备通信的自干扰消除提供更好的折中；并为与无线大数据、关键任务通信、大规模机器类型通信和触觉互联网相关的智能网络优化、移动边缘计算、网络切片和无线资源管理提供更实用的解决方案。

事实上，无线通信中机器学习技术的开发正在爆炸式增长，已成为相关学术、研究和工业界的最大趋势之一。这些新应用可分为三类：（i）基于机器学习的频谱智能和自适应无线资源管理；（ii）基于机器学习的传输智能和自适应基带信号处理；（iii）基于机器学习的网络智能和自适应系统级优化。所有这些新应用的成功开发和部署将具有挑战性，需要工业界、学术界、标准化组织和监管机构付出巨大努力。

从实际应用和研究发展的角度来看，本书旨在成为第一部单卷著作，对与无线通信和网络中机器学习相关的所有技术方面提供全面且高度连贯的处理，涵盖系统架构和优化、物理层和跨层处理、空口和协议设计、波束成形和天线配置、网络编码和切片、小区接入和切换、调度与速率适配、无线接入控制、智能主动缓存以及自适应资源分配。

本书分为 21 章，共 3 部分。

## 第 1 部分：频谱智能与自适应资源管理

第一部分由八章组成，介绍了机器学习在动态频谱接入（DSA）和共享、认知无线电管理与分配、覆盖与容量优化、流量与移动性预测、能效最大化和智能数据传输方面的使用等所有技术细节。

针对高效接入和自适应共享的先进机器学习算法，[第 1 章](#c01.xhtml) 通过涵盖基本原理、数学模型、全局优化准则、学习规则和速率、分步算法以及示意性处理流程，对不同实际应用场景和真实环境中的频谱智能概念进行了全面介绍。更具体地说，本章介绍的关键技术方面是如何采用先进的机器学习算法通过持续监控无线性能并审慎调整传输参数来动态学习环境，从而实现未来无线通信和网络的系统级最优频谱使用和资源效率。

[第 2 章](#c02.xhtml) 专门研究各种强化学习（RL）算法在自适应无线资源管理中的应用，重点关注认知无线电网络中的分布式资源分配。与传统的 DSA 方法相比，基于强化学习的技术可以提供与认知循环方法保持一致的优势，以及在无需系统模型先验知识的情况下实现跨层资源分配的灵活性。以平均意见分为关键体验质量指标，本章深入研究了与 Q 学习和深度 Q 网络相关的个体学习和协作学习对资源分配性能和收敛时间的影响。
