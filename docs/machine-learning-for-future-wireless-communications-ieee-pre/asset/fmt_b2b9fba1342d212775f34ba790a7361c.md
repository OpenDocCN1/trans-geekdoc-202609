### 10.3.2 Parametric Learning
The weakness of non‐parametric approaches (`eMLD`, `MMD`) is that they cause high computational complexity. In both methods, the receiver should compute all distances in the training set (![images](images/c10-i0062.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mo stretchy="false">&#124;</mo><mi mathvariant="script"> D</mi><mo stretchy="false">&#124;</mo><mo>=</mo><mi mathvariant="script"> M</mi><mo>&#215;</mo><mi>T</mi></mrow></math>).
