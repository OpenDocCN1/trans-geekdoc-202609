
隐藏层的激活函数是 `ReLU`。在输出层之后使用 `sigmoid` 激活函数，这使得输出神经元的值被限制在零和一之间。这是由 `sigmoid` 函数的形状决定的。如果网络输出的结果更接近于零，则该估计比特可以被认为是零。如果网络输出的结果更接近于一，则该估计比特可以被认为是一。

`DNNs` 本质上描述了一种高度可并行化的结构，能够实现一次性解码。该实验中有两种类型的码：随机码和极化码。它们代表不同的编码方案：非结构化编码和结构化编码。该方法是在一个特定的 `SNR` 点训练所有 ![图像](images/c14-i0006.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msup><mn>2</mn><mi>k</mi></msup></mrow></math> 可能的序列，并在不同的 `SNR` 点测试随机的 0-1 序列以展示泛化能力。

仿真结果如图 [14.6](#c14.xhtml#c14-fig-0006) 和 [14.7](#c14.xhtml#c14-fig-0007) 所示。可以看出，对于两种码族，随着训练轮数的增加，最大后验 (`MAP`) 与 `NND` 性能之间的差距越小。而对于极化码，在 ![图像](images/c14-i0007.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi>M</mi><mrow><mi>e</mi><mi>p</mi></mrow></msub><mo>=</mo><msup><mn>2</mn><mn>20</mn></msup></mrow></math> 时已接近 `MAP` 性能。仿真结果表明，具有确定性编码结构的极化码比随机码更易被神经网络学习。

### 14.2.2 可扩展深度学习方法

不幸的是，之前方法的局限性在于其训练复杂度：对于长度为 ![图像](images/c14-i0008.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>N</mi></mrow></math> 且码率为 ![图像](images/c14-i0009.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>r</mi></mrow></math> 的短码，存在 ![图像](images/c14-i0010.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msup><mn>2</mn><mrow><mi>N</mi><mo>&#42;</mo><mi>r</mi></mrow></msup></mrow></math> 个不同的码字；也就是说，训练复杂度随着码长增加而呈指数增长。因此在实际训练中，由于计算机性能的限制，神经网络可能无法完全训练。因此，之前 `NND` 使用的码长限制为 16。

为了解决这个问题，(Cammerer et al., [2017](#c14.xhtml#c14-bib-0003)) 中的作者提出了一种可扩展的方法来解码中等长度的极化码。该方法基于 `NND` 与传统 `BP` 解码的结合。他们定义了可分区的码，其含义是每个子块可以独立解码。然后，每个子图通过剩余的 `BP` 结果与其他子块耦合。整个分区神经网络 (`PNN`) 解码结构如图 [图14.8](#c14.xhtml#c14-fig-0008) 所示。

该结构由许多独立的 `NND` 网络组成，与之前的 `NNDs` 相同。`NND` 结构的输入是经过数个阶段传播的 `LLR` 值。然后首先对第一个 `NND` 块进行解码。解码后的比特被视为固定比特，例如 `LLR` 被设为无穷大。解码完第一个 `NND` 块后，剩余的块也可以使用此方法进行解码。采用这种结构，整个解码过程可以像流水线一样呈现。

通过使用该神经网络解码器，(Cammerer et al., [2017](#c14.xhtml#c14-bib-0003)) 中提出了使用中等码长 (128, 64) 的解码，其中作者还报告了使用八个分区提出的该解决方案的仿真结果和相应比较。每个块的码长为 16，信息比特数 ![图像](images/c14-i0011.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>k</mi></mrow></math> 不同。仿真结果表明，具有 `PNN` 的解码器可以实现与诸如逐次消除 (`SC`) 和逐次消除列表 (`SCL`) 等其他方法相似的 `BER` 性能。然而，由于分区造成的性能损失，该方法的解码长度仍然较短。读者可以参考 (Cammerer et al., [2017](#c14.xhtml#c14-bib-0003)) 查看更多仿真细节。
