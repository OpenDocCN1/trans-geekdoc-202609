### 9.3.3 Actions, States, and Rewards
Using the Markov process, ML‐assisted AMC systems can take actions based on the collected environment states and rewards to adapt to dynamically changing channel conditions. More details about the actions, states, and rewards are given as follows.

#### Actions
The target of AMC is to maximize throughput for a given state of the environment by adopting the modulation and coding schemes. In practical protocols such as IEEE 802.11n, there are only a finite number of modulation and coding schemes. Each scheme is considered an action, and the agent selects the optimal scheme based on past experiences just before packet transmission.
