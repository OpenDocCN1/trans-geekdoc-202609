
The resulting trees in will be used in the data‐transmission phase to efficiently reduce the search space according to a new observation ![images](images/c10-i0114.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi mathvariant="bold-italic">r</mi></mrow></math>. It is noticeable that the algorithm constructs multiple hierarchical trees having possibly different decomposition structures, and thus is able to improve the quality of a resulting reduced search space.

(A cluster size at the last hierarchical level can be called the size of the leaf node because the output structure of this process can be viewed as a tree: [Figure 10.7](#c10.xhtml#c10-fig-0007).) Also, the leaf node size equals branch factor ![images](images/c10-i0118.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>J</mi></mrow></math>. If we operate this process multiple times, several distinctive trees (forest) are constructed.

In order to help you understand `Algorithm 2`, we provide a simple example ([Figure 10.8](#c10.xhtml#c10-fig-0008)) that finds a reduced search space based on the structure built in the prior example ([Figure 10.6](#c10.xhtml#c10-fig-0006)). During the first search, the observation continues selecting the closest centroid at each level until it reaches a leaf node. The elements included in the leaf node are returned into the reduced search space (![images](images/c10-i0126.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi mathvariant="script"> S</mi><mo stretchy="false">(</mo><mi mathvariant="bold-italic">r</mi><mo stretchy="false">)</mo></mrow></math>). Moreover, the unselected centroids are put into the priority queue that sorts centroids in such an order that makes an efficient nearest‐neighbor search possible. For the second search, the same search method begins from the first node in the priority queue. This algorithm ends when it satisfies the predetermined size of the reduced search space (![images](images/c10-i0127.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mo stretchy="false">&#124;</mo><mi mathvariant="script"> S</mi><mo stretchy="false">(</mo><mi mathvariant="bold-italic">r</mi><mo stretchy="false">)</mo><mo stretchy="false">&#124;</mo></mrow></math>).
