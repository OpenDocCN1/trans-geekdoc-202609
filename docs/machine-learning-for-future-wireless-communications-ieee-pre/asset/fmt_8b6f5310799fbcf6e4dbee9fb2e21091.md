
### 11.4.1 The Canonical Iteration

We now proceed to pose the learning problem as a special case of the *convex feasibility problem* involving (possibly) countably infinitely many sets. This problem is then solved with a particular version of the *adaptive projected subgradient method* Yamada and Ogura ([2005](#c11a.xhtml#c11-bib-0008)).
