### 12.4.2 基于深度学习神经网络的均衡器

随着 `MLP` 变得更深，即具有更多隐藏层，其对复杂函数（如时变信道脉冲响应）的表示能力变得更强。因此，在 `DL` 的帮助下，本小节将 `MLP` 扩展为 `DL` `NN`，在此基础上进一步提出了一种信道均衡器。

#### 12.4.2.1 系统模型与网络结构

通过引入更多全连接隐藏层，`MLP` 被扩展为 `DNN`，其结构如图 [图 12.5](#c12.xhtml#c12-fig-0005) 所示。与其他神经网络一样，`DNNs` 可通过不同的任务进行训练以执行不同的功能。具体而言，当其以恢复经过信道失真的信号为任务进行训练时，`DNN` 能够学习信道特征，从而逼近均衡化函数，使接收信号接近期望信号。这样即可构建基于 `DNN` 的信道均衡器。

具有基于 `DNN` 的信道均衡器的广义通信系统架构如图 [图 12.6](#c12.xhtml#c12-fig-0006) 所示。在发送端，信息消息首先被编码，码字根据某种基带调制方案进行数字调制。调制后的符号随后发送到无线信道，其中可能经历不同的失真。在接收端，在数据解调和解码之前，使用基于 `DNN` 的信道均衡器来对抗信道失真。在图 [图 12.6](#c12.xhtml#c12-fig-0006) 中，`DNN` 通常在在线部署，即实际实时应用之前离线训练。网络训练的细节将在下一小节中提供。需要注意的是，在在线部署阶段，基于 `DNN` 的均衡器可以在没有显式信道估计的情况下恢复期望信号。
