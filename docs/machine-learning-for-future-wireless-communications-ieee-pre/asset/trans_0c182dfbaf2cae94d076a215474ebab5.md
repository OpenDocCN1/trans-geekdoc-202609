

在文献中，已使用多种不同的指标来定义 EE。最常见的方法是将 EE 定义为系统吞吐量与功耗之比，表示为 ![images](images/c06-i0001.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mo stretchy="false">\[</mo><mtext>bits</mtext><mo stretchy="false">/</mo><mtext>Joules</mtext><mo stretchy="false">\]</mo></mrow></math> (Feng et al., [2013](#c06.xhtml#c06-bib-0018))。基于该定义，文献中许多工作尝试根据特定应用或环境最大化 EE。例如，在蜂窝网络中，由于降低运营成本的潜力，EE 受到了大量关注 (Feng et al., [2013](#c06.xhtml#c06-bib-0018))。此外，无线通信中连接设备的指数级增长带来了严重的持续增长问题，因为碳排放激增至令人担忧的水平。因此，许多绿色蜂窝的早期研究显示了显著的 EE 改善，以支持用户需求并最大程度地减少这些负面影响 (Gandotra et al., [2017](#c06.xhtml#c06-bib-0020))。在这些大规模场景中，BSs 占总能耗的最大份额：高达 80%，原因是电源、冷却以及与电网的连接 (Auer et al., [2011](#c06.xhtml#c06-bib-0007))。

例如，(Richter et al., [2009](#c06.xhtml#c06-bib-0034)) 中的工作研究了不同 BS 布局对蜂窝网络能耗的影响，显示出在满载场景中微站部署带来的节能效果适中，并且强烈取决于宏站和微站的偏移功耗。该工作的扩展，发表于 (Fehske et al., [2009](#c06.xhtml#c06-bib-0017))，采用仿真评估了在传统宏站基础上部署微站的能耗，并显示微站的部署可显著降低网络功耗。EE 也已应用于其他类型的网络，例如无线传感器网络 (WSNs)。在 (Cui et al., [2004](#c06.xhtml#c06-bib-0012), [2005](#c06.xhtml#c06-bib-0013); Pereira et al., [2018](#c06.xhtml#c06-bib-0032)) 中，例如，作者已显示，当传输距离较大 (![images](images/c06-i0002.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mo>&#62;</mo><mn>100</mn></mrow></math> m) 时，发射功率占总功耗的主导地位。另一方面，对于极短距离应用 (![images](images/c06-i0003.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mo>&#60;</mo><mn>10</mn></mrow></math> m)，射频电路使用的功率可能占总功耗的主导地位。因此，对于每个场景都需要 WSNs 的适当功耗模型，并且优化 EE 的方法可能大不相同。

传统上，凸优化 (Xu and Qiu, [2013](#c06.xhtml#c06-bib-0041))、分数规划 (Zappone et al., [2015](#c06.xhtml#c06-bib-0046)) 和博弈论 (AlSkaif et al., [2015](#c06.xhtml#c06-bib-0004)) 等技术已被用于最大化无线网络中的 EE。此类方法试图找到解析解，优化诸如发射功率、调制阶数和操作模式等多种通信参数。然而，通常需要许多简化来推导这些表达式，因此通常仅考虑点对点场景。此外，几个不切实际的假设可能是这些解决方案的限制因素，因为其中许多通常需要移动网络中无法及时或现实地获得的信息，例如特定时间连接的用户数量或其确切位置。此外，由于连接设备数量和业务密度的增长以及它们异构的需求，未来蜂窝网络预计将变得更加复杂 (Valente Klaine et al., [2017](#c06.xhtml#c06-bib-0039))。由于这种复杂性，经典优化技术 (Zappone et al., [2015](#c06.xhtml#c06-bib-0046); AlSkaif et al., [2015](#c06.xhtml#c06-bib-0004); Xu and Qiu, [2013](#c06.xhtml#c06-bib-0041)) 的应用在未来网络场景中可能不可行。

为克服这些问题，很明显，随着网络变得越来越复杂，传统解决方案将不再最优。此外，更稳健、更灵活的解决方案更受青睐，这些解决方案能够探索网络生成的数据并实时做出决策。因此，能够分析大量数据并从中学习的技术，例如机器学习 (ML) 算法，可以成为未来网络的可行解决方案 (Valente Klaine et al., [2017](#c06.xhtml#c06-bib-0039))。

在本章中，介绍了 ML 算法在未来无线网络中关于 EE 的重要性和应用概述。本章在 [第 6.1 节](#c06.xhtml#c06-sec-0002) 开始，通过给出自组织网络 (SONs) 的简要定义以及在 EE 背景下涉及 ML 算法的一些相关解决方案。然后，在 [第 6.2 节](#c06.xhtml#c06-sec-0003) 和 [第 6.3 节](#c06.xhtml#c06-sec-0004) 中介绍了应用于更具体主题的 ML 技术概述，例如资源分配、业务预测和认知无线电网络。最后，在 [第 6.4 节](#c06.xhtml#c06-sec-0005) 中介绍了某些未来趋势并得出结论，强调了 ML 在未来网络中的重要性。总结起来，本章的目标可以描述如下：

*   概述近期文献中的 ML 方法，重点关注未来无线网络 EE 的最大化。
*   简要回顾最常见的 ML 技术，并突出这些技术的应用示例和目标。
*   识别当前设计中可能存在的困难，并阐述 ML 在节能无线网络方面的未来研究方向。
*   介绍 ML 可作为实现节能设计的有力工具的未来趋势。
*   列出使用 ML 技术以改善 EE 而带来的即将到来的挑战。

## 6.1 自组织无线网络

如 (Valente Klaine et al., [2017](#c06.xhtml#c06-bib-0039); Aliu et al., [2013](#c06.xhtml#c06-bib-0003)) 中所定义，SON 是一种能够自适应、可扩展、稳定、敏捷和自主的网络，以便管理和控制某些网络目标。因此，这些网络能够自主实时做出决策，并基于先前和历史数据学习和改进其性能。由于这种自动化，SONs 可以在网络内部提供智能，以便于运营商的工作并降低整体复杂性，为移动运营商提供显著的成本和节能。

SONs 可分为三个主要分支 (Valente Klaine et al., [2017](#c06.xhtml#c06-bib-0039); Aliu et al., [2013](#c06.xhtml#c06-bib-0003))：自配置、自优化和自愈，共同称为 *自-X 功能*。 [图 6.1](#c06.xhtml#c06-fig-0001) 说明了 SONs 在蜂窝网络中的一些应用，突出了三个主要的自-X 分支和常见的相关用例。在这种情况下，ML 技术 certainly 可以改进 SON，使网络能够通过观察其当前状态来适应，并利用这种经验在未来操作中调整参数。在这种意义上，改善 EE 可能是参数调整的主要指导原则之一。
