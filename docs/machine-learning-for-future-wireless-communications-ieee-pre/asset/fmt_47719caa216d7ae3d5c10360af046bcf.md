
# Gradient Descent

The basic principle behind the gradient descent algorithm is to use the derivative of the objective function to update the decision variables, so that the value of the objective function (or the cost) can be reduced.

Consider a function ![images](images/c12-i0098.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>r</mi><mo stretchy="false">(</mo><mi>x</mi><mo stretchy="false">)</mo></mrow></math> in the real domain, and denote its derivative as ![images](images/c12-i0099.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msup><mi>r</mi><mo>&#8242;</mo></msup><mo stretchy="false">(</mo><mi>x</mi><mo stretchy="false">)</mo></mrow></math>. Then, at the point ![images](images/c12-i0100.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>x</mi></mrow></math>, ![images](images/c12-i0101.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>r</mi><mo stretchy="false">(</mo><mi>x</mi><mo>+</mo><mi>&#949;</mi><mo stretchy="false">)</mo></mrow></math> for small ![images](images/c12-i0102.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>&#949;</mi></mrow></math> can be approximated as ![images](images/c12-i0103.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>r</mi><mo stretchy="false">(</mo><mi>x</mi><mo stretchy="false">)</mo><mo>+</mo><mi>&#949;</mi><msup><mi>r</mi><mo>&#8242;</mo></msup><mo stretchy="false">(</mo><mi>x</mi><mo stretchy="false">)</mo></mrow></math>. Furthermore, we can see that, provided ![images](images/c12-i0104.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mo stretchy="false">&#124;</mo><msup><mi>r</mi><mo>&#8242;</mo></msup><mo stretchy="false">(</mo><mi>x</mi><mo stretchy="false">)</mo><mo stretchy="false">&#124;</mo><mo>&#62;</mo><mn>0</mn></mrow></math>, ![images](images/c12-i0105.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>r</mi><mo stretchy="false">(</mo><mi>x</mi><mo>&#8722;</mo><mi>&#949;</mi><mtext>sign</mtext><mo stretchy="false">(</mo><msup><mi>r</mi><mo>&#8242;</mo></msup><mo stretchy="false">(</mo><mi>x</mi><mo stretchy="false">)</mo><mo stretchy="false">)</mo><mo stretchy="false">)</mo></mrow></math> is smaller than ![images](images/c12-i0106.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>r</mi><mo stretchy="false">(</mo><mi>x</mi><mo stretchy="false">)</mo></mrow></math>. In other words, the derivative gives the information to reduce the function value by introducing a small change in the variable ![images](images/c12-i0107.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>x</mi></mrow></math>. In this way, we may repeatedly update the variable using ![images](images/c12-i0108.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msup><mi>x</mi><mo>&#8242;</mo></msup><mo>=</mo><mi>x</mi><mo>&#8722;</mo><mi>&#949;</mi><mtext>sign</mtext><mo stretchy="false">(</mo><msup><mi>r</mi><mo>&#8242;</mo></msup><mo stretchy="false">(</mo><mi>x</mi><mo stretchy="false">)</mo><mo stretchy="false">)</mo></mrow></math> to derive the minimal value of the function as well as the point achieving this minimum value.
