
To find an edge‐caching policy for these two network models, let us consider an actor‐critic RL–based multi‐agent framework. In this framework, there are ![images](images/c21-i0014.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>N</mi></mrow></math> actor networks and one centralized critic network. We consider each local cache server an agent that adopts one of the actor networks to seek its own caching policy. And we assume there are control channels that allow local content servers to send the caching state and data traffic parameters to the upper‐level server, so that the upper‐level server can act as the centralized critic to evaluate the overall caching state. Similarly as in the study by Zhong et al. ([2018](#c21.xhtml#c21-bib-0040)), in each operation cycle, the agent can either keep the cache state the same or replace unpopular content files with the popular ones. However, since there can be more than one request arriving at a local content server at the same time, the agent needs to jointly decide which cached content will be deleted and which content requested by which user will be cached.
