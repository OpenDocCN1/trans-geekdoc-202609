## 4.1 Introduction

移动网络在过去几十年中不断扩展，其主要目标是为尽可能多的人口提供覆盖。传统上，由于用户密度高，城市地区是覆盖较好的区域，而远离城市的稀疏人口的农村地区往往覆盖有限。然而，随着持续的互联网可用性对许多用户而言变得越来越必要，移动运营商正在扩展其网络，以在偏远地区为用户提供更好的覆盖。与此同时，即使在通常覆盖良好的地区，人群的意外出现也会由于该区域网络容量的限制而降低每个用户的可用带宽。后一种情况下的趋势是通过过度配置来增加小区密度，以便在这些情况发生时在特别繁忙的地区提高总网络容量。

事实上，除了移动通信技术进步带来的改进之外，解决覆盖和容量问题的传统手段是通过向网络添加额外资源来实现的。从长远来看，这是一种昂贵的解决方案，在经济和环境上都变得不可持续。这些额外资源既包括物理元素，例如基站和核心网络升级，也包括增加的能源需求。

为了在仍为用户提供良好服务质量 QoS 的同时降低部署这些资源的成本，已经提出了几种网络覆盖与容量优化 CCO 技术。这些技术通常试图在两者之间取得权衡，主要是容量和覆盖。Phan 等人 (Phan et al., [2017](#c04.xhtml#c04-bib-0022)) 提供了关于 CCO 文献的良好综述。为此使用的技术包括为节省能源而打开和关闭基站 (Wu et al., ; Guo et al., [2016](#c04.xhtml#c04-bib-0010))，根据需求调整天线下倾角或功率 (Fehske et al., [2013](#c04.xhtml#c04-bib-0007); Gao et al., [2013](#c04.xhtml#c04-bib-0009))，通过将移动用户从拥挤的小区切换到不拥挤的小区来进行负载均衡 (Li et al., [2011](#c04.xhtml#c04-bib-0016))，以及天线放置优化技术 (Hafiz et al., [2013](#c04.xhtml#c04-bib-0011))。
