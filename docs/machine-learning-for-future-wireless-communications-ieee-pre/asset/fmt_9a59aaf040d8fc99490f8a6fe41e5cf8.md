Channel equalization is a classic, well‐known technique in telecommunication engineering, and considerable research has been done. Typical equalization algorithms include the `ZF` algorithm, `MMSE` algorithm, optimum `MLSE` algorithm, etc. Before introducing the `ML`‐based equalization algorithms, let us first briefly review the principles of these three equalizers.
