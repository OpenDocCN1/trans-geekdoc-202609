
本章全面介绍了人工神经网络（ANNs）应用在物理层带来的进展。为实现这一目标，我们首先向读者概述了无线通信网络中最常用的 ANN。接下来，我们讨论了 ANN 对设计用于信号情报收集的物理层的影响。认识到将这些技术扩展到硬件实现的重要性，我们讨论了一些可以采取的步骤，以确保这些技术迅速过渡到商用硬件。最后，我们讨论了一些需要解决的开放性问题，以进一步促进 ANN 在无线网络中的采用。本章的总体目标是为研究人员提供基本工具，使其能够理解 ANN 在无线通信信号情报背景下的应用，并让他们了解最新的进展，从而激发新的和现有工作。
