
我们在上一节中讨论的频谱接入算法主要集中于模型和目标依赖的问题设置，通常需要更复杂的实现（例如载波侦听、宽带监测），因此这些解决方案通常无法有效适应处理更复杂的现实世界模型。因此，本节概述了为克服这些问题而采用的基于深度学习的非常新近的发展。具体而言，我们现在关注模型无关的分布式学习算法来求解 ([1.9](#c01.xhtml#c01-disp-0009))，该算法能够有效适应网络拓扑、目标函数、时间范围（在此范围内求解动态规划变得非常具有挑战性，或对于大 ![images](images/c01-i0185.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>T</mi></mrow></math>）往往不可能）等的变化。然而，获得此处考虑的频谱接入问题的最优解是一个组合优化问题，其具有部分可观测的网络状态，随着网络规模的增大在数学上变得难以处理（Zhao et al., [2007](#c01.xhtml#c01-bib-0095)）。因此，本节概述了使用深度强化学习（`DRL`）方法的方法，因为它能够在处理非常大的状态和动作空间的同时提供良好的近似解。我们首先描述 `Q-learning` 和 `DRL` 的基本思想。然后我们概述 DRL 求解 DSA 问题的最新进展。

### 1.3.3.1 Q学习和深度强化学习（DRL）的背景：

`Q-learning` 是一种强化学习方法，旨在为动态规划问题找到良好的策略。它已广泛应用于各种决策问题，主要是因为它能够在无需事先了解系统模型的情况下评估可用动作中的期望效用，并且能够在随机转移发生时进行适应（Watkins and Dayan, [1992](#c01.xhtml#c01-bib-0087)）。该算法最初是为与完全可观测的马尔可夫环境交互的单智能体设计的（在这种情况下，在某些正则条件下收敛到最优解是有保证的）。它也已广泛应用于更复杂的情况（例如多智能体、非马尔可夫环境），并表现出强大的性能，尽管在这些设置下收敛到最优解通常仍是开放问题。假设我们可以将过程到时间 ![images](images/c01-i0186.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>t</mi></mrow></math> 的整个历史编码为系统所观测的状态 ![images](images/c01-i0187.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>s</mi><mo stretchy="false">(</mo><mi>t</mi><mo stretchy="false">)</mo></mrow></math>。通过将 `Q-learning` 应用于我们的设置，算法按如下方式在每个时间 ![images](images/c01-i0188.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>t</mi></mrow></math> 为每个动作-状态对更新 `Q-value`：
