The DPD function in the forward path described in Eq. ([17.8](#c17.xhtml#c17-disp-0008)) can be implemented to operate in real time in a programmable logic (PL) device following different approaches, such as look‐up tables (LUTs) (e.g. in Molina et al. ([2017](#c17.xhtml#c17-bib-0076)), Gilabert et al. ([2007](#c17.xhtml#c17-bib-0033))), complex multipliers following a polynomial approach using the Horner's rule as in Mrabet et al. ([2012](#c17.xhtml#c17-bib-0078)), or some combination of complex multipliers and memory blocks as in Cao et al. ([2017](#c17.xhtml#c17-bib-0012)).

Unlike the DPD in the forward path, the identification/adaptation of the parameters does not need to be carried out in real time, and thus it can be implemented in a processing system (PS). Therefore, the DPD coefficients can be extracted and adapted iteratively in a slower time scale than real time. The extraction of the DPD coefficients can be carried out following either a direct learning or an indirect learning approach.

The block diagram of a closed‐loop adaptive DPD architecture following an indirect learning approach is shown in [Figure 17.5](#c17.xhtml#c17-fig-0005). The DPD function in the forward path is described in Eq. ([17.8](#c17.xhtml#c17-disp-0008)) or, considering a matrix notation, in Eq. ([17.9](#c17.xhtml#c17-disp-0009)). However, with the indirect learning approach, the inverse PA model is estimated as a postdistortion. That is, the assumption made is that the coefficients of the postdistortion are equal to the coefficients of the predistortion; as mentioned in Braithwaite ([2015](#c17.xhtml#c17-bib-0007)), the approximation can be considered a valid approximation as long as there is no saturation in either the transmit path or observation path.

The block diagram of a closed‐loop adaptive DPD architecture following a direct learning approach is shown in [Figure 17.6](#c17.xhtml#c17-fig-0006). As explained in Braithwaite ([2015](#c17.xhtml#c17-bib-0007)), in comparison to the indirect learning approach, with the direct learning estimation we gain robustness against noisy PA output observations and avoid the offset of the coefficient vector from its optimal value.

### 17.2.4 Regularization

The method of `LS` performs well to approximate the solution of overdetermined systems when considering big datasets. However, it may face the risk of `underfitting` or `overfitting` (see [Figure 17.7](#c17.xhtml#c17-fig-0007)). An underfitted model lacks essential coefficients in the model description. On the contrary, an overfitted model contains more parameters than the model really needs. Both underfitted and overfitted models tend to misrepresent the training data and will therefore have poor predictive performance.
