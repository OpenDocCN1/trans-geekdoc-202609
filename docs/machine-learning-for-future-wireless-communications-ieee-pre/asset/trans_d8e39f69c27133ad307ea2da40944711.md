
在提出的 `RCLSTM` 模型中，神经元是随机连接的，而不是像 `LSTM` 中那样全连接。实际上，`LSTM` 中的可训练参数仅存在于输入部分——当前时刻的输入（即 ![images](images/c07-i0040.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi mathvariant="bold">x</mi><mi>t</mi></msub></mrow></math>）与前一时刻的输出（即 ![images](images/c07-i0041.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi mathvariant="bold">h</mi><mrow><mi>t</mi><mo>&#8722;</mo><mn>1</mn></mrow></msub></mrow></math>）的组合，以及功能部分——门控层和输入更新层的组合之间。因此，`LSTM` 架构可以进一步在 [图 7.4](#c07.xhtml#c07-fig-0004) 中描述，这表明 `LSTM` 神经元是否连接可以通过一定的随机性来决定。如 [图 7.4](#c07.xhtml#c07-fig-0004) 上部所示，使用虚线表示可以添加或省略的神经连接。如果神经元是全连接的，则成为标准 `LSTM` 模型。另一方面，如果神经元根据随机生成的概率值进行连接，则创建 `RCLSTM` 模型。[图 7.4](#c07.xhtml#c07-fig-0004) 的右下部分显示了一个示例 `RCLSTM` 结构，其中神经连接是随机稀疏的，与 `LSTM` 模型不同。

基于提出的 `RCLSTM` 块，Hua 等 ([2018](#c07.xhtml#c07-bib-0011)) 构建了一个与 `LSTM` 网络在 [图 7.3](#c07.xhtml#c07-fig-0003) 中相似的三层 `RCLSTM` 网络；但循环记忆块被 `RCLSTM` 块取代，用于仿真验证 `RCLSTM` 对交通预测的性能。仿真结果显示在 [图 7.5](#c07.xhtml#c07-fig-0005) 和 [7.6](#c07.xhtml#c07-fig-0006) 中。[图 7.5](#c07.xhtml#c07-fig-0005)a 描述了 `RCLSTM` 模型在不同神经连接百分比下的 `RMSE` 和计算时间（注意 100% 连接意味着全连接的 `LSTM` 模型），这表明 `RCLSTM` 模型的性能略低于 `LSTM` 模型；但具有非常稀疏神经连接（即 1%）的 `RCLSTM` 与基线 `LSTM` 相比可将计算时间减少约 30%。[图 7.5](#c07.xhtml#c07-fig-0005)b 直观地说明了实际交通值和预测交通值，可以观察到预测值能够很好地匹配实际值的变化趋势和特征。[图 7.5](#c07.xhtml#c07-fig-0005)c 和 d 显示了 `RCLSTM` 模型的预测能力如何受训练样本数量和输入交通序列长度的影响。可以从 [图 7.5](#c07.xhtml#c07-fig-0005)c 观察到，`RCLSTM` 模型对训练样本数量比 `LSTM` 更敏感，因为当训练样本数量增加时，`RCLSTM` 模型的 `RMSE` 比 `LSTM` 模型变化更显著。[图 7.5](#c07.xhtml#c07-fig-0005)d 给出了相关结果并显示 `RCLSTM` 模型比 `LSTM` 模型受输入序列长度的影响更小。最后，[图 7.6](#c07.xhtml#c07-fig-0006) 是 `RCLSTM` 与四种知名预测技术 `SVR`、`ARIMA`、`FFNN` 和 `LSTM` 的比较。这些结果表明，记忆单元大小为 300 的 `LSTM` 的性能远优于其他方法，其次是记忆单元大小为 300 且神经连接为 1% 的 `RCLSTM`。总之，`RCLSTM` 模型在性能和计算时间方面是一种极具竞争力的交通预测解决方案。
