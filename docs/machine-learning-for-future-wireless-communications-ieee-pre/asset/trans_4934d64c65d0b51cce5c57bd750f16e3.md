## 2.3 协作学习与资源分配

本章中出现的认知 `SUs` 在运行 `Q-learning` 算法学习无线环境以及不同动作的奖励/惩罚后执行资源分配。无论算法是基于 `Q-table` 还是 `DQN` 方法，从宏观角度来看，这些算法的功能都是学习动作与无线环境之间的关系，随着学习算法的进展，该关系以更高的精度表示。该关系要么表示为存储在 `Q-table` 中的 Q 值，要么表示为表征 `DQN` 中 Q 函数的神经网络参数。由于无线环境的一部分涉及背景噪声以及每个 `SU` 对系统其余部分造成的干扰，`Q-table` 或 `DQN` 参数将反映每个 `SU` 的个体局部无线环境以及系统组件之间的集体相互关系。因此，研究不同 `SUs` 表示动作与环境之间关系的方式的差异和相似性是值得的。

对于 `Q-learning` 的 `Q-table` 方法，[`Figure 2.3`](#c02.xhtml#c02-fig-0003) 显示了两个 `SUs` 的 `Q-tables` 随它们之间距离变化的比较。`Q-tables` 通过计算对应于相同动作的 `Q-tables` 元素之间的相对差异的平均值来进行比较。该比较在具有 16 个 `SUs` 的网络上对 `Q-learning` 算法进行了 10,000 次运行，每次运行对应于 `SUs` 的不同随机位置（进一步的网络设置细节将在后面介绍）。结果以平均相对差异的统计频率值形式呈现。该图显示了 `Q-tables` 随着 `SUs` 靠近而变得更相似的预期结果。对于小于 100 米的距离，`Q-tables` 平均差异小于 10% 的概率接近 50%。更有趣的是，该图显示，即使对于相距很远的 `SUs`，其 `Q-tables` 平均差异在 10% 或更小的概率仍然显著。这是因为 `Q-tables` 不仅包含每个 `SU` 的局部环境信息，还包含整个网络组件的相互作用信息。
