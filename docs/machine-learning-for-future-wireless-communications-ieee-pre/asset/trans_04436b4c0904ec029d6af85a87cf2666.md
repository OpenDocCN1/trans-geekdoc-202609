
为了实现 5G 及后续无线通信网络代所宣称的性能增益，需要对整体网络运行进行显著增强（Andrews et al., [2014](#c05.xhtml#c05-bib-0006)；Boccardi et al., [2014](#c05.xhtml#c05-bib-0013)）。与 5G 相关的全新业务（ITU, [2017](#c05.xhtml#c05-bib-0034)；Shafi et al., [2017](#c05.xhtml#c05-bib-0055)；Iwamura, [2015](#c05.xhtml#c05-bib-0035)）即使对于位于小区边缘且处于严重干扰下的移动用户，也表现出严格的服务质量（QoS）和网络连通性要求。除了将所用频率扩展到毫米波范围（Ghosh et al., [2014](#c05.xhtml#c05-bib-0024)；Rappaport et al., [2013](#c05.xhtml#c05-bib-0052)）以及部署大规模多输入多输出（MIMO）天线阵列（Larsson et al., [2014](#c05.xhtml#c05-bib-0039)）之外，第三个重要的资源域也受到了显著关注：网络架构的空间密度增加。利用上述方法所实现的整体网络容量提升，关键取决于与每项技术相关的单个性能增益是否能够在协同作用下并在大覆盖范围内累积。对此问题的肯定回答需要对异构多小区网络的无线资源管理取得进展。这已被确定为超密集无线网络运行中的一个挑战（Andrews et al., [2016](#c05.xhtml#c05-bib-0007)），尤其是当相应的网络架构需要基于局部信道状态信息（CSI）和有限的小区间协调的分布式网络控制时（Ye et al., [2013](#c05.xhtml#c05-bib-0063)；You and Yuan, [2017](#c05.xhtml#c05-bib-0064)）。

多小区网络中的网络管理和资源优化通常与二元或整数决策相关，其中例如用户被分配到基站，离散时频资源被分配给移动设备（Cheng et al., [2013](#c05.xhtml#c05-bib-0018)；Cheng and Pesavento, [2015](#c05.xhtml#c05-bib-0017)；Liu and Fan, [2018](#c05.xhtml#c05-bib-0041)；Alfa et al., [2016](#c05.xhtml#c05-bib-0005)）。由于当今蜂窝网络从根本上受干扰限制，相关的整数规划问题通常具有组合性质，其中优化的目标是在网络中的参与者之间权衡相互冲突的利益（即移动用户、基站、子网络等），并且解在最好情况下也仅是局部帕累托最优。严格数学意义上的最优网络管理对于大型网络而言已知在实践中不可行，因为相应的整数规划问题随网络规模扩展而表现不佳，通常具有禁止性的计算复杂度，因此不适合在线运行。此外，由于延迟要求和网络实体之间有限的控制信息交换，实际多小区网络中的决策需要在分布式方式下并仅基于部分 CSI 进行。因此，严格最优的资源分配作为整数规划公式的解，仅用作小到中等规模网络场景在集中控制下的基准。

实际上，大规模多小区网络的资源管理通常以严格次优的方式进行，并基于工程启发式方法。过去，工程师基于工程直觉、真实网络数据分析和广泛的系统级建模与仿真，开发了用于优化网络运行的复杂决策规则。在此背景下，机器学习 ML 成为一个有前景的工具，有可能弥合两个世界之间的差距：一个来自实际应用，对分布式决策和在线网络优化的要求；另一个来自性能角度，希望获得具有潜在巨大性能增益的理论上最优的网络管理解决方案。

本章介绍的用于网络优化问题的监督学习方法的总体思想，在异构网络中用户和资源分配的示例中是直观的。与手动为组合资源优化问题设计工程启发式和决策规则相比，其思想是训练一台机器基于统计分类进行分布式决策。在这种方法中，关于网络优化问题的工程知识仅通过选择适当的分类特征间接使用。为最优资源分配而提出的计算上不可处理的整数规划问题公式被离线用于为大量中等规模网络实例生成训练数据。对于这些实例，资源分配理想情况下是通过最优求解相应的优化问题来完成的。虽然这在计算上要求很高，但重要的是要注意，训练问题可以在中央机器上离线求解，并且有全网范围的 CSI 可用。对于这些实例获得的最优决策提供了在训练中使用的标签数据，以及相应的特征向量，这些特征向量可以根据每个实例的局部网络信息以分布式方式计算。用这些数据训练的机器能够基于局部 CSI 和网络信息进行分布式决策。与其他 ML 应用一样，在基于学习的网络管理和资源优化背景下出现的一个关键问题是，已用给定网络实例的标记数据训练的机器将其知识推广到不同规模、拓扑或底层信道特性的网络的能力如何。

## 5.1.1 网络容量与密集化

无线网络扩展的一个有前景且目前非常流行的技术方向旨在联合利用大规模 MIMO 阵列和毫米波无线接入。部署室内和室外小小区被理解为该技术的必要补充，以提供广泛的网络覆盖（Xiao et al., [2017](#c05.xhtml#c05-bib-0060)；Rappaport et al., [2015](#c05.xhtml#c05-bib-0053)）和容量提升（Jungnickel et al., [2014](#c05.xhtml#c05-bib-0037)）。然而，已确立无线通信网络的密集化存在基本限制（Andrews et al., [2016](#c05.xhtml#c05-bib-0007)；Nguyen and Kountouris, [2017](#c05.xhtml#c05-bib-0047)），超过该限制后无法实现容量提升。自然地，无线网络密集化存在实际限制原因，例如相关硬件成本和能耗的增加（Cavalcante et al., [2014](#c05.xhtml#c05-bib-0015)；Hoydis et al., [2011](#c05.xhtml#c05-bib-0032)），以及部署站点和回传的可用性有限（Ge et al., [2016](#c05.xhtml#c05-bib-0023)）。然而，密集化饱和效应的主要原因是网络中干扰的增加，导致网络实体的信干噪比（SINR）恶化。这限制了网络中可实现的数据速率，或者反过来，增加在时间、频率、空间和功率资源方面的需求，以实现所请求的 QoS 超出可承受水平。
