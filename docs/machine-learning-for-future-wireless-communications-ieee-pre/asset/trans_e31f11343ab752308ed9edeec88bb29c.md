
前馈神经网络的原始表述由 Rosenblatt 于 ([1962](#c13.xhtml#c13-bib-0052)) 提出。它可以被视为对感知器算法的扩展，该算法最初由 Rosenblatt 于 ([1957](#c13.xhtml#c13-bib-0051)) 提出，并对线性分类器应用了逐元素非线性转换函数。这种非线性转换函数使超平面决策边界能够呈现非线性形式，从而使模型能够分离线性不可分的训练数据。单层的表述如下，
