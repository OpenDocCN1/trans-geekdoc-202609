
其中 `r[t]` 表示时间 `t` 时的接收信号，`s[t]` 为发射符号，`n` 代表加性高斯白噪声（`AWGN`），而 `h[t]` 表示信道增益。由于反馈和处理延迟，在选择自适应传输参数时所处的信道条件在实际使用之前可能已过时，即 `h[t] ≠ h[t+τ]`，其中 `τ` 表示延迟。过时的 `CSI` 对各种自适应传输系统造成了严重负面影响。信道预测的目标是获得预测增益 `ĥ[t+τ]`，使其尽可能接近在实际使用所选参数进行传输的瞬间 `t+τ` 时的实际值 `h[t+τ]`。
