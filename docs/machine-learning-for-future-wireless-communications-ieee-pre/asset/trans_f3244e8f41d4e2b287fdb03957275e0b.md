
## 6.4

此外，涉及深度学习的另一个有趣的研究方向已被 (O'Shea and Hoydis, [2017](#c06.xhtml#c06-bib-0029); O'Shea et al., [2017](#c06.xhtml#c06-bib-0030)) 提出。其思想是利用 ML 工具重新定义物理层功能的设计方式。例如，在一个简单的通信系统示例中，发射机将期望信息转换为数据包，该数据包会被信道破坏，而接收机则尽可能恢复原始信息。传统上，文献关注的是对这类通信系统中的每个模块进行数学设计。另一方面，(O'Shea and Hoydis, [2017](#c06.xhtml#c06-bib-0029); O'Shea et al., [2017](#c06.xhtml#c06-bib-0030)) 使用了 `autoencoder` 的概念，即一种训练用于在输出处重建输入的 NN。例如，(O'Shea and Hoydis, [2017](#c06.xhtml#c06-bib-0029); O'Shea et al., [2017](#c06.xhtml#c06-bib-0030)) 提出的方案显示出在与传统方案相比时提供更低的误比特率和对无线信道损伤更好的鲁棒性方面具有很大潜力，例如空时分组码 (STBCs) 和基于奇异值分解 (SVD) 的预编码。

### 6.4.2 Positioning of Unmanned Aerial Vehicles

鉴于其适应性和灵活性，无人机小蜂窝 (DSCs) 被认为是一种良好的替代方案，以便能够快速、高效地部署通信网络。典型场景包括可能导致已部署网络拥塞的大型活动，或网络基础设施受损的灾难情况。在这些情况下，通过无人机 (UAVs) 部署 DSCs 是快速实施的来源，并且与地面通信相比具有很大的重新配置可能性 (Zeng et al., [2016](#c06.xhtml#c06-bib-0049))。然而，正如 (Zeng et al., [2016](#c06.xhtml#c06-bib-0049)) 也指出的那样，尽管节能通信配置已在地面通信中得到广泛研究，但其对 UAV 通信系统的系统性研究仍不成熟。

在此背景下，UAV 部署优化具有很大兴趣 (Alzenad et al., [2017](#c06.xhtml#c06-bib-0006))。例如，(Klaine et al., [2018](#c06.xhtml#c06-bib-0025)) 最近采用了一种 RL 技术来优化紧急场景中 UAV 的位置。所提解决方案的主要目标是最大化被应急通信网络覆盖的用户数量。与文献中的不同定位策略相比，RL 解决方案优于其他方案，减少了中断用户数量，且这种情况在更少的回合中发生。然而，EE 仍未被研究，因此是一个可能未来的工作场景。

### 6.4.3 Learn‐to‐Optimize Approaches

深度学习社区中的另一个研究趋势是一种被称为 `learn‐to‐optimize` 的方法 (Zappone et al., [2018b](#c06.xhtml#c06-bib-0048))，它利用关于待解决问题先验信息。在无线通信的背景下，这代表了巨大的研究机会，因为理论模型通常是可用的，尽管可能存在简化。因此，所有这些可用的框架相比于 ML 已成功应用的其他科学领域提供了更深入的先验信息。

这种概念与 (Ericsson, [2018](#c06.xhtml#c06-bib-0016)) 中最近提出的 `machine reasoning` 愿景相契合。正如作者所述，机器推理必须实现抽象时间不是必需的；因此，它适用于响应时间低的算法。另一方面，在线训练主要在需要动态适应数据集中新模式时进行：例如，当函数严重依赖于时间时。例如，部署依赖在线训练的算法，或需要长时间训练且高度依赖时间的函数，将导致无法生成准确预测 (Valente Klaine et al., [2017](#c06.xhtml#c06-bib-0039))。

总之，正如 (Ericsson, [2018](#c06.xhtml#c06-bib-0016)) 所描述的那样，将 ML 接受为无线网络等复杂系统自动化的可行方法仍面临一些重要的技术挑战。特别是，需要实时智能决策，以及面向分布式和去中心化系统的智能。最后，数据可用性和训练对于满足未来无线网络的严格需求至关重要。

## 6.5 Conclusions

本章中，ML 已被讨论为改善无线网络 EE 的手段。在此意义上，我们回顾了最常见的 ML 方法，重点关注 EE 的最大化、一些应用示例以及这些技术目标。

本工作还强调了当前设计中关于节能无线网络 ML 的一些困难。因此，深度学习、机器推理以及基于 UAV 的网络被列为该领域的一些未来趋势。此外，使用 ML 技术引发的一些挑战也被 delineated，特别是与数据收集和网络训练相关。

最后，基于本文讨论的见解，我们得出结论，ML 方法已在改善 EE、优化网络部署的许多方面以及以智能方式分配资源方面发挥关键作用，而在这些方面闭式解析模型过于复杂或缺乏所需的灵活性而无法使用。
