## 基于 QoE 的性能评估

如前所述，随着我们迈向 5G 时代，基于 `QoE` 的性能评估正受到越来越多的关注。因此，我们现在将使用 `QoE` 作为网络性能指标来评估所交付流量的质量。在用于建模 `QoE` 的指标中，我们选择了 `MOS`，因为它流行且被广泛使用。因此，资源分配将针对所有类型的流量进行，采用基于平均 `QoE` 的奖励函数。由于我们将集中于实时视频和常规数据流量，下面我们总结了对于此类流量 `MOS` 指标是如何从 `QoS` 测量中得出的：
