## QoE-based Performance Assessment

As mentioned earlier, `QoE`‐based performance assessment is gaining significant attention as we move toward the 5G era. Consequently, we will now use `QoE` as the network performance metric to assess the quality of the delivered traffic. Among the metrics used to model `QoE`, we chose `MOS` because of its popularity and widespread use. Thus, resource allocation will be carried on for all types of traffic using a reward function that is based on average `QoE`. Since we will concentrate on real‐time video and regular data traffic, we summarize next for this type of traffic how `MOS` metrics are derived from `QoS` measurements:

### Video MOS model

The peak signal‐to‐noise ratio (`PSNR`) is commonly accepted as an objective video quality assessment metric to measure, for example, coding performance.
