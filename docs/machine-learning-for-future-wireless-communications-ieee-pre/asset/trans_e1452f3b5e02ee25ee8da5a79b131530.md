## 18.4 结论
本章提供了 FD 通信和数字 SI 消除方法的自成体系且全面的概述。特别是，详细介绍了 FD 收发机模型，并描述并建模了使数字 SI 消除具有挑战性的主要收发机非理想因素。基于上述模型，提出了一种多项式 SI 消除方法，该方法在文献中常用于 SI 消除。然后，提出了一种替代的基于 NN 的 SI 消除方法，并检查并比较了两种方法的计算复杂度。最后，实验结果表明，基于 NN 的 SI 消除器实现了与多项式 SI 消除器相同的数字 SI 消除性能，但计算和硬件实现复杂度显著更低。

### 18.4.1 开放性问题
本章所述的基于 NN 的消除方法使用简单的单层前馈 NN。尽管该方法效果良好，但通过考虑其他 NN 架构，可以在性能和/或复杂度方面取得显著改进。例如，已表明深度前馈 NN 在各种应用中通常优于单层前馈 NN。因此，对于相同数量的可训练参数，深而窄的（即每层神经元较少）NN 可能优于浅而宽的 NN，或者它可以用更少的训练参数提供相似的性能。此外，由于 SI 信号具有记忆性，一个自然的选择是使用递归 NN（RNN），该网络只需两个输入（即 ![图像](images/c18-i0152.png)`x[n]` 的实部和虚部）即可重现 SI 记忆，而不是前馈 NN 所需的 ![图像](images/c18-i0153.png)`2L` 个输入。
SI 信道随时间变化且需要跟踪。对于多项式消除器，可以通过重新估计式 ([18.16](#c18.xhtml#c18-disp-0016)) 中的参数 ![图像](images/c18-i0154.png)`γ_{p,q}[l]` 来跟踪 SI 信道，使用标准最小二乘估计或最小二乘估计算法的自适应版本，例如最小均方或递归最小二乘。对于基于 NN 的消除器，可以通过重新运行反向传播训练算法来跟踪 SI 信道。必须检查并比较多项式和基于 NN 的消除器的 SI 信道跟踪方法。特别地，比较每种跟踪方法的计算复杂度、收敛速度和所需训练样本数将很有趣。
最后，现有的基于 NN 的 SI 消除方法没有考虑任何关于该问题的专家知识。图 18.1 中的 SI 收发系统图和式 ([18.16](#c18.xhtml#c18-disp-0016)) 提供了有价值的信息，可用于推导数字 SI 消除的物理启发式 NN 架构，类似于 Mkadem 和 Boumaiza 的物理启发式射频功率放大器建模 ([2011](#c18.xhtml#c18-bib-0016))。
