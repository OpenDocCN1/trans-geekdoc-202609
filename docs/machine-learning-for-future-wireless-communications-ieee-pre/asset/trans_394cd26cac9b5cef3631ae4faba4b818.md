
# SVM 用于 AMC

`SVM` 算法在训练集中最大化不同类别之间的间隔，并且根据每个类别的不同间隔边界的距离，将标签 ![images](images/c09-i0119.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>y</mi><mo>&#8712;</mo><mo stretchy="false">&#123;</mo><mo>+</mo><mn>1</mn><mo>,</mo><mo>&#8722;</mo><mn>1</mn><mo stretchy="false">&#125;</mo></mrow></math> 放置在特征集实现上。也就是说，`SVM` 构建最大间隔分类器以确定每个特征集的类别区域。当我们将 `SVM` 应用于 `AMC` 时，类别区域对应于传输的成功或失败。也就是说，它们表示接收端帧解码是否成功。通常，成功/失败类别分别用 ![images](images/c09-i0120.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mo>+</mo><mn>1</mn></mrow></math> 和 ![images](images/c09-i0121.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mo>&#8722;</mo><mn>1</mn></mrow></math> 表示。对于特征集实现 ![images](images/c09-i0122.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi mathvariant="bold">x</mi><mo>&#8712;</mo><msup><mi mathvariant="double-struck">R</mi><mi>p</mi></msup></mrow></math>，其中 `p` 是特征向量的维度，`R` 是实数集合，`SVM` 的间隔由推理函数 ![images](images/c09-i0125.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>h</mi><mo stretchy="false">(</mo><mi mathvariant="bold">x</mi><mo stretchy="false">)</mo><mo>=</mo><msup><mi mathvariant="bold">w</mi><mi>T</mi></msup><mi>&#966;</mi><mo stretchy="false">(</mo><mi mathvariant="bold">x</mi><mo stretchy="false">)</mo><mo>+</mo><mi>b</mi></mrow></math> 定义，其中 `w` 可定义为训练用的线性判别向量，`phi(x)` 是对特征集执行的 `SVM` 特征变换以生成 `SVM` 特征集，而 `b` 被表示为间隔偏置。

然后推理函数的结果作为判别函数 ![images](images/c09-i0129.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>g</mi><mo stretchy="false">(</mo><mi>h</mi><mo stretchy="false">(</mo><mi mathvariant="bold">x</mi><mo stretchy="false">)</mo><mo stretchy="false">)</mo></mrow></math> 的输入，该函数是 `x` 的复合函数，定义为当 ![images](images/c09-i0132.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>z</mi><mo>&#8805;</mo><mn>0</mn></mrow></math> 时 `g(z)=1`，而当 ![images](images/c09-i0134.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>z</mi><mo>&#60;</mo><mn>0</mn></mrow></math> 时 `g(z)=-1`。每个 `SVM` 提供二元分类，因此需要 `mu` 个 `SVM` 来区分 `mu` 种调制与编码方案类别。分类器被定义为 `one-versus-none` 分类器 (Daniels and Heath, [2010](#c09.xhtml#c09-bib-0004))。第 `m` 个分类器用于在类别 `m` 中选择合适的对象。当 `PER` 约束 `PER(m, x) <= F` 未满足时，其中 `F` 是 `PER` 的阈值，则不选择任何类别。当编码为 `MCS` `i` 的帧被分类器选为成功传输时，分类器会被强化以选择 `MCS` `i`。否则，当帧传输被视为失败传输时，分类器会被强化以不选择任何 `MCS` 类别。因此，在应用 `mu` 个 `one-versus-none` 分类器后，可以从 `mu` 个 `MCS` 类别中为帧传输选择合适的 `MCS`。

事实上，`one-versus-none` 分类无法解决 `PER` 约束。为了适应训练集 `PER` 的变化，来自训练集的训练数据被赋予相等权重。带有 `PER` 回归的判别函数被回归函数取代，并分别针对不同的 `MCS` 类别设置，以便计算每个类别的后验概率。然后回归函数被设为 ![images](images/c09-i0145.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi>r</mi><mi>m</mi></msub><mo>:</mo><mi mathvariant="double-struck">R</mi><mo>&#8594;</mo><mo stretchy="false">\[</mo><mn>0</mn><mo>,</mo><mn>1</mn><mo stretchy="false">\]</mo></mrow></math>，其取决于 `m` 而不同。
