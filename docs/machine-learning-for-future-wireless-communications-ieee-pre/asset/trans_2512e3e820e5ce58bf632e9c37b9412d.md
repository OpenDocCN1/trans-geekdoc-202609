
监督学习（`SL`）方法具有以下优势，有助于其在 `AMC` 中的应用。首先，在通信网络运行期间，可以在线收集训练数据以更新数据集。其次，存在丰富的训练数据集，包括循环冗余校验（`CRCs`）、信道状态信息（`CSI`）、相关的调制与编码方案（`MCS`）等。这些数据可用于更新训练集以在特定无线网络中学习 `AMC`，或通过迁移学习（Pan et al., [2010](#c09.xhtml#c09-bib-0020)）在其他网络中重复使用进行训练。最后，模型化方法中常被近似或忽略的非理想操作，例如模拟电路元件中的非线性放大和有限分辨率（Daniels et al., [2008](#c09.xhtml#c09-bib-0006)），在执行链路自适应时因黑箱方法而被 `SL` 技术所接受。

`SL` 方法的一个缺点是所获得的样本数据很难准确代表信号可能经历的所有情况，包括时变的无线信道条件、放大器的非线性行为、非高斯分布的噪声和干扰等（Leite et al., [2012](#c09.xhtml#c09-bib-0014)）。因此，`SL` 方法可能不适用于在线学习，其中特征集可能是变化的，并且收集大量训练样本可能不切实际。

相比之下，强化学习（`RL`）和马尔可夫决策过程（`MDP`）方法能够直接从环境中学习，从而为通信系统所需的在线学习提供解决方案。与从外部监督者提供的示例中学习的 `SL` 方法不同，`RL` 方法具有在线学习的能力。最近，(Jiang et al., [2017](#c09.xhtml#c09-bib-0010)) 将 `RL` 引入无线通信领域（Jiang et al., [2017](#c09.xhtml#c09-bib-0010)）。在 (Leite et al., [2012](#c09.xhtml#c09-bib-0014)) 中，提出了一种基于 `Q-learning` 的框架，用于在给定信噪比（SNR）时选择最佳 `MCS`。在 (Melián‐Gutiérrez et al., [2015](#c09.xhtml#c09-bib-0016)) 中，作者提出了一种基于混合隐马尔可夫决策和置信上界（`UCB`）的算法，用于优化认知无线电中次要用户的性能。然而，将该技术用于 `AMC` 的主要缺点是与环境交互的时间可能过长，无法选择首选的 `MCS`。这对于时变无线信道的运行来说是明确不期望的。为了缓解此问题，可能需要一些离线训练。

众所周知，机器学习辅助的 `AMC` 迄今为止主要是在 `SL` 或 `RL` 的背景下实现的。虽然无监督学习，如主成分分析（`PCA`），已在 (Daniels et al., [2008](#c09.xhtml#c09-bib-0006)) 中用于降低特征维度，但其最终决策仍借助 ![images](images/c09-i0001.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>k</mi></mrow></math>‐最近邻(![images](images/c09-i0002.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>k</mi></mrow></math>‐`NN`) 算法完成，而该算法是一种 `SL` 方法。其原因在于无监督学习主要适用于数据预处理，而不适用于决策，例如在 `AMC` 中。

考虑到 `SL`，最广泛使用的学习算法包括支持向量机（`SVMs`）、决策树、![images](images/c09-i0003.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>k</mi></mrow></math>‐`NN`、神经网络等。所有这些算法都需要标记数据。经过适当训练后，它们都可以作为分类器运行。因此，在不失一般性的情况下，在以下各节中，我们将仅考虑 ![images](images/c09-i0004.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>k</mi></mrow></math>‐`NN` 和 `SVM` 作为我们的两个示例，以展示 `SL` 在 `AMC` 中的应用。对于 `RL`，我们将讨论 `Q-learning`，因为它在文献中已被广泛研究（Venkatraman et al., [2010](#c09.xhtml#c09-bib-0025); Oksanen et al., [2010](#c09.xhtml#c09-bib-0018); Leite et al., [2012](#c09.xhtml#c09-bib-0014)）。

在以下各节中，我们将首先介绍 `SL` 辅助和 `RL` 辅助 `AMC` 的原理。然后研究 `AMC` 方案的性能。在我们的研究中，使用了 `IEEE 802.11n` 标准中定义的规定和参数。注意，`IEEE 802.11n` 是 Wi-Fi 联盟的基础协议，是首个支持 `MIMO-OFDM` 传输的 Wi-Fi 协议。

本章其余部分组织如下。[第 9.1.2 节](#c09.xhtml#c09-sec-0003) 对 `IEEE 802.11n` 中规定的 `AMC` 方案进行了简要概述，并给出了标准中使用的调制类型和编码速率的详细信息。然后，[第 9.2 节](#c09.xhtml#c09-sec-0004) 专门讨论 `SL` 辅助 `AMC`，其中考虑了 ![images](images/c09-i0007.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>k</mi></mrow></math>‐`NN` 和 `SVM` 方法。在 [第 9.3 节](#c09.xhtml#c09-sec-0014) 中，讨论了基于 `RL` 和 `MDP` 的 `AMC` 方案。相应的仿真结果和分析分别在 [第 9.2 节](#c09.xhtml#c09-sec-0004) 和 [第 9.3 节](#c09.xhtml#c09-sec-0014) 末尾提供。本章最后一节提供了进一步的讨论和观察。
