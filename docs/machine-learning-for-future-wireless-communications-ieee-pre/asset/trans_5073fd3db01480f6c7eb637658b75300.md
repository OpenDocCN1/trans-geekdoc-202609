根据式 ([9.4](#c09.xhtml#c09-disp-0004))，对于每个子载波，我们可以从每个空间流的 `SNR` 获得一个特征查询。然而，正如 (Daniels et al., [2008](#c09.xhtml#c09-bib-0006)) 中所述，清晰可实现的 MIMO-OFDM `AMC` 方法非常受期望。为了简化 `AMC` 系统，在以下分析中，每个数据包只会产生一个特征查询，而不是为每个子载波产生一个特征查询。此外，数据包的每个子载波都将根据该特征查询应用相同的 `MCS`。下面，我们将讨论频率平坦衰落和频率选择性衰落的情况，因为从数据包中提取特征查询的方式在这两种衰落信道中是不同的。

对于频率平坦衰落信道上的传输，所有子载波共享相同的信道状态。因此，对所有子载波平均的后处理 `SNR` 可作为特征查询。然后根据式 ([9.4](#c09.xhtml#c09-disp-0004))，我们可以获得用于 `MCS` 0-7 的一维特征集（一个空间流）和用于 `MCS` 8-15 的二维特征集（两个空间流）。由于存在两个维度不同的特征集，我们在每个特征集中执行 `Algorithm 1`。一旦我们为每个特征集获得建议的 `MCS`，则选择速率最高的 `MCS`。

然而，对于频率选择性衰落信道上的传输，平均后处理 `SNR` 不能有效反映信道条件的变化，而这些变化是由信道矩阵、信号能量和噪声方差唯一决定的。在这种情况下，训练集的特征空间可能包括 ![images](images/c09-i0098.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi mathvariant="bold">H</mi><mi>n</mi></msub></mrow></math>、![images](images/c09-i0099.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi>E</mi><mi>s</mi></msub></mrow></math> 和 ![images](images/c09-i0100.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi>N</mi><mn>0</mn></msub></mrow></math>，这导致特征空间维度更高。另一方面，由于 `SL` 中的维度灾难，数量级为 ![images](images/c09-i0101.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi>N</mi><mi>r</mi></msub><mo>&#215;</mo><msub><mi>N</mi><mi>t</mi></msub><mo>&#215;</mo><mi>N</mi></mrow></math> 的维度即使在 ![images](images/c09-i0102.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi>N</mi><mi>r</mi></msub></mrow></math>、![images](images/c09-i0103.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi>N</mi><mi>t</mi></msub></mrow></math> 和 ![images](images/c09-i0104.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>N</mi></mrow></math> 的典型值下也需要极大的训练集。
