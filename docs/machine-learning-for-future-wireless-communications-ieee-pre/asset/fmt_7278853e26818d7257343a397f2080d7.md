
# Spatio-temporal Mobility Prediction Framework

## Introduction

Note that the spatio‐temporal sequence forecasting problem is different from the conventional time‐series forecasting problem, since the prediction target of the former is a sequence that contains both spatial and temporal structures.

## Framework Overview

In order to address this problem, a spatio‐temporal mobility‐prediction framework is given in [Figure 7.11](#c07.xhtml#c07-fig-0011), which mainly contains a preprocessing module and a spatio‐temporal prediction module.
