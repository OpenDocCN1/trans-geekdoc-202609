

在仿真部分，引入了一个五层 `DNN`，结构为 `(16, 128, 64, 32, 8)`，作为神经网络解码器用于解码长度为 `(16, 8)` 的极化码。`NND` 接收 `CNN` 等化器的软输出以恢复原始传输比特。具有 `ISI` 和 `AWGN` 的色散信道的信道非线性函数和冲激响应可在 (Xu et al., [2018](#c14.xhtml#c14-bib-0029)) 中找到。

`CNN` 输出可能不遵循 `AWGN` 信道输出的相同分布，这可能会导致性能下降。因此，使用 `CNN` 等化器的软输出联合训练 `NND`（`CNN+NND–Joint`）可以补偿性能损失。测试了极化码 `(16, 8)`，并给出了与 (Hao Ye, [2017](#c14.xhtml#c14-bib-0012)) 的仿真对比。初步结果表明，由 `GPC` 算法进行均衡和 `SC` 算法进行解码组成的传统 `GPC+SC` 方法比 `CNN+NND` 差 1 dB。`CNN` 和 `NND` 的联合训练（`CNN+NND–joint`）比 `CNN+DNN` 提高了约 0.5 dB。`CNN+DNN–joint` 方案的性能非常接近 (Hao Ye, [2017](#c14.xhtml#c14-bib-0012)) 中的方法，后者使用 `DNN` 进行联合均衡和解码。

这些案例表明，神经网络可以用在不仅仅是像信道编码这样的单一通信部分的操作上。使用 `DL` 学习通信系统中的多个模块也是一个很有前景的方向。

### 14.2.4 一种解码多种码的统一方法

在 `5G` `eMBB` 场景中，极化码和 `LDPC` 码分别用作控制信道和数据信道的信道编码方法。在这种情况下，我们需要同时实现可靠的控制信令和高吞吐量数据传输，因此需要混合解决方案。从硬件角度来看，挑战在于硬件资源需要对解码结构进行精心设计，并且推广到不同的编码速率将具有挑战性。从 `DL` 角度来看，基于 `DL` 的解码结构是否可以应用于支持多种编码方案仍是一个开放问题。

### 14.2.5 总结

尽管在利用 `DNN` 解码线性码方面投入了大量研究，但目前仍存在一些局限性。首先是码长问题，因为计算复杂度随着码长的增加呈指数增长。因此，目前还没有很好的方法将 `DL` 解码应用于 `5G` 的标准码长。第二局限性是联合优化问题。另一方面，解码与其他通信模块的结合是 `DL` 的另一个研究方向。这些方向很可能在未来成为新的选择，通过用基于 `DNN` 的解决方案取代传统的耗时算法。
