
在更深层次上，使用 `CR` 范式及其认知循环，为资源分配解决方案提供了超越直接应用 `ML` 算法所显现的机会。资源分配的跨层技术实现就是一个例证。众所周知，资源分配的跨层方法能带来性能更好的解决方案。然而，商用无线设备架构仍然是分层的，不仅因为跨层设计可能导致模块化网络协议实现上的妥协，更重要的是，因为整个网络协议栈的开发过程被划分为不同的团队，每个团队专门负责在特定处理器（例如主 CPU 或基带无线处理器）中实现某一层或子层。这导致软件模块缺乏交换实现跨层解决方案所需的数据和命令的能力。然而，正如 [图 2.1](#c02.xhtml#c02-fig-0001) 右侧所示，认知循环通过实现一个认知引擎，使其能够感知环境（在 `Observe` 状态）并对环境发出动作（在 `Act` 状态），所使用的变量和参数对应于网络协议栈的所有层，从而实现无缝模块化跨层无线网络技术。这是一种在保留模块化架构的同时优雅地允许跨层操作的框架，并在本章中在适当时使用。

如所述，本章将重点关注在认知无线电网络中使用 `ML` 进行分布式资源分配。在现有的 `ML` 技术中，我们感兴趣的是那些反映认知循环且适用于跨层解决方案应用的技术。此外，在采用 `CR` 范式时，我们感兴趣的是考虑那些不预设对环境中动作影响的先验模型，而是将该知识作为 `CR` 中学习过程的一部分来推导的 `ML` 技术。一类符合这些要求的 `ML` 技术是 `reinforcement learning`。

从高层次来看，使用 `reinforcement learning`，智能体通过尝试不同的可能动作并评估其相对于实现目标的适应性来学习最佳动作。动作实现目标的能力是通过计算每个所采取动作对环境产生的实测效应的奖励（或成本）来评估的。`reinforcement learning` 名称的由来在于，智能体通过多次尝试所有动作来学习，逐渐偏好那些产生更大奖励的动作，最终确定奖励最大的动作。通常，学习过程逐渐从 `exploration phase` 演变而来，在该阶段智能体在对环境影响知之甚少的情况下主要随机尝试动作，到 `exploitation phase`，智能体优先尝试那些奖励更大的动作。有许多 `reinforcement learning` 技术，其中最常见的一种是 `Q-learning`，本章采用了该技术。

虽然 `reinforcement learning` 技术为智能体学习其动作对环境的影响提供了手段，但多次尝试动作的过程往往导致学习过程缓慢。为解决这一问题，最近的发展是考虑动作对环境的影响及其对预期目标的反映作为一个函数，其参数为所采取的动作和环境的状态。由于该函数初始未知，智能体通过应用 `ML` 技术来学习它。通过避免多次测试所有动作，学习速度得以提高。这是在本章后面讨论的 `deep Q-learning` 技术的核心思想。此外，在具有能够相互通信的认知智能体的背景下，加速学习的另一种方法是利用某些智能体获得的经验并将其转移给经验较少的智能体，以便它们能够缩短其 `exploration phase`。本章后面在讨论合作学习和迁移学习时，我们将更详细地阐述这一思想。

本章其余部分分为四个章节。 [第 2.1 节](#c02.xhtml#c02-sec-0002) 解释了 `Q-learning` 用于跨层资源分配的使用， [第 2.2 节](#c02.xhtml#c02-sec-0003) 描述了基于 `deep Q-learning` 技术的资源分配。 [第 2.3 节](#c02.xhtml#c02-sec-0004) 重点关注不同 `CRs` 在学习过程中如何合作。最后， [第 2.4 节](#c02.xhtml#c02-sec-0005) 提出了一些结论性意见。
