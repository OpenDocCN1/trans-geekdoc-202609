
# LASSO 回归

最小绝对收缩和选择算子（`LASSO`）回归分析方法由 `Tibshirani` 于 ([1994](#c17.xhtml#c17-bib-0111)) 提出。与 `Ridge` 回归类似，`LASSO` 可用于正则化和生成稀疏模型（即减少模型的参数或分量）。而 `Ridge` 回归的约束是系数的平方和，`LASSO` 的约束则由系数的绝对值之和构成。因此，`LASSO` 回归的解满足以下 ![图像](images/c17-i0071.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi>&#8467;</mi><mn>1</mn></msub></mrow></math> 优化问题：
