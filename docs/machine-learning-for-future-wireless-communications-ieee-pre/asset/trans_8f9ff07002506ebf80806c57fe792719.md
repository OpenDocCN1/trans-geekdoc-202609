
在我们的实验中，我们假设一个具有 64 个子载波、64 个导频符号以及 CP 长度为 16 的 OFDM 系统。我们假设数据调制采用 4-QAM，并且采用单径瑞利衰落信道，其实部和虚部服从均值为零、方差为 0.5 的高斯分布。我们还考虑了扩展行人 A 模型 (EPA) (3GPP, [2017](#c12.xhtml#c12-bib-0001))，其中路径数设为 7，最大延迟扩展为 9 个采样周期。此外，还考虑了扩展典型城市模型 (ETU) (3GPP, [2017](#c12.xhtml#c12-bib-0001))，其路径数为 9，最大延迟扩展为 16 个采样周期。

在 [图 12.15](#c12.xhtml#c12-fig-0015) 中，我们比较了分别采用我们提出的基于 DNN 和 CNN 的均衡器的 OFDM 系统与采用传统基于 LS 和 MMSE 的均衡器的 OFDM 系统的 BER 性能，假设通信在单径瑞利衰落信道上进行。[图 12.15](#c12.xhtml#c12-fig-0015) 显示，LS 方法在四种均衡器中表现最差，其结果是它没有利用对信道均衡有用的信道统计先验知识。相比之下，MMSE 方法由于利用了信道的二阶统计特性而优于 LS 方法。可以观察到，基于 DNN 和 CNN 的均衡器在低到中等 SNR 范围内均能获得比 LS 和 MMSE 方法更好的 BER 性能。然而，在高 SNR 区域，基于 DNN 和 CNN 的均衡器可能被基于 MMSE 的均衡器超越。此外，基于 CNN 的均衡器实现了比基于 DNN 的均衡器更低的 BER，这得益于 CNN 的特性，其提供了信号和信道的更多时域信息。

## 12.6 结论与讨论

在本章中，我们首先讨论了各种 NN 结构和学习方法，以解决信道均衡问题。然后考虑了几种具有代表性的 NN 算法。此外，还提出了两种基于 ML 的均衡器，即基于 DNN 和 CNN 的均衡器，并研究了其性能并与基于 LS 和 MMSE 原理开发的两种传统均衡器进行了比较。我们的研究和性能结果表明，与传统的信道均衡和检测方法不同，在基于 ML 的均衡方法中不需要单独计算信道统计信息。更重要的是，采用基于 ML 的均衡器的 OFDM 系统的 BER 性能通常优于采用传统基于 LS 和 MMSE 的均衡器的 OFDM 系统。这意味着基于 ML 的均衡器具有更高的学习和分析无线信道复杂特性的能力，并且更有效地对抗 ISI。同时，在具有或不具有频率选择性衰落的信道上通信时，基于 ML 的均衡方法表现出比基于 LS 和 MMSE 的均衡方法更好的 BER 性能。由于其不需要关于无线信道结构和特性的先验知识的特性，基于 NN 的均衡器构成了未来超高数据速率无线通信系统中信道均衡的有希望的候选方案。
