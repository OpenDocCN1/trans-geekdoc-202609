## 15.4 结论

在本章中，我们讨论了数字通信中深度学习可以发挥重要作用的广泛而富有成效的应用。 我们提供了 DL 技术概述，重点关注 FEC 码，并以极化码为案例研究，考察了最先进的 DL 辅助解码器。 已证明，现成的 DL 解码器可以达到短码长下的 MAP 解码性能，并且由于其一次性解码特性，它们能够实现并行执行。 然而，对于较长的码长，现成的 DL 解码器需要一个随码长呈指数增长的训练数据集。 该问题成为这些解码器在实际应用中的主要挑战。 另一方面，领域知识可以被利用来设计 DL 辅助解码器，正如各种神经 BP 解码器所证明的那样。 研究表明，神经 BP 解码器可以在保持相同解码延迟的同时，相对于其传统对应方案获得显著的解码性能增益。

未来研究关于将 DL 技术应用于 FEC 的研究可以沿着多个方向进行，例如为各种非线性通信信道设计定制 DL 辅助解码器和神经信道噪声估计器的联合训练系统。 此外，如极化码等线性分组码的顺序解码可以适当地形式化为 RL 问题，从而极大地促进最先进的 RL 算法在 FEC 中的应用。 其他方法可能包括将 DL 技术用作传统解码算法的优化方法，这些方法的解是基于近似或大规模蒙特卡洛模拟得到的。
