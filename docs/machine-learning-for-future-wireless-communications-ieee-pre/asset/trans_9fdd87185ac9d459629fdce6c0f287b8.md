
在自适应基带信号处理中，使用机器学习技术的思路主要是用少数学习算法取代基于模型的收发机的许多构建模块，旨在大幅减少对系统模型的假设数量以及对复杂估计技术的需求。然而，这种模型知识的减少带来了许多技术挑战，例如需要大规模训练集和较长的训练时间。针对多用户环境中的符号检测，[第11章](#c11.xhtml)展示了如何将和空间中再生核希尔伯特空间（RKHSs）的理论与自适应投影次梯度方法相结合，从而生成可唯一分解为线性分量和由高斯核构建的非线性分量的滤波序列。通过这样做，对应的机器学习解决方案不仅能够应对小规模训练集和环境中的突发变化，还能超越具有完美信道知识的传统解决方案。

[第12章](#c12.xhtml)通过涵盖工作原理、信道建模、训练数据收集、复杂度分析和性能比较，对各种神经网络架构及其对应的机器学习算法在未来无线通信的信道均衡和信号检测中的应用进行了全面介绍。本章介绍的神经网络主要包括多层感知机（MLP）网络、径向基函数网络、循环神经网络（RNNs）、函数链接人工神经网络、深度神经网络（DNNs）、卷积神经网络（CNNs）、支持向量机（SVMs）以及极限学习机，以及为联合均衡和检测专门开发的改进版本。以误码率作为关键性能指标，本章证明了基于神经网络的信道均衡器在处理非线性和复杂的信道条件方面非常强大，而这正是未来无线通信系统的特点。

从理论到实践，基于机器学习的信号智能的所有技术方面都在[第13章](#c13.xhtml)中得到论述，重点在于自动调制分类和自适应无线干扰分类及其实时实现。更具体地说，自动调制分类任务涉及在给定接收端观察到的原始信号的情况下，确定用于调制发射信号的方案。另一方面，自适应无线干扰分类任务本质上是指识别环境中存在何种类型的无线发射机。为了以更高效、更实用的方式通过基于神经网络的方法完成这些任务，本章提供了收集频谱数据、设计无线信号表示、形成训练数据和选择训练算法的详细指南，特别是针对大规模无线信号数据集和复值数据表示格式的情况。

[第14章](#c14.xhtml)专门研究各种神经网络及其相关学习算法在无线通信和网络的信道编码（编码器和解码器）中的应用，包括低密度奇偶校验（LDPC）编解码器、极化码编解码器和Turbo编解码器。由于其强大的非线性映射和分布式处理能力，基于神经网络的机器学习技术在编码性能、计算复杂度、功耗和处理延迟等许多方面可以提供比传统方法更强大的信道编码解决方案。本章介绍了使用神经网络进行信道编码的三种不同方法。第一种方法中，基于神经网络的解码器执行传统解码器所需的所有处理模块。第二种方法使用神经网络执行整个解码任务的部分处理。第三种方法使用神经网络执行解码器的后处理或预处理，包括降噪和对数似然比估计。

由于其在无限码长下对任意信道实现期望容量的能力，极化码编解码器被认为是一项近期技术突破，并在许多新兴的无线通信和网络系统中得到广泛应用。通过阐述其工作原理、算法细节和性能评估，[第15章](#c15.xhtml)介绍了三种基于深度学习的极化码解码方法。更具体地说，这三种方法分别被称为现成深度学习极化码解码器、深度学习辅助极化码解码器，以及针对极化码解码器和噪声估计器的联合学习方法。本章证明了这些基于深度学习的极化码解码方案在短码长下可以达到最大后验解码性能，并且在保持相同解码延迟的同时，相对于传统方案获得显著的解码性能增益。

[第16章](#c16.xhtml)重点研究机器学习和神经网络方法用于无线信道状态信息（CSI）预测，以便根据瞬时信道条件合理调整传输参数，如调度用户、调制与编码方案、发射功率、中继节点、时隙、子载波以及发射或接收天线。为了充分利用循环神经网络所支持的时间序列预测能力，本章首先使用循环神经网络为平坦衰落单天线信道实现多步预测器，然后将该方案扩展到多天线信道和频率选择性多天线信道。从[第16章](#c16.xhtml)中报告的理论分析和仿真结果可以看出，循环神经网络在无线衰落信道预测应用中表现出很高的灵活性、通用性、可扩展性和适用性，因此可以被视为将传输智能技术引入实际应用的非常有前景的工具。

## 第3部分：网络智能与自适应系统优化

本书记述的第三部分由五章组成，专门研究机器学习和人工智能技术在系统级和网络层面的应用，涵盖灵活的回传和前传、跨层优化与编码、全双工无线电、数字前端（DFE）和射频（RF）处理、雾无线接入网络以及主动缓存。

通过聚焦波峰因子降低、同相正交不平衡抑制、峰均功率比降低和数字预失真线性化，[第17章](#c17.xhtml)提供了非常全面的概述，展示如何应用机器学习技术在数字前端和软件定义射频处理中提供智能解决方案。由于其强大的非线性映射和分布式处理能力，本章证明基于神经网络的机器学习技术在系统性能、编程灵活性、内存访问、架构可扩展性、计算复杂度、功耗和处理延迟等许多方面能够大大优于传统的数字前端方法。此外，基于神经网络的解决方案在未来的数字前端实现和部署中，包括智能向量处理器和功能IP模块，也能发挥非常重要的作用。
