信道均衡是电信工程中一种经典且众所周知的技术，已有大量研究。典型的均衡算法包括 `ZF` 算法、`MMSE` 算法、最优 `MLSE` 算法等。在介绍基于 `ML` 的均衡算法之前，让我们先简要回顾这三种均衡器的原理。
