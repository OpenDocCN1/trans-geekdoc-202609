
如前所述，毫米波通信是 5G 网络的重要组成部分，因为其有潜力支持极高的数据速率和低延迟服务。尽管毫米波频段比常用的低频和中频段提供更宽的频谱，但在许多部署场景中由于容量需求大和用户密度高，通过充分利用授权和免授权频谱实现高频谱效率和高频谱利用率非常重要。频谱共享通过允许多个服务提供商和移动网络运营商访问同一频谱频段用于相同或不同的服务集合来解决这一目标。与此同时，为 5G 服务新开放的频段，包括 37 GHz 和 57–71 GHz 频段，通过共享宝贵的频谱资源提供了改善频谱利用率的机会。

多个移动网络运营商之间共享频谱的前身是 3GPP 定义的基于 NR 的许可辅助接入。它能够在免授权频谱中部署与非 3GPP 技术共存的蜂窝网络，从而促进多种无线接入技术之间的频谱共享。然而，将许可辅助接入促进的频谱共享扩展到甚至授权频段的共享，开启了新的范式，这些范式特别适用于利用空间域的毫米波部署。这一新范式可以建立在关键观察之上：在毫米波网络中，大型天线阵列、定向通信和独特的传播环境大大简化了共享频谱中干扰管理的问题；参见 (S. Ghadikolaei et al., [2016](#c03a.xhtml#c03-bib-0015))、(Boccardi et al., [2016](#c03a.xhtml#c03-bib-0006))。

5G NR 频谱共享技术的空中演示已经完成。预计使用 5G 频谱共享技术将改善使用免授权和共享毫米波频谱的移动宽带和物联网服务的性能 (Tehrani et al., [2016](#c03a.xhtml#c03-bib-0019))。

早期研究表明，四个主要方面对频谱共享方案的性能和可行性有重大影响：波束成形的选择、信息交换量（协调）、共享的频谱量以及共享架构：

* 在毫米波网络中，发射端和接收端均采用的波束成形和定向通信是频谱共享的关键技术使能因素。数字、模拟和混合波束成形是实现定向通信的关键使能技术。合适的波束成形技术取决于波束形成、处理所需的灵活性以及功耗、成本和信道状态信息获取方面的约束。
* 不同移动网络运营商之间的协调水平（运营商间协调）对频谱共享的可行性和有效性有实质性影响。如果没有协调，频谱共享甚至可能没有益处，尤其是在传统的 sub-6 GHz 网络中。完全协调可能带来吞吐量方面的显著性能增益，尤其因为它能够实现联合预编码和负载均衡等互补技术。从技术角度来看，挑战在于多运营商场景下信道估计的高开销以及核心网络的复杂性。
* 运营商之间共享的频谱量是一个因素，因为增加带宽可能会通过预对数因子（即在可实现数据速率的对数函数之外的因子）改善可实现容量，但通常会降低信干噪比，这是由于噪声和干扰功率更高所致。如果预对数因子的贡献超过由此产生的 SINR 下降，则频谱共享是有益的。
* 支持架构是影响频谱共享性能的另一个方面。基础设施共享是提高频谱共享增益的架构示例。一般而言，性能增益与协议开销之间的权衡决定了频谱共享是否有益。文献 (Boccardi et al., [2016](#c03a.xhtml#c03-bib-0006)) 讨论了毫米波网络频谱共享的各种支持架构，包括无线接入网络和核心网络的接口。

### 3.1.4 基于模型与数据驱动的方法

尽管毫米波 MIMO 蜂窝网络中频谱共享的问题动机充分，但由于信令和计算复杂性，本质上仍是开放的。的确，类似的问题，如蜂窝网络中的协调和多小区波束成形，传统上使用 *基于模型的方法* 来解决。然而，这些方法始终存在信令和计算复杂性升高的问题，从而阻碍了它们在实际蜂窝网络中的实施。我们将在 [第 3.2.2 节](#c03.xhtml#c03-sec-0020) 中展示，使用这些基于模型的方法，所考虑的问题是难以处理的。

尽管基于模型的方法是通信系统的基础 (Tse and Viswanath, [2005](#c03a.xhtml#c03-bib-0020))，但为数学可处理性而经常需要的简化模型和多次近似可能导致在实践中效果不佳的协议 (Ghadikolaei et al., [2018](#c03a.xhtml#c03-bib-0010))。另一方面，数据驱动方法通过从数据（通常通过测量获得）中学习和优化，并对系统模型做出最小假设来解决这一缺点。然而，这些方法可能需要大量训练样本才能表现良好，而由于无线网络的时间变化，大多数无线网络中并不具备这些样本 (Sevakula et al., [2015](#c03a.xhtml#c03-bib-0017))。

认识到基于模型和数据驱动方法的优势和局限性，本章介绍了混合方法的使用，其中 *基于模型的部分* 在较小的时标上运行，而 *数据驱动组件* 在较粗的时标上运行并细化基于模型部分中使用的模型。我们将此方法应用于多运营商蜂窝网络中频谱共享这一重要（但难以解决）的问题。如本章所述，混合（基于模型和数据驱动）方法的范式适用于无线通信机器学习领域的大量问题。我们注意到 Recht ([2018](#c03a.xhtml#c03-bib-0014)) 提出了类似的结论，即混合方法仍可在最优控制领域提供纯基于模型方法的大部分益处。
