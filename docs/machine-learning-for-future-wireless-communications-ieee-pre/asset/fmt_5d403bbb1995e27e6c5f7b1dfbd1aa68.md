
## Parallel Hammerstein Model

Each active component in the transceiver chain shown in [Figure 18.1](#c18.xhtml#c18-fig-0001) is essentially a dynamic nonlinear system, which can be modeled in a variety of ways. The Volterra series is one of the most accurate models, but it has a very large number of parameters and is thus rarely used in practice. Instead, a simplification of the Volterra series, called a `parallel Hammerstein model`, is often used.
