### 15.2.3 Successive‐Cancellation List Decoding

`SCL` decoding improves the error‐correction performance of `SC` decoding by running multiple `SC` decoders in parallel. Instead of using Eq. ([15.9](#c15.xhtml#c15-disp-0009)) to estimate ![images](images/c15-i0050.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi mathvariant="bold-italic">u</mi></mrow></math> as in `SC` decoding, each bit is estimated considering both its possible values 0 and 1. Therefore, at each bit estimation, the number of candidates doubles.
