
其中 `Q_V` 表示视频的 `MOS`，而 `c`、`d` 和 `f` 是逻辑函数的参数。本章中，我们选择逻辑函数来评估视频流量的质量。

为了计算公式 (2.17) 中逻辑函数的参数，需要一组 `PSNR`s 及其对应的 `MOS` 值，同时我们希望将 `PSNR` 与比特率 `R_i^(S)` 关联起来，以便公式 (2.17) 本身将视频 `MOS` 刻画为比特率这一 `QoS` 变量的函数。为了首先获得代表不同分辨率和活动水平视频序列的 `PSNR`-比特率函数，我们对多个 `MPEG-4` 编码视频序列在不同分辨率 (240p、360p 和 480p) 下的 `PSNR`-比特率函数进行了平均，这些函数按 39% (240p)、32% (360p) 和 28% (480p) 的比例组合，以遵循实际流量中观察到的分辨率混合 (Mobile (2011))。所使用的视频序列为 30 帧每秒 (`fps`) 且分辨率为 480p 的 “Flowervase” 和 “Race Horses”，而对于 360p 分辨率，则选择了 24 `fps` 的 “Tennis” 和 “Park Scene”。结果表明，形式为 `PSNR = k log R_i^(S) + p` 的函数可用于非常接近地近似平均 `PSNR`-比特率曲线，其中 `k = 10.4` 和 `p = -28.7221` 为常数。接下来，为了获得公式 (2.17) 中逻辑函数的参数，我们使用 `PSNR`-比特率曲线计算了 `PSNR` 值，比特率取自所有候选资源分配动作的公式 (2.15)。为了获得与计算得到的 `PSNR` 值对应的 `MOS` 值，我们使用了图 2.2 中的线性映射和表 2.1 中的转换的平均值。在获得 `MOS`-`PSNR` 对之后，公式 (2.17) 中的结果参数为 `c = 6.6431`、`d = -0.1344` 和 `f = 30.4264`。
