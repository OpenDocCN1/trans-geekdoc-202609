## 12.4 基于神经网络的均衡与检测

在本节中，我们首先简要介绍反馈神经网络的一个典型模型，即 `MLP`，以便对 `NN` 的构建和训练提供一些见解。然后，基于 `MLP` 和 `DL`，提出了一种 `DNN` 方案用于信道均衡器的实现。最后，简要描述了基于不同类型 `NN` 的均衡器。

### 12.4.1 多层感知器模型

通常，`NNs` 需要用大量数据进行训练以提取关键特征参数。训练过程通常由 `gradient descent` 算法实现，该算法在每次迭代中使用 `forward` 和 `backward propagation`。本小节简要介绍了 `MLP` 的原理及其训练方法。
