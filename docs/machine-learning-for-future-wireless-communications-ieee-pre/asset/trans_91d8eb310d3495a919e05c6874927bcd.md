
# 使用 I/Q 分量的 ANN 训练

## 权重和偏置初始化

如在比较 `CV`‐ 和 `RV`‐ 数据在 `ANNs` 中的操作时所介绍的那样，使用 `I` 和 `Q` 分量可通过使用实数权重而非复数权重实现显著更快的训练。选择 `ANN` 的合适的初始权重和偏置值对于避免训练发散或学习不显著的长时间训练周期从而导致性能欠佳的模型至关重要。应遵循的一般规则是避免极值（最小值或最大值）以及权重的对称分布，这会使神经元表现相似，从而引发不必要的冗余和性能下降。如果不考虑初始知识，则权重应以这样的方式选择，使得下一个激活函数的输入通常位于线性区和饱和区之间（参见 [图 17.18](#c17.xhtml#c17-fig-0018)）。`−0.8–+0.8` 的随机初始化可提供一个相当不错的起点，而低于 `−1` 和高于 `+1` 的值则应避免，因为神经元学习会非常缓慢或停止。

## 前向-反向传播和优化算法

在每个训练 epoch（或迭代）中，既有前向传播，其中使用 `ANN` 的输出和期望输出计算误差代价函数，也有反向传播，计算应应用于 `NN` 权重和偏置的增量以最小化该代价函数。在基带调制解调器中采用自适应数字辅助线性化或 `RF` 损伤补偿技术会对用于学习以达到期望建模性能的 epoch 数量施加一定的限制。Rawat 等人 ([2010](#c17.xhtml#c17-bib-0095)) 中给出了快速 `BPLA` 技术的一种分类。在第一类中，我们找到启发式技术（Haykin ([2009](#c17.xhtml#c17-bib-0040)) 中提供了更多细节），它们源于对标准最陡下降算法的分析。这里可以包括带动量的梯度下降 (`GDM`)，它可防止陷入不良的局部最小值；以及诸如可变学习率 (`GDA`)、动量和自适应学习规则 (`GDX`) 以及弹性反向传播 (`RP`) 等变体。标准数值优化技术属于第二类（Hagan 等人 ([1996](#c17.xhtml#c17-bib-0037)) 中扩展了相关信息）。该类别包括 (i) 基于共轭梯度的技术，如 Polak‐Ribiere (`CGP`)、Fletcher‐Powell (`CGF`)、Powell‐Beale (`CGB`) 和缩放共轭梯度 (`SGC`)；(ii) 拟牛顿算法，如 Broyden‐Fletcher‐Goldfarb‐Shanno (`BFG`) 和一步割线 (`OSS`)；以及 (iii) Levenberg‐Marquardt (`LM`) 算法。`LM` 结合了梯度下降和 Gauss‐Newton 方法，并在 `ANNs` 中被广泛用于最小化 `DPD` 相关应用中的代价函数，因其快速收敛特性，同时具有良好的建模性能和合理的实现复杂度 (Haykin ([2009](#c17.xhtml#c17-bib-0040)))。
