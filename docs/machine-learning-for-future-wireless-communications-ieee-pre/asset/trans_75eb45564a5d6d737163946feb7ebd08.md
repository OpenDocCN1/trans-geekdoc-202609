
1. *在代理之间无协调*：这是一种纯粹的去中心化方法，其中代理纯粹基于本地环境信息优化其行为，且不受协调实体施加的任何约束。因此，它们对带宽和 RSRQ 阈值都有完全控制。

2. *在代理之间有协调*：最初提出的来自[图 4.7](#c04.xhtml#c04-fig-0007)的分层方法，其中代理受到协调实体施加的约束。代理只能控制 RSRQ 阈值，而带宽操作则由协调代理施加。

3. *具有在线学习能力*：与前一种方案类似，不同之处在于代理采取行动后，会将观察到的结果与预期估计值（即通过 `DNN` 推断的值）进行评估，如果实际遇到的值排名低于其他行动的估计值，则可以选择另一个行动。当最初估计的第二名行动最终比第一名行动更有效时，这可能很有用。

作为基线，我们选择全频复用。这是因为，正如 (Marinescu et al., [2018](#c04.xhtml#c04-bib-0018)) 所观察到的，相对于边缘用户，静态频谱复用方案平均而言往往表现不如全频复用。尽管某些静态频谱复用方案在遇到特定 UE 分布时可以提高特定小区的性能，但在网络层涉及现实的 UE 分布时，将这些方案扩展到大量相邻小区最终会对网络整体性能产生不利影响。

我们在[表 4.3](#c04.xhtml#c04-tbl-0003)中总结了三种类型 MAS 实现的性能，考虑了先前在[图 4.10](#c04.xhtml#c04-fig-0010)中展示的小区。我们选择内层三个小区进行评估，因为只有九个小区受代理控制，因此我们可以在内层三个小区中最好地注意到行动的影响。此性能也可以在[图 4.12](#c04.xhtml#c04-fig-0012)中可视化。

### 4.4.5 摘要

本节介绍了基于神经网络的多智能体系统可为 `LTE` 网络性能带来的改进。所提出的框架是一种高度可适应的解决方案，可根据网络中广泛的用户分布进行调整，解决小区之间的负载不平衡，并包含学习能力，以便在与神经网络训练基础差异过大的情况下提高性能。本章还展示了基于 `ML` 的代理如何通过协调实体合作，在全球网络层面实现性能改进。本章提出的神经网络可以通过推理帮助无线网络做出最优选择，而无需探索次优动作，这些动作可能会在运行时对 `LTE` 网络产生负面影响。采用这种基于 `ML` 的动态频率复用方案，边缘用户的覆盖范围可增加近三倍，同时网络仍保持了全频复用情况下 95% 的容量。[2](#c04.xhtml#c04-note-0002)

## 4.5 结论

在本章中，我们展示了机器学习辅助解决方案如何改善无线网络中与覆盖和容量优化相关问题的性能。提出了两种不同的方法，针对流量需求和网络环境条件的长期和短期适应。长期解决方案涉及通过深度 `RL` 方法打开或关闭 `BSs`，以在非平稳流量条件下节省能源，同时仍满足用户需求。当在此处也采用流量模型时，解决方案的性能会得到改善。另一方面，短期解决方案在我们的设想中与长期解决方案互补，它重新分配网络中当前可用的资源，以根据网络条件最大化全球网络性能。在这里，基于神经网络引导的小区代理的多智能体系统框架用于实现动态分数频率复用，以改善网络覆盖，同时最小化潜在的容量损失。这两种技术都利用无线网络中可用的大量数据/`KPIs` 来辅助决策过程。这样，提出的 `ML` 启发式方法能够及时成功地解决复杂问题。

实时数据可用性和建模对这些算法的决策过程至关重要。可用的历史数据越多，算法推断无线网络潜在未来行为的能力就越好。对未来网络行为的预测可以帮助提高解决方案的性能，因为代理可以预先采取行动来应对即将到来的变化，无论是短期还是长期。因此，我们预计准确的基于 `ML` 的流量和移动性建模将在未来解决无线网络的覆盖和容量优化问题方面发挥关键作用。
