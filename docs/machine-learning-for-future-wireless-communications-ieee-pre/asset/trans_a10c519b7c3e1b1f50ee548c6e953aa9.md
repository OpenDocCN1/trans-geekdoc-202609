
我们假设每个 `FAN` 在 `B_h = 18 MHz` 带宽上运行（100 个资源块，每个资源块 180 kHz），并且以固定功率水平 `P = 20 W` 发射。此外，噪声功率 `σ²` 假定为 `2 × 10⁻⁷ W`。

基于小小区场景中 `WINNER II` 信道模型 `Khan and Oestges` ([2011](#c19.xhtml#c19-bib-0020))，`FAN` `h` 与 `UT` `u` 之间的路径损耗系数由 `g_hu(t) = 10^{-PL(d_hu(t))/10}` 定义，其中 `d_hu(t)` 是时隙 `t` 中 `FAN` `h` 到 `UT` `u` 的距离，且 `PL(d) = A log10(d) + B + C log10(f0/5) + X_dB`，其中 `f0` 是载波频率，`X_dB` 是方差为 `σ_dB²` 的阴影对数正态变量；`A` = 18.7，`B` = 46.8，`C` = 20，且 `σ_dB² = 9` 在视距 (`LOS`) 条件下；`A` = 36.8，`B` = 43.8，`C` = 20，且 `σ_dB² = 16` 在非视距 (`NLOS`) 条件下。

每个链路独立随机处于 `LOS` 或 `NLOS` 状态，其概率分别为 `p_l(d)` 和 `1 - p_l(d)`，其中

(19.20)
```
p_l(d) = { 1 , d ≤ 2.5 m
          1 - 0.9 * (1 - (1.24 - 0.6 log(d))³)^{1/3} , otherwise. }
```
