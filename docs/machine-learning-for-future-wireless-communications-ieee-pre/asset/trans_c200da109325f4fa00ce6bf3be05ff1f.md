
# 联合解码器-噪声估计器

`[Figure 15.4](#c15.xhtml#c15-fig-0004)` 描述了一种联合解码器-噪声估计器方法，该方法源自 (Liang et al., [2018](#c15.xhtml#c15-bib-0025), Bennatan et al., [2018](#c15.xhtml#c15-bib-0006))，其中噪声估计器是一个 `DL` 模型，例如 `NN`、`CNN` 或 `RNN`。与现成的 `DL` 解码器不同，后者试图直接根据信道 `LLRs` 预测消息字，联合解码器和噪声估计器方法仅利用现成的 `DL` 模型来去噪信道 `LLR` 值，而主要的解码算法仍由传统的 `BP` 解码执行。

### 15.3.3 评估

在本节中，我们提供了在极化码上应用时各种最先进的 `DL` 辅助 `BP` 解码器在 `FER` 方面的性能比较。此外，包括 `BP` (Arıkan, [2010](#c15.xhtml#c15-bib-0004)) 和 `SCL` (Balatsoukas‐Stimming et al., [2015](#c15.xhtml#c15-bib-0005), Hashemi et al., [2016](#c15.xhtml#c15-bib-0018)) 解码在内的传统解码器的 `FER` 性能也被绘制出来。所考察的极化码的码长为 64，信息位为 32，并被选用于 `5G` 的 `eMBB` 控制信道 (`3GPP`, [2018](#c15.xhtml#c15-bib-0001))。我们将 `BP`![images](images/c15-i0099.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi>I</mi><mi mathvariant="normal">max</mi></msub></mrow></math>，其中 ![images](images/c15-i0100.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi>I</mi><mi mathvariant="normal">max</mi></msub><mo>&#8712;</mo><mo stretchy="false">&#123;</mo><mn>5</mn><mo>,</mo><mn>30</mn><mo stretchy="false">&#125;</mo></mrow></math>，表示为具有 ![images](images/c15-i0101.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi>I</mi><mi mathvariant="normal">max</mi></msub></mrow></math> 次迭代的传统最小和 `BP` 解码器，而 `SCL32` (Tal and Vardy, [2015](#c15.xhtml#c15-bib-0035)) 表示为列表大小为 32 的 `SCL` 解码器。本节中考虑的所有神经 `BP` 解码器均包含五个展开的 `BP` 迭代。
