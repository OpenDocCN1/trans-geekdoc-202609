
*数据驱动方法* 具有吸引力，因为它们不需要模型准确反映相应的物理过程。我们将读者引向 (S. Ghadikolaei et al., [2018](#c03a.xhtml#c03-bib-0016))，其中作者使用 `MAB` 框架重新表述了频谱共享问题。具体来说，`agent`（决策者）通过采取不同的 `actions`（每个动作对应于波束成形向量、关联和协调的选择）来探索未知的 `environment`，并观察相应的 `rewards`（和速率）。目标是找到使收集的奖励最大化的最优动作集合；有关强化学习的概述，请参阅 `Appendix A.1`。

## 3.3 混合解决方案方法

我们迄今已论证了纯模型驱动方法（即对 ![images](images/c03-i0158.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mrow><mi mathvariant="script"> P</mi></mrow><mn>1</mn></msub></mrow></math> 的直接求解）的实际局限性，原因在于巨大的复杂性、信令开销以及缺乏 `CSI`。另一方面，维度灾难使得纯数据驱动方法在学习任务可用的有限时间内无法找到最优的协调和关联决策。在所提出的混合方法中，学习任务不断完善每个 UE 的速率模型，而不是优化决策变量。然后模型驱动部分使用更新后的速率模型来找到最优的关联和协调策略。
