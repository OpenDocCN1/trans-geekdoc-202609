
# 支持向量回归

支持向量回归理论的基本思想在 Smola 和 Schölkopf ([2004](#c17.xhtml#c17-bib-0103)) 中提出。给定训练数据包含 ![images](images/c17-i0295.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>m</mi></mrow></math> 维变量和 1 个目标变量 ![images](images/c17-i0296.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mo stretchy="false">&#123;</mo><mo stretchy="false">(</mo><msub><mi mathvariant="bold-italic">x</mi><mn>1</mn></msub><mo>,</mo><msub><mi>y</mi><mn>1</mn></msub><mo stretchy="false">)</mo><mo>,</mo><mo stretchy="false">(</mo><msub><mi mathvariant="bold-italic">x</mi><mn>2</mn></msub><mo>,</mo><msub><mi>y</mi><mn>2</mn></msub><mo stretchy="false">)</mo><mo>,</mo><mi>&#8943;</mi><mspace width="0.3em"/><mo>,</mo><mo stretchy="false">(</mo><msub><mi mathvariant="bold-italic">x</mi><mi>n</mi></msub><mo>,</mo><msub><mi>y</mi><mi>n</mi></msub><mo stretchy="false">)</mo><mo stretchy="false">&#125;</mo></mrow></math>，其中 ![images](images/c17-i0297.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi mathvariant="bold-italic">x</mi><mo>&#8712;</mo><msup><mi>&#8476;</mi><mi>m</mi></msup></mrow></math> 且 ![images](images/c17-i0298.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>y</mi><mo>&#8712;</mo><mi>&#8476;</mi></mrow></math>，目标是找到一个函数 `f(x)`，使其在考虑一定裕度 `epsilon` 的同时返回最佳拟合，并且尽可能平坦。如 [图 17.26](#c17.xhtml#c17-fig-0026) 所示，对于所有训练数据，允许与实际获得的目标值 `y_i` 存在一定偏差（最多为 `epsilon`）。

假设 `x` 与 `y` 之间的关系近似线性，`f(x)` 的形式为

其中 `w` 是系数向量，`b` 是截距或偏置项。在公式 ([17.47](#c17.xhtml#c17-disp-0047)) 的情况下，平坦性意味着解必须考虑较小的 `w`，即一种正则化条件（与岭回归类似），其包括最小化欧几里得范数 `||w||_2`（也称为 `L2` 范数 `||w||_2^2`）。形式上，我们可以将此问题写成如下凸优化问题：
