
在过去 10 年里，满足用户移动宽带容量需求的无线通信技术的需求与降低成本和 ![图像](`images/c17-i0209.png`)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mtext>CO</mtext><mn>2</mn></msub></mrow></math> 排放的需求相耦合。这推动了具有大量单元的 MIMO 收发器解决方案的研究、开发和产业化，既用于宏基站，也用于超密集部署的下一代小基站。这些方案中大量的 RF 收发链路使得集成度、功耗和成本效益成为突出的设计约束，可能与采用性能最佳的方案相悖。高通道密度射频集成电路（RFICs）集成了数据转换级、I/Q 调制器和解调器以及 LO 信号合成与分配，与来自大批量市场的通常中等成本的 PA 一起使用，以受益于规模经济。[图 17.21](`#c17.xhtml#c17-fig-0021`)a 显示了基站高度集成 MIMO 发射机的通用架构（省略了 Rx 块）。在 Tx 端，串扰可能发生在同一集成电路中共享公共 LO 的多通道 I/Q 调制级，或在 PA 输出端发生（例如由于天线交叉耦合）。这些效应使传统的单天线 DPD 方法失效，因为它们在强或中等水平耦合（即通常为 −15—30 dB）下无法满足期望性能。与使用超外差架构相比，使用直接转换 Tx/Rx 链路以及由此产生的 I/Q 调制器/解调器在集成度和成本方面具有明显优势；然而，该架构由于 I 和 Q 支路之间的失配、直流偏移和带内 LO 耦合而存在 I/Q 增益和相位不平衡。图像抑制比（IRR）通过测量调制器输出端由缺陷产生的镜像信号与感兴趣信号之间的比率来表征 I/Q 不平衡（即典型值为 −20—40 dB）。所有这些损伤的综合效应在 [图 17.21](`#c17.xhtml#c17-fig-0021`)b 中示出。
