When one‐bit ADCs are employed at receivers, it is shown that `SLBM` outperforms `SLGM` since the former is developed for and more proper to the treatment of binary data.

The principle of parametric learning is very close to that of a nearest‐centroid classifier (`NCC`), which is a simple solution of the classification problem in `SL`. `NCC` assigns the class label of an unlabelled observed vector by using the centroid vectors that represent their classes. Similarly, in parametric learning, the `SL` detector works by selecting a message that has the minimum distance from the conditional mean vector of the pilot signals. This resemblance is a good example to show an interesting connection between a data‐detection problem in wireless communications and a classification problem in `SL`.

## 10.4 Low‐Complexity `SL` (`LCSL`) Detector

Although a parametric learning detector requires lower complexity than a non‐parametric learning detector, the computational complexity is prohibitive as the size of search‐space (e.g. ![images](images/c10-i0106.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mo stretchy="false">&#124;</mo><mi mathvariant="script"> M</mi><mo stretchy="false">&#124;</mo><mo>=</mo><msup><mi>m</mi><mi>K</mi></msup></mrow></math>) grows exponentially with ![images](images/c10-i0107.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>K</mi></mrow></math>. Thus, as in conventional `MIMO` systems, sphere decoding, which efficiently finds a reduced search space, can be considered. However, the conventional sphere decoding in Hassibi and Vikalo ([2005](#c10.xhtml#c10-bib-0003)) cannot be used directly due to the nonlinearity of the considered channel models. So‐called one‐bit sphere decodings (`OSDs`), which are suitable for one‐bit quantizations, have been proposed in Jeon et al. ([2018b](#c10.xhtml#c10-bib-0007)), Kim et al. ([2017](#c10.xhtml#c10-bib-0008)). In this section, OSD based on a hierarchical clustering forest (`OSD-HCF`) is introduced, which can yield a higher‐quality reduced search space. In this method, a fast binary nearest neighbor search algorithm (`flann`) Muja and Lowe ([2012](#c10.xhtml#c10-bib-0015)) is used, which finds a reduced search space efficiently by exploiting hierarchical clustering structures. Combining with the `SL` detector, it is called a low‐complexity `SL` (`LCSL`) detector. The overall procedures of the `LCSL` detector are provided as follows:

1. First decompose the (binary) Hamming space hierarchically so as to build a tree structure. It starts with choosing ![images](images/c10-i0108.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>J</mi></mrow></math> elements from ![images](images/c10-i0109.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mover accent="true"><mrow><mi mathvariant="script"> U</mi></mrow><mo>&#770;</mo></mover></mrow></math> randomly, which act as ![images](images/c10-i0110.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>J</mi></mrow></math> cluster centroids.

2. The previous step forms the ![images](images/c10-i0111.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>J</mi></mrow></math> clusters around these centroids, and the decomposition process is repeated recursively (see `Algorithm 1`).

3. This process is performed ![images](images/c10-i0112.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>W</mi></mrow></math> times to construct ![images](images/c10-i0113.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mo stretchy="false">&#123;</mo><msub><mrow><mi mathvariant="script"> T</mi></mrow><mn>1</mn></msub><mo>,</mo><mi>&#8230;</mi><mo>,</mo><msub><mrow><mi mathvariant="script"> T</mi></mrow><mi>W</mi></msub><mo stretchy="false">&#125;</mo></mrow></math> trees.
