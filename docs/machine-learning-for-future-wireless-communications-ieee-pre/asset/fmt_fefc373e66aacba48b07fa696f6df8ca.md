
# SVM for AMC

The `SVM` algorithm maximizes the margin between different classes in the training set, and also places the label ![images](images/c09-i0119.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>y</mi><mo>&#8712;</mo><mo stretchy="false">&#123;</mo><mo>+</mo><mn>1</mn><mo>,</mo><mo>&#8722;</mo><mn>1</mn><mo stretchy="false">&#125;</mo></mrow></math> on the feature set realizations according to the distance from different margin boundaries of each class. That is to say, the `SVM` constructs the maximum margin classifier to determine the class region of each feature set. When we apply `SVM` for `AMC`, the class regions correspond to the success or failure of transmissions. Namely, they represent whether frame decoding at the receiver is successful or not. Usually, success/failure classes are denoted by ![images](images/c09-i0120.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mo>+</mo><mn>1</mn></mrow></math> and ![images](images/c09-i0121.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mo>&#8722;</mo><mn>1</mn></mrow></math>, respectively. For the feature set realization ![images](images/c09-i0122.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi mathvariant="bold">x</mi><mo>&#8712;</mo><msup><mi mathvariant="double-struck">R</mi><mi>p</mi></msup></mrow></math>, where `p` is the dimension of the feature vector and `R` is the set of real numbers, the margin of `SVM` is defined by the inference function ![images](images/c09-i0125.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>h</mi><mo stretchy="false">(</mo><mi mathvariant="bold">x</mi><mo stretchy="false">)</mo><mo>=</mo><msup><mi mathvariant="bold">w</mi><mi>T</mi></msup><mi>&#966;</mi><mo stretchy="false">(</mo><mi mathvariant="bold">x</mi><mo stretchy="false">)</mo><mo>+</mo><mi>b</mi></mrow></math>, where `w` can be defined as a linear discriminant vector for training, `phi(x)` is the `SVM` feature transformation performing on the feature set to generate the `SVM` feature set, and `b` is denoted as the margin bias.

Then the result of the inference function acts as the input to the discriminant function ![images](images/c09-i0129.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>g</mi><mo stretchy="false">(</mo><mi>h</mi><mo stretchy="false">(</mo><mi mathvariant="bold">x</mi><mo stretchy="false">)</mo><mo stretchy="false">)</mo></mrow></math>, which is the compound function of `x` defined as `g(z)=1` when ![images](images/c09-i0132.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>z</mi><mo>&#8805;</mo><mn>0</mn></mrow></math>, and `g(z)=-1` when ![images](images/c09-i0134.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>z</mi><mo>&#60;</mo><mn>0</mn></mrow></math>. Each `SVM` provides the binary classification, so `mu` `SVM`s are needed to distinguish `mu` modulation and coding scheme classes. The classifiers are defined as `one-versus-none` classifiers (Daniels and Heath, [2010](#c09.xhtml#c09-bib-0004)). The `m`th classifier is used to select the appropriate one among the class `m`. When the `PER` constraint `PER(m, x) <= F` is not met, where `F` is the threshold of `PER`, no class is selected. When a frame encoded with `MCS` `i` is chosen by the classifier as a successful transmission, the classifier is reinforced to choose `MCS` `i`. Otherwise, when a frame transmission is considered a failure transmission, the classifier is reinforced to choose no `MCS` classes. Thus, the appropriate `MCS` for the frame transmission can be selected from `mu` `MCS` classes after applying the `mu` `one-versus-none` classifiers.

As a matter of fact, `one-versus-none` classification cannot address the `PER` constraint. In order to fit in with the change of `PER` of training sets, the training data from training sets are equally weighted. The discriminant functions with `PER` regression are replaced with regression functions and are respectively set with different `MCS` classes so as to calculate the posterior probability of each class. Then the regression functions are set as ![images](images/c09-i0145.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><msub><mi>r</mi><mi>m</mi></msub><mo>:</mo><mi mathvariant="double-struck">R</mi><mo>&#8594;</mo><mo stretchy="false">\[</mo><mn>0</mn><mo>,</mo><mn>1</mn><mo stretchy="false">\]</mo></mrow></math>, which differs depending on `m`.
