
在本节中，对多项式抵消器和神经网络抵消器的计算复杂度进行了研究。多项式抵消器在复数上运行，而神经网络抵消器在实数上运行。因此，为了进行公平比较，统计了执行每种方法计算所需的实数加法和实数乘法的数量。令 `a`, `b` ∈ `C`，为简单起见令 `a_R` = ℜ{`a`} 且 `a_I` = ℑ{`a`}。则复数加法可写为：

(18.26)
```
a + b = (a_R + b_R) + j (a_I + b_I)
```

且复数乘法可写为：

(18.27)
```
a b = (a_R + j a_I)(b_R + j b_I)
```
(18.28)
```
= (a_R b_R - a_I b_I) + j ((a_R + a_I)(b_R + b_I) - a_R b_R - a_I b_I)
```

因此，一个复数加法相当于两个实数加法，而一个复数乘法相当于三个实数乘法和五个实数加法。

### 18.2.4.1 Linear Cancellation
对式 (`18.18`) 中线性抵消表达式的求值需要 `L` 个复数乘法和 `L - 1` 个复数加法。等价地，它需要 `N_{MUL,linear} = 3 L` 个实数乘法和 `N_{MUL,linear} = 7 L - 2` 个实数加法。

### 18.2.4.2 Polynomial Nonlinear Cancellation
式 (`18.14`) 中复值参数 `ζ_{p,q}[l]` 的总数可按 Korpi et al. (`2017`) 计算：

(18.29)
```
N_{poly} = L/4 (P + 1)(P + 3)
```
