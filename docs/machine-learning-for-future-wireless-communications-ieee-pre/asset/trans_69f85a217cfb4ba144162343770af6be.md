### 15.2.3 逐次抵消列表译码

`SCL` 译码通过并行运行多个 `SC` 译码器来提高 `SC` 译码的纠错性能。与 `SC` 译码中那样使用公式 ([15.9](#c15.xhtml#c15-disp-0009)) 来估计 ![图像](images/c15-i0050.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi mathvariant="bold-italic">u</mi></mrow></math> 不同，每个位在估计时都考虑其可能的取值 0 和 1。因此，在每次位估计时，候选数量翻倍。为了限制 `SCL` 译码的高复杂度，在每次位估计时，仅允许 ![图像](images/c15-i0051.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>L</mi></mrow></math> 个候选存活，基于路径度量计算（Balatsoukas-Stimming 等，[2015](#c15.xhtml#c15-bib-0005)，Hashemi 等，[2016](#c15.xhtml#c15-bib-0018)）
