
我们强调，尽管这种混合方法是在毫米波网络频谱共享的背景下提出的，但其要点对广泛的“无线通信机器学习”问题仍然有效：多小区网络的波束成形/合并设计、多小区协作、资源分配等。众所周知，基于模型的解决方案因巨大的计算/信令开销而失效。另一方面，获取样本——用于构建训练集——通常是通过导频传输完成的，而导频在大多数无线通信系统中是稀缺资源。这反过来意味着训练集的规模很小，大多数 `ML` 工具将失效。因此，我们认为所谓的混合方法将为解决这些问题提供一种新范式，这些问题常出现在未来的无线通信中。
