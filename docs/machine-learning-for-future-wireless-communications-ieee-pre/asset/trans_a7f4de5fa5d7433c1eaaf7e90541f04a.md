
对于两种消除器，通过反复试验发现，`L=13` 个记忆抽头足以建模等效自干扰信道。此外，对于多项式消除器，采用最大非线性阶数 `P=7`，因为进一步增加该参数对实现的自干扰抑制增益非常有限，且在某一点之后甚至由于过拟合导致性能下降。`NN` 使用 `Keras` 框架实现，后端为 `TensorFlow`。此外，训练中使用 `Adam` 优化算法，均方误差代价函数，学习率为 `λ=0.004`，小批量大小为 `B=32`。所有剩余参数均采用默认值。`NN` 具有 `2L=26` 个输入单元和 `N_h=18` 个隐藏单元。隐藏层中的神经元使用修正线性单元 (`ReLU`) 激活函数，定义为 `f_h(x)=max(0,x)`，而输出神经元使用恒等激活函数，定义为 `f_o(x)=x`。

### 18.3.2 自干扰消除结果

[图 18.3](#c18.xhtml#c18-fig-0003) 显示了使用 [第 18.2.2 节](#c18.xhtml#c18-sec-0006) 中的多项式消除器和第 [18.2.2](#c18.xhtml#c18-sec-0006) 节的 `NN` 消除器的自干扰消除结果。可以观察到，数字线性消除提供了大约 37.9 dB 的消除量，将残余自干扰功率降低至 `−80.6` dBm。多项式消除器和 `NN` 消除器均额外降低了 6.9 dB 的自干扰，导致残余自干扰功率为 `−87.5` dBm，这仅比接收机噪声基底高出 3.3 dB。在 [图 18.5](#c18.xhtml#c18-fig-0005) 中可以观察到，仅经过四个训练轮次，`NN` 就已能在训练和测试帧上实现超过 6 dB 的非线性自干扰消除。经过 20 个训练轮次后，非线性自干扰消除达到约 7 dB，且没有明显的过拟合迹象，因为训练数据和测试数据上的自干扰消除非常相似。

在 [图 18.4](#c18.xhtml#c18-fig-0004) 中可以看到，如果在 `NN` 消除器之前不进行线性消除，则实现的自干扰消除明显更差。具体而言，在这种情况下，即使是具有 `N_h=100` 个隐藏神经元的较大 `NN` 消除器，训练总共 1000 个轮次，也仅能实现 37.1 dB 的消除（已采取措施确保未发生过拟合）。该自干扰消除量与仅使用（复杂度低得多）线性消除器所实现的消除量相似。原则上，`NN` 应该能够学习同时消除信号的线性和非线性部分。然而，由于自干扰信号的非线性部分明显弱于线性部分，似乎由于使用小批量导致的梯度计算噪声几乎完全将自干扰信号的非线性结构隐藏于学习算法之外。

### 18.3.3 计算复杂度

在找到导致相同自干扰消除性能的参数集合 `P=7`、`L=13` 和 `N_h=18` 后，可以通过评估 [第 18.2.4 节](#c18.xhtml#c18-sec-0008) 中推导出的复杂度表达式，公平地比较多项式消除器与 `NN` 消除器的复杂度。更具体地说，多项式消除器需要 `N_ADD,poly=1818` 次实数加法和 `N_MUL,poly=780` 次实数乘法，而 `NN` 消除器需要 `N_ADD,NN=611` 次实数加法和 `N_MUL,NN=543` 次实数乘法。换句话说，与多项式消除器相比，`NN` 消除器所需的实数加法减少 66%，实数乘法减少 30%。这种复杂度降低在两种消除器的硬件实现中也得到了很好的体现。具体而言，当使用 28 nm FD-SOI 技术实现为 ASIC 时，`NN` 消除器被证明比多项式消除器小 11%，快 60% Kurzo 等人 ([2018](#c18.xhtml#c18-bib-0015))。所有实现结果汇总于 [表 18.2](#c18.xhtml#c18-tbl-0002)。
