
我们现在评估基于 ML 的 IRLV 性能作为 NN 复杂度的函数，即层数。[图 20.9](#c20.xhtml#c20-fig-0009) 显示了平均 MD 概率作为层数 `L` 的函数，对于固定的 FA 概率，`k_t = 10^5` 且每个隐藏层的 `N_h = 10`。请注意，训练集大小是固定的，并且随着 NN 参数数量增大，它变得不足以进行适当的训练。对于此特定设置，在所有平均 FA 概率下，最小的平均 MD 概率是在 `L = 3` 层时取得的。

## 20.5 结论
本章中，我们提出了一种将 IRLV 形式化为假设检验问题的解决方案。多个 AP 收集的功率衰减值被用作测试函数的输入，由学习机器实现。ML 算法的一个关键设计驱动因素是参数调优所需的训练样本数量，这在复杂性和分类准确性之间提供了一个权衡。我们回顾了一些关于训练集大小的关键界限，并将其应用于基于 ML 的 IRLV。

我们根据 ROC 评估了 ML 算法在模拟传播场景和实验数据方面的性能。我们通过改变隐藏层的数量探索了不同的 NN 架构，并数值评估了训练大小对 MD 概率的影响。

我们考虑的概念算法在 ML 框架中开辟了新的研究机会，例如 NN 架构可以进一步优化（在神经元数量、层形状和激活函数类型方面），以更好地适应不同的 IRLV 场景。
