
需要考虑的一些优缺点将在下文讨论，以便决定是否使用基于 ANN 或 SVR 的解决方案。虽然基于 ANN 的模型允许对多维函数进行紧凑表示，但它们存在两个主要弱点：（i）ANN 通常收敛于局部最小值而非全局最小值，以及（ii）由于 ANN 采用的传统经验风险最小化原则，它们可能出现过拟合问题。SVR 技术则采用结构风险最小化原则，避免模型过度迎合训练集的特殊性，从而防止过拟合。此外，SVR 的解是全局唯一的。关于维度，ANN 是参数模型，其大小固定并取决于其特定架构，而 SVR（基于核）由一组支持向量组成，这些向量选自训练集，每个向量都有一个权重。在最坏情况下，支持向量的数量恰好等于训练样本的数量，通常其模型大小呈线性增长。因此，如果训练样本数量很高，则 SVR 的计算复杂度也随之升高。最后，虽然 ANN 可以有任意数量的输出，但 SVR 只有一个。创建具有 SVR 的 MIMO 系统的最直接方法是创建多个支持向量机并逐一训练它们。

在当前实际情况下，ANN 因其逼近任意连续函数的能力，已成功应用于 DFE 的多个应用中。文献报道 ANN 已用于晶体管、电路和系统级建模。SVR 技术已成功应用于电路建模，用于表征和设计天线、滤波器和功率放大器。然而在系统级，基于 SVR 方法通过 DPD 对 PA 进行建模或线性化的解决方案并不像基于 ANN 的解决方案那样广泛。人们强烈认为，基于 ANN 或 SVR 的解决方案将在未来的 DFE 实现和部署中发挥非常重要的作用，包括智能矢量处理器和功能 IP 块。
