
近年来机器学习（ML）被引入无线通信，部分原因在于机器学习在科学界日益普及，另一部分原因在于无线通信中出现的问题的本质。随着计算能力的提升以及收集和存储海量数据的能力，机器学习技术已进入众多不同的科学领域，试图将上述两者充分利用。这一概念在无线通信中同样适用。此外，无线通信系统中出现的问题经常被表述为分类、检测、估计和优化问题，而机器学习技术都能为其提供优雅且实用的解决方案。在这种背景下，将机器学习应用于无线通信似乎几乎是自然而然的，并呈现出明确的动机（Bkassiny et al., [2013](#c13.xhtml#c13-bib-0005); Jiang et al., [2017](#c13.xhtml#c13-bib-0031); Chen et al., ）。

本章的目的是深入探讨人工神经网络（ANNs）对物理层产生的影响。首先，我们在[第13.2节](#c13.xhtml#c13-sec-0003)中提供了人工神经网络的概述。在[第13.3节](#c13.xhtml#c13-sec-0006)中，我们讨论了人工神经网络在物理层的具体应用，以获取信号情报。接下来，在[第13.4节](#c13.xhtml#c13-sec-0009)中，我们讨论了在机器学习背景下硬件实现的意义。最后，在[第13.5节](#c13.xhtml#c13-sec-0015)中，我们讨论了当前可能阻碍机器学习在无线系统应用的开放性问题。
