
## 多小区模型传输时延

在所考虑的多小区模型中，如果用户 `j` 请求的内容未被用户可连接的任何基站缓存，则内容文件将首先从云数据中心传输到基站 `i_hat`，即距离用户 `j` 最近的基站，然后再从基站 `i_hat` 传输到用户 `j`。因此，缓存未命中情况下的最小传输时延 `D_hat_j` 可表示为

(21.5)
```
D_hat_j = T_{c,i_hat} + T_{i_hat,j}
```

其中 `T_{c,i_hat}` 表示从云数据中心到基站 `i_hat` 的传输时延，而 `T_{i_hat,j}` 是从基站 `i_hat` 到用户 `j` 的传输时延。

然而，如果请求的文 件被可连接用户 `j` 的基站 `i` 缓存，则缓存命中情况下的传输时延 `D_j` 可表示为

(21.6)
```
D_j = T_{i,j}
```

现在，缓存未命中和命中两种情况下的传输时延已知，我们将传输时延减少量 `ΔD_j` 定义为

(21.7)
```
ΔD_j = D_hat_j - D_j
```

因此，一个操作周期内的平均传输时延减少量为

(21.8)
```
ΔD = 1/U sum_{j=1}^{U} ΔD_j
```
(21.9)
```
= 1/U sum_{j=1}^{U} (D_hat_j - D_j)
```
(21.10)
```
= 1/U sum_{j=1}^{U} (T_{c,i_hat} + T_{i_hat,j} - T_{i,j})
```
