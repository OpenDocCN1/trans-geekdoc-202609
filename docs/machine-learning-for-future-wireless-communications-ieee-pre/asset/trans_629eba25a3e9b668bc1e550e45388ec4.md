
如果环境是非平稳的，朴素的经验回放可能会出现问题。在 [`Figure 4.4`](#c04.xhtml#c04-fig-0004) 中展示的是我们使用原始 `DQN` 算法实验中的一个例子。顶部曲线显示了在一分钟时间窗口内平滑后的每个时间步的平均请求数。流量模式明显是非平稳的。受流量变化驱动，回放记忆中的经验分布（中间曲线）在以唤醒为主和以休眠为主的模式之间振荡。由于 `Eq. ### 4.3.3.1 按动作划分的经验回放

在现实世界中经常遇到的非平稳流量模式下，朴素的经验回放方法可能存在问题。如 [`Figure 4.4`](#c04.xhtml#c04-fig-0004) 所示，描绘了一个明显非平稳的真实流量轨迹。在这种情况下，朴素的经验回放可能会过早收敛到当前流量模式，而不适用于未来的变化。就此而言，我们提出了一种按动作划分的经验回放方法。不同流量阶段的经验存储在同一个经验回放缓冲区中，使得学习过程免受对特定流量阶段过拟合的影响。
