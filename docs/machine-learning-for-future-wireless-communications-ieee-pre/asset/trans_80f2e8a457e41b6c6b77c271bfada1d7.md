
# 主动星座扩展与神经网络仿真

为了降低包络波动从而降低 `PAPR` 值，在 `ACE` 中，部分外层信号星座符号会被动态扩展到不影响解调判决的区域。`ACE` 不需要边信息；然而，由于其通常收敛缓慢，获得降低的 `PAPR` 信号可能需要相当长的时间。为了降低复杂度并提升诸如 `SLM`、`PTS` 和智能梯度投影 (`SGP`) `ACE` 等经典方案的性能，Jabrane 等人在 ([2010](#c17.xhtml#c17-bib-0047)) 中提出将近似梯度投影 (`AGP`) `ACE` 与 `RV MLP ANN` 相结合。`ACE` 模块中的 `AGP` 算法（优先考虑收敛性而非速度）将为 `ANN` 提供训练和验证信号，该网络将利用反向传播 `LM` 算法学习低包络波动信号的特性。由于时域 `RV ANN` 很难学习哪些星座区域是允许的、哪些是不允许的，因此在时域 `ANN` 模型使用 `AGP` 时域选定测试数据进行验证后，将一个工作在频域的第二 `ANN` 与之前的 `ANN` 级联。在第二个 `ANN` 中，`DFT` 同时应用于来自前一个 `ANN` 的输入实部和虚部训练数据，以及 `AGP` 提供的数值。之后，训练数据被分离为四个星座区域，以 `LM` 算法训练八个 `ANNs`（每个变换后的实部和虚部分量各有四个 `ANNs`）；一旦 `ANNs` 训练完成，则使用 `AGP` 频域选定的测试数据进行验证。这些信息在 [图 17.24](#c17.xhtml#c17-fig-0024) 中以可视化方式表示（即当所有开关处于“关”状态时，仅时域 `ANN` 工作；当开关处于“开”状态时，时域和频域 `ANNs` 同时工作）。该过程被理解为设置整体 `ANN` 参数的初始离线训练。内部 `ANNs` 具有一个隐藏层，包含两个神经元并使用三角激活函数，这导致整数乘法和整数加法的数量与子载波数成比例。与 `SLM` 和 `PTS` 相比，经过训练的 `AGP-ACE` `RV MLP ANN` 方案变得更简单（总操作数约为一个数量级更少），因为它不需要那么多 `IFFT` 操作（仅需两个），并且操作更简单（即主要为整数运算）且更易并行化。前文作者还提供了对调制 512、1024 和 2048 个子载波的 50,000 个随机生成的 `QPSK` 和 `16-QAM` 符号的仿真结果。约 70% 的数据用于训练，30% 用于验证。对于 512 个子载波，`AGP-ACE` 在三次度量 (`CM`) 方面比所提出的 `ANN` 方法（时域或时频域 `ANN`）表现好约 0.9 dB，`CM` 比 `PAPR` 度量更精确地表征 `PA` 回退，而对于 2048 个子载波则仅好约 0.35 dB。与 `SLM` 相比，`ANNs` 在 512 和 1024 个子载波时分别好 0.3 dB 和 0.9 dB，在 512 个子载波时与 `PTS` 性能相似，但在 2048 个子载波时约好 0.75 dB。因此，`RV MLP` 时频 `ANNs` 的性能优于 `SLM` 和 `PTS`，略逊于 `AGP-ACE`，但计算复杂度降低。关于 `BER` 与 `SNR` 的特性，时频域 `ANN` 的性能优于其他方法（当调制阶数增加时更为明显）。这是因为在 `ANN` 方法中，与 `ACE` 相比，映射到外层星座点的符号从原始位置的扩展更小，因此星座能量保持更集中。此外，由于扩展到允许区域的符号数量更多（注意在此区域符号受系统噪声影响较小），只有少数符号会经历有效更低的 `SNR`。在 Jiménez 等人 ([2011](#c17.xhtml#c17-bib-0053)) 中，作者在相同的时频域 `ANN` 架构之上构建了自适应神经模糊推理系统 (`ANFIS`)。`ANFIS` 用于通过应用模糊启发式规则作为自适应网络来合成未知行为，该网络可结合 `LS` 方法计算反向传播梯度向量。时域 `ANFIS` 学习哪些时域信号具有较低的包络波动，而时频域 `ANFIS` 学习哪些星座区域是允许的、哪些是不允许的。还为 `SLM` 和 `PTS` 变体、`SGP-ACE` 以及时域 `ANFIS` 和时频域 `ANFIS` 提供了详细的复杂度基准测试。这些方法的一个修改版本是如 Sohn ([2014](#c17.xhtml#c17-bib-0104)) 所示移除频域 `ANN`。然而，该架构在接收端（信道均衡后）构建了另一个时域 `ANN`。`Rx ANN` 使用 `Tx ANN` 输出进行训练，并以原始 `OFDM` 信号作为期望信号（在 `Tx` 端，`ANN` 的期望信号由 `ACE` 给出，如前例工作中所述）。再次强调，所有这些 `ANN`
