
# 强化学习过程

在学习过程的 `kth` 阶段，智能体在观测到的状态 `s_k ∈ S` 下执行动作 `a_k ∈ A`。在下一阶段，在状态以概率 `P(s_k, a_k, s_{k+1})` 转变为 `s_{k+1} ∈ S` 之前，智能体接收到环境生成的奖励 `R_k(s_k, a_k)`。随后，类似的过程继续进行，智能体从环境中接收一系列后续奖励 `R_{k+1}`、`R_{k+2}`、`R_{k+3}`、…。

智能体的目标是找到一个策略 `π`，该策略定义了从状态到动作的映射行为 – `π: S → A` – 以尽可能获得折扣累积奖励。用 `π(s)` 表示智能体在状态 `s` 下采取的动作，则累积奖励是与状态值相关的一个函数，可通过以下方式计算

(9.19)

```
V^π(s) = Σ_{k=0}^{∞} γ^k R_k(s_k, π(s_k) | s_0 = s)
       = R(s, π(s)) + γ Σ_{s' ∈ S} P(s' | s, π(s)) V^π(s')
```

其中 `0 ≤ γ ≤ 1` 是用于加权长期累积奖励的折扣因子。折扣因子决定了未来奖励对累积奖励函数的贡献程度。

随着时间的推移，未来奖励变得越来越不可靠和难以预测，因此未来奖励的重要性不如当前奖励，故 `γ ≤ 1`。更具体地说，如果折扣因子接近 0，智能体高度重视当前奖励而几乎忽略未来奖励，而 `γ` 的更高值会使智能体更加重视长期未来奖励。
