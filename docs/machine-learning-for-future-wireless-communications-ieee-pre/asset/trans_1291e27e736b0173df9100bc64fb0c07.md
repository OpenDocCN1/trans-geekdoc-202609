## 环境
为了进行实验，我们考虑无线蜂窝网络，其中有一个上层服务器、![图像](images/c21-i0096.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>N</mi></mrow></math> 个本地内容服务器，以及 ![图像](images/c21-i0097.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>U</mi></mrow></math> 个用户分布在服务器的覆盖区域内。允许智能体自行做出缓存决策并相互协作，框架变为集中式评论网络与去中心化行动者网络相结合。因此，智能体将自己的观测输入行动者网络，并将完整的状态空间输入评论网络。
