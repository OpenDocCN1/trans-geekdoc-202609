### 20.2.3 ML Classification Optimality

首先需要解决的问题是 `ML` 方法是否在某种程度上等价于最优的 `NP` 方法。请注意，`ML` 方法的性能显著取决于 (i) 模型的复杂性/配置，例如 `NN` 的神经元或特征空间变换函数，以及 (ii) 大小/类型，例如训练集中两个类别的衰减之间的平衡。

因此，我们仅期望在无限大小的训练集和足够（无限）复杂的模型下实现 `NP` 检验的性能。确实，Brighente 等人 ([2018](#c20.xhtml#c20-bib-0004)) 已证明在这些渐近条件下，基于 `NN` 和 `LS-SVM` 的检验均能达到 `NP` 检验的性能。

为了证明这一点，采用 `MSE` 准则进行 `NN` 设计，Ruck 等人 ([1990](#c20.xhtml#c20-bib-0010)) 已证明其收敛于贝叶斯最优判别函数的最小 `MSE` 近似

## 20.3 Learning Phase Convergence

对于 `ML` 方法而言，训练阶段的收敛速度是一个关键问题：虽然更大的训练集可以更好地调整机器参数，但训练所带来的复杂性（和时间）也会增加。在此，我们首先回顾训练集大小关于期望分类精度的一些理论界限，然后给出所考虑的 IRLV 场景的一些数值结果。

### 20.3.1 Fundamental Learning Theorem

学习算法的性能可以在 *大概正确* (`PAC`) 学习框架内进行分析。为此，我们首先回顾两个基本概念：`PAC` 可学习性和 Vapnik-Chervonensky (`VC`) 维数。
