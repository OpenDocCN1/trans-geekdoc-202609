梯度下降算法的另一个缺点是它可能陷入局部最小值。然而，（Goodfellow 等，[2016](#c12.xhtml#c12-bib-0024)）认为许多机器学习模型在用梯度下降算法训练时可以工作良好。此外，作者指出，尽管不能保证在合理时间内找到全局最小值，但该算法通常可以快速找到损失函数的值，该值对于实际目的来说足够低。因此，这一特性使梯度下降算法在实践中很有用。
