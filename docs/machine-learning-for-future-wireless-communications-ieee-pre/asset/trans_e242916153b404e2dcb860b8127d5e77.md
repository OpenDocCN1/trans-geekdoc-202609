5G 无线网络预计不仅要克服当前蜂窝网络的局限性，还要解决新的用例和场景，使广泛的新应用成为可能。预计到 2030 年，数十亿台设备将连接到移动网络 (Cisco, [2017](#c06.xhtml#c06-bib-0011))，因此 5G 必须为大量设备提供连接。此外，5G 还必须在任何地方提供覆盖和容量，同时增强用户体验和数据速率 (Huawei, [2013](#c06.xhtml#c06-bib-0023); Valente Klaine et al., [2017](#c06.xhtml#c06-bib-0039))。然而，人们提出了巨大担忧，因为为了实现所有这些要求，预计 5G 网络的能耗将比当前系统高出一千倍 (Buzzi et al., [2016](#c06.xhtml#c06-bib-0009))。为了克服这一点，5G 网络必须变得非常节能，推动开发更绿色、更可持续的网络，不仅针对基站 (BSs)，还针对移动设备 (Tullberg et al., [2016](#c06.xhtml#c06-bib-0037))。因此，能源效率 (EE) 已成为现代通信场景的主要目标之一，学术界和工业界的多个研究团体已将工作重点放在这一主题上。
