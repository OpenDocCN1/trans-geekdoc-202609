### 1.2.5.3 High‐Level Pseudocode and Implementation Discussion
To summarize the discussion, the cognitive user applies the following algorithm:
1. For all ![images](images/c01-i0114.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>K</mi></mrow></math> channels, execute an exploration epoch where a single observation is taken from each channel.
2. If condition Eq. ([1.7](#c01.xhtml#c01-disp-0007)) holds for some channel (say ![images](images/c01-i0115.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>i</mi></mrow></math>), then execute an exploration epoch for channel ![images](images/c01-i0116.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>i</mi></mrow></math>; and, when completing the exploration epoch, go to Step 2 again. Otherwise, go to Step 3.
3. Execute an exploitation epoch. When completing the exploitation epoch, go to Step 2.
