## 16.3 过时信道状态信息的影响

从实际角度来看，在选择传输参数时使用的信道状态信息可能与使用所选参数进行传输的瞬时信道状态信息存在很大差异。利用过时的信道状态信息而非实际信道状态信息可能会严重恶化系统性能。本节首先提供一个数学模型来量化过时信道状态信息的误差，然后以 `ORS` 系统为例说明过时信道状态信息对自适应传输系统性能的影响。
