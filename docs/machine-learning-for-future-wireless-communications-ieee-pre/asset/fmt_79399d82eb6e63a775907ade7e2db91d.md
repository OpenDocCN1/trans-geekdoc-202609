
We underline that although this hybrid approach was presented in the context of spectrum sharing in millimeter‐wave networks, the take‐home messages are valid for a wide class of “machine leaning for wireless communications” problems: beamforming/combining designs for multi‐cell networks, multi‐cell coordination, resource allocations, etc. It is well known that model‐based solutions for these problems fail due to the huge computational/signaling overhead. On the other hand, acquiring samples – needed to build the training set – is generally done with pilot transmissions, which are scarce resources in most wireless communication systems. This in turn implies that the size of the training set is small, and most `ML` tools will fail. Thus, we believe that the so‐called hybrid approach will offer a new paradigm for solving these problems, often encountered in future wireless communications.
