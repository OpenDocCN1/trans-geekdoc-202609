
# LASSO Regression

The least absolute shrinkage and selection operator (`LASSO`) regression analysis method was introduced in `Tibshirani` ([1994](#c17.xhtml#c17-bib-0111)). Similarly to `Ridge` regression, `LASSO` can be used for both regularization and to generate a sparse model (i.e. reducing the number of parameters or components of the model). Whereas the constraint of the `Ridge` regression is the sum of square of the coefficients, the `LASSO` constraint consists of the sum of the absolute value of the coefficients.
