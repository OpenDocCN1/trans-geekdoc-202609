## 5.3 资源最小化方法

在本节中，DP 到基站的分配是基于分配矩阵和用于范围扩展的偏置值的优化设计来处理的。为此，提出了一个混合整数线性规划 (MILP)，其中分配和偏置值被选择以在满足每个 DP 的 QoS 约束的同时最小化网络总资源消耗。所提出的优化设计计算需求高，且随问题网络规模呈指数增长，因此对于大规模网络的在线优化是不可行的。此外，该问题必须在具有网络范围 CSI 信息的中央计算机上求解。此信息包括例如网络范围的信道条件、负载水平和可实现的数据速率。集中式 CSI 的使用是一个主要问题，因为它需要在网络中进行全局控制信息交换，这在实践中是不可行的。因此，我们在 [小节 5.3.2](#c05.xhtml#c05-sec-0010) 和 [5.3.4](#c05.xhtml#c05-sec-0012) 中考虑了一种完全去中心化的基于监督学习的方案，以获得具有低复杂度和局部 CSI 的接近最优的 DP 分配解。基于本节中介绍的整数规划问题的最优解，生成数据标签。这些标签与本地可用的网络信息结合使用，从中提取选择性特征，以便训练分类器来复制优化的行为。
