
在本章中，我们概述了用于在同一频段共存的用户之间实现高效频谱共享的 DSA 算法。DSA 算法的运行基于根据部分观测动态学习环境，通过持续监控系统性能并审慎调整传输参数以实现高频谱效率。

我们首先关注在线学习算法，这些算法用于在存在外部用户的情况下学习频谱占用情况以提高频谱利用率。随后，我们关注用于以分布式方式有效分配信道给用户的算法，其目标是最大化某个全局目标。最后，我们关注了基于深度学习的用于 DSA 的人工智能（AI）算法的最新进展，这些算法能够有效自适应复杂的现实世界环境。

现有的用于 DSA 的 AI 算法主要基于价值学习（即 Q‐learning）方法来获取 DSA 策略。在这方面未来的研究方向是开发基于策略的学习和混合价值/策略学习，旨在直接学习策略，以在状态空间增大时改善收敛性。另一个研究方向是开发基于 DRL 的算法，用于用户在具有多包接收的干扰信道上传输的情况。
