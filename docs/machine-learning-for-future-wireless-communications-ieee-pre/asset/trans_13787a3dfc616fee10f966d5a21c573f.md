
[图 16.11](#c16.xhtml#c16-fig-0011) 说明了 `MIMO-OFDM` 系统在由 `3GPP` 扩展典型城市（`ETU`）模型指定的频率选择性信道中实现的性能，最大多普勒频移为 `f_d = 300` Hz。首先，`RNN` 预测器被调至单步预测模式（`D = 1`），以便与 `KF` 预测器进行直接比较。预测步长 `D = 1` 相当于 64 us 的时间范围，而相干时间为 `T_c ≈ 1 / f_d = 3.3` ms。以完美模式的曲线作为基准，`KF` 预测器实现了最佳性能。尽管 `RNN` 预测器略逊于 `KF` 预测器，但它仍然非常接近最佳性能，并且明显优于过时模式。信道插值误差定义为完美 CSI 与插值 CSI 之间的差异，在信道估计过程中也是一个关注点，因此评估了插值误差对性能的影响。为了更好地说明，选择了导频间隔为 `N_P = 3` 的结果在图中展示。即使在单步预测 `D = 1` 模式下，过时的 CSI 在中断概率为 `1e-3` 时与完美模式相比也有 3.6 dB 的显著损失。`KF` 预测器容易受到插值误差的影响，导致的结果非常接近过时模式。相比之下，`RNN` 预测器具有鲁棒性，并以 3.1 dB 的 SNR 增益优于 `KF` 预测器。为了观察信道相关性的影响，应用了由 `3GPP` LTE 标准为 `ETU` 信道推荐的相关矩阵生成的相关信道。在 `α = 0.3` 指示的中等相关性以及 `D = 5` 的多步模式下，过时的 CSI 在 `P(R) = 1e-2` 时与完美模式相比性能损失约为 5 dB，而信道预测可以收回近 4 dB。如前所述，`KF` 预测器只能进行单步预测，因此不适用于此情况。

## 16.6 摘要

本章全面介绍了信道预测技术，重点在于基于 `NN` 的预测。开始时，简要介绍了两种代表性自适应传输系统的原理——：发射天线选择和机会中继——，随后是过时 CSI 对性能的影响。然后，回顾了基于统计建模的经典信道预测方法，即参数模型和自回归模型。在解释了循环 `NN` 的内部结构后，详细介绍了基于 `RNN` 的多步预测，该预测可应用于平坦衰落和频率选择性信道中的 `SISO` 或 `MIMO` 系统。为了进一步阐明 `RNN` 预测器的机制，说明了将预测器集成到 `MIMO-OFDM` 系统中以提高发射端天线选择正确性的情况。在 `3GPP` `ETU` 信道模型指定的多径衰落环境中，考虑了空间相关性、多普勒频移以及插值误差等多种影响因素的性能结果得以展示。已验证应用 `RNN` 预测器来解决过时 CSI 问题是有效且高效的。尽管其计算复杂度高于卡尔曼滤波器，但所需计算资源相对于现成硬件仍然可以承受。总之，`RNN` 在无线衰落信道预测应用中表现出很强的灵活性、通用性、可扩展性和适用性，因此可被视为未来无线通信中非常有前景的机器学习技术。
