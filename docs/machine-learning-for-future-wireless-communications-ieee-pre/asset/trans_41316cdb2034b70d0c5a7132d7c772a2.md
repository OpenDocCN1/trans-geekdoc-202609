
# 神经网络训练与输出层

## 随机梯度下降

训练大多数类型神经网络最常见的方式是称为随机梯度下降（`SGD`）的优化方法。`SGD` 与众所周知的梯度下降方法类似，不同之处在于在更新参数时并未使用相对于模型参数的损失函数的真实梯度。通常，梯度是使用单个训练样本或整个训练集的某个子集相对于损失计算的，该子集通常被称为 `mini-batch`，从而得到 `mini-batch SGD`。这导致网络的更新遵循噪声梯度，而实际上这通常有助于网络的学习过程，因为它能够避免在神经网络的非凸损失景观中普遍存在的局部最小值处收敛。将 `SGD` 应用于模型参数的标准方法是通过使用 Rumelhart 等人开发的著名 `back-propagation` 算法反复应用求导的链式法则。([1986](#c13.xhtml#c13-bib-0053))。

## 输出层

给定神经网络中的最后一层称为 `output layer`。`output layer` 与内部层不同之处在于，`output layer` 中使用的 `activation function` 的选择与 `loss function` 的选择以及网络输出的期望结构紧密相关。通常，关于 `output layers` 和 `loss functions` 的以下讨论适用于所有神经网络，包括本节后面介绍的那些。
