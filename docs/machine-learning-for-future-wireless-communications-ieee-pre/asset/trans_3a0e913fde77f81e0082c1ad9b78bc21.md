
# 学习率与动量对 BPLA 收敛的影响

为了保证 `BPLA` 的收敛性，在最小化估计误差的算法中引入了学习率和动量项。正如在经典的 `DPD` 学习方案中所发现的，学习率控制着收敛速度。如果学习率过小，收敛会非常缓慢，达到期望的建模性能需要更多的 epoch；而如果过高，则可能使算法发散。在 Bertsekas 和 Tsitsiklis ([1996](#c17.xhtml#c17-bib-0006)) 中，最佳学习率由输入信号的 Hessian 矩阵得出，然而该矩阵随时间变化显著且计算上复杂难以跟踪。在 Mkadem 和 Boumaiza ([2011](#c17.xhtml#c17-bib-0075)) 中，作者提出在每个 epoch 根据网络输出与期望输出之间的误差是否分别满足期望性能，对学习因子施加递增或递减的速率。鉴于即使选择了合适的学习率，`BPLA` 仍可能收敛到局部最优，为了更好地逼近全局最优，作者遵循 Plaut 等人 ([1986](#c17.xhtml#c17-bib-0091)) 的做法并将动量项纳入 `BPLA`。该因子以振荡下降解的形式，将当前和过去误差的相对贡献添加到估计参数的当前变化中。因此，`ANN` 建模性能可以通过先在静态或动态学习率之间选择，然后在静态或动态动量项之间选择来进行基准测试。通过考虑 `Eq. (17.44)` ([17.44](#c17.xhtml#c17-disp-0044))，Jaraut 等人 ([2018](#c17.xhtml#c17-bib-0049)) 中的作者采用的学习率初始值为 0.01。根据性能指标 ![images](images/c17-i0241.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>E</mi></mrow></math> 是增加还是减少，学习率分别乘以或除以一个额外因子 ![images](images/c17-i0242.png)<math xmlns="http://www.w3.org/1998/Math/MathML" display="inline" overflow="scroll"><mrow><mi>β</mi></mrow></math>，其值设为 10。

# ANN 设计流程

为了在建模性能和处理复杂度之间实现更好的权衡，在寻找基于 `ANN` 的解决方案时应遵循以下流程，尽管不存在通用规则：

## 输入数据记忆深度

输入信号的记忆深度通常通过在建模性能或 `NMSE`（表征期望输出与 `ANN` 获得的输出之间的误差）以及复杂度方面对不同深度值进行基准测试来选择。例如，如果抽头数量能够显著减少且获得的 `NMSE` 根据应用要求已足够，则比最佳 `NMSE` 低 2 dB 的记忆抽头设置可能是最优的。对 `PA` 物理特性的了解以及设计人员在宽带调制信号下评估 `PA` 响应的专业知识可以帮助减少需要评估的情况数量。

## 隐藏层和神经元数量

Cybenko ([1989](#c17.xhtml#c17-bib-0020)) 的通用逼近定理已在本章中介绍过，以证明单隐藏层 `ANN` 在使用合适的激活函数时能够以任意期望误差逼近任何非线性函数的能力。然而，该定理并未在学习时间（或 epoch）、实现复杂度、隐藏神经元数量或对未训练数据的泛化能力方面指定最佳解决方案，并且假设训练数据无噪声，而在实际测量数据中这一假设并不总是成立。多项分析双隐藏层与单隐藏层 `ANN` 方案性能的研究得出结论，双隐藏层 `ANN` 具有更好的泛化能力和对训练数据噪声的稳定性。Chester ([1990](#c17.xhtml#c17-bib-0018)) 证明，增加第二个隐藏层可以滤除单隐藏层操作无法滤除的测量噪声（因为后者建模噪声而不是滤除噪声）。Hush 和 Horne ([1993](#c17.xhtml#c17-bib-0043)) 证明，双隐藏层网络在逼近建模函数时可能需要的总神经元数量少于单隐藏层方案。总体而言，很难找到选择隐藏层数量的通用确定性方法，因为它们需要在大量不同的数据集下进行验证。因此，隐藏层的最终经验选择最终可能由 `ANN` 的整体大小或复杂度、学习时间和建模精度之间的权衡驱动（Thomas 等人 ([2016](#c17.xhtml#c17-bib-0110))）。

尽管 `PA` 非线性越强，隐藏层（具有非线性激活函数）中的神经元数量越大，但在选择每个隐藏层的最佳神经元数量时并没有具体规则。然而，`ANN` 的复杂度可以通过结合偏差-方差困境（Geman 等人 ([1992](#c17.xhtml#c17-bib-0027))）和交叉验证技术（Stone ([1978](#c17.xhtml#c17-bib-0107))，Haykin ([2009](#c17.xhtml#c17-bib-0040))）所获得的泛化误差来设定。偏差误差可以看作在使用训练或估计数据集时，`ANN` 模型输出数据与期望数据相差多远。较高的偏差误差表明欠拟合。方差误差来自于使用验证数据集评估 `ANN` 输出时，对训练数据集上微小变化的敏感性。较高的方差误差表明 `ANN` 在建模训练数据中的随机噪声而非预期输出，从而出现过拟合。当隐藏神经元数量增加时，偏差误差通常会减小，而方差误差会增加。这些参数在反向传播算法中被考虑，该算法分阶段学习，随着训练会话的进行以及迭代或 epoch 数量的增加，从实现更简单到更复杂的映射函数。使用此流程，训练会话会定期停止（即每五个 epoch），并且在获得 `ANN` 权重和偏置值后，在每个周期对模型在验证子集上进行测试。在训练期间，随着 epoch 数量的增加，估计的 `MSE` 单调递减，而在验证中，`MSE` 曲线先下降到最小值然后上升（学习算法开始对训练数据集建模噪声）。早期的 `MSE` 最小值可以定义选择 `ANN` 参数的停止点；然而，epoch 数量通常会增加到该停止点之外，以检查早期的 `MSE` 最小值是否为局部最小值，然后选择最合适的停止点。交叉验证方法和剪枝程序的几种改进版本可在 Haykin ([2009](#c17.xhtml#c17-bib-0040)) 中找到。
