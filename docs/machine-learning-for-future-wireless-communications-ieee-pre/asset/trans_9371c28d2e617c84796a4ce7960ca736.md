
无线通信设备的位置信息如今被用于各种服务，例如社交网络、游戏、内容分发系统和导航。仅依赖设备自身报告信息的定位相关应用很容易被恶意用户通过篡改软件或全球导航卫星系统（`GNSS`）接收机而修改。

为了有效抵御这些攻击，位置验证系统独立于报告的位置验证用户位置。特别是，*区域位置验证*（`IRLV`）旨在评估用户是否处于特定授权区域或*感兴趣区域*（`ROI`）。为此，网络检查通信发生的物理层信道的*特征*。一般而言，任何与用户位置相关的信道特征——例如与视距接收、反射、散射和多普勒现象相关的分量——都可被利用，本章重点关注宽带信道在各种频率下的衰减，从而考虑多径、路径损耗、阴影和衰落。事实上，其中一些特性（如衰落）实际上充当信道路径损耗的干扰，而路径损耗最能准确标识位置。

`IRLV` 可被视为设备位于 `ROI` 内部或外部两种假设之间的假设检验问题。由于上述干扰，检验结果会受到两种类型误差的影响：虚警（`FAs`），发生在 `ROI` 内部的用户被分类为外部时；以及漏检（`MDs`），发生在 `ROI` 外部的用户被分类为内部时。最优[1](#c20.xhtml#c20-note-0001) 检验由 Neyman-Pearson（`NP`）定理给出，由 Neyman 等人提出（[1933](#c20.xhtml#c20-bib-0008)）。

为了执行 `NP` 检验，需要在两种假设下信道特征的概率密度函数（`PDFs`）。然而，`PDFs` 的闭式表达式可能无法立即获得，例如在新环境部署时或环境随时间变化时。在这种情况下，机器学习（`ML`）方法提供了合适的解决方案，如 Brighente 等人（[2018](#c20.xhtml#c20-bib-0004)）所讨论的：在学习阶段，估计位于 `ROI` 内部和外部的可信设备的信道特征，并训练合适的模型以将特征分类为两个类别。在 `ML` 分类解决方案中，本章重点关注使用神经网络（`NNs`）和支持向量机（`SVMs`）的方法（有关这些主题的介绍，请参阅 Bishop（[2006](#c20.xhtml#c20-bib-0003)））。

## 文献综述
一些关于 `IRLV` 的工作假设特征测量不受误差影响并且与设备位置以确定性方式相关，因此既不会产生 `FAs` 也不会产生 `MDs`。Sastry 等人（[2003](#c20.xhtml#c20-bib-0011)）首次研究了 `IRLV` 问题，其中验证网络的接入点（`APs`）测量与被测设备超声链路的往返时间（与 `AP`–设备距离相关）。使用经验方法，如果往返时间低于根据声称用户位置计算的阈值，则验证位置。Vora 和 Nesterenko（[2006](#c20.xhtml#c20-bib-0017)）利用无线电波，因为设备发送功率递增的消息序列：如果 `ROI` 内部的 `APs` 比外部的 `APs` 更早检测到消息，则用户被分类为位于 `ROI` 内部。Singelee 和 Preneel（[2005](#c20.xhtml#c20-bib-0013)）使用由每个 `AP` 级联运行的距离边界协议（`DBPs`）来限定 `APs` 与被测设备之间的距离上限，表明使用至少三个 `APs` 和三角测量技术可以获得准确的 `IRLV`。Song 等人（[2008](#c20.xhtml#c20-bib-0014)）在车载自组织网络的背景下使用 `DBPs`，其中 `IRLV` 用于防止 `GNSS` 欺骗。

Wei 和 Guan（[2013](#c20.xhtml#c20-bib-0018)）考虑了检验误差的存在，他们采用了类似于 Vora 和 Nesterenko（[2006](#c20.xhtml#c20-bib-0017)）在传感器网络背景下的策略。在这种情况下，如果在给定观察到的特征的情况下该事件的概率高于阈值，则用户被分类为位于 `ROI` 内部，因此再次需要信道特征的 `PDF`。Yan 等人（[2016](#c20.xhtml#c20-bib-0019)）在更复杂的模型（接收功率包括高斯空间相关阴影）和更复杂的攻击（攻击者可以调整发射功率）下使用 `NP` 检验。在 Brighente 等人（[2018](#c20.xhtml#c20-bib-0004)）中，首次引入了 `ML` 策略应用于 `IRLV` 问题，并建立了 `NN` 和 `SVM` 分类器与 `NP` 检验的联系。

`ML` 方法已在与 `IRLV`密切相关的问题中得到应用，即*用户认证*，旨在通过检查消息是否通过与先前已认证消息相同的信道来验证消息是否来自声称的发送方。在这种情况下，Pei 等人（[2014](#c20.xhtml#c20-bib-0009)）使用三种信道特征（信道脉冲响应、接收信号强度和到达时间），并采用 `SVM` 或线性 Fisher 判别分析算法（参见 Fukunaga（[2013](#c20.xhtml#c20-bib-0005)））。Abyaneh 等人（[2018](#c20.xhtml#c20-bib-0002)）则在接收信号上应用 `NN` 分类器。

## 章节目标与大纲
本章分析用于 `IRLV` 的 `ML` 算法，重点关注多层 `NN` 和 `SVM` 方法。由于这些解决方案在收敛时有效地匹配 `NP` 假设检验的性能（参见 Brighente 等人（[2018](#c20.xhtml#c20-bib-0004)）），它们在计算复杂度、资源消耗和处理延迟方面既有效又高效。

本章其余部分组织如下。[第20.1节](#c20.xhtml#c20-sec-0004) 描述了 `IRLV` 系统模型并回顾了最优假设检验框架。[第20.2节](#c20.xhtml#c20-sec-0006) 介绍了 `ML` `IRLV` 流程并简要回顾了 `NNs` 和 `SVMs` 的基础。我们还讨论了基于 `ML` 的分类的最优性。[第20.3节](#c20.xhtml#c20-sec-0010) 回顾了 `ML` 解决方案的复杂度-性能权衡的理论结果，这些结果将用于评估基于 `NNs` 的方法性能。[第20.4节](#c20.xhtml#c20-sec-0017) 展示了在蜂窝系统衰减值实验数据集上获得的结果；最后一节我们提出进一步讨论和结论。
