
Another similar work is shown in (Doan et al., [2018](#c14.xhtml#c14-bib-0005)). In this paper, the authors propose `NSC` (neural `SC`) decoding, which is constructed of multiple `NNDs` connected with `SC` decoding in a way similar to the previous paper (Cammerer et al., [2017](#c14.xhtml#c14-bib-0003)). The result shows that the `NSC` decoder has similar `BER` and `FER` performance in comparison with `PNN` in (Cammerer et al., [2017](#c14.xhtml#c14-bib-0003)), `SC`, and `BP` decoders. However, from the perspective of complexity, the `NSC` decoder can reduce the number of time steps required for the `PNN` decoder with the same error‐correction performance. The decoding architecture (`N=8`) is shown in [图 14.9](#c14.xhtml#c14-fig-0009). For more detailed information, readers can refer to (Doan et al., [2018](#c14.xhtml#c14-bib-0005)).

### 14.2.3 用于联合均衡和信道解码的 DNN

除了信道解码之外，在通信系统中同时训练多个模块（如均衡和解码）也已成为研究的课题。 这是因为神经网络（如 `DNNs`）本质上是黑盒，可以同时学习这些模块的特征。

在实际通信系统中，由于信道具有记忆性，并且放大器和转换器引入了非线性失真，因此存在码间干扰（`ISI`）。 信道均衡用于处理 `ISI` 并恢复传输信号。 但在均衡步骤之后，噪声将不再是高斯白噪声。 因此，在考虑均衡和解码时，很难保证性能仍然良好。 相反，基于 `DL` 的联合考虑这两个步骤的方法可能解决此问题。

为了进一步提高性能，另一篇论文 (Xu et al., [2018](#c14.xhtml#c14-bib-0029)) 提出了一种联合信道均衡器和解码器。 与之前的架构不同，他们分别使用 `CNN` 进行均衡，使用 `DNN` 进行解码。 架构如图 [图 14.11](#c14.xhtml#c14-fig-0011) 所示。

首先使用 `CNN` 均衡器来补偿信号失真。 然后将另一个极化 `DNN` 解码器连接到 `CNN` 之后以解码恢复的序列。 使用 `CNN` 进行均衡的原因是 `CNN` 具有强大的特征提取能力。 `CNNs` 可以处理非线性信道模型，因为 `ISI` 仅存在于传输序列的连续比特之间，并且非线性失真的影响对每个比特都是独立的。

在信道均衡的情况下，`CNN` 的输入格式是 1-D 向量，而不是图像处理领域典型的 2-D 图像。 然后可以使用多层 `DNN` 来解码 `CNN` 网络均衡器的输出。 换句话说，`DNN` 的输入是从 `CNN` 均衡器得到的 1-D 向量。
