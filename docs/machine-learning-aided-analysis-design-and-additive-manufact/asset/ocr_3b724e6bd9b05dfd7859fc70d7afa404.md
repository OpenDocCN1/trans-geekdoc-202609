where the coefficients $f_{0,0}, f_{0,1}, f_{1,0}, f_{n1,2}$ of Chebyshev polynomials for 2D model can be obtained by Chebyshev orthogonality [29] as shown below:

```
$f_{0,0} = \frac{1}{p_1 p_2} \sum_{i_1=1}^{p_1} \sum_{j_1=1}^{p_2} f(x_{i_1}, y_{j_1}) \quad i_1 \ge 1$
ff_{1,0} = \frac{2}{p_1 p_2} \sum_{i_1=1}^{p_1} \sum_{j_1=1}^{p_2} f(x_{i_1}, y_{j_1}) T_1(x_{i_1}) \quad i_1 \ge 1$
ff_{0,1} = \frac{2}{p_1 p_2} \sum_{i_1=1}^{p_1} \sum_{j_1=1}^{p_2} f(x_{i_1}, y_{j_1}) T_1(y_{j_1}) \quad i_2 \ge 1$
ff_{1,1} = \frac{4}{p_1 p_2} \sum_{i_1=1}^{p_1} \sum_{j_1=1}^{p_2} f(x_{i_1}, y_{j_1}) T_1(x_{i_1}) T_1(y_{j_1}) \quad i_1 \ge 1, i_2 \ge 1$
```

Similarly, the multidimensional systems can be obtained by making the tensor product w.r.t. each one dimensional polynomial, such as:

```
$f(\mathbf{x}) \approx g(\mathbf{x}) = \sum_{i_1=0}^{p_1} \cdots \sum_{i_n=0}^{p_n} \left(\\frac{1}{2}\right)^{\eta} f_{i_1, \dots, i_n} T_{i_1}(x_{i_1}) \cdots T_{i_n}(x_{i_n})$
```

where $\mathbf{x} = [x_1, x_2, \dots, x_n]$; $n_i$ denotes the degree in each dimension of the Chebyshev polynomial; $\eta$ represents the total occurrence of zeros in subscripts $i_1, \dots, i_n$; and $T_{i_1, \dots, i_k}$ is the $k$-dimensional Chebyshev polynomials, which can be expressed as:

```
$T_{i_1, \dots, i_k}(\mathbf{x}) = T_{i_1}(x_{i_1}) \cdots T_{i_k}(x_{i_k}), x_i \in [-1, 1], (i = 1, 2, \dots, k)$
```

The coefficients of higher-dimensional polynomials in each dimension can be determined by:

```
$f_{i_1, \dots, i_k} = \left(\\frac{k}{2}\right)^{\eta} \sum_{j_1=1}^{p_1} \cdots \sum_{j_k=1}^{p_k} \frac{f(\mathbf{x})}{\sqrt{1-x_1^2} \cdots \sqrt{1-x_k^2}} dx_1 \cdots dx_k$
\approx \left(\\frac{2^k}{p_1 p_2 \cdots p_k}\right)^{\eta} \sum_{j_1=1}^{p_1} \cdots \sum_{j_k=1}^{p_k} f(\cos\theta_{j_1}, \dots, \cos\theta_{j_k}) \cos\theta_{j_1}, \dots, \cos\theta_{j_k}$
```
