exhibited in Fig. 3.2. The material properties along with the thickness of geometric model can be derived from the following equations [1,18]:

```
$E(z) = E_1 \left[1 - e_0\cos\left(\frac{\pi z}{h}\right)\right]$$\nnG(z) = G_1 \left[1 - e_0\cos\left(\frac{\pi z}{h}\right)\right] \qquad (3.1)\n\nrho(z) = \rho_1 \left[1 - e_m\cos\left(\frac{\pi z}{h}\right)\right]$
```

```
$E(z) = E_1 \left[1 - e_0\cos\left(\frac{\pi z}{2h} + \frac{\pi}{4}\right)\right$\nnG(z) = G_1 \left[1 - e_0\cos\left(\frac{\pi z}{2h} + \frac{\pi}{4}\right)\right] \qquad (3.2)\n\n\rho(z) = \rho_1 \left[1 - e_m\cos\left(\frac{\pi z}{2h} + \frac{\pi}{4}\right)\right]$
```

where $E(z), G(z),$ and $\rho(z)$ indicate the elastic modulus, shear modulus, and density characteristic of geometric model, $E_1, G_1$ and $\rho_1$ denote the maximum value of $E(z), G(z),$ and $\rho(z)$, and $e_0$ and $e_m$ are the porosity coefficients and can be derived

```
$e_0 = 1 - \frac{E_0}{E_1} = 1 - \frac{G_0}{G_1}(0 \le e_0 < 1)\n\ne_m = 1 - \frac{\rho_0}{\rho_1}(0 \le e_m < 1)\n\ne_m = 1 - \sqrt{1 - e_0}$ \qquad (3.3)
```

where $E_0, G_0,$ and $\rho_0$ are the minimum value of material parameters.
