Free and forced vibrations of functionally graded porous cylindrical shells

Rayleigh's dissipation function is expressed as:

```
$W_c = \frac{1}{2} \int_{0}^{2\pi} \int_{0}^{L} \left(cfrac{\partial w}{\partial t}\right)^2 R dx d\theta \quad (4.131)
```

where $c$ represents the viscous damping coefficient and can be expressed by:

```
$c = 2\xi_{mn} \omega_{mn}^2 \quad (4.132)
```

where $\omega_{mn}$ and $\xi_{mn}$ are the natural frequency and the damping ratio of the shell for $(m, n)$, respectively.

The middle surface displacements of the FG circular cylindrical shell satisfying supported boundary conditions are expressed in the form of:

```
$u = \sum_{m=1}^{\infty} \sum_{n=1}^{\infty} [cos(n\theta)X_{mn}^a(t) + sin(n\theta)X_{mn}^b(t)] \cos(\gamma_{mn}x) = X(x,\theta,t)\nv = \sum_{m=1}^{\infty} \sum_{n=1}^{\infty} [sin(n\theta)Y_{mn}^a(t) + cos(n\theta)Y_{mn}^b(t)] \sin(\gamma_{mn}x) = Y(x,\theta,t)\nw = \sum_{m=1}^{\infty} \sum_{n=1}^{\infty} [cos(n\theta)Z_{mn}^a(t) + sin(n\theta)Z_{mn}^b(t)] \sin(\gamma_{mn}x) = Z(x,\theta,t) \quad (4.133)
```

where $n$ and $m$ represent the numbers of circumferential waves and longitudinal half-halves; $t$ represents the time; $\gamma_{mn}=m\pi/L, X_{mn}^a(t), X_{mn}^b(t), Y_{mn}^a(t), Y_{mn}^b(t), Z_{mn}^a(t), Z_{mn}^b(t)$ are generalized coordinates. The superscripts $a$ and $b$ indicate the driven mode and the response mode, respectively. $X(x,\theta,t), Y(x,\theta,t), Z(x,\theta,t)$ are listed as follows:

```
$X(t,\theta) = [X_{11}^a(t), ... X_{mn}^a(t), X_{11}^b(t), ... X_{mn}^b(t), ...]^T\nYY(t,\theta) = [Y_{11}^a(t), ... Y_{mn}^a(t), Y_{11}^b(t), ... Y_{mn}^b(t), ...]^T\nZ(t,\theta) = [Z_{11}^a(t), ... Z_{mn}^a(t), Z_{11}^b(t), ... Z_{mn}^b(t), ...]^T \quad (4.134)
```

```
$x(t) = \{X_{11}^a(t), ... X_{mn}^a(t), X_{11}^b(t), ... X_{mn}^b(t), ...\}^T\ny(t) = \{Y_{11}^a(t), ... Y_{mn}^a(t), Y_{11}^b(t), ... Y_{mn}^b(t), ...\}^T\nz(t) = \{Z_{11}^a(t), ... Z_{mn}^a(t), Z_{11}^b(t), ... Z_{mn}^b(t), ...\}^T \quad (4.135)
```

The more degrees of freedom there are, the more accurate the forced response is, but the more computation effort is required. The modes having great influence should be selected to improve the calculation efficiency while ensuring the accuracy of the results.
