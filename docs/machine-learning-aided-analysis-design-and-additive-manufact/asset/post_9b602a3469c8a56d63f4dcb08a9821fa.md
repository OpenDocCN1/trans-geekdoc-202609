
$M_{v} = \dot{b} \int_{-b/2}^{b/2} \sigma_{v} dz \quad (2.10b)$

By substituting Eq. (2.6) into Eq. (2.10), the further expression can be rewritten in a strain-dependent form as:

```
$$\begin{cases} N_{\zeta} \\ M_{\zeta} \\ Q_{\zeta} \end{cases} = \begin{cases} A_{11} & B_{11} & 0 \\ B_{11} & D_{11} & 0 \\ 0 & 0 & A_{55} \end{cases} \begin{cases} \varepsilon_{\zeta} \\ k_{\zeta} \\ \gamma_{\zeta} \end{cases} \quad (2.11)
```

where the extensional stiffness coefficient $A_{11}$, the extensional coefficient $B_{11}$, bending coupling stiffness coefficient $D_{11}$, and shear stiffness coefficient $A_{55}$ can be expressed as:

```
$A_{11} = \tilde{A}_{11} - \frac{1}{R_{\zeta}}\tilde{B}_{11} \quad (2.12a)$
```

```
$B_{11} = \tilde{B}_{11} - \frac{1}{R_{\zeta}}\tilde{D}_{11} \quad (2.12b)$
```

```
$D_{11} = \tilde{D}_{11} - \frac{1}{R_{\zeta}}\hat{C}_{11} \quad (2.12c)$
```

```
$A_{55} = \kappa\tilde{A}_{55} - \frac{1}{R_{\zeta}}\tilde{B}_{55} \quad (2.12d)$
```

where

```
$$\hat{\mathbf{Q}} = \mathbf{A} - \mathbf{BC}^{-1}\mathbf{B}^{T} \quad (2.13a)$$
```

```
$$\bar{\mathbf{Q}} = \begin{pmatrix} \tilde{A}_{11} & \tilde{B}_{11} \\ \tilde{B}_{11} & \tilde{D}_{11} \end{pmatrix} \quad (2.13b)$$
```

```
$$\mathbf{A} = \begin{pmatrix} \tilde{A}_{11} & \tilde{B}_{11} \\ \tilde{B}_{11} & \tilde{D}_{11} \end{pmatrix}, \mathbf{B} = \begin{pmatrix} A_{12} & 0 & B_{12} & 0 \\ B_{12} & 0 & D_{12} & 0 \end{pmatrix}, \mathbf{C} = \begin{pmatrix} \hat{A}_{11} & 0 & 0 \\ \hat{A}_{55} & 0 & 0 \\ 0 & 0 & \hat{D}_{11} \\ 0 & 0 & \hat{D}_{55} \end{pmatrix} \quad (2.13c)$$
```

```
$(\hat{A}_{ij\zeta}, \hat{B}_{ij\zeta}, \hat{D}_{ij\zeta}, \hat{C}_{ij\zeta}) = \int_{-b/2}^{b/2} Q_{0}(z)(1, z, z^{2}, z^{3}) dz \quad (2.13d)$$
```

```
$Q_{12}(z) = vQ_{11}(z) \quad (2.13e)$
```

where $\kappa$ is the shear correction factor, set to 5/6 hereafter.

According to the constitutive relation expression and strain energy formulation, the strain energy $U_f$ of FGP curved beam can be given as:

```
$U_f = \frac{1}{2} \int_{\varphi_1}^{\varphi_2} \left[ \left( \frac{A_{11}}{R_{\varphi}^2} + w \frac{\partial w}{\partial t} \right)^2 + 2B_{11} \frac{1}{R_{\varphi}^2} \frac{\partial \varphi}{\partial t} \left( \frac{\partial u}{\partial \varphi} + w \right) + \left( \frac{D_{11}}{R_{\varphi}^2} \frac{\partial \varphi}{\partial t} + A_{55} \frac{1}{R_{\varphi}} \left( \frac{\partial u}{\partial t} - u + \phi \right) \right)^2 \right] R_{\varphi} d\varphi \quad (2.14)$
```

The kinetic energy $T$ is:

```
$T = \frac{1}{2} \int_{\varphi_1}^{\varphi_2} \left[ I_0 \left( \frac{\partial w}{\partial t} \right)^2 + 2I_{01} \frac{\partial w}{\partial t} \frac{\partial \varphi}{\partial t} + I_0 \left( \frac{\partial \varphi}{\partial t} \right)^2 + I_2 \left( \frac{\partial \phi}{\partial t} \right)^2 \right] R_{\varphi} d\varphi \quad (2.15)$
```

where the inertia terms $I_0, I_1$, and $I_2$ are presented:

```
$(I_0, I_1, I_2) = \int_{-h/2}^{h/2} p(z) \left( 1 + \frac{z}{R_{\varphi}} \right)^2 (1, z, z^2) dz \quad (2.16)$
```

The boundary conditions of FGP curved beam are achieved by selecting appropriate stiffness of the springs placed at both ends of the beam, the potential energy of which can be given as:

```
$U_b = \frac{1}{2} \int_{\varphi_1}^{\varphi_2} \left[ (k_w^2 w^2 + k_{w}^2 w^2 + k_{\theta}^2 \theta^2) + (k_u^2 u^2 + k_{u}^2 u^2 + k_{\phi}^2 \phi^2) \right] d\varphi \quad (2.17)$
```

In addition, to facilitate consequent validation, the excitation $F_f$ applied to the FGP curved beam is parallel to the z-axis. Therefore the work $W_f$ done by the fixed-point load is given as:

```
$W_f = F_f W \quad (2.18)$
```

## 2.2.3 Model discretization and solution

Based on Chebyshev polynomials with finite terms, the approximate expression of the one-dimensional infinitely differentiable function $f(\varphi)$ is:

```
$f(\varphi) \cong \sum_{n=0}^{N-1} a_n C_n(\varphi) \quad (2.19a)$
```

```
$C_{N-1}(\varphi) = \cos[0 \cdot \cos^{-1}(\varphi)], \cos[1 \cdot \cos^{-1}(\varphi)], \dots, \cos[(N-1) \cdot \cos^{-1}(\varphi)] \quad (2.19b)$
```

```
$\mathbf{a} = (a_0, a_1, \dots, a_{N-1})^T \quad (2.19c)$
```

where $N$ is the truncation number of Chebyshev polynomial and $\mathbf{a}$ represents the coefficient vector.

By applying Gauss-Lobatto points to discret sample a one-dimensional curved beam,

```
$\varphi_i = -\cos\left(\frac{i\pi}{N-1}\right), \quad i=0, 1, \dots, N-1 \quad (220)$
```

The function value $f(\varphi)$ at discrete points can be obtained:

```
$\mathbf{f} = \mathbf{C}\mathbf{a} \quad (221)$
```

where

```
$\mathbf{f} = [f(\varphi_0), f(\varphi_1), \dots, f(\varphi_{N-1})]^T \quad (222a)$
```

```
$\mathbf{C} = [C_{N-1}(\varphi_0), C_{N-1}(\varphi_1), \dots, C_{N-1}(\varphi_{N-1})]^T \quad (222b)$
```

By derivation of Eq. (221), the following expression can be obtained as:

```
$\mathbf{f}^{(\theta)} = \mathbf{C}\mathbf{D}\mathbf{a} = \mathbf{Q}_{\theta}\mathbf{a} \quad (223)$
```

where $\mathbf{D}$ and $\mathbf{Q}_{\theta}$ represent the differential matrix of Chebyshev polynomials and the $p$-order derivative matrix, respectively. After recursion of low-order Chebyshev polynomials, the derivative of each Chebyshev polynomial can be given as:

```
$\mathbf{D}^{(p)} = \left(\frac{1}{s}\mathbf{D}\right)^p \begin{cases} D_{ij} = j-1, & j \text{ even} \\ D_{ij} = 2(j-i), & i>1, i+j \text{ is odd} \\ D_{ij} = 0, & \text{otherwise} \end{cases} \quad (24b)$
```

where $s = (\varphi_1-\varphi_0)/2$ is the scaling factor. The integral expression of $f(\varphi)$ is written as:

```
$\int_{-1}^1 f(\varphi)d\varphi = \mathbf{v}\mathbf{a} \quad (225)$
```

```
$v_k = \begin{cases} \frac{2s}{1-k^2}, & k \text{ even} \\ 0, & k \text{ odd} \end{cases}$
```

The integral of multiplying functions is expressed in matrix form as:

```
$\int_{-1}^1 [f(\varphi)] R_{\theta}(\varphi) d\varphi = \mathbf{f}^T \mathbf{V}_{R_{\theta}} \mathbf{f}$
```

in which

```
$\mathbf{V}_{R_{\theta}} = \text{diag}(\mathbf{R}_{\theta})$
```

$R_{\theta}$ is the vector of $R_{\theta}(\varphi)$ at the Gauss–Lobatto discrete points. According to the above formulations obtained by the spectral-Chebyshev method, the translation and rotation displacement functions in Eq. (2.5) are rewritten as:

```
$\begin{bmatrix} u \\ v \\ \theta \end{bmatrix} = e^{-j\varphi} \mathbf{C} \begin{bmatrix} c \\ d \\ e \end{bmatrix} = e^{-j\varphi} \mathbf{q}$
```

where the coefficients $c, d$, and $e$ are the coordinates in the three directions, respectively, while $q$ denotes the generalized coordinate. Similarly, the strain, kinetic, boundary springs, and external load expressions can be reconstructed into matrix form.

The whole energy equation of FGP curved beam subjected to external load can be expressed as:

```
$L = T - (U_e + U_{\theta}) + W_f$
```

By substituting this energy equation into the Lagrange equation, the expression in matrix form can be obtained as:

```
$(\mathbf{M}\omega^2 - \mathbf{K} - \mathbf{K}_s)\mathbf{q} = \mathbf{F}$
```
