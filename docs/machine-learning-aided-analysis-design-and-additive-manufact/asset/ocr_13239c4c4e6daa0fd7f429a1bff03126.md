$Q_{12}(z) = vQ_{11}(z) \quad (2.13e)$

where $\kappa$ is the shear correction factor, set to 5/6 hereafter.

According to the constitutive relation expression and strain energy formulation, the strain energy $U_f$ of FGP curved beam can be given as:

```
$U_f = \frac{1}{2} \int_{\varphi_1}^{\varphi_2} \left[ \left( \frac{A_{11}}{R_{\varphi}^2} + w \frac{\partial w}{\partial t} \right)^2 + 2B_{11} \frac{1}{R_{\varphi}^2} \frac{\partial \varphi}{\partial t} \left( \frac{\partial u}{\partial \varphi} + w \right) + \left( \frac{D_{11}}{R_{\varphi}^2} \frac{\partial \varphi}{\partial t} + A_{55} \frac{1}{R_{\varphi}} \left( \frac{\partial u}{\partial t} - u + \phi \right) \right)^2 \right] R_{\varphi} d\varphi \quad (2.14)$
```

The kinetic energy $T$ is:

```
$T = \frac{1}{2} \int_{\varphi_1}^{\varphi_2} \left[ I_0 \left( \frac{\partial w}{\partial t} \right)^2 + 2I_{01} \frac{\partial w}{\partial t} \frac{\partial \varphi}{\partial t} + I_0 \left( \frac{\partial \varphi}{\partial t} \right)^2 + I_2 \left( \frac{\partial \phi}{\partial t} \right)^2 \right] R_{\varphi} d\varphi \quad (2.15)$
```

where the inertia terms $I_0, I_1$, and $I_2$ are presented:

```
$(I_0, I_1, I_2) = \int_{-h/2}^{h/2} p(z) \left( 1 + \frac{z}{R_{\varphi}} \right)^2 (1, z, z^2) dz \quad (2.16)$
```

The boundary conditions of FGP curved beam are achieved by selecting appropriate stiffness of the springs placed at both ends of the beam, the potential energy of which can be given as:

```
$U_b = \frac{1}{2} \int_{\varphi_1}^{\varphi_2} \left[ (k_w^2 w^2 + k_{w}^2 w^2 + k_{	heta}^2 \theta^2) + (k_u^2 u^2 + k_{u}^2 u^2 + k_{\phi}^2 \phi^2) \right] d\varphi \quad (2.17)$
```

In addition, to facilitate consequent validation, the excitation $F_f$ applied to the FGP curved beam is parallel to the z-axis. Therefore the work $W_f$ done by the fixed-point load is given as:

```
$W_f = F_f W \quad (2.18)$
```
