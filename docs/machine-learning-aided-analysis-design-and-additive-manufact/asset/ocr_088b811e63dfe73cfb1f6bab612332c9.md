The variation of the material properties exhibited from the porosity distribution Type 2 presents a continuous decline from the top surface to the bottom surface. The change process of material properties for Type 1 and Type 2 can be expressed in the mathematical form of Eqs. (2.2) and (2.3), which can be obtained from Refs. [8,30].

```
$E(z) = E_{max} \left[1 - e_{0E}\cos\left(\frac{\pi z}{h}\right)\right]$ \quad (2.2a)
```

```
$G(z) = G_{max} \left[1 - e_{0G}\cos\left(\frac{\pi z}{h}\right)\right]$ \quad (2.2b)
```

```
$\rho(z) = \rho_{max} \left[1 - e_{m\rho}\cos\left(\frac{\pi z}{2h} + \frac{\pi}{4}\right)\right]$ \quad (2.2c)
```

```
$E(z) = E_{max} \left[1 - e_{mE}\cos\left(\frac{\pi z}{2h} + \frac{\pi}{4}\right)\right]$ \quad (2.3a)
```

```
$G(z) = G_{max} \left[1 - e_{mG}\cos\left(\frac{\pi z}{2h} + \frac{\pi}{4}\right)\right]$ \quad (2.3b)
```

```
$\rho(z) = \rho_{max} \left[1 - e_{m\rho}\cos\left(\frac{\pi z}{2h} + \frac{\pi}{4}\right)\right]$ \quad (2.3c)
```

where the relationship between the porosity coefficients $e_{0} = 1 - E_{min}/E_{max}$ and $e_{m} = 1 - \rho_{min}/\rho_{max}$ ($0 < e_m < 1$) is [8,30]:

```
$e_{m} = 1 - \sqrt{1 - e_{0}}$ \quad (2.4)
```

It is worth noting that when the porosity coefficient is 0, there are no pores in the material, which can be assumed as an isotropic material.
