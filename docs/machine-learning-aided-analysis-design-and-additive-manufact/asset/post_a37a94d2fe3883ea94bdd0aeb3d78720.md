
## Machine learning-aided stochastic analysis of functionally graded porous plates

Due to the positive nature of structural material properties, incorporating a lognormal distribution to model material input uncertainty is more physically realistic than using a Gaussian distribution.

Moreover, the spatial variation of uncertain structural properties is studied using the exponential covariance function $C_{HHH}(x,x')$. Divided into 1D, 2D, and 3D fields, the relevant covariance functions are shown as:

```
$C_{HHH}(\mathbf{x,x'}) = \begin{cases} \sigma_H^2 e^{-\frac{|x-x'|}{l_x}} & \text{for 1D fields} \\ \sigma_H^2 e^{-\frac{|x-x'|}{l_x} - \frac{|y-y'|}{l_y}} & \text{for 2D fields} \quad (11.21) \\ \sigma_H^2 e^{-\frac{|x-x'|}{l_x} - \frac{|y-y'|}{l_y} - \frac{|z-z'|}{l_z}} & \text{for 3D fields} \end{cases}$
```

where $\sigma_H \in \mathbb{R}^{++}$ represents the standard deviation for the random field; $l_x, l_y, l_z \in \mathbb{R}^+$ represent the correlation lengths in x axis, y axis, and z axis, respectively.

One popular random field discretization technique is the Karhunen–Loève expansion. With the combination decomposition of a bounded, symmetric, and positive definite covariance function $C_{HHH}(\mathbf{x,x'})$, it can be explained as:

```
$C_{HHH}(\mathbf{x,x'}) = \sum_{i=1}^{\infty} \lambda_i \varphi_i(\mathbf{x})\varphi_i(\mathbf{x'}) \quad (11.22)$
```

in which the eigenfunctions of $C_{HHH}(\mathbf{x,x'})$ are taken as the solutions of the following equation:

```
$\forall i = 1, ... \int_D C_{HHH}(\mathbf{x,x'})\varphi_i(\mathbf{x})dD = \lambda_i\varphi_i(\mathbf{x}) \quad (11.23)$
```

From which the orthogonal property is guaranteed through following equation:

```
$\int_D \varphi_i(\mathbf{x})\varphi_j(\mathbf{x})dD = \delta_{ij} \quad (11.24)$
```

in which, $\delta_{ij}$ as the Kronecker symbol. Then the parameters of the random variable set are calculated as:

```
$\zeta(\theta) = \frac{1}{\sqrt{N}} \int_D [H(\mathbf{x}, \theta) - \mu(\mathbf{x})]\varphi_i(\mathbf{x})dD \quad (11.25)$
```

To simplify the calculations, truncate the K-L expansion $H(\mathbf{x}, \theta)$ with $M$ terms as:

```
$H(\mathbf{x}, \theta) \approx \hat{H}^M(\mathbf{x}, \theta) = \mu(\mathbf{x}) + \sum_{i=1}^{M} \sigma(\mathbf{x})\sqrt{\lambda_i}\zeta_i(\theta)\varphi_i(\mathbf{x})$
```

in which $\mu(\mathbf{x})$ and $\sigma(\mathbf{x})$ are the mean and standard deviation for the Gaussian field. Transforming the corresponding lognormal random field into the exponential product of the Gaussian random field as:

```
$H(\mathbf{x}, \theta) \approx \hat{H}^M(\mathbf{x}, \theta) = \exp[\mu(\mathbf{x}) + \sum_{i=1}^{M} \sigma(\mathbf{x})\sqrt{\lambda_i}\zeta_i(\theta)\varphi_i(\mathbf{x})]$
```

in which:

```
$\mu(\mathbf{x}) = \frac{\log[\mu_{log}(\mathbf{x})]}{\sqrt{\sigma_{log}^2(\mathbf{x})}}$,
$\sigma(\mathbf{x}) = \sqrt{\log[\sigma_{log}^2(\mathbf{x})/\mu_{log}^2(\mathbf{x})]}$
```

and $\mu_{log}$ means the mean of the lognormal random field, while $\sigma_{log}$ means the standard deviation.

### 11.4.2 Machine learning-aided stochastic analysis of functionally graded plate

By using the K-L expansion, the lognormal random fields of Poisson’s ratio and Young’s modulus can be explicitly formulated as:

```
$H_E(\mathbf{x}, \theta) \approx \hat{H}_E^M(\mathbf{x}, \theta) = \exp[\mu_E(\mathbf{x}) + \sum_{i=1}^{M} \sigma_E(\mathbf{x})\sqrt{\lambda_i}\zeta_i(\theta)\varphi_i(\mathbf{x})]$
```

```
$H_Y(\mathbf{x}, \theta) \approx \hat{H}_Y^M(\mathbf{x}, \theta) = \exp[\mu_Y(\mathbf{x}) + \sum_{i=1}^{M} \sigma_Y(\mathbf{x})\sqrt{\lambda_i}\zeta_i(\theta)\varphi_i(\mathbf{x})]$
```

where $\zeta_E(\theta)$ and $\zeta_Y(\theta)$ mean the random variables of Young’s modulus and Poisson’s ratio. Therefore the stress–strain relationship of the static problem will be reformulated considering the uncertain variables:

```
$\sigma = \begin{cases} \sigma_x \\ \sigma_y \end{cases} = \mathbf{D}_k[\zeta_x(\theta), \zeta_y(\theta)]$
$\tau = \begin{cases} \tau_{xz} \\ \tau_{yz} \end{cases} = \mathbf{D}_k[\zeta_x(\theta), \zeta_y(\theta)]$
```

Consequently, when taking the stochastic system parameters into consideration, the determined governing equation for the static problem can be described as:

```
$\mathbf{K}[\zeta^r(\theta), \zeta^s(\theta)] \mathbf{U} = \mathbf{F}[\zeta^s(\theta)] \quad (11.32)$
```

Where $\mathbf{K}[\zeta^r(\theta), \zeta^s(\theta)]$ is the stochastic stiffness matrix of the structure and $n$ is the total number of degree of freedom; $\mathbf{U}\in\mathbb{R}^n$ is the stochastic displacement; $\zeta^s(\theta)$ is the stochastic force vector of the uncertain system.

### 11.4.3 Artificial neural networks

As one compelling method, the ANN model analysis method can be commonly used in various generics which provide only little information. The ANN model can get the expected outputs and results by being trained to learn from it. Recently, many papers have proved that the ANN models are excellent tool for approximation and interpolation in actual engineering applications.

The ANN is also called a neural network (NN), an interconnected group of neurons to analyze the provided information by a mathematical model or computational model. The most important part of the ANN method, learning, can help the ANN models to update the weight parameters at the interconnection level of the neurons. The ANN models can be used to analyze different independent data and predict the output for values that are different from the examples. For example, ANN model is established by implementing the feedforward and backward propagation (BP) algorithm based on the MATLAB® R2021b tool. BP training algorithm has been adopted for the system reduce the mean squared error between desired output and actual result. ### 11.4.4 The extended support vector regression

The conventional support vector machine (SVM) was proposed by Vapnik [7] and has been implemented into various forms with characteristics along the newly developed X-SVR approach. For input and output vectors of $\mathbf{x}$ and $\mathbf{y}$, the governing equation for determining the hyperplanes separating two types of objects is described as:

$$\hat{f}(\mathbf{x})=\mathbf{wx}^T - \gamma \quad (11.35)$$

where $\mathbf{w}=[w_1, w_2, ..., w_n]^T\in\mathbb{R}^n$ is the perpendicular vector against the hyperplane; $\gamma$ is the bias.

Based on the research of Feng et al. [8-10], the X-SVR approach was proposed based on the doubly regularized support vector regression and the regression method. For input and output vectors of $\mathbf{x}$ and $\mathbf{y}$, the X-SVR creates a hyperface$(\mathbf{x})$ to describe the relationship between the datapoints:

$$\hat{f}(\mathbf{x})=k(\mathbf{p}_i - \mathbf{q}_j)^T - \tilde{e}_i^T G_{ij} \tilde{u}_j \quad (11.36)$$

where $k(\cdot)$ is the kernel-induced vector for the inputs, $\mathbf{p}_i, \mathbf{q}_j \in\mathbb{R}^n$ are the two kernelized coefficients, $\tilde{u}_j$ is the concerned optimal solution, matrix $G_{ij}$ and vector $\tilde{e}_i$ are defined by:

```
$p_{ij} = \begin{cases} 0, w_j \le 0 & -w_j, w_j < 0 \\ w_j, w_j > 0, & 0, w_j \ge 0 \end{cases} \quad q_{ij} = j=1, ..., n \quad (11.37)$
```
