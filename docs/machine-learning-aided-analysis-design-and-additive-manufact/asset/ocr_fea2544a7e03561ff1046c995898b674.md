where $f_t$ and $	au$ are respectively the amplitude and pulse width of the load acting on the shallow shell, $t$ stands for the time variable. $\xi$ denotes the constant term. On the basis of the previous derivation, the transient dynamic analysis of the shallow shell can be further carried out. The basic equation of motion can be expressed as:

# $\mathbf{M}\ddot{\mathbf{u}} + \mathbf{C}_u\dot{\mathbf{u}} + \mathbf{K}\mathbf{u} = \mathbf{F}$

where $\mathbf{M}$, $\mathbf{K}$, and $\mathbf{F}$ are consistent with the previous formulation, $\ddot{\mathbf{u}}$, $\dot{\mathbf{u}}$, and $\mathbf{u}$ represent the acceleration vector, the velocity vector, and the displacement vector, $\mathbf{C}_R$ is the damping matrix of the structure, which can be defined as [15].

# $\mathbf{C}_R = \beta_1\mathbf{M} + \beta_2\mathbf{K}$

$eta_1$ and $eta_2$ stand for the Rayleigh damping coefficients. For the current investigation, the damping is not taken into account, that is, $\mathbf{C}_R=0$.

In order to obtain the response of FGP shallow shell, the Newmark-$eta$ method is employed to solve the transient dynamic equation. According to Newmark-$\beta$, the recursive relationship between displacement $\mathbf{u}_i$ and velocity $\dot{\mathbf{u}}_i$ for the response of FGP shallow shell can be obtained and the transient response at an arbitrary moment can be computed.

```
$$\mathbf{u}_{i+\Delta t} = \mathbf{u}_i + (1-\delta)\dot{\mathbf{u}}_i\Delta t + \frac{\delta}{2}\ddot{\mathbf{u}}_{i+\Delta t}\Delta t^2$\n$\dot{\mathbf{u}}_{i+\Delta t} = \dot{\mathbf{u}}_i + \ddot{\mathbf{u}}_i\Delta t + (\frac{1}{2}-\alpha)(\ddot{\mathbf{u}}_i + \ddot{\mathbf{u}}_{i+\Delta t})\Delta t^2$
```

From Eq. (5.37), it can be deduced that the calculation formulas of acceleration and velocity at $t_{i+1}$ are as follows:

```
$$\ddot{\mathbf{u}}_{i+1} = a_0(\dot{\mathbf{u}}_{i+1} - \dot{\mathbf{u}}_i) + a_2(\mathbf{u}_{i+1} - \mathbf{u}_i$\n$\dot{\mathbf{u}}_{i+1} = a_1(\dot{\mathbf{u}}_{i+1} - \dot{\mathbf{u}}_i) + a_4(\mathbf{u}_{i+1} - \mathbf{u}_i)$
```

where

```
$a_0 = \frac{1}{\alpha\Delta t^2}, a_1 = \frac{\delta}{\alpha\Delta t}, a_2 = \frac{-1}{\alpha}, a_3 = \frac{1}{2\alpha}, a_4 = \frac{-1}{2\alpha}, a__5 = \frac{\Delta t}{2}(\frac{1}{\alpha}-1)$
```

where $\alpha=\frac{1}{2}$ and $\delta=\frac{1}{2}$.\nAccording to Eq. (5.34), the equation of motion at $t_{i+1}$ can be obtained:

```
$$\mathbf{M}\ddot{\mathbf{u}}_{i+1} + \mathbf{C}_R\dot{\mathbf{u}}_{i+1} + \mathbf{K}\mathbf{u}_{i+1} = \mathbf{F}_{i+1}$
```
