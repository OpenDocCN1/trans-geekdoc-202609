# 3.2.4 Solving procedure

According to Eqs. (3.10–3.13), the overall energy equation $L$ of the FGP plate can be expressed as

```
$$L = T - U_i - U_{wp} + W_f \quad (3.33)$
```

Substituting Eq. (3.32) in Eq. (3.33), set the partial derivatives of the Lagrangian with respect to the unknown coefficients, one can be obtained as:

```
$$(\mathbf{K} - \omega^2\mathbf{M})\mathbf{Q} = \mathbf{F}$
\mathbf{Q} = [q_1, q_2, q_3, q_4, q_5]^T$
```

where $F$ represents the external loading vector, $\mathbf{K}$ and $\mathbf{M}$ are the stiffness and mass matrices; $\omega$ and $\mathbf{Q}$ denote the circular frequencies and generalized displacement vector.
