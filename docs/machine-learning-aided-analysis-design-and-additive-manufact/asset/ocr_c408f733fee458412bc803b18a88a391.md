# Machine learning aided stochastic vibration analysis of functionally graded porous plates

Monic Carlo simulation (MCS) approach with 1 million simulation cycles is chosen as the reference result to validate.

From the tables, it is clear that the MLA-SFV framework is competent to provide reliable results. Compared with the MCS results, the absolute maximum relative error (RE) for the GPR method is -2.715%, while the RE is -1.224% for the X-SVR method, also in a computational method more efficient style. Moreover, with the traditional MCS methods, both machine learning algorithms reduce a great amount of computational time but still deliver accurate frequencies for the FGP plate.

The PDFs and CDFs for the first three natural frequencies in Case A and B by the two methods are plotted in Figs. 12.5–12.6, in comparison to the reliability curves of MCS approach. From Figs. 12.5 and 12.6, the reliability curves in Case A predicted by the machine learning algorithms correlate with the reference. Same conclusions can be made for Case B of the FGP plate, which demonstrates the accuracy, efficiency, and applicability of MLA-SFV analysis for fgmp.
