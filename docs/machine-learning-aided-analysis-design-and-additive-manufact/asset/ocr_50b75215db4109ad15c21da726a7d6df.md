Introduce the vector **q** as follows:

```
q = \begin{bmatrix} x(t) \ y(t) \ z(t) \end{bmatrix} \eqno (4.136)
```

The equations of motion are:

```
d\frac{\partial T}{\partial q_i} - \d\frac{\partial U}{\partial q_i} = -\frac{\partial W_c}{\partial q_i} - \frac{\partial W_l}{\partial q_i}, \quad i=1, 2, \dots, N \eqno (4.137)
```

where **N** means the number of generalized coordinates.
By substituting Eqs. (4.90–4.131) into Eq. (4.137), the nonlinear differential equations can be written in the matrix form as:

```
**\mathbf{M}\dot{\mathbf{q}} + \mathbf{C}\dot{\mathbf{q}} + \mathbf{K}\mathbf{q} = \mathbf{f}cos(\\Omega t) \eqno (4.138)
```

where **M**, **C**, and **K** are the mass, damping, and stiffness matrices, respectively; **M** includes the quadratic and cubic nonlinear terms; **f** is the vector of the excitation amplitude. Their specific expressions are listed as follows:

```
\mathbf{M} = \begin{bmatrix} L_{RP1} & 0 & 0 \ 0 & L_{RP2} & 0 \ 0 & 0 & L_{RP3} \end{bmatrix} \eqno (4.139)
```

```
\mathbf{C} = \begin{bmatrix} 0 & 0 & 0 \ 0 & 0 & 0 \ 0 & 0 & c_{RP3} \end{bmatrix} \eqno (4.140)
```

```
\mathbf{K} = \begin{bmatrix} K_1 & K_2 & K_3 \ & K_4 & K_5 \ \texttext{symmetric} & & K_6 \end{bmatrix} \eqno (4.141)
```

```
\mathbf{N} = \begin{bmatrix} N_1 \ N_2 \ N_3 \end{bmatrix} \eqno (4.142)
```

```
\mathbf{f} = \begin{bmatrix} 0 \ 0 \ \end{bmatrix}f[Z(L/2,0)]^T \eqno (4.143)
```
