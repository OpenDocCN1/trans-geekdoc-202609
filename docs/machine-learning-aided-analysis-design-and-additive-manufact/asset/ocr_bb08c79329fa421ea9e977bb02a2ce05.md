Secondly, the compression of a graded foam is illustrated in Fig. 15.22. Graded foams deform successfully from weaker regions to stronger regions. As the specimen is compressed to the position $h$, the height of the not plastically deformed region (blue region inside foams) is $H-h$. In Figure.15.22 it is assumed that the deformed region is fully compressed as all pores inside foams are compressed to be densified. The height of the plastically deformed region (red region in Fig. 15.22) is $h_{deformed}$, where $\rho_{deformed}$ is the average relative density of the plastically deformed region and can be computed:

```
$$\rho_{deformed} = \frac{\int_0^h \rho(h) dh}{h}$$ (15.8)
```

where $h$ is the normalized height and can be determined by $h/H$.
