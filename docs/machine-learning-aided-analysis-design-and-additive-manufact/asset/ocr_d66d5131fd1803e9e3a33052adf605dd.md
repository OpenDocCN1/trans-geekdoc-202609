# 4.2.1 Governing equations

The kinetic energy of the FG cylindrical shell is defined as:

```
$T = \frac{L}{2}\int_{-h/2}^{h/2}\int_0^{2\pi} \rho(z)[\dot{u}^2+\dot{v}^2]R d\theta dz \quad (4.7)$
```

The strain energy of the FG porous cylindrical shell is expressed as:

```
$U_s = \frac{L}{2}\int_0^h\int_0^{2\pi} \epsilon^T \cdot S\epsilon d\theta dz \quad (4.8)$
```

where $\epsilon$ is the strain vector and S is the stress matrix.
