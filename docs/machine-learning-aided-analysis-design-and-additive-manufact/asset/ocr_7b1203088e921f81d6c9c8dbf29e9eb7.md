This chapter will investigate the stochastic problem of FGM porous structures. The basic theory, like the FSDT, will be discussed explicitly. The stochastic finite element method (SFEM) is introduced to get an efficient uncertainty quantification framework for investigating the system uncertainty for FGM porous structures. Based on SFEM, the machine learning-aided stochastic static analysis (MLSSA) is also proposed, which can help define the material properties and implement them into various systems. Two type of machine learning algorithms, namely the neural networks (ANNs) and extended support vector regression (SVR) are introduced to find the relationship between data and structure. Different polyharmonic kernel functions are adopted in machine learning analysis to improve the regression's robustness, stability, and accuracy. The established regression model can help predict the static results for different situations. Besides, the structural safety of the FGM porous structure can be assessed through the reliability properties, including probability density function (PDF) and cumulative density function (CDF). Due to the exceptional advantages in saving computational efforts, the MLA-SSA framework can provide some reference for actual composite structure applications in specific projects.
