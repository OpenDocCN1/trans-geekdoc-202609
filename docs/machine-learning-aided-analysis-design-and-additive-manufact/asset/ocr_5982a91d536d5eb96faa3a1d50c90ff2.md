The solution of Eq. (4.121) takes the form of:

```
$A = \frac{1}{2}ae^{\omega t} \quad (4.122)$
```

where $a$ represents the response amplitude, and $a$ and $\phi$ are real numbers.
Substituting Eq. (4.122) into Eq. (4.121), and separating real and imaginary
parts, we obtain:

```
$$\begin{cases} \frac{\dot{a}}{T_2} = 0 \ \frac{3a_3}{8}a + \omega\frac{\dot{\phi}}{T_2} = 0 \end{cases} \quad (4.123)$
```

From Eq. (4.123), we have:

```
$$\phi = \frac{3a_3^2T_2}{8\omega j} + \phi_0 \quad (4.124)$
```

where $\phi_0$ is a constant.
Inserting Eq. (4.124) and $T_2=\varepsilon^2t$ into Eq. (4.122), it yields:

```
$A = \frac{1}{2}a \exp(1 + \frac{3a_3a^2\varepsilon^2t}{8\omega j} + i\phi_0) \quad (4.125)$
```

```
$w_i = \varepsilon acos(\omega t + \phi_0) + O(\varepsilon^3) \quad (4.126)$
```

By applying the initial conditions in Eq. (4.112), we obtain:

```
$$\begin{cases} \varepsilon = 0 \ \a\varepsilon = w_{max} \end{cases} \quad (4.127)$
```

Finally, the nonlinear frequency of the FG circular cylindrical shell is
obtained as:

```
$$\omega_n = \sqrt{a_1}(1 + \frac{3a_1}{8a_1}\varepsilon^2a^2) + O(\text{\varepsilon}^3) \quad (4.128)$
```

Thus the nonlinear to linear frequency ratio of the FG circular cylindrical
shell is given by:

```
$$\omega_n/\omega_j = 1 + \frac{3a_1}{8a_1}w_{max}^2 \quad (4.129)$
```
