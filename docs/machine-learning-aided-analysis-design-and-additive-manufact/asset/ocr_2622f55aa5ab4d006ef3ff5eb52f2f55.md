In this chapter, not only the free vibration analysis of the FGM shallow shell, but also the forced vibration analysis will be carried out. The work $W_j$ done by the external force considered here can be written as [45]:

```
$W_j = \frac{1}{2} \int_{V} (F_{it} + F_{iv} + F_{iw}w_j) dV$ (5.17)
```

where $f(i=u,v,w)$ represents the components along the $x, y,$ and $z$ axes. The potential energy $U_g$ of elastic foundation can be written as:

```
$U_g = \frac{1}{2} \int_{0}^{b} \left[ K_w w^2 + K_x \left( \frac{\partial w}{\partial x} \right)^2 + K_y \left( \frac{\partial w}{\partial y} \right)^2 \right] \left( 1 - \frac{h}{2R_s} \right) \left( 1 - \frac{h}{2R_s} \right) dxdy$ (5.18)
```
