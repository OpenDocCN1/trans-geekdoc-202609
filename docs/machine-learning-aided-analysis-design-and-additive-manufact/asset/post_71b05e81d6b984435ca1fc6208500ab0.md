
$$k_{31} = \frac{(B_{12}+2B_{60})L^2mn\pi^2+A_{12}m^2\piR+B_{11}m^3\pi^2}{L^3\rho^2} \quad (4.104)$$
$$k_{32} = \frac{B_{11}L^2n^3+A_{11}L^2n^2+(B_{12}+2B_{60})mn^2\pi^2}{L^3\rho^2} \quad (4.105)$$
$$k_{33} = \frac{L^2[2B_{21}L^2n^5+A_{11}L^2n^2+2m\pi^2(D_{12}n^2+D_{60}n^2+B_{12}R)] + \frac{D_{11}(L^2n^4+m^4\pi^4)}{L^4R^4\rho^2} \quad (4.106)$$
$$k_{34} = \frac{9A_{11}(L^2n^4+m^4\pi^4)+(A_{12}+4A_{60})L^2mn^2\pi^2}{32L^4\rho^2} \quad (4.107)$$

Neglecting inertia terms $\rho\ddot{u}$ and $\rho\ddot{v}$, which are insignificant in transverse vibration, we can solve $u_i$ and $v_i$ by combining Eq. (4.95) with Eq. (4.96). Inserting the results into Eq. (4.97), it yields:

$$\frac{\ddot{w}_i}{t^2} + a_1w_i + a_3w_i^3 = 0 \quad (4.108)$$

where
$$a_1 = \frac{k_{13}k_{22}k_{31}}{k_{12}k_{21}-k_{11}k_{22}} - \frac{k_{12}k_{23}k_{31}}{k_{12}k_{21}-k_{11}k_{22}} - \frac{k_{13}k_{21}k_{32}}{k_{12}k_{21}-k_{11}k_{22}} + \frac{k_{12}k_{23}k_{32}}{k_{12}k_{21}-k_{11}k_{22}} - k_{33} \quad (4.109)$$
$$a_3 = k_{34} \quad (4.110)$$

## 4.4.2 Solution procedure

The linear inertia is obtained as:
$$\omega = \sqrt{a_1} \quad (4.111)$$

The initial conditions are defined as:
$$w_i|_{t=0} = w_{max}, \frac{\dot{w}_i}{t}|_{t=0} = 0 \quad (4.112)$$

where $w_{max}$ is the maximum value of $w_i(t)$.

### Free and forced vibrations of functionally graded porous shells

Next, the method of multiple scales is utilized to solve Eq. (4.108). Firstly, we introduce the scaled time as:
$$T_\psi = \varepsilon t, \quad \psi = 0, 1, 2... \quad (4.113)$$

$\varepsilon$ is a small dimensionless parameter. The time derivatives are given in terms of $T_\psi$ as follows:
$$\frac{\partial}{\partial t}=-D_0 + \varepsilon D_1 + \varepsilon^2 D_2 + \dots$$
$$\frac{\partial^2}{\partial t^2}=D_0^2 + 2\varepsilon D_0D_1 + \varepsilon^2(D_1^2 + 2D_0D_2) + \dots \quad (4.114)$$

where $D_\psi=\frac{\partial}{\partial T_\psi}, \quad \psi=0, 1, 2... \quad (4.115)$

The vibration response is written as the function of different scaled times:
$$w=\varepsilon w_1(T_0, T_2) + \varepsilon^2 w_2(T_0, T_2) \quad (4.116)$$

Because the nonlinearity in Eq. (4.108) is cubic, $\varepsilon T_1$ and $\varepsilon^2 w_2$ are absent. Substituting Eqs. (4.117) and (4.116) in Eq. (4.108) and equating coefficients of each power of $\varepsilon$ to zero, we obtain:

$$D_0^2 w_1 + \omega_1^2 w_1=0 \quad (4.117)$$
$$D_0^2 w_2 + \omega_1^2 w_2=-2D_0D_2w_1-a_iw_1^3 \quad (4.118)$$

The solution of Eq. (4.117) can be given by:
$$w_1=A(T_2)e^{i\omega_1 T_0} + \bar{A}(T_2)e^{-i\omega_1 T_0} \quad (4.119)$$

$A(T_2)$ is an undetermined function; $\bar{A}(T_2)$ is the conjugate of the former. Substituting Eq. (4.119) into Eq. (4.118) gives:
$$D_0^2 w_2+\omega_1^2 w_2=-a_i A^3 e^{i\omega_1 T_0}-(3a_i A^2\bar{A}+2i\omega_1 D_2A)e^{i\omega_1 T_0}+cc \quad (4.120)$$

$cc$ represents the conjugate function of all the previous terms. The secular terms in Eq. (4.120) should be eliminated, so we have:
$$3a_i A^2\bar{A}+2i\omega_1 D_2A=0 \quad (4.121)$$

The solution of Eq. (4.121) takes the form:
$$A = \frac{1}{2}ae^{\phi T_2}$$

where $a$ represents the response amplitude, and $a$ and $\phi$ are real numbers. Substituting Eq. (4.122) into Eq. (4.121), and separating real and imaginary parts, we obtain:
$$\frac{\dot{a}}{T_2} = 0, \quad \frac{\dot{\phi}}{T_2} = 0 \quad (4.123)$$

From Eq. (4.123), we have:
$$\phi = \frac{3a^2T_2}{8\omega} + \phi_0 \quad (4.124)$$

where $\phi_0$ is a constant. Inserting Eq. (4.124) and $T_2=\varepsilon^2 t$ into Eq. (4.122), it yields:
$$A = \frac{1}{2}a\exp\left(1 + \frac{3a^2\varepsilon^2t}{8\omega} + \phi_0\right) \quad (4.125)$$
$$w=\varepsilon a\cos(\omega t + \phi_0) + O(\varepsilon^3) \quad (4.126)$$

By applying the initial conditions in Eq. (4.112), we obtain:
$$\varepsilon a = w_{max}, \quad \phi = 0 \quad (4.127)$$

Finally, the nonlinear frequency of the FG cylindrical shell is obtained as:
$$\omega_n = \omega\left(1 + \frac{3w_{max}^2\varepsilon^2}{8\omega^2}\right) \quad (4.128)$$

Thus the nonlinear to linear frequency ratio of the FG cylindrical shell is given by:
$$\omega_n/\omega = 1 + \frac{3w_{max}^2\varepsilon^2}{8\omega^2}$$
