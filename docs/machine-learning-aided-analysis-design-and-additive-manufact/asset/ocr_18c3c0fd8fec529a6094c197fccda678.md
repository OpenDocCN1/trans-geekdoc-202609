where G(x, z) is the shear modulus which can be obtained by:

```
$G = \frac{E}{2(1 + v)} \quad (6.16)$
```

# 6.3.4 Hamilton principle

Using the Hamilton principle, equation of motion of the porous beam can be derived. To employ the Hamilton principle, total kinetic, potential, and nonconservative energies of the system need to be calculated. Total kinetic energy of the system can be expressed as:

```
$K = \frac{1}{2} \int (\dot{U}^2 + \dot{w}^2) dV \quad (6.17)$
```

where time derivative of a quantity is represented by a superposed dot. Furthermore, strain energy of the system can be calculated by:

```
$U = \frac{1}{2} \int (\sigma_{xx}\varepsilon_{xx} + \sigma_{xz}\gamma_{xz}) dV \quad (6.18)$
```

Also, potential energy due to the external loads can be calculated by:

```
$V = - \int_0^l (P_z w + \frac{1}{2} P_x (\frac{\partial w}{\partial x})^2) dx \quad (6.19)$
```

where $P_z$ and $P_x$ represent harmonic vertical load and axial constant load, respectively. Governing equations of motion using Hamilton's principle (Eq. 6.20) can be obtained as Eqs. (6.21)-(6.23).

```
$\delta_{i_0}^{i_1} (U + V - T) = 0 \quad (6.20)$
```
