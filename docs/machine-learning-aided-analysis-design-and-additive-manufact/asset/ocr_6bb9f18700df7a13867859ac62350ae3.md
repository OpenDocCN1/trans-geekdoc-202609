# Free and forced vibrations of functionally graded porous cylindrical shells

Next, the method of multiple scales [32] is utilized to solve Eq. (4.108). Firstly, we introduce the scaled time as:

```
$T_{\psi} = e^{\psi t}, \quad \psi = 0, 1, 2... \quad (4.113)
```

$\varepsilon$ is a small dimensionless parameter. The time derivatives are given in terms of $T_{\psi}$ as follows:

```
$$\frac{\partial}{\partial t}=-D_0 + \varepsilon D_1 + \varepsilon^2 D_2 + ...$\$
$\frac{\partial^2}{\partial t^2}=D_0^2 + 2\varepsilon D_0D_1 + \varepsilon^2(D_1^2 + 2D_0D_2) + ...$ \quad (4.114)
```

where $D_{\psi}$ is

```
$D_{\psi}=\{\partial}{\partial T_{\psi}}, \quad \psi=0, 1, 2... \quad (4.115)
```

The vibration response is written as the function of different scaled times:

```
$w_t=\varepsilon w_1(T_0, T_2) + \varepsilon^2 w_2(T_0, T_2) \quad (4.116)
```

Because the nonlinearity in Eq. (4.108) is cubic, $\varepsilon T_1$ and $\varepsilon^2 w_2$ are absent [32]. Substituting Eqs. (4.117) and (4.116) in Eq. (4.108) and equating coefficients of each power of $\varepsilon$ to zero, we obtain:

```
$D_0^2 w_1 + \omega_1^2 w_1=0 \quad (4.117)
```

```
$D_0^2 w_2 + \omega_1^2 w_2=-2D_0D_2w_1-a_iw_1^3 \quad (4.118)
```

The solution of Eq. (4.117) can be given by:

```
$w_1=A(T_2)e^{i\omega_1 T_0} + \bar{A}(T_2)e^{-i\omega_1 T_0} \quad (4.119)
```

$A(T_2)$ is an undetermined function; $\bar{A}(T_2)$ is the conjugate of the former. Substituting Eq. (4.119) into Eq. (4.118) gives:

```
$D_0^2 w_3+\omega_1^2 w_3=-a_i A^3 e^{i\omega_1 T_0}-(3a_i A^2\bar{A}+2i\omega_1 D_2A)e^{i\omega_1 T_0}+cc \quad (4.120)
```

$cc$ represents the conjugate function of all the previous terms. The secular terms in Eq. (4.120) should be eliminated, so we have:

```
$3a_i A^2\bar{A}+2i\omega_1 D_2A=0 \quad (4.121)
```
