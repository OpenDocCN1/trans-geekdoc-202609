# 5.3.1 Convergence studies

According to the theoretical derivation, it can be found that there may be many aspects that affect the convergence of the calculation, such as boundary stiffness and elastic foundation parameters, but only the number of terms of the polynomial will determine the dimension of the matrix in the linear dynamic equation. Choosing an appropriate truncation number can help improve the calculation efficiency and accuracy of solutions. Table 5.1 lists the first order modal frequencies of the four FGP shallow shells under different truncation numbers. As a matter of convenience, the truncation numbers in two directions of the shallow shells coincide the same value, $M=N$, $M\timesN=4\times4$, $8\times8$, $10\times10$, and $12\times12$, are selected in the analysis. The structure in the analysis adopts the first type of pore distribution, which the porosity coefficient is $e_0=0.2$ and the geometry $b=1$ m, $h=1$ m. It can be formed from the table that $M=N=8$ makes the calculation converge in the lower order frequencies cases. For relatively high order cases, $M=N=12$ is sufficient to meet the convergence requirements. Therefore in all subsequent analyses, the polynomial truncation number is set as 15.
