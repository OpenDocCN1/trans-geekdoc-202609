# 5.2.4 Spectral Chebyshev method

In the natural coordinate system, the unknown function p(x, y) of the shallow shell can be transformed into q(ξ, η), which can be expressed by Chebyshev polynomials of first kind:

```
$x = \frac{a}{2}\xi + \frac{a}{2}y = \frac{b}{2}\eta + \frac{b}{2}, \xi \in[-1, 1], \eta \in[-1, 1]$ \eqn (5.19)
```

```
$q(\xi, \eta) \equiv C_{\q}a \eqn (5.20a)
```

```
$C_{\q} = C_{M-1}(\xi) \otimes C_{N-1}(\eta)$ \eqn (5.20b)
```

```
$C_{M-1}(\xi) = \{cos[0 \cdot \xi], cos[1 \cdot \xi], \dots, cos[(M-1) \cdot \xi]\}$\}$ \eqn (5.20c)
```

```
$C_{N-1}(\eta) = \{cos[0 \cdot \eta], cos[1 \cdot \eta], \dots, cos[(N-1) \cdot \eta]\}$\}$ \eqn (5.20d)
```

```
$a = (a_{0,0}, \dots, a_{0,N-1}, a_{1,0}, \dots, a_{1,N-1}, \dots, a_{M-1,N-1})^T \eqn (5.20e)
```

where a is the coefficient vector of expansion. M and N are the total terms of polynomials, which are also termed as the truncation number.
The Gauss-Lobatto points are used for discrete sampling the rectangle domain in the natural coordinate system:

```
$$\xi_i = -cos\left(\frac{\pi i}{M-1}\right), i=0, 1, \dots, M-1.$ \eqn (5.21)
```

```
$$\eta_j = -cos\left(\frac{\pi j}{N-1}\right), j=0, 1, \dots, N-1.$ \eqn (5.21)
```

Then the relationship between the function value vector and the expansion coefficient can be written as follows:

```
$q = C_{\q}a, \quad a = C_{\q}^{-1}q \eqn (5.22)\nwhere
$$q = (q_{0,0}, \dots, q_{0,N-1}, \dots, q_{M-1,0}, \dots, q_{M-1,N-1})^T$$ \eqn (5.23a)\n$$C = C_{M-1}(\xi) \otimes C_{N-1}(\eta)$$ \eqn (5.23b)$
```
