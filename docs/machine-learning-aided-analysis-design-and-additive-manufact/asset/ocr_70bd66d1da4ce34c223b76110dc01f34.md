where $u(t)$, $v_s(t)$, and $w_d(t)$ represent generalized coordinates related to $t$; $m$ and $n$ denote numbers of axial half-waves and circumferential waves, respectively.

The Lagrange equations of motion are:

```
$$\frac{d}{dt}\frac{\partial T}{\partial q_i} - \frac{\partial(T-U)}{\partial q_i}\dot{q}_i = 0, \quad i=1, 2, 3$
```

where $q_i$ is the $i$th element of the vector $\mathbf{q} = \{u(t), v_s(t), w_d(t)\}$; $\dot{q}_i = dq_i/dt$.
Substituting Eqs. (4.90) and (4.91) in Eq. (4.94), we can obtain the following ordinary differential equations:

```
$k_{11}u_i + k_{12}v_i + k_{13}w_i = \frac{\partial^2u_i}{\dt^2}$
```

```
$k_{21}u_i + k_{22}v_i + k_{23}w_i = \frac{\partial^2v_i}{\dt^2}$
```

```
$k_{31}u_i + k_{32}v_i + k_{33}w_i + k_{34}w_i^2 = \frac{\partial^2w_i}{\dt^2}$
```

where

```
$k_{11} = \frac{A_{11}R^2\pi^2 + A_{66}L^2n^2}{L^2R^2\rho^2}$
```

```
$k_{12} = \frac{(A_{12}+A_{66})mn\pi}{LR\rho^2}$
```

```
$k_{13} = \frac{m\pi[A_{12}L^2R+B_{11}m^2\pi^2R^2+(B_{12}+2B_{66})L^2n^2]}{L^3R^3\rho^2}$
```

```
$k_{21} = \frac{(A_{12}+A_{66})mn\pi}{LR\rho^2}$
```

```
$k_{22} = \frac{A_{11}L^2n^2+A_{66}m^2\pi^2R^2}{L^2R^2\rho^2}$
```

```
$k_{23} = \frac{n[B_{11}L^2R+A_{11}L^2R+(B_{12}+2B_{66})m^2\pi^2R^2]}{L^2R^3\rho^2}$
```
