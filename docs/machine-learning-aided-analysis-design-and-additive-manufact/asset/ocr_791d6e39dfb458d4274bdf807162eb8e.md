# 9.2.2 Numerical simulations

The finite element (FE) simulations are performed using the dynamic implicit solver as a quasi-static analysis in the commercial software ABAQUS. The Young’s modulus and Poisson’s ratio of PLA filament are 2.1 GPa and 0.33. A linear elastic material was modeled, and the simulation was modeled under a 2D plane strain approximation. All-self contact definition in ABAQUS was used, which allows contact detection on all surfaces. Mesh refinement was studied to ensure an optimal mesh size for the rest of the simulation. 2D units were constructed and discretized using Abaqus element type CPS3 with a global mesh size of 0.75 mm. The quasi-static analysis was chosen to simulate the nonlinearities of contact as well as the snap-through behavior and the kinetic energies were monitored to be below the quasi-static nature. Thus we ran only a total of 168 simulations for symmetry for $3 \times 3$ cells and 16,576 simulations for $4 \times 4$ patterns the “unique” patterns. Fig. 9.1B shows the response curves, including a lower (LB) pattern without infills, an arbitrary pattern with five infills and an upper (UB) pattern with full (nine) infills, indicating that the number and the layout of unit cells can significantly affect the observed location and propagation sequence of localized buckling of each pattern. Fig. 9.1C and D show the domain expansion and a response curve for a representative nonuniform $4 \times 4$ unit cell.

# 9.2.3 Neural network parameters and architecture of machine learning framework

In this work, ML models are generally statistics-based data-driven algorithms that are trained to recognize and predict relations in data. Once properly trained, the model is capable of predicting solutions to problems in a minuscule amount of computational time. These approaches are especially useful for solving problems that exist in large design spaces and have numerous prohibitive parameters. We previously built an ML-based framework that contains three components (Ref. [27] for details): data preparation, training of the DNN, and implementation with the trained model. In the data preparation, we generated 65,536 possible patterns for the $4 \times 4$ unit cell. Any given pattern may share the same physical phenomenon under the axial compression with its sisters due to geometric symmetry, there are only 16,576 unique patterns that can exhibit different mechanical responses under the axial compression for the $4 \times 4$ unit cell.
