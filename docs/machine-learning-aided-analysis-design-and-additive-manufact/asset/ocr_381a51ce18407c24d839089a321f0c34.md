# 10.2.3 Convolutional neural networks

To date, multiple deep CNN models have been developed to facilitate and improve the feature extraction of images. One of these models is U-Net which initially developed for the segmentation of biomedical images [36]. In the last couple of years, there have been many variations of U-Net introduced in different research areas, such as Uet++ [37], Attention U-Net [38], Residual U-Net [39], and Nas U-Net [40], with each one modifying and improving the original architecture for their desired tasks. The general U-Net architecture is constructed of an encoder with the objective of finding features of different scales and semantic values from the input image; a decoder path for upsampling produced features to generate the final segmentation layers [4]. During convolution, there is a concatenation of the last layer of the corresponding block in the encoder path. This concatenation helps the model recover information that might be lost during downsampling.

Another significant concern with CNNs was the introduction of ResNets [42]. Originally it was expected that, as the number of layers, the model performance increases, but in practice, after a certain number of layers, the model plummeted due to the vanishing gradient issue [1]. ResNet solved this issue by introducing residual blocks and skip connections. Skip connections modify the main differentiator between normal and residual blocks. The block by adding the input of the block to the final layer output. One method is to add input to the final layer output while maintaining the same dimension as identity mapping, which is a 1 x1 convolution. These skip connections prevent the gradient from becoming too small, avoiding the model performance reduction. A simple residual block is shown in Fig. 10.5.

The model used in this work is a combination of the aforementioned models originally proposed by [39] for road extraction from aerial images. It incorporates the downsampling from the ResNet model followed by a series of fully connected layers to generate a regression model for the prediction of the Young's modulus. The connections and the residual block, as well as the model architecture, are shown in Fig. 10.6.
