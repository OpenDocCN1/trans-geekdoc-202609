fG porous composite structures

```
$$\mathbf{x} = [x_1, x_2, \dots, x_m]^T \rightarrow \hat{k}(\mathbf{x}) = \begin{bmatrix} \Theta(x_1)^T & \Theta(x_1) \ \Theta(x_2)^T & \Theta(x_2) \ \vdots & \vdots \ \Theta(x_m)^T & \Theta(x_m) \end{bmatrix}$$\n = \begin{bmatrix} k(x_1, x_1) & k(x_1, x_2) \ k(x_2, x_1) & k(x_2, x_2) \ \vdots & \vdots \ k(x_m, x_1) & k(x_m, x_2) \end{bmatrix}$
```

where $k(\mathbf{x})$ is the empirical kernel vector, and the kernelized form of X-SVR can be shown as:

```
$$\min_{\mathbf{p}_i, \mathbf{q}_i, \vartheta} \frac{1}{2} ||\mathbf{p}_i - \mathbf{q}_i||^2 + \gamma_1 k(\\mathbf{p}_i, \mathbf{q}_i) + \gamma_2 \frac{1}{2} (\dot{\vartheta}^2 + \vartheta^2)$$\n$\$\text{s.t.} \quad k(\mathbf{p}_i, \mathbf{q}_i) - \delta e_{im} \leq y_i \leq \lambda e_{im} + \vartheta,\$\n\quad y_i - k(\mathbf{p}_i, \mathbf{q}_i) \leq \delta e_{im} \leq \lambda e_{im},\$\n\quad \mathbf{p}_i, \mathbf{q}_i \geq 0; \quad \vartheta \geq 0$$
```

where $\gamma_1, \gamma_2$ are the tuning parameters; $\vartheta$ is the tolerable variable; $k$ denotes the kernelized process. From the optimization problem adopted in the DrSVM model, the regression function can be simplified and considered as a quadratic programming problem by introducing a nonnegative Lagrange multiplier $\beta_k \in \mathbb{R}^{im}$ as:

```
$$\min_{\beta_k} \frac{1}{2} \beta_k^T \mathbf{P}_k \beta_k - \mathbf{L}_k^T \beta_k; \quad \beta_k \geq \mathbf{0}_{im}$$
```

where $\mathbf{P}_k$ and $\mathbf{L}_k$ are optimization vectors and matrices. Considering $\beta_k^* \in \mathbb{R}^{im}$ as the obtained global solution for the optimization problem, the overall kernel equation of the kernel-SVR model can be reformulated as:

```
$$\hat{f}_n(\mathbf{x}) = (\mathbf{p}_n - \mathbf{q}_n)^T k(\mathbf{p}_n, \mathbf{x}) - \mathbf{v}_k^T \beta_k^*$\n$\$\mathbf{p}_n - \mathbf{q}_n = \mathbf{v}(1:m) - \mathbf{v}(m+1:2m); \quad \mathbf{v}_k^T = (\mathbf{R}_k + \mathbf{I}_{lm \times k})^T \beta_k^* - \gamma_2 \mathbf{u}_k$$
```

As mentioned before, the ultimate regression performance of the X-SVR model depends on the kernel selected, and a new kind of kernel, as the generalized Gaussian kernel (GGK) has been proposed, which is defined recursively by:

```
$$\P_k^0(x) = 1$\n\P_k^1(x) = 2\sigma x$\n\P_k^d(x) = \frac{1}{d} [2\sigma x^d(d + \sigma - 1)P_{x-1}^{d-1}(x) - (d + 2\sigma)P_{x-2}^{d-2}(x)], \quad d=2, 3, 4, \dots$$
```

where $\sigma$ denotes polynomial hyperparameter; $d$ is the polynomial order.
