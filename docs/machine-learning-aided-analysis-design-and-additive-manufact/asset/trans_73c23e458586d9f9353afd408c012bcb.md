### 3.3.2 FGP 板的瞬态响应

如图 39 所示，本文采用了四种加载类型：(A) 矩形脉冲；(B) 三角脉冲；(C) 半正波脉冲；(D) 指数脉冲，其表达式如下：

对于矩形脉冲：
```
f(t) = f_r(H(t) - H(t - t_r))
```

对于三角脉冲：
```
f(t) = f_r(1 - t/t_r)
```

对于半正波脉冲：
```
f(t) = f_r.sin(pi*t/t_r)H(t)
```

对于指数脉冲：
```
f(t) = f_r e^{-Dt}
```
