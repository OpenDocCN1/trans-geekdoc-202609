# 4.4.3 Results and discussion

To validate the present nonlinear results, nonlinear to linear frequency ratio $\omega_r/omega_t$ of a simply supported isotropic cylindrical shell is calculated and compared with those given by Raju and Rao [33], as shown in Table 4.4. The difference between the current results and the material parameters of the FG porous circular shell is very small.

The geometric and material parameters of the FG porous circular shell are given in the following equations:

```
$L=5$ m, R=1$ m, h=0.002$ m, E^*=2.04 \times 10^{11}$ Pa, 
\rho^*=7850$ kg/m$^2, \mu^*=0.3$.
```

Linear natural frequencies of the simply supported FG circular cylindrical shell with porosity distributions are tabulated in Tables 4.5–4.7 for different modes. It is seen that the mode ($m=1, n=5$) corresponds to the smallest natural frequency (fundamental frequency) for all three types of porosity
