FGP material typically has various types of porosity, such as uniform distribution, symmetric distribution, and non-symmetric distribution. In the chapter, two representative porosity distributions along the thickness are namely Type 1: symmetric distribution, Type 2: asymmetric. The biggest difference between the two types is that the porosity distribution function along the thickness coordinate direction is different. The material property function of Type 1 can be expressed as follows:

```
$E(z) = E_1 - e_{e_0}cos\left(\frac{\pi z}{h}\right)\nG(z) = G_1 - e_{g_0}cos\left(\frac{\pi z}{h}\right) \quad (5.1)\n\rho(z) = \rho_1 - e_{\rho_0}cos\left(\frac{\pi z}{h}\right)$
```

The material expression of Type 2 is defined as Eq. (5.2). It is obvious that the Young's modulus, the mass density, and shear modulus show a monotonic trend along the thickness direction.

```
$E(z) = E_1 - e_{e_0}cos\left(\frac{\pi z}{2h} + \frac{\pi}{4}\right)\nG(z) = G_1 - e_{g_0}cos\left(\frac{\pi z}{2h} + \frac{\pi}{4}\right) \quad (5.2)\n\rho(z) = \rho_1 - e_{\rho_0}cos\left(\frac{\pi z}{2h} + \frac{\pi}{4}\right)$
```

In the above formula, $h$ indicates the thickness of the shell, and $e_m$ are the porosity coefficients [42], which is given by

```
$e_0 = 1 - \frac{E_0}{E_1} = 1 - \frac{G_0}{G_1}(0 < e_0 < 1)\ne_m = 1 - \sqrt{1 - e_0} \quad (5.3)$
```

where $E$ is the elastic modulus, $\rho$ is the mass density, $G$ is the shear modulus. In addition, the subscripts 0 and 1 represent the minimum and maximum values of the material parameters. It is worth noting that $e_0 = e_m = 0$ indicates that there are no pores in the material, while $e_0=e_m=1$ is obviously an impossible form of existence
