# 3.3.2 Transient response of FGP plates

As shown in Fig. 39, there are four types of loading employed in this paper: (A) Rectangular pulse; (B) Triangular pulse; (C) Half-sine pulse; (D) Exponential pulse, which can be expressed as

For rectangular pulse:

```
f(t) = f_r(H(t) - H(t - t_r))
```

For triangular pulse:

```
f(t) = f_r(1 - t/t_r)(H(t) - H(t - t_r))
```

For half-sine pulse:

```
f(t) = f_r.sin(pi t/t_r)H(t) - H(t - t_r))
```
