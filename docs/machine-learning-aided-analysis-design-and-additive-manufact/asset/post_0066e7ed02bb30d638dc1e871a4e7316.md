$\beta$ is the random power-factor of GPLs. The parameters $c_{l1}, c_{l2}, c_{l3},$ and $c_{l4}$ are the maximum values of GPL volume fraction of porous nanocomposite beams for different combinations of porosity distributions and GPL dispersion patterns.

Employing Halpin-Tsai micromechanical model, the maximum Young's modulus $E_{max}$ of porous nanocomposite beams can be written as:

```
$E_{max} = E_m \times \frac{1 + \eta_L \mu_L V_{GPL}}{1 - \mu_L V_{GPL}} + 0.625 \times \frac{1 + \eta_T \mu_T V_{GPL}}{1 - \mu_T V_{GPL}} \eqno (7.5)$
```

where $\eta_l = 2l_{GPL}/h_{GPL}, \eta_T = 2w_{GPL}/h_{GPL}$ are the relationship between average length $l_{GPL}$, width $w_{GPL}$, and thickness $h_{GPL}$ of GPL nanofibers, respectively. $E_m$ is the Young's modulus of metal foam. $V^{GPL}$ is the ratio of total volume $V$ of the nanocomposite beams. The material coefficients $\mu_L, \mu_T$ can be further expressed as:

```
$$\mu_L = \frac{E_{GPL} - E_m}{E_{GPL} + \eta_L}, \mu_T = \frac{E_{GPL} - E_m}{E_{GPL} + \eta_T} \eqno (7.6)$$
```

in $E_{GPL}$ denote the Young's modulus of GPLs.

The mass density and Poisson's ratio of FGGER beams are expressed as:

```
$$\rho_{max} = \rho_{GPL}^{GPL} + \rho_{m}(1 - V_{f}^{GPL}) \\ v_{max} = v_{GPL}^{GPL} + v_{m}(1 - V_{f}^{GPL})$$ (7.7)
```

where $\rho_{m}$ and $v_{m}$ are the mass density and Poisson's ratios of matrix and GPLs, respectively. The relationship of volume fraction for these two components is $V^{GPL} + V^{m} = 1$. To compare different porosity distributions and GPL patterns, mass $M$ constant, therefore the volume of GPLs $V_{GPL}$ can be written as:

```
$V_{GPL} = \frac{V_{f}^{GPL}}{\rho_{max}}, M = \int_{-h/2}^{h/2} \rho(z)dz$ (7.8)
```

Furthermore, volume fraction of GPLs is determined by rule of mixture, which is expressed as:

```
$V_{GPL} = \frac{V_{f}^{GPL}}{V_{GPL} + V_{m}} = \frac{\Delta_{GPL}}{\Delta_{GPL} + (1 - \rho_{GPL}/\rho_{m})}$ (7.9)
```

in which $\Delta_{GPL}$ is the weight fraction of reinforcement inside the matrix, also marked as wt in some studies. By using Eq.(7.9) into Eq.(7.8), and then combining with Eq.(7.4), the parameters $c_{s1}, c_{s2}, c_{s3}$ and $c_{s4}$ of porous nanocomposite for different combinations of porosity distributions and dispersions can be derived from:

```
$c_{s1} = \int_{-h/2}^{h/2} [1 - \cos(\frac{\pi z}{h})] \frac{\rho(z)}{\rho_{max}}dz \\ c_{s2} = \int_{-h/2}^{h/2} [1 - \cos(\frac{\pi z}{2h})] \frac{\rho(z)}{\rho_{max}}dz \\ c_{s3} = \int_{-h/2}^{h/2} [1 - \cos(\frac{\pi z}{4})] \frac{\rho(z)}{\rho_{max}}dz \\ c_{s4} = \int_{-h/2}^{h/2} \frac{\rho(z)}{\rho_{max}}dz \\ \Delta_{GPL}^{h/2}^{h/2} = \int_{-h/2}^{h/2} (1 - e_{m}(\rho(z)))dz \Delta_{GPL} + (1 - \rho_{GPL}/\rho_{m})}$ (7.10)
```

where $e_m$ is the mass density of metal foams. The relationship between Young's modulus and mass density is introduced by adopting Gaussian field model:

```
$E_{max} = \frac{E(z)}{\varphi(z)} + \frac{1}{\rho_{max}^2}$
```

By substituting Eq.(7.1) into Eq.(7.11), one can obtain:

```
$e_m = \frac{1 - \sqrt{1 - \varphi(z)}}{\varphi(z)}$
```

Furthermore, the coefficient of porosity for even porosity distribution $\varphi_0$ can be derived as:

```
$\varphi_0 = \frac{1}{e_0} \left[1 - (\frac{M}{\rho_{max}} + \frac{1}{\rho_{max}^2})\right]$
```

## 7.3 Theoretical formations of axes

The displacement of points along axes $x$ and $z$ of the beam, $U(x,z,t)$ and $W(x,z,t)$ can be expressed as:

```
$U(x,z,t) = u_0(x,t) + z\psi(x,t) \\ W(x,z,t) = w_0(x,t)$
```

where $u_0(x,t)$ and $w_0(x,t)$ are the longitudinal and transverse displacements. $\psi$ is the rotation of the beam cross-section. The linear normal strain $\varepsilon_{xx}$ and shear strain $\gamma_{xz}$ can be derived as:

```
$\varepsilon_{xx} = \frac{\partial u_0}{\partial x} + z\frac{\partial\psi}{\partial x}, \gamma_{xz} = \frac{\partial w_0}{\partial x} + \frac{\partial\psi}{\partial x}$
```

And the corresponding normal stress $\sigma_{xx}$ and shear stress $\tau_{xz}$ are given as:

```
$\sigma_{xx} = \frac{E(z)}{1-v(z)^2}\varepsilon_{xx}, \tau_{xz} = G(z)\gamma_{xz}$
```

Employing the Hamilton's principle as follows:

```
$$\int_{0}^{\tau} (\delta U_k - \delta U_s + \delta U_d)dt = 0 \quad (7.17)$$
```

where $\delta U_k, \delta U_s,$ and $\delta U_d$ denote kinetic energy, strain energy, and potential energy due to the external force, respectively. The following governing equations of FGGR reinforced beam be obtained as:

```
$$\delta u : \frac{\delta N_s}{\delta x} = I_0 \frac{\partial^2 u_0}{\partial t^2} + I_1 \frac{\partial^2 \psi}{\partial t^2} \\ \delta w : \frac{\delta Q_s}{\delta x} = -P_x \frac{\partial^2 w_0}{\partial x^2} + \frac{\partial^2 \psi}{\partial t^2} \\ \delta \psi : \frac{\delta M_s}{\delta x} = I_1 \frac{\partial^2 u_0}{\partial x^2} + I_2 \frac{\partial^2 \psi}{\partial t^2} \quad (7.18)$$
```

where $N_s, M_s,$ and $Q_s$ can be expressed as:

```
$N_s = A_{11} \frac{\partial u_0}{\partial x} + B_{11} \frac{\partial \psi}{\partial x} \\ M_s = B_{11} \frac{\partial u_0}{\partial x} + D_{11} \frac{\partial \psi}{\partial x} \\ Q_s = A_{55} (\frac{\partial w_0}{\partial x} + \frac{\partial \psi}{\partial x})$
```

And stiffness components are calculated by:

```
$A_{11}, B_{11}, D_{11} = \int_{-h/2}^{h/2} \frac{E(z)}{1-v(z)^2} dz \\ A_{55} = \int_{-h/2}^{h/2} G(z)dz \quad (7.20)$
```

and $b$ is the width of the beam and $k$ denotes shear correction factor and is taken $k=5/6$ in this study. Substituting Eq.(7.18), Eq.(7.19), the governing equation of GPL reinforced beams can be rewritten as:

```
$A_{11} \frac{\partial^2 u_0}{\partial x^2} + B_{11} \frac{\partial^2 \psi}{\partial x^2} = I_0 \frac{\partial^2 u_0}{\partial t^2} + I_1 \frac{\partial^2 \psi}{\partial t^2} \\ A_{55} (\frac{\partial^2 w_0}{\partial x^2} + \frac{\partial^2 \psi}{\partial x^2}) = -P_x \frac{\partial^2 w_0}{\partial x^2} + I_2 \frac{\partial^2 \psi}{\partial t^2} \quad (7.21)$
```

in which the inertia terms are given by:

```
$(I_0, I_1, I_2) \approx \int_{-h/2}^{h/2} \rho(z)(1, z, z^2)dz \quad (7.22)$
```

## 7.4 Solution methodology and equations

### 7.4.1 Discrete singular convolution algorithm

Employing the DSC theorem [28], the $n^{th}$ derivative of a function $F(x)$ with respect to $x_i$ can be expressed as:

```
$$F^{(n)}(x_i) = \sum_{j=i-M}^{i+M} \phi_{\Delta}^{(n)}(x_i - x_j)F(x_j), \quad (n=0, 1, 2, \dots) \quad (7.23)$$
```

$x_i$ represents set of equally spaced grid points centered around $x_i$. In addition, $\delta_{\Delta}^{(n)}(x_i - x_j)$ represents the DSC kernel of Dirichlet type. Shannon’s kernel is selected as DSC kernels as follows:

```
$$\delta_{\Delta, \sigma}(x_i - x_j) = \frac{\sin(\pi/\Delta)}{(\pi/\Delta)(x_i - x_j)} \exp\left(-\frac{1}{2}\left\{(x_i - x_j)/\sigma\right}^2\right) \quad (7.24)$$
```

$\sigma$ and $\Delta$ are the regularization parameters and grid point spacing, respectively. The ratio of them is fixed by the discretization parameter ($r=\sigma/\Delta$). One can obtain an appropriate $r$ by using Eq. (7.25), which is proposed by Wei et al. [28].

```
$$r(\pi - B\Delta) > \sqrt{4.6\mu}, M/r > \sqrt{4.6\mu} \quad (7.25)$$
```

By using the DSC method, the first and second derivatives of $F(x)$ with respect to $x_i$ can be written as follows:

```
$$F^{(1)}(x_i) = F_i^{(1)} \approx \sum_{j=i-M}^{i+M} \phi_{\Delta}^{(1)}(x_i - x_j)F(x_j) = \sum_{j=i-M}^{i+M} A_{ij}F_j \quad (7.26)$$
```

```
$$F^{(2)}(x_i) = F_i^{(2)} \approx \sum_{j=i-M}^{i+M} \phi_{\Delta}^{(2)}(x_i - x_j)F(x_j) = \sum_{j=i-M}^{i+M} B_{ij}F_j$$
```

For more details about DSC method, please check Refs. [17] and [28].
