Once the energy expressions and the admissible functions are obtained, the Ritz method is employed to derive the eigenvalue equation of the FG porous cylindrical shell.

Substituting Eq.(4.16) into Eq.(4.7), the kinetic energy T of the FG porous cylindrical shell can be expressed as:

```
$T = \frac{\pi LR}{2} \rho_0^2 \int_{0}^{L} \omega^2 (U^2 + V^2 + W^2) d\etaquad (4.19)$
```

where

```
$\rho_0^2 = \int_{-L}^{L} \rho(z) dz \quad (4.20)$
```
