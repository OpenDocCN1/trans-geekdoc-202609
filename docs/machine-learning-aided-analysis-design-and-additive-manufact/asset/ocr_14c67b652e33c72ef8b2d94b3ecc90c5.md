# 11.3.1 First-order shear deformation of plate

In order to do the static analysis of the FGP, the Mindlin plate theory or the FSDT for plates will be adopted. Take $\Omega$ the midplane domain. The assumed displacement for a field plate (thickness $h$) $u(x,y,z)$, $v(x,y,z)$, and $w(x,y,z)$ are described as:

```
$u(x,y,z) = u_0(x,y) + z\beta_x(x,y), \\nv(x,y,z) = v_0(x,y) + z\beta_y(x,y), \quad -\frac{h}{2} \le z \le \frac{h}{2}$\
w(x,y,z) = w_0(x,y) \quad (11.5)$
```

where $\mathbf{u} = (u_0, v_0, w_0)$ and $\beta_x, \beta_y$ represent the membrane displacements, the deflection of the midplane and in the $x-z$ and $y-z$ planes, respectively.

Based on the small strain theory, the relationships for the displacement and strains $\varepsilon = (\varepsilon_{xx}, \varepsilon_{yy})$ can be explained as:

```
$\varepsilon = \begin{bmatrix} \frac{\partial u_0}{\partial x} + \frac{\partial \beta_x}{\partial x} & \frac{\partial \beta_x}{\partial y} \\\frac{\partial v_0}{\partial x} & \frac{\partial v_0}{\partial y} + \frac{\partial \beta_y}{\partial y} \\\frac{\partial u_0}{\partial z} & \frac{\partial v_0}{\partial z} \end{bmatrix} = \varepsilon^m + z\varepsilon^l \quad (11.6)$
```

The relationships between the shear strain $\gamma = (\gamma_{xz}, \gamma_{yz})$ and displacement can be explained as:

```
$\gamma = \begin{bmatrix} \gamma_{xz} \\gamma_{yz} \end{bmatrix} = \begin{bmatrix} \frac{\partial u_0}{\partial z} + \beta_x \\frac{\partial v_0}{\partial z} + \beta_y \end{bmatrix} \quad (11.7)$
```

Assuming a null transverse normal stress $\sigma_z$, the stress-strain relationships are shown as:

```
$\sigma = \begin{bmatrix} \sigma_x \ \sigma_y \ \sigma_z \end{bmatrix} = \mathbf{D}\varepsilon$
$\tau = \begin{bmatrix} \tau_{xz} \\tau_{yz} \end{bmatrix} = \mathbf{D}^T\gamma \quad (11.8)$
```
