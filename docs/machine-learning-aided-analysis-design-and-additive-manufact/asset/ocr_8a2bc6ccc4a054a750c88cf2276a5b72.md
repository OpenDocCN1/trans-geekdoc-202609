Substituting Eqs. (4.7) and (4.15) into Eq. (4.56), the governing equation of the FG porous cylindrical shell can be derived as:

```
$M\dot{q} + C\dot{q} + (K+K_s)q=F(t) \quad (4.57)$
```

with

```
$q = [q_u, q_v, q_w]^T \quad (4.58)$
```
