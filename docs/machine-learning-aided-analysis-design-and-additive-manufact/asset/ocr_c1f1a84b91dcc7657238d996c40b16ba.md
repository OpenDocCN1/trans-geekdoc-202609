# 4.3.2 Solution procedure

The frequency response function of the FG porous cylindrical shell is given by:

```
$$\mathbf{H} = [(\mathbf{K} + \mathbf{K}_b) + i\omega\mathbf{C} - \omega^2\mathbf{M}]^{-1} \quad (4.77)$
```

According to the orthogonality of modes, Eq. (4.78) can be obtained:

```
$$\mathbf{Q}^T\mathbf{M} = \mathbf{I}_{3(G+1) \times 3(G+1)}$$\n$$$\mathbf{Q}^T(\mathbf{K} + \mathbf{K}_b)\mathbf{Q} = \text{diag}(\omega_1^2, \omega_2^2, \dots, \omega_{3N(G+1)}^2) \quad (4.78)$$\n$$$\mathbf{Q}^T\mathbf{C} = \text{diag}(\alpha_1 + \beta_1\omega_1^2, \dots, \alpha_{3N(G+1)} + \beta_{3N(G+1)}\omega_{3N(G+1)}^2)$
```

where $I$ is the identity diagonal matrix, $\omega_1, \omega_2, \dots, \omega_{3N(G+1)}$ represent the circular frequencies of different orders, $Q$ is the mode vector of the system is expressed as:

```
$$\mathbf{Q} = [q_1; \dots; q_{3N(G+1)}] \quad (4.79)$
```

Eq. (4.77) can be decoupled using Eq. (4.78), so the frequency response matrix of displacement is obtained:

```
$$\mathbf{H}_{ij}(\omega) = \sum_{n=1}^{NT} \frac{q_{in}q_{jn}}{\omega_n^2 + (\alpha_n + \beta_n\omega_n^2)\omega^2} \quad (4.80)$
```

where $NT$ represents the truncated number of modes in practical calculation.
 fact, the mode vectors $q_i$ are unknown coefficients of the displacement functions [see Eq. (4.48)], which can be expressed as follows:

```
$$\mathbf{q}_i = \begin{bmatrix} \alpha_{i1}^a & \alpha_{i2}^a & \dots & \alpha_{iNG}^a \ \alpha_{i1}^b & \alpha_{i2}^b & \dots & \alpha_{iNG}^b \ \alpha_{i1}^c & \alpha_{i2}^c & \dots & \alpha_{iNG}^c \ b_{i1}^a & b_{i2}^a & \dots & b_{iNG}^a \ b_{i1}^b & b_{i2}^b & \dots & b_{iNG}^b \ b_{i1}^c & b_{i2}^c & \dots & b_{iNG}^c \end{bmatrix}^T$ (Wait, simplified representation))\quad (4.81)$
```

It is significant to note that the frequency response function between the excitation $p$ and the response $q$ of an arbitrary point, which is an element of the frequency response matrix in Eq. (4.80). Generally, the radial response of the FG porous cylindrical shell is of interest with the other directions. The mode vectors constructing the excitation point and the response point are based on radial displacement functions, which are expressed as follows:

```
$$\q_i^a = \sum_{e=0}^G T_{ie}^a(r_p)\cos(\theta_e), \sum_{e=0}^G T_{ie}^a(r_p)\cos(2\theta_e), \dots, \sum_{e=0}^G T_{ie}^a(r_p)\cos(G\theta_e)$$\n$\q_i^b = \sum_{e=0}^G T_{ie}^b(r_p)\cos(\theta_e), \sum_{e=0}^G T_{ie}^b(r_p)\cos(2\theta_e), \dots, \sum_{e=0}^G T_{ie}^b(r_p)\cos(G\theta_e)$ \quad (4.82)$
```
