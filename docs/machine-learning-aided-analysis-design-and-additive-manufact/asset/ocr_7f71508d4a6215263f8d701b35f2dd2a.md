# 12.5.3 Fused porous drone base structure

The second example involves a FGP drone base structure for quadcopters and the geometry is shown in Fig. 12.9. The thickness of FGP is 1 cm with material properties changing from bottom to top. The metal and ceramic components of the FGP base are made of steel and alumina (Al2O3). The four ends of the base are fixed and the stochastic FEM analysis is considered for the base. Calculating using FEM, the convergence of different meshes is discussed for the FGP, and the most converged mesh size is selected as $h_{min}=0.1cm.

To reinforce the effectiveness for MLA-SFV framework, two different cases of Case A and Case B representing two porosity distributions are investigated.
