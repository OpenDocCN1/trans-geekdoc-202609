where $n=1$ represents the conventional porosity distributions (or first order distributions) and the higher order distributions can be obtained for $n>1$. However, values greater than 3 could be impractical due to difficulties with the manufacturing. Here $n=3$ is selected, which is chosen to result in better response of porous structures [18,29]. In addition, constants $\eta_0, \eta_1, \eta_2, \eta_3$ and $\eta_n$ are introduced to equalize the porosity volume fraction for all porosity distributions, which can be found by the following relations:

```
$$\lambda = bLh$$
```

The material density of the porous beam can be obtained by:

```
$$\rho = (1-V_p)\rho_0$$
```

where $ho_0$ is the density of the parent material, which is the material that is used for the cells of the porous structure. It is assumed that beams are made of open-cell porous materials, and the effective elastic properties follow the Gibson and Ashby model [41,42] as:

```
$$\E = E_0(\rho/\rho_0)^2$$
```

where $E_0$ is the elastic modulus of the parent material. Inserting Eqs. (6.1) and (6.9) into Eq. (6.10), the elastic modulus of the porous beam based on the total volume fraction of porosity can be expressed as:

```
$$\E = E_0(1-\lambda_a\alpha)^2$$
```
