# 4.2.2 Solution procedure

The mode of the FG cylindrical shell in the circumferential direction is defined as a harmonic function, and the axial mode is selected as a polynomial. Then displacement functions can be expressed as:

```
$u(\eta, \theta, t) = \cos(n\theta+\omega t)U(\eta) \nv(\eta, \theta, t) = \sin(n\theta+\omega t)V(\eta) \nw(\eta, \theta, t) = \cos(n\theta+\omega t)W(\eta) \n(4.16)
```

where $\omega$ is circular frequency of vibration and $n$ is circumferential wave number. The axial mode functions $U(\eta)$, $V(\eta)$, and $W(\eta)$ expressed by the Chebyshev polynomials can be written as:

```
$U(\eta) = \sum_{g=0}^{NT} a_g \varphi_g^u(\eta) \nV(\eta) = \sum_{g=0}^{NT} b_g \varphi_g^v(\eta) \nW(\\eta) = \sum_{g=0}^{NT} c_g \varphi_g^w(\eta) \n(4.17)
```

in which NT is the truncation order; $a_g$, $b_g$, and $c_g$ are unknown coefficients; $\varphi_g^u(\eta)$, $\varphi_g^v(\eta)$, and $\varphi_g^w(\eta)$ are the Chebyshev polynomials of the first kind, of which the recurrence relations are given by:

```
$\varphi_0(\eta) = 1, \varphi_1(\eta) = \eta, \varphi_{g+1}(\eta) = 2\eta\varphi_g(\eta) - \varphi_{g-1}(\eta), g \ge 1 \n(4.18)
```

The transformation of coordinates from $\eta$ to $2\eta-1$ is necessary for applying the Chebyshev polynomials since the Chebyshev polynomials are defined in the interval $[-1, 1]$, while $\eta \in [0, 1]$.
