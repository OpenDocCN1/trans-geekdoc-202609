
The parameters of RVEs are computed with metal foam characteristics, and the following approach is merely suitable for high-porosity foams. The estimated RVE internal cell number $N_{cell}$ is linked to the foam average cell size $\varnothing_{cell}$ which comes from the manufacturers, via

```
$N_{cell} \approx (H/\varnothing_{cell})^2$
```

where $H$ denotes the height/width of square RVEs.
The total cell length $L_{cell}$ differs based on the morphology of each RVE and is essential in the determination of the cell thickness (uniform for all the cell walls)

```
$t_{cell}=S_{RVE}\mu/L_{cell}$
```

of which $S_{RVE}=H^2$ and $\mu$ is the relative density.
Following construction of RVE models, FE simulations are performed in ANSYS to evaluate their structural behaviors by meshing the geometry with Smart Size (1) (fine mesh, ANSYS automatic sizing) and beam element (BEAM188). All of the out-of-plane displacements are restricted, since 2D homogenization is carried out in this study to focus on in-plane deformations. It has been demonstrated that 2D modeling is feasible for porous foam analysis [31,32] and closed-cell metal foam simulations [15,53,34]. PBCs are applied to the related RVE nodes along left/right edges which share the same vertical coordinates, while fixed supports are imposed across bottom edges. A uniform in-plane vertical displacement ($0.01 \times H$), moving and zero horizontal movement are prescribed on the top edges

```
$E = F/(0.01H_{cell})$
```

that is assumed to be the Young's modulus of the effectiveness of metal foams.
A validation case is conducted to confirm the effectiveness of the proposed RVE modeling to mimic the foam materials in reality. We use the specimen from an existing paper [35] ALPORAS closed-cell aluminum foams: specimen size $50\times50\times30$ mm$^3$; average cell size 2.88 mm, cell wall materials: Young's modulus 61.7 GPa, metal density 2700 kg/$m^3$; Poisson's ratio 0.3; relative density 8.52% $\pm0.74\%$. The proposed RVE model is shown in Fig. 10.2 with external size $30\times30$ mm$^2$, cell number $N_{cell}=109$ (Eq. (10.11)), relative density 8.52%, and the same cell wall material properties as those from the experimental specimen. The predicted compressive modulus $E=1.103$ GPa (Eq. (10.3)) is within the suggested range 1.0–1.2 GPa [35], verifying the validity of the proposed method. Please note that the RVE external sizes do not evidently impact the overall stiffness when sufficient cells are enclosed [17].

To date, multiple deep CNN models have been developed to facilitate the feature extraction of images. One of these models is U-Net which initially developed for the segmentation of biomedical images [36]. In the last couple of years, there have been many variations of U-Net introduced in different areas, such as Uet++ [37], Attention U-Net [38], Residual U-Net [39], and Nas U-Net [40], with each modifying and improving the original architecture for desired tasks. The general U-Net architecture is constructed of an encoder with the objective of finding features of different scales and semantic values from the input; a decoder path for upsampling produced features to generate the final layers [4]. During convolution, there is a concatenation of the last layer of the corresponding block in the encoder path. This concatenation helps the model recover information that might be lost during downsampling.

Another significant concern with CNNs was the introduction of ResNets [42]. Originally it was expected that, as the number of layers, the model performance increases, but in practice, after a certain number of layers, the model plummeted due to the vanishing gradient issue [1]. ResNet solved this issue by introducing residual blocks and skip connections. Skip connections modify the main differentiator between normal and residual blocks. The block by adding the input of the block to the final layer output. One method is to add input to the final layer output while maintaining the same dimension as identity mapping, which is a 11 convolution. These skip connections prevent the gradient from becoming too small, avoiding the model performance reduction. A simple residual block is shown in Fig. 10.5.

The model used in this work is a combination of the aforementioned models originally proposed by [39] for road extraction from aerial images. It incorporates the downsampling from the ResNet model followed by a series of fully connected layers to generate a regression model for the prediction of the Young's modulus. The connections and the residual block, as well as the model architecture, are shown in Fig. 10.6.

Given the nature of the predicted values, multiple loss functions were tested for optimal results. The Mean Absolute Error (MAE) provided significantly better results compared to other test functions, that is Mean Squared Error (MSE) or Root Mean Squared Error (RMSE). The L1 loss function is given

```
MAE = \frac{1}{n} \sum_{i=1}^{n} |y_{actual} - y_{predicted}|
```
