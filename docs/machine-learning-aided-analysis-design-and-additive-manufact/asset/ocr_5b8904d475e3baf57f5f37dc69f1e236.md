Free and forced vibrations of functionally graded porous circular cylindrical shells

The springs stiffness matrix $\mathbf{K}_s$ is expressed as:

```
$$\mathbf{K}_s = egin{bmatrix} \mathbf{K}_{s11} & 0 & 0 \ 0 & \mathbf{K}_{s22} & 0 \ 0 & 0 & \mathbf{K}_{s33} \end{bmatrix} \quad (4.70)$
```

where

```
$\mathbf{K}_{s11} = \int_{0}^{2\pi} (k_1^0U(0)T(0) + k_1^1U(1)T(1))Rd\theta \quad (4.71)$
```

```
$\mathbf{K}_{s22} = \int_{0}^{2\pi} (k_2^0V(0)V^T(0) + k_2^1V(1)V^T(1))Rd\theta \quad (4.72)$
```

```
$\mathbf{K}_{s33} = \int_{0}^{2\pi} [k_3^0W(0)W^T(0) + k_3^1W(1)W^T(1) + \frac{k_3^0}{L_2^2}\frac{\partial W(0)}{\partial eta}\frac{\partial W^T(0)}{\partial eta} + \frac{k_3^1}{L_2^2}\frac{\partial W(1)}{\partial eta}\frac{\partial W^T(1)}{\partial eta}}]Rd\theta \quad (4.73)$
```

```
$\mathbf{C} = \alpha\mathbf{M} + \beta\mathbf{K} \quad (4.74)$
```

where $\alpha$ and $\beta$ represent the damping coefficients and are given by:

```
$\alpha = 2 \left( \frac{\xi_u}{\omega_u} - \frac{\xi_v}{\omega_v} \right) \left( \frac{1}{\omega_u^2} - \frac{1}{\omega_v^2} \right) \quad (4.75)$ \n$\eta = 2 \left( \frac{\xi_u}{\omega_u} - \frac{\xi_v}{\omega_v} \right) / \left( \frac{1}{\omega_u^2} - \frac{1}{\omega_v^2} \right)$
```

in which $\omega_u, \omega_v$ are the first- and second-order natural frequencies, respectively; $\xi_u, \xi_v$ are the corresponding modal damping ratios.

The single-point harmonic excitation acting on the post $(\eta_0, \theta_0)$, is considered in this section, which can be expressed as:

```
$F(t) = [f_u, f_v, f_w]^T = [0, 0, f_{ex}\cos(\omega_{ex}t)]^T_{\eta_0, \theta_0} \quad (4.76)$
```

where $f_{ex}$ is the excitation amplitude and $\omega_{ex}$ is the excitation frequency.
