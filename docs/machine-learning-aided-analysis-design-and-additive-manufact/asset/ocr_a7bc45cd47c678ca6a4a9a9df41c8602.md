Machine learning-aided stochastic analysis of functionally graded porous plates

Due to the positive nature of structural material properties, incorporating a lognormal distribution to model material input uncertainty is more physically realistic than using a Gaussian distribution.

Moreover, the spatial variation of uncertain structural properties is studied using the exponential covariance function C$_{HHH}$(x,x'). Divided into 1D, 2D, and 3D fields, the relevant covariance functions are shown as:

```
$C_{HHH}(\mathbf{x,x'}) = \begin{cases} \sigma_H^2 e^{-\frac{|x-x'|}{l_x}} & \text{for 1D fields} \ \sigma_H^2 e^{-\frac{|x-x'|}{l_x} - \frac{|y-y'|}{l_y}} & \text{for 2D fields} \quad (11.21) \ \sigma_H^2 e^{-\frac{|x-x'|}{l_x} - \frac{|y-y'|}{l_y} - \frac{|z-z'|}{l_z}} & \text{for 3D fields} \end{cases}$
```

where $\sigma_H \in \mathbb{R}^{++}$ represents the standard deviation for the random field; $l_x, l_y, l_z \in \mathbb{R}^+$ represent the correlation lengths in x axle, y axle, and z axle, respectively.

One popular random field discretization technique is the Karhunen–Loève expansion. With the combination decomposition of a bounded, symmetric, and positive definite covariance function $C_{HHH}(\mathbf{x,x'})$, it can be explained as:

```
$C_{HHH}(\mathbf{x,x'}) = \sum_{i=1}^{\infty} \lambda_i \varphi_i(\mathbf{x})\varphi_i(\mathbf{x'}) \quad (11.22)$
```

in which the eigenfunctions of $C_{HHH}(\mathbf{x,x'})$ are taken as the solutions of the following equation:

```
$\forall i = 1, ... \int_D C_{HHH}(\mathbf{x,x'})\varphi_i(\mathbf{x})dD = \lambda_i\varphi_i(\mathbf{x}) \quad (11.23)$
```

From which the orthogonal property is guaranteed through following equation:

```
$\int_D \varphi_i(\mathbf{x})\varphi_j(\mathbf{x})dD = \delta_{ij} \quad (11.24)$
```

in which, $\delta_{ij}$ as the Kronecker symbol. Then the parameters of the random variable set are calculated as:

```
$\zeta(\theta) = \frac{1}{\sqrt{N}} \int_D [H(\mathbf{x}, \theta) - \mu(\mathbf{x})]\varphi_i(\mathbf{x})dD \quad (11.25)$
```
