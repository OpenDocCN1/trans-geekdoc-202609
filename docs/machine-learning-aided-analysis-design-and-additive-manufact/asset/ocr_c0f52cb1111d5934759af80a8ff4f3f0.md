```

```

In these equations, $x, y,$ and $z$ are spatial coordinates in the three-dimensional Cartesian coordinate system. $w$ are the periodicities of level-set approximation function, defined by:

```
$w_i = 2\pi\frac{n_i}{L_i} = x, y, z \quad (13.9)$
```

where $n_i$ determines the number of units along the directions $x, y, z$. $L_i$ is the size of the structure in the corresponding direction.

# 13.2.2 From periodic minimal surface to lattice structures

Surfaces that represent the topologies of TPMS can be plotted by evaluating the level-set approximation equations, and the resulting surfaces will divide the threimensional space into two subunits. Lattice structures based on topologies of TPMS can be produced following two strategies [39]. The first type of solid lattice is named network/solid phase TPMS structures. It can be generated by evaluating the level-set equation at a level-constant and considering one of the줘야 as the surface to be solid while the other to be void. The second type of surface is called minimal surface with a level-constant of 0, which can be generated based on a modified level-set approximation equation. Note that two or more different surfaces that correspond to two or more level-set values can be plotted together. These surfaces will not intersect one another. If two surfaces correspond to two level constants, these surfaces will have the same magnitude but different signs are plotted in opposite directions from a hypothetical surface evaluated at the average of the level-values, where in this case, $c=0$.
