$C_{M-1}(\xi) = [C_{M-1}(\xi_0); \quad C_{M-1}(\xi_1); \quad \dots \quad C_{M-1}(\xi_{M-1})] \quad (5.23c)$

$C_{N-1}(\eta) = [C_{N-1}(\eta_0); \quad C_{N-1}(\eta_1); \quad \dots \quad C_{N-1}(\eta_{N-1})] \quad (5.23d)$

According to the recursive property of Chebyshev polynomials, the partial derivative of the function $q(\xi, \eta)$ with respect to $\xi$ and $\eta$ can be calculated as:

```
$\frac{\partial^2q}{\partial\xi\partial\eta} = [C_{M-1}(\xi)D_{M-1}^*(\xi) \otimes D_N_{N-1}^*(\eta)]\mathbf{q} = Q_{\xi\eta}\mathbf{q} \quad (5.24)$
```

where, partial differential matrix, $D$ denotes the derivative matrix [46].
The integral of $q(\xi, \eta)$ is calculated by the Gauss-Lobatto quadrature rule:

```
$\int_{-1}^1\int_{-1}^1 q(\xi, \eta)d\xi d\eta = \mathbf{V}\mathbf{C}^{-1}\mathbf{q} \quad (5.25)$
```

where

```
$\mathbf{V} = \int_{-1}^1 C_{M-1}(\xi)d\xi \otimes \int_{-1}^1 C_{N-1}(\eta)d\eta = \mathbf{v}_{M-1} \otimes \mathbf{v}_{N-1} \quad (5.26)$
```

$v$ denotes the integral value vector of Chebyshev polynomials:

```
$v_l = \begin{cases} \frac{2}{1-k^2}, & k \text{ even} \ 0, & k \text{ odd} \end{cases} \quad (5.27)$
```

The double integral operation of the rectangle can be calculated as:

```
$\int_{-1}^1\int_{-1}^1 [q(\xi, \eta)]^2 d\xi d\eta = \mathbf{q}^T\mathbf{V}\mathbf{q} \quad (5.28)$
```

where $\mathbf{W} = \text{diag}(\mathbf{V}\mathbf{C}^{-1})$ is the Chebyshev inner product matrix [46].
The admissible displacement function of nucl can be written as:

```
$\begin{bmatrix} u \ q'_1 \ v \ q'_2 \ w = e^{-j\omega t}q'_3 \ \varphi_{\xi} \ q'_4 \ \varphi_{\eta} \ q'_5 \end{bmatrix} = e^{-j\omega t}\mathbf{C}_{\xi\eta}\begin{bmatrix} a^1 \ a^2 \ a^3 \ a^4 \ a^5 \end{bmatrix} \quad (5.29)$
```

where $j$ represents the imaginary unit, and $\omega$ is the circular frequency.
