$(k_{2,1} + k_{2,2} - k_{2,3})\dot{\phi}_n - (k_{2,4} + k_{2,5} + k_{2,6})\ddot{w}_n = -m_{2,1}\frac{d^2\hat{w}_n}{dt^2} \quad (6.35)

$k_{3,1}\hat{u}_n\hat{w}_n + (k_{3,2} + k_{3,3} + k_{3,4} + k_{3,5})\dot{\phi}_n + (k_{3,7} + k_{3,8} - k_{3,9}) \
 -k_{3,10} - k_{3,11})\hat{w}_n + k_{3,12}\frac{d^2\hat{w}_n}{dt^2} = (m_{3,1} - m_{3,2})\ddot{P}_z + \dot{P}_z\dot{w}_n \quad (6.36)

where stiffness (k) and mass (n) coefficients are defined in the [Appendix]. For Eq. (6.34) and (6.36), $\hat{u}_n$ and $\phi_n$ can be obtained based on $\hat{w}_n$, respectively. Subsequently, by substituting $\hat{u}_n$ and $\phi_n$ into Eq. (6.36), a reduced, nonlinear, sec-ond order ODE is obtained:

```
$M\frac{d^2\hat{w}_n}{dt^2} + (K_i - \hat{P}_s)\dot{\hat{w}}_n + K_{it}\hat{w}_n = \hat{P}_z \quad (6.37)
```

where $K_i, K_{it}$ and $M$ are the linear stiffness, nonlinear stiffness, and mass of the system, respectively, which are defined in the [Appendix]. Based on Eq. (6.37), the linear natural frequency can be obtained as:

```
$\omega_n = \sqrt{\frac{K_i - \hat{P}_s}{M}} \quad (6.38)
```

# 6.4.2 Harmonic balance method

Since the external load is harmonic (periodic excitation), the beam is experiencing a periodic motion. Thus HBM, which is widely used for obtaining a periodic solution of a nonlinear differential equation, can be applied as follows. Based on HBM, the steady state response can be approximated by [45]:

```
$\hat{w}_n = \sum_{i=0}^{\lambda} A_{cos}\cos(i\omega t) + B_{sin}\sin(i\omega t) \quad (6.39)
```

Nonlinear differential equation of motion (Eq. 6.37) can be solved by inserting Eq. (6.39) and separating the identical harmonic components. Considering a single-term harmonic balance and some algebra, the nonlinear fundamental natural frequency and response of the system can be obtained:

```
$\omega_{nonlinear} = \sqrt{\frac{K_i - \hat{P}_s}{M} \left(1 + \frac{3K_{it}\alpha_{0w}}{4(K_i - \hat{P}_s)}ight)} \quad (6.40)
```
