in which the inertia terms are given by:

```
$$(I_0, I_1, I_2) \approx \int_{-h/2}^{h/2} \rho(z)(1, z, z^2)dz \quad (7.22)$
```

# 7.4 Solution methodology and equations

# 7.4.1 Discrete singular convolution algorithm

Employing the DSC theorem [28], the $n^{th}$ derivative of a function $F(x)$ with respect to $x_i$ can be expressed as follows:

```
$$$F^{(n)}(x_i) = \sum_{j=i-M}^{i+M} \phi_{\Delta}^{(n)}(x_i - x_j)F(x_j), \quad (n=0, 1, 2, \dots) \quad (7.23)$
```

$x_i$ represents set of equally spaced grid points centered around $x_i$. In addition, $\delta_{\Delta}^{(n)}(x_i - x_j)$ represents the DSC delta kernel of Dirichlet type. Shannon’s kernel is selected as DSC kernels as follows:

```
$$$\delta_{\Delta, \sigma}(x_i - x_j) = \frac{\sin(\pi/\Delta)}{(\pi/\Delta)(x_i - x_j)} \exp\left(-\frac{1}{2}\{(x_i - x_j)/\sigma\\}^2\right) \quad (7.24)$
```

$\sigma$ and $\Delta$ are the regularization parameters and grid point spacing, respectively. The ratio of them is fixed by the discretization parameter ($r=\sigma/\Delta$). One can obtain an appropriate $r$ by using Eq. (7.25), which is proposed by Wei et al. [28].

```
$$$r(\pi - B\Delta) > \sqrt{4.6\mu}, M/r > \sqrt{4.6\mu} \quad (7.25)$
```

By using the DSC method, the first and second derivatives of $F(x)$ with respect to $x_i$ can be written as follows:

```
$$$F^{(1)}(x_i) = F_i^{(1)} \approx \sum_{j=i-M}^{i+M} \phi_{\Delta}^{(1)}(x_i - x_j)F(x_j) = \sum_{j=i-M}^{i+M} A_{ij}F_j \quad (7.26)$
```

```
$$$F^{(2)}(x_i) = F_i^{(2)} \approx \sum_{j=i-M}^{i+M} \phi_{\Delta}^{(2)}(x_i - x_j)F(x_j) = \sum_{j=i-M}^{i+M} B_{ij}F_j$$
```

For more details about DSC method, please check Refs. [17] and [28].
