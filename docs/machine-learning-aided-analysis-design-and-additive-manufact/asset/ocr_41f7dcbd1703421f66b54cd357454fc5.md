```
$s(\bar{h}) = \frac{s_{max} + s_{min}}{2} + \frac{s_{max} - s_{min}}{2} \cdot (1-2\bar{h})}{\frac{\dot{h}}{2}} \quad (0 \le \bar{h} \le \frac{1}{2})$$
$s(\bar{h}) = s_{min} + \frac{s_{max} - s_{min}}{2} \cdot (2-2\bar{h})^M \quad (\frac{1}{2} \le \bar{h} \le 1) \quad (15.1)$
```

where $M$ is the gradient parameter. $h$ is the normalized height and is defined as $h/H$, where $h$ is the coordinate along the height direction with an origin at the loading end of the uniformed specimen, and $H$ is the initial height of specimens (Fig. 15.3A). $s_{min}$ and $s_{max}$ are the minimum and maximum cell sizes of graded foams and are 5 and 10 mm, respectively. According to Eq. (15.1), the number of internal cells gradually increases along the crushing density, causing a gradually increasing density. Moreover, to get a negative gradient density, the cell size distribution is defined by:

```
$s(\bar{h}) = s_{min} + \frac{s_{max} - s_{min}}{2} \cdot (2-\bar{h})^M \quad (0 \le \bar{h} \le \frac{1}{2})$$
$$s(\bar{h}) = s_{min} + \frac{s_{max} - s_{min}}{2} \cdot (2-\bar{h})^{\frac{1}{M}} \quad (\frac{1}{2} \le \bar{h} \le 1) \quad (15.2)$
```

The number of internal cells gradually decreases along the loading direction, causing a gradually decreasing density.
