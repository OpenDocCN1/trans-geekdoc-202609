$M_2 = \rho^b_{LR} \int_0^{2\pi} \mathbf{VV}^T d\theta\eta \quad (4.61)

$M_3 = \rho^b_{LR} \int_0^{2\pi} \mathbf{WW}^T d\theta\eta \quad (4.62)

The stiffness matrix **K** is expressed as:

```
$K = \begin{bmatrix} \frac{1}{2}K_{11} & \frac{1}{2}K_{12} & \frac{1}{2}K_{13} \ \frac{1}{2}K_{21} & \frac{1}{2}K_{22} & \frac{1}{2}K_{23} \ \frac{1}{2}K_{31} & \frac{1}{2}K_{32} & \frac{1}{2}K_{33} \end{bmatrix} \quad (4.63)
```

where

```
$K_{11} = \frac{L}{R} \int_0^{2\pi} \left( \frac{L}{A_{66}} \frac{\partial U}{\partialtheta} \frac{\partial U^T}{\partialeta} + \frac{R^2 A_{11}}{L^2} \frac{\partial U}{\partialtheta} \frac{\partial U^T}{\partialeta} + \frac{D_{66}}{4R^2} \frac{\partial U}{\partialtheta} \frac{\partial U^T}{\partialeta} \right) d\theta\eta \quad (4.64)
```

```
$K_{12} = \frac{L}{R} \int_0^{2\pi} \left( \frac{2RA_{12}}{L} \frac{\partial U}{\partialtheta} \frac{\partial U^T}{\partialeta} + \frac{2RA_{66}}{L} \frac{\partial U}{\partialtheta} \frac{\partial U^T}{\partialeta} - \frac{3D_{66}}{2LR} \frac{\partial U}{\partialtheta} \frac{\partial U^T}{\partialeta} \right) d\theta\eta \quad (4.65)
```

```
$K_{13} = \frac{L}{R} \int_0^{2\pi} \left( \frac{2RA_{12}}{L} \frac{\partial U}{\partialtheta} \frac{\partial W^T}{\partialeta} + \frac{2D_{66}}{LR} \frac{\partial U}{\partialtheta} \frac{\partial W^T}{\partialeta} \right) d\theta\eta \quad (4.66)
```

```
$K_{22} = \frac{L}{R} \int_0^{2\pi} \left( A_{22} + \frac{D_{22}}{R^2} \frac{\partial W}{\partialtheta} \frac{\partial W^T}{\partialeta} + \frac{R^2 A_{66}}{L^2} \frac{\partial W}{\partialtheta} \frac{\partial W^T}{\partialeta} + \frac{D_{66}}{4L^2} \frac{\partial W}{\partialtheta} \frac{\partial W^T}{\partialeta} \right) d\theta\eta \quad (4.67)
```

```
$K_{23} = \frac{L}{R} \int_0^{2\pi} \left( \frac{2A_{22}}{L} \frac{\partial V}{\partialtheta} \frac{\partial W^T}{\partialeta} - \frac{2D_{22}}{R^2} \frac{\partial W}{\partialtheta} \frac{\partial W^T}{\partialeta} + \frac{6D_{66}}{L^2} \frac{\partial W}{\partialtheta} \frac{\partial W^T}{\partialeta} - \frac{2D_{12}}{L^2} \frac{\partial V}{\partialtheta} \frac{\partial W^T}{\partialeta} \right) d\theta\eta \quad (4.68)
```

```
$K_{33} = \frac{L}{R} \int_0^{2\pi} \left( A_{22}\mathbf{W}\mathbf{W}^T + \frac{D_{22}}{R^2}\frac{\partial W}{\partialtheta}\frac{\partial W^T}{\partialeta} + \frac{R^2 A_{11}}{L^5}\frac{\partial W}{\partialtheta}\frac{\partial W^T}{\partialeta} + \frac{4D_{60}}{L^2}\frac{\partial W}{\partialtheta}\frac{\partial W^T}{\partialeta} \right) d\theta\eta \quad (4.69)
```
