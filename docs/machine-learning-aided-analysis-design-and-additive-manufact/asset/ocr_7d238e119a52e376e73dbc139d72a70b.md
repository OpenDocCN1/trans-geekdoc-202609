FG porous composite structures

The internal forces and moments are:

```
$$\begin{bmatrix} N_{xx} & M_{xx} \ N_{	heta	heta} & M_{	heta	heta} \ N_{	heta z} & M_{	heta z} \end{bmatrix} = \begin{bmatrix} \sigma_{xx} \ \sigma_{	heta	heta} \ \sigma_{	heta z} \end{bmatrix} \{z_0}^0 z^1 dz \quad (4.87)$
```

By Inserting Eqs. (4.84–4.86) into Eq. (4.87), it gives:

```
$$\begin{bmatrix} N_{xx} \ N_{	heta	heta} \ N_{	heta z} \end{bmatrix} = \begin{bmatrix} A_{11} & A_{12} \ A_{21} & A_{12} \ 0 & 0 \end{bmatrix} {z_0}^0 + \begin{bmatrix} B_{11} & B_{12} \ B_{21} & B_{11} \ 0 & 0 \end{bmatrix} {z_0}^1 + \begin{bmatrix} C_{xx} \ \gamma_{	heta	heta} \ \gamma_{	heta z} \end{bmatrix} A_{66}^2 \ \quad (4.88)$
```

```
$$\begin{bmatrix} M_{xx} & M_{xx} \ M_{	heta	heta} & M_{	heta	heta} \ M_{	heta z} & M_{	heta z} \end{bmatrix} = \begin{bmatrix} B_{11} & B_{12} \ B_{21} & B_{11} \ 0 & 0 \end{bmatrix} {z_0}^0 + \begin{bmatrix} D_{11} & D_{12} \ D_{21} & D_{11} \ 0 & 0 \end{bmatrix} {z_0}^1 + \begin{bmatrix} E_{xx} \ \gamma_{	heta	heta} \ \gamma_{	heta z} \end{bmatrix} A_{66}^2 \ \quad (4.89)$
```

The strain energy $U_r$ and kinetic energy $T$ of the FG porous cylindrical shell are obtained by:

```
$U_r = \frac{1}{2} \int_0^{h/2} \int_0^{2\pi} \int_0^L (\sigma_{xx}\varepsilon_{xx} + \sigma_{	heta\theta}\varepsilon_{	heta\theta} + \sigma_{	heta z}\varepsilon_{	heta z}) Rdxd\theta dz \ \quad (4.90)$
```

```
$T = \frac{1}{2} \int_0^{h/2} \int_0^{2\pi} \int_0^L [(\left{\frac{\dot{u}}{\partial x}\right)^2 + (\left{\frac{\dot{v}}{\partial \theta}\right)^2 + (\left{\frac{\dot{w}}{\partial z}\right)^2] Rdxd\theta dz \ \quad (4.91)$
```

```
$\rho_z^0 = \int_{-z_0}^{z_0} \rho(z) dz \ \quad (4.92)$
```

where

For the simply supported boundary condition, the middle surface displacement functions of the shell can be set:

```
$u = u_t(t)\cos(\left(\frac{m\pi x}{L}\right)) \,v = v_t(t)\sin(\left(\frac{m\pi x}{L}\right)) \,w = w_t(t)\sin(\left(\frac{m\pi x}{L}\right)) \ \quad (4.93)$
```
