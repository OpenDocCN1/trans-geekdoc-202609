where $e_m$ is the mass density coefficient of metal foams. The relationship between Young's modulus and mass density is introduced by adopting Gaussian random field model:

```
$E_{\max} = \frac{E(z)}{\varphi(z)} + \frac{0.121}{1.121\rho_{\max}}^{2.3}$
```

By substituting Eq. (7.1) into Eq. (7.11), one can obtain:

```
$e_m = \frac{1.121(1 - \sqrt{1 - e_0\varphi(z)})}{\varphi(z)}$
```

Furthermore, the coefficient of porosity for even porosity distribution $\varphi_0$ can be derived as:

```
$\varphi_0 = \frac{1}{e_0} \left[1 - (\frac{M}{1.121\rho_{\max}} + \frac{0.121}{1.121})^{2.3}\right]$
```

# 7.3 Theoretical formations of axes

The displacement of points along axes $x$ and $z$ of the beam, $U(x,z,t)$ and $W(x,z,t)$ can be expressed as:

```
$U(x,z,t) = u_0(x,t) + z\psi(x,t)\nW(x,z,t) = w_0(x,t)$
```

where $u_0(x,t)$ and $w_0(x,t)$ are the longitudinal and transverse displacements. $\psi$ is the rotation of the beam cross-section. The linear normal strain $\varepsilon_{xx}$ and shear strain $\gamma_{xz}$ can be derived as:

```
$\varepsilon_{xx} = \frac{\partial u_0}{\partial x} + z\frac{\partial\psi}{\partial x}, \gamma_{xz} = \frac{\partial w_0}{\partial x} + \frac{\partial\psi}{\partial x}$
```

And the corresponding normal stress $\sigma_{xx}$ and shear stress $	au_{xz}$ are given as:

```
$\sigma_{xx} = \frac{E(z)}{1-v(z)^2}\varepsilon_{xx}, \tau_{xz} = G(z)\gamma_{xz}$
```
