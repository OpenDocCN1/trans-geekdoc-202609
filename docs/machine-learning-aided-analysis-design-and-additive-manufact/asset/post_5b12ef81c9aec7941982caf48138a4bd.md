## 4.5 Nonlinear forced vibration

In this section, the nonlinear forced vibration of simply supported FG porous cylindrical shells is analyzed. Attention is focused on the 1:1 internal resonance. The cylindrical shell is subjected to a harmonic concentrated force $F$ at the midspan point ($x=L/2, \theta=0$), as shown in Fig. 4.17.

### 4.5.1 Governing equations and solution

The virtual work done by the force is given by:

```
$W_f = \hat{F}w|_{x=L/2, \theta=0} = f \cos(\Omega_f t)w|_{x=L/2, \theta=0} \quad (4.130)$
```

where $f$ and $\Omega_f$ are the amplitude and frequency of the excitation, respectively.

Rayleigh's dissipation function is expressed as:

```
$W_c = \frac{1}{2} \int_{0}^{2\pi} \int_{0}^{L} \left(\frac{\partial w}{\partial t}\right)^2 R dx d\theta \quad (4.131)$
```

where $c$ represents the viscous damping coefficient and can be expressed by:

```
$c = 2\xi_{mn} \omega_{mn}^2 \quad (4.132)
```

where $\omega_{mn}$ and $\xi_{mn}$ are the natural frequency and the damping ratio of the shell for $(m, n)$, respectively.

The middle surface displacements of the FG circular cylindrical shell satisfying supported boundary conditions are expressed in the form of:

```
$u = \sum_{m=1}^{\infty} \sum_{n=1}^{\infty} [cos(n\theta)X_{mn}^a(t) + sin(n\theta)X_{mn}^b(t)] \cos(\gamma_{mn}x) = X(x,\theta,t)$
$v = \sum_{m=1}^{\infty} \sum_{n=1}^{\infty} [sin(n\theta)Y_{mn}^a(t) + cos(n\theta)Y_{mn}^b(t)] \sin(\gamma_{mn}x) = Y(x,\theta,t)$
$w = \sum_{m=1}^{\infty} \sum_{n=1}^{\infty} [cos(n\theta)Z_{mn}^a(t) + sin(n\theta)Z_{mn}^b(t)] \sin(\gamma_{mn}x) = Z(x,\theta,t) \quad (4.133)$
```

where $n$ and $m$ represent numbers of circumferential waves and longitudinal-halves; $t$ represents time; $\gamma_{mn}=m\pi/L$, $X_{mn}^a(t), X_{mn}^b(t), Y_{mn}^a(t), Y_{mn}^b(t), Z_{mn}^a(t), Z_{mn}^b(t)$ are generalized coordinates. Superscripts $a$ and $b$ indicate driven mode and response mode, respectively. $X(x,\theta,t), Y(x,\theta,t), Z(x,\theta,t)$ are listed as follows:

```
$X(t,\theta) = [X_{11}^a(t), ... X_{mn}^a(t), X_{11}^b(t), ... X_{mn}^b(t), ...]^T$
$Y(t,\theta) = [Y_{11}^a(t), ... Y_{mn}^a(t), Y_{11}^b(t), ... Y_{mn}^b(t), ...]^T$
$Z(t,\theta) = [Z_{11}^a(t), ... Z_{mn}^a(t), Z_{11}^b(t), ... Z_{mn}^b(t), ...]^T \quad (4.134)$
```

```
$x(t) = \{X_{11}^a(t), ... X_{mn}^a(t), X_{11}^b(t), ... X_{mn}^b(t), ...\}^T$
$y(t) = \{Y_{11}^a(t), ... Y_{mn}^a(t), Y_{11}^b(t), ... Y_{mn}^b(t), ...\}^T$
$z(t) = \{Z_{11}^a(t), ... Z_{mn}^a(t), Z_{11}^b(t), ... Z_{mn}^b(t), ...\}^T \quad (4.135)$
```

The more degrees of freedom there, the more accurate the forced response is, but the more computation is required. Modes having great influence should be selected to improve calculation efficiency while ensuring the accuracy of the results.

Introduce the vector $q$ as follows:

```
$q = \begin{bmatrix} x(t) \\ y(t) \\ z(t) \end{bmatrix} \quad (4.136)$
```

The equations of motion are:

```
$\frac{\partial T}{\partial q_i} - \frac{\partial U}{\partial q_i} = -\frac{\partial W_c}{\partial q_i} - \frac{\partial W_l}{\partial q_i}, \quad i=1, 2, \dots, N \quad (4.137)$
```

where $N$ means the number of generalized coordinates.

By substituting Eqs. (4.90–4.131) into Eq. (4.137), the nonlinear differential equations can be written in the matrix form as:

```
$\mathbf{M}\dot{\mathbf{q}} + \mathbf{C}\dot{\mathbf{q}} + \mathbf{K}\mathbf{q} = \mathbf{f}\cos(\Omega t) \quad (4.138)$
```

where $\mathbf{M}, \mathbf{C}$, and $\mathbf{K}$ are the mass, damping, and stiffness matrices, respectively; $\mathbf{M}$ includes quadratic and cubic nonlinear terms; $\mathbf{f}$ is the vector of the excitation amplitude. Their specific expressions are listed as follows:

