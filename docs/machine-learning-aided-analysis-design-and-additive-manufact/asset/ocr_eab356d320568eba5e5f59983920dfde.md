# ## 12.4.4 Optimizing hyperparameters

The kernels used in GPR and X-SVR depend a great deal on the hyperparameters chosen in the optimization process, which would inherently affect the prediction accuracy of the regression models. For validation, the k-fold cross-validation method is an effective way to test the prediction accuracy under different hyperparameters. In present work, the fivefold CV approach can be adopted for GPR and X-SVR with:

```
$Err_{MCV} = \sum_{i=1}^{5} err_i^2 \quad (12.26)$
```

where err, is the mathematical measure of mean square error between the predicted and actual responses in each fold. To efficiently select the appropriate hyperparameters, recently, the Bayesian optimization technique is becoming popular among the machine learning algorithms [16]. That is, Bayesian optimization utilizes the available information from previous evaluations and makes probabilistic approximations for the parameter selections. Due to these features, the Bayesian optimization can be integrated into the regression model construction and automatically choose the hyperparameters for training, and the searching range for the hyperparameters are listed in Table 12.1.
