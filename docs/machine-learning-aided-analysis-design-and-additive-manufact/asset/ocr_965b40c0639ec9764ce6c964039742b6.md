
The normal and shear strains are denoted by symbols of $\varepsilon_{\varphi}$ and $\gamma_{\varphi z}$, respectively. Based on small deformation hypothesis, the strain–displacement relations considering

```
$$\begin{pmatrix} \varepsilon_{\varphi} \ \gamma_{\varphi z} \end{pmatrix} = \frac{1}{1+z/R_{\varphi}} \begin{pmatrix} 0 & 0 \ 0 & 1 \end{pmatrix} \begin{pmatrix} 0 \ \kappa_{\varphi} \end{pmatrix}$ $\quad (2.6)$
```

where the superscript $0$ indicates the variable $\kappa_{\varphi}$ denotes the curvature, which can be expressed as:

```
$\varepsilon_{\varphi}^0 = \frac{1}{R_{\varphi}} \frac{\partial u}{\partial \varphi} + w), k_{\varphi}^0 = \frac{1}{R_{\varphi}} \frac{\partial \Phi}{\partial \varphi}, \gamma_{\varphi z}^0 = \frac{1}{R_{\varphi}} (\frac{\partial w}{\partial \varphi} - u)$ $\quad (2.7)$
```

The expression of stress–strain constitutive relation obtained by applying the generalized Hooke’s law can be presented as:

```
$$\begin{pmatrix} \sigma_{\varphi} \ \tau_{\varphi z} \end{pmatrix} = \begin{pmatrix} Q_{11} & 0 \ 0 & Q_{55} \end{pmatrix} \begin{pmatrix} \varepsilon_{\varphi} \ \gamma_{\varphi z} \end{pmatrix}$ $\quad (2.8)$
```
