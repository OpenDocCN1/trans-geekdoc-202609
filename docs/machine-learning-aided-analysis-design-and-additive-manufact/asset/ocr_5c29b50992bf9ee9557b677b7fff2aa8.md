Finally, the nominal strain of the specimen can be determined by:

```
$$\varepsilon = \frac{H-(h\rho_{\text{deformed}}+H-h)}{H} = \tilde{h} - \int_{0}^{\tilde{h}} \tilde{ho}(h)\mathrm{d}h = f(\tilde{h}).\quad(15.9)$
```

Eq. (15.9) gives the relationship between the nominal strain of graded foams and the value of normalized height. When the gradient distribution function $\tilde{ho}(h)$ is identified, the nominal strain to the normalized height can be given by Eq. (15.9). The gradient density can be expressed as $\tilde{f}^{-1}(\varepsilon)$, therefore the local relative density corresponding to each nominal strain can be determined:

```
$$\sigma(\varepsilon) = E^*-\\sigma_{\text{y}}^*e^{-\varepsilon/\lambda})+\sigma_{\text{y}}^*\varepsilon.\quad(15.10)$
```

$\rho_{\text{av}} = \frac{1}{H}\int_{0}^{H}\rho(h)\mathrm{d}h$ and $\tilde{ho}=\rho(h)$, where $\kappa$ and $\lambda$ are the shape parameter and the scale parameter, respectively. The shape parameter and the scale parameter are insensitive to the relative density and are 0.0335 and 1.469, respectively. The Weibull distribution is applied to Eq.(15.10) because it captures the elastic stage and the stress-drop region of foams [48]. In addition, as discussed in Section 15.5, the densification stage of graded foams can be determined by using foams with a similar overall relative density. However, this requires experimental data of considering foams, which brings extra work in practical engineering applications. More, foam material loses its energy absorption potential entering the densification stage. Hence, this stage is not considered in the present elastic, plastic-hardening model for generality and conciseness.
