## 16. 功能梯度孔结构的应用

尽管研究人员在研究吸能方面取得了显著进展，但泡沫的制备仍然困难。此外，增材制造（AM）能够制造具有复杂几何形状的结构。许多研究致力于主动制造材料，例如金属微点格[44]复合材料[45]负泊松结构[46]聚合物衍生陶瓷[47]八面体晶格材料[48]以及光滑格[49]。通过微观方法，AM可以产生相应的样品，使仿真和实验中的微观几何结构保持一致。
