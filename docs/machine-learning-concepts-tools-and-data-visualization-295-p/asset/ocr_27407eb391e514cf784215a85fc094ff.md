Figure 6-23 ROC Curve of Predictive Model through “Evaluate Model”

6-23 shows the receiver operating characteristic curve of the model. The ROC curve is a graph which shows the ratio of true positives to false positives. It is a visualization of the predictive performance of a binary classification model. The larger area under the ROC, the better the performance. Of course, if the area of ROC is 1, you should suspect overfitting.
