# AlphaGo Fan

In October 2015, the distributed version of AlphaGo defeated the European champion Fan Hui, a 2-dan (9-dan being the highest) professional, 5-0. In the battle with Fan Hui, AlphaGo used 1202 CPUs and 176 GPUs. This is known as AlphaGo Fan, Version 12.
