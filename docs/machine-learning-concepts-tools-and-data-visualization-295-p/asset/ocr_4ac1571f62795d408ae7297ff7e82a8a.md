After placing the blocks, you need to set properties which you will learn by clicking the “Launch column selector” in the “Train Model” block.
The desired value in this chapter is the number of people getting on during the morning rush hours. Therefore, the objective is to predict the number of people between 07:00 and 08:00, so select the 07-08 property, as shown in Figure 9-51.
Click the “Run” button at the bottom, and when the model has completed the learning, check the trained model by visualizing it as shown in Figure 9-52.
