# Source (8-3)

```
dataset1 <- maml.mapInputPort(1)
mydata <- dataset1[sample(1:nrow(dataset1), 50, replace=FALSE),]

data.set = mydata
print(mydata)
maml.mapOputPort("data.set");
```

After that, take 50 dataset1 values and place them into “my data”. You can check the entire sample data through the print function. The source can be found below.
Train the prediction model by clicking the “Run” button at the bottom. After that, you can check the extracted value by clicking “Visualize” in the “Result Dataset” menu, as shown in Figure 8-4.
