# Create Prediction Models using Microsoft Azure Machine Studio 11

Place a “Select Columns in Dataset” block on the canvas, as shown in Figure 7-8, and connect the Score Model to the web service output. Then click on “Launch Column Selector” to select the Scored Labels and Score Probabilities for output.

Select and include the “Scored Labels” and “Scored Probabilities” columns, beginning with “NO COLUMNS”, as in Figure 7-9. Check it and click “Run” in the bottom menu to train your web service model.
