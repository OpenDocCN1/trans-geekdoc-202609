Figure 11-42 shows a filled map. A filled map uses shading, hues, and patterns to indicate how a particular value differs based on a particular place or region. It is used mainly when quantitative information is displayed on maps and when working with socio-economic data.

Figure 11-43 shows a funnel chart. A funnel chart is used to visualize sequentially connected processes, i.e. linear processes.
