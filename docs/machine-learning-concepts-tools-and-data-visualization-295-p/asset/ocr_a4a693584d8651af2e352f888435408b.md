# ## 3.1 Definition and Concepts of Deep Learning

Artificial intelligence is defined as the understanding of human judgment, action, and cognition which we draw upon to equip machines¹ with human intelligence. Recently, there seems to be a lot of confusion about machine learning and deep learning. Therefore, simply put, artificial intelligence is a prerequisite for a machine to possess human intelligence, and it must “learn” in order to produce this artificial intelligence. One class of kind of learning is machine learning, while deep learning is the class of learning similar to neural networks for machine learning. Figure 3-1 shows these relationships.
