机器学习的历史虽然短，但组织严密，并解释了微软对 Microsoft Azure Machine Learning Studio 程序的方法。即使是不懂编程语言的人，只要对机器学习感兴趣，也可以轻松地进行编程。在第二部分中，使用 Microsoft Machine Learning Studio 逐步编写了一个示例程序。读者可以遵循该示例获得结果。此外，预计使用真实数据将对数据科学和分析领域的研究人员有所帮助。

微软（韩国）IoT 解决方案架构师，执行董事总经理，Geon Bok Lee

LGU+ 高级副总裁/企业销售组 2，Sunguly Park，
