# 7.2.1 Integrating the Web Service with R

The R program can be downloaded from https://www.r-project.org/. The libraries used are RCURL and rjson. To use the web service in R, Primary Key and Request-Respond values are required.

If you write and run the code above, you can see the prediction from the model created in Azure Machine Studio, as shown in Figure 7-24.

```
source <- source("C:\Users\Desktop\azureWebService.R")
[i]<-"Result"
$Results
$ResultsOutput
$ResultsOutput[[i[1]]<-"Scored Labels"
[i]<-$SCORE

$ResultsOutput[[i[1]]<-"Scored Probabilities"
[i]<-"0.003552711531112"
```
