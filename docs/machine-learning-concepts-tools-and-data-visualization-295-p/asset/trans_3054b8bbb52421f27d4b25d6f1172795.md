## 11.5 Power BI 可可视化

### 11.5.1 如何在 Power BI 中使用可视化

你可以通过 Power BI 的“可视化”（Visualizations）菜单方便地可视化插入的数据。“可视化”菜单位于图 11-21 的右上角。数据导入应在可视化之前完成。然后从可视化菜单选择图表进行应用。图 11-22 右上角的图表可以通过更改大小进行自由调整。
