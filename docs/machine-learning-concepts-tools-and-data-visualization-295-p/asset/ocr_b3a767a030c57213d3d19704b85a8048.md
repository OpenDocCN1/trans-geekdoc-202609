# 74 Machine Learning: Concepts, Tools and Data Visualization

(1) Category
Sidebar for managing datasets, experiments, etc.

(2) Palette
Area containing the main functions of the project.

(3) Experiment Canvas
The drag-and-drop workflow area, in which models can be created and real analysis performed.

(4) Properties
Displays the properties of each module. Each module can have different properties.

(5) Option Menu
Users can save, execute and publish web services, galleries, etc. The “+NEW” button can be selected to insert datasets, import modules, etc.
