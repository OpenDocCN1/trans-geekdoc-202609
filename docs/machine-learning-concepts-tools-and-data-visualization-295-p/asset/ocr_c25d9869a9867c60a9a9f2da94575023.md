Figure 11-40 shows a treemap. A treemap displays hierarchical data as a set of nested squares. The rectangles are arranged in order of size, with the largest being in the upper left, and the smallest being in the lower right. In particular, it is used to represent large quantities of hierarchical data or to indicate the ratio between each part and the whole.

Figure 11-41 shows a map. A map links location data to the map to compare the size of quantitative data.
