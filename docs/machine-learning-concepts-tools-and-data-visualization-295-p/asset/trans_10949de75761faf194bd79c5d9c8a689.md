## 1.2.4 人工智能的复兴（1969–1990）

AI 的开发面临挑战有许多原因；然而，通用搜索方法为这些问题提供了解决方案。这些问题的原因在于对待解决问题的各个部分的知识十分匮乏，而在解决问题的复杂部分时，性能不可避免地会降低。这些方法被称为“弱方法”，虽然很常见，但使得它们难以解决更大规模或更困难的问题。

解决方案是使用更强大的领域特定知识，以便更容易地处理通常发生的情况，并允许进行更显著的推理。在这方面，当有人试图解决一个困难的问题时，他们最终意识到，只有通过应用从已经知道答案的人那里汲取的知识，才能有效地解决问题：换句话说，就是使用专家知识。

布坎南（Buchanan）在此时左右发布的“DENDRAL”程序就是一个典型的例子。

DENDRAL 项目是最早的专家系统之一，其主要目标是通过在有机化学特定领域开展工作，研究科学推理方法和科学知识的公式化。DENDRAL 为新且未知的化学品提出了最可能的候选结构，在某些类有机材料中，其性能可以与人类专家相媲。DENDRAL 的意义在于，它可能是历史上第一个成功的知识密集型系统。

## 1.3 人工智能的分类

从哲学角度来看，AI 可以分为强人工智能和弱人工智能。强人工智能被定义为可以思考和解决问题的基于计算机的人智能，而弱人工智能被定义为无法执行这些任何任务的基于计算机的人智能。

## 1.3.1 强人工智能

感知和自我意识的特质可以被认为是了人工智能的形式。因此，这种形式与弱人工智能之间存在区别，因为前者实际上可以思考或解决问题。它是人工智能的一种，计算机程序可以以类人类的方式行动或思考。

换句话说，强人工智能不仅仅是一台计算机，而是一台能够以人类智能思考的计算机。就像电影《终结者》中引发与人类战争的机器一样，人工智能不仅可以在没有命令的情况下独立工作，还可以拒绝它认为不理性的命令。因此，AI 有两种形式：类人 AI（涉及像人类思维一样运行的计算机程序）和非人类 AI（涉及产生与人类不同的感知和推理的计算机程序）。

- 通用人工智能 (AGI)
在人工智能术语中，“通用”应该被理解为“广泛”而非“普通”。换句话说，与只能在特定条件下的人的智能不同，通用人工智能指的是适用于所有情况的智能。

# 人工智能总结

因此，通用人工智能与弱人工智能不同，它涉及到机器通过学习并执行以前未做过的任务的能力。它是通过视觉和听觉学习的形式。通用人工智能是目前人工智能人员旨在的目标，“让机器像人类”。

- **人工意识 (AC)**
人工意识是人工智能的一种形式，也被称为机器意识或合成意识。它可以被认为是通用人工智能的下一个形式。如果说人工智能分析和理解普通物体，那么人工意识超越了这一点，模仿情感、自我甚至创造力。它也是一种能够控制自身、对环境做出判断并主动利用某些物体执行任务的人工智能。因此，人工意识假设了与人类相似或超越人类的智能，与仅仅通过编程计算机执行任务的人工智能不同，人工意识不仅需要工具。它需要与人类同等的智能。可以假设人工智能在发展的未来某一点将达到人工意识水平，但在目前，它应该被视为一种假设。
最后，关于是否可能实现像人类一样思考的意识，以及理论上是否可以制造类人机器，是人工智能领域的一个基础性争论。这也是一个具有重大伦理影响的争论。

## 1.3.2 弱人工智能

弱人工智能被定义为专注于特定问题的智能，计算机实际上无法思考或解决问题。尽管它们实际上并不智能，也不拥有所谓的智能，但通过使用一组预定义的规则开发的程序产生了类似于智能的行为。虽然在强人工智能领域的研究被认为是目前人工智能人员最青睐的路径，但它也有缺点；然而，在专注于特定目标的弱人工智能领域取得了很大进展。

Google 的 AWS、DeepMind 的 AlphaGo 和 IBM 的 Watson 都是基于规则的人工智能的示例，因此也是弱人工智能的示例。
