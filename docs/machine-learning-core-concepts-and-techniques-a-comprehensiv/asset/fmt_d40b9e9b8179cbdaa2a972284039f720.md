
Example: In biology, hierarchical clustering can be used to group species based on genetic similarity. A dendrogram would illustrate how species are related, with closely related species being grouped together earlier in the clustering process.

Advantages:
* Does not require specifying the number of clusters.
* Produces a dendrogram, providing insight into the data's structure at different levels of granularity.

Disadvantages:
* Computationally expensive for large datasets.
* Sensitive to noise and outliers, especially in agglomerative clustering.

#### DBSCAN (Density-Based Spatial Clustering of Applications with Noise)

`DBSCAN` is a density-based clustering algorithm that groups data points that are closely packed together (based on a distance metric) and marks points that lie alone in low-density regions as outliers.

* Core Points: Points that have a minimum number of neighbouring points within a specified radius are considered core points.
* Border Points: Points that are within the radius of a core point but do not have enough neighbours to be considered core points themselves.
* Noise Points: Points that do not fall within the radius of any core point are considered noise or outliers.

`DBSCAN` does not require specifying the number of clusters in advance, and it can discover clusters of arbitrary shapes.

Example: `DBSCAN` is useful in detecting anomalies in network traffic. For example, in network security, `DBSCAN` can be used to identify unusual patterns of traffic that may indicate malicious behaviour. Legitimate traffic will form dense clusters, while anomalous traffic will be marked as noise or outliers.

Advantages:
* Can find clusters of arbitrary shapes.
* Robust to noise and outliers.
* Does not require specifying the number of clusters in advance.

Disadvantages:
* Struggles with datasets of varying density.
* Sensitive to the choice of hyperparameters (e.g., radius and minimum points).

### 2. Dimensionality Reduction

In many real-world datasets, the number of features (or dimensions) can be extremely large, making it difficult to visualize, analyse, and model the data effectively. Dimensionality reduction techniques are used to reduce the number of features while preserving the underlying structure and important patterns in the data. This not only simplifies the dataset but can also improve the performance of machine learning algorithms by removing noise and redundant information.

#### Principal Component Analysis (PCA)

`PCA` is a linear dimensionality reduction technique that transforms the data into a new coordinate system, where the axes (called principal components) correspond to the directions of maximum variance in the data. The first principal component captures the most variance, the second captures the second most, and so on. By keeping only the first few principal components, we can reduce the dimensionality of the data while retaining most of its important information.

Steps in `PCA`:
1. Standardize the data (centre and scale).
2. Compute the covariance matrix of the data.
3. Perform eigenvalue decomposition to find the eigenvectors and eigenvalues.
4. The eigenvectors are the principal components, and the eigenvalues indicate how much variance is explained by each component.
5. Select the top K principal components to reduce dimensionality.

Example: In genomics, researchers often deal with datasets that have thousands of genes as features. `PCA` can be used to reduce the number of features while retaining the key patterns of variation in the data. For example, `PCA` might reduce the data from 10,000 genes to just 10 principal components, making the data easier to analyse and visualize.

Advantages of `PCA`:
* Reduces dimensionality while preserving variance.
* Helps with visualization of high-dimensional data.
* Can improve the performance of machine learning models by reducing noise.

Disadvantages:
* Assumes linear relationships between variables.
* May not perform well when the important information is in non-linear relationships.

#### t-SNE (t-Distributed Stochastic Neighbour Embedding)

`t-SNE` is a non-linear dimensionality reduction technique particularly well-suited for visualizing high-dimensional data. Unlike `PCA`, which seeks to preserve global structure, `t-SNE` focuses on preserving local relationships between data points. It does this by modelling the similarity between points in high-dimensional space and mapping them to a lower-dimensional space (typically 2D or 3D).

* Local Structure: `t-SNE` excels at capturing local groupings in data, making it ideal for visualizing clusters.
* Distance Preserving: It attempts to map high-dimensional distances to low-dimensional ones while minimizing the distortion of those distances.

Example: `t-SNE` is commonly used in image recognition tasks to visualize how different images relate to each other. For instance, in a dataset of handwritten digits, `t-SNE` can reduce the high-dimensional pixel data to a 2D map where similar digits are clustered together, making it easier to visualize the groupings of different digit classes.

Advantages:
* Captures non-linear relationships.
* Excellent for visualizing clusters in high-dimensional data.

Disadvantages:
* Computationally expensive for large datasets.
* Sensitive to hyperparameter tuning (especially perplexity).
* The results can vary between runs due to randomness in the algorithm.

### 3. Association Rule Learning

Association Rule Learning is a technique used to find interesting relationships or associations between variables in large datasets. It is most commonly used in market basket analysis, where the goal is to identify which items are frequently purchased together.

#### Apriori Algorithm

The `Apriori` algorithm is a classic method used for association rule learning. It operates by finding frequent itemset in the data (i.e., groups of items that appear together frequently) and then generating rules based on these itemset. The algorithm uses a bottom-up approach, where it starts with single items and progressively builds larger itemset by checking for frequent patterns.

* Support: The support of an itemset refers to the proportion of transactions in which the itemset appears.
* Confidence: The confidence of a rule refers to the likelihood that the consequent of the rule occurs given that the antecedent has occurred.
* Lift: Lift measures the strength of a rule compared to how often the consequent occurs independently. A lift greater than 1 indicates a strong association.

Example: In a supermarket, the `Apriori` algorithm can be used to discover rules such as "if a customer buys bread and butter, they are likely to buy milk." These rules can be used for cross-selling and recommendation strategies, such as placing milk near the bread and butter in the store.

Advantages of the `Apriori` Algorithm:
* Provides interpretable rules that can be used for decision-making.
* Widely used in market basket analysis and recommendation systems.

Disadvantages:
* Computationally expensive, especially with large datasets.
* May generate a large number of rules, many of which are irrelevant.

### FP-Growth Algorithm

The `FP-Growth` (Frequent Pattern Growth) algorithm is an efficient alternative to the `Apriori` algorithm for mining frequent itemset in large datasets. While `Apriori` can be computationally expensive because it generates a large number of candidates itemset and repeatedly scans the dataset, `FP-Growth` avoids this by using a more compact data structure called the `FP-tree` (Frequent Pattern Tree).

#### How FP-Growth Works:
1. Building the FP-Tree:
   * The first step is to scan the dataset and identify frequent items (items that meet a minimum support threshold).
