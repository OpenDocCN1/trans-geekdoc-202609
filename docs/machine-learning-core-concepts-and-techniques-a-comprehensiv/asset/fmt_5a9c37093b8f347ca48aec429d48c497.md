
### Backward Pass

* Once the network produces an output, the loss function calculates the error between the predicted output and the actual output.

### Backward Pass

* The algorithm calculates the gradient of the loss function with respect to each weight in the network using the chain rule of calculus. This gradient indicates the direction in which the weights should be adjusted to minimize the loss.

### Weight Update

* The weights are updated by taking a small step in the direction opposite to the gradient (this step is controlled by the learning rate). This process is repeated for multiple iterations (`epochs`) until the loss is minimized.

Example: Consider training an `MLP` to classify images of cats and dogs. Initially, the network makes random predictions. During training, backpropagation adjusts the weights based on the error (how wrong the prediction was), gradually improving the network's accuracy.

Advantages of Backpropagation:

* Efficient for training deep networks.
* Works with any differentiable loss function and activation function.

Disadvantages:

* Prone to the vanishing gradient problem in deep networks, where gradients become too small to make significant updates, especially with sigmoid or tanh activation functions in deep layers.

### 3. Convolutional Neural Networks (CNNs)

Convolutional Neural Networks (`CNNs`) are a specialized type of neural network designed for processing grid-like data such as images. `CNNs` leverage the spatial structure of the data to efficiently detect patterns such as edges, textures, and objects, making them particularly effective for tasks like image classification, object detection, and image segmentation.

#### Key Components of CNNs:

1. Convolutional Layers:

   * Instead of fully connecting each neuron to every input pixel, `CNNs` use a set of filters (or kernels) that slide over the input image, applying a convolution operation. This captures local patterns (e.g., edges or textures) in the image.
   * Each filter detects a different feature, and multiple filters are used in each convolutional layer.

2. Pooling Layers:

   * After convolution, `CNNs` typically apply a pooling operation (such as max pooling) to reduce the spatial dimensions of the feature maps, making the network more computationally efficient and reducing the risk of overfitting.

3. Fully Connected Layers:

   * After several layers of convolutions and pooling, the high-level features extracted by the network are passed to fully connected layers for classification or regression.

4. Activation Functions:

   * Commonly, `RLU` activation is applied after each convolutional layer to introduce non-linearity.

Example: A `CNN` could be used to classify handwritten digits (such as in the `MNIST` dataset). The network's convolutional layers would learn to detect features like edges and curves, pooling layers would reduce the dimensionality, and fully connected layers would predict the digit's label.

Advantages of CNNs:

* Effective at recognizing patterns in images, video, and other spatial data.
* Reduces the number of parameters compared to fully connected networks, making them more efficient to train.

Disadvantages:

* Requires large labelled datasets for training.
* Computationally expensive, especially for large images or deep networks.

### 4. Recurrent Neural Networks (RNNs) and Long Short-Term Memory (LSTM)

Recurrent Neural Networks (`RNNs`) are designed to handle sequential data, where the order of inputs matters. Unlike feedforward networks, `RNNs` have loops in their architecture, allowing them to maintain a memory of previous inputs, which makes them suitable for tasks like time series forecasting, language modelling, and speech recognition.

#### Recurrent Neural Networks (RNNs)

`RNNs` process sequential data by maintaining a hidden state that captures information from previous time steps. At each time step, the hidden state is updated based on the current input and the previous hidden state, enabling the network to learn from sequences of varying lengths.

* Forward Pass:

  * For each time step in the sequence, the `RNN` updates its hidden state and produces an output.

* Backpropagation Through Time (BPTT):

  * The error is propagated back through the network for each time step, allowing the network to learn from both past and present information.

Example: In language modelling, an `RNN` can predict the next word in a sentence by using information from previous words. For example, if the input is "The cat sat on the," the `RNN` would predict that the next word is likely "mat."

Limitations of RNNs:

* Vanishing Gradient Problem: Similar to backpropagation in deep networks, `RNNs` can suffer from vanishing gradients, especially when dealing with long sequences, making it difficult to learn long-term dependencies.

### Long Short-Term Memory (LSTM)

Long Short-Term Memory (`LSTM`) networks are a type of Recurrent Neural Network (`RNN`) specifically designed to handle the vanishing gradient problem, enabling the model to learn long-term dependencies in sequential data. `LSTMs` are particularly well-suited for tasks where the context or previous data points are essential for making accurate predictions, such as time series forecasting, speech recognition, and natural language processing (`NLP`).

#### Why LSTMs?

Standard `RNNs` suffer from the vanishing gradient problem, which occurs when gradients during backpropagation become very small, preventing the network from learning long-term dependencies in data. `LSTMs` overcome this issue by introducing a more sophisticated architecture with gates that control the flow of information through the network. This allows `LSTMs` to learn what information is important to remember or forget over long sequences of data.

#### LSTM Architecture

The `LSTM` architecture is built around a cell state, which is the core of the `LSTM`'s memory, and three main gates that control how information flows in and out of this cell state. These gates allow the `LSTM` to selectively keep or discard information as it processes sequential data.

1. Cell State:

   * The cell state is like a conveyor belt that runs through the `LSTM`, carrying important information along the sequence. Information can be added or removed from the cell state using gates.

2. Forget Gate:

   * The forget gate controls what information from the previous cell state should be discarded. It takes the previous hidden state and the current input, passes them through a sigmoid function (which outputs values between 0 and 1), and multiplies the result with the cell state. A value of 0 means "completely forget," while a value of 1 means "completely keep."

```
ft=σ(Wf⋅[ht−1,xt]+bf)
f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)
ft​=σ(Wf​⋅[ht−1​,xt​]+bf​)
```

Where `ft` is the forget gate's output, `ht−1` is the previous hidden state, `xt` is the current input, and `Wf` and `bf` are the weights and bias for the forget gate.

3. Input Gate:

   * The input gate decides which new information should be added to the cell state. It consists of two parts:

     1. A sigmoid layer that decides which values to update.
     2. A tanh layer that creates a vector of new candidate values to add to the cell state.
