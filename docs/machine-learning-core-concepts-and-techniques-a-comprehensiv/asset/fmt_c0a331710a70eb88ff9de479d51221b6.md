## 5.1.2 Multiclass Logistic Regression

For multiclass problems, we use techniques like one-vs-rest (OvR) or softmax regression.

Example: Predicting iris flower species

```python
from sklearn.datasets import load_iris
```

## 5.2.2 Pros and Cons of Decision Trees

### 5.4 k-Nearest Neighbors (k-NN)

k-NN is a simple, instance-based learning algorithm that classifies a data point based on the majority class of its k nearest neighbors.

Example: Classifying iris flowers using k-NN

```python

conf_matrix = confusion_matrix(y_test, y_pred)

print(f"Classification Report:\\n{class_report}")
```

## 5.4.1 Choosing the right k

The choice of k can significantly impact the performance of k-NN. We can use cross-validation to find the optimal k.

```python
from sklearn.model_selection import cross_val_score

k_range = range(1, 31)
k_scores = []

for k in k_range:
    knn = KNeighborsClassifier(n_neighbors=k)
    scores = cross_val_score(knn, X_train, y_train, cv=5, scoring='accuracy')
    k_scores.append(scores.mean())

plt.plot(k_range, k_scores)
plt.xlabel('Value of K')
plt.ylabel('Cross-Validated Accuracy')
plt.show()
```
