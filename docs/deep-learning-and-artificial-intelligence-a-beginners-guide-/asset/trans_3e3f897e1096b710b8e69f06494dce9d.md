

# 欢迎来到本书的结尾

欢迎来到本书的结尾，虽然这可能是本书的结尾，但你可能在想关于神经网络还有更多可以学习的内容。老实说，其实没有。我真的不想这样对你，因为通常我会说你面前有一条漫长的道路，等待你去吸收大量的知识，但诚实的真相是，我们已经涵盖了几乎所有内容。唯一没有涵盖的是如何实际去做，而这真的取决于你使用什么。例如，我们为你提供了一个出色的 API，它将帮助你初步接触神经网络，但这只是市场上可能有一百种不同 API 中的一种。Python 只是众多语言中的一种，还有许多语言，人们根据自己认为出色的编程方面，创建了 API 来处理神经网络。例如，你有 Java、C 和 C# 作为起点。仅仅这三种语言，就可能有大约 5 到 10 种不同类型的应用程序，你可以在其中部署神经网络。你可能会认为外面可能有更复杂的神经网络，但事实是，神经网络是一个相当新的话题，这也是它为什么在新闻中如此热门的原因。它并不是一个非常复杂的话题，但因为它被神秘化了，而且巨型公司都在做这门生意，人们认为它比实际情况要复杂得多。这种效应在人们试图用数学术语来描述它时会被放大。从数学角度来看，它有点复杂，但在理解它的工作原理方面，复杂程度大约只到代数 2 的末尾。现在，这并不意味着你不能用它做非常复杂的事情，因为这真的取决于你想用它做什么。例如，如果你试图从 2D 图像外推一个 3D 模型，那么你将需要背后的一些重型数学，以及一些预测分析和一些数据库条目，用于你试图从中外推 3D 模型的形状。它可以像你想要的那样复杂，但当你开始理解它时，技术本身是相当简单的。我们实际上已经多次讲解了这些东西的工作原理，而这类话题的问题在于，既然你期望这是一个全新的技术领域，你也可能期望它比实际情况要复杂得多。如果你理解神经元是如何工作的，你就理解神经网络是如何相互连接的。你在这一点上不理解的是它的应用，例如你可能想要在此基础上构建的程序的实际代码，或者它可以应用在哪里，这也包括它如何被应用。基本上，你学会了工具，但你没有学会如何有效地利用这个工具，而唯一可以教会这一点的方法是，你进入数据库并开始与它玩耍。因此，我将向你说再见，祝你在神经网络之路上好运。
