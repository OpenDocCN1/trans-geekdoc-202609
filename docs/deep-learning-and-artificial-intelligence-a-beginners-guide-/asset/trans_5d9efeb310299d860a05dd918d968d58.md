## 什么是 Keras 模型？

模型是你在这个 API 中开始的方式，在谈论这个 API 拥有的不同模型时，有两种特定的模型。一种是 Sequential 模型，另一种是 Model 函数式模型。Sequential 模型是个双关语，有点像 API 本身的实际名称，因为它按顺序运行所有内容。你可以将模型视为处理这个 API 时的简单模式，也是你用来开始理解如何使用这个 API 的第一个模型之一。另一方面，你还有 Model 模型。一旦你彻底理解了 Sequential 模型，就可以转向更高级的模型。这个模型允许你完全自定义你希望事情如何执行，这不一定意味着你希望你的操作按顺序执行。然而，这并没有真正告诉你什么是模型。

在这个 API 中，`Model` 类是你利用神经网络不同方面的方式。这意味着如果你想要创建一个神经网络，你首先需要设置你的模型，以便你可以按顺序或非顺序地布局必要的权重、偏差，甚至信息。同样，你可以让模型与其他模型交互，以创建一个更复杂的模型。每个模型代表一个独立的神经网络，因此通过利用你的模型与其他模型交互，你可以创建一个深度神经网络。这并不是说你不能在单个模型中创建一个，但为了跟踪所有内容，通常最好调制神经网络想要执行的所有不同职责，这就是为什么你被赋予了调用不同模型来做不同事情的能力，以便获得完全不同的输出。现在我们理解了模型基本上代表一个神经网络，你现在需要理解每个神经网络都有许多，我是指，许多不同的层。

## 什么是 Keras 层？

层代表神经网络的不同组件，例如神经网络的密度或输入。它们是你在 API 中将要处理的主要代码，因此你需要理解不同层的列表并不真正详尽。如果你决定放弃 Sequential 模型，你可以在程序中开发自己的层，以便执行你想要做的特定事情，例如比程序中已经设置的要复杂得多的任务，但这种情况比较罕见。他们保持开放，以防你是那些正在处理需要大量定制的极其复杂系统的开发者之一。如果你试图利用模型或层，你将不得不导入你想要利用的所有内容。同样，这个 API 不假设你需要他们创建的所有内容，因此你不能简单地导入一个模型就获得他们创建的庞大 API 的访问权限。这使你能够拥有运行平稳高效且用户友好的代码。此外，正如你可以将其他模型与单个模型一起使用一样，你也可以利用多个带有多个输入的层。

## 进入 Keras 之前你需要理解什么？

这个 API 的开发者假设你首先了解神经网络的工作原理，如果你不了解神经网络的工作原理，我建议你先阅读本书的其余部分，并对这项技术进行进一步的深入了解，然后再使用这个 API。我之所以建议这样做，是因为实现神经网络如此容易，以至于它掩盖了你正在实现的背后的许多技术定义。因此，如果你不知道什么是 `RELU`，那你就没办法了，因为这个 API 假设你已经知道这一点，如果你想要实现它，你必须先了解它是什么，然后才能正确地将其应用到神经网络中。

# 深度学习算法

## RBM：受限玻尔兹曼机

在所有机器学习算法中，RBM 是最突出的，因为它通过处理梯度消失问题，为神经网络的发展带来了最大的突破。本质上，你有一个输入层和一个隐藏层，输入层同时也是输出层。隐藏层仅由一组神经元组成，这最大限度地减少了传播量。这里的关键是，隐藏层中的任何节点都不与隐藏层中的其他节点共享连接。由于这些限制，训练 RBM 是一个快速的过程。输入首先被发送到隐藏层，以便进行转换。数据更改后，会提供权重和/或偏差的替换，无论是相同的还是不同的权重和/或偏差。然后它被发送回输入层，该层现在已成为输出层，以提供该数据的重建。如果信息错误，则会调整权重和/或偏差，直到数据的重建正确。RBM 是自动编码器家族的一部分，它与未标记的数据配合得非常好。
