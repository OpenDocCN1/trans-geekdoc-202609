

每当特定神经元决定特定事物是什么时，它就完成了一次分类。根据神经网络的规模，它在最终向你提供输出的过程中，可能会进行几十到几百甚至几千种不同的分类。我们已经讨论过这些特定神经元的输入内容，但分类方法通常由分类器决定。正如我们在前面章节中讨论过的，神经网络并非通用工具，目前必须针对特定任务进行调优。在日常生活中，它们无法处理过于复杂的任务。但它们确实有一些极佳的应用，凭借其能够提供的极致专注度。每当我们谈论分类器时，基本上就是在谈论如何对部分信息进行分类的方法。本质上，分类器真正只是分类方法论的名称。因此，每当你去搜索不同类型的神经网络时，实际上必须搜索分类器。我们将在单独的章节中介绍不同的深度学习方法论，但让我们在此做出清晰的区分。你可以拥有分类或识别模式。当我们谈论分类时，实际上是在谈论对象分类。这与数值模式识别不同。数值模式识别由仅与数值相关的图表和数据表示。如果我们谈论的是对象的颜色或对象本身，我们是在谈论分类。如果我们提取属性并利用这些属性构建对象，那么它就成为分类；但如果我们获取数值并根据模式提供数值，我们就在谈论模式识别。这两种形式之间存在显著差异，因为它们为你提供不同的信息。

## 消失梯度

消失梯度是指神经网络中出现的一种明显但抽象的模式。如你已知，神经元的信息基于前一个神经元提供的内容。这可能发生在前向传播和反向传播中，我们将在后面章节讨论。本质上，随着信息传递到神经元，传递到特定神经元的信息量在向前或向后传播时会变得更加复杂。消失梯度是指，如果某事物呈指数级复杂，对该数据做出决策的时间也会呈指数级升高。很长一段时间里，深度信念网络和大多数神经网络在复杂情况下都极难训练，原因正是消失梯度，它指的是时间可能随复杂度呈指数级增长。

## 层：输入层、隐藏层和输出层

在神经网络中有三层，之所以我既有输入和输出的章节，又有层的章节，是因为大多数处理神经网络的人将其称为层，而不是输入和输出。输入层是用户将必要信息输入神经网络的地方。这可能是他们提供的任何数量的不同数据集，但理念是，这是个人输入信息的层，甚至可能不在代码层面。你看，当我们谈论输入层时，实际上可能是在谈论个人用于将输入放入系统的图形用户界面。这意味着开发者团队已经为非开发者创建了神经网络。这就是为什么它真正被称为输入层，因为不仅输入本身可能存在巨大差异，使用此类技术的用户也可能存在巨大差异。这也是为什么输出实际上被称为输出层，因为不仅你可能处理来自命令行的数字，还可以将其渲染为 HTML，以便他们在浏览器中查看，或渲染到 Windows 框中，以便他们在软件中查看。本质上，称其为层要容易得多，因为这样可以涵盖用户和发送变量的巨大差异。毕竟，程序员能理解 RGB 是什么，但这对普通用户来说并没有实际意义。现在，我们之前已经提到过，但每当神经网络处理信息时，网络会发出几十到几百甚至几千种不同的输出，但只有最终结果是用户看到的。这个区域，因为你实际上看不到它，被称为隐藏层，因此每当人们处理神经网络时，他们将此区域称为隐藏层，不仅是因为当其他人决定使用神经网络库时，他们可能不会查看神经网络内部以了解其工作原理，还因为你实际上看不到神经网络做出的任何决策，直到神经网络完成所有决策，从而产生最终输出。

## 前向传播和反向传播

很多人喜欢分别讨论这两个主题，但我不知道为什么，因为它们非常容易理解。前向传播是指当你输入数据，这些输入到达输出时发生的情况。这意味着你正在向前传播信息。同样，当你执行反向传播时，你将算出的输出进行逆向过程，以便查看系统内部情况，或生成不同的输入，看看是否得到了预期的路径。

## GPU 训练

很长一段时间里，CPU 是训练神经网络时主要使用的组件，但 CPU 的问题在于核心数量不足以处理真正复杂的任务。例如，CPU 最多拥有约 32 到 64 个核心，这些核心位于服务器处理器中。服务器处理器相当昂贵。因此，某个聪明人决定从使用 CPU 核心改为使用 GPU 核心。由于 GPU 核心的数量多年来呈爆炸式增长，现在不仅可以使用 32 个核心，还可以在 GPU 中使用近两千个甚至更多核心。这可以轻松将数年的训练时间缩短到几天。因此，如果你打算研究神经网络，我强烈建议你购买一张性能出色的显卡，以便拥有大量核心供你使用。
