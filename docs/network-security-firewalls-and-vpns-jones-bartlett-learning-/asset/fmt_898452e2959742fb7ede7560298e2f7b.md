
## RFC 1918 私有地址空间

![Image](images/bull1.jpg) **Class B**—`172.16.0.0–172.31.255.255/12` (16 个 Class B 网络)

![Image](images/bull1.jpg) **Class C**—`192.168.0.0–192.168.255.255/16` (256 个 Class C 网络)

**RFC 1918 addresses** 仅用于私有网络。互联网路由器会丢弃使用这些地址的任何数据包。如果没有 NAT，使用这些私有 IP 地址的网络将无法与互联网通信。通过使用 RFC 1918 地址，网络可以建立另一道抵御基于互联网攻击的屏障，且无需为租用内部地址付费。

正如所提到的，NAT 是允许在可用公共 IP 地址耗尽后继续扩展使用 IPv4 的技术之一。现在 IPv6 过渡正在进行中，NAT 在提供 IPv4 到 IPv6 的转换方面发挥着新的作用。许多防火墙和代理设备可能包含 IPv6 转换服务。在研究防火墙采购或部署时，此功能是一个值得列入功能清单的选项。

## 技术提示

NAT 和 PAT 的一个有趣细节是：大多数支持 PAT 的设备和软件产品，在其文档和配置接口中实际上声明它们支持 NAT。看来 NAT 已被重新定义为包含端口地址转换的功能，尽管该特定附加技术已有官方首字母缩写词。大多数认证考试也将两者结合在一起。问题可能使用 NAT 缩写，但实际指的是端口转换 (PAT)。

## 路由器、交换机和网桥

**路由器**、**交换机**和**网桥**是常见的网络设备。虽然它们通常不直接标记为网络安全设备，但你可以部署它们来支持安全，而不是阻碍安全。

路由器的主要目的是沿最佳已知当前可用路径将流量导向其指定目的地（参见 [图 1-11](#07_chapter01.xhtml#fig1-11)）。RIP、OSPF、IGRP、EIGRP、BGP 等路由协议根据各种度量标准动态管理路由选择。路可通过引导流量走首选路由而非那些在逻辑或物理上可能不那么安全的路由来支持安全。如果黑客能诱骗路由器改变传输路径，网络流量可能会经过黑客放置 **嗅探器** 的网段。嗅探器也称为包分析器、网络分析器和协议分析器，是一种捕获网络通信以进行调查和分析的软件工具或硬件设备。

虽然这种情况不太可能发生，但并非不可能。确保路由器使用身份验证来交换路由数据，并防止未经授权的物理访问，将防止这种及其他基础设施级别的攻击。[图 1-11](#07_chapter01.xhtml#fig1-11) 描绘了一个路由网络部署示例。

交换机通过硬件提供网络分段。在交换机上，临时专用的电子通信路径连接会话的端点（如客户端和服务器）。这种交换路径可防止冲突。此外，交换机允许你利用网络连接的全部潜在吞吐容量进行通信，而不是像集线器那样浪费 40% 或更多的带宽在冲突上。参见 [图 1-12](#07_chapter01.xhtml#fig1-12)。

一旦你检查这个过程是如何进行的，就可以将交换机的这一基本功能视为安全优势。交换机在 OSI 模型的第 2 层（数据链路层）运行，MAC 地址在此定义和使用。交换机通过以太网帧中的源和目的 MAC 地址来管理流量。以太网帧是数据链路层（第 2 层）的一个逻辑数据集构造，由网络层（第 3 层）的有效载荷加上以太网帧头和帧尾组成（[图 1-13](#07_chapter01.xhtml#fig1-13)）。

交换机采用四个主要过程，标记为“学习”、“转发”、“丢弃”和“泛洪”。学习过程是从帧头的源位置收集 MAC 地址。源 MAC 地址连同接收该帧的端口号一起进入映射表。一旦帧的目的 MAC 地址出现在映射表中，就会发生转发。该表随即指导交换机从最初发现相关 MAC 地址的端口转发该帧。

如果帧要发往映射表指示的目的端口相同的端口，则该帧会被丢弃。交换机无需将该帧再传回其来源的网段。最后，如果目的 MAC 不在映射表中，交换机将恢复泛洪——即将帧从每个端口发出——以确保帧有最大机会到达目的地。

通过监控交换机的活动——具体来说，观察映射表的构建和修改以及帧头中 MAC 地址的变化——你可以检测错误和恶意流量。智能或多层交换机本身或外部 IDS/IPS 服务可以执行此安全监控功能。

当交换机过程失败时，网络会受损。这可能意味着吞吐量降低、导致拒绝服务的阻塞，或允许黑客尝试修改或窃听的流量重定向。幸运的是，此类攻击在产生大量异常网络流量方面是“吵闹”的，因此你可以用基本安全传感器检测到它们。仅这一优势就是使用交换机而非集线器的重要理由。

网桥连接网络之间。网桥在网络之间创建路径或路由，仅当通信的目的地实际位于网桥对面的网络上时才使用。这类似于一座河流将一座城市一分为二。当该城市的人想去河流同侧的一个地点时，他们无需过桥即可到达。

网络网桥也是如此。网桥的工作方式与交换机类似，它们使用几个基本过程来管理流量。网桥使用学习、转发和丢弃过程。因此，通过这些过程，只有目的地位于对面网络的流量才会通过网桥到达该网络。所有目的地位于接收流量同侧的流量都会被丢弃，因为流量已经在正确的网络上。

当你需要一个简单的按需使用链路，而路由器、交换机或防火墙的复杂性既非特别要求也非期望时，可使用网桥连接网络、网段或子网。参见 [图 1-14](#07_chapter01.xhtml#fig1-14)。除协议外，网桥还可以连接基础设施大多数方面存在差异的网络。这包括不同的拓扑、线缆类型、传输速度，甚至有线与无线。

你可以使用网桥检测交换机所检测的同类流量滥用。此外，网桥和交换机都可以对 MAC 地址实施过滤。这里可以使用**黑名单**或白名单概念，即允许除黑名单/阻止列表上的流量外的所有流量，或阻止除白名单/允许列表上的流量外的所有流量。
