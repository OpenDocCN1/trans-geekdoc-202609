
基于操作系统的 VPN 非常方便，因为您可以通过分配的互联网协议（IP）地址引用远程服务器，而无需使用网络地址转换（NAT）。这避免了连接到多对一 NAT 配置背后的服务器所固有的问题。您可以从多种方式中选择，使用运行商业操作系统的计算机来安装 VPN。您可以从客户端计算机配置 VPN 连接，支持的操作系统包括 Windows XP、Vista、Windows 7、Linux 和 UNIX。

VPN 是面向远程工作者的软硬件解决方案，通过防火墙为用户提供数据加密网关，使其能够进入企业网络。VPN 曾经仅适用于大型企业。然而如今，大多数企业（无论大小）都能负担得起这项技术，VPN 在中小型企业市场中越来越普及。VPN 非常适合拥有远程办公人员、分支机构或出差员工的公司，这些人员需要通过互联网连接到企业网络。如果使用得当，VPN 可以阻止试图访问您的网络以窃取敏感数据的黑客。它们还可以为您的组织节省大量长途电话费。

作为互联网上的数据加密隧道，VPN 可以为您的组织提供强大且安全的互联网连接。它也可以作为专用电话线的廉价替代方案。一些面向小公司的解决方案起价低至 200 美元。如何判断您的组织是否需要 VPN？这取决于您在决定使用 VPN 之前应考虑的一些关键因素：

![Image](images/bull1.jpg) 您的组织是否处理敏感数据？对于大多数企业，答案可能是肯定的。大多数公司在其内部网络中都有客户信息和记录、财务记录以及专有信息，这些都值得保护。另一方面，如果您的组织将敏感数据离线存储，或者您在线上没有任何引起黑客兴趣的内容，那么您的组织可能不需要投资 VPN。

![Image](images/bull1.jpg) 您的组织是否雇佣了远程办公人员、出差员工或其他远程工作者？如果是，VPN 可以提供两大主要优势：它可以为离开办公室、出差或在外地工作的员工提供安全的网络访问；它还可以将企业网络延伸至他们，使他们能够在办公室外保持高效工作。

![Image](images/bull1.jpg) 您的公司是否已经使用安全套接字层（SSL）加密的互联网页面？例如，一些使用 Microsoft Exchange 服务器进行电子邮件的公司，可能已经拥有远程工作者所需的加密保护——至少用于访问其电子邮件（通过 Outlook Web Access）。在这种情况下，VPN 是操作系统的内置功能。没有敏感信息的企业可以使用基于操作系统的 VPN 和基于 Web 的 VPN 替代方案进行身份验证和加密，尽管这些可能安全性较低。

![Image](images/bull1.jpg) 您的组织是否有不止几名员工？对于员工少于五人的公司，VPN 可能是一项昂贵的解决方案，因此一些替代方案可能更适合此类环境。

假设您已考虑这些问题，并得出结论：您的组织确实需要 VPN。在这种情况下，以下是需要进一步考虑的六个重要因素：

![Image](images/bull1.jpg) 考虑**基于用户侧设备（CPE）的 VPN**与**基于操作系统的 VPN**之间的区别。CPE 解决方案代表了市场上大多数的 VPN，通常被称为 VPN 设备。该解决方案易于设置、管理和维护。`Windows Server 2008 Network Access` 是基于操作系统的 VPN 的一个示例。如果您有一台运行 `Windows Server 2008` 的服务器，可以安装网络策略和访问服务角色，并将服务器配置为 VPN 服务器。这需要一定的 `Windows Server 2008` 专业知识，并且可能比 CPE 解决方案稍具挑战性。然而，基于操作系统的 VPN 可能比 CPE 更便宜且更易于管理。

![Image](images/bull.jpg) 您应该自己安装 VPN 还是使用托管服务？任何称职的 IT 人员都可能安装来自 Cisco 或 SonicWall 等供应商的领先商业产品。虽然 DIY 方法能提供对设置和使用的更多控制，但错误安装 VPN 可能会无意中在组织网络中打开一个安全漏洞。此外，内部管理 VPN 有时可能很复杂。Qwest、Verizon 和 BellSouth 等电信公司以及多家互联网服务提供商提供托管安全解决方案，可以为您节省时间和金钱。

![Image](images/bull1.jpg) 您有防火墙吗？VPN 无法替代防火墙。一些管理员倾向于用 VPN 代替防火墙，这并不明智。VPN 的目的是创建一个穿过网络防火墙的加密隧道或网关，并阻挡黑客。VPN 对数据片段进行加密，但防火墙仍保护内部网络免受外部威胁。没有防火墙的 VPN 在安全方面讲不通。

![Image](images/bull1.jpg) 您有基于操作系统的 VPN 吗？无论您最终采用哪种策略，请确保您拥有符合 IPSec（互联网协议安全）标准的操作系统。IPSec 是包含在 `Windows XP`、`Vista`、`Windows 7`、`Windows Server 2008` 和 `Windows Server 2008 R2` 中的支持 VPN 的技术。配合兼容的 VPN 使用时，IPSec 可保证网络流量的真实性、完整性和机密性。Macintosh 系统或某些 UNIX 或 Linux 变体与 VPN 的互操作性可能存在问题。如果您决定购买 VPN，请确保它与您的操作系统兼容。

![Image](images/bull1.jpg) 您有无线局域网（LAN）吗？VPN 应能与其安全协同工作。VPN 可以增强无线 LAN 的功能，但将 VPN 不当地分层部署在无线网络上可能会导致安全漏洞。一种方法是将无线 LAN 放在防火墙外部，将 VPN 托管在防火墙后面以确保安全。否则，无线网络流量可以访问防火墙后面的系统，从而抵消 VPN 的优势。许多组织使用分层防火墙，使无线网络免受外部攻击，同时限制对内部的访问。从本质上讲，LAN 在所谓的非军事区（DMZ）中运行。

![Image](images/bull1.jpg) 您的组织能否容忍网络性能潜在的下降？VPN 可能会导致内部用户访问互联网时出现性能延迟。当 10% 到 15% 的互联网带宽作为安全开销时，就会发生这种情况。虽然 VPN 非常适合建立安全连接，但它们会对连接速度产生可衡量的影响。权衡在于：VPN 为远程和出差工作者提供安全连接，是值得投资的。

## 组织中的 VPN 使用

VPN 以两种主要方式服务于组织的计算机网络。它们为远程用户提供对内部网络的访问，或者连接两个独立的办公室。这就是**主机到网关模型**和**网关到网关模型**：

![Image](images/bull.jpg) **主机到网关 VPN**——在**主机到网关 VPN**中，移动用户采取特定操作来连接到 VPN。例如，移动用户首先会从组织外部的远程位置连接到互联网。一旦连接到互联网，用户便可以启动 VPN 以穿越互联网建立隧道。VPN 设备或服务器随后充当网关，供用户访问内部网络上的资源。
