

# 术语表

## S

**Slack space（松散空间）** | 分配给存储文件的最后一个簇中未使用的部分。它可能包含先前存储在该位置的文件的残留数据。黑客可劫持松散空间以创建隐藏的存储区。

**Slideware（幻灯件）** | 行业术语，指出现在供应商 PowerPoint 幻灯片中，但尚未在其任何产品中提供的产品。有时也称为“Vaporware（蒸汽件/虚拟软件）”。

**Sniffer（嗅探器）** | 用于捕获网络通信以进行调查和分析的软件工具或硬件设备。也称为数据包分析器、网络分析器和协议分析器。

**Social engineering（社会工程学）** | 诱导人们执行任务或泄露违反安全规定的信息的技巧。社会工程学依赖于讲述令人信服的谎言来操纵人员，或利用受害者乐于助人的心理。

**Socket（套接字）** | IP 地址和端口号的组合，作为完整的地址。

**Software firewall（软件防火墙）** | 安装在客户端或服务器上的主机防火墙。

**Software VPN（软件 VPN）** | 由软件而非硬件构建的 VPN。软件 VPN 可能是操作系统的一项功能，也可能是第三方应用程序。

**SOHO (small office, home office) network（小型办公室/家庭办公室网络）** | 由小型企业、家庭企业或仅仅是家庭部署的任何小型网络、工作组或客户端/服务器网络。

**Spam（垃圾邮件/垃圾信息）** | 不需要且通常未经请求的消息。垃圾邮件在技术上不属于恶意软件，但因其巨大的数量，会对 IT 基础设施产生严重的负面影响。估计数据不一，但垃圾邮件可能占所有电子邮件的 95%（这意味着每 1 封合法邮件可能对应多达 19 封无关的垃圾邮件）。

**Split tunnel（分隧道）** | 允许在同一连接上同时访问安全的 VPN 链路和非安全的互联网接入的 VPN 连接。

**Spoofing（欺骗）** | 信息的伪造。欺骗通常是指隐藏用户的真实身份或通信的真实来源。

**Spyware（间谍软件）** | 键盘记录技术的进阶形式，用于监控和记录许多其他用户活动。间谍软件差异很大，但它可以收集已启动的应用程序列表、访问的 URL、发送和接收的电子邮件、发送和接收的聊天记录、所有打开的文件名。它还可以记录网络活动、定期捕获屏幕截图，甚至从麦克风或网络摄像头进行录制。可与广告软件关联。

**SQL injection（SQL 注入）** | 一种网站/应用程序攻击形式，黑客提交 SQL 表达式以导致身份验证绕过、数据提取、信息植入或命令 Shell 访问。

**State（状态/会话）** | 客户端与资源服务器之间的逻辑连接。可能存在于 OSI 模型的第 3、4 或 5 层。也称为会话或电路。

**Stateful inspection（状态检测）** | 自动跟踪会话或状态以允许针对先前出站请求的入站响应的过程。也称为动态包过滤。

**Static electricity discharge (SED) or Electrostatic discharge (ESD)（静电放电）** | 通常具有高电压和低电流的突发性、瞬时电流，在两个物体之间流动。通常由低湿度环境引起。人体、聚酯和塑料容易积累静电。静电放电可能损坏大多数计算机组件。

**Static NAT（静态 NAT）** | 跨 NAT 服务的静态编码转换路径。也称为端口转发和反向代理。

**Static packet filtering（静态包过滤）** | 使用静态或固定规则集过滤网络流量的方法。规则可侧重于源或目标 IP 地址、源或目标端口号、IP 头协议字段值、ICMP 类型、分片标志和 IP 选项。因此，静态包过滤主要关注网络层（第 3 层），但也可包含传输层（第 4 层）元素。静态包过滤关注头部内容，不检查数据包或段的有效载荷。

**Sunk cost（沉没成本）** | 已在项目、事件或设备上花费的时间、金钱和精力。在经济学中，沉没成本与未来决策无关。但在情感上，人们常以沉没成本为借口，继续失败的流程或程序。

**Switch（交换机）** | 一种通过硬件提供网络分段的设备。在交换机上，会在会话的端点（如客户端和服务器）之间创建临时的专用电子通信路径。这种交换路径可防止冲突。此外，交换机允许通信利用网络连接的全部潜在吞吐容量，而不是像集线器那样浪费 40% 或更多的带宽在冲突上。

**Symmetric cryptography（对称加密）** | 基于使用单个共享密钥的算法的加密技术。同一密钥用于加密和解密数据，且同一密钥必须与同一会话的所有通信伙伴共享。

**Synchronous dynamic random access memory (SDRAM)（同步动态随机存取存储器）** | 具有同步接口的动态随机存取存储器（DRAM）。传统上，DRAM 具有异步接口，这意味着它会尽可能快地响应控制输入的变化。SDRAM 具有同步接口，意味着它在响应控制输入前等待时钟信号，因此与计算机的系统总线同步。

**Systems Network Architecture (SNA)（系统网络架构）** | IBM 开发的一种遗留网络协议，常用于支持大型机之间的通信。大多已被 TCP/IP 取代。

## T

**Tangible cost (or value)（有形成本/价值）** | 直接与预算资金相关的成本或价值。可包括但不限于：采购、许可、维护、管理、行政、支持、公用事业、培训、故障排除、硬件、软件、更新/升级等。

**Tcpdump** | 一种在命令行运行的常用数据包分析器。它允许用户拦截并显示计算机所连接的网络上传输或接收的 TCP/IP 和其他数据包。

**Telco（电信公司）** | Telecommunications company 或 corporation 的简称。用于指代销售或租赁 WAN 连接服务的任何公司，无论有线还是无线。

**Telecommuting（远程办公/电信通勤）** | 从家庭、远程或移动位置工作，同时连接到“雇主的专用网络”，通常使用 VPN。

**Telnet** | 一种协议和服务，用于通过纯文本命令行界面远程控制或管理主机。

**Terminal server/services/session（终端服务器/服务/会话）** | 传统瘦客户端操作的现代形式。瘦客户端软件工具连接到中央终端服务器，后者模拟远程控制。终端服务系统可支持多个同时的终端客户端连接。使用终端服务时，客户端工作站转变为瘦客户端状态。所有存储和处理操作随后在终端服务器上进行。

**Thin client computing（瘦客户端计算）** | 用于控制大型机的传统终端概念。瘦客户端没有本地处理或存储能力。现代瘦客户端模拟这些限制，并在终端服务器、远程控制服务器或瘦客户端服务器上执行所有操作。

**Threat（威胁）** | 对网络上的资源或节点的任何潜在危害。威胁可以是自然的或人为的，由自然或人类引起，或由无知或恶意导致。威胁源于内部和外部。

**Traceroute（路由跟踪）** | 一种计算机网络工具，用于显示数据包跨 IP 网络所采取的路由。IPv6 变体 `traceroute6` 也广泛可用。

**Traffic congestion（流量拥塞）** | 过多数据跨越网络段时出现的问题。这会导致吞吐量降低、延迟增加和数据丢失。
