# 第 2 章：防火墙基础

对一些网络管理员而言，防火墙是其基础设施安全的关键组件。对另一些人而言，防火墙则是一种麻烦，是完成基本任务的障碍。在大多数情况下，对防火墙的负面看法源于对防火墙本质及其工作原理的基本误解。本章将帮助消除这种困惑。
