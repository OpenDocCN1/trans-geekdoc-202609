

VPN 提供许多优势，包括广泛的实现选择。各种设备和软件产品都支持 VPN 连接。VPN 的端点可以位于防火墙内部、防火墙上或防火墙外部。VPN 可以支持移动主机的远程访问，在单个系统之间创建链接，并支持网络之间的通道。VPN 可以采用隧道模式或传输模式加密。它们可以使用您在其他地方部署的用于一般网络安全的相同认证和授权技术。
