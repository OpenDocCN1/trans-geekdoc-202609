## 设备选择

设备选择是安全网络设计中常被忽视的一个方面。普遍认为任何能够执行 IT 功能的硬件都适合部署，但遗憾的是事实并非如此。无论廉价还是昂贵的产品，都可能存在众所周知的或尚未被发现的安全缺陷。

随意或自动选择最便宜或最昂贵的产品并非制胜的安全策略。您应仔细评估每一件计算机设备（从网络设备到主机系统）的原生安全防御能力或缺陷，而不论其成本如何。

在选择、采购和部署设备时，应考虑引入的漏洞以及对基础设施安全态势的任何防护或改进。每一件设备都会以某种方式提高或降低安全性。某些设备会增加新的弱点或扩大组织的攻击面，而其他设备则充当对策，保护其他组件的弱点并减小攻击面。

只要可能，应选择能更大程度提升安全性的设备，而非有害设备。这看似显而易见的准则，只有在您认真评估每个设备的安全配置文件时才能遵循。未能妥善评估新设备的安全性，可能意味着您无意中将新漏洞引入组织的网络和系统中。

设备安全顾虑包括：

![Image](images/bull1.jpg) **电力消耗**——过度的能源使用不仅会导致电费增加，还会导致设备内部及配电系统温度升高。功率过大的电路可能导致断路器过载。断路器跳闸会导致停机，并可能造成数据丢失和设备损坏。

![Image](images/bull1.jpg) **产生的热量**——设备产生的热量越多，供暖、通风和空调（HVAC）系统为将室温维持在可接受范围内就必须更努力地工作。过度产热的设备还会增加火灾风险。

![Image](images/bull1.jpg) **重置按钮**——重置按钮用于将设备恢复为出厂默认设置。如果有人按下重置按钮，设备上定义的任何安全配置都将丢失。如果可能，应选择没有重置按钮、或按钮可被禁用以提供物理安全的设备。

![Image](images/bull1.jpg) **易触及的电源开关**——如果电源开关易于触及或触发，与设备的偶然接触可能导致断电。此外，易触及的电源开关允许恶意人员关闭设备或触发重启。

![Image](images/bull1.jpg) **易触及的管理控制台端口或接口**——如果设备可通过 LCD 屏幕和几个按钮（如打印机）重新配置，或控制台/终端端口允许快速访问配置或管理接口（如无线接入点、路由器或交换机），则部署设备时需谨慎，并评估物理访问安全级别。

![Image](images/bull1.jpg) **可移动介质**——带有可移动介质托架（如磁带、光盘、软盘等）或外部外设端口（如通用串行总线 `USB`、防火墙、以太网等）的设备，可能比那些较少或没有这些访问点的设备更容易受到攻击。

![Image](images/bull1.jpg) **可移动机箱**——设备机箱越容易拆卸或打开，越容易被入侵、植入监听器或修改其功能。

![Image](images/bull1.jpg) **便携性**——设备是否足够小，可放入口袋、钱包或背包，从而容易被盗？

![Image](images/bull1.jpg) **可机架安装**——安装在机架上的设备一旦拧入可上锁的机架机箱，被盗可能性较小。

![Image](images/bull1.jpg) **BIOS/固件刷新**——更改设备嵌入式软件的能力既是优势也是问题。刷新到更新、更安全的固件版本是积极的益处。然而，如果黑客能轻易将固件替换为有缺陷的第三方版本或旧版本，则会成为问题。

![Image](images/bull1.jpg) **远程连接**——如果设备支持远程连接，则风险增加。应限制、加密并监控远程连接。

![Image](images/bull1.jpg) **明文协议**——设备默认使用或仅支持明文协议越多，其安全性越低。应选择支持加密的设备。

评估新设备部署时，还有许多其他设备安全方面很重要。无论是高端服务器、用户笔记本、智能手机、网络路由器还是其他任何设备，都应彻底考虑设备安全性，而不仅仅基于设备成本做采购建议。

请记住，前期廉价或免费的设备，从长远来看，其管理和安全成本可能远高于更昂贵的设备。然而，高成本并不意味着低安全管理需求。单凭资金很难衡量任何事物的真实安全性。

## 认证、授权与审计

安全最终由认证、授权和审计（AAA）支持和强制执行。AAA 是通常被称为**身份与访问管理（IAM）**的安全领域的一部分。如果没有正确实施这三大安全基础，真正的安全就不存在。
