

# IDS 插入攻击

IDS 插入是一种攻击形式，它利用网络型 IDS 收集和分析每个数据包的特性，欺骗 IDS 接受一个数据包，而终端系统却拒绝该数据包。这会导致 IDS 的状态与终端系统的状态不同步，从而使攻击者能够绕过 IDS 的检测。

> **技术提示**
>
> 当 IDS 接受一个终端系统拒绝的数据包时，就会发生 **IDS 插入**。这会导致 IDS 认为连接处于某种状态，而终端系统实际上处于不同的状态。攻击者可以利用这种差异来规避检测。

![Image](images/bull1.jpg) `MAC 欺骗`——黑客的计算机使用服务器的 MAC 地址；当服务器被淹没时，黑客的系统会接收本应发往目标服务器的流量。`MAC 欺骗`必须发生在子网内。

![Image](images/bull1.jpg) `DNS 投毒`——要实施 `DNS 投毒`，黑客会攻陷一台 DNS 服务器并植入虚假的 FQDN 到 IP 映射记录。DNS 来源会向后续的用户查询提供虚假数据。

![Image](images/bull1.jpg) `DNS 欺骗`——DNS 是一种非认证查询服务，用于请求将 FQDN 解析为其相关的 IP 地址。托管流氓 `DNS 欺骗` 工具的黑客可以发回虚假的 DNS 响应。

> **技术提示**
>
> 当使用 `非认证查询服务` 时，它不会确认所收到的任何响应的来源或有效性。因此，如果你收到伪造的、欺骗性的或流氓响应，系统会将其视为真实响应并接受，查询会话随之结束。如果真实响应随后到达，系统会将其作为无效或迷途数据包予以拒绝，因为它将不再与任何打开的查询会话对应。
