
# 安全设计与实施的核心原则

安全设计和实施中另一组常见的三要素是**预防**、**检测**和**响应**。

*   **预防**是使用防护措施来阻止攻击或妥协。预防入侵和违规通常比事后应对更高效、更容易且更具成本效益。
*   **检测**需即时发现尝试性和成功的安全违规。恶意行为与权威响应之间的时间跨度越长，肇事者不受惩罚就逃脱的可能性就越大。
*   **响应**意味着准备好遏制损害、限制进一步妥协，并实施修复以使系统恢复正常。

## 认证、授权与审计的重要性

不要忽视**认证**、**授权**和**审计**的重要性。这些服务是安全基础设施的关键。你必须控制谁被允许进入设施和接入网络。对授权用户能做什么设置限制。让所有实体——甚至高层管理人员——对其行为、活动和结果负责。

## 建立“默认拒绝”哲学

专注于建立**默认拒绝**而非**默认允许**的哲学。通过将阻止一切作为起点，只有那些你判断并认为安全且合适的特性、服务、协议、端口、应用程序和用户才能通过例外启用。默认允许的立场意味着你必须创建源源不断的显式拒绝，因为你检测到新的妥协或恶意事件。**默认拒绝/例外允许**始终是首选的安全立场。

## 实施应用程序白名单控制

实施白名单应用程序控制。白名单是在默认拒绝背景下的允许例外列表。通过使用白名单配置系统，除非可执行文件在允许的例外列表中，否则全部阻止。白名单包含应用程序名称、其文件名和文件的哈希值。这可以防止恶意或未经批准的应用程序仅通过重命名可执行文件来进行欺骗。

这组网络安全管理最佳实践应作为你开展有效安全工作的起点。存在其他有效且有用的指南，因此不要假设这份建议清单——或来自任何其他来源的任何其他清单——是详尽无遗的。你总有新的经验要学习、新的挑战要面对、新的智慧要获取。

# 故障安全、故障开放与故障关闭选项

故障不是一种选择；它是必然。在组织的生命周期中，故障迟早会发生。你是否准备好妥善处理它，以及故障会造成多大伤害？

故障可能源于材料或结构中未知缺陷导致硬件停止正常运行；可能源于意外静电放电损坏电路；可能源于非典型天气淹没建筑物；也可能源于恶意软件感染导致服务器崩溃，或零日漏洞利用从外部破坏安全。

故障意味着问题、停机、损失和后果。然而，故障不一定意味着破产、倒闭、入狱或灾难性损失。灾难与单纯不便的区别在于**规划**。与安全的大多数方面一样，适当且广泛的规划有助于设计能够预防或有效度过任何问题的基础设施。

规划故障就是规划如何响应和恢复故障。目标是故障转入安全状态，而非不安全或混乱状态。这被称为**故障安全**。故障安全状态会恢复到一种几乎没有危害、或者至少不会造成进一步危害的状态。根据情况，故障安全状态可能是**故障开放**或**故障关闭**。

*   **故障开放**是指恢复到开放、可用或解锁状态。在物理世界中，故障开放对人员安全至关重要（如故障开放门允许人员轻松撤离建筑物）。但这类易于开启的门可能成为入侵者进入安全内部区域的弱点。在 IT 领域，故障开放是指恢复到无过滤通信或数据访问状态。
*   **故障关闭**是指恢复到关闭、不可用或锁定状态。在物理世界中，故障关闭是在紧急情况或妥协期间防止门或容器被打开。在 IT 领域，故障关闭会阻断对通信和其他数字资源的访问。

根据具体情况，故障开放或故障关闭任一状态都可以是故障安全或故障保险选项。无论哪种情况，你都应仔细考虑并规划将使用的默认响应类型，特别是在紧急情况、入侵、妥协或系统故障期间。

# 物理安全

没有物理安全就没有安全。逻辑保护只能防范逻辑攻击，物理保护才能防范物理攻击。仅凭几分钟的物理接触，黑客就能克服或绕过大多数逻辑安全措施。

物理安全是防止未经授权的人员直接物理接触、访问或影响 IT 基础设施的敏感组件。任何设计良好的网络安全解决方案都将包含物理安全组件。如果你未能充分解决物理安全问题，就意味着你未能理解组织面临的威胁。

物理安全包括：
*   **抗强行进入的设施**：选择、改进或建设能防止和阻止未经授权物理入侵的设施。如果物理破门而入是可能且潜在有利可图的，盗窃更有可能发生。
*   **所有人员活动监控**：可靠的物理访问控制包括记录员工进出每个安全或敏感区域的时间。良好的物理访问控制可阻止外部人员访问并强制要求访客陪同。
*   **技术手段部署**：应包括刷卡进入、防盗警报、运动探测器和安全摄像头。利用最佳可用技术来威慑和检测物理安全违规。

# 监控妥协迹象

组织中的每个人都是物理安全工作的一部分。所有人都有责任遵守安全边界，并报告违规或可疑活动。安全关乎“锁定”与“监控”。并非每位员工都能协助锁定过程，但所有人都能且应协助监控违规和可疑行为。

除人工监控外，还应利用所有可用技术查找安全违规。在适当情况下使用审计、`IDS`（入侵检测系统）、`IPS`（入侵防御系统）、安全摄像头、运动探测器等。正确的网络安全管理包含为监控违规而进行的正确设计。

违规可能发生在物理世界，也可能发生在计算机、网络和互联网的逻辑世界中。不要假设违规未造成直接物理伤害就不值得了解或追究。无论是物理犯罪还是逻辑犯罪，犯罪就是犯罪。设计并实施检测机制以注意、记录和监控可疑或异常活动。

# 事件响应

事件响应是对负面情况或事件的计划性反应。安全违规或至少违规尝试不可避免地会发生。当这些事件以任何方式影响组织或其执行任务的能力时，事件响应即被触发。事件响应的目标是将停机时间最小化、将损失最小化，并尽快将环境恢复到安全的正常状态。
