
# 黑客攻击

**黑客攻击**最初是指摆弄或修改系统以进行学习和探索。然而，该术语后来演变为指恶意且可能构成犯罪的计算机入侵和操纵行为。无论哪种情况，恶意或犯罪黑客都是严重威胁。每一位网络管理员都应关注黑客攻击问题。

安全的某些重要方面源于对黑客技术、方法和动机的理解。一旦你学会像黑客一样思考，就可能预判未来的攻击。这使你能够在黑客成功**突破**贵组织网络之前，设计出新的防御措施。

那么黑客是如何思考的？黑客沿着操纵或变更的思路思考。他们研究规则，以创造新的方法来规避、打破或篡改这些规则。许多成功的安全漏洞利用，只不过是对网络通信规则的细微变体或违背而已。

黑客寻找容易下手的目标或被忽视的漏洞。黑客寻求能给他们带来最大收益的目标，通常是经济回报。黑客将事物颠倒过来、彻底剖析、反其道而行之。黑客尝试以不同顺序、使用错误数值、超出边界执行任务，旨在引发反应。黑客从错误中学习并加以利用，特别是网络安全专业人员未能妥善保护组织资产的错误。

为什么像黑客一样思考至关重要？六世纪中国军事战略家兼哲学家孙子，在其著名军事著作《孙子兵法》中指出：“知彼知己，百战不殆。”一旦你了解黑客如何思考、他们使用的工具、其漏洞利用手段以及采用的攻击技术，就能制定有效的防御措施来抵御他们。

你常听到“最好的防御是进攻”。虽然这句话在其他领域可能有其道理，但大多数网络安全管理员既没有进攻黑客的奢侈条件，也没有法律权利。相反，你需要扭转这一战略口号：最好的进攻是防御。虽然网络安全管理员不能合法或合乎道德地攻击黑客，但他们完全有权限保护网络和资产免受黑客的猛烈攻击。

## 典型 IT 基础设施的七大域

黑客寻找任何一切机会来利用目标。IT 基础设施的任何方面都存在**风险**，也没有任何方面能免受黑客的审视。在像黑客一样思考时，要分析典型 IT 基础设施的七大**域**（[图 1-2](#07_chapter01.xhtml#fig1-2)）中每一个潜在的漏洞和弱点。要彻底。黑客只需防御体系中的一道裂缝，就能开始瓦解防线。你需要找到每一个可能的突破点，将其加固并强化网络。

典型 IT 基础设施的七大域包括：

![Image](images/bull1.jpg) **用户域**—该域指实际用户，无论他们是员工、顾问、承包商还是其他第三方用户。任何访问和使用组织 IT 基础设施的用户，在获得组织 IT 资源和基础设施的访问权限前，必须阅读并签署可接受使用策略（`AUP`）。

![Image](images/bull1.jpg) **工作站域**—该域指最终用户的桌面设备，如台式计算机、笔记本电脑、`VoIP` 电话或其他端点设备。工作站设备通常需要安全对策，如防病毒、反间谍软件和漏洞软件补丁管理，以维护设备的完整性。

![Image](images/bull1.jpg) **局域网域**—该域指用于支持工作站连接到组织网络基础设施的物理和逻辑**局域网 (LAN)** 技术（即 100Mbps/1000Mbps 交换式以太网、802.11 系列无线局域网技术）。

![Image](images/bull1.jpg) **局域网到广域网域**—该域指组织的互联网络以及局域网与广域网基础设施之间的互连点。路由器、防火墙、**非军事区 (DMZ)**、**入侵检测系统 (IDS)** 和**入侵防御系统 (IPS)** 常被用作该域中的安全监控设备。

![Image](images/bull.jpg) **远程访问域**—该域指用户远程访问组织 IT 基础设施、系统和数据的授权和认证远程访问程序。远程访问解决方案通常涉及 `SSL-128` 位加密的远程浏览器访问或加密的 `VPN` 隧道，以实现安全的远程通信。

![Image](images/bull1.jpg) **广域网域**—拥有远程站点的组织需要**广域网 (WAN)** 来互联它们。组织通常从服务提供商处外包广域网连接，以获得端到端的连接和带宽。该域通常包括路由器、电路、交换机、防火墙以及远程站点的同类设备，有时由服务提供商通过托管服务提供。

![Image](images/bull1.jpg) **系统/应用域**—该域指通常位于组织数据中心和/或机房内的硬件、操作系统软件、数据库软件、客户端/服务器应用程序和数据。

第一步是认识到妥协（被攻破）的可能性存在于整个组织中。下一步是理解网络安全的目标。

## 网络安全目标

网络**安全目标**因组织而异。但通常包含一些共同的指令：

![Image](images/bull1.jpg) 确保资源的机密性

![Image](images/bull1.jpg) 保护数据的完整性

![Image](images/bull1.jpg) 维护 IT 基础设施的可用性

![Image](images/bull1.jpg) 确保个人可识别数据的隐私

![Image](images/bull1.jpg) 实施访问控制

![Image](images/bull1.jpg) 监控 IT 环境中的策略违规行为

![Image](images/bull1.jpg) 支持**业务任务**和组织的整体使命

无论贵组织的安全目标是什么，要实现它们，都需要将这些目标记录下来，并制定详尽的计划来执行。没有书面计划，安全充其量只是杂乱无章，极可能无法保护资产。有了书面计划，网络安全就走上了成功之路。一旦定义了安全目标，这些目标将成为组织保护整个 IT 基础设施的路线图。

## 如何衡量网络安全的成功？

组织通过其既定安全目标的达成程度和安全标准的维持情况来衡量其网络的安全性。从本质上讲，这成为组织信息系统安全的基准定义。例如，如果网络上的私密信息未泄露给外部人员，则你为维护机密性所做的努力就是成功的。又如，如果员工能按时按预算完成工作，则你为提供系统完整性保护所做的努力就是成功的。

然而，如果发生违规行为，导致资产受损或无法实现安全目标，则网络安全就不算成功。但让我们面对现实吧，安全永远不是完美的。事实上，即使设计和执行得再好，意外、错误甚至蓄意的有害攻击也会困扰你的最佳努力。完美的安全组件不存在。它们都有弱点、局限性、**后门**、变通方法、编程错误或其他可被利用的因素。
