## 会话劫持

会话劫持是指黑客在客户端通过服务器认证后接管连接的情况（[图 4-10](#10_chapter04.xhtml#fig4-10)）。要执行此攻击，黑客必须窃听会话以了解详细信息，例如会话端点的地址和序列号。利用这些信息，黑客可以使客户端不同步，接管客户端的地址，然后将精心制作的数据包注入数据流。如果服务器接受初始伪造数据包为有效数据包，则会话已被劫持。

![Image](images/pg137.jpg)

**图 4-10**

会话劫持从客户端窃取连接。

在会话劫持中，攻击者不会直接获知客户端的凭据。如果黑客失去连接，他将不得不寻找另一个会话进行劫持。失去会话的客户端会意识到连接已丢失，但不一定会意识到该断开连接是一次劫持攻击。

会话劫持有时会采用 DNS 欺骗、投毒、ARP 欺骗、ICMP 重定向和流氓 DHCP 来改变会话的路由或路径。黑客利用这种路径改变，强制目标会话通过更易访问的网段传输，从而使会话劫持攻击更容易实施。

任何在未加密的情况下使用 TCP/IP 的主机都容易受到会话劫持的攻击。即使使用复杂或伪随机的数据包序列编号，只需少量窃听，黑客（或黑客工具）就能预测未来的序列值。防止会话劫持的唯一真正保护措施是加密，例如 VPN。

## 欺骗攻击

欺骗是对信息的伪造。大多数欺骗是对来源身份的伪造。电子邮件地址、MAC 地址和 IP 地址都很容易被伪造。欺骗会诱使用户或主机相信通信源自除其实际来源以外的其他位置。这是垃圾邮件传输中的常用策略。欺骗会冒充授权实体，例如通过 MAC 欺骗绕过无线接入点的 MAC 过滤。

欺骗难以预防，且在一定程度上难以检测。大多数欺骗检测发生在你监控正常流量并寻找寻址异常时。例如，如果交换机发现某个特定 MAC 地址是交换机端口 6 接收到的帧的源地址，而该 MAC 地址也作为交换机端口 9 接收到的帧的源地址出现，这就是 MAC 欺骗的症状（[图 4-11](#10_chapter04.xhtml#fig4-11)）。另一个例子是，如果防火墙在其外部接口接收到一个数据包，而源 IP 地址是内部 LAN 地址，则可能正在发生欺骗。

### 技术提示

NTFS 的**备用数据流 (ADS)** 是为支持来自 **POSIX**、**OS/2** 和 Macintosh 的文件而添加到该文件系统的一项功能。此功能于 1990 年代中期添加到 NTFS 中，以推动政府采购 Windows NT。然而，即使现在 Windows 已放弃对 POSIX 和 OS/2 的支持，且 Macintosh **分层文件系统 (HFS)** 支持不再需要，NTFS 仍保留了此功能。ADS 是文件包含多个资源分支的能力。NTFS 对 ADS 的支持导致不仅额外资源，而且完整的额外文件都可以隐藏在任何正常文件对象之下。

一个正常的文件对象（包括目录）可以在其下包含许多额外的文件。额外文件的数量仅受驱动器上可用空间总量和隐藏文件大小的限制。一旦文件作为 ADS 存储，它就不再被操作系统本身看到或轻松访问。有几种黑客工具可以创建和操纵 ADS。只有少数扫描工具（如 *[sysinternals.com](http://sysinternals.com)* 的 Streams）和极少数恶意软件扫描器能专门扫描驱动器中的 ADS 隐藏代码。

欺骗是需要监控和过滤的对象，但不存在真正或直接的欺骗预防措施。此外，如果传输中的真实数据未加密，黑客可以拦截并修改这些数据。因此，欺骗数据并不总是作为伪造通信产生的。

## 隐蔽信道

**隐蔽信道**是隐藏的、未知的、独特的、非典型的信息传输路径。该信道之所以隐蔽，是因为它未知且不可见。黑客利用隐蔽信道进行秘密通信，通常用于将数据泄露出安全环境。隐蔽信道是不安全的传输路径。如果路径已知，它将成为公开信道，并可能被阻止、过滤或以其他方式保护。

隐蔽信道主要有两种形式：时序和存储。时序信道通过定时和同步的活动传递信息。时序隐蔽信道的几个潜在示例包括：

![Image](images/bull1.jpg) 操纵风扇转速，使较高和较低的音调噪音产生二进制传输

![Image](images/bull1.jpg) 节流互联网链路上的带宽消耗，使得在特定间隔内，利用率读数低于 60% 表示二进制通信中的零，高于则表示一

存储隐蔽信道通过未被发现或未被察觉的存储位置传递信息。存储隐蔽信道的几个潜在示例包括：

![Image](images/bull1.jpg) 使用硬盘的**未分区空间**，通过十六进制编辑器写入数据存储

针对隐蔽信道的最佳防御包括 IDS 和 IPS，以及对 IT 基础设施的所有方面进行彻底监控，以发现任何类型的异常或反常事件。预测隐蔽信道很困难，因为就其本质而言，它们是未知且不可见的。

## 黑客如何劫持松散空间

硬盘包含称为扇区的段。扇区是驱动器中最小的固定大小存储块，大小为 512 字节。当文件系统应用于**分区**时，会由一个或多个扇区创建**簇**。松散空间是存储文件仅部分占用的最后一个簇的未使用部分。簇:扇区比率通常在 1:1 到 1:128 之间，对应簇大小从 512 字节到 64 KB。
