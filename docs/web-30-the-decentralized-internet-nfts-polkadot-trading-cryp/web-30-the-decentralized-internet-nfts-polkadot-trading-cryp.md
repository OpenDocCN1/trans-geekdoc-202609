## 权力不可避免的重新分配

每一代人都有一两次定义其存在年份的重大斗争。令人记忆的包括人们为了更大的利益不惜牺牲个人而携手。最深刻的植根于捍卫公平与公正的防线。

正如早期的去中心化努力一样，无论是工会还是合作社，去中心化 Web 的构建将看到其反抗的章节。

它看起来可能不像过去的战场，但不要误会，这关乎权力的重新分配。

正如皮特·西格（Pete Seeger）所说，在未来的某个时刻，你将必须选择：“你站在哪边？” 只是，未来的世界可能不像过去那样非黑即白，会有许多侧面供你选择。系好带，以下是我这么说的原因：

## 理解当今控制的本质 - 针对少数人的规模化倾斜

在多个行业中出现了一种新兴模式，其设定是向少数人倾斜的，以牺牲许多人为代价。如果需要变革，控制权仍留在成员手中，或者顶多留在股东手中，这两者的经济激励可能与更大的利益相悖。对于公司超越最大化股东利益的职责能力，我持悲观态度，而且对于这种火箭飞一般的增长来说，这甚至是是荒谬的。

这并非关乎对错，而是为了什么。

全球聚合器将以牺牲受影响者的福祉为代价来优化运营效率。外卖业务将使丰丰但不健康的选择在网站上变得容易找到。考虑到由于善意而产生的副作用，中央控制的组织或由中间人运营的环境正在扩大对受影响社区的不合理权力。更糟糕的是，同样的权力在没有对其价值来源的成员直接负责的情况下影响未来，让游说客起草法律，或让社交媒体公司设定标准。

对于对用户或“伙伴”直接负责运营和数据的机构，难道不应该重新设计吗？

## 断裂线在哪里？被剥夺者的边缘

为了评估哪些机构已通过去中心化进行变革，利益相关者或社区远离流程有多远：

-   **利益对齐（ALIGNMENT）**：如今，控制者与受影响者之间的收益相关性有多强？（例如，保险公司持有人与福祉之间的相关性很弱）
-   **代表性（REPRESENTATION）**：如今，有多少变革是由受影响者而非控制者驱动的？（例如，政府在实施社会福利方面几乎没有话语权）
-   **影响力（INFLUENCE）**：如今，机构创造的价值有多少是社区努力的直接结果？（例如，零工经济平台是伙伴工作的有效中间人）
-   **赋能（ENABLEMENT）**：如今，社区与机构之间的日常互动有多少潜力被规则集代码化？（例如，零售银行的需求可以局限于预测的步骤内）
-   **所需的感知专家（SENTIENT）**：如今，对领域专家在管理异常和特殊情况方面的需求有多深？（例如，社交媒体平台需要人类参与来解决仇恨言论）

你将感觉到一种正在出现的模式，它横跨了我们所知的 Web 2.0 大部分，涵盖社交媒体巨头、保险公司、零工经济平台，甚至是社会保障和福利。而这仅仅是冰山一角。

## 替代方案是什么样的？透明优先的心态

几个世纪以来，我们一直以“控制优先”的心态设计我们的社会、工业和政治机构。Web 3.0 为“透明优先”的组织提供了协议、基础设施和工具。

这意味着我们的民主和市场已经崩溃了吗？概念本身可能没问题，但需要的微调是在执行上，从“控制优先”转向“透明优先”的设定，特别是对于那些符合上述条件的机构。

现在没有更好的时候来重新思考创业了，将其视为一种与受影响者共同带来大规模变革的追求。

这在社区建设、技术创新和行为经济学的交叉点得到最好的赋能。去中心化结构可以通过消除决定如何提取价值的权力以及自动化提取价值的能力来实现，从而大幅减少历史上普遍的信息不对称、腐败和低效。

这现在感觉是向往的，但很快将成为入场券。透明优先的心态将重新定义治理者与被治者之间的关系。对成员负运营和数据访问的机构必须重新设计。

## 需要什么？Web 3.0 的政治学

底层的 Web 3.0 构造具有潜力让那些通过特定中间人的控制和权力被隔绝在资本收益之外的人“工会化”。一旦技术解决，斗争将转向政治化。在这个转型过程中，最大的挑战不是 DAO 中社交层的去中心化民主设定，也不是自动化治理自我执行的技术复杂性。这些问题是努力的结果，并将得到解决。

最大的挑战将是与有权者进行对话，让他们愿意为了社区更大的利益而放弃他们的控制权。

在商业领域，长远来看，市场将强制这种移动，因为没有中间人的结构将从新的价值创造模式中获益。在公共部门（由政府领导的治理），道路是陡峭且向上的。

## 我们如何到达那里？仅靠技术是不够的

我们需要更多关于我们如何忘记多年来被洗脑的对话，转而以透明优先的心态从底层开始设计机构并建立治理。

除了技术人员之外，物理世界的建设者、领导合作社的社区组织者、推动政府机构的官僚、创作者、歌手等是否会拥抱或推动变革？感觉感觉技术掩盖了有关主流用例的讨论，例如，对合作社动员的影响、政府运营的透明度、创意所有权等，是巨大的。我们需要设计师、社会学家、社区建设者等来塑造这些。

我们大众所需要的对话不仅仅是区块链、代币或 NFT。那些只是工具。它们会被炒作、演进、拥抱并被取代。

现在我们已经有了更巧妙的方法来嵌入透明度和自动化，我们该如何应对？
