34. Which of the following is NOT part of the OWASP Top Ten list of critical web application security risks?

+   A. Injection

+   B. Sensitive data exposure

+   C. Insecure direct object references

+   D. User ID and password authentication schemes

D. User ID and password authentication schemes are not a specific component of the OWASP Top Ten list of critical web application security risks. Many other components incorporate threats to authentication schemes and systems, but the list does not treat them as their own entity.

A is incorrect because injection is a specific component of the list. An injection attack occurs when a malicious actor sends commands or arbitrary data through input and fields with intent the application or system execute the code as part of its normal processing and queries. This can trick an application into exposing data that is not intended or authorized, and potentially allow an attacker to gain insight into configurations or security controls.

B is incorrect because sensitive data exposure is a specific component of the list. Sensitive data exposure occurs when protected information, such as PII or credit card information, is not properly encrypted or masked, and is thus susceptible to attackers. This refers to specific data within the application and is not directly related to specific functions of the application.

C is incorrect because insecure direct object references are a specific component of the list. Insecure direct object references occur when a developer has in their code reference to something on the application side, such as a database key, the directory structure of the application, configuration information about the hosting system, or any other information that pertains to the workings of the application that should not be exposed to users or the network.
