

4. BCDR 计划包含几种不同类型的操作和主要组件。在测试和规划中，以下哪一个部分是整个过程中最容易被忽略的？

-   A. 服务恢复
-   B. 变更管理流程
-   C. 人员可用性与需求
-   D. 服务恢复

-   D. 一旦 BCDR 事件结束，且常规数据中心和托管资源再次可用时，进行有序的正常运行返回是至关重要的。虽然 BCDR 计划在将生产业务迁移到恢复站点时通常非常详尽并经过了彻底的测试，但在将服务恢复到正常运行时，往往无法达到同等的详细程度和测试水平。由于这一疏忽，组织在将其数据和服务恢复到正常运行状态的过程中，可能会产生大量的延迟、成本，甚至潜在的停机。

-   A 是错误的，因为灾难期间的服务恢复通常是任何 BCDR 计划和测试的关注重点，绝不是容易被忽略的内容。

-   B 是错误的，因为大多数 BCDR 规划在确保执行变更管理流程方面做得很好。

-   C 是错误的，因为大多数 BCDR 规划都很好地确保了人员可用性和需求，这些流程在规划和测试期间通常不会被忽略。

5. 哪个概念允许用户或人员在不访问实际网络接口的情况下更改网络配置？

-   A. 逻辑网络
-   B. VLAN
-   C. 广域网访问
-   D. 软件定义网络 (SDN)

-   D. 软件定义网络 (SDN) 是云计算的一个重要方面。在 SDN 中，关于流量的过滤和实际的转发是分离的。在云计算中，这种分离允许云提供商根据当前需求和需求快速地调整网络流，而无需访问实际网络组件。云提供商可以使用管理工具或云管理接口进行此类更改。在 SDN 实现中，访问级别是受控制的。

-   A 是错误的，因为逻辑网络涉及在较大的物理网络内划分，但不涉及网络管理或访问授权。

-   B 是错误的，因为虚拟局域网 (VLANs) 与逻辑网络相同，将一个较大的物理网络划分为不同的段，但不涉及网络管理。

-   C 是错误的，因为广域网访问指的是云计算在公共互联网上可用，而不是与传统数据中心相关的私有网络。

6. 在联邦系统中，哪个实体接收身份提供者的响应并处理它以确定用户的授权属性？

-   A. 服务提供者
-   B. 服务方
-   C. 依赖方
-   D. 应用提供者

-   C. 在身份过程中，身份提供者向依赖方发送关于用户的特定属性（名称、位置等）。依赖方使用这些信息来确定哪些主机可以获得有限资源的级别和类型，以及是否授予。在联邦系统中，这种判断是根据策略或云需求做的。

-   A 是错误的，因为预留是云环境中保证给客户的最小资源水平。预留涉及计算的两个主要方面：内存和处理。有了预留，提供商保证云客户至少拥有启动和运行任何服务的必要资源。

-   B 是错误的，因为服务方听起来与依赖方相似，但在这种情况下不是正确的术语。

-   D 是错误的，因为应用提供者听起来与依赖方相似，但在这种情况下不是正确的术语。

7. 哪种云存储方法利用值来访问应用程序或客户端的数据？

-   A. 对象
-   B. 卷
-   C. 结构化
-   D. 非结构化

-   A. 对象存储在系统和应用程序外部，并通过值对每个对象访问。它不是组织在文件系统的分层结构中，而是一个每个对象通过值分类的扁平结构。

-   B 是错误的，因为卷存储在常规计算机或服务器上使用传统的文件夹、文件名和文件系统结构。尽管它可以使用类似于值的文件，但不是以对象存储的方式进行存储或访问。

-   C 是错误的，因为结构化存储类似于数据库，具有定义的结构、标签和字段。它不是用于通用类型，不使用对象存储相同的值。

-   D 是错误的，因为非结构化存储与结构化存储配合用于辅助文件，但它不像对象存储那样使用值。

8. 对于具有高数据读写依赖的系统，对象存储面临以下哪项最突出的问题？

-   A. 对象的完整性
-   B. 对象的复制
-   C. 对象的大小
-   D. 对象的数量

-   B. 对象存储系统是自包含的且位于客户外部。当系统对其他主机有高数据读写依赖时，可能会出现一致性问题。

-   A 是错误的，因为这里的关注点不是对象的完整性。

-   C 是错误的，因为这里的关注点不是对象的大小。

-   D 是错误的，因为这里的关注点不是对象的数量。

9. 当系统资源利用率面临巨大需求，可能接近云环境的总体容量时，以下哪种概念将设定哪些主机接收资源的优先级？

-   A. 预留 (Reservations)
-   B. 份额 (Shares)
-   C. 限制 (Limits)
-   D. 托管 (Escrows)

-   B. 云环境中的份额概念用于缓解和控制客户请求。当达到高利用率时，系统会自动根据每个主机的份额评分来确定哪些主机可以访问有限资源。特定主机的值越高，获得的资源就越多。

-   A 是错误的，因为预留是云环境中保证给客户的最小资源水平。预留涉及计算的两个主要方面：内存和处理。有了预留，提供商保证云客户至少拥有启动和运行任何服务的必要资源。在拥有大量客户的大云环境中，此功能在拒绝服务攻击或其他主机和系统高利用资源的情况下可能尤为重要。

-   C 是错误的，因为限制的实施是为了强制云客户对内存或处理的最大利用。这些限制可以在虚拟机级别执行，也可以针对客户进行全面限制。它们的目的是确保云资源不会被单个主机或客户分配或消耗，从而损害其他主机和客户。带有自动伸缩和按需自服务等云计算功能，限制可以是硬性的（固定的），也可以是灵活的允许动态更改。通常，当允许限制根据当前条件和消耗动态更改时，是通过“借用”额外资源实现的，而不是通过更改实际限制。

-   D 是错误的，因为托管听起来与份额相似，但在这种情况下不是正确的术语。

-   A. 份额 (Share)
