

# 运营领域

第 5 域关注以下主题：

- 云数据中心的规划和设计流程
- 如何实施、运行和管理数据中心的物理和逻辑方面
- 如何对服务器、网络和存储系统进行安全和加固
- 如何开发和实施基线（Baseline）
- 如何对云系统进行风险评估
- 用于管理和符合法规的 ITIL 服务组件
- 如何从云环境中安全地收集数字证据

运营领域聚焦于如何规划、设计、运行、管理和操作云数据中心的逻辑组件和物理组件。我们将涵盖每一层的关键组件——包括服务器、网络设备和存储系统——以及它们与传统数据中心相比在云数据中心的独有之处。我们还将调查系统的风险评估过程及其与云系统的关系，以及取证证据是如何收集的，它在云环境中面临的独特挑战和考虑因素。
