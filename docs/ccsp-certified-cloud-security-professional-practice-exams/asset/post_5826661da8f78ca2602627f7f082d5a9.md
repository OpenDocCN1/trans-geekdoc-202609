# Answers and Explanations

1. Why does the use of a Type 2 hypervisor typically incur more security concerns than a Type 1 hypervisor?
A Type 2 hypervisor runs on top of an operating system and is dependent on the security of that OS for its own security. Because the host OS is a large attack surface, it represents a significant risk if it is compromised.

2. A variety of limits can be set within a cloud environment. Which of the following is NOT a unit where a limit can be set?
Limits can be set at the customer, application, or virtual machine level. However, the hypervisor is the software that manages these resources, not the unit where the limit is defined for the user.

3. With volume storage, a slice of storage space is allocated to a system to be used in whatever manner is necessary for that particular system and its requirements. What is this slice of storage referred to as?
A LUN (Logical Unit Number) is a unique identifier to a set of storage devices or a storage medium.

4. Which of the following capabilities would NOT be covered by a reservation within a cloud environment?
A reservation ensures that resources are available for the customer. With cloud computing features such as auto-scaling and on-demand self-service, limits can be either hard (or fixed) or flexible and allowed to change dynamically. When typically, limits are allowed to change dynamically based on current conditions and consumption, it is done by "borrowing" additional resources rather than a change to the actual limits themselves.

5. Without the ability to segregate networks physically within a cloud environment, which concept is heavily used for network isolation and segmentation?
VLANs (Virtual Local Area Networks) are used to create logically separate networks on the same physical infrastructure, allowing for isolation and segmentation without physical cabling changes.

6. Under the guidance of industry-accepted best practices, which of the following is the correct frequency for BCDR plan testing?
BCDR plans should be tested annually to ensure they remain effective and that the staff knows the procedures.

7. Software-defined networking (SDN) is intended to separate different network capabilities and allow for the granting of granular configurations, permissions, and features to non-network staff or customers. Which network capability is separated from forwarding of traffic?
The control plane (which makes routing decisions) is separated from the data plane (which forwards the actual traffic).

8. Different storage paradigms within a cloud environment handle formatting, allocation, and security controls differently. What handles these aspects for volume storage?
The storage host is typically responsible for managing the formatting, allocation, and security of the volume-based storage.

9. Which aspect of cloud computing would be most negatively impacted by incurring vendor lock-in with a cloud provider?
Portability is the ease of moving data or applications from one provider to another; lock-in hinders this.

10. A denial of service (DoS) attack can potentially impact all customers within a cloud environment with the continued allocation of additional resources. Which of the following could be useful for a customer to protect themselves from a DoS attack against another customer?
Limits are used to cap the amount of resources a single customer can consume, preventing them from exhausting the shared pool.

11. What aspect of a Type 2 hypervisor involves additional security concerns that are not relevant with a Type 1 hypervisor?
A Type 2 hypervisor relies on a host operating system, meaning it is vulnerable to any security flaws present in that underlying OS.

12. During a system or application audit, which of the following populations will be the most important driver of the audit and testing?
Regulators often set the requirements and standards that drive the scope and focus of audits for compliance.

13. A common strategy employed when using cloud services for BCDR strategies is to only maintain images offline at the cloud provider, or to only have a minimal set of systems running until needed. With the strategy of only running a minimal level of systems until needed, which aspect of cloud computing would be most beneficial during an actual BCDR situation?
Rapid elasticity allows the environment to quickly scale up resources when the minimal systems needs to be fully operational.

14. Although cloud storage systems will ultimately be consumed by cloud customers users from a logical configuration, what are the two types of underlying physical storage systems most used with cloud computing?
RAID and SAN (Storage Area Network) are common physical architectures used to provide high-performance and redundant storage.

15. Although performing BCDR tests at regular intervals is a best practice to ensure processes and documentation are still relevant and efficient, which of the following represents a reason to conduct a BCDR review outside of the regular interval?
Significant changes, such as regulatory changes, may necessitate an immediate review of the BCDR plan.

16. When an organization is considering the use of a cloud provider as part of its BCDR strategy, which of the following is most important to consider from a security perspective?
Jurisdiction refers to the legal location where data is stored, which impacts security compliance and data protection laws.

17. A primary focus during a BCDR situation is for systems and applications to meet an acceptable level of operations. Which value represents this status?
The RSL (Recovery Service Level) defines the minimum level of performance that is acceptable during a disaster.

18. Different storage paradigms within a cloud environment handle formatting, allocation, and security controls differently. What handles these aspects for volume storage?
The storage host manages the specifics of volume-based storage.

19. Which aspect of cloud computing would be most negatively impacted by incurring vendor lock-in with a cloud provider?
Interoperability is the ability for different systems to work together; lock-in makes this difficult.

20. A denial of service (DoS) attack can potentially impact all customers within a cloud environment with the continued allocation of additional resources. Which of the following could be useful for a customer to protect themselves from a DoS attack against another customer?
Reservations ensure a specific amount of resources is held for a customer regardless of demand.

21. With volume storage, a slice of storage space is allocated to a system to be used in whatever manner is necessary for that particular system and its requirements. What is this slice of storage referred to as?
A LUN (Logical Unit Number) is the allocated slice of storage.

22. When is a system hosted in a virtualized environment but NOT vulnerable than a physical server?
