

26. 发现攻击者能够通过你的 Web 应用程序发送格式正确的 SQL 代码，以获取底层数据库的整个架构（schema）。这最好代表哪种类型的攻击？

-   A. 注入 (Injection)
-   B. 敏感数据泄露 (Sensitive data exposure)
-   C. 安全配置错误 (Security misconfiguration)
-   D. 不安全直接对象引用 (Insecure direct object references)

-   A. 注入攻击是指恶意者通过输入数据字段发送命令或其他任意数据，目的是让应用程序或系统作为正常处理和查询的一部分执行代码。这可以欺骗应用程序暴露非预期或未授权的数据，或者可能允许攻击者深入了解配置或安全控制。

-   B 是错误的，因为敏感数据泄露指的是许多 Web 应用程序经常使用用户数据，例如信用卡、身份验证据、个人身份信息 (PII) 和财务信息。如果信息没有通过加密和安全传输机制得到妥善保护，就会迅速成为攻击者的容易目标。Web 应用程序必须在应用端执行强加密和安全控制，但还需要确保与访问信息的浏览器和其他客户端使用安全的通信方法。对于敏感信息，应用程序理想情况下应该对浏览器进行检查，以确保它们根据支持的版本和协议符合安全标准。

-   C 是错误的，因为安全配置错误发生在应用程序和系统没有以安全的方式进行适当配置或维护时。这可能是由于安全基准或配置的缺陷、对系统配置的未经授权的更改，或者在供应商发布安全补丁时未能对系统进行修复和更新。安全配置错误还包括在使用和部署应用程序之前未更改自带的默认配置或凭据。

-   D 是错误的，因为不安全直接对象引用发生在开发者在代码中引用了应用程序端的某些内容，例如数据库键、应用程序的目录结构、托管系统的配置信息，或任何与应用程序运行相关且不应暴露给用户或网络的其他信息。

27. 你的应用程序一直是 SQL 注入尝试的持续目标。以下哪些技术最适合用于防止成功的 SQL 注入利用发生的概率？

-   A. XML 加速器 (XML accelerator)
-   B. WAF (Web 应用防火墙)
-   C. 沙箱 (Sandbox)
-   D. 防火墙 (Firewall)

-   B. Web 防火墙 (WAF) 是一种设备或插件，用于解析和过滤来自浏览器或客户端的 HTTP 流量，并在允许流量进入实际应用程序服务器之前应用一组规则。WAF 最常见的用途是在 SQL 注入和跨站脚本攻击到达应用程序之前对其进行发现和拦截。

-   A 是错误的，因为 XML 加速器是一种设计用于设备，用于将 XML 处理从实际应用程序和系统上卸载，转而利用专为该目的设计的优化过的和专用的设备。在大多数情况下，特别是对于频繁使用的应用程序，XML 加速器可以大幅提高系统性能，并提供可能的安全益处，因为 XML 处理是在专用资源上完成的，远离实际应用程序。这允许在触发实际应用程序代码之前对输入进行解析和验证，与 XML 防火墙的作用类似。

-   C 是错误的，因为沙箱是一个概念，用于根据安全、监管或测试要求将网络内的系统进行相互隔离（segregating）。

-   D 是错误的，因为防火墙用于根据源和目的 IP 地址以及使用的端口和协议来控制网络级访问。防火墙不提供检查实际流量内容（如 SQL 注入尝试）的能力。

28. 联邦身份系统由两个主要组件组成。以下哪些组合代表了正确的两个组件？

-   A. 身份提供者 (Identity provider) 和依赖方 (Relying party)
-   B. 身份验证提供者 (Authentication provider) 和 服务提供者 (Service provider)
-   C. 身份提供者 (Identity provider) 和 依赖提供者 (Relying provider)
-   D. 单点登录 (Single sign-on) 和 应用程序 (Application)

-   A. 构成联邦身份系统的两个组件是身份提供者（处理用户的身份验证和属性发布）和依赖方（接受身份验证并消耗用户属性，通常将其提供给应用程序或服务）。

-   B 是错误的，虽然身份验证提供者和服务提供者听起来与正确术语相似，且在某些情况下用法与官方术语相同，但在这种情况下是不正确的。

-   C 是错误的，因为只有身份提供者是一个组件的正确术语。另一个组件是依赖方；它消耗身份令牌和属性，而不作为这些内容的提供者。

-   D 是错误的，虽然单点登录和应用程序在某种程度上描述了联邦身份系统的广泛使用，这些术语并不是通用的，且在这种情况下是不正确的。

29. 哪种概念涉及系统响应针对其攻击方法的能力，并自动更改安全配置和防御措施以补偿这些攻击？

-   A. DAST (动态应用安全测试)
-   B. Pen (渗透测试)
-   C. RASP (运行时应用自保护)
-   D. SAST (静态应用安全测试)

-   C. 运行时应用自保护 (RASP) 涉及对具有检测攻击和威胁能力的系统进行测试，自动调整其安全设置或其他配置以补偿并缓解这些攻击和威胁。RASP 设计在真实的实时系统上执行。

-   A 是错误的，因为动态应用安全测试 (DAST) 是作为“黑盒”测试运行的，测试人员对系统没有或没有特定的了解，必须通过使用工具来发现他们关于系统的一切信息。DAST 不会像渗透测试那样尝试执行恶意行为。

-   B 是错误的，因为渗透测试是作为“黑盒”测试进行的，但使用的是攻击者在评估系统时会使用的相同的工具和方法。

-   D 是错误的，因为静态应用安全测试 (SAST) 是一种“白盒”测试，在不执行代码的情况下进行分析。

30. 哪种测试类型对系统运行已知攻击以发现弱点？

-   A. 漏洞扫描 (Vulnerability scanning)
-   B. 渗透测试 (Pen testing)
-   C. 基准扫描 (Baseline scanning)
-   D. 合规性扫描 (Compliance scanning)

-   A. 漏洞扫描使用预定义的签名对系统进行扫描以给出风险评分。

-   B 是错误的，因为渗透测试是作为“黑盒”测试进行的。

-   C 是错误的，因为基准扫描用于确认服务器已应用适当的配置。基准扫描并不测试漏洞；相反，它专注于标记任何偏差。

-   D 是错误的，因为合规性扫描可以指基准扫描或满足监管要求的扫描。

31. 考虑到云系统专门使用广泛的网络访问，哪种技术通常用于支持人员访问系统进行维护和管理？

-   A. IPS (入侵防护)
-   B. TLS (传输层安全)
-   C. SSH (安全外壳)
-   D. VPN (虚拟专用网络)

-   D. 虚拟专用网络 (VPN) 用于从云环境外部到内部网络创建一个安全的网络隧道，在许多情况下它用于访问无法访问的信任区域。VPN 对于系统支持人员和管理员维护系统至关重要。

-   A 是错误的，因为网协议安全 (IPSec) 用于在两个主机之间的网络层加密数据包。它不会提供问题中所描述的访问类型。

-   B 是错误的，因为 TLS 是可能与 VPN 结合使用的加密方法，但它本身不提供管理员从外部连接到安全内部网络所需的相同功能或特性。
