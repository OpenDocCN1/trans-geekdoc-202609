29. The use of baseline images, especially with the auto-scaling capabilities of cloud environments, is crucial for secure operations. What is the first step undertaken when creating a new baseline image?

- A. Clean the operating system install.

- B. Update all software on the install.

- C. Disable or remove all nonsensical services.

- D. Bring patching to the latest level.

- A. In order to create a new baseline image, it is crucial that you are starting from a base image with known configuration settings and defaults in place. Starting with an image that has been in use or modified increases the likelihood that configuration or policy changes have been put in place that will end up on the image you are trying to create (possibly without you realizing that they were carried over), thus impacting security, or at the very least leading to an unintended configuration.

- B is incorrect because you would not update all software on a baseline image until you perform a clean install and have evaluated each software package for the correct version and feature set to be included with the image. Updating software without a clean install, or without analyzing which versions and features are necessary and required, can lead to inadvertent configurations or services on the final image.

☒ D is incorrect because patching up to the latest level is crucial, but only when applied to a clean installation where the patching can be properly tracked and verified.

30. In order to maintain proper utilization and balancing of resources within a cloud environment, distributed resource scheduling (DRS) is heavily used. What resources DRS not used with?

- A. Virtual machines

- B. Physical servers

- C. Storage solutions

- D. Clusters

☒ B. Distributed resource scheduling (DRS) balances virtual computing workloads over an environment to ensure that all are properly balanced on the underlying physical servers. DRS looks at the physical servers to determine load and balance, but it does not have the capacity to change configurations or alter the physical servers. Due to their physical nature, they cannot be migrated in the way virtual resources can.

☒ A is incorrect because virtual servers are one of the key components of a cloud environment that DRS monitors and moves to maintain balance and available resources. As physical servers' loads and demands change, virtual machines can be moved among them to maintain proper balance and distribution of processes and resources.

☒ C is incorrect because storage solutions within a cloud environment are constantly monitored as part of DRS to ensure adequate storage is available between physical hosts. As storage demands change, DRS will balance and migrate storage among physical locations to maintain the proper use of resources.

☒ D is incorrect because clusters, and the virtual components that comprise their systems and storage, are constantly monitored by DRS to ensure proper balancing and availability of resources. Although a cluster is special in regard to its redundant nature, the underlying storage and virtual machines still must be maintained by the cloud environment and balanced with other systems.

31. What concept is used for network segregation and isolation within a cloud environment?

- A. VPN

- B. LAN

- C. VLAN

- D. Cabling

- C. A VLAN (Virtual Local Area Network) is used for network segregation and isolation within a cloud environment. It allows for the grouping of devices regardless of their physical location, providing security and management by isolating traffic.

☒ A is incorrect because a VPN is used for secure connections over networks, not for internal segregation within the cloud environment.

☒ B is incorrect because a LAN is a local area network, and while it provides connectivity, it is not the specific concept used for logical segregation within a cloud architecture.

☒ D is incorrect because cabling refers to the physical media, not the logical concept used for segregation and isolation.

32. Which of the following is NOT a capability of an IDS?

- A. Sending data

- B. Holding a communications channel

- C. Authenticating connections

- D. Receiving data

C. An IDS (Intrusion Detection System) is designed to monitor traffic and alert on suspicious activity. It does not have the capability to send data, hold open channels, or authenticate users.

☒ A is correct because sending data is not a function of an IDS.

☒ B is incorrect because holding a communications channel is a function of a stateful firewall or proxy, not an IDS.

☒ D is incorrect because receiving data is a requirement for an IDS to monitor the traffic.

33. Firewalls are used to control access to networks based on origin, destination, and protocols used. Which of the following is NOT an origin or destination designation used?

- A. VLAN

- B. Physical network

- C. IP address

- D. IP range

☒ A. A VLAN is a logical network segment used for segregation, not a physical origin/destination designation in the same way an IP address is.

☒ B is incorrect because physical network interfaces are origins or destinations for traffic.

☒ C is incorrect because an IP address is a primary origin or destination designation in firewall rules.

☒ D is incorrect because an IP range is frequently used to define sets of allowed or denied traffic.

34. Which of the following is a very common complaint concerning the use of an IDS?

- A. False positives

- B. Latency

- C. Incorrect blocking

- D. Dropping packets

A. With an IDS watching network traffic, the likeliness of generating false positives—and in some cases an enormous number of false positives—is very likely. An IDS requires tuning to eliminate false positives. However, if false positives are totally eliminated, it is very likely you will miss actual alerts to real threats and attacks.

☒ B is incorrect because an IDS is typically a passive device and does not introduce significant latency compared to an inline IPS.

☒ C is incorrect because an IDS is only used to inspect and alert on suspicious activity; it does not block traffic.

☒ D is incorrect because an IDS does not drop packets; it only monitors and alerts.
