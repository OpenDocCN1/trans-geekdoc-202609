+   3. Where would be the most appropriate location for an XML firewall within a system architecture?

+   A. Between the presentation and data layers

+   B. Between the application and data layers

+   C. Between the firewalls and application servers

+   D. Before the firewalls

+   C. An XML firewall validates XML data before it reaches an application server. The appliance can perform validation as well as control what users or services are allowed to access specific XML functions of an application. Positioning the XML firewall between the firewalls and applications allows for initial network filtering based on origination and destination of packets before the content analysis of the appliance is performed before the traffic is allowed to reach the application servers.
