

## D. 额 (Cap)

- C. 设置限制（Limits）的目的是强制执行云客户对内存或处理能力的最大利用率。这些限制可以在虚拟机级别实施，也可以针对客户在整体上实施。其目的是确保单个主机或客户不会分配或消耗大量资源，从而损害其他主机和客户的利益。结合自动伸缩和按需服务等云计算功能，限制可以是硬性的（固定的），也可以是灵活的并允许动态更改。通常情况下，当允许根据当前状况和使用情况更改限制时，是通过“借用”额外资源来实现的，而不是对限制本身进行实际更改。

- A 是错误的，因为云环境中的“份额”（shares）概念用于在环境当前没有能力提供这些资源的能力时，缓解并控制客户对资源分配的。份额的工作原理是通过由云提供商定义的权重系统对云环境内的主机进行优先级排序。当达到高利用率和高分配期时，系统会自动根据每个主机的份额值进行评分，以决定哪个主机可以访问剩余的有限资源。特定主机的值越高，允许利用的资源就越多。

- B 是错误的，因为预留（reservation）是云环境中向客户保证的最低资源水平。预留可以涉及计算的两个方面：内存和处理。有了预留，云提供商保证云客户始终至少有启动和运行其任何服务所需的最低资源。在拥有大量客户的大型云环境中，这项功能在发生拒绝服务攻击或其他主机和系统资源高利用率的情况下可能尤为重要，因为它为所有客户提供了有保障的最低操作水平。

- D 是错误的，虽然 cap（额度/上限）听起来与 limits（限制）一词相似，但在这种情况下它不是一个正确的术语。

11. BCDR（业务连续与性恢复）计划的关键指标之一是服务恢复到管理层满意点所需多长时间。哪个指标代表了这一点和该值？

- A. RTO（恢复时间目标）
- B. RPO（恢复点目标）
- C. RSL（恢复服务水平）
- D. SRE（站点可靠性）

- A. 恢复时间目标（RTO）是衡量在发生故障后，恢复操作到满足管理层 BCDR 目标这一点所需的时间量。

- B 是错误的，因为恢复点目标（RPO）定义为公司为了在管理层接受的水平上运行需要维护和恢复的数据量。这可能是或可能不是恢复到完全运行能力，取决于管理层认为什么是至关重要的核心。

- C 是错误的，因为恢复服务水平（RSL）衡量了在发生故障时需要恢复的以满足 BCDR 目标的总生产服务水平的百分比。

- D 是错误的，因为 SRE 是一个与问题无关的额外选项。

12. 当资源限制超过云提供商确定的阈值且需要调用份额（shares）时，以下哪项决定份额分配的驱动因素？

- A. 优先级权重
- B. 客户规模
- C. 用户数量
- D. 资源成本

- A. 云环境内的系统和服务根据合同要求、购买的服务级别或其他可能的值被分配一个优先级值。当达到限制并需要分配资源时，这种优先级权重决定了系统或服务接收请求资源的顺序。

- B 是错误的，因为客户规模与优先级权重值无关，因为它是由客户的合同和/或购买的服务级别决定的。

- C 是错误的，因为用户数量与优先级权重值无关，因为它是由客户的合同和/或购买的服务级别决定的。

- D 是错误的，因为资源成本与优先级权重值无关，因为它是由客户的合同和/或购买的服务级别决定的。

14. 云环境完全基于虚拟机和虚拟设备，这些镜像也需要在环境中进行存储。通常使用什么类型的存储用于虚拟镜像？

- A. 卷（Volume）
- B. 结构化（Structured）
- C. 非结构化（Unstructured）
- D. 对象（Object）

- D. 对象存储托管在系统和应用程序外部，通过每个对象的键值对进行访问。它不是组织在目录或文件系统的层级结构中，而是具有平坦化结构，每个对象都被分类。

- A 是错误的，因为卷存储托管在系统和应用程序外部，通过每个对象的键值对进行访问。它不是组织在目录或文件系统的层级结构中，而是具有平坦化结构，每个对象都被分类。

- B 是错误的，因为结构化存储托管在系统和应用程序外部，通过每个对象的键值对进行访问。它不是组织在目录或文件系统的层级结构中，而是具有平坦化结构，每个对象都被分类。

- C 是错误的，因为非结构化存储托管在系统和应用程序外部，通过每个对象的键值对进行访问。它不是组织在目录或文件系统的层级结构中，而是具有平坦化结构，每个对象都被分类。

15. 组织可能有许多在行业内通用的原因触发 BCDR 情况。以下哪项不是激活 BCDR 计划的典型原因？

- A. 自然灾害
- B. 公用事业停电
- C. 人员流失
- D. 恐怖攻击

- C. BCDR 情况涉及通常影响整个数据中心的广泛问题或灾难。人员流失不是利用 BCDR 情况的合适时间，因为不会直接影响系统和托管，而且 BCDR 情况的触发高度依赖于适当人员的可用和可访问。

- A 是错误的，因为自然灾害是 BCDR 策略的主要考虑因素，可能是影响整个数据中心的广泛事件。

- B 是错误的，因为公用事业停电是 BCDR 策略的主要考虑因素，可能是影响整个数据中心的广泛事件。

- D 是错误的，因为恐怖攻击是 BCDR 策略的主要考虑因素，可能是影响整个数据中心的广泛事件。

16. 哪种类型的系统暴露在公共网上，但为了维护安全，仅执行特定功能，并针对该功能设有安全控制和监控？

- A. 蜜罐（Honeypot）
- B. 堡机（Bastion）
- C. WAF（Web 应用防火墙）
- D. VPN（虚拟专用网络）

- B. 堡机（Bastion host）是完全暴露在公共网上服务器；它经过极端加固以防止攻击，并且通常只针对一个应用程序或用途。这种单一的关注允许进行更严格的安全加固和监控。

- A 是错误的，因为蜜罐被设计成类似于带有生产数据的生产系统，以诱捕攻击者并监控他们尝试破解的方法。这些知识可以用于增强或更改安全控制，以应对系统或应用程序面临的真实威胁。

- C 是错误的，因为 Web 应用防火墙（WAF）设计用于根据内容过滤入站 Web 流量并处理，然后可能对其采取额外的安全措施、拒绝、过滤或许多可以在到达应用程序服务器之前卸载并完成的其他操作。
