# 系列前言

MIT出版社基础知识系列丛书提供通俗易懂、简明扼要、制作精良的口袋书，涵盖当前热门话题。由领军思想家撰写，该系列书籍对从文化、历史到科学、技术等学科提供专家级的概览。

在当今即时获取信息即时满足的时代，我们轻而易举就能获得观点、合理化解释和肤浅的描述。真正难得的是能够奠定对世界原则性理解基础的根本知识。基础知识系列丛书填补了这一需求。通过为非专业人士综合专业主题，并以基础理论探讨关键议题，每一本小册子都为读者理解复杂思想提供了切入点。

# 前言

2023年春天，当我们正在完成您正在阅读的这本书时，亚得里亚海沿岸、黑山蒂瓦特附近的一个度假村里发生了一场非凡的聚会。包括我们两位在内的几百人聚集在Zuzalu，这是一个由以太坊区块链的远见卓识的创始人Vitalik Buterin等人发起的“快闪城市”。来自各行各业的人们——区块链工程师和计算机科学家、艺术家和哲学家、企业家和律师等等——聚集在一起，讨论从人工智能到人类长寿以及民族国家未来等各种话题。

Zuzalu汇聚了多种意识形态和利益诉求。一些居民致力于建立超越任何国家法律管辖权的区域，以便测试延缓衰老疗法。对他们而言，Zuzalu是“网络国家”这一概念的一种初步显现，该概念由硅谷科技企业家Balaji Srinivasan提出，设想分散的人群和资本网络最终获得主权实体的认可。网络国家的理念建立在有着悠久历史的自由意志主义愿景之上。这从安·兰德的《阿特拉斯耸耸肩》中隐秘的“高尔奇峡谷”——一个在无效政府倒台中幸存下来的飞地——到彼得·蒂尔所设想的公海上的海上平台，据称能让人类逃离政治、为资本主义和自由寻找安全空间。然而，对许多其他居民来说，Zuzalu的吸引力在于它提供了一个机会，让人们在现有民族国家内构想后资本主义的未来，并开发用于社会变革的新工具和实践。从这个意义上说，它的精神更接近Calafou，这是一个位于加泰罗尼亚的自我管理的生态工业社区，Buterin在起草以太坊白皮书前几个月曾在此逗留。

Zuzalu居民的共同兴趣在于：世界既有的制度，以及我们目前所知的治理方式，并非我们治理社会的唯一工具。我们不必做拥有明确领土、以及传统公民身份所包含的权利和义务的民族国家公民。相反，我们可以在“数字部落”和“网络群岛”之间穿梭，它们可能存在于任何地方、任何时间。我们将拥有多重公民身份，属于多个网络，所有这些都基于我们的个人兴趣，这些兴趣有时汇聚、有时分歧。对一些人来说，网络国家许诺了一个重来的机会，一个拆解构成现代国家特征的法规、繁文缛节和官僚主义、并将社会重建为人类自主、政治自由和经济自由堡垒的机会。对另一些人来说，网络国家是一个流行词，被用来推销从中美洲到南太平洋的狂野殖民事业，这些事业在没有民主监督的情况下运作，威胁来之不易的法定保护，并使当地社区和机构面临风险。以这种方式，一些人试图将波多黎各变成加密货币避税天堂和新技术实验的试验场，同时吸食当地民众的血汗。

相比之下，其他愿景并不将*退出*视为全球治理的核心组织原则，而是视*相互依存*为核心。在我们两人于Zuzalu召集的会议中，我们讨论了“协调国家”和“新型网络主权”的理念，这些理念可以利用区块链和其他技术（例如用于身份管理），但主要旨在通过培育共同价值观、参与式治理和资源互助，促进地方和全球层面的人类合作。协调国家不是将公共品私有化或蚕食国家主权，而是与国家共存，满足国家无法满足的需求。无论您对这一主题持何种观点，对我们而言，Zuzalu宛如古希腊的阿哥拉广场，一个人们可以通过协商和争辩自由交换乌托邦理想的场所。
