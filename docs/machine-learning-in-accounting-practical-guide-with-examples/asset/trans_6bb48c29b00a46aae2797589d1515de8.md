
### 5. 使用适当参数的提升算法，如 `XGBoost` 或 `LightGBM`。

### 6. 调整决策阈值：
相比使用二元分类的默认 `0.5` 阈值，应根据 `precision` 与 `recall` 在你的欺诈检测场景中的相对重要性来调整它。

### 7. 使用合适的评估指标：
不要仅依赖 `accuracy`。使用 `precision`、`recall`、`F1-score` 以及 ROC 曲线下面积（`AUC-ROC`）等更适合不平衡数据集的指标。

## 实用提示
在处理欺诈检测中的不平衡数据集时，请考虑业务背景。假阳性（将合法交易标记为欺诈）可能在客户满意度方面造成成本，而假阴性（遗漏欺诈交易）可能在财务损失方面造成成本。根据在特定情况下哪种类型的错误更可容忍来调整你的方法。

# 第 3 章：欺诈检测与风险评估

## 3.1 用于识别欺诈交易的机器学习技术
欺诈检测是机器学习在会计中最具影响力的应用之一。传统的基于规则的欺诈检测系统越来越多地被能够适应新欺诈模式并处理复杂高维数据的机器学习模型补充或取代。以下是欺诈检测中使用的一些关键机器学习技术：

### 1. 监督学习方法：
* `Logistic Regression`：尽管简单，逻辑回归在欺诈检测中可能很有效，尤其是在可解释性很重要时。
* `Decision Trees` 和 `Random Forests`：这些可以捕捉特征之间的非线性关系和交互作用，使其在欺诈检测中非常强大。
* `Gradient Boosting Machines`（例如 `XGBoost`、`LightGBM`）：这些在欺诈检测任务上通常能达到最先进的性能。
* `Neural Networks`：深度学习模型可以捕捉复杂模式，但可能更难解释。

### 2. 无监督学习方法：
* `Isolation Forests`：特别擅长在高维空间中检测异常。
* `One-Class SVM`：可以学习正常交易的边界，将落在其外的交易标记为潜在欺诈。
* `Autoencoders`：基于神经网络的方法，通过比较输入与重构输出来检测异常。

### 3. 网络分析：
* 基于图的方法可用于检测涉及多个实体的复杂欺诈方案。

### 4. 集成方法：
* 结合多个模型通常能带来更好的性能和鲁棒性。

## 3.2 构建和训练欺诈检测模型
构建有效的欺诈检测模型涉及多个步骤：

### 1. 数据收集与准备：
* 收集历史交易数据，包括欺诈和合法交易。
* 如第 2 章所述清洗和预处理数据。
* 创建相关特征，包括领域特定的特征，如速度检查（例如，过去一小时内的交易数量）。

### 2. 特征选择：
* 使用相关性分析、互信息或递归特征消除等技术来选择最相关的特征。

### 3. 模型选择：
* 根据你的数据特征和需求（例如，可解释性与原始性能）选择模型或模型集成。

### 4. 训练与验证：
* 将你的数据拆分为 `training`、`validation` 和 `test` 集合。
* 使用 `cross-validation` 以确保稳健的性能估计。
* 对于不平衡数据集，考虑使用 `stratified sampling` 以保持类别比例。

### 5. 模型调优：
* 使用 `grid search` 或 `Bayesian optimization` 等技术来找到最佳超参数。

### 6. 评估：
* 使用适合不平衡数据集的指标（例如 `precision`、`recall`、`F1-score`、`AUC-ROC`）。
* 考虑假阳性与假阴性的业务影响。

### 7. 可解释性：
* 使用 `SHAP`（`SHapley Additive exPlanations`）值等技术来了解哪些特征驱动着模型的决策。

### 8. 监控与更新：
* 实施系统以随时间监控模型的性能。
* 定期重新训练模型以适应新的欺诈模式。

## 3.3 案例研究：在中型会计师事务所实施欺诈检测系统
让我们考虑一个假设的案例研究：一家中型会计师事务所为其客户——一家区域零售连锁店实施欺诈检测系统。

背景：该零售连锁店每天在多个门店和电子商务平台上处理数千笔交易。他们经历了多次欺诈事件，包括员工盗窃、退货欺诈和信用卡欺诈。

方法：
1. 数据收集：该事务所收集了两年的交易数据，包括 `POS` 数据、员工日志和客户信息。他们根据之前的调查对已知的欺诈交易进行了标记。
2. 特征工程：他们创建了包括以下内容的特征：
   * 相对于该产品类别平均值的交易金额
   * 每个客户上次交易以来的时间
   * 员工销售额相对于其历史平均值
   * 速度检查（例如，每张信用卡每小时的交易数量）
3. 模型选择：他们决定使用集成方法，结合：
   * 一个 `random forest`，因其捕捉非线性关系的能力
   * 一个 `isolation forest` 用于异常检测
   * 一个 `gradient boosting machine`（`XGBoost`），因其在不平衡数据集上的高性能
4. 训练与调优：他们使用分层 `5-fold` 交叉验证来调优超参数，优化精度-召回曲线下面积。
5. 评估：最终模型实现了：
   * `Precision`：`0.82`（82% 的被标记交易确实是欺诈）
   * `Recall`：`0.75`（75% 的所有欺诈交易被捕获）
   * `F1-Score`：`0.78`
6. 实施：他们部署模型以近实时评分交易，将高风险交易标记为立即审查。
7. 监控：他们设置了一个仪表板以随时间跟踪模型的性能，包括假阳性率和欺诈分数的分布。

结果：在实施后的前六个月，系统：
* 检测到 27 起由之前的基于规则的系统遗漏的欺诈案件
* 相比旧系统，假阳性减少了 60%
* 节省了估计 $150,000 的防止欺诈损失

经验教训：
* 集成方法比任何单一模型更稳健
* 定期重新训练（本例中为每月）对保持性能至关重要
