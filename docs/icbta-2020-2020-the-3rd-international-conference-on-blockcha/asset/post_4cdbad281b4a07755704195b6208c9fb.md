## 4.2 Network Layer

The network layer realizes P2P network. This provides the basic ability to build up block chain network at the bottom, including node, sequencer, client, CA and gossip.

## 4.3 Block Chain Service Core Layer

Kubernetes and Fabric compose the core layer of railway block chain. Kubernetes framework is adopted to realize members joining dynamically, elastic contraction and flexible deployment. The core layer of block chain provides the bottom infrastructure, including member services, security and privacy protection, block chain services, smart contract services and cross chain services.

## 4.4 Business Processor

The service processor includes gRPC, data encryption, message sending and interface adaptation. The gRPC refers to establish a link with the block chain to complete user authentication, data security verification and data integrity verification. That supports the data transaction and query of the block chain. Data encryption refers to calling encrypt service (optional) or software to realize encryption and decryption function. Message sending and receiving uses message interface protocol to encapsulate the written message by HTTP. This function ensures the message visible between the sender and the receiver. Interface adaptation provides Rest WebService interface adaptation service.

## 4.5 Interface Layer

The railway block chain service platform provides users various interfaces, like SDK, API and CLI.

## 4.6 Block Chain Management Layer

The management layer adopts the micro-service framework Spring Cloud / Spring Boot for development. The management layer mainly includes node management, member management, block chain service management, block chain status monitoring management, account book browsing, warning management, contract management, user management, log management, role management and audit management.

# 5 OVERALL SCHEME FOR RAILWAY BLOCK CHAIN SERVICE PLATFORM

The railway block chain service platform relies on the main data center of China Railway. The platform provides users with one-stop, high security, simple and easy-to-use block chain services. The railway block chain service platform integrates development, management, operation and maintenance, which supports users to quickly deploy alliance block chain network environment on the cloud. Based on the railway block chain service platform, users can reduce the acquisition cost of the bottom technology. That makes them more focused on the development and operation of block chain business model innovation and business application.

In design, the railway block chain service platform meets the security and compliance requirements of financial level. The platform can adjust the business resource dynamically. Users can quickly build block chain services on an elastic and open cloud platform. The railway block chain service platform can be quickly compatible with many bottom block chain technologies, including Hyperledger Fabric, Ethereum, BCOS, etc. The platform will provide users with many optional bottom technology frameworks.

# 6 APPLICATION AND IMPLEMENTATION PATH FOR RAILWAY BLOCK CHAIN SERVICE PLATFORM

The application and implementation of the railway block chain service platform should be set up by three stages. The unified path will promote the railway block chain service platform to the implement orderly.

## 6.1 Experiment Stage (2020~2022)

According to China Railway Information Planning, we should plan the railway block chain service platform uniformly, including the overall architecture, application architecture and technical standards. The application pilot of block chain is carried out from the trusted data exchange & sharing and China-EU train logistics tracking and financial services based on the block chain.

## 6.2 Promotion Stage (2023~2024)

In the application and promotion stage of block chain, multi fields and business will integrated the block chain deeply. The converged application of block chain will promote the application implementation, such as multimodal transport, railway credit investigation and freight logistics. China Railway will open up the collaborative chain with upstream and downstream enterprises to create an ecological chain of railway industry.

## 6.3 Deepening Stage (2025~2030)

Considering the continuous development of block chain in the future, railway block chain will break through the key problems, like compatibility, performance, security and legal supervision. The railway block chain service platform aims to prosper the railway ecosystem. The block chain application will develop from single application to upstream application of industrial chain, from peer application to application of different industry alliance, to further prosper the industry ecosystem.

# 7 CONCLUSION

Combining block chain and railway business can effectively solve the problems of sharing railway big data and the common problems of railway freight transportation business in the Belt and Road. The railway block chain service platform can improve the connotation of railway integrated information integration platform. At the same time, that can provide the bottom technical support and quick service response for railway block chain application. The RBaaS will benefit the multi chain integration from different fields, different industries and different subjects and improve the China Railway technology level.
