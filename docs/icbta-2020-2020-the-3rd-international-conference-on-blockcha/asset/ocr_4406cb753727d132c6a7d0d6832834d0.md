# 4 TECHNICAL ARCHITECTURE FOR RAILWAY BLOCK CHAIN SERVICE PLATFORM

The technical architecture of railway block chain service platform contains storage layer, network layer, block chain service core layer, business processor, interface layer and block chain management layer, as shown in Figure 3

# 4.1 Storage Layer

The storage layer applies virtualization technology to set up docker clusters with high scalability and reliability on the cloud. That is suitable for different types of block chain platform layer nodes. Distributed ledger status data applies Rocks DB, CouchDB, Level DB and MySQL. Distributed ledger transaction data applies HDFS, GFS and TFS.
