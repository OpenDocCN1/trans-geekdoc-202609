# ## 4.2 Network Layer

The network layer realizes P2P network. This provides the basic ability to build up block chain network at the bottom, including node, sequencer, client, CA and gossip.

# ## 4.3 Block Cain Service Core Layer

Kubernetes and Fabric compose the core layer of railway block chain. Kubernetes framework is adopted to realize members joining dynamically, elastic contraction and flexible deployment. The core layer of block chain provides the bottom infrastructure, including member services, security and privacy protection, block chain services, smart contract services and cross chain services.

# ## 4.4 Business Processor

The service processor includes gRPC, data encryption, message sending and interface adaptation. The gRPC refers to establish a link with the block chain to complete user authentication, data security verification and data integrity verification. That supports the data transaction and query of the block chain. Data encryption refers to calling encrypt service (optional) or software to realize encryption and decryption function. Message sending and receiving uses message interface protocol to encapsulate the written message by HTTP. This function ensures the message visible between the receiver and the receiver. Interface adaptation provides Rest WebService interface adaptation service.

# ## 4.5 Interface Layer

The railway block chain service platform provides users various interfaces, like SDK, API and CLI.

# ## 4.6 Block Chain Management Layer

The management layer adopts the micro-service framework Spring Cloud / Spring Boot for development. The management layer mainly includes node management, member management, block chain service management, block chain status monitoring management, account book browsing, warning management, contract management, user management, log management, role management and audit management.

# ## 5 OVERALL SCHEME FOR RAILWAY BLOCK CHAIN SERVICE PLATFORM

The railway block chain service platform relies on the main data center of China Railway. The platform provides users with one-stop, high security, simple and easy-to-use block chain services. The railway block chain service platform integrates development, management, operation and maintenance, which supports users to quickly deploy alliance block chain network environment on the cloud. Based on the railway block chain service platform, users can reduce the acquisition cost of the bottom technology. That makes them more focused on the development and operation of block chain business model innovation and business application.

In design, the railway block chain service platform meets the security and compliance requirements of financial level. The platform can adjust the business resource dynamically. Users can quickly build block chain services on an elastic and open cloud platform. The railway block chain service platform can be quickly compatible with many bottom block chain technologies, including Hyperledger Fabric, Ethereum, BCOS, etc. The platform will provide users with many optional bottom technology frameworks.
