You can see a history of when this website was archived, and pull up previous versions of the website. In many cases this will provide useful information about the target network. This site is useful, but is probably one of the less useful sources of information for a penetration tester. It can give you a history of information for that website, but it cannot provide you with current vulnerabilities.

# Shodan

This may be the single most important tool we discuss in this chapter. The website https://www.shodan.io/ is essentially a search engine for vulnerabilities. You need to sign up for a free account to use it, but then it can be invaluable to a pen tester trying to identify vulnerabilities. You can also be sure that attackers use this site as well.
