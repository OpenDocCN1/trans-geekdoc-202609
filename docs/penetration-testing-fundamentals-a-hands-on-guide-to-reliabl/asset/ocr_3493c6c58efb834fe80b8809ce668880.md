# Hacking Wi-Fi Using Aircrack

The first step is to use CommView to scan for wireless access points. You can download this tool from http://www.tamos.com/download/main/ca.php. Figure 18-3 shows CommView.

![](bbox=[0.115, 0.198, 0.72, 0.515])

Now you select one of the wireless access points you wish to target. In Figure 18-4, we selected one running WEP. With WEP you have a high probability of success. With WPA or WPA2 you have a very low chance of succeeding with this method.
