# Summary

This chapter introduced the basics of how websites work, various web hacking techniques, and some tools to help you with penetration testing of a website. In Chapter 8 you will be introduced to vulnerability scanners, then Chapter 13 introduces Metasploit. The primary goals of this chapter are that you understand common web attacks, and that you have at least some knowledge of some basic techniques and tools.
