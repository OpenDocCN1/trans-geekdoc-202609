# PEARSON IT CYBERSECURITY CURRICULUM (ITCC)
AT-A-GLANCE

Pearson's IT Cybersecurity Curriculum (ITCC) series is a turn-key curriculum solution for two- or four-year degree or certificate programs. Designed to support the critical need for workforce development in cybersecurity, Pearson ITCC provides multi-modal, real-world focused, hands-on courseware that can be used as a complete program or individual courses that can be chosen ad hoc to fill in your program to fit your student profile, workforce needs, and school requirements and articulation agreements. The program emphasizes applied, hands-on learning and validation through certifications set by industry organizations like EC Council, CompTIA, and Cisco.
