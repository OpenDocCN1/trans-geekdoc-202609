# Wireshark

This tool is not really a port scanner or a network enumeration tool. It is one of the most widely known network packet sniffers. Often a penetration tester can learn a great deal from simply sniffing the network traffic on a target network. Wireshark provides a convenient GUI for examining network traffic. It is a free download you can get at https://www.wireshark.org/. Figure 14-13 shows the main interface.
