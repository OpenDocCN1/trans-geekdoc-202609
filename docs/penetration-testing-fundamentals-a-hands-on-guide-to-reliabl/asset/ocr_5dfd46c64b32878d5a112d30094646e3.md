# Using Kali as a Hotspot

By now you should be aware that Kali is replete with various tools that will be useful to you as a penetration tester. One of these tools is wifi-honey. It is a shell tool, but is very easy to use. Before we use it, we have to find out what wireless adapters we have. There are several commands that will do that, including:

```
netstat -i
ifconfig -a
```
