+   - **-g:** initial_group. This option assigns a group name or number as the user’s initial login group. This must be an already existing group; you cannot create the group as you add the user.
+   - **-G:** Group. A list of groups which the user is also a member of. Each group is separated from the next by a comma, with no intervening whitespace.
+   - **-l:** login_name. This changes the user’s login name.
+   - **-p:** Password. This sets the user’s encrypted password, as returned by **crypt(3)**.
+   - **-s:** Shell. With this option you can set the user’s default shell. Setting this field to blank causes the system to select the default login shell.
+   - **-u:** user ID: This option is used to set the user ID.
+   - **-L:** This option is used to lock the user’s password. You can’t use this option with **-p** or **-U**.
+   - **-U:** This is used to unlock a user’s password. You can’t use this option with **-p** or **-L**.
