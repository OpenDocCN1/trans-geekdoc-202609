In this chapter, we will explore Kali Linux. The Kali Linux distribution is meant specifically for hacking, forensics, and cyber security. It is simply full of tools that can be used for penetration testing. You should be aware, however, that new releases sometimes change the toolset included. Some tools might be added or removed.

# Kali Linux History

Kali Linux is based on the Debian Linux distribution. Kali is maintained by Offensive Security, the vendors who also provide the Offensive Security Certified Professional (OSCP) certification test. While there are tools that come and go, some like nmap, Wireshark, Metasploit, and Burp suite are always included.

Kali is the successor to BackTrack Linux. That distribution was based on Knoppix Linux and also included a wide range of pen testing related tools.
