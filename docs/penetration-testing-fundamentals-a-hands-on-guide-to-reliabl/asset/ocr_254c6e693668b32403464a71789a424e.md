There are several items in this basic script that need to be understood. While this is a very elementary script, if you fully understand it, you will be on your way to understanding basic Ruby scripting.

Let us begin by examining the variable declarations:

```
anumber = 0
```

Notice we did not use the symbols previously discussed. That is because this very simple program has no classes or functions, so there are not different types of variables (instance, local, class, etc.).

Next you see we use the puts statement to prompt the user:

```
puts 'enter a number to cube'
```

But now you see something new—how to get the input from the user and place that in a variable:

```
anumber = gets.to_i
```

If this had been a string, we would just have wrote gets. But because we are looking for an integer, it is gets.to_i (convert to integer).
