+   - **-s, --short:** This option will display only name, line, and time (default).
+   - **-t, --time:** This option displays the last system clock change.
+   - **-T, -w, --mesg:** This option will add the user's message status as +, -, or ?.
+   - **-u, --users:** This option will list users logged in.
+   - **--message:** This is the same as **-T**.
+   - **--writable:** This is also the same as **-T**.
+   - **--help:** This will display the help.
+   - **--version:** This will display version information and exits.
