# Summary

Cryptography is a complex topic, and a penetration tester need not be a cryptographer or cryptanalyst. However, a basic working knowledge of cryptography is useful for a penetration tester. It is unlikely that you will have any success “cracking” modern encryption. However, you may find various methods for circumventing encryption to be useful. Password retrieval is also a task every penetration test should include.
