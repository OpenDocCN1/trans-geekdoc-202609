# net view

The **net view** command is one of my personal favorites. It shows the networked items this computer can communicate with. If you have gained access to one machine, this command is invaluable in enumerating the network. You can see **net view** in Figure 6-5.

![](bbox=[0.07, 0.55, 0.62, 0.72])
