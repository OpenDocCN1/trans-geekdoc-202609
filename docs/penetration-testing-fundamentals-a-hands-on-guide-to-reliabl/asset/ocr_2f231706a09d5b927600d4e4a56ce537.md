# Basic File and Directory Commands

Basic directory and file commands will be useful to you. The most basic are covered here. To create a directory, you use the mkdir command followed by the directory name, such as

```
mkdir testdir
```

To delete a file, you use the rm command, as shown here:

```
rm txt
```

To move a file, you use the mv command with the filename and destination, like this:

```
mv testfile.txt testdir
```

To delete a directory, it must be empty first, then use rmdir:

```
rmdir testdir
```
