# PROJECT 3

Use nmap to port scan a computer. While port scanning is not illegal, you should select a lab computer that you have permission to scan. You may use the command line nmap or the GUI Zenmap. Use at least the following flags:

+   1. Set the timing to T5, then repeat with timing T1.
+   2. Try **-sO** Protocol Scan.
+   3. Try **-sW** Windows Scan.
+   4. Try each of the following:
+      a. **nmap -sS** *targetsite*
+      b. **nmap -sO** *targetsite*
+      c. **nmap -sO -sS -oX -T4** *targetsite*
