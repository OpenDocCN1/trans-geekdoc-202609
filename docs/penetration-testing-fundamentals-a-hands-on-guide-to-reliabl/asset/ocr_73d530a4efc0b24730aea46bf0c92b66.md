# Passive Scanning Techniques

Passive reconnaissance is the process of gathering information about a target network without actually connecting to the network. More skillful attackers will always start with passive reconnaissance, and so should penetration testers. In this section, we will examine some tools and techniques for performing passive reconnaissance. The concept is to gather information on a target website without actually connecting to that website. That way there is no chance of triggering an intrusion detection system, or leaving a trace in the log files of the target system.

# Netcraft

It is often useful to understand as much about a target website as you possibly can before connecting to that website. Penetration tests often involve testing web servers. So, a good first step is to learn all you can about the target web server. The site netcraft.com can be very useful in this regard. You can see the main page of netcraft.com in Figure 4-1.
