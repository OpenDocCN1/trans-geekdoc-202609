In Ethereum, the contract data are stored as key-value pairs and they are organized in a more advanced Merkle Patricia tree than the plain balanced binary Merkle tree. A Merkle Patricia tree allows the insertion and deletion operations efficiently. The root of the tree is included in the block header.
