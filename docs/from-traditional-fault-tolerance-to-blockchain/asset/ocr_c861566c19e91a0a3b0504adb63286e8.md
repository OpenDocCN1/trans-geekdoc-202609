The aggregator would create a transaction including a signed tuple with the aggregated value and the Merkle root corresponding to the set of samples < S, R >σ (where σ is the digital signature), and sends the transaction to the blockchain network. After a little while, the transaction will be included in a new block and placed on the blockchain. Furthermore, to facilitate searching for raw data based on the aggregated data, and vice versa, the set of raw data and the corresponding aggregated data tuple are logged sequentially together, i.e., the aggregated data would be logged right after the set of raw data, as shown in Figure 10.10. For instance, the data in the example would be logged on the disk as d1, d2, d3, d4, d5, d6, d7, d8, < S, R >σ.
