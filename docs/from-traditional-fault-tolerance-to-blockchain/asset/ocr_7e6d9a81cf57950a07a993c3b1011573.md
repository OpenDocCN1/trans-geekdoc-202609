The primary then transfers the ordering information to the backups so that they deliver the requests in the same order and carry out the nondeterministic operations in the same order as that in the primary. Note that in semi-active replication, all replicas deliver and execute the requests. To tolerate fail-stop faults only, it is more efficient to disable the sending of replies from the backups (so that such messages do not compete against network and processing resources).
