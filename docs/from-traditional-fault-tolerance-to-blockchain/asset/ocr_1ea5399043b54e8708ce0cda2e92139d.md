# 8.2.1 Decentralized network and architecture

Bitcoin operates on a peer-to-peer network, that is, the system does not rely on any centralized server for processing or data storage, nor does it rely on any trusted third party, such as a timestamp server or a public registry as mentioned in earlier work prior to Bitcoin, not even the public-key infrastructure, which is often needed for public-key distribution.
