# Creating a Tensor Filled with Zeros:

```
zero_tensor = torch.zeros(3, 2)
```

```
print(zero_tensor)
```

This will create a tensor of shape 3x2 filled with zeros.
The output will be:

```
tensor([[0., 0.],
    [0., 0.],
    [0., 0.]])
```
