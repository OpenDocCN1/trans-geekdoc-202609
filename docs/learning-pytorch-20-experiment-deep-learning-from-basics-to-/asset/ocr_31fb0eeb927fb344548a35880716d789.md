# Stacking Sequence of Tensors

The stack() function is used to concatenate a sequence of tensors along a new dimension. All tensors need to be of the same size.

```
# Create two tensors
```

```
tensor1 = torch.tensor([1, 2, 3])
```

```
tensor2 = torch.tensor([4, 5, 6])
```

```
# Stack the tensors
```

```
stacked_tensor = torch.stack((tensor1, tensor2))
```

```
print("\nStacked Tensor:")
```

```
print(stacked_tensor)
```
