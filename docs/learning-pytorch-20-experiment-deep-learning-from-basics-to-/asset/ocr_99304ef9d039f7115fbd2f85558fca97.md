The following is how you define the MSE loss function and the Adam optimizer in PyTorch:

```
# Define the loss function and the optimizer

criterion = nn.MSELoss()

optimizer = torch.optim.Adam(model.parameters(),
lr=0.001)
```

The nn.MSELoss() function creates a criterion that measures the mean squared error between each element in the input x and target y.

The torch.optim.Adam() function creates an Adam optimizer. We pass the parameters of our model to this function so the optimizer knows which tensors it should update. The learning rate lr specifies the speed at which our optimizer should update the model's parameters.
