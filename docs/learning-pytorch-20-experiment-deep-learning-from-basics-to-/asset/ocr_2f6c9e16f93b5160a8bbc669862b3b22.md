# Selecting Specific Indices

For more complex selection, you can use the index_select() method to select data by specific indices:

```
# Create an index tensor

indices = torch.tensor([0, 2])

# Select rows at indices 0 and 2

selected_rows = tensor.index_select(0, indices)

print("\nSelected Rows at Indices 0 and 2:")

print(selected_rows)
```
