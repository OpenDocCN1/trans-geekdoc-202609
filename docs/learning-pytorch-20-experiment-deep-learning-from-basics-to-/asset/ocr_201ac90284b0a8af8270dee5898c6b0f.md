# Viewing Tensor Dimensions

The view() function is similar to reshape(), but it operates as an in-place operation, and it can infer the size of a dimension by using -1. If the tensor is not contiguous, you may have to use reshape() or call contiguous() before using view().

```
# View the tensor

viewed_tensor = tensor.view(2, 4)

print("\nViewed Tensor:")

print(viewed_tensor)
```

Viewed Tensor:

tensor([[1, 2, 3, 4],
