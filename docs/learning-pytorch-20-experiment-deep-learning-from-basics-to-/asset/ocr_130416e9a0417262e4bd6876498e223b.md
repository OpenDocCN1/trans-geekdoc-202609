# Evaluation

Following the completion of the training phase, you will need to assess how well your model performs on data that it has not previously seen (your test set). You will get a sense from this of how effectively your model generalizes to new data if you do this. It is essential to keep in mind that the performance of the model while it is being trained is not always indicative of how well it will perform on data it has not previously seen.

# Model Saving and Loading

Once you are satisfied with the performance of your model, you will be able to save the parameters of the model to a file. Because of this, you will no longer need to retrain the model in order to generate predictions after loading these parameters later on.
