# Save the Model

Once you are satisfied with your model's performance, you'll want to save it so you can reuse it later. In PyTorch, you typically save and load only the model parameters, not entire models, as it's more portable.

To save your model parameters, you can use torch.save:

```
# Save the model parameters

torch.save(model.state_dict(), 'fish_weight_model.pt')
```

In this code, model.state_dict() returns an OrderedDict holding the model's parameters (and gradients), and 'fish_weight_model.pt' is the file name.
