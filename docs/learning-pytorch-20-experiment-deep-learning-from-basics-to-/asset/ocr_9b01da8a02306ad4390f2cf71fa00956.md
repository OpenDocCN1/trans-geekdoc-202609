# Aggregation Operations

Aggregation operations in PyTorch are those that reduce the number of elements contained within a tensor.
These include operations like finding the sum, mean, maximum, or minimum of the elements.

We will create a tensor and perform various aggregation operations:

```
# Import PyTorch

import torch

# Create a tensor

tensor = torch.tensor([[1, 2, 3], [4, 5, 6]],
dtype=torch.float32)

print("Tensor:")

print(tensor)
```
