# 332 Part IV: Not So Simple Applications

Once the problem is entered, it should be tracked by the staff. Each action in the attempt to solve the problem should be noted. And the tracking should have a public and private realm—actions that you want the user to see should be differentiated from those you do not want the user to see.

Those with issues should be able to keep track of their problems in two ways. They should be e-mailed whenever an update is made to their case that should be publicly viewable,and it should without saying—a Web page detailing the problem should be available.
