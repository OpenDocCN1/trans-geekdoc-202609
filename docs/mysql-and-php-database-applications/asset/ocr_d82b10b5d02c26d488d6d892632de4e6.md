# TABLE_ROW() This function not prints the opening <tr> tag and attributes; it also prints the table cells that will be nested within the <tr> tags.

```
function table_row () {
  $astlist = "";
  $cellstring = "";
  $cells = func_get_args();
  while (list($cell) = each($cells)) {
    if (is_array($cell)) {
      $astlist .= get_astlist($cell);
    } else {
      if (!eregi("td",$cell)) {
        $cell = table_cell($cell);
        $cellstring .= ".trim($cell)."\n";
      }
    }
  }
  $output = <<<EOQ
<tr>$astlist>
$cellstring
</tr>
EOQ:
  return $output;
}
```

This function works by taking nested function calls.
