However, using MySQL grants we're taking another step. MySQL grants won't allow us to say "grant authority to user on stories table stage_id=4". Instead we create an additional table named format_review_stories. Rights to this table will be granted to only those who need format review capability. As a story makes, its way through the editorial process, the story_id will be copied to the appropriate stage. When it reaches format_review_stories, the story_id will be copied to the format_review_stories table. Because we can enforce grants on a table, we know that unauthorized users will not be able to access the format_review_stories table. If an unauthorized user tries to update the format_review_stories table, the query will be refused.

This is hardly ideal. In fact, it's pretty silly. If we were to deploy this application in the real world it is doubtful that we'd actually try to make this work with grant statements. We'd probably just make sure the user had no direct access to the database whatsoever use the user_stage_map table to make sure the users are properly restricted. However we thought it would be useful to show an example of how to work with MySQL grants from a PHP interface.
