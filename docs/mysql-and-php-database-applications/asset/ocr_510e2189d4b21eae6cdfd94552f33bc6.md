# Objects in practice

So far in this book you have seen variables of all shapes and sizes. There have been strings, integers, arrays, associative arrays, and all kinds of fun stuff. However, our variables are going to be a bit more complex. Take a look at these two lines, which we have already explained:

```
$c = new Category;
$c -> LoadCategory($category_id);
```
