# # Using Built-In Variables

There are a variety of variables set by your server and PHP environment. You can find a complete list of these by running phpinfo(). If you haven't done it yet, run to your keyboard, type in the following, and then run the following script:

```
<?php
phpinfo();
?>
```

It will deliver a page that looks like what you see in Figure 4–3.

![](bbox=[0.181, 0.337, 0.758, 0.695])

Figure 4-3: phpinfo();

It's a good idea to delete this page when you're done with it. No need to give crackers any more than absolutely necessary.
You can use this variety of variables in a variety of ways. We'll take a look at some of these now, and show when and when you use them. Some variables come from the PHP engine, others originate from your Web server.
