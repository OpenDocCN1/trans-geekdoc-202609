# Introduction

The query asks MySQL for every row in the database. Then the script enters a loop. Each row in the database is loaded into the variable $row, one row at a time. Rows will continue to be accessed until none is left. At that time, the script will drop out of the while loop.

As it works through the loop, each column in that row is displayed. For example

```
print $row["email"]
```

print it out the e-column for the row being accessed.
When run, this script will print every row in the database. Figure I-4 shows what the page will look like.
