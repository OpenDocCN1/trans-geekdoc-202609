If either of the arguments in the call to this function is not an integer, the function will return FALSE. A call to this improved function might look like this:

```
if(!($added_value = basic_math(7, 5))) {
    echo "What exactly are you doing?";
} else {
    echo $added_value;
}
```

If the function returns a value (any value), that value will be the behavior of many of the PHP built-in functions. If not, a special message will be printed. Notice how this mimics yours. Its purpose is to perform a task, and if it fails to do, it returns false.

Actually, there's something else that needs to be pointed out in this function. What will happen if the sum of the arguments to the function equals zero, so -1 and 1. In a case like this, your function will return 0. And, as we discussed in Chapter 5, 0 is FALSE in PHP. So you need to be careful about situations. You may run into situations with some of PHP's string handling functions, strpos(), for example. You might be better off evaluating a call to the previous function:

```
if (!is_$added_value = basic_math(-1,1)))
```
