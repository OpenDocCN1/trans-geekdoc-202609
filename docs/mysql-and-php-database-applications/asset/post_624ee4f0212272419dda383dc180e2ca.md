# Determining the Scope and Goals of the Application

A survey application could be ultra-simple. If you wanted only to gather responses from a single question and return basic statistical information on the responses (how many votes for choice A, B, and so on), you wouldn't need a whole lot of code (or a chapter explaining it). A single table that stored answers would do the trick. The question could be hard-coded into the HTML. But that would not make for very interesting learning experience, would it?
Instead of just one, application will allow for two, ten, or more—whatever you want. Not only that, survey will record demographic information (such as age and country of origin) and allow for sorting on the basis of this information. We also decided to add the ability to pick a winner from those who filled out the personal information—this encourage people to give real rather than fictitious answers.
