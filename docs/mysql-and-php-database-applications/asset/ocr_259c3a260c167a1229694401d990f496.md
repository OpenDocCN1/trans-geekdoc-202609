This function is going to make sure that the information entered is moderately useful. If there are problems with the information, a text string describing the problem will be assigned to the variable $errmsg. If, after the function is executed, $errmsg is empty, the values will be inserted into the database. Otherwise the error message will be printed, and the values user entered will be assigned to globals so that they can be printed as the default values in the fields next time through. In order, this function checks for the following:

+   * The name field contains something
* The @mail address is potentially a proper address (contains text, and a period (,)) Note that this is not very strong validation of e-mail. It takes a very long and complicated script to thoroughly validate an e-mail, as you will see in later chapters.
* If the e-mail looks okay, that this e-mail address hasn't been entered in the database already
* The URL is potentially valid
