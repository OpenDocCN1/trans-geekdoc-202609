# Part V: Appendices

At this point the only place to find PEAR code is the /pear directory of your PHP installation. As the writing of this book, there were several components in PEAR, most of which were still undergoing quite a bit of work. There is a database abstraction layer, an XML processing class, and some code for directory searching. I suggest you browse the documentation in your own installation, and every now and then look in the latest go-ings at snaps.php.net.

# PHPClasses

A Portuguese programmer named Manual Lemos is among the most prolific PHP coders on the planet, and God bless him—he shares his code at http://phpclasses.uppedesign.com. In fact, PHPClasses is now a code repository for anyone who has classes to design with the PHP world. The following are of particular note:

+   * Processing Class provides a uniform method for creating and validating forms. It accounts for every type of validation imaginable.

+   * Metabase — This is a complete database abstraction layer.

+   * Mail Class. This class came to our attention late to include on the CD. Word is, this makes the sending of e-mail quite a bit easier.

# PHP base library

The PHP base library has a fairly large user base—and it's no wonder. It's a very nice set of tools that can easily add to your PHP system. Many originally used this library because it was the easiest way to use Sessions in PHP3. Now, I would recommend using PHP's built-in session functions. Even so, there are authorization routines, user administration functions, and a template that could save you some time.

# Binarycloud

The folks at Binarycloud are working on creating a common code base to help with rapid development of PHP applications. So (as of September 2000) there isn't a lot of code to review. But their documentation looks really promising. I'd recommend checking in on http://www.binarycloud.com to see what they're up to.
