If an integer argument N is specified, it is used as the seed value. You cant use a column with RAND() values in an 'order' by clause order would evaluate the column multiple times. In MySQL 3.23, you can, however, do: select * from table_name order rand(). This is useful to get a random sample. Note that RAND() in a WHERE clause will be re-evaluated every time the WHERE clause is executed.

# LEAST

With two or more arguments, this function returns the smallest (minimum-valued) argument.

```
LEAST(X,Y,....)
RETURNS: type of X
mys> select least(2,7,9,1)
+----------------+
| least(2,7,9,1) |
+----------------+
|                1 |
+----------------+
1 row in set (0.00 sec)
```

# GREATEST

GREATEST returns the largest (maximum-valued) argument. In MySQL versions prior to 3.22.5, you can use MAX() instead of GREATEST.

```
GREATEST(X,Y,....)
RETURNS: type of X
mys> select greatest(2,7,9,1)
+----------------+
| greatest(2,7,9,1) |
+----------------+
|                9 |
+----------------+
1 row in set (0.00 sec)
```
