## show columns/show fields

These commands, which are synonymous, are very handy if you can't remember the column types and attributes declared in your create statement. For example, let's say you created a table with the following command.

```sql
create table topics (
    topic_id integer not null auto_increment primary key,
    parent_id integer default 0 not null,
    root_id integer default 0,
    name varchar(255),
    description text null,
    create_dt timestamp,
    modify_dt timestamp,
    author varchar(255) null,
    author_host varchar(255) null,
    index my_index(parent_id)
);
```

### Basic select

When comes time to take the information from your database and lay it out on Web pages, you'll need to limit the information returned from tables to get proper information. You'll start with the data, and return a smaller set. This result has columns and rows and thus can be thought of as a table (or a two-dimensional array, if your mind works that way). This table doesn't actually exist in the database, but it helps to think about this way.

The basic select statement requires you to indicate the table you are selecting from and the column names. If you wish to select all the columns from a given table, you can substitute asterisk (*) for the names.

```sql
select column_1, column_2, column_3 from table_name
select * from table_name
```

Keep in mind that with a select statement you are not altering the tables in the query. You are simply retrieving information. From PHP, you will send the query to MySQL the mysql_query() function. There are all sorts of ways you can choose to lay out the information, but a simple HTML table with the column names put in a header row. The simple PHP code in Listing 3-1 will lay out any SQL query in a simple HTML table. It includes a simple format that will allow you to enter a query. If you don't understand this code, don't worry about it; all the PHP functions will be covered in Chapter 6. Alter the mysql_connect() and mysql_select_db() if you wish to change the database used.

Listing 3-1: PHP script that converts a SQL query to an HTML table

```php
if(!isset($query) || empty($query)) {
    $query = "select * from users";
    // stripslashes is necessary because the select statement is
    // coming from a form. In some systems, the magic_quotes
    // setting (see Appendix B) will prepend single quotes
    // with backslashes, which could be problematic.
    $query=stripslashes($query);
}

mysql_connect("username", "password", "") or die("Could not connect to database.");
mysql_select_db("test") or die("Cannot select database.");
$result = mysql_query($query) or die(mysql_error());
```

```php
$number_cols = mysql_num_fields($result);

echo "<b>query: $query</b>";
//layout table header
echo "<table border = 1\n";
echo "<tr align=center>\n";
```

```php
for ($i=0; $i<$number_cols; $i++) {
    echo "<th>" . mysql_field_name($result, $i) . "</th>\n";
}
echo "</tr>\n";//end table header
```

```php
//layout table body
while ($row = mysql_fetch_row($result)) {
    echo "<tr align=left\n";
    for ($i=0; $i<$number_cols; $i++) {
        echo "<td>";
        if (isset($row[$i])) //test for null value
            echo "NULL";
        else
            echo $row[$i];
        echo "</td>\n";
    }
    echo "</tr\n";
}
```
