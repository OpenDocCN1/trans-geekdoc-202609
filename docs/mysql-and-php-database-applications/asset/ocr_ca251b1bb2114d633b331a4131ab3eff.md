string ere_replace(string pattern, string replacement, string string)

If you want to delete the querystring from a URL, you could use this:

```
$url = "http://www.phpmysqlbook.com/index.php?var=hello"
$parsed_url = ere_replace("\.\*$", "\1",$url);
echo $parsed_url;
```

This would print http://www.phpmysqlbook.com/index.php. This regular expression matches a question mark, and all characters that occur it until the end of the line. The question mark must be escaped with a backslash because it has a specific meaning to the regular expression. Following the question mark match any number of characters until the dollar sign, which is the inline charac-. It needs to be escaped with a backslash without the backslash, PHP will think the character represents a variable.

But often you need a bit more functionality than this. If you want to preserve the string you are searching for in the replacement string? Or if your search contains distinct offsets set of parentheses? Here's a simple example. We want to replace the current queryst by adding an additional name=value pair between the two name=value pairs currently in the string. That is, we want to put "newvar-here" after "var=hello" and "var2=yup.

```
$url = "http://www.phpmysqlbook.com/index.php?var=hellovar2=yup"
$parsed_url = ere_replace("?..*$", "\1newvar-here&",$url);
echo $parsed_url;
```

This creates the following:

http://www.phpmysqlbook.com/index.php?var=hellonewvar-here&var2=yup
