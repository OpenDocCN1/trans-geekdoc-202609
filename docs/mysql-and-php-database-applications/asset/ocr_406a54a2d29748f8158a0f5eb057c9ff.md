# Null

One of the first decisions you will have to make for every column in your tables is whether or not you going back to your ninth grade math, you may recall the null set, which is a grouping that contains nothing. In relational databases, null has the same meaning: a null field contains nothing.

Keep in mind that a null field is distinctly different from a string with no characters (a zero-length string) or the numerical value of zero. The difference is that empty strings and zeros are values. In your programming you most likely have an occasion where you have had to check whether a string contained any value, perhaps as part of an... statement. In PHP, it would look like this:

```
$var //this is a variable used in the test
if ($var == "")
{
    echo "Var is an empty string";
} else {
    echo $var;
}
```

The syntax above would work for comparisons will not work with null. These sorts of comparison will the absence of value, any comparison with any value (including null) is meaningless. In Chapter 3 you will see that null values require the application developer to be very careful when writing table joins.
