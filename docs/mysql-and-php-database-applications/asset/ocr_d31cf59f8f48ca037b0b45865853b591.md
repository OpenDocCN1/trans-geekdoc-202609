# Chapter 2: The Structured Query Language for Creating and Altering Tables

In your SQL select statements (covered in Chapter 3), there are a couple of ways to check if a field contains a null value. First, you can use MySQL's isnull() function. For to find rows in a table where the middle_name column contains null values, you could run the following query:

```
select * from names where isnull(middle_name);
```

Or, to exclude null values in the query result:

```
select * from names where !isnull(middle_name);
```

The exclamation point means "not".

You can also use the is and not null statements. For example:

```
select * from users addr2 is null;
select * from users where addr2 is not null;
```
