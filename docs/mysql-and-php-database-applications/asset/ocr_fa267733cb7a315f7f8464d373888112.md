Now is time to make the connection and check if the credit card is verified. The cURL functions are a little strange at this point. They are fairly new and aren't as polished as some of the other function sets. By the time you read this, there may be a PEAR (PHP Extension and Application Repository) class that makes dealing with cURL easier. Make sure to check in the php.net site for the latest updates to the cURL functions.

```
global $ch;
$ch = curl_init($authorize_net_url);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, 1);
$data = curl_exec($ch);
curl_close($ch);
```
