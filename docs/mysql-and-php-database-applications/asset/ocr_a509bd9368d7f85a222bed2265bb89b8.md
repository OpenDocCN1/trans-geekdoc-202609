# Chapter 6: PHP’s Built-in Functions

```
$year = 2000;
$month = 1;
$day = 1;
echo date("l F d, Y", mktime(0,0,0,$month,$day-1, $year));
```

This code will let you know December 31, 1999 was a Friday.
Notice that the preceding code calculates the timestamp of the date indicated by mktime() and then prints out that you use the function.
If you exclude arguments from the right, these parameters will be retrieved from the current timestamp. So, print what the date and time will be in five hours, this will do the:

```
echo date("l F d, Y g:i a", mktime(date(H)+5));
```

Note the nesting of functions. Starting at the innermost function, date(H) returns the current hour in 24-hour format. Then five is added to, and the timestamp is calculated for five hours in the future. The timestamp is then formatted using the string indicated.

TIME() This function returns the current time measured in the number of seconds since the Unix Epoch (January 1 1970 00:00:00 GMT).

```
int time(void);
```

MICROTIME() This function returns the string "msec sec" where sec is the current time measured in the number of seconds since the Unix Epoch (0:00:00 January 1, 1970 (GMT), and msec is the microseconds part.

```
string microtime(void);
```

This function is only available on operating systems that support the gettimeofday() system call.
The returned string will look something like 0.12082400 969034581. With this function you can reasonably ensure that it will never return the same number twice. It is often used to seed the random number generator.
