# CLASS CARTSTYLE

This is similar to the CartStyle class and includes a method for printing Styles that is better for the shopping cart.

Class Name: CartStyle
Extends Style
Default Properties:

Methods:

+   - CartStyle. The class constructor. Takes two arguments: $parent and $satts. Calls the Base() method, assigning each element of the $satts array to Object properties.

+   - AddSubStyle. This method overwrites the AddStyle() method that is in the parent (Style) class. It creates an array, called $substyles, each member of which is an object formed by calling the CartSubStyle() class.

+   - PrintStyleRow. Takes no attributes. Overwrites the PrintStyleRow() method of the parent (Style) class.

# CLASS CARTUBSTYLE

This is similar to the CartSubStyle class and includes a method for printing substyles that is better for the shopping cart.

Class Name: CartSubStyle
Extends SubStyle
Default Properties:

Methods:

+   - CartSubStyle. The class constructor. Takes two arguments: $parent and $satts. Calls the Base() method, assigning each element of the $satts array to Object properties.

+   - AddSubStyle. This method overwrites the AddStyle() method that is in the parent (Style) class. It creates an array, called $substyles, each member of which is an object formed by calling the CartSubStyle() class.

+   - PrintSubStyle. Takes three attributes, $style_price, $style_dsc, $product_dsc. Overwrites the PrintSubStyle() method of the parent (Style) class.
