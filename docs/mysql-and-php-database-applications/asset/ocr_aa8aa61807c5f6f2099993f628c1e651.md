Once the array is flipped, these entries will look like this:

```
[$copy] => (c)
[&reg] => (r)
```

Then str() replaces each value to its key. So in the end this code will make sure that any character that needs to be represented by an HTML entity will be.

Note that if an array has two identical values before being flipped, only one can survive the flipped array. You can't have two array elements with same key. If there is a conflict the element in the right-most position will be maintained.

ARRAY_MERGE() As you can guess, this function merges, or concatenates, two or more arrays.

```
array_merge (array1, array2 [, ...])
```

If any of the arrays contain the same associative keys, the elements in the rightmost array will be preserved.

ARRAY_SPLICE() This function takes the array indicated in the first argument and removes elements following the offset specified in the second argument. It can insert additional elements.

```
array_slice (array input, int offset [, int length [, array replacement]])
```

If the offset is a positive number, the elements will be counted from the left; if the offset is a negative number, all items to the left of the indicated number will be deleted. The third argument can indicate how many elements after the offset you wish to delete. For example:

```
$knicks_array = array("Childs", "Sprewell", "Ewing", "Johnson", "Houston");
array_slice($knicks_array, 2,1);
```

will remove elements starting at offset 2 and remove only one element. So "Ewing" will be deleted from this array. array_slice() also gives you the ability to replace the deleted portion with another array. So, to account for trades, you can do this.

```
$knicks_array = array("Childs", "Sprewell", "Ewing", "Johnson", "Houston");
$new_knicks = array("Longley", "Rice");
```

```
array_slice($knicks_array, 2,1,$new_knicks);
```
