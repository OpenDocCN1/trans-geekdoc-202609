# Summary

As you've seen, PHP has more functions than you will be able to commit memory any time soon. It can seem intimidating, but the quantity and quality of these functions are what make PHP such a great language. Most anything you need to be done quickly and painfully.

At first, you may need to study and play with the functions in order to get to work. But in time, it will get a lot easier. You'll be making use of more and more functions, and keeping your scripts more compact and easier to read.
