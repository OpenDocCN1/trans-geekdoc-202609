> Tip In PHP, constructor methods of parent classes are not automatically run when the child class is called. For example, calling $p = new Product not run the Category() method.

We'll add a quick constructor method:

```

    var $product_name;
```

Notice that this method not only assigns values to the properties for this product, it also calls the constructor of the Category class, which then assigns values to those properties. Note that of inheritance, we could write a script as follows:

```

```

You see that the properties of Category are available to the Product object.
