Here we've included something interesting: a constant, named PAGE_LIMIT. A constant is a variable in that it contains a value (in this instance, 2). However, value cannot be changed by a simple assignment or by functions other than define(). Constants do not run into the same problems that are encountered with variables, so they can be used within functions without having to pass them as arguments or worry about declaring them. After running the define() function, the constant PAGE_LIMIT will the number of entries that will be viewable on each page. You are welcome to change this if you would like to see a larger number.

![](bbox=[0.187, 0.467, 0.258, 0.545])

If you are putting together a query using a constant, you will have to end your quoted string in order to make use of that constant. For example,
query = "select * from db_name limit PAGE_LIMIT"
will confuse because PHP has not replaced the name of the constant with its value. However, this will work:
query = "select * from db_name limit " PAGE_LIMIT

![](bbox=[0.187, 0.646, 0.258, 0.715])

PHP has many built-in constants you can use within your scripts. A list of constants is included in the PHP manual: http://www.php.net/manual/language.constants.php
