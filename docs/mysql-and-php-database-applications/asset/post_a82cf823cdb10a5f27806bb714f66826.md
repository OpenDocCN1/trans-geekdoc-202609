You can use this function in two ways. First, you can place a regular expression in the first argument and for its existence in the second argument. The function will return TRUE or FALSE, depending on the outcome of the search. For example:

```php
if (ereg("http://.*", $str)) {
    echo "This is a URL:";
}
```

The third argument is an array that is created from the regular expression. The portions of the regular expression that will become elements in the array are indicated by parentheses in the regular expression.

```
ereg("(....)(..)-(.*)", $publish_date, $date_array);
```

This example was taken from the Content Manager application, creates an array $date_array, wherein the first element will be the complete string matched by the regular expression. The next three elements in the array will be portions indicated by the regular expression. So $date_array[1] will contain 4 characters, and $date_array[2] and $date_array[3] will contain 2 characters each.

Note that arrays created by the third argument in ereg() will always contain 11 elements. Even if you have more than ten substrings within parentheses, only the first 10 will be in the array. If you have fewer than 10 substrings, the array will still contain 11 elements. If you want to test whether anything exists in the array element, have to test against an empty string(""). An isset() will always test TRUE. After running this code:

```php
$publish_date = "2000-10-02";
ereg("(....)(..)-(.*)", $publish_date, $date_array);
```

$date_array would contain the following:

```
[0] => 2000-10-02
[1] => 2000
[2] => 10
[3] => 02
[4] =>
[5] =>
[6] =>
[7] =>
[8] =>
[9] =>
```

Note that ereg() performs a case-sensitive match.

# Chapter 6: PHP's Built-in Functions

### EREGI()
This function is a case-insensitive version of ereg().

```php
int eregi(string pattern, string string [, array regs])
```

### EREG_REPLACE()
You can use this function for string replacement based on complex patterns.

```php
string ere_replace(string pattern, string replacement, string string)
```

If you want to delete the querystring from a URL, you could use this:

```php
$url = "http://www.phpmysqlbook.com/index.php?var=hello";
$parsed_url = ere_replace("\?.*$", "\1", $url);
echo $parsed_url;
```

This would print http://www.phpmysqlbook.com/index.php. This regular expression matches a question mark, and all characters that occur it until the end of the line. The question mark must be escaped with a backslash because it has a specific meaning to the regular expression. Following the question mark match any number of characters until the dollar sign, which is the inline character. It needs to be escaped with a backslash without the backslash, PHP will think the character represents a variable.

But often you need a bit more functionality than this. If you want to preserve the string you are searching for in the replacement string? Or if your search contains distinct offsets set of parentheses? Here's a simple example. We want to replace the current querystring by adding an additional name=value pair between the two name=value pairs currently in the string. That is, we want to put "newvar-here" after "var=hello" and "var2=yup".

```php
$url = "http://www.phpmysqlbook.com/index.php?var=hellovar2=yup";
$parsed_url = ere_replace("(..?.*$", "\1newvar-here&", $url);
echo $parsed_url;
```

This creates the following:

http://www.phpmysqlbook.com/index.php?var=hellonewvar-here&var2=yup

Here the single set of parentheses indicate 1. Then, by using the notation \1, we can include that portion in the newly created string. If more than one portion is indicated by additional parentheses, you can echo the back into the result by matching portion you need.

```php
$url = "this is a test ";
$parsed_url = ere_replace("(this.a).*(test)", "\1 regular expression", $url);
echo $parsed_url;
```

The result of these commands is: "this is a regular expression test"
The regular expression matches everything between "this" and "test". We use parentheses to indicate a substring that starts with "this" and moves to the letter "a". The next \. portion matches any number of characters. Finally, "test" is another sub-string. These substrings are echoed back in the second argument, with \1 echoing the first substring and \2 echoing the second substring.
Regular expression matches case-sensitive.

# PERL-COMPAT REGULAR EXPRESSIONS (PCRE)

For years, the programmers of the world have had regular expressions unlike others. If you have experience with Perl, it's likely that you've come to love the additional power these regular expressions give you. PCRE are, a fairly large topic, that explains briefly. However, if you're looking to get a good job on learning about Perl expressions and how they work for you, the information at the following URL is a good read: http://www.perl.com/doc/manual/html/perl.html. There is also a decent description of Perl regular expressions in the PHP manual: http://www.php.net/manual/pcre.pattern.syntax.

The major reason for PCRE functions is that they give you choice between "greedy" and "non-greedy" matching. For a quick example, take the following string:

```php
$str = "I want to match here. But end matching here";
```

Using preg() or ere_replace() there is no way to match from "I" to the first occurrence of "here". The following will not work as you expect:

```php
$new_str = ere_replace("I.*", "Where", $str);
echo $new_str;
```

This will print "Where" and nothing else will be replaced. However, using preg_replace(), you could do the following:

```php
$new_str = preg_replace("I.*?", "Where", $str);
echo $new_str;
```

In this instance, I.*? matches all characters until the first occurrence.

# PCRE FUNCTIONS USED IN THIS BOOK

### PREG_MATCH()
This is similar to the preg() function in that you can assign the optional third argument an array of matched patterns, if any are found in the regular expression. preg_match returns the number of matches found or if none.

```php
int preg_match(string pattern, string subject [, array matches])
```

### PREG_REPLACE()
This makes replacements based on Perl expressions. This is similar to ere_replace(), though the pattern must be a Perl regular expression. It can also use of \digit to echo the matched substring into the result. The optional fourth argument will limit the number of replaces that preg_replace makes.

```php
mixed preg_replace(mixed pattern, mixed replacement, mixed subject [, int limit])
```

```php
preg_replace("/<br>&nbsp;+/i", "", $body);
```

This example, taken from the content management system, will remove all occurrences where <br>, non-breaking spaces &nbsp;, or white space (spaces, tabs, new lines) appear consecutively. This replacement is not case-sensitive (the "i" flag denotes to ensure that both <BR> and <br> are matched). The brackets indicate that anything within the brackets will start the match. The asterisk indicates if the character following the match is one of the characters in the brackets, the pattern is matched and a replace should occur.
