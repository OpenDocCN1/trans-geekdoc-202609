# Regular expression functions

Regular expressions offer a method for complex pattern matching. If you're new to the concept of regular expressions, consider this: Given the string handling functions you have seen so far, how could you insert a newline and a break \n<br> after 45 characters? Or how could you find out if a string contains at least one uppercase letter? You may be able to pull it off, but it won't be pretty.

By the way, the following code would solve the previous questions.

```
//insert <br> after each 45 characters
$new_str = ereg_replace(".*{45}", "\\l\\n<br>", $str);
```

```
//check if string contains uppercase letter
if (ereg("[A-Z]*", $str)) {
    echo "it does";
}
```

Statements like these may seem a bit opaque at first, but after working with them for a while, you will grow to love the convenience they offer.

See Appendix F for a rundown on how regular expressions work.

Note regular expressions are a good deal slower than string-handling functions. If you have, a simple replace that doesn't require regular expressions, use str_replace() and not ereg_replace().
