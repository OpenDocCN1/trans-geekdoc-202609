CREATE_TOPIC() This function inserts the data taken from a form and inserts into the database. As mentioned earlier, we are taking the IP address from the Apache $REMOTE_ADDR variable, which will also be inserted into the database. Many of the fields (for instance, $root_id) will be coming from hidden fields. And root_id will be set to 0 if the user is attempting to create a new top-level topic. In those cases the parent_id will need to be set to the same value as the topic_id.

```
function create_topic ($name="[no name]", $author="[no author"
  $description="[no comments]", $parent_id=0, $root_id=0
{
  global $REMOTE_ADDR;

  $name = cleanup_text($name);
  $description = cleanup_text($description);
  $author = cleanup_text($author);

  $query = "insert into topics
(name,description, parent_id, root_id, author, author_host)
values
  ('$name', '$description', $parent_id
  $root_id, '$author', '$REMOTE_ADDR')
";

  $result = safe_query($query);
  if (!$result) {
    print subtitle("hey! insert failed, dammit.");
  }
  $top_id = mysql_insert_id();

  if (!empty($top_id)) {
    if ($root_id == 0) {
      safe_query("update topics set root_id = $top_id
      where topic_id = $topic_id and root_id = 0
");
    }
}
```
