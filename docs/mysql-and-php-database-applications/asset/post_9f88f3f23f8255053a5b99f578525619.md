
## Chapter 6: PHP’s Built-In Functions

## MySQL API

There are a total of 33 MySQL functions available in PHP. Only 17 of these are used in the applications in this book. You may find some of the other MySQL functions in your applications, but you probably won't use all of them. For the sake of this listing, I'll break the functions into the set you use the most, and the ones that're less likely to use extensively.

## FREQUENTLY USED MYSQL FUNCTIONS

You will probably end up using the following functions frequently. You may want to dog-ear this page.

### MYSQL_CONNECT() You can't do anything with MySQL until you make the connection using the following function.

```
int mysql_connect(str host, str username, str password);
```

Most often you will be connecting to MySQL on localhost using a username and password assigned to you, the Web developer. The integer that returns to you is a connection identifier. You may need to track the connection identifier and use it with mysql_db_select(). It will typically look something like this:

```php
$conn = mysql_connect("localhost", "username", "password") or die ("Could Not Connect to Database");
```

![](img/245156cc770929860a3ede93c01f9981_147_0.png)

If MySQL is not installed on a standard port or if the mysql socket is located in /tmp/mysql.sock, you can specify the port of socket location in the host string. For example:

```php
mysql_connect("localhost:/usr/local/mysql.sock",
"username", "password");
```

Or, if the MySQL database is sitting in another machine, you can access it with the following

```php
mysql_connect("mymachine.mydomain.com", "username",
"password");
```

![](img/245156cc770929860a3ede93c01f9981_147_1.png)

You can also specify host, username, and password in the php.ini file. That way you could leave one or more of these arguments empty.

## Part II: Working with PHP

### MYSQL_PCONNECT() The mysql_pconnect() function works exactly like mysql_connect() but with one important difference: The link to MySQL will not close when the script finishes running.

```
int mysql_pconnect(str host, str username, str password)
```

When you use this function the connection remains open, and additional calls to mysql_pconnect() will attempt to use these connections when they run. This could make your scripts quite a bit faster.

It is interesting to note what happens when mysql_pconnect() is run. The first time it is run, PHP will ask for a connection, and MySQL will open a connection to the database. When that script finishes, the connection remains available. The next time a PHP page is requested, PHP will ask for a connection that is already open. If MySQL has one available, it will grant PHP the open connection. If there are no open connections available, a new connection will be opened.

Establishing a connection with the MySQL database will be the slowest function in your scripts. If PHP can use a connection that has already been opened, there will be far less overhead in the application.

In order for mysql_pconnect() to work, set the following lines in your php.ini file:

```
mysql.allow_persistent = On
mysql.max_persistent = -1; maximum number of :persistent links. -1 means no limit
```

Note that these are the defaults. You will probably want to limit the persistent connections if you use this method.

### MYSQL_SELECT_DB() The mysql_select_db() function changes the focus to the database you wish to query.

```
int mysql_select_db (string database_name [, int link_identifier)
```

You can include the integer it returns in the mysql_query() function, but it is only really needed if you are connecting to more than one database. The second, optional argument is the link identifier retrieved from the mysql_connect()/mysql_pconnect() function. It typically looks like this:

```php
$db = mysql_select_db("database_name") or die("Could Not Select Database");
```

See the description of the db_connect() function in Chapter 8 to see how to handle connections to the MySQL server and a specific database in a single function.

### MYSQL_QUERY() This mysql_query() function is probably the MySQL function that you will use frequently in your scripts.

```
int mysql_query(string query [, int link_identifier)
```

This function sends any query that you can put together to MySQL. It is important to understand that this function does not actually return the result of the query. It opens a cursor that points to the result set on MySQL. So if you were to do the following:

```php
echo mysql_query("select * from table");
```

- would not get a meaningful answer, only the number that identifies the result. Setting mysql_query(), you will need to make one of the functions that actually retrieves the data from MySQL (mysql_fetch_row(), mysql_fetch_array(), mysql_result()).

The optional second argument would be the result of either mysql_connect() or mysql_select_db(). It is typically used as in this code sample. Note that a query can fail for any number of reasons. It is best to use mysql_error() to find why the query failed.

```php
$result = mysql_query("select * from db") or
die (mysql_error());
```

> See the discussion of the safe_query() function in Chapter 8 to see how to safely handle queries with a uniform function.

### MYSQL_FETCH_ARRAY() Once you have retrieved your result from a query, you will (more often than not) use mysql_fetch_array() to retrieve the rows from a query.

```
array mysql_fetch_array (int result [, int result_type)
```

This function returns an associative array, with names of the select columns as the key. By default, mysql_fetch_array() will return each column in row twice: the first will have an associative key, the second will have a numeric key. To tell PHP to limit the results to numeric results using MYSQL_NUM as the second argument. To get only the associative keys, use MYSQL_ASSOC as the second argument. This function returns FALSE when there are no rows left to fetch.

The following will print the results of a query as follows:

```php
$query =("select * from table_name");
$result = mysql_query($query)
or die ( echo mysql_error() );
echo "<table>";
//if I don't use MYSQL_ASSOC or MYSQL_NUM, each row will
// be retrieved twice, and I don't want that
while ($row = mysql_fetch_array($result, MYSQL_ASSOC)) {
```

```php
echo "<tr>";
while ( list($key, $value) = each($row)) {
    echo "<td>" . $value . "</td>";
}
echo "</tr>";
echo "</table>";
```

In Chapter 3 there is a script that prints any query to a table that includes the column names as table headers.

**MYSQL_FETCH_ROW()** The mysql_fetch_row() function works almost exactly like mysql_fetch_array(), but it only returns a numeric array of the fetched row.

```
array mysql_fetch_row (int result)
```

> Tip There's generally little reason to use mysql_fetch_row(), and we recommend that you use mysql_fetch_array() instead.

**MYSQL_INSERT_ID()** The primary key of a MySQL table will be an auto-increment field. In cases where you insert you may need to know the ID assigned to the newly row.

```
int mysql_insert_id ((int link_identifier))
```

We use this function many times throughout the book; one example is Chapter 12 in admin_user.php. You might think that the following method would work equally well for the row that just inserted.

```php
mysql_query("insert into users (fname, lname) values ('jay','greenspan') or
die (mysql_error());
mysql_query("select max(user_id) from users");
```

However, there is no guarantee that this script will return an accurate result. On a busy server, it is possible that an insert (perhaps runs by other users accessing the script) will occur between the time it took for these two queries to run. In such cases, your user will end up with bogus data. mysql_insert_id() returns the value of the auto_increment field associated with the specific code of the script, so you know successfully that the number it returns is.

**MYSQL_NUM_ROWS()** A query can execute successfully, but still return zero rows in the result. This function will tell you how many rows have been returned by a select query.

```
int mysql_num_rows (int result)
```

You might use it in a case like this:

```php
$query = "select * from table_name";
$result = mysql_query($query) or
die (mysql_error());
if (mysql_num_rows($result) == 0) {
  echo "Sorry, no results found.";
} else {
  //print rows
}
```

**MYSQL_AFFECTED_ROWS()** This function is similar to the mysql_num_rows() function, but works for a different set of queries. It returns the number of rows in a table that are affected by an update, insert, or delete query.

```
int mysql_affected_rows (int link_identifier)
```

This function is excellent for checking that you have has actually accomplished something.

```php
$query = "delete from table_name where unique_id = 1";
$result = mysql_query($query) or
die (mysql_error());
$deleted_rows = mysql_affected_rows();
if ($deleted_rows == 0) {
  echo "no rows removed from the table.";
}
```
