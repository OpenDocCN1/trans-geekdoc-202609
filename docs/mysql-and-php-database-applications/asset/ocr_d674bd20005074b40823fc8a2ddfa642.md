# Part II: Working with PHP

On subsequent pages the $my_var will be available, but only after you run the session_start() function. That function tells PHP to look for a session and if the exists, to make all the session variables accessible as globals. It can take a little work with statements to make your session variables properly accessible. Look at the following short script for

```
<php
session_start();
session_register("your_name");
// check to see if $your name contains anything
if(!empty($your_name))
{
echo "I already know your name, $your_name";
//this portion will probably run the first time to
//this page.
elif(empty($your_name) && isset($submit))
{
echo "<form action=myform method=post>$PHP_SELF\n<input type=text name=first_name> first name<br>
<input type=text name=last_name> last name<br>
<input type=submit name=submit value=submit>n</form>"";
//if the form has been submitted, this portion will
//run and make an assignment to $your_name.
else if isset($submit) && empty($your_name))
{
$your_name = $first_name . " " . $last_name;
echo "Thank you, $your_name:";
}
```

After running this code, refresh on your browser. You will see the script members who you are.

> Your setcookie() and session_start() functions should always be at the very top of your file. If you try sending anything to the browser prior to setting a cookie, you will get error messages.
