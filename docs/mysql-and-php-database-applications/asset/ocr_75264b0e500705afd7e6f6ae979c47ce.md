# CURL_SETOPT)

bool curl_setopt(int ch, string option, mixed value)

Before you execute the communication, there are over 40 options you can set for cURL. Many of these are not really necessary, given the quality of PHP's function set. Others aren not really relevant to the application presented here. See the manual (http://www.php.net/manual/ref.curl.php) if you would like to see the full list of cURL functions. For the sake of this application, all you need is to get the results of the https request returned to a PHP variable. For that you can use the CURLOPT_RETURTRANSFER option.

```
curl_setopt($ch, CURLOPT_RETURTRANSFER, 1);
```

# CURL_EXEC()

This function executes the transfer. The one argument should be the results of the curl_init() function and you should set all the necessary options.

```
bool curl_exec(int ch)
```

# CURL_CLOSE()

This function finishes the cURL connection using the curl handle:

```
void curl_close(int ch)
```

In the end, this set of functions will conduct the transaction and return a result to the $Sdata variable.

```
$ch = curl_init($authorize_net_url);
curl_setopt($ch, CURLOPT_RETURTRANSFER, 1);
$data = curl_exec($ch);
curl_close($ch);
```

# Dealing with the credit-card processor

You are going to get some information directly from the entity processing the transaction. Most processing companies we've seen work similarly. You send them request with all the expected credit card information: number, expiration date, address, and so forth, and they send you some codes in response.
