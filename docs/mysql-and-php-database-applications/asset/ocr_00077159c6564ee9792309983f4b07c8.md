# Appendix E: PHP Function Reference 459

| Function | Returns | Action |
|---|---|--|
| dirname(string path) | string | Returns the directory name component of the path |
| strstr(string haystack, string needle) | string | Finds first occurrence of a string within another |
| strchr(string haystack, string needle) | string | Alias for strstr() |
| strstr(string haystack, string needle) | string | Finds first occurrence of a string within another (case-insensitive) |
| strpos(string needle [, int offset]) | int | Finds position of first occurrence of a string within another |
| strrpos(string haystack, string needle) | int | Finds position of last occurrence of a character in string within another |
| strchr(string haystack, string needle) | string | Finds the position of the last occurrence of a character in string within another |
| chunk_split(string str [, int hunklen [, string ending]]) | string | Splits a line by inserting, by default, \n every 76 characters. The length of the chunks and the separation string can be indicated |
| substr(string str, int start [, int length]) | string | Returns part of a string, as specified by the start position and length. If the length is a negative number, position is determined from the end of the string |
| substr_replace(string str, string repl, int start [, int length]) | string | Replaces part of string with another string |
| quotemeta(string str) | string | Returns a string with the following characters prepended by a backslash: .+\*?[\](\$) |
| ord(string character) | int | Returns ASCII value of character |
| chr(int ascii) | string | Converts ASCII code to a character |
