# String-handling functions

In creating Web-based applications, string handling and manipulation is one of the most critical tasks of the language you work with. Text cleanup and validation is extremely important, and good Web middleware will make working with it relatively easy. PHP excels in this department: It contains built-in functions that cover anything you'd want to do to text.

In fact, there are far more functions than we could cover. As of PHP 4.0.2, there were 70 string-handling functions listed on http://www.php.net/manual/ref.strings.html. In this book we cover only a portion of them. We cover all of the string-handling functions we use in the course of creating the applications in Sections III and IV, and we will cover some other notable functions that we didn't have the opportunity to use.

STRIP_TAGS() This function removes HTML and PHP tags.

```
string strip_tags(string str, string allowable_tags);
```

One of the most important things you will need to do with every Web-based application you write is make sure that the users of your Web pages haven't passed your malicious text. As we discuss in Chapter 8, if you're not careful, you might find your pages filled with HTML tags (<img>, <div>>, etc.) or JavaScript that you don't want. You could also find result in trouble if some character decides to litter your form fields with something like <script> alert("you stink");</script>.
The strip_tags() function will remove all HTML and PHP tags, except for those explicitly allowed in the second argument. If you wanted to allow <b><b> and <i><i> tags, you might use:

```
strip_tags($str, "<b><i></i></b>");
```

# ADDSLASHES() This function is intended to work with your database and update queries.

```
string addslashes(string str);
```

If you take a look at a typical insert query you see a potential problem:

```
insert into table_name(char_field, numeric-field)
values ('$str', $num);
```

What if the value in $str contains a contraction as "ain't? You could get an error because the apostrophe is going to confuse MySQL. You will need to escape all occurrences of single quotes (''), double quotes ("), and NULLs in the string. For example:

```
$str1 = "let's see";
$str2 = "you know";
$str1 = addslashes($str1);
$result = mysql_query("insert into show_stuff($stuff_desc, stuff_stuff) values('$str1', '$str2');\
echo mysql_affected_rows();
```

So, given this problem, do you need to put all of your form input through addslashes()? Not necessarily. It depends on the magic_quotes_gpc setting in your php.ini file. If it is set to on, which is the default, data that comes from Get, Post, or Cookies is automatically escaped, so you don't need to worry about putting the information through addslashes().

# STR_REPLACE() This function replaces all occurrences of the first argument and replaces them with the string in the second argument.

string str_replace (string to search for, string to replace with, string to be affected)

For example, if we wanted to print out the names of both authors of this book, the following would work:

```
$str = "This book written by Brad. Brad wrote a nice book."
$str = str_replace("Brad", "Brad and Jay", $str);
echo $str;
```

This would print: "This book written by Brad and Jay. Brad and Jay wrote a nice book."

# SUBSTR_REPLACE() This function operates on the string in the first argument. The third and fourth arguments determine the portion to be replaced.

```
string substr_replace (string string, string replacement, int start [, length])
```

The third argument should be the offset you wish to start. The fourth, which is optional, can have an integer representing the length of the string. For example:

```
echo substr_replace("this my string", "this is", 0);
```

will print "this is my string". And:

```
echo substr_replace("this my string", "new string!", -1);
```

will print "this is new string!"

# STRCMP() This function compares two strings.

```
int strcmp (string str1, string str2)
```

> If the first string is greater than the second the function will return a number greater than 0. It will return a number less than 0 if string two is greater than one.

# STRLEN() This function returns an integer that gives the number of characters in a string.

```
int strlen (string string)
```

For example:

```
echo strlen("My String");
```

will print "9".

# STRPOS() This function returns the position of the string in the second argument within the first argument. It will return FALSE if the string isn't found.

```
int strpos (string to search, string to find [, int offset])
```

For example:

```
$str = "Where is the first space"
echo strpos($str, " ");
```

This will return "5". If you wanted to get the first space after the fifth character you could make use of the third argument.

```
$str = "Where is the first space"
echo strpos($str, " ", 6);
```

This will return "8"Suppose you want to test if a string contains a specific character, a space. You might think the following would work since strpos() returns FALSE if the second argument is not found.

```
if( strpos($str, " "))
{
echo "thank you for including a space"
} else
{
echo "include a space, please"
}
```

But, if you remember back to Chapter 5, the value of zero will also test as FALSE. In the preceding code, if $str starts with a space, the condition will evaluate as FALSE. Therefore, if you want to use a test like this, you will need to alter the condition. In PHP 4 you can run a test against the constant FALSE. For example:

```
$str = "Whereisthefirstspace"
if( strpos($str, " ")==FALSE )
{
echo "you have not included a space."
} else
{
echo "thank you for the space."
}
```
