The final if block will run if a file has not been uploaded.

METHOD SET_THUMB_SRC() This method sets a thumb_src property. It determines the property based on the image_src stored in the database. We are not storing the thumb_src property in the database, so when we need access to the thumbnail, we will need to run this method.
The last period image_src is replaced with “thumb.”. If no period is found in image_src, thumb is set to image_src plus “thumb”.

```
function set_thumb_src() {
    $last_period = strpos($this->image_src, ".");
    if ($last_period === false) {
        $this->thumb_src = $this->image_src."_thumb";
    } else {
        $this->thumb_src = substr_replace(
            $this->image_src,
            "_thumb",
            $last_period,
            1
        );
    }
```
