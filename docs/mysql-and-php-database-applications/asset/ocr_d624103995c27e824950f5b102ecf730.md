# Summary

If you would like to see the rest of the code comes together, take a look at the accompanying CD. The other files are well-commented and should be relatively easy to follow.

You should come away from this chapter with the understanding of two concepts. The first is recursion. Recursion is a nifty tool that can be very helpful at times. If you'd like to see another example of recursion, check out the recurse_directory() function in Appendix G, which will display all of the contents on a Web server.

The other key is how we went about organizing the data. We didn't follow a strict normalization procedure, like the one described in Chapter 1. Here we were more concerned with what gets the job done. In the end that's all us application developers are trying to do, right?
