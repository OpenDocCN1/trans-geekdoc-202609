# Encryption and security tools

Given you have just read about encryption and security, it probably stands for reason that you are going to need some new tools. Here's a basic rundown.

First off, you are going to need add SSL to Apache. With everything else discussed in this book, adding SSL does not require you to pay for specialized software. All you need to install is Apache with mod_ssl. You can read more about at http://www.modssl.org to work with Apache in the United States, you will need an additional piece of software csare from RSA.

The installation of these tools with Apache is well documented in INSTALL.SSL file, so we won't cover it here. If you are having trouble getting mod_ssl, PHP, and MySQL to work for you, we recommend this site, which goes through the installation by step: http://www.devdshed.com/Server_Side/PHP/SoothinglySeamless/page8.html.

> Make sure you read about the credit-authorization options in the following section before you configure Apache with PHP.
