```
else
{
    echo "string not found";
}
```

This will test and print "pattern found". However, with a simple string like this, you wouldn't need a regular expression. One of PHP's string functions would work and be a good deal faster. For example, in the preceding example,strstr($str, "jay*) would work equally well.

# Characters

In regular expressions you can make use of the following characters.

+   \n-Newline
\t-Tab
\r-Return
\f-Form feed
^- (Shift-6)—Start of string
$-End of string
. (dot)-Matches any non-newline character.

So if you needed to match the word "jay" at the beginning of a string, you could do this:

```
ereg("jay", $str);
```

And if you wanted to make sure there was nothing before or after "jay" in the string, you could do the following:

```
ereg("jay$", $str);
```

The meaning of the dot (.). It stands for any non-newline character. If you wanted to print whatever four characters followed "jay" in a string, you could do the following:

```
ereg("jay....", $str, $arr);
echo $arr[1];
```
