# Random number generator functions

Note that the random number generator needs to be seeded before use. That, as is to have a generator that is reasonably unique to begin with. For this, as you will see, the `microtime()` function will be of great use.

Keep in mind that there are two sets of random number generators. There are the standard `rand()` and `srand()`, which you need in order to get the generator for `shuffle()` and `array_rand()`. # RANDOM NUMBER GENERATOR FUNCTIONS USED IN THIS BOOK

# MT_SRAND() This function seeds your random number generator.

```php
void mt_srand(int $seed)
```

# HTTP header functions

There are two vital HTTP header functions, both of which you will need to get to know.

# HEADER()

If you are going to be communicating with the browser or with other HTTP servers, this is the function to use.

```php
int header (string $string)
```

Essentially, you can send any header that would be expected over RFC 2616 (ftp://ftp.isi.edu/in-notes/rfc2616.txt). The RFC itself is a handful (and the sweetest sleep you’re having all year. Here is a common header when is likely to send.

```php
header("Location:http://www.php.net");
```

This is more than a redirect; it sends the browser to a page you specify. If you have been working with straight HTML and the <META type=refresh> tag or JavaScript to do your redirects, you will switch to this type of header whenever possible. It will work for all browsers and the redirection will be totally transparent to the user.

> **IMPORTANT:** No, make that VERY IMPORTANT. You cannot send a header after anything — ANYTHING—has been sent to the browser. If you send a header after a hard return, there will be an error. If there is a hard return before opening your `php tag`, you will get an error. If there is a hard return in in included file that precedes the `header()` function, you will get an error. This should not be a problem you encounter frequently; your pages should be so that most of the logic is handled prior to the display. However, if you have a situation you just can't work around, take a look at the output buffering functions.

```php

```

The first argument will be the name of the cookie. The second will be the value.
