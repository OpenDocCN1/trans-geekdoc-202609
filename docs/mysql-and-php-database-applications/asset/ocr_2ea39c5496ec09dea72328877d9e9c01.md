# Assigning two-dimensional arrays in a script

PHP also supports multi-dimensional arrays. The most commonly used dimensional array is the two-dimensional array. Two-dimensional arrays look a lot like tables. They store information that is based on two keys. For instance, if we wanted to store information on more than one person, a two-dimensional array would work well. We would assign an array named \$people, and within \$people there be individual addresses addressing each person:

```
$people = array (
    "Jay" => array (
        "last_name" => "greenspan",
        "age" -> 32
    ),
    "john" => array (
        "last_name" => "doe",
        "age" -> 52
    )
);
```

The \$people array contains information on two people, Jay and John. To access information on any single value, you will need to use both keys. To print out John's last age, the following two commands would work:

```
echo \$people["john"]["age"]; //prints 52
```
