As you have seen now, the PHP mysql_connect() function takes three arguments: username, host, and password. In the preceding code you used the corresponding field names. MySQL identifies a user by a combination of the user-name and host. For instance, user can have a different set of rights for each host that connects to MySQL. If you or your PHP scripts are accessing MySQL from the local machine, you will usually assign a host of localhost.

The other columns are intuitively named. As you can see, all the Host, User, and Password columns allow only Y or N column values. As we mentioned earlier, any of these rights that are set to Y will be granted to every table of every database. Most of the columns' names correspond to SQL statements (e.g. delete, create, and so forth).

The user table also contains a set of columns that grant administrative rights. These columns are File_priv, Grant_priv, Process_priv, Reload_priv, and Shutdown_priv. The following is a brief explanation of the meaning of these columns. If you are security-mined, grant these rights sparsely.

+   * File_priv — If granted, this privilege allows the database server to read and write files from the file system. You will most often use it when loading a file into a database table.

+   * Grant_priv — A user with this right will be able to assign privileges to other users.

+   * Process_priv — This right gives a user the ability to view and kill all running processes and threads.
