There are a few things that require explanation. First, notice that the method (i.e., the function) has exactly the same name as the class. That PHP this is the constructor. A constructor is automatically run as soon as a class is instantiated. The other thing to note is the use of `$this->`. It identifies a property or method within the current class. Above, we are assigning values to the properties: category_id, category_name, and category_description. If we wanted to call a method, we would indicate with parentheses: `$this->method_call()` or `$this->method_call($value)
