# Appendix E: PHP Function Reference

Use of these functions requires that PHP be compiled --with-postgres."

TABLE E-37 SESSION FUNCTIONS

| Function | Returns | Action |
| --- | --- | --- |
| session_set_cookie_params([int lifetime [, string path, string domain]]) | void | Sets session cookie parameters |
| session_get_cookie(void) | array | Returns the session cookie parameters |
| session_name([string newname]) | string | Returns the current session name; if newname is given, the session name is replaced with newname |
| session_module_name((string newname)) | string | Returns the current module used for accessing session data; if newname is given, the module name is replaced with newname |
| session_set_save_handler(string open, string read, string write, string destroy, string gc) | void | Sets user-level functions |
| session_save_path([string newname]) | string | Returns the current save path to module_; if newname is given, the save path is replaced with newname |
| session_id([string newid]) | string | Returns the current session id; if newid is given, the session id is replaced with newid |
| session_register(mixed var_names [, mixed ...]) | bool | Adds variable names to the list of variables stored by the session |
