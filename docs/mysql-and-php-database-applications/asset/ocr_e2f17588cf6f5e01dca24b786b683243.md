We loop through each of the style_ids returned from the previous queries and run queries that delete the style_ids from the style_substyle_map table, the styles table, and the products table. Note that in relational databases we could delete rows from many tables at once by using a join. MySQL, however, allows for when performing deletes.

```
while ($row = mysql_fetch_object($result)) {
```
