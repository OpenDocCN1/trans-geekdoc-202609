# What do we need to prevent?

The major problem that we need to tackle here is one that is common to any application with input. It is possible for vandals to inject nasty code into your forms that will screw the pages for everyone who comes along. If you used the guestbook application in the Introduction you could be in serious trouble. Consider what would happen if someone inserted the following code into a text field:

```
<script>alert("boo");</script>
```
