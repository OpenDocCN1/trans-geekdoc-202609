# Chapter 2: The Structured Query Language for Creating and Altering Tables

From PHP, you can get a list of tables by using mysql_list_tables().

```
<?
mysql_connect("localhost", "root", "");
$result = mysql_list_tables("test");

while($row = mysql_fetch_array($result)) {
    echo $row[0] . "<br>\n";
}
>
```

![](bbox=[0.181, 0.336, 0.256, 0.396])

You are better off not using mysql_list_tables(), as this function may be available in the future. Running a show tables command through mysql_query() is a better choice.

# show columns/show fields

These commands, which are synonymous, are very handy if you can't remember the column types and attributes declared in your create statement. For example, let's say you created a table with the following command.

```
create table topics (
    topic_id integer not null auto_increment primary key,
    parent_id integer default 0 not null,
    root_id integer default 0,
    name varchar(255),
    description text null,
    create_dt timestamp,
    modify_dt timestamp,
    author varchar(255) null,
    author_host varchar(255) null,
    index my_index(parent_id)
);
```
