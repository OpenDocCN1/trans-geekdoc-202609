# The where clause

The where clause limits the rows that are returned from your query. To get a single row from a table, you would run the query against the primary key. For instance, you will get all the information on Brad, from this query:

```
select * from users userid = 2
```

Figure 3-2 shows the results of this query.
If you're doing a comparison to a column that contains a string (char, varchar, etc.), you will need to surround the string in single quotes in the where clause by single quotes.

```
select * from users city = 'San Francisco' 
```
