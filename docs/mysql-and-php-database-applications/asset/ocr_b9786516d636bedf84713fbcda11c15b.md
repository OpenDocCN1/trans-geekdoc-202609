# RTRIM

This function returns the string str with trailing space characters removed.

```
RTRIM(str)
RETURNS: string
```

# TRIM

This function returns the string str with all remstr prefixes and/or suffixes
removed. If none of the specifies BOTH, LEADING, or TRAILING are given, BOTH is
asumed. If remstr is not specified, spaces are removed.

```
TRIM([[BOTH | LEADING | TRAILING][remstr] FROM) str) (used in
examples)
RETURNS: string

mysql> select trim(both '\n' from '\n mystring');
```
