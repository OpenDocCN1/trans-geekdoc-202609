Though Apache works best on Unix systems, there are also versions that run on Windows operating systems. Nobody, not even the Apache developers, recommends that Apache be on a busy server under Windows. If you have decided to use the Windows platform for serving Web pages, you are better off using IIS.

But there are conditions under which you'll be glad Apache run under Windows. You can run Apache, PHP, and MySQL on a Windows 98 machine and then transfer these applications to Linux with practically no changes to the scripts. This is the easiest way to go if you need to develop locally on Windows but to serve off Unix/Apache server.

# MIDDLEWARE

PHP belongs to a class of languages known as middleware. These languages work closely with the Web server to interpret the requests from the Wide Web, process these requests, interact with other programs on the server to fulfill the requests, and indicate to the server what to serve to the client's browser.

The middleware is where you'll be doing the vast majority of your work. With a little luck, you can have your Web server up and running without a whole lot of effort. And once it is up and running, you won't need to feel with it a whole lot.

But as you are developing your applications, you will spend a lot of time writing code that makes your applications work. In addition to PHP, there are several that perform similar functions. Some of the more popular choices are ASP, Perl, and ColdFusion.

# RELATIONAL DATABASES

Relational Database Management Systems (RDBMSs) provide a great way to store and access complex information. They have been around for quite a while. In fact, they precede the Web, Linux, and Windows NT, so it should be no surprise that there are many RDBMSs to choose from. All of the most popular databases use the Structured Query Language (SQL).

Some of the popular commercial RDBMSs are Oracle, Sybase, Informix, Microsoft's SQL Server, and IBM's db2. In addition to MySQL, there are now two major-source relational databases. Postgres has the major alternative to MySQL in the open-source area. In August 1999, Borland released its Interbase product under an open-source license and allowed free download and use.
