# Chapter 6: PHP’s Built-In Functions

# MySQL API

There are a total of 33 MySQL functions available in PHP. Only 17 of these are used in the applications in this book. You may find some of the other MySQL functions in your applications, but you probably won't use all of them. For the sake of this listing, I'll break the functions into the set you use the most, and the ones that're less likely to use extensively.

# FREQUENTLY USED MYSQL FUNCTIONS

You will probably end up using the following functions frequently. You may want to dog-ear this page.

MYSQL_CONNECT() You can't do anything with MySQL until you make the connection using the following function.

```
int mysql_connect(str host, str username, str password);
```

Most often you will be connecting to MySQL on localhost using a username and password assigned to you, the Web developer. The integer that returns to you is a connection identifier. You may need to track the connection identifier and use it with mysql_db_select(). It will typically look something like this:

```
$conn = mysql_connect("localhost", "username", "password") or die ("Could Not Connect to Database");
```

![](bbox=[0.181, 0.597, 0.25, 0.653])

If MySQL is not installed on a standard port or if the mysql socket is located in /tmp/mysql.sock, you can specify the port of socket location in the host string. For example:

```
mysql_connect("localhost:/usr/local/mysql.sock",
"username", "password");
```

Or, if the MySQL database is sitting in another machine, you can access it with the following

```
mysql_connect("mymachine.mydomain.com", "username",
"password");
```

![](bbox=[0.181, 0.847, 0.25, 0.903])

You can also specify host, username, and password in the php.ini file. That way you could leave one or more of these arguments empty.
