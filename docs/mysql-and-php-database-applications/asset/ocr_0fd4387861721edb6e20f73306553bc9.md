You already know that PAGE_LIMIT sets the number of records displayed per page. The second argument in the limit clause, the $offset variable indicates which records will be returned from the query. If you are having problems understanding $offset, take a look at the explanation of the limit clause in Chapter 3. A value for $offset will be passed through the navigational elements. We will examine this in detail when we discuss the next function.

To retrieve the date in a readable way, this query uses MySQL's date functions. MySQL stores the date and time as a 14-digit number (YYYY:MM:DD:HH:SS), but it's nicer for humans to read. The MySQL date_format function retrieves the information in the way we want to use. This function and other MySQL functions are discussed in Appendix I.

NAV() This function's purpose is to create navigational elements.

```
function nav ($offset=0,$this_script="")
{
    global $PHP_SELF;

    if (empty($this_script)) { $this_script = $PHP_SELF; }
    if (empty($offset)) { $offset = 0; }

    // get the total number of entries in the guest book
    // we need this to know if we can go forward from where we are
    $result = safe_query("select count(*) from guestbook");
    list($total_rows) = mysql_fetch_array($result);

    print "<p\n";
    if ($offset > 0)
    {
        // if we're not on the first record, we can always go
        backwards
        print "<a href=\\$this_script?offset=$($offset-PAGE_LIMIT).\&lt;Previous Entries&gt;/&nbsp; ";
    }
    if ($offset+PAGE_LIMIT < $total_rows)
    {
        // offset + limit gives us the maximum record number
        // that could have displayed on this page, it's
        // less than the total number of entries, that means
        // there are more entries to see, and we can go forward
        print "<a href=\\$this_script?offset=$($offset+PAGE_LIMIT).\">Next Entries&gt;&lt;/a&nbsp; ";
```
