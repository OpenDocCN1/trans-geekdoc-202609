Note that you don't need to make any alterations in the php.ini file to make PHP with MySQL. MySQL support is, in fact, built into PHP for Windows.

> If you uncomment the directive extension-php_mysql.dll, you will have all kinds of problems getting a PHP page to load.

The basics are what you need to get going with PHP and MySQL Note that you can also install PHP as an ISAPI filter for Internet Information Server (IIS) and PWS. The instructions for doing so are included in the readme.txt file included in the PHP zip file. As of this writing, running PHP as an IIS filter is not recommended in a production environment.
