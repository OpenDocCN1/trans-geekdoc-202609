# # MySQL Utilities

THIS APPENDIX PRESENTS A BRIEF OVERVIEW of some of the MySQL administrative utilities. These are the tools you'll use to build and maintain your databases. Whether or not you have access to them depends on the exact version number you are running.

The best place to get the full details about the tools you have available to you is the Docs subdirectory of your local installation of MySQL (Note: This is the install directory, not the data directory). You also check the version of the MySQL documentation at http://www.mysql.com/documentation/

But warned—the online manuals check the most recent version of MySQL, which at the time of this writing is the release 3.23.

If you're running the production release, 3.22, many of the features you'll read about on the Web site won't be available to you. I've marked off version 3.23 enhancements in this document where I could. You can always find out what your version of a tool supports by running it with the --help option (e.g., mysql --help).

# # mysql

This is the command-line interface to MySQL; it allows you to run any arbitrary SQL command, as well as the MySQL-specific commands like describe table. It's a tool you should know. You can use it to test or debug queries for your code, create your database, create tables, add columns to existing tables—everything, really. It also has batch-oriented options that make it handy to use in maintenance scripts, or as a quick no-frills reporting tool.

mysql [options] [database name] [<inputfile] [outputfile]

If you just type mysql, you'll start the tool up, but you won't be anywhere. When you try to do anything that involves interaction with a database, you'll get this error:

ERROR 1046: No Database Selected
