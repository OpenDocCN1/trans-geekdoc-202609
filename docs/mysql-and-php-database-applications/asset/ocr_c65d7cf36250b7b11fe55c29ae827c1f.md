# Type-conversion functions

This is a category of my own making. In the manual, these functions will fall under other headings. However, we feel the specialized nature of these functions demands a unique category.

Chapter 4 discusses PHP variables in detail, including PHP's flexible typing. If you recall, if you need to evaluate a string as if it were an integer, you can make use of the intval() function. See Chapter 4 for similar variable conversion functions.

But at times the conversion will be a bit more extreme, turning strings into arrays and arrays into strings. Why, you ask, might you want to do this?

24.16,9,54,21,88,17

You have this string of integers, maybe retrieved from a text file. How would you go about sorting it in ascending order? If you have to deal with it as a string the code is going to get very nasty. However, if you can make use of myriad functions, life gets quite a bit easier. You could simply use the sort() function. Take a look:

```
$str = "24.16,9,54,21,88,17";
//turn $str into an array
$array = explode(".", $str);
//sort($array, SORT_NUMERIC);
//turn the array back into a string and print
$new_str = implode(".", $array);
echo $new_str;
```
