| Flag | Alternate Flag | Description |
| --- | --- | --- |
| -p[...] | --password[=...] | Password to use when connecting to server. If password is not given on the command line, you will be prompted for it. If you use the short form '-p' you can't have a space between the option and the password. |
| -P port_num | --port=port_num | The TCP/IP port number to use for connecting to a host. (This is used for connections to hosts other than 'localhost', for which Unix sockets are used.) |
| -Ir | --ignore --replace --replace options control handling of input records that duplicate existing records on unique key values. If you specify --replace replace existing rows that have the same unique key value. If you specify --ignore, rows that duplicate an existing row on a unique key value are skipped. If you don't specify either, an error occurs when a duplicate key value is found, and the rest of the text is ignored. |
| -s | --silent | Silent mode. Write output when errors occur. |
| -u user_name | --user=user_name | The MySQL user name to use when connecting to the server. The default value is your Unix login name. |
| -c | --columns= | This option takes a comma-separated list of field names as argument. The field list is passed to the LOAD DATA INFILE sql command, which mysqldimport calls MySQL. For more information, please see 'LOAD DATA INFILE' |
