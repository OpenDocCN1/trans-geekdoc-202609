An interest: Suppose you want to test if a string contains a specific character, a space. You might think the following would work since strpos() returns FALSE if the second argument is not found.

```
if( strpos($str, " " ))
{
echo "thank you for including a space"
} else
{
echo "include a space, please"
}
```

But, if you remember back to Chapter 5, the value of zero will also test as FALSE. In the preceding code, if $str starts with a space, the condition will evaluate as FALSE. Therefore, if you want to use a test like this, you will need to alter the condition. In PHP 4 you can run a test against the constant FALSE. For example:

```
$str = "Whereisthefirstspace"
if( strpos($str, " \)==FALSE )
{
echo "you have not included a space."
} else
{
echo "thank you for the space."
}
```
