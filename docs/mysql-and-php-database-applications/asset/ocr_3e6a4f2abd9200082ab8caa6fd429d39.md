# Why PHP?

Programming languages are a like shoes. Look good to some people yet look really ugly to others. To carry the analogy a little further, some shoes just fit well on some feet.

What we mean is this; when it comes to Web programming, all languages do pretty much the same thing; they interact with relational databases; they all work with a filesystem; they all interact with a Web server. The question about which language is best is rarely a matter of a language's inability to perform certain actions. It is usually a matter of how quickly you can do what you need to do with the least amount of pain.

# IT'S FAST AND EASY

What about speed? There are really three things that we know for sure when it comes to comparing speeds of Web programming. First, applications written in C will be the fastest. Second, programming in C is rather difficult and will much longer than any of the other languages mentioned so far. Third, comparisons between languages are extremely difficult. From everything we know, we feel safe saying that the PHP is as fast as anything out there.

More than not choosing a language comes back to the same issues involved in buying shoes. You'll want to go with what feels comfortable. If you like us, PHP is the perfect mix of power, structure, and ease of use. Again, this is a matter of opinion, but we believe the syntax of PHP is superior to ASP and JSP And we believe it puts power over your fingertips quickly than ColdFusion and is not as difficult to learn as Perl.

In the end, we believe PHP offers the best opportunity to develop Web applications. That generalization, we believe there are other reasons for choosing PHP.

# IT'S CROSS-PLATFORM

In the rundown of Web architecture, we mentioned that PHP will run on Windows 2000/NT and Unix with IIS and Apache. The cross-platform abilities of PHP go far beyond these platforms. If you happen to be using Netscape, Roxen, or just about anything else, it is likely PHP will work with it.

Yes, ASP can run on Linux, and ColdFusion can run on Solaris and Linux, and JSP is adaptable across many platforms. At this point, PHP works as well as on a variety of systems as any other available product.

What do you need to access in the course of creating your Web applications? LDAP? IMAP mail? Oracle? Informix? DB2? Or may you need an XML parser or WDDX functions.

Whatever you need to use, it is more likely that PHP has a built-in set of functions that make getting whatever you need very easy. But what if it doesn't have something built in that you'd like? That brings us to our next point.
