## Appendix F: Regular Expressions

### Overview

REGULAR Expressions provide a means for pattern matching in strings. Patterns may be as simple as a literal, or they can grow to complex. If you're new to regular expressions this may look bad.

The Perl Compatible Regular Expressions (PCRE) are quite different in places, and they offer some functionality that cannot be replicated with the standard ere functions. After you have a good feel for regular expressions, you should probably head over to this page to see the differences: http://www.perl.com/pub/doc/manual/html/pod/perlre.html. The major PCRE functions are preg_match(), preg_match_all(), and preg_replace().

### Literal Patterns

The simplest possible pattern match is to of known characters. For instance, to match "jay" within a string, you could do this:

```php
$str = "this is a string with my name: jay";
if(ereg("jay", $str)){
  echo "pattern found";
} else {
    echo "string not found";
}
```

This will test and print "pattern found". However, with a simple string like this, you wouldn't need a regular expression. One of PHP's string functions would work and be a good deal faster. For example, in the preceding example, strstr($str, "jay") would work equally well.

### Characters

In regular expressions you can make use of the following characters:

- \n-Newline
- \t-Tab
- \r-Return
- \f-Form feed
- ^ (Shift-6)—Start of string
- $-End of string
- . (dot)-Matches any non-newline character.

So if you needed to match the word "jay" at the beginning of a string, you could do this:

```php
ereg("^jay", $str);
```

And if you wanted to make sure there was nothing before or after "jay" in the string, you could do the following:

```php
ereg("jay$", $str);
```

The meaning of the dot (.). It stands for any non-newline character. If you wanted to print whatever four characters followed "jay" in a string, you could do the following:

```php
ereg("jay....", $str, $arr);
echo $arr[1];
```
