```php
function workstart($when="")
{
    if (empty($when)) { $when = "now()"; }
    elseif($when != "create_dt") { $when = "$when"; }
    return $from_days(to_days($when)-dayofweek($when) + 1);
}
```

It works like: The MySQL to_days() returns an integer of the number of days since January 1, 2000. dayofweek() returns an integer representing the day of the week (Sunday 1, Saturday 7). So the portion to_days($now)-dayofweek($when)+1 will return an integer representing the Sunday of the week in question. The from_days() function turns that number into a date. The number 10 here limits the number of answers to each question. This block gets the answers for the selected question and prints them out text fields. Additional information is put inside hidden fields. When printed out the result for one answer will look like this:

```html
<input type="text" name="answer_text[1]" value="" size="60">
<input type="hidden" name="answer_id[1]" value="10">
```

When this is submitted, $answer_text will be an array. $account will see the key of the array is incremented by 1 for each additional field. That we need to make use of a hidden element. Because each answer requires two pieces of information: what the answer number is (1-10), the answer, and if the answer came from the database, we need to know the primary key of the row answer came from. The hidden field will create an array named $answer_id. The value in each element of array will be the primary key of the row. The index of array will match the index of $answer_text. So in code it looks like this:

```php
$i = 1;
$answer_text[$i];
$answer_id[$i];
```

You'd know that $answer_id[$i] contains the primary key of a row, and $answer_text[$i] is the answer that belongs in that row.
