**MYSQL_FETCH_ROW()** The mysql_fetch_row() function works almost exactly like mysql_fetch_array(), but it only returns a numeric array of the fetched row.

array mysql_fetch_row (int result)

> Tip There's generally little reason to use mysql_fetch_row(), and we recommend that you use mysql_fetch_array() instead. However, you will see many scripts use this function.

**MYSQL_INSERT_ID()** The primary key of a MySQL table will be an auto-increment field. In cases where you insert a query you may need to know the number MysID assigned to the newly inserted row.

```
int mysql_insert_id ((int link_identifier))
```
