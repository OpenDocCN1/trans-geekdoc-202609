# # phpMyAdmin

If you are an old-time Unix guy or gal, you may be perfectly comfortable keying in all of your commands and sorting out the errors when you mistype or sweep the syntax. But myself, I will be thrilled to know that a couple of programmers have used PHP to create a great Web-based interface to MySQL.

Best of all, they're giving their program away. All you need is to cruise over phpmyadmin.net and download the appropriate .gz, or .zip file. We have included it on the CD, but you're really off getting the most recent version off their site. It's constantly being improved.

This package will cover all the MySQL administrative functions you'll come across. Figures 2-3 and 4 show a bit of what you can expect for phpMyAdmin.
