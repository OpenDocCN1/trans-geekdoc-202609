# Includes

Every language has a facility for including external files. PHP has four commands that accomplish this. Before we get to those, we will briefly discuss why includes are so critical for writing organized and readable code. We'll start with a very common example.

In Web sites, header information will vary very little from page. There are opening tags (<HTML>, <HEAD>, etc), and perhaps some navigation information. The following is a typical header to an HTML page.

```
<HTML>
<HEAD>
<TITLE>My Page Name</TITLE>
</HEAD>
<body bgcolor="#FFFF" link="#8e0402" vlink="#20297c">
```

It would be an absolute waste to type this text into every file within a Web site. Moreover, it could be a real pain. Say you wanted to change the bgcolor attribute of the body> tag throughout the site. If this information were hard-coded in every file, you would have no choice but to go into each file individually and make the change, or write a script that would do it for you.

# Part II: Working with PHP

You are far better off keeping all of this information in a single file (maybe header.php) and then using a command that will split the contents of that into the file being accessed. For this, you would use one of the PHP functions discussed in the following section. For this example we will include().

> If you have access to your Apache httpd.conf file you will probably want to give your files a distinct extension: .inc is a typical choice. Additionally, if possible, you will want to keep your includes out of the htdocs directory, so that they cannot be accessed by a URL. We did not use either of these techniques in this book because most use ISPs to host their PHP/MySQL applications will not be able to alter their setups in this way.

Let's have two files, header.php and index.php. Notice that the <title> tags now contain a PHP variable

Now for the index.php.

```php
<?php
$page_title = "Welcome to My Site";
include('header.php');
echo "Here are the contents of my PHP pages. Anything could be here.";
?>
```

Notice that the variable $page_title will be picked up in the include. So when the index.php is served, the source code of the PHP page will be as follows:

```
<HTML>
<HEAD>
<TITLE> Welcome to My Site </TITLE>
</HEAD>
<body bgcolor="#FFFFFF" link="#8e0402" vlink="#20297c">
```

# include() and require()

These commands are very similar and can be used interchangeably. However, you should know what distinguishes the two, as at times using the one can cause problems.
The require() command imports the content of the specified file even if the file is not used. This means, for starts, even if the require() is within a block that tests false, the outside file will still be included. You can probably deduce that this isn't a big deal because code within a block that tests false won't be executed. However, it takes time for PHP to do the import, and there is no need to add execution time to your script by placing a require within a block that could test false.

![](img/245156cc770929860a3ede93c01f9981_203_1.png)

> There are other differences between include and require in the PHP manual, but these are more relevant to PHP 3. PHP 4 is pretty smart handling includes and decides for which is the best for you when it interprets your script. It is very difficult to write a script that will be different using include and require.

The include() command will work better in a situation like the one above. include() command will be executed each time it is encountered within a script.

# User-Defined Functions

The great thing about user-defined functions is that they allow you to reuse code. Instead of writing the same code over and over, you can write it once in a function and call it whenever you need it. This makes your code much cleaner and easier to maintain.

A function is defined in PHP using the `function` keyword, followed by the name of the function and a pair of parentheses. The code to be executed by the function is placed within curly braces.

```php
function sayHello() {
    echo "Hello, world!";
}
```

To call the function, you simply use its name followed by parentheses:

```php
sayHello();
```

Functions can also take arguments, which are values you pass into the function. Arguments are defined in the parentheses of the function definition and used when the function is called.

```php
function greet($name) {
    echo "Hello, " . $name . "!";
}
```

```
greet("Alice");
greet("Bob");
```

Functions can also return values to the caller using the `return` statement.

```php
function add($a, $b) {
    return $a + $b;
}
```

```
$result = add(5, 10);
echo $result; // Output: 15
```

User-defined functions are a powerful tool in PHP. They allow you to organize your code, reduce redundancy, and make it easier to maintain.

# Function basics

We'll start writing a simple function that writes out the start of an HTML table.

```php
function start_table() {
    echo "<table border=1\n";
}
```

To call this function within our PHP page, we would access it just like a built-in PHP function:

```
start_table();
```

That's easy enough. But what if we want the border to vary in given situations? We could make the border a variable, and then in the function call specify the value for border.

```php
function start_table($border) {
    echo "<table border=$border\n";
}
```

```
start_table(1);
```

Now that most of the time we want the border to be 1, but would like to change the border within the function call. The following would do the trick:

```php
function start_table($border=1) {
    echo "<table border=$border\n";
}
```

Here $border has been given a default value of 1. But we can overwrite that value by specifying a different value when calling the function. For example, if we were to call the function with the following command, the table would have a border of 2:

```
start_table(2);
```

Once again, 1 is the default value, so if this function is called with the following code, the table border will be 1:

```
start_table();
```
