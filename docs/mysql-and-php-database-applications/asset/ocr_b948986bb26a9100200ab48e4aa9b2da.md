MYSQL_ERRNO() If there is a problem with a query, this function will spit out the
error number registered with MySQL.

```
int mysql_errno ([int link_identifier])
```

On its own, this isn't terribly helpful. For the most part, you would only use
if you wished to use custom error handling. Better error messages come from mysql-
error() which is discussed next.

MYSQL_ERROR() This function should accompany every mysql_query() you run.

```
string mysql_error ([int link_identifier])
```

As you can see in code samples throughout the book we make use of mysql-
error with the die statement.

```
mysql_query("select * from my_table") or
die (mysql_error()));
```

Without it, you will only know that your query has failed. You won't know if
y're searching for a database that doesn't exist or if you're trying to insert a
string into a numeric field, or have made some sort of syntactic blunder.

MYSQL_RESULT() This function, grabs the contents of a specific cell, should
be used sparingly.

```
mixed mysql_result (int result, int row [, mixed array])
```

It's relatively slow and can always be replaced by mysql_fetch_array().
However, if you need to get data from a single cell it can be convenient.
The second argument will be the number of the row you are accessing. The third
can either be the numeric offset of the column or the column name.

Here's an example of how you could use mysql_result(). In this case, we're
unning a simple count(), so there is only one value to be accessed. Using mysql_
result() is a bit easier than: mysql_fetch_array().

```
mysql_connect("localhost", "username", "password");
mysql_select_db("test");
$result = mysql_query("select count(*) from users") or
die (mysql_error()));
echo mysql_result($result,0);
```
