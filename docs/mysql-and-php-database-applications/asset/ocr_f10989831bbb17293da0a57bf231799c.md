This page provides another view. If a user clicks on a thread that does not start a topic, the page will show all threads beneath. At the top of the page the script will print the top-level post (or root) and the post immediately prior to the one being viewed (parent). Figure 12-3 shows an example of this view.

Everything in the previous figures was handled by one page. The second page will post threads to the board. This requires only a simple form that form elements for a subject, a name, and room for the comment. The form will need to be aware of where in the thread message belongs. For new top-level topics without any context will be free (see Figure 12-4), but for replies within an existing thread some context will be helpful (see Figure 12-5).
