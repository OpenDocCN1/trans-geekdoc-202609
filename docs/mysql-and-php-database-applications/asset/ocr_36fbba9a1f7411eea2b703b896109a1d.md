If you're wondering how this would work if your function contained some parameters prior to the set of arguments that might vary, good for you: it's an excellent question.

There are two PHP functions that will work in such situations: func_num_args(), which returns the number of arguments sent to a function, and func_getarg(), which returns a specific argument based on its numeric index, starting at 0. So, for example, you might have a function that prints an HTML form with a variable number of fields.

```
function print_form($action="", method="POST") {
  if (empty($action)) return FALSE;
  echo "<form action=$$action method=$$method>";
  $numargs = func_num_args();
  for ($i = 2; $i < $numargs; $i++) {
    echo "<input type=text name=" . func_get_arg($i) . ">";
  }
  echo "</form>";
}
```

# Variable scope

To with functions you need to understand how PHP handles variable scope. Scope is an important topic in any programming language, and PHP is no different.
In PHP, variables assigned outside of functions are known as global variables. These can be variables that you create, they come from HTML form elements through either GET or POST, or they may be any of the variables inherited from the Apache environment. All globals are accessible from an array known as \$GLOBALS. You can add to delete from this array.
