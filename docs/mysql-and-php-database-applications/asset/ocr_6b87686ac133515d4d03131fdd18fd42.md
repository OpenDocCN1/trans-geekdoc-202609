| Function | Returns | Action |
| --- | --- | --- |
| curl_setopt (int ch, string option, mixed value) | bool | Sets an option for a CURL transfer |
| curl_exec (int ch) | bool | Performs a CURL session |
| curl_close (int ch) | void | Closes a CURL session |

Use of these functions requires the curl library and PHP to be compiled --with-curl. The cURL functions are discussed in more detail in Chapter 14.
