# Part III: Simple Applications

The number 10 here limits the number of answers to each question to 10. This block gets the answers for the selected question and prints them out outside text fields. Additional information is put inside hidden fields. When printed out the result for one answer will look like this:

```
<input type="text" name="answer_text[1]" value="Answer
size="60">
<input type="hidden" name="answer_id[1]" value="10">
```

When this is submitted, $answer_text will be an array. $account will see the key of the array is incremented by 1 for each additional field name. That we need to make use of a hidden form element. Because each answer requires two pieces of information: what the answer number is (1-10), the answer, and if the answer came from the database, we need to know the primary key of the row answer came from. The hidden field will create an array named $answer_id. The value in each element of array will be the primary key of the row storing the answer. The index of array will match the index of $answer_text. So in code it looks like this:

```
$i = 1;
$answer_text[$i];
$answer_id[$i];
```

You'd know that $answer_id[$i] contains the primary key of a row, and $answer_text[$i] is the answer that belongs in that row.
The previous section of code will print form elements only where there is an answer. By you should offer block form elements the administrator can enter new answers.

```
while ($account < 10) {
  $account++;
  print text_field("answer_text[$account]",","60);\n  print hidden_field("answer_id[$account]",0);
```
