# # Basic Architecture

At the most basic level, the Web works off of a client/server architecture. Simply stated, that both a central server and a client are responsible for some amount of processing. This differs from a program such as Microsoft Word, which operates just fine without any help from a server. Those of you who used older VAX machines will remember the days of dumb terminals, which had no processing whatsoever. Depending on whatever you work today, perhaps in a university or a bank, you may still use applications that are in no dependent on the client. In other words, all the work is done on the central computer.
