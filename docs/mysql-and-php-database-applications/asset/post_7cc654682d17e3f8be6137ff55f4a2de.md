```php
$knicks = array("sprewell", "houston", "Ewing", "childs");

```

Additional arrays can be added to the function. For example:

```php
$knicks = array("sprewell", "houston", "Ewing", "childs");
$all_stars = array("mourning", "houston", "carter", "davis");
$miller = array("miller");
$non_knick_all_stars = array_diff($all_stars, $knicks, array("carter"));
```

Given this, "carter" will also be removed from the returned array.

### ARRAY_INTERSECT() This returns the elements that two (or more) arrays have in common.

```php
array_intersect (array1, array2, [ ... ])
```

### ARRAY_POP() The array_pop() function returns the last element in an array, and removes that from the original array.

```php
mixed array_pop (array)
For example,
$array = array(1,2,3,4,5);
$int = array_pop($array);
```

After this runs, $array will contain (1,2,3,4), and $int will contain 5.

### ARRAY_PUSH() This function will add elements to the array indicated in the first argument.

```php
array_push (array, mixed var [, . mixed ...])
```

The additional values will be values you wish to tack onto the array.

```php
$array = array(1,2,3);
array_push($array,4,5,6);
```

The resulting array will contain 1,2,3,4,5,6.

### ARRAY_RAND() This function will pick one or more random elements from an array.

```php
mixed array_rand (array input [, int num_req])
```

Note that it does not pick the value; rather it picks the key of the chosen elements. For instance, given the following:

```php
rand((double) microtime() * 1000000);
$names = array("Jay", "brad", "john", "Jeff");
$rand_keys = array_rand($names, 2);
```

$rand_keys will contain an array with two numbers. To get the values from the $names array, you will first need to get the key value extracted by array_rand(), and you will need to use something like this:

```php
echo $names[$rand_keys[0]];
```

> Tip Seed the random number generator only once per script.

### SHUFFLE() This function randomizes the elements in an array.

```php
void shuffle (array array)
```

You will need to seed the random number generator before using it. For instance:

```php
rand((double) microtime() * 1000000);
shuffle($array);
```

### IN_ARRAY() This convenient function will search all of the values of an array, and return TRUE if the value in the first argument is found in the array in the second argument.

```php
bool in_array (mixed needle, array haystack)
```

You might be wondering if there is an in_keys() function. Actually, there is no need for such a function, because the following will serve the same purpose:

```php
if(isset($array["key"]))
```

### SORT() If there is no second argument, this function will sort an array in ascending or alphabetical order.

```php
void sort (array array [, int sort_flags])
```

The flags can be:

- SORT_NUMERIC—compare items numerically
- SORT_STRING—compare as as strings

If the array you wish to sort has only numbers, PHP will sort the array numerically; if the array contains only strings, it will be sorted alphabetically. If the array has a mix of strings and numbers, it defaults to sorting by a string.

# Print functions

There are a few functions that you can use to print information to the screen. Only two pop up in this book, but you should be aware of all the functions listed in this section.

# PRINT FUNCTIONS USED IN THIS BOOK

In this case the "functions" may be something of a misnomer. For instance, print() is probably better described as a language construct. In any case, you will use all of these very much like you will use functions; thus, they are included here.

### PRINT As you would expect, this prints what you specify.

```php
print
```

### ECHO This also isn't a function, but a language construct. We use it constantly throughout this book, so at this point you probably know what it does.

```php
echo
```

Keep in mind that you can mix variables and code within double quotes.

```php
$var = "this string";
echo "Please print $var";
```

However, within single quotes the string will be treated literally.

```php
$var = "this string";
echo 'Please print $var';
```

The preceding code will print "Please print $var". This concept is discussed in greater detail in Chapter 4.

![](img/245156cc770929860a3ede93c01f9981_181_0.png)

print versus echo. Which one should you use? This is very much a matter of personal preference: use whichever you think better on the page. There's only one major difference between the two, and this may influence your decision. echo can take multiple arguments. That is, with echo, different portions can be separated by commas. This will work:

```php
echo "this is part 1", "this is part 2";
```

But this will not:

```php
print "this is part 1", "this is part 2";
```

### PRINT_R() This function is great for putting to productive the time you'd otherwise spending pulling your hair out. It prints the contents of any variable—most notably arrays and objects—to the screen.

```php
void print_r (mixed expression)
```

We use it frequently when we're not getting the results we expect from arrays and objects.

![](img/245156cc770929860a3ede93c01f9981_181_1.png)

Do not print_r($GLOBALS). You will create an infinitely recursive loop.

### VAR_DUMP This function behaves like print_r, but gives you a bit more information.

```php
void var_dump (mixed expression)
```

In addition to printing out the contents of a variable, it includes the type.

# DATE/TIME USED IN THE BOOK

The following are some date/time functions.

```php
string date (string format [, int timestamp])
```

If you include a second argument, value will be formatted. Otherwise, the current time will be used.

> Tip The time and date functions are based on the server. You will need to make use of the client's computer.

You can format the date using any of the indicators in Table 6-1.
