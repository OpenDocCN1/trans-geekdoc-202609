PHP HAS AN AMAZING number of built-in functions. Many are only available to you if PHP is compiled with certain options. If, for example, you need to do some XML parsing, PHP has two functions that can help you. (One uses a SAX approach, the other a DOM approach). If you need LDAP, IMAP, or PDF functions, there is a function set for each. Additionally, PHP has an API (application programming interface) for about every relational database on the planet. But really, there’s no need to cover most of these functions in this book.

Another thing to keep in mind is that the function set is changing almost daily. PHP 4 is internally structured in a way that makes it extremely easy for programmers to add additional functions. In fact, if you know your way around C, you could easily add a new function into PHP in a few hours. So you can expect additions to the core function set.

Your best friend, as always, is the online PHP manual: http://www.php.net/manual. It is the only source where you can be sure that the list of functions is up to date. If you want to go directly to the explanation of a function, all you need to do is point your browser at http://www.php.net/function_name.

We want to point out one more thing before we get started. There are seven applications in the final two portions of this book. In the course of creating these functions, we made use of little over 100 of PHP’s built-in functions. While there are thousands of built-in functions, you will probably only make regular use a relatively small number.
