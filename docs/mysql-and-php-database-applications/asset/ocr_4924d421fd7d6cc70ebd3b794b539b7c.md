```

```

Waiting? A little more code from your shopping cart? Well, most of it is in the include (cart_form.php). Just note that the session is started. And that there are two session variables which will be tracking. The cart object, as you will see in a moment, is created on the page, two things happen. First, if they exist already, they are pulled into the session file. Second, if they are changed in the course of the page, they will be written out with those changes at the end of the page.

Note that the $Last_item variable holds the description of the last item ordered by the user. We use it to prevent multiple orders of the same item, typically caused by the user hitting the Order! more than once. If the user wants two of an item instead of one, they can change the quantity for the item.
