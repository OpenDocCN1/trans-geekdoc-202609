The other item of particular interest is the extensive text processing in this script. This is an example of the type of processing you might need to do if your users are working with some sort of processing tool (HTML editor, word processor). Every tool has its own little quirks that you will need to account for. The only way you are going to find out exactly what type cleanup you need to do is examine the code created the text editor in your workplace.

For instance, you are not going to have <body> tags in the body of an article.

```
$body = eregi_replace(".*<body[^]*>.*",","",$body);
$body = eregi_replace("</</body>.*.*","",$body);
```

Of course, PHP's strip_tags function could work for you, if you want to allow a limited tag set and remove all others tags.
