DISPLAY_KIDS() Usually in this part of the book, a function is displayed and then described. However, this function must be treated a bit differently because recursion can be somewhat difficult conceptually. Before I display the function, let's take a look at recursion (If you already know your way around recursive functions, feel free to skip).

The important to keep in mind is that you have no idea how deep any thread will be; there may be one level of replies, or there may be twenty. So to properly lay all the children of any thread you need a very, very flexible script. It will need to do something like this:

```
print current topic
while the current topic has unprocessed child topic
    set current topic to next unprocessed child
    go to line 1
end while
if current topic has a parent
    set current topic to that parent and go to line 2
else
    exit
end if
```

This must be repeated indefinitely until there are no other answers. How do you well tell a script to do something until it runs out of answers? The looping mechanisms we discussed so far won't really work. The for... while..., and do...while loops that we talked about Chapter 2, and that we've used in the previous chapters, are of no help.
