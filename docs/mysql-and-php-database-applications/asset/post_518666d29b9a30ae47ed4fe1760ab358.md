## Instantiating an object

Instantiating basically means "creating." Let's say we have a PHP page that is intended to delete categories. To make this work with the above class, we need to do a few things. First, we need to include the file containing the class.

```php
require "classes.php";
```

Next we have to create an instance of the object. We can do this with the key-word:

```php
$c = new Category;
```

Now, using object $c, we can access any of the properties or methods using the same syntax seen in the previous example: $c->property or $c->method(). We want to put together a page that actually removes a category from the database. For the sake of this example, assume that a single $category_id has been passed via the querystring.

```php

$c = new Category($category_id);
```

## Inheritance

So far, we have worked with only one class. But one of the great advantages of object-oriented programming is that methods and properties from one class are inherited by another. We'll show a very quick example of this by writing a class called Product. Here's the shell:

```php
class Product extends Category {
    var $product_id;
    var $product_name;
    var $product_price;
}
```

Notice the use of word extends. This tells PHP that all of the products and methods available in Category should be available in Product. If we wanted to call the delete_category() method from within the Product class, we could call it with $this->delete_category($category_id).

## Part II: Working with PHP

> Tip: In PHP, constructor methods of parent classes are not automatically run when the child class is called. For example, calling $p = new Product does not run the Category() method.

We'll add a quick constructor method:

```php
class Product extends Category {
    var $product_id;
    var $product_name;
    var $product_price;

    function Product($product_id=0) {
        //expecting a product_id to be passed
        if ($product_id ==0) {
            return FALSE;
        }

        $query = "select product_name, product_desc, product_price, category_id from products where product_id = $product_id";

        $result = mysql_query($query);
        list($this->product_name, $this->product_price) = mysql_fetch_array($result);

        $this->Category($category_id);
    }
}
```

Notice that this method not only assigns values to the properties for this product, it also calls the constructor of the Category class, which then assigns values to those properties. Note that of inheritance, we could write a script as follows:

```php
require 'classes.php';

$p = new Product($product_id);
echo $p->category_name;
```

You see that the properties of Category are available to the Product object.
