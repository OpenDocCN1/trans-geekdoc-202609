Notice that the function has only two default arguments ($row and $preserve), which the call to the function has nine arguments. The first argument, $row, is from a database call. It is expecting that the row was taken from a query using `mysql_fetch_array()` so that the contents of row are associative array, the keys of which are equal to the column names of the database table. The second argument, $preserve, is needed for the `cleanup_text` function, which we have discussed previously. The rest of the arguments are equivalent to associative keys in $row.

The arguments sent to any user-defined function make up an array. The number of the final element in the array can be retrieved with `func_num_args()`. Using the call to `print_entry()` seen above, the previous paragraph, `func_num_args()` would return 8. (There are 9 arguments, the first of which is 0).

The value of each argument can be accessed via `func_get_arg()`. This allows for a structure like the one used here, where a loop accesses and then processes each argument sent to the function. The first time for the loop, $field is assigned the third element in the array, "name". You can use the value in $field to access the element in the associative array `$row("name")`.

After you make sure the argument contains no capital letters or spaces, the value is sent to the `cleanup_text` function and printed. It's nice to structure a function like this because it allows an arbitrary number of arguments to be sent to the function. You could include one or many fields to print.

```php
function create_entry($name,$location,$email,$url,$comments)
{
    // remove all HTML tags, and escape any
    // other special characters
    $name = cleanup_text($name);
    $location = cleanup_text($location);
    $email = cleanup_text($email);
    $url = cleanup_text($url);
    $comments = cleanup_text($comments);

    // start out with an empty
    // error message. as validation tests fail.
    // add errors to it.
    $errmsg = "";
    if (empty($name))
    {
        $errmsg .= "<li>you have to put in a name, at least!\n";
    }

    // do a very simple check on the format of the email address
    // supplied by the user. an email address is required.
    if (empty($email)) || preg_match("/^([A-Za-z0-9\-_]+@[A-Za-z0-9\-_]+\.[A-Za-z0-9\-]+\+.*$/", $email))
{
    $errmsg = "<li>$email doesn't look like a valid email address</li>";
}
else
// if the format is OK, check to see if this user has already
// signed the guestbook, multiple entries are not allowed.
$query = "select * from guestbook where email = '$email'";
$result = safe_query($query);
if (mysql_num_rows($result) > 0)
{
    $errmsg = "<li>$email has already signed this guestbook.\n";
}

// perform a very simple check on the format of the url supplied
// by the user (any)
if (empty($url) && !preg_match("/^https?:\//", $url))
{
    $errmsg = "<li>$url doesn't look like a valid URL</li>";
}
if (empty($comments))
{
    $errmsg = "<li>comments cannot be empty</li>";
}

$query = "insert into guestbook (name,location,email,url,comments) values ('$name','$location','$email','$url','$comments')";
safe_query($query);
$errmsg = "<li>Thank you for signing our guestbook!</li>";
echo "<h2>Thanks!</h2>";
```

`NAV()` This function's purpose is to create navigational elements.

function nav ($offset=0,$this_script="")
{
    global $PHP_SELF;

    if (empty($this_script)) { $this_script = $PHP_SELF; }
    if (empty($offset)) { $offset = 0; }

    // get the total number of entries in the guest book
    // we need this to know if we can go forward from where we are
    $result = safe_query("select count(*) from guestbook");
    list($total_rows) = mysql_fetch_array($result);

    print "<p>";
    if ($offset > 0)
    {
        // if we're not on the first record, we can always go
        backwards
        print "<a href=\$this_script?offset=$($offset-PAGE_LIMIT).&lt;Previous Entries&gt;/&nbsp;";
    }
    if ($offset+PAGE_LIMIT < $total_rows)
    {
        // offset + limit gives us the maximum record number
        // that could have displayed on this page, it's
        // less than the total number of entries, that means
        // there are more entries to see, and we can go forward
        print "<a href=\$this_script?offset=$($offset+PAGE_LIMIT).\">&lt;Next Entries&gt;&lt;/a&nbsp;";
    }
    print "</p>";
}
