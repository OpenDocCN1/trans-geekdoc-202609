SET_RESULT_VARIABLE() This function turns results of a query into global variables.

```
function set_result_variables($result)
{
    if(!$result || mysql_num_rows($result)) { return; }
    $row = mysql_fetch_array($result,MYSQL_ASSOC);
    if(!is_array($row)) {
        print "<no array returned : result=$result row=$$row";
        return $result;
    }
    while (list($key,$value) = each($row)) {
        global $$key;
        $$key = $value;
    }
}
```

If you remember our discussion about variable scope in Chapter 7, you'll remember that variables passed through either GET or POST or declared outside of a function are globals, and they are available within the GLOBAL's array.

Frequently, you are going to use the column names used in your query as variables. It is nice to be able to use them without having to go through the associative array using mysql_fetch_array(). This function will transform the variables used in your query into globals throughout your script.


This code will make the variables $fname and $lname, along with their values, available as globals. If a result set with multiple rows is sent to the query, only the first row is used by this function.
