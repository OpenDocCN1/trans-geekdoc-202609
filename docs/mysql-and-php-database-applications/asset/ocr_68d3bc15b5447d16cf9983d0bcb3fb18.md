For the remainder of this chapter you will see how to build on the complexity of the select statement. See things in action, we created a table in MySQL which we can run these queries. This is the create statement for a table named "users", which holds personal information:

```
CREATE TABLE users (
userid int(10) unsigned NOT NULL auto_increment,
fname varchar(25) NOT NULL,
name varchar(25) NOT NULL,
addr varchar(255) NOT NULL,
addr2 varchar(255),
city varchar(40) NOT NULL,
state char(2) NOT NULL,
zip varchar(5) NOT NULL;
```
