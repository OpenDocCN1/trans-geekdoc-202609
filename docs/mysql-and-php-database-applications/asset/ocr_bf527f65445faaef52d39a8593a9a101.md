STR() This function takes the string in the first argument and translates each character in the second argument to the corresponding character in the third argument.

```
string strtr(string str, string from, string to)
or
string strtr(string str, each, associative array)
```

So in the following *a* will be tuned into an *i* and each *o* will be turned into *a*.

```
strtr($str, "ao", "iu")
```

Note that it does all the replacements at once. For example, this code

```
$str = "i";
echo strtr($str, "iu", "uv");
```

you might think that function would first turn "i" into "u", then "u" into "v". This is not the case. It will do the replacements in a batch, so the output of this operation is "u".

This function can also work with only two arguments. In such cases, the second argument should be replaced by its corresponding value in the string.

```
$str = "this are strings";
$replace_array = array("this"->"these", "is"->"are");
echo strtr($str, $replace_array);
```

This code prints "these are strings". Once again

UCFIRST() This function makes the first character in the string uppercase.

```
string ucfirst(string str);
```

Note that it leaves everything after the first character untouched. If you wanted to make sure that the first and only the first character of a string was capitalized, you would have to do something like this.
