# # DATE_ADD

These functions perform date arithmetic. They are new for MySQL 3.22.

```
DATE_ADD(date,INTERVAL expr type)

or
DATE_SUB(date,INTERVAL expr type)

or
ADDDATE(date,INTERVAL expr type)
```

SUBDATE(date,INTERVAL) (used in examples)
RETURNS: date

ADDDATE() and SUBDATE() are identical to DATE_ADD() and DATE_SUB(). In MySQL 3.23, you can use + - instead of DATE_ADD() and DATE_SUB(). (See example.) date is a DATETIME or DATE value specifying the starting date. expr is an expression specifying the interval to be added or subtracted from the starting date. expr is a string; it may start with a - negative intervals. type is a keyword indicating how the expression should be interpreted.

Table I-1 shows how the type and expr arguments are related.

# Table I-1 DATE_ADD() OPERATORS

| type | Meaning | Expected expr format value |
|---|---|---|
| SECOND | Seconds | SECON |
| MINUTE | Minutes | MINUTES |
| MINUTE_SECOND | Minutes and seconds | "MINUTES:SECONDS" |
| HOUR | Hours | HOURS |
| HOUR_SECOND | Hours, minutes, seconds | "HOUR:MINUTES:SECONDS" |
| HOUR_MINUTE | Hours and minutes | "HOUR:MINUTES" |
| DAY | Days | DAYS |
| DAY_SECOND | Days, hours, minutes, seconds | "DAYHOURS:MINUTES:SECONDS" |
