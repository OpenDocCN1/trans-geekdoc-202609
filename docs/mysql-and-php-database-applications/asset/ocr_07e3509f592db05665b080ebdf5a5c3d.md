Say you want each level to be indented little further than the previous one, with the HTML blockquote tag. Now that you're calling the below function by passing the topic_id of 7.

```
function RecurFor($topic_id) {
  $query = "SELECT * from topics WHERE topic_id = $topic_id";
  $result = mysql_query($query) or
  die("Query failed");
  $row = mysql_fetch_array($result);
  echo "<blockquote>";
  echo $row["name"] . "\n";
  RecurFor($row["parent_id"]);
}
```

You may know how to actually run a script like this—there's no error checking, and eventually, when there are no responses to the query, it will cause an error. I wrote this function so you can look at the last line. You see what it does: the function calls itself. If you're not clear about the impact this will have, let's walk through it.
