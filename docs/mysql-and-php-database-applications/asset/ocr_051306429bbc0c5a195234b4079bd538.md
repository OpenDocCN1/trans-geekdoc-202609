# TEXT EDITOR

As of this writing, there are no slick, integrated development environments (IDEs) for PHP. To code PHP and your Web pages, you will need a text editor. You could use Notepad or something similarly basic, but if you're starting without an allegiance to any particular editor, I suggest you get something with syntax highlighting. On Windows, Allaire's Homesite (www.allaire.com) is a tool that works well with PHP, and we've heard excellent things about Editplus (www.editplus.com).

If you have been working on Unix for some time, it is likely that you already know and love some text editor or another, whether it be Emacs, vi, or K. If any of these are fine, the first two do not take getting used to. If you're working on Unix, but don't have the patience to learn vi, try Pico. It is very easy to use.

> Tip If you need a text editor under Unix but don't know your way around vi, try Pico. It's a very basic, easy-to-use text editor.
