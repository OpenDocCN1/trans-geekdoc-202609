## Returning values

Of course your functions will do more than print HTML. Functions may perform database calls or mathematical computations or do some string handling. They can just about anything, and often you will want to make the result of the script aware of the results of your function. You can do this by using the keyword return. When a function hits the return it leaves the function, and it will return whatever you specify—a variable, a boolean value (TRUE or FALSE), or nothing at all, if that's what you prefer.

```php
function basic_math($val1, $val2)
{
  $added = $val1 + $val2;
  return $added;
}
```

You could call this function and print the results.

```php
$added_value = basic_math(5,4);
echo $added_value;
```

If, the following would work equally:

```php
echo basic_math(5,4);
```

Functions can return any type (strings, object, arrays, and the like), or, in the case of database calls, they can return identifiers. Additionally, functions can return FALSE. If you read Chapter 5, you may remember that in PHP, any non-zero, non-false value will be evaluated in an if statement as true. So we might want to improve the previous function by making sure the values passed can be added.

```php
function basic_math($val1, $val2)
{
  if (!is_int($val1) || !is_int($val2))
  {
    return FALSE;
  }
  $added = $val1 + $val2;
  return $added;
}
```

What will happen if the sum of arguments to the function equals zero, so -1 and 1. And, as we discussed in Chapter 5, 0 is FALSE in PHP. So you need to be careful about situations. Take a quick look at the following function. We think it's a good example of how functions can save you time, headaches, and keystrokes. The mysql_query function is fine; it sends a query to MySQL and if it succeeds, returns a result. If it fails, does not automatically return any information. Unless you do a bit of digging, you won't know what the problem was with the query. For every query in your applications (and there will be plenty) tack on or die:

```php
mysql_query("select * from table_name") or die("Query failed:" . mysql_error());
```

But life gets quite easier if you create a function like the following, and then send all of your queries through that function.

```php
function safe_query($query = "")
{
    if (empty($query)) { return FALSE; }
    $result = mysql_query($query) or die("Query failed: " . mysql_error());
    return $result;
}
```

So your applications might include a file with this function on every page, and then use safe_query() in place of mysql_query().

function print_form($action="", method="POST") {

  echo "<form action=$action method=$method>";
  $numargs = func_num_args();
  for ($i = 0; $i < $numargs; $i++) {
    echo "<input type=text name=" . func_get_arg($i) . ">";
  }
  echo "</form>";
}

## Variable scope

To work with functions you need to understand how PHP handles variable scope. Scope is an important topic in any programming language, and PHP is no different. In PHP, variables assigned outside of functions are known as global variables. These can be variables that you create, they come from HTML form elements through either GET or POST, or they may be any of the variables inherited from the Apache environment. All globals are accessible from an array known as $GLOBALS. You can add to delete from this array.

> Tip We've said it before, and we'll say it again: phpinfo() to get information about variables in your environment or your configuration.

In PHP a global variable is not automatically available within a function. If you want to use a global within a function, you must indicate within the function that the variable you are accessing is a global. Here is an example of using a global within a function:

```php
function add_numbers($val_2)
{
  global $number;
  echo $number + $val_2;
}
$number = 10;
add_numbers(5);
```

This code will print "15". Here $number is a global because it was assigned outside of a function. Using the keyword global tells PHP that we want to fetch the specified number from the $GLOBALS array. This code could also be written like this:

```php
function add_numbers($val_2)
{
  echo $GLOBALS["number"] + $val_2;
}
$number = 10;
add_numbers(5);
```

In the applications in this book we will be using the technique shown in the first example, as it seems a bit cleaner. It's nice to see where your variable is coming from the top of the function.
