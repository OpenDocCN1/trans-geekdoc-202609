# admin_winners.php

We created a few pages to ensure that the winner is notified of the exciting news and that we give the notification in a way that gives some security. This isn't much, but to make reasonably sure that the person who claimed the prize was the person you intend, you would need to make use of a login system, and users of a silly little survey may not be interested in keeping track of yet another reward.
The best we can do here is make sure that if improper person sees the claim information one week, that will not be able to spoof our system in future weeks. When we send the winner notification, we will include an eight-character claim code. This prize can only be claimed with knowledge of the code.
