# Part III: Simple Applications

To make things as secure as possible, we want to make sure this code is unique and very difficult to guess.

```
mt_rand((double)microtime()) * 1000000;
$claim_code = substr(md5(uniqid(rand()))),0,8);
```

This uses the uniqid() and md5() functions to create a string that is very random. There's little for a hacker to latch onto when trying to figure out how the string is constructed. md5() will create a string that is 32 characters, but that can be a bit unwieldy. We're using substr() to limit the string to 8 characters. The user_id, claim code, and the week of interest are inserted into the winners table.

```

values('$weekdate, $user_id, '$claim_code', now()))";
```
