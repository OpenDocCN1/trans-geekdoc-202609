# Part II: Working with PHP

You can use this function in two ways. First, you can place a regular expression
in the first argument and for its existence in the second argument. The func-
tion will return TRUE or FALSE, depending on the outcome of the search. For
example:

```
if (ereg("http://.*", $str) {
    echo "This is a URL:";
}
```

The third argument is an array that is created from the regular expres-\sion. The portions of the regular expression that will become elements in the array
are indicated by parentheses in the regular expression.

```
ereg("(....)(..)-(.*)", $publish_date, $date_array);
```

This example was taken from the Content Manager application, creates
an array $date_array, wherein the first element will be the complete string
matched by the regular expression. The next three elements in the array will be
portions indicated by the regular expression. So $date_array[1] will contain 4 charac-	ers, and $date_array[2] and date_array[3] will contain 2 characters each.
Note that arrays created by the third argument in ereg() will always contain II
elements. Even if you have more than ten substrings within parentheses, only the first
10 will be in the array. If you have fewer than 10 substrings, the array will still
contain 11 elements. If you want to test whether anything exists in the array element,
have to test against an empty string(""). An isset() will always test TRUE.
After running this code:

```
$publish_date = "2000-10-02"
ereg("(....)(..)-(.*)", $publish_date, $date_array);
```

$date_array would contain the following:

```
[0] => 2000-10-02
[1] => 2000
[2] => 10
[3] => 02
[4] =>
[5] =>
[6] =>
[7] =>
[8] =>
[9] =>
```

Note that ereg() performs a case-sensitive match.
