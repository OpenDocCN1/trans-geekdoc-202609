As mentioned, one of the goals of this application is to make use of the classes created in the catalog. We want to write little new code as possible. We inherit the methods and properties in the classes we already created.

One class from Chapter 10 doesn't quite do enough for inclusion in the. That is the Base class. We're going to create another Base class with some extended functionality. Then all we have to do is make the categories that extend Base call our new version. This is easily done with includes. In our classes.php file we include the new Base class, and then, when a class that extends Base is included, it sees the new class. When you look at the classes.php file, remember that the entire content of each of the included files is sucked into this file when it is parsed by PHP.
