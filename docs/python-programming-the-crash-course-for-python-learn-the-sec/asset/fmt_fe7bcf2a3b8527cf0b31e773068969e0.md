## Working with the regression algorithm

The second Python machine learning algorithm that we are going to focus on here is called the regression analysis. This algorithm is going to help you out when you would like to see whether there is any relationship, and what type of relationship, will show up between the two variables in your code, the predictor variable ad the dependent variable. This is a technique that often works well when you would like to make sure you can check out whether there is a casual relationship that shows up in the forecasting part of the variable, or the time-series modeling in place. The reason that a programmer would want to work with the regression algorithm at all is that it is able to take ahold of the information that you have, and then can fit it back onto a simple curve, and often a line, as much as possible. There may be some points that are way far away from this line, but the line or the curve is set up to handle the majority of the data points as much as possible.
