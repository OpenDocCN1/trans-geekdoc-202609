
机器学习已成为近期技术中一个新兴学科。它可用于多种领域，例如计算生物学、计算机视觉、计算机安全等。数据分析（`DA`）是现代工业中同样重要的一部分。`ML` 和 `DA` 通过应用统计方法分析数据，并基于对观测数据的分析为计算机提供学习能力。根据学习方式，机器学习算法（`MAA`）基本上可分为不同的组，即监督学习（`SL`）、无监督学习（`UL`）和半监督学习（`SSL`）。使用 `ML` 技术的主要缺点通常被认为是计算时间和存储，尤其涉及大量数据时。除此之外，当使用当前深度学习算法时，训练时间可能变得更长。在下一代中，研究人员通过利用量子计算机方法获得了可行的替代方案，该方法足以智能地减少上述提到的存储和计算时间。

许多 `ML` 问题使用线性代数通过将数据表示为矩阵来计算矩阵运算。量子计算（`QC`）能够使多种线性代数计算更快，从而无保留地改进经典 `ML` 任务 [[1](#bodymatter-001.xhtml#b_9783110670707-001_ref_001), [2](#bodymatter-001.xhtml#b_9783110670707-001_ref_002)]。数值优化方法是一个备受推崇的研究领域，其旨在改进所述优化程序的计算。与经典优化类似，量子优化作为 `QC` 的一个分支，试图进一步改进所述技术。这类著名的两种方法是量子梯度下降（`QGD`）[[3](#bodymatter-001.xhtml#b_9783110670707-001_ref_003)] 和量子近似优化算法（`QAOA`）[[4](#bodymatter-001.xhtml#b_9783110670707-001_ref_004)]。这些方法被有效地应用于量子神经网络（`QNN`），例如量子玻尔兹曼机 [[5](#bodymatter-001.xhtml#b_9783110670707-001_ref_005)]。

近来，量子机器学习这一非常新的新兴跨学科研究领域已出现，其目标是将机器学习理论与量子计算的特性融合在一起。量子机器学习（`QML`）旨在通过应用量子叠加和量子纠缠等量子特性以高效率解决不同问题，在量子环境（系统）中实现机器学习算法（`MLLs`）[[6](#bodymatter-001.xhtml#b_9783110670707-001_ref_006)]。基本上，`QML` 被认为是一个量子信息处理研究的子学科，其目标是引入通常从数据中学习的量子算法，以改进 `ML` 中的现有方法。因此，目的是开发各种 `MLLs` 的量子应用，同时具有量子计算机的影响以及 `MLLs` 的灵活性和学习能力。

已为多种机器学习模型引入了若干量子算法，其中包括神经网络（`NN`）、图形模型、支持向量机（`SVM`）等等。`QML` 从量子视角探索关于学习的更基本问题。在某些情况下，研究人员广泛地将 `QML` 定义为将 `ML` 应用于量子信息。

除了 `QML` 中使用的隐式方法外，还存在几种经典 `ML` 算法的量子版本。量子支持向量机（`QSVM`）[[1](#bodymatter-001.xhtml#b_9783110670707-001_ref_001)]，主要用于线性分类，是此类流行的例子。此外，量子主成分分析（`QPCA`）[[7](#bodymatter-001.xhtml#b_9783110670707-001_ref_007)]是一种流行的降维方法，量子高斯混合模型 [[8](#bodymatter-001.xhtml#b_9783110670707-001_ref_008)]是另一种用于估计聚类和密度的著名方法。`ML` 的一个新兴子学科称为深度学习（`DL`）。近日，量子计算机被用于涉及大量存储和时间的 `DL` 应用。这些应用的一些流行示例是量子玻尔兹曼机 [[5](#bodymatter-001.xhtml#b_9783110670707-001_ref_005)]、量子生成对抗网络 [[9](#bodymatter-001.xhtml#b_9783110670707-001_ref_009)]、量子卷积神经网络 [[10](#bodymatter-001.xhtml#b_9783110670707-001_ref_010)] 和量子变分自编码器 [[11](#bodymatter-001.xhtml#b_9783110670707-001_ref_011)]。此外，`ML` 内部一个更先进的领域被称为强化学习（`RL`）。`RL` 可以描述为通过探索环境随着时间的推移而学习。

## 1.2 Grover 搜索算法

Grover 搜索算法（`GAA`）是一种非常流行的量子搜索算法 [[12](#bodymatter-001.xhtml#b_9783110670707-001_ref_012)]。该算法找到满足特定条件的一组元素。为执行此任务，通常称为预言机的黑盒具有识别元素的能力，必须满足所需找到的标准。假设该组有 `N` 个元素，对于经典计算，预言机被调用 `O(M)` 次以获取满足上述标准的所有元素。利用量子力学，该算法能够通过使用 $O(\\sqrt{M)}$ 次对预言机的调用获得相同结果。

该算法能够通过利用量子计算的特殊特性——称为并行处理——同时对预言机进行多次调用。假设搜索列表有 `N` 个元素。`GAA` 使用维度为 `N` 的希尔伯特空间来表示它们，这可以通过 `n = logM`（以 2 为底）的量子比特实现。每个 `el`∈`N` 的元素，其索引为 `y`，在量子比特的状态空间中由一个正交归一向量表示，称为 `|y⟩`。目标是识别满足给定搜索标准的特定元素的索引 `z`。

起初，预言机被使用，其中一个酉操作具有以下特征

(1.1a)1.  `if` `y` = `z`, `U[z]`|`y`⟩=−|`y`⟩ (1.1b)2.  `if` `y` ≠ `z`, `U[z]`|`y`⟩=|`y`⟩

[式 (1.1a)](#bodymatter-001.xhtml#b_9783110670707-001_eq_001) 和 [(1.1b)](#bodymatter-001.xhtml#b_9783110670707-001_eq_001) 也可以表示如下：

(1.2)`U[z]` = `I` − 2|`z`⟩⟨`z`|

其中，`I` 表示恒等算子。`GAA` 同时使用最后的预言机算子和 Grover 扩散算子，定义为

(1.3)`U[p]` = 2|`p`⟩⟨`p`| − `I`

其中，$|p\\rangle = \\frac{1}{\\sqrt{N}}\\sum\_{y = 1}^{N}y$。[式 (1.2)](#bodymatter-001.xhtml#b_9783110670707-001_eq_002) 和 [(1.3)](#bodymatter-001.xhtml#b_9783110670707-001_eq_003) 的使用如下。
