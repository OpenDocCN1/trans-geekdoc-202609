
# 遗传算法 (GA)

著名的受自然启发的元启发式算法名为遗传算法 (`GA`) 是一种基于达尔文进化论概念的进化算法。约翰·霍兰德被认为是 `GA` 的发明者，他于1975年提出该算法 [[9](#bodymatter-005.xhtml#b_9783110670707-005_ref_009)]。

`GA` 是一种非常有用的基于种群的自适应搜索过程，其中种群中的每个个体称为染色体。为了获得最优解，`GA` 基本上会探索整个搜索空间。在搜索过程中，当前种群通过应用三种遗传操作，如选择、交叉和变异，进化为相同规模的下一代种群。在后续迭代中，从上一代池中参与的染色体中选择最佳染色体，选择取决于其计算的适应度值。选择目的可使用多种方法，如 Boltzmann 选择、轮盘赌选择、排序选择、锦标赛选择等。交叉操作用于通过组合两个或多个随机选择的父染色体的部分来产生一对新染色体，从而通过用新染色体替换父染色体来产生种群。在交叉操作期间，可以从种群中的每个个体中选择一个或多个点作为分割点。为了确保种群的遗传多样性，会进行变异操作，其中随机选择的染色体的随机选择位置会根据预定义的值即变异概率而改变。这种改变可以在种群中一个或多个随机选择的个体的单点或多点上执行。为了实现更快的收敛，建议在每一代执行精英主义。`GA` 已成功应用于许多应用，如数据聚类 [[17](#bodymatter-005.xhtml#b_9783110670707-005_ref_017), [18](#bodymatter-005.xhtml#b_9783110670707-005_ref_018)]，投资组合管理 [[41](#bodymatter-005.xhtml#b_9783110670707-005_ref_041)]，图像处理 [[42](#bodymatter-005.xhtml#b_9783110670707-005_ref_042)] 等等。

## 遗传算法的基本步骤

遗传算法涉及的基本步骤如下。
1. 染色体种群被随机初始化。
2. 评估每个染色体的适应度。
3. 对下一代进行染色体选择。
4. 重复以下步骤直到满足终止条件。
5. 根据预定义的交叉概率，在一对随机选择的父染色体之间进行交叉以获得子染色体。
6. 根据预定义的变异概率，对随机选择的后代/染色体应用变异以在种群中引入多样性。
7. 进行选择以生成下一代种群。
8. 结束循环。

# 5.3 蝙蝠算法概述

在2010年，一种高效的受自然启发的基于种群的元启发式算法，即蝙蝠算法，该算法最初由 Yang 开发 [[14](#bodymatter-005.xhtml#b_9783110670707-005_ref_014)]。该算法能够从给定的问题中识别出最优解或近似最优解，该问题可以是简单或复杂类型的优化问题。蝙蝠通常使用回声定位来感知猎物并在黑暗中识别它们的栖息裂缝。它们也可以通过回声定位避免即将到来的障碍。一般来说，蝙蝠能够产生非常响亮的声音脉冲并聆听来自周围环境的反射回声。根据响应的响度和从发射到反射的时间延迟，它们可以了解猎物的形状、大小和速度，并据此导航。众所周知，高频发射的声音脉冲使它们能够获得有关其近距离环境的详细信息的，从而能够精确地探测猎物的位置并允许它们移动较短的距离。但是，如果发射的声音脉冲频率较低，则它们会传播更远的距离并提供有关其周围环境的粗略信息。此外，回声定位的响度值越高，表明它们离猎物越近，并且会更快地产生声音脉冲。以下过程描述了蝙蝠狩猎策略中涉及的基本步骤。
1. 所有蝙蝠都能够通过使用回声定位特性来探测猎物/食物与其周围障碍物之间的距离。
2. 蝙蝠能够从位置 `P[i]` 以速度 `V[i]`、固定频率 `F[min]`、变化的波长 `λ` 和响度 `L[0]` 随机飞行以搜索猎物。
3. 它们的响度可以从一个大数值 `L[0]` 改变到最小常数 `L[min]`，频率也可以从 `F[min]` 变化到 `F[max]`。

假设在搜索空间中，`n` 只蝙蝠随机飞行。在时间戳 `t`，它们从位置 `P[i]` 开始搜索，具有初始速度 `V[i]`、频率 `F[min]`、脉冲率 `r[i]` 和响度 `L[0]`。在时间戳 `t + 1`，它们可能会使用以下方程改变其下一个位置和速度。

`(5.1) F[i] = F[min] + (F[min] - F[max]) * β`
`(5.2) V[i]^(t + 1) = V[i]^(t) + (P[i]^(t + 1) - P[best]) * F[i]`
`(5.3) P[i]^(t + 1) = P[i]^(t) + V[i]^(t + 1)`

其中，`β ∈ [0, 1]`。最小和最大频率分别为 `F[min] = 0` 和 `F[max] = 2`。这里，`P[best]` 表示当前种群中 `n` 只蝙蝠位置中的全局最佳蝙蝠的位置。在评估种群中所有解的适应度后，其中最佳解的位置被确定为全局最佳位置。现在，需要通过它们的脉冲率来检查蝙蝠是远离猎物还是靠近猎物。低脉冲率 `r[i]` 伴随高概率 (`rand[1] > r[i]`) 表明蝙蝠将在进行短暂随机飞行之前飞向当前更优的蝙蝠附近。否则，认为蝙蝠更接近猎物，它们将在当前位置周围进行随机飞行。这里，`rand[1]` 是 [0, 1] 之间的均匀分布随机数。以下方程用于表示蝙蝠的新位置。

`(5.4) P[new] = P[old] + ε * L^(t)`

其中，`ε ∈ [-1, 1]`，在时间戳 `t`，`n` 只蝙蝠的平均响度由 $L^{t} = \\frac{1}{n}\\sum\_{i = 1}^{n}L\_{i}^{t}$ 计算。随机飞行后，如果一只蝙蝠能够达到比当前全局最佳位置更好的位置，并且其发出的声音足够响亮并且也优于一个随机数 (`rand[2] < L[i]`)，则认为蝙蝠将飞向此新位置，并且当前全局最佳位置值将用新生成的位置值更新。这里 `rand[2]` 是在 [0, 1] 之间均匀分布的随机数。现在，蝙蝠的脉冲率 (`r[i]`) 增加，同时蝙蝠的响度 (`L[i]`) 减小，由以下方程同时进行。

`(5.5) r[i]^(t + 1) = r[i]^0 * (1 - e^(-γ t))`
`(5.6) L[i]^(t + 1) = α * L[i]^(t)`

其中，`r[i]^0 ∈ [0, 1]` 表示初始脉冲率，其中 `γ` (0 < `γ` < 1) 和 `α` (0 < `α` < 1) 为常数。现在，通过计算所有蝙蝠的适应度来选择当前的 `P[best]`。

## 蝙蝠算法的基本步骤

蝙蝠算法涉及的基本步骤如下。
1. 蝙蝠种群 `𝒫` 被随机初始化。
2. 每个个体的脉冲频率 (`ℱ`)、速度 (`𝒱`)、脉冲率 (`r[i]`) 和响度 (`ℒ[0]`) 被初始化。
