
我们讨论一种基于量子的方法来计算点积 [[31](#bodymatter-004.xhtml#b_9783110670707-004_ref_031)]，针对两个训练输入（归一化），∥ `X⃗[i]`⟩ & ∥ `X⃗[j]`⟩（在量子排列中），在线性核中。对于 ∥ `X⃗[i]`⟩ & ∥ `X⃗[j]`⟩ 的点积计算，首先，我们使用一个辅助变量生成两个量子态 ∥ `ψ`⟩ 和 ∥ `ϕ`⟩。接下来，我们估计两个训练输入的平方范数之和，设参数 `Z` = |`X⃗[i]`|² + |`X⃗[j]`|²。最后，我们执行 `swap test` 对仅辅助量子比特进行投影测量。

首先，通过查询 `QRAM`，我们构造量子态 |`ψ`⟩：

(4.20)$|\\psi\\rangle = \\frac{1}{\\sqrt{2}}\\left( {\\left| {0\\rangle} \\right|{\\overrightarrow{X}}\_{i}\\rangle + \\left| {1\\rangle} \\right|{\\overrightarrow{X}}\_{j}\\rangle} \\right)$

让我们假设另一个量子态：

(4.21)$|\\xi\\rangle = \\left( {\\frac{1}{\\sqrt{2}}\\left( {\\left| {0\\rangle -} \\right|1\\rangle} \\right)\\; \\otimes \\;|0\\rangle} \\right)$

我们对态 |`ξ`⟩ 施加幺正变换 [[32](#bodymatter-004.xhtml#b_9783110670707-004_ref_032)] `e`^( − `i` `H` `t`)，其中 `H` = ((∥ `X⃗[i]` ∥ |0⟩⟨0| + ∥ `X⃗[j]` ∥ |1⟩⟨1|) ⊗ `σ[x]`) 是一个哈密顿量。这得到以下态，

(4.22)$\\begin{matrix} & \\left\\lbrack {\\frac{1}{\\sqrt{2}}\\left( {cos\\left( {{\\parallel {\\overrightarrow{X}}\_{i} \\parallel}t} \\right)\\left| {0\\rangle - cos\\left( {{\\parallel {\\overrightarrow{X}}\_{j} \\parallel}t} \\right)} \\right|1\\rangle} \\right) \\otimes |0\\rangle} \\right\\rbrack \\\\ & {\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\,\\, - \\left\\lbrack {\\frac{i}{\\sqrt{2}}\\left( {sin\\left( {{\\parallel {\\overrightarrow{X}}\_{i} \\parallel}t} \\right)\\left| {0\\rangle - sin\\left( {\\parallel {\\overrightarrow{X}}\_{j} \\parallel} \\right)} \\right|1\\rangle} \\right) \\otimes |1\\rangle} \\right\\rbrack} \\\\ \\end{matrix}$

在适当选择 `t` 后，我们现在测量辅助比特，其中 `X⃗[i]` `t`, `X⃗[j]` `t` ≪ 1，这得到态：

(4.23)$|\\phi\\rangle = \\frac{1}{\\sqrt{\\left( {{\\parallel {\\overrightarrow{X}}\_{i} \\parallel}^{2} + {\\parallel {\\overrightarrow{X}}\_{j} \\parallel}^{2}} \\right)}}\\left( {{\\parallel {\\overrightarrow{X}}\_{i} \\parallel}\\left| {0\\rangle - {\\parallel {\\overrightarrow{X}}\_{j} \\parallel}} \\right|1\\rangle} \\right),$

概率为 $\\frac{1}{2}{\\lbrack{({{\\parallel {\\overrightarrow{X}}\_{i} \\parallel}^{2} + {\\parallel {\\overrightarrow{X}}\_{j} \\parallel}^{2}})t}\\rbrack^{2}}$。

这使得可以估计 |`X⃗[i]` ⟩ & |`X⃗[j]`⟩ 的平方范数之和。通过应用 `quantum counting`，我们可以估计 (∥ `X⃗[i]`∥² + ∥ `X⃗[j]`∥²) 并以精度 `ϵ` 生成量子态 |`ϕ`⟩。复杂度为 `O`(`ϵ`^( − 1))。使用仅辅助量子比特，我们随后用态 |`ψ`⟩ & |`ϕ`⟩ 执行 `swap test`。如果 |`ψ`⟩ & |`ϕ`⟩ 相等，则测量结果为零。因此，考虑 `QRAM` 访问 [[30](#bodymatter-004.xhtml#b_9783110670707-004_ref_030)]、估计 (∥ `X⃗[i]`∥² + ∥ `X⃗[j]`∥²) 以及构造量子态 |`ϕ`⟩ 时，评估训练实例的单个点积的总体复杂度为 `O`(`ϵ`^( − 1) `log` `N`)。

### 4.3.4 The HHL algorithm

Harrow, Hassidim, and Lloyd [[20](#bodymatter-004.xhtml#b_9783110670707-004_ref_020)] 开发了 `HHL` 算法，该算法在量子力学中求解线性方程组。该算法是最重要和最基本的量子算法之一，也是构建许多 QML 算法的基础。该算法旨在量子计算机中求解方程组 `A` `x⃗` = `b⃗`。在量子力学中表示为 `A`|`x`⟩ = |`b`⟩，其中 `A` 是厄米矩阵。`b⃗` 表示为量子态 |`b`⟩ = ∑[n] `b`[n] |`E`[n]⟩，在 `log`[2] `N` 个量子比特上，其中 `E`[n] 是 `A` 的特征向量，对应特征值 `λ`[n] ≥ `Λ`，而 `x⃗` 表示为 |`x`⟩。该算法旨在求解 |`x`⟩ = `A`^( − 1) |`b`⟩，其中 `A`^( − 1) 是 `A` 的逆。我们随后通过应用 `phase estimation` 计算 `λ`[n]。通过反计算 `phase-estimation`，我们得到 $\\sum\_{n}b\_{n}|E\_{n}\\rangle\\left( {\\frac{\\Lambda}{\\lambda\_{n}}|1\\rangle + \\sqrt{1 - \\frac{\\Lambda^{2}}{\\lambda\_{n}^{2}}}|0\\rangle} \\right)$，其中 $\\frac{\\Lambda}{\\lambda\_{n}}$ 是通过该 ancillary 量子比特旋转的 arcsin 的角度。为了成功，我们在应用 `amplitude amplification` 后应用 `O`(`||A||`/`Λ`) 次态制备电路。

与经典对应方法相比，该算法在某些问题陈述下声称具有指数级加速增益。该算法输出 `O`(( `log` `N`)²) 个量子态，而经典计算机输出需要 `O`(`N` `log` `N`) 步。

### 4.3.5 Quantum principal component analysis

主成分分析 (`PCA`) [[33](#bodymatter-004.xhtml#b_9783110670707-004_ref_033)] 是一种非常重要的降维技术。更正式地说，我们可以定义 `PCA` 通过对数据协方差矩阵 `C` = ∑[j] `v⃗` `v⃗`[j]^(`T`) 进行对角化来操作，其中 `T` 是转置操作。协方差矩阵封装了数据不同分量之间的相关性。协方差矩阵以特征向量和特征值的形式可以表示为 `C` = ∑[k] `e`[k] `c⃗`[k] `c⃗`[k]^†，其中 `e`[k] 是对应于 `C` 的特征向量 `c⃗`[k] 的特征值。与其余相比较大的几个特征值被称为主成分。每个主成分随后被视为新的特征向量。`PCA` 的经典算法在 `O`(`d`²) 运行时间复杂度下工作，其中 `d` 是希尔伯特空间的维度。在量子 `PCA` [[33](#bodymatter-004.xhtml#b_9783110670707-004_ref_033)] 中，随机选择的数据向量使用 `QRAM` [[30](#bodymatter-004.xhtml#b_9783110670707-004_ref_030)] 映射到量子态。所得态具有密度矩阵 $\\rho = \\frac{1}{N}\\sum\_{j}\\left| {v\_{j}\\rangle\\langle v\_{j}} \\right|$，其中 N 是数据向量集合的基数。使用 `density matrix exponentiation` [[34](#bodymatter-004.xhtml#b_9783110670707-004_ref_034)] 与 `quantum phase estimation algorithm` [[35](#bodymatter-004.xhtml#b_9783110670707-004_ref_035)]，并重复数据采样，可以将数据向量分解为主成分。量子 `PCA` 算法在 `O`(( `log` `d`)²) 运行时间复杂度下工作。
