
已对绝热近似在 AQC 框架下 Grover 量子搜索情况下基于这三个条件的适用性进行了严格研究，见 [[46](#bodymatter-003.xhtml#b_9783110670707-003_ref_046)]。发现最初由 Folk 定理得到的结论仍然有效。由于本章主要使用 Grover 搜索，因此本章其余部分将应用 Folk 定理的结果。

Grover 量子搜索算法 [[47](#bodymatter-003.xhtml#b_9783110670707-003_ref_047)]及其变体可作为子程序用于设计求解优化问题的算法。Grover 搜索算法的变体，如不需要预先知道目标实体数量的 Boyer 的提议 [[48](#bodymatter-003.xhtml#b_9783110670707-003_ref_048)]和不动点方案 [[49](#bodymatter-003.xhtml#b_9783110670707-003_ref_049)]，尤其适用于此类问题。Durr 和 Høyer 在 [[50](#bodymatter-003.xhtml#b_9783110670707-003_ref_050)]中提出了一种算法，用于在数据库中寻找最小值，该算法采用 [[48](#bodymatter-003.xhtml#b_9783110670707-003_ref_048)]中提出的算法作为子程序。

用于定位最小值的量子算法在未排序的表‘`D`’中搜索最小项，`D`包含 `K` 个项目，每个项目的值属于一个有序集合。量子最小值搜索算法的伪代码如下：

1. 随机选择阈值索引 `J[in]` ∈ [0,`K`−1]。
2. 重复直到总运行时间超过 22.5√`K` + 1.4 lg² `K`。
    1. 应用 Boyer 等人的量子搜索算法 \[48\]。
    2. 观测第一个寄存器：令 `D`[`J[in′]`] 为结果。
    3. 如果 `D[J[in′]]` < `D[J[in]]`，则将阈值索引 `J[in]` 设置为 `J[in′]`。
3. 返回 `J[in]`。

量子最小值搜索算法找到最小值的索引，并为进一步开发优化算法和启发式方法提供了灵感，因此在某种程度上是开创性的研究。

## 3.4 Grover 自适应搜索

Baritompa 等人将量子最小值搜索算法推广用于求解有限全局优化问题，其表述如下 [[52](#bodymatter-003.xhtml#b_9783110670707-003_ref_052)]：

(3.12) *优化* `f`(`α`), `α` ∈ `A`

其中 `f` 是有限集 `A` 上的实值函数。

设集合 `A` 的基数为 `N`。设 `a[1]` < `a[2]` < `a[3]` … < `a[L]` 为所有 `α` ∈ `A` 的目标函数 `f`(`α`) 的 ‘`L`’ 个不同取值。因此，`L` 应小于或等于 `N`，即如果 `L` 等于 `N`，则集合 `A` 中每个 `α` 值都有 `f` 的不同目标函数值。设 `A` 上存在均匀概率测度 `λ`，使得 `ϒ` 为由 `f` 诱导的随机向量 (`ϒ[1]`, `ϒ[2]`, …, `ϒ[L]`) 给出的范围测度，使得 `ϒ[j]` = |`f^(−1)`(`a[j]`)|/`N`，其中 `j` = 1, 2, …, `L`。设 `P[j]` = $\\sum\_{i = 0}^{j}\\Upsilon\_{j}$，即随机点取值小于或等于 ‘`a[j]`’ 的概率，即 `P[L]` = 1。因此，存在一个改进区域，对应于目标函数 `f`(`α`) 的所有取值，该取值属于 `A` 的子集，其中 `f`(`α`) 具有严格更好的值 [[52](#bodymatter-003.xhtml#b_9783110670707-003_ref_052)]。`λ` 下改进区域的测度记为改进分数 `P`。因此，如果我们为目标函数选择一个特定值，例如 ‘`θ`’，则改进区域将包括所有目标函数值优于 ‘`θ`’ 的点的集合。

Baritompa 等人提出的算法被称为 Grover 自适应搜索（GAS），它以旋转次数序列和目标函数值阈值作为输入。其伪代码如下 [[52](#bodymatter-003.xhtml#b_9783110670707-003_ref_052)]：

1. 在 `A` 中选择 `α[1]`，并设 `θ[1]` = `f`(`α[1]`)。
2. 设计数 `nc` = 1。
3. 当终止条件未满足时
* {
* a. 对 `f` 执行 `r[nc]` 次旋转的 Grover 搜索，阈值为 `V[nc]`，并用 `α` 和 `θ` 表示输出。
* b. 如果 `v` < `V[nc]`，则设 `θ[nc+1 ]` = `α` 且 `V[nc +1 ]` = `v`；否则，设 `θ[nc+1 ]` = `θ[nc]` 且 `V[nc +1 ]` = `V[nc]`。
* c. `nc` = `nc` + 1。
* }

GAS 已使用 [[53](#bodymatter-003.xhtml#b_9783110670707-003_ref_053), [54](#bodymatter-003.xhtml#b_9783110670707-003_ref_054), [55](#bodymatter-003.xhtml#b_9783110670707-003_ref_055)] 中开发的自适应搜索框架进行研究，该框架已应用于使用随机全局搜索的优化方法的收敛性质的理论分析。自适应算法的基本假设之一是搜索可以在一定成本下找到更好的“改进”解。GAS 基于一个预言函数，该函数在每次迭代中以有限概率找到比当前解更好的解，如果存在的话。该预言机接收输入字符串 `α` ∈ `A`，计算 `f`(`α`)，将 `f`(`α`) 与当前阈值进行比较，并根据比较结果和所求解的优化问题的类型，即是最小化还是最大化问题，输出零或一。此类预言机可使用可逆/量子电路实现，如 [第 3.3.1 节](#bodymatter-003.xhtml#b_9783110670707-003_s_003_s_003_s_001) 所示。

因此，GAS 生成一系列域解，这些解在前一解的改进区域中均匀分布。此外，根据 [[54](#bodymatter-003.xhtml#b_9783110670707-003_ref_054)] 中给出的定理 1 和推论 6，这样的序列会迅速收敛到全局最优解；例如，在期望情况下，在大小为 `K` 的域中，唯一的最优解可以在 1 + ln(`K`) 次改进后定位 [[54](#bodymatter-003.xhtml#b_9783110670707-003_ref_054)]。

定理 1 [[54](#bodymatter-003.xhtml#b_9783110670707-003_ref_054)]。*求解由* [式 (3.12)](#bodymatter-003.xhtml#b_9783110670707-003_eq_012) *描述的有限优化问题所需的迭代次数 I 的期望值为：*

1. $I = 1 + \\sum\\limits\_{i = 2}^{N}\\frac{\\Upsilon\_{i}}{P\_{i}}$ *用于强纯自适应搜索。*
2. $I = 1 + \\sum\\limits\_{i = 2}^{N}\\frac{\\Upsilon\_{i}}{P\_{i - 1}}$ *用于弱纯自适应搜索。*

其中强纯自适应搜索意味着搜索算法的每次迭代都应从严格改进区域采样目标函数值。弱自适应搜索意味着搜索算法的每次迭代应采样目标函数值，该值相等或更好。

### 推论 6

[[54](#bodymatter-003.xhtml#b_9783110670707-003_ref_054)]。*求解由* [式 (3.12)](#bodymatter-003.xhtml#b_9783110670707-003_eq_012) *描述的有限全局优化所需的迭代次数 I 的期望值，在目标函数值上给定均匀分布时，为：*

1. *强纯自适应搜索的上界为 1 + log`N`。*
2. *弱纯自适应搜索的上界为 2 + log(`N`−1)。*
