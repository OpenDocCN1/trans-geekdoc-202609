
`C`[`N`][`i`] ≠ ∅, ∀`i` = {1, 2,…, `p`}. `C`[`N`][`i`] ∩ `C`[`N`][`j`] = ∅, ∀`i`, `j` = {1, 2,…, `p`} and `i` ≠ `j`. $\\sum\_{i = 1}^{p}{C\_{N}}\_{i} = DS.$

聚类可以通过多种方式实现，研究人员致力于设计多种成功的聚类方法，例如，K-means \[[3](#bodymatter-005.xhtml#b_9783110670707-005_ref_003)\]、分区方法 \[[4](#bodymatter-005.xhtml#b_9783110670707-005_ref_004)\]、层次聚类 \[[5](#bodymatter-005.xhtml#b_9783110670707-005_ref_005)\]、基于模型聚类 \[[6](#bodymatter-005.xhtml#b_9783110670707-005_ref_006)\]、模糊聚类 \[[7](#bodymatter-005.xhtml#b_9783110670707-005_ref_007)\]、基于密度的聚类 \[[8](#bodymatter-005.xhtml#b_9783110670707-005_ref_008)\] 等。可以看出，在这些方法中，K-means \[[3](#bodymatter-005.xhtml#b_9783110670707-005_ref_003)\] 优于其他方法。在 K-means 算法的情况下，始终需要 `apriori` 知识来了解数据集中存在的聚类数量。另一方面，可以开发自动聚类技术来发现数据集中存在的最佳聚类数量，尽管对检查的数据集了解很少或没有任何信息，这可能有助于解决分割以及分类问题的目的，这促使研究人员探索具有自动化的聚类领域。

自然启发的元启发式算法对于在最短的时间内为简单或复杂的优化问题提供最优解非常有用。一些著名的自然启发式种群型元启发式算法是遗传算法 (GA) \[[9](#bodymatter-005.xhtml#b_9783110670707-005_ref_009)\]、粒子群优化 (PSO) \[[12](#bodymatter-005.xhtml#b_9783110670707-005_ref_012)\]、蚁群优化 (ACO) \[[13](#bodymatter-005.xhtml#b_9783110670707-005_ref_013)\]、蝙蝠算法 \[[14](#bodymatter-005.xhtml#b_9783110670707-005_ref_014), 本文中，提出了两种不同的量子启发式元启发式算法，即 QIGA 和 QIBA，用于图像数据集的自动聚类技术，并且还对两种不同的经典算法，即经典遗传算法和经典蝙蝠算法与其相应的量子影响对应算法进行了比较。适应度均值、该适应度的标准差、该适应度的标准误差以及最小计算时间是衡量这些量子启发式技术相对于其类似经典对应技术的有效性的标准。尽管实验结果有利于量子启发式技术，但仍进行了统计优越性检验，即非配对 `t-test` \[[37](#bodymatter-005.xhtml#b_9783110670707-005_ref_037)\]，并且相应的评估 `p` 值确立了这些量子启发式技术的有效性。最后，在所有提出的程序之间进行了 Friedman 检验 \[[38](#bodymatter-005.xhtml#b_9783110670707-005_ref_038), [39](#bodymatter-005.xhtml#b_9783110670707-005_ref_039)\] 以判断一个程序相对于另一个程序的优越性。聚类有效性指数即 DB 指数 \[[40](#bodymatter-005.xhtml#b_9783110670707-005_ref_040)\] 被用作计算聚类有效性的目标函数。
