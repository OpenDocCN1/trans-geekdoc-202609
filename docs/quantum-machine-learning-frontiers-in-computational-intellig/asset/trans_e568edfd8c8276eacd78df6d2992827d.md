
地形图提供了人工神经网络与量子计算之间的另一个接触点，因为大脑中的计算图足够大且密集，可以在数学上被有用地视为 *场*，即连续量的连续分布 \[[9](#bodymatter-002.xhtml#b_9783110670707-002_ref_009)\]。此类表征让人联想到量子力学波函数，后者也是连续量的连续分布（复概率幅）。在这两种情况下，这些场在数学上都被视为连续域上的连续函数，而希尔伯特空间提供了描述它们的数学框架 \[[7](#bodymatter-002.xhtml#b_9783110670707-002_ref_007)\]。在本章中，我们利用这一类比来实现受大脑启发的量子机器学习方法。

由于其对值的空间表征，地形图可用于在大脑中实现任意函数，本质上是一种查表。假设大脑需要实现一个（可能是非线性的）变换，`y = f(x)`。这可以通过从输入图中的位置 `r = µ(x)` 到表示结果空间的输出图中的对应位置 `s = μ'(y) = μ'[f(x)]` 的神经连接来实现。因此，输入图中代表 `x` 的活动将导致输出图中代表 `y` 的相应活动。此外，输入值的叠加将导致输出值的相应叠加。因此，地形表征允许在线性叠加中计算非线性函数 \[[9](#bodymatter-002.xhtml#b_9783110670707-002_ref_009), [10](#bodymatter-002.xhtml#b_9783110670707-002_ref_010), [11](#bodymatter-002.xhtml#b_9783110670707-002_ref_011), [12](#bodymatter-002.xhtml#b_9783110670707-002_ref_012), [13](#bodymatter-002.xhtml#b_9783110670707-002_ref_013)\]，这表明了它们在量子计算中的有用性 \[[7](#bodymatter-002.xhtml#b_9783110670707-002_ref_007)\]。另一方面，地形图对表征资源的利用相对低效，因为每个被表征的值都必须在图中有一个位置 \[尽管这可以通过 *粗编码* 来缓解，通过这种方式，精确值由具有重叠感受野的宽调谐神经元群体来表征 \[[14](#bodymatter-002.xhtml#b_9783110670707-002_ref_014), [15](#bodymatter-002.xhtml#b_9783110670707-002_ref_015)\]\]。因此，使用地形表征需要相当可扩展的量子计算技术。本章我们探讨两种地形量子计算方法，重点关注机器学习。

## 2.3 地形基映射

在大脑中，地形图的状态是一个定义在（通常是二维）空间 Ω 上的实值函数。为了将这些思想应用于量子计算，我们考虑一个量子态 |*ψ*⟩，其中位置 **r** ∈ Ω 处的概率幅 *ψ*(**r**) 通过对应关系 **r **\= *µ*(**x**) 表示值 **x** 的幅值（存在、重要性等）。这里 **r** ∈ Ω 可以是一个连续指标，表示例如空间位置，或离散量子态的指标，如波长或量子比特寄存器的状态。态 |*r*⟩ 构成了输入和输出量子态的离散基或连续伪基。在连续情况下，输入值 **x** 由连续基态 |*μ*(**x**)⟩ 表示，它是 **r **\= *µ*(**x**) 处的狄拉克单位脉冲，即 |**r**⟩ = *δ***[r]**，其中 *δ***[r]**(**s**) = *δ*(**s **− **r**)。类似地，输出值 **y** 由连续基态 |*μ*^′(**y**)⟩=|*μ*^′\[*f*(**x**)\]⟩ = *δ*[*μ*^′(**y**)] 表示。我们称这种表征（无论是离散还是连续）为 *地形基映射*。

对于这样的连续基，我们可以定义一个希尔伯特-施密特线性算子：

$T\_{f} = \\int\\limits\_{\\mathcal{X}}^{}d\\mathbf{x}\\left| {\\mu^{\\prime}\\left\\lbrack {f\\left( \\mathbf{x} \\right)} \\right\\rbrack} \\right.\\rangle\\langle\\mu\\left( x \\right)|,$

其中 𝒳 是输入值的空间。（当 *f* 在上下文中明确时，我们写 *T *\= *T[f]*。）该算子具有期望的行为：*T*|*μ*(**x**)⟩=|*μ*^′\[*f*(**x**)\]⟩ 对所有 **x** ∈ 𝒳 成立。以这种方式，线性算子 *T* 通过计算图计算非线性函数 *f*。我们称这样的算子为 *图核*，因为它使用 *f* 的显式 *图* \[即所有 **x** ∈ 𝒳 的成对集合 (*μ*^′\[*f*(**x**)\]， *μ*(**x**))\] 来进行一种查表。[²](#fn2)

请注意，如果输入图是输入值的叠加，|*ψ*⟩=*a*|*μ*(**x**)⟩ + *b*|*μ*(**x**^′)⟩，那么输出图将是相应结果的叠加：*T*|*ψ*⟩=*a*|*μ*^′\[*f*(**x**)\]⟩ + *b*|*μ*^′\[*f*(**x**^′)\]⟩。因此，连续地形基映射允许在线性叠加中计算非线性函数（量子并行）。这是迈向量子计算的一步，但 *T* 可能不是幺正的，我们还有更多工作要做。

读者可能会质疑使用连续基。首先，注意对于可分希尔伯特空间，连续基始终可以用无限离散基代替，例如用适当维度的正弦或复指数的离散序列。其次，无限离散基可以用有限离散基来近似，例如用带限正弦或复指数。这种近似对于神经网络机器学习尤其合适，后者只需要低精度计算。
