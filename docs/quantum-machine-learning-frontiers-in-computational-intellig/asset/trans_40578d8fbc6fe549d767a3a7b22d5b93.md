
## Grover 自适应搜索
`GAS` 对应于 `Pure Adaptive Search` 的较弱版本，因为在应用 `Grover Search` 之后无法保证能找到严格更好的解。可以认为 `Grover Search` 可能返回一个小于阈值的目标函数值，因此它并不对应于 `Pure Adaptive Search Framework`，但在这种情况下，较差的值将被丢弃，并且当前阈值将被视为该迭代中算法的输出。因此，整体的 `GAS` 对应于 `Pure Adaptive Search` 的较弱版本。

### 旋转次数序列
`Grover's Adaptive Search` 的一个重要设计决策是旋转次数序列的确定。只要有关于域的改进分数 `P` 的信息，就有可能为 `GAS` 的每次迭代确定最佳旋转次数 `r`。因此，如果在 `Grover's Search` 的每次运行中都使用最佳旋转次数，那么在 `GAS` 的每次迭代中几乎肯定会找到更好的（改进的）解。然而，在实际问题中，改进分数 `P` 通常是未知的。通过利用迭代结束时可获得的所有信息并考虑问题的性质，始终可以对改进分数 `P` 进行估计。也就是说，可以通过在每次迭代中跟踪改进分数的后验分布序列来应用贝叶斯方法，该序列随后将用于在特定迭代中选择旋转次数。然而，这种方法可能非常复杂且繁琐 [[56](#bodymatter-003.xhtml#b_9783110670707-003_ref_056)]。因此，已经设计了其他方法来在实现简易性和旋转次数选择的优化性之间取得平衡，其中包括基于 Boyer 等人 [[48](#bodymatter-003.xhtml#b_9783110670707-003_ref_048)] 的方法，由 Durr 和 Hoyer 使用并在 [[50](#bodymatter-003.xhtml#b_9783110670707-003_ref_050)] 中说明。

### 收益-成本启发式
Baritompa 等人提出的另一种方法基于最大化启发式中参数 `b` 表示的收益成本比 [[52](#bodymatter-003.xhtml#b_9783110670707-003_ref_052)]。收益被认为是域的改进分数的预期减少，这在不知道所解决问题的性质的情况下难以确定。成本取决于旋转次数。启发式的伪代码如下：
```
1. Initialize u[0](Ω) = Ω // u[0] is a polynomial
2. For i = 1, 2, …, do: // Generating rotation count r for ith iteration
   1. E[u_i] = 1 − ∫[0]¹ u[i](Ω) dΩ
   2. β = 0
   3. For r = 0, 1, … , until E[u_i]/(r+1) < 2β, do:
      1. v(Ω) = u_i(Ω) + Ω ∫_Ω^1 g_r(P)/P du_i(P) // g_r(P) = sin²((2r + 1) sin⁻¹√P)
      2. E[v] = 1 − ∫[0]¹ v(Ω) dΩ
      3. b = (E_ui - E_v)/(r + 1)
      4. If b > β, then
         1. ȓ = r
         2. β = b
         3. u[i+1](Ω) = v(Ω)
   4. Output ȓ
```
该启发式产生的旋转次数序列与特定的优化问题无关，前 33 个条目如下 [[52](#bodymatter-003.xhtml#b_9783110670707-003_ref_052)]：
`0, 0, 0, 1, 1, 0, 1, 1, 2, 1, 2, 3, 1, 4, 5, 1, 6, 2, 7, 9, 11, 13, 16, 5, 20, 24, 28, 34, 2, 41, 49, 4, 60, …`.

### 动态旋转计划
最近，上述启发式方法已被 Liu 和 Koehler 进一步研究和改进 [[56](#bodymatter-003.xhtml#b_9783110670707-003_ref_056)]。一项改进是采用 Chebyshev 多项式来简化计算分布时涉及的计算，从而大大减少了计算时间。另一项改进是将上述启发式转换为动态启发式，该启发式考虑了特定迭代中 Grover 搜索是否成功。这是通过使用贝叶斯定律根据找到更好解的成功或失败来更新一次完整的 Grover 搜索后的分布而实现的。计算动态旋转计划的启发式如下：
```
1. Initialize u[0](Ω) = Ω
2. For i = 1, 2, …, do: // Generating rotation count r for ith iteration
   1. E_ui = 1 - ∫_0^1 u_i(Ω) dΩ
   2. β = 0
   3. For r = 0, 1, … , until E[u_i]/(r+1) < 2β, do:
      1. b = ∫_0^1 P g_r(P) du_i(P)
      2. If b > β, then
         1. ȓ = r
         2. β = b
   4. Output ȓ
   5. If Search_outcome = Success
      u_{i+1}(Ω) = [∫_0^y g_r(P) du_i(P) + ∫_y^1 y/P g_r(P) du_i(P)] / ∫_0^1 g_r(P) du_c(P)
      Else
      u_{i+1}(yΩ) = [u_i(Ω) - ∫_0^y g_r(P) du_i(P)] / [1 - ∫_0^1 g_r(P) du_c(P)]
```
Liu 和 Koehler 报告称，由 Durr 和 Hoyer [[50](#bodymatter-003.xhtml#b_9783110670707-003_ref_050)]（基于 Boyer 等人算法 [[48](#bodymatter-003.xhtml#b_9783110670707-003_ref_048)]）、Baritompa 等人 [[52](#bodymatter-003.xhtml#b_9783110670707-003_ref_052)] 及其改进的动态版本 [[56](#bodymatter-003.xhtml#b_9783110670707-003_ref_056)] 的用于全局优化的量子算法提案所需预期时间的正式推导是困难的。这是由于用于搜索的基本子程序需要了解改进分数的分布函数。因此，已使用数值模拟来比较这些方法。然而，这样的模拟研究在计算上非常昂贵，因为它们需要数字计算机来模拟量子计算机。因此，这类算法的性能只能在规模很小的问题上进行研究，这些问题没有多大实际意义。

本章指出上述全局优化算法中的基本问题是由于基本搜索子程序依赖于改进分数来确定特定迭代中的旋转次数。这个问题可以通过将量子计算模型从量子电路模型更改为绝热量子计算 (`AQC`) 模型来解决。

`AQC` 在 Grover 搜索方面比量子电路模型具有明显的优势，即它消除了过冲问题。这是可能的，因为解被编码为问题哈密顿量的基态，因此，即使系统演化的时间超过所需时间，系统仍保持在问题哈密顿量的基态。`AQC` 的这一特性使得能够正式推导出基于 `AQC` 的全局优化算法的预期运行时间。
