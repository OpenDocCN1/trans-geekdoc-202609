
# 机器学习算法与项目概述

一些流行的机器学习算法有人工神经网络（`ANN`）\[[8](#bodymatter-003.xhtml#b_9783110670707-003_ref_008)\]、支持向量机（`SVM`）\[[9](#bodymatter-003.xhtml#b_9783110670707-003_ref_009)\]、`K-means` 聚类 \[[10](#bodymatter-003.xhtml#b_9783110670707-003_ref_010)\]、回归 \[[11](#bodymatter-003.xhtml#b_9783110670707-003_ref_011)\]、决策树 \[[12](#bodymatter-003.xhtml#b_9783110670707-003_ref_012)\] 等。任何机器学习项目中涉及的通用步骤如下：

## 任何机器学习项目中的通用步骤

### 数据收集
本步骤涉及收集与待解决的问题相关的数据。数据应具有高质量，这对于高质量的模型是必要的。评估数据质量有多种衡量标准 \[[13](#bodymatter-003.xhtml#b_9783110670707-003_ref_013)\]。数据质量低通常会导致模型质量低，进而影响预测或决策。

### 模型选择
本步骤涉及选择特定的技术，如 `ANN` 或 `SVM` 等。此外，还涉及选择模型的结构，即在 `ANN` 的情况下，隐藏层的数量、每层隐藏层的神经元数量、激活函数等。

### 训练
在此步骤中，模型的参数被确定，即在 `ANN` 和 `SVM` 的情况下，使用某种损失函数确定权重，即表示模型在训练数据集上性能的损失函数被用来搜索/计算权重。

### 验证
在此步骤中，确定模型在测试数据集上的性能并与其他现有模型进行比较。

### 部署
最后，模型被部署，以便在实际情况下用于做出预测或决策。

第一步特定于使用机器学习解决的问题，但在大多数情况下可以实现自动化，以使数据收集过程可靠、快速且廉价。第二步模型选择通常需要过去的经验和试错方法，这可以转化为启发式 \[[13](#bodymatter-003.xhtml#b_9783110670707-003_ref_013)\]。模型的选取通常会进行多次，并且通常基于关于模型性能的经验证据，而该证据在验证后才知道。第三步训练通常是所有其他步骤中最耗计算的步骤，并且取决于模型的复杂性，如果底层过程是线性的，则其建模会产生表现良好的损失函数，即损失函数在感兴趣区域内是凸的、连续的且可微的。然而，大多数损失函数通常表现不佳，这是由于生成数据的底层非线性过程所致，在这种情况下，损失函数的优化成为机器学习技术成功实现的关键挑战。经常有经验表明，当损失函数表现良好时，模型的有用性较低 \[[14](#bodymatter-003.xhtml#b_9783110670707-003_ref_014)\]，而当损失函数难以优化时，所得到的模型更强大 \[[15](#bodymatter-003.xhtml#b_9783110670707-003_ref_015)\]。验证和部署通常在计算上花费较少，因为训练好的模型接收输入并以预测或决策的形式给出输出。在本章中，我们将主要关注通过量子优化使机器学习中的训练更高效。

## 机器学习中的优化

优化常规应用于几乎所有类型的机器学习技术及其应用中。Chambers 词典将优化描述为“使任何事物变得最优或最好”的行为。因此，在机器学习训练阶段执行优化意味着找到模型最合适或最佳的参数。存在像线性 `SVM` 这样的机器学习模型，其权重可以通过矩阵求逆技术确定 \[[16](#bodymatter-003.xhtml#b_9783110670707-003_ref_016)\]，该技术在量子计算的门模型中可以高效实现，从而显示出指数级加速。然而，这类技术通常需要量子 RAM \[[17](#bodymatter-003.xhtml#b_9783110670707-003_ref_017)\] 的存在以及数据由低噪声的线性过程生成。在现实世界问题中，线性假设经常被违反，因此最流行的技术是非线性的，并且凸性无法保证。如果优化问题是凸的，则基于梯度的技术无论初始化如何都能保证找到全局最优 \[[18](#bodymatter-003.xhtml#b_9783110670707-003_ref_018)\]。因此许多优化技术试图简化问题，使其看起来是线性的或凸的 \[[13](#bodymatter-003.xhtml#b_9783110670707-003_ref_013)\]。或者，它们尝试通过使用诸如 `stochastic gradient descent` \[[19](#bodymatter-003.xhtml#b_9783110670707-003_ref_019)\] 之类的技术近似求解问题，这些技术是迭代的，而不是期望的单次技术。因此，这些技术通常计算耗时，因为它们试图解决的问题本质是非线性、不可微、分维、多峰和随机的。已经提出了几种量子增强方法来解决机器学习中的计算问题，其中使用绝热量子计算 (`AQC`) 的全局优化是一种有前景的技术，特别适用于非线性、不可微、分维和多峰的问题。人们也努力在 `AQC` 模型上解决二次无约束二元优化问题 \[[20](#bodymatter-003.xhtml#b_9783110670707-003_ref_020)\]。在本章中，我们提出了一种基于绝热量子计算的迭代全局优化器，用于最小化机器学习技术的损失函数，这在优化问题是非线性、不可微、分维和多峰时很有用，在这种情况下，像 \[[19](#bodymatter-003.xhtml#b_9783110670707-003_ref_019)\] 这样的基于梯度的技术和单次技术 \[[21](#bodymatter-003.xhtml#b_9783110670707-003_ref_021)\] 在计算上效率不高或不相关。此外，还有一些变分量子计算的提案，其中它们专注于在近期量子计算设备上实现函数求值，并在经典计算机上实现传统的无梯度优化技术，如 `Nelder-Meads` 方法 \[[19](#bodymatter-003.xhtml#b_9783110670707-003_ref_019)\]，然而，我们的提案与此类提案不同，因为整个优化步骤将在未来的绝热量子计算机上运行。本章的进一步组织如下：关于 `AQC` 基于算法发展的相关工作在 [第 3.2 节](#bodymatter-003.xhtml#b_9783110670707-003_s_003_s_002) 中讨论。绝热量子计算的理论基础在 [第 3.3 节](#bodymatter-003.xhtml#b_9783110670707-003_s_003_s_003) 中讨论。[第 3.4 节](#bodymatter-003.xhtml#b_9783110670707-003_s_003_s_004) 介绍了 `Grover’s Adaptive Search` 的发展。问题表述在 [第 3.5 节](#bodymatter-003.xhtml#b_9783110670707-003_s_003_s_005) 中描述。[第 3.6 节](#bodymatter-003.xhtml#b_9783110670707-003_s_003_s_006) 介绍了基于 `AQC` 的量子搜索。基于 `AQC` 的最小值查找算法在 [第 3.7
