

在 \[[34](#bodymatter-003.xhtml#b_9783110670707-003_ref_034)\] 中，证明了量子线路模型上的部分绝热搜索算法可以实现，并且通过研究系统哈密顿量的第一激发态与基态之间的最小能量间隙，该算法的性能与单元素被标记即 `M = 1` 的情况的局部绝热算法相同。此外，该算法在从初始到最终/问题哈密顿量的演化过程中仅在很小的时间间隔内全局演化，从而保持了全局绝热算法的优点，同时不损失局部绝热搜索算法的加速。

在 \[[22](#bodymatter-003.xhtml#b_9783110670707-003_ref_022)\] 中，证明了量子线路模型可以高效模拟任意基于 AQC 的算法。随后，在 \[[35](#bodymatter-003.xhtml#b_9783110670707-003_ref_035)\] 中也证明了适当的基于 AQC 的算法可以高效模拟任何量子线路模型。此外，Mizel 等人 \[[36](#bodymatter-003.xhtml#b_9783110670707-003_ref_036)\] 提供了绝热量子计算与线路模型量子计算之间等价性的简单证明。因此，AQC 和量子线路计算模型本质上是等价的，这意味着量子算法可以在两种模型中的任一种中设计以解决困难问题。Brady 和 Van Dam 还研究了基于 AQC 优化所需的运行时间 \[[37](#bodymatter-003.xhtml#b_9783110670707-003_ref_037)\]，并表明非绝热加速在一般情况下不会发生，而只在特殊情况下发生。最近，量子近似优化算法（QAOA）\[[38](#bodymatter-003.xhtml#b_9783110670707-003_ref_038), [39](#bodymatter-003.xhtml#b_9783110670707-003_ref_039)\] 和变分量子本征求解器 \[[40](#bodymatter-003.xhtml#b_9783110670707-003_ref_040)\] 分别被提出用于解决经典组合优化和量子化学问题。

本章中，基于绝热量子计算求解全局优化问题的框架已在 [第 3.4 节](#bodymatter-003.xhtml#b_9783110670707-003_s_003_s_004) 中提出。，这将有助于训练机器学习技术，该技术模拟非线性过程，而与计算高效的对应方法不同。此外，使用 AQC 的约束优化在 \[[41](#bodymatter-003.xhtml#b_9783110670707-003_ref_041)\] 中进行了讨论。

## 3.3 绝热量子计算

绝热量子计算 \[[42](#bodymatter-003.xhtml#b_9783110670707-003_ref_042)\] 是量子计算的一种替代方法，已被证明等价于量子线路模型，但似乎在某些方面优于线路模型 \[[31](#bodymatter-003.xhtml#b_9783110670707-003_ref_031)\]。它基于量子力学中一种众所周知的技术，即绝热近似 \[[43](#bodymatter-003.xhtml#b_9783110670707-003_ref_043)\]。它用于在系统的哈密顿量随时间缓慢变化的条件下确定薛定谔方程的近似解。这意味着如果量子系统被制备在其第 n 个本征态中，则在邻近能量间隙足够大且其哈密顿量变化足够缓慢的情况下，它将在整个演化过程中保持在第 n 个本征态。

设量子系统处于状态 `|φ〉`，根据薛定谔方程演化：

(3.1)$i\\hslash\\frac{d}{dt}|\\Phi\\left( t \\right)\\rangle = {}H\\left( t \\right)|\\Phi\\left( t \\right)\\rangle$

其中 `H(t)` 是量子系统的哈密顿量，而 `ħ` 是约化普朗克常数 \[[31](#bodymatter-003.xhtml#b_9783110670707-003_ref_031)\]。设 `H[ini]` 为系统在其初始状态即 `t = 0` 时的哈密顿量，而 `H[fin]` 为系统在其最终状态即 `t = T` 时的哈密顿量，其中

(3.2)`H(t) = (1 - s(t)) H[ini] + s(t) H[fin]`

其中 `s(t)` 是一个连续函数，且 `s(0) = 0` 且 `s(T) = 1`。与 `H[i]` 相关的瞬时本征态用 `|ψ[i]⟩` 表示。一般而言，设 `H(t)` 的本征态为 `|ψ[k](t)⟩`，使得：

(3.3)`H(t) |ψ[k](t)⟩ = E[k](t) |ψ[k](t)⟩`

其中 `E[k](t)` 为相应的本征值，且 `k` 标记本征态（`k = 0` 表示基态）。

最低两个本征值之间的最小间隙定义如下：

(3.4)$g\_{min} = \\min\\limits\_{0 \\leq t \\leq T}\\lbrack E\_{1}\\left( t \\right) - E\_{0}\\left( t \\right)\\rbrack$

`dH/dt` 在两个相应本征态之间的矩阵元的最大值由下式给出：

(3.5)$D\_{max} = \\max\\limits\_{0 \\leq t \\leq T}\\left| \\left\\langle \\frac{dH}{dt} \\right\\rangle\_{1,0} \\right|$

其中 `⟨ dH/dt ⟩_{1,0} = ⟨ψ1(t) | dH/dt | ψ0(t)⟩`

绝热定理指出，如果系统在时间 `t = 0` 时处于其基态 `|ψ[ini]⟩ = |ψ[0](0)⟩`，并在哈密顿量 `H(t)` 下演化，则

(3.6)`|⟨ψ[0](T) | Φ(T)⟩| ≥ 1 - ε²`

前提是：

(3.7)$\\frac{D\_{max}}{g\_{min}^{2}} \\leq \\varepsilon$

其中 `0 < ε ≪ 1`，

并且

(3.8)$\\left| \\frac{\\langle\\psi\_{1}\\left( t \\right)\\left| \\frac{dH}{dt} \\right|\\psi\_{0}\\left( t \\right)\\rangle}{\\left\\lbrack {E\_{1}\\left( t \\right) - E\_{0}\\left( t \\right)} \\right\\rbrack^{2}} \\right| < \\varepsilon,t\\ \\epsilon\\ \\left\\lbrack {0,T} \\right\\rbrack.$

其中 `ε ≪ 1`。

上述绝热计算的条件基于 Folk 定理，该定理最近受到批评 \[[44](#bodymatter-003.xhtml#b_9783110670707-003_ref_044)\]。这些条件不能保证绝热近似的普遍适用性。人们已做出多次尝试来严格研究绝热定理并为绝热近似的通用适用性提供新的条件 \[[45](#bodymatter-003.xhtml#b_9783110670707-003_ref_045)\]。Tong 等人还提出了一组条件，足以验证绝热近似的有效性 \[[46](#bodymatter-003.xhtml#b_9783110670707-003_ref_046)\]。这些是三个条件：

(3.9) $\\!\\!\\!\\! I.\\quad\\quad\\left| \\frac{\\langle\\psi\_{n}\\left( t \\right)|\\psi\_{\\!\\! m}^{\\prime}\\left( t \\right)\\rangle}{E\_{n}\\left( t \\right) - E\_{m}\\left( t \\right)} \\right| \\ll 1,{}t\\ \\epsilon\\ {}{}\\left\\lbrack {0,T} \\right\\rbrack$ (3.10) ${II}.\\quad\\;\\;\\int\\limits\_{0}^{T}\\left| {\\left( \\frac{\\langle\\psi\_{n}\\left( t \\right)|\\psi\_{\\!\\! m}^{\\prime}\\left( t \\right)\\rangle}{E\_{n}\\left( t \\right) - E\_{m}\\left( t \\right)} \\right)^{\\prime}} \\right|dt \\ll 1$ (3.11) $\\quad\\quad\\quad\\quad\\;{III}.\\quad\\int\\limits\_{0}^{T}\\left| \\left( \\frac{\\langle\\psi\_{n}\\left( t \\right)|\\psi\_{\\!\\! m}^{\\prime}\\left( t \\right)\\rangle}{E\_{n}\\left( t \\right) - E\_{m}\\left( t \\right)} \\right)^{\\prime} \\right|\\left| {\\langle\\psi\_{n}\\left( t \\right)|\\psi\_{l}\\!^{\\prime}\\left( t \\right)\\rangle} \\right|dt \\ll 1$

其中 `m ≠ l`，`n ≠ m`，`T` 为总演化时间，`|ψ[k](t)⟩` 和 `E[k](t)` 为时间 `t` 时 `H` 的特征向量和相应特征值，`k = 1,…,N`（`N` 为系统的状态空间大小，其中包括 `l`、`m` 和 `n`）。`ψ′[m]` 是 `ψ[m]` 的一阶导数。
