
目标函数 `f(x)` 以及不等式和等式约束通常是非线性的、非凸的、不可微的、多峰的且维度很高。因此，像梯度法和穷举搜索这样因其确定性而高效的优化技术，在解决此类定义不明确的问题时往往失效 [[57](#bodymatter-003.xhtml#b_9783110670707-003_ref_057)]。基于微积分的方法通常利用搜索空间域信息如局部梯度进行局部优化 [[58](#bodymatter-003.xhtml#b_9783110670707-003_ref_058)]。枚举策略受制于维度灾难，即运行时间复杂度随问题维度呈指数增长 [[59](#bodymatter-003.xhtml#b_9783110670707-003_ref_059)]。

在 [第 3.4 节](#bodymatter-003.xhtml#b_9783110670707-003_s_003_s_004) 中已表明，量子全局优化算法可用于求解有限搜索域问题。任何实变量问题的搜索域都是无限的。为了克服量子算法的这一局限，[[60](#bodymatter-003.xhtml#b_9783110670707-003_ref_060)] 中的实变量搜索空间已被离散化。即一个变量由有限数量的量子比特表示，这决定了解析度和离散化水平。例如，连续域中的决策变量 `x[i]` 由 `x[il]` 和 `x[iu]` 限制。通过取 `n[i]` 个量子比特，可以对变量 `x[i]` 的搜索空间进行离散化，从而在 `[x[il], x[iu]]` 范围内有 `2^(n[i])` 个不同的 `x[i]` 值可供选择。最大离散化误差 `Δe[i]` 如下：
```
(3.14)*Δ**e*[*i*] = (*x*[*i**u*]−*x*[*i**l*])/2^((*n**i* + 1))
```
这种离散化误差即使在经典数字计算机执行的计算中也存在。映射离散化解空间所需的量子比特总数 `nq` 如下：
```
(3.15)*n**q* = ∑[*i*]*n*[*i*]
```
量子比特数量越大，精度越高，然而它也会增加量子算法的运行时间。因此，精度和计算时间之间存在权衡。还需要一个输出或辅助量子比特，其演化根据可逆电路实现的客观函数计算结果而定 [[52](#bodymatter-003.xhtml#b_9783110670707-003_ref_052)]。

## 3.6 基于 AQC 的量子搜索

绝热量子计算是离散门量子计算的模拟类比，它是一个依赖于哈密顿量和绝热定理的通用框架 [[31](#bodymatter-003.xhtml#b_9783110670707-003_ref_031)]。为所求解的问题设计一个问题哈密顿量 (`H[fin]`)，使其为时间无关哈密顿量，且 `H[fin]` 的基态 `|ψ[fin]⟩` 表示问题的解。量子系统由时间相关哈密顿量 `H(t)` 演化。`H(0)` 对应于一个时间无关哈密顿量，称为初始哈密顿量 (`H[ini]`)，其基态易于构造。哈密顿量 `H(t)` 随时间变化并支配系统的演化，它根据绝热定理给出的界限从 `H[ini]` 变化到 `H[fin]`，使得量子系统在达到 `H[fin]` 之前始终接近瞬时哈密顿量 `H(t)` 的基态。因此，绝热量子算法具有以下主要步骤：
1. 确定在量子系统中表示问题所需的量子比特数 `nq`。
2. 找到一个易于构造的初始基态并构造其对应的 `H[ini]`。
3. 根据所求解的问题设计 `H[fin]`。
4. 构造时间相关哈密顿量 `H(t)`，它将在时间 `T` 内支配系统的演化：
```
*H*(*t*) = *H*[*i**n**i*] \* (1−*t*/*T*) + *H*[*f**i**n*] \* (*t*/*T*)
```
or,
```
(3.16)*Ĥ*(*s*) = *H*[*i**n**i*] \* (1−*s*) + *H*[*f**i**n*] \* (*s*)
```
其中 `s = t/T` 且 `s(0) = 0` 且 `s(T) = 1`。
5. 估计总演化时间 `T`。
6. 根据薛定谔方程在时间 `T` 内演化量子系统：
```
(3.17)$i\\hslash\\frac{d|\\psi\\left( t \\right)\\rangle}{dt} = H\\left( t \\right)|\\psi\\left( t \\right)\\rangle$
```
其中 `ħ = 1`。
7. 在时间 `T` 后对量子系统进行测量以获得问题的解。

Farhi 等人在 [[31](#bodymatter-003.xhtml#b_9783110670707-003_ref_031)] 中也尝试使用绝热定理的全局版本在包含 `N[e]` 个元素的无结构数据库中搜索标记元素，用于其量子算法。这导致运行时间为 `N` 量级，即 `O(N)`，与经典算法相比并无优势。Roland 和 Cerf 通过使用局部绝热演化方法改进了该问题的绝热量子算法性能 [[32](#bodymatter-003.xhtml#b_9783110670707-003_ref_032)]。因此，Grover 搜索的绝热版本也具有与电路模型相同的复杂度。本章采用 Roland 和 Cerf 在 [[32](#bodymatter-003.xhtml#b_9783110670707-003_ref_032)] 中提出的绝热演化的局部版本用于 Grover 搜索，以设计求解连续域优化问题的量子算法。

该算法以初始态 `|φ[0]⟩` 开始，它是所有基态的等叠加，`N[e]`（`j` 表示无序数据库中元素的索引）：
```
(3.18)$\\left| \\phi\_{0} \\right.\\rangle = \\frac{1}{{\\sqrt{N}}\_{e}}\\sum\\limits\_{j = 0}^{Ne - 1}|j\\rangle$
```
系统的初始哈密顿量 `H[ini]` 选择为：
```
(3.19)*H*[*i**n**i*] = *I*− |*ϕ*[0]⟩⟨*ϕ*[0]|
```
其中 `I` 是单位矩阵，且 `|φ[0]⟩` 是其零能量的基态。因此，量子搜索算法的 `H[ini]` 与问题无关。假设存在一个可表示如下的问题哈密顿量 `H[fin]`：
```
(3.20)$H\_{fin} = I - \\sum\\limits\_{M \\in m\_{e}}\\left| {\\phi\_{M}\\rangle\\langle\\phi\_{M}} \\right|,$
```
其中 `m[e]` 是解的集合，且 `|φ[M]⟩` 表示基态，也是解。`H[fin]` 可以在不显式知道 `|φ[M]⟩` 的情况下通过使用预言机来判断是否找到解而应用。其实现如下：
```
(3.21)*H*[*f**i**n*]|*ϕ*[*i*]⟩ = *f**p**b*(*ϕ*[*i*])|*ϕ*[*i*]⟩
```
其中函数 `fpb(φ[i])` 实现如下：
```
*I**f*(|*ϕ*[*i*]⟩ ∈ {|*ϕ*[*M*]⟩}) *f**p**b*(*ϕ*[*i*]) = 0
else
*f**p**b*(*ϕ*[*i*]) = 1
```
也就是说，如果 `|φ[i]⟩` 是标记态，则 `fpb(φ[i])` 等于零，对应基态，即最低能量；如果 `|φ[i]⟩` 不是标记态，则 `fpb(φ[i])` 等于一，即能量水平高于基态。`fpb(φ[i])` 可以通过使用与 [第 3.3.1 节](#bodymatter-003.xhtml#b_9783110670707-003_s_003_s_003_s_001) 中对预言机描述的相同技术可逆地实现。

将系统从初始哈密顿量演化到最终哈密顿量的时间相关哈密顿量如下：
```
(3.22)*H*(*t*) = (1 − *s*(*t*)) *H*[*i**n**i*] + *s*(*t*)*H*[*f**i**n*]
```
其中 `s(t)` 是一个连续函数，且 `s(0) = 0` 且 `s(T) = 1`。设 `H(t)` 的本征态为 `|ψ[k](t)⟩`，满足：
```
(3.23)$\\begin{matrix} & {{fpb}\\left( q \\right){= 0;}} \\\\ & {{fpb}\\left( q \\right){= 1;}} \\\\ \\end{matrix}$
```
其中 `E[k](t)` 为相应的本征值，且 `k` 标记本征态（`k = 0` 表示基态）。

最低两个本征值 `E[0]` 和 `E[1]` 之间的能隙由以下方程描述 [[32](#bodymatter-003.xhtml#b_9783110670707-003_ref_032)]：
```
(3.24)$g\\left( s \\right) = \\sqrt{1 - 4\\left( {1 - \\frac{m\_{e}}{N\_{e}}} \\right)s\\left( t \\right)\\left( {1 - s\\left( t \\right)} \\right)}$ $g\_{min} = \\ \\sqrt{}\\left( {m\_{e}/N\_{e}} \\right){\\, and\\, occurs\\ at\\, s = 1/2}.$
```
