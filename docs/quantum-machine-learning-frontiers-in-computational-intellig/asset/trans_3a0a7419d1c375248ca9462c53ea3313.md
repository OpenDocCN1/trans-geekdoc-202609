# 6 结论

Siddhartha Bhattacharyya

机器学习是人工智能的一个分支，它试图开发具有从经验中学习能力的技术。这些经验被表述为由底层模型生成的数据。任何机器学习技术的目标都是可靠地抽象出底层模型，以用于预测和决策等特定任务。受量子力学多功能性的吸引，科学家们开始基于量子力学原理发展机器学习算法。因此，不同形式的经典机器学习算法已在量子计算机制中出现。本书旨在揭示这一方向的一些最新进展。

本书首先向读者介绍量子机器学习的基础知识，参考了众所周知的量子算法的形式，如格罗弗搜索算法 \[[1](#bodymatter-006.xhtml#b_9783110670707-006_ref_001)\]、量子强化学习 \[[2](#bodymatter-006.xhtml#b_9783110670707-006_ref_002), [3](#bodymatter-006.xhtml#b_9783110670707-006_ref_003), [4](#bodymatter-006.xhtml#b_9783110670707-006_ref_004), [5](#bodymatter-006.xhtml#b_9783110670707-006_ref_005), [6](#bodymatter-006.xhtml#b_9783110670707-006_ref_006)\] 和量子退火 \[[7](#bodymatter-006.xhtml#b_9783110670707-006_ref_007), [8](#bodymatter-006.xhtml#b_9783110670707-006_ref_008)\]。还呈现了量子神经网络演进的概览 \[[9](#bodymatter-006.xhtml#b_9783110670707-006_ref_009), [10](#bodymatter-006.xhtml#b_9783110670707-006_ref_010), [11](#bodymatter-006.xhtml#b_9783110670707-006_ref_011), [12](#bodymatter-006.xhtml#b_9783110670707-006_ref_012), [13](#bodymatter-006.xhtml#b_9783110670707-006_ref_013), [14](#bodymatter-006.xhtml#b_9783110670707-006_ref_014), [15](#bodymatter-006.xhtml#b_9783110670707-006_ref_015), [16](#bodymatter-006.xhtml#b_9783110670707-006_ref_016), [17](#bodymatter-006.xhtml#b_9783110670707-006_ref_017)\]。量子算法的信息处理能力取决于涉及非线性函数的机器学习算法的量子实现，这些函数作用于以地形方式表示的信息，如神经皮层中常见的情况。已提出了几种通过地形表示进行机器学习量子计算的方法。这些方法展示了构建可单元算子的方式，可在量子计算机上实现，并通过计算映射实现任意（包括非线性）函数。

优化问题在机器学习和其他领域如工程中无处不在，并且已经开发了许多专门技术来高效解决特定问题。一种基于绝热量子计算的新的量子优化算法，通过局部演化并受格罗弗搜索算法思想 \[[1](#bodymatter-006.xhtml#b_9783110670707-006_ref_001)\] 的启发，可以用于寻找最小值并应用于求解无约束优化问题。

作为从经典范式向量子范式的过渡，几位研究人员参与开发量子启发式算法以弥合两者之间的差距。其中值得注意的是能够实时输出的量子启发式元启发式算法。归功于科学家的不懈努力，量子启发式元启发式算法的不同形式已出现。这些算法足以通过在经典计算机上模拟量子力学原理来获得稳定输出。在大多数情况下，发现量子启发式版本的元启发式算法优于其经典对应算法。

尽管大多数量子机器学习算法基于双能级量子比特，但最近，使用多能级量子系统（使用qutrits或qudits）的工作正在进行中，这有望提高效率。
