
# 绝热量子算法

绝热量子算法由 Farhi 等人 \[[22](#bodymatter-003.xhtml#b_9783110670707-003_ref_022)\] 提出，基于由 Folk 定理推导出的绝热条件。这些算法具有为所求解问题构建的哈密顿量，被称为问题哈密顿量 (`H[fin]`)。`H[fin]` 的基态可以表示为问题的最优解。此外，系统最初被制备在易于构建的初始哈密顿量的基态中。随后，初始哈密顿量逐步改变趋向于 `H[fin]`，使得在演化结束时找到解的概率很大。然而，从初始哈密顿量到最终哈密顿量即 `H[fin]` 的变化不能是瞬时的，甚至不能小于绝热定理要求的最小时间。如果系统演化得足够缓慢，则绝热定理保证系统将保持在瞬时哈密顿量的基态中，因此从初始到问题的哈密顿量变化的演化时间是基于 AQC 的算法复杂度的度量。若干约束满足问题以及优化问题可以用一组聚合的局部哈密顿量 `H = ∑i H i` 表示，其中 `H i` 表示一个局部约束。`H` 的基态将满足尽可能多的此类约束，并在多峰问题（即具有一个以上最优解的问题）的情况下代表其他可能最优解中的期望最优解。系统保持在演化哈密顿量的瞬时基态，因为只要从初始到 `H[fin]` 的哈密顿量变化率保持在绝热定理规定的界限内，它就会保持接近基态。演化时间的界限取决于初始和问题哈密顿量的能量以及瞬时哈密顿量 `H(t)` 的能隙的倒数。哈密顿量的基态与其第一激发态之间的能量差代表哈密顿量的能隙。也就是说，当哈密顿量表示为矩阵时，能隙是哈密顿量最小和第二小特征值之间的差。Farhi 等人 \[[22](#bodymatter-003.xhtml#b_9783110670707-003_ref_022)\] 提出了并研究了针对 `3SAT` 等 NP-完全问题的基于 AQC 的算法。然而，基于 AQC 的算法解决特定问题的关键挑战是哈密顿量能隙的解析计算，目前大多数问题的能隙尚不清楚。另一种方法是数值模拟系统，但用经典计算机模拟量子力学系统的计算成本非常昂贵，因此数值模拟中的量子比特数有限。然而，\[[22](#bodymatter-003.xhtml#b_9783110670707-003_ref_022)\] 中对小规模问题进行的数值模拟确实显示，解决 NP-完全问题所需的时间仅随问题规模多项式增长。但后来的工作 \[[23](#bodymatter-003.xhtml#b_9783110670707-003_ref_023)\] 对 \[[22](#bodymatter-003.xhtml#b_9783110670707-003_ref_022)\] 中显示的基于 AQC 算法的加速提供了强烈的负面证据。研究表明，绝热算法的性能甚至对初始哈密顿量的选择很敏感，如果初始哈密顿量的选择未根据问题的结构进行，算法可能会失败 \[[23](#bodymatter-003.xhtml#b_9783110670707-003_ref_023)\]。此外，在 \[[24](#bodymatter-003.xhtml#b_9783110670707-003_ref_024)\] 中通过将 `3-SAT` 的某些实例的 `H[fin]` 映射到 Ising 模型进行了一些研究，并表明在某些问题实例中哈密顿量能隙呈指数级小。此外，在 \[[25](#bodymatter-003.xhtml#b_9783110670707-003_ref_025)\] 中还构造了一些 `3-SAT` 的特殊实例，这些实例对基于 AQC 的算法很困难。随后，在 \[[26](#bodymatter-003.xhtml#b_9783110670707-003_ref_026), [27](#bodymatter-003.xhtml#b_9783110670707-003_ref_027)\] 中表明，某些优化问题的局部最小值会导致哈密顿量谱中出现非常小的能隙。这些研究设计了难题实例以突出基于 AQC 算法的弱点。但在 \[[28](#bodymatter-003.xhtml#b_9783110670707-003_ref_028)\] 中，使用了 NP-完全问题 Exact Cover 3 (`EC3`)（也称为 `1-in-3 SAT`）的随机生成实例来测试基于 AQC 的算法，并表明基于 AQC 的算法的失败概率很高。Altshuler 等人认为他们的研究为绝热量子优化提供了强有力的反证，即 NP-完全问题的难题实例对基于 AQC 的算法很困难，但这一结论的基础取决于其他 NP-完全问题（如 `3-SAT`）共有的一些特性。然而，最初 Choi \[[29](#bodymatter-003.xhtml#b_9783110670707-003_ref_029)\]，后来 Dickson 和 Amin \[[30](#bodymatter-003.xhtml#b_9783110670707-003_ref_030)\] 对 \[[28](#bodymatter-003.xhtml#b_9783110670707-003_ref_028)\] 中的反 AQC 论点提出了质疑。Choi 认为，基于 AQC 的算法的特定实例的失败不足以得出该问题对绝热量子计算/优化普遍困难的结论。基于 AQC 的算法包含三个可变组成部分，即初始哈密顿量、问题哈密顿量和演化路径。因此，设计基于 AQC 的算法时，这三个组成部分存在许多可能的组合。他进一步认为，如果要证明绝热量子计算即使对特定问题也是低效的，则必须证明该问题不存在多项式时间的绝热量子算法，这需要测试设计基于 AQC 算法时所有可能的组合，而不仅仅是少数实例。此外，Dickson 和 Amin \[[30](#bodymatter-003.xhtml#b_9783110670707-003_ref_030)\] 解析地证明了对于 NP-困难的最大独立集问题，始终存在绝热路径，沿此路径最终哈密顿量的局部最小值与其全局最小值之间不会发生此类交叉，因此哈密顿量能隙不必趋于零，从而可以设计高效的基于 AQC 的算法。因此，要证明绝热量子优化对任何 NP-完全问题都失败，必须证明在多项式时间内不可能找到此类路径以及初始和问题/最终哈密顿量的组合。因此，AQC 是否能高效解决 NP 完全问题仍然是一个开放问题。然而，越来越清楚的是，可能不存在一条唯一路径来解决所有 NP 完全问题。

## 量子无结构搜索

Farhi 等人 \[[31](#bodymatter-003.xhtml#b_9783110670707-003_ref_031)\] 已绝热地实现了量子无结构搜索。该实现基于全局演化模型，其计算复杂度为 `O(N)`，其中 `N` 是数据库的大小。后来 Roland 和 Cerf 表明，通过连续调整初始哈密顿量切换到最终哈密顿量的速率，仅在局部满足绝热性条件，也可以在绝热版本中实现二次加速 \[[32](#bodymatter-003.xhtml#b_9783110670707-003_ref_032)\]。绝热量子搜索已被 Rezakhani 等人 \[[33](#bodymatter-003.xhtml#b_9783110670707-003_ref_033)\] 严格研究，其中确定了与基于 AQC 算法的精度和运行时间相关的结果。还已证明，基于 AQC 的算法在误差方面表现出两个可区分的区域，即在相当一般的条件下，误差在短时间内呈指数下降，然后在较长时间内呈多项式下降。
