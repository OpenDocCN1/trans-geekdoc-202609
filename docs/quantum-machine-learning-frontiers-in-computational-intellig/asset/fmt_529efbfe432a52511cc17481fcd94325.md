
The frequency (`ℬℱ[*i*]`) and velocity (`ℬ𝒱[*i*]`), Pulse Rate (`ℬ*R*[*i*]`) and Loudness (`ℬ*A*[*i*]`) were initialized for every quantum solutions inside the quantum population (Lines 3–4).

Now, in order to generate the active cluster points a selection procedure was applied on the population and the selection process was guided by the quantum state `Q^(BAT)(t)` to produce a binary solution `Bs(t)`. The binary solution `Bs(t)` = {`bs[1]^(t)`, `bs[2]^(t)`,…, `bs[N]^(t)`} was produced by perceiving the state `Q^(BAT)(t)` in the initial generation `t` = 1.

Each of the binary solution `bc[i]^(t)` was generated as follows.

```
$bs_{i,j}^{t} = \\left\\{ \\begin{matrix} {1,\\,\\, IfP\\\_ BAT\\_{ij}^{\\beta t} > P\\\_ BAT\\_{ij}^{\\alpha t}} \\\\ {0,Otherwise} \\\\ \\end{matrix} \\right.,\\,\\, st.i = \\left\\{ {1,2,\\ldots,P\\, size} \\right\\}\\,\\, and\\,\\, j = \\left\\{ {1,2,\\ldots,BLn} \\right\\}$
```

The criteria `bs[i, j]^(t)` = 1 was set to identify the activated cluster points from the population `P_BAT(t)` ([Figure 5.1](#bodymatter-005.xhtml#b_9783110670707-005_fig_001)) for the `t^(th)` generation, where `i` = {1,2,…,`Psize`} and `j` = {1,2,…,`BLn`}. It was considered that the excited states are influenced to make the active cluster centroids from each of the solutions of the population and are denoted by `𝒩[C][i]` for each of the solution of the population. The `𝒩[C][i]` number of activated unique cluster points was stored in `ℬCP[i]`.

![Figure 5.1: Cluster Centroid Representation Scheme.](graphic/converted/b_9783110670707-005_fig_001.png)
Figure 5.1: Cluster Centroid Representation Scheme.

Now, from `ℬCP[i]`, the fitness (`ℱ[T][i]`) of each solution was evaluated with the help of a cluster validity index namely, `DB-Index`. [[eq. (5.12)](#bodymatter-005.xhtml#b_9783110670707-005_eq_012)]. (Lines 5–10).

Now, the best fitness value `𝒪_ℱ[T]` was identified from all computed fitness values (`𝒪_ℱ[T][i]`) and saved along with the respective number of cluster points `𝒪_𝒩[C]`. (Line 11).

Using rotation gate ([eq. (5.10)](#bodymatter-005.xhtml#b_9783110670707-005_eq_010)) strategy another set of populations `P_BAT[new]^(α)` and `P_BAT[new]^(β)` were created. Update the values of `P_BAT^(α)` and `P_BAT^(β)` by using their earlier values or by using their recently created values of `P_BAT[new]^(α)` and `P_BAT[new]^(β)` on the basis of the best value of fitness. Now, if the recently created values were not able to make better fitness values then the current set of values were rejected and the old set of values were preserved in the population otherwise the new set of values were accept. Now, it was possible to create a novel quantum population as it produces the diversity in the solution space (Line 12).

The rotation gate updating process was applied which yielded the best fitness value (`ℬℱ[T]`) and the respective cluster points were preserved in `ℬCP` and `ℬnc` conserved the total number of cluster points (Line 13).

During each execution of the main loop, the quantum positions and velocities were updated by the [eqs. (5.13)](#bodymatter-005.xhtml#b_9783110670707-005_eq_021) and [(5.14)](#bodymatter-005.xhtml#b_9783110670707-005_eq_022) (Line 16).

The rotation gate strategy was responsible for the improvement of the best quantum solutions (Line 17).

The best solution was selected from the computed fitness of the updated positions and a local solution was generated by using the [eq. (5.15)](#bodymatter-005.xhtml#b_9783110670707-005_eq_015). (Lines 18–20).

Next, the new quantum solutions were estimated and by applying rotation gate strategy each value of the state `Q^(BAT)(t)[J]`, `P_BAT[J]^(α)` and `P_BAT[J]^(β)` were updated. (Lines 21–22).

Now the new solution was accepted and the pulse rate of each bat was increased and the loudness of each bat was decreased by the [eqs. (5.16)](#bodymatter-005.xhtml#b_9783110670707-005_eq_016) and ([5.17](#bodymatter-005.xhtml#b_9783110670707-005_eq_017)). (Lines 23–26).

The best quantum solutions was determined and saved (Line 27).

In order to achieve the best solution the main loop was continued for a predefined number of times (Lines 14–29).

Finally, the best quantum solution was determined and the optimum number of cluster was identified along with its associated value of fitness. (Line 30).

The working principle for QIBA is presented as follows.

### Algorithm
Quantum Inspired Bat Algorithm for automatic clustering

Input parameter:
Maximum number of Iteration: `MI`
Size of population: `Psize`

Output parameter:
Optimum cluster number: `𝒪_𝒩[C]`
Optimum fitness value: `𝒪_ℱ[T]`

```
1. A population P_BAT having Psize number of particles (bat) was initialized.
2. Quantum state Q^(BAT)(t) was created for each of the elements of P_BAT. And in order to encode P_BAT the information of the quantum state was used and produce P_BAT^(α) and P_BAT^(β).
3. The frequency (ℬℱ)[i] and velocity (ℬ𝒱[i]) were initialized for every solution of the population.
4. The loudness (ℬA[i]) and the pulse rates (ℬR[i]) were also initialized.
5. for i = 1 to Psize do
6. for j = 1 to BLn do
7. 𝒩[C][i] numbers of cluster points from P_BAT[i] were created by satisfying the condition P_BAT[ij]^(β) > P_BAT[ij]^(α) and the cluster points were stored in ℬCP[i].
8. Now, the fitness ℱ[T][i] was evaluated from ℬCP[i] by using the cluster validity index (DB-Index).
9. end for.
10. end for.
11. The best solution in terms of the best fitness value 𝒪_ℱ[T] was identified.
12. Now, the quantum state Q^(BAT)(t) was updated by using quantum rotation gate to generate new set of values of P_BAT^(α) and P_BAT^(β).
13. The steps 5 to 12 were continued until a predefined condition was satisfied in order to identify the best fitness value ℬℱ[T].
14. for I = 1 to MI do
15. for J = 1 to Psize do
16. The velocity and location of every particles in P_BAT[J] were modified by using the eqs. (5.13) and (5.14).
17. Each value of the state Q^(BAT)(t)[J], P_BAT[J]^(α) and P_BAT[J]^(β) were updated using the rotation gate strategy in order to achieve a better solution from the population.
18. if (Rand(0,1)>ℬR[ij]) then
19. The best solution was selected after calculating the fitness of all bats from their updated positions and a native solution was generated with the help of the eq. (5.15).
20. end if.
21. Now, new solution was evaluated.
22. Each value of the state Q^(BAT)(t)[J], P_BAT[J]^(α) and P_BAT[J]^(β) were updated by using the rotation gate strategy in order to achieve a better solution from the population.
23. if (Rand(0,1)<ℬA[i]&ℬℱ[T][new]<ℬℱ[T][Best]) then
24. New solution was accepted.
25. ℬR[i] was increased and ℬA[i] was decreased by using the eqs. (5.16) and (5.17).
26. end if.
27. The best solution was chosen.
28. end for.
29. end for
30. Finally, the algorithm produced and reported the optimal number of cluster points 𝒪_𝒩[C] with its associated fitness value 𝒪_ℱ[T].
```
