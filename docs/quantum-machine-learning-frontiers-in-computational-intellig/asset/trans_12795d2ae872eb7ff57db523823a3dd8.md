
我们在此讨论一些关于量子机器学习算法实现的重要进展。

2003年[[50](#bodymatter-004.xhtml#b_9783110670707-004_ref_050)]，一群研究人员讨论了图像数据可以非常高效地编码在量子态中。这可能会将执行某些特定且具有挑战性的图像处理任务所需的资源降低几个数量级。2009年[[51](#bodymatter-004.xhtml#b_9783110670707-004_ref_051)]，D-Wave 利用其绝热 D-Wave 量子系统展示了一些显著的成果。利用正则化提升和非凸目标函数，研究人员在 D-Wave 系统中进行了实验以识别图像中的汽车。同年（2009年），另一研究小组展示了使用绝热量子计算的量子 Hopfield 网络将输入数据映射并用哈密顿量记忆数据[[52](#bodymatter-004.xhtml#b_9783110670707-004_ref_052)]。

自 2013 年以来[[53](#bodymatter-004.xhtml#b_9783110670707-004_ref_053), [54](#bodymatter-004.xhtml#b_9783110670707-004_ref_054)]，NASA、Google 研究团队以及大学空间研究协会一直在探索使用 D-Wave 量子计算机解决复杂优化问题，这可能有助于利用量子特性带来的优势解决部分机器学习算法。2015年，研究人员通过在液态量子计算机上使用核磁共振（Nuclear magnetic resonance）技术实现量子支持向量机算法，演示了数字‘6’与‘9’之间的分类[[55](#bodymatter-004.xhtml#b_9783110670707-004_ref_055)]。同年 2015 年，另一项重要成果是研究团队使用非线性光子学实现了一种全光学线性分类器[[56](#bodymatter-004.xhtml#b_9783110670707-004_ref_056)]。

近期，IBM 推出了一个在线框架以访问其量子计算机（名为 IBM Q），该系统支持约 32 + 个量子比特进行操作。他们允许免费使用最多 5 个量子比特在真实量子计算机上工作。我们可以在该系统中运行特定小型量子例程（例如，Grover’s search、Hadamard gate、quantum SWAP test 等），这有助于通过使用这些特定小型量子子例程的输出来解决复杂的机器学习用例[[16](#bodymatter-004.xhtml#b_9783110670707-004_ref_016)]。通过在量子动力学中实现非线性相互作用，可以实现完全功能的量子神经网络，这一说法最近由 2016 年的一个研究团队提出[[57](#bodymatter-004.xhtml#b_9783110670707-004_ref_057)]。

非常近期的 2017 年[[58](#bodymatter-004.xhtml#b_9783110670707-004_ref_058)]，研究人员证明了他们的模型能够生成手写数字。该模型是一种基于任意成对连接的概率生成模型。也在 2017 年，研究人员在量子系统中用量子图像编码图像信息并讨论了该主题上的一些有趣挑战[[59](#bodymatter-004.xhtml#b_9783110670707-004_ref_059)]。2017 年，Yao et.al. 的一项非常有趣的研究工作讨论了量子图像处理及其在边缘检测中的应用[[60](#bodymatter-004.xhtml#b_9783110670707-004_ref_060)]。

2018 年 7 月，Google 在首届量子软件与量子机器学习国际研讨会（QSML）上宣布了 Cirq 的首个公开 alpha 版，这是一个开源框架。这将使开发人员能够构建量子算法，其中可能包括使用小规模数据集的简单量子机器学习算法，而无需量子物理背景[[61](#bodymatter-004.xhtml#b_9783110670707-004_ref_061)]。2020 年，Google 宣布了 TensorFlow Quantum，这是一个用于快速原型设计混合量子-经典 ML 模型的量子机器学习库 [62]。

## 4.7 结论

量子机器学习是一个快速新兴的研究领域，为基于人工智能的研究和应用开辟了新的视野。我们正在看到该领域的积极研究进展，随着量子计算机和量子设备的进步，它可能解决一些用经典机器学习难以在合理时间内解决的最具挑战性的问题，如使用大数据进行聚类和分类训练。深度学习的最新进展帮助我们借助 GPU 和高性能计算训练复杂的机器学习模型，展示了显著的加速和提高的准确性。更复杂的机器学习问题需要大量数据和巨大的计算能力，并且由于硅基芯片技术的局限性，我们在计算能力的上限方面存在显著限制。与经典系统相比，基于量子的系统有望在加速因子方面实现显著改进。一些量子机器学习算法，如量子二元/多类 SVM、量子 K-Means 聚类和量子玻尔兹曼机，在大数据上显示出实质性的性能改进。然而，我们有重要挑战需要解决，以便实现有效且高效的量子机器学习算法，例如：如何以非常高效的方式将经典大数据转换为量子形式；运行此类量子算法的硬件仍处于开发的初始阶段，因此对这些理论量子机器学习模型的适当测试和验证仍然是一个问题。此外，QML 为探索其他领域开辟了新的大门，如理解基于神经网络的算法（如深度学习）的处理，理解用经典机器学习进行量子实验数据分析。与完全功能的量子计算机相比，小型量子设备更容易开发。据信，这些小型特定量子设备可以加速量子术语和方法与机器学习术语和方法的融合，并在混合框架中解决许多特定领域的复杂问题，在该框架中，这些小型量子设备用于解决大复杂问题域中的小型复杂任务。
