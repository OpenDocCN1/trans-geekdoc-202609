
量子计算源于费曼和德意志对量子领域高效搜索技术的研究。这些搜索技术在时间和空间上均优于经典技术。受此启发，研究人员热衷于将现有的软计算工具与量子计算范式相结合，以发展更稳健、更高效的智能算法。由此产生的算法在解决多个科学和工程问题方面具有极大用处，包括数据处理和分析、机器视觉、社会网络、大数据分析、流水车间调度问题等。

量子机器学习是一个新兴的跨学科研究领域，其运用量子物理学原理应用于机器学习。量子机器学习算法通过利用量子计算提供的优势来改进机器学习的经典方法。鉴于量子计算特性所提供的固有并行性，研究人员已发展出不同更稳健、性能更高效的智能工具和技术。

量子增强机器学习是指解决机器学习任务的量子算法，从而改进经典机器学习方法。此类算法通常需要将给定的经典数据集编码到量子计算机中，以便使其可用于量子信息处理。之后，可应用量子信息处理程序，并通过测量量子系统读取量子计算结果。例如，量子比特测量的结果可能揭示二元分类任务的结果。虽然许多量子机器学习算法的提议仍纯属理论，需要全尺寸通用量子计算机进行测试，但其他算法已在小型或专用量子设备上实现。

本书由六章组成，作者均为领先的量子机器学习研究人员。

第1章概述了量子机器学习的基本概念和原理。除阐明量子算法的不同方面外，本章还对量子强化学习和量子退火的原理进行了概览。量子神经网络的发展，特别是该方向的开创性工作也被提及，以启发读者。

大脑中最常见的资讯表征之一是地形或计算图，其中神经元根据其所代表的值系统排列。通过空间表示定量关系，计算图使大脑能够以所需的精度计算复杂非线性函数。第2章提出了两种利用地形表征进行机器学习的量子计算方法。它展示了如何构建可在量子计算机上实现的幺正算子，通过计算图实现任意（包括非线性）函数。

机器学习技术的训练通常需要解决一个困难的优化问题，这是整个模型构建过程及其应用中最昂贵的步骤。在不久的将来，减少机器学习技术训练过程执行时间的一种可能解决方案是将其在量子计算机而非经典计算机上实现。第3章讨论了一种基于绝热量子计算（AQC）的全局优化技术，用于在不限制其结构和所学习底层模型的情况下求解损失函数的最小化。此外，还表明在所提出的框架中，基于AQC的方法在解决全局优化问题方面将优于基于电路的方法。

第4章中，作者讨论了从经典机器学习到量子机器学习（QML）的转变，并探讨了该领域的最新进展。QML不仅与开发可在量子计算机上运行且性能显著提升的高性能机器学习算法相关，而且在其他方面也有非常多样化的含义。本章也试图简要涉及这些方面，但主要重点在于开发可在量子计算机上运行的机器学习算法领域的进展。

第5章旨在介绍两种基于量子启发框架的图像数据集自动聚类技术，采用两种不同的元启发式算法，即遗传算法（GA）和蝙蝠算法（BA）。这项工作提供了两种新颖的技术，可自动识别图像数据集中存在的最佳聚类数，并对量子启发遗传算法（QIGA）和量子启发蝙蝠算法（QIBA）进行了比较研究。还对这些量子启发算法与其经典对应算法进行了比较。实验期间观察到，量子启发技术优于其经典对应技术。比较是基于适应度的均值、聚类有效性指数计算适应度的标准差、标准误差以及最佳计算时间制定的。最后，通过统计优越性检验（t检验）计算得到的p值验证了算法的优越性，并通过Friedman检验得出所提方法的排名。在计算过程中，适应度的改进由一个众所周知的聚类有效性指数——DB指数来评判。实验在四个伯克利图像和两个真实灰度图像数据集上进行。

第6章总结了本书所能实现的内容。本章还阐明了涉及多级量子系统的量子机器学习的未来趋势。
