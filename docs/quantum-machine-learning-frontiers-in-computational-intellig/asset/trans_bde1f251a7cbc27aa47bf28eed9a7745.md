# 4 从经典到量子机器学习

Arit Kumar Bishwas AIIT, Amity University, 信息技术, Noida, Uttar Pradesh, India Ashish Mani EEE, ASET, Amity University, EEE, ASET, G012A, E-I Block, Sector 125, 201303, Noida, Uttar Pradesh, India Vasile Palade Coventry University, 工程与计算学院, Coventry University, Coventry, UK

## Abstract

近年来，机器学习（ML）已开始普遍应用于几乎所有人类活动领域。尽管传统或经典机器学习（CML）方法在解决许多复杂任务方面很有用，但此类方法仍面临许多挑战。一个问题是当前基于硅技术的计算机处理速度的限制，这促使研究人员转向基础的量子理论原理并尝试运行复杂的量子计算实验。未来，为了开发更复杂的人工智能系统，我们必须高速处理海量数据，而现有的经典计算可能无法很好地满足这一目的，原因是硅技术限制。需要一种能够处理海量数据且速度快的不同的技术。近年来，量子计算研究的进展似乎为克服速度处理瓶颈提供了 hopeful 答案。这对于许多计算密集型机器学习模型的训练非常重要。量子技术的最新进展似乎很有前景，可以整体推动机器学习领域的发展。在本章中，我们讨论从经典机器学习到量子机器学习（QML）的转变，并探讨该领域的最新进展。QML 不仅与开发可在量子计算机上运行且性能显著提升的高性能机器学习算法相关，而且在其他方面也有非常多样化的含义。本章也试图简要涉及这些方面，但主要重点是开发将在量子计算机上运行的机器学习算法领域的进展。

Keywords: 量子算法, 量子随机存取存储器（QRAM）, 量子深度学习, 量子计算,

## 4.1 Introduction

机器学习是当今一个重要且热门的研究领域，因为人工智能和智能算法已融入我们的日常生活。机器学习模型使用一些基于数学和统计的算法，利用大量数据进行训练。机器学习算法可分为两大类——监督学习算法和无监督学习算法。在监督学习中，数据以标记数据的形式提供。在无监督学习的情况下，数据集未标记。近年来，机器学习在许多现实生活的重要领域的应用中展现出巨大的可见性和影响力，例如医学图像处理、在线产品推荐系统、金融建模与预测、风险评估、人类语言处理等。深度学习研究的最新进展为解决复杂问题开辟了更多可能性。在机器学习中，数据发挥着至关重要的作用。有些问题可以用较少的数据很好地解决，但深度学习需要海量数据。除了大数据集可用性的问题外，系统的处理和学习速度是另一个关键因素。深度学习算法计算量非常大。尽管使用 GPU 和高性能计算系统可以某种程度上缓解这一问题，但在大数据上进行机器学习（尤其是深度学习）仍然需要很长时间。经验法则是，为了用更多数据进行训练，我们需要更强的处理能力。为了开发处理海量数据的更复杂未来的人工智能系统，现有的经典计算技术可能不足以满足需求，原因是与基于硅的技术相关的限制。我们需要一种不同的技术，能够处理处理速度问题并处理海量数据。经典计算机现在是我们生活的一部分，帮助我们解决复杂问题，但仍然存在一些问题的巨大挑战（例如优化问题），其计算复杂度会随着输入的微小增加而以非常高的比例增长。这类问题对于经典计算机来说非常困难或无法解决。量子计算是克服这些处理问题的答案。量子计算机的计算能力随着系统规模的增长而显著提升，这是由于其独特的属性，这些属性在经典系统中找不到，其中两个最重要的属性是——叠加 & 纠缠。第3节详细讨论了这些属性。

术语量子机器学习（QML）主要指可在量子计算机上运行的经典机器学习算法 [[1](#bodymatter-004.xhtml#b_9783110670707-004_ref_001), [2](#bodymatter-004.xhtml#b_9783110670707-004_ref_002)]。这主要涉及研究人员致力于开发经典机器学习算法的量子版本，主要关注训练过程的加速因素。除此之外，术语 QML 也有更一般的含义。开发功能齐全的商用量子计算机是一个非常活跃的领域，但目前尚不清楚我们是否能在近期拥有可用的设备。近期，研究人员专注于开发小型量子子程序/设备，这些设备可以与经典机器学习方法结合，以在一定程度上获得量子优势 [[3](#bodymatter-004.xhtml#b_9783110670707-004_ref_003)]。这些量子子程序/设备可以设计用于解决在经典领域计算困难的一些复杂任务 [[4](#bodymatter-004.xhtml#b_9783110670707-004_ref_004), [5](#bodymatter-004.xhtml#b_9783110670707-004_ref_005), [6](#bodymatter-004.xhtml#b_9783110670707-004_ref_006)]。

一些最新研究也表明，通过使用量子算法我们可以分析量子态 [[7](#bodymatter-004.xhtml#b_9783110670707-004_ref_007)]。术语 QML 也与分析量子实验生成的数据相关联。将机器学习应用于分析量子相变是这一点的经典例子 [[8](#bodymatter-004.xhtml#b_9783110670707-004_ref_008), [9](#bodymatter-004.xhtml#b_9783110670707-004_ref_009), [10](#bodymatter-004.xhtml#b_9783110670707-004_ref_010), [11](#bodymatter-004.xhtml#b_9783110670707-004_ref_011)]。
