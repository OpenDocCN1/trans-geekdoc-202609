

# 将文件添加到 IPFS

运行 IPFS 的计算机可以询问其连接的所有对等节点是否拥有特定哈希的文件，如果其中某个节点拥有，则会发送回整个文件。如果没有像加密哈希这样的短而唯一的标识符，这将是不可能的。 [https://ipfs.io](https://www.google.com/url?q=https://ipfs.io&sa=D&source=editors&ust=1624824293510000&usg=AOvVaw1baEc1cpfOituSzR6oAvPn) [在 YouTube 上观看](https://www.google.com/url?q=https://youtu.be/UAy1llcOcJw&sa=D&source=editors&ust=1624824293510000&usg=AOvVaw0PsTfdmK2DLBhjBbxJjwcC)

| 预计时间 || 2 分钟 |

| --- | --- |

| 前置要求 |

| --- |

| [创建你的 IPFS 节点](#text00022.html#a2ZM) |

| 命令概览 |

| --- |

| `ipfs daemon` |

| 在 127.0.0.1:5001 上启动 IPFS 本地服务器。 |

| `echo "<text>" > <file>` |

| 将给定文本输出到新文件。 |

| `ipfs add <file>` |

| 将文件添加到你的 IPFS 本地节点。 |

| `ipfs cat <hash>` |

| 查看 IPFS 文件内容。 |

## 添加文件 VS CODE - BASH 终端

| 终端 |

| --- |

```
$ ipfs daemon  

$ echo "test"  hello.txt  

$ ipfs add hello.txt  |
```

文件已添加到 ipfs，生成哈希标识符 在控制台查看文件内容 VS CODE - BASH 终端

| 终端 |

| --- |

```
$ ipfs cat "hash"  |
```

你将看到文件内容被显示 在 Web UI 中检查文件 访问 http://127.0.0.1:5001/webui 点击“files” 点击“pins” 复制哈希 通过此哈希查找，你可以看到该哈希存在 在浏览器中查看文件内容 打开新标签页 ipfs://"hash" 现在你可以在浏览器中看到文件内容

# 在本地节点上固定和取消固定 IPFS 文件

为确保数据在 IPFS 上持久化，且在垃圾回收期间不会被删除，可以将数据固定到一个或多个 IPFS 节点。固定使你能够控制磁盘空间和数据保留。因此，你应使用该控制权来固定任何你希望在 IPFS 上无限期保留的内容。IPFS 的默认行为是将文件固定到本地 IPFS 节点。 [https://ipfs.io](https://www.google.com/url?q=https://ipfs.io&sa=D&source=editors&ust=1624824293532000&usg=AOvVaw14MFFSLQLRpUz6efw6ws_v) [在 YouTube 上观看](https://www.google.com/url?q=https://youtu.be/POdQACj-jRI&sa=D&source=editors&ust=1624824293533000&usg=AOvVaw1Wy1-R77UmY-SuEHo3pkxq)

# 使用 Pinata 在远程节点上固定和取消固定文件

也可以将文件固定到远程固定服务。这些第三方服务让你有机会将文件固定到它们运营的节点，而不是你自己的本地节点。你不需要担心自己节点的可用磁盘空间或运行时间。虽然你可以使用远程固定服务自己的 GUI、CLI 或其他开发工具来管理固定到其服务的 IPFS 文件，但你也可以直接使用本地 IPFS 安装与固定服务协作——这意味着你不需要学习固定服务的独特 API 或其他工具。 [https://ipfs.io](https://www.google.com/url?q=https://ipfs.io&sa=D&source=editors&ust=1624824293548000&usg=AOvVaw0VSY8BUfCvuDgwERgg3yG5) [https://pinata.cloud](https://www.google.com/url?q=https://pinata.cloud&sa=D&source=editors&ust=1624824293549000&usg=AOvVaw1qcUHfmnL8hVloIQhkcdOT) [在 YouTube 上观看](https://www.google.com/url?q=https://youtu.be/0bC_YGrJAkA&sa=D&source=editors&ust=1624824293549000&usg=AOvVaw1-XdElxsKyE8Zvj1agIza6)

| 预计时间 || 4 分钟 |

| 前置要求 |

| --- |

| [创建你的 IPFS 节点](#text00022.html#a2ZM) |

| --- |

| `ipfs pin remote service add pinata <endpoint> <jwt_key>` |

| 添加新的远程固定服务。 |

| `ipfs pin remote service ls` |

| 列出已添加的现有固定服务。 |

| `ipfs add <file>` |

| 将文件添加到你的 IPFS 本地节点。 |

| `ipfs cat <hash>` |

| 查看 IPFS 文件内容。 |

| `ipfs pin remote add --service=pinata -name=<file> <hash>` |

| 将文件固定到远程 IPFS 固定服务。 |

| `ipfs pin remote rm --service=pinata -name=<file> <hash>` |

| 从远程 IPFS 固定服务取消固定文件。 |

## 在 Pinata 上设置 API 密钥

登录你的 Pinata 账户 访问“API Keys” 点击“New Key” 勾选“Admin” 使用“admin-cli”作为你的“Key Name” 点击“Create Key” 将为你生成一个新密钥 从此窗口复制“JWT”值 在终端上设置 Pinata 作为远程服务 将 Pinata 添加为固定远程服务 VS CODE - BASH 终端

| 终端 |

| --- |

```
$ ipfs pin remote service add pinata https: //api.pinata.cloud/psa your\_jwt\_key  |
```

列出所有现有远程服务并检查 Pinata 是否存在

| 终端 |

| --- |

```
$ ipfs pin remote service ls  |
```
