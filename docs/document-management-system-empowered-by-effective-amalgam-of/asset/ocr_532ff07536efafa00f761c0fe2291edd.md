# 2. Related Work

# 2.1. Blockchain

Blockchain is a decentralized network that updates a shared records database by cryptography. A decentralized network eliminates the requirement for a middlemen: one of the parties involved in the transaction requires a basic verification with the Blockchain history to authorize it.

Unlike the traditional system, the Blockchain registry is distributed and stored on computers and data centers. Thus, no single ownership of the data, and each instance contains all the transactions. Blockchain is similar to a massive ledger maintained by all participants in the system, in which transactions are irrevocably revoked [3]. It is a compiled and validated sequence of all transactions in the network since it is public, unique, and shared by system members.

# 2.1.1. Distributed Consensus

Distributed consensus is a critical component of Blockchain and cryptocurrencies in distributed systems. Consensus signifies that many agrees, as opposed to unanimity, which requires everyone to agree. The consensus in Blockchain occurs by methods comprised of specific protocols and well-defined rules between the Peer-to-Peer (P2P) network participants [4].

# 2.1.2. Transactions

With cryptocurrencies, the data structure that captures the semantics of the application is similar to that of a credit balance sheet. It is made up of the following components: A Timestamp, the Previous Transaction's Hash, The Input Value, The Output Value, the Receiver, Account Key of Receiver [5].

# 2.1.3. Chain of Blocks (Blockchain)

Merkle Tree is a tree structure based on hashes that connects transactions in a block [6]. The leaves of the Merkle Tree represent transactions, and the hashes of the children develop the hashes of the parents. The hashes of the leaves, and the hashes of the intermediate branch are calculated using the hashes of the immediate branches, until the hash of the tree's root is included in the block.

# 2.1.4. Smart Contracts

A Smart Contract is defined as a piece of code written in some specific programming language that can be deployed to the Blockchain network to create contract accounts. The contract contains the instructions which define the contract account must be. Smart contracts are self-executing and self-enforcing when the rules are met at all stages. They are tamper-proof, as no one can change what's been programmed, directly written into lines of code. Smart contracts offer several advantages such as [7]: speed and real-time updates, less execution risk, fewer intermediaries, and lower costs.

# 2.1.5. Decentralized Applications (DApps)

Decentralized Applications (DApps) are open-source entities that a group of users may deploy by agreement. They need the for centralized entities like governments or public companies. DApps share some characteristics, which are as follows [8]: open source, decentralized, incentivize, and proof of value protocol.

# 2.2.1. Blockcerts

A developed project was initiated by MIT Media Lab and Machine Learning, Now Hyland Credentials. Blockcerts use an open standard for issuing, viewing, and verifying certificates [9]. It was implemented in Blockchain, and now they are working on expanding to the Ethereum chain. Their primary goal is to facilitate the maintenance of all forms of certificates, including educational credentials, professional certifications, workforce development, and public records.
