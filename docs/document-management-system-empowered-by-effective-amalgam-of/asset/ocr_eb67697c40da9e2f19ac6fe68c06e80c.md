# 4.3. Smart Contracts Implementation

Contracts Implemented: IdentificationCertificateContract.sol, PassportCertiContract.sol, BirthCertificateContract.sol, Dashboard.sol,ShareCertificateContract.sol, Login.sol, NotificationContract.sol
Some important functions are dotted below:

```
function newIdentificationCertificate(string memory accName, string memory _name _number, string memory _ipsfHash, string memory _description)
public {
    IdentificationCertificate memory c;
    c.ipsfHash = _ipsfHash;
    c.description = _description;
    c.name = _name;
    c.number = _number;
    c.state = 0;
    c.accName = _accName;
    IdentificationCertificates[accName] = c;
    IdentificationCertificateQueue memory b;
    b.state = 0;
```
