# Abstract

The world has started digitization, even before the global market, which had led to various processes, like verification and application of documents, going online. This also leads to an increase in the amount of data and traffic on the internet, causing an increase in cyber fraud, as document (digital) forgery. All this led to the need for a secure digital document management platform. With the help of Blockchain Technology, a safe alternative for the same can be developed. In this paper, we have studied the cases where digital forms of documents are used, and based on Blockchain Technology, we have created a secure web application for all the processing of documents. The web application generates credentials as requested for defined templates and stores them securely in the distributed network (Polygon) and the document as an IPFS (InterPlanetary File System). It provides the facility to verify the authenticity of the document. It also allows users to share access to their documents for a specific time.

With the increasing accessibility of the internet throughout the country, the rate of cybercrime is increasing, with an 18% rise in the cybercrime rate [1]. The number of cases of digital forgery is also increasing, with 580 cases in 2020, 515 cases in 2019, and 338 cases of digital document tampering were also seen in the year 2020 [2]. In today's world, the need for a more convenient and secure way to authenticate, share, approve and official digital documents is rising. The existing portals for online processes generally involve filling registration forms, and then uploading a few documents for the verification of information are typically stored in a centralized server, which makes data vulnerable to attacks. The documents are stored at an onsite-server and, in most of the cases is digital form of paper-based original document, which increases the chance of digital forgery and tampering.
Thus, using Blockchain-based services for online applications and other processes provides a solution to improve the security of the document and also result in a decrease of counterfeiting.

## 1.1. Motivation

The cybercrime rate is constantly increasing with the use of digital space. However, cybercriminals like digital forgery and document tampering can go unnoticed if proper checking and inquiries are not made. Thus, there may be cases where the crime has taken place, but due to unawareness of the victim, they are not noticed. Moreover, in a country like India, where the percentage of the uneducated population is considerable, and are dependent on third parties for their various work related to documents, the act of crime against them is high. Thus, the Blockchain-based management system will help improve this situation, especially against unaware people, as it is a more secure option and will lead to a cleaner organization in terms of fake or tampered documents.

## 2. Related Work

### 2.1. Blockchain

Blockchain is a decentralized network updated by cryptography. Unlike the traditional system, the registry is distributed and stored by all participants, and each instance contains all transactions [3].

#### 2.1.1. Distributed Consensus

Distributed consensus is a critical component of Blockchain and cryptocurrencies. It signifies that many agree, as opposed to unanimity, which occurs by methods comprised of specific protocols and well-defined rules between Peer-to-Peer (P2P) network participants [4].

#### 2.1.2. Transactions

With cryptocurrencies, the data structure that captures the semantics of the application is similar to that of a balance sheet. It is made up of the following:
- Timestamp
- Previous Transaction's Hash
- Input Value
- Output Value
- Receiver Account Key of Receiver [5]

#### 2.1.3. Chain of Blocks (Blockchain)

Merkle Tree is a tree structure based on hashes that connects transactions in a block [6]. The leaves of the Merkle Tree represent transactions, and the hashes of the children develop the hashes of the parents. The hashes of the leaves and the hashes of the intermediate branch are calculated using the hashes of the immediate branches until the hash of the tree's root is included in the block.

#### 2.1.4. Smart Contracts

A Smart Contract is defined as a piece of code written in some specific programming language that can be deployed to the Blockchain network to create contract accounts. The contract contains the instructions which define the contract account must be. Smart contracts are self-executing and self-enforcing when the rules are met at all stages. They are tamper-proof, as no one can change what has been programmed directly into lines of code. Smart contracts offer several advantages such as [7]:
- Speed and real-time updates
- Less execution risk
- Fewer intermediaries
- Lower costs

#### 2.1.5. Decentralized Applications (DApps)

Decentralized Applications (DApps) are open-source entities that a group of users may deploy by agreement. They do not need centralized entities like governments or public companies. DApps share some characteristics, which are as follows [8]:
- Open source
- Decentralized
- Incentivize
- Proof of value protocol
