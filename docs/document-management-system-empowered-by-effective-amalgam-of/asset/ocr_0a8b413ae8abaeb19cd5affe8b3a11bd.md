# 2.3. Blockchain Platforms

There are many Blockchain platforms that can be used for deploying DApps and smart contracts. Let's look at few of them with pros and cons.

# 2.3.1. Ethereum

Ethereum is an open-source Blockchain, which is widely used to develop and deploy decentralized and reliable applications. Every node in the Ethereum network stores a full copy of the Blockchain, so all the transactions are executed by the nodes must agree upon the transaction.
Without incurring the expenditures of constructing their own, anyone may create a Blockchain-based system and operate on Ethereum's infrastructure. Ether is used by the Ethereum network to reward nodes for computations and move money between accounts/wallets. Downtime, censorship, fraud, or third-party intervention do not affect Ethereum Blockchain applications.

# 2.3.2. Hyperledger Fabric

It is a business Blockchain network hosted by Linux Foundation, using a modular architecture ensuring confidentiality and scalability. The platform allows developers to build all types of private Blockchain apps. It is extremely popular for organizational use [11]. The differences between Ethereum and Hyperledger Fabric are mentioned in Table 1.

Table 1. Comparison between Ethereum and Hyperledger Fabric [12]

| Points To Consider | Ethereum | Hyperledger Fabric |
|---|---|--|
| Ideal For | Business-to-Consumer businesses and general apps | Business-to-Business Businesses |
| Discretion | Transparent | Confident Transactions |
| Consensus Algorithm | Proof of Work (PoW) | Pluggable Consensus |
| Cryptocurrency Used | Ether is used to execute contracts | No Cryptocurrency |
| Programming Language | Solidity is used to write Smart Contracts | Golang is used to write Chainchains |

# 2.3.3. Polygon (Matic)

Polygon (Matic) is an L2 scaling solution developed on top of Ethereum to solve some of the most significant barriers to DApp adoption: scalability, usability, and speed. Since the users on Polygon can create off-chain actions for payments and smart contract interactions, Polygon calls itself the "Ethereum of blockchains." Polygon makes a distinctive approach to L2 scaling by plasma, a L2 scaling solution that generates a tree-like set of "child Blockchains" that utilize the Ethereum as a tree and arbitration layer.
