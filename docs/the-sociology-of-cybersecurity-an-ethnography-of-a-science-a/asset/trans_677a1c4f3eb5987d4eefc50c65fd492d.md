
同样地，由于 CVE 将每个漏洞置于本体中，clearbluejar 展示了如何通过分析 CVE 的父类别来概括和比较 CVE，以寻求模式并通过他们所称的 CVE North Stars 方法识别根本原因（[clearbluejar, 2023](#bibliography.xhtml#_24044-2003_chp005_ref29)）。我并不声称我理解网络安全科学方面的所有细节。我所声称的是，像 clearbluejar 这样的详细 walk-through 和描述相当于社会学家在生物学实验室中观察到的高级论文和详细的复制协议（[Latour & Woolgar, 1986](#bibliography.xhtml#_24044-2003_chp005_ref83)）、物理学（[Doing, 2009](#bibliography.xhtml#_24044-2003_chp005_ref40)；[Knorr-Cetina, 1999](#bibliography.xhtml#_24044-2003_chp005_ref77)）或行星科学（[Vertesi, 2015](#bibliography.xhtml#_24044-2003_chp005_ref157)）。

我在此没有引用 clearbluejar 的作品，因为它们可以在网上获取，而且占用了一些篇幅。它们不一定对没有一定技术背景或至少互动知识的人来说是可访问的，但 72. 它们做了科学论文应该做的事情。Clearbluejar 以及许多其他安全研究人员使用 CVE 不仅仅是为了进一步推进对已知漏洞的认知。

不，我引用 North Star CVE 和 CVE-2033–23397 的案例是为了说明 CVE 系统化允许对网络安全作为一门科学做出更严格的定义。不仅仅是一门描述并法医式审视旧漏洞历史的科学，以在旧攻击中发现新机制，而是一门利用这一知识来预测并创建关于未来的假设的科学。

73. 这些假设很少以哲学认识论认可的风格形式化。它们依赖于科学的工具性标准，正如 Nancy Cartwright（[Cartwright, 1983](#bibliography.xhtml#_24044-2003_chp005_ref22)）或 Ian Hacking（[Hacking, 2001](#bibliography.xhtml#_24044-2003_chp005_ref63)）等哲学家所提出的。根据 [Cartwright (1983)](#bibliography.xhtml#_24044-2003_chp005_ref23)，科学定律应被理解为在抽象模型的框架内精确成立。在此意义上，科学定律是构建模型的工具。现实是混乱而复杂的，因此科学的角色不仅在于理解和发展定律作为工具的使用，而且同等重要的是理解模型的局限性、边界条件和关键案例。

理论上的悖论在于，网络安全按定义关注局限性、边界条件和关键案例，就像免疫学关注身体对异常的反应，以及材料失效和疲劳科学研究材料科学恰好希望避免的东西一样。像那些共生地，或如果你更喜欢你的思维更肮脏一些，辩证地相互构建元层面的知识追求，这些元层面像分形结构一样累积。每一种知识都依赖于对其例外、失败和边界的知识，正如 Ludwik Fleck 所识别的那样，作为在 [第2章](#ch02.xhtml#_24044-2003_ch002) 中讨论的思想集体的一种社会机制。构成科学就是提供区分统计噪声与真正新颖悖论的工作机制。

从这个意义上说，网络安全是电子学、计算机科学、密码学、自动控制以及许多其他相邻领域（包括社会学和心理学）的元科学。它之所以如此，是因为网络安全正在标准化和研究精确的失效点，或稳定条件，针对其他领域可能认为实际上无关紧要、无法搜索或建模参数失效点的情形。

这就是为什么工具主义作为网络安全作为科学的哲学方法被发现如此有用（[Spring & Illari, 2019](#bibliography.xhtml#_24044-2003_chp005_ref143)）。乍一看，它违背了健全的逻辑，因为它提出科学并不探索现实，而只是探索其简化版本。更糟糕的是，与其说是真理（无论它是什么），科学是根据操纵这个世界简化版本的标准来评判的。实际上，它不仅允许将网络安全研究框定为对模型的研研究，而不是“being just cataloguing and discussing historical cases”（非正式演讲的转述）。同样重要的是，它提供了一种切实可行的方法，使网络安全研究摆脱矛盾、伦理疑虑以及公众中稳定不稳定性的表演性所带来的其他关切。

这就是为什么 CVE 很重要。不仅仅因为它带来了新一代的研究，尤其是在人工智能时代，而且它还为划界提供了入口，或将社会政治背景与科学问题分离。通过 CVE 框定漏洞或安全问题，系统化管理者能够决定哪些社会政治背景被纳入研究的相关范围，哪些被排除。这就是 Leigh Star 及其合著者将标准理解为政治性的方式（[Lampland & Star, 2009](#bibliography.xhtml#_24044-2003_chp005_ref79)），74. 不仅仅因为它们很重要，而是因为它们将可以置于分类数据背景之外的内容分离出来，并由此延伸到基于此类数据构建的研究和基础设施。

因此，标准化机构的划界权力在非常直接的意义上是守门权力。谁可以任命能够验证 CVE 编号的机构？谁可以检查 CVE 本体并提出会被认真对待的更改？谁决定关于 CVE 要向公众披露什么，什么留在后台？在 CVE 董事会的情况下，其所有成员都是美国公民，尽管 CVE 在全球范围内使用。这是对布鲁塞尔效应的一个特殊变体，因为标准化机构并不在国家边界的公认范围内运作。由于 MITRE 总部位于弗吉尼亚州，“the Virginia effect”似乎是一个合适的名称。

作为其布鲁塞尔对应物的变体，弗吉尼亚效应是通过数字基础设施领域的正式自愿标准提案对国家政治权力的延伸。在 CVE 的情况下，它从大约 25 年前的模糊概念发展成为一个可访问且庞大的本体，允许自动化的网络安全研究或防御。同样，弗吉尼亚效应始于关于系统化的社会惯例或对话，以报告或简报的形式出现。随着时间的推移，它固化为物质基础设施本身，获得了网络效应的好处。即使其他方对标准化的细节不满意，像 CVE 这样的系统化也变得太有用或太普遍而无法忽视。因此，曾经的认识论提案最终成为国家或公司的直接政治权力。

幸运的是，仍然有可能调查一份最有可能导致今天所理解的 CVE 的文件之一。约在 2010 年，MITRE 受美国国防部委托准备关于网络安全作为科学的报告和一系列简报。MITRE 将此任务交给了 JASON，这是一个在冷战期间创建的科学家团体，负责就国家防御等事务提供建议。JASON 的报告已以 JSR-10–102 的签名公开（[JASON, 2010](#bibliography.xhtml#_24044-2003_chp005_ref75)）。在撰写本书时，我没有足够的时间重建 JSR-10–102 与 CVE 标准变化之间的关系细节，但由于两者都源自同一机构的同一部门，并且两者共享一些相关方，如网络安全的 NIST 代表，因此很可能发生了某些理论反馈。
