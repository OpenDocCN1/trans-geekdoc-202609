
这说明了网络安全作为一门科学中对手的根本二元性。对手只是混乱、随机故障，还是对手狡猾且始终隐匿？

正如诺伯特·维纳和查尔斯·W·米尔斯时代那样，今天也是如此，神学层面的考量在权力精英中找到了其吸引力。这可能并非 JASON 2010 年简报的意图，但到 2025 年，维纳的思想可能在硅谷精英中会找到不止少数几个拥趸。

韦恩迪·陈在她对硅谷精英软件工作场所的民族志研究中发现，对正念及类似实践的类宗教式迷恋超出了放松或偶发精神性的需求（[Chen, 2022](#bibliography.xhtml#_24044-2003_chp005_ref28)）。正如陈所观察到的，软件公司认识到员工可能对工作赋予“精神”意义，于是他们开始将宗教与编程绑定。其目的与每次将宗教与工作场所绑定时相同：让人们更愿意为更少的报酬工作，或让他们接受否则不会接受的条件。当谈到为了某些研究而在工作场所进行洗脑时，宗教几乎和学术界一样有效（嘿，它们的社会起源是相同的！）。

需要注意的是，陈在人工智能投资热潮席卷劳动力市场之前就已经观察并描述了此类意识形态和社会实践。在加密货币时期支持下的人工智能热潮催生了 TESCREAL^()

TESCREAL 的宇宙生成论是不清晰的，并且本身就起到了蜜罐的作用。它通过新奇或荒谬来诱惑，随后逐渐为某些读者改变其含义，其方式类似于气候否认主义或扁平地球理论。这就是我不愿详细讨论它的原因。

将硅谷或美国权力精英视为世俗技术官僚或完全无神论者是一种错误。宗教意象发挥着重要的象征性作用，不一定作为直接的宗教符号，而是作为其他类型的边界对象；这次至少是为暂时停火和谈判支持或资金所必需的。我的专业专长与美国福音派或一般基督教相距太远，  78. 以及其对保守主义的影响，以至于无法更详细地讨论，但这并不意味着我会对显而易见的事情视而不见。

## Summary

在本章中，我提出了如何将计算机安全漏洞理论化为准理论对象。它们是理论性的，因为它们始终以某种抽象或提案的形式存在。它们是准理论性的，因为它们依赖于计算机基础设施才能被发现或发挥作用。它们也是在特纳理论的意义上以及实验史的悠久传统中的表演性。

如果没有观众来见证和验证新不稳定性和现有不稳定性之间的差异，并且没有来自网络安全专业或科学的验证，不稳定性只存在于假设或通知层面，而非事实。这就是为什么未经测试、未知的零日漏洞处于这一概念的边界，类似于未经测试的科学仪器。

当一种稳定化的不稳定性被执行时，它也成为一个社会事实。基础设施被测试或遭到入侵。公众可能被告知或激动，但公众抗议很少会带来反制措施。这就是网络安全作为一门科学之所以具有政治性的方式，通过稳定化的不稳定性重新安排公共领域中社会信任、私密性和可见性的边界，而不仅仅是通过助长针对个人的数字服务或无人机发射导弹的打击。肖夏娜·祖博夫的行为盈余概念（[Zuboff, 2019](#bibliography.xhtml#_24044-2003_chp005_ref185)）可以被解读为网络安全作为一门科学的社会影响的个体维度。重要且痛苦，对直接受影响的个人而言，但不足以理解对未受影响者的影响。

通过对稳定化不稳定性的理解，本章讨论了网络安全系统学，其作为 NIST CSF 在官方国家层面部署，以及我所称的弗吉尼亚效应的代理工具：CVE、CVSS 和 MITRE 框架。通过文献示例和访谈片段来说明标准，我展示了网络安全如何创造知识。通过讨论 CVE 研究的例子，我还展示了与现有关于网络安全作为一门科学的哲学提案的共识点和批判点。我同意采用工具主义和马赛克统一性作为第一程度的哲学近似，但我仍然批判国际、公众在伦理方面的不问责，以及在交易区和边界对象问题上的不问责。

与 Spring 及合著者的现有哲学文献（[Spring et al., 2017](#bibliography.xhtml#_24044-2003_chp005_ref145)）相反，本章主张研究 CVE 或 MITRE 框架等分类系统作为边界对象，以实现交易区或马赛克的有效运作和审视。我认为 CVE 充当共同语言和共同材料，正如 JASON 所设想的那样，而 Spring 及合著者则对其表示怀疑。  79. 然而，Spring 等人关于 JASON 报告的论文仍然是该领域哲学和社会学中的关键贡献。对后续哲学-网络安全论文的进一步辩论（[Spring, 2023](#bibliography.xhtml#_24044-2003_chp005_ref152)）；[Spring & Illari, 2019](#bibliography.xhtml#_24044-2003_chp005_ref143)，[2025](#bibliography.xhtml#_24044-2003_chp005_ref144)）仍然开放。

最后，为了讨论网络安全知识如何在脱离民主控制的情况下发展，我通过查尔斯·W·米尔斯的“权力精英”框架讨论了我的认识论重建的结果。表明网络安全恰恰关乎权力-知识机构的不透明性、透明性和问责性，我揭示了网络安全作为一门科学是如何作为美利坚合众国权力精英的工具而发展的。

美国并不垄断网络安全知识的标准化，因此欧盟推出了其 CVE 的等价物，欧盟漏洞数据库（[ENISA, 2025](#bibliography.xhtml#_24044-2003_chp005_ref49)）。类似的数据库可能存在于中国等国家的认识论影响范围内，或将开始存在。还有一些数据库名义上由非党派国际机构维护，但 CVE 仍然是最大且最具影响力的。

这就是为什么理解奥古斯丁和马尼教魔鬼的政治神学——正如使用 MITRE 简报和彼得·加利森的研究所讨论的那样——仍然是理解网络安全与 TESCREAL 意识形态集合的相关性以及硅谷和计算机行业精英中宗教社会学研究的重要要素。

本章提供的重建、示例和理论化绝对不能提供该领域在全球范围内的全貌，甚至不能提供在美国影响范围内的全貌。作为对 CVE 权力以及其他未充分审视的标准化机构的批判者，我无法逃脱最后的讽刺。通过本章，最终我分享同样的希望：虽然本章给出的社会-认识论模型可能是错误的，但我希望它会变得有用。
