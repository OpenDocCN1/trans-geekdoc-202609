# # Viewing the Card

We're almost finished; all we need now is the card_show.php script that shows the card to the recipient and notifies the sender that the card was picked up. The first part is like nearly any other script; it loads the include files and sanitizes the input parameters. In this case, we throw out any nonalphanumeric characters in the token parameter:

```
<?php
require_once("card_include.php");
$token = preg_replace('/[^a-z0-9]/i', '', $_REQUEST['token']);
```

We need to know the card content and the details of this particular message. That's easy to do by joining the card_list and cards_sent tables on the ID fields and looking up by the token.
