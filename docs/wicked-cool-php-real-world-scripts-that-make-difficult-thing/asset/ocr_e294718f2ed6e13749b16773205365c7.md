# COLOPHON

The fonts used in Wicked Cool PHP are New Baskerville, Futura, and Dogma. The book was printed and bound at Malloy Incorporated in Ann Arbor, Michigan. The paper is Glatfelter Thor 60# Antique, which is made from 15 percent postconsumer content. The book uses a RepKover binding, which allows it to lay flat when open.
