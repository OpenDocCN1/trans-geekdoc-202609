After you've run through all of the items, all you need to do is output the XML. Use the $doc->asXML() function, and you're finished:

```
print $doc->asXML();
```

function printerror($message) {
	$message = htmlentities($message);

	";
}
?>

This is about all there is to web services. There are plenty of ways to make them more complicated, such as using SOAP and WSDL, but at the end of the day, all that you are doing is gathering data and putting it into the appropriate slots.
