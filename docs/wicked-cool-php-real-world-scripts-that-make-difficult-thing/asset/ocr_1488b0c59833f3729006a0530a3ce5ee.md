Here's how to print out all of the sins in our sample:

```
foreach ($data->sins->sin as $sin) {
    print $sin . " : " . $sin["type"];
    print "<br />";
}
```

As you have probably noticed, it's possible to get confused between attributes and child nodes with this syntax, but in general it's not too bad. You can even use print_r() to print the whole mess if you ever get lost. The output looks like this:
