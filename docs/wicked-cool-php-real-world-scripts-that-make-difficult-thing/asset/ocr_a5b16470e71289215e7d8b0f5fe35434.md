# # Sending the Card

After choosing a card, the user fills out a form with the recipient, sender, and message and sends the card notification on its way.

As with many scripts of this type, card_send.php handles both functions, so it's important to watch the control flow. When presenting the form, the script takes a card ID parameter named ID. When it accepts the form, there are several additional parameters: sender_email, sender_name, recip_email, recip_name, and message.
