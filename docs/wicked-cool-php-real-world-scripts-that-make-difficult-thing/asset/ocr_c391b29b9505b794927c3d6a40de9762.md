Notice the notified field in cards_sent: this indicates whether or not the card has already been viewed. It should always be set to 0 just after sending the card.

Now let's get around to notification. Obviously, we don't want to send another email message to the sender if this is not the first time the card has been viewed, so we check for that first. As we did in card_send.php, we'll use PHPMailer to send the email message:

```
if (!$row['notified']) {
    /* Notify sender that the message was picked up. */
    include_once("phpmailer/class.phpmailer.php");
    $mail = new PHPMailer();
    $mail->ClearAddresses();
    $mail->AddAddress($row['sender_email'], $row['sender_name']);
    $mail->From = 'example@example.com';
    $mail->FromName = 'E-card People';
    $mail->Subject = 'e-card retrieved';
    $mail->Body = "Your e-card to $row[recip_name] has been picked up.
                    Sincerely,
                    Those e-card guys";
    $mail->Send();
}
```
