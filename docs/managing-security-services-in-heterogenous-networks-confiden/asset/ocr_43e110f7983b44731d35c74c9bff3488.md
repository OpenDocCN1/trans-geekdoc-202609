$t_{ik} = max_{1 \le j \le n} \{t_{ij} \times t_{jk}\}$.

Here node i can apply this formula iteratively to find the trust values of multichip away nodes like

+   $t_i = (N^T)t_i$
+   $t_i = (N^T)^2t_i$
+   $\vdots$
+   $t_i = (N^T)^n t_i$

# 3.5 Conclusion

In MANETs, due to resource constraints and network dynamics, the implementation of complex security algorithms degrades network performance. In this work, this limitation is overcome with trust handling methods. Here node trust is evaluated by taking into consideration ability (resources) and attitude. A comprehensive discussion was provided on the trust attacks and their countermeasures. Different soft computing techniques (i.e. fuzzy logic, fuzzy Petri-nets, Dempster-Shafer theory, and trust matrix operations) are discussed for trust management in MANETs.
