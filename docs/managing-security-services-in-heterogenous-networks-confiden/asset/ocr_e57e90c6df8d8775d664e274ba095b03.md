# 4.3 Proposed Model: Proof of Virtue

The new model proposes to circumvent the higher energy and computational resource consumption in the famous POW consensus of Bitcoin. This is done by removing the tougher energy- and resource-intensive nonce identification for block hash generation. Bitcoin has proved safe from all the double-spending attacks using this puzzle calculation. What will happen if we remove this step from the processing? An alternative way is to introduce a new mechanism that is less resource intensive than public blockchain. Since this is a permissionless, public blockchain network, it can accommodate any number of participants joining the network.
