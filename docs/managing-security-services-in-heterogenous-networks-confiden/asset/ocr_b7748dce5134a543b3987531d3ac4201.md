The clustering module forms a cluster based on the pre-processing phase recommendation and the energy level of the current nodes. Weighted fuzzy rules are stored in a knowledge base. The routing module is responsible for selecting the trust paths with the help of the decision manager's recommendation. The decision manager is responsible for controlling all the components of the proposed system architecture.
