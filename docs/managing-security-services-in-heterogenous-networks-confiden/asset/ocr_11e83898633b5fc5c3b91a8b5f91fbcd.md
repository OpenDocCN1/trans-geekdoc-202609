# 4.3.3 Advantages

+   1. Energy and other resource waste is brought down due to the removal of nonce (puzzle) generation in the hash generation process.

+   2. Mining power does not play any role in block generation, which prevents 51% of attacks.

+   3. A new user has to wait for a certain period until he gets the required credit score for participating in the block generation process, which will make the network Sybil resistant.

+   4. Since there is no restriction on the minimum time taken for block generation, the transaction speed will be increased, making the system more scalable.

+   5. The consensus mechanism applied for the block verification and validation makes the system Byzantine fault tolerant.
