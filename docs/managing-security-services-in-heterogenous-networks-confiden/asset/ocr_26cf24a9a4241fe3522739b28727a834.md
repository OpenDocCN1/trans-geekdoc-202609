m_i(k) = \sum_{j \in N_i} \hat{\epsilon}_{ji} T_j(k) (5)

# 3.2.6.3 Hybrid Method

In the hybrid method, a node can evaluate the target node;s trust value based on its direct interactions and by considering other node recommendations. The hybrid trust is computed using Equation (6)

T_{a,b} = \alpha T_d + \beta T_r (6)

Here T_d and T_r represent direct and recommended trust, respectively. \alpha, \beta represents weights to the direct and recommended trusts, respectively, where \alpha + \beta = 1.
