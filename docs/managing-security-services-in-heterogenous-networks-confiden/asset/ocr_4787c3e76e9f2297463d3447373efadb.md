Figure 2.2 shows the performance of the proposed IWFCSRA without outlier detection. Here, the standard ad-hoc on-demand distance vector (AODV) routing algorithm uses a trust mechanism called the AOTDV algorithm and AODV without a trust model with respect to packet delivery ratio. Here, five experiments such as E1, E2, E3, E4, and E5 have been conducted for evaluating the performance of the proposed system in the particular time period.

From Figure 2.2, it can be observed that the performance of the proposed model without clustering performs better when it is compared with the existing algorithms such as AODV and AOTDV. This is due to the fact that the proposed algorithm uses only the trusted nodes, which are identified by the proposed outlier detection method for effective communication in the network for the particular time period.
