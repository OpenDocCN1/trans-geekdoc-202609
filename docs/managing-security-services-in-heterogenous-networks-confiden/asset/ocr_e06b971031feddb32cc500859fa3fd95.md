# 6.3.4.1 Predictive Modeling

We are using three basic prediction models for healthcare data analysis [11]:

+   - Regression
+   - Classification
+   - Patient similarity

Regression and classification are the basic mathematical models to analyze the data, and patient similarity is a technique to find the customized distance metric for a specific clinical context. Let us consider a case study to describe the working procedure of “patient similarity.”
