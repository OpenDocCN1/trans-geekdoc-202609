# Automation Anywhere Enterprise Bot Management Platform

Figure Courtesy: Beginners’ guide to Automation Anywhere-Course created by Automation Anywhere

AAE’s Bot management platform consists of the following three main components:

+   - **Bot creator:** Bot creator is a development client and comprises process specialists and IT experts to enhance, streamline and automate processes by deploying bots.

They are used for authoring and unit testing of automation. They are mainly two types of bots, namely, Task bots and Meta bots. Task bots are used for automating rule-based processes and use structured data. Meta bots are reusable (across several task bots) building blocks that offer speed and scalability to the automation process and are configured only once.

+   - **Control Room:** The control room is the brain of the platform and helps to launch the bots and any type of infrastructure. The CR enables in license management, user management, source code management and offers a dashboard with analytics regarding all the bots deployed. The control room offers centralized deployment, access control and collaboration and digital workforce
