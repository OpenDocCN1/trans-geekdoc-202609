The advent of the ‘Smart City’ concept is leading to a number of IoT devices being used across the landscape of modern infrastructure for leveraging automation of building home, corporate and convenience facilities. The vulnerability of many of these IoT devices have been well exposed in a research study undertaken, namely, the ‘Chain Reaction’ attack.

# ZIGBEE CHAIN REACTION ATTACK

Chain reaction is an academic simulation project that demonstrates the vulnerability of a set of IoT devices to penetration by unauthorized worms that can enter the system through a single device like a Philips Hue bulb.

Source: (https://eprint.iacr.org/2016/1047.pdf )
