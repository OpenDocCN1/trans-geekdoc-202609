
你可以看到它是从早期年份到后期年份的数字顺序排列。请记住，再次强调，这实际上是一个栈，所以顺序会被颠倒。了解这一点后，程序会特意比较 `b` 与 `a`，而不是 `a` 与 `b`。顺序之所以重要，是因为比较的实现方式决定了这一点。由于栈是按照值弹出的顺序来逆序排列的，因此比较第二个值与第一个值（而不是第一个值与第二个值）至关重要。如果你把比较语句改为 `movies.sort_by(|a,b| a.cmp(&b.year))`，你将得到如下所示的输出结果。通常，你会比较 `a` 与 `b`，即在 `a` 上调用 `cmp()` 特征，并将 `b.year` 作为参数传入。但这假设你使用的是队列而不是栈，意味着列表的顶端是第一个值，而不是最后一个值。

## SEARCH TREES

还有其他通过使用数据结构来进行排序的方法，这些结构可能更适合当前任务。计算机科学中常见的数据结构类型是 `binary tree`（二叉树）。与链表、队列或栈那样的列表不同，二叉树看起来像它的名字所暗示的那样——一棵树。计算机科学家在谈论树时，通常指的是一种结构，其根节点位于顶部，并向下辐射出多个节点。在二叉树的情况下，每个节点会有两个子节点。如在 [Figure 14.6](#c14.xhtml#c14-fig-0006) 所示，二叉树的结构类似于树根从单一顶部节点发出的样子。当计算机科学家提到树时，通常指的是这种从顶部单一节点向下发散的结构。对于二叉树，每个节点会有两个子节点，如 [Figure 14.6](#c14.xhtml#c14-fig-0006) 所示。通常，树在构建时会保持有序。父节点保持不变，而后续节点会根据其值相对于父节点的大小进行定位。通常，小于父节点的值会移动到左侧，然后与下一个节点比较，若值更小则继续向左，若值更大则向右。

如果你看 [Figure 14.6](#c14.xhtml#c14-fig-0006) 顶部的树，在其右侧有一个新条目。该条目尚未被放置。数值 8 大于 5，因此它会移动到树的右侧。接下来我们遇到的值是 12。我们知道 8 小于 12，因此我们会移动到左分支。如果该分支上没有节点，则可以直接在该位置放置 8。你可以在 [Figure 14.7](#c14.xhtml#c14-fig-0007) 中看到此操作的结果。
