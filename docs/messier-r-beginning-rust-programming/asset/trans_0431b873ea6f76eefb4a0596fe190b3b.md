### 读取 GPIO

点亮 LED 很有趣，但使用 GPIO 还能做的事情远不止这些。我们也可以从 GPIO 读取值。我们可以查看如何正确连接面包板以读取开关的值。这是一个推拉按钮设备，当正确的引脚读取其值时，它的值会改变。首先，我们需要正确连接所有组件。有多种方法可以实现这一点。如果你在网络上搜索在树莓派上使用推拉按钮的 GPIO，你会发现很多不同的接线图。为了简化，我们将采用简化的方法。推拉按钮的一端将连接到 GPIO #23，另一端连接到地。你可以在 [Figure 13.11](#c13.xhtml#c13-fig-0011) 中看到面包板，按钮已正确连接。你也会看到 LED 已经连接，因为你可以使用此接线让按钮打开 LED 并关闭 LED。我们在此不使用完整的接线设置，因为我们只关注读取 GPIO 引脚的值。
