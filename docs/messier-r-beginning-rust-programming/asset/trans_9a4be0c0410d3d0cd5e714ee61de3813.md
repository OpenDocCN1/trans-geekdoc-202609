由于拥有权的概念，引用的使用以及变量的管理方式是Rust语言构建的基础概念，你需要适应它们的工作方式。如果你不需要修改一个值，并且在函数调用后需要访问该值，你可以使用引用将值传递给函数。这意味着变量不会被调用函数占有，因此当变量在函数结束时超出作用域时，内存会被释放。

C中的struct类型是C++中class的基础。事实上，在C++中，struct类型本质上是没有关联函数的public class。或者换一种说法，你可以把class看作是带有函数或方法的struct。面向对象编程的基础概念是class，但它更是数据封装的基础元素。虽然数据封装是面向对象设计的基础，但它不仅仅与这种语言设计方法相关。事实上，由Niklaus Wirth（他还开发了Pascal，曾是常用教学语言）设计的Modula-2编程语言使用数据封装，但它并不是面向对象语言。

数据封装在语言设计和程序设计中的思想是将数据与所有作用于该数据的程序方法放在一起。这保护了数据不被其他方法作用。在像C++和Java等常见面向对象语言中，我们获得了确保对象内的数据保持私有、仅由该对象的方法可访问的能力。这种使属性私有的能力伴随着数据的公共和私有设计ations的概念。

为什么要提到这些？在Rust中，struct也是基础。作为一门现代语言，Rust认识到数据并非孤立的，它通常与其他数据相关联。此外，Rust语言开发者认识到，一旦你拥有复杂的数据类型，你就会想对其进行操作。这意味着你可以使用trait为struct附加函数，这为你提供了直接在数据结构内对数据进行操作的方式。

与C struct声明的另一个区别是，C要求以分号终止声明，就像任何其他语句一样。在Rust中，这不被视为需要终止的语句，因此你可以省略分号。

### Traits and Implementations

在struct声明的顶部有一行与向struct添加功能性有关，即程序可以作用于struct中的数据的内容。在我们继续之前，让我们先谈谈这些程序实现。在Rust中，你定义trait。这些是可执行的特性，一个struct可能拥有它们。Rust中的trait类似于C++中的interface，C++中的interface是一种抽象技术，就像trait是Rust中的抽象技术。你定义trait，包括它的调用方式，而不关心其实现，实现则单独处理。
