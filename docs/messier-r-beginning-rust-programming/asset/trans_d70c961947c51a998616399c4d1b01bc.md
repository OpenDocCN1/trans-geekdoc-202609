### 使用 Windows 事件日志

syslog 服务通常在类 Unix 系统（如 Linux 和 macOS）上运行。你可以为 Windows 系统获得 syslog 服务，但 Windows 已经内置了广泛的日志功能。Windows 事件日志，通常通过 Windows 事件查看器应用程序访问，是 Windows 提供的用于记录消息的服务或子系统。[Figure 13.1](#c13.xhtml#c13-fig-0001) 展示了 Windows 事件查看器的外观。这与我们一直在查看的基于文本的 syslog 日志不同。与 syslog 相比，几乎不需要开发专用查看器来查看日志，因为它们都是文本格式且通常可读。字段并不多，且可以轻松区分。每条日志消息的格式都相同。虽然这也适用于 Windows 事件日志，即每条记录都有明确定义的信息，但 Windows 系统中的每条记录传达的细节更丰富。
