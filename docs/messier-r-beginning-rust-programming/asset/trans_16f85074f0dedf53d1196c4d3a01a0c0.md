
一旦我们使用 `use` 语句添加了 `log` 和 `winlog` 的功能，我们就可以开始编写程序。我们首先要做的是注册一个事件源。这通过 `winlog::register()` 完成。你可以为它提供任何名称。然而，我们需要初始化日志系统，使用 `winlog::init()` 并传入我们日志的名称。一旦我们拥有一个已初始化的标识符，它将提供访问 Windows 日志子系统的权限，我们就可以调用宏。每个宏都基于消息的严重程度。[Figure 13.5](#c13.xhtml#c13-fig-0005) 展示了日志中的错误消息。此程序实际上会生成三条不同的日志消息。其中一条是警告消息，一条是信息消息，一条是错误消息。

![FIGURE 13.5: Error message in Windows Event Log](images/c13f005.png)

[**FIGURE 13.5**](#c13.xhtml#R_c13-fig-0005): Error message in Windows Event Log

你可以看到事件 ID 为 1。`winlog` 崩溃相当有限，部分原因是它依赖于 `log` 崩溃。如前所述，Windows API 调用需要大量数据。`winlog` 崩溃无法访问可传递给 Windows 事件日志的不同信息。相反，它假设一些默认值，导致日志中的消息不如它们本可以表达的那样丰富。不过，你可以自定义要写入的消息，并且该消息会发送到日志子系统，因此这样做仍然具有很大价值。

## WORKING WITH RASPBERRY PI

树莓派是一款低成本的单板计算机，这意味着它包含一个处理器、内存、输入/输出设备（以 USB 接口形式）、存储（以 microSD 卡插槽形式）、网络、视频和音频，全部集成在一块电路板上。虽然你现在可以找到几乎所有组件都集成在单块电路板上的设备，但通常内存需要与主板插槽配合的独立卡片。除此之外，树莓派的体积也很小。它是一种单板计算机，尺寸约等于一副扑克牌，如 [Figure 13.6](#c13.xhtml#c13-fig-0006) 所示。照片展示了一块树莓派 Model 4 与一副标准扑克牌并置。

树莓派之所以能如此小巧，有几个原因。其一是它不支持额外的板卡来提供更多功能，与传统计算机不同。这意味着无需在主板上预留插槽给那些额外板卡使用。此外，它不提供多存储设备的连接器，这简化了输入/输出需求。无需为多个 SATA 驱动器提供线缆和接口。树莓派内置视频，以 mini HDMI 接口形式呈现。这是一个简单的计算设备，因此不需要体积庞大。

![FIGURE 13.6: Raspberry Pi](images/c13f006.png)

[**FIGURE 13.6**](#c13.xhtml#R_c13-fig-0006): Raspberry Pi

如果你观察现代主板，你可能会看到一个大型处理器。事实上，处理器本身并不大。但现代处理器会产生大量热量；处理器占用的空间大部分用于散热。过去，处理器可以通过散热器散热即可。如今，不仅需要散热器，还需要风扇主动将热量从处理器中抽走，防止其过热。树莓派使用一种不同于当前台式机或笔记本电脑处理器的处理器，从而避免了散热器的需求。[Figure 13.7](#c13.xhtml#c13-fig-0007) 展示了 AMD Ryzen 处理器上的风扇大小，其占用的面积仅为传统风扇顶部风扇面积的一部分。

![FIGURE 13.7: AMD processor with a fan](images/c13f007.png)

[**FIGURE 13.7**](#c13.xhtml#R_c13-fig-0007): AMD processor with a fan

Intel 处理器（包括兼容的 AMD 处理器）采用复杂指令集，意味着支持大量指令。每个处理器家族都有定义好的指令集，被称为 *operation codes* (opcodes)。CISC 设备中的每条指令可能执行多项任务，可能需要多个时钟周期完成。这使得每条指令既强大又使得很难确定处理器每秒能处理的指令数量，因为每条指令所需的时钟周期数是可变的（电压变化指示任务执行时机，即时钟周期）。

树莓派采用 *reduced instruction set computing* (RISC) 技术。其设计哲学是每条指令应执行简单、明确的任务。树莓派使用 ARM 公司开发的处理器，该公司专注于 RISC 处理器。你也会在移动设备中看到 ARM 处理器。相较于更复杂的 Intel 派生处理器，ARM 处理器的一个优势是功耗更低。由于功耗更低，热量更少，无需像大型系统那样具备散热能力。因此，树莓派无需体积巨大即可提供强大的计算系统。正如 [Figure 13.8](#c13.xhtml#c13-fig-0008) 所示，树莓派在传统计算机内部的风扇上放置，体积小于传统台式机处理器所需的空间。

![FIGURE 13.8: Raspberry Pi compared with a traditional processor](images/c13f008.png)

[**FIGURE 13.8**](#c13.xhtml#R_c13-fig-0008): Raspberry Pi compared with a traditional processor

树莓派还提供了一项在现代计算设备中独有的特性。回顾 [Figure 13.6](#c13.xhtml#c13-fig-0006)，你会看到一组看起来准备好连接的引脚。这是通用输入/输出 (GPIO) 头，可连接单独的引脚或连接在 ribbon cable 末端的连接器。该 ribbon cable 可能连接到面包板，从而在更便捷的空间中布线电路，而非直接使用数根跳线电缆连接到 GPIO 头。你可以在 [Figure 13.9](#c13.xhtml#c13-fig-0009) 中看到面包板的示例。该示例展示了 ribbon cable 连接的插头，以及一些将被布线到面包板以实现特定功能的元件。
