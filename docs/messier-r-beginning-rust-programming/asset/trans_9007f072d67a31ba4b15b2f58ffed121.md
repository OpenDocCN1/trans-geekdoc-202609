
一旦我们开始讨论持久性数据存储，就应该考虑以不同的方式结构化我们的应用程序。这需要结合文件的内容。Suzanne的浏览器可以处理HTML并显示它。如果Suzanne将数据发送到服务器，例如当她在搜索产品时，仅有的Web服务器无法处理它。它需要引入另一个软件组件。

应用服务器，负责运行程序或函数，可以与Web服务器在同一台机器上运行，这可能是PHP（一种脚本语言）的情况，它可以通过Web服务器内的模块进行处理。应用服务器也可以在完全独立的系统上，或者至少在其自身的应用程序空间内。这在像JBoss或Tomcat这类Java应用服务器中很常见。请求从Web服务器发送到应用服务器。应用服务器本身可能需要处理HTTP请求，因为Web服务器可能只是将请求转发给它。除了处理HTTP请求外，应用服务器还会从终端用户（例如Suzanne）那里获取参数，并使用它们执行程序化操作。

如前所述，一个操作是查找产品信息。这通常需要数据库服务器。再次强调，数据库服务器是一种接收请求并提供响应的软件。它可能是存储某条信息的请求，也可能是查询已存储的信息的请求。在我们的示例中（如[图8.1](#c08.xhtml#c08-fig-0001)所示），数据库是一个独立的物理服务器系统。它不一定如此，但在我们的情况是如此。
