### 栈

另一种常见的集合类型是栈。我们在讨论内存管理时已经提到过栈。每当函数被调用时，会在栈上压入一个新的帧。与栈的操作涉及一对函数：`push` 用于将条目压入栈，`pop` 用于从栈中弹出值。这意味着我们是在向集合中添加和移除值，而不是让它们一直保持在内存中并顺序遍历条目。可以在 [Figure 14.4](#c14.xhtml#c14-fig-0004) 中看到使用栈的示例。左侧展示了四个已压入栈的条目。当我们弹出一个值以获取它时，该条目会被移除，不再存在于集合中。但是，移除一个条目会让我们能够访问其下方的下一个值。

栈的概念及其工作方式常通过类比餐厅的托盘来解释。这可能部分是因为餐厅中的托盘通常存放在弹簧加载的机制中。这使得 `push` 和 `pop` 的直观观察变得容易。你将托盘压入托盘堆栈，堆栈随之下沉；你取出托盘，堆栈在去除托盘重量后略微回升。但通过观察 [Figure 14.5](#c14.xhtml#c14-fig-0005) 中的盘子也可以轻松看到栈的结构。这也是一个栈，展示了计算机中的栈如何运作。你从洗衣机中取出干净的盘子并将其叠加到堆栈上——即把盘子压入栈。这会持续增加栈的大小，直到需要进食时，你取出一盘或多盘盘子。 [Figure 14.5](#c14.xhtml#c14-fig-0005) 展示了两盘白色盘子，随后是三盘红色盘子，最后是一盘白色盘子。当你从栈中取出盘子时，你会取下最上面的那盘，使栈大小减少一个。我们对数据的操作方式相同：我们将条目（或盘子）压入栈，使栈大小增大；当我们想要获取条目时，我们弹出它，使栈大小减少一个。

虽然 Rust 有所谓的 *智能指针*，但通常不使用它们，因为让 Rust 管理内存更安全；我们可以使用 `Option` 枚举数据类型来获得类似指针的效果。在传统语言如 C 中，你通过检查指针值是否为 `NULL` 来判断是否到达列表末尾，这意味着没有指向任何内存位置。在 Rust 中，你通过将值包装在 `Some` 枚举中来创建列表；如果没有值，则得到 `None`，概念上类似于 `NULL`，表示什么都没有。
