The proposed approach involves integration of the MAS and BCT to detects early warning signals for system failure prediction during executing. Our approach, first extracts the log key from execution traces by grouping the identical log message together and replaces all free text of the original log message with the log key, which reduces the amount of data drastically. Second, we send the output from the first step to rule based classifier algorithm to classify the data. Third, we use a Finite State Automaton (FSA) to model the execution behavior of each problem. Finally, we do a prediction using decision tree algorithm. The main contributions of our work can be summarized as follows: (1) We developed a general log analysis fully automatic approach involves integration of the MAS and BCT to detects early warning signals for system failure prediction before it happens. It works on analyzing the log line by line, it does not need a series of lines (features) to make the prediction which is often associated with log-based analysis. (2) We designed and implemented automated log analysis, which can analyze log data on a large scale accurately, quickly and efficiently. (3) We designed a prediction system based on the supervised learning algorithms (rule-based classification, decision tree algorithm), which is able to outperform the most existing systems. (4) We evaluated our approach by using real dataset (Hadoop Distributed File System) and validated its effectiveness through the standard performance metrics, precision, recall and F-score. We have also shown that our system can identify the exact type of failure before it occurs and also provide a detailed report to the administrators about the failure before it occurs.
