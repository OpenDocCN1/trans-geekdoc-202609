## 5 CONCLUSION

This paper presents prediction approach, an approach for automatic analysis of execution traces and detects early warning signals for system failure prediction during execution using a MAS and BCT-based approach. The proposed prediction approach uses event sequences to predict failure before it happened. The proposed prediction approach is constructed using a four-layer MAS architecture. First is data preprocessing layer, second is data classification layer, third layer is building a failure model and finally, prediction layer. Our approach, validated on real data, it addresses a major need for administrators of these large systems, predict anomalies before it occurs with 100% accuracy.
