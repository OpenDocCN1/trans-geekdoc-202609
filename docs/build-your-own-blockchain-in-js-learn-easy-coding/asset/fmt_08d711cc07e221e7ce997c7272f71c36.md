
# Add mining interval, halving period and halving percentage

To add mining halving period, and halving percentage to the blockchain, you can modify the `Blockchain` class and `mineBlock` method as follows:

```javascript
class Blockchain {
  constructor(name, currency, totalSupply, miningReward, miningInterval, halvingPeriod, halvingPercentage) {
    this.name = name;
    this.currency = currency;
    this.totalSupply = totalSupply;
    this.miningReward = miningReward;
    this.chain = [this.createGenesisBlock()];
    this.difficulty = 4;
    this.miningInterval = miningInterval; // in seconds
    this.halvingPeriod = halvingPeriod; // in blocks
    this.halvingPercentage = halvingPercentage; // as a decimal (e.g., 0.5 for 50%)
  }

  createGenesisBlock() {
    return new Block(0, "01/01/2024", {name: this.name, currency: this.currency, totalSupply: this.totalSupply}, "0");
  }

  getLatestBlock() {
    return this.chain[this.chain.length - 1];
  }

  addBlock(newBlock) {
    newBlock.previousHash = this.getLatestBlock().hash;
    newBlock.mineBlock(this.difficulty);
    this.chain.push(newBlock);
  }

  isChainValid() {
    for (let i = 1; i < this.chain.length; i++) {
      const currentBlock = this.chain[i];
      const previousBlock = this.chain[i - 1];
      if (currentBlock.hash !== currentBlock.calculateHash()) {
        return false;
      }
      if (currentBlock.previousHash !== previousBlock.hash) {
        return false;
      }
    }
    return true;
  }

  mineBlock(minerAddress) {
    const latestBlock = this.getLatestBlock();
    const now = new Date().getTime() / 1000;
    // Check if mining interval has elapsed
    if ((now - latestBlock.timestamp) < this.miningInterval) {
      console.log(`Mining interval has not elapsed. Please wait ${(this.miningInterval - (now - latestBlock.timestamp)).toFixed(2)} seconds before mining the next block.`);
      return;
    }
    const newBlock = new Block(
      latestBlock.index + 1,
      now,
      [],
      latestBlock.hash
    );
    // Calculate mining reward
    const currentReward = this.miningReward * (1 - Math.floor((latestBlock.index + 1) / this.halvingPeriod) * this.halvingPercentage);
    // Add mining reward to miner's address
    console.log(`Mining block ${newBlock.index}...`);
    console.log(`Mining reward: ${currentReward} ${this.currency}`);
    console.log(`Adding ${currentReward} ${this.currency} to miner's address ${minerAddress}...`);
    // Here, you would add the mining reward to the specified miner's address in your blockchain implementation.
    newBlock.data.push(`Mining reward: ${currentReward} ${this.currency}`);
    this.addBlock(newBlock);
  }
}
```

In this updated `Blockchain` class, the constructor takes three additional arguments: `miningInterval`, `halvingPeriod`, and `halvingPercentage`. The `mineBlock` method has been modified to check if the mining interval has elapsed before allowing the mining of the next block. It then calculates the current mining reward based on the current block index and the halving period and percentage specified in the constructor. The mining reward is added to the specified miner's address (you would need to implement this in your blockchain implementation) and the mining reward is also added to the data of the new block.

Note that in the `mineBlock` method, the mining reward is added to the console output and the data of the new block. In your implementation, you would need to modify this to add the mining reward to the miner's address in your blockchain network.

# Hashing Algorithm

In the above implementation of the blockchain, the hashing algorithm used is SHA-256 (Secure Hash Algorithm 256-bit). This is a commonly used hashing algorithm in many blockchain networks, including Bitcoin.

In the `Block` class, the `calculateHash` method uses the SHA-256 algorithm to create the hash of the block's contents. Here is the code snippet that shows the SHA-256 hashing implementation in JavaScript:

```javascript
const SHA256 = require("crypto-js/sha256");

class Block {
  constructor(index, timestamp, data, previousHash = "") {
    this.index = index;
    this.timestamp = timestamp;
    this.data = data;
    this.previousHash = previousHash;
    this.hash = this.calculateHash();
    this.nonce = 0;
  }

  calculateHash() {
    return SHA256(
      this.index +
      this.previousHash +
      this.timestamp +
      JSON.stringify(this.data) +
      this.nonce
    ).toString();
  }

  mineBlock(difficulty) {
    while (
      this.hash.substring(0, difficulty) !== Array(difficulty + 1).join("0")
    ) {
      this.nonce++;
      this.hash = this.calculateHash();
    }
  }
}
```

Here, `SHA256` is imported from the `crypto-js` library and used to calculate the hash of the block's contents in the `calculateHash` method.

# Create Wallet for above new coin

To create a wallet for the new coin, you need to generate a key pair consisting of a public key and a private key. The public key is the address to which other users can send coins, and the private key is used to sign transactions and prove ownership of the coins associated with the address. Here's an example of how you can create a key pair using the `elliptic` library in JavaScript:

```javascript
const EC = require('elliptic').ec;
const ec = new EC('secp256k1');

class Wallet {
  constructor() {
    this.keyPair = ec.genKeyPair();
    this.publicKey = this.keyPair.getPublic('hex');
    this.privateKey = this.keyPair.getPrivate('hex');
  }
}
```

Here, the `elliptic` library is used to create an instance of the `EC` class with the `secp256k1` curve, which is the same curve used by Bitcoin. Then, in the `Wallet` class constructor, a new key pair is generated using the `genKeyPair` method, and the public and private keys are extracted and stored as properties of the wallet object.

With this code, you can create a new wallet object by calling `new Wallet()`, which will generate a new key pair and return the corresponding wallet object with the public and private keys as properties. You can then use the public key to receive coins and the private key to sign transactions and spend the coins.

# Auto generate publickey and privatekey

To auto-generate the public key and private key for each wallet, you can modify the `Wallet` constructor to generate a new key pair if no keys are provided as arguments, like this:

```javascript
const EC = require('elliptic').ec;
const ec = new EC('secp256k1');

class Wallet {
  constructor(publicKey = null, privateKey = null) {
    if (!publicKey || !privateKey) {
      const keyPair = ec.genKeyPair();
      this.publicKey = keyPair.getPublic('hex');
      this.privateKey = keyPair.getPrivate('hex');
    } else {
      this.publicKey = publicKey;
      this.privateKey = privateKey;
    }
  }
}
```

Here, the `publicKey` and `privateKey` arguments are optional, and if they are not provided, a new key pair is generated using the `genKeyPair` method of the `EC` class. Otherwise, if the keys are provided, they are used as the public and private keys for the wallet.

With this modification, you can create a new wallet object without providing any keys, like this: `new Wallet()`. This will generate a new key pair and return the corresponding wallet object with the public and private keys as properties. Alternatively, you can create a wallet object with specific keys, like this: `new Wallet('public key', 'private key')`.
