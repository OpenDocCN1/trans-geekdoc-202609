To summarize and make the final decision, all quantile values obtained from the baseline and monitoring phases are collected into the vector q = [[qx1, ..., qxn], [qz1, ..., qzm]]. Using the threshold obtained from the baseline phase, it is expected that the first n samples of the vector q locate under the threshold implying the undamaged condition of the structure; otherwise, each of the quantile values over the threshold is a false alarm error.

For the quantile values of the monitoring phase, |qz1|, ..., |qzm|, there are three situations:

+   - If each of the quantile values |qz1|, ..., |qzm| exceeds the threshold, it needs to alarm the occurrence of damage.
+   - After alarming the occurrence of damage and without any repairing, retrofitting, and rehabilitating procedures on the structure, any quantile value under the alarming threshold is indicative of false negative.
+   - If the quantile values |qz1|, ..., |qzm| do not exceed the threshold, one can make sure the undamaged state of the structure.
