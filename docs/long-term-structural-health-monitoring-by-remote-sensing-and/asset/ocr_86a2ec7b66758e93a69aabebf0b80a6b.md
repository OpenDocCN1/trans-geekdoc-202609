**Category III.** The underlying goal of an SHM process is to determine the difference between at least two structural state conditions (i.e., an undamaged state versus a current state, which can be undamaged or damaged). Accordingly, one should only find the discrepancy between these conditions via various novelty detectors (Sarmadi and Karamodin 2020; Sarmadi and Yuen 2021, 2022; Daneshvar and Sarmadi 2022; Entezami et al. 2020d; Bigoni and Hesthaven 2020; Turrisi et al. 2022) or statistical distance metrics (Deza and Deza 2013; Entezami 2021; Entezami and Shariatmadar 2018; Entezami et al. 2022d, e). The main objective of these methods is to yield discriminative novelty indices or damage indicators for discriminating the possible damaged state from the undamaged one. Having considered a relatively large displacement data points, this book initially proposes a probabilistic novelty detector with the aid of the NNS, EVT, and quantile modeling. The great innovation in this methodology (NNS-EVT) is to define a new probabilistic novelty index that is a quantile value from some extreme samples. One of the great benefits of this methodology is that one can develop different novelty detectors by using various extreme value distribution models, their quantile values, and two different techniques for extreme value modeling, that is, block maxima and peak-over-threshold. This means that although the NNS-EVT presents a single algorithm for novelty detection, it is possible to use it with different extreme value distributions and frameworks. In relation to small displacement data, although the proposed hybrid learning methods in offline manners (i.e., HMC-MD, HMC-DAE-MD, HMC-UTSL-MD, and HMC-DTL-MD) utilize the tried-and-tested Mahalanobis distance metric, the online hybrid learning methods (i.e., HMC-ODTL-EMD and SLS-ODTL-EMD) propose a new novelty index. The key innovation pertains to the mechanism of deriving a univariate distance value from a multivariate distance metric.
