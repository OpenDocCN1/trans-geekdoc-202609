In the EVT, the distribution of \(M_n\) can be derived exactly for all values of \(n\) samples as follows:

```
\(\mathbb{P}r (M_n < x) = \mathbb{P}r(X_1 < x, \dots, X_n < x) = \mathbb{P}(X_1 < x) \times \cdots \times \mathbb{P}r(X_n < x) = F(x)^n \quad (2.2)\)
```

Equation (2.2) assumes that \(X_1, \dots, X_n\) are identically distributed. However, the main issue in Eq. (2.2) is that the distribution \(F\) is unknown. One of the solutions is to estimate this distribution from available sampling data. Although this solution is plausible, it may yield considerable discrepancies in \(F^n\) by occurring very small change in the estimation. Alternatively, the other solution is to assume that \(F\) is unknown and one should search to find approximate families of models for \(F^n\), which are carried out by using the only extreme values. Accordingly, it is attempted to investigate the behavior of \(F^n\) when \( n \rightarrow \infty \). However, for the smallest value, which can result in \(F(x) = 1\), the distribution of \(M_n\) degenerates to a point on that smallest value. To alleviate this limitation, it can be utilized a linear normalization of the variable \(M_n\) for the sequences of constants \(a_n > 0\) and \(b_n\) as follows:

```
\(M_n^* = \frac{M_n - b_n}{a_n} \quad (2.3)\)
```

On this basis, suitable choices for \(a_n\) and \(b_n\) can stabilize the location and scale of \(M_n^*\) when \(n\) increases thereby avoiding the difficulties that arise with the variable \(M_n\). Therefore, one should seek limit distributions for \(M_n^*\) with suitable choices of \(a_n\) and \(b_n\), instead of \(M_n\). For this goal, the entire range of possible limit distributions for \(M_n^*\) is accordance with this theorem that if there exist sequences of constants \(a_n > 0\) and \(b_n\), one can express:

```
\(\mathbb{P} \left( \frac{M_n - b_n}{a_n} < x \right) = \mathbb{P} (M_n \le a_n x + b_n) \rightarrow G(x), n \rightarrow \infty \quad (2.4)\)
```

where \(G\) is a non-degenerate distribution function. As such, the underlying goal of the EVT is to assign this distribution function to the independent random variables (i.e., extreme samples) and model them. Having considered the BM technique and random samples X1, ..., Xn, the function G can have three forms: Gumbel, Fréchet, and Weibull (Coles et al. 2001; Salvadori et al. 2007):

```
Gumbel: \( G(x) = exp\left(-exp\left(-\frac{x-\lambda}{\delta}\right)\right) -\infty < x < \infty \& \delta > 0 \) (2.5)
```

```
Fréchet \( G(x) = \begin{cases} exp\left(-\left(\frac{\delta}{x-\lambda}\right)^{\xi}\right), & \text{if } x \ge \lambda \\ 0 & \text{otherwise} \end{cases} \) (2.6)
```

```
Weibull: \( G(x) = \begin{cases} 1 & \text{if } x \ge \lambda \\ exp\left(-\left(\frac{\lambda-x}{\delta}\right)^{\xi}\right), & \text{otherwise} \end{cases} \) (2.7)
```

where \(\xi\), \(\delta\), and \(\lambda\) are the shape, scale (i.e., standard deviation), and location (i.e., mean) parameters, which are the main unknown parameters of the Gumbel, Fréchet, and Weibull distribution models. Hence, it is important to properly estimate them in order to have correct extreme value modeling. One of the important limitations in applying these functions is the necessity for selecting the most appropriate distribution model, which may arise the complexity of the process. Note that, it is possible to integrate these extreme value functions and reach a single model called generalized extreme value distribution (GEVD), which is expressed in the following equation:

```
\( G(x) = exp\left( - \left( 1 + \xi_G \left( \frac{x - \lambda_G}{\delta_G} \right) \right) ^{-\frac{1}{\xi_G}} \right) \) (2.8)
```

where \(\xi_G\), \(\delta_G\), and \(\lambda_G\) represent the shape, scale, and location associated with the generalized function. The key property of the GEVD is the capability of recognizing the type of the classical extreme value distributions. In other words, as the GEVD is an integration of the Gumbel, Fréchet, Weibull distribution functions, one can define their relationships by using the shape parameter. In this regard, if \(\xi_G < 0\), the GEVD is the Weibull-type distribution. When \(\xi_G > 0\), the GEVD is based on the Fréchet-type distribution. Finally, if \(\xi_G = 0\), it is compatible with the Gumbel-type distribution (Coles et al. 2001; Salvadori et al. 2007).

All the above-mentioned distribution functions are used to model maximum samples under the Fisher-Tippet theorem and the BM technique. The other important and widely-used extreme value function is based on the generalized Pareto distribution (GPD). Similar to the other extreme value distribution models, the GPD is often used to represent the tails of extreme samples based on a threshold-based strategy. This probability distribution resembles the GEVD in terms of a single model function. Generally, the GPD is considered to model extreme samples over a threshold under the concept of the POT technique. On this basis, once the adequate extreme samples above the threshold have been selected, the GPD model is fitted to such data points by estimating the model shape and scale parameters. Let X1, ..., Xt denote t maximum samples from n data samples above a threshold level, the GPD model is defined as follows:

\( H(y) = \left\{ \begin{array}{ll} 1 - \left(1 + \frac{\xi_p}{\delta_p}(y-u)\right)^{-\frac{1}{\xi_p}}, & \xi_p \neq 0 \\ 1 - \exp\left(-\frac{1}{\delta_p}(y-u)\right), & \xi_p = 0 \end{array} \right. \)

where \( u \) is the threshold value for distinguishing the main extreme samples from the other data points. Furthermore, \( \xi_p \) and \( \delta_p \) are the shape and scale parameters of the GPD, respectively. An important note about this probability distribution is that it is modeled by these two parameters, whereas the GEVD requires the three parameters (i.e., the shape, scale, and location). This makes sense that the extreme value modeling via the GPD needs fewer parameters than the GEVD. As the other note, similar to the GEVD, it is feasible to reach the classical extreme value distributions based on the shape parameter of the GPD. Accordingly, if \( \xi_p = 0 \), \( \xi_p > 0 \), and \( \xi_p < 0 \), the GPD is equivalent to the Gumbel, Fréchet, and Weibull models, respectively (Coles et al. 2001).

Maximum likelihood estimation (MLE) is one of the main and important techniques for estimating the parameters of the extreme value distribution models. This technique is based on defining maximum likelihood estimators and maximizing likelihood functions of the mentioned distribution models. For this purpose, logarithmic transformations of likelihood functions are often incorporated. Having considered the \( b \) maximum samples \( X_1, ..., X_b \) from \( b \) blocks, the log-likelihood function of the GEVD under \( \xi_G \neq 0 \) is written as follows (Coles et al. 2001):

\( L_G(\lambda_G, \delta_G, \xi_G) = -b \log(\delta_G) - \left(1 + \frac{1}{\xi_G}\right) \sum_{i=1}^b \log\left(1 + \xi_G \left(\frac{X_i - \lambda_G}{\delta_G}\right)\right) - \sum_{i=1}^b \left(1 + \xi_G \left(\frac{X_i - \lambda_G}{\delta_G}\right)\right)^{-\frac{1}{\xi_G}} \)

provided that

\( 1 + \xi_G \left(\frac{X_i - \lambda_G}{\delta_G}\right) > 0 \)

where \( i = 1, ..., b \). On the other hand, when \( \xi_G = 0 \), the log-likelihood function is formulated as follows (Coles et al. 2001):

\( L_G(\lambda_G, \delta_G) = -b \log(\delta_G) - \sum_{i=1}^b \log\left(\frac{X_i - \lambda_G}{\delta_G}\right) - \sum_{i=1}^b \exp\left(-\left(\frac{X_i - \lambda_G}{\delta_G}\right)\right) \)

The maximization of Eqs. (2.10) and (2.12) with respect to the parameters of the GEVD leads to the maximum likelihood estimate of the GEVD. Since there is no analytical solution, it is feasible to implement the maximization process by using standard numerical optimization algorithms (Coles et al. 2001).

The same strategy can be considered for the GPD model in order to estimate its parameters. Given the maximum samples $X_1, ..., X_t$ over the threshold $u$, the log-likelihood function of the GPD under $\xi_P \neq 0$ is defined as follows:

$$ L_P(\delta_P, \xi_P) = -t \log(\delta_P) - \left(1 + \frac{1}{\xi_P}\right) \sum_{i=1}^t \log\left(1 + \frac{\xi_P X_i}{\delta_P}\right) $$

provided that

$$ 1 + \frac{\xi_P X_i}{\delta_P} > 0 $$

where $i = 1, ..., t$. If \(\xi_P = 0\), the log-likelihood function of the GPD is rewritten in the following form:

$$ L_P(\delta_P) = -t \log(\delta_P) - \frac{1}{\delta_P} \sum_{i=1}^t X_i $$

Similar to the GEVD, the maximization of Eqs. (2.13) and (2.15) can be carried out by differentiating the log-likelihood functions with respect to the unknown GPD parameters, from which one can derive the maximum likelihood estimators by means of numerical techniques (Coles et al. 2001).

### 2.2.2 Semi-parametric Extreme Value Model

All of the above-mentioned extreme value distributions are parametric models. This means that modeling of the extreme samples depends on the unknown shape, scale, and location, which should be obtained by one of the parameter estimation techniques such as the maximum likelihood estimation. The other issue is related to the model selection. In other words, unlike the generalized distribution function, one needs to use an additional technique to choose the most appropriate function among the Weibull, Fréchet, and Gumbel distributions. To address these issues, it is possible to consider the concept of the semi-parametric EVT and its single distribution function. The great advantage of this theory and function lies in the fact that one does not require allocate a parametric model to extreme values. Moreover, no parameter estimation technique is needed. To put it another way, the semi-parametric distribution modeling depends only on some extreme samples by estimating the extreme value index (EVI) from the same samples without any parameter estimation technique (Gomes and Guillou 2015).
