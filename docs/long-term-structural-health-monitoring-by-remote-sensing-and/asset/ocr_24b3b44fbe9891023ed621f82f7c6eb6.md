More specifically, the proposed ODTL method begins by applying the first dataset of the augmented displacement samples of the first image. The main objective is to train a consecutive three-hidden-layer DAE and obtain the final residual matrix. This step resembles the original DTL algorithm. Because there is only one set of augmented data points in the first step, those serve as both the training and validation data. Using the MD-based novelty detector, the distance values of these datasets are computed. It is natural that both sets provide the same distance values. The MD quantities of the training set are subsequently applied to estimate a threshold, which is set as a measure for the stopping condition. Here, the threshold is obtained by using the standard confidence interval of the damage indicators of the training points under 5% significance level. Accordingly, the rate of false positive in the validation data is computed. Note that any new data received by the first stage should be considered as validation data. Indeed, one assumes that augmented validation data (new information) comes from the healthy condition of the structure. Therefore, their novelty indices should fall below the threshold.
