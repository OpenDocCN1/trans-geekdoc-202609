The encoding and decoding procedures are implemented on all augmented training and test data points to reconstruct them. For the process of data normalization in the HMC-DAE-MD method, the undercomplete DAE with the three hidden layers is considered as shown in Fig. 2.6a. Moreover, the logistic sigmoid functions are considered for the encoding and decoding activations. Suppose that X = [x₁ ... xₙ] is the training matrix entailing the augmented displacements regarding the undamaged structural state. Each of the training data points is fed to the DAE to reconstruct it and provide the reconstructed training matrix X̂ = [x̂₁ ... x̂ₙ]. In other words, the DAE learned from the training data X serves as a data normalization model and the reconstructed training data X̂ is the model output. Therefore, the data normalization is carried out by extracting the residual between the input (X) and output (X̂) in the following form:

$$ \mathbf{E}_x = |\mathbf{X} - \hat{\mathbf{X}}| $$ (2.31)

The same strategy can be performed by applying the expanded displacement data points in the test matrix Z = [z₁ ... zₘ]. Note that this matrix contains the validation data samples, which are the known augmented displacements, and actual unknown test samples associated with the unknown/current condition of the structure. To obtain the test residual data samples, the learned DAE from the training data is used here to predict the network output Ẑ = [ẑ₁ ... ẑₘ]. As such, the new residual matrix can be expressed as follows:

$$ \mathbf{E}_z = |\mathbf{Z} - \hat{\mathbf{Z}}| $$ (2.32)

# 2.3.2.2 Hyperparameter Optimization in DAE

In machine learning, the unknown elements of a machine or model that control how it learns from data are called hyperparameters (Yang and Shami 2020; Sarmadi 2021). These elements should be optimized or selected so that the model of interest can minimize modeling or learning errors and increase generality. Because hyperparameters significantly influence overall performances of machine learning models, it is indispensably to choose them before the learning process. On the other hand, there are other kinds of unknown elements in machine learning called model-parameters. In contrast to hyperparameters, model-parameters can be estimated during the learning process, in which case it is not necessary to elaborately select them prior to learning.
