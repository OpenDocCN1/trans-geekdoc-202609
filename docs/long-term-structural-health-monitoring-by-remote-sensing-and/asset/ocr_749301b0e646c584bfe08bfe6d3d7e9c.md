On this basis, the residual set of the last DAE (E_x) is extracted as the final output associated with the undamaged state for feature discrimination. For the real augmented test data Z, the seven trained DAEs are re-used consecutively in order to extract their residual samples (E_z1, ..., E_z6). Finally, the residual set of the seventh (last) DAE (E_z7) is extracted as the final output concerning the monitoring (testing) phase for feature discrimination. In other words, the residual matrices E_x7 and E_z7 are inserted into the MD-based novelty detector to determine the novelty indices of the training and test data points.
