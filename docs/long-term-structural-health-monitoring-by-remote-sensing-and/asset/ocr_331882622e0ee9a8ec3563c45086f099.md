In the second step, these distances are arranged in ascending order to obtain the sorted values \( \tilde{d}_1 < \cdots < \tilde{d}_{n-1} \), where \( \tilde{d}_1 \) refers to the maximum distance value between \( \mathbf{x}_i \) and one of the feature points in \( \mathbf{X} \).

Similarly, \( \tilde{d}_{n-1} \) is the minimum distance value between \( \mathbf{x}_i \) and one of the feature samples. Under the concept of NNS, the \( k \) smallest distance values (SDVs) are selected. These selected distances are equivalent to the representative features. In other words, one attempts to remove large distance values that belong to the features sensitive to variability or outliers. Hence, the third step serves as a feature selection approach. Because Eq. (2.16) is valid for the maximum samples, the signs of the \( k \) SDVs should be changed to provide the \( k \) negative maximum distances for the semi-parametric extreme value modeling. Using the moment estimator, the EVI is estimated via Eq. (2.18). Finally, the quantile of the negative \( k \)-SDVs is computed to use as a novelty index of \( \mathbf{x}_i \). In order to avoid obtaining meaningless indices, the absolute value of the estimated quantile is considered as the final novelty index. Having considered all feature samples \( \mathbf{x}_1,...,\mathbf{x}_n \), one can obtain \( n \) absolute values of the quantiles \( |q_{x_1}|,...,|q_{x_n}| \). Finally, these quantile values are considered to estimate a threshold for SHM and early warning alarm. Moreover, note that the negative arranged distances \( \tilde{d}_1 < \cdots < \tilde{d}_k \) are equivalent to the order statistics \( X_{1:n} < \cdots < X_{1:n} \) or \( -\tilde{d}_1 > \cdots > -\tilde{d}_k \) equivalent to \( -X_{1:n} > \cdots > -X_{k-1:n} \).
