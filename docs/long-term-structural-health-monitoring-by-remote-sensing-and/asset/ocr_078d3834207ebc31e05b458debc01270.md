Even though Figueiredo et al. (2011) achieved to obtain reliable outputs of data normalization through this neural network in their problem, Sarmadi et al. (2021a) indicated that this network may not be reliable for any engineering issue with various EOCs. To address this drawback, this study proposes a consecutive three-hidden-layer DAE based on the concept of transfer learning. Unlike some well-known deep transfer learning techniques, the proposed method does not make a single ANN. In contrast, a sequence of three-hidden-layer DAEs is developed to generate a new deep neural network (DNN). Moreover, the proposed neural network differs from some well-known stacked DNNs (e.g. stacked autoencoders). This is because the proposed DNN does not implement any stacking process. By contrast, the main idea is to compute the direct difference between the input and output fed into any DAE and use this difference (residual) as a new input to the next network.

Figure 2.11 indicates the graphical representation of the proposed DNN under transfer learning. As can be seen in this figure, the consecutive ANN learning process is an iterative algorithm of k iterations or steps. For the first iteration, the input is the expanded training data X, which is fed into the first DAE. The main objective is to extract the residual matrix of the input and output. On this basis, the extracted residual data is set as a new input (i.e., Input 2) in the second iteration and this input is applied to the next (second) DAE. This process continues until the last (k) iteration. Hence, the final residual extraction is performed to determine the last or kth residual set, which serves as the final normalized expanded feature matrix (Ex) of the undamaged state. This set is then used to compute its novelty scores for decision-making. It should be mentioned that the iterative procedure illustrated in Fig. 2.11 should be implemented by using both the augmented training and test data sets. Nonetheless, the learning process is only performed via the training set. This means that the trained neural networks (i.e., along with their estimated weights and biases) are only employed to obtain the residuals of the augmented test data.
