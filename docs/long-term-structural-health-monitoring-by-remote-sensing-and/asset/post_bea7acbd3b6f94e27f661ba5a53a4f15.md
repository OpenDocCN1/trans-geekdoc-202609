
## 2.4 The Frontier of Real-Time SHM: Proposed Online Hybrid Learning Methods

All the previously proposed methods are based on consideration of adequate training samples. In the SAR-aided SHM problems, since it is possible to access prior information (images) of a civil structure in a certain interval of time, the learning process of the previously proposed techniques are reasonable and reliable. This kind of SHM in machine learning perspective is called offline learning. It should be clarified that this approach is also valid for other kinds of SHM methods.

This section intends to suggest a new methodology under the idea of online learning for real-time SHM. In machine learning, online learning sets out to update a machine or computational model by new data. On this basis, the machine or model of interest can be developed by the previous information, in which case online learning improves it by receiving new training data. In some cases, an online learning strategy is considered to the initial step of a machine. For the applications of SHM, if the new information belongs to an undamaged structural state, the online learning process should be continued; otherwise, it should be stopped and the further investigation is based on the last updated model. In this regard, any new information is treated as test data.

In this section, one attempts to propose two online learning methods in hybrid fashions. In other works, these methods (i.e., HMC-ODTL-EMD and SLS-ODTL-EMD) entail three parts of data augmentation, online data normalization, and feature discrimination. The first step of the proposed hybrid methods is concerned with the data augmentation. Hence, both the HMC and SLS techniques are considered to augment the small displacement data. Therefore, the major differences of these methods against the other proposed techniques are related to the process of online data normalization conducted by an ODTL algorithm and feature discrimination by EMD.

### 2.4.1 Online Deep Transfer Learning Paradigm

One of the main prerequisites of the DAE in the DTL framework is to use adequate (augmented) data. In other words, it is based on an offline learning strategy. In this section, the enhanced version of DTL under the idea of online learning is proposed and discussed. The proposed ODTL algorithm consists of two stages. The first stage is an online learning algorithm till the stopping condition terminates this algorithm. Accordingly, this stage declares that the new data utilized in the learning procedure does not belong to the undamaged structural state and it is probably associated with a damaged condition. To put it another way, the algorithm alarms the occurrence of an abnormal change. Hence, the second stage starts calling the last trained DAE from the first stage. More specifically, the proposed ODTL method begins by applying the first dataset of the augmented displacement samples of the first image. The main objective is to train a consecutive three-hidden-layer DAE and obtain the final residual matrix. This step resembles the original DTL algorithm. Because there is only one set of augmented data points in the first step, those serve as both the training and validation data. Using the MD-based novelty detector, the distance values of these datasets are computed. It is natural that both sets provide the same distance values. The MD quantities of the training set are subsequently applied to estimate a threshold, which is set as a measure for the stopping condition. Here, the threshold is obtained by using the standard confidence interval of the damage indicators of the training points under 5% significance level. Accordingly, the rate of false positive in the validation data is computed. Note that any new data received by the first stage should be considered as validation data. Indeed, one assumes that augmented validation data (new information) comes from the healthy condition of the structure. Therefore, their novelty indices should fall below the threshold.

If the false positive error is zero or inconsiderable or its rate is less than a pre-defined value (\(\beta\)), this means that the validation set is concerned with the healthy state. In this case, this type of data should be added to the previous training data in an effort to update the previous DAE. In contrast, if the false positive error is substantial or its rate is larger than \(\beta\), the online learning process is terminated and the new data should be transformed into the next stage to use as the test data. In this case, this kind of data contains damaged information of the structure. For simplicity, the procedure of the ODTL algorithm can be summarized as:

- (1) If the false positive error is smaller than \(\beta\), this means that the premise about the validation data and the healthy state of the structure is correct. Hence, the online learning (the first stage of the ODTL) should be kept on. In addition, the Euclidean norm of the MD values of the validation data is computed to obtain a result at each online step for real-time SHM (see Sect. 2.4.2).

- (2) If the false positive error is greater than \(\beta\), this means that the premise about the validation data and the healthy state of the structure is incorrect. Accordingly, it needs to stop the online learning and begin the second stage of the ODTL concerning online damage detection. In this regard, the augmented validation data is treated as test data. Accordingly, the last updated DAE from the first stage is called to extract the new residual matrix and compute a new novelty index by the EMD. This process continues for any new data.

### 2.4.2 Feature Discrimination for Real-Time SHM

The final step for real-time SHM is feature discrimination by a different novelty detector compared with the previously proposed techniques. Apart from this issue, the other difference relates to how to perform the process of feature discrimination. In the previously proposed techniques, one needs to calculate the novelty indices of all training and test points via the MD-based novelty detector and compare them with a threshold. In a different manner, the proposed online hybrid learning methods exploit the threshold within their algorithms; that is, online learning and online damage detection. Moreover, the shift from the first stage to the second one infers the existence of an abnormal change in the structure. Eventually, both stages give scalar novelty indices by computing the Euclidean norm of the MD amounts of the residual data points in an online way.

Let \(\mathbf{E} = [\mathbf{e}_1, \dots, \mathbf{e}_n] \in \mathbb{R}^{p \times n}\) denotes the matrix of \(n\) residual data points gained by the ODTL algorithm from one structural state (i.e., one image from satellite). To determine a scalar novelty index, it suffices to estimate the mean vector and covariance matrix of \(\mathbf{E}\), which are defined here as \(\mathbf{b_e} \in \mathbb{R}^p\) and \(\mathbf{C_e} \in \mathbb{R}^{p \times p}\), respectively. The MD quantity of each column vector of \(\mathbf{E}\) is obtained as:

\(d_{MD}(\mathbf{e}_i) = (\mathbf{e}_i - \mathbf{b_e})^T \mathbf{C_e}^{-1} (\mathbf{e}_i - \mathbf{b_e}), \quad \forall i = 1, \dots, n \quad (2.42)\)

Accordingly, it can be gained \(n\) MD values \(\{d_{MD}(\mathbf{e}_1), \dots d_{MD}(\mathbf{e}_n)\}\). Applying the Euclidean norm, it can be written:

\( d_E = \sqrt{(d_{MD}(\mathbf{e}_1))^2 + \dots + (d_{MD}(\mathbf{e}_n))^2} \quad (2.43) \)

Hence, \( d_E \) is the only scalar novelty index for representing the status of the structure in both stages of online learning and online damage detection. This means that any \( d_E \) value in the first stage declares the undamaged state of the structure and any \( d_E \) value in the second stage triggers that the structure is damaged. This kind of feature discrimination in the proposed online hybrid techniques is the major improvement against the previously proposed techniques.

## 2.5 Chapter Summary

This chapter has fully discussed the main proposed methods in this book for the enhanced SAR-aided SHM. These methods have consisted of two categories of relatively large displacement data and small displacement data. For the first category, this work has proposed a new probabilistic machine learning method on the basis of the concepts of NNS and EVT. At first, the fundamental principles and theoretical basis of the EVT and all possible extreme value distribution models have been described in detail. Subsequently, a new algorithm for the NNS-EVT method based on the semi-parametric quantile modeling has been developed to establish a probabilistic novelty detector for SHM. For the second category, the proposed hybrid learning methods in offline and online manners have been discussed elaborately.

In this chapter, it can be deduced that the proposed NNS-EVT method has good diversity for developing many novelty detectors for SHM. Although, this book has considered one type of novelty detector based on the semi-parametric extreme value distribution model and its quantile function for novelty index definition, it is possible to exploit the other (parametric) extreme value distributions such as the GEVD based on the BM technique and the GPD based on the POT technique for designing new novelty detectors. This means that the proposed NNS-EVT method develops a general methodology by high diversity of applicability with other models (i.e., GEVD and GPD) and techniques (i.e., BM and POT).

In relation to the hybrid learning methods, it can be concluded that the unsupervised DAE is a powerful and effective approach to designing various data normalization approaches. With the aids of advanced machine learning algorithms such as teacher-student learning, transfer learning, online learning, one can design different configurations of the DAEs for data normalization. Moreover, the random data generation based on Markov Chain Monte Carlo algorithms can provide non-parametric strategies for data augmentation. Finally, when the challenge of the EOCs is solvable, non-parametric novelty detectors based on the statistical distance metrics, especially Mahalanobis distance, can be the first choice.
