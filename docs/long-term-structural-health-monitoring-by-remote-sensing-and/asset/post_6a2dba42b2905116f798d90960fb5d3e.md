
## 2.3.3 Data Normalization by Unsupervised Teacher-Student Learning

Similar to the previous technique HMC-DAE-MD, the proposed HMC-UTSL-MD method consists of three parts of data augmentation by HMC sampling, data normalization by a new approach, and MD-based feature discrimination. Since the first and third parts have been explained, in this section, the main focus is on the proposed unsupervised teacher-student learning (UTSL) method for data normalization. The crux of this method originates from the concept of the teacher-student learning that develops a two-stage learning framework by a complex model (teacher) and a simple model (student). The teacher is often a complicated and rigorous method, which makes attempt to provide the best representation learning for measured data, while the student utilizes the outputs from the teacher in order to facilitate the learning process or continue the other tasks without applying a complex model (Mirzaei et al. 2020). Depending on the presence of supervision information, any teacher-student learning can be categorized as supervised and unsupervised classes. Similar to the other types of learning algorithms, a supervised teacher-student learning technique is comprised of supervised machines by using fully labeled training data, while an unsupervised teacher-student learning method consists of unsupervised machines by utilizing the only unlabeled data.

The proposed data normalization method in this section is based on an unsupervised teacher-student learning framework. This method exploits different AEs for developing the teacher and student models. In the first step, an undercomplete DAE with seven hidden layers (L = 3) is considered to train a complex teacher model. Figure 2.8a shows this ANN and its configuration. In this regard, it needs to train this deep ANN by using the augmented training data (X) and then reconstruct it (X̂) at the model output layer. The main output of teacher learning is the residual matrix (Eₓ) between the input and output. Subsequently, this matrix serves as a new input to the student model. Hence, in the second step, an overcomplete shallow AE is designed to undertake the student learning. Figure 2.8b shows the student model and its configuration. Accordingly, the residual matrix of the teacher model (Eₓ) is fed into the input layer of the shallow AE to reconstruct it (Eₓ̄). In the following, a new residual extraction process is carried out to obtain a new residual matrix Eₓ̅ = |Eₓ − Eₓ̄| from the student model. For simplicity, Fig. 2.9 depicts the graphical flowchart of the proposed UTSL method.

Although the aforementioned strategies are related to the augmented training data, it is essential to run them for the augmented test data (Z). The main difference is that the trained teacher and student models should only be used to determine the residual matrices of the test data. This means that no learning process is required in the testing phase. In this case, the expanded test data is fed into the trained undercomplete DAE in an effort to reconstruct it (Ẑ) and determine the teacher residual matrix (E_z). This matrix is then applied to the trained overcomplete shallow AE in order to reconstruct it (E_z̄) once again. Finally, the student residual matrix E_z̅ = |E_z − E_z̄| is extracted as the output of the UTSL algorithm in the testing/monitoring phase. After extracting the student residual matrices from the augmented training and test sets, these are incorporated into the MD-based novelty detector for feature discrimination (see Sect. 2.3.5).

### 2.3.3.1 Hyperparameter Optimization of UTSL

The proposed UTSL methods consists of two AE networks with different configurations. In these neural networks, the only hyperparameters are the neurons of the seven hidden layers of the undercomplete DAE and the single encoding layer of the overcomplete shallow AE. Recently, Entezami et al. (2020) proposed an effective algorithm based on a controlled grid search for finding the neuron numbers of an AE based on the reconstruction error of the network training and the final prediction error (FPE) function. Inspired by that technique, this research takes advantage of the Akaike information criterion (AIC) for hyperparameter optimization of the teacher and student models. In this regard, Table 2.1 lists the sample neuron numbers for the hidden layers of the undercomplete DAE.

Using these sample neurons, it only suffices to design ten different undercomplete DAEs and implement the first step of the proposed UTSL algorithm regarding the teacher model learning and calculate the sum of residual data points. Assume that \(N_{H_i}\) is the number of neurons of the \(i\)th hidden layer, where \(i = 1, ..., 7\). On this basis, the AIC metric is written in the following equation:

\(AIC = \ln(\varepsilon) + \frac{2N_v}{pn}\) (2.35)

In this equation, the scalar values \( e_{xj} \) and \( \overline{e}_{xj} \) are the \( j \)th row data points of the residual matrices \(\mathbf{E_x}\) and \(\overline{\mathbf{E_x}}\), respectively. Having considered all trials of the neurons of the hidden layers, one can obtain ten values of AIC. The best collection of the sample neurons is one that leads to the smallest AIC amount.

After selecting the optimum neuron collection, the remaining hyperparameter is the neuron number of the encoding layer of the shallow AE in the student learning. In this case, it should be mentioned that the choice of a small neuron number may not affect positively the learning process. For this issue, the lower bound of the neuron size should be greater than \( p \) to allow us to design an overcomplete shallow AE. On the other hand, a very large neuron number arises the risk of an overfitting problem. Hence, the sum of the optimum neuron collection concerning the undercomplete DAE in the teacher learning is set as the optimum value for the neuron size of the shallow AE; that is, \( N_S = \sum_{i=1}^7 N_{H_i} \).

## 2.3.4 Data Normalization by Deep Transfer Learning

One of the major challenges in parametric machine learning methods is their hyperparameter selections. On this basis, the learning and/or decision-making procedures may be time-consuming and complex. In order to develop an efficient and effective SAR-aided SHM strategy, this section proposes a new deep transfer learning (DTL) method under consecutive DAEs. In machine learning perspective, transfer learning is an improvement of a learning process in a new task via the transfer of knowledge from a related task that has been learned previously (Yang et al. 2020). In other words, in the new domain, it is not necessary to implement the same steps of the source domain or estimate new parameters. Instead, one can apply all or part of the information of the source domain in the new domain. A well-known example is the application of some popular deep neural networks with high general performances to other engineering fields (Gao and Mosalam 2018; Azimi and Pekcan 2020).

Having considered this concept in machine learning, the fundamental principle of data normalization in HMC-DTL-MD is to exploit the concept of transfer learning and ignore a rigorous hyperparameter optimization for obtaining the neurons of the hidden layers. The key idea of the proposed DTL is that an undercomplete three-hidden-layer DAE (L = 1), see Fig. 2.6a, with pre-determined neurons for the mapping, encoding, and de-mapping layers suffices to eliminate the EOC effects without any hyperparameter optimization. In other words, the main intention of proposing the DTL is to ignore determining the neurons of the DAE hidden layers.
