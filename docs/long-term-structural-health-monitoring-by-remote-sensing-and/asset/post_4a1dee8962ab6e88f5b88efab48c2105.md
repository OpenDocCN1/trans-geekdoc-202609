The encoding and decoding procedures are implemented on all augmented training and test data points to reconstruct them. For the process of data normalization in the HMC-DAE-MD method, the undercomplete DAE with the three hidden layers is considered as shown in Fig. 2.6a. Moreover, the logistic sigmoid functions are considered for the encoding and decoding activations. Suppose that X = [x₁ ... xₙ] is the training matrix entailing the augmented displacements regarding the undamaged structural state. Each of the training data points is fed to the DAE to reconstruct it and provide the reconstructed training matrix X̂ = [x̂₁ ... x̂ₙ]. In other words, the DAE learned from the training data X serves as a data normalization model and the reconstructed training data X̂ is the model output. Therefore, the data normalization is carried out by extracting the residual between the input (X) and output (X̂) in the following form:

$$ \mathbf{E}_x = |\mathbf{X} - \hat{\mathbf{X}}| $$ (2.31)

The same strategy can be performed by applying the expanded displacement data points in the test matrix Z = [z₁ ... zₘ]. Note that this matrix contains the validation data samples, which are the known augmented displacements, and actual unknown test samples associated with the unknown/current condition of the structure. To obtain the test residual data samples, the learned DAE from the training data is used here to predict the network output Ẑ = [ẑ₁ ... ẑₘ]. As such, the new residual matrix can be expressed as follows:

$$ \mathbf{E}_z = |\mathbf{Z} - \hat{\mathbf{Z}}| $$ (2.32)

### 2.3.2.2 Hyperparameter Optimization in DAE

In machine learning, the unknown elements of a machine or model that control how it learns from data are called hyperparameters (Yang and Shami 2020; Sarmadi 2021). These elements should be optimized or selected so that the model of interest can minimize modeling or learning errors and increase generality. Because hyperparameters significantly influence overall performances of machine learning models, it is indispensably to choose them before the learning process. On the other hand, there are other kinds of unknown elements in machine learning called model-parameters. In contrast to hyperparameters, model-parameters can be estimated during the learning process, in which case it is not necessary to elaborately select them prior to learning.

![](img/3d323f4db48c9242205a3db747902f6d_64_0.png)

Fig. 2.7 The graphical representation of the unsupervised data normalization by ANN

For instance, the numbers of hidden layers and their neurons are the key hyperparameters of an ANN, while the weight matrices and bias vectors of these layers are its model-parameters (Sarmadi 2021).

In the proposed HMC-DAE-MD method, the process of data normalization is carried out by an undercomplete DAE with three hidden layers, as shown in Fig. 2.6a, in which case the number of hidden layers is known. This means that the neurons of the mapping, encoding, and de-mapping layers are the main hyperparameters of this ANN. Typically, the error reconstruction based on the mean-square-error (MSE) is the major criterion for this hyperparameter optimization. As the undercomplete DAE is suggested to mitigate the negative effects of the EOCs, this research proposes a simple but effective grid search approach to optimize the neurons of the DAE hidden layers. The underlying reason for suggesting this grid search approach is the strong influence of EOCs on SHM results. Therefore, the proposed hyperparameter optimization of the DAE is developed so that this ANN can significantly alleviate the EOC effects.

The major rationale behind the grid search approach is to examine a relatively large trials for the main hyperparameters and evaluate the feedback of the SHM method (i.e., the proposed HMC-DAE-MD) in terms of the effects of the EOCs on the method outputs by using the only training data. In other words, after using the sample hyperparameters, the method yields novelty indices (distances) for each trial. On this basis, one can measure the variance of novelty indices. The optimal hyperparameter is one that gives the minimum rate of variance. The main idea of this criterion comes from this fact that a robust SHM method under unknown EOCs in the training phase should yield smooth outputs (novelty indices) with a low variance amount (Sarmadi and Yuen 2021).

Algorithm 1 presents the main steps and the pseudo-code of the proposed grid search technique for hyperparameter optimization of the undercomplete DAE. The inputs of this algorithm include the training data (X), trials for sample neurons of mapping (N<sub>m0</sub>), encoding (N<sub>e0</sub>), and de-mapping (N<sub>d0</sub>) layers. As the DAE has an undercomplete configuration, N<sub>m0</sub> > N<sub>e0</sub> and N<sub>d0</sub> > N<sub>e0</sub>. On the other hand, the DAE of interest has a symmetric form, in which case N<sub>m0</sub> = N<sub>d0</sub>. The main contents of Steps 1–3 of Algorithm 1 have been described in Sect. 2.3.2.2. Regarding Step 4, the residual matrix E<sub>x</sub> is applied to the MD-based novelty detector to determine the distance values of all samples of this matrix. More details of this procedure are available in Sect. 2.3.5. In Step 9, it is necessary to check the overfitting problem in learning the DAE. For this problem, the final choice of the neuron numbers should satisfy the following conditions:

\( N_e < 2N_m < \frac{p(n - N_e)}{p + N_e + 1} \) (2.33)

\( (N_m + N_d) < n \) (2.34)
