To sample from the marginal density for x (i.e., p(x)), it needs to sample from p(x, y) and then ignore the y values. Since the generation of random samples from p(x, y) is not tractable, it is necessary to define a Markov chain to enable us to converge to that distribution. Given the current sample x, one should generate y from the conditional distribution of y given x, in which case one can sample the new x from the slice S = {x: y < f(x)}. Because the sample generation from the slice S is difficult due to the lack of exact information and form of S, one can exploit the algorithm proposed by Neal (2003), which updates x through a process that leaves the uniform distribution of S invariant. Given the current state x0, the next one is generated in the following steps:

+   (1) Draw y0 uniformly from (0, f(x0)) and define the horizontal slice S = {x: y0 < f(x)}.
+   (2) Find an interval that consists of all or much of S using the stepping-out procedure described in Neal (2003).
+   (3) Generate and draw a new sample within the interval of Step 2.
+   (4) Update the step i to i + 1 and repeat the previous steps to terminate the process by a desired number of samples.

# 2.3.2 Data Normalization by Deep Auto-encoder

In the proposed HMC-DAE-MD method, a data normalization strategy based on the DAE is added to the previously proposed HMC-MD method to enhance its performance in reducing the EOC effects. Data normalization in SHM is a technique for eliminating the level of changes in data caused by any kind of non-damage conditions; that is, environmental and operational, and sometimes noisy conditions. In most cases, one attempts to construct a computational/statistical model by using training data, which serves as an input applied to that model, and then predict it as the model output. On this basis, data normalization intends to perform a residual extraction process by computing the direct difference between the input and output.
