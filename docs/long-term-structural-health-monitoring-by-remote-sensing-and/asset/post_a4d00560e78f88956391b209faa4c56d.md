
\( F(x) = \left\{ \begin{array}{ll} \exp\left(-(1+\xi x)^{-\frac{1}{\xi}}\right), & \text{if } \xi \neq 0 \\ \exp(-\exp(-x)) & \text{if } \xi = 0 \end{array} \right. \quad (2.16) \)

where \(\xi\) denotes the so-called EVI, which is the primary parameter in the semi-parametric modeling of the extreme value samples. When \(\xi \neq 0\), one can derive the semi-parametric Weibull (\(\xi < 0\)) and Frechet (\(\xi > 0\)) models. Moreover, the second (bottom) expression in Eq. (2.16) regarding \(\xi = 0\) refers to the semi-parametric Gumbel distribution. Therefore, the most effort is to estimate the EVI parameter by some estimators. The most famous estimator for \(\xi > 0\) is the Hill estimator. Given the order statistics of \(X_1, \dots, X_n\), that is, \(X_{n:n} > \dots > X_{1:n}\), the Hill estimator is expressed as follows (Hill 1975):

\(\hat{\xi}_H = \frac{1}{k} \sum_{i=1}^k (\log X_{n-i+1:n} - \log X_{n-k:n}) \quad (2.17)\)

where \(k\) is a number (sample fraction) that separates the extreme values from the other ones for the semi-parametric extreme value modeling. The major limitation of the Hill estimator is its only applicability to the positive EVI. Since this condition limits this estimator for general cases of \(\xi\), some generalized EVI estimators were proposed to address this problem. One of them is the moment estimator proposed by Dekkers et al. (Dekkers and De Haan 1989), which is expressed as follows:

\(\hat{\xi}_M = \hat{\xi}_H - \frac{1}{2} \left( 1 - \frac{\left(M_{k,n}^{(1)}\right)^2}{M_{k,n}^{(2)}} \right)^{-1} + 1 \quad (2.18)\)

so that

\(M_{k,n}^{(j)} = \frac{1}{k} \sum_{i=1}^k (\log X_{n-i+1:n} - \log X_{n-k:n})^j \quad (2.19)\)

where \(j=1,2\). The great merit of the moment estimator is its suitability for all cases of the EVI; that is, \(\xi \in \mathbb{R}\). In other words, depending upon the number of data points selected as the extreme samples, one can obtain negative or positive EVIs. This is opposite to the classical Hill estimator, which only gives the positive EVI for each case of the sample selection.

## 2.2.3 Quantile Modeling

The main objective of this section is to define an index for the unsupervised novelty detector in the proposed NNS-EVT method. This novelty index can provide a criterion for discriminating an abnormal (damaged) condition from a normal (undamaged) one. For this reason, the quantile of selected extreme values is defined as a novelty score or damage indicator for SHM. In statistics and probability theory, the inverse of the CDF is defined as the quantile of sampling data (i.e., extreme value data) under a significance level. A quantile for a random variable is a value exceeded with a specific probability, so-called significance level. In terms of the EVT, quantile modeling refers to the estimate of a quantile of extreme samples that quantifies the risk in tail distributions. When this process relies on a very small probability (i.e., the case occurred in the EVT), the purpose of modeling is to estimate a high quantile. Having considered \(k\) extreme samples \(X_{n:n} > \dots > X_{n-k:n}\) from the order statistics \(X_{n:n} > \dots > X_{1:n}\), a significance level \(\alpha\), and the estimated EVI from the selected samples, the quantile of these samples is expressed as follows:

\[ q = X_{n-k:n} \left( \frac{k}{n\alpha} \right)^{\hat{\xi}} \tag{2.20} \]

On this basis, the quantile value \(q\) is defined as a score or index for novelty detection.

## 2.2.4 Probabilistic Novelty Index

The proposed NNS-EVT method exploits the capacities of the EVT, semi-parametric extreme value distribution, and quantile modeling for developing a probabilistic machine learning framework in the view of unsupervised learning. This method is performed in the baseline/training and monitoring/inspection stages. The main objectives in these stages include calculating distance values between each displacement points with the other ones, finding nearest neighbors of each displacement sample, selecting the k-smallest distance values, estimating the EVI of the negative k-smallest distance values, and computing their quantile.

### Baseline phase

Assume that \(X = [x_1, \dots, x_n] \in \mathbb{R}^{p \times n}\) stands for the set (matrix) of the feature/training data points (i.e., displacements, modal data, etc.) regarding the baseline phase, where the structure is undamaged. Based on the SAR-aided SHM, it is considered that the displacement matrix is obtained from extracting the displacement points from \(p\) target points on the structure from \(n\) SAR images. By selecting \(p\) target points on the structure, the displacement values at these points for each of the \(n\) SAR images are extracted by one of the interferometric techniques. For the other kinds of SHM, the variable \(p\) can be one of the feature types (e.g., the number of modes). On this basis, the proposed method consists of six main steps including distance calculation, distance arrangement for obtaining order statistics, sample fraction selection (\(k\)), sign alteration for providing negative maximum values, the EVI estimation, and quantile modeling based on the previous sections. For simplicity, Fig. 2.2 depicts the flowchart of the main steps of the proposed method.

In the first step, one needs to calculate the distance between each feature sample with the other ones. For this reason, the well-known Euclidean distance is applied to perform this process. For two vectors \(\mathbf{x}_i\) and \(\mathbf{x}_j\), Eq. (2.21) represents the function of this distance:

\[ d_E(\mathbf{x}_i, \mathbf{x}_j) = (\mathbf{x}_i - \mathbf{x}_j)^T (\mathbf{x}_i - \mathbf{x}_j) \]

where \(j = 1, \dots, n-1\) and \(i \neq j\). Because it is ignored to compute the distance of each point with itself, there are \(n-1\) distance values for each feature sample.

- Step 1: Calculate the distance between \(\mathbf{x}_i\) and the remaining feature/training samples \(\mathbf{x}_1, \dots, \mathbf{x}_{i-1}, \mathbf{x}_{i+1}, \dots, \mathbf{x}_n\)
- Step 2: Arrange the distance values in ascending order
- Step 3: Find the \(k\)-smallest distance values (SDVs)
- Step 4: Change the signs of the selected distance values
- Step 5: Estimate the EVI of the negated \(k\)-SDVs
- Step 6: Compute the absolute value of the \(i^{\text{th}}\) quantile of the negated \(k\)-SDVs

In the second step, these distances are arranged in ascending order to obtain the sorted values \(\tilde{d}_1 < \cdots < \tilde{d}_{n-1}\), where \(\tilde{d}_1\) refers to the maximum distance value between \(\mathbf{x}_i\) and one of the feature points in \(\mathbf{X}\).

Similarly, \(\tilde{d}_{n-1}\) is the minimum distance value between \(\mathbf{x}_i\) and one of the feature samples. Under the concept of NNS, the \(k\) smallest distance values (SDVs) are selected. These selected distances are equivalent to the representative features. In other words, one attempts to remove large distance values that belong to the features sensitive to variability or outliers. Hence, the third step serves as a feature selection approach. Because Eq. (2.16) is valid for the maximum samples, the signs of the \(k\) SDVs should be changed to provide the \(k\) negative maximum distances for the semi-parametric extreme value modeling. Using the moment estimator, the EVI is estimated via Eq. (2.18). Finally, the quantile of the negative \(k\)-SDVs is computed to use as a novelty index of \(\mathbf{x}_i\). In order to avoid obtaining meaningless indices, the absolute value of the estimated quantile is considered as the final novelty index. Having considered all feature samples \(\mathbf{x}_1, \dots, \mathbf{x}_n\), one can obtain \(n\) absolute values of the quantiles \(|q_{x_1}|, \dots, |q_{x_n}|\). Finally, these quantile values are considered to estimate a threshold for SHM and early warning alarm. Moreover, note that the negative arranged distances \(\tilde{d}_1 < \cdots < \tilde{d}_k\) are equivalent to the order statistics \(X_{1:n} < \cdots < X_{1:n}\) or \(-\tilde{d}_1 > \cdots > -\tilde{d}_k\) equivalent to \(-X_{1:n} > \cdots > -X_{k-1:n}\).

Instead of considering all test displacement points, it is assumed that each of them is available at one time to provide realistic conditions of SHM. For example, in the problem of the SAR-aided SHM, this means that one SAR image or measurement regarding a specific inspection time is needed initially. Having considered the previous \(p\) target points on the structure or feature types selected in the baseline phase, one can obtain the feature sample \(\mathbf{z} \in \mathbb{R}^p\). Note that this process should be repeated \(m\) times.
