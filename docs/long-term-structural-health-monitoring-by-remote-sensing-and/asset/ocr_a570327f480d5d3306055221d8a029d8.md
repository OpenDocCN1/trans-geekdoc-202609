# 2.2.3 Quantile Modeling

The main objective of this section is to define an index for the unsupervised novelty detector in the proposed NNS-EVT method. This novelty index can provide a criterion for discriminating an abnormal (damaged) condition from a normal (undamaged) one. For this reason, the quantile of selected extreme values is defined as a novelty score or damage indicator for SHM. In statistics and probability theory, the inverse of the CDF is defined as the quantile of sampling data (i.e., extreme value data) under a significance level. A quantile for a random variable is a value exceeded with a specific probability, so-called significance level. In terms of the EVT, quantile modeling refers to the estimate of a quantile of extreme samples that quantifies the risk in tail distributions. When this process relies on a very small probability (i.e., the case occurred in the EVT), the purpose of modeling is to estimate a high quantile. Having considered k extreme samples X_{n:n} > ... > X_{n-k:n} from the order statistics X_{n:n} > ... > X_{1:n}, a significance level α, and the estimated EVI from the selected samples, the quantile of these samples is expressed as follows:

```
q = X_{n-k:n} \left( \frac{k}{n\alpha} \right)^{\hat{\xi}} (2.20)
```

On this basis, the quantile value qq is defined as a score or index for novelty detection.

# 2.2.4 Probabilistic Novelty Index

The proposed NNS-EVT method exploits the capacities of the EVT, semi-parametric extreme value distribution, and quantile modeling for developing a probabilistic machine learning framework in the view of unsupervised learning. This method is performed in the baseline/training and monitoring/inspection stages. The main objectives in these stages include calculating distance values between each displacement points with the other ones, finding nearest neighbors of each displacement sample, selecting the k-smallest distance values, estimating the EVI of the negative k-smallest distance values, and computing their quantile.
