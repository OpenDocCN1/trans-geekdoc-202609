analytical solution, it is feasible to implement the maximization process by using standard numerical optimization algorithms (Coles et al. 2001).

The same strategy can be considered for the GPD model in order to estimate its parameters. Given the maximum samples $X_1, ..., X_t$ over the threshold $u$, the log-likelihood function of the GPD under $\xi_P \neq 0$ is defined as follows:

$$ L_P(\delta_P, \xi_P) = -t \log(\delta_P) - \left(1 + \frac{1}{\xi_P}\right) \sum_{i=1}^t \log\left(1 + \frac{\xi_P X_i}{\delta_P}\right) $$

provided that

$$ 1 + \frac{\xi_P X_i}{\delta_P} > 0 $$

where $i = 1, ..., t$. If $\xi_P = 0$, the log-likelihood function of the GPD is rewritten in the following form:

$$ L_P(\delta_P) = -t \log(\delta_P) - \frac{1}{\delta_P} \sum_{i=1}^t X_i $$

Similar to the GEVD, the maximization of Eqs. (2.13) and (2.15) can be carried out by differentiating the log-likelihood functions with respect to the unknown GPD parameters, from which one can derive the maximum likelihood estimators by means of numerical techniques (Coles et al. 2001).

# ## 2.2.2 Semi-parametric Extreme Value Model

All of the above-mentioned extreme value distributions are parametric models. This means that modeling of the extreme samples depends on the unknown shape, scale, and location, which should be obtained by one of the parameter estimation techniques such as the maximum likelihood estimation. The other issue is related to the model selection. In other words, unlike the generalized distribution function, one needs to use an additional technique to choose the most appropriate function among the Weibull, Fréchet, and Gumbel distributions. To address these issues, it is possible to consider the concept of the semi-parametric EVT and its single distribution function. The great advantage of this theory and function lies in the fact that one does not require allocate a parametric model to extreme values. Moreover, no parameter estimation technique is needed. To put it another way, the semi-parametric distribution modeling depends only on some extreme samples by estimating the extreme value index (EVI) from the same samples without any parameter estimation technique (Gomes and Guillou 2015).
