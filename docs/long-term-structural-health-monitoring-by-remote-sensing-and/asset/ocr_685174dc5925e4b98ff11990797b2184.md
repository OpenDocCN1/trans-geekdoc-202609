# ## 4.3.3 HMC-DTL-MD

Similar to the previous hybrid methods, HMC-DTL-MD undertakes to detect early damage or predict collapse before its occurrence under unpredictable EOCs. To do this, it needs to gain the optimum number of consecutive DAEs so that each of them entails three hidden layers of the sizes 10, 2, 10 neurons for mapping, encoding, and de-mapping layers, respectively. According to the proposed hyperparameter optimization (see Sect. 2.3.4.1), it is only necessary to determine the number of iterations (i.e., a stopping condition) in the iterative algorithm of this process. Figure 4.14 indicates the amounts of accuracy by using 10 trails for the sample neural networks. As can be observed, the seventh sample provides the best accuracy rate close to 100%. Hence, the DTL algorithm for data normalization requires seven DAEs. In this regard, the first input fed into the first DAE is the real augmented training data X and remaining inputs (E_x1, ..., E_x6) fed into the next six DAEs are the residual samples between each input and output of the previous DAE.
