# 2.3.3 Data Normalization by Unsupervised Teacher-Student Learning

Similar to the previous technique HMC-DAE-MD, the proposed HMC-UTSL-MD method consists of three parts of data augmentation by HMC sampling, data normalization by a new approach, and MD-based feature discrimination. Since the first and third parts have been explained, in this section, the main focus is on the proposed unsupervised teacher-student learning (UTSL) method for data normalization. The crux of this method originates from the concept of the teacher-student learning that develops a two-stage learning framework by a complex model (teacher) and a simple model (student). The teacher is often a complicated and rigorous method, which makes attempt to provide the best representation learning for measured data, while the student utilizes the outputs from the teacher in order to facilitate the learning process or continue the other tasks without applying a complex model (Mirzaei et al. 2020). Depending on the presence of supervision information, any teacher-student learning can be categorized as supervised and unsupervised classes. Similar to the other types of learning algorithms, a supervised teacher-student learning technique is comprised of supervised machines by using fully labeled training data, while an unsupervised teacher-student learning method consists of unsupervised machines by utilizing the only unlabeled data.

The proposed data normalization method in this section is based on an unsupervised teacher-student learning framework. This method exploits different AEs for developing the teacher and student models. In the first step, an undercomplete DAE with seven hidden layers (L = 3) is considered to train a complex teacher model. Figure 2.8a shows this ANN and its configuration. In this regard, it needs to train this deep ANN by using the augmented training data (X) and then reconstruct it (X̂) at the model output layer. The main output of teacher learning is the residual matrix (Eₓ) between the input and output. Subsequently, this matrix serves as a new input to the student model. Hence, in the second step, an overcomplete shallow AE is designed to undertake the student learning. Figure 2.8b shows the student model and its configuration. Accordingly, the residual matrix of the teacher model (Eₓ) is fed into the input layer of the shallow AE to reconstruct it (Eₓ̄). In the following, a new residual extraction process is carried out to obtain a new residual matrix Eₓ̅ = |Eₓ − Eₓ̄| from the student model. Although the aforementioned strategies are related to the augmented training data, it is essential to run them for the augmented test data (Z). The main difference is that the trained teacher and student models should only be used to determine the residual matrices of the test data. This means that no learning process is required in the testing phase. In this case, the expanded test data is fed into the trained undercomplete DAE in an effort to reconstruct it (Ẑ) and determine the teacher residual matrix (E_z). This matrix is then applied to the trained overcomplete shallow AE in order to reconstruct it (E_z̄) once again.
