In the constructor, the class parses out the query part of the URL to determine the table name and the names of the fields in which the log information is stored. The assumption is that the table will be created using a SQL statement such as the following. The field names don't matter (because they're configurable in the connection string), but the data types in your table should be the same (or compatible data types):

```
create table logdata (
   message text,
   loglevel smallint,
   logdate timestamp,
   module varchar(255)
);
```

To use the new PostgreSQL logger, the code should look something like the following:

```
<?php
require_once('class.Config.php');
require_once('class.Logger-enhanced.php');
Config::addConfig('LOGGER_LEVEL', Logger::INFO);
```
