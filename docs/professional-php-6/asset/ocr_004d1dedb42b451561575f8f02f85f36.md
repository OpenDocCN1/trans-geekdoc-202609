printArray() takes an array of at least one dimension and prints an HTML table that shows the contents of that array. Multidimensional arrays are properly handled. Objects have only their class name printed.

The following code shows how this class is used:

```
<?php

require_once( 'class.Debugger.php' );
require_once( 'class.Config.php' );

Config::addConfig( 'DEBUG_LEVEL', DEBUG_INFO );

$myData = array();
$myData[] = 'hello';
$myData[] = array( 'name' => 'Bob',
        'colors' => array( 'red', 'green', 'blue' ) );

Debugger::debug( $myData, 'my data' );
$x = 5 + 8;
Debugger::debug( $x, 'x' );

Debugger::debugPrint();

?>
```
