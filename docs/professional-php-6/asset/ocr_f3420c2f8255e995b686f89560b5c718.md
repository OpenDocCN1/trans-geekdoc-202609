```
public function getStringRepresentation() {
    $strMyRepresentation = "";
    if ($this->recipient_name) {
        $strMyRepresentation .= $this->recipient_name . " ";
    };
    $strMyRepresentation .= "<" . $this->recipient_address . ">";
    return($strMyRepresentation);
}
```

Because the readily accepted format for e-mail addresses is First Name Last Name <user@example .com>, that is the format used here.

The remainder of the class is dedicated to accessor methods — that is, methods to get and set the various properties of the e-mail recipient.
