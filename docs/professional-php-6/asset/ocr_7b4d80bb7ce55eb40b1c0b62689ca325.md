Notice that all the concrete instruments (such as DrumSet and Guitar) descend from the AbstractInstrument class. Also notice that all the subclasses inherit the implemented methods in the abstract class. To implement the getDescription() method, the current instrument is checked to see whether it has children. If it does, then the method is called recursively until it travels through the entire tree. Figure 4-4 shows the output from composite.php.
