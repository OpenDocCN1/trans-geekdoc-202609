The big advantage of this process is that if an error is spotted at any stage during the four phases, then the steps backward that must be retaken are much smaller because you are dealing with only one discrete component, rather than the entire application. In addition, the client is able to play with the first components of your application much sooner, which can have huge political benefits.

Note that the testing phase in the waterfall process deviates slightly from the spiral process in that the tests applied with each new component should ideally include all the previous tests from previous components, too. This is to ensure that no new piece of functionality is causing a previously tested and signed-off piece of functionality to fail — a process known as regression testing.
