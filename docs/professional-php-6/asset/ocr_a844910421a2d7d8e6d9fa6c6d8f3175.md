Note that `isSalesPerson()`, `isSalesManager()`, and `isAccountant()` all access `contentBase`, rather than call `$this->role`. Otherwise, it would be dispatched through the `getRole()` function, which returns human-readable results such as “Sales Manager.” It is not a good idea to try to return Boolean values based on human-readable results because they could change on a whim.
