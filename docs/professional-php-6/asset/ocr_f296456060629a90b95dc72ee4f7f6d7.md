# PHPUnit

The idea here is to write the test to simulate the way in which you plan on using the software associated with your current story. It’s called test-driven development, and, in addition to its development strengths, you end up with a great suite of tests. You met it first in Chapter 13 when you looked at application architecture. It is hoped that you still have PHPUnit installed.

> Testing the application in the same manner in which you will be using it forces you to look at the function or object and nail down the arguments and other elements.
> This avoids creating functionality that isn’t used, or is used in the wrong places.

Far from “tying you down,” having a testing suite provides you with a great degree of freedom, because you know instantly whether you happened to break distant parts of the system by adding new features or modifying existing code.
