This code sample is fairly similar to the SOAP example of the same name, but it uses the far more familiar curl extension and basic XML processing, instead of the SOAP extension (with which many developers may not be familiar). Depending on how you have PHP configured, you could also simply use file_get_contents($url) to fetch the XML, if HTTP requests are allowed in that function (this is a php.ini setting). This example also has the benefit of enabling you to debug problems by simply entering the $url value into your Web browser and looking at the output in the browser window. The SOAP extension keeps you far enough away from the actual interactions with the remote server that debugging basic connection problems can often be difficult and time-consuming.

The returned XML structure lacks the outer envelope section of the SOAP transaction, but it is otherwise the same. Therefore, this examination does not include a discussion of the iteration over the Items, because the code is identical.
