Note how simple the PHP is, including very basic statements such as `if` and `for`. # searchresults.php

The search results page will be the immediate target of the search page and has the job of determining whether its input is acceptable.

It does *not* have the job of informing the user whether the input is not acceptable. Instead, the user will be diverted via a 302 HTTP redirect *back* to the original search page, which then explains the shortcomings.
