If you click Refresh in your Web browser several times, you should get the same output repeatedly. The session identifier is perpetuated, therefore remaining the same.

If you want to prove to yourself that the logged-in state of the session really is maintained, try commenting out the Logout line (which reads `<?php $objSession->Logout(); ?>`) and clicking Refresh. You should see that the Logged in? statement at the top of the page repeatedly returns Yes.

It's worth looking at the database, too. As soon as the user is logged in successfully, that flag is set against the session in the database table, and remains until either the session itself is deleted or the explicit Logout method is called:
