```
CREATE TABLE "session_variable" (
"id" SERIAL PRIMARY KEY NOT NULL,
"session_id" int4,
"variable_name" character varying(64),
"variable_value" text
);
```

As you can see, the sessions are stored as indexed by a standard serial ID, rather than by their PHP-generated session ID. This enables far faster indexing when you look at session variables (numbers always index better than strings).
