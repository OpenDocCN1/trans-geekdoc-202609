The $formfunc Smarty variable holds the name of a JavaScript function that is executed when the HTML form is loaded, $formfunc. The onload form property is set to $formfunc, or an empty string if $formfunc is not defined. This enables you to selectively recalculate your entire spreadsheet during the loading process. By doing so, daycalc() must be concerned only with its column, row, and the totals, rather than with recalculating every cell during every keystroke.
