因此，女性主义哲学家是首批批评以理性为人类尊严基础的人之一，主张一种关系性的自主概念（[Stoljar, 2013](#ch2.xhtml#ref2_45)）。

同样，Mhlambi 提出了一种基于南非 Ubuntu 哲学的替代性人工智能伦理方法，该哲学以关系性术语诠释人格与人类尊严，其前提是个体福祉只能通过整个社会繁荣来实现（[Mhlambi, 2020](#ch2.xhtml#ref2_35)）。正如 Tom Zwart 所强调的，Ubuntu 敦促人类超越个人利益，要求“合作、相互依存和集体责任”（[Zwart, 2012](#ch2.xhtml#ref2_51): 555）。

因此，Ubuntu 视角可以为 ADM 在歧视和社会排斥背景下所带来的挑战提供新的启示。本章的目的是通过展示 Ubuntu 如何在 HCAI 的背景下被操作化为伦理和法律原则，为关于人工智能监管的跨文化对话提供信息，从而为这一努力做出贡献。

## Ubuntu 作为伦理和法律概念

源于恩古尼哲学，Ubuntu 传统构成了后种族隔离南非社会政治身份的基石，影响着其政府、企业和组织的结构（[Reviglio et Alunge, 2020](#ch2.xhtml#ref2_43)）。此外，Ubuntu 的影响力超越了南非，构成了许多撒哈拉以南社会中存在的道德哲学的基石。

阐述 Ubuntu 的全面定义是一项具有挑战性，甚至可能是不可能的任务。这是因为其含义高度情境化且开放（[Bohler-Muller, 2005](#ch2.xhtml#ref2_9)）。Chuma Himonga 认为，作为一种元规范，Ubuntu 最好以抽象术语来构想，参考其“共同体、相互依存、尊严、团结、责任和理想”的基本属性（[Himonga, 2013](#ch2.xhtml#ref2_22): 173）。南非宪法法院前法官 Yvonne Mokgoro 将 Ubuntu 描述为

> 一种生活哲学，其最根本的意义代表人格、人性、人道和道德；一种描述群体团结的隐喻，而这种群体团结对于资源稀缺的社区的生存至关重要，其基本信念是 […] 一个人之所以为人，是因为其他人。

> ([Mokgoro, 2012](#ch2.xhtml#ref2_36): 317)

这一描述阐明了 Ubuntu 对人类中心人工智能辩论的贡献，强调本质上，Ubuntu 正是关注在（数字）社会中成为人的意义。词语本身的词源唤起了获得人格的过程——在属于恩古尼语族的语言之一的祖鲁语中，词根“Ntu”表示人或人民，而前缀“ubu”表示存在或成为（[Mhlambi, 2020](#ch2.xhtml#ref2_35): 13）。从这个意义上说，Ubuntu 中的人格不同于人类物种的单纯生物学独特性，超越了“意识、记忆、意志、灵魂、理性或心理功能”等要求（[Cornell, 2014](#ch2.xhtml#ref2_3): 160）。正如著名非洲哲学家 Ifeanyi Menkiti 所强调的那样，获得完整人格并非个人能够独自实现，因为它需要整个社区的参与（[Menkiti, 2004](#ch2.xhtml#ref2_32)）。

人格的关系性概念对法律如何规范社会关系具有影响，而法律的基本功能是“保障人类在其存在中”（[Murungi, 2004](#ch2.xhtml#ref2_37): 525）。因此，从规范意义上讲，尽管未在南非宪法文本中明确表述，Ubuntu 被认为是一种“渗透宪法整体，特别是体现了既定基本权利的第三章”的价值。

## 通过 Ubuntu 透镜看 *égale dignité* 概念——来自南非宪法法院的教训

Ubuntu 指向人与人之间的亲缘感（[Ramose, 1999](#ch2.xhtml#ref2_42)），并且与人类尊严价值不可分割地联系在一起，“强调尊严在社会关系和实践中的美德”（[Mokgoro, 2012](#ch2.xhtml#ref2_36): 318）。然而，Ubuntu 中对尊严的理解与欧洲哲学思想之间存在显著差异。本节说明南非宪法法院如何通过 Ubuntu 的透镜诠释尊严，从而保护弱势群体免受社会排斥。

### 社会排斥作为关系性尊严的侵犯

现代人类尊严概念之父伊曼努尔·康德将尊严与实践理性的能力联系起来，这种能力使人类能够行使自主权，而在 Ubuntu 中，尊严并非根植于理性，而是根植于人类的独特性与独特性及其建立与他人和谐关系的能力（[Metz, 2020](#ch2.xhtml#ref2_33)）。正如 Tom Bennett 所主张的那样，正是“嵌入于共同体中”的概念使 Ubuntu 不同于西方的尊严观念（[Bennett, 2011](#ch2.xhtml#ref2_5)）。因此，Ubuntu 的精神常被表达为格言：“我之所以存在，是因为我们存在，而既然我们存在，因此我存在”（[Mbiti, 1990](#ch2.xhtml#ref2_31)）。
