# DOMINANCE IN THE UNITED STATES

The IT Governance Institute was created by the Information Systems Audit and Control Association (ISACA). ISACA, in turn, is the primary professional association for IT audit professionals in the United States. The Association’s certified information systems auditor (CISA) certification is the dominant certification for U.S. IT auditors, so it is not surprising that COBIT has become the dominant framework for auditing IT controls in the United States.

# The ISO/IEC 27000 Series

While COBIT focuses on the governance of the IT function broadly, the ISO/IEC 27000 series of standards focuses specifically and in detail on IT security. The first standard in this series was originally called ISO/IEC 17799. When it was decided to have all security standards begin with 27000, this standard was renamed ISO/IEC 27000.

# ISO/IEC 27002

This standard divides security into 14 broad areas (listed below) and offers best practices for information security controls within an organization.

+   1. Information security policies
+   2. Organization of information security
+   3. Human resource security
+   4. Asset management
+   5. Access control
+   6. Cryptography
