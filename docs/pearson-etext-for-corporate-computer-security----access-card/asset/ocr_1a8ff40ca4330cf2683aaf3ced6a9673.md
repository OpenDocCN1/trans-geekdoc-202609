Peer-to-Peer Redirect   Similar to a DDoS attack, a **peer-to-peer (P2P) redirect attack** uses many hosts to overwhelm a victim using normal P2P traffic (Figure 4-7, Step 1). A P2P redirect attack differs from a traditional DDoS attack in several ways. The attacker does not have to control each of the hosts (i.e., make them bots) used to attack the victim. The attacker just needs to convince the hosts to redirect their *legitimate* P2P traffic (Step 2) from the P2P server to the victim (Step 3).
