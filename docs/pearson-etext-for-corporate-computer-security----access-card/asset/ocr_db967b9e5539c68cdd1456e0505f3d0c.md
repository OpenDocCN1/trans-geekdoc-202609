AUDIT POLICIES Finally, audit policies would provide an audit trail for system events. These system events could be attacks, attempts to disable security protections, changes in permissions, and so on. Implementing audit policies provide systems administrators with detailed information about who caused these events to occur (i.e., which user attempted to log in remotely), what they may have changed (i.e., elevated a user’s permissions without authorization), and when the event occurred.

Figure 7-35 shows audit policy settings available on every Microsoft Windows 10 host. Administrators can track account logon events, account changes, policy changes, privilege use, and so on. Informing users that system events are logged and audited can provide a disincentive for improper behavior. Audit policies can also be used to gather information about attacks. These logs can later be used against attackers in legal proceedings.
