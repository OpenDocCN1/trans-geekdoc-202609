## BENEFITS OF VIRTUALIZATION

Virtualization provides multiple benefits in the host hardening process. It allows systems administrators to create a single security baseline for each server (or remote client) within the organization. Subsequent instances of that server can be cloned from an existing hardened virtual machine in a few minutes instead of hours or days.

Cloning hardened virtual machines minimizes the chance of incorrectly configuring a server, reduces the time needed to configure the server, and eliminates the need to install applications, patches, or service packs.

In addition to being more secure, virtual environments can also benefit businesses by reducing labor costs associated with server administration, development, testing, and training. It can also reduce utility expenses by shutting down unused physical servers, and increasing fault tolerance and availability.

## Systems Administrators

IT employees who manage individual hosts or groups of hosts are called systems administrators. (No, the name is not very descriptive.) Typically, it is the job of the systems administrator of a particular server to conduct the hardening effort. Larger firms have many systems administrators, and security baselines help ensure uniformity across the hardening efforts of systems administrators. Systems administrators do not, in general, administer the network.

## In the News

### Meltdown, Spectre, Foreshadow, and ZombieLoad

In 2018 the world was shocked when security researchers showed that all computer chips produced in the past 20 years have inherent flaws that allow an attacker to steal sensitive information.¹ Researchers named these flaws Meltdown and Spectre. Essentially, they take advantage of two techniques commonly used in CPUs to speed up processing — caching and speculative execution. Attackers can use specialized software to manipulate the caching and speculative execution functions and gain access to protected memory. This allows attackers access to passwords, bank account numbers, or anything else that runs through a CPU.

What could be worse than two hardware vulnerabilities that make nearly every chip on the planet hackable? Four hardware vulnerabilities. In late 2018 and mid-2019, researchers found two more vulnerabilities in Intel chips called Foreshadow and ZombieLoad.² Both flaws allow malicious hackers to extract data as it's being processed. These flaws affect nearly all CPUs made since 2011. Security practitioners are becoming weary of the continual notifications that all of their hardware is coming with built-in vulnerabilities that aren't easily fixed.

### D-Link's Audit

In 2019 the well-known Taiwanese networking equipment manufacturer D-Link settled a lawsuit with the U.S. Federal Trade Commission (FTC). The FTC was suing D-Link for a host of serious security flaws in the networking equipment that put its users at risk. The FTC claimed that D-Link was installing nonremovable default passwords in its IP cameras, leaking router security keys, and continuing to ship software with known injection flaws.³

D-Link argued that there was no proof that anyone had been harmed as a result of its lax security practices and asked that the case be dismissed. In a settlement, D-Link claimed no liability for the weaknesses, but it did agree to 20 years of security audits and the creation of a new comprehensive security program designed to secure its devices.

### Hacked Smart Plugs

In 2018 security researchers at McAfee found a buffer-overflow weakness in an IoT smart plug made by Belkin.⁴ The flaw in the Wemo Insight Smart Plug could allow attackers access to any devices attached to a local network. The weakness in the Smart Plug highlights the ever-expanding “attack surface” that companies have to protect. As devices become *smart*, they also become *vulnerable* to attack. This becomes even more worrisome as more IoT devices flood the market each year.

## 7.2 Important Server Operating Systems

### 7.2 Know important server operating systems.

In previous chapters, we looked at several types of hosts including servers, client PCs, routers, and firewalls. In this section, we will look at a couple of the more common server operating systems. We will focus on server operating systems because they are the frequent target of attack.

Attackers like to focus their efforts on servers because they contain valuable data, are a critical part of corporate information systems, and provide an excellent platform from which they can launch additional attacks. It is important to be familiar with these operating systems and know how to harden them against attacks.
