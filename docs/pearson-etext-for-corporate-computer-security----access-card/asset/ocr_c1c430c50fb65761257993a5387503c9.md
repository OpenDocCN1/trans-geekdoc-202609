# Project 1

AxCrypt® is a great third-party encryption tool. You just select the files you want encrypted, enter your password, and you’re done. It is even available as an option in the shortcut menu when you right-click a file. AxCrypt will automatically re-encrypt the file after you are done modifying it. It uses 128-bit AES and is completely free. Let’s look at some of the functionality built into AxCrypt.

+   1. Download AxCrypt from www.axcrypt.net.
+   2. Click Download.
+   3. Click on the appropriate version for your operating system.
+   4. If the program doesn’t automatically open, browse to your download folder.
+   5. Right-click AxCrypt-2-Setup.exe.
+   6. Click Run as administrator.
+   7. Click Yes if prompted.

+   8. Click I Agree.
+   9. Click Custom Installation.
+   10. Deselect all the bloatware (from Amazon).
+   11. Click Install.
+   12. Deselect Register.
+   13. Click Finish.
+   14. Save all your work, exit all other programs, and reboot your computer. Once your computer is rebooted you can continue on to the next step.
+   15. Right-click your desktop.
+   16. Click New and Text Document.
+   17. Name the file YourName.txt. Replace YourName with your first and last name.
+   18. Right-click the file named YourName.txt.
+   19. Select AxCrypt, and Encrypt.
+   20. Enter the password “tiger1234” (without quotes).
