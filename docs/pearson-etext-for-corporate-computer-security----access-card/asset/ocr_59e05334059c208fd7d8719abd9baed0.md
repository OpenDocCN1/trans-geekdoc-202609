# List of Known Passwords

Security researcher Troy Hunt has collected a growing list of more than 555 million real-world unique passwords that were collected and anonymized from 8.4 billion stolen accounts in thousands of data breaches.12 Figure 5-6 shows the top 20 unique passwords across all data breaches. The password "123456" is the most commonly used password chosen by users. Systems administrators can use Troy Hunt's list to ban previously compromised passwords from internal systems. Preventing users from choosing weak passwords will make internal systems more secure.

# Data Breaches Expose Passwords

Password auditing becomes even more important when you consider that while operating systems automatically hash and store your password, online applications and e-commerce sites do not. For example, in 2009, hackers used a well-known SQL vulnerability to steal 32 million passwords from RockYou.com. RockYou.com was storing all usernames, passwords, and partner data as plaintext.13 RockYou.com would also send plaintext passwords to users via e-mail.

Even if you are using a strong password, the website you are using may not store it securely. If an attacker steals it, your strong password will go on a list of known passwords and then be used by attackers to access your accounts. Regular auditing using known passwords will ensure that passwords used on internal systems are secure. Consider the comparison of Troy Hunt's list with passwords taken from separate data breaches.
