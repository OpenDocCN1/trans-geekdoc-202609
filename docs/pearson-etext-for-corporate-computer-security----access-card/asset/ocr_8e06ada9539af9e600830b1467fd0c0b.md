**ARP poisoning** is a network attack that manipulates host ARP tables to reroute local-area network (LAN) traffic. An attacker can reroute traffic for a man-in-the-middle attack, or stop it altogether in an **ARP DoS attack**. ARP poisoning only works on LAN traffic. This requires an attacker to have a computer on the local network for ARP poisoning to work.

Rerouting traffic using ARP poisoning is an attack on both the *functionality* and *confidentiality* of a network. An attacker changes the normal operation of a network, and gleans information about network traffic. An ARP DoS attack is an attack on the *availability* of a network by rerouting traffic to a nonexistent host and thereby forcing it to be dropped.
