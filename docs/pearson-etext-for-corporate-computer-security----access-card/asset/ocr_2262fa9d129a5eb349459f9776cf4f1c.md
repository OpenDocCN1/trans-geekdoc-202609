# Application Content Filtering in Stateful Packet Inspection Firewalls

Application proxy firewalls are not the only firewalls that can provide application content filtering. As Figure 6-15 notes, most stateful packet firewalls have started to include application content filtering—often the same types of application content filtering that application proxy firewalls do.

Stateful packet inspection firewalls do not have to implement relay operation as application firewalls do. This permits SPI firewalls to add application content filtering more economically.
