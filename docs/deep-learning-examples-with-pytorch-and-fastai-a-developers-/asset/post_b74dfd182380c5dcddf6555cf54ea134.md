```python
    _open_args = {'mode': 'RGB'}

    @classmethod
    def create(cls, fn:(Path,str,Tensor,ndarray,bytes), **kwargs)->None:
        "Open an `Image` from path `fn`"
        if isinstance(fn, TensorImage): fn = fn.permute(1,2,0).type(torch.uint8)
        if isinstance(fn, Tensor): fn = fn.numpy()

        if isinstance(fn, bytes): fn = io.BytesIO(fn)
        return cls(load_image(fn, **merge(cls._open_args, kwargs)))

    def show(self, ctx=None, **kwargs):
```

All the available types in the fastai framework follow along this pattern. We can use a base class for the type that provides a create and a show method.

The `create` method does all the preparation and conversion of the data into a tensor. It then converts the tensor data into something that can be viewed or visualized by the matplotlib library.

If we check out the base type `TensorPoint` class we see the same pattern:

```python
class TensorPoint(TensorBase):
    "Basic type for points in an image"
    _show_args = dict(s=10, marker='.', c='r')

    @classmethod
    def create(cls, t, img_size=None)->None:
        "Convert an array or a list of points `t` to a `Tensor`"
        return cls(tensor(t).view(-1, 2).float(), img_size=img_size)

    def show(self, ctx=None, **kwargs):
        if 'figsize' in kwargs: del kwargs['figsize']
        x = self.view(-1,2)
        ctx.scatter(x[:, 0], x[:, 1], **{**self._show_args, **kwargs})
        return ctx
```

We have a `create` method that accepts a list of points and an optional image size and returns a tensor with a shape of (-1, 2). The `show` method just creates a scatterplot of these points and returns the plot to the caller.

### 3.1 Model Optimizer

During optimization, our goal is to minimize the error (calculated by the loss function mse). Our optimizer starts with some random parameters, calculates the gradient and makes some adjustment to the parameters. Next, we repeat this step until our error is smaller than a value epsilon or until a fixed amount of epochs. (https://en.wikipedia.org/wiki/Stochastic_gradient_descent)

First let's make this parameter:

```python
a = nn.Parameter(a); a
```


Now we have to implement our update function which checks if the current value of our parameter a improves the training results. If so, move in this direction.

```python
def update():
    y_hat = x@a
    loss = mse(y, y_hat)
```
