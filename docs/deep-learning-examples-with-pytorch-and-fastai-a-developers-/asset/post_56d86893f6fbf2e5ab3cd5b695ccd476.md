## 23.2 Building the Model

As with any regression problem we want to define a range for the y-values to improve the learning capabilities of our model. This way the model has a kind of “target area” where to zoom in while doing the training. Therefore we have to decide what this maximum value could be.

In our case we will just use the maximum of our sales data and multiply this
by the factor 1.2 to leave room for some wiggling.

```
max_log_y = np.max(train_df['Sales'])*1.2
max_log_y

12.7616122408592
```

Now we can build a range-tensor from 0 to this maximum:

```
y_range = torch.tensor([0, max_log_y])
y_range
tensor([ 0.0000, 12.7616])
```

We can now start to train our learner! What is exactly passing into the architecture of our learner?

- We are passing in two fully connected layers with 1000 and 500 neurons.
- The ps means “*dropout*”. We are passing in two parameters – (notice, we have to pass in one value per layer!)
- The embed_p parameter we are passing in, handles dropout with the embedding layers
- y_range is the interval of our target predictions
- We are using exp_rmspe for the metric and
- MSELossFlat as a loss-function because we are doing regression

If we omit the loss-function, the tabular-learner tries to figure out what is happening and chooses a loss-function on its own. Yet with regression we have to declare the loss-function, otherwise we get an error.

```
learn = tabular_learner(dls, layers=[1000,500], ps=[0.001,
0.01],
embed_p=0.04, y_range=y_range,
metrics=exp_rmspe,
loss_func=MSELossFlat())
```

As always, we want to analyze our model. We can see that there is a bunch of embedding layers followed by a drop-out. Next are our two fully-connected linear layers. The last layer is a linear layer with an output of 1.

The next step is to find a good learning-rate and train for some epochs.

```
learn.lr_find()
```
