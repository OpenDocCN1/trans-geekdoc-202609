Now we can create our customized Learner. We pass all the elements (our dataloaders, our model-architecture and our loss-function).

Now we can check the summary of our model and reassure that all the layers show the correct dimensions. The summary also shows the number of trainable parameters. This can be an index on how one model behaves in comparison to another one.

```
learner = Learner(dataloaders, net, loss_func=loss_fun)
```

After creating the learner we look for a suitable learning rate and train our model for just one epoch.

*Why just one epoch?* Because every time we train a batch, the style from the image is extracted and the weights are stored away and the models are updated.
