## 4.4 Create and Train the Model

For our model creation we use a ResNet34 pretrained architecture. As our model should do a multi-class classification we want to use accuracy_multi as a metric-function during training.

All the other steps will be the same as with single-classification:

- 1. create the dataloader (passing into it our model-architecture and the accuracy_multi metric function
- 2. find a good learning rate with lr_find()
- 3. train for some epochs by calling fit_on_cycle()

```
from torchvision.models import resnet34
from fastai.metrics import accuracy_multi
```

```
learner = cnn_learner(dataloaders,

```

When detecting multiple labels, our model won’t use softmax to determine the label with the highest probability but needs a threshold value to return any label with a higher probability than the threshold.

We also improve our loss-function and use BCEWithLogitsLossFlat(). This is like CrossEntropyLoss but flattens input and targets. BCEWithLogitsLoss is built upon Sigmoid which is numerically unstable. Therefore we need to add similar loss modules to address this numerical instability issue.

See: https://dev.fast.ai/layers.html#BCEWithLogitsLossFlat class

→ target."

The code above shows the implementation of the loss-function. We first calculate a sigmoid activation: return torch.sigmoid(x) and afterwards we check whether the values are higher than a threshold. This way we can detect multiple labels for our data.
