```

```

```
def ListSplitter(items):
    def _inner(it):
        val_mask = tensor([o.name in items for o in it])
        return [~val_mask, val_mask]
    return _inner

name2id = {v:k for k,v in enumerate(codes)}
void_code = name2id['Void']

def acc_camvid(inp, targ):
    targ = targ.squeeze(1)
    mask = targ != void_code
    return (inp.argmax(dim=1)[mask]==targ[mask]).float().mean()
```

The only thing that changes is the resolution of our images. Therefore we have to rebuild our dataloaders and use the full size for training.

## Chapter 9 ImageWoof Dataset

We are using the ImageWoof dataset in this chapter. You can find the dataset here: https://github.com/fastai/imagenette

This dataset is a simpler version of ImageNet with only 10 different classes and is meant for training a new model architecture for only a small amount of epochs so you can check if your model-architecture is working well.

There are a few more datasets available:

- **ImageNette:** Slightly easier than ImageWoof, 10 easily classified classes from ImageNet (tench, English springer, cassette player, chain saw, church, French horn, garbage truck, gas pump, golf ball, parachute)
- **ImageWoof:** 10 different dog breeds, Australian terrier, Border terrier, Samoyed, Beagle, Shih-Tzu, English foxhound, Rhodesian ridgeback, Dingo, Golden retriever, Old English sheepdog
- (Pronounced **Imagewang**, "net" in Chinese): Both ImageNette and Woof but:
  ![](img/d5454da46c702784893ef8b0b539e5b9_132_0.png)
  - The validation set is the same as Imagewoof (i.e. 30% of Imagewoof images); there are no Imagenette images in the validation set (they're all in the training set)
  - Only 10% of Imagewoof images are in the training set!
  - The remaining are in the unsup ("unsupervised") directory, and you can not use their labels in training!

We want to use the most fundamental API from fastai with this dataset and work without a pretrained model. So let's grab the dataset.

### 9.1 The Architecture and the New Implementations

There have been a lot of new findings in model-architectures and I would like to deal with some of them:

- **XResNet** – Based on the *Bag of Tricks for ResNet* (https://arxiv.org/abs/1812.01187) paper. *XResNet* is the new model-architecture we want to use.
- **Mish** (https://arxiv.org/abs/1908.08681v1) – A new activation function that has shown fantastic results. The *Mish* activation function in combination with *Ranger* optimizer promises very improved training results.
