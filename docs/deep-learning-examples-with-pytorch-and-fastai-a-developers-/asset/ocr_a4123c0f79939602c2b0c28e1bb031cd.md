# 21.1.2 Selecting Rows and Columns

There are different methods for selecting rows and columns for your dataframe. For rows you have two different row selectors: * loc and * iloc

Each of them works a little different. The loc-function uses the index as a label. This means if you do a df.iloc[:3] you will get all rows with a row matching the given interval from 0 to 3. With our dataframe we get a total of 4 rows!

```
df.loc[:3]
```
