Now we want to fit a straight line. This means our model should minimize the mean squared error. Let’s define our loss-function: mean-squared-error.

```
def mse(y_hat, y):
    return ((y_hat-y)**2).mean()
```

We can run our model and try to predict, let’s say a = tensor(.5, .75) (This is our initialization for the weights.) Our model will make a prediction and calculate the error.

