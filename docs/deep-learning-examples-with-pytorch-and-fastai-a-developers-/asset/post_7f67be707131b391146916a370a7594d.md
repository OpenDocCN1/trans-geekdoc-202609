*What does Tensor.view(..) do?* This function is used to reshape any tensor into the given format. E.g. if you want to transform a tensor into a matrix of 2x2 you call `view(2, 2)`. But what if you know how many columns you want but not how many rows? Then we use -1. The call we use `view(-1, 2)` means: create a tensor with 2 columns and as many rows as we need.

We could add an input that keeps track of the image size:

```python
class MyTensorPoint(TensorBase):
    @classmethod
    def create(cls, t, img_size=None)->None:
        return cls(Tensor(t).view(-1, 2).float(),
                   img_size=img_size)
```

Now we have just one thing to finish up. We have to implement the encode / decode functions. Both methods (encode and decode) accept an object of type PILBase that is the parent class of PILImage because PILImage extends PILBase. We grab the size of x by calling our _grab_sz(x) and just return the values.

```python
class MyPointScaler(Transform):

def _grab_sz(self, x):
self.sz = [x.shape[-1], x.shape[-2]] if isinstance(x, Tensor) else x.size

def encodes(self, x:(PILBase, TensorImageBase)): return self._grab_sz(x)
def decodes(self, x:(PILBase, TensorImageBase)): return self._grab_sz(x)
```
