### 21.1.1 Head and Tail

The functions `head` and `tail` are equivalent to the unix `head` and `tail` functions. They show the first rows of a dataframe and then the last rows of the dataframe respectively. You can pass a value `n` to show `n` rows – the default for `n` is 5. So both `head` and `tail` are handy functions to get a quick glance at your data before you start working with it.

### 21.1.2 Selecting Rows and Columns

There are different methods for selecting rows and columns for your dataframe. For rows you have two different row selectors: `loc` and `iloc`.

Each of them works a little different. The `loc` function uses the index as a label. This means if you do a `df.loc[:3]` you will get all rows with an index matching the given interval from 0 to 3. With our dataframe we get a total of 4 rows!

```python
df.loc[:3]
```

```python
df.iloc[:3]
```

### 21.1.3 Selection based on Values

We can also select rows by passing in some kind of condition: `df.loc[df['column_name'] == some_value]`. E.g. let’s get a list of all *female* passengers:

```python
df.loc[df['sex'] == 'female'].head(2)
```

### 21.1.4 Plotting the Data from a DataFrame

For humans it can be extremely important to plot data because you can probably find biases faster and more easily with plotted data than with tabular data.

We can just call the `plot` function on any dataframe we want. The `plot` function is based on matplotlib. Therefore we can pass in any parameter that we could have used with matplotlib, too.

For example, if we want to plot the passenger classes, we pass in a title and set the kind of the plot to bar.

```python
df['pclass'].iloc[:5].plot(kind='bar', title='pclass')
```

## 21.2 Working with multiple DataFrames

For this demo we split the original dataframe into two, sharing one common column called `name`.

```python
df1 = df[['sibsp', 'parch', 'ticket', 'fare', 'cabin',
          'embarked', 'name']].iloc[:50]
df2 = df[df.columns[:6]].iloc[:50]
```
