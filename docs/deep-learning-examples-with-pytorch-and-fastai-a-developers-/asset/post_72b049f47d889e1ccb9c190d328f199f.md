```python
    def measure_col(self, name:str):
        "Measures change after column shuffle"

        perm = np.random.permutation(len(orig))
```

## 24.3 Ensembling

Ensembling is like a panel of experts. Everyone brings in a different expertise. In the end we are just averaging on the individual predictions. So we bring in the predictions from the neuralnet and from the gradient boosting tree model and take the average. In the end we take the argmax.

```
avgs = (nn_preds + xgb_preds) / 2
```
