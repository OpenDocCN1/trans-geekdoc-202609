# 21.1.4 Plotting the Data from a DataFrame

For humans it can be extremely important to plot data because you can probably find biases faster and more easily with plotted data than with tabular data.

We can just call the plot-function on any dataframe we want. The plot-function is based on matplotlib. Therefore we can pass in any parameter that we could have used with matplotlib, too.

For example, if we want to plot the passengers classes, we pass in a title and set the kind of the plot to bar.

```
df['pclass'].iloc[:5].plot(kind='bar', title='pclass')
```
