# 1.6.1 Getting the Data

Let’s download the data set and have a look at some of the images. We will directly use the Path library to set a reference to our data-folder. The URLs class contains constant values for all the different data sets that ship with the fastai library.

The data set we will use is called Oxford-IIIT Pet Dataset. You can have a look at the homepage to get a better understanding of the data: (https://www.robots.ox.ac.uk/~vgg/data/pets/)

There are special images for the heads because back in 2015 the best model for distinguishing the breeds was a combined model with different layers trained on the whole image and on recognizing just parts of the image like the head, etc.
