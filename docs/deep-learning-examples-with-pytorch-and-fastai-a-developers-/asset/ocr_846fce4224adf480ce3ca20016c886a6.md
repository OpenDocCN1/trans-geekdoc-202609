We can tune many hyper-parameters with this model.
And now we can make use of our model! There are many different values we can pass in, here is a brief summary:

+   - n_d: Dimensions of the prediction layer (usually between 4 to 64).
+   - n_a: Dimensions of the attention layer (similar to n_d).
+   - n_steps: Number of successive steps in our network (usually 3 to 10).
+   - gamma: A scaling factor for updating attention (usually between 1.0 to 2.0).
+   - momentum: Momentum in all batch normalization layers.
+   - n_independent: Number of independent GLU layers in each block (default is 2).
+   - n_shared: Number of shared GLU layers in each block (default is 2).
+   - epsilon: Should be kept very low (avoid log(0)).
