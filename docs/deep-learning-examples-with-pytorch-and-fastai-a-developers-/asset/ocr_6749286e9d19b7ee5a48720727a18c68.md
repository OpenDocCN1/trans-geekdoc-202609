TabNet was a paper that was updated early this year: *TabNet: Attentive Interpretable Tabular Learning*: https://arxiv.org/pdf/1908.07442.pdf

The main difference between TabNet and the fully connected model that is used by fastai is the **use of attention mechanism** in TabNet. Therefore with this architecture we can understand what is going on in the model during training.

For this chapter we will be using the fast_tabnet wrapper from *Michael Grankin* to utilize the model.

path = untar_data(URLs.ADULT_SAMPLE)

```

This should all look very familiar to you. We are defining our categorical and continuous variables, building the TabularPandas object and creating the dataloaders.

```
```
cat_names = ['workclass', 'education', 'marital-status', → 'occupation',
'relationship' , 'race']
cont_names = ['age', 'fnlwgt', 'education-num']
procs = [Categorify, FillMissing, Normalize]
splits = RandomSplitter()(range_of(df))
to = TabularPandas(df, procs, cat_names, cont_names,

y_names="salary", splits=splits)
dls = to.dataloaders(bs=1)
```
