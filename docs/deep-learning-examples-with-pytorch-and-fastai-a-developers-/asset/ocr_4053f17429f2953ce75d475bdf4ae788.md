# How can we grab our x-values?

We need a lambda function that returns a path-object to exactly one image.

Let’s use the new python string api:

```
f'{x[0]}.jpg'
```

Note, the x is the actual object that’s being passed into the dataloader. We have seen that one item of our data contains a path to the image and a string containing all the associated labels separated by spaces. Let’s verify this:

```
get_x = lambda x:planet_source/'train'/f'{x[0]}.jpg' val = df.values[0]; val array(['train_21983', 'partly_cloudy primary'], dtype=object)
```

Here we use image train_21983 that should have the labels partly_cloudy and primary associated with it. If we extract the x-values from this data-item we would expect to get a path like this:

```
.../train/train_21983.jpg
```

get_x(val)
Path('/home/bmayr/.fastai/data/planet_sample/train/train_21983.jpg') ...
exactly what we had expected
To grab our y-values we will just have to split the string on the blank.

```
get_y = lambda x:x[1].split()
```

```
get_y(val)
['partly_cloudy', 'primary']
```

With lambdas we can provide a clean and more *pythonic* way of reading the data with the DataBlock-Api. Let’s finish up without DataBlock. Put it into the dataloaders and have a look at a sample batch.
