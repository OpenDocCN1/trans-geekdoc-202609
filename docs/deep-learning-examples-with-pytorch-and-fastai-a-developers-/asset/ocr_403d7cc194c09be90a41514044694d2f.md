# 26.1.2 Dependency Plots

Dependency plots use the same variable on the x and y axis, with the y axis being the “SHAP” values. We can pass in a variable name and a particular class ID and it will show the dependency plot for all of the test data we passed in. This allows us to recognize the relationship of these variables when they are together. For example, when my relationship is high and my age is high: How does this affect my data? (You can think of it as a kind of cluster analysis).

If we now pass in age into our dependency plot, the figure shows us the most correlated variable. In this case marital-status is the most correlated variable. So if our age-value decreases, how is this affected by the marital-status variable?

```
exp.dependence_plot('age', class_id=0)

If we pass in 1 for the class parameter class_id we should see the opposite of the plot.

```
