*What does Tensor.view(..) do?* This function is used to reshape any tensor into the given format. E.g. if you want to transform a tensor into a matrix of 2x2 you call `view(2, 2)`. But what if you know how many columns you want but not how many rows? Then we use -1. The call we use `view(-1, 2)` means: create a tensor with 2 columns and as many rows as we need.

We could add an input that keeps track of the image size:

```
```python
class MyTensorPoint(TensorBase):
    @classmethod
    def create(cls, t, img_size=None)->None:
        return cls(Tensor(t).view(-1, 2).float(),
                   img_size=img_size)
```
