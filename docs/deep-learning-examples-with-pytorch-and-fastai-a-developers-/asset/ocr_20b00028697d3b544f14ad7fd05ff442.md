# Chapter 29
Resources

If you are interested in a more in-depth introduction on the fastai library, you should watch the online courses on [www.fast.ai](http://www.fast.ai). Another great resource (that was also one of the sources for this book) are the notebooks from Mueller Z. These notebooks are free on github: [https://github.com/muellerzr/Practical-Deep-Learning-for-Coders-2.0/](https://github.com/muellerzr/Practical-Deep-Learning-for-Coders-2.0/). Many of the examples from this book were inspired by his great lectures.
