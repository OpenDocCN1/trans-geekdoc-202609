When we now build our data, we do not want to think about dataloaders, datasets or anything else like this. We want to take a step back. We have the data – we know all of the images and all the possible labels for those images. This is what our transform will expect.

Within the SiamesePair we create a class mapping. When we create the dataset, we create two Siamese images based on the two inputs. We randomly select an image out of all the available images as the partner for another image x. Therefore, there is a random chance of becoming the same image or a different one.
