Sometimes this is a bit hard to read – especially for long classes. But we see the sections: – **Signature:** This shows all the parameters and default values for the constructor – **Source:** Shows the implementation – **File:** This shows the path to file that contains the source code – **Type:** Shows type of implementation

We can go directly to the fastai repository and open the file learner.py from the vision-package.
This is the link (*maybe this link will change in the future*): https://github.com/fastai/fastai/blob/master/fastai/vision/learner.py If we analyze the source-code, we see what happens behind the scenes:

+   1. The function grabs some model architecture: `meta = model_meta.get(arch, _default_meta)`
+   2. It builds the model: `model = create_cnn_model(arch, n_out, ifnone(cut, meta['cut']), pretrained, n_in=n_in, y_range=y_range, **config)`
+   3. It creates an instance from the base Learner-class: `learn = Learner(dls, model, loss_func=loss_func, splitter=ifnone(splitter, meta['split']), **kwargs)`
