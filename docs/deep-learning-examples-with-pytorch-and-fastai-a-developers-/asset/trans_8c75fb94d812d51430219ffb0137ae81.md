## 20.8 MFCC + Delta

我们关注的另一个变换是 Delta 变换。Delta 定义为输入数据沿所选轴导数的局部估计。

这意味着我们可以从单一信号生成多个通道。通过批次数据，我们可以看到不同的通道（通道图像 0、通道图像 1 等等）。

item_tfms = [CropSignal(1000), aud2mfcc, Delta()]
