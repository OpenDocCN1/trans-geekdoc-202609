To create our datasource and our dataloaders we have to create a filesplitter function.
We use the FileSplitter function that checks for all the image files in our path.
If the filename is contained in the validation file and the file is a valid image file, it puts the file into training or validation source.

```
def FileSplitter(fname):
    "Split `items` depending on the value of `mask`."
    valid = Path(fname).read().split('\n')
    def _func(x): return x.name in valid
    def _inner(o, **kwargs): return FuncSplitter(_func)(o)
    return _inner
```

## 8.2 Training

Now that we have our dataset prepared, we can start training. We want to improve our training process by transferring the model between datasets of different size.

This means we start training with small images and then retrain with bigger and bigger images while transferring the pretrained weights of the model.
Doing training this way we get higher accuracy way quicker than if we start training with full resolution images for a bigger number of epochs.

We start with images half the size of the original images.

Looks great! Now we can create our individual loss-function that takes care of the voids. For segmentation, we want to squeeze all the output values to have it as a matrix of digits for our segmentation mask. From there, we want to match their argmax to the target’s mask for each pixel and take the average.

```python
def accuracy_camvid(inp, target):
    target = target.squeeze(1)
    mask = target != void_code
    return (inp.argmax(dim=1)[mask] == target[mask]).float().mean()
```

### 8.2.1 Creating and Training the Model

When working with image segmentation we are using a model-architecture that is called UNET.

### Network Architecture

Contracting path

Expansive path

input image tile

output segmentation map

- conv 3x3, ReLU
- copy and crop
- max pool 2x2
- up-conv 2x2
- Conv 1x1

image-source: [http://deeplearning.net/tutorial/_images/unet.jpg](http://deeplearning.net/tutorial/_images/unet.jpg)

The term UNET is derived from the U-Form of the model. The model first sizes down an image, allowing one to look at a pixel-wise representation of the image and afterwards, sizes the image up again into a high-resolution image. The first part of the model (the *downsizing*) is called the encoder and the second part (the *upsizing*) is called decoder.

A unet_learner comes with the fastai library and accepts a configuration (unet_config) that can modify the behaviour of the learner.
We can customize:

- Blur/blur final: avoid checkerboard artifacts
- Self attention: A self-attention layer
- y_range: Last activations go through a sigmoid for rescaling
- Last cross – Cross-connection with the direct model input
- Bottle – Bottleneck or not on that cross
- Activation function
- Norm type

Now create the learner. We will use self_attention and Mish for activation function. We want to use Ranger as an optimizer function. We set our accuracy_camvid as the loss function to our learner.

```
config = unet_config(self_attention=True, act_cls=Mish) optimizer = ranger

learner = unet_learner(dataloaders,
resnet34,
metrics=accuracy_camvid,
config=config,
opt_func=optimizer)
```
