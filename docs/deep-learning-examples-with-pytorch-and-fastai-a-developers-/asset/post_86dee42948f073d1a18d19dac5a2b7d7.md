The next step is to create pairs of points from these lists. We implement a function called seperate_points for this purpose.

```python
def seperate_points(coords: array) -> Tensor:
    """Seperate a set of points to groups"""
    key_pts = []
    for i in range(1, int(coords[0]*2), 2):
        key_pts.append([coords[i], coords[i+1]])
    return tensor(key_pts)
point_pairs = seperate_points(keypoints)
```

We can orchestrate all the steps we have done so far.

To get the groundtruth keypoints, we create a get_y function for our dataset.

```python
def get_y(f: Path):
    """Get keypoints for image with path `f`"""
    keypoints = np.genfromtxt(image_to_keypoints(f))
    return seperate_points(keypoints)
```

So by now we can be sure that all of our images can be associated with the correct pairs of keypoints.
Is there anything else we have to check for?

Well, there could be keypoints of images that are out of the region of the image. What does this mean? Some images could be annotated with keypointcoordinates outside the bounds of the image. But how can we check this?

We will generate a list of all the images with bad keypoint coordinates. For each image in our dataset we will perform the following steps:

- make sure that we can open the image
- if there is any point associated with the image outside of the image’s bounds, we remove the image from the dataset
- if there is any point with negative values, we also remove the image from the dataset

```python
bad_images = []
for img in images:
    image = PILImage.create(img)
    y = get_y(img)
    for coord_pair in y:
        # coordinate width in range 0 < x < image.width
        # coordinate height in range 0 < y < image.height
        if coord_pair[0] > image.size[0] or coord_pair[0] < 0 or \
        coord_pair[1] > image.size[1] or coord_pair[1] < 0:
            bad_images.append(img)
```

So when we first run this script we will get about 350 duplicate names within our dataset. We have different options on how to deal with these images. We could:

- remove all of them from our training/validation data
- transform those points to (-1,-1)
- do nothing and just keep them

Each of these options have some benefits and it strongly depends on your goal. We want to do a regression and calculate real coordinates. Therefore we want to remove those images from our dataset. We can use the unlink function from Pathlib-library to remove the files.

```python
for file in list(bad_images):
```

## 14.3 Create DataBlock and Train our Model

While building our datablock we also make use of *clamping*. What does this mean?

Think of this use-case: While we do our transforms, the keypoints could be moved outside of the image range (e.g. RandomResizeCrop - this transform crops the image). While doing the cropping, the coordinates of our keypoints could be moved outside of the cropped image.

We can handle this case differently:
- Should we keep the point and let the model guess the new keypoint coordinates or
- do we want our model to remove the point

We will build a custom ClampBatch transform. Later on we do have to use the block because our model will either use padding or squishing on the resize transforms.
