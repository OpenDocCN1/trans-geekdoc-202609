
```python
self.res5 = ResidualBlock(128)
# Upsampling Layers
self.deconv1 = UpsampleConvolutionLayer(128, 64, ks=3, stride=1, upsample=2)
self.in4 = nn.InstanceNorm2d(64, affine=True)
self.deconv2 = UpsampleConvolutionLayer(64, 32, ks=3, stride=1, upsample=2)
self.in5 = nn.InstanceNorm2d(32, affine=True)
self.deconv3 = ReflectionLayer(32, 3, ks=9, stride=1)
# Non-linearities
self.relu = nn.ReLU()

def forward(self, X):
    y = self.relu(self.in1(self.conv1(X)))
    y = self.relu(self.in2(self.conv2(y)))
    y = self.relu(self.in3(self.conv3(y)))
    y = self.res1(y)
    y = self.res2(y)
    y = self.res3(y)
    y = self.res4(y)
    y = self.res5(y)
    y = self.relu(self.in4(self.deconv1(y)))
    y = self.relu(self.in5(self.deconv2(y)))
    y = self.deconv3(y)
    return y

net = TransformerNet()
```

## 11.7 Exporting the Model

If we want to export the model we have to take care of the loss function. If we just run `learner.export` we will get an error saying `Can't pickle local object "get_features.<local>._inner"`.

This is because we had declared the function `get_features` in our notebook and pytorch doesn’t know how to serialize this object.

We could make the function not serialize but this is kind of hard to do. Therefore we will convert the function into something that can be serialized. We just set the loss-function of the model to any of the loss-functions that come with the fastai library because these can be serialized.

For e.g. we could use `CrossEntropyLossFlat()`. We could revert back to the original loss-function because we have saved it away anyway but when we want to use our model for serving we do not care about the loss-function.

Afterwards we just run the export function on our learner for model export.

```python
learner.loss_func = CrossEntropyLossFlat()
learner.export('09-style-transfer-model')
```
