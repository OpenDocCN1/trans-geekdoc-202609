Looks great! Now we can create our individual loss-function that takes care of the voids. For segmentation, we want to squeeze all the output values to have it as a matrix of digits for our segmentation mask. From there, we want to match their argmax to the target’s mask for each pixel and take the average.

```python
def accuracy_camvid(inp, target):
    target = target.squeeze(1)
    mask = target != void_code
    return
        (inp.argmax(dim=1)[mask] == target[mask]).float().mean()
