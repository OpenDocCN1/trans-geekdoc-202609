## 23.4 Permutation Importance

The main goal of this technique is to get an insight into which columns are more or less important for the accuracy of your model. We can do this by shuffling each column in the dataframe and analyzing how changing a particular column affects the y-values. If we do this shuffling, we are losing all the relations this column had with the model and we get an idea on how this variable affected the outcome of the model.

We can do these permutation tests on the training data or on the testdata.
These two give us different answers.
The one on the validation set tells you:

> “While the model was training, what was it looking at?”

Whereas, the one on the training data tells you:

```
self.dl.items[col] = orig
return metric
```

Here we are doing the permutations! With TabularPandas we can keep everything as a DataFrame. If we modify an element in the TabularPandas it updates all the dataloaders and batches automatically. Within this function we copy the original data and do a permutation. Reassign all the permuted values directly into the dataloader, run validate and replace the permuted values with the original data.

After applying this to each column, we measure the base-error minus the original value normalized by the base-error. The rest of the code is just a helper for plotting, etc. See this code:

self.df = df

    self.dl = learn.dls[1]

self.na = learn.dls.x_names.filter(lambda x: '_na' in x) self.y = learn.dls.y_names
self.results = self.calc_feat_importance()
self.plot_importance(self.ord_dic_to_df(self.results))

def measure_col(self, name:str):
    'Measures change after column shuffle'
    col = [name]
    if f'{name}_na' in self.na: col.append(name) orig = self.dl.items[col].values
    perm = np.random.permutation(len(orig))
    self.dl.items[col] = self.dl.items[col].values[perm]
    metric = learn.validate(dl=self.dl)[1]
    self.dl.items[col] = orig
    return metric

def calc_feat_importance(self):
    'Calculates permutation importance by shuffling a \ column on a percentage
    scale'
    print('Getting base error')
    base_error = self.learn.validate(dl=self.dl)[1]
    self.importance = {}
    pbar = progress_bar(self.x_names)
    print('Calculating Permutation Importance')
    for col in pbar:

        self.importance[col] = self.measure_col(col)
    for key, value in self.importance.items():
        #this can be adjusted
        self.importance[key] = (base_error-value)/base_error
