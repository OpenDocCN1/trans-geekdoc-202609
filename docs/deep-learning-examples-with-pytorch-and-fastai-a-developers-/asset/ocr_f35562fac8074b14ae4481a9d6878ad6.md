# Analyzing Neural Nets with the SHAP Library

The SHAP library is built for analyzing and interpreting neural networks. We are using it today to analyze tabular data. For this chapter we use FastSHAP which is a version of the shap library ported to fastai by Zachary Mueller ([https://github.com/muellerzr/fastinference](https://github.com/muellerzr/fastinference)) – note that the FastSHAP library has been integrated into the fast inference framework recently and only works for TabularData.

Because we want to do some interpretation of a neural net we have to build one beforehand. Let’s use the ADULTS dataset again. This model will be our baseline for analyzing neural nets.

```
from fastai.tabular.all import *
path = untar_data(URLs.ADULT_SAMPLE)
df = pd.read_csv(path/'adult.csv')
dep_var = 'salary'
cat_names = ['workclass', 'education', 'marital-status',
             'occupation', 'relationship', 'race']
cont_names = ['age', 'fnlwgt', 'education-num']
procs = [Categorify, FillMissing, Normalize]

splits = IndexSplitter(list(range(800,1000)))(range_of(df))
to = TabularPandas(df, procs, cat_names, cont_names, y_names="salary",
                   splits=splits)

dls = to.dataloaders()
learn = tabular_learner(dls, layers=[200,100], metrics=accuracy) learn.fit(1,
```
