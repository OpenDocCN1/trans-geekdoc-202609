The abbreviation GAN stands for *generative adversarial network*. This means we have two networks playing against each other. One tries to fool the other, both are trying to get better.

### 18.1 Let’s build the crappified Data

Our crapifier will take two parameters:

- a path for the low resolution and
- a path for the high resolution images.

The crapifier will draw a random number onto the image and store it. from PIL import ImageDraw, ImageFont

```
def resize_img_to(img, target_size, use_min=False):
    width, height = img.size
    min_size = (min if use_min else max)(width, height)
    ratio = target_size / min_size
    return int(width*ratio), int(height*ratio)
```

```
class Crappifier():
    """Quickly draw texts and numbers on an image"""
    def __init__(self, path_lr, path_hr):
        self.path_lr = path_lr
        self.path_hr = path_hr
```

```
def __call__(self, fn):
    dest = self.path_lr / fn.relative_to(self.path_hr)
    dest.parent.mkdir(parents=True, exist_ok=True)
    img = Image.open(fn)
    targ_sz = resize_img_to(img, 96, use_min=True)
    img = img.resize(targ_sz, resample=Image.BILINEAR).convert('RGB')
    width, height = img.size
    q = random.randint(10,70)
    ImageDraw.Draw(img).text((random.randint(0,width//2), random.randint(0,height//2)), str(q), fill=(255,255,255))
    img.save(dest, quality=q)
```
