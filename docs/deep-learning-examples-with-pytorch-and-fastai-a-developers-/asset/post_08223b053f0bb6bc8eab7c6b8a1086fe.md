## 22.4 The DataLoaders

Now we can define our dataloaders. We need to split the data and declare our y-names. We use the range_of function from DataFrame. This function returns the list of all the indices from a dataframe that we can pass into our RandomSplitter.

```
splits = RandomSplitter()(range_of(df))
```

We grab the categorical and the continuous variables along with our

preprocessors. We declare Categorify, FillMissing and Normalize. These are implemented in the given order.

We also need the name of our y-value (the variable we want to predict) which is in our case the salary column. For the y-values, we define a Category-Block.

```
cat_names = ['workclass', 'education', 'marital-status', 'occupation', 'relationship', 'race']
cont_names = ['age', 'fnlwgt', 'education-num']
procs = [Categorify, FillMissing, Normalize]
y_names = 'salary'
y_block = CategoryBlock()
```

With all these values declared we can create the TabularPandas:

```
to = TabularPandas(df, procs=procs, cat_names=cat_names, cont_names=cont_names, y_names=y_names, y_block=y_block, splits=splits)
```

### Second attempt: Create two dataloaders for training and validation:

We can also create two DataLoaders (one for training and one for validation).

One great reason why we prefer this way of implementation is **we can pass in different batch sizes into each TabDataLoader**, along with changing options like shuffle and drop_last (at the bottom I’ll show why that’s super cool).

So how do we use it?

Our training and validation data live in to.train and to.valid right now. So we specify that along with our options. When you make a training DataLoader, you want shuffle to be True and drop_last to be True. This way the last incomplete batch will be dropped.

For the validation-dataloader, we use all the data from to.valid and a higher batch-size of 128 (because we have less data and can go through faster). We do not shuffle the data and keep the last smaller batch.

Then we just call DataLoaders and pass in our two dataloaders.

```
trn_dl = TabDataLoader(to.train, bs=64,
shuffle=True, drop_last=True)
val_dl = TabDataLoader(to.valid, bs=128)
```

```
dls = DataLoaders(trn_dl, val_dl)
dls.show_batch()
```
