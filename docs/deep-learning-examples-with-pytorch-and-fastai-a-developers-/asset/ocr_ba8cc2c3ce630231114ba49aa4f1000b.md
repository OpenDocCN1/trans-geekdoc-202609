# Improve our Pet Classifier with
Multi-classification

The early pet classifier worked well but has a big downside: It always predicts/classifies an image as either being a dog or a cat – even if it’s an elephant.

We can work around this problem by using a multi-class classifier that works with thresholds. Because if the threshold of any label isn’t above the set value, our model will predict nothing.

Let’s refactor our dog/cat-breed classifier!
First untar the data-set:

```
path = untar_data(URLs.PETS)/'images'
```

But now our classifier expects the labels for the training images as a list. Therefore, we have to convert our y-values into a list before feeding into the batch and pass this conversion into the get_y function of our DataBlock.

```
def multi_l(l): return [l]

pets = DataBlock(blocks=blocks,
    get_items=get_image_files,
    splitter=RandomSplitter(),
    get_y=[RegexLabeller(pat=r'([^/]+)_\d+.jpg$'),
        multi_l],
    item_tfms=RandomResizedCrop(460,
        min_scale=0.75),
```
