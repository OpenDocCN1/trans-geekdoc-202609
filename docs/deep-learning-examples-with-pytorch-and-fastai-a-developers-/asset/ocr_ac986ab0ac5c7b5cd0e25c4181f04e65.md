```
def create(cls, t, img_size=None)->None:
    return cls(tensor(t).view(-1,2).float(),
               img_size=img_size)

def show(self, ctx=None, **kwargs):
    if 'figsize' in kwargs: del kwargs['figsize']
    x = self.view(-1,2)
    ctx.scatter(x[:,0],
                x[:,1],
                **{**self._show_args, **kwargs})
    return ctx
```

First of all we make sure that the parameter figsize isn’t contained in the arguments list. If it is, we want to use this value and not the default one.

Next take the tensors and convert them into our view with 2 columns for pixel values. We use the parameter self that is linked to the object on which the show function is being called.

Note: We do not use self with the create-function because we have annotated this function as a class method.

Then we make the scatterplot and return the plot to the caller. Let’s give the function a try!
