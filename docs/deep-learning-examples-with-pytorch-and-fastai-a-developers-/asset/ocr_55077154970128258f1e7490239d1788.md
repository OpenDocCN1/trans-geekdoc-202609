# 14.1 DataSet

As always we first have a look at the dataset we want to use. We are using the cats dataset from kaggle which you can find here: https://www.kaggle.com/crawford/cat-dataset

> This dataset “ includes over 9,000 cat images. For each image, there are annotations of the head of the cat with nine points, two for eyes, one for the mouth, and six for ears.”

This dataset contains the positions for different keypoints on the cats faces:

> The annotation data is stored in a file with the name of the corresponding image plus “.cat” at the end. There is one annotation file for each cat image. For each annotation file, the annotation data is stored in the fol lowing sequence:

+   - Number of points (default is 9)
+   - Left Eye
+   - Right Eye
+   - Mouth
+   - Left Ear-1
+   - Left Ear-2
+   - Left Ear-3
+   - Right Ear-1
+   - Right Ear-2
+   - Right Ear-3
