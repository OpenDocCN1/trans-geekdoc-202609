We want to do a stratified split to make sure that all of our submodels look like the original model. Before doing the split we shuffle the elements in the list.
In sklearn there is StratifiedKFold and StratifiedShuffleSplit.

If we work with KFold we typically do not want to overlap any test set, even after shuffling. Therefore we shuffle the data once and use KFold to split into the models. The testdata is always in one of the splits and the rest of the data belongs in the training data set.

If we would use ShuffleSplit the data would have shuffled again at each split. This could result in test datasets overlapping the splits.

```
import random
random.shuffle(train_images)
k_folds_strat = StratifiedKFold(n_splits=5, shuffle=True)
```
