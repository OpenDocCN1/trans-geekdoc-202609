# 8.2 Training

Now that we have our dataset prepared, we can start training. We want to improve our training process by transferring the model between datasets of different size.

This means we start training with small images and then retrain with bigger and bigger images while transferring the pretrained weights of the model.
Doing training this way we get higher accuracy way quicker than if we start training with full resolution images for a bigger number of epochs.
