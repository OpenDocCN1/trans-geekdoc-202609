The annotations for the dataset come with a JSON file. The fastai library comes with a handy function get_annotations that easily reads the annotations from the json files. We get the extracted coordinates of the bounding boxes and the corresponding label names.

images, label_boxes = get_annotations(path/'train.json') Let’s have a look at the first image and the corresponding labels. images[0], label_boxes[0] ('000012.jpg', ([[155, 96, 351, 270]], ['car']))

So for each image we get a list that contains a sublist with coordinates for each bounding box and a list of labels. We get 4 values for two coordinates (bottom-left and top-right).
