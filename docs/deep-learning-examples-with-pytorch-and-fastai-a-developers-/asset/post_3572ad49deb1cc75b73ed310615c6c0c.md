## 2.2.7 Creating a ResNet Model Architecture

All the ResNet derivatives (ResNet34, ResNet50, etc.) are built with a layer called a **ResBlock**. The idea of a Residual Block is to concatenate two convolutional layers and adding the original layer.

This image is borrowed from a nice tutorial on residual net architecture: [https://towardsdatascience.com/residual-blocks-building-blocks-of-re](https://towardsdatascience.com/residual-blocks-building-blocks-of-re)

![](img/d5454da46c702784893ef8b0b539e5b9_51_0.png)

snet-fd90ca15d6ec

You can have a look at the source code of ResBlock in fastai: ??ResBlock.

But by now we want to build a ResBlock on our own. We define a class ResBlock that inherits from a fastai Module. This is why we only have to overwrite the constructor (__init__) and the forward method.

So if we want to see the implementation of Module, again we just call ?? Module.

```
class ResBlock(Module):
def __init__(self, number_filters: int):
    self.conv1 = ConvLayer(number_filters, number_filters)
    self.conv2 = ConvLayer(number_filters, number_filters)

def forward(self, x):
    return x + self.conv2(self.conv1(x))
```
