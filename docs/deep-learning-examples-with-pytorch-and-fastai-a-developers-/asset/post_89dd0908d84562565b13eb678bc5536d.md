### Siamese Twins

What is the “Siamese Twins”-Problem? It’s just deciding whether two images belong to the same class or not.
When do you use Siamese Twins? Think of these situations for example:

- Identification of persons
- Augmentation of a very small size of training data

Given a training set that contains 5 different images for each one of the 3 different classes, you would normally expect that this amount of training data
is far too little for neural networks.

BUT: If we pair two photos and decide if the images in the tuples are the same or not, we get 120 different pairs of images.
If you do not know how we have calculated the amount of images – here is the tip:

```
class SiamesePair(Transform):
"""A transform to generate Siamese data"""
def __init__(self, items, labels):
self.items, self.labels, self.assoc = items,labels,self
sortlbl = sorted(enumerate(labels), key=itemgetter(1))
self.clsmap = {k:L(v).itemgetter(0) \
for k,v \
in itertools.groupby(sortlbl, key=itemgetter(1))}
self.idxs = range_of(self.items)
def encodes(self,i):
"""x: tuple of `i`th image and a random image from same or different class;\
y: True if same class"""
othercls = self.clsmap[self.labels[i]] if
random.random()>0.5 else self.idxs
otherit = random.choice(othercls)
same = tensor([self.labels[otherit]==self.labels[i]]).int()
return SiameseImage(self.items[i], self.items[otherit], same)
labeller = RegexLabeller(pat = r'/([^/]+)_\d+.jpg$')
labels = items.map(labeller)
```
