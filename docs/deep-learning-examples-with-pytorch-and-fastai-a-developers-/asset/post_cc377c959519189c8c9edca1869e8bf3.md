The concept of Bayesian Optimization is a concept of hyper-parameter tuning. We define a search grid and pseudo randomly try values inside this search grid area to analyze which values seemed to be working well.

If we want to work with Bayesian Optimization, we have to implement a fit_with-function that accepts the tunes parameter values and does whatever we require of it.

```python
def fit_with(lr:float, wd:float, dp:float):
# create a Learner
learn = tabular_learner(data,
```

Inside this function we can try optimize whatever we want. At the end, the function needs to know how to grade the modifications:

`acc = float(learn.validate()[1])`

And that’s what the function should return. The concept is similar to importance permutation but in a more structured way.
Let’s adjust this further to show how we would go about adjusting the learning rate, embedded weight decay, drop out and layer size:

