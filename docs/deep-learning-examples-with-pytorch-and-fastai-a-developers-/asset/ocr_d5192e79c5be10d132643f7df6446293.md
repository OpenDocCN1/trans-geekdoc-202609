If we want to export the model we have to take care of the loss function. If
we just run `learner.export` we will get an error saying Can't pickle local object
"get_features.<local>._inner.

This is because we had declared the function `get_features` in our notebook
and pytorch doesn’t know how to serialize this object.

We could make the function not serialize but this is kind of hard to do.
Therefore we will convert the function into something that can be serialized.
We just set the loss-function of the model to any of the loss-functions that
come with the fastai library because these can be serialized.

For e.g. we could use CrossEntropyLossFlat(). We could revert back to the
original loss-function because we have saved it away anyway but when we
want to use our model for serving we do not care about the loss-function.

Afterwards we just run the export function on our learner for model export.

```
learner.loss_func = CrossEntropyLossFlat()
learner.export('09-style-transfer-model')
```
