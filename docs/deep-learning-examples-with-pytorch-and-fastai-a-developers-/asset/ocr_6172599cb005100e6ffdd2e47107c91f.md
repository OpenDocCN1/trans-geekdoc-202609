We want to select a range on the diagram before the loss rate skyrockets. In this case a range between 1e-6 and 1e-4 will be a good choice. Yet you will probably have to try different values to improve the results.

When training the whole model we select a range and not a single value because we want to train the first layers with a lower learning rate than the last layers. This is called learning-rate annealing. A concept presented in Stanford’s CS231: (http://cs231n.github.io/neural-networks-3/#anneal)

```
learn.unfreeze();
learn.fit_one_cycle(4, lr_max=slice(1e-6, 1e-4))
epoch train_loss valid_loss error_rate time
```
