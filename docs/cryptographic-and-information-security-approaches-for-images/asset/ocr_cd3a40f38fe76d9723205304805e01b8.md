**Definition 4.3:** *[2] A vector Boolean transformation is a vector Boolean function with the identical number of input bits as output bits which can be expressed as follows:*

ζ : ℤ₂ⁿ → ℤ₂ⁿ.  (4.3)

**Definition 4.4:** *To each Boolean function g : ℤ₂ⁿ → ℤ₂, we associate its sign function, or character form, denoted by ĝ : ℤ₂ⁿ → ℝ* ⊆ ℂ*, and defined by the following expression (Table 4.1):*

ĝ(x) = (-1)^{g(x)}.  (4.4)

**Definition 4.5:** *The Hamming weight of a Boolean function g : ℤ₂ⁿ → ℤ₂, is defined as the number of 1's in the binary truth table, or number of -1's in the sign function of g.*

**wt**(g) = Σₓ g(x) = ½ (2ⁿ - Σₓ ĝ(x))

**Definition 4.6:** *For two Boolean functions g, h : ℤ₂ⁿ → ℤ₂, we define the Hamming distance as the number of arguments where g and h differ, that is*

d(g, h) = #{x ∈ ℤ₂ⁿ | g(x) ≠ h(x)} = **wt**(g ⊕ h).  (4.5)

**Definition 4.7:** *The support of a Boolean function g is defined as*

**supp**(g) = {x ∈ ℤ₂ⁿ | g(x) = 1}.  (4.6)

**Definition 4.8:** *A (0,1)-sequence (1, -1)-sequence) is called balanced if it contains an equal number of zeros and one (ones and minus ones). A function is balanced if its sequence is balanced that is **wt**(g) = 2^{n-1}.*
