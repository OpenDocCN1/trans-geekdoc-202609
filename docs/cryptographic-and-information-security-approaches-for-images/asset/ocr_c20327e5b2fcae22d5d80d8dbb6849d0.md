# 20.5 Conclusion and Future Work

This paper presents a novel VSS scheme using QR code. In this scheme, a secret image is distributed and encoded into n QR code shares. The proposed scheme exploits the error correction mechanism in the QR code structure, to generate the bits corresponding to shares by VSS from a secret bit in the processing of encoding QRs. Each share is a valid QR code which contains original information when scanned. So, it reduces the likelihood of attracting the attention of potential attackers if distributed via public channels.
