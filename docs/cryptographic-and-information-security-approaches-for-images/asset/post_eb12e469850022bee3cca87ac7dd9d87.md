DecKeyGen(𝒫𝒫, ℳ𝒦, A_d, δ_d) This algorithm takes as input 𝒫𝒫, ℳ𝒦, a set A_d ⊂ U_e of decryption attributes and a threshold δ_d, and computes the decryption key 𝒟𝒦_{A_d, δ_d} := [δ_d, {D_i, i ∈ A_d}] as follows.

- Let f_d be a random polynomial of degree δ_d − 1 such that f_d(0) = a. Compute D_i := g₂^{f_d(i)+t_i} k₀^{-t_i} for each i ∈ A_d.

SignKeyGen(𝒫𝒫, ℳ𝒦, A_s, δ_s) This algorithm takes as input 𝒫𝒫, ℳ𝒦, a set A_s ⊂ U_s of signing attributes and a threshold δ_s, and computes the signing key 𝒮𝒦_{A_s, δ_s} := [δ_s, {S_i, i ∈ A_s}] as follows.

- Let f_s be a random polynomial of degree δ_s − 1 such that f_s(0) = a. Compute S_i := g₂^{f_s(i)+z_i} h₀^{-z_i} for each i ∈ A_s.

Signcrypt(𝒫𝒫, 𝒮𝒦_{A_s, δ_s}, W_e, W_s, msg) This algorithm takes as input 𝒫𝒫, an encryption attribute set W_e ⊂ U_e, a signing attribute set W_s ⊂ A_s with |W_s| ≥ δ_s, the signing key 𝒮𝒦_{A_s, δ_s} and a message msg ∈ ℳ. Then it carries out the following steps.

- Sample α, γ ← ℤ_p^* and set m := SE-Enc(KDF(Y^α || W_e || W_s), msg)
- C := g^α, C_i := k_i^α, ∀i ∈ W_e
- σ_i := S_i · 𝒲(θ)^α, ∀i ∈ W_s, where θ = H₁(m || W_e || W_s || δ_s)
- ct := [m, C, {C_i : i ∈ W_e}] and σ := {σ_i : i ∈ W_s}
- C_e := (ξ₁^β ξ₂^γ ξ₃)^α, where β = H₂(ct || σ || W_e || W_s || δ_s)
- The ciphertext is 𝒞𝒯 := [W_e, ct, σ, C_e, γ, δ_s].

Unsigncrypt(𝒫𝒫, 𝒞𝒯, W_v, 𝒟𝒦_{A_d, δ_d}) Given 𝒫𝒫, 𝒞𝒯, a verification attribute set W_v ⊂ U_s and 𝒟𝒦_{A_d, δ_d}, this algorithm proceeds as follows.

- Choose a set Ω_s ⊂ W_v of signature attributes of size (at least) δ_s, compute β = H₂(ct || σ || W_e || W_v || δ_s), θ = H₁(m || W_e || W_v || δ_s) and check whether

e(g, C_e) ?= e(C, ξ₁^β ξ₂^γ ξ₃) (9.1)

e(g, ∏_{i∈Ω_s} σ_i^{Λ_{i,Ω_s}(0)}) · e(h₀·g₂^{-1}, ∏_{i∈Ω_s} h_i^{Λ_{i,Ω_s}(0)}) ?= Y · e(C, 𝒲(θ))^{∑_{i∈Ω_s} Λ_{i,Ω_s}(0)} (9.2)

If any one of these two equations does not hold, output ⊥. Otherwise, execute the subsequent steps. Now, $W_v = W_s$.

- If $|A_d \cap W_e| < \delta_d$, then output $\bot$.
- Otherwise, choose a decryption attribute set $\Omega_d = A_d \cap W_e$ of size (at least) $\delta_d$ and then compute

$e\left(C, \prod_{i\in\Omega_d} D_i^{\Delta_{i,\Omega_d}^{(0)}}\right) \cdot e\left(k_0 \cdot g_2^{-1}, \prod_{i\in\Omega_d} C_i^{\Delta_{i,\Omega_d}^{(0)}}\right) = Y^{\alpha} \tag{9.3}$

■ Recover the correct message $msg = \text{SE-Dec}\big(\text{KDF}(Y^{\alpha} \| W_e \| W_v), m\big)$.

## Lemma 9.1 The proposed tABSC scheme is correct.

Proof. Assume the hypothesis of Definition 9.1. Since $W_v = W_s$, we have $\theta = H_1(\text{m} \| W_e \| W_s \| \delta_s)$ and $\beta = H_2(ct \| \sigma \| W_e \| W_s \| \delta_s)$. Hence,

$e(g, C_e) = e\left(g, (\xi_1^{\beta} \xi_2^{\gamma} \xi_3)^{\alpha}\right) = e\left(g^{\alpha}, \xi_1^{\beta} \xi_2^{\gamma} \xi_3\right) = e(C, \xi_1^{\beta} \xi_2^{\gamma} \xi_3)$

and

$e\left(g, \prod_{i\in\Omega_s} \sigma_i^{\Delta_{i,\Omega_s}^{(0)}}\right) \cdot e\left(h_0 \cdot g_2^{-1}, \prod_{i\in\Omega_s} h_i^{\Delta_{i,\Omega_s}^{(0)}}\right) = e\left(g, \prod_{i\in\Omega_s} (g_2^{f_{s}(i)+z_i} h_0^{-z_i} \mathcal{W}(\theta)^{\alpha})^{\Delta_{i,\Omega_s}^{(0)}}\right) \cdot e\left(h_0 \cdot g_2^{-1}, \prod_{i\in\Omega_s} h_i^{\Delta_{i,\Omega_s}^{(0)}}\right) = e\left(g, g_2^{\sum_{i\in\Omega_s} f_{s}(i)^{\Delta_{i,\Omega_s}^{(0)}}} \right) e\left(g, \prod_{i\in\Omega_s} (\mathcal{W}(\theta)^{\alpha})^{\Delta_{i,\Omega_s}^{(0)}}\right) = e\left(g, g_2^{f_s(0)}\right) e\left(g^{\alpha}, \mathcal{W}(\theta)^{\sum_{i\in\Omega_s} \Delta_{i,\Omega_s}^{(0)}}\right)$

= Y · e(C, 𝒲(θ))^{∑_{i∈Ω_s} Λ_{i,Ω_s}(0)}

Since f_s(0)=a. This establishes the correctness of Equations 9.1 and 9.2. Similarly, one can verify the correctness of Equation 9.3. Finally,

SE-Dec(KDF(Y^α || W_e || W_s), m) = SE-Dec(KDF(Y^α || W_e || W_s), m) = msg.

## 9.4.2 Security Analysis

Theorem 9.1. Suppose the key derivation function KDF is secure and the one-time symmetric-key encryption scheme Π_SE is semantically secure. Assume H1 and H2 are collision-resistant hash functions. If a PPT adversary is able to break IND-sEA-CCA2 security of tABSC scheme with advantage ε in standard model, then there is a PPT algorithm B that can break the DBDH assumption with advantage (ε/2)(1-(q/p)), where q is the number of unsigncryption queries requested by the adversary in the game Game_{tABSC}^{IND-sEA-CCA2}.

Proof. Suppose an adversary A has advantage ε in breaking IND-sEA-CCA2 security of our tABSC scheme. We build an algorithm B that breaks the DBDH assumption with advantage (ε/2)(1-(q/p)). Suppose B is given the DBDH problem instance [Σ, Γ1 := g^a, Γ2 := g^b, Γ3 := g^c, Z], where Σ := [p, G1, G_T, g, e]. Note that B does not know explicitly the values a,b,c ∈ Z_p^*. Now, B interacts with A and responds to all the queries requested by A as follows.

Commit. A sends an encryption attribute set W_e^* ⊂ U_e to B.

Setup Phase. B computes the public parameters as follows.

- Set g1 := Γ1, g2 := Γ2 and Y := e(Γ1, Γ2)^r.
- For each i ∈ U_s, select ẑ_i ← ℤ_p^* and set h_i := g^{ẑ_i}·Γ1^{-1}; i.e., z_i is implicitly defined as z_i := ẑ_i - a.
- For each i ∈ U_e, pick t̂_i, v_i ← ℤ_p^* and set

k_i := { g^{t̂_i}, if i ∈ W_e^*; g^{t̂_i}·Γ1^{-v_i}, if i ∉ W_e^* }

Here t_i is implicitly defined as

t_i := { t̂_i, if i ∈ W_e^*; t̂_i - a v_i, if i ∉ W_e^* }

- Choose η, ν, w₁, w₂ ←ᴿ ℤₚ* and set h₀ := g^η and k₀ := Γ₂ (g^{w₂})^{1/(ν w₁)}.
- Pick ϑ₁, ϑ₂, ϑ₃, τ₂, τ₃ ←ᴿ ℤₚ* and set ξ₁ := Γ₁·g^{ϑ₁}, ξ₂ := (Γ₁)^{τ₂}·g^{ϑ₂}, ξ₃ := (Γ₁)^{τ₃}·g^{ϑ₃}.
- For each i ∈ {0,1,2,…,ℓ}, select πᵢ ←ᴿ ℤₚ* and then set uᵢ := g^{πᵢ}.
- Choose H₁ : {0,1}* → {0,1}^ℓ and H₂ : {0,1}* → ℤₚ* from appropriate families of collision-resistant hash functions.

Finally, ℬ gives the public parameters

𝒫𝒫 := [Σ, g1, g2, Y, {hᵢ}ᵢ∈Uₛ, {kᵢ}ᵢ∈Uₑ, h₀, k₀, ξ₁, ξ₂, ξ₃, u₀, {uᵢ}ᵢ₌₁^ℓ, H₁, H₂, 𝒲, Πₛₑ, KDF, ℳ, U] to 𝒜.

These parameters have the same distribution as in the real construction from 𝒜’ view.

### Query Phase 1. 𝒜 adaptively issues the following queries.

- DecKey Query: The simulation of this query is analogous to the simulation of the Extract query described in the security proof of (t,t)-ABS small universe scheme [16]. That is, when 𝒜 submits [A_d, δ_d] as input for decryption key 𝒟𝒦_{A_d,δ_d}, ℬ responds as in [16].

- SignKey Query: For any request of signing key query on [A_s, δ_s], ℬ chooses η₁, η₂, …, η_{s-1} ←ᴿ ℤₚ* and implicitly defines f_s(x) := a + η₁x + η₂x² + ⋯ + η_{s-1}x^{s-1}. For each i ∈ A_s, it sets S_i := (Γ₂)^{η_i} g^{-η₂^{i}} (Γ₁)^η Π_{j=1}^{i-1} (Γ₂)^{η_j}. The signing key 𝒮𝒦_{A_s,δ_s} := [δ_s, {S_i, i ∈ A_s}] will be given to 𝒜. It is not difficult to see that the signing key simulated by ℬ is a well-formed key in 𝒜’s point of view.

- Unsigncrypt Query: When 𝒜 asks for a Unsigncrypt query on the input [𝒞𝒯, W_v, A_d, δ_d], where 𝒞𝒯 := [W_e, ct := [m, C, {C_i : i ∈ W_e}]], σ := {σ_i : i ∈ W_s}, C_e, γ, δ_s], ℬ checks Equations 9.1 and 9.2, and |A_d ∩ W_e| ≥ δ_d. If any one of these three tests does not hold, it outputs ⊥. Otherwise, if |A_d ∩ W_e*| < δ_d, then ℬ obtains the decryption key 𝒟𝒦_{A_d,δ_d} by performing DecKey query for the tuple [A_d, δ_d] and returns the output of Unsigncrypt(𝒫𝒫, 𝒞𝒯, W_v, 𝒟𝒦_{A_d,δ_d}) to 𝒜. If |A_d ∩ W_e*| ≥ δ_d, ℬ cannot execute the DecKey query and then it responds as follows. First ℬ computes β = H₂(ct || σ || W_e || W_v || δ_s), and checks whether β + γτ₂ + τ₃ = 0 which happens with probability at most 1/p. If so, it aborts (we refer to this event as abort) and outputs a random bit. Else if C := g^α, ℬ can compute Y^α as e(C_e · C^{-(β+γτ₂+τ₃)}, Γ₂^{(β+γτ₂+τ₃)^{-1}}) = Y^α where β = H₂(ct || σ || W_e || W_v || δ_s). Now, ℬ returns msg = SE-Dec(KDF(Y^α || W_e || W_v), m) to 𝒜.

### Challenge. 𝒜 outputs two equal length messages msg₀*, msg₁* ∈ ℳ and a signing attribute set W_s* ⊂ U_s. ℬ selects a random bit μ ∈ {0,1} and signcrypts msg_{μ}* under the challenge encryption attribute set W_e* and signing attribute set W_s* in the following way.
