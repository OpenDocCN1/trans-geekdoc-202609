# 16.2.1.1 Multi View Fusion

In this fusion method the images of the same modality are taken at the same time but from different viewpoints. The aim of this method is to produce corresponding information from different views. For many applications single view images of the scene are adequate. The fusion process depends upon number of views to be fused. Different views will clearly contain more information about the scene, but will require extended data acquisition and processing times. This fusion method provides higher isotropic resolution than in any of the unprocessed individual views [30].

Many image processing techniques give better results from the availability of multiple views such as interpolation, enhancement, segmentation, object recognition and in monitoring and surveillance applications. A multi view fusion example [30] is given in Figure 16.1. Real time 3-D echocardiography permits the acquisition and visualization of the beating heart in 3-D. In this the fusion is based on the wavelet sub bands.
