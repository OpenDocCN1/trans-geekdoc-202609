steganography techniques can find optimal threshold values in blocks of image, it can embed more message bits.

In the future, DICOM medical file format, which includes the file header of the image with patient’s personal data and the pixels’ data, may be combined with the health reports, and other biological signals according to health standards in a new DICOM version.
