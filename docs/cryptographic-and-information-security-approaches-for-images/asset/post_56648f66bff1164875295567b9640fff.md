
## Algorithm 2 The proposed scheme

- Input: An M × N binary secret image S, Original QR₁ message, Original QR₂ message, ..., Original QRₙ message, the threshold parameters (k, n)
- Output: QR code shares SC₁, SC₂, ..., SCₙ

- Step 1: Flip left and right the secret image, then rotate it 90 degrees anticlockwise.
- Step 2: S is divided into 2n regions, denoted as:
  - A[1] = {(i, j) | 1 ≤ i ≤ N, 1 ≤ j ≤ ⌊M/(2n)⌋}
  - A[2] = {(i, j) | 1 ≤ i ≤ N, ⌊M/(2n)⌋ ≤ j ≤ ⌊M/n⌋}
  - ...
  - A[2n] = {(i, j) | 1 ≤ i ≤ N, ⌊(2n−1)M/(2n)⌋ ≤ j ≤ M}
- Step 3: Let Q₁, Q₂, ..., Qₙ denote the regions of QR₁, QR₂, ..., QRₙ with the same size as S in the processed QR codes from the coordinate of (7,7) to the lower-right corner of the QR code, and Qₓ(i, j) indicates the encoded bits corresponding to the QRₓ message. In the encoding process of QR₁ message, QR₂ message, ..., QRₙ message, for each position (i, j) ∈ {(i, j) | 1 ≤ i ≤ N, 1 ≤ j ≤ M}, repeat Steps 4–5.
- Step 4: For the regions of A[x] and A[n + x], randomly select (k−1) processed QR codes from Q₁, Q₂, ..., Qₙ excluding Qₓ, denoted as Qᵢ₁(i, j), Qᵢ₂(i, j), ..., Qᵢₖ₋₁(i, j).
- Step 5: If S(i, j) ≠ Qₓ(i, j) ⊕ Qᵢ₁(i, j) ⊕ Qᵢ₂(i, j) ⊕ ... ⊕ Qᵢₖ₋₁(i, j), set Qₓ(i, j) = ¬Qₓ(i, j).
- Step 6: Output the n QR code shares SC₁, SC₂, ..., SCₙ.

Algorithm 2 takes one secret image S and n original QR code messages as the input and outputs n QR code shares SC₁, SC₂, ..., SCₙ. Each QR code share is a valid QR code which will gain the original message when decoded by a QR code reader. The secret recovery of the proposed scheme can be based on stacking or XOR operation, and the secret image can be revealed in the encoding regions by any k or more QR code shares.

### 20.3.2 Performance Analyses

From the above steps, in Step 1 the data generation when encoded before data mask is stored in an array module from left to right while the pixels of image shown are from top to bottom, so that the secret image preprocessing as Step 1 can be shown correctly while embedded in QR code. Step 2 divides the processed secret image into 2n regions, A[1], A[2], ..., A[2n]. The reason can be described as follows:

- 1. In [18] of our previous work, it can be concluded that the number of codewords which can be modified in the error correction region is equal to or less than that in the data region, so that we can reach the maximum modified codewords number in the data region. The maximum altered region can be a rectangle from the coordinate of (7, j) to the lower-right corner and the value of j can be determined by Equation 20.1 in Section 20.2. The maximum altered region can reach one third of the blue region as shown in Figure 20.1. So, the QR code can be correctly decoded.
- 2. To make sure that k out of n QR code shares can reveal each part of the original secret, we need to divide the original secret into 2n regions so that each QR code takes two pieces of the 2n regions, denoted as A[x] and A[n + x]. In this case, the reconstructed secret image could reveal the original whole secret.
- 3. Due to the characteristics and basic design principles of QR code, the QR code can be correctly decoded when we alter the region of A[x] and A[n + x], where the altered region can be controlled to satisfy the error correction mechanism. The bigger the value of n, the bigger the capacity of embedding a secret will be.

In Step 3, select the regions of QR₁, QR₂, ..., QRₙ with the same size as S from the processed QR codes at the same locations, denoted as Q₁, Q₂, ..., Qₙ, and Qₓ(i, j) indicates the encoded bits corresponding to the QRₓ message. S is divided into 2n regions, so Qₓ has the same divided regions as S. If the regions of both A[x] and A[n + x] need to be altered, we only modify the bits in the two regions of Qₓ while preserving Qy (y = 1, 2, ..., x−1, x+1, ..., n). For the regions of A[x] and A[n + x], in Step 4 randomly select k−1 QR codes from the rest of the processed QR codes, i.e., Q₁, Q₂, ..., Qₙ excluding Qₓ, denoted as Qᵢ₁(i, j), Qᵢ₂(i, j), ..., Qᵢₖ₋₁(i, j). Check whether S(i, j) and the result obtained by XORing Qₓ(i, j), Qᵢ₁(i, j), Qᵢ₂(i, j), ..., Qᵢₖ₋₁(i, j) are the same; if not, the bit of Qₓ(i, j) will be altered in Step 5. For each position (i, j) ∈ {(i, j) | 1 ≤ i ≤ N, 1 ≤ j ≤ M}, repeat Steps 4 and 5, then output the QR code shares in Step 6.

In such a way, the proposed approach can satisfy the error correction mechanism in the QR code, which is applicable to all QR code versions. Although the capacity of embedding a secret is different for different QR code versions, the approach is the same. In our article, we just list some typical examples to test the efficiency of the proposed approach.
