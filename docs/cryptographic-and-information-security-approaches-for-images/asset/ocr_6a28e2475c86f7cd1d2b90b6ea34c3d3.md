# 7.2.1.3.3 Temporal Scalability

The temporal enhancement layer depends on inter prediction technique, which uses a range of block sizes from 16 × 16 to 4 × 4 to predict pixels in the current frame from similar regions in previous frames. These previously coded frames may occur before or after the current frame in display. We encode the ten video sequences with four temporal scalability layers, set the images between the temporal layer 0 to the temporal layer 2 as blank, define motion vectors as zero, and then only decode the temporal layer 3. Experimental results indicate that the temporal enhancement layer of the motion sequence scan causes significant information leakage. However, the temporal enhancement layers of static sequences, such as Bridge-close, Bridge-far, generally have less residual and cause small leakage. Figure 7.5a illustrates the 26th frame of the Hall sequence in which the person's profile can clearly detected.
