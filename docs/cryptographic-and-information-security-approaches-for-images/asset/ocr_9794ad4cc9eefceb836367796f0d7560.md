During Login, the user transmits a set of data for validation to the Authentication Server (AS). The message transfer during each round of the biometric based authentication scheme is shown in Figure 31.3.

When the client and the server both satisfy the validation criteria, then the data transfer will occur. If the client validation does not succeed it is rejected or the client is requested to start the authentication from the beginning of the login phase. As in every initial handshake message, the client sends its identifier, password and along with these the client’s biometric data. In the biometric scheme, there is a biometric linking phase and a biometric verification phase.
