# 5.1 Introduction

Optical cryptography essentially refers to encoding any information using optical means. The encryption and decryption procedure or either of them is accomplished using the principles of optics. Electromagnetic fields offer various degrees of freedom such as the amplitude, phase, wavelength and state of polarization which can be used as parameters to encrypt information.
