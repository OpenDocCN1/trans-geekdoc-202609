# 16.3.1 Features of Digital Watermarking

The main features of digital watermarking techniques are very attractive, since it provides the following main features [36–38]. The watermarking process embeds the secured information into the cover image directly in such a way that it need not requires additional bandwidth [39–40].

+   - Imperceptibility
+   - Robustness
+   - Inseparability
+   - Security

# 16.3.2 Applications of Watermarking

There is a wide range of applications with the digital watermarking process [36, 41]. Some of the applications are listed below:

+   - Security/Defense
+   - Medial communication
+   - Copyright Protection
+   - Broadcasting
+   - Satellite/Space communications
