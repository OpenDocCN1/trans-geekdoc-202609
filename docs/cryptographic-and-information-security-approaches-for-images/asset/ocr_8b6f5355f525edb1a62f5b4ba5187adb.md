# 1.15 Steganographic Protocols

The three basic types of steganographic protocols are:

# 1.15.1 Pure Steganography

We call a steganography framework unadulterated when it doesn`t require earlier trade of some mystery data before sending information.

Definition 1.4: A pure steganography consists of four parts (C,S,D,E), where C is the set of possible covers, S is the set of secret massages with |C| ≥ |S|, E : C × S → C, the embedding function and D : C → S, is the extraction function with the property that D(E(c,s)) = S ∀ c ∈ C and s ∈ S.

# 1.15.2 Private Steganography

We call a steganographic framework private when it requires an earlier trade of information like shared keys. In this case, the sender chooses the cover and installs the mystery knead into the cover utilizing a mystery key. There is a very small chance of secret key can be utilized as a part of embedding process. It is known to receiver, he can use the reverse procedure and recover the hidden message by using his secret key.

Definition 1.5: A private key steganography consists of five parts (C,S,K,E_K,D_K), where C is the set of possible covers, S is the set of secret massages, K is the set of secret keys, E_K : C × S × K → C, the embedding function and D : C × K → S, is the extraction function with the property that D_K(E_K(c,s)) = s ∀ c ∈ C, s ∈ S and k ∈ K.
