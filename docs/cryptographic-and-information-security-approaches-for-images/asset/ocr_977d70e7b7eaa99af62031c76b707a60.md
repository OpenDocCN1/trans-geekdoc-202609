# 15.4.3.2 Watermark Extraction Process

Once watermark embedding is done, the extraction Equation in 15.23 is applied to extract the watermarks from the attacked watermarked image. Initially, the receiver runs the texture analysis phase to find the closeness values of the attacked textured blocks and the extraction process uses these closeness values and the public key alpha (α) to extract the attacked watermark. The pseudo-code of the attacked watermarks extraction process is illustrated in algorithm (5).

As illustrated in Equation 15.23, the extraction procedure is blind. Indeed, the receiver uses only the public key alpha (α) to extract the attacked watermark without any knowledge about the original watermark or the original image. As well, the public key alpha (α) used in the extraction process is not fixed. For each host image, a new key is generated. This increases the robustness of the watermarking process against brute force attacks.
