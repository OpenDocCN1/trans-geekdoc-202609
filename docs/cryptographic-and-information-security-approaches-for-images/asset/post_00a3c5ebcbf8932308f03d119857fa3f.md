Standard Deviation = σ_k = \sqrt{\frac{\sum_{i=0}^{M-1}\sum_{j=0}^{N-1} (I_k(i,j) - μ)^2}{M \times N}},

Skewness = γ_1 = \frac{\sum_{i=0}^{M-1}\sum_{j=0}^{N-1} (I_k(i,j) - μ)^3}{M \times N \times σ^2},

Kurtosis = γ_2 = \frac{\sum_{i=0}^{M-1}\sum_{j=0}^{N-1} (I_k(i,j) - μ)^4}{M \times N \times σ^4} - 3.
