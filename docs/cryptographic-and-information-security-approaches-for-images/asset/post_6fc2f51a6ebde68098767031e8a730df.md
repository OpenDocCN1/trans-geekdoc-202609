## Key Terminology and Definitions

PSNR—Peak Signal to Noise ratio (PSNR) is used for measuring the quality of the watermarked images.

NC—Normalized correlation (NC) is a performance parameter used to measure the similarities and differences between the original and extracted watermark(s) images.

BER—The Bit error rate (BER) is used to determine the ratio of number of incorrectly decoded bits to total number of bits.

SSIM—Structural Similarity Index (SSIM) is one of the recent performance parameters which measure the perceptual quality between watermarked image and original image, or how similar the two images are to each other.

WPSNR—is a performance parameter which measures the quality of the watermarked images through an arbitrary texture masking function called visibility function (NVF).
