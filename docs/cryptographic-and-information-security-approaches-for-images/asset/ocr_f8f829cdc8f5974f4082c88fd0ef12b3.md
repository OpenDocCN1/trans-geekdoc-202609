# 23.8.1.3 Frame-Insertion/Removal/Replication

Frame-insertion (or removal) forgeries involve insertion (or removal) of a set of frames into (or from) a video sequence. In a frame-replication or duplication forgery, a set of frames are copied and inserted at another temporal location within the same video (see Figure 23.20).

Such forgeries are among the most unconvoluted methods of event falsification; by removing a handful of frames from a video sequence, one can easily remove all evidence of occurrence of a particular event. Similarly, by moving a set of frames from one temporal location to another within a video, one can falsify the occurrence of an event during a time period in which it did not actually occur.
