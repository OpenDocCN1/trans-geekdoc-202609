# 17.6 Vital Performance Parameters in Digital Watermarking

Researchers are using various parameters for evaluating the performance of watermarking algorithms/systems. Some of the important parameters are introduced as follows [1,12]:

# 17.6.1 Peak Signal to Noise Ratio (PSNR)

It is a ratio of maximum possible power of a signal to the power of corrupting noise. It is used for measuring the quality of the watermarked images. Ideally PSNR value greater than 28 is considered tolerable for watermarking systems. Therefore, the higher the value of PSNR the more imperceptible it is (similar to original image).

PSNR = 10 log (255)^2 / MSE  (17.3)

The mean squared error (MSE) is defined as MSE = 1/(X × Y) Σ_{k=1}^{L} Σ_{l=1}^{L} (P_{kl} - Q_{kl})^2  (17.4) where X × Y = size of the cover image/watermarked image, P_{kl} = pixel of the original image, and Q_{kl} = pixel of the watermarked image.
