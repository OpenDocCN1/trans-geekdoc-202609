# 31.9.1 The First Flow

B ◁ {(ID_A ⊕ *N_U), SB_A, ID_B, h(PW_A), {B_A ⊕ ID_A}_x}_{+K}, B ⊃ -K / B ◁ ((ID_A ⊕ *N_U), SB_A, ID_B, h(PW_A), {B_A ⊕ ID_A}_x) (T 4) If B is told (ID_A ⊕ *N_U), SB_A, ID_B, h(PW_A), {B_A ⊕ ID_A}_x with the public key +K encrypted than the server holds the corresponding private key -K then the server is considered to have also been told the decrypted contents of that encrypted formula

B ◁ {B_A ⊕ ID_A}_x, B ⊃ x / B ◁ (B_A ⊕ ID_A) If B is told encrypted formula (B_A ⊕ ID_A) with key x the server B possesses, then the server is believed to have been informed the decrypted values of the encrypted equation.

B |≡ φ(ID_A), B ⊃ x / B |≡ φ{B_A ⊕ ID_A}_x (R1, R2) If B considers that the formula ID_A is identifiable and holds the key x then the server B is entitled to believe that the encrypted equation B ◁ {B_A ⊕ ID_A}_x of which B ◁ {B_A ⊕ ID_A}_x is a part which is identifiable. Therefore it is proved that the secret in the smart card is proved by the server.

B |≡ φ{B_A ⊕ ID_A}_x B ⊃ +K / B |≡ φ{ (ID_A ⊕ *N_U), SB_A, ID_B, h(PW_A), {B_A ⊕ ID_A}_x }_{+K} If B considers that the formula {B_A ⊕ ID_A}_x is identifiable and holds the public key +K, then B is entitled to believe that the encrypted equation, {(ID_A ⊕ *N_U), SB_A, ID_B, h(PW_A), {B_A ⊕ ID_A}_x}_{+K}, of which {B_A ⊕ ID_A}_x is a part which is identifiable. Therefore, it is proved that the server B can identify the communication in the first run of the proposed scheme.
