# 11.5.1.1 Histogram Analysis

Visual assessment is the first examining metric in any encryption scheme. The histogram represents the graphical measure of plotting the pixel values at each intensity level typically. For an accurately random cipher image, it is evident that the histogram should be uniformly flat over the entire range of pixel values and should differ entirely from the histogram of the original input image over visual evaluation.
