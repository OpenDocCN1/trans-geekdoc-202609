# 15.4.3 Approach 2: Blind Image Watermarking Using Spatial Pixels

The second image watermarking approach also starts by applying the texture analysis phase to identify the top 10% of highly textured blocks for the watermark embedding process. Then, it uses the closeness value of each of the selected blocks to achieve embedding and extraction procedures. As well, it uses the maximum closeness value to define a public key $\alpha$ for a blind watermarking. The value of the public key is calculated according to Equation 15.21.
