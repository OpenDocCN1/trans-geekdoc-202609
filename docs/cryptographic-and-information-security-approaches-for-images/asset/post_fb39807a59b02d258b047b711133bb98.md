### Definition 4.14: The number of variables in highest order monomial with non-zero coefficients is called the algebraic degree.

### Definition 4.15: The Algebraic Normal Form (ANF) is an n-variables Boolean function which can be written as follows:
g(x) = b0 ⊕ b0 x0 ⊕ ... ⊕ b01 x0 x1 ⊕ b012...n-1 x0 x1 x2 ... xn-1, (4.11)

where the coefficients $b \in \mathbb{Z}_2^n$ form the elements of the truth table of the ANF of $g(x)$. Note that each product term in the ANF is calculated by the multiplication of each of the components of that term.

### Definition 4.16: A Boolean function is said to be homogeneous if its algebraic normal form only contains terms of the same degree.

### Definition 4.17: An $n$ variable Boolean function $g(x)$, which contains all $n$ variables in its ANF is called a nondegenerate function. Conversely, if $g(x)$ does not contain every variable in its ANF representation then the function is degenerate.

### Definition 4.18: The algebraic degree of a Boolean function $g(x)$, denoted by $\deg(g)$, is defined to be the number of variables in the largest product term of the function's ANF having a non-zero coefficient. The algebraic degree of a Boolean function is a good indicator of the function's algebraic complexity. The higher the degree of a function, the greater is its algebraic complexity.

## 4.3 The Walsh Transform
In this section, we introduce one of the most important tools in cryptography. Namely, the Walsh transform which is the characteristic 2 case of the discrete Fourier transform. We define the Walsh transform of a Boolean function as follows [2]:

### Definition 4.21: [2] The Walsh transform of a function $g$ on $\mathbb{Z}_2^n$ is a map $\Omega: \mathbb{Z}_2^n \to \mathbb{R}$ defined by
$$\Omega(g)(u)=\sum_{x\in\mathbb{Z}_2^n} g(x)(-1)^{\langle u,x\rangle}, \qquad (4.13)$$
where $\langle u,x\rangle$ is the canonical scalar product.

### Lemma 4.22: [2, Lemma 3.2] If $u \in \mathbb{Z}_2^n$, we have
$$\sum_{x\in\mathbb{Z}_2^n}(-1)^{\langle u,x\rangle}=\begin{cases}2^n, & \text{if } u=0\\0, & \text{else.}\end{cases} \qquad (4.14)$$

### Theorem 4.23: [2, Theorem 3.3] The Walsh transform $\Omega: \mathbb{Z}_2^n \to \mathbb{R}$ is bijective and the inversion is given by:
$$\Omega^{-1}=\Omega/2^n. \qquad (4.15)$$

### Definition 4.24: The Sylvester-Hadamard matrix (or Walsh-Hadamard matrix) of order 2^n, denoted by H_n is generated by the recursive relation
H_n = [ H_{n-1}  H_{n-1} ; H_{n-1}  -H_{n-1} ] = H1 ⊗ H_{n-1}   (4.16)
for n=1,2,... and H0 = (1).

### Lemma 4.25: [4] If the Boolean function can be obtained from h by an affine transformation of the input that is h = g(Av ⊕ b), with A an invertible matrix and b ∈ Z2^n, then the Walsh transform of g and h are related by
Ω(h)(u) = ± Ω(g)(u A^{-1}).   (4.17)

### Corollary 4.26: [2, Corollary 3.10] In particular Ω(ĝ)(u) is always even and we have
-2^n ≤ Ω(ĝ)(u) ≤ 2^n.   (4.18)

### Definition 4.27: Let g and h be any Boolean functions on Z2^n. The Convolution of g and h is defined by
(g * h)(x) = Σ_{y∈Z2^n} g(y) h(x ⊕ y).   (4.19)

### Corollary 4.28: (Parseval's equation) For any Boolean function g in n variables, the following equations hold
Σ_{u∈Z2^n} (Ω(ĝ))(u)^2 = 2^{2n}.   (4.20)

### Lemma 4.29
Σ_{u∈Z2^n} Ω(ĝ)(u) Ω(ĝ)(u ⊕ v) = { 2^{2n} if v = 0, 0 if v ≠ 0. }

### Theorem 4.30: A Boolean function on ℤ₂ⁿ satisfies
Ω̂(r)(t) = Ω̂(g)²(t),  (4.21)
for all t ∈ ℤ₂ⁿ.

### Definition 4.31: The spectral radius of a Boolean function g : ℤ₂ⁿ → ℤ₂ is defined by
R_g = max{|Ω̂(g)(u)| : u ∈ ℤ₂ⁿ}  (4.22)

## 4.4 Correlation Immune Boolean Functions
Correlation immune functions were introduced by Siegenthaler [5] in order to protect some shift register based on stream ciphers against correlation attacks.

### Definition 4.35: [*5*] A Boolean function g in n variables is said to be correlation immune of order k, 1 ≤ k ≤ n, if any fixed subset of k variables the probability that, given the value of g(x), the k variables have any fixed set of values, is always 2^{-k}, no matter what the choice of the fixed set of k values is. In other words, g is correlation immune of order k if its values are statistically independent of any subset of input variables.

We can formulate the definition of correlation immunity to an equivalent information theory condition. If the chosen subset of variables is (x(i₁),x(i₂),...,x(iₖ)) then the above definition of correlation immunity of order k is equivalent to the information theory condition that the information obtained about the values of (x(i₁),x(i₂),...,x(iₖ)) given is zero. Now we collect some useful equivalent conditions to correlation immunity of order 1 given in [4,6].

### Lemma 4.36: [*4*] A function g in n variables is correlation immune of order k, 1 ≤ k ≤ n, if and only if all of the Walsh transforms
$$\Omega(\hat{g})(u) = \sum_{x \in \mathbb{Z}_2^n} (-1)^{g(x) \oplus \langle u,x \rangle}, \quad 0 \le \mathbf{wt}(u) \le k, \tag{4.25}$$
are equal to zero.

$$\sum_{u \in \mathbb{Z}_2^n} c(g;\alpha_u)^2 = 1. \tag{4.26}$$
