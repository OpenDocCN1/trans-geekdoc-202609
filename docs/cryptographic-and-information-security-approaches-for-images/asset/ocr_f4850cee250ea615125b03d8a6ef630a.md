where the coefficients $b \in \mathbb{Z}_2^n$ form the elements of the truth table of the ANF of $g(x)$. Note that each product term in the ANF is calculated by the multiplication of each of the components of that term.

**Definition 4.16:** *A Boolean function is said to be homogeneous if its algebraic normal form only contains terms of the same degree.*

**Definition 4.17:** *An $n$ variable Boolean function $g(x)$, which contains all $n$ variables in its ANF is called a nondegenerate function. Conversely, if $g(x)$ does not contain every variable in its ANF representation then the function is degenerate.*

**Definition 4.18:** *The algebraic degree of a Boolean function $g(x)$, denoted by $\deg(g)$, is defined to be the number of variables in the largest product term of the function's ANF having a non-zero coefficient. The algebraic degree of a Boolean function is a good indicator of the function's algebraic complexity. The higher the degree of a function, the greater is its algebraic complexity.*
