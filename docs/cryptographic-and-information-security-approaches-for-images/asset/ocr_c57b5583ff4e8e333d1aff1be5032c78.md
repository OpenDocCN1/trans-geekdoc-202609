# 16.4.1.1.2 Discrete Cosine Transform

Similarly, DCT (Discrete Cosine Transform) is another important transform domain technique (shown in Figure 16.13). It is mainly applicable for image compression, image watermarking and image fusion [5, 12]. The image is transformed into DCT domain using the following equations:

DCT transform:

F(k,l)=α(k)α(l)=∑_{m=0}^{N-1}∑_{n=0}^{N-1}f(m,n)cos[(2m+1)πk/2N]cos[(2n+1)πl/2N]

Inverse DCT transform:

f(m,n)=∑_{m=0}^{N-1}∑_{n=0}^{N-1}α(k)α(l)F(k,l)cos[(2m+1)πk/2N]cos[(2n+1)πl/2N] (4.6)
