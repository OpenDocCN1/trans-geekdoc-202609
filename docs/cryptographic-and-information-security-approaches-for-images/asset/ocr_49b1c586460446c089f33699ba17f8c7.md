```

Î(x,y) = I(x-1,y) + (I(x,y-1) - I(x-1,y-1))/2
Î(x,y) = I(x,y-1) + (I(x-1,y) - I(x-1,y-1))/2
Î(x,y) = (I(x,y-1) - I(x-1,y))/2
```

In the coding, the predicted error is the I(x,y) - Î(x,y) which is coded with either Huffman coding or arithmetic coding. This predictive way is very similar with the intra-prediction in video coding which will be introduced in the following. The data hiding is performed by modifying the predictive error or histogram shifting in Sections 14.3 and 14.4.
