**Definition 1:** A cryptosystem is a quintuplets (M,C,K,E,D) in which M is called the plaintext space; C is a called the ciphertext space; K is called the key space; E is an encryption rules; D is a decryption rules. For each K ∈ K, there is a function e_K ∈ E and a corresponding function d_K ∈ D such that for any plaintext message x ∈ P, d_K(e_K(x)) = x. Notice that this means d_K is the inverse of the function e_K.
