# 31.9.3 The Third Flow

```
B ◁ { {h(K_S),K_S,h(PW_A),(N_S ⊕ ID_B),CID_A,} 
      { (h(PW_A) ⊕ B_A),ID_B } }_sign , N_P }_N_S , B ⊃ N_S
---------------------------------------------------------
B ◁ ( { h(K_S),K_S,h(PW_A),(N_S ⊕ ID_B),CID_A, }
      { (h(PW_A) ⊕ B_A),ID_B }_sign , N_P )
```

If B is told the formula ({h(K_S),K_S,h(PW_A),(N_S ⊕ ID_B),CID_A,(h(PW_A) ⊕ B_A), ID_B}_sign , N_P) encrypted with the key N_S that B possesses, and then B is believed to have been informed the decrypted values of the encrypted equation.

```
B ≡ φ(signed message), B ⊃ N_S
----------------------------------- (R1,R2)
B ≡ φ { {h(K_S),K_S,h(PW_A),(N_S ⊕ ID_B),CID_A,}
        { (h(PW_A) ⊕ B_A),ID_B } }_sign , N_P }_N_S
```

Signed message denotes {h(K_S),K_S,h(PW_A),(N_S ⊕ ID_B),CID_A,(h(PW_A) ⊕ B_A), ID_B}_sign . If B considers that ID_B is identifiable then the formula of which ID_B is a part is identifiable. Therefore, it is proven that B can identify the third flow of the proposed scheme.

```
B ≡ φ((h(K_S),K_S,h(PW_A),(N_S ⊕ ID_B),CID_A,
       (h(PW_A) ⊕ B_A),ID_B)_sign , N_P), B ≡ #(N_S), B ⊃ N_S
--------------------------------------------------------------- (R1,R2)
A ≡ #{ {h(K_S),K_S,h(PW_A),(N_S ⊕ ID_B),CID_A,
       (h(PW_A) ⊕ B_A),ID_B }_sign , N_P }_N_S
```

If B considers that the formula ID_B is identifiable and B has the key N_S and considers that it is new, then B considers that the encrypted equation {{h(K_S),K_S,h(PW_A),(N_S ⊕ ID_B),CID_A,(h(PW_A) ⊕ B_A),ID_B}_sign , N_P}_N_S, of which ID_B is a part is new. Therefore, B can recognize the third flow message of the proposed scheme as new.
