# 9.2.4 Hardness Assumptions

Decision Bilinear Diffie-Hellman Assumption The DBDH problem is defined as follows: given Σ, Γ₁ := gᵃ ∈ 𝔾, Γ₂ := gᵇ ∈ 𝔾, Γ₃ := gᶜ ∈ 𝔾 for unknown a, b, c ∈ ℤₚ* and Z ∈ 𝔾_T, to decide whether Z = e(g, g)^{abc} or Z is a random element of 𝔾_T. We say that the DBDH assumption holds in Σ if the advantage Adv_A^{DBDH} := |Prob[1 ← A(Σ, Γ₁, Γ₂, Γ₃, e(g, g)^{abc})] − Prob[1 ← A(Σ, Γ₁, Γ₂, Γ₃, Z)]| of every PPT algorithm A in solving DBDH problem is negligible.

Computational Diffie-Hellman Assumption The CDH is defined as follows: given Σ, Γ₁ := gᵃ ∈ 𝔾, Γ₂ := gᵇ ∈ 𝔾 for unknown a, b ∈ ℤₚ*, to compute g^{ab} ∈ 𝔾. We say that the CDH assumption holds in 𝔾 if the advantage Adv_A^{CDH} := Prob[g^{ab} ← A(Σ, Γ₁, Γ₂)] of every PPT algorithm A in solving CDH problem is negligible.
