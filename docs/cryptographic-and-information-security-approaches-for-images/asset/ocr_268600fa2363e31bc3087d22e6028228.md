DecKeyGen(𝒫𝒫, ℳ𝒦, A_d, δ_d) This algorithm takes as input 𝒫𝒫, ℳ𝒦, a set A_d ⊂ U_e of decryption attributes and a threshold δ_d, and computes the decryption key 𝒟𝒦_{A_d, δ_d} := [δ_d, {D_i, i ∈ A_d}] as follows.

+   - Let f_d be a random polynomial of degree δ_d − 1 such that f_d(0) = a. Compute D_i := g₂^{f_d(i)+t_i} k₀^{-t_i} for each i ∈ A_d.

SignKeyGen(𝒫𝒫, ℳ𝒦, A_s, δ_s) This algorithm takes as input 𝒫𝒫, ℳ𝒦, a set A_s ⊂ U_s of signing attributes and a threshold δ_s, and computes the signing key 𝒮𝒦_{A_s, δ_s} := [δ_s, {S_i, i ∈ A_s}] as follows.

+   - Let f_s be a random polynomial of degree δ_s − 1 such that f_s(0) = a. Compute S_i := g₂^{f_s(i)+z_i} h₀^{-z_i} for each i ∈ A_s.

Signcrypt(𝒫𝒫, 𝒮𝒦_{A_s, δ_s}, W_e, W_s, msg) This algorithm takes as input 𝒫𝒫, an encryption attribute set W_e ⊂ U_e, a signing attribute set W_s ⊂ A_s with |W_s| ≥ δ_s, the signing key 𝒮𝒦_{A_s, δ_s} and a message msg ∈ ℳ. Then it carries out the following steps.

+   - Sample α, γ ← ℤ_p^* and set m := SE-Enc(KDF(Y^α || W_e || W_s), msg)
+   - C := g^α, C_i := k_i^α, ∀i ∈ W_e
+   - σ_i := S_i · 𝒲(θ)^α, ∀i ∈ W_s, where θ = H₁(m || W_e || W_s || δ_s)
+   - ct := [m, C, {C_i : i ∈ W_e}] and σ := {σ_i : i ∈ W_s}
+   - C_e := (ξ₁^β ξ₂^γ ξ₃)^α, where β = H₂(ct || σ || W_e || W_s || δ_s)
+   - The ciphertext is 𝒞𝒯 := [W_e, ct, σ, C_e, γ, δ_s].

Unsigncrypt(𝒫𝒫, 𝒞𝒯, W_v, 𝒟𝒦_{A_d, δ_d}) Given 𝒫𝒫, 𝒞𝒯, a verification attribute set W_v ⊂ U_s and 𝒟𝒦_{A_d, δ_d}, this algorithm proceeds as follows.
