+   where:
+   - Z is the number of the rules
+   - S_j is the center of similarity value in the jth rule
+   - μ_prem^j(L) is defined in Equation 22.14 [1,54].

μ_prem^j(L) = μ_R^j(L_ΔR) μ_G^j(L_ΔG) μ_B^j(L_ΔB) (22.14)

In the last stage, the local similarity values of neighboring pixels are obtained by Equation 22.12. The coordinates mean similarity values of the neighboring pixels are used to replace the LSBs of the message.
