Calculations for metrics like accuracy, precision, and recall are made using the categorization and confusion report. The formulas for calculating recall, precision, and accuracy are presented below,

+   1. Precision = True Positive / (True Positive + False Positive)
+   2. Accuracy = (True Positive + True Negative) / (True Positive + True Negative + False Positive + False Negative)
+   3. F1 score = 2 * (Precision*Recall) / (Precision + Recall)
+   4. Recall = True Positive / (True Positive + False Negative) (Aljumah, 2021)
