# IMPLEMENTATION

The implementation process for the blockchain-based messaging system with double AES encryption involved several important steps. To begin with, we conducted initial tests using online websites and tools to assess the viability of double encryption with different types of data, including audio, images, and text. Through these tests, we discovered that double encryption and decryption did not work effectively for audio and image files.
