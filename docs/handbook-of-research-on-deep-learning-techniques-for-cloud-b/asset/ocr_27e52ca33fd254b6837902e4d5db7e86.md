# Disease Monitoring

The LOFAR-agro Project is the best example for crop or plant monitoring. This project protects the potato crop by monitoring different climate conditions such as temperature and humidity through WSN (Sreekantha, 2017). The proposed system protects the crop by analysing the collected data from fungal diseases.

# Environmental Condition Monitoring

An environmental condition monitoring system is proposed that measures the spatial sampling of humidity sensors using WSN. To determine the behaviour of 2D correlation, a historical database is being used in the proposed system ICOS, 2020). Moreover, another environmental condition monitoring system is proposed that integrates forecasting and drought monitoring using IoT.
