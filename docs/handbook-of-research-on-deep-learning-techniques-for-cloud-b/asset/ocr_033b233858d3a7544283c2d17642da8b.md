Given, X= {x₁, … xₙ} ⊂ R^p, the EB partitions X into c fuzzy subsets by reducing the following objective function

J(U,V)=∑_{i=1}^c ∑_{k=1}^n U_i^m ||X - V_i||²  (1)

Where c is the number of clusters, which is favored in this study as a predetermined significance level, and n denotes the number of data points, A well-known alternating iterative algorithm minimizes the function J_m.

Now consider the proposed EB formula.

J(U,V)=∑_{i=1}^c ∑_{k=1}^n U_i^m ||Ø(X)-Ø(V_i)||²  (2)

||Ø(X_k)-Ø(V_i)||² = K(X_k,X_k)+K(V_i,V_i)-2K(X_k,V_i)  (3)
