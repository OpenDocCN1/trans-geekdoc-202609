# CONCLUSION

The YOLOv5s model is used as the basis for the proposed network model for tomato detection at different scales and under different environmental conditions. To improve the YOLOv5s model’s ability to detect small dense tomatoes, the coordinate attention mechanism has been introduced. Secondly, the bi-directional feature pyramid network is added to the neck part of the YOLOv5s model. The proposed model, which outperformed the original YOLOv5s model with good visualisation outcomes, provided an accuracy of 87.4%.
