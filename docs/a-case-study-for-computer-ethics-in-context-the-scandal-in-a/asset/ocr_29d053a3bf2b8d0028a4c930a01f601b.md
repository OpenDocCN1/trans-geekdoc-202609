Sharon’s use of an AI tool to generate some discussion text mostly falls within the same frame except that it’s a little more complicated because of the formality associated. Journals, book publishers, conference chairs, schools… all of these have come increasingly down on the use of generative text and images within publications and assignments. Some GPT text is used within **this** book for example, but it is always clearly identified and provided as part of a commentary on generative AI. There is no intent **or attempt** to deceive.
