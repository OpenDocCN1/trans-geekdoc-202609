

## 情境中的计算机伦理案例研究

在英国，拒绝信息自由法案（FOIA）请求的理由十分广泛。你可以直接以处理起来在时间和金钱上成本过高为由，整体拒绝一项请求（占被拒绝请求的27%），或者以该请求属于纠缠骚扰或同一人重复提交为由予以拒绝（占4%）。当然，外部人士若想就第一项理由质疑某机构的回应，会发现无论从哪个方向都难以举证；而“纠缠骚扰”则取决于“合理性”、“正当性”或“语气”等主观标准。² 在没有法律挑战的情况下，对这些标准的裁决权掌握在信息持有方手中。

如果这还不够，通用数据保护条例（GDPR）中的条款还可以对信息持有方提供全面保护，使其免于在特定类别下披露某些信息。有一些特定的豁免条款可以采用，这些条款占被拒绝的FOIA请求的比例高达惊人的69%。其中一些包括：计划未来公开的信息（大学里几乎任何东西都适用）；研究信息（同样适用）；与安全机构和国家安全相关的信息；与调查相关且对执法不利的信息；公共政策及公共事务的有效开展；与王室家族的通信；个人信息；保密信息；商业秘密；等等。

请注意，所有这些豁免条款都附带有关于何时可以公平采用的指导说明，其中一些豁免是因为披露事项受其他法律管辖（如数据访问请求或环境影响请求）。但可以肯定地说，想要从FOIA请求中隐藏信息的当事方有大量途径可供探索。这些豁免条款因国家而异，但立法在平衡公众知情权与组织有效内部治理权之间承担着艰难的任务。一条错误的数据，在缺乏任何上下文背景的情况下，可能造成巨大的损害。虽然并非依据《信息自由法》获得，但我们可以回顾“气候门”争议（Leiserowitz et al., 2013），当时东英吉利大学气候研究部门泄露的电子邮件和文件被歪曲和曲解，用以支持气候变化否定论者的议程（Garud et al., 2014）。一个随口的玩笑，一次不经意的名字使用，也许就足以点燃阴谋论的火焰。

当出现此类令人难堪的披露时，许多官僚的第一反应就是通过关闭所有当前可访问记录的访问权限来遏制事态。很可能需要进行一次审计，以了解情况究竟会变得多糟，而与此同时，随着成千上万的利益相关方开始仔细翻阅所有原始记录，公众披露就像一颗滴答作响的定时炸弹，这无疑让局面雪上加霜。在许多情况下，公共机构负有透明度的义务，而且除了事后回顾，永远无法预先看出哪种透明度会在丑闻中引发问题。也许在一个案例中是某次会议的日期；在另一个案例中是请假成员的名单；还有可能是在另一个案例中，某个特定问题被讨论过但从未跟进。信息安全的问题在于，数据会以意想不到的方式和意想不到的组合转化为信息。我们之前已经讨论过这一点，例如，无内容的元数据如何通过与其他元数据结合评估，从而提供它所缺失的内容。如果有人给医生打了电话，然后给伴侣打，接着给堕胎诊所打，我们不需要通话记录就能知道这些通话的主题。

这里的欧洲森林委员会（EFC）的官僚们采取了最初看起来明显的自保行为——在损害程度得到评估之前，关闭对公共文件的访问。这并不一定意味着掩盖真相，而是意味着，最佳的公开回应应当基于获得比公众自身更多的关于正在浮现的丑闻的信息。这使得与披露的直接损害保持一定距离，以便能构建出一个更冷静、更沉稳的回应。它允许保护组织的声誉，正如我们已经讨论过的，这是组织的首要任务之一。短期内禁止访问文件，在行政层面等同于给开放性伤口包扎绷带。

记住约翰·吉尔摩曾说过的：“互联网将审查视为破坏并对其进行攻击。”互联网处理审查的机制并不稳健可靠，但在特定情境下却会令人非常难堪。因此，明智的Twitter用户会使用自动删除功能，清除超过一定期限的推文。没有人知道未来社交媒体权威人士会认为何种行为是不可饶恕的冒犯，也没有人知道这些内容何时会意外地在网络讨论中大放异彩（或成为众矢之的）。完整的Reddit发帖历史是一种负担。公开的Facebook订阅源是一场灾难。这里的情况也是如此——一个著名的公共机构肯定会发现其内容被备份在互联网档案馆中，而且那里是某种特定类型的网民会首先查看的地方。在试图为自己的数据伤口包扎的过程中，这个情境中的EFC恰好将聚光灯引向了其伤口最脆弱的部位。斯特莱桑效应再次显现，对那些试图根据当下的紧急情况来修改过去的人予以严厉斥责。

再次强调，这里必须指出，（可能只是暂时性地）关闭受感染文件的访问权限这一行为本身，并非渎职或掩盖真相的证据。这可能是审计所发生事件的合理且必要的第一步。新闻和社交媒体受新奇性和内容病毒式传播的驱动。成熟、理智的反思不会得到转发。脱口而出的“即兴锐评”才是让自己获得关注和转发的方式。而且在这方面，如果你迎合自己派系的利益并与流行的不满情绪挂钩，效果会最好。见解的肤浅并不会限制转发的速度——事实上，它很可能是加速器，因为它会激发支持或驳斥性的引用推文。这样的环境不利于社交媒体经理去应对一场社交媒体风暴，并提供强有力、有意义的回应。尤其不利于冷静、审慎的决策——不得不不断与边缘言论交锋。向猜测浇点冷水——在火种点燃之前将其移除——是完全合理的做法。但问题在于，社交媒体之火燃烧得如此炽热，足以将冷水分解成氢气和氧气，而结果是你并没有移除火种，反而只是用一种效率更高的燃料替代了它。
