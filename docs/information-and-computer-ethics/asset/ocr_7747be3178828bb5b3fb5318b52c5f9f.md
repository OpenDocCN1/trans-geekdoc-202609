The software autonomous agent is known to reconnoiter the target, identify, and differentiate the susceptibilities and strategizes a method to exploit these susceptibilities. The important stages of the cyber-attack are as follows:

+   - **Reconnaissance:** Reconnaissance involves the process of researching about the objects, identification of the objects and selection of the targets.

+   - **Weaponization:** The process of the weaponization involves the combination of the different malware to the researched targets.

+   - **Delivery:** The process of delivering or sending the malware or viruses to the identified and selected targets by the emails, messages, pen drives, different attachments, and other routes.

+   - **Exploitation:** The delivered viruses or malware start becoming sensitive and execute the harmful set of operations that are programmed in the malware.

+   - **Installation:** The process of exploitation becomes effective with the successful installation of the harmful malware which would give them access to the data of the target continuously.

+   - **Command and Control:** The installed malware not just provides the existing information, but also gives access to the users which would enable outsiders to establish a command on the system and control the targets activities.

+   - **Actions on objective:** The attackers would plan and execute the attack with a set of objectives which are successfully achieved with the attack. These objectives would vary according to the requirements of the attackers, and they could be things like destruct the data, access the data or replace the data, gain control over the network or corrupt a software and any more.
