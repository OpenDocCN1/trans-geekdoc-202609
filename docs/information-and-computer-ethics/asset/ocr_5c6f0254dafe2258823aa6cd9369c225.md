# 7.5.4. Command and Control

The process of cyberwarfare or cyber-attack begins with prior research, identification of the target, infiltration, and followed by the process of acquiring command and control on the data and information of the target. There are a lot of factors that determine and are instrumental in acquiring the command and control over the cyberwarfare such as the identified potential vulnerabilities and the design of the programs accordingly. There are a set of preprogrammed instructions in the malware which play an important role in attacking the target and gaining access over the target database.

The process of acquiring command and control over the target database is a major security breach as it can cause serious privacy and security threats. If the target is the army database or any financial database, then the loss that is caused by the attack of this malware cannot be measured.

These attacks must be expected, and the security settings of the software must be updated in order to protect from these malicious attacks, and there are a set of tactics, techniques, and procedures that are used for the intelligent autonomous agents to protect them from the malicious cyber-attacks.
