### 8.3.5. Malicious Codes

Malicious code is code that causes damage to a computer or system. This code attacks several types of computer programs created with the purpose of causing data loss or damage. The three main types of malicious code attacks are viruses, Trojan horses, and worms.

A virus always attacks a system. It is malicious software attached to another program to execute an unwanted function on a workstation. An example is a program attached to command.com (the primary interpreter for Windows systems) that deletes certain files and infects other versions of command.com that it can find.

A Trojan horse is a program in a computer system that may change system settings. A Trojan horse virus can even attack a system, so antivirus protection is needed against these attacks.

Viruses can even slow down a system, making it very difficult for users to work. They can damage files so they cannot be opened. They can also cause various other problems, such as difficulty installing applications or game applications. Therefore, it is necessary to install a good antivirus on a computer system and update it whenever required.

Computer worms can also attack systems and cause file trouble. Upon exploitation of a vulnerability, the worm copies its code from an infected host to a compromised system to restart the cycle.

Viruses can affect files or anything related to personal data, which can be lost easily. Once a virus enters a system, everything stored can be affected. The infection can then transfer itself to files and code on other computers through magnetic disks, other memory storage devices, computer networks, or online systems. Replicating viruses often multiply until they destroy data or render other program codes meaningless.

A virus can cause a system to restart repeatedly, making it difficult for users to concentrate on their work. Users will not be focused if they encounter system trouble. A virus can crash a system very quickly, and it is even more dangerous if the system is not scanned regularly.

Once a virus appears in a system, it becomes very difficult for users to work or store data. Viruses can appear at any time and are unsafe for stored files. Therefore, it is necessary to scan for viruses; otherwise, users face serious consequences, including system crashes and organizations ceasing operations for certain periods. Antivirus software helps systems run smoothly, so all major businesses and organizations have antivirus installed on every individual’s system.

Logic bombs are also sometimes planted. There is clearly a lot of antivirus software on the market now that helps deal with this ever-growing problem.
