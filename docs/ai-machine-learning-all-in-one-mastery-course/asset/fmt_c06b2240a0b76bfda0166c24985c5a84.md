## 1. What Are Recurrent Neural Networks (RNNs)?

### 1.1. Definition and Purpose

Recurrent Neural Networks (`RNNs`) are a type of neural network architecture specifically designed for processing sequences of data. Unlike traditional feedforward neural networks, `RNNs` have connections that loop back on themselves, allowing them to maintain a “memory” of previous inputs in the sequence.

Key Objectives of `RNNs`:
● Sequential Data Processing: Handle data where current inputs are dependent on previous ones, such as time series or natural language.
● Contextual Understanding: Learn patterns over time and remember information from earlier in the sequence.
● Prediction and Classification: Make predictions or classifications based on both current and historical information.

### 1.2. Historical Background

`RNNs` were first introduced in the 1980s to address the need for models that could handle sequential data. Over time, several advances have improved their capabilities:
● 1980s: The concept of `RNNs` was introduced with the goal of creating networks that could remember past information.
● 1997: Long Short-Term Memory (`LSTM`) networks were proposed by Sepp Hochreiter and Jürgen Schmidhuber to overcome `RNN` limitations like vanishing gradients.
● 2014: Gated Recurrent Units (`GRUs`) were introduced by Kyunghyun Cho and colleagues as a simpler alternative to `LSTM`s with comparable performance.

### 2.2. The Recurrent Process in RNNs

In `RNNs`, the recurrent process involves the following steps:
1. Forward Pass: The input data is processed, and the hidden state is updated.
2. Recurrent Connection: The hidden state from the previous time step is passed to the next time step.
3. Output Computation: The final hidden state is used to generate predictions.

Mathematical Representation:
For a given input sequence `{x1,x2,…,xT}\{x\_1, x\_2, \ldots, x\_T\}{x1​,x2​,…,xT​}`:
`h_t = tanh(W_h h_{t-1} + W_x x_t + b)` `y_t = W_y h_t + b_y`

Where:
● `h_t` is the hidden state at time `t`.
● `x_t` is the input at time `t`.
● `W_h`, `W_x`, `W_y` are weight matrices.
● `b` and `b_y` are biases.

## 3. Types of Recurrent Neural Networks

### 3.1. Basic RNN

The simplest form of `RNN`, which processes sequences using a single recurrent layer.

Example Code:
```python
model = tf.keras.Sequential([
    tf.keras.layers.SimpleRNN(50, activation='tanh', input_shape=(10, 1)),
    tf.keras.layers.Dense(1, activation='sigmoid')
])
```

### 3.2. Long Short-Term Memory (LSTM)

`LSTM`s address the vanishing gradient problem by using gates to control the flow of information.

Components of `LSTM`:
● Forget Gate: Decides what information to discard.
● Input Gate: Decides what new information to store.
● Output Gate: Decides what information to output.

Example Code:
```python
model = tf.keras.Sequential([
    tf.keras.layers.LSTM(50, activation='tanh', input_shape=(10, 1)),
    tf.keras.layers.Dense(1, activation='sigmoid')
])
```

### 3.3. Gated Recurrent Unit (GRU)

`GRU`s are similar to `LSTM`s but with a simplified architecture, combining the forget and input gates.

Components of `GRU`:
● Update Gate: Controls the update of the hidden state.
● Reset Gate: Controls the influence of the previous state.

Example Code:
```python
model = tf.keras.Sequential([
    tf.keras.layers.GRU(50, activation='tanh', input_shape=(10, 1)),
    tf.keras.layers.Dense(1, activation='sigmoid')
])
```

### 3.4. Bidirectional RNNs

Bidirectional `RNNs` process sequences in both forward and backward directions.

Example Code:
```python
model = tf.keras.Sequential([
    tf.keras.layers.Bidirectional(tf.keras.layers.LSTM(50, activation='tanh', return_sequences=True), input_shape=(10, 1)),
    tf.keras.layers.Dense(1, activation='sigmoid')
])
```
