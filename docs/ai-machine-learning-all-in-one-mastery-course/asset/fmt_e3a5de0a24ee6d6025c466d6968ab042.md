
- **Confidence**: The likelihood that the consequent is bought given that the antecedent is bought.

`Confidence(A→B) = Count(A and B) / Count(A)`

- **Lift**: The ratio of the observed support to the expected support if A and B were independent.

`Lift(A→B) = Confidence(A→B) / Support(B)`

## 1.2. Historical Background

Association Rule Learning emerged from research in the late 20th century, primarily in the field of market basket analysis. The `Apriori` algorithm, introduced by Rakesh Agrawal and Ramakrishnan Srikant in 1994, was one of the first algorithms developed for this purpose. Later advancements introduced other methods like `Eclat`, which improved efficiency for finding frequent itemsets.

## 2. The Apriori Algorithm

### 2.1. Overview of Apriori

The `Apriori` Algorithm is one of the most well-known algorithms for finding frequent itemsets and generating association rules. It uses a breadth-first search strategy to discover frequent itemsets and prune the search space.

#### Algorithm Steps

1. Generate Candidate Itemsets: Start with individual items and generate candidate itemsets for larger combinations.
2. Count Itemsets: Count the occurrences of each candidate itemset in the transactions.
3. Prune: Eliminate itemsets that do not meet the minimum support threshold.
4. Repeat: Generate new candidate itemsets by combining frequent itemsets and repeat the process until no more frequent itemsets can be found.

Example:

Consider a dataset of transactions:

| Transaction | Items |
|---|---|
| 1 | Bread, Milk |
| 2 | Bread, Diaper |
| 3 | Milk, Diaper |
| 4 | Bread, Milk, Diaper |

`Apriori` Algorithm in Action:

1. Find Frequent Itemsets:
   - Generate itemsets such as `{Bread}`, `{Milk}`, `{Diaper}`, and their combinations.
   - Calculate support for each itemset.
2. Generate Rules:
   - Extract rules like `{Bread} → {Milk}` based on support and confidence.

#### Python Implementation

Here is a simple implementation of the `Apriori` algorithm using the `mlxtend` library:

```python
from mlxtend.frequent_patterns import apriori, association_rules
import pandas as pd

# Sample Transaction Data
data = {'Transaction': [1, 2, 3, 4],
'Items': [['Bread', 'Milk'], ['Bread', 'Diaper'], ['Milk', 'Diaper'], ['Bread', 'Milk', 'Diaper']]}

# Convert data to one-hot encoded DataFrame
df = pd.get_dummies(pd.DataFrame(data).set_index('Transaction')['Items'].apply(pd.Series).stack()).groupby(level=0).sum()

# Apply Apriori Algorithm
frequent_itemsets = apriori(df, min_support=0.5, use_colnames=True)
rules = association_rules(frequent_itemsets, metric="confidence", min_threshold=0.7)

print(frequent_itemsets)
print(rules)
```

Code Explanation:
- **Data Preparation**: Convert transactions into a one-hot encoded matrix.
- **Apply Apriori**: Extract frequent itemsets with a minimum support threshold.
- **Generate Rules**: Create rules with confidence above the specified threshold.

### 2.2. Strengths and Limitations

Strengths:
- **Simple and Intuitive**: Easy to understand and implement.
- **Widely Used**: A foundational algorithm in data mining.

Limitations:
- **Scalability Issues**: Can be slow with large datasets due to the combinatorial explosion of itemsets.
- **High Memory Usage**: Requires significant memory for storing candidate itemsets.

## 3. The Eclat Algorithm

### 3.1. Overview of Eclat

The `Eclat` Algorithm (Equivalence Class Transformation) is a more efficient alternative to `Apriori` for finding frequent itemsets. It uses a depth-first search strategy and intersects transaction lists to find frequent itemsets.

#### Algorithm Steps

1. Build Transaction Lists: Construct transaction lists for each itemset.
2. Intersect Transaction Lists: Find common items between transaction lists.
3. Prune: Remove itemsets that do not meet the minimum support threshold.
4. Generate Itemsets: Expand itemsets by combining frequent itemsets and repeat.

Example:

For the same dataset:

1. Generate Itemsets: Start with single items and find their intersections.
2. Count Occurrences: Count how often itemsets appear together.
3. Expand: Combine itemsets to find larger frequent itemsets.

#### Python Implementation

Here’s an example of the `Eclat` algorithm using the `efficient_apriori` library:

```python
from efficient_apriori import apriori

# Sample Transaction Data
transactions = [['Bread', 'Milk'], ['Bread', 'Diaper'], ['Milk', 'Diaper'], ['Bread', 'Milk', 'Diaper']]

# Apply Eclat Algorithm
itemsets, rules = apriori(transactions, min_support=0.5, min_confidence=0.7)

print(itemsets)
print(rules)
```

Code Explanation:
- **Transaction Data**: List of transactions.
- **Apply Eclat**: Find frequent itemsets and generate rules with specified support and confidence thresholds.

### 3.2. Strengths and Limitations

Strengths:
- **Efficient**: More memory-efficient than `Apriori` due to the use of transaction lists.
- **Scalable**: Better suited for large datasets.

Limitations:
- **Complex Implementation**: More complex than `Apriori` to implement from scratch.
- **Limited Flexibility**: Less flexible in terms of advanced rule generation compared to `Apriori`.
