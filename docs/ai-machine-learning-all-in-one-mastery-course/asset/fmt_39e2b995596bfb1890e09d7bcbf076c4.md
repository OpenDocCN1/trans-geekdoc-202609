# Word Embeddings: Word2Vec and GloVe

Welcome to this comprehensive tutorial on Word Embeddings! In this session, we will explore two of the most popular techniques for representing words in a way that captures their meanings and relationships: `Word2Vec` and `GloVe`. These techniques are fundamental in Natural Language Processing (NLP) for converting text data into numerical forms that machine learning models can interpret. Let’s dive into these powerful methods and understand how they work!

## 1. Introduction to Word Embeddings

Word embeddings are numerical representations of words that capture semantic meaning and relationships between words. Unlike traditional methods like one-hot encoding, which represent words as sparse vectors, word embeddings provide dense, low-dimensional vectors that capture complex word relationships.

### Why Are Word Embeddings Important?

Word embeddings transform text into a format that machine learning models can process. They are crucial for tasks such as:

● Text Classification: Identifying categories or sentiments.
● Named Entity Recognition (NER): Extracting specific information from text.
● Machine Translation: Translating text from one language to another.
● Information Retrieval: Searching and indexing documents.

Word embeddings are more effective than simple methods because they capture context and meaning through dense vector representations.

## 2. Word2Vec: Understanding the Model

`Word2Vec` is a popular word embedding technique developed by a team led by Tomas Mikolov at Google in 2013. It generates vector representations of words by analyzing large text corpora.

### Word2Vec Architecture

`Word2Vec` uses two primary models to create embeddings: `Skip-Gram` and Continuous Bag of Words (`CBOW`).

#### 2.1. Skip-Gram Model

The `Skip-Gram` model predicts surrounding words given a target word. For example, in the sentence “The cat sat on the mat,” given the target word “sat,” the model predicts the context words “the,” “cat,” “on,” “the,” and “mat.”

How It Works:

1. Training Data: Pairs of target words and context words are created from the text.
2. Training Process: The model adjusts word vectors to maximize the probability of context words given the target word.
3. Output: A dense vector representation for each word is generated.

Example Code:

```python
from gensim.models import Word2Vec

# Sample text data
sentences = [["the", "cat", "sat", "on", "the", "mat"],
["the", "dog", "barked"],
["the", "cat", "meowed"]]

# Train a Skip-Gram Word2Vec model
model = Word2Vec(sentences, vector_size=50, window=2, sg=1, min_count=1)

# Retrieve the vector for the word 'cat'
vector_cat = model.wv['cat']

print(vector_cat)
```

#### 2.2. Continuous Bag of Words (CBOW) Model

The `CBOW` model predicts the target word from the surrounding context words. For the same sentence, given the context words “the,” “cat,” “on,” “the,” and “mat,” the model predicts the target word “sat.”

How It Works:

1. Training Data: Pairs of context words and target words are created from the text.
2. Training Process: The model adjusts word vectors to maximize the probability of the target word given the context words.
3. Output: Dense word vectors are produced.

Example Code:

```python
from gensim.models import Word2Vec

# Sample text data
sentences = [["the", "cat", "sat", "on", "the", "mat"],
["the", "dog", "barked"],
["the", "cat", "meowed"]]

# Train a CBOW Word2Vec model
model = Word2Vec(sentences, vector_size=50, window=2, sg=0, min_count=1)

# Retrieve the vector for the word 'cat'
vector_cat = model.wv['cat']

print(vector_cat)
```

### Why Word2Vec Matters

`Word2Vec` embeddings are versatile and have been used in various NLP applications. They capture word meanings based on context and can be fine-tuned for specific tasks.

## 3. GloVe: Understanding the Model

`GloVe` (Global Vectors for Word Representation) is another popular technique for generating word embeddings. Developed by Jeffrey Pennington, Richard Socher, and Christopher D. Manning at Stanford in 2014, `GloVe` focuses on capturing the global statistical information of a text corpus.

### GloVe Architecture

`GloVe` creates word embeddings by leveraging the co-occurrence matrix of words from a large corpus.

#### 3.1. How GloVe Works

1. Co-occurrence Matrix: Builds a matrix from the text corpus where each cell represents the frequency of two words occurring together.
