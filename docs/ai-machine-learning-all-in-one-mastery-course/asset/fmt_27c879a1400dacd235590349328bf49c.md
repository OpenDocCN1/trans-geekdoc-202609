
F1 Score is ideal when you need a balance between `Precision` and `Recall`, particularly in imbalanced datasets. It is beneficial in scenarios where both false positives and false negatives are important.

### Example Calculation

If `Precision` is 0.75 and `Recall` is 0.60, the `F1 Score` is:

F1 Score=2×0.75×0.600.75+0.60=0.67 or 67%\\text{F1 Score} = 2 \\times \\frac{0.75 \\times 0.60}{0.75 + 0.60} = 0.67 \\text{ or } 67\\%F1 Score=2×0.75+0.600.75×0.60​=0.67 or 67%

### 5.3. F1 Score vs. Accuracy

The `F1 Score` provides a more comprehensive evaluation than `Accuracy`, especially in the presence of class imbalance.

## 6. Comparing Metrics

To understand how these metrics relate to each other, let’s review a confusion matrix and the associated calculations.

### 6.1. Confusion Matrix

A confusion matrix provides a detailed breakdown of predictions versus actual outcomes:

|  | Actual Positive | Actual Negative |
| --- | --- | --- |
| Predicted Positive | True Positive (`TP`) | False Positive (`FP`) |
| Predicted Negative | False Negative (`FN`) | True Negative (`TN`) |

### 6.2. Metrics Calculation from Confusion Matrix

From the confusion matrix, you can calculate:

- `Accuracy`: `TP+TN` / `TP+TN+FP+FN` \\frac{`TP` + `TN`}{`TP` + `TN` + `FP` + `FN`}
- `Precision`: `TP` / `TP+FP` \\frac{`TP`}{`TP` + `FP`}
- `Recall`: `TP` / `TP+FN` \\frac{`TP`}{`TP` + `FN`}
- `F1 Score`: 2×`Precision`×`Recall` / `Precision+Recall` 2 \\times \\frac{`Precision` \\times `Recall`}{`Precision` + `Recall`}

### Example Calculation

Consider the following confusion matrix for a classification model:

|  | Actual Positive | Actual Negative |
| --- | --- | --- |
| Predicted Positive | 40 | 10 |
| Predicted Negative | 15 | 35 |

Here’s how you would compute the metrics:

- `Accuracy`: (40 + 35) / (40 + 35 + 10 + 15) = 75 / 100 = 0.75 or 75%
- `Precision`: 40 / (40 + 10) = 40 / 50 = 0.80 or 80%
- `Recall`: 40 / (40 + 15) = 40 / 55 = 0.73 or 73%
- `F1 Score`: 2 × 0.80 × 0.73 / (0.80 + 0.73) = 2 × 0.584 / 1.53 = 0.76 or 76%

### 7.2. Medical Diagnosis

For medical diagnoses, `Recall` is critical to identify as many cases as possible.

### 7.3. Fraud Detection

In fraud detection, you might balance `Precision` and `Recall` with the `F1 Score` to manage false positives and false negatives effectively.

## 1. Introduction to Unsupervised Learning

### 1.1. What is Unsupervised Learning?

`Unsupervised Learning` refers to a type of machine learning where the algorithm is used to find hidden patterns or intrinsic structures in input data without the use of labeled responses. Unlike supervised learning, where we train a model on input-output pairs, unsupervised learning aims to infer the natural structure present within a set of data points.

#### Types of Unsupervised Learning Tasks:

- `Clustering`: Grouping data points into clusters based on their similarity.
- `Dimensionality Reduction`: Reducing the number of features while retaining important information.
- `Anomaly Detection`: Identifying unusual data points that differ significantly from the majority of the data.
- `Association Rule Learning`: Discovering interesting relationships or associations between different features.

### 1.2. Historical Background

Unsupervised learning has been around since the early days of statistics and data analysis. However, it gained prominence in the 1990s with the advent of more advanced computational techniques and algorithms. The growth of big data and advancements in computational power have since accelerated the development and application of unsupervised learning methods.

## 2. Clustering

### 2.1. What is Clustering?

Clustering is the process of grouping a set of objects in such a way that objects in the same group (or cluster) are more similar to each other than to those in other groups.

Popular Clustering Algorithms:

- `K-Means Clustering`: Partitions data into K distinct, non-overlapping subsets or clusters.
- `Hierarchical Clustering`: Builds a hierarchy of clusters either in a bottom-up or top-down approach.
- `DBSCAN` (Density-Based Spatial Clustering of Applications with Noise): Groups together closely packed points and identifies outliers.

#### Example: K-Means Clustering

In `K-Means Clustering`, you specify the number of clusters `K`, and the algorithm iteratively assigns data points to clusters and updates the cluster centers to minimize the variance within each cluster.

Algorithm Steps:

1. Initialize: Choose `K` initial cluster centroids randomly.
2. Assign: Assign each data point to the nearest centroid.
3. Update: Calculate new centroids based on the mean of data points in each cluster.
4. Repeat: Continue until centroids no longer change or converge.
