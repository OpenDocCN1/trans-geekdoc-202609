### 2.4. Target Encoding

Target encoding, also known as mean encoding, replaces categories with the mean of the target variable for each category.

#### 2.4.1. How It Works

For each category, calculate the average value of the target variable and replace the category with this average.

#### 2.4.2. Implementation

```python
import pandas as pd

# Example data
data = pd.DataFrame({
'Color': ['Red', 'Blue', 'Green', 'Blue', 'Red'],
'Price': [10, 20, 30, 25, 15]
})

# Calculate the mean target value for each category
mean_target = data.groupby('Color')['Price'].mean()

# Map the mean target value to each category
data['Color_Target_Encoded'] = data['Color'].map(mean_target)

print(data)
```

Output:

| Color | Price | Color_Target_Encoded |
| --- | --- | --- |
| Red | 10 | 12.5 |
| Blue | 20 | 22.5 |
| Green | 30 | 30.0 |
| Blue | 25 | 22.5 |
| Red | 15 | 12.5 |

### 2.5. Frequency Encoding

Frequency encoding replaces categories with the frequency or count of occurrences in the dataset.

#### 2.5.1. How It Works

Each category is replaced with the number of times it appears in the dataset.

#### 2.5.2. Implementation

```python
import pandas as pd

# Example data
data = pd.DataFrame({'Color': ['Red', 'Blue', 'Green', 'Blue', 'Red']})

# Frequency encoding
frequency = data['Color'].value_counts()
data['Color_Frequency_Encoded'] = data['Color'].map(frequency)
```

### 2.7. Feature Hashing

Feature hashing, also known as the hashing trick, hashes features into a fixed number of bins.

#### 2.7.1. How It Works

A hash function maps categories to a fixed number of hash buckets.

#### 2.7.2. Implementation

```python
import pandas as pd
from sklearn.feature_extraction import FeatureHasher

# Example data
data = pd.DataFrame({'Color': ['Red', 'Blue', 'Green', 'Blue', 'Red']})

# Feature hashing
hasher = FeatureHasher(n_features=4, input_type='string')
hashed_features = hasher.transform(data['Color'])
hashed_df = pd.DataFrame(hashed_features.toarray(), columns=[f'Color_{i}' for i in range(4)])

print(hashed_df)
```
