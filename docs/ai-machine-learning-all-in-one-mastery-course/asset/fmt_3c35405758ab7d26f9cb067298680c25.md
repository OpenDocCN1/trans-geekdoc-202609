### 1.1. Definition and Purpose

Backpropagation is an algorithm used to optimize the `weights` and `biases` of a neural network by minimizing the `loss function` through gradient descent. The core idea is to propagate errors backward through the network, computing gradients that indicate how much each weight and bias contributed to the error.

Key Objectives of Backpropagation:

- Minimize Error: Adjust model parameters to reduce the difference between predicted outputs and actual targets.
- Compute Gradients: Calculate the gradient of the loss function with respect to each parameter.
- Update Weights and Biases: Use the gradients to perform optimization steps that improve the model's performance.

Backpropagation gained prominence in the 1980s, thanks to the work of Rumelhart, Hinton, and Williams, who demonstrated its effectiveness for training multi-layer neural networks. Before backpropagation, training neural networks was challenging due to the complexity of computing gradients for deep networks.

- 1969: Minsky and Papert's book criticized the limitations of perceptrons, which led to reduced interest in neural networks.
