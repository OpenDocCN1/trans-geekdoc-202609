
- Type I Error: Rejecting the null hypothesis when it is actually true.
- Type II Error: Failing to reject the null hypothesis when the alternative hypothesis is true.
- Balancing Errors: Researchers aim to minimize both types of errors, balancing the significance level (`α`) and the power of the test.

## 3.3. Steps in Hypothesis Testing
1. State the Hypotheses: Formulate the null and alternative hypotheses.
2. Choose the Significance Level: Determine the probability of rejecting the null hypothesis when it is true (common choices are 0.05, 0.01).
3. Select the Test Statistic: Choose a test based on data type and research question (`t-test`, `chi-square test`, etc.).
4. Perform the Test: Calculate the test statistic and p-value.
5. Make a Decision: Compare the p-value to the significance level to accept or reject the null hypothesis.
6. Draw a Conclusion: Interpret the results in the context of the research question.

## 4. Estimation Techniques
Estimation involves using sample data to estimate population parameters. There are two main types of estimation techniques: point estimation and interval estimation.

### 4.1. Point Estimation
- Definition: Provides a single value estimate for a population parameter.
- Example: Using the sample mean to estimate the population mean.

### 4.2. Interval Estimation
- Definition: Provides a range of values within which the population parameter is expected to fall.
- Formula:
`Confidence Interval = Point Estimate ± (Critical Value × Standard Error)`
- Example: A 95% confidence interval for a mean might be `[50,55]`, meaning we are 95% confident that the true population mean lies within this range.

### 4.3. Confidence Intervals
- Definition: A range of values, derived from the sample statistic, that is likely to contain the population parameter.
- Common Intervals: 95% and 99% confidence intervals.
- Applications: Estimating population means, proportions, and differences between groups.

## 5. Regression Analysis
Regression analysis examines the relationship between a dependent variable and one or more independent variables. It is used for prediction and to understand relationships between variables.

### 5.1. Simple Linear Regression
- Definition: Models the relationship between two variables using a straight line.
- Equation:
`Y = β0 + β1 X + ϵ`
- `Y`: Dependent variable.
- `X`: Independent variable.
- `β0`: Y-intercept.
- `β1`: Slope of the line.
- `ϵ`: Error term.
- Applications: Predicting outcomes, understanding relationships (e.g., predicting sales based on advertising spend).

### 5.2. Multiple Linear Regression
- Definition: Extends simple linear regression to include multiple independent variables.
- Equation:
`Y = β0 + β1 X1 + β2 X2 + … + βn Xn + ϵ`
- Applications: Complex predictions involving several factors (e.g., predicting housing prices based on location, size, and amenities).

### 5.3. Logistic Regression
- Definition: Used for binary outcome variables.
- Equation:
`logit(p) = β0 + β1 X1 + β2 X2 + … + βn Xn`
- `p`: Probability of the outcome.
- `logit(p)`: Log-odds of the outcome.
- Applications: Classification problems (e.g., predicting if a customer will buy a product).

## 6. Analysis of Variance (ANOVA)
ANOVA is a statistical technique used to compare the means of three or more groups to determine if at least one group mean is different from the others.

### 6.1. One-Way ANOVA
- Definition: Tests differences among group means in one factor.
- Concept: Compares the variance between groups to the variance within groups.
- Applications: Testing the effect of different treatments or conditions (e.g., comparing the effectiveness of three different teaching methods).

### 6.2. Two-Way ANOVA
- Definition: Tests differences among group means considering two factors.
- Concept: Evaluates the main effects of each factor and their interaction.
- Applications: More complex experimental designs involving two independent variables.

## 7. Bayesian Statistics
Bayesian statistics offers an alternative approach to inferential statistics using Bayes' Theorem to update probabilities as new information becomes available.

### 7.1. Bayes’ Theorem
- Definition: Updates the probability of a hypothesis based on new evidence.
- Formula:
`P(A|B) = P(B|A) ⋅ P(A) / P(B)`
- Applications: Decision-making processes, medical diagnoses, and machine learning algorithms.

### 7.2. Bayesian vs. Frequentist Approaches
- Bayesian Statistics: Incorporates prior knowledge and updates beliefs with new data.
- Frequentist Statistics: Relies on sample data and long-term frequencies for inference.
