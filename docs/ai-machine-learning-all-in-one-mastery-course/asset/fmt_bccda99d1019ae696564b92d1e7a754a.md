
## 4.1. BLEU Score

BLEU Score measures the overlap between the model’s output and reference translations.

Formula:

BLEU=BP×exp⁡(∑precisionn)\\text{BLEU} = \\text{BP} \\times \\exp\\left(\\sum \\text{precision}\_n \\right)BLEU=BP×exp(∑precisionn​)

Example Code:

```python
from nltk.translate.bleu_score import sentence_bleu

# Example references and hypotheses
references = [["Hola", "¿Cómo estás?"]]
hypothesis = ["Hola", "¿Cómo estás?"]

# Compute BLEU score
bleu_score = sentence_bleu(references, hypothesis)

print(f"BLEU Score: {bleu_score}")
```

## 4.2. METEOR Score

METEOR Score evaluates translations based on precision, recall, and synonym matching.

Formula:

METEOR=Precision×Recall×Matching\\text{METEOR} = \\text{Precision} \\times \\text{Recall} \\times \\text{Matching}METEOR=Precision×Recall×Matching

Example Code:

```python
from nltk.translate.meteor_score import meteor_score

# Example references and hypotheses
references = [["Hola", "¿Cómo estás?"]]
hypothesis = ["Hola", "¿Cómo estás?"]

# Compute METEOR score
meteor_score_value = meteor_score(references, hypothesis)

print(f"METEOR Score: {meteor_score_value}")
```

Text Generation refers to the process of creating coherent and contextually relevant text based on a given input or seed text. Text Generation has wide-ranging applications across various fields. Its significance can be seen in:

## 2. Techniques and Models for Text Generation

Text Generation employs a variety of techniques and models, each suited to different types of generation tasks.

### 2.1. Rule-Based Text Generation

Rule-Based Text Generation involves creating text generation rules manually.

How It Works:

1. Define Rules: Create a set of grammatical rules and templates.
2. Generate Text: Use the rules to produce text based on input parameters.

Pros:

- High control over output text.
- Simple to implement for specific tasks.

Cons:

- Requires extensive manual effort.
- Limited flexibility and scalability.

Example Code:

```python
# Simple rule-based text generation
def generate_text(template, data):
    return template.format(**data)

# Define a template and data
template = "Hello, my name is {name} and I am {age} years old."
data = {"name": "Alice", "age": 30}

# Generate text
text = generate_text(template, data)
print(text)
```

### 2.2. N-gram Models

N-gram Models use statistical methods to predict the next word based on the previous `n-1` words.

How It Works:

1. Collect Data: Gather a large corpus of text.
2. Build Model: Create a frequency table of n-grams.
3. Generate Text: Predict the next word based on n-gram probabilities.

Pros:

- Simple and intuitive.
- Easy to implement.

Cons:

- Limited context awareness.
- Requires large datasets for better performance.

Example Code:

```python
from nltk import ngrams
from collections import Counter

# Sample text
text = "I love machine learning and natural language processing"

# Create bigrams and count frequencies
bigrams = ngrams(text.split(), 2)
bigram_freq = Counter(bigrams)

print(bigram_freq)
```

### 2.3. Recurrent Neural Networks (RNNs)

Recurrent Neural Networks use feedback connections to maintain context across sequences.

How It Works:

1. Design Network: Create an RNN architecture with hidden states.
2. Train Model: Feed sequences into the network to learn text patterns.
3. Generate Text: Use the trained model to generate new sequences.

Pros:

- Captures sequential dependencies.
- Effective for text generation tasks.

Cons:

- Limited by vanishing gradient problems.
- May require substantial computational resources.

Example Code:

```python
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense

# Define RNN model
model = Sequential([
    LSTM(128, input_shape=(None, 1)),
    Dense(1, activation='softmax')
])

# Compile and train model
model.compile(loss='categorical_crossentropy', optimizer='adam', metrics=['accuracy'])
```

### 2.4. Long Short-Term Memory Networks (LSTMs)

LSTMs are a type of RNN designed to overcome vanishing gradient issues.

How It Works:

1. Design Network: Implement LSTM cells with gates to manage long-term dependencies.
2. Train Model: Feed text sequences to the LSTM network.
3. Generate Text: Use LSTM to generate text sequences.

Pros:

- Handles long-term dependencies well.
- More stable for longer text sequences.

Cons:

- More complex than vanilla RNNs.
