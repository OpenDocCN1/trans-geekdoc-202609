
1. Feature Extraction: Convert text into numerical features (e.g., `TF-IDF`).
2. Model Training: Train classifiers like `Logistic Regression`, `Naive Bayes`, or `Support Vector Machines`.
3. Prediction: Classify new text based on the trained model.

Example Code:

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import make_pipeline

# Sample text data
texts = ["I love the new phone!", "The camera is amazing.", "The battery life could be better."]
labels = ["positive", "positive", "negative"]

# Create a TF-IDF vectorizer and a Naive Bayes classifier
model = make_pipeline(TfidfVectorizer(), MultinomialNB())

# Train the model
model.fit(texts, labels)

# Predict sentiment for new text
new_text = ["The phone is great but the battery life is poor."]
prediction = model.predict(new_text)

print(prediction)
```

## Evaluating Sentiment Analysis Models
Evaluating the performance of sentiment analysis models involves using metrics to assess accuracy, precision, recall, and F1 score.

### Accuracy
Accuracy measures the proportion of correctly classified instances out of the total.
Formula: `Accuracy = Number of Correct Predictions / Total Number of Predictions`

### Precision
Precision measures the proportion of true positive predictions out of all positive predictions.
Formula: `Precision = True Positives / (True Positives + False Positives)`

### Recall
Recall measures the proportion of true positive predictions out of all actual positives.
Formula: `Recall = True Positives / (True Positives + False Negatives)`

### F1 Score
F1 Score is the harmonic mean of precision and recall.
Formula: `F1 Score = 2 × Precision × Recall / (Precision + Recall)`

Example Code:

```python
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score

# Sample true and predicted labels
true_labels = ["positive", "positive", "negative"]
predicted_labels = ["positive", "negative", "negative"]

# Compute metrics
accuracy = accuracy_score(true_labels, predicted_labels)
precision = precision_score(true_labels, predicted_labels, pos_label='positive')
recall = recall_score(true_labels, predicted_labels, pos_label='positive')
f1 = f1_score(true_labels, predicted_labels, pos_label='positive')

print(f"Accuracy: {accuracy}")
print(f"Precision: {precision}")
print(f"Recall: {recall}")
print(f"F1 Score: {f1}")
```

## What is Named Entity Recognition (NER)?
Named Entity Recognition (`NER`) is a crucial task in Natural Language Processing (`NLP`) that involves identifying and classifying entities in text into predefined categories. These entities can be names of people, organizations, locations, dates, and other proper nouns that convey specific information.

### Why is NER Important?
NER is essential for extracting structured information from unstructured text. Its applications are diverse and impactful:
- Information Extraction: Identifying key information from documents, such as names, places, and dates.
- Content Categorization: Categorizing content for search engines or recommendation systems.
- Customer Support: Automating ticket categorization and information retrieval.
- Knowledge Graphs: Building and enriching knowledge bases with entities and their relationships.
- Financial Analysis: Extracting financial entities and events for analysis.

NER helps organizations and researchers transform raw text data into actionable insights and structured information.
