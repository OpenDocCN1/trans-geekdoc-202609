
```python
from sklearn.metrics import r2_score

r2 = r2_score(y, predictions)

print("R-squared Score:", r2)
```

### 4.3. Adjusted R-squared
Adjusts the R-squared value for the number of predictors in the model.

```python
n = X.shape[0]  # number of observations
p = X.shape[1] - 1  # number of features (excluding the intercept)
# Calculate Adjusted R-squared
adj_r2 = 1 - (1 - r2) * (n - 1) / (n - p - 1)

print("Adjusted R-squared Score:", adj_r2)
```

## 1. Introduction to Logistic Regression

### 1.1. What is Logistic Regression?
Logistic regression is a statistical model used for binary classification tasks. Unlike linear regression, which predicts a continuous outcome, logistic regression predicts the probability of a binary outcome based on one or more independent variables. It’s called "logistic" because it uses the logistic function to model the probability of a class.

#### Key Features:
● Binary Classification: Predicts probabilities for two classes.
● Sigmoid Function: Maps predictions to a range between 0 and 1.
● Interpretable Model: Coefficients represent the impact of features on the outcome.

### 1.2. Key Terminology
● Dependent Variable (`Y`): The binary outcome we want to predict (e.g., success/failure).
● Independent Variables (`X`): The features used for prediction (e.g., age, income).
● Odds Ratio: The ratio of the probability of an event occurring to it not occurring.
● Logit Function: The natural log of the odds ratio, used in logistic regression.

#### Basic Formula
The logistic regression model is represented by the following formula:

P(Y=1)=11+e−(β0+β1X1+β2X2+⋯+βnXn)P(Y=1) = \frac{1}{1 + e^{-(β0 + β1X1 + β2X2 + \cdots + βnXn)}}P(Y=1)=1+e−(β0+β1X1+β2X2+⋯+βnXn)1​

Where:
● `P(Y=1)` is the probability of the outcome being 1.
● `β0` is the intercept.
● `β1, β2, …, βn` are the coefficients of the independent variables.
● `X1, X2, …, Xn` are the features.
● `e` is the base of the natural logarithm.

***

## 2. How Logistic Regression Works

### 2.1. The Logistic Function
The logistic function, also known as the sigmoid function, transforms the linear regression output into a probability.

#### Mathematical Expression
`Sigmoid Function = 1 / (1 + e^{-z})`

Where `z` is the linear combination of inputs:
`z = β0 + β1 X1 + β2 X2 + … + βn Xn`

The output of the sigmoid function is always between 0 and 1, making it suitable for binary classification.

#### Visualization
The sigmoid curve looks like an S-shaped graph where:
● The value approaches 0 as `z` becomes very negative.
● The value approaches 1 as `z` becomes very positive.
● At `z = 0`, the sigmoid function outputs 0.5.

```python
import numpy as np
import matplotlib.pyplot as plt

# Define the sigmoid function
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

# Generate data for plotting
z = np.linspace(-10, 10, 100)
s = sigmoid(z)

# Plot the sigmoid function
plt.figure(figsize=(8, 4))
plt.plot(z, s, label='Sigmoid Function')
plt.xlabel('z')
plt.ylabel('P(Y=1)')
plt.title('Sigmoid Function')
plt.legend()
plt.grid(True)
plt.show()
```

### 2.2. Training the Model
Training a logistic regression model involves finding the optimal coefficients that minimize the error between predicted probabilities and actual outcomes.

#### Training Process
1. Initialization: Start with initial guesses for coefficients.
2. Compute Predictions: Use the logistic function to get predicted probabilities.
3. Calculate Error: Measure the difference between predicted and actual outcomes using a loss function.
4. Update Coefficients: Adjust coefficients to minimize the error using optimization algorithms like `Gradient Descent`.
5. Repeat: Continue the process until the model converges to the best solution.
