
- Feature Mapping: Linear transformations are used to map data to different feature spaces in algorithms like kernel methods.
- Dimensionality Reduction: Techniques like `PCA` use linear transformations to reduce data dimensions while retaining variance.

## 5. Eigenvalues and Eigenvectors

Eigenvalues and eigenvectors are fundamental concepts used in various ML algorithms to understand matrix properties and perform data transformations.

### 5.1. Definitions
- Eigenvector: A non-zero vector `v` such that `Av = λv`, where `A` is a matrix and `λ` is the corresponding eigenvalue.
- Eigenvalue: A scalar `λ` such that `Av = λv`.

### 5.2. Computation
- Characteristic Polynomial:
  - Find eigenvalues by solving `det(A - λI) = 0`, where `I` is the identity matrix.
- Applications in ML:
  - `PCA`: Principal Component Analysis uses eigenvectors to find principal components of the data.
  - Spectral Clustering: Uses eigenvalues and eigenvectors of matrices derived from the data to perform clustering.

## 6. Singular Value Decomposition (SVD)

Singular Value Decomposition is a matrix factorization technique used in many ML applications.

### 6.1. Definition and Notation
- SVD: Decomposes a matrix `A` into three matrices `U`, `S`, and `V^T` such that `A = U S V^T`.
- Components:
  - `U`: Orthogonal matrix containing left singular vectors.
  - `S`: Diagonal matrix containing singular values.
  - `V^T`: Orthogonal matrix containing right singular vectors.

### 6.2. Applications in ML
- Dimensionality Reduction: `SVD` is used in Latent Semantic Analysis for text data.
- Recommendation Systems: `SVD` is employed in collaborative filtering to make recommendations based on user-item interactions.

# Descriptive Statistics: A Comprehensive Introduction

Descriptive statistics is a fundamental aspect of data analysis used to summarize and describe the main features of a dataset. Unlike inferential statistics, which aims to make predictions or generalizations about a population based on a sample, descriptive statistics focuses on organizing, presenting, and analyzing data to provide a clear overview of its characteristics. This tutorial will delve into key concepts, measures, and techniques in descriptive statistics that are essential for effective data analysis.

## 1. Introduction to Descriptive Statistics

Descriptive statistics provides a way to summarize and interpret the data collected from experiments, surveys, or observations. It helps researchers and analysts understand the distribution, central tendency, and variability of their data, offering insights that inform decision-making and further analysis.

### 1.1. Purpose of Descriptive Statistics

The primary goals of descriptive statistics are to:
- Summarize Data: Condense large amounts of data into a more understandable format.
- Describe Data Characteristics: Provide a snapshot of the data's main features.
- Organize Data: Structure data in a way that highlights patterns or trends.
- Present Data: Communicate findings effectively through graphs, tables, and summary statistics.

## 2. Measures of Central Tendency

Measures of central tendency describe the center point or typical value of a dataset. These measures provide a single value that represents the "center" of the data distribution.

### 2.1. Mean
- Definition: The mean, or average, is the sum of all values divided by the number of values.
- Formula:
  `Mean(x̄) = Σ xi / N`
- Example: For the dataset `[2,4,6,8,10]`, the mean is `(2 + 4 + 6 + 8 + 10) / 5 = 6`.
- Applications: The mean is used in various analyses, including calculating averages in finance, sports statistics, and more.

### 2.2. Median
- Definition: The median is the middle value when data is ordered from smallest to largest. If there is an even number of observations, the median is the average of the two middle numbers.
- Steps to Find:
  1. Arrange data in ascending order.
  2. If the number of observations is odd, the median is the middle value.
  3. If even, the median is the average of the two central values.
- Example: For the dataset `[1,3,3,6,7,8,9]`, the median is `6`.
- Applications: The median is useful for understanding the central tendency in skewed distributions, such as income or housing prices.

### 2.3. Mode
- Definition: The mode is the value that appears most frequently in a dataset.
- Example: In the dataset `[4,1,2,2,3,4,4,5]`, the mode is `4`.
- Applications: The mode is often used in categorical data analysis to determine the most common category or value.

## 3. Measures of Variability

Measures of variability describe the spread or dispersion of data values. They help to understand how much the data values differ from the mean or median.

### 3.1. Range
- Definition: The range is the difference between the maximum and minimum values in a dataset.
- Formula:
  `Range = Maximum - Minimum`
- Example: For the dataset `[3,7,5,9,2]`, the range is `9 - 2 = 7`.
- Applications: The range provides a simple measure of the spread of data but can be affected by outliers.

### 3.2. Variance
- Definition: Variance measures how much the data values deviate from the mean.
- Formula:
  `Variance(σ²) = Σ (xi - x̄)² / N`
- Example: For a dataset with values `[2,4,4,4,5,7,9]`, the variance quantifies the average squared deviations from the mean.
- Applications: Variance is used in financial analysis to assess risk and in experimental design to evaluate variability.
