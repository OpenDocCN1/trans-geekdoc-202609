
```python
def update_parameters(weights, biases, gradients, learning_rate):
    weights -= learning_rate * gradients
    biases -= learning_rate * gradients
    return weights, biases
```

## 2.2 Mathematical Formulation

Let's dive into the mathematical details of backpropagation:

1. Forward Propagation: Compute activations and losses.
   - For each layer, the activation `a` is computed as `a = f(z)`, where `z = W ⋅ x + b`.
   - Loss is calculated using a loss function `L`.

2. Backward Propagation: Compute gradients and update parameters.
   - Gradient of Loss Function: `∂L/∂W = ∂L/∂a ⋅ ∂a/∂z ⋅ ∂z/∂W`
   - Gradient Calculation: Compute gradients for weights and biases to adjust them using gradient descent.

Gradient Descent Formula:
`W = W - η ∂L/∂W`

Where:
- `W` represents the weights.
- `η` is the learning rate.
- `∂L/∂W` is the gradient of the loss function with respect to the weights.

## 3 Components of Backpropagation

### 3.1 Activation Functions

Activation functions determine the output of a neuron and introduce non-linearity into the model. Common activation functions include:
- Sigmoid Function: `σ(x) = 1 / (1 + e^{-x})`
- ReLU Function: `ReLU(x) = max(0, x)`
- Tanh Function: `tanh(x) = (e^x - e^{-x}) / (e^x + e^{-x})`

Choosing an Activation Function:
- Sigmoid: Suitable for binary classification problems.
- ReLU: Commonly used in hidden layers of deep networks.
- Tanh: Good for hidden layers when zero-centered data is preferred.

### 3.2 Loss Functions

Loss functions measure the performance of the model. Common loss functions include:
- Mean Squared Error (MSE): Measures the average squared difference between predicted and actual values.
  `L(y, ŷ) = 1/N Σ_{i=1}^N (ŷ_i - y_i)^2`
- Cross-Entropy Loss: Used for classification problems to measure the performance of a classification model whose output is a probability value.
  `L(y, ŷ) = - Σ_{i=1}^N y_i log(ŷ_i)`

### 3.3 Optimization Algorithms

Optimizers adjust the learning rate and update weights and biases. Common optimizers include:
- Stochastic Gradient Descent (`SGD`): Updates weights based on each data point.
- Adam Optimizer: Combines momentum and adaptive learning rates.

Example Code for Adam Optimizer:

```python
optimizer = Adam(learning_rate=0.001)
weights, biases = optimizer.update(weights, biases, gradients)
```

## 4 Advanced Topics in Backpropagation

### 4.1 Vanishing and Exploding Gradients

Vanishing Gradients: Occur when gradients become very small, causing the network to stop learning.

Exploding Gradients: Occur when gradients become very large, causing numerical instability.

Solutions:
- Gradient Clipping: Limiting the size of gradients to avoid explosion.
- Normalization Techniques: Techniques like batch normalization can help mitigate vanishing gradients.

### 4.2 Regularization Techniques

Regularization methods help prevent overfitting by penalizing large weights:

Dropout: Randomly drops neurons during training to prevent co-adaptation.

Example Code:

```python
def dropout(layer_output, dropout_rate):
    mask = np.random.binomial(1, 1 - dropout_rate, size=layer_output.shape)
    return layer_output * mask
```

L1/L2 Regularization: Adds a penalty term to the loss function.

Example Code for L2 Regularization:

```python
loss = original_loss + lambda * np.sum(weights**2)
```

### 4.3 Backpropagation Through Time (BPTT)

`BPTT` is an extension of backpropagation for training Recurrent Neural Networks (`RNNs`) by unrolling the network in time.

Key Concept:
- Unroll RNN: Treat each time step as a separate layer during backpropagation.

# Convolutional Neural Networks (CNNs): A Comprehensive Introduction

Welcome to this in-depth tutorial on Convolutional Neural Networks (`CNNs`)! `CNNs` are a specialized type of neural network designed for processing structured grid data, such as images. This tutorial will guide you through the core concepts, architecture, and applications of `CNNs`, providing you with the knowledge to start building and applying these powerful models in your machine learning projects.

## 1 What Are Convolutional Neural Networks (CNNs)?

### 1.1 Definition and Purpose

Convolutional Neural Networks (`CNNs`) are a class of deep learning algorithms specifically designed for visual recognition tasks. They are inspired by the visual processing mechanisms in the human brain and are particularly effective at detecting patterns and features in image data.

Key Objectives of `CNNs`:
- Feature Extraction: Automatically identify and extract important features from input images.
- Hierarchical Learning: Learn complex patterns through multiple layers of convolutions and pooling.
- Reduction of Parameters: Achieve high accuracy with fewer parameters compared to traditional fully connected networks.

### 1.2 Historical Background

`CNNs` were developed to tackle challenges in image and video recognition. The concept has evolved significantly since its inception:
- 1980s: The first `CNNs`, like Neocognitron by Kunihiko Fukushima, laid the groundwork for pattern recognition.
