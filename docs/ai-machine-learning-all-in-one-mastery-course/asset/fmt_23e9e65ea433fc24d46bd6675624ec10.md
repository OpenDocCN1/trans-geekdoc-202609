## 3. Dimensionality Reduction

### 3.1. What is Dimensionality Reduction?

Dimensionality Reduction techniques aim to reduce the number of features in the dataset while preserving as much information as possible. This process can help to visualize high-dimensional data and reduce computational costs.

Popular Dimensionality Reduction Techniques:
● Principal Component Analysis (`PCA`): Reduces dimensionality by projecting data onto a lower-dimensional subspace.
● t-Distributed Stochastic Neighbor Embedding (`t-SNE`): Used for visualizing high-dimensional data by mapping it to a 2D or 3D space.
● Linear Discriminant Analysis (`LDA`): Finds the linear combinations of features that best separate different classes.

#### Example: Principal Component Analysis (`PCA`)

`PCA` works by identifying the directions (principal components) in which the data varies the most and projecting the data onto these directions.

Algorithm Steps:
1. Standardize: Scale the data to have zero mean and unit variance.
2. Compute Covariance Matrix: Measure how features vary together.
3. Calculate Eigenvalues and Eigenvectors: Determine the principal components.
4. Project Data: Transform the data onto the principal components.

Visualization of `PCA`

![PCA](image_rsrcKCH.jpg)

Figure 2: Principal Component Analysis Visualization

### 3.2. Practical Applications of Dimensionality Reduction

● Data Visualization: Reducing dimensions for better visualization of complex data.
● Noise Reduction: Removing noise and irrelevant features from data.
● Feature Extraction: Identifying important features for predictive modeling.

#### Python Implementation Example

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.decomposition import PCA

# Sample data
data = np.random.rand(100, 5)

# PCA
pca = PCA(n_components=2)
reduced_data = pca.fit_transform(data)

# Plot
plt.scatter(reduced_data[:, 0], reduced_data[:, 1])
plt.title('PCA Visualization')
plt.xlabel('Principal Component 1')
plt.ylabel('Principal Component 2')
plt.show()
```

## 4. Anomaly Detection

### 4.1. What is Anomaly Detection?

Anomaly Detection involves identifying data points that do not conform to the expected pattern or distribution of the rest of the data. These outliers or anomalies may indicate critical incidents, such as fraud or system malfunctions.

Popular Anomaly Detection Techniques:
● `Isolation Forest`: An ensemble method specifically designed for anomaly detection.
● `One-Class SVM`: Finds a decision boundary that separates normal data from anomalies.
● Local Outlier Factor (`LOF`): Measures the local density deviation of a data point with respect to its neighbors.

#### Example: `Isolation Forest`

`Isolation Forest` isolates observations by randomly selecting features and splitting values. Anomalies are more easily isolated than normal observations.

Algorithm Steps:
1. Construct Isolation Trees: Randomly select features and split values.
2. Score Anomalies: Anomalies are expected to be isolated with fewer splits.

Visualization of `Isolation Forest`

![Isolation Forest](image_rsrcKCJ.jpg)

Figure 3: Isolation Forest Visualization

### 4.2. Practical Applications of Anomaly Detection

● Fraud Detection: Identifying unusual financial transactions.
● Network Security: Detecting unusual patterns in network traffic.
● Quality Control: Finding defects in manufacturing processes.

#### Python Implementation Example

```python
from sklearn.ensemble import IsolationForest

# Sample data
data = np.random.rand(100, 2)

# Anomaly Detection
iso_forest = IsolationForest(contamination=0.1)
outliers = iso_forest.fit_predict(data)

# Plot
plt.scatter(data[:, 0], data[:, 1], c=outliers, cmap='coolwarm', marker='o')
plt.title('Anomaly Detection using Isolation Forest')
plt.xlabel('Feature 1')
plt.ylabel('Feature 2')
plt.show()
```

## 5. Association Rule Learning

### 5.1. What is Association Rule Learning?

Association Rule Learning aims to discover interesting relationships or associations between variables in large datasets. It is commonly used in market basket analysis to find product associations.

Popular Techniques:
● `Apriori` Algorithm: Identifies frequent itemsets and generates association rules based on these itemsets.
● `ECLAT` Algorithm: Uses a depth-first search strategy to find frequent itemsets.

#### Example: Market Basket Analysis with `Apriori` Algorithm

In market basket analysis, you might find that customers who buy bread are also likely to buy butter.

Algorithm Steps:
1. Generate Itemsets: Find frequent itemsets in transactions.
2. Create Rules: Form rules from frequent itemsets and measure their strength.

Visualization of Association Rules

![Apriori Algorithm](image_rsrcKCK.jpg)

Figure 4: Apriori Algorithm Visualization

### 5.2. Practical Applications of Association Rule Learning

● Market Basket Analysis: Finding product associations in retail.
● Cross-Selling Strategies: Suggesting additional products to customers.
● Web Usage Mining: Identifying patterns in web page visits.

#### Python Implementation Example

```python
from mlxtend.frequent_patterns import apriori, association_rules

# Sample data
transactions = [{'milk', 'bread'}, {'bread', 'butter'}, {'milk', 'butter'}, {'milk', 'bread', 'butter'}]

# Convert data to one-hot encoded DataFrame
from mlxtend.preprocessing import TransactionEncoder
te = TransactionEncoder()
te_ary = te.fit(transactions).transform(transactions)
df = pd.DataFrame(te_ary, columns=te.columns_)

# Apply Apriori algorithm
frequent_itemsets = apriori(df, min_support=0.5, use_colnames=True)

# Generate Association Rules
rules = association_rules(frequent_itemsets, metric="confidence", min_threshold=0.7)

print(rules)
```
