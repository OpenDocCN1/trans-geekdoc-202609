### 2.2. Tanh Function

The `Tanh` Function maps input values to a range between -1 and 1. It is used in hidden layers of neural networks to center data around zero.

Mathematical Formula:

`tanh(x) = (e^x - e^{-x}) / (e^x + e^{-x})`

Characteristics:

- Range: (-1, 1)
- Usage: Hidden layers in neural networks.
- Pros: Zero-centered, which can help with gradient flow during training.
- Cons: Can still suffer from vanishing gradients for very large or small inputs.

### 2.3. ReLU (Rectified Linear Unit)

The `ReLU` Function is widely used in hidden layers of neural networks due to its simplicity and effectiveness.

Mathematical Formula:

`ReLU(x) = max(0, x)`

Characteristics:

- Range: [0, ∞)
- Usage: Hidden layers in deep neural networks.
- Pros: Computationally efficient, helps mitigate the vanishing gradient problem.
- Cons: Can cause dead neurons that do not activate for negative inputs.

Graph of the ReLU Function:

![ReLU Function](image_rsrcKCU.jpg)

### 2.4. Leaky ReLU

`Leaky ReLU` addresses the issue of dead neurons in the `ReLU` function by allowing a small gradient when the input is negative.

Mathematical Formula:

`Leaky ReLU(x) = { x if x > 0 ; alpha * x if x <= 0 }`

Characteristics:

- Range: (-∞, ∞)
- Usage: Hidden layers in deep networks.
- Pros: Reduces the problem of dead neurons.
- Cons: The choice of `alpha` is often arbitrary and needs to be tuned.

### 2.5. Softmax Function

The `Softmax` Function converts raw output scores into probabilities for multi-class classification tasks.

Mathematical Formula:

`Softmax(x_i) = e^{x_i} / sum_j e^{x_j}`

Characteristics:

- Range: (0, 1)
- Usage: Output layer for multi-class classification.
- Pros: Converts outputs into a probability distribution.
- Cons: Can be sensitive to very large or very small input values.

## 3. Choosing the Right Activation Function

### 3.1. Task Considerations

When selecting an activation function, consider the nature of the task:

- Binary Classification: Use `Sigmoid` for the output layer.
- Multi-Class Classification: Use `Softmax` for the output layer.
- Hidden Layers: `ReLU` and its variants (like `Leaky ReLU`) are commonly used.

### 3.2. Performance and Experimentation

Choosing the right activation function often requires experimentation. Testing different functions and observing their impact on training performance and convergence can help identify the best choice for your specific problem.

### 3.3. Common Pitfalls

Be aware of common pitfalls:

- Vanishing Gradients: `Sigmoid` and `Tanh` can suffer from vanishing gradients for very deep networks.
- Exploding Gradients: `Softmax` combined with a high learning rate can cause gradients to explode.
- Dead Neurons: `ReLU` functions can result in neurons that never activate.

## 4. Advanced Activation Functions

### 4.1. ELU (Exponential Linear Unit)

The `ELU` Function improves on `ReLU` by providing a smooth transition for negative values, which helps reduce the bias shift.

Mathematical Formula:

`ELU(x) = { x if x > 0 ; alpha * (e^x - 1) if x <= 0 }`

Characteristics:

- Range: (-alpha, ∞)
- Usage: Hidden layers in deep networks.

### 4.2. Swish Function

The `Swish` Function is a newer activation function proposed by Google, combining the benefits of sigmoid and ReLU.

Mathematical Formula:

`Swish(x) = x * sigma(x)`

Characteristics:

- Range: (-∞, ∞)
- Usage: Hidden layers in neural networks.

## 1. Understanding Feedforward Neural Networks

### 1.1. What is a Feedforward Neural Network?

A Feedforward Neural Network is a type of artificial neural network where connections between the nodes do not form cycles. It is called "feedforward" because the data flows in one direction—from the input layer, through one or more hidden layers, to the output layer—without looping back.

Key Characteristics of FNNs:

- Layered Structure: FNNs have a clear flow of information from input to output.
- No Cycles: Information moves forward from input to output; there are no recurrent connections.
- Learning Process: Weights and biases are adjusted based on the error between predictions and actual values.
