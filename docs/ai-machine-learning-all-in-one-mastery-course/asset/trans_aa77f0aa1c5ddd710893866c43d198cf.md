## 5. Common Issues and Solutions

### 5.1. Overfitting

过拟合发生在模型在训练数据上表现良好但在新数据上表现不佳时。

#### Solutions:

● 正则化：应用 L1 或 L2 正则化。

● 交叉验证：使用 k 折交叉验证等技术。

● 特征选择：移除无关特征。

### 5.2. Multicollinearity

多重共线性发生在自变量高度相关时。

#### Solutions:

● 移除变量：消除冗余特征。

● 主成分分析 (PCA)：使用降维技术。

### 5.3. Imbalanced Data

不平衡数据可能使结果偏向多数类。

#### Solutions:

● 重采样：应用过采样或欠采样技术。

● 类权重：在逻辑回归模型中调整类权重。

## 1. Introduction to Decision Trees

### 1.1. What is a Decision Tree?

决策树是一种类似流程图的结构，用于做出决策和预测结果。它将数据拆分为分支以形成类似树的决策模型。每个内部节点代表基于特征的决策，每个分支代表该决策的结果，每个叶节点代表最终结果或分类。

#### Key Features:

● 层次结构：模仿具有节点和分支的树。

● 决策：基于特征值拆分数据。

● 多功能：可用于分类和回归任务。

### 1.2. Basic Terminology

● 根节点：决策过程开始的最顶层节点。

● 内部节点：代表基于特征的决策点的节点。

● 分支：基于特征值连接节点的路径。

● 叶节点：代表结果或预测的终端节点。

● 分裂：基于特征值划分数据集的过程。

● 修剪：减小树大小以防止过拟合的过程。

#### Decision Tree Structure

| 节点类型 || 描述 |
| --- | --- |
| 根节点 || 树的起点，在此做出第一个决策 |
| 内部节点 || 数据根据特征值在此处被拆分的地方 |
| 分支 || 连接节点并代表决策结果的路径 |
| 叶节点 || 代表最终分类或预测的端点 |

## 2. How Decision Trees Work

### 2.1. Building a Decision Tree

构建决策树涉及选择最佳特征来拆分数据，以实现最大的信息增益。

#### Steps to Build a Decision Tree

1. 选择特征：选择最能分离数据的特征。

2. 拆分数据：基于所选特征划分数据。
