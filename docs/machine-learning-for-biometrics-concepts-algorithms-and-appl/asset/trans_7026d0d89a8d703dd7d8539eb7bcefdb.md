
## 图 1 印度生物识别市场份额（单位：百万美元）[⁴](#fn4)

根据生物识别市场情况，指纹被广泛用于人员识别。儿童的指纹很小，不易采集。第二大使用的生物识别模态是人脸。人脸图像易于采集，且在寻找失踪儿童的情况下非常有用。因此，我们使用人脸生物识别技术进行儿童识别。我们数据库中儿童不同生物特征的示例见[图 2](#B9780323852098000110.xhtml#f0015)。

![图 2 用于儿童识别的不同生物特征。](images/B9780323852098000110/f01-02-9780323852098.jpg "fig:")

人脸是一个 3D 模型，我们可以通过其特征（如眼睛、脸型和肤色）来识别它。自动人脸识别基于人物的 2D 照片。1964 年和 1965 年，Woody Bledsoe 与 Helen Chan 和 Charles Bisson 一起首次利用计算机识别人脸。如今，成人人脸识别的准确率已达到 99.63% 的极高水平 [⁵](#fn5)
