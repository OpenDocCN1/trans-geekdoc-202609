
医疗行业中信息和通信技术的实现通过互联网提供远程和自我监测医疗服务。特别是无线体域网（WBAN）和云计算的指数级增长增强了远程医疗服务，同时也降低了患者的医疗支出和时间。WBAN 是一种围绕人体的低功耗无线个人域网，由各种可穿戴医疗传感器和一个个人移动设备组成 [^246]。

各种慢性病居家护理服务需求的增加导致医疗数据极快增长 [^247]。

由于患者的 WBAN 设备天然受限于计算能力、通信带宽、存储和电池电量，因此无法应用强加密操作来执行患者和医生之间的安全通信。因此，需要一种轻量级、高效的相互认证和密钥协商协议来维护通信过程中的安全性 [^248]。

虽然轻量级认证和密钥协商协议确保了传输过程中数据的隐私，但患者移动设备上的数据丢失风险始终存在。移动设备可能被对手窃取，除非移动设备完全安全，否则对手将从该移动设备获取患者的生理信息和诊断报告。因此，有必要保护患者移动设备中存储的数据，使得对手在窃取患者移动设备后无法获得任何优势。

认证是一种有前景的加密解决方案，可为存储在移动设备中的机密信息提供安全访问。所有认证技术至少依赖以下方法之一。

*   **用户拥有的东西**：也称为基于令牌的认证。在此机制中，每个用户（需要被认证者）拥有某个物理识别对象，可唯一标识该用户，例如智能卡。
*   **用户知道的东西**：也称为基于知识的认证。在此机制中，用户必须记住密码或 PIN 以进行认证过程。
*   **用户本身的东西**：也称为基于生物特征的认证。这包括指纹扫描、虹膜扫描等机制。

由于简单易部署，基于密码的认证是最广泛的用户认证技术。不幸的是，由于人类记忆的有限认知能力，密码容易受到某些安全威胁 [^249]。

因此，在远程医疗信息系统（TMIS）中，需要一种使用生物特征哈希的轻量级认证和密钥协商协议。

### 1.1 贡献

为满足 TMIS 中的安全需求，我们提出了一种用于云环境中医疗数据交换的改进型轻量级认证协议。本工作的主要研究贡献如下。

*   所提协议在通信双方（即患者和医生）之间建立相互认证。
*   使用生物特征哈希，我们确保了患者移动设备的安全性，也确保了医生设备的安全性。
*   我们使用形式分析和非形式分析方法对协议进行了检验，发现该协议实现了所需的安全属性，并能抵抗各种已知攻击。
*   会话密钥仅使用哈希运算和异或运算建立，因此计算开销小、重量轻。
*   性能分析表明，与其他现有协议相比，所提协议更高效。

### 3.3 安全目标

*   **认证**：在接受任何消息之前，所有参与者都应能够验证发送者的声称身份。它可防止冒充攻击、中间人攻击等安全协议攻击。
*   **报告机密性**：在 TMIS 中，保护患者健康信息的机密性至关重要。除指定医疗专业人员外，任何内部人员和外部人员都不应能获取秘密报告。
*   **报告完整性**：关键医疗数据的任何未经授权修改都可能危及患者生命 [^259]。
*   **患者匿名性**：应隐藏患者的真实身份，即窃听传输消息后，任何对手都无法将消息与特定患者关联，也无法判断两条消息是否来自同一患者。
*   **患者不可链接性**：患者与其医生之间的关联或关系应保密。否则，会危及患者的隐私和匿名性。
