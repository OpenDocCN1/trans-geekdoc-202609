## 4.1 预处理

为平滑输入侧面图像中存在的噪声，采用了高斯低通滤波器。在高斯核 (`G`) 和侧面图像 (`I`) 之间执行卷积运算，以获得平滑后的输入图像 (`I'`)，如下所示：

```
I' = I * G(u, v, σ)
G(u, v, σ) = 1 / (√(2π) σ) * exp(- (u² - v²) / (2σ²))
```

![si2_e](images/B9780323852098000031/si2_e.png)  (1)

其中 `σ` 为高斯核的标准差。

## 4.2 基于分块 SPT-BSIF 描述符的特征提取

在本工作中，我们在耳部和侧脸图像上采用三尺度六方向的可操纵金字塔滤波器组，将图像分解为 18 个不同尺度和方向的子带。然后，将所有子带划分为若干个不重叠的块，并对所有块应用 BSIF 特征提取器。所有块的归一化直方图纹理描述符被连接以形成 (`SPT-BSIF`) 特征向量。最后，我们分别获得了耳部和侧脸的两个归一化特征向量 `F[Ear]` 和 `F[PF]`。

## 4.3 匹配与分类

在执行分类之前，通过两个步骤计算所有探针样本的匹配得分：(1) 使用公式 ([2](#B9780323852098000031.xhtml#fo0015)) 中给出的卡方度量，将每个探针图像与所有图库图像进行比较以生成一组匹配得分；(2) 使用 kNN 分类器为每个探针样本获得单个匹配得分。

```
χ(F₁, F₂) = Σₖ₌₁ᴺ (f₁,ₖ - f₂,ₖ)² / (f₁,ₖ + f₂,ₖ)
```

![si3_e](images/B9780323852098000031/si3_e.png)  (2)

在本章中，我们以验证模式使用了所提出的方法。在这种情况下，将探针图像与图库图像进行匹配以验证个体声称的身份。最后，使用公式 ([3](#B9780323852098000031.xhtml#fo0020)) 利用探针样本的匹配得分计算误接纳率 (`FAR`) 和误拒率 (`FRR`)，以评估所提出方法的识别准确率 (%)。另一个公认的性能度量是等错误率 (`EER`)，即 `FAR` 和 `FRR` 相等时的比率 [[^(55)](#fn55)]

```
Accuracy = 100 - (FAR + FRR) / 2
```

![si4_e](images/B9780323852098000031/si4_e.png)  (3)

## 4.4 多模态融合

在本工作中，同时考察了特征级融合和得分级融合，以确定所提出方法的更高识别性能。

## 4.5 特征级融合

在特征级融合中，耳部特征 `F[Ear]` 和侧脸特征 `F[PF]` 被合并为单个特征向量 `F[Fused]`，如下所示：

```
F_Fused = F_Ear ∪ F_PF
```

![si5_e](images/B9780323852098000031/si5_e.png)  (4)

## 4.6 得分级融合

在得分级融合中，耳部匹配得分 `S[Ear]` 和侧脸匹配得分 `S[PF]` 分别使用卡方距离度量计算，并基于公式 ([5](#B9780323852098000031.xhtml#fo0030)) 进行融合，以获得用于通过 kNN 分类器识别个体的融合得分。

```
S_Fused = (A_Ear × S_Ear + A_PF × S_PF) / (A_Ear + A_PF)
```

![si6_e](images/B9780323852098000031/si6_e.png)  (5)

其中 `A[Ear]` 和 `A[PF]` 分别为耳部和侧脸模态的识别准确率。
