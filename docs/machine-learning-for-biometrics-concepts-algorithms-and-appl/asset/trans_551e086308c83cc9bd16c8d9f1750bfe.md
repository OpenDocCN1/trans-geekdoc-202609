
它是探索 CNN 中使用的层不必按顺序排列这一概念的模型之一。通过使用 Inception 模块，它证明了不同的层结构可以带来特征提取的性能和计算优势。网络中的集体参数为 679.77 万，其中大部分参数归因于网络的 Inception 模块。事实上，这个数字相当庞大，这反过来使 GoogLeNet 成为一个非常复杂且高容量的深度网络。作为末端全连接层的替代方案，GoogLeNet 使用全局平均池化，因此它不太容易过拟合，并节省了大量参数。与最大池化层类似，GAP 层用于减小 3D 张量的空间维度。然而，GAP 层实现了一种更极端的降维形式，即维度为 `h × w × d` 的张量被缩减为维度为 `1 × 1 × d` 的大小。为了将每个 `h × w` 特征图减少为单个数字，GAP 层计算每个 `hw` 个值的平均值。

### 4.2: 特征图像形成

不使用原始人脸图像来学习人脸特征，而是使用特征图像，因为它们在初始层面代表了一些显著特征。特征图像形成的过程在后续章节中解释。

### 4.3: 局部方向模式 (LDP) 图像形成

#### 4.3.1: 边缘方向幅度计算

#### 4.3.2: 最高边缘方向幅度识别

从尺寸为 `n * p` 的输入图像 `I` 中计算最大边缘方向幅度 `E`，使用公式 [(3)](#B9780323852098000092.xhtml#fo0020)。

```
$E_{i,j} = \max_{z = 1,2,\ldots,8}\sum\limits_{l = - 1}^{1}\sum\limits_{k = - 1}^{1}K_{ij}^{z} * I_{l + i,k + j}$
```

![si3_e](images/B9780323852098000092/si3_e.png)  (3)

其中 `i` 和 `j` 分别从 2 到 `n − 1` 和 2 到 `p − 1`。它是基于所有罗盘方向上的八个 Kirsch 核系列 `k` 计算的。它取决于产生最重要边缘幅度的掩模。

#### 4.3.3: LDP 图像计算

设 `Kirsch[i]` 为应用所有八个 Kirsch 核 `K[i]` (`i = 1, 2 … 8`) 后得到的响应。设最高边缘幅度表示为 `Kirsch[max]`。所有像素的 LDP 值使用公式 [(4)](#B9780323852098000092.xhtml#fo0025) 计算。

```
$\begin{matrix} {\mathit{LDP} = \sum\limits_{i = 0}^{7}b\left( {\mathit{Kirsch}_{i} - \mathit{Kirsch}_{\max}} \right) * 2^{i}} \\ {\text{where}\mspace{9mu} b\left( x \right) = \left\{ \begin{array}{l} {1;\mspace{9mu} x > 0} \\ {0;\mspace{9mu}\text{otherwise}} \\ \end{array} \right\}} \\ \end{matrix}$
```

![si4_e](images/B9780323852098000092/si4_e.png)  (4)

由于图像是通过考虑所有八个方向生成的，因此产生了一个鲁棒的特征图像。

## 5: 浅层 CNN

本工作中采用的浅层 CNN 结构如 [图 8](#B9780323852098000092.xhtml#f0045) 所示。CNN 包含三个卷积层以及三个池化层。在 [表 1](#B9780323852098000092.xhtml#t0010) 中，列举了每个 CNN 层采用的参数。为了将特征图像集转换为可学习的 3D 滤波器集，采用了卷积层。为了减小特征图的维度并消除冗余细节，采用池化层来完成下采样。

这些层最小化了所用参数的空间复杂度，并且还消除了过拟合问题。这些层的使用方式使它们能够自适应地学习更具判别力和最优的特征。卷积层中使用的滤波器组处理输入的局部部分。这些滤波器在处理人脸的某些部分时产生强烈响应，同时抑制其他部分，从而产生关键的局部结构。在卷积层中经过几次这样的滤波后，在最大池化层中对滤波结果进行下采样，使其对位置变化具有鲁棒性。

归一化层被用在中间，以改进训练过程并减少网络对初始化的依赖。它对流经网络的梯度值进行归一化。
