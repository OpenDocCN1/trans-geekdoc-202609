

## 3.1.2：评估

为了评估所用质量估计与我们提出框架的对比情况，我们使用了扩展 Yale 数据库 B [^(171)](#fn171)。

其次，为评估所提亮度度量如何反映图像亮度的变化，我们引入了光照偏差。模型性能的一个关键因素是图像亮度。图像应有适当的照明，以保持高光、中间调和阴影之间的可区分性。

为测试模型性能，我们人为引入了图像亮度强度的一些变化。`Gamma parameter` 是我们调整光照强度所依据的关键概念。若 `γ < 1`，映射趋向更高亮度，反之亦然。为评估性能如何受聚焦、锐度、模糊度变化的影响，我们在不同层级上操控了图像的平滑处理。

当通过 `Gamma parameter` 将图像对比度设定在 0.4 左右时，可获得最佳结果。对于亮度，度量值在 0.5 左右时效果最佳。当 `gamma value` 设定在 0.1 到 0.2 之间时，聚焦度量处于最佳。图像锐度应保持在 0.7 左右，光照在 0.6 左右以获得最佳结果。因此，我们可以得出结论：人脸识别模型的性能依赖于输入图像的各种外部条件。条件最优时，我们可获得约 97.2% 的准确率。然而，平均准确率为 95.3%。在现实世界中，该框架极可能遇到光照一般的室内场景。因此采集了如 [图 8](#B9780323852098000018.xhtml#f0045) 所示的测试图像以复现此类场景。若环境光照过暗且 `HOG algorithm` 无法确定对比度梯度，框架准确率将降至 75%–85%。若人脸背后有强逆光，准确率也会显著下降。网络摄像头在此类情况下会自动调整曝光，导致人脸变暗，使框架无法识别人脸。[表 1](#B9780323852098000018.xhtml#t0010) 将所提框架与其他一些 HOG 实现进行了对比。
