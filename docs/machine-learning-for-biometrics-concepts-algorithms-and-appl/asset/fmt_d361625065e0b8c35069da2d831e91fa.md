
# Fundus Camera and ANFIS Architecture

A fundus camera is also called a retinal camera. It is equipped with a camera attached to a sophisticated low-power microscope in order to photograph the eye's inner surface. The retinal vasculature, macula, posterior pole (also named fundus), optic disc, and retina form the interior surface of the eye. Based on the indirect ophthalmoscope, the optical design is done using a fundus camera. The viewing angle is the optical acceptance angle of the lens used to describe fundus cameras.

In a fundus camera, a wide angle of view has an angle of view between 45 and 140 degrees, a normal angle of view has an angle of view of 30 degrees, and a narrow angle of view has an angle of view of 20 degrees or less. The normal angle of view is used to create a film image 2.5 times larger than life. The wide angle of view provides proportionately less retinal magnification. [Fig. 5A–C](#B9780323852098000055.xhtml#f0030) shows the different views of the retina at different angles of view such as 20, 40, and 60 degrees, respectively.

In the training phase depicted in [Fig. 6](#B9780323852098000055.xhtml#f0035), a fundus camera is employed in capturing the image of the retinal fundus from a set of human eyes. In image preprocessing, the blood vessels in the retinal image of human eyes are segmented using Mathematical-Morphology-Based Edge Detection. Using the Canny edge detection technique, the edge of the fovea has been extracted. Once the edge has been extracted, the diameter of the fovea has been measured. Similarly, other features have been extracted and stored as a dataset. (See [Fig. 7](#B9780323852098000055.xhtml#f0040).)

Then, the segmented image is given as the input to the process of feature extraction technique for extracting the feature from the segmented feature to perform the training process.

Once the feature has been extracted, it is converted to a dataset for further processing. Once the dataset creation is finished with sufficient retinal images, it is given as an input to `ANFIS` for training. Once the training is completed, the `ANFIS` trained model is ready for evaluation.

In order to demonstrate the working process of the `ANFIS` architecture, the network structure is shown in [Fig. 8](#B9780323852098000055.xhtml#f0045). Based on a first-order Sugeno model, the following two rules, which are fuzzy IF-THEN rules, are defined:

$$
\begin{array}{l}
\text{Rule}_{(1)}:\mspace{9mu}\mathbf{IF}\mspace{2mu} x\mspace{2mu}\text{is}\mspace{2mu} A_{1}\mspace{2mu}\mathbf{AND}\mspace{2mu} y\mspace{2mu}\text{is}\mspace{2mu} B_{1},\mathbf{THEN} \\
\mspace{104mu} f_{1} = p_{1}x + q_{1}y + r_{1} \\
\text{Rule}_{(2)}:\mspace{9mu}\mathbf{IF}\mspace{2mu} x\mspace{2mu}\text{is}\mspace{2mu} A_{2}\mspace{2mu}\mathbf{AND}\mspace{2mu} y\mspace{2mu}\text{is}\mspace{2mu} B_{2},\mathbf{THEN} \\
\mspace{104mu} f_{2} = p_{2}x + q_{2}y + r_{2}
\end{array}
$$

where

*   `x` and `y` are the variables that are given as input,
*   `f[1]` and `f[2]` are the first-order polynomials that produce the output,
*   `A` and `B` are the sets of fuzzy available in the antecedents part of IF-THEN rules, and
*   `p[1]`, `q[1]`, `p[2]`, and `q[2]` are the design parameters which are constants that are determined during the training phase.

![Fig. 8 ANFIS network structure.](images/B9780323852098000055/f05-08-9780323852098.jpg)

**Fig. 8** ANFIS network structure.

The step-by-step procedure involved at each and every individual layer in the `ANFIS` structure is illustrated in detail in the forthcoming steps:

## Step 1: Fuzzification Layer

Each and every node in this layer contains a membership function which is adaptive in nature. The Fuzzification Layer is the first layer which is used to fuzzificate the inputs; that is, it produces the membership values for the given input as an output of this layer. The membership function associated with every node, `i`, in this layer is described in Eq. [(1)](#B9780323852098000055.xhtml#fo0015).

$$O_{i}^{1} = \mu_{A_{i}}(x)$$

![si2_e](images/B9780323852098000055/si2_e.png) (1)

where

*   `x` is the input variable that is given as an input to node `i`,
*   `\mu[Ai]` is the fuzzy membership function of the variable `A[i]`, and
*   `A[i]` is the linguistic variable associated with this node function.

The equation to determine the bell-shaped membership function `\mu[A[i]](x)` is formulated as in Eq. [(2)](#B9780323852098000055.xhtml#fo0020) or in Eq. [(3)](#B9780323852098000055.xhtml#fo0025)

$$\mu_{A_{i}}\left( x \right) = \frac{1}{1 + \left\lbrack \left( \frac{x - c_{i}}{a_{i}} \right)^{2} \right\rbrack^{b_{i}}},\mspace{22mu} i = 1,2$$

![si3_e](images/B9780323852098000055/si3_e.png) (2)

or

$$\mu_{A_{i}}\left( x \right) = \exp\left\{ {- \left( \frac{x - c_{i}}{a_{i}} \right)^{2}} \right\}\mspace{342mu}$$

![si4_e](images/B9780323852098000055/si4_e.png) (3)

where

*   `x` is the variable that is given as an input and
*   `{a[i], b[i], c[i]}` is the set of parameters of the membership function to be tuned.

## Step 2: Implication Layer

In this layer, all the nodes are fixed and labeled with the symbol "M" that represents the multipliers. The firing fuzzy strength `w[i]` of each rule is determined by multiplying the incoming signals using the fuzzy AND operators and producing the product value as an output for all nodes using the formula in Eq. [(4)](#B9780323852098000055.xhtml#fo0030)

$$O_{i}^{2} = w_{i} = \mu_{A_{i}}(x) \times \mu_{B_{i}}(y),\quad i = 1,2$$

![si5_e](images/B9780323852098000055/si5_e.png) (4)

## Step 3: Normalizing Layer

In this layer, all the nodes are fixed and labeled with the symbol "N" that represents the normalization process. For each node, the normalized fuzzy firing strength of a rule is calculated using the formula that node's firing strength of a rule divided by the sum of firing strengths of all the rules. The following Eq. [(5)](#B9780323852098000055.xhtml#fo0035) is used to determine the output from that node which is the normalized firing fuzzy strength

$$O_{i}^{3} = \overline{w_{i}} = \frac{w_{i}}{w_{1} + w_{2}},\mspace{22mu} i = 1,2$$

![si6_e](images/B9780323852098000055/si6_e.png) (5)

## Step 4: Defuzzification Layer

All the nodes are adaptive in this layer. The output, which is the weighted consequent value, of this layer is determined using the node function given by Eq. [(6)](#B9780323852098000055.xhtml#fo0040)

$$O_{i}^{4} = \overline{w_{i}}f_{i} = \overline{w_{i}}\left( {p_{i}x + q_{i}y + r_{i}} \right),\mspace{22mu} i = 1,2$$

![si7_e](images/B9780323852098000055/si7_e.png) (6)

where

*   `{p[i], q[i], r[i]}` is the set of parameters of the membership function to be tuned and
*   `w[i]` is the output of Layer 3

In this layer, parameters to be tuned are called consequent parameters.
