
几个世纪以来，人们一直利用身体特征来相互辨识，如面部、语音和步态。19世纪时，德里警察总部刑事识别科主管阿方斯·贝蒂永建立并制定了利用不同身体测量值来识别罪犯的方法。同样，随着他的思想普及，在19世纪末，它被指纹独特性这一无疑更伟大、更可行的发现所掩盖。不久后，几个重要的立法部门理解了首先“交换”罪犯指纹并将其存入数据库的概念。此后，可在犯罪现场“提取”额外的指纹，并与数据库中的指纹同步以识别个人身份。鉴于生物识别技术源于其在执法领域识别罪犯的广泛应用，如今它越来越多地用于众多非执法应用中以实现个体识别。所提系统使用基本的视频采集网络摄像头，并利用信号处理方案调整面部图像的颜色，这可在心跳辅助下执行，以便后续改进。建议的生物识别技术无需任何重要传感器即可工作。它完整且持续，独特地体现了任何活人的心脏运作方式。且极难伪造；与其传统对应物相比，在标准上将具有超稳定性。本文提出了一种利用这一新型生物识别技术进行个体验证的方法，该方法采用充分的信号处理程序和以分类为主的选择系统 [^(151)](#fn151)。

### 2.1: 人脸检测与视频采集

建议的方法要求利用红、绿、蓝 (RGB) 摄像头获取面部视频。由于主要基于心跳信号分析的面部视频无限框架主要使用直接网络摄像头进行视频获取，因此此处该方法选择基于网络摄像头的视频获取方法 [^(152)](#fn152)。

### 2.2: 特征提取

我们从 Radon 图像中提取特征，因为这些快照在基于 ECG 的游戏计划中已被证实能带来适当的结果。要制作此类图像，我们需要一条路径图，该图可通过从面部视频获取的重复心跳信号创建。复制的数量相当于视频中投影的数量 [^(153)](#fn153)。

```
[*f*(*a*,*b*)] = ∫[−∞]^∞ *f*(*a*′cos cos *Ɵ* − *b*′sin sin *Ɵ*,*a*′sin sin *Ɵ* − *b*′cos cos *Ɵ*)*d**y*′………
```

![si1_e](images/B9780323852098000043/si1_e.png)  (1)

其中 *Ɵ* 是 Radon 空间中一条线从线心与主轴的距离向量所形成的点，且：

```
[*a*′*b*′] = [*Ɵ*−sin sin *Ɵ* sin sin *Ɵ* cos cos *Ɵ*] [*a* *b*]
```

![si2_e](images/B9780323852098000043/si2_e.png)  (2)

我们利用著名的闵可夫斯基距离度量来计算 Radon 图像 *R* 的 *m* × *n* 像素的成对距离：

```
$d_{\mathit{st}} = \sqrt[p]{\sum_{i = 1}^{n} \mid \mathit{Rsi} - \mathit{Rti} \mid}p$
```

其中 *R[s]* 和 *R[t]* 是代表 *R* 的每个行向量的行向量。

### 2.3: 识别

我们使用基于决策树的框架进行识别。这是一种流程图状的结构，包含三种区域：(i) 内部节点倾向于对一个属性进行测试；(ii) 分支代表测试的结果；(iii) 叶节点倾向于一个类别标签，这是通过在内部节点隔离所有特征而得出的决定。在使用树（试验阶段）之前，必须对其进行训练。在训练阶段，使用训练数据的特征向量来构建节点并生成决策树。在试验阶段，试验数据的特征向量经历内部节点中的测试，最终获得一个类别名称，其中一个类别代表一个待识别的主体。数据的训练/试验划分在初步结果中说明。

## 3: 结果与讨论

### 3.1: 实验环境

为测试框架的性能，我们使用了公开可访问的 `MAHNOB-HCI` 数据库。该数据库已收集完成，包含由连接到 PC 的简单摄像机（如网络摄像头）捕获的面部记录。该数据库包含两类数据：`Feeling Elicitation Experiment (EEE)`（情绪诱发实验）和 `Verifiable Tagging Experiment (ITE)`（可验证标注实验）。其中，来自 `EEE` 的视频片段为正面人脸视频统计数据，适合我们的试验。因此，我们从 `MAHNOB-HCI` 数据库中选择了 `EEE` 视频片段作为我们的生物识别识别结构的面部记录。[图 3](#B9780323852098000043.xhtml#f0020) 中展示了来自 `MAHNOB-HCI` 数据库的一些视频片段的描述。该数据库从 30 个受试者中产生了 3810 个面部记录。然而，并非所有这些记录都适合我们的试验，原因是时长短、文件缺失以及某些记录中面部被遮挡（额头）。因此，我们选择了 351 个适合我们研究的记录。这些记录来自 18 个受试者（每个受试者 16-20 个记录）。我们在新颖的重叠测试中，使用每个视频的前 20 秒进行测试，并用 80% 的数据进行规划。
