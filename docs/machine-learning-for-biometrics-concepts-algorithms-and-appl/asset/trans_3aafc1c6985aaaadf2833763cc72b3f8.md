

# 学龄前儿童 0.29 0.05

## 儿童面部发育

Farkas 等人的论文研究表明，在儿童面部发育的前 2 年中，嘴宽增加而嘴高减小。嘴部形状从“花蕾状”转变为更成人的类型。面部特征在第一年生长非常迅速，第二年增长速度减缓。从 3 岁到 9 岁，后续变化缓慢且不规则 [⁶](#fn6)。

儿童识别还有其他困难，例如他们通常处于玩耍心情，这会导致表情和姿态变化。虽然成人监督和激励有助于提高数据采集质量，但幼儿的注意力持续时间非常有限。正面人脸采集过程中仅允许表情变化。如果通过目视检查采集的图像发现姿态、光照或模糊等其他变化，则需要重新采集图像 [⁷](#fn7)。

因此，数据采集过程中保持冷静是非常推荐的。数据采集所需时间也比成人数据采集更长。由于这些障碍，公开可用的儿童数据库很少。

### 4.1：数据库预处理

根据儿童人脸识别文献研究，预处理是手动进行的 [^(12)](#fn12)。

预处理步骤包括人脸归一化、统一图像尺寸、基于眼睛对齐以及强度归一化。根据特征提取算法的需要，人脸图像被手动裁剪为不同尺寸。[图 9](#B9780323852098000110.xhtml#f0050) 显示了手动裁剪图像的样本。本研究中，为 PCA 和 LDA 算法进行灰度转换，CNN 使用 RGB 图像。每个受试者的裁剪图像（5–10 张）存放在单独文件夹中。最后，所有受试者文件夹放在一个数据库文件夹中。

![图 9 预处理后的图像。](images/B9780323852098000110/f01-09-9780323852098.jpg "fig:")

根据研究观察，手动裁剪图像效果较好。因此，我们手动裁剪所有图像，使其尺寸一致。PCA 和 LDA 特征提取算法中进行 RGB 转灰度处理。CNN 使用 RGB 图像。

### 4.2：COTS——商用现成人脸匹配器

它是包含特征提取的完整解决方案。大多数儿童人脸识别研究使用 COTS 匹配器 [^(13)](#fn13)。

## 5：特征提取技术

特征提取是一个过程，其主要目标是从数据库图像中减少特征数量。系统仅凭这些特征即可识别不同人员的人脸图像。特征可以是线条、双眼距离、点、唇眼距离等。它还能从现有特征创建新特征。新创建的特征数量较少，有助于降低计算复杂度。特征提取技术的性能取决于其利用这些简化特征识别原始图像的效果。此处总结了用于儿童人脸识别的机器学习特征提取算法。这些算法的性能完全依赖于特征提取。

### 5.1：PCA——主成分分析

PCA 是一种简单且广泛使用的基于外观的算法。它是一种无监督学习算法，即 PCA 算法中不使用类标签。在新生儿人脸识别的初步研究中，Bharadwaj 等人指出，降低图像分辨率可提高 PCA 性能 [^(14)](#fn14)。

PCA 用于人脸识别时，通过预处理图像准备人脸图像数据库。

`S = {Γ[1], Γ[2], Γ[3], … Γ[M]}`

![si1_e](images/B9780323852098000110/si1_e.png) (1)

设每张图像大小为 224 × 224 像素。将其转换为 M × N 维向量。此时图像向量大小为 50,176。计算平均人脸。平均人脸向量 (Ψ) 通过公式 [(2)](#B9780323852098000110.xhtml#fo0015) 计算。

```
Ψ = (1/M) Σ_{n=1}^{M} Γ_n
```

![si2_e](images/B9780323852098000110/si2_e.png) (2)

儿童平均人脸图像如 [图 10](#B9780323852098000110.xhtml#f0055) 所示。

![图 10 儿童平均人脸图像。](images/B9780323852098000110/f01-10-9780323852098.jpg "fig:")

从原始人脸中减去平均人脸向量，结果存储在变量中，

`φ[i] = Γ[i] − Ψ`

![si3_e](images/B9780323852098000110/si3_e.png) (3)

然后，协方差矩阵 C 通过以下方式获得，

```
C = (1/M) Σ_{n=1}^{M} φ_n φ_n^T
C = A A^T  N² × N² 矩阵，
```

![si4_e](images/B9780323852098000110/si4_e.png) (4)

其中 `A = [φ[1], φ[2], φ[3], φ[4], … φ[M]]` N² × M 矩阵。

进一步计算协方差矩阵的特征向量和特征值。公式 [(4)](#B9780323852098000110.xhtml#fo0025) 中的协方差矩阵 C 维度很高。对于 224 × 224 图像，必须计算 50,176 × 50,176 矩阵并得出 50,176 个特征脸。从计算角度看这效率不高，因为大多数特征脸对我们的任务无用。

因此，我们考虑矩阵（M × M 矩阵）。

`现在计算 L = A A^T 的特征向量 v[i]，`

![si5_e](images/B9780323852098000110/si5_e.png) (5)

L 的 M 个特征向量用于求出 C 的 M 个特征向量，它们构成特征脸基，儿童的 90 个特征脸如 [图 11](#B9780323852098000110.xhtml#f0060) 所示。

```
u_i = Σ_{i=1}^{M} v_i φ_i
```

![si6_e](images/B9780323852098000110/si6_e.png) (6)

![图 11 特征脸示例。](images/B9780323852098000110/f01-11-9780323852098.jpg "fig:"")

仅保留 K 个特征向量（对应 K 个最大特征值），特征值低的其他特征脸可省略，因为它们仅解释人脸特征的一小部分。[图 12](#B9780323852098000110.xhtml#f0065) 显示了儿童人脸的 PCA 投影。

![图 12 儿童的 PCA 投影。](images/B9780323852098000110/f01-12-9780323852098.jpg "fig:")

然后绘制特征值谱图（[图 13](#B9780323852098000110.xhtml#f0070)）以确定主成分数量。分析图表后发现，90 个分量后方差几乎恒定。因此，研究使用前 90 个主成分。

![图 13 特征值与主成分关系图。](images/B9780323852098000110/f01-13-9780323852098.jpg "fig:")

PCA 降低数据维度，对小型数据库效果较好。因未使用类别成员信息（无监督学习），同类和异类样本处理方式相同。

混淆矩阵可作为性能参数。它显示预测准确率与实际准确率。同会话 PCA 特征提取结合 SVM 分类准确率为 76%。其混淆矩阵如下 [图 14](#B9780323852098000110.xhtml#f0075) 所示。

![图 14 同会话数据库混淆矩阵。](images/B9780323852098000110/f01-14-9780323852098.jpg "fig:")

### 5.2：LDA——线性判别分析

LDA 是一种有监督学习算法，即使用类标签。LDA 是对 PCA 方法的改进。它最适合类别分离。它使用类内散度矩阵和类间散度矩阵。Tiwari 等人将 FLDA 用于婴儿人脸识别，在 10 个类别下使用 l² − 范数获得了良好准确率 [^(15)](#fn15)。

假设有 C 个类别，μ[i] 为第 i 类的均值向量，i = 1,2,3, …, C。M[i] 为第 i 类内的样本数，i = 1,2,3, …, C。

设 M = Σ[i=0]^C M[i] 为总样本数。

现在，散度矩阵通过类内矩阵与类间矩阵计算。

```
S_w = Σ_{i=1}^{C} Σ_{j=1}^{M} (Xj - μ_i) (Xj - μ_i)^T
```

![si7_e](images/B9780323852098000110/si7_e.png) (7)

```
S_b = Σ_{i=1}^{C} (μ_i - μ) (μ_i - μ)^T
```

![si8_e](images/B9780323852098000110/si8_e.png) (8)

其中 `μ = (1/C) Σ_{i=1}^{C} μ_i` ![si9_e](images/B9780323852098000110/si9_e.png) 为整个数据集的均值。

数据投影由公式 [(9)](#B9780323852098000110.xhtml#fo0050) 给出，

`y = U^T x`

![si10_e](images/B9780323852098000110/si10_e.png) (9)

其中 `U^T` 为投影矩阵。

LDA 计算使类间散度最大化且类内散度最小化的变换

```
max |U^T S_b U| / |U^T S_w U| = max |S̃_b| / |S̃_w|  特征值乘积
```

![si11_e](images/B9780323852098000110/si11_e.png) (10)

`S̃_b,` ![si12_e](images/B9780323852098000110/si12_e.png) `S̃_w` ![si13_e](images/B9780323852098000110/si13_e.png)：投影数据 y 的散度矩阵。

LDA 对大型数据库效果最佳。因使用标签，类间分类效果好。LDA 结果对小型数据库非最优。

LDA 特征提取结合线性回归分类器，跨会话数据库准确率达 84%。其混淆矩阵如下 [图 15](#B9780323852098000110.xhtml#f0080) 所示。

![图 15 跨会话数据库混淆矩阵。](images/B9780323852098000110/f01-15-9780323852098.jpg "fig:")

机器学习分类指数据的自动分类或归类。本研究执行多类别儿童识别。因此详细介绍多分类技术。不同分类技术如 [图 16](#B9780323852098000110.xhtml#f0085) 所示。

![图 16 不同分类技术。](images/B9780323852098000110/f01-16-9780323852098.jpg "fig:")

### 6.1：逻辑回归

逻辑回归是一种统计方法，主要用于二分类。它通过 Sigmoid 函数从线性回归推导而来。

线性回归方程。

`y = β0 + β1 X1 + β2 X2 + … + βn Xn`

![si14_e](images/B9780323852098000110/si14_e.png) (11)

其中 y 为因变量，X1, X2, … Xn 为自变量。

Sigmoid 函数：

```
S(x) = 1 / (1 + e^{-x})
```

![si15_e](images/B9780323852098000110/si15_e.png) (12)

将 Sigmoid 函数应用于线性回归得到逻辑回归方程。

```
S(x) = 1 / (1 + e^{-β0 + β1 X1 + β2 X2 + … + βn Xn})
```

![si16_e](images/B9780323852098000110/si16_e.png) (13)

该方程输出始终在 0 和 1 之间。多项逻辑回归可用于多分类。它使用 Softmax 函数进行多分类。

```
ŷ = softmax(xW + b)
```

![si17_e](images/B9780323852098000110/si17_e.png) (14)

### 6.2：K-近邻

它是一种有监督学习算法，分类不使用概率，而是使用距离度量。KNN 算法基于特征相似性搜索。它认为相似特征总是彼此靠近。KNN 算法中，K 为最近邻数量。K 的选择由用户决定；通常为奇数。K 值多为 n 的平方根。KNN 使用的距离度量有闵可夫斯基距离、曼哈顿距离和欧氏距离。

闵可夫斯基距离方程为通式，可推导出曼哈顿和欧氏距离。

```
d(x,y) = (Σ_{i=1}^{n} |x_i - y_i|^p)^{1/p}
```

![si18_e](images/B9780323852098000110/si18_e.png) (15)

`p = 1`，曼哈顿距离；`p = 2`，欧氏距离；`p = ∞`，切比雪夫距离。

### 6.3：决策树

它是一种有监督学习算法。该算法持续将数据分割成更小部分直到达到其类别。它使用节点、边和叶节点等术语。决策树分类器中，首先计算数据库的熵。它告诉我们数据库的不确定性程度。不确定性值越小，分类结果越好。计算每个特征的信息增益。这表明分割数据库后不确定性减少了多少。最后计算所有特征的信息增益，按信息增益最高的特征分割数据库。过程重复直到所有节点清晰。决策树分类器的基本结构及实现如 [图 17](#B9780323852098000110.xhtml#f0090) 所示。

![图 17 决策树基本结构与实现。](images/B9780323852098000110/f01-17-9780323852098.jpg "fig:")

### 6.4：支持向量机

它是一种有监督学习算法。我们将其用于图像分类。SVM 旨在为数据库特征找到正确的超平面。正确超平面是使两个或更多数据点间间隔最大化的超平面。借助这些超平面，我们能分类不同数据点。[图 18](#B9780323852098000110.xhtml#f0095) 给出了分离数据点的三个超平面 A、B 和 C。超平面 B 到两个数据点的间隔最大。因此，B 是分离这两类的正确超平面。分类两类以上使用多类 SVM [^(16)](#fn16)。

![图 18 支持向量机分类器。](images/B9780323852098000110/f01-18-9780323852098.jpg "fig:")

### 6.5：高斯朴素贝叶斯

朴素贝叶斯分类器基于贝叶斯定理。它提供图像特征间的强独立性假设。它们属于概率分类器范畴。这些分类器易于实现，因此在机器学习分类中广泛使用。贝叶斯定理如公式 [(16)](#B9780323852098000110.xhtml#fo0085) 所示。

```
P(A | B) = P(B | A) P(A) / P(B)
```

![si19_e](images/B9780323852098000110/si19_e.png) (16)

高斯朴素贝叶斯是朴素贝叶斯的一种分类模型。连续数据服从正态（高斯）分布。因此，我们使用高斯朴素贝叶斯对连续数据分类。在高斯模式下，从训练数据库计算均值和标准差更容易。

## 7：深度学习方法

深度学习是机器学习的一个分支，结合了特征提取和分类过程。在大数据集上表现优于机器学习算法。儿童人脸识别使用 CNN。CNN 第一层学习人脸图像的低级特征，如线条和边缘。随着 CNN 层数增加，学习高级特征。因此，深度学习方法擅长高级特征。

本研究从基础到优化级实现了 CNN。首先 CNN 有 3 个卷积层，随后为同会话和跨会话数据库增加到 6 层。激活函数用 ReLU，全连接层用 Softmax。损失函数为稀疏分类交叉熵损失。训练集 70%，测试集 30%。CNN 架构如 [图 19](#B9780323852098000110.xhtml#f0100) 所示。
