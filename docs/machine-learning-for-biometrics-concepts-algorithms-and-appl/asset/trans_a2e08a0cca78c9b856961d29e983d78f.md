

# 3.2.4：测试与结果

用于训练的序贯模型包含五个全连接层、一个用于调整过拟合的 Dropout 层以及一个批量归一化层。前四个全连接层分别包含 512、256、128 和 64 个 ReLU 激活单元。ReLU 是一种非线性激活函数，可表示如下：

$$a = \mathit{ReLU}\left( b \right) = \left\{ \begin{matrix} {b;\mspace{27mu}\text{if}\ b \geq 0} \\ {0;\mspace{27mu}\text{if}\ b < 0} \\ \end{matrix} \right.$$

![si1_e](images/B9780323852098000018/si1_e.png) (1)

此处，“a” 和 “b” 分别代表输出信号和输入信号 [^(180)](#fn180)。

测试数据集从原始的 30,000 张图像池中获取，按 90:10 的比例划分训练集和测试集。每张图像都按前述顺序进行了预处理：转换为灰度图，随后进行人脸检测、裁剪和调整大小。

Dropout 率降低至 0.7 以保持较低的训练损失；例如，较低的 Dropout 率（0.4）会显著增加最后几个周期的训练损失，同时也会降低测试准确率。当批量归一化层放在第三个全连接层之后时，效果最好。该序贯模型在训练数据集上达到了 89.58% 的准确率，在测试数据集上达到了 89.2% 的准确率。训练期间，学习率设置为 0.001。使用的损失函数是带有 Adam 优化器的分类交叉熵损失。

[图 12](#B9780323852098000018.xhtml#f0065) 和 [图 13](#B9780323852098000018.xhtml#f0070) 分别展示了在序贯模型的训练和测试验证过程中，准确率和分类交叉熵损失随周期变化的图表。结果发现，在第 13 个周期之后，测试验证损失开始增加，而相应的准确率没有显著提高。这暗示发生了过拟合，因为训练准确率在第 13 个周期后仍在持续提高。

召回率矩阵显示，某些情绪类别略微偏向“厌恶”情绪类别。来自“悲伤”和“中性”情绪类别的多张图像被归类为“厌恶”情绪。其原因可能归因于训练数据集中标记为“悲伤”或“中性”的图像数量相对较少，少于标记为“厌恶”的图像数量。这一后果进一步体现在标记为“中性”的图像的召回率值上，即 79.3，这是所有检测到的情绪类别中最低的值。另一方面，“愤怒”情绪类别具有最高的召回率 91.4，这可能是因为训练数据集中标记为“愤怒”的图像数量是所有情绪类别中最多的。

精确率矩阵中的数值表明，“愤怒”情绪类别中有更多的图像被正确分类。这可能归因于该类别训练图像数量较多，且“愤怒”图像面部特征与其他类别差异显著。然而，“悲伤”情绪类别记录了最低的精确率值 77.8，表明被正确分类的预测“悲伤”图像数量较少。

该序贯模型在执行 7 类分类问题时实现了高准确率，该问题涉及将检测到的面部表情分类为 7 个类别之一——愤怒、厌恶、恐惧、开心、中性、悲伤和惊讶。模型及其权重已保存到磁盘，以便对任意拍摄的照片实施情绪检测。
