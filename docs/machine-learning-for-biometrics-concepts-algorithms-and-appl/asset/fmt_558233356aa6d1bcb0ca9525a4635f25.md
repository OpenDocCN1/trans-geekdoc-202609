## 2 文献综述

RDH 是信息安全领域的一个活跃研究领域。RDH 方案允许我们在数字内容中隐藏一些秘密消息以实现安全传输。在接收端，可以在提取隐藏消息的同时恢复原始载体内容。现有的 RDH 方案主要用于以下两个应用：

1.  **医学图像传输**：在医学图像传输中，RDH 方案用于随医学图像一起传输患者记录 [[236]](#fn236)。
2.  **云服务提供商**：云服务提供商使用 RDH 方案将一些额外的元数据信息隐藏在用户上传到云端的数字内容中。由于用户上传的数据应原样返回给云用户，因此云服务提供商不得对上传的数据进行任何永久性更改。在这种情况下，云服务提供商可以使用 RDH 方案 [[237]](#fn237)。

现有的 RDH 方案大体可分为三类：

1.  **自然图像上的 RDH**：在数据隐藏过程中，数据隐藏者会改变原始像素值。基于自然图像的著名 RDH 方案基于直方图平移、差值扩展等概念。还有一些其他方案可用 [[238]](#fn238)。
2.  **加密图像上的 RDH**：在此方案中，数据隐藏者将获得一幅加密图像，并在 RDH 过程中修改加密像素。加密图像上的 RDH 主要有两种方法：加密前预留空间和加密后预留空间 [[239]](#fn239)。
3.  **通过加密的 RDH**：在此方案中，RDH 将在加密图像的过程中进行。RDH 过程将被微调，使得数据隐藏在加密过程中成为可能 [[240]](#fn240)。

在我们提出的方案中，我们采用了通过加密的 RDH 方案，将摄像头捕获的人脸图像视为原始图像，将压缩的指纹数据视为数据。通过使用通过加密的 RDH 方案，指纹数据将被嵌入人脸图像中。最终，我们将得到一幅包含隐藏消息的加密图像。

通过加密的 RDH 方案于 2018 年引入。现有通过加密的 RDH 方案的概述见 [表 1](#B978032385209800002X.xhtml#t0010)。

## 3 提出的方案

本节详述了提出的方案。该方案将用于生物识别认证系统，我们在其中使用云服务提供商存储经过认证人员的详细信息。提出的方案采用双级认证方案，使用人脸识别和指纹识别进行认证。在注册和认证时，用户的人脸图像和指纹应传输到云存储。为了安全地传输人脸图像和指纹等生物识别详细信息，我们使用了通过加密过程的 RDH 方案。提出的方案使用了一种通过加密的 RDH 方案，这与参考文献 [[244]](#fn244) 中报道的方案非常相似。

| 步骤 1 | 使用摄像头捕获彩色人脸图像 |
| :--- | :--- |
| 步骤 2 | 使用指纹扫描仪捕获指纹 |
| 步骤 3 | 将指纹图像（灰度）转换为相应的二值图像 |
| 步骤 4 | 对二值指纹应用游程编码 |
| 步骤 5 | 使用 Elias gamma 编码过程对游程序列进行编码 |
| 步骤 6 | 在 RDH 通过加密的帮助下，将压缩的指纹细节隐藏在人脸图像中，得到包含隐藏数据的加密图像 |
| 步骤 7 | 将包含指纹细节的加密人脸图像传输给云服务提供商 |

RDH 方案的局限性之一是嵌入率低。指纹数据经过压缩，以确保 RDH 方案在将细节嵌入人脸图像时不会遇到任何困难。从人脸图像中分别提取所有三个颜色平面（即 R、G 和 B），并在嵌入指纹数据时分别处理每个平面。每个颜色平面将被划分为不重叠的块，并在每个块中嵌入来自压缩指纹细节的一比特数据。数据隐藏阶段的输出将最终得到一幅加密图像。加密图像可以安全地传输给云服务提供商，用于存储或认证目的。云将处理接收到的数据，并将认证控制消息返回给客户端，以激活某些硬件模块，允许用户进入受限区域。发送端的操作序列见算法 1。
