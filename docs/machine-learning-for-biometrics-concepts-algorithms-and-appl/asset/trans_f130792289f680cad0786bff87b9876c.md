
我们工作的主要目标是融合耳部和侧脸模态，以提高识别性能。其基本原理如下：（1）虽然已有许多利用耳部模态的多模态方法被研究，但基于耳部和侧脸的多模态生物识别研究尚显不足。（2）耳部和侧脸模态具有兼容的特征向量，适合进行特征级和分数级融合。（3）生物特征模态通过使用单一传感器同时采集，从而降低了传感器成本和注册时间。

## 6：结论

在本章中，我们提出了一种基于SPT和局部纹理描述符的改进型多模态耳部和侧脸生物识别身份认证方法。对三种局部描述符LDP、LPQ和BSIF的有效性进行了比较。最后，利用两种独立的融合技术——特征级融合和分数级融合——整合了耳部和侧脸的特征向量。实验结果表明，所提出的多模态识别方法在非受控环境下取得了优于单一耳部和侧脸生物识别的性能。采用BSIF特征描述符的提出方法获得了与最先进的多模态生物识别技术相比极具前景的识别准确率。未来，通过探索各种非手工设计特征以及其他有效的融合方案，可以设计出更高效的多模态生物识别系统。
