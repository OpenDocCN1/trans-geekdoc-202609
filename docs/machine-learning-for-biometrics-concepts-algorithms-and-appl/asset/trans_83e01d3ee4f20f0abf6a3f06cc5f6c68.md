

# 用于入侵检测与防御的深度学习

深度学习（DL）、卷积神经网络（CNN）和循环神经网络（RNN）可用于构建更先进的 ID/IP 系统，通过更准确地评估流量并区分恶意与非恶意网络活动。令人印象深刻的解决方案包括下一代防火墙（NGFW）、Web 应用防火墙（WAF）和 UEBA。为了识别已知威胁，ID/IP 系统使用基于规则和基于特征的控制。对手可以通过更改恶意软件特征轻松绕过传统的网络 ID/IP 系统。基于深度神经网络的系统已被用于解决传统安全用例，如恶意软件和间谍软件检测 [^(223)](#fn223)

## 6.2：恶意软件检测

标准防火墙通过基于特征的检测方案来检测恶意软件。公司维护一个已识别威胁的数据库，并定期更新以纳入新近出现的威胁。虽然该策略对这类威胁效果良好，但难以应对更复杂的威胁。DL 算法无需调用现有特征或攻击样本即可检测更复杂的威胁。相反，它们学习网络行为，并能发现可能预示着不良行为者或恶意软件存在的可疑活动 [^(224)](#fn224)

## 6.3：社会工程学与垃圾邮件检测

社会工程学攻击通常需要心理操纵，以说服毫无戒备的消费者或员工泄露机密或敏感信息。通常，社会工程学包含一封电子邮件或其他联系方式，在受害者心中灌输紧迫感、恐惧或其他相关情绪，导致受害者泄露机密信息或点击恶意链接 [^(225)](#fn225)

## 6.4：网络流量分析

在分析 HTTPS 流量以搜索恶意行为时，深度学习算法显示出了良好的效果。这在应对各类网络威胁（如 SQL 注入和 DoS 攻击）方面极为有用 [^(226)](#fn226)

Alice 与目标服务器之间的通信过程如[图 9](#B9780323852098000079.xhtml#f0050)所示。Alice 通过请求通往服务器的路由发起联系。AES 加密路径由 TOR 网络提供。该路径在 TOR 网络内随机生成。数据包的加密路径以红色高亮显示。简单数据包被传递给服务器，直到到达出口节点，即 TOR 网络的边缘节点。在每个接收阶段，数据包均使用密钥解密。解密后会暴露下一个目标中继地址。此过程持续直到到达 TOR 网络的出口节点，此时数据包的加密终止，并将一个简单的 HTTP 数据包转发给目标服务器 [^(227)](#fn227)

![图 9 TOR 网络中的客户端-服务器通信。](images/B9780323852098000079/f10-09-9780323852098.jpg)

**图 9** TOR 网络中的客户端-服务器通信。

TOR 的创建旨在保护用户隐私。企业网络通过不允许安装 TOR 客户端或阻断入口节点 IP 地址来封锁 TOR 流量。然而，对手和恶意软件有多种方式接入 TOR 网络并利用其发送数据和信息。封锁 IP 地址并非明智之举。对手可能生成不同的 IP 来进行通信。可通过分析流量数据包来检测 TOR 流量。此项检测可在 TOR 节点上进行，也可在客户端与入口节点之间进行。每个流由源地址、源端口、目的地址和目的端口组成的元组构成。

数据研究所用数据获自新不伦瑞克大学。其数据由对大学互联网流量回顾分析所得特征组成。[表 1](#B9780323852098000079.xhtml#t0010) 显示了从数据中提取的元数据。除这些之外，还使用了其他基于流的参数。[图 10](#B9780323852098000079.xhtml#f0055) 描绘了数据集中的一个代表性示例。

| 元信息参数 | 参数解释 |
| --- | --- |
| FIAT | 前向包间到达时间，指前向发送的两个数据包之间的时间间隔（均值、最小值、最大值、标准差）。 |
| BIAT | 后向包间到达时间，指后向发送的两个数据包之间的时间间隔（均值、最小值、最大值、标准差）。 |
| FLOWIAT | 流包间到达时间，指任一方向发送的两个数据包之间的时间间隔（均值、最小值、最大值、标准差）。 |
| ACTIVE | 流在变为空闲前保持活动状态的时间量（均值、最小值、最大值、标准差）。 |
| IDLE | 流在变为活动前保持空闲状态的时间量（均值、最小值、最大值、标准差） |
| FB PSEC | 流字节每秒。流数据包每秒。时长：流的持续时间。 |

隐藏层数量从 2 到 10 不等。N = 5 被认为是最佳数量。所有隐藏层均使用 ReLU 作为激活函数。隐藏层默认为稠密层，维度为 100。输出节点由 Sigmoid 函数激活。DL 模块在后端使用 Keras 和 TensorFlow 进行训练。FFN 使用二元交叉熵损失进行优化。模型使用不同的轮数进行训练。[图 12](#B9780323852098000079.xhtml#f0065) 描绘了一次训练模拟，随着轮数增加，效率提升且损失值最小化。

将 DL 系统的结果与其他估计器进行比较。使用召回率、精确率和 F-Score 等标准分类指标衡量估计器的效率。所提出的基于 DL 的框架在检测 TOR 类别方面表现良好。对于非 TOR 类别样本，基于 DL 的方法显示出了最小化误报案例的效果 [^(228)](#fn228)
