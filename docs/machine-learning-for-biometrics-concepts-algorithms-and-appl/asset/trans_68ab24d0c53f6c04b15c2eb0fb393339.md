## 9：讨论与结论

儿童的健康与安全是任何国家的重要议题。稳健的儿童人脸识别系统是当务之急。利用人脸识别进行儿童生物特征识别，有助于关注儿童健康以及寻找失踪儿童。人脸识别系统应能应对儿童自然活动引起的各种变化。此外，算法应足够强大，以追踪儿童面部的纵向变化。在本章中，我们提出了一种基于机器学习和深度学习的儿童人脸识别方法。

构建人脸识别系统的主要障碍是数据库收集。正如本章所讨论的，网上有许多人脸图像数据库可用，但大多包含成人面部图像，儿童面部图像很少。此外，儿童图像数量很少，且多在单一会话中拍摄。为了对儿童面部进行实时研究，我们需要儿童的纵向数据集。这表明数据集应在一段时间内收集（间隔几个月），以记录面部变化并相应调整识别系统。因此，我们收集了自己的纵向数据集。该数据集包含 81 位同一会话受试者和 48 位跨会话受试者，后者为同 48 位受试者在几个月后拍摄的面部图像。两次会话间的间隔为 3-6 个月。

获取的数据集需要预处理，以提高人脸识别算法后续步骤的性能。主要任务是从每张图像中所有其他背景中仅提取人脸区域。此处，我们采用了人工裁剪人脸图像的方式，因为大多数研究者也使用相同技术。所有裁剪后的人脸图像均调整为相同尺寸。

预处理之后是特征提取步骤。特征提取通过降低原始数据的维度，使其易于处理，同时使识别过程在计算上更高效。此处，我们主要采用基于 `PCA` 和 `LDA` 的方法进行特征提取，这些方法更常用于成人人脸识别。提取特征后，我们使用了基于机器学习的多类分类技术。本研究对 `支持向量机 (SVM)`、`K-近邻 (KNN)`、`逻辑回归 (LR)`、`决策树` 和 `高斯朴素贝叶斯` 进行了比较研究和评估。采用 `LDA` 特征和 `逻辑回归` 获得的结果最为理想。众所周知，`LDA` 是 `PCA` 的改进，最适合类别分离。`逻辑回归` 是一种借助 softmax 函数进行多类分类的统计方法。在基于机器学习的分类器层面，虽然有许多算法可供比较，但对于我们的儿童人脸数据库，`LDA` 和 `LR` 表现最为理想。

为进一步提升性能，特别是针对跨会话人脸图像识别，我们实施了深度学习方法。深度学习是利用人工神经网络的机器学习分支。`CNN` 是深度学习的方法之一。`CNN` 主要用于图像识别和分类。`CNN` 不需要复杂的预处理算法，能自行检测显著特征。我们首先实现了基础 `CNN`，然后对其进行优化以适应儿童人脸数据库。在层数为 6、激活函数为 `Relu` 的优化 `CNN` 中，跨会话准确率从 86% 提升至 94%。

此处我们展示了机器学习和深度学习可用于追踪童年期的面部变化，并能给出良好的识别准确率。本文工作的主要亮点在于：收集了跨会话面部图像（数据库）、采用了识别模式（而大多数文献讨论验证模式）、以及机器学习方法获得的准确率与其他研究者报道的相当。未来需要利用更大的数据库和增强数据进行进一步研究，以训练网络并获得更好的结果。
