

# 眼底相机与 ANFIS 架构

眼底相机也称为视网膜相机。它配备了一台连接在精密低倍显微镜上的相机，用于拍摄眼球内表面。视网膜血管、黄斑、后极（也称为眼底）、视盘和视网膜构成了眼球的内表面。基于间接检眼镜，使用眼底相机进行光学设计。视角是用于描述眼底相机的透镜的光学接受角。

在眼底相机中，广角视角的视角在 45 到 140 度之间，标准视角的视角为 30 度，窄角视角的视角为 20 度或更小。标准视角用于创建放大 2.5 倍的胶片图像。广角视角提供的视网膜放大倍数成比例地较小。[图 5A–C](#B9780323852098000055.xhtml#f0030) 分别显示了 20、40 和 60 度等不同视角下的视网膜不同视图。

![图 5 不同视角下的视网膜不同视图。](images/B9780323852098000055/f05-05-9780323852098.jpg)

**图 5** 不同视角下的视网膜不同视图。

然后，将分割后的图像作为输入提供给特征提取技术的过程，以从分割特征中提取特征来执行训练过程。

一旦提取了特征，它就会被转换为数据集以供进一步处理。一旦使用足够的视网膜图像完成了数据集的创建，它就会作为输入提供给 `ANFIS` 进行训练。一旦训练完成，`ANFIS` 训练模型就准备好进行评估了。

为了演示 `ANFIS` 架构的工作过程，网络结构如 [图 8](#B9780323852098000055.xhtml#f0045) 所示。基于一阶 Sugeno 模型，定义了以下两条模糊 IF-THEN 规则：

$$
\begin{array}{l}
\text{规则}_{(1)}:\mspace{9mu}\mathbf{IF}\mspace{2mu} x\mspace{2mu}\text{是}\mspace{2mu} A_{1}\mspace{2mu}\mathbf{AND}\mspace{2mu} y\mspace{2mu}\text{是}\mspace{2mu} B_{1},\mathbf{THEN} \\
\mspace{104mu} f_{1} = p_{1}x + q_{1}y + r_{1} \\
\text{规则}_{(2)}:\mspace{9mu}\mathbf{IF}\mspace{2mu} x\mspace{2mu}\text{是}\mspace{2mu} A_{2}\mspace{2mu}\mathbf{AND}\mspace{2mu} y\mspace{2mu}\text{是}\mspace{2mu} B_{2},\mathbf{THEN} \\
\mspace{104mu} f_{2} = p_{2}x + q_{2}y + r_{2}
\end{array}
$$

其中

*   `x` 和 `y` 是作为输入给定的变量，
*   `f[1]` 和 `f[2]` 是产生输出的一阶多项式，
*   `A` 和 `B` 是 IF-THEN 规则前件部分中可用的模糊集合，以及
*   `p[1]`、`q[1]`、`p[2]` 和 `q[2]` 是在训练阶段确定的作为设计参数的常数。

![图 8 ANFIS 网络结构。](images/B9780323852098000055/f05-08-9780323852098.jpg)

**图 8** ANFIS 网络结构。

`ANFIS` 结构中每个单独层所涉及的分步过程在以下步骤中详细说明：

## 步骤 1：模糊化层

该层中的每个节点都包含一个自适应性质的隶属函数。模糊化层是第一层，用于对输入进行模糊化；即它产生给定输入的隶属值作为该层的输出。与该层中每个节点 `i` 相关的隶属函数在公式 [(1)](#B9780323852098000055.xhtml#fo0015) 中描述。

$$O_{i}^{1} = \mu_{A_{i}}(x)$$

![si2_e](images/B9780323852098000055/si2_e.png) (1)

其中

*   `x` 是作为输入提供给节点 `i` 的输入变量，
*   `\mu[Ai]` 是变量 `A[i]` 的模糊隶属函数，以及
*   `A[i]` 是与该节点函数相关的语言变量。

确定钟形隶属函数 `\mu[A[i]](x)` 的公式如公式 [(2)](#B9780323852098000055.xhtml#fo0020) 或公式 [(3)](#B9780323852098000055.xhtml#fo0025) 所示

$$\mu_{A_{i}}\left( x \right) = \frac{1}{1 + \left\lbrack \left( \frac{x - c_{i}}{a_{i}} \right)^{2} \right\rbrack^{b_{i}}},\mspace{22mu} i = 1,2$$

![si3_e](images/B9780323852098000055/si3_e.png) (2)

或

$$\mu_{A_{i}}\left( x \right) = \exp\left\{ {- \left( \frac{x - c_{i}}{a_{i}} \right)^{2}} \right\}\mspace{342mu}$$

![si4_e](images/B9780323852098000055/si4_e.png) (3)

其中

*   `x` 是作为输入给定的变量，以及
*   `{a[i], b[i], c[i]}` 是待调整的隶属函数参数集。

## 步骤 2：蕴含层

在该层中，所有节点均为固定节点，并标记为代表乘法器的符号 "M"。每条规则的模糊触发强度 `w[i]` 通过使用模糊 AND 运算符相乘传入信号来确定，并使用公式 [(4)](#B9780323852098000055.xhtml#fo0030) 为所有节点产生乘积值作为输出

$$O_{i}^{2} = w_{i} = \mu_{A_{i}}(x) \times \mu_{B_{i}}(y),\quad i = 1,2$$

![si5_e](images/B9780323852098000055/si5_e.png) (4)

## 步骤 3：归一化层

在该层中，所有节点均为固定节点，并标记为代表归一化过程的符号 "N"。对于每个节点，使用该节点的规则触发强度除以所有规则触发强度之和的公式来计算规则的归一化模糊触发强度。以下公式 [(5)](#B9780323852098000055.xhtml#fo0035) 用于确定该节点的输出，即归一化的模糊触发强度

$$O_{i}^{3} = \overline{w_{i}} = \frac{w_{i}}{w_{1} + w_{2}},\mspace{22mu} i = 1,2$$

![si6_e](images/B9780323852098000055/si6_e.png) (5)

## 步骤 4：去模糊化层

该层中的所有节点均为自适应节点。该层的输出（即加权后件值）使用由公式 [(6)](#B9780323852098000055.xhtml#fo0040) 给出的节点函数来确定

$$O_{i}^{4} = \overline{w_{i}}f_{i} = \overline{w_{i}}\left( {p_{i}x + q_{i}y + r_{i}} \right),\mspace{22mu} i = 1,2$$

![si7_e](images/B9780323852098000055/si7_e.png) (6)

其中

*   `{p[i], q[i], r[i]}` 是待调整的隶属函数参数集，以及
*   `w[i]` 是第 3 层的输出

在该层中，待调整的参数称为后件参数。
