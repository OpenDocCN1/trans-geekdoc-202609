
在本文中，我们讨论了利用空域和频域增强技术、以最小误差进行掌纹图像质量评估的优良度量。这使其更适合特定任务。多种定量图像质量度量 [[^(83)](#fn83)]

### 表 2：图像质量统计度量

| 序号 | 质量度量 | 数学公式 | 说明/最优值 |
| --- | --- | --- | --- |
| 1 | 对比度度量 | `CM = (1/N) * Σ (Var_j(processed) / Var_j(original))` | 其中 `Var[j]` 表示 16 × 16 补丁尺寸的强度值的方差。`Var[j](original)` 是在原始图像上计算的方差，`Var[j](processed)` 表示在处理后图像上计算的方差。`N` 代表补丁的数量。 |
| 2 | 峰值信噪比 (PSNR) | `PSNR = 20 * log10(L^2 / ((1/(M*N)) * ΣΣ (I_m(i,j) - I_g(i,j))^2))` | 其中 `L` 表示图像中存在的灰度级数。PSNR 用于量化信号最大功率与影响其表示可靠性的噪声干扰功率之间的关系。PSNR 的最优值对应越高越好。 |
| 3 | 平均绝对偏差 (MAD) | `MAD = (Σ |A_i - F_i|) / n` | 其中 `A[i]` 和 `F[i]` 分别代表原始图像和增强图像的像素值，`n` 代表总观测数。MAD 用于评估增强版图像中存在的标准误差。最优值对应数值越低质量越好。 |
| 4 | 相关系数 (CC) | `C_c = (Σ (x_i - x̄)(y_i - ȳ)) / (√(Σ (x_i - x̄)^2) * √(Σ (y_i - ȳ)^2))` | 其中 `x[i]`、`y[i]` 代表同源像素的灰度值。相关系数用于评估增强图像与原始图像之间的关系。`C[c] = 1` 表示相应图像绝对相似，为最佳值。`C[c] = 0` 表示两幅图像完全不相关。`C[c] = -1` 表示两幅图像完全负相关。 |
| 5 | 熵 | `Entropy = Σ p_i * log(p_i)` | 符号 `p[i]` 表示在不同强度值数量（8位图像为256）中具有强度 i 的像素。特定图像可获得的熵极值取决于现有灰度级的总数。 |
| 6 | 归一化最小二乘误差 (NLSE) | `NLSE = (ΣΣ (f(x,y) - r(x,y))^2) / (ΣΣ (r(x,y))^2)` | NLSE 用于指示图像增强版与原始图像之间的归一化差异。NLSE 值越小代表质量越好。 |
| 7 | 标准差 (SD) | `σ = √((1/N) * Σ (x_i - x̄)^2)` | 符号 `x[i]` 代表数据向量；均值用 `x̄` 表示。SD 用于表示图像增强版中的对比度。高质量图像具有较小的 SD 值。 |
| 8 | 平均绝对百分比误差 (MAPE) | `MAPE = (Σ |(A_t - F_t) / A_t| / n) * 100` | `n`：总观测数。高质量图像具有较小的 MAPE 值。 |

### 3.1 主观图像质量评估

主观图像质量评估是人类专家就图像性质提供观点的产物。但结果可能因人而异。在使用直方图的任意计算中，确定图像的准确性。直方图易于测量，且常适用于基于硬件的经济型实现，因此可有效用于图像增强目的。这使得直方图成为实时处理图像的常用方法。直方图是以图形形式表示图像的示意图，横坐标为 0–255 范围内的灰度值，纵坐标为频率。直方图按灰度级分为四个基本特征：亮、暗、高对比度 [[^(84)](#fn84)]

对于暗图像，直方图的分量集中在现有灰度级的低侧（即接近 0 值）。同理，亮图像直方图的元素偏向灰度级的高端。高对比度图像的直方图覆盖了灰度级的宽频谱。像素分布不太远离。高质量多见于高对比度图像。

### 3.2 客观图像质量评估

对于数学算法，执行客观计算。可以将客观图像质量度量 (IQM) 指标分为相应的三类：（i）全参考 (FR)；（ii）降低参考；以及（iii）无参考 [[^(85)](#fn85)]
