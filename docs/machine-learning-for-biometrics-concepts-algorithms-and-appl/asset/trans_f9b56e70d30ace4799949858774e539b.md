
其中 `c` 为常数；`s` 为输出图像；`r` 为像素值。因此，1 被应用于输入图像的每个像素。因为，如果输入图像的像素强度为 0，则 `log (0) = 无穷大`。负变换和对数变换获得低对比度直方图分量。由于直方图分量偏向灰度等级的中间，图像质量显得较差。幂律变换产生较暗的图像。

### 2.2：基于频域的增强

基于图像正交变换的操作称为频域技术 [^(75)](#fn75)

`G(m,n) = H(m,n) * F(m,n)`

![si13_e](images/B9780323852098000109/si13_e.png)  (5)

已知有四种频域图像增强方法，如下所示。

#### 2.2.1：高斯低通滤波器 (GLPF)

高斯低通滤波器的常见用途是消除噪声和平滑图像。在高斯低通滤波器中，频率系数不会被突然切断，而是采用更平滑的截止过程 [^(76)](#fn76)

`H(m,n) = e^(-D^2(m, n)/2D[0]^2)`

![si14_e](images/B9780323852098000109/si14_e.png)  (6)

#### 2.2.2：高斯高通滤波器 (GHPF)

下面给出的方程表示 GHPF 的传递函数。其定义如下：

`H(m,n) = 1 - e^(-D^2(m, n)/2D[0]^2)`

![si15_e](images/B9780323852098000109/si15_e.png)  (7)

#### 2.2.3：巴特沃斯低通滤波器 (BLPF)

BLPF 用于频域中的图像平滑。它去除数字图像中的高频噪声并保留低频分量。巴特沃斯滤波器是一种在通带区域频率响应平坦的滤波器。BLPF 的传递函数见公式 [(8)](#B9780323852098000109.xhtml#fo0045)。其定义如下：

$H\left( {m,n} \right) = \frac{1}{1 + \left\lbrack {D\left( {m,n} \right)/D_{0}} \right\rbrack^{2r}}$

![si16_e](images/B9780323852098000109/si16_e.png)  (8)

其中 `r` 代表阶数，`D[0]` 为具有截止频率的原点距离。

#### 2.2.4：巴特沃斯高通滤波器 (BHPF)

为了在频域中锐化图像，使用了 BHPF。锐化技术用于增强数字图像中的精细细节和突出边缘。此方法保留高频分量并去除输入图像的低频分量。BLPF 是 BHPF 的反向操作。BHPF 的传递函数见公式 [(9)](#B9780323852098000109.xhtml#fo0050)。其定义如下：

$H\left( {m,n} \right) = \frac{1}{1 + \left\lbrack {D_{0}/D\left( {m,n} \right)} \right\rbrack^{2r}}$

![si17_e](images/B9780323852098000109/si17_e.png)  (9)

### 2.3：图像复原

它通过减少噪声和恢复丢失的分辨率来改变图像的外观，有助于使用不同的图像校正方法更好地可视化图像 [^(77)](#fn77)

#### 2.3.1：中值滤波器 (MF)

MF 被称为一种非线性数字滤波方法。MF 用于从输入图像或信号中去除噪声。在 MF 中，特定像素被其邻域像素的中值所替代 [^(78)](#fn78)

#### 2.3.2：对比度受限自适应直方图均衡化 (CLAHE)

CLAHE 是自适应直方图均衡化的推广 [^(79)](#fn79)

#### 2.3.3：去相关拉伸 (DS)

DS 具有逐像素和线性的功能。此外，逐像素过程的特定因子取决于真实图像数据和目标图像数据对应值的对应值。向量 `a` 属于 `A`。`a` 表示 `A` 每个波段中给定的像素值。这里，`A` 是输入图像。然后，它被转换为像素 `b`，其中 `b` 对应输出图像 `B` 中的值。

`b = T * (a - m) + m_target`

![si18_e](images/B9780323852098000109/si18_e.png)  (10)

#### 2.3.4：二维自适应滤波器

自适应滤波器 [^(80)](#fn80)

`e2 = E{(f - f̂,)2}`

![si19_e](images/B9780323852098000109/si19_e.png)  (11)

#### 2.3.5：二维序统计滤波器

序统计滤波器 (OSF) 利用序统计的线性组合来估计数据的均值。长期以来，统计学家已将序统计滤波器视为估计器，但后来由 Bovik 等人重新命名并应用于图像处理问题的分析中 [^(81)](#fn81)

#### 2.3.6：调整后的图像

图像调整映射图像强度值。亮度调整被视为基本图像处理操作。期望的亮度变化被添加到每个颜色分量中。映射值使得 1% 的值在高和低输入图像强度处饱和。通过此过程增加输出图像的对比度。

## 3：统计度量

对于大多数图像处理应用，图像特征计算很重要，它是图像的一种特征，用于测试图像相对于理想或完美图像的感知退化。需要对增强图像的内容进行评估以及统计质量度量。指标可以是定性的，也可以是定量的。由于人眼视觉的局限性，通常使用定性测试来直观地增加图像的可解释性。

然而，在统计建模中，客观度量更受青睐。开发了许多图像质量度量来说明对增强图像进行质量评估的必要性。图片质量通过基于人眼观察的直方图，利用主观质量度量来衡量。使用定量质量度量的测量取决于数学标准。由于主观内容评估，图像质量的定量评估更受青睐。然而，它更耗时、繁琐、昂贵，且因人而异。

通过实施“图像质量度量”来评估多种图像增强技术的质量。图像质量评估分为两类：客观图像质量测量和主观图像质量测量。在主观质量测量中，图像质量通过取决于人眼观察的直方图来衡量。质量（客观）参数基于统计质量度量。主观内容计算是一个耗时、繁琐、昂贵、不适合实际应用且因人而异的过程。因此，有必要使用客观图像质量测量。七种与质量相关的度量指标用于计算客观图像质量 [^(82)](#fn82)

图像质量的不同参数集。

| 序号 | 图像质量度量 | 图像质量 |
| --- | --- | --- |
| 1 | 均方误差 (MSE) | 较低值代表较低质量 |
| 2 | 峰值信噪比 (PSNR) | 较高值代表较高质量 |
| 3 | 平均差值 (AD) | 较高值代表较低质量 |
| 4 | 归一化互相关 (NCC) | 范围在 1 内的得分值代表较高质量 |

| 7 | 最大差值 (MD) | 较高值代表较高质量 |
