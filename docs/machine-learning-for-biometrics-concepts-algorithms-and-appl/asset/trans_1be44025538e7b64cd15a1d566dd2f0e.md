
*   步骤 3：患者向移动设备输入其密码和生物特征哈希值。然后，移动设备计算 `h(PW∥R[U])` 并将其与 `P[1]` 进行验证。如果验证通过，移动设备检索 `A[2] = P[1] ⊕ P[2]`、`kp = PK[i] ⊕ A[2]`。然后，患者使用密钥 `kp` 从接收到的 `E[D]` 中检索 `M[D]`。接着，验证 `D[6]`。如果验证通过，患者信任来自医生的接收诊断报告 `M[D]`。然后，计算 `P[8] = h(M[D]∥PW∥SID[P])`。最后，将 `P[8]` 与相应的 `E[D]` 一起存储在 CS 中以备将来参考。

## 5: 安全分析

本节同时采用形式化安全分析和非形式化安全分析，证明我们提出的协议是安全的，并能抵御各种已知攻击。

### 5.1: 基于真实-随机模型的形式化安全分析

本节应用广泛接受的真实-随机（ROR）模型 [[261]](#fn261)，展示我们协议的形式化安全分析。

#### 5.1.1: 安全模型

本节描述 ROR 安全模型。根据该安全模型，定义了各种查询和预言机，如下所示：

*   **参与者**：设 `Π` 为所有参与者的集合，`D` 为所有医生的集合，`C` 为所有云服务器的集合，`H` 为所有医疗中心的集合。符号 `Π^i` 表示参与者 `Π` 的第 i 个实例。参与者的任何实例称为一个预言机。
*   **伙伴关系**：伙伴关系由参与通信的参与者的唯一会话 ID 表示。如果两个实例 `Π^i` 和 `Π^j` 在一个会话中拥有相同的会话 ID，则它们是伙伴关系。
*   **攻击者**：在该模型中，假设攻击者 `A` 在多项式时间内运行。`A` 完全控制网络，可以窃听、阻塞、篡改和重放消息。`A` 的能力由此处讨论的查询定义：
    *   **Execute(Π^i, Π^j)**：响应此查询时，攻击者 `A` 获取两个授权参与者 `Π^i` 和 `Π^j` 之间通信的所有消息。它模拟 `A` 的窃听攻击。
    *   **Send(Π^i, msg)**：通过此查询，`A` 可向授权参与者实例 `Π^i` 发送消息 `msg`，并从参与者接收相应的回复。它模拟重放攻击、冒充攻击和篡改攻击。
    *   **CorruptMD(P)**：通过此查询，攻击者 `A` 提取存储在患者移动设备中的信息。它模拟移动设备丢失攻击。
    *   **Test(Π^i)**：此查询表示参与者 `Π^i` 建立的会话密钥的语义安全性。`Π^i` 在此测试查询中的响应取决于一次无偏硬币翻转 `c` 的结果。`A` 不知道翻转结果 `c`。如果 `c = 1`，`Π^i` 向攻击者 `A` 返回实际会话密钥；否则如果 `c = 0`，`Π^i` 返回同一域中的一个随机数。
*   **Hash(x, k)**：哈希预言机表示哈希运算 `h()`，当查询输入 `x` 时提供输出 `k = h(x)`。当有人查询 `h(x)` 时，它在表 `(x, k)` 中搜索，如果 `x` 出现在表中则返回 `k`。否则，它返回一个均匀随机字符串 `k` 并将 `(x, k)` 插入表中。
*   **Biohash(x, k′)**：生物哈希预言机表示生物哈希运算 `h_Bio()`，对于输入 `x` 提供输出 `k′ = h_Bio(x)`。当有人查询 `h_Bio(x)` 时，如果 `x` 与阈值内的现有值匹配，则返回 `k′`。否则，它返回一个均匀随机字符串 `k′` 并将 `(x, k′)` 插入表中。

会话密钥的语义安全性：提供前面讨论的查询，攻击者 `A` 面临的挑战是确定翻转结果 `c` 的值，即会话密钥是真实的还是随机的。如果 `A` 成功区分真实密钥和随机密钥，则协议无法提供语义安全性。设 `Succ` 表示 `A` 获胜的事件，即正确区分真实密钥和随机密钥。`A` 破解协议 `P` 语义安全性的优势为 `Adv_P^(ake) = |2 ⋅ Pr[Succ] − 1|`。如果 `Adv_P^(ake)` 可忽略不计，则协议 `P` 在 ROR 模型中是安全的。

**定理 1。**

在随机预言机模型中，攻击者 `A` 在多项式时间 `t` 内针对我们的协议 `P` 发起攻击。设 `A` 执行 `q_h` 次哈希查询、`q_s` 次发送查询、`q_b` 次生物哈希查询和 `q_e` 次执行查询以破坏 `P`。则 `A` 破坏协议 `P` 安全性的优势如下：

```
Adv_P^ake(A) ≤ q_b^2 / H_1 + q_h^2 / H_2 + 2q_s / |D_1 ∥ D_2|
```

其中 `|H_1|`、`|H_2|`、`|D_1|` 和 `|D_2|` 分别表示生物哈希函数的值域空间、哈希函数的值域空间、均匀分布密码字典的大小和均匀分布生物特征模板的大小。

**证明。**

为证明定义了一系列从 `G_0` 到 `G_3` 的游戏。在每个游戏 `G_i` 中，攻击者 `A` 尝试预测 `c` 的正确值。设 `Succ_i` 表示该事件，`Pr[Succ_i]` 表示相应的概率。

*   **游戏 G_0**：它模拟攻击者 `A` 对我们协议 `P` 的实际攻击。最初，比特 `c` 随机选择。因此，根据定义我们有
    ```
    Adv_P^ake = 2 ⋅ Pr[Succ_0] - 1.
    ```
*   **游戏 G_1**：为了提高获胜优势，攻击者 `A` 使用 `Execute(Π^i, Π^j)` 查询发起窃听攻击。然后，在 `Test(Π^i)` 预言机中，`A` 必须确定 `c` 的值。由于 `SK` 由 `R_1` 和 `R_2` 计算得出，`A` 试图从 `M_1`、`M_2` 中检索 `R_1` 和 `R_2`。我们知道 `R_1 = P_5 ⊕ A_3`。因此，要提取 `R_1`，`A` 需要患者的密码和生物特征以及移动设备。没有 `R_1` 无法提取 `R_2`。因此，窃听攻击不会提高获胜优势，我们有
    ```
    Pr[Succ_1] = Pr[Succ_0].
    ```
*   **游戏 G_2**：在该游戏中，攻击者 `A` 试图借助 `Send()`、`Hash` 预言机和 `Biohash` 预言机误导参与者实例接受伪造消息。它考虑了 `P` 中可能出现的所有碰撞。由于每条消息都包含时间戳、随机数等随机因素，攻击者将无法找到任何碰撞。因此，根据生日悖论，我们得到
    ```
    |Pr[Succ_2] - Pr[Succ_1]| ≤ q_b^2 / (2|H_1|) + q_b^2 / (2|H_2|).
    ```
*   **游戏 G_3**：该游戏模拟与患者移动设备丢失相关的风险。通过查询 `CorruptMD()` 预言机，`A` 检索存储的凭证，如 `P_1`、`P_2`、`P_3`。然后，`A` 尝试猜测密码和生物特征哈希。由于密码字典和生物特征模板的大小分别为 `|D_1|` 和 `|D_2|`，我们有
    ```
    |Pr[Succ_3] - Pr[Succ_2]| ≤ q_s / (|D_1||D_2|).
    ```
