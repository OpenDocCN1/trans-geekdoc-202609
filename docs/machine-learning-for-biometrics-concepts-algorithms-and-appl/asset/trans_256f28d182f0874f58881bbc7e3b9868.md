### 5.2 实验设置

在所有实验中，从 UND-E 和 UND-J2 数据集的每个受试者中选取了三个样本。两个数据集均采用全对全测试策略，形成了三种可能的训练-测试集组合；即每次选择一个样本作为测试样本，其余两个样本用于训练。

在所有实验中，均使用三尺度六方向的 SPT 以获得更好的结果。在实验中，探索了 SPT 与特征描述符的三种不同组合，分别为 `SPT-LDP`、`STP-LPQ` 和 `SPT-BSIF`。最后，在特征层面或得分层面执行融合，以提高识别性能。

### 5.3 结果

所提方法的识别性能在单模态生物识别（使用耳部和侧脸）以及基于特征层面融合和得分层面融合的多模态生物识别方面进行了评估。在实验中，使用 `SPT-LDP`、`SPT-LPQ` 和 `SPT-BSIF` 特征提取器生成判别性特征向量。在实验中，通过卡方距离度量利用 `kNN` 分类器获得探针特征向量与图库特征向量的匹配，以实现个体识别。识别性能以准确率（Accuracy）和等错误率（EER）的百分比来衡量。单模态（耳部和侧脸）和多模态（特征层面融合和得分层面融合）生物识别在 UND-E 和 UND-J2 数据集上的性能结果如[表 1](#B9780323852098000031.xhtml#t0010)所示。

所提方法通过单独使用耳部和侧脸进行单模态身份识别，并通过特征层面融合和得分层面融合将两种模态结合用于多模态身份识别。[表 1](#B9780323852098000031.xhtml#t0010)中的高亮数值表示实验中准确率和 EER 方面的最佳结果。实验结果表明，在耳部生物识别中，分别在 UND-E 和 UND-J2 数据集上获得了准确率（97.73% 和 97.54%）和 EER（1.67% 和 2.45%）。在实验中，与各单一模态相比，将耳部模态与侧脸结合使用特征层面融合和得分层面融合可获得令人鼓舞的识别性能。此外，还观察到，与特征层面融合的准确率（98.47% 和 98.24%）及 EER（1.59% 和 1.75%）相比，所提方法使用得分层面融合在 UND-E 和 UND-J2 数据集上分别提供了显著更高的准确率（99.98% 和 99.97%）和 EER（0.01% 和 0.04%）。此外，在三种不同的特征提取器组合中，直方图描述符 `SPT-LPQ` 和 `SPT-BSIF` 的性能优于 `STP-LDP`，且基于 `SPT-BSIF` 特征描述符的所提方法优于所有其他特征描述符。所提识别方法在 UND-E 和 UND-J2 数据集上的 ROC 曲线分别如[图 5A 和 B](#B9780323852098000031.xhtml#f0030)所示。

### 5.4 与最先进方法的比较
